# 关于本站

## 这是什么

这是一个用 **Astro + Starlight** 搭建的个人知识库，用于记录学习笔记、技术文档和随笔。

## 为什么搭建

- **沉淀知识**：把散落在各处的笔记集中管理，方便回顾和检索
- **以教促学**：写下来的过程就是梳理和深化理解的过程
- **留下痕迹**：记录成长轨迹，回头看时能看到自己的进步

## 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | Astro 4.x |
| 主题 | Starlight |
| 数学公式 | KaTeX |
| 部署 | GitHub Pages |
| 写作格式 | Markdown / MDX |

## 如何更新

所有内容都在 `src/content/docs/` 目录下，按分类存放：

```
src/content/docs/
├── index.mdx        # 首页
├── textbooks/       # 教材专区
│   ├── ai/          # AI 教材
│   ├── modeling/    # 数学建模竞赛教材
│   └── chemistry/   # 高等化学教材
├── notes/           # 学习笔记
├── ai/              # AI 技术
├── coding/          # 编程笔记
└── essay/           # 随笔
```

新增一篇文章，只需要在对应目录下创建一个 `.md` 文件，写好 frontmatter 和正文，提交后自动部署。

## 数学公式支持

行内公式用 `$...$`，例如 $E = mc^2$。

块级公式用 `$$...$$`，例如：

$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$

矩阵、行列式、方程组等复杂公式也都支持。
