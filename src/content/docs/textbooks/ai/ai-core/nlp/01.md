# 第 1 章 文本与语言：从字符到句法

## 1.1 语言与文本：机器看见的是什么

### 1.1.1 语言的三个观察层级

语言学家把语言能力分成若干层级，NLP 也大致沿着这些层级组织任务：

- **形态层（morphology）**：词的构成，如英语 "unhappiness = un + happy + ness"，中文的构词法相对贫密；
- **句法层（syntax）**：词如何组成合法结构，如"我打了他"与"他打了我"语序不同、含义相反；
- **语义与语用层（semantics & pragmatics）**：结构与语境共同决定含义，如"苹果又降价了"中"苹果"指水果还是公司取决于语境。

NLP 的历史可以概括为：**从手工规则描述这些层级（1970s–1990s），到从数据中统计地学习它们（1990s–2013），再到用神经网络端到端地隐式学习它们（2013 至今）**。即便在今天，这些层级仍然是设计任务、诊断错误的心智地图。

### 1.1.2 文本的数字表示：码点与编码

给机器输入文本的第一步，是把字符变成数字。这里有一个初学者最容易忽略、工程上又极其常见的坑——**字符（character）不是一个字节，Unicode 才是现代 NLP 的事实标准**。

- **码点（code point）**：Unicode 给每个字符分配一个整数，记作 `U+XXXX`。例如 `A` 是 U+0041，`中` 是 U+4E2D，`é` 可以是一个码点 U+00E9，也可以拆成 `e`(U+0065) + 组合尖音符 U+0301 两个码点。
- **编码（encoding）**：把码点映射为字节序列的方案。UTF-8 是变长编码：ASCII 字符占 1 字节，中文常用字占 3 字节。**"字符数"与"字节数"是两个不同的数**——这直接影响截断、长度统计、正则匹配。

```python
# Unicode 基础：码点与 UTF-8 字节
s = "中A"
print(len(s))                          # 2（2 个字符）
print([hex(ord(c)) for c in s])        # ['0x4e2d', '0x41']（码点）
print(s.encode("utf-8"))               # b'\xe4\xb8\xadA'（3 + 1 = 4 字节）
```

在现代深度学习框架中，"词元（token）"才是模型的输入单位，而词元可能短于字符（如 BPE 的子词，见第 5 章）也可能长于字符。但无论上游如何设计，**一切混乱都始于对码点层的忽视**，这是 1.2 节的主题。

## 1.2 文本规范化与 Unicode 工程细节

**文本规范化（text normalization）**是把"表面不同、语义等价"的文本统一表示的过程。真实的网络文本充满：全角/半角混杂、大小写混杂、组合字符与预组合字符混用、数字与货币符号变体。做检索、匹配、语言模型统计时，不规范化会让词典规模虚增、统计被稀释。

Unicode 定义了四种标准规范化形式（Unicode Standard Annex #15）：

| 形式 | 含义 | 典型用途 |
|---|---|---|
| NFC | 组合（把 e + U+0301 合成 é） | 一般文本交换、互联网默认 |
| NFD | 分解（把 é 拆成 e + U+0301） | 需要按基础字符检索/排序 |
| NFKC | 兼容分解后再组合（ﬁ→fi，Ａ→A） | 搜索索引、跨系统比对 |
| NFKD | 兼容分解（ﬁ→f i） | 去除格式信息 |

```python
import unicodedata
s1 = "café"           # é 为预组合码点 U+00E9
s2 = "cafe\u0301"     # 'e' + 组合尖音符 U+0301
print(s1 == s2)                                        # False！肉眼无法区分
print(unicodedata.normalize("NFC", s2) == s1)          # True：NFC 后相等
print([hex(ord(c)) for c in unicodedata.normalize("NFD", s1)])
# ['0x63', '0x61', '0x66', '0x65', '0x301']
print(unicodedata.normalize("NFKC", "ﬁ") == "fi")      # True：连字被展开
print(unicodedata.normalize("NFKC", "１２３４５") == "12345")  # True：全角→半角
```

（预期输出已写在注释中。）

中文场景的常见规范化流水线（顺序很重要）：

1. NFKC 规范化（统一全角/半角、展开连字与单位符号）；
2. 统一或移除不可见字符（零宽空格 U+200B、BOM U+FEFF）；
3. 大小写折叠（英文；`str.casefold()` 比 `lower()` 更激进，德语 ß→ss）；
4. 按任务决定是否去标点、繁简转换（繁简不是 Unicode 问题，需要映射表）。

**工程警示**：规范化的选择应当写入项目文档并在全链路一致。一个真实事故模式是：训练语料做了 NFKC，而线上输入只做了 NFC，导致模型对"全角问号"的输入行为异常。

## 1.3 分词：把连续文本切成单位

### 1.3.1 英文分词

英文有天然的空格边界，但仍需处理：缩写（don't → do / n't）、连字符（state-of-the-art）、数字（3.14）、URL 与表情。标准工具如 NLTK 的 Treebank 分词器内置了数十条规则。**关键意识：分词器本身是一个有偏统计模型**——Treebank 风格会把 "don't" 拆成 "do" 和 "n't"，这个决定会影响下游所有词频统计。

### 1.3.2 中文分词：无空格的难题

中文词与词之间没有空格：「自然语言处理」可以切成「自然 / 语言 / 处理」也可以切成「自然语言 / 处理」，且**没有唯一正确答案**（分词标准之争持续了几十年）。经典统计方法将分词视为**序列中最优切分路径的搜索问题**：

- **最大匹配法（Maximum Matching）**：贪心词典法。正向最大匹配从左往右每次取出词典中最长的可匹配词。
- **基于语言模型的切分**：枚举切分路径 $S$，选择使 $p(S)$ 最大的路径，其中路径概率可以用 1.4 节的 n-gram 估计。这一视角把"分词"统一进"语言模型"框架，也预示了第 5 章子词分词器（BPE 同样是在词表约束下寻找高概率切分）的思想。
- **统计学习法**：把分词当作逐字标注任务（B/M/E/S 四标签），这正是第 3 章序列标注框架的应用之一。

### 1.3.3 最大匹配算法实现

```python
# 正向最大匹配中文分词（纯 Python，无依赖）
def forward_max_match(text, lexicon, max_len=4):
    words, i = [], 0
    while i < len(text):
        matched = None
        for L in range(min(max_len, len(text) - i), 0, -1):  # 从最长候选往回试
            cand = text[i:i + L]
            if cand in lexicon:
                matched = cand; break
        words.append(matched if matched else text[i])        # 单字兜底
        i += len(words[-1])
    return words

lexicon = {"自然", "自然语言", "语言", "处理", "研究", "研究生", "生命", "起源"}
print(forward_max_match("研究生命起源", lexicon))
# ['研究', '生命', '起源'] —— 注意：正向最大匹配给出的并非唯一合理解
print(forward_max_match("自然语言处理", lexicon))
# ['自然语言', '处理']
```

**歧义案例**「研究生命起源」：正向最大匹配输出「研究 / 生命 / 起源」，但「研究生 / 命 / 起源」在词面上也成立——这是**交集型歧义**。处理歧义需要概率信息（哪种切分更常见）甚至上下文，这正是统计与神经方法的用武之地。

## 1.4 n-gram 语言模型与困惑度

语言模型（language model, LM）回答一个问题：**一个句子出现的概率是多少？** 它是第 4 章 Seq2Seq、第 5 章 GPT 的概念雏形，也是最早的成功范式。

### 1.4.1 从链式法则到马尔可夫假设

给定词序列 $w_{1:n} = w_1 w_2 \cdots w_n$，由概率链式法则（《概率论·第 1 章》）：

$$
p(w_{1:n}) = p(w_1)\, p(w_2 \mid w_1)\, p(w_3 \mid w_{1:2}) \cdots p(w_n \mid w_{1:n-1}) = \prod_{t=1}^{n} p(w_t \mid w_{1:t-1}).
$$

这个恒等式精确但无法估计：条件历史 $w_{1:t-1}$ 的组合数随长度指数爆炸。**马尔可夫假设（Markov assumption）**将条件历史截断为前 $k$ 个词：

$$
p(w_t \mid w_{1:t-1}) \approx p(w_t \mid w_{t-k:t-1}).
$$

$k=1$ 时称为 **bigram 模型**（前 1 个词 + 当前词共 2 个词），$k=2$ 称为 **trigram 模型**。参数由最大似然估计（相对频率）给出：

$$
p(w_t \mid w_{t-1}) = \frac{c(w_{t-1}, w_t)}{c(w_{t-1})},
$$

其中 $c(\cdot)$ 为语料中的计数。为统一处理句首句尾，惯例在每句前后加特殊符号 `<s>` 与 `</s>`。

### 1.4.2 数据稀疏与平滑：概率质量守恒

MLE 有致命缺陷：任何未在训练语料中同现的 bigram 概率为 0，进而整句概率为 0。而语言的组合性决定了**测试集中必然出现训练中未见过的组合**（比如每个词都常见、但组合新颖的句子）。**平滑（smoothing）**从高概率事件身上"匀"一点概率质量给未见过的事件，保持概率总和为 1（概率质量守恒）。

**(1) 拉普拉斯平滑（Laplace / add-one）**：

$$
p_{\text{Lap}}(w_t \mid w_{t-1}) = \frac{c(w_{t-1}, w_t) + 1}{c(w_{t-1}) + V},
$$

其中 $V$ 为词表大小。它保证 $\sum_{w} p(w_t \mid w_{t-1}) = 1$（分母把 $V$ 个词各加的 1 恰好补齐），但 +1 幅度太大，对大词表效果很差，现代几乎不用，但它是理解其他平滑的原型。

**(2) Add-$k$ 平滑**：把加 1 换成加 $\delta \in (0,1)$：

$$
p_{\text{add-}k}(w_t \mid w_{t-1}) = \frac{c(w_{t-1}, w_t) + \delta}{c(w_{t-1}) + \delta V}.
$$

**(3) 插值（interpolation，Jelinek–Mercer）**：把低阶与高阶模型线性混合：

$$
p_{\text{int}}(w_t \mid w_{t-2}, w_{t-1}) = \lambda_3\, p_{\text{MLE}}(w_t \mid w_{t-2}, w_{t-1}) + \lambda_2\, p_{\text{MLE}}(w_t \mid w_{t-1}) + \lambda_1\, p_{\text{MLE}}(w_t),
$$

$\lambda_i \ge 0$、$\sum \lambda_i = 1$，可在留出集上优化。直觉：**高阶模型记性更好但容易过拟合，低阶模型更稳但更粗糙；根据证据强度动态加权**。

**(4) 回退（backoff，Katz 平滑思想）**：高阶计数存在就用高阶（并打折匀出概率质量）；高阶计数为零则"回退"到低阶。折扣率常用 Good–Turing 估计 $d = \frac{c^*}{c}$（$c^*$ 为调整后计数）。Kneser–Ney 平滑进一步改进低阶项：一个词 $w$ 作为"接续"的能力不应看它出现了多少次，而应看**有多少种不同的前驱**（$|\{w': c(w', w) > 0\}|$）——"Francisco" 在 "San" 后出现极多，但作为任意位置的接续词并不通用。Kneser–Ney 是 n-gram 时代的最强平滑，也是现代子词/神经 LM 时代之前困惑度的标杆。

### 1.4.3 困惑度的严格定义与推导

如何给语言模型打分？给定测试集 $W = w_1 w_2 \cdots w_N$（$N$ 个词），模型 $p$ 对它的对数似然为 $\log p(W) = \sum_{t=1}^{N} \log p(w_t \mid \text{history})$。定义**平均每词交叉熵**（以自然对数计，单位 nats）：

$$
H(p, q) = -\frac{1}{N} \log q(w_{1:N}).
$$

由《信息论》与《概率论·第 2 章》的知识，当测试数据真实分布为 $p$ 时，交叉熵 $H(p,q) \ge H(p)$，等号当且仅当 $q = p$；交叉熵越低，模型对测试数据的压缩能力越强。

**困惑度（perplexity, PP）就是交叉熵的指数化**：

$$
\mathrm{PP}(q) \;=\; \exp\!\big(H(p,q)\big) \;=\; q(w_{1:N})^{-1/N} \;=\; \left(\prod_{t=1}^{N} q(w_t \mid \text{history}_t)\right)^{-1/N}.
$$

第二、三个等号把定义写成两种常用形式：整句概率的 $N$ 次几何平均倒数，以及每词平均负对数似然的指数。**直观解读**：困惑度 ≈ "模型在每个位置上认为等可能的有效候选词数"。均匀分布于 $V$ 个词的模型困惑度为 $V$；完美模型困惑度趋于 1。

推导中要注意两个细节（初学者最常错）：

1. **$N$ 的口径**：是"被预测的词数"，通常不把句首 `<s>` 计入 $N$，但句尾 `</s>` 要计入（它也是被预测的对象）。跨句评测时按句子拼接统计。
2. **对数底数**：以 2 为底时交叉熵单位是比特，$\mathrm{PP} = 2^{H}$；以 e 为底时单位是 nats，$\mathrm{PP} = e^{H}$。两者只差常数倍，比较模型时必须统一口径。

## 1.5 词性标注与句法分析概览

### 1.5.1 词性标注

**词性标注（part-of-speech tagging）**给句中每个词分配词类标签（名词/动词/形容词……），是许多下游流水线的第一步。它本质是**序列到等长序列**的标注问题，两大经典解法将在第 3 章详述：

- **生成式**：隐马尔可夫模型（HMM），建模 $p(w_{1:n}, t_{1:n})$，用维特比算法（Viterbi，动态规划）求最优标签序列；
- **判别式**：条件随机场（CRF），直接建模 $p(t_{1:n} \mid w_{1:n})$，可融合任意重叠特征。

词性歧义是核心难点："研究"可以是名词也可以是动词（「研究生命」vs「生命研究」），判断依赖上下文——这正是统计方法优于词典方法的原因。NN 系统时代，词性标注通常作为预训练模型的一个 token 分类头出现（第 5 章）。

### 1.5.2 句法分析

**句法分析（parsing）**揭示词与词之间的结构关系，两大表示传统：

- **短语结构语法（constituency / phrase-structure）**：句子由名词短语、动词短语等递归组成，产生式规则形如 $S \to NP\ VP$。上下文无关文法（CFG）的 CKY 算法用动态规划在 $O(n^3)$ 时间内求最优树（《数据结构与算法·第 6 章》区间 DP 思想的经典应用）。
- **依存句法（dependency parsing）**：以"词—词"二元依存关系（主谓、动宾、修饰）表示结构，如「猫/追/老鼠」中"追"是根，"猫"作主语依存于"追"，"老鼠"作宾语。转移基依存分析器把解析变成"状态—动作"序列决策问题，与第 7 章 Agent 的动作规划在形式上同构。

理解句法的价值即使在大模型时代也没有消失：它提供**诊断语言**（模型到底学没学到主谓一致、长距离依存？）、**探针实验**（probing，用简单分类器从词向量中解码句法信息）与**结构化约束**（解析树作为归纳偏置注入模型）的工具。

## 1.6 编辑距离与拼写纠错

### 1.6.1 定义与动态规划解法

**编辑距离（edit distance / Levenshtein distance）**：把字符串 $a$ 变成 $b$ 所需的最少单字符编辑操作次数，操作为插入、删除、替换（各计 1）。它是《数据结构与算法·第 6 章》动态规划思想的直接应用：设 $D[i][j]$ 为 $a$ 的前 $i$ 个字符变成 $b$ 的前 $j$ 个字符的最少操作数：

$$
D[i][j] = \begin{cases}
i, & j = 0 \\
j, & i = 0 \\
\min\begin{cases} D[i-1][j] + 1 \\ D[i][j-1] + 1 \\ D[i-1][j-1] + \mathbb{1}[a_i \ne b_j] \end{cases} & \text{otherwise}
\end{cases}
$$

三个分支分别对应"删 $a_i$"、"插 $b_j$"、"替换/匹配 $a_i$ 与 $b_j$"。答案为 $D[m][n]$，时间与空间复杂度均为 $O(mn)$（空间可滚动数组优化到 $O(\min(m,n))$）。

### 1.6.2 应用：拼写纠错

拼写纠错的经典两段式：**(1) 候选生成**——枚举编辑距离 ≤ 2 的词（或用字符 n-gram 索引倒排加速）；**(2) 候选排序**——按噪声信道模型（noisy channel）选使 $p(\text{输入} \mid \text{候选})\, p(\text{候选})$ 最大的候选，前者是混淆集（confusion set）上的错误概率，后者正是 1.4 节的语言模型。**语言模型 + 信道模型的两段式思维**会反复出现：机器翻译（第 4 章）、语音识别都是它的后代。

## 1.7 关键公式速查

| 公式 | 名称 | 适用条件 |
|---|---|---|
| $p(w_{1:n}) = \prod_t p(w_t \mid w_{1:t-1})$ | 链式法则 | 精确恒等式 |
| $p(w_t \mid w_{1:t-1}) \approx p(w_t \mid w_{t-k:t-1})$ | 马尔可夫假设 | n-gram 近似 |
| $p(w_t \mid w_{t-1}) = c(w_{t-1},w_t)/c(w_{t-1})$ | bigram MLE | 计数非零 |
| $p = \dfrac{c + \delta}{c_{\text{ctx}} + \delta V}$ | Add-$\delta$ 平滑 | $\delta>0$，概率质量守恒 |
| $p_{\text{int}} = \sum_i \lambda_i\, p_{\text{MLE}}^{(i)}$ | 插值平滑 | $\lambda_i \ge 0,\ \sum \lambda_i = 1$ |
| $\mathrm{PP} = q(w_{1:N})^{-1/N} = \exp\!\big(-\tfrac{1}{N}\log q(w_{1:N})\big)$ | 困惑度 | $N$ 为被预测词数（含 `</s>` 不含 `<s>`） |
| $D[i][j] = \min(D[i-1][j]{+}1,\ D[i][j-1]{+}1,\ D[i-1][j-1]{+}\mathbb{1}[a_i{\ne}b_j])$ | 编辑距离 DP | 单字符插入/删除/替换等价代价 |

## 1.8 示例与案例

### 示例 1（手算）：bigram 困惑度

设测试句为 `I love NLP </s>`（含句尾符，不含 `<s>`，$N = 4$），某 bigram 模型给出 $p(\text{I}\mid\text{<s>}) = 1.0$，$p(\text{love}\mid\text{I}) = 0.5$，$p(\text{NLP}\mid\text{love}) = 0.5$，$p(\text{</s>}\mid\text{NLP}) = 1.0$。则

$$
\mathrm{PP} = (1.0 \times 0.5 \times 0.5 \times 1.0)^{-1/4} = 0.25^{-1/4} = \sqrt{2} \approx 1.4142.
$$

交叉熵为 $\frac{1}{4}\ln 4 = \ln 2 \approx 0.6931$ nats。验算提示：每次条件概率均为 $2^{-1}$ 的情形下，$\mathrm{PP} = 2^{H}$ 恰好等于几何平均。

### 示例 2（手算）：编辑距离矩阵

求 `kitten → sitting` 的编辑距离。$D$ 的前两行为：

```
        ""  s  i  t  t  i  n  g
    ""   0  1  2  3  4  5  6  7
    k    1  1  2  3  4  5  6  7
    i    2  2  1  2  3  4  5  6
    ...
```

按 DP 递推填满矩阵，得 $D[6][7] = 3$：k→s（替换）、e→i（替换）、插入 g。程序验证见下方代码。

### 示例 3（代码）：从零实现 bigram 语言模型与困惑度

```python
# 纯 Python，无第三方依赖
import math
from collections import Counter

train = "the cat sat on the mat the dog ate the fish the cat saw the dog".split()
train = ["<s>"] + train + ["</s>"]

def ngrams(tokens, n):
    return [tuple(tokens[i:i + n]) for i in range(len(tokens) - n + 1)]

uni, bi = Counter(train), Counter(ngrams(train, 2))
V = len(uni)

def bigram_prob(w1, w2, k=1.0):          # Add-k 平滑
    return (bi[(w1, w2)] + k) / (uni[w1] + k * V)

def perplexity(tokens, k=1.0):
    toks = ["<s>"] + tokens + ["</s>"]
    N = len(toks) - 1                     # 被预测词数：含 </s>，不含 <s>
    ll = sum(math.log(bigram_prob(toks[i], toks[i + 1], k)) for i in range(N))
    return math.exp(-ll / N), -ll / N     # (困惑度, 每词交叉熵 nats)

print("V =", V)                                  # V = 11
print("P(cat|the)  = %.4f" % bigram_prob("the", "cat"))    # 0.1765 (3/17)
print("P(fish|the) = %.4f" % bigram_prob("the", "fish"))   # 0.1176 (2/17)
print("P(the|the)  = %.4f" % bigram_prob("the", "the"))    # 0.0588 (1/17)
test = ["the", "cat", "sat", "on", "the", "mat"]
print("PP (k=1)   = %.4f" % perplexity(test, k=1.0)[0])    # 6.9853
print("PP (k=0.5) = %.4f" % perplexity(test, k=0.5)[0])    # 5.6619
print("PP (k=0.1) = %.4f" % perplexity(test, k=0.1)[0])    # 3.6711
print("PP (k=1, OOV) = %.4f" % perplexity(["the","unicorn","sat"], k=1.0)[0])  # 10.7719
try:
    perplexity(["the", "cat", "barked"], k=0.0)   # “the cat”未曾同现
except ValueError:
    print("k=0 时未见 bigram -> log(0) -> ValueError")
```

注意两个教学点：(1) **$k$ 越小，测试句困惑度越低**——因为测试句的 bigram 恰好都见过，说明困惑度可以被"过拟合"骗过，评测必须用独立测试集并固定 $k$（或用留出集调 $k$）；(2) $k=0$ 时未见的 bigram 会使对数似然爆炸，这就是平滑存在的意义。

### 示例 4（代码）：编辑距离（完整 DP，可打印矩阵）

```python
def edit_distance(a, b, return_table=False):
    m, n = len(a), len(b)
    D = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1): D[i][0] = i          # 全部删除
    for j in range(n + 1): D[0][j] = j          # 全部插入
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            D[i][j] = min(D[i-1][j] + 1,                          # 删除 a[i-1]
                          D[i][j-1] + 1,                          # 插入 b[j-1]
                          D[i-1][j-1] + (a[i-1] != b[j-1]))       # 替换或匹配
    return (D[m][n], D) if return_table else D[m][n]

print(edit_distance("kitten", "sitting"))  # 3
print(edit_distance("flaw", "lawn"))       # 2
print(edit_distance("中文", "中文标点"))     # 2（插入两个字符）
```

## 1.9 常见误区与陷阱

1. **把字节数当字符数。** Python 3 的 `str` 以码点计数，但读入文件若用 `errors='ignore'` 或错误编码（GBK vs UTF-8）会静默损坏文本。读文件永远显式 `encoding='utf-8'`，入模前统一规范化（1.2 节）。
2. **困惑度跨词表/跨分词器直接比较没有意义。** 字符级、BPE 子词级、词级模型的困惑度对应不同单位，数值不可比；即便同一词表，$N$ 是否含 `</s>` 也会造成系统性偏差。比较时必须"同一测试集、同一分词口径、同一对数底"。
3. **用平滑系数"刷低"困惑度。** 如示例 3 所示，$k\to 0$ 会让见过的组合显得极好、未见组合概率归零；正确的做法是用开发集选择 $k$ 或使用插值/Kneser–Ney。
4. **以为英文分词"就是按空格切"。** `don't`、`New York`、`3.14`、URL 的处理没有标准答案；换分词器会改变所有下游统计，实验中分词器应与模型配置一起作为固定的一部分报告。
5. **认为分词结果唯一正确。** 中文「研究生命起源」示例表明分词是标准依赖的；评测分词质量需要金标准语料，且不同金标准（PKU/MSR/CTB）之间本就冲突。
