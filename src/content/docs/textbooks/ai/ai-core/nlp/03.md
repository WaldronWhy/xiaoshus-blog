# 第 3 章 序列标注与经典任务

> **本章定位**：结构化预测（structured prediction）的代表章。前置于第 1 章（词性/分词的任务定义）、第 2 章（词向量作为输入特征）、《机器学习·第 5 章》（概率模型与 EM）与《数据结构与算法·第 6 章》（动态规划）；本章的前向/维特比递归在概念上通向第 4 章 Seq2Seq 解码，条件随机场的"全局归一"思想是理解第 5 章自回归分解的对照面。

## 3.0 本章学习目标

学完本章后，你能够：

1. 用 BIO/BIOES 标注体系把命名实体识别（NER）等形式化任务转成序列标注问题，并解释标注体系选择对边界错误的影响；
2. 写出 HMM 的定义，说清三大问题（评估/解码/学习）各自求解什么，并完整推导前向算法及其 $O(TN^2)$ 复杂度；
3. 实现维特比算法（Viterbi）并对 HMM 给出最优标签路径；
4. 写出线性链 CRF 的条件分布与对数似然，用前向递归计算配分函数，并从判别式/生成式、局部归一/全局归一两个维度对比 HMM 与 CRF（含标注偏置问题 label bias）；
5. 搭建一个完整的 NER 流水线（特征→模型→实体级 P/R/F1 评测），并对典型错误类型做系统分析。

## 3.1 任务定义与 BIO 标注体系

### 3.1.1 什么是序列标注

**序列标注（sequence labeling）**：给定输入词序列 $w_{1:n}$，输出等长的标签序列 $y_{1:n}$。除 NER 外，同构任务包括词性标注（第 1 章）、中文分词（第 1 章的 B/M/E/S 视角）、浅层组块分析（chunking）、拼写与错字检测。其难点在于**输出空间随输入长度指数增长**：若标签集大小 $N$，可能的标签序列有 $N^n$ 个——穷举不可行，必须有动态规划或贪心结构。

### 3.1.2 BIO 与 BIOES

**命名实体识别（Named Entity Recognition, NER）**要找出文本中人名（PER）、地名（LOC）、组织（ORG）、时间等实体的**确切边界与类型**。仅给每个词打"是否实体"标签无法表达边界，于是有了把边界信息编码进标签的体系：

- **BIO**：`B-X`（X 类实体的起始词）、`I-X`（X 类实体的延续词）、`O`（非实体）。约束：`I-X` 必须跟在 `B-X` 或 `I-X` 之后。
- **BIOES**：增加 `E-X`（实体结束词）与 `S-X`（单词实体）。它把"实体恰好到哪结束"显式写进标签，能区分「上海」（B-LOC E-LOC）与「上海大学」（B-ORG I-ORG），对边界错误的定位更细。

例：句子「张三 在 北京 大学 读书」，BIO 标注为：

```
张三/B-PER  在/O  北京/B-LOC  大学/I-LOC  读书/O
```

以 BIO 输出还原实体时，一条 `I-X` 出现在非 `X` 上下文（如 `O I-LOC`）是非法序列，工程上通常"宽容降级"为从该处开一个新实体——评测与部署代码必须显式规定这个策略，否则复现结果对不上（见 3.5 节错误分析与练习 7）。

## 3.2 隐马尔可夫模型（HMM）

### 3.2.1 定义与两大假设

**隐马尔可夫模型（Hidden Markov Model, HMM）**是生成式序列模型：假设标签（隐状态）序列是一条马尔可夫链，每个标签随机生成一个观测词。参数为：

- 初始分布 $\pi_i = p(y_1 = i)$；
- 转移矩阵 $A_{ij} = p(y_t = j \mid y_{t-1} = i)$（**一阶马尔可夫假设**：当前标签只依赖前一个标签）；
- 发射矩阵 $B_i(w) = p(w_t = w \mid y_t = i)$（**输出独立性假设**：当前词只依赖当前标签，条件独立于其余一切）。

联合分布：

$$
p(w_{1:n}, y_{1:n}) = \prod_{t=1}^{n} p(y_t \mid y_{t-1})\, p(w_t \mid y_t), \qquad p(y_0) \equiv \pi.
$$

参数由带标注语料的相对频率估计（如 $A_{ij} = c(i,j)/\sum_{j'} c(i,j')$；发射概率需对低频词平滑，常用做法是把部分概率质量分给未见词的 `<UNK>`）。

### 3.2.2 三大问题

HMM 的经典框架围绕三个问题展开：

1. **评估问题（likelihood）**：给定模型 $\lambda = (A, B, \pi)$，计算观测概率 $p(w_{1:n} \mid \lambda)$；
2. **解码问题（decoding）**：找最可能的标签序列 $\hat{y} = \arg\max_y p(y \mid w_{1:n})$；
3. **学习问题（learning）**：仅给观测序列时估计参数（Baum–Welch / EM，《机器学习·第 5 章》）。

三者的解法共享同一套递归结构，评估问题的**前向算法**是最核心的推导，下面完整展开。

### 3.2.3 前向算法：完整推导

直接计算 $p(w_{1:n}) = \sum_{y_{1:n}} \prod_t A_{y_{t-1} y_t} B_{y_t}(w_t)$ 要枚举 $N^n$ 条路径——指数复杂度。关键是定义**前向变量**并找到递归。

**定义**：$\alpha_t(i) = p(w_{1:t},\ y_t = i)$——"看到前 $t$ 个词、且第 $t$ 个标签为 $i$"的联合概率。

**初始化**（$t=1$）：$\alpha_1(i) = \pi_i\, B_i(w_1)$。依据：输出独立性假设，$\pi_i$ 乘发射概率。

**递归**（$t > 1$）：

$$
\alpha_t(j) = \Big( \sum_{i=1}^{N} \alpha_{t-1}(i)\, A_{ij} \Big) B_j(w_t).
$$

**推导依据（两步都不跳）**：

$$
\alpha_t(j) = p(w_{1:t}, y_t = j) = p(w_t \mid w_{1:t-1}, y_t = j)\, p(w_{1:t-1}, y_t = j)
$$

第一步用条件概率定义。由输出独立性假设，$p(w_t \mid w_{1:t-1}, y_t = j) = B_j(w_t)$。第二步对 $y_{t-1}$ 全概率展开：

$$
p(w_{1:t-1}, y_t = j) = \sum_{i} p(y_t = j \mid y_{t-1} = i,\ w_{1:t-1})\, p(w_{1:t-1}, y_{t-1} = i).
$$

由一阶马尔可夫假设，$p(y_t = j \mid y_{t-1}=i, w_{1:t-1}) = A_{ij}$，而第二个因子恰是 $\alpha_{t-1}(i)$。合并即得递归式。

**终止**：$p(w_{1:n} \mid \lambda) = \sum_i \alpha_n(i)$。

**复杂度**：每个时刻对每个状态 $j$ 求和 $N$ 项，共 $T$ 个时刻，$O(TN^2)$（对比枚举的 $O(N^n)$）；空间 $O(N)$（滚动数组）。这与《数据结构与算法·第 6 章》"把指数问题压成多项式"的 DP 哲学完全同构：$\alpha_t(j)$ 就是"以 $j$ 结尾的最优/全体子问题"缓存。

### 3.2.4 解码：维特比算法

把前向算法中的**求和换成取最大**，就得到维特比算法：定义 $\delta_t(j) = \max_{y_{1:t-1}} p(y_{1:t-1}, y_t = j, w_{1:t})$，递归

$$
\delta_t(j) = \max_i \big( \delta_{t-1}(i) A_{ij} \big) B_j(w_t),
$$

同时用回溯指针 $\psi_t(j) = \arg\max_i \delta_{t-1}(i) A_{ij}$ 记录每步的最优前驱，终点取 $\arg\max_j \delta_n(j)$ 后沿指针回溯。复杂度同 $O(TN^2)$。注意维特比求的是**联合最优** $\max p(w, y)$，与"逐词最大发射概率"不同——后者可能拼出非法转移；这正是"结构化"预测的含义：**决策是全局的，不是逐位独立的**。

（细节提示：实现时应在 log 空间计算，把乘法变加法、避免下溢——这是《线性代数·第 6 章》数值稳定性原则的直接应用。）

### 3.2.5 学习：Baum–Welch 与 HMM 的边界

仅给定观测序列时，参数用 Baum–Welch（即 EM 算法在 HMM 上的实例，见《机器学习·第 5 章》）交替估计：E 步用前向-后向算法计算每个时刻处于/转移到各状态的后验期望，M 步按期望计数重新归一化参数。HMM 用于词性标注/NER 时若**有标注语料**，通常直接监督训练并只保留维特比；无标注时 EM 才登场。HMM 的两大假设（一阶转移、输出独立）限制了特征表达——它无法使用"上一个词是小写""当前词以大写开头"这类丰富的观测特征，这一局限正是 CRF 兴起的直接原因。

## 3.3 条件随机场（CRF）

### 3.3.1 从生成式到判别式

**条件随机场（Conditional Random Field, CRF）**直接建模条件分布 $p(y \mid w)$，不再对 $p(w)$ 做任何假设。**线性链 CRF（linear-chain CRF）**定义：

$$
p_\theta(y \mid w) = \frac{1}{Z(w)} \exp\Big( \sum_{t=1}^{n} \theta^\top f\big(w, t, y_{t-1}, y_t\big) \Big),
$$

其中 $f$ 是**特征函数**向量（可包含任意重叠特征：当前词本身、大小写、前后缀、前一词词性、当前转移对 $(y_{t-1}, y_t)$ 等），$Z(w) = \sum_{y'} \exp(\sum_t \theta^\top f(w, t, y'_{t-1}, y'_t))$ 为配分函数，对所有标签序列求和——同样是 $O(TN^2)$ 的前向递归可算（把 3.2.3 的概率换成 exp-分数即可，见 3.7 示例代码）。

对数似然（单个样本）为：

$$
\log p_\theta(y \mid w) = \theta^\top f(w, y) - \log Z(w),
$$

梯度为"观测特征期望 − 模型边缘分布期望"：

$$
\frac{\partial \log p_\theta(y \mid w)}{\partial \theta} = f(w, y) - \mathbb{E}_{y' \sim p_\theta(\cdot \mid w)}[f(w, y')],
$$

其中模型期望里的边缘概率由前向-后向算法高效计算。梯度形式正是《机器学习·第 7 章》指数族模型的"充分统计量之差"，训练用 L-BFGS 或带 L2 正则的 SGD（《最优化·第 3、5 章》）。

### 3.3.2 CRF 与 HMM 的系统对比

| 维度 | HMM | 线性链 CRF |
|---|---|---|
| 建模对象 | 联合 $p(w, y)$（生成式） | 条件 $p(y \mid w)$（判别式） |
| 特征 | 只能用"标签→词"发射与标签转移 | 任意重叠、任意上下文特征 |
| 归一化 | 每步发射概率局部归一 | 整条序列全局归一（$Z(w)$） |
| 解码/推断 | 维特比 $O(TN^2)$ | 维特比 $O(TN^2)$（结构相同） |
| 训练 | 频率计数 / EM（Baum–Welch） | 极大化条件对数似然（凸，带正则） |
| 弱点 | 表达力受两大假设限制 | 需标注数据；每步都要算 $Z(w)$ |

**标注偏置问题（label bias）**：HMM 与"每状态局部归一"的最大熵马尔可夫模型（MEMM）存在系统性偏好：若某状态发出的转移概率集中于少数出口（甚至只有一条），局部归一化会把这一"别无选择"当作高概率传递下去，削弱对观测的重视。CRF 全局归一，配分函数在序列层面竞争，**不存在这一偏置**——这是 Lafferty et al.（2001）提出 CRF 的核心动机之一。

**另一层关系（生成式可视为判别式的特例）**：若把 CRF 的特征限制为 HMM 的对数转移/对数发射，CRF 参数取 HMM 参数的对数，则 CRF 表达的 $p(y \mid w)$ 与 HMM 推出的完全一致。可见 CRF 是 HMM 的严格泛化。

### 3.3.3 神经时代的定位

2015 年前后的事实标准是 **BiLSTM/BERT 编码器 + CRF 输出层**：神经网络给出每步的发射分数 $S_t(y) = \theta^\top f(t, y, w)$，CRF 层在其上加转移分数 $A_{ij}$ 并负责全局归一——即把 3.3.1 的特征函数换成学习到的表示。**CRF 层的价值**：显式建模 `I-X` 不能接在 `O` 后这类结构约束，输出合法序列；其训练目标（条件对数似然）与解码目标（维特比）在同一分数体系内，推理与训练一致。这一"神经网络打分 + 结构化归一"的混合范式是结构化预测的当代形态，也是理解第 5 章"自回归 + softmax"（局部逐步归一）的绝佳对照：**全局归一与自回归是序列概率模型的两大归一哲学**。

## 3.4 NER 完整流水线

### 3.4.1 流水线设计

一个经典 NER 系统由五段组成：

1. **数据与标注**：CoNLL-2003 格式（每行 `token gold_tag`，空行分句）；标注一致性需要双标+仲裁（实体边界不一致是标注噪声的最大来源）。
2. **特征工程**（CRF 时代核心，神经时代退居二线）：当前词及其小写形式、是否大写/数字、前后缀（前 3/后 3 字符）、上下文窗口词、 gazetteer（词典）匹配等。
3. **模型**：CRF（本章）或 BiLSTM/BERT+CRF（第 5 章后）；本节以 CRF 为主线。
4. **解码**：维特比，输出最优标签序列，再按 BIO 规则还原实体。
5. **评测**：实体级 P/R/F1（3.4.2 节）。

### 3.4.2 实体级评测：P/R/F1 的精确定义

**实体级匹配要求（span, type, boundary）全对**：预测实体记 $\hat{E}$，金标准实体记 $E$，计数

- 真阳性 $TP = |\hat{E} \cap E|$（span 边界与类型都一致的实体数）；
- 精确率 $P = TP / |\hat{E}|$，召回率 $R = TP / |E|$；
- $F_1 = 2PR / (P + R)$。

注意与"token 级准确率"的本质区别：一个 5 词实体若边界偏移一个词，token 级只错 2/5，实体级则记 **2 个错误**（1 个假阳性 + 1 个假阴性）——NER 的实际应用（如事件抽取、知识图谱构建）要求边界精确，因此必须用实体级指标。多类型NER 常再按类型分解报告 per-type F1。

### 3.4.3 错误分析

拿到 F1 之后，工作才刚开始。系统化错误分析的经典分类：

- **边界错误（boundary error）**：类型对、边界错（「北京 大学」切成了「北京」）；
- **类型错误（type error）**：边界对、类型错（PER↔ORG 混淆最常见：人名常兼任组织名）；
- **漏报（false negative）**：低频实体、缩写、嵌套实体（「北京大学」内部含「北京」——扁平标注体系无法表达，需要嵌套 NER 模型）；
- **误报（false positive）**：大写词被误判为实体（句首词）、词典污染。

分析方法：按错误类型分桶统计占比、按实体长度/频率/类型分层报告 F1、抽 50 个错误逐条归因（标注噪声 / 特征缺失 / 模型容量 / 数据偏斜）。**错误分析的产出是数据与特征改进路线，而不是调参记录**——这一习惯请贯穿到第 6 章微调与 99 章综合项目。

## 3.5 关键公式速查

| 公式 | 名称 | 适用条件 |
|---|---|---|
| $p(w,y) = \prod_t A_{y_{t-1}y_t} B_{y_t}(w_t)$ | HMM 联合分布 | 一阶马尔可夫 + 输出独立 |
| $\alpha_t(j) = \big(\sum_i \alpha_{t-1}(i) A_{ij}\big) B_j(w_t)$ | 前向递归 | 评估问题，$O(TN^2)$ |
| $p(w_{1:n}) = \sum_i \alpha_n(i)$ | 前向终止 | 全部隐状态求和 |
| $\delta_t(j) = \max_i (\delta_{t-1}(i) A_{ij}) B_j(w_t)$ | 维特比递归 | 解码问题，sum→max |
| $p_\theta(y \mid w) = \frac{1}{Z(w)} \exp(\sum_t \theta^\top f(w, t, y_{t-1}, y_t))$ | 线性链 CRF | 全局归一 |
| $\nabla_\theta \log p_\theta(y \mid w) = f(w, y) - \mathbb{E}_{p_\theta}[f(w, y')]$ | CRF 梯度 | 前向-后向算期望 |
| $F_1 = \frac{2TP}{2TP + FP + FN}$ | 实体级 F1 | span+type 全对才算 TP |

## 3.6 示例与案例

### 示例 1（手算）：前向算法两步求解

设标签集 $\{H, C\}$（模拟"热/冰"天气，Jurafsky 经典例子），观测（冰淇淋日销量编码 1=少量, 2=中, 3=多）为 $w = (2, 3, 1)$，参数：

$$
\pi = [0.8, 0.2], \quad A = \begin{pmatrix} 0.6 & 0.4 \\ 0.5 & 0.5 \end{pmatrix} \ (H{\to}), \quad B_H = [0.2, 0.4, 0.4],\ B_C = [0.5, 0.4, 0.1].
$$

$t=1$（$w_1 = 2$）：$\alpha_1(H) = 0.8 \times 0.4 = 0.32$，$\alpha_1(C) = 0.2 \times 0.4 = 0.08$。

$t=2$（$w_2 = 3$）：$\alpha_2(H) = (0.32 \times 0.6 + 0.08 \times 0.5) \times 0.4 = 0.232 \times 0.4 = 0.0928$；$\alpha_2(C) = (0.32 \times 0.4 + 0.08 \times 0.5) \times 0.1 = 0.168 \times 0.1 = 0.0168$。

$t=3$（$w_3 = 1$）：$\alpha_3(H) = (0.0928 \times 0.6 + 0.0168 \times 0.5) \times 0.2 = 0.06408 \times 0.2 = 0.012816$；$\alpha_3(C) = (0.0928 \times 0.4 + 0.0168 \times 0.5) \times 0.5 = 0.0456 \times 0.5 = 0.022760$。

故 $p(w) = 0.012816 + 0.022760 = 0.035576$。若同时跑维特比：$\delta_1 = (0.32, 0.08)$，$\delta_2(H) = \max(0.32\times0.6, 0.08\times0.5)\times0.4 = 0.192\times0.4 = 0.0768$（前驱 H），$\delta_2(C) = \max(0.32\times0.4, 0.08\times0.5)\times0.1 = 0.0128$（前驱 H），$\delta_3(C) = \max(0.0768\times0.4, 0.0128\times0.5)\times0.5 = 0.01536$，$\delta_3(H) = \max(0.0768\times0.6, 0.0128\times0.5)\times0.2 = 0.009216$——最优路径为 $HHC$，概率 $0.01536$。（数值验算见示例 2 代码。）

### 示例 2（代码）：从零实现前向算法与维特比

```python
# 纯 Python，无依赖
states = ["H", "C"]                      # 两个隐状态
obs = [2, 3, 1]                          # 观测：冰淇淋销量编码
A = {"H": {"H": 0.6, "C": 0.4}, "C": {"H": 0.5, "C": 0.5}}
B = {"H": {1: 0.2, 2: 0.4, 3: 0.4}, "C": {1: 0.5, 2: 0.4, 3: 0.1}}
pi = {"H": 0.8, "C": 0.2}

def forward(obs):
    T = len(obs)
    alpha = [{s: pi[s] * B[s][obs[0]] for s in states}]
    for t in range(1, T):
        alpha.append({s: B[s][obs[t]] *
                      sum(alpha[t-1][sp] * A[sp][s] for sp in states)
                      for s in states})
    return alpha, sum(alpha[-1].values())

alpha, p_obs = forward(obs)
print([round(alpha[t][s], 6) for t in range(3) for s in states])
# [0.32, 0.08, 0.0928, 0.0168, 0.012816, 0.02276]
print("P(obs) = %.6f" % p_obs)           # 0.035576

def viterbi(obs):
    T = len(obs)
    delta = [{s: pi[s] * B[s][obs[0]] for s in states}]
    bp = [{s: None for s in states}]
    for t in range(1, T):
        delta.append({}); bp.append({})
        for s in states:
            best = max(states, key=lambda sp: delta[t-1][sp] * A[sp][s])
            delta[t][s] = delta[t-1][best] * A[best][s] * B[s][obs[t]]
            bp[t][s] = best
    final = max(states, key=lambda s: delta[-1][s])
    path = [final]
    for t in range(T - 1, 0, -1):
        path.insert(0, bp[t][path[0]])
    return path, delta[-1][final]

path, p_best = viterbi(obs)
print("viterbi path:", "".join(path), " prob = %.6f" % p_best)  # HHC  0.015360
```

### 示例 3（代码）：线性链 CRF 的配分函数、条件概率与最优路径（log 空间）

设 $T=3$、标签 $\{0,1\}$，发射分数 $S[t, y]$、转移分数 $A[i, j]$（均为 exp 势函数的对数）。CRF 定义 $\text{score}(y) = \sum_t S[t, y_t] + \sum_t A[y_{t-1}, y_t]$，$p(y \mid w) = e^{\text{score}(y)} / Z$。

```python
# 需要安装: pip install numpy
import numpy as np

S = np.array([[1.0, 0.5], [0.2, 1.2], [0.8, 0.1]])   # 发射分数 [t, label]
A = np.array([[0.4, 0.6], [0.3, 0.7]])               # 转移分数 [prev, cur]
T, N = S.shape

# 前向（log-sum-exp，数值稳定）
def lse(v):
    m = v.max(); return m + np.log(np.exp(v - m).sum())

alpha = S[0].copy()
for t in range(1, T):
    alpha = S[t] + np.array([lse(alpha + A[:, j]) for j in range(N)])
logZ = lse(alpha)
print("logZ = %.6f" % logZ)                          # 5.218010

# 维特比
delta = S[0].copy(); bp = np.zeros((T, N), dtype=int)
for t in range(1, T):
    sc = delta[:, None] + A
    bp[t] = sc.argmax(0); delta = S[t] + sc.max(0)
yT = delta.argmax(); best = delta[yT]; path = [yT]
for t in range(T-1, 0, -1):
    path.insert(0, bp[t][path[0]])
print("best score=%.4f path=%s log p(best|x)=%.6f" % (best, path, best - logZ))
# best score=3.9000 path=[0, 1, 0] log p(best|x)=-1.318010

# 某条具体路径的条件对数概率，如 y = [0, 1, 1]
y = [0, 1, 1]
score = S[0, y[0]] + A[y[0], y[1]] + S[1, y[1]] + A[y[1], y[2]] + S[2, y[2]]
print("log p(y=[0,1,1]|x) = %.6f" % (score - logZ))  # -1.618010
```

注意一个自检点：最优路径分数 3.9 小于 $\log Z = 5.218$——这是必然的，因为 $\log Z$ 是**所有**路径 log-score 的 log-sum-exp，永远大于等于其中最大的一条。条件概率 $p(\text{best} \mid w) = e^{3.9-5.218} \approx 0.268$。

### 示例 4（代码）：实体级 P/R/F1 评测器

```python
def extract_entities(tags):
    """从 BIO 标签序列还原实体列表 [(start, end, type), ...]，end 为排他边界"""
    ents, start, typ = [], None, None
    for i, t in enumerate(tags + ["O"]):          # 哨兵闭合最后一个实体
        if t.startswith("B-") or (t.startswith("I-") and start is None):
            if start is not None: ents.append((start, i, typ))
            start, typ = i, t[2:]
        elif t == "O" or (t.startswith("B-") is False and t.startswith("I-") is False):
            if start is not None: ents.append((start, i, typ)); start = None
    return ents

def ner_f1(gold_seqs, pred_seqs):
    G, P, tp = 0, 0, 0
    for g, p in zip(gold_seqs, pred_seqs):
        ge, pe = set(extract_entities(g)), set(extract_entities(p))
        G += len(ge); P += len(pe); tp += len(ge & pe)
    prec = tp / P if P else 0.0
    rec = tp / G if G else 0.0
    return prec, rec, 2 * prec * rec / (prec + rec) if prec + rec else 0.0

gold = ["B-PER I-PER O B-LOC".split(), "B-ORG O".split()]
pred = ["B-PER I-PER O B-PER".split(), "O B-ORG".split()]
print("%.3f %.3f %.3f" % ner_f1(gold, pred))       # 0.500 0.500 0.500
```

第二条句子的 `B-ORG` 预测边界正确但整体（ORG）与金标准（ORG）一致——它是 TP；第一条 LOC 被判成 PER，产生 1 FP + 1 FN。请自己数一数验证 P = R = 0.5。注意：`I-PER` 直接出现在句首时 `extract_entities` 宽容地按新实体处理（工程惯例），换策略会改变 F1。

## 3.7 常见误区与陷阱

1. **用 token 级准确率报告 NER 性能。** `O` 标签通常占 80% 以上，一个全预测 `O` 的退化模型 token 准确率可达 0.8+ 而实体级 F1 为 0。永远报告实体级 P/R/F1（并注明匹配标准：CoNLL 精确匹配 vs 部分匹配）。
2. **前向算法与维特比混淆。** 前向是求和（全路径概率），维特比是取最大（最优路径概率）；二者数值不同（示例 1 中 0.035576 vs 0.015360），替换错误是最常见的作业扣分点。
3. **在原始概率空间递归导致下溢。** 长序列连乘会小于浮点下限；工程与比赛实现必须在 log 空间（log-sum-exp），或按时刻缩放。参见示例 3。
4. **以为 CRF"总比 HMM 好"。** 无标注数据时 HMM+EM 仍可用；CRF 特征设计不当（或神经编码器欠拟合）时同样会输；且 CRF 推断每句都要算配分函数，训练代价高于直接 softmax 分类头。
5. **忽略 BIO 约束的解码降级策略。** 遇到非法 `I-X` 序列时，"开新实体"、"丢弃该 token"、"约束解码强制合法"三种策略给出不同 F1；论文复现对不上时，先核对这一处。
