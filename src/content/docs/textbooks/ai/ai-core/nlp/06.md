## 6.1 从基座到助手：对齐问题的提出

[第 5 章](/xiaoshus-blog/textbooks/ai/ai-core/nlp/05/)结尾留下的悬念：纯自回归预训练学的是"互联网文本的分布"，它会续写问题，而不是回答问题；会顺着你写有害内容，而不是拒绝。**对齐（alignment）**指把模型行为校准到人类意图与价值观上的全部技术。InstructGPT（Ouyang et al., 2022）给出了沿用至今的三阶段模板：

1. **SFT（监督微调）**：用人类示范的"指令→回答"对微调基座；
2. **RM（奖励模型训练）**：用人类对多个回答的偏好排序训练打分模型；
3. **RL（强化学习微调）**：用 PPO 最大化奖励模型打分，同时用 KL 惩罚把策略锚定在 SFT 模型附近。

一个值得记住的实验事实：1.3B 的 InstructGPT 在人类偏好评测中胜过 175B 的 GPT-3——**对齐带来的质量提升可以超过 100 倍的参数差距**。

## 6.2 SFT：指令微调的数据工程

### 6.2.1 格式与模板

SFT 样本有两种基本形态。**指令格式**：`{instruction, input, output}`，适合单轮任务；**对话格式**：多轮消息列表 `[{role, content}, ...]`，role ∈ {system, user, assistant}。训练前必须套上**聊天模板（chat template）**，把消息序列渲染成模型见过的字符串，例如（示意）：

```
<|system|> 你是一个乐于助人的助手 <|end|>
<|user|>   解释什么是困惑度 <|end|>
<|assistant|> 困惑度是…… <|end|>
```

模板是模型契约的一部分：换模板 = 换输入分布 = 行为退化。这是新手最常见的翻车点之一。

### 6.2.2 Loss mask：只对"回答"计损

SFT 的损失是自回归交叉熵，但只对 assistant 生成的 token 计算：

$$
\mathcal{L}_{\text{SFT}}(\theta) = -\sum_{t \in \mathcal{A}} \log p_\theta(w_t \mid w_{1:t-1}),
$$

其中 $\mathcal{A}$ 是所有 assistant 回答 token 的位置集合。指令与用户输入是**条件**而非目标——若不对它们 mask，模型会把大量容量花在"复述问题"上，并学会在回答中途续写新的用户回合。这正是[第 5 章](/xiaoshus-blog/textbooks/ai/ai-core/nlp/05/)方式三的落地细节。

### 6.2.3 质量 > 数量

LIMA（Zhou et al., 2023）用仅 1000 条精选数据就微调出对齐良好的 65B 模型，其结论"Superficial Alignment Hypothesis"（对齐主要是教会模型**格式与风格**，知识来自预训练）影响了整个领域。数据工程的三个维度：

- **质量**：人工精标 > 模型自生成后人工筛 > 原始爬取；去重（精确哈希 + MinHash 近似去重）、去毒、长度与格式校验；
- **多样性**：覆盖任务类型（问答/写作/代码/推理/多语言）、难度、领域；多样性不足会导致模型"只会一种口吻"；
- **一致性**：多人标注需标注规范与一致性检验（回忆[《机器学习·第 7 章》](/xiaoshus-blog/textbooks/ai/ai-core/machine-learning/07/)的标注者间信度）。

## 6.3 RLHF 完整流程

### 6.3.1 偏好数据与奖励模型：Bradley–Terry

人类很难给出绝对分数，但比较两个回答"哪个更好"容易得多。收集三元组 $(x, y^+, y^-)$（同样提示下，偏好回答与被拒回答）。**Bradley–Terry 模型**假设偏好概率只取决于两个"强度"之差：

$$
p(y^+ \succ y^- \mid x) = \sigma\!\left(r_\phi(x, y^+) - r_\phi(x, y^-)\right),
$$

其中 $\sigma$ 是 sigmoid，$r_\phi$ 是奖励模型（通常由 SFT 模型初始化，把最后的标量头接到序列表示上，如最后一 token 的隐状态）。训练目标即负对数似然：

$$
\mathcal{L}_{\text{RM}}(\phi) = -\mathbb{E}_{(x,y^+,y^-)}\left[\log \sigma\!\left(r_\phi(x,y^+) - r_\phi(x,y^-)\right)\right].
$$

注意 RM 是**点估计的判别模型**，只在"同一提示下的成对比较"上有意义，其绝对分值跨提示不可比——这个性质将解释 DPO 与 PPO 的诸多工程差异。

### 6.3.2 KL 约束的 RL 目标：完整推导

现在把微调表述为强化学习：提示 $x\sim\mathcal{D}$，策略 $\pi_\theta(y\mid x)$ 生成回答，奖励 $r(x,y)$ 来自 RM。若单纯最大化 $\mathbb{E}[r]$，策略会立刻"作弊"：生成 RM 给高分但人类觉得糟糕的文本（RM 只在训练分布附近可信），并滑向退化语言（详见 6.5）。因此优化的实际目标是**带 KL 锚定的期望奖励**：

$$
\max_{\pi_\theta}\; \mathbb{E}_{x\sim\mathcal{D},\,y\sim\pi_\theta(\cdot\mid x)}\left[r(x,y)\right] - \beta\, \mathbb{E}_{x,y}\left[\mathrm{KL}\!\left(\pi_\theta(\cdot\mid x)\,\|\,\pi_{\text{SFT}}(\cdot\mid x)\right)\right].
$$

**第一步：求逐样本的最优策略（闭式解）。** 固定 $x$，把 KL 项展开：

$$
\mathrm{KL}(\pi\|\pi_{\text{SFT}}) = \mathbb{E}_{y\sim\pi}\left[\log \pi(y\mid x) - \log \pi_{\text{SFT}}(y\mid x)\right].
$$

目标逐 $x$ 写成：

$$
J(\pi) = \mathbb{E}_{y\sim\pi}\left[r(x,y) - \beta\log\frac{\pi(y\mid x)}{\pi_{\text{SFT}}(y\mid x)}\right] + \beta \underbrace{\log Z(x)}_{\text{与 }\pi\text{ 无关的常数项重排}}.
$$

定义**奖励改写** $r'(x,y) = \dfrac{1}{\beta} r(x,y) - \log \dfrac{\pi(y\mid x)}{\pi_{\text{SFT}}(y\mid x)}$，则 $J = \beta\,\mathbb{E}_{y\sim\pi}[r'(x,y)]$。由 Gibbs 不等式（$\mathrm{KL}(p\|q)\ge 0$ 当且仅当 $p=q$），最优策略是以 $r'$ 为能量的 Boltzmann 分布：

$$
\pi^\ast(y\mid x) = \frac{1}{Z(x)}\, \pi_{\text{SFT}}(y\mid x)\, \exp\!\left(\frac{1}{\beta} r(x,y)\right),
$$

其中配分函数 $Z(x) = \sum_y \pi_{\text{SFT}}(y\mid x)\exp(r(x,y)/\beta)$ 对生成式 $y$ 不可计算。**结论**：最优策略 = 参考策略 × 奖励的指数倾斜。$\beta \to 0$ 时退化为只顾奖励（会作弊），$\beta \to \infty$ 时退化为 SFT 模型（不对齐）。

**第二步：用 PPO 逼近 $\pi^\ast$。** 在[《强化学习》第 4 章·策略梯度]中你学过 REINFORCE 与重要性采样的策略梯度。PPO 的目标（对语言模型的逐 token 形式，回答 $y$ 的每个 token 视作一个动作）：

$$
L^{\text{PPO}}(\theta) = \mathbb{E}_{t}\left[\min\!\left(\rho_t(\theta)\,\hat A_t,\; \text{clip}\!\left(\rho_t(\theta),\,1-\epsilon,\,1+\epsilon\right)\hat A_t\right)\right], \qquad \rho_t = \frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{\text{old}}}(a_t\mid s_t)},
$$

其中 $\hat A_t$ 是优势估计。RLHF 中的惯例是：优势由**可验证的逐 token KL 惩罚**并入奖励得到——每个 token 的即时奖励为 RM 的总分减去 $\beta$ 倍的逐 token KL：

$$
r_t = \begin{cases} -\beta \log \dfrac{\pi_\theta(a_t\mid s_t)}{\pi_{\text{SFT}}(a_t\mid s_t)}, & t < T \text{（中间 token 仅 KL 惩罚）},\\[2pt] r_{\text{RM}}(x,y) - \beta \log\dfrac{\pi_\theta(a_t\mid s_t)}{\pi_{\text{SFT}}(a_t\mid s_t)}, & t = T \text{（末 token 加上奖励模型分数）}.\end{cases}
$$

工程上同屏需要**四个模型**：策略 $\pi_\theta$（训练中）、参考 $\pi_{\text{SFT}}$（冻结）、奖励模型 $r_\phi$（冻结）、价值网络 $V_\psi$（常由 RM 初始化，PPO 的 critic）。显存与吞吐压力催生了 LoRA-PPO、_off-policy_ 化（如 GRPO 用组内相对优势替代 critic，DeepSeek 提出）等变体。

### 6.3.3 为什么要"奖励模型"而不直接问人

在线 RL 每步都需要海量比较信号，人类标注太慢太贵；RM 是人类偏好的**可微代理**，可以离线打无限分。代价是代理误差：RM 只在其训练分布内可信，这正是 KL 锚定不能取消的根本原因。

## 6.4 DPO：跳过奖励模型

### 6.4.1 推导

Direct Preference Optimization（Rafailov et al., 2023）的起点是 6.3.2 的闭式解 $\pi^\ast \propto \pi_{\text{SFT}} \exp(r/\beta)$。**反解奖励**：

$$
r(x, y) = \beta \log \frac{\pi^\ast(y\mid x)}{\pi_{\text{SFT}}(y\mid x)} + \beta \log Z(x).
$$

把它代回 Bradley–Terry 偏好模型，$Z(x)$ 在同一 $x$ 的正负样本相减时**恰好消去**：

$$
\begin{aligned}
p(y^+\succ y^-\mid x) &= \sigma\!\left(r(x,y^+) - r(x,y^-)\right) \\
&= \sigma\!\left(\beta \log\frac{\pi(y^+\mid x)}{\pi_{\text{SFT}}(y^+\mid x)} - \beta \log\frac{\pi(y^-\mid x)}{\pi_{\text{SFT}}(y^-\mid x)}\right).
\end{aligned}
$$

于是可以**直接对策略 $\pi_\theta$ 做极大似然**，奖励模型只是被隐式表示：

$$
\mathcal{L}_{\text{DPO}}(\theta) = -\mathbb{E}_{(x,y^+,y^-)}\left[\log \sigma\!\left(\beta \log\frac{\pi_\theta(y^+\mid x)}{\pi_{\text{SFT}}(y^+\mid x)} - \beta \log\frac{\pi_\theta(y^-\mid x)}{\pi_{\text{SFT}}(y^-\mid x)}\right)\right].
$$

直观读法：**增大"偏好回答相对参考的提升"，同时压低"被拒回答相对参考的提升"**。$\beta$ 控制偏离参考策略的程度，与 PPO 中的 $\beta$ 同一角色。

### 6.4.2 DPO 与 PPO 的工程对比

| 维度 | PPO-RLHF | DPO |
|---|---|---|
| 训练时需要的模型 | 策略+参考+RM+价值（4 个） | 策略+参考（2 个） |
| 数据形态 | 在线生成 + RM 打分 | 离线偏好对，一次前向 |
| 是否可在训练中探索新回答 | 能（on-policy） | 不能（off-policy，受限于偏好数据分布） |
| 典型失败模式 | 奖励作弊、超参敏感、训练不稳 | 对分布外样本过拟合、隐式奖励与真实偏好脱节 |
| 适用场景 | 有算力、需要在线迭代的大厂管线 | 资源有限、偏好数据充足的学术/中小团队 |

后续演进（IPO、KTO、SimPO 等）都在修正 DPO 的离线过拟合或成对数据要求；把它们读作"6.4.1 推导框架下改一个目标函数"即可举一反三。

## 6.5 对齐税、奖励作弊与安全

- **对齐税（alignment tax）**：对齐过程常以通用能力为代价——SFT 数据偏窄、RM 偏保守、KL 锚定太紧都会让模型变"笨"或变"啰嗦"。缓解：混入预训练分布的正则数据、更宽的偏好分布、更细的 $\beta$ 调度。
- **奖励作弊（reward hacking / overoptimization）**：Gao 等（2023）用 Goodhart 定律刻画：RM 分数随 KL 预算增长后必然回落，真实人类分数甚至先升后降。表现包括冗长讨好（sycophancy）、堆砌格式、把"看起来对"做到极致。缓解：KL 锚定、RM 集成与不确定度惩罚、周期性用人类评测校准。
- **安全与越狱**：对齐不是绝对防线；越狱（jailbreak）通过角色扮演、编码绕道、长上下文稀释等方式诱导有害输出。工程防线包括训练期安全偏好数据（拒答与安全替代）、推理期输入/输出过滤、红队测试。更系统的"用宪法替代人工标注"思路见 Constitutional AI（Bai et al., 2022，RLAIF）。
- **诚实性与幻觉**：RLHF 会加重"自信地错"——RM 天然偏好流利确定的回答（与第 7 章幻觉一节呼应）。

## 6.6 评估基准与污染问题

**自动基准**：MMLU（多选题知识）、GSM8K/MATH（数学）、HumanEval（代码，pass@k）、TruthfulQA（真实性）、AlpacaEval/Arena-Hard（用强模型当裁判的指令跟随评测，MT-Bench 同类）。

**LLM-as-a-judge**：让 GPT-4 级模型按细则给回答打分/比较。便宜且可扩展，但有系统性偏差：偏好长回答、偏好自家风格、位置偏差（先读到的更好）。规范做法是交换顺序评两次 + 报告与人类评测的一致率。

**数据污染（contamination）**：基准题（或其改写）泄漏进预训练语料，分数虚高。这是当前 LLM 评测最大的效度威胁。检验与缓解：n-gram 重叠检测（13-gram 精确匹配是 GPT-3 论文的做法）、嵌入相似度检测、时间切分（只用语料截止日期之后的新题）、换皮重写题库、私有保留集。这与[《实验设计与评估》](/xiaoshus-blog/textbooks/ai/engineering/experiment-design/00/)的"测验效度"是同一件事：**分数只有在无泄漏的前提下才度量能力**。

## 6.7 关键公式速查

| 公式 | 含义 | 适用条件 |
|---|---|---|
| $\mathcal{L}_{\text{SFT}}=-\sum_{t\in\mathcal{A}}\log p_\theta(w_t\mid w_{<t})$ | SFT 损失 | 只对 assistant token 计损 |
| $p(y^+\!\succ\! y^-)=\sigma(r_\phi(x,y^+)-r_\phi(x,y^-))$ | Bradley–Terry 偏好模型 | 成对比较；RM 训练目标 |
| $\max_\pi \mathbb{E}[r]-\beta\,\mathrm{KL}(\pi\|\pi_{\text{SFT}})$ | RLHF 的 KL 约束目标 | $\beta$ 平衡奖励与漂移 |
| $\pi^\ast=\frac{1}{Z(x)}\pi_{\text{SFT}}\exp(r/\beta)$ | 闭式最优策略 | 由 Gibbs 不等式；$Z(x)$ 不可计算 |
| $r(x,y)=\beta\log\frac{\pi^\ast}{\pi_{\text{SFT}}}+\beta\log Z(x)$ | 奖励的反解 | DPO 推导第一步 |
| $\mathcal{L}_{\text{DPO}}=-\log\sigma\!\big(\beta\Delta\log\frac{\pi_\theta}{\pi_{\text{SFT}}}\big)$ | DPO 损失 | 成对偏好数据；$Z(x)$ 已消去 |
| $L^{\text{PPO}}=\mathbb{E}[\min(\rho_t\hat A_t,\ \text{clip}(\rho_t,1-\epsilon,1+\epsilon)\hat A_t)]$ | PPO 裁剪目标 | 逐 token；配合 KL 奖励改写 |

## 6.8 示例与案例

### 示例 1（手算）：RM 的一步梯度与 DPO 的损失值

**Bradley–Terry 一步梯度。** 设 $r_\phi(x,y^+)=1.0$，$r_\phi(x,y^-)=0.2$。差 $d=0.8$，$\sigma(0.8)\approx 0.6900$，损失 $-\log 0.6900\approx 0.3711$。损失对差值的梯度 $\partial \mathcal{L}/\partial d = \sigma(d) - 1 \approx -0.3100$（负号意味着增大 $d$ 可降低损失）。于是 $r(x,y^+)$ 收到梯度 $-0.31$（要升），$r(x,y^-)$ 收到 $+0.31$（要压）。

**DPO 损失数值。** 设 $\beta=0.1$，策略相对参考的对数比：$\log\frac{\pi_\theta(y^+)}{\pi_{\text{SFT}}(y^+)}=2$，$\log\frac{\pi_\theta(y^-)}{\pi_{\text{SFT}}(y^-)}=0.5$。则 $\beta(2-0.5)=0.15$，$\mathcal{L}_{\text{DPO}}=-\log\sigma(0.15)\approx 0.6644$。若策略把 $y^+$ 的对数比提升到 4、$y^-$ 压到 0，损失降为 $-\log\sigma(0.4)\approx 0.5130$——DPO 奖励"拉开相对差距"，与直觉一致。

### 示例 2（代码）：Bradley–Terry 奖励模型的最小实现（torch）

```python
# 需要: pip install torch
# 用"序列最后一 token 的隐状态"代表整条回答（真实系统用更大的编码器/解码器）。
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)
d_model, n_pairs = 16, 64
hidden = torch.randn(2 * n_pairs, d_model)      # 每对两行: [y+ 的表示, y- 的表示]

class RewardHead(nn.Module):
    def __init__(self, d):
        super().__init__()
        self.proj = nn.Sequential(nn.Linear(d, d), nn.Tanh(), nn.Linear(d, 1))
    def forward(self, h):                        # h: (B, d) -> 标量奖励
        return self.proj(h).squeeze(-1)

rm = RewardHead(d_model)
opt = torch.optim.Adam(rm.parameters(), lr=1e-2)

for step in range(300):
    r = rm(hidden)                               # (2B,)
    r_plus, r_minus = r[0::2], r[1::2]
    loss = F.binary_cross_entropy_with_logits(r_plus - r_minus, torch.ones_like(r_plus))
    opt.zero_grad(); loss.backward(); opt.step()

with torch.no_grad():
    acc = ((rm(hidden)[0::2] > rm(hidden)[1::2]).float()).mean()
print(f"loss={loss.item():.4f} train_acc={acc.item():.2f}")
# 预期输出: train_acc 接近 1.00 —— 两层网络足以"记住"64 对随机点。
# 教学要点: BT 损失在记忆容量足够的模型上总能拟合训练对, 因此 train_acc 高
# 不能说明 RM 质量; 必须用留出的验证偏好对来度量泛化（呼应第 1 章/机器学习的评估纪律）。
```

### 示例 3（代码）：DPO 损失与隐式奖励的验证（torch）

```python
# 需要: pip install torch
# 验证: 沿 DPO 损失梯度下降, 策略会同时提升 y+ 相对参考的对数比、压低 y- 的对数比
# （即隐式奖励被拉开）。玩具设定: 逐位置独立分布 pi(y|x) = prod_t pi_t(y_t)。
import torch
import torch.nn.functional as F
torch.manual_seed(0)

V, T = 20, 6
beta = 0.1
idx_plus  = torch.tensor([3, 5, 7, 9, 11, 13])
idx_minus = torch.tensor([2, 4, 6, 8, 10, 12])
ref_logits = torch.randn(T, V)                             # 参考策略 pi_SFT 的 logits
pi_sft = F.softmax(ref_logits, dim=-1)
theta_logits = ref_logits.clone().requires_grad_(True)     # 策略 logits 从 SFT 出发

def margin(logits):
    """隐式奖励差 margin = (log pi(y+)/pi_ref(y+)) - (log pi(y-)/pi_ref(y-))"""
    lp  = F.log_softmax(logits, dim=-1)[range(T), idx_plus].sum()
    lm  = F.log_softmax(logits, dim=-1)[range(T), idx_minus].sum()
    rp  = F.log_softmax(ref_logits, dim=-1)[range(T), idx_plus].sum()
    rm_ = F.log_softmax(ref_logits, dim=-1)[range(T), idx_minus].sum()
    return (lp - rp) - (lm - rm_)

opt = torch.optim.Adam([theta_logits], lr=5e-2)
for step in range(200):
    loss = -F.logsigmoid(beta * margin(theta_logits))      # 即 6.4.1 的 DPO 损失
    opt.zero_grad(); loss.backward(); opt.step()

print(f"margin(隐式奖励差)={margin(theta_logits).item():.3f}  初始={margin(ref_logits).item():.3f}")
# 预期输出: 初始 margin=0.000, 训练后显著为正且可能很大（如 > 10）——
# 隐式奖励差没有上界, 这正是 6.4.2 所说 DPO 在偏好数据未覆盖的分布上容易
# 过拟合的原因; 注意策略必须以 logits 参数化, 若直接把概率表当优化变量,
# 梯度下降会把概率推成负数导致 log(negative)=nan。
```

### 示例 4（代码）：SFT 的 loss mask（transformers）

```python
# 需要: pip install torch transformers
# 用一个真实小模型演示"只对回答 token 计损"的实现方式。
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

name = "Qwen/Qwen2.5-0.5B"   # 约 1GB; 也可换成 gpt2 以减小下载量
tok = AutoTokenizer.from_pretrained(name)
model = AutoModelForCausalLM.from_pretrained(name)

prompt = "用户: 用一句话解释过拟合\n助手:"
answer = "模型在训练集上表现好但在新数据上表现差的现象。"
input_ids = tok(prompt, return_tensors="pt").input_ids
full_ids  = tok(prompt + answer, return_tensors="pt").input_ids
labels = full_ids.clone()
labels[:, : input_ids.shape[1]] = -100          # 关键: 条件部分不计损
out = model(input_ids=full_ids, labels=labels)
print("SFT loss (masked):", round(out.loss.item(), 3))
# 预期输出: 一个有限的正数（对未微调基座约为 2-6 之间），且明显不同于
# 不加 mask 时（把 prompt 也算进 labels）的 loss——两者不应相等。
```

## 6.9 常见误区与陷阱

1. **把 RM 分数当绝对质量**：RM 的分值只在同提示比较中有效；用"RM 平均分上升"证明模型变好是典型的度量误用。
2. **$\beta$ 当普通超参随手调**：$\beta$ 是对齐-漂移的旋钮，过小必然作弊、过大等于没对齐；应随 KL 预算一起规划（Goodhart 曲线）。
3. **SFT 忘记 loss mask 或模板不一致**：训练与推理模板不一致是"模型突然变笨"的最常见原因，排查应先于怀疑能力。
4. **以为 DPO 完全等价于 PPO**：两者优化同一族目标，但 DPO 是离线极大似然，不产生新样本；在偏好数据未覆盖的分布上，DPO 的隐式奖励无约束，容易过拟合。
5. **在污染基准上追逐分数**：MMLU 等高分可能只是背题；报告结果时应附污染检测与新鲜题评测。

## 6.12 进阶方向

- **在线 DPO 与混合方法**：iterative DPO、-online DPO、GRPO（组相对策略优化，去掉 critic）；需要先补 on/off-policy 差异的方差分析。
- **可验证奖励的 RL（RLVR）**：数学/代码等可自动判分的领域直接用规则奖励，绕开 RM 的 Goodhart 风险；从本章出发只需替换奖励来源。
- **过程奖励模型（PRM）**：奖励打在推理步骤而非整条回答上；需要步骤级标注与蒙特卡洛估计工具。
- **可扩展监督（scalable oversight）与 AI 反馈**：辩论、递归奖励建模、宪法式原则反馈；前置知识是本章 RM + 博弈论基础。
