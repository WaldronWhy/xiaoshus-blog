## 2.1 深度训练的核心困难：一图导览

第 1 章的两层网络训练顺利，是因为它足够浅。当深度 $L$ 增大，三件事同时恶化：

1. **信号衰减**：前向激活值逐层缩放（方差连乘），要么爆炸成 `inf` 要么消失为 0——初始化必须解决；
2. **梯度失稳**：反向 $\Delta^{(l)} = (\Delta^{(l+1)} W^{(l+1)}) \odot \sigma'$ 是 $L$ 个雅可比因子的连乘（1.5 节公式的复合），比前向更脆弱；
3. **内部协变量偏移**（internal covariate shift，Ioffe & Szegedy, 2015 的原始表述）：浅层参数一变，深层的输入分布随之漂移，每一层都在"追移动靶"——归一化层试图解决。

本章工具与失败模式的对应表（先给地图，逐节展开）：

| 失败模式 | 工具 | 小节 |
|---|---|---|
| 前向方差爆炸/消失 | Xavier / He 初始化 | 2.2 |
| 梯度消失/爆炸 | 激活选择、残差（第 3 章）、梯度裁剪（第 8 章）、归一化 | 2.2, 2.3, 2.7 |
| 各层输入分布漂移 | BatchNorm / LayerNorm | 2.3 |
| 过拟合 | dropout、数据增强、权重衰减 | 2.4, 2.5 |
| 收敛慢/不稳 | 学习率调度、warmup | 2.6 |
| "训练不动了" | 曲线诊断 | 2.7 |

## 2.2 初始化：方差守恒的推导

**问题设定**：设 $L$ 层线性链 $z^{(l+1)} = W^{(l+1)} a^{(l)} + b^{(l+1)}$（本节用单样本向量形式便于推导），各 $W^{(l)}$ 独立同分布、各元素独立。问：$W$ 的方差应取多大，才能让信号在深度方向"活下来"？

### 2.2.1 前向视角：Xavier/Glorot 初始化

设 $z_j^{(l+1)} = \sum_{i=1}^{n_{\mathrm{in}}} w_{ji} a_i^{(l)}$。假设各 $a_i$ 零均值、两两独立、方差 $\mathrm{Var}(a)$，$w_{ji}$ 零均值方差 $\mathrm{Var}(w)$，则（用方差的独立和公式，[《概率论与数理统计》第 3 章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/03/)）：

$$\mathrm{Var}(z_j^{(l+1)}) = \sum_{i=1}^{n_{\mathrm{in}}} \mathrm{Var}(w_{ji}\, a_i^{(l)}) = n_{\mathrm{in}}\, \mathrm{Var}(w)\, \mathrm{Var}(a^{(l)}).$$

**方差守恒**要求 $\mathrm{Var}(z^{(l+1)}) = \mathrm{Var}(a^{(l)})$，即

$$\mathrm{Var}(w) = \frac{1}{n_{\mathrm{in}}} \quad \Longrightarrow \quad w_{ij} \sim \mathcal{U}\Big(-\tfrac{\sqrt{6}}{\sqrt{n_{\mathrm{in}}+n_{\mathrm{out}}}},\ +\tfrac{\sqrt{6}}{\sqrt{n_{\mathrm{in}}+n_{\mathrm{out}}}}\Big) \ \text{或} \ \mathcal{N}\Big(0, \tfrac{2}{n_{\mathrm{in}}+n_{\mathrm{out}}}\Big).$$

（均匀分布 $U[-c, c]$ 的方差是 $c^2/3$，Glorot & Bengio, 2010 用 $\frac{2}{n_{\mathrm{in}}+n_{\mathrm{out}}}$ 折中兼顾反向：对反向梯度做同样分析得 $\mathrm{Var}(w) = 1/n_{\mathrm{out}}$，两者取调和折中。）

### 2.2.2 ReLU 时代：He 初始化

ReLU 把一半输入截为零：$a = \max(0, z)$，$z$ 零均值对称时 $\mathrm{Var}(a) = \frac{1}{2}\mathrm{Var}(z)$。代入上式：

$$\mathrm{Var}(z^{(l+1)}) = n_{\mathrm{in}}\, \mathrm{Var}(w) \cdot \tfrac{1}{2}\mathrm{Var}(z^{(l)}),$$

守恒要求

$$\mathrm{Var}(w) = \frac{2}{n_{\mathrm{in}}} \quad \Longrightarrow \quad w_{ij} \sim \mathcal{N}\Big(0, \tfrac{2}{n_{\mathrm{in}}}\Big). \qquad \text{(He et al., 2015)}$$

**两个公式的差别只在因子 2**——它精确补偿 ReLU 砍掉的方差。这个 2 在 ResNet（第 3 章）等深网络中是"能训起来"与"训不动"的差别。

**经验法则**：偏置初始化为 0（或极小值）；ReLU 网络用 He；tanh/sigmoid 用 Xavier。第 1 章案例 2 的 $\sqrt{2/d}$ 即 He 初始化。

## 2.3 批归一化：把每层输入"钉"回标准分布

### 2.3.1 定义（训练模式）

对一个 mini-batch $Z = \{z_1, \dots, z_B\}$（$z_i$ 是某层某神经元在 batch 内的取值向量，归一化沿 batch 维逐特征做）：

$$\mu_B = \frac{1}{B}\sum_{i=1}^B z_i, \qquad \sigma_B^2 = \frac{1}{B}\sum_{i=1}^B (z_i - \mu_B)^2,$$

$$\hat{z}_i = \frac{z_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \qquad y_i = \gamma \odot \hat{z}_i + \beta.$$

$\gamma, \beta$ 是**可学习参数**（每特征一对）：归一化后允许网络再学回任意均值方差——"先标准化，再给网络自由"。$\epsilon \approx 10^{-5}$ 防止除零。

**推理模式**：推理时没有 batch（或 batch=1），$\mu_B, \sigma_B^2$ 用训练期间累计的**滑动平均**代替：

$$\mu_{\mathrm{EMA}} \leftarrow (1 - m)\,\mu_{\mathrm{EMA}} + m\, \mu_B, \qquad \text{动量 } m \approx 0.1.$$

### 2.3.2 它为什么有效（含争议）

- **原始解释（Ioffe & Szegedy, 2015）**：缓解内部协变量偏移，使每层输入分布稳定，从而可以用更大学习率、更快收敛；
- **后续修正（Santurkar et al., NeurIPS 2018）**：实验表明 BN 的收益与"分布稳定"关系不大，更本质的是**让损失面更平滑**（Lipschitz 常数更小），梯度更可预测，大学习率因此可行；
- **工程事实**：BN 还附带轻微正则化效果（batch 内噪声），并改变训练/推理行为（这正是陷阱之一）。Transformer 时代用 LayerNorm（对**单样本的特征维**归一化，无 batch 统计量、无训练/推理差异，见第 5 章）取代了 BN。

### 2.3.3 BN 的反向传播（第 1 章机制的一次实战）

BN 前向有分支（$\mu, \sigma^2$ 被 $B$ 个样本共享），梯度必须沿所有路径累加（第 1 章推论 B）。对某样本的 $\hat z_i$，设上游梯度为 $g_i = \partial \ell/\partial \hat z_i$，记 $\bar g = \frac1B \sum_i g_i$，$\overline{g\hat z} = \frac1B \sum_i g_i \hat z_i$，则

$$\frac{\partial \ell}{\partial z_i} = \frac{1}{\sqrt{\sigma_B^2 + \epsilon}}\Big( g_i - \bar g - \hat z_i \cdot \overline{g\hat z} \Big).$$

三项分别对应：直接通路、对 $\mu_B$ 的通路（batch 内所有样本都受 $\mu$ 影响且影响方向相同）、对 $\sigma_B^2$ 的通路。$B=1$ 时 $\sigma_B^2 = 0$、$\bar g = g_i$，梯度恒为零——这就是"batch 太小 BN 失效"的数学根源。

## 2.4 Dropout：训练时的随机集成

**算法（inverted dropout，现代标准实现）**：训练时每层以概率 $p$ 丢弃每个激活：

$$\tilde a = \frac{m \odot a}{1 - p}, \qquad m_i \sim \mathrm{Bernoulli}(1-p); \quad \text{推理时恒等变换。}$$

除以 $1-p$ 使激活的期望不变（$\mathbb{E}[\tilde a] = a$），故推理无需缩放——"inverted"之名即来自把缩放搬到训练时。

**为什么有效**（两个互补视角）：

1. **集成视角**：每个 mini-batch 相当于训练一个子网络（共享权重的不同 thinned 结构）；$L$ 层、丢弃率 $p$ 对应指数多个子网络的隐式集成，推理时用全部权重近似其平均；
2. **共适应破坏视角**：单个神经元无法依赖特定伙伴的"合谋"特征，迫使每个单元独立有用（Srivastava et al., JMLR 2014）。

**使用要点**：全连接层 $p = 0.2\text{–}0.5$；卷积层用空间 dropout 或干脆不用；BN + dropout 同用时注意相互作用（有研究建议小学习率下二者叠加可能反而有害）；数据充足的大模型时代，dropout 用得越来越少（大模型主要靠数据规模），但它是理解"随机正则化"的原型。

## 2.5 数据增强与权重衰减

**数据增强（data augmentation）**：对输入施加**保标签不变**的随机变换（图像：随机裁剪、翻转、色彩抖动、MixUp/CutMix），等效于免费扩充训练集并在输入空间注入先验。它与 dropout 的分工：dropout 随机化**网络内部**，增强随机化**数据分布**。设计原则——变换必须保持语义（竖直翻转数字 6 会变 9，故 MNIST 不做竖直翻转）；第 3 章 CIFAR-10 实验将实际使用 RandomCrop + HorizontalFlip。

**权重衰减与 L2 的微妙差别**：在纯 SGD 下，`weight decay`（每步 $w \leftarrow w(1 - \eta\lambda)$）与 L2 正则（梯度加 $\lambda w$）等价；但 **Adam 下二者不等价**——L2 惩罚会被自适应分母缩放，而 weight decay 是对参数的直接衰减。解耦版本称 **AdamW**（Loshchilov & Hutter, ICLR 2019），是现代默认。细节承接[《最优化方法》第 5 章](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/05/) Adam 一节的实现。

## 2.6 学习率调度与 warmup

《最优化方法》第 5 章 5.3 节已证明：SGD 收敛需要学习率满足 Robbins–Monro 条件（$\sum \eta_k = \infty$，$\sum \eta_k^2 < \infty$），且"先大后小"由信号/噪声比决定。深度学习的调度把这一理论工程化为常见菜单：

| 调度 | 公式 | 适用场景 |
|---|---|---|
| 阶梯衰减（step） | 每 $S$ 步乘 $\gamma$（如 0.1） | 传统 CV 训练 |
| 余弦退火（cosine） | $\eta_t = \eta_{\min} + \frac{\eta_{\max}-\eta_{\min}}{2}(1 + \cos(\pi t/T))$ | 现代默认（配合 AdamW） |
| warmup + 余弦 | 前 $T_w$ 步从 0 线性升到 $\eta_{\max}$ 再余弦降 | Transformer 训练标配 |
| 循环（cyclic） / One-cycle | 周期性升降 | 快速达到好结果（super-convergence） |

**为什么 Transformer 必须 warmup**：训练初期 Adam 的二阶矩估计 $v_t$ 尚未可靠（偏差修正初期放大效应，见《最优化方法》5.5.3）、且无预训练初始化时早期梯度方向噪声大，大学习率会造成不可逆的"跑飞"。warmup 把最初几百~几千步的学习率压小，等动量/二阶矩统计稳住再提速——第 5 章训练 mini-GPT 时将实际使用。

## 2.7 梯度消失/爆炸的定量分析与训练诊断

### 2.7.1 雅可比连乘：消失与爆炸的数学

由第 1 章 $\Delta^{(l)} = (\Delta^{(l+1)} W^{(l+1)}) \odot \sigma'$，从第 $L$ 层到第 $l$ 层：

$$\Delta^{(l)} = \Delta^{(L)} \left[\prod_{k=l+1}^{L} W^{(k)} \mathrm{diag}\big(\sigma'(z^{(k-1)})\big)\right].$$

（顺序：先过激活的"逐元素门"，再过权重转置——由 1.5 节两步复合。）梯度范数的行为由连乘矩阵的**谱半径**控制：若每个因子把范数平均缩放 $c$ 倍，则总缩放 $\sim c^{L-l}$：

- sigmoid：$|\sigma'| \le 1/4$，即便 $W$ 谱范数为 1，$c \le 0.25$——**20 层后梯度缩至 $0.25^{20} \approx 10^{-12}$**。这是 2010 年前"深网络训不动"的第一元凶；
- ReLU + He 初始化：期望意义上 $c \approx 1$（He 初始化的推导正是让这个 $c = 1$），中性；
- $W$ 谱范数 $> 2/|\sigma'|_{\max}$ 时指数爆炸，表现为 loss 变 `nan`（梯度爆炸的典型症状是突然 nan，消失的典型症状是"深层的参数梯度趋零、浅层几乎不更新"）。

**对策清单**（本章给两个，其余在后续章节兑现）：He/Xavier 初始化（本章）；残差连接给梯度开恒等旁路（第 3 章）；门控与记忆细胞（第 4 章 LSTM）；归一化层（本章 BN/LayerNorm）；梯度裁剪（第 8 章）。

### 2.7.2 训练曲线诊断决策树

拿到一次训练，按序回答：

1. **初始 loss 合理吗？** 分类 $K$ 类的初始 loss 应 $\approx \ln K$（随机猜测的熵）。10 类却初始 loss $= 8$，说明初始化/标度坏了（先查 logits 是否巨大、BN 统计是否用错）；
2. **train loss 下降吗？** 不降→学习率过大（震荡/nan）或过小（平台）或实现有 bug（先在 1 个 batch 上过拟合测试，见第 8 章）；
3. **train 与 val 的差距随时间如何变化？** 差距持续扩大→过拟合（加正则/增强/早停）；两者都高→欠拟合（加深加宽、训练更久、提高学习率）；
4. **val loss 仍在降但很慢？** → 调度问题，试余弦退火或更大学习率 + warmup；
5. **中后期突然 nan？** → 梯度/激活爆炸（查 fp16 溢出、加梯度裁剪、降学习率）。

把这五问写成训练脚本里的自动检查（初始 loss 断言、每 epoch 记录曲线），是第 8 章实验管理的一部分。

## 2.8 关键公式速查

| 公式 | 含义 | 适用条件 |
|---|---|---|
| $\mathrm{Var}(z^{(l+1)}) = n_{\mathrm{in}} \mathrm{Var}(w) \mathrm{Var}(a^{(l)})$ | 方差传播基本式 | 独立零均值 |
| $\mathrm{Var}(w) = 1/n_{\mathrm{in}}$（前向）或 $1/n_{\mathrm{out}}$（反向） | Xavier 依据 | tanh/sigmoid，零均值 |
| $\mathrm{Var}(w) = 2/n_{\mathrm{in}}$ | He 初始化 | ReLU 家族 |
| $\hat z = (z - \mu_B)/\sqrt{\sigma_B^2 + \epsilon},\ y = \gamma \hat z + \beta$ | BatchNorm | 沿 batch 维 |
| $\tilde a = m \odot a / (1-p)$ | inverted dropout | 训练时，推理恒等 |
| $\eta_t = \frac{\eta_{\max}}{2}(1+\cos(\pi t/T))$ | 余弦退火 | $\eta_{\min}=0$ 简化式 |
| $\Delta^{(l)} = \Delta^{(L)} \prod_k W^{(k)} \mathrm{diag}(\sigma')$ | 雅可比连乘 | 消失/爆炸分析 |
| $\|\nabla w^{(l)}\| \sim c^{L-l}$ | 梯度随深度缩放 | $c$ 为单层平均缩放 |

## 2.9 示例与案例

### 案例 1（数值算例：验证初始化的方差传播）

```python
import numpy as np
rng = np.random.default_rng(0)
L, width = 50, 512
x = rng.standard_normal((256, width))          # 批量输入, 单位方差

for name, scale in [("过小 *0.05", 0.05), ("Xavier *sqrt(1/fan_in)", np.sqrt(1/width)),
                    ("He    *sqrt(2/fan_in)", np.sqrt(2/width))]:
    a = x.copy()
    for _ in range(L):
        a = np.maximum(0, a @ (rng.standard_normal((width, width)) * scale))
    print(f"{name:28s} 50层后激活标准差 = {a.std():.3e}")

# 预期输出(量级):
# 过小                          ≈ 0 (激活已完全消失, 下溢为 0)
# Xavier *sqrt(1/fan_in)        ≈ 1e-2 ~ 1e-3 量级 (ReLU 下仍逐层衰减)
# He    *sqrt(2/fan_in)         ≈ 1e-1 ~ 1 量级  (近似守恒)
```

结论一眼可见：同样是"看起来合理"的缩放，只有 He 让 ReLU 深链的信号存活。请把激活换成 tanh 再跑一遍，验证 Xavier 才是 tanh 的正确搭档。

### 案例 2（完整对照实验：一个"失败配置"被逐项修复）

在同一任务（第 1 章的 digits 数据）上系统对比 6 种配置，输出表格化训练结果——这是"训练科学"的标准实验设计（单变量消融）：

```python
import numpy as np
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split

X, y = load_digits(return_X_y=True); X /= 16.0
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.25, stratify=y, random_state=0)
d, K = 64, 10

def run(width, init_scale, lr, epochs=100, bn=False, seed=0):
    rng = np.random.default_rng(seed)
    W1 = rng.standard_normal((width, d)) * init_scale(d)
    W2 = rng.standard_normal((K, width)) * init_scale(width)
    b1 = np.zeros(width); b2 = np.zeros(K)
    g  = np.ones(width);  beta = np.zeros(width)     # BN 的 gamma/beta
    mu_e, var_e = np.zeros(width), np.ones(width)    # 推理统计(EMA)
    best = 0.0
    B = 32
    for ep in range(epochs):
        idx = rng.permutation(len(Xtr))
        for s in range(0, len(Xtr), B):
            j = idx[s:s+B]; Xb = Xtr[j]; m = len(j)
            Z1 = Xb @ W1.T + b1
            if bn:                                   # 训练模式 BN
                mu, var = Z1.mean(0), Z1.var(0)
                Z1h = (Z1 - mu) / np.sqrt(var + 1e-5)
                Z1n = g * Z1h + beta
                mu_e = 0.9*mu_e + 0.1*mu; var_e = 0.9*var_e + 0.1*var
            else:
                Z1n = Z1
            A1 = np.maximum(0, Z1n)
            Z2 = A1 @ W2.T + b2
            Z2 = Z2 - Z2.max(1, keepdims=True)
            P = np.exp(Z2); P /= P.sum(1, keepdims=True)
            Y = np.zeros((m, K)); Y[np.arange(m), ytr[j]] = 1
            D2 = (P - Y) / m
            dW2 = D2.T @ A1; db2 = D2.sum(0)
            D1 = (D2 @ W2) * (Z1n > 0)
            dW1 = D1.T @ Xb; db1 = D1.sum(0)
            if bn:                                   # BN 反传(2.3.3 公式) + gamma/beta 梯度
                gh = D1 * g
                G = (gh - gh.mean(0) - Z1h * (gh * Z1h).mean(0)) / np.sqrt(var + 1e-5)
                dW1 = G.T @ Xb; db1 = G.sum(0)
                dg = (D1 * Z1h).sum(0); dbeta = D1.sum(0)
                g -= lr * dg; beta -= lr * dbeta
            W1 -= lr * dW1; b1 -= lr * db1; W2 -= lr * dW2; b2 -= lr * db2
        if bn:  # 推理模式评估
            Z1e = (Xte @ W1.T + b1 - mu_e) / np.sqrt(var_e + 1e-5) * g + beta
            acc = np.mean(((np.maximum(0, Z1e) @ W2.T + b2).argmax(1)) == yte)
        else:
            acc = np.mean(((np.maximum(0, Xte @ W1.T + b1) @ W2.T + b2).argmax(1)) == yte)
        best = max(best, acc)
    return best

configs = [
    ("sigmoid激活+Xavier+lr0.5", 32, np.sqrt(1/64), 0.5, False),  # 占位: 下面换成函数
]
# 实际运行示例(ReLU):
for name, w, scale, lr, bn in [
    ("小初始化*0.01      ", 128, lambda f: 0.01,        0.5, False),
    ("Xavier(ReLU欠佳)   ", 128, lambda f: (1/f)**0.5,  0.5, False),
    ("He + lr=0.5        ", 128, lambda f: (2/f)**0.5,  0.5, False),
    ("He + lr=0.05       ", 128, lambda f: (2/f)**0.5, 0.05, False),
    ("He + BN + lr=0.5   ", 128, lambda f: (2/f)**0.5,  0.5, True),
]:
    print(f"{name}  best test acc = {run(w, scale, lr, bn=bn):.4f}")

# 预期输出(典型量级, 有随机浮动):
# 小初始化*0.01        best test acc ≈ 0.90~0.93 (收敛慢)
# Xavier(ReLU欠佳)     best test acc ≈ 0.94~0.96
# He + lr=0.5          best test acc ≈ 0.96~0.97
# He + lr=0.05         best test acc ≈ 0.93~0.95 (学习率偏小)
# He + BN + lr=0.5     best test acc ≈ 0.97~0.98 (最稳最快)
```

这个实验体现了"单变量消融"的实验方法论：每次只改一个因素。《实验设计与评估》课程将把它升级为带显著性检验的完整流程。

## 2.10 常见误区与陷阱

1. **忘记 `model.train()` / `model.eval()`**。BN 在推理时用了 batch 统计量（而非 EMA）或 dropout 在推理时仍生效——训练时精度好、部署即崩的头号来源。PyTorch 中这两个开关控制全局状态。
2. **对 BN 后的层再做 He 初始化的"补偿叠加"**。BN 已把输入钉回单位方差，其后的 He 因子 2 反而偏大；实践中无伤大雅，但理论上应按"BN 后输入方差恒定"重新配平（部分现代架构直接用 $1/\mathrm{fan\_in}$）。
3. **把过拟合归咎于"学太久"就一停了之**。早停是合理的默认，但更好的顺序是：先确认训练准确率还在升（模型容量没问题），再加正则/增强/数据，而不是简单砍训练时间。
4. **warmup 只对 Transformer 必要** 是误解——大学习率 + Adam + 无预训练初始化的任何场景都建议 warmup；但小 CNN 用 SGD 时通常不需要。
5. **"BN 使训练更稳，所以可以随便放大学习率"**。BN 平滑损失面但不改变大学习率下的噪声地板（《最优化方法》5.2 的结论仍适用）；放大学习率仍需逐步试探。
