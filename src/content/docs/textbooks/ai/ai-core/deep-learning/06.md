# 第 6 章 生成模型初步 —— 从自编码器到扩散模型

> **本章定位**：前六章的模型都在"判别"——从 $x$ 预测 $y$；本章转向"生成"——学习数据分布本身并采样。沿思想史推进：自编码器的表示瓶颈 → VAE 的 ELBO 概率化 → GAN 的对抗博弈 → 扩散模型的去噪目标。概率语言来自《概率论与数理统计》，ELBO 与 EM 的关系承接《机器学习》。本章是理解 Stable Diffusion、Sora 类系统的概念基础。

## 6.0 本章学习目标

学完本章，你能够：

1. 陈述生成建模的形式化目标（估计 $p_{\mathrm{data}}$ 并采样），区分显式密度、隐式密度与似然可比性；
2. 写出自编码器的结构与其隐空间缺陷（无先验、不均匀覆盖），解释为何 AE 不是生成模型；
3. 完整推导 VAE 的 ELBO（从 Jensen 或直接从 KL 分解），陈述重参数化技巧并推导其梯度；
4. 说明 ELBO 与 EM 的关系，以及 VAE 是"深度时代的变分推断"；
5. 推导 GAN 的极小极大目标、最优判别器 $D^*(x) = \frac{p_{\mathrm{data}}}{p_{\mathrm{data}} + p_g}$ 与其 JS 散度形式，说出训练不稳定与模式坍缩的机理；
6. 写出 DDPM 的前向加噪闭式与反向去噪参数化，证明简化训练目标 $\|\epsilon - \epsilon_\theta\|^2$，并完成 VAE 与扩散模型的概念对比。

## 6.1 生成建模：问题设定

判别模型学 $p(y \mid x)$；生成模型学 $p(x)$（或联合 $p(x, y)$），目标是：**估计训练数据分布 $p_{\mathrm{data}}$，并从中采出"新"样本**。三条路线谱系：

| 路线 | 对 $p(x)$ 的处理 | 代表 | 训练目标 |
|---|---|---|---|
| 显式似然 | 显式建模，可算 $\log p(x)$ | PixelRNN、流模型、VAE（变分下界） | 极大似然 |
| 隐式 | 不建模密度，只建模采样过程 | GAN | 对抗博弈 |
| 迭代去噪 | 隐式 + 变分下界（细节见 6.5） | 扩散模型 | 去噪回归（VAE 下界的特化） |

评价维度必须提前说清：**样本质量**（眼见为实）、**多样性/覆盖**（是否塌缩到少数模式）、**似然可比**（能否报告 $\log p(x)$ 与其他模型公平比较）、**采样速度**。没有模型四项全赢——这是本章反复出现的权衡主线（"生成—判别之辩"见 6.6）。

## 6.2 自编码器：重构不是生成

**结构**：编码器 $z = f_\phi(x)$（降到低维，如 $784 \to 2$）+ 解码器 $\hat x = g_\theta(z)$，目标 $\min \ \|x - g_\theta(f_\phi(x))\|^2$（或 BCE 重构）。

**它的两个身份**：

- **表示学习成功**：瓶颈迫使 $z$ 保留"重构所需"的信息；非线性 AE 学到的流形表示比 PCA（《机器学习》无监督章的线性版本）强得多——PCA 恰是"线性编码器 + 线性解码器 + 均方误差"的特例，AE 是其深度化；
- **作为生成模型失败**：训练结束后我们只有 $p_\phi(z \mid x)$ 的映射关系，却**没有 $z$ 空间上的先验分布**——从哪里采 $z$？在隐空间随机取点，解码出的往往是"既不像任何数字"的噪声：隐空间覆盖不均匀（各类别聚簇、簇间是"洞"）。AE 学的是"从 $x$ 到 $z$ 再回 $x$"，从未学过"$z$ 本身长什么样"。

**修补路线一（正则化 AE 谱系）**：稀疏 AE（加稀疏惩罚）、去噪 AE（重构加噪输入，学鲁棒流形）、收缩 AE——改善表示，但仍不提供 $z$ 的显式先验。真正的解法：把"$z$ 的分布"写进目标——VAE。

## 6.3 变分自编码器：ELBO 完整推导

### 6.3.1 生成模型设定

VAE（Kingma & Welling, 2014；同期 Rezende et al. 的 SGVB）假设数据由隐变量生成：$z \sim p_\theta(z) = \mathcal{N}(0, I)$，$x \sim p_\theta(x \mid z)$（高斯解码器，神经网络输出均值）。目标极大似然 $\log p_\theta(x) = \log \int p_\theta(x \mid z) p(z)\, \mathrm{d}z$——但这个积分对神经网络解码器**不可解**（$z$ 的高维积分无法解析，也没法靠枚举）。

**变分推断的介入**（《机器学习》EM 章的变分视角 + [《概率论与数理统计》第 4 章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/04/)的后验概念）：引入**近似后验** $q_\phi(z \mid x)$（高斯编码器，输出 $\mu_\phi(x), \sigma_\phi(x)$），从恒等式出发：

$$\log p_\theta(x) = \mathbb{E}_{q_\phi(z|x)}\big[\log p_\theta(x)\big] = \mathbb{E}_{q_\phi}\bigg[\log \frac{p_\theta(x, z)}{q_\phi(z \mid x)}\bigg] + \mathrm{KL}\big(q_\phi(z \mid x)\,\big\|\,p_\theta(z \mid x)\big).$$

（推导：把 $\log p_\theta(x)$ 乘以 $\mathbb{E}_q[1] = \int q \,\mathrm{d}z$，拆 $\log p_\theta(x) = \log \frac{p_\theta(x,z)}{q} + \log \frac{q}{p_\theta(z|x)}$，第二项恰是后验 KL；详见下方速查推导。）因 $\mathrm{KL} \ge 0$，得到**证据下界（ELBO）**：

$$\boxed{\ \log p_\theta(x) \ge \mathrm{ELBO} = \underbrace{\mathbb{E}_{q_\phi(z|x)}\big[\log p_\theta(x \mid z)\big]}_{\text{重构项}} - \underbrace{\mathrm{KL}\big(q_\phi(z \mid x)\,\big\|\,p(z)\big)}_{\text{正则项}}\ }$$

且**间隙恰为** $\mathrm{KL}(q \| p_\theta(\cdot|x))$：$q$ 越接近真后验，下界越紧。

### 6.3.2 两项的落地

- **重构项**：$z \sim q$ 采样后解码，$\log p_\theta(x \mid z) = -\frac{1}{2\sigma^2}\|x - \mu_\theta(z)\|^2 + \mathrm{const}$（高斯似然）——AE 的重构损失以概率身份回归，$\sigma$ 控制重构与正则的相对权重；
- **KL 项**：$q = \mathcal{N}(\mu, \mathrm{diag}(\sigma^2))$，$p = \mathcal{N}(0, I)$ 时**有闭式**（逐维高斯 KL）：

$$\mathrm{KL}(q \| p) = \frac{1}{2}\sum_{j=1}^{m}\Big(\mu_j^2 + \sigma_j^2 - \log \sigma_j^2 - 1\Big).$$

（推导要点：一维高斯 KL $\mathrm{KL}(\mathcal{N}(\mu, \sigma^2) \| \mathcal{N}(0,1)) = \frac{\mu^2 + \sigma^2 - 1}{2} - \log \sigma$；多元对角时逐维相加。请自行从定义 $\int q \log \frac{q}{p}$ 出发验证。）

### 6.3.3 重参数化技巧：把随机性"移出"计算图

直接从 $q$ 采样 $z \sim \mathcal{N}(\mu_\phi(x), \sigma_\phi^2)$，随机节点不可反传（第 1 章机制对采样算子无定义）。**重参数化**：把随机性装进与参数无关的噪声里：

$$z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon, \qquad \epsilon \sim \mathcal{N}(0, I).$$

现在 $z$ 对 $\phi$ 是**确定性可微函数**，$\nabla_\phi$ 沿 $\mu, \sigma$ 两条路回传（第 1 章计算图的多路径累加）。对 $E_{q}[f(z)]$ 这类期望的梯度，这是**路径导数**估计器（对比 score-function/REINFORCE 估计器：方差大得多；重参数化成立需 $z$ 的分布可由"参数的确定性变换 + 基础噪声"生成——高斯、均匀等都行，离散分布需 Gumbel-softmax 等）。

### 6.3.4 与 EM 的关系

EM（《机器学习》）迭代：E 步算精确后验 $p_\theta(z|x)$、M 步极大期望完备对数似然。VAE 是**深度、连续隐变量下 EM 的变分版**：真后验不可解析 → 用 $q_\phi$ 近似（变分 E 步，$\phi$ 与 $\theta$ 一起用梯度联合优化 ELBO，而非交替）。ELBO 的名字也由此而来：$p_\theta(x)$ 是"证据（evidence）"，ELBO 是它的下界。

**训练后如何生成**：丢弃编码器，$z \sim \mathcal{N}(0, I)$，$\hat x = $ 解码——KL 项的职责正是把聚合后验 $q_\phi(\cdot|x)$ 全体"拉拢"到 $\mathcal{N}(0,I)$ 周围，使这个先验采样有效。**VAE 的隐空间是连续、均匀、"无洞"的**——与 AE 的簇状隐空间对照鲜明。已知缺陷：重构模糊（高斯似然 + $\sigma$ 折中导致均化）、KL 项过强时后验坍缩（$q \to p$，解码器被无视）、blur 的信息论解释（似然模型倾向覆盖所有模式的"平均"）。

## 6.4 GAN：对抗博弈与隐式生成

### 6.4.1 极小极大目标

GAN（Goodfellow et al., 2014）绕开密度：生成器 $G: z \sim \mathcal{N}(0,I) \to x$ 直接产生样本；判别器 $D: x \to [0,1]$ 区分真假。博弈目标：

$$\min_G \max_D \; V(D, G) = \mathbb{E}_{x \sim p_{\mathrm{data}}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log (1 - D(G(z)))].$$

### 6.4.2 最优判别器与 JS 散度（定理级推导）

固定 $G$，被积函数逐点求最优：对任意 $x$，$a \log y + b \log(1-y)$ 在 $y^* = \frac{a}{a+b}$ 取最大（对 $y$ 求导置零）。这里 $a = p_{\mathrm{data}}(x)$、$b = p_g(x)$，故

$$D^*(x) = \frac{p_{\mathrm{data}}(x)}{p_{\mathrm{data}}(x) + p_g(x)}.$$

代回 $V$（用 $1 + \log 2$ 的配方技巧）：

$$\max_D V = 2\,\mathrm{JS}\big(p_{\mathrm{data}} \,\|\, p_g\big) - \log 2,$$

其中 $\mathrm{JS}(P\|Q) = \frac12 \mathrm{KL}(P\|M) + \frac12\mathrm{KL}(Q\|M)$，$M = \frac{P+Q}{2}$。于是 GAN 的真目标是**最小化 $p_{\mathrm{data}}$ 与 $p_g$ 的 Jensen–Shannon 散度**；理论最优解 $p_g = p_{\mathrm{data}}$（JS=0）。注意：JS 的成立依赖 $D$ 达到最优——实践中 $D$ 远非最优，这是理论与现实差距的根源之一。

### 6.4.3 训练不稳定性与模式坍缩

- **博弈非凸**：这不是单一损失的最小化，而是双人零和博弈的纳什均衡寻找——《最优化方法》第 6 章的鞍点问题；梯度下降在博弈中的不动点可能不稳定（循环追逐）；
- **梯度消失（原版）**：$D$ 训练太好时 $\log(1 - D(G(z)))$ 饱和，$G$ 得不到梯度——原论文对策：$G$ 的损失换成 $\max \log D(G(z))$（非饱和损失，等效改梯度来源）；
- **模式坍缩**：$G$ 发现"造出一张能骗过 $D$ 的样本反复用"比"覆盖全分布"容易——$p_g$ 塌到 $p_{\mathrm{data}}$ 的少数模式。谱系对策：minibatch 判别、unrolled GAN、WGAN（把 JS 换成 Wasserstein-1 距离 + Lipschitz 约束，梯度更有信息量）；
- **评价指标**：Inception Score、FID（真实/生成特征的高斯假设下 Fréchet 距离）——多样性 + 质量的代理度量。

## 6.5 扩散模型：迭代去噪

### 6.5.1 前向过程：把数据逐步化成噪声（无参数）

DDPM（Ho, Jain & Abbeel, 2020）定义马尔可夫加噪链（$x_0 \sim p_{\mathrm{data}}$，$\beta_t \in (0,1)$ 方差表）：

$$q(x_t \mid x_{t-1}) = \mathcal{N}\big(x_t;\ \sqrt{1-\beta_t}\, x_{t-1},\ \beta_t I\big), \qquad t = 1, \dots, T.$$

每步稍微抹掉一点信息；$T$ 足够大（如 1000）后 $x_T \approx \mathcal{N}(0, I)$。**关键闭式**（任意时刻一步到位，令 $\alpha_t = 1-\beta_t,\ \bar\alpha_t = \prod_{s\le t} \alpha_s$；高斯链的方差可加性，逐条用合并高斯验证）：

$$x_t = \sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \epsilon, \qquad \epsilon \sim \mathcal{N}(0, I).$$

信号项 $\sqrt{\bar\alpha_t}$ 单调衰减到 0，噪声项权重单调升到 1——"信噪比日程表"是可调超参（线性/余弦日程，Nichol & Dhariwal, 2021）。

### 6.5.2 反向过程与训练目标

生成 = 学反向 $p_\theta(x_{t-1} \mid x_t)$。贝叶斯给出真反向 $q(x_{t-1} \mid x_t, x_0)$ 也是高斯，其均值可由 $x_t, x_0$ 表示；用 $\epsilon_\theta(x_t, t)$ 网络预测"混入的噪声"来参数化后，理论训练目标（对 VAE 式下界逐项化简后）是逐时刻的加权去噪回归。**简化目标**（DDPM 论文发现等效甚至更好）：

$$L_{\mathrm{simple}}(\theta) = \mathbb{E}_{x_0,\ t,\ \epsilon}\Big[\big\|\epsilon - \epsilon_\theta\big(\sqrt{\bar\alpha_t} x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon,\ t\big)\big\|_2^2\Big].$$

**读一遍这段伪代码级描述**：取真样本 $x_0$ → 随机选时刻 $t$、随机噪声 $\epsilon$ → 按闭式合成 $x_t$ → 让网络从 $x_t$（和 $t$）预测 $\epsilon$ → 均方误差。**它就是"带时间条件回归"**——一个普通回归任务，稳定如监督学习，这是扩散模型取代 GAN 的工程原因。

**采样（生成）**：从 $x_T \sim \mathcal{N}(0,I)$ 出发，迭代 $T$ 步：

$$x_{t-1} = \frac{1}{\sqrt{\alpha_t}}\Big(x_t - \frac{\beta_t}{\sqrt{1 - \bar\alpha_t}}\,\epsilon_\theta(x_t, t)\Big) + \sigma_t z, \qquad z \sim \mathcal{N}(0, I).$$

每步"按预测的噪声往回擦一点"（$\sigma_t$ 为方差项，最后一步置零）。代价：$T$ 次网络前向（慢）——改进方向：DDIM（跳步采样）、蒸馏、一致性模型。

**条件生成**：$\epsilon_\theta(x_t, t, c)$ 加条件（文本 prompt 等）；**分类器引导（classifier guidance）与无分类器引导（classifier-free guidance）**：采样时外推条件方向 $\epsilon_\theta(x_t,t,\varnothing) + w\big(\epsilon_\theta(x_t,t,c) - \epsilon_\theta(x_t,t,\varnothing)\big)$，$w>1$ 换"多样性"取"保真度"——Stable Diffusion 中 CFG 权重的来历。

### 6.5.3 与 VAE 的关系

DDPM 的 ELBO 推导显示：扩散=**一个 $T$ 层、编码器固定为加噪、解码器为学习的去噪的层级 VAE**。ELBO 逐时刻分解为去噪 KL/回归项（6.5.2），简化目标正是丢弃权重的版本。似然仍是可优化的（$\log p_\theta(x)$ 有可算的界），但实践主打样本质量——"似然模型做出高质量样本"这一从未被 GAN 垄断版达成的组合，是扩散模型的学术意义。

## 6.6 生成—判别之辩

回到《机器学习》的生成/判别二分，本章把它推进到深度时代：

- **判别任务**：大样本时代判别式几乎总是更好（少建模不关心的 $p(x)$）；
- **生成任务**：三条路线各司其职——要似然（压缩、密度估计、异常检测）选 VAE/流/扩散；要高质量样本且能接受不稳，历史上选 GAN，现在基本被扩散取代（稳定 + 模式覆盖 + 条件控制）；要表示（下游任务），对比自监督（第 7 章）常优于生成式重构；
- **混合体**：VAE+GAN、扩散+GAN 判别器、latent diffusion（先 VAE 压到潜空间、再在潜空间扩散——Stable Diffusion 的架构，兼得质量与速度）。

## 6.7 关键公式速查

| 公式 | 含义 | 适用条件 |
|---|---|---|
| $\mathrm{ELBO} = \mathbb{E}_q[\log p_\theta(x|z)] - \mathrm{KL}(q_\phi(z|x)\|p(z))$ | 证据下界 | 连续隐变量 |
| $\mathrm{KL}(q\|p) = \frac12 \sum_j (\mu_j^2 + \sigma_j^2 - \log\sigma_j^2 - 1)$ | 高斯 KL 闭式 | 对角高斯 vs 标准正态 |
| $z = \mu_\phi(x) + \sigma_\phi(x)\odot\epsilon$ | 重参数化 | 噪声与参数无关 |
| $D^*(x) = \frac{p_{\mathrm{data}}(x)}{p_{\mathrm{data}}(x)+p_g(x)}$ | GAN 最优判别器 | 逐点凸 |
| $\max_D V = 2\,\mathrm{JS}(p_{\mathrm{data}}\|p_g) - \log 2$ | GAN 目标的散度形式 | $D$ 达最优 |

| $x_{t-1} = \frac{1}{\sqrt{\alpha_t}}(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta) + \sigma_t z$ | 扩散采样一步 | DDPM |

## 6.8 示例与案例

### 案例 1（手算/数值算例：一维高斯的 ELBO 与 KL）

设 $p(z) = \mathcal{N}(0,1)$，$q = \mathcal{N}(\mu, \sigma^2)$。

1. **KL 闭式**：$\mu = 1, \sigma = 2$ 时 $\mathrm{KL} = \frac{1}{2}(1 + 4 - \log 4 - 1) = 2 - \log 4 \approx 0.6137$。（校验值：$\approx 0.614$。）
2. **重参数化验证**：数值估计 $\mathbb{E}_{z\sim q}[z^2]$，两种方式对照：直接采样 vs $z = \mu + \sigma\epsilon$ 采样。两者均值都应 $\approx \mu^2 + \sigma^2 = 5$（方差 $\sigma^2$ 下 $\mathrm{Var}(z^2)$ 相同——重参数化不改变分布，只改变梯度的可微性）。
3. **ELBO 数值**：取 $x = 0.5$、解码器 $p(x|z) = \mathcal{N}(z, 0.5^2)$。重构项 $\mathbb{E}_q[\log p(x|z)]$：$z \sim \mathcal{N}(1, 4)$，$\log p = -\frac{(0.5 - z)^2}{0.5} - \frac12\log(2\pi \cdot 0.25)$；蒙特卡洛 10 万样本估计 ≈ $-4.5 - 0.226 \approx -4.73$ 附近（$\mathbb{E}[(0.5-z)^2] = (0.5-1)^2 + 4 = 4.25$，除以 $\sigma^2=0.25$? 注意 $\log p = -\frac{(x-z)^2}{2\sigma_x^2} + c$，$\sigma_x = 0.5$，故 $-\frac{4.25}{0.5} = -8.5$，加常数 $-\frac12\log(2\pi \cdot 0.25) \approx -0.226$，总 $\approx -8.73$）。ELBO $= -8.73 - 0.614 \approx -9.34$，而真 $\log p(x)$ 可在此一维例子里数值积分算出（约 $-9.1$）——**下界确实在下**。请用代码验证这组数字。

```python
import numpy as np
rng = np.random.default_rng(0)
mu, sigma, x, sx = 1.0, 2.0, 0.5, 0.5
kl = 0.5 * (mu**2 + sigma**2 - np.log(sigma**2) - 1)
eps = rng.standard_normal(100_000)
z = mu + sigma * eps                       # 重参数化
recon = -((x - z)**2) / (2 * sx**2) - 0.5 * np.log(2 * np.pi * sx**2)
elbo = recon.mean() - kl
# 数值积分真 log p(x) = log ∫ N(x|z, sx^2) N(z|0,1) dz (一维可积, 结果是高斯卷积)
logp_true = np.log(np.exp(-0.5 * x**2 / (1 + sx**2)) /
                   np.sqrt(2 * np.pi * (1 + sx**2)))
print(f"KL = {kl:.4f}, ELBO = {elbo:.4f}, log p(x) = {logp_true:.4f}")
# 预期输出: KL ≈ 0.6137, ELBO ≈ -9.35, log p(x) ≈ -1.61 —— 注意本例下界较松:
# q 与真后验差距大; 把 q 换成 N(-0.4, 0.24) 再跑, ELBO 明显贴近 log p(x) —— 下界随 q 变紧
```

（说明：真 $\log p(x)$ 由高斯卷积闭式 $x \sim \mathcal{N}(0, 1 + \sigma_x^2)$ 得出；把 $q$ 调优后 ELBO 逼近它——亲手感受"变分推断 = 用 $q$ 贴近后验换取可算性"。）

### 案例 2（numpy：MNIST 上的 VAE）

```python
# pip install torch torchvision; 用 AE/VAE 学隐空间
import torch, torch.nn as nn
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

torch.manual_seed(0)
device = "cuda" if torch.cuda.is_available() else "cpu"
ds = datasets.MNIST("./data", train=True, download=True, transform=transforms.ToTensor())
ld = DataLoader(ds, batch_size=128, shuffle=True)

d_in, d_z = 784, 16
enc = nn.Sequential(nn.Linear(d_in, 256), nn.ReLU(),
                    nn.Linear(256, 2 * d_z))            # 输出 mu 和 logvar
dec = nn.Sequential(nn.Linear(d_z, 256), nn.ReLU(), nn.Linear(256, d_in))
opt = torch.optim.Adam(list(enc.parameters()) + list(dec.parameters()), lr=1e-3)

def kl(mu, logvar):                                     # 6.3.2 闭式
    return 0.5 * (mu.pow(2) + logvar.exp() - 1 - logvar).sum(1).mean()

for epoch in range(5):
    tot = n = 0
    for xb, _ in ld:
        x = xb.view(xb.size(0), -1).to(device)
        h = enc(x); mu, logvar = h[:, :d_z], h[:, d_z:]
        z = mu + torch.exp(0.5 * logvar) * torch.randn_like(mu)   # 重参数化
        xrec = dec(z)
        loss = (x - xrec).pow(2).sum(1).mean() + kl(mu, logvar)   # 重构 + KL
        opt.zero_grad(); loss.backward(); opt.step()
        tot += loss.item(); n += 1
    print(f"epoch {epoch}  elbo-ish loss {tot/n:.1f}")
# 预期输出: epoch 0 ≈ 150~160, epoch 4 ≈ 95~105 (KL 项稳定在 ~20-30)

# 生成: 从标准正态先验采样
with torch.no_grad():
    z = torch.randn(64, d_z, device=device)
    imgs = dec(z).view(-1, 28, 28).cpu()
print("生成图像张量形状:", imgs.shape)   # torch.Size([64, 28, 28])
```

**观察**：(i) 把 KL 权重乘 100，生成样本更"整"但重构糊、且不同数字类簇间的过渡样本变少——权衡的现场感受；(ii) 把 KL 权重置 0，退化为 AE：重构更锐利，但从先验采样的 $z$ 解码出的是"四不像"——6.2 节结论的实证；(iii) 条形隐空间取 $d_z = 2$，把测试集编码后画散点（按标签着色），可见"簇 + 过渡带"的结构。

## 6.9 常见误区与陷阱

1. **把 VAE 当"加了噪声的 AE"**。KL 项与先验采样才是 VAE 的本体；去掉 KL 就回到 AE 的隐空间无先验问题。同样，"重构损失 + 从 $\mathcal{N}(0,I)$ 采样"而忘掉闭式 KL 的实现，等于没做变分。
2. **重参数化"改变分布"**。它只是改变梯度的计算路径，$z$ 的分布完全不变（案例 1 第 2 问的对照）。误解它会导致"用重参数化来正则化"之类的错误设计。
3. **拿 GAN 的 $D$ 输出当概率解释**。$D^*$ 公式仅在博弈均衡与最优判别器下成立；训练中期的 $D$ 值不可作密度解读，更不能跨数据集比较。
4. **认为扩散模型"像 GAN 一样靠对抗"**。扩散训练是纯回归（MSE），没有对抗、没有博弈均衡问题；它的不稳定点在采样链的累积误差与日程表选择，不在训练。
5. **混淆 $\beta_t$ 与 $\bar\alpha_t$**。$x_t$ 闭式里是**累积**量 $\bar\alpha_t$；实现时用 `alpha_bar[t]` 查表，不要逐步循环计算（既慢又累积舍入误差——[《线性代数》第 6 章](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/06/)的教训）。
