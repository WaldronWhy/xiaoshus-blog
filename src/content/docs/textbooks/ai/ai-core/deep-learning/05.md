# 第 5 章 Transformer 与自注意力

> **本章定位**：现代 AI 的主干架构。本章把第 4 章的注意力机制推向其完备形态——自注意力与 Transformer：QKV 的完整推导、缩放因子的方差论证、多头机制、位置编码、残差与 LayerNorm 的布局、逐块拆解、$O(n^2)$ 复杂度分析，并用 PyTorch 手写 Transformer 块。此后一切大模型（GPT/BERT/CLIP/Stable Diffusion 的骨干）都是本章组件的排列组合。

## 5.1 从 Bahdanau 到自注意力：一个决定性的抽象

第 4 章末尾指出：注意力 = 查询（Query）对一组键（Key）打分、聚合对应值（Value）。Transformer（Vaswani et al., 2017）的第一步是把这套机制**通用化并标准化**：

- 查询、键、值不再来自不同 RNN，而是**同一序列的每个位置**通过三个可学习矩阵投影得到；
- 打分从加性改为**点积**——纯矩阵乘法，GPU 友好、完全并行；
- 彻底**抛弃循环**：序列内所有位置在同一层中两两交互。

先点破自注意力的语义：它是**可微分的软字典查找**。普通字典：给一个 key，精确返回对应 value。软字典：查询与所有 key 做相似度，softmax 成权重，返回 value 的加权和——"按相关性混合取值"。序列建模需要的"上下文相关表示"恰好是这种操作：一个词的表示应由"与它相关的上下文"动态构成。

## 5.2 缩放点积自注意力：完整推导

### 5.2.1 QKV 投影

输入序列表示矩阵 $X \in \mathbb{R}^{n \times d_{\mathrm{model}}}$（$n$ 个 token，每行一个表示）。三个投影：

$$Q = X W_Q,\quad K = X W_K,\quad V = X W_V, \qquad W_Q, W_K \in \mathbb{R}^{d_{\mathrm{model}} \times d_k},\ W_V \in \mathbb{R}^{d_{\mathrm{model}} \times d_v}.$$

### 5.2.2 注意力输出

$$\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\Big(\frac{Q K^\top}{\sqrt{d_k}}\Big) V,$$

其中 softmax 按行做（每行是"一个查询对所有键"的分布）。逐步解读：

1. **打分** $S = QK^\top \in \mathbb{R}^{n \times n}$：$S_{ij} = q_i^\top k_j$ 是第 $i$ 个位置对第 $j$ 个位置的相似度（内积 = 余弦相似度去掉归一化，[《线性代数》第 1 章](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/01/)的内积视角）；
2. **缩放** $\frac{1}{\sqrt{d_k}}$：见 5.2.3 的方差论证；
3. **归一化** $A = \mathrm{softmax}(S)$（按行）：每行变成权重分布 $\alpha_{ij}$，$\sum_j \alpha_{ij} = 1$；
4. **聚合** $A V$：输出第 $i$ 行 $= \sum_j \alpha_{ij} v_j$，是所有值向量按相关性的凸组合。

整个操作只有矩阵乘、softmax——$n$ 个位置**同时**完成交互，无任何串行依赖。

### 5.2.3 为什么除以 $\sqrt{d_k}$：方差论证

设 $q, k$ 的分量独立、零均值、方差 1（由适当初始化/归一化近似保证），则点积

$$s = q^\top k = \sum_{i=1}^{d_k} q_i k_i, \qquad \mathrm{Var}(s) = \sum_i \mathrm{Var}(q_i k_i) = d_k \quad (\text{独立积的方差} = \mathrm{Var}(q_i)\mathrm{Var}(k_i) = 1).$$

（用[《概率论与数理统计》第 3 章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/03/)的方差运算法则。）于是 $d_k = 64$ 时 $s$ 的标准差为 8——logits 分布过宽，softmax 落入**饱和区**（个别分量接近 1，其余接近 0）：梯度 $\mathrm{diag}(a) - aa^\top$ 几乎为零（第 4 章公式 $\partial p_i/\partial z_j = p_i(\delta_{ij}-p_j)$ 在硬分布下退化），注意力"一锤定音"而无法学习。除以 $\sqrt{d_k}$ 把方差拉回 1，softmax 保持在可学习区。**这是"高维内积的尺度随维度增长"的普适现象**——与第 2 章初始化的方差守恒、第 7 章对比学习的相似度缩放是同一族问题。

### 5.2.4 因果掩码（语言模型所需）

自回归生成要求位置 $i$ 只能看 $\le i$ 的位置。实现：打分后对 $j > i$ 的位置加 $-\infty$（代码中加一个 $-\infty$ 的上三角掩码或 `masked_fill`）再 softmax——被掩位置的权重精确为 0，梯度也为 0。这正是 GPT 式解码器与 BERT 式编码器的唯一结构性区别之一（双向 = 无掩码）。

## 5.3 多头注意力

单头注意力的 softmax 是"软"的：一次只能做一种加权聚合。**多头（multi-head）**把它并行化到 $h$ 个子空间：

$$\mathrm{head}_i = \mathrm{Attention}\big(X W_Q^{(i)},\ X W_K^{(i)},\ X W_V^{(i)}\big), \quad d_k = d_v = \frac{d_{\mathrm{model}}}{h},$$

$$\mathrm{MHA}(X) = \mathrm{Concat}(\mathrm{head}_1, \dots, \mathrm{head}_h)\, W_O, \qquad W_O \in \mathbb{R}^{d_{\mathrm{model}} \times d_{\mathrm{model}}}.$$

**设计要点**：每个头的 $d_k$ 缩小 $h$ 倍，总计算量与一个全维单头**相同**——多头是"分预算"而非"加预算"。不同头可学到不同关系类型（句法依配、共指、位置邻近等；对 BERT 的探针实验证实头功能分化）。

**参数量**：$W_Q, W_K, W_V, W_O$ 各 $d_{\mathrm{model}}^2$（投影合起来仍是满维），共 $4 d_{\mathrm{model}}^2$；加上 FFN 的 $2 \times d_{\mathrm{model}} \times 4d_{\mathrm{model}} = 8 d_{\mathrm{model}}^2$，**每个 Transformer 块 $12 d_{\mathrm{model}}^2$**——记住这个数，它是大模型参数估算的常用公式。

## 5.4 位置编码：给无序机制注入顺序

自注意力是**置换等变**的：打乱输入行，输出相应打乱——序列顺序信息对它完全不可见。必须显式注入位置。

**正弦位置编码（原文方案）**：对位置 $pos$ 与维度 $i$：

$$PE_{(pos,\, 2i)} = \sin\Big(\frac{pos}{10000^{2i/d}}\Big), \qquad PE_{(pos,\, 2i+1)} = \cos\Big(\frac{pos}{10000^{2i/d}}\Big).$$

性质：(i) 每一维是不同波长的正弦，$PE_{pos}$ 唯一；(ii) **相对位移可线性表达**：$PE_{pos+k}$ 是 $PE_{pos}$ 的线性变换（$\sin(a+b)$ 展开为 $2\times2$ 旋转矩阵作用于相邻维对）——模型理论上易学相对位置；(iii) 可外推到训练长度之外（实践中效果有限）。$x_{pos} = \mathrm{token\_emb}(pos) + PE_{pos}$（相加而非拼接，省参数）。

**演化谱系**（思想脉络）：学习式绝对编码（BERT/GPT-2 的可训练位置向量）→ 相对位置编码（T5 bias、Transformer-XL）→ **旋转位置编码 RoPE**（把"相对位置 = 查询键的内积只依赖 $m - n$"做成对 $q, k$ 的旋转变换，LLaMA 等现代 LLM 默认）→ ALiBi（线性距离惩罚）。本课程只需掌握正弦版的机制与"为什么需要"的原理，具体谱系在《自然语言处理》展开。

## 5.5 完整架构逐块拆解

### 5.5.1 Transformer 块（训练的主循环单元）

现代 **pre-LN** 布局（GPT-2 之后的主流，训练更稳）：

$$x \leftarrow x + \mathrm{MHA}\big(\mathrm{LN}(x)\big), \qquad x \leftarrow x + \mathrm{FFN}\big(\mathrm{LN}(x)\big),$$

$$\mathrm{FFN}(x) = GELU(x W_1 + b_1) W_2 + b_2, \qquad d_{\mathrm{ff}} = 4 d_{\mathrm{model}}.$$

三个组件各自的角色，全部来自前面章节：

- **残差连接**（第 3 章 3.4.2）：梯度恒等通路 $\Delta^{(l)} = \Delta^{(l+1)}(I + \partial \mathrm{Sublayer}/\partial x)$，深层可训；
- **LayerNorm**（第 2 章 2.3 的 BN 的变体）：对**每个样本的特征维**归一化 $\hat x = \frac{x - \mu}{\sigma} \odot \gamma + \beta$。不用 BN 的原因：变长序列上 batch 统计量不稳定，且推理需维护 EMA；LN 无跨样本依赖。深层 pre-LN 还为残差提供"归一化的输入"，缓解表示无限增长（ResNet 深层的激活尺度漂移问题）；
- **FFN**：逐位置的两层 MLP（第 1 章），承担"记忆与变换"——探针实验表明事实性知识多存于 FFN 权重。

### 5.5.2 编码器、解码器与三种注意力

原始 Transformer（机器翻译的 encoder–decoder，直接继承第 4 章框架）：

1. **编码器**：$N$ 个块串联，块内自注意力**双向**（无掩码）——每个位置看全句；
2. **解码器**：$N$ 个块，块内含两个注意力子层：
   - **掩码自注意力**（因果，5.2.4）——保证自回归合法；
   - **交叉注意力（cross-attention）**：$Q$ 来自解码器表示，$K, V$ 来自**编码器末层输出**——正是第 4 章 Bahdanau 注意力的角色分工（解码查询源句），只是打分换成点积；
3. **输入端**：token 嵌入 × $\sqrt{d}$ + 位置编码（$\sqrt{d}$ 平衡嵌入与 PE 的尺度）；**输出端**：线性层 + softmax（常与嵌入层共享权重，tied embedding）。

三类模型范式一览（现代用法）：

| 范式 | 注意力 | 代表 | 适用 |
|---|---|---|---|
| encoder-only | 双向自注意力 | BERT | 理解/分类/抽取 |
| decoder-only | 因果自注意力 | GPT | 生成（现代 LLM 主流） |
| encoder–decoder | 双向 + 掩码 + 交叉 | T5、原始 Transformer | 序列到序列 |

### 5.5.3 梯度通路（用第 1 章语言走一遍）

以因果自注意力的 $W_Q$ 为例：$\partial \ell / \partial Q = \partial \ell/\partial A \cdot \partial A/\partial S \cdot K$ 型三段复合——$\partial A/\partial S$ 是逐行 softmax 的 Jacobian（第 4 章公式 $\mathrm{diag}(a) - aa^\top$ 的批量版）；$Q = XW_Q$ 是批量线性层，故 $\partial \ell/\partial W_Q = (\partial \ell/\partial Q)^\top X$（第 1 章核心公式）。注意 $X$ 同时经过 $W_Q, W_K, W_V$ 三条路径，梯度相加——第 1 章"多次使用则累加"的再次兑现。$A V$ 聚合对 $V$ 的梯度是 $A^\top (\partial \ell/\partial \mathrm{out})$，对 $A$ 的梯度被 $V$ 加权——注意力权重本身也可学习地被上游"重新分配"。

## 5.6 复杂度分析：$O(n^2)$ 的代价与收益

设序列长 $n$、表示维 $d$、FFN 维 $4d$。单块：

| 操作 | 时间 | 空间（激活） | 可并行性 |
|---|---|---|---|
| QKV 投影 + 输出投影 | $O(n d^2)$ | $O(n d)$ | 全并行 |
| 打分 $QK^\top$ | $O(n^2 d)$ | $O(n^2)$ | 全并行 |
| 聚合 $AV$ | $O(n^2 d)$ | — | 全并行 |
| FFN | $O(n d^2)$（$d_{ff}=4d$ 时为 $8 n d^2$ 系数口径不同） | $O(n d)$ | 全并行 |

**自注意力 $O(n^2 d)$ vs RNN $O(n d^2)$**：序列短、$d$ 大时 RNN 更省；$n \gtrsim d$ 时自注意力的 $n^2$ 项主导。两笔账要分开算：

- **训练总时间**：Transformer 全并行（$n$ 步 RNN 计算被压成常数深度），GPU 利用率高一个数量级——这是它"主宰"的第一原因；
- **任意两位置的信息通路长度**：RNN 需 $O(n)$ 步（梯度路径长，第 4 章的消失问题）；自注意力 $O(1)$ 步直达——这是第二原因（学习长程依赖容易）；
- **代价**：$O(n^2)$ 激活内存限制上下文长度（$n = 10^5$ 时注意力矩阵本身 $10^{10}$ 元素），催生 FlashAttention（分块重算，I/O 感知精确注意力）与线性注意力家族——见进阶方向。

## 5.7 为什么 Transformer 成为主宰架构

汇总成四条，每条都有前文的数学依据：

1. **训练完全并行**（5.6）：$n$ 个位置的表示一步算完，规模扩展不受串行深度限制；
2. **长程依赖一跳直达**（5.6 + 第 4 章对照）：梯度不随距离衰减（残差 + 注意力直连）；
3. **归纳偏置最小化**：CNN 的局部性/平移先验、RNN 的时序先验都被移除，"结构"只剩集合式两两交互——**表达能力让位给数据**。这解释了"大数据吃掉归纳偏置"的现象：小数据 CNN 更好，大数据/多模态 Transformer 通吃（ViT 直接把图像切块当 token，第 3 章结尾埋的问题在此揭晓）；
4. **架构统一性**：文本、图像 patch、音频帧、蛋白质残基、代码——只要能变成 token 序列，同一个块即可处理。一种架构 + 一种训练范式（第 7 章自监督）= 规模化的技术前提。

## 5.8 关键公式速查

| 公式 | 含义 | 适用条件 |
|---|---|---|
| $\mathrm{Attn}(Q,K,V) = \mathrm{softmax}(QK^\top/\sqrt{d_k})V$ | 缩放点积注意力 | softmax 按行 |
| $\mathrm{Var}(q^\top k) = d_k$（单位方差分量） | 缩放 $\sqrt{d_k}$ 的依据 | 分量独立零均值 |
| $\mathrm{MHA} = \mathrm{Concat}(\mathrm{head}_1..\!h)\,W_O$ | 多头聚合 | $d_k = d/h$ |
| $PE_{pos,2i} = \sin(pos/10000^{2i/d})$ | 正弦位置编码 | 维对取 sin/cos |
| $x \leftarrow x + \mathrm{MHA}(\mathrm{LN}(x))$；$x \leftarrow x + \mathrm{FFN}(\mathrm{LN}(x))$ | pre-LN 块 | 现代默认布局 |
| 块参数 $= 12 d^2$（含 $4d$ FFN） | 参数估算 | 标准配置 |
| 单块时间 $O(n d^2 + n^2 d)$ | 复杂度 | $n$ 长 $d$ 维 |
| $S_{ij} = -\infty\ (j > i)$ | 因果掩码 | 自回归解码 |

## 5.9 示例与案例

### 案例 1（手算算例：2 token、$d_k=2$ 的完整注意力）

取 $q_1 = (2, 0), q_2 = (0, 1)$；$k_1 = (1, 0), k_2 = (0, 2)$；$v_1 = (1, 0), v_2 = (0, 1)$（省略 $\sqrt{d_k}=\sqrt2$ 以便心算，此处展示机制）。

打分：$s_{11} = 2,\ s_{12} = 0,\ s_{21} = 0,\ s_{22} = 2$。softmax 逐行：第 1 行 $e^2/(e^2+1) \approx 0.881$ → $a_1 = (0.881, 0.119)$；同理 $a_2 = (0.119, 0.881)$。聚合：$\mathrm{out}_1 = 0.881 v_1 + 0.119 v_2 = (0.881, 0.119)$；$\mathrm{out}_2 = (0.119, 0.881)$。

**读出三个现象**：(i) 输出是值的凸组合（分量和为 1）；(ii) 若 $s$ 乘以 10（相当于不缩放的高维情形），softmax → $(0.99995, 0.00005)$——饱和，梯度 $\mathrm{diag}(a)-aa^\top \approx 0$；(iii) 输出行 $i$ 的相似性结构由 $q_i k_j$ 决定，与 $v$ 无关——查询/值解耦的意义。（校验值：$a_1 \approx (0.881, 0.119)$。）

### 案例 2（PyTorch：手写 Transformer 块 + 小型因果语言模型）

```python
# pip install torch
import torch, torch.nn as nn, torch.nn.functional as F, math

class Block(nn.Module):                       # pre-LN Transformer 块
    def __init__(self, d, h):
        super().__init__()
        self.ln1 = nn.LayerNorm(d)
        self.qkv = nn.Linear(d, 3 * d)        # QKV 合并投影(工程惯例)
        self.proj = nn.Linear(d, d)
        self.ln2 = nn.LayerNorm(d)
        self.ffn = nn.Sequential(nn.Linear(d, 4*d), nn.GELU(), nn.Linear(4*d, d))
        self.h = h
    def forward(self, x):                     # x: (B, n, d)
        B, n, d = x.shape
        h = self.ln1(x)
        q, k, v = self.qkv(h).split(d, dim=2)
        # 多头: 把 d 拆成 h 个 d/h 维子空间, 头维放进 batch 维并行
        q = q.view(B, n, self.h, d // self.h).transpose(1, 2)   # (B, h, n, dk)
        k = k.view(B, n, self.h, d // self.h).transpose(1, 2)
        v = v.view(B, n, self.h, d // self.h).transpose(1, 2)
        att = (q @ k.transpose(-2, -1)) / math.sqrt(k.size(-1)) # (B, h, n, n)
        mask = torch.triu(torch.ones(n, n, device=x.device), diagonal=1).bool()
        att = att.masked_fill(mask, float("-inf"))              # 因果掩码
        att = att.softmax(dim=-1)
        y = (att @ v).transpose(1, 2).reshape(B, n, d)          # 拼回各头
        x = x + self.proj(y)                                     # 残差1
        x = x + self.ffn(self.ln2(x))                            # 残差2
        return x

class MiniGPT(nn.Module):
    def __init__(self, vocab, d=128, h=4, depth=4, maxlen=64):
        super().__init__()
        self.tok = nn.Embedding(vocab, d)
        self.pos = nn.Embedding(maxlen, d)                        # 学习式位置编码
        self.blocks = nn.Sequential(*[Block(d, h) for _ in range(depth)])
        self.ln = nn.LayerNorm(d)
        self.head = nn.Linear(d, vocab)
        self.apply(self._init)                                    # GPT-2 式初始化
    def _init(self, m):
        if isinstance(m, (nn.Linear, nn.Embedding)):
            nn.init.normal_(m.weight, std=0.02)
    def forward(self, idx):                   # idx: (B, n) token id
        B, n = idx.shape
        x = self.tok(idx) + self.pos(torch.arange(n, device=idx.device))
        x = self.blocks(x)
        return self.head(self.ln(x))          # (B, n, vocab) 每位预测下一 token

# ---- 训练: 在一段重复文本上做字符级语言模型 ----
import urllib.request
try:
    text = urllib.request.urlopen(
        "https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt"
    ).read().decode("utf-8")[:200000]         # tiny shakespeare 片段
except Exception:
    text = "深度学习是现代人工智能的通用引擎。" * 3000   # 离线兜底语料
chars = sorted(set(text)); c2i = {c: i for i, c in enumerate(chars)}
data = torch.tensor([c2i[c] for c in text], dtype=torch.long)

model = MiniGPT(len(chars))
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)
sched = torch.optim.lr_scheduler.OneCycleLR(opt, max_lr=1e-3, total_steps=1000)
n = 64
for step in range(1001):
    i = torch.randint(len(data) - n - 1, (32,))
    xb = torch.stack([data[j:j+n] for j in i])          # (B, n)
    yb = torch.stack([data[j+1:j+n+1] for j in i])      # 下一位预测目标
    loss = F.cross_entropy(model(xb).reshape(-1, len(chars)), yb.reshape(-1))
    opt.zero_grad(); loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)  # 第4章裁剪(第8章详解)
    opt.step(); sched.step()
    if step % 200 == 0:
        print(f"step {step:4d}  loss {loss.item():.4f}  ppl {math.exp(loss.item()):.2f}")

# 采样(自回归生成)
model.eval()
idx = torch.zeros(1, 1, dtype=torch.long)     # 起始 token 0
for _ in range(120):
    logits = model(idx[:, -n:])[:, -1]        # 只用最近 n 个位置
    probs = F.softmax(logits / 0.8, dim=-1)   # 温度采样
    idx = torch.cat([idx, torch.multinomial(probs, 1)], dim=1)
print("生成:", "".join(i2c[i] for i in idx[0].tolist()))

# 预期输出(量级):
# step    0  loss ≈ 4.4  ppl ≈ 81   (≈ ln|chars| = ln 65 ≈ 4.17, 初始体检通过)
# step  400  loss ≈ 1.6 ~ 2.0  ppl ≈ 5 ~ 7
# step 1000  loss ≈ 1.3 ~ 1.6  ppl ≈ 4 ~ 5
# 生成: 拼写正确的"伪莎士比亚"风格片段(1000 步内学出词形与标点节律)
```

**观察**：(i) 初始 ppl ≈ 词表大小——第 2 章体检；(ii) warmup 由 OneCycle 内建；(iii) 把 `math.sqrt(k.size(-1))` 删掉重跑，loss 明显变差且头部分布更尖锐——5.2.3 方差论证的实证；(iv) 把 mask 去掉，loss 更低但生成完全混乱——训练/推理行为不一致的教训。

## 5.10 常见误区与陷阱

1. **缩放/掩码的顺序错误**。掩码必须在 softmax **之前**加 $-\infty$；对已 softmax 的权重置零不等于掩码（softmax 未重新归一化，破坏分布且梯度错误）。
2. **多头 reshape 的维度错位**。`(B, n, h, dk)` 与 `(B, h, n, dk)` 混淆会导致"头间信息泄漏"或形状报错；正确的做法如案例 2 的 `view + transpose`，务必用小例子手验。
3. **以为位置编码"拼接"更好**。拼接会增加维度与参数，且使位置信息在后续层中更难与内容融合；相加是尺度上更平衡的标准做法（嵌入 × $\sqrt{d}$ 就是为匹配 PE 的幅度）。
4. **把 $O(n^2)$ 当成不可逾越**。$n^2$ 限制的是**上下文长度**而非能力；工程上有 FlashAttention（exact）、滑动窗口、线性注意力等大量缓解手段——但都改变了"全局一跳直达"的性质，需权衡。
5. **pre-LN 与 post-LN 混用/调参误判**。post-LN（原论文）没有 final LayerNorm 且深层更难训；pre-LN 块的残差主干"未归一化"，导致表示尺度随深度温和增长——不少"训练不稳"的报告其实是两者布局混搭所致。统一布局 + final LN 是现代默认。
