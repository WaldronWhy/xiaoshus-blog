# 第 3 章 图像分类·CNN 时代

> **本章定位**：本章把《深度学习》第 3 章（CNN 结构）与第 7 章（预训练与迁移）的结论落地到视觉的第一大任务——图像分类，并完成迁移学习实战与模型可解释性（Grad-CAM）。本章的分类骨干（ResNet）与评估习惯（Top-1/Top-5）是第 4 章检测分割、第 5 章 ViT 对比的共同参照系。

3. 用 torchvision 预训练 ResNet 在小数据集上完成特征提取与微调两种迁移策略，并做出正确的层冻结与学习率分层决策；

## 3.1 分类任务定义与评价指标

### 3.1.1 任务形式化

给定图像 $x \in \mathbb{R}^{3\times H\times W}$ 与类别集合 $\mathcal{Y} = \{1, \dots, K\}$，学习映射 $f_\theta : \mathbb{R}^{3H W} \to \mathbb{R}^K$，训练目标为交叉熵（[深度学习·第 1 章](/xiaoshus-blog/textbooks/ai/ai-core/deep-learning/01/)）：

$$
\mathcal{L} = -\frac{1}{N} \sum_{i=1}^{N} \log \frac{\exp\big(f_\theta(x_i)_{y_i}\big)}{\sum_{k=1}^{K} \exp\big(f_\theta(x_i)_k\big)}
$$

推理时预测 $\hat y = \arg\max_k f_\theta(x)_k$。与《机器学习》第 7 章一致：**测试集必须与训练集独立同分布（i.i.d.），且每个样本只允许用来评一次**——反复在测试集上选模型等于信息泄漏。

### 3.1.2 Top-1 与 Top-5

设模型输出概率排序后前 $k$ 名的集合为 $\operatorname{Top}_k(x)$：

$$
\operatorname{Acc@}k = \frac{1}{N} \sum_{i=1}^{N} \mathbb{1}\big[\, y_i \in \operatorname{Top}_k(x_i) \,\big]
$$

- **Top-1**：正确类恰为第一名的比例，即通常意义的准确率；
- **Top-5**：正确类进入前五名的比例。ImageNet 有 1000 类且存在大量细粒度近义类（如 120 种犬类），Top-5 在历史上承担了"区分模型间排序"的角色——一个把"哈士奇"认成"爱斯基摩犬"的模型 Top-1 错了，但它显然学会了核心语义。

**使用注意**：当 $K$ 很小（如 10 类）Top-5 无意义；当类别数极多或需要开集识别时，Top-$k$ 会掩盖校准问题（模型可能"前五都进、但置信度乱排"），需配合置信度校准（reliability diagram）评估。分类**精度指标之外**还必须看**每类准确率**——整体准确率在类不均衡时会被大类主导（第 7 章长尾问题的种子）。

### 3.1.3 混淆矩阵与错误分析

混淆矩阵 $C \in \mathbb{N}^{K\times K}$，$C_{ij}$ = 真实类 $i$ 被预测为类 $j$ 的样本数。对角线为正确，非对角线的**结构性聚集**（如"豹↔美洲豹"互相混淆）往往揭示类别定义或数据的系统性问题，是错误分析的第一工具。工程习惯：先把最重的 10 个非对角混淆对逐个人工复查 20 张，再决定是加数据、合并类别还是改增强。

## 3.2 数据增强策略

数据增强（data augmentation）在保持语义不变的约束下对训练样本做随机变换，等价于向训练分布注入先验，作用机理有三层（[机器学习·第 1 章](/xiaoshus-blog/textbooks/ai/ai-core/machine-learning/01/) 的正则化视角）：

1. **扩大有效样本**：同一图像每个 epoch 呈现不同形态，减缓过拟合；
2. **注入不变性先验**：对图像做水平翻转 ≈ 告诉模型"类别与左右无关"，与卷积的平移不变偏置（[深度学习·第 3 章](/xiaoshus-blog/textbooks/ai/ai-core/deep-learning/03/)）互补——卷积只保证平移等变性，翻转/旋转不变性靠增强来教；
3. **模拟部署分布**：若部署端存在低光、压缩伪影，就在训练端加对应扰动。

常用增强按机理分类：

| 类别 | 算子 | 注入的不变性/先验 | 风险 |
|---|---|---|---|
| 几何 | 随机裁剪、水平翻转、缩放 | 位置、平移、镜像 | 上下翻转对多数自然场景破坏语义（天与地） |
| 颜色 | 亮度/对比度/饱和度抖动、ColorJitter | 光照 | 过强会抹掉颜色本身是判别特征的类（花卉） |
| 遮挡 | RandomErasing | 遮挡鲁棒性 | 可能遮挡判别性小区域 |
| 混合 | MixUp：$\tilde x = \lambda x_i + (1-\lambda) x_j$，$\tilde y = \lambda y_i + (1-\lambda) y_j$；CutMix：把 $x_j$ 的矩形块贴到 $x_i$ 上并按面积混合标签 | 线性行为、局部性 | 训练目标与真实分布偏离，需较长收敛时间 |

两条纪律：**增强的参数只允许依据训练集调节**（用验证集选增强 = 泄漏验证分布）；**验证/测试集不做随机增强**（只做确定性的 resize + center crop）。

## 3.3 分类网络演进速览与 ResNet

从 LeNet（1998）到 AlexNet（2012）、VGG（2014）、GoogLeNet（2014）到 ResNet（2015），结构演进的每一步都在回答同一个问题：**深度增加时梯度流与优化如何保持健康**。ResNet 的残差连接（[深度学习·第 3 章](/xiaoshus-blog/textbooks/ai/ai-core/deep-learning/03/) 已推导）

$$
y = x + F(x)
$$

把"学习目标映射"改写为"学习相对恒等映射的残差"，使百层网络的训练成为可能，其 $1\times1$ 卷积瓶颈设计兼顾了计算量。本实验采用 **ResNet-18**：结构简单、参数约 11M，是理解"预训练骨干 + 新分类头"范式的最小完整样例。

## 3.4 迁移学习实战

### 3.4.1 原理：预训练特征的可迁移性

《深度学习》第 7 章已建立预训练-微调范式。视觉经验规律：CNN 的**底层特征（边缘、纹理、颜色）高度通用**，**高层特征（物体部件、类别相关）随任务变化**。由此导出两种策略：

- **特征提取（linear probing）**：冻结骨干，只训练新分类头。适合：目标数据极小（每类几十张）、域与预训练数据接近。
- **微调（fine-tuning）**：整网或部分层以小学习率继续训练。适合：目标数据中等（每类数百张以上）或域差异大（如医学影像）。

微调的学习率纪律：**骨干用小学习率（如 $10^{-4}$）、新头用大学习率（如 $10^{-3}$）的分层学习率**；因为预训练权重已在一个好的盆地附近，大步长会把它推出盆地（灾难性遗忘）。

### 3.4.2 完整代码

```python
# transfer_resnet18.py —— 需要 pip install torch torchvision
# 用 torchvision 合成数据集（FakeData）演示完整流程；替换为真实 ImageFolder 即可实战。
import torch, torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms, models

def get_loaders(batch_size=32):
    # 训练增强：几何 + 颜色；验证只做确定性预处理（3.2 节纪律）
    train_tf = transforms.Compose([
        transforms.RandomResizedCrop(224, scale=(0.7, 1.0)),
        transforms.RandomHorizontalFlip(),
        transforms.ColorJitter(0.2, 0.2, 0.2),
        transforms.ToTensor(),
        transforms.Normalize([0.485, 0.456, 0.406],   # ImageNet 统计量
                             [0.229, 0.224, 0.225]),
    ])
    eval_tf = transforms.Compose([
        transforms.Resize(256), transforms.CenterCrop(224),
        transforms.ToTensor(),
        transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225]),
    ])
    # 演示用 FakeData（随机图像+随机标签）；实战换成
    # datasets.ImageFolder("data/train", transform=train_tf) 即可
    train_ds = datasets.FakeData(512, (3, 224, 224), 10, transform=train_tf)
    val_ds   = datasets.FakeData(128, (3, 224, 224), 10, transform=eval_tf)
    return (DataLoader(train_ds, batch_size, shuffle=True, num_workers=0),
            DataLoader(val_ds, batch_size, num_workers=0))

def build_model(num_classes=10, mode="finetune"):
    model = models.resnet18(weights=models.ResNet18_Weights.IMAGENET1K_V1)
    if mode == "linear":                       # 策略一：特征提取
        for p in model.parameters():
            p.requires_grad = False
    # 换分类头：ResNet-18 的全连接层 (512 -> 1000) 替换为 (512 -> num_classes)
    model.fc = nn.Linear(model.fc.in_features, num_classes)
    return model

@torch.no_grad()
def evaluate(model, loader, device, topk=(1, 5)):
    model.eval()
    correct = {k: 0 for k in topk}
    total = 0
    for x, y in loader:
        x, y = x.to(device), y.to(device)
        _, pred = model(x).topk(max(topk), dim=1)
        correct_mask = pred.eq(y.view(-1, 1))
        for k in topk:
            correct[k] += correct_mask[:, :k].any(dim=1).sum().item()
        total += y.size(0)
    return {k: correct[k] / total for k in topk}

def main():
    device = "cuda" if torch.cuda.is_available() else "cpu"
    train_loader, val_loader = get_loaders()
    model = build_model(mode="finetune").to(device)

    # 分层学习率：新头 1e-3，预训练骨干 1e-4
    head_params = list(model.fc.parameters())
    backbone_params = [p for p in model.parameters()
                       if p.requires_grad and all(p is not h for h in head_params)]
    opt = torch.optim.SGD([
        {"params": backbone_params, "lr": 1e-4},
        {"params": head_params,     "lr": 1e-3},
    ], momentum=0.9, weight_decay=1e-4)
    sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=3)
    loss_fn = nn.CrossEntropyLoss()

    for epoch in range(3):
        model.train()
        running = 0.0
        for x, y in train_loader:
            x, y = x.to(device), y.to(device)
            opt.zero_grad()
            loss = loss_fn(model(x), y)
            loss.backward()
            opt.step()
            running += loss.item() * y.size(0)
        sched.step()
        acc = evaluate(model, val_loader, device)
        print(f"epoch {epoch}: loss={running/len(train_loader.dataset):.4f} "
              f"top1={acc[1]:.3f} top5={acc[5]:.3f}")
    # 预期输出（FakeData 为随机标签，用于验证流程可跑通，准确率约 1/K 附近；
    # 换成真实 ImageFolder 小数据集后，微调 3~5 epoch 应显著超过从头训练）:
    # epoch 0: loss=2.3xxx top1=0.1xx top5=0.5xx
    # epoch 2: loss=2.2xxx top1=0.1xx top5=0.6xx

if __name__ == "__main__":
    main()
```

**实战检查点**（换成真实数据后）：① linear probing 的准确率应明显高于随机初始化整网的同期训练——这就是预训练特征可迁移性的直接证据；② 微调若出现训练损失下降而验证准确率停滞，优先怀疑学习率过大或增强过弱，而不是加层。

## 3.5 类激活图：CAM 与 Grad-CAM

### 3.5.1 CAM：全局池化带来的免费热力图

CNN 分类网络最后一层通常是全局平均池化（GAP）+ 线性分类头。GAP 把最后一个卷积特征图 $A_k \in \mathbb{R}^{H'\times W'}$（$k$ 为通道）压缩成标量 $F_k = \frac{1}{HW}\sum_{i,j} A_k(i,j)$，分类得分（单类 $c$ 的权重 $w^c_k$）：

$$
y_c = \sum_k w^c_k F_k = \sum_k w^c_k \frac{1}{HW} \sum_{i,j} A_k(i, j)
$$

CAM（Zhou et al., 2016）注意到：把求和号里的空间下标保留，就得到类 $c$ 的空间归因图：

$$
M_{\mathrm{CAM}}(i, j) = \sum_k w^c_k A_k(i, j)
$$

局限：它要求网络结构恰好是"最后卷积层 → GAP → 单线性层"，无法应用于任意结构。

### 3.5.2 Grad-CAM：用梯度做任意网络的 CAM

Grad-CAM（Selvaraju et al., 2017）用"得分对特征图的梯度"代替分类权重，摆脱结构限制。对任意目标得分 $y_c$（可以是任何类的 logit、甚至 VQA 的答案分数）与任一选定卷积层特征 $\{A^k\}$：

$$
\alpha_k = \frac{1}{HW} \sum_{i} \sum_{j} \frac{\partial y_c}{\partial A^k(i, j)}, \qquad
L_{\mathrm{Grad\text{-}CAM}} = \operatorname{ReLU}\!\Big( \sum_k \alpha_k A^k \Big)
$$

$\alpha_k$ 是通道 $k$ 对类 $c$ 的**平均重要性**（[最优化方法](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/00/) 的链式法则直接应用）；ReLU 只保留对 $y_c$ 有正贡献的位置。热力图上采样回原图分辨率后叠加显示。与 CAM 的关系：当网络恰为 CAM 的结构时，$\alpha_k$ 退化为常数 $w^c_k$，两者一致——Grad-CAM 是 CAM 的严格推广。

**解读纪律**：Grad-CAM 显示的是"哪个区域在支持这个预测"，不是"模型的因果依据"；它有时会把注意力指向背景捷径（如水印、时间戳）——这恰恰是它作为**调试工具**的价值（3.6 节）。

```python
# gradcam.py —— 需要 pip install torch torchvision numpy opencv-python matplotlib
import torch, torch.nn as nn, torch.nn.functional as F
import numpy as np, cv2
from torchvision import models, transforms
from PIL import Image

class GradCAM:
    def __init__(self, model, target_layer):
        self.acts, self.grads = None, None
        target_layer.register_forward_hook(
            lambda m, i, o: setattr(self, "acts", o.detach()))
        target_layer.register_full_backward_hook(
            lambda m, gi, go: setattr(self, "grads", go[0].detach()))

    def __call__(self, x, class_idx=None):
        logits = model(x)                            # 前向（钩子记录 acts）
        class_idx = class_idx or logits.argmax(1).item()
        model.zero_grad()
        logits[0, class_idx].backward()              # 对目标得分反传
        A, G = self.acts[0], self.grads[0]           # (C, h, w)
        alpha = G.mean(dim=(1, 2))                   # (C,) 通道平均梯度
        cam = F.relu((alpha[:, None, None] * A).sum(0))
        cam = (cam - cam.min()) / (cam.max() - cam.min() + 1e-8)
        return cam, class_idx

if __name__ == "__main__":
    model = models.resnet18(weights=models.ResNet18_Weights.IMAGENET1K_V1).eval()
    cam_extractor = GradCAM(model, model.layer4[-1])  # 最后一个残差块
    # 准备一张真实图像（此处用随机图占位；实战换成你自己的照片）
    tf = transforms.Compose([transforms.Resize(224),
                             transforms.ToTensor(),
                             transforms.Normalize([0.485,0.456,0.406],
                                                  [0.229,0.224,0.225])])
    img = Image.fromarray((np.random.rand(300, 400, 3) * 255).astype(np.uint8))
    x = tf(img)[None]
    heat, cls = cam_extractor(x)
    print("预测类别索引:", cls)
    print("热力图尺寸:", tuple(heat.shape))
    # 预期输出: 预测类别索引: (0~999 的某个整数)
    #           热力图尺寸: (7, 7)   <- layer4 输出为 224/32 = 7
    # 叠加到原图保存：
    heat_up = cv2.resize(heat.numpy(), (x.shape[3], x.shape[2]))
    base = (x[0].permute(1, 2, 0).numpy() * 0.5 + 0.5).clip(0, 1)
    overlay = (cv2.applyColorMap((heat_up * 255).astype(np.uint8), cv2.COLORMAP_JET)
               * 0.4 + (base * 255).astype(np.uint8)[:, :, ::-1] * 0.6).astype(np.uint8)
    cv2.imwrite("gradcam_overlay.png", overlay)
```

## 3.6 标签噪声与数据集偏差

### 3.6.1 标签噪声

标注错误（类间模糊、疲劳误标、众包分歧）在真实数据集中普遍存在。形式化为训练标签 $ \tilde y $ 由噪声转移矩阵刻画：$P(\tilde y = j \mid y = i) = T_{ij}$。影响与对策：

- **非对称噪声**（某类系统性误标为另一类）比对称噪声危害大得多，因为它把决策边界整体推歪；
- 对策：早停（网络先拟合干净模式再记忆噪声）、损失修正（forward correction：用 $T$ 修正交叉熵）、co-teaching（两个网络互相挑选"小损失"样本训练）、或最实用的**置信学习（confident learning）**：用交叉验证的预测概率找出与自身类别系统性冲突的样本送人工复审；
- 实验习惯：给干净数据人为注入已知比例的对称噪声，画出"准确率–噪声率"曲线，作为评估标注流程质量的基准。

### 3.6.2 数据集偏差与捷径学习

模型会利用数据集中与标签**虚假相关**的线索（shortcut learning）。著名案例：以肺炎数据集学习时利用医院系统的金属标记（来自便携式 X 光机与前位/后位拍摄方式的系统性相关）；"牛在草地上"的数据集让模型学会"草背景 ⇒ 牛"。检测手段：

1. **Grad-CAM 审查**（3.5 节的工具正为此服务）：热力图大量落在背景而非物体 → 红旗；
2. **背景不变性测试**：把物体粘贴到统一背景或随机背景上看准确率跌落幅度；
3. **跨域评估**：在一个医院/相机/季节上训练、另一个上测试（第 7 章分布偏移的正式框架）。

缓解手段：平衡采样与重加权、对元数据（拍摄地点、设备）做对抗性去相关、以及最根本的——**扩大采集多样性而非修模型**。

## 3.7 关键公式速查

| 公式 | 名称 | 适用条件 / 说明 |
|---|---|---|
| $\mathcal{L}=-\frac1N\sum_i \log \frac{e^{f(x_i)_{y_i}}}{\sum_k e^{f(x_i)_k}}$ | 交叉熵损失 | 多类分类；与 softmax 联用 |
| $\operatorname{Acc@}k=\frac1N\sum_i \mathbb{1}[y_i\in\operatorname{Top}_k(x_i)]$ | Top-$k$ 准确率 | $k\le K$；大类数场景 Top-5 才有区分度 |
| $y_c=\sum_k w^c_k \frac1{HW}\sum_{i,j}A_k(i,j)$ | GAP + 线性头的得分分解 | CAM 的结构前提 |
| $M_{\mathrm{CAM}}(i,j)=\sum_k w^c_k A_k(i,j)$ | 类激活图 | 仅限"最后卷积层→GAP→线性"结构 |
| $\alpha_k=\frac1{HW}\sum_{i,j}\frac{\partial y_c}{\partial A^k(i,j)}$，$L=\operatorname{ReLU}(\sum_k\alpha_k A^k)$ | Grad-CAM | 任意网络任意层；只保留正贡献 |
| $\tilde x=\lambda x_i+(1-\lambda)x_j,\ \tilde y=\lambda y_i+(1-\lambda)y_j$ | MixUp | $\lambda\sim\mathrm{Beta}(\alpha,\alpha)$；标签需可平滑混合 |

## 3.8 示例与案例

### 案例 2：对比 linear probing 与微调（实验设计）

在同一小数据集（例如每类 100 张的 CIFAR-10 子集上采样到 224）上运行 3.4.2 代码两次（`mode="linear"` 与 `mode="finetune"`），各跑 5 个 epoch，记录验证 Top-1。预期结论与解释：linear probing 收敛快且首 epoch 即大幅领先；微调最终更优但需要更小学习率。若微调反而更差，几乎总是学习率未分层——这正是 3.4.1 纪律的实验印证。

## 3.9 常见误区与陷阱

1. **在测试集上反复调参**。任何基于测试集的决策都使其失效；正确做法是三分训练/验证/测试，测试集只在最终评估时触碰。
2. **验证预处理与训练不一致**。给验证集也加随机裁剪/翻转会让指标带有随机噪声且系统性偏低；验证集只允许确定性变换。
3. **换头时忘归一化统计量**。预训练模型要求输入用 ImageNet 的 mean/std 归一化；用 $[0,1]$ 输入直接喂 ResNet 会导致隐性掉点。
4. **把 Grad-CAM 的亮区当"模型看到的物体"**。热力图对目标层选择、ReLU、上采样方式都敏感；结论需要跨多个图像与多个层验证，谨防确认偏误。
5. **用整体准确率评估不均衡数据**。1000 正例 + 99000 负例的任务里，全预测负例就有 99% 准确率；应改用每类召回、宏平均 F1 或 PR 曲线（[机器学习·第 7 章](/xiaoshus-blog/textbooks/ai/ai-core/machine-learning/07/)）。

## 3.12 进阶方向

1. **细粒度识别与检索**：当类别差异在局部（鸟的喙、车的格栅），需要 part-based 方法或度量学习（对比损失、ArcFace），衔接第 6 章 CLIP 的对比目标。
2. **校准与选择性预测**：温度缩放、deep ensembles、conformal prediction，让"置信度"可信并可拒答——部署前必修（衔接《模型部署与 MLOps》的监控阈值设计）。
3. **持续学习**：微调新类会遗忘旧类，需要正则化（EWC）或回放缓冲，是 MLOps 持续训练一节的算法基础。
4. **弱监督与噪声鲁棒学习**：从 image-level 标签做分割（CAM 的原始动机），以及 symmetric/asymmetric 噪声下的理论可识别性条件。

## 3.13 课后思考与练习

1. **概念辨析**：为什么在 1000 类任务中 Top-5 有区分度而 10 类任务中没有？给出一个 Top-5 高但模型实际很差的情形。
2. **概念辨析**：CutMix 与 MixUp 都混合标签，为什么 CutMix 的"面积比例"是标签权重的自然选择而 MixUp 用 Beta 分布采样？
3. **计算推导**：由 $y_c=\sum_k w^c_k F_k$ 出发，逐步推导 $M_{\mathrm{CAM}}$，并证明当网络恰为 CAM 结构时 Grad-CAM 的 $\alpha_k$ 等于 $w^c_k$。
4. **计算推导**：设对称标签噪声率 $\eta$（真实类以 $\eta$ 概率均匀换成其他类），推导干净数据上最优模型在此噪声训练集上测试（干净测试集）的期望准确率上界与 $\eta$ 的关系。
5. **编程实现**：把 3.4.2 的 `mode="linear"` 改成只训练最后一层，并在真实小数据集（如 Oxford-IIIT Pet 的 2 类子集）上对比 linear probing / 微调 / 从头训练三种设置的验证 Top-1 曲线（输出曲线数值表）。
6. **编程实现**：给训练循环加入 MixUp（$\alpha = 0.2$），对比加入前后验证准确率与训练损失的下降速度，并解释为何 MixUp 会让训练损失显得"更高"。
7. **编程实现**：实现批量 Grad-CAM：对一批图像输出热力图网格图；再用"把热力图归零对应区域后重新前向"的方法，验证被高亮区域确实贡献了主要置信度（置信度应显著下降）。
8. **开放思考**：你训练一个"识别皮肤病变"模型，训练集主要来自浅肤色人群照片。列出三种检测该偏差的实验设计与一种不引入新标注的缓解手段。
9. **开放思考**：迁移学习中"冻结低层、微调高层"的经验规律，与第 2 章"底层边缘/纹理通用、高层语义任务相关"的手工特征视角有何呼应？给出一个该规律失效的域偏移例子（提示：深度图、X 光）。
10. **挑战题**：阅读 Northcutt et al. (2021)，复现其置信学习核心步骤：用交叉验证 out-of-fold 概率构造 $Q_{\tilde y, y^\ast}$ 计数矩阵，估计给定数据集中可能被错标的样本清单，并与人工抽检 20 条的结果对比报告精确率。
