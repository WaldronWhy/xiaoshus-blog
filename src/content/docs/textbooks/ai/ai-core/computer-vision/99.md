## 8.1 项目 A：完整图像分类项目（从数据到 Grad-CAM）

### 8.1.1 任务描述

自选一个你有真实兴趣且**能自己采集或合法下载**的分类问题（例如：校园植物 10 类、外卖菜品 8 类、螺丝/垫圈工业件 5 类）。完成从原始数据到带可解释性分析的可部署模型的全部流程。数据规模要求：每类训练样本 ≥ 80 张（自己拍摄优先），并**有意保留**每类 5–10 张"困难样本"（遮挡、光照极端、相似类混淆）。

**基础（60 分）**

**挑战（10 分）**

10. 置信度校准分析：可靠性图（reliability diagram）+ 温度缩放前后的 ECE 对比。

### 8.1.4 提示与常见坑

- **按拍摄批次划分**而不是随机划分：同一批次的照片高度相似（同光照同背景），随机划分会造成"同批泄漏"，验证集指标虚高——这是本项目最重要的实验设计点；
- HOG+SVM 基线别跳过：它会让你直观看到"手工特征能到 60 分、深度迁移能到 90 分"，也让第 2 章↔第 3 章的技术史对照变成亲身数据；
- Grad-CAM 的目标层选 `layer4` 最后一个块；若热力图整体均匀（无峰），通常是模型欠训练或数据有系统性问题，先查数据再调模型；
- 遇到类间混淆严重的类对，优先的干预顺序是：补充该类对的困难样本 > 定向增强 > 换更大骨干（第 3 章 3.1.3 的错误分析纪律）。

### 8.2.3 关键代码骨架（B2 工具库）

```python
# yolo_mini_utils.py —— 项目 B 的几何工具库与单元测试（需要 pip install numpy）
import numpy as np

def iou_xyxy(a, b):
    """单对框 IoU。a, b: (4,) [x1,y1,x2,y2]。"""
    x1, y1 = np.maximum(a[:2], b[:2])
    x2, y2 = np.minimum(a[2:], b[2:])
    inter = max(0.0, x2 - x1) * max(0.0, y2 - y1)
    area_a = (a[2]-a[0]) * (a[3]-a[1]); area_b = (b[2]-b[0]) * (b[3]-b[1])
    return inter / (area_a + area_b - inter + 1e-12)

def encode(box, cell_x, cell_y, S=7, img_size=224):
    """真值框 -> 相对所属网格单元的 (tx,ty,tw,th)（4.2.1 节参数化）。"""
    cx, cy = (box[0] + box[2]) / 2, (box[1] + box[3]) / 2
    w, h = box[2] - box[0], box[3] - box[1]
    gx, gy = int(cx / img_size * S), int(cy / img_size * S)
    cell = img_size / S
    tx = cx / cell - gx; ty = cy / cell - gy          # 相对单元左上角，∈[0,1)
    tw = np.log(w / cell); th = np.log(h / cell)
    return (gx, gy), np.array([tx, ty, tw, th])

def decode(t, gx, gy, cell):
    """编码的逆操作；box 中心 = (gx+tx)*cell。"""
    tx, ty, tw, th = t
    cx, cy = (gx + tx) * cell, (gy + ty) * cell
    w, h = np.exp(tw) * cell, np.exp(th) * cell
    return np.array([cx - w/2, cy - h/2, cx + w/2, cy + h/2])

def nms(boxes, scores, thr=0.5):
    """贪心 NMS（第 4 章实现）。"""
    order = scores.argsort()[::-1]; keep = []
    while order.size:
        i = order[0]; keep.append(i)
        if order.size == 1: break
        rest = boxes[order[1:]]
        ious = np.array([iou_xyxy(boxes[i], b) for b in rest])
        order = order[1:][ious <= thr]
    return keep

if __name__ == "__main__":
    # 单元测试 1：IoU 数值
    a = np.array([0, 0, 10, 10.]); b = np.array([5, 0, 15, 10.])
    assert abs(iou_xyxy(a, b) - 50/150) < 1e-6, "IoU 测试失败"
    # 单元测试 2：编码-解码往返一致性
    box = np.array([35.0, 40.0, 75.0, 120.0])
    (gx, gy), t = encode(box, 0, 0)
    rec = decode(t, gx, gy, 224 / 7)
    assert np.abs(rec - box).max() < 1e-4, "编解码不一致"
    # 单元测试 3：NMS 保留 2 个不重叠目标
    boxes = np.array([[0,0,10,10.],[1,1,11,11.],[100,100,110,110.]])
    scores = np.array([0.9, 0.8, 0.85])
    assert nms(boxes, scores, 0.5) == [0, 2], "NMS 测试失败"
    print("全部单元测试通过")
    # 预期输出: 全部单元测试通过
```

### 8.2.5 提示与常见坑

- **先写单元测试再写训练**。mAP 和编解码的 bug 在训练损失里极难定位，但在单元测试里一秒现形——本项目刻意把 B2 独立成验收项；
- 编码时**用哪个格**的规则（中心点所在格 vs 最大 IoU 格）要与解码、训练分配完全一致，三者不一致是 YO-mini 复现失败的头号原因；
- 置信度 BCE 建议：正样本目标是该预测框与真值的 IoU（而非硬 1），这能校准置信度使 NMS 排序更可靠；
- 负样本抑制权重（noobj 系数 0.5 附近起步）：全负样本参与 BCE 会把置信度压到全 0，训练"看似收敛"实际永远输出空预测——用可视化抽检 B1 数据和 B4 分配来避免盲飞；
- AP 计算务必按第 4 章 4.3 的规则逐条对齐（降序、真值一次性使用、包络积分），并与 torchvision 的 `MeanAveragePrecision`（仅用于验证）比对，绝对误差 < 0.02 才算实现正确。

### 8.3.3 核心代码骨架（C2 + C3）

```python
# clip_project.py —— 需要 pip install open_clip_torch torch pillow numpy
import torch, torch.nn.functional as F, numpy as np, open_clip

model, _, preprocess = open_clip.create_model_and_transforms(
    "ViT-B-32", pretrained="laion2b_s34b_b79k")
tokenizer = open_clip.get_tokenizer("ViT-B-32")
model.eval()

def embed_images(paths):
    """批量编码图像，返回 L2 归一化嵌入 (N, 512)。"""
    from PIL import Image
    feats = []
    with torch.no_grad():
        for i in range(0, len(paths), 64):            # 分批防显存溢出
            batch = torch.stack([preprocess(Image.open(p).convert("RGB"))
                                 for p in paths[i:i+64]])
            feats.append(F.normalize(model.encode_image(batch), dim=-1))
    return torch.cat(feats)

def zeroshot(image_emb, class_names, templates):
    """多模板集成零样本分类：类嵌入 = 各模板嵌入的平均（再归一化）。"""
    with torch.no_grad():
        text = tokenizer([t.format(c) for c in class_names for t in templates])
        t_all = F.normalize(model.encode_text(text), dim=-1)
        t_all = t_all.reshape(len(class_names), len(templates), -1)
        t_cls = F.normalize(t_all.mean(1), dim=-1)    # (K, 512)
        logits = 100.0 * image_emb @ t_cls.T
    return logits.argmax(1).numpy()

def recall_at_k(img_emb, txt_emb, ks=(1, 5, 10)):
    """以图搜文的 Recall@k：正确文本排前 k 的比例。"""
    S = img_emb @ txt_emb.T
    ranks = S.argsort(dim=1, descending=True)         # (N_img, N_txt)
    hits = {k: 0 for k in ks}
    for i, ranked in enumerate(ranks):
        for k in ks:
            hits[k] += int(i in ranked[:k].tolist())  # 第 i 图对应第 i 文本
    return {k: v / len(ranks) for k, v in hits.items()}

if __name__ == "__main__":
    rng = np.random.default_rng(0)
    fake_img = F.normalize(torch.randn(50, 512), dim=-1)   # 演示占位
    fake_txt = F.normalize(torch.randn(50, 512), dim=-1)
    print("随机基线 Recall@k:", recall_at_k(fake_img, fake_txt))
    # 预期输出: 随机基线 Recall@k: {1: 0.02, 5: 0.1, 10: 0.2}
    # （即 1/N, 5/N, 10/N —— 用于检验检索代码正确性的必要条件）
```

### 8.3.5 提示与常见坑

- **归因要有本体再动手**：先定义 5 类失败模式与判别标准（两人对同一案例独立标注、不一致的案例单独讨论），否则 C4 会退化成印象流；
- 温度：open_clip 的 logit 缩放已内置在模型里，自己再加 `100.0 *` 只是为了与论文记号对齐，重复缩放会让 softmax 饱和、top-1 之外概率全为 0——这不影响 argmax 但影响你做的置信度分析；
- CIFAR-10 图像只有 32×32，直接过 224 预处理会被插值模糊，属正常现象，但要在报告中声明（它本身就是一种域偏移）；
- 检索评测必须双向：以图搜文与以文搜图的结果矩阵不同（softmax 方向不同），只报一个方向会漏掉不对称的失败模式（第 6 章 6.1.2 的对称损失在此的呼应）。
