## 4.1 检测任务定义与挑战

**目标检测**：给定图像，输出若干个 $(\text{box } b, \text{class } c, \text{score } s)$，其中 $b = (x, y, w, h)$。它是"分类 + 定位"的联合问题，且**每张图的目标数量不定**。

区别于分类的核心挑战：

1. **空间组合爆炸**：目标可出现在任意位置、任意尺度（第 1 章金字塔的动机）、任意长宽比，穷举窗口不可行；
2. **类别不平衡的极端版**：一张图有数万个背景窗口却只有几个正样本，训练信号被背景淹没；
3. **评估的耦合性**：定位误差与分类误差必须联合评价（IoU 阈值），指标从"准确率"变为 mAP（4.3 节）。

**IoU（交并比）**是定位质量的度量：$\mathrm{IoU}(B_1, B_2) = \frac{|B_1 \cap B_2|}{|B_1 \cup B_2|} \in [0, 1]$。预测框与真值框 IoU 超过阈值（常用 0.5）且类别正确才算检测成功。

## 4.2 两阶段检测：R-CNN → Fast/Faster R-CNN

### 4.2.1 演进逻辑：三次计算结构的重构

- **R-CNN（2014）**：候选区域（region proposal，由 Selective Search 生成约 2000 个）→ 每个区域独立过 CNN 分类。精度高但一张图要跑 2000 次卷积，推理数秒。
- **Fast R-CNN（2015）**：整图先过一次 CNN 得特征图，各候选区域在**特征图上**裁剪（ROI Pooling）后接全连接头。卷积计算从 2000 次降到 1 次，但候选区域生成仍在外部（CPU 瓶颈）。
- **Faster R-CNN（2015）**：用 **RPN（Region Proposal Network）**——一个在特征图上滑动的小卷积网络——代替 Selective Search，提出"共享卷积 + 端到端可学习的候选生成"。RPN 在每个特征图位置放 $k$ 个**锚框（anchor，不同尺度/长宽比的先验框）**，输出每个锚框"是前景的概率 + 相对锚框的回归偏移"。

**框回归参数化**（对锚框 $A=(x_a,y_a,w_a,h_a)$ 预测目标 $B=(x,y,w,h)$）：

$$
t_x = \frac{x - x_a}{w_a}, \quad t_y = \frac{y - y_a}{h_a}, \quad
t_w = \log\frac{w}{w_a}, \quad t_h = \log\frac{h}{h_a}
$$

预测 $t$ 分量再反解回框。用相对量与 $\log$ 比值使回归对尺度不敏感、输出值域稳定。损失为多任务形式：

$$
\mathcal{L} = \mathcal{L}_{\mathrm{cls}} + \lambda\, \mathbb{1}[\text{foreground}]\, \mathcal{L}_{\mathrm{reg}}(t, t^\ast)
$$

回归损失常用 Smooth L1（在 1 附近退化为 L1，远离时为二次——对离群框稳健）。正负样本定义：与某真值 IoU $> 0.7$ 的锚为正、$< 0.3$ 为负、中间忽略；采样保持正负比约 $1:3$——这正是对 4.1 挑战 2 的直接回应。

### 4.2.2 ROI Pooling 与 ROI Align 推导

**问题**：候选框定义在输入图坐标系（浮点），而特征图分辨率是输入的 $1/32$。ROI Pooling 把 ROI 划分为 $p\times p$ 网格并逐格最大池化，但过程中**两次取整**：

1. ROI 坐标除以 stride 后取整（四舍五入到整数特征图格点）；
2. 每个池化 bin 的边界再取整。

例：输入图上 ROI 为 $(x, y, w, h) = (0.3, 0.9, 40.6, 80.4)$，stride = 32，$p = 2$。特征图坐标 $(0.0094, 0.0281, 1.269, 2.513)$ → 取整为 $(0, 0, 1, 3)$。bin 宽 $1/2 = 0.5$ → 边界 $0, 0.5, 1$ 取整为 $0, 0, 1$——**第一个 bin 宽度为 0**！该 bin 的池化退化，误差在小目标上被放大（小目标的 ROI 本来只占几个特征格）。

**ROI Align（Mask R-CNN, 2017）**取消全部取整：bin 边界保持浮点，在每个 bin 内取 $2\times2$ 规则采样点，用**双线性插值**（[线性代数·第 3 章](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/03/) 的加权思想在网格上的推广）从周围 4 个特征格点计算采样值，再对 4 个采样点取最大。上例中每个 bin 都有定义良好的采样值，且梯度可经插值权重平滑回传。

## 4.3 mAP 的精确计算

mAP 是检测的标准指标，但实现细节繁多，必须精确掌握。以 Pascal VOC / COCO 通用流程为准：

1. **匹配规则**：将某类所有预测按置信度**降序排列**，依次与该图该类的真值框尝试匹配：与未匹配真值 IoU 最大且 $\ge \tau$ 的那个真值记为匹配（贪心），该真值随后标记为已用；若无可匹配真值则该预测为 FP。**同一真值只能被匹配一次**——重复检测中只有置信度最高的算 TP，其余是 FP。
2. **逐置信度累积**：沿排序扫描，累计 TP 数 $N_{\mathrm{TP}}(i)$ 与 FP 数 $N_{\mathrm{FP}}(i)$，得到（累积）精度与召回序列：
   $\mathrm{Prec}(i) = \frac{N_{\mathrm{TP}}(i)}{N_{\mathrm{TP}}(i) + N_{\mathrm{FP}}(i)}, \quad \mathrm{Rec}(i) = \frac{N_{\mathrm{TP}}(i)}{N_{\mathrm{GT}}}$
3. **AP 积分**：AP = PR 曲线下面积。VOC2010+ 与 COCO 采用**全点插值**：对每个召回水平 $r$，取"召回 $\ge r$ 的所有点中精度的最大值"（包络）后积分：
   $$\mathrm{AP} = \sum_{r \in \{0, 1/N_{\mathrm{GT}}, \dots, 1\}} p_{\mathrm{env}}(r)\, \Delta r$$
4. **mAP**：对各类 AP 取平均。COCO 进一步对 IoU 阈值 $0.5{:}0.05{:}0.95$ 共 10 档分别算 mAP 再平均（记作 $AP@[.5:.95]$），并按目标尺度（小/中/大）分桶报告——单一阈值的 mAP 会掩盖"大目标好、小目标差"的结构性问题。

常见变体差异要点：VOC 早期版本对召回变化处取"右端最大精度"且只算 11 个召回点；COCO 不允许"检测多于真值时把多余真值放宽"（没有 per-image 豁免）。**复现论文数字前必查其 AP 版本**。

## 4.4 单阶段检测：YOLO 与 anchor-free 演进

### 4.4.1 YOLO 思想

YOLO（Redmon et al., 2016）把检测变成**单次回归**：把图像划分为 $S\times S$ 网格，每个网格单元直接预测 $B$ 个框的 $(x, y, w, h, \mathrm{conf})$ 与类别分布，一次前向同时输出所有检测。相比两阶段的优势是速度（实时视频），代价是初期对小目标与密集目标召回差（每格框数有限、不同目标共用格子互相挤压）。后续版本（v2–v8 及其衍生）逐步吸收锚框聚类、多尺度预测头（FPN，特征金字塔，正是第 1 章金字塔思想在学习框架中的复现）、更好的损失（GIoU/DIoU/CIoU）与解耦头。

### 4.4.2 anchor-free 演进

锚框机制是超参负担（尺度/长宽比先验需按数据集调）。anchor-free 两条路线：

- **关键点路线**：CornerNet（2018）预测目标左上/右下角点热图再组合；CenterNet（2019）预测中心点 + 宽高，简洁高效。
- **逐像素稠密预测路线**：FCOS（2019）对特征图每个位置直接回归"到目标四边的距离 $(l, t, r, b)$"，并用**centerness 分支**抑制远离中心的低质量框（centerness $= \sqrt{\frac{\min(l, r)}{\max(l, r)} \cdot \frac{\min(t, b)}{\max(t, b)}}$，越居中越接近 1）。歧义位置（一个点落在多个目标内）用多尺度 FPN 层级分配解决。

演进的主线可以概括为：**"先验从何而来"从人工（anchor 设计）让位于数据（每个位置按感受野自适应预测）**——与第 5 章"归纳偏置从手工转向学习"的命题同构。

## 4.5 NMS 从零实现

非极大值抑制（NMS）去除同一目标的重复检测：按分数降序保留，删去与已保留框 IoU 超阈值的后续框。类别**独立**进行（跨类别的重叠由更高级的 class-agnostic NMS 或 Soft-NMS 处理）。

```python
# nms.py —— 需要 pip install numpy
import numpy as np

def iou_matrix(boxes):
    """boxes: (N,4) [x1,y1,x2,y2]，返回 (N,N) IoU 矩阵。"""
    x1 = np.maximum(boxes[:, None, 0], boxes[None, :, 0])
    y1 = np.maximum(boxes[:, None, 1], boxes[None, :, 1])
    x2 = np.minimum(boxes[:, None, 2], boxes[None, :, 2])
    y2 = np.minimum(boxes[:, None, 3], boxes[None, :, 3])
    inter = np.clip(x2 - x1, 0, None) * np.clip(y2 - y1, 0, None)
    area = (boxes[:, 2] - boxes[:, 0]) * (boxes[:, 3] - boxes[:, 1])
    return inter / (area[:, None] + area[None, :] - inter + 1e-12)

def nms(boxes, scores, iou_thr=0.5):
    """贪心 NMS。返回保留的索引（按分数降序）。"""
    order = scores.argsort()[::-1]                 # 分数降序
    keep = []
    while order.size > 0:
        i = order[0]
        keep.append(i)
        if order.size == 1:
            break
        ious = iou_matrix(boxes[order])[0, 1:]     # 首框与其余框的 IoU
        order = order[1:][ious <= iou_thr]         # 删除重叠过高者
    return keep

if __name__ == "__main__":
    boxes = np.array([
        [10, 10, 60, 60],    # A：真目标，分数最高
        [12, 12, 62, 62],    # B：A 的重复检测（IoU≈0.74）
        [11, 10, 61, 60],    # C：A 的另一个重复（IoU≈0.92）
        [200, 200, 260, 260],# D：另一处的目标（与 A 无重叠）
        [205, 205, 265, 265],# E：D 的重复
    ], dtype=np.float32)
    scores = np.array([0.95, 0.80, 0.90, 0.85, 0.70], dtype=np.float32)
    keep = nms(boxes, scores, iou_thr=0.5)
    print("保留索引:", keep)      # 预期输出: [0, 3]
    # 过程: 降序 A(0.95)→C(0.90)→D(0.85)→B(0.80)→E(0.70)
    #       A 保留; C 与 A 的 IoU≈0.92>0.5 删除; D 保留; B 与 A 的 IoU≈0.74 删除;
    #       E 与 D 的 IoU≈0.725 删除。最终保留 A 与 D。
    print("对应分数:", scores[keep])
```

变体提示：**Soft-NMS** 不直接删除高 IoU 框而按 $s_i \leftarrow s_i (1 - \mathrm{IoU})$ 衰减其分数，在密集场景（群体、货架）提升召回；**DIoU-NMS** 把中心点距离并入抑制准则，缓解"相邻不同目标被误删"。

## 4.6 语义分割：FCN 与 U-Net

### 4.6.1 FCN：全卷积化

**语义分割（semantic segmentation）**给每个像素分配类别。FCN（Long et al., 2015）的关键一步：把分类网络的全连接层全部替换为卷积层，使网络输出与输入同构的空间图，再通过**转置卷积（transposed convolution / 反卷积）**上采样回原图分辨率。转置卷积输出尺寸公式（对应第 1 章的卷积公式反向）：$H_{out} = (H_{in} - 1) \cdot s - 2p + k$。上采样信息量不足的问题用**跳跃连接（skip connection）**缓解：把深层上采样结果与浅层高分辨率特征逐元素相加，"深层语义 + 浅层细节"互补。

### 4.6.2 U-Net：编码器-解码器与对称跳跃

U-Net（Ronneberger et al., 2015，医学影像）把上述思想做成对称的编码器-解码器结构：

- **编码器（下采样路径）**：重复"卷积块 → 2× 下采样"，通道翻倍，分辨率减半——逐级压缩出语义；
- **解码器（上采样路径）**：每级"上采样 → 与编码器同分辨率特征**拼接（concatenate）**→ 卷积块"；
- **跳跃连接的作用**用信号语言表述：下采样是有损低通（第 1 章拉普拉斯金字塔！），编码器各级丢失的高频细节由解码器从对应编码层"借回"，且拼接（而非相加）让解码器自己学习如何融合两个频带。损失函数常用逐像素交叉熵 + Dice（对类不平衡鲁棒：$\mathrm{Dice} = \frac{2|X \cap Y|}{|X| + |Y|}$）。

与 ResNet 残差连接（跨层相加、深度方向）不同，U-Net 跳跃连接是跨**分辨率层级**的拼接——两者都解决"信息在深路径中流失"的问题，方向正交。第 6 章将看到：Stable Diffusion 的去噪网络正是"带注意力模块的 U-Net"。

## 4.7 实例分割：Mask R-CNN 思想

**实例分割**进一步要求区分同类不同个体。Mask R-CNN = Faster R-CNN + 一个并行的小分割头：对每个 ROI，用 ROI Align 取 $14\times14$ 特征，经 2–3 层卷积与反卷积输出 $28\times28$ 的逐像素二值掩码（每个 ROI 一个类别特定的掩码通道）。训练时掩码损失 $\mathcal{L}_{\mathrm{mask}}$ 只在预测类别对应的通道上计算（解耦分类与分割）。ROI Align 在这里不是锦上添花而是**必需**：掩码是像素级任务，Pool 的取整误差直接造成掩码错位。分割家族的三个层次归纳：语义（每像素一类）/ 实例（每目标一掩码）/ 全景（panoptic，两者并集，背景区域归语义"stuff"）。

## 4.8 关键公式速查

| 公式 | 名称 | 适用条件 / 说明 |
|---|---|---|
| $\mathrm{IoU}(B_1,B_2)=\dfrac{|B_1\cap B_2|}{|B_1\cup B_2|}$ | 交并比 | 定位质量度量；匹配阈值常取 0.5 |
| $t_x=\frac{x-x_a}{w_a},\ t_w=\log\frac{w}{w_a}$（$y,h$ 同理） | 框回归参数化 | 相对锚框；尺度不敏感 |
| $\mathcal{L}=\mathcal{L}_{\mathrm{cls}}+\lambda\,\mathbb{1}[\mathrm{fg}]\,\mathcal{L}_{\mathrm{reg}}$ | 多任务检测损失 | 回归只在正样本上计 |
| $\mathrm{AP}=\sum_r p_{\mathrm{env}}(r)\,\Delta r$ | AP（全点插值） | 匹配须按置信度降序贪心、真值一次性使用 |
| $\mathrm{Dice}=\frac{2|X\cap Y|}{|X|+|Y|}$ | Dice 系数 | 分割重叠度量；对类不平衡比像素准确率合理 |
| $H_{out}=(H_{in}-1)s-2p+k$ | 转置卷积输出尺寸 | 上采样；stride 即放大倍数 |

## 4.9 示例与案例

### 案例 1：手算 mAP

单类任务，2 张图共 3 个真值框（$N_{\mathrm{GT}}=3$）。预测按置信度降序及匹配结果：

| 排名 | 置信度 | 是否 TP | 累积 TP | 累积 FP | 精度 | 召回 |
|---|---|---|---|---|---|---|
| 1 | 0.95 | 是 | 1 | 0 | 1.00 | 0.333 |
| 2 | 0.90 | 否 | 1 | 1 | 0.50 | 0.333 |
| 3 | 0.85 | 是 | 2 | 1 | 0.667 | 0.667 |
| 4 | 0.70 | 否 | 2 | 2 | 0.50 | 0.667 |
| 5 | 0.60 | 是 | 3 | 2 | 0.60 | 1.000 |

包络精度 $p_{\mathrm{env}}$：在召回 $0.333$ 处取 $\max(1.0, 0.5) = 1.0$（召回 ≥ 0.333 的点中精度最大值为 1.0）；召回 $0.667$ 处取 $\max(0.667, 0.5) = 0.667$；召回 $1.0$ 处取 $0.6$。

$$
\mathrm{AP} = 1.0 \times \tfrac{1}{3} + 0.667 \times \tfrac{1}{3} + 0.6 \times \tfrac{1}{3} = 0.756
$$

校验：注意若不取包络而直接用原始精度积分会得 $(1.0+0.5+0.667+0.5+0.6)$ 的锯齿面积 ≈ 0.656——两者差异正是插值规则的意义（单调下降的 PR 包络）。

### 案例 2：从零实现简化 mAP

```python
# simple_map.py —— 需要 pip install numpy
import numpy as np

def iou(b1, b2):
    x1, y1 = max(b1[0], b2[0]), max(b1[1], b2[1])
    x2, y2 = min(b1[2], b2[2]), min(b1[3], b2[3])
    inter = max(0.0, x2 - x1) * max(0.0, y2 - y1)
    a1 = (b1[2]-b1[0]) * (b1[3]-b1[1]); a2 = (b2[2]-b2[0]) * (b2[3]-b2[1])
    return inter / (a1 + a2 - inter + 1e-12)

def ap_single_class(imgs_pred, imgs_gt, iou_thr=0.5):
    """imgs_pred: 每图 (n,5)=[x1,y1,x2,y2,score]；imgs_gt: 每图 (m,4)。"""
    preds = sorted(((*p, i) for i, ps in enumerate(imgs_pred) for p in ps),
                   key=lambda r: -r[4])
    n_gt = sum(len(g) for g in imgs_gt)
    matched = [set() for _ in imgs_gt]           # 每图已匹配的真值索引
    tp = np.zeros(len(preds)); fp = np.zeros(len(preds))
    for i, (x1, y1, x2, y2, s, im) in enumerate(preds):
        best, best_j = 0.0, -1
        for j, g in enumerate(imgs_gt[im]):
            if j in matched[im]:
                continue                          # 真值一次性使用
            v = iou((x1, y1, x2, y2), g)
            if v > best:
                best, best_j = v, j
        if best >= iou_thr:
            tp[i] = 1; matched[im].add(best_j)
        else:
            fp[i] = 1
    cum_tp, cum_fp = np.cumsum(tp), np.cumsum(fp)
    rec = cum_tp / max(n_gt, 1)
    prec = cum_tp / (cum_tp + cum_fp)
    mrec = np.r_[0, rec, 1]; mpre = np.r_[1, prec, 0]      # 哨兵点
    for i in range(len(mpre) - 2, -1, -1):                 # 右向最大值包络
        mpre[i] = max(mpre[i], mpre[i + 1])
    idx = np.where(mrec[1:] != mrec[:-1])[0]
    return float(((mrec[idx + 1] - mrec[idx]) * mpre[idx + 1]).sum())

if __name__ == "__main__":
    preds = [np.array([[0, 0, 10, 10, 0.95], [20, 20, 30, 30, 0.6]]),
             np.array([[5, 5, 15, 15, 0.9], [100, 100, 110, 110, 0.85]])]
    gts   = [np.array([[0, 0, 10, 10], [20, 20, 30, 30]]),
             np.array([[5, 5, 15, 15]])]
    print("AP =", round(ap_single_class(preds, gts), 3))
    # 预期: AP = 0.917
    # 手工复核（按置信度降序）：
    #   0.95 的框 (0,0,10,10) 与图0真值0 IoU=1 → TP，累积 TP=1，召回=1/3，精度=1
    #   0.9  的框 (5,5,15,15)  与图1真值  IoU=1 → TP，累积 TP=2，召回=2/3，精度=1
    #   0.85 的框 (100,100,..) 图1无匹配真值   → FP，召回=2/3，精度=2/3
    #   0.6  的框 (20,20,30,30) 与图0真值1 IoU=1 → TP，召回=1，精度=3/4
    #   包络精度: 召回≤1/3 → 1；≤2/3 → 1；=1 → 0.75
    #   AP = (1/3)·1 + (1/3)·1 + (1/3)·0.75 = 0.917
```

> 提示：运行后应得 $\mathrm{AP} \approx 0.917$，并用案例 1 的手算流程逐点复核，验证你对"包络积分"的理解。

## 4.10 常见误区与陷阱

1. **NMS 前忘记跨类处理**。对每类独立 NMS 后，同一目标可能同时留下"狗 0.9 / 狼 0.6"两条；是否允许跨类抑制取决于业务（class-agnostic NMS）。
2. **mAP 版本混用**。VOC-11point、VOC-2010、COCO $AP@[.5:.95]$ 数值不可直接比较；论文复现错版本是常见事故。
3. **把 mAP 当"准确率"解读**。mAP 是排序质量指标，对"置信度整体虚高/偏低"不敏感（只关心相对次序）；监控线上系统时必须配合置信度校准与召回率。
4. **ROI Pooling 用在小目标上**。stride=32 的特征图上一个小目标只占 2–3 格，两次取整误差占比极大；这正是 ROI Align 被发明的直接原因。
5. **语义分割评估用逐像素准确率**。道路/天空等大类会淹没小物体类别；应报告 mIoU 或按类 Dice。
6. **转置卷积的棋盘伪影（checkerboard artifact）**。当 kernel 不能被 stride 整除时上采样出现周期性伪影；工程上常用 `interpolate + conv` 替代。
