# 第 5 章 视觉 Transformer 与现代架构

> **本章定位**：本章把《深度学习》第 5 章的 Transformer 引入视觉：ViT 证明"纯注意力 + 最少的视觉先验"在数据充足时超越 CNN，这迫使我们必须严肃回答"归纳偏置与数据规模的关系"这一表征学习的根本问题。本章的架构对比与选型方法是第 6 章 CLIP/扩散、第 7 章效率分析的架构基础。

## 5.1 动机：卷积的先验是否总有益

回顾第 1–3 章：卷积自带两条先验——**局部性**（每个输出只看 $k\times k$ 邻域）与**平移等变性**（权重共享）。这两条先验让 CNN 在 ImageNet 规模（约 120 万图）上高效收敛，但也是天花板：卷积核的 receptive field 需要堆很多层才能覆盖全图，远距离关系（如"左上角的红色云与右下角的雨伞"）只能靠层层间接传递。

Transformer 的自注意力（[深度学习·第 5 章](/xiaoshus-blog/textbooks/ai/ai-core/deep-learning/05/)）

$$
\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\left( \frac{QK^{\top}}{\sqrt{d}} \right) V
$$

每层都能让任意两个位置直接交互——**零局部性先验、零平移先验**。好处是表达上限更高、对全局关系建模更直接；代价是没有先验兜底时需要**更多数据**来自己学出这些规律。ViT（Dosovitskiy et al., 2021）的核心实验结论正是这两点的合一：在小数据集上从头训练，ViT 劣于同级 CNN；在 JFT-300M（3 亿图）预训练后迁移，ViT 全面反超。这是"先验 vs 数据"的教科书案例，与 [机器学习·第 1 章](/xiaoshus-blog/textbooks/ai/ai-core/machine-learning/01/) 的偏差-方差框架一脉相承。

## 5.2 ViT 完整架构

以 ViT-Base/16 为例（$d=768$，12 层，12 头）。输入 $x \in \mathbb{R}^{3 \times 224 \times 224}$。

**第 1 步：patch embedding（图像切块）**。把图像切成 $16\times16$ 的不重叠 patch，得 $N = (224/16)^2 = 196$ 个 patch。每个 patch 展平为 $3\times16\times16 = 768$ 维，再线性投影到 $d$ 维。巧妙的是：**展平 + 线性投影在数学上等价于一个 $16\times16$ 核、stride 16 的卷积**——ViT 的第一步仍然是一个卷积！形状变化：

$$
x \in \mathbb{R}^{3\times224\times224} \xrightarrow{\ \text{Conv2d}(3, d, k=16, s=16)\ } z \in \mathbb{R}^{768\times14\times14} \xrightarrow{\ \text{flatten}\ } \mathbb{R}^{196\times768}
$$

**第 2 步：[CLS] token 与位置编码**。拼接一个可学习的分类 token $z_{\mathrm{cls}} \in \mathbb{R}^{1\times768}$（BERT 的做法），并加上位置编码 $E_{\mathrm{pos}} \in \mathbb{R}^{(N+1)\times d}$（原始 ViT 用可学习一维位置编码，实验表明比二维正弦编码更好——一个反直觉的发现：网络自己能从数据中恢复二维结构）：

$$
z_0 = [\, z_{\mathrm{cls}}\ ;\ \operatorname{Conv}(x)^{\top} \,] + E_{\mathrm{pos}} \in \mathbb{R}^{197 \times 768}
$$

**第 3 步：Transformer 编码器**。$L$ 层标准结构（预归一化版本）：

$$
\begin{aligned}
z'_{\ell} &= z_{\ell-1} + \operatorname{MSA}\big( \operatorname{LN}(z_{\ell-1}) \big) \\
z_{\ell} &= z'_{\ell} + \operatorname{MLP}\big( \operatorname{LN}(z'_{\ell}) \big)
\end{aligned}
$$

其中 MSA 为多头自注意力，MLP 为 $d \to 4d \to d$ 的两层 GELU 网络。

**第 4 步：分类头**。取最后一层的 [CLS] 输出 $z_L^{0}$，接线性层（预训练时接 MLP 头做 1000 类，微调时换成单线性层）：

$$
\hat y = \operatorname{Linear}\big( \operatorname{LN}(z_L^{0}) \big)
$$

**与 NLP Transformer 的三点差异总结**：token 来源从词表嵌入换成 patch 投影；位置编码可学习且低维仍有效；无解码器——分类只用编码器输出。[CLS] token 的注意力在训练后自动学会聚合全局信息，这正是第 3 章 Grad-CAM 在 ViT 上的对应物（可直接对 $z_L^0$ 的注意力加权可视化）。

```python
# mini_vit.py —— 从零实现简化版 ViT（需要 pip install torch）
# 目标：跑通前向与形状，理解每个组件；非训练脚本。
import torch, torch.nn as nn

class PatchEmbed(nn.Module):
    def __init__(self, img=224, patch=16, in_ch=3, d=768):
        super().__init__()
        self.proj = nn.Conv2d(in_ch, d, kernel_size=patch, stride=patch)
        self.n_patches = (img // patch) ** 2
    def forward(self, x):                     # (B, 3, 224, 224)
        z = self.proj(x)                      # (B, d, 14, 14)
        return z.flatten(2).transpose(1, 2)   # (B, 196, d)  patch 序列

class MiniViT(nn.Module):
    def __init__(self, img=224, patch=16, d=768, depth=12, heads=12, n_cls=1000):
        super().__init__()
        self.patch = PatchEmbed(img, patch, d=d)
        self.cls = nn.Parameter(torch.zeros(1, 1, d))            # [CLS] token
        self.pos = nn.Parameter(torch.zeros(1, self.patch.n_patches + 1, d))
        block = lambda: nn.TransformerEncoderLayer(
            d_model=d, nhead=heads, dim_feedforward=4 * d,
            activation="gelu", batch_first=True, norm_first=True)
        self.encoder = nn.TransformerEncoder(block(), num_layers=depth)
        self.norm = nn.LayerNorm(d)
        self.head = nn.Linear(d, n_cls)
    def forward(self, x):
        B = x.shape[0]
        z = torch.cat([self.cls.expand(B, -1, -1),
                       self.patch(x)], dim=1)   # (B, 197, d)
        z = self.encoder(z + self.pos)
        return self.head(self.norm(z[:, 0]))    # 只取 [CLS] 位置

if __name__ == "__main__":
    model = MiniViT(depth=2, n_cls=10)          # 演示用 2 层
    x = torch.randn(4, 3, 224, 224)
    y = model(x)
    n_params = sum(p.numel() for p in model.parameters())
    print("输出形状:", tuple(y.shape))           # 预期: (4, 10)
    print("参数量(M):", round(n_params / 1e6, 1))
    # 预期: 参数量(M) 8.9 左右（2 层演示版；ViT-Base/16 完整版约 86M）
    print("token 序列长度:", model.patch.n_patches + 1)  # 预期: 197
```

## 5.3 归纳偏置与数据规模

### 5.3.1 实验证据

ViT 原文的三组关键实验值得记住（可直接作为"数据规模-架构交互作用"的证据）：

1. **小数据集从头训**（ImageNet-1k，1.28M 图）：ViT 明显弱于 ResNet——缺乏先验的模型需要更多样本来学出局部性；
2. **中等规模**（ImageNet-21k，14M 图）：两者接近；
3. **大规模**（JFT-300M，303M 图）预训练后迁移：ViT-Base/16 在多数基准超过 BiT-ResNet152（同样大规模预训练的 CNN）。

### 5.3.2 中间态证据：注意力真的在"看局部"吗

对预训练 ViT 做探针分析（probing）发现：**浅层的注意力头自发学出了类似卷积的局部模式**（注意相邻 token 的头、 attend 到边缘的头），位置嵌入的相似性也重建了二维网格结构。也就是说，**ViT 在数据中学出了 CNN 生而具有的先验**——当数据足够便宜，先验可以学习获得；当数据昂贵，先验必须手工注入。这给了我们一个统一判断框架：

$$
\text{架构选择} \sim f(\text{数据量},\ \text{算力},\ \text{延迟预算})
$$

注意"归纳偏置是双刃剑"的另一面：CNN 的平移不变先验在**位置敏感**任务（需要精确知道"在哪"，如第 4 章检测的稠密回归、文档理解）上可能成为限制，这正是 ViT 系架构在这些任务上常常更好的原因之一。

### 5.3.3 复杂度对比

设特征图 token 数 $N$（ViT：$N = 196$；CNN：以像素计 $N = 3136$ @ $56\times56$ 特征层）：

| 结构 | 每层计算 | 空间交互方式 | 全局感受野 |
|---|---|---|---|
| 卷积层 | $O(k^2 N d^2)$ | 局部（$k\times k$） | 需 $\sim N/k$ 层 |
| 自注意力 | $O(N^2 d)$ | 全局一对一 | 1 层即得 |
| 窗口注意力（Swin） | $O(N w^2 d)$，$w$ 为窗宽 | 窗内全局 | $\log_2 w$ 层跨窗混合 |

$N=196$ 时 $N^2$ 并不贵（ViT-Base 单图推理约 17.5 GFLOPs，ResNet-50 约 4.1 GFLOPs 但层数更深）；但当输入分辨率翻倍，$N$ 变 4 倍，注意力计算变 **16 倍**——分辨率敏感的检测/分割任务因此需要 Swin 这类层次化设计。

## 5.4 DeiT：数据高效的蒸馏

ViT 原版依赖 JFT-300M 级私有数据， academia 难以复现。DeiT（Touvron et al., 2021）证明：**用蒸馏 + 强增强 + 更好的训练配方，86M 参数的 ViT 只用 ImageNet-1k 就能达到相近水平**。关键机制是**蒸馏令牌（distillation token）**：在输入中增加一个与 [CLS] 并列的可学习 token $z_{\mathrm{dist}}$，训练时被约束去逼近**教师（RegNetY-16GF，一个 CNN）**的输出：

$$
\mathcal{L}_{\mathrm{global}} = (1-\lambda)\, \mathcal{L}_{\mathrm{CE}}\big( \psi(z_{\mathrm{cls}}), y \big)
+ \lambda\, \mathcal{L}_{\mathrm{CE}}\big( \psi(z_{\mathrm{dist}}),\, y_{\mathrm{teacher}} \big)
$$

其中 $\psi$ 是分类头，$y_{\mathrm{teacher}}$ 是教师在**同一增强视图**上的预测。有趣发现：蒸馏 token 学到的表示与 [CLS] 不同且互补（二者余弦相似度低），且**CNN 教师 > 同规模 Transformer 教师**——教师传递的正是 CNN 的归纳偏置，等于"把局部性先验通过知识蒸馏注入"。这把《深度学习》第 7 章的预训练-蒸馏范式扩展出"跨架构蒸馏"一维。

### 5.4.1 训练配方：DeiT 之外的公共成分

ViT 系模型对训练配方的敏感度显著高于 CNN（这是"先验少 → 更依赖优化技巧"的又一表现）。DeiT 与后续工作沉淀出的公共成分值得记住，它们在第 3 章的训练工具箱中各有出处：

- **强增强组合**：RandAugment / AutoAugment + MixUp（$\alpha=0.8$）+ CutMix（$\alpha=1.0$）+ Random Erasing——先验不足时靠增强注入不变性（第 3 章 3.2）；
- **更长的训练**：CNN 在 ImageNet 上 90–300 epoch 收敛，ViT 系通常 300–800 epoch；学习率采用warmup（5–20 epoch）+ 余弦退火（[深度学习·第 2 章](/xiaoshus-blog/textbooks/ai/ai-core/deep-learning/02/)）；
- **正则化组合**：随机深度（stochastic depth，随深度线性增大丢弃率 0.1 左右）、权重衰减 0.05 量级（显著大于 CNN 常用的 1e-4）、LayerScale（给每个残差分支乘一个可学习的小初始化标量，稳定深层训练）；
- **优化器**：AdamW 而非 SGD——Transformer 对自适应优化器的依赖与 CNN 形成对照。

一个务实的结论：**比较"架构 A vs 架构 B"时必须同时声明配方**，ViT 论文早期社区复现的惨败多数是"用 ResNet 配方训 ViT"。ConvNeXt 的反向实验（5.6 节）证明该效应是对称的——配方搬到 CNN 上同样涨点。

## 5.5 Swin：层次化的窗口注意力

Swin Transformer（Liu et al., 2021）针对两件事：注意力 $O(N^2)$ 的分辨率代价 + 检测分割需要的多尺度金字塔特征（第 4 章 FPN）。

**机制一：窗口注意力（W-MSA）**。把 $H\times W$ 特征图划成 $\frac{H}{M}\times\frac{W}{M}$ 个 $M\times M$（$M=7$）互不重叠的窗口，注意力只在窗口内计算，复杂度 $O(HW M^2 d)$，对 $H W$ **线性**。代价：窗口之间无法通信。

**机制二：移位窗口（SW-MSA）**。交替使用两种划分——第 $\ell$ 层用规则网格窗，第 $\ell+1$ 层把窗口整体移位 $\lfloor M/2 \rfloor$ 个 token。两层叠加后，信息流经"窗内 → 移位后的窗"即可跨过原窗口边界传播（类似卷积两层感受野扩大）。实现时对移位产生的"跨边界窗口"做 cyclic shift + attention mask（掩掉不属于同一逻辑窗的 token 对）。

**层次化设计**：四个 stage 之间用 patch merging（$2\times2$ 邻域合并 + 线性降维）使分辨率 $H/4 \to H/8 \to H/16 \to H/32$、通道 $C \to 2C \to 4C \to 8C$——与 ResNet 的金字塔完全对齐，因此 Swin 可以**直接替换** Faster R-CNN / U-Net 的骨干（Swin 各 stage 输出正好充当 FPN 的四级）。相对位置偏置（relative position bias）加入注意力 logits：$A = QK^{\top}/\sqrt{d} + B_{\Delta}$，比绝对位置编码更适配平移变化。

## 5.6 现代骨干网络选型指南

| 场景 | 推荐 | 理由 |
|---|---|---|
| 数据少、域近 ImageNet、CPU/端侧延迟敏感 | ResNet-50 / EfficientNet / MobileNet 系 | 先验强、优化稳定、算子高度优化（部署生态最好） |
| 大规模预训练可用、分类为主 | ViT-Base/Large（DINOv2、MAE 预训练） | 上限高，特征对下游迁移质量最好 |
| 检测/分割（多尺度稠密预测） | Swin / ConvNeXt / Hierarchical ViT | 金字塔特征 + 相对可控的计算增长 |
| 超高分辨率（遥感、病理切片） | 窗口注意力系或局部卷积 | 全局注意力 $N^2$ 爆炸不可承受 |
| 极端算力受限 | MobileNetV3 / GhostNet + 第 7 章量化 | 深度可分离卷积的 $O(k N d)$ 优势 |

两条经验法则：**下游任务与预训练分辨率差异大时选层次化/卷积系**（ViT 对分辨率插值位置编码敏感但可用插值缓解）；**特征将用于密集对齐任务（第 2 章几何）时，优先卷积或混合骨干**。ConvNeXt（2022）值得一读：它把 ViT 的训练配方（大核 $7\times7$、LayerNorm、GELU、更少激活）反向移植回 CNN，证明"配方"与"架构"对性能的贡献同样重要——CNN/ViT 的对立在应用层面已被"混合与互鉴"取代。

## 5.7 关键公式速查

| 公式 | 名称 | 适用条件 / 说明 |
|---|---|---|
| $z_0=[z_{\mathrm{cls}};\operatorname{Conv}_{k=s=16}(x)^{\top}]+E_{\mathrm{pos}}$ | ViT 输入嵌入 | patch 投影等价于大核大步长卷积；$N=(H/P)^2$ |
| $z'_{\ell}=z_{\ell-1}+\operatorname{MSA}(\operatorname{LN}(z_{\ell-1}))$ | 编码器块（预归一化） | MSA 内部即《深度学习》第 5 章多头注意力 |
| $\hat y=\operatorname{Linear}(\operatorname{LN}(z_L^0))$ | ViT 分类头 | 只用 [CLS] 位置输出 |
| $\mathcal{L}=(1-\lambda)\mathcal{L}_{\mathrm{CE}}(\psi(z_{\mathrm{cls}}),y)+\lambda\mathcal{L}_{\mathrm{CE}}(\psi(z_{\mathrm{dist}}),y_{\mathrm{teacher}})$ | DeiT 蒸馏损失 | 教师固定；$y_{\mathrm{teacher}}$ 对同一增强视图 |
| 窗口注意力 $\sim O(HWM^2 d)$ | Swin 复杂度 | $M$=窗宽；跨窗通信靠移位窗口交替 |
| $A=QK^{\top}/\sqrt{d}+B_{\Delta}$ | 相对位置偏置注意力 | $B_\Delta$ 按相对坐标查表；适合平移变化 |

## 5.8 示例与案例

### 案例 1：手算 ViT 的形状与参数

ViT-Tiny/16（$d=192$，12 层，3 头，$224$ 输入）：

- token 数：$(224/16)^2 + 1 = 197$；
- 单层参数：MSA 中 $Q,K,V,O$ 各 $d\times d = 192^2 = 36864$（共约 147k）+ MLP $192\times768\times2 = 294912$ ≈ 0.44M/层；12 层 ≈ 5.3M + patch 投影 $3\cdot16^2\cdot192 \approx 0.15$M。与 ViT-Tiny 官方约 5.7M 参数一致（其余为 LayerNorm 与嵌入）。
- 注意力 FLOPs 量级：$O(197^2 \cdot 192) \approx 7.5\times10^6$ MAC/层——远小于该层 MLP 的 $197 \cdot 192 \cdot 768 \cdot 2 \approx 5.8\times10^7$。**结论：在 224 分辨率下 ViT 的瓶颈是 MLP 而非注意力**；分辨率提高到 512 时 token 数 1025，注意力才反超。

### 案例 3：手写移位窗口的划分与复原（Swin 机制的几何直觉）

```python
# shifted_window.py —— 用 numpy 演示 Swin 的窗口划分与 cyclic shift（纯 numpy）
import numpy as np

def partition(H, W, M):
    """把 (H, W) 索引矩阵切成 (H//M, W//M) 个 M×M 窗口，返回每 token 的窗口号。"""
    yy, xx = np.meshgrid(np.arange(H), np.arange(W), indexing="ij")
    return (yy // M) * (W // M) + (xx // M)          # (H, W) 窗口号图

if __name__ == "__main__":
    H, W, M = 8, 8, 4
    win = partition(H, W, M)
    print("规则划分（每行窗口号）:\n", win)
    # 预期: 2×2 个窗口，左上 4×4 全为 0，右上 4×4 全为 1……
    # 移位 M//2 = 2 个像素（cyclic shift），再重新划分：
    shifted = np.roll(win, shift=(-2, -2), axis=(0, 1))
    win2 = partition(H, W, M)
    print("移位后重新划分:\n", win2)
    print("同一物理窗口在移位后落入的不同新窗口数（每个旧窗口）:")
    for old in np.unique(win):
        new_ids = np.unique(win2[win == old])
        print(f"  旧窗口 {old} -> 新窗口 {new_ids.tolist()}")
    # 预期: 每个旧窗口的 token 被分散到 4 个新窗口——这正是"跨窗通信"的机制；
    # 实际实现中还需要 attention mask 掩掉被 cyclic shift 拼接、但物理上不相邻的
    # token 对（Swin 原文的 SwinTransformerBlock 前向中的 attn_mask 即为此服务）。
```

**观察要点**：① 规则划分下两个相邻窗口中的 token 永远无法在同层交互；② 循环移位两层后，任意一对 token 至少在某一个窗口中"同窗"过——信息通路建立；③ mask 的必要性来自 roll 的环形拼接：图像左边缘的 token 会与右边缘 token 落进同一新窗口，而它们在物理上并不相邻，必须屏蔽其注意力。

## 5.9 常见误区与陷阱

1. **以为 ViT "没有卷积"**。patch embedding 就是卷积；ViT 缺的是**层层堆叠的局部先验**，不是卷积算子本身。
2. **用 ImageNet-1k 从头训练 ViT 然后抱怨它弱**。这是设计之外的适用域；小数据请用预训练 ViT 或直接用 CNN。
3. **位置编码插值踩坑**。把 224 训练的 ViT 用于 384 输入必须对位置编码做双线性插值，否则性能大幅掉落；Swin 用相对位置偏置则天然无此问题。
4. **混淆窗口注意力与稀疏注意力**。Swin 是"规则的局部窗口 + 移位"，不是全局稀疏化；跨窗信息要经层数累积，单层窗口注意力不具备全局感受野。
5. **忽略 batch_first 与 norm_first 的一致性**。用 `nn.TransformerEncoderLayer` 搭 ViT 时 `batch_first=True` 与预归一化都要显式设置，否则形状报错或训练不收敛（原始 `nn.Transformer` 默认后归一化、序列优先）。
