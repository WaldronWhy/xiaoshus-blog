## 7.1 数据集构建与标注质量控制

### 7.1.1 标注协议先行

数据集质量的上限由**标注规范（annotation guideline）**决定：类目定义（边界案例归哪类？）、标注单元（框贴多紧？遮挡多少比例才标？）、歧义仲裁流程（多人分歧谁来裁决？）。规范本身要先在 50–100 样本的试标上迭代收敛，再全面铺开——先标 10 万张再改规范是数据工程最昂贵的事故。

### 7.1.2 标注者间一致性

**Cohen's kappa** 度量两名标注者在 $K$ 类上的超额一致性（扣除随机撞对）：

$$
\kappa = \frac{p_o - p_e}{1 - p_e}, \qquad
p_o = \sum_k p_{kk}, \quad p_e = \sum_k p_{k+}\, p_{+k}
$$

其中 $p_o$ 是观测一致率，$p_e$ 是按边际分布计算的期望一致率。经验阈值（Landis & Koch）：$\kappa > 0.8$ 近乎完美，$0.6\text{–}0.8$ 实质一致，$< 0.4$ 说明类目定义或规范有严重歧义。多标注者版本用 Fleiss' kappa 或 Krippendorff's alpha。工程实践：抽样 10% 做双标（double annotation），$\kappa$ 低于阈值的批次整批返工并回溯规范。

### 7.1.3 标注偏差的系统来源

标注者的注意力分布、文化背景、报酬激励都会系统性进入标签：众包标注的情感极性随标注者语言漂移；医学影像中不同医院的标注习惯不同。检测手段：把"标注者 ID"作为元数据训练探针模型，若能从图像+标注者预测出标注者身份，说明标注风格本身是可学习信号——此时需要仲裁与混合标注（multiple annotator + majority/STAPLE 融合）。本节与第 3 章标签噪声一节构成"点错误（随机噪声）↔ 系统偏差（结构性误标）"的完整谱系。

## 7.2 分布偏移与长尾

### 7.2.1 三种偏移的分类

沿用[《机器学习》第 1 章](/xiaoshus-blog/textbooks/ai/ai-core/machine-learning/01/)的记号，数据分布 $P(X, Y) = P(X)\, P(Y\mid X)$：

1. **协变量偏移（covariate shift）**：$P(X)$ 变、$P(Y\mid X)$ 不变。视觉最常见：训练集是白天的街景、部署后遇到雨夜；相机换型号。应对：更强的增强模拟目标域（第 3 章）、域自适应（对抗对齐 DANN、自训练/伪标签）、测试时适配（TENT 等只调 BatchNorm/熵最小化）。
2. **标签偏移（label shift）**：$P(Y)$ 变、$P(X\mid Y)$ 不变。疫情后口罩人脸占比骤变是经典案例。应对：先估计测试标签分布（BBSE 等用混淆矩阵反解），再按先验重加权或直接调分类阈值。
3. **概念漂移（concept drift）**：$P(Y\mid X)$ 本身变化。同一种视觉外观被重新定义（"未佩戴口罩"的判定标准变了、新车型加入"轿车"类）。**无法靠重加权解决**，只能重新标注与再训练——这是 MLOps"持续训练"触发器的理论依据。

检测统计量：对输入分布监控每层特征或输出的统计漂移（PSI、KS 检验）；对输出监控置信度分布与预测类别占比；最可靠的是对一小股流量做**人工抽检的准确率监控**——所有代理指标都可能被模型自己的适应骗过（Goodhart 定律）。

### 7.2.2 长尾分布

视觉数据几乎必然长尾：少数头部类有海量样本，尾部类几十张。整体准确率被头部类主导（第 3 章已预警）。主流应对按作用位置分类：

- **数据层**：头部类欠采样、尾部类过采样与增强放大；
- **损失层**：类平衡损失（按 $1/n_c^\gamma$ 重加权）、Focal Loss（压低易分样本的损失贡献）、**logit adjustment**——训练时把 logit 减去 $\tau \log n_c$，等价于让 softmax 适应先验，测试时（先验均衡假设下）把该偏置移除：

$$
\mathcal{L} = -\log \frac{\exp(f_{y}(x) - \tau \log n_y)}{\sum_{c} \exp(f_c(x) - \tau \log n_c)}
$$

其理论依据是贝叶斯决策：长尾下最优分类器会把头部类的先验"折算"进决策边界，logit adjustment 显式补偿之（[概率论·第 4 章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/04/) 的后验校正思想）；
- **评估层**：报告头部/中部/尾部三段的每类平均准确率，而不是单一 mAP/Top-1。

## 7.3 公平性

视觉公平问题的形态：人脸分析系统对不同肤色/性别的错误率差异（性别分类对深肤色女性的错误率比对浅肤色男性高一个数量级的著名审计）；医学影像模型对少数群体子人群的召回不足。常用度量（均在子群上分解第 3 章的指标）：

- **群体均等（demographic parity）**：预测阳性率跨群一致；
- **机会均等（equal opportunity）**：真实正例上的召回率（TPR）跨群一致；
- **校准（calibration）**：同一预测分数在跨群时对应同一经验正确率。

三者**一般不可同时满足**（存在数学上的不可能定理），选哪个取决于应用的成本结构——医疗筛查选 TPR 均等，风控选校准。工程流程：先**分群评估**（把混淆矩阵按子群切片），差异超阈值时从数据（子群采样、定向采集）与训练（重加权、对抗去偏）两侧干预，并在发布文档（model card）中公开分群性能。

## 7.4 对抗攻击：FGSM 原理与可视化

### 7.4.1 线性化视角

对抗样本（adversarial example）：对输入加人类不可察觉的扰动 $\delta$，使模型输出被定向改变：$\hat y(x + \delta) \ne \hat y(x)$。Goodfellow 等的解释基于损失的一阶泰勒展开：

$$
\mathcal{L}(\theta, x + \delta) \approx \mathcal{L}(\theta, x) + \nabla_x \mathcal{L}(\theta, x)^{\top} \delta
$$

沿梯度上升方向走一步、每维限幅 $\varepsilon$（$L_\infty$ 球内），得 **FGSM（Fast Gradient Sign Method）**：

$$
\delta = \varepsilon \cdot \operatorname{sign}\big( \nabla_x \mathcal{L}(\theta, x) \big)
$$

只用一次反传，因此"快"。直觉：高维输入中每个像素被推一小步、方向一致地累积，就能把内部表示推过决策边界——**扰动总量随维度线性增长而单维感知不变**，这是高维模型普遍脆弱的结构性原因，也与第 5 章"高维空间中距离集中"的现象呼应。更强的迭代版（PGD/I-FGSM）多走几步小步并投影回 $\varepsilon$ 球；物理世界的攻击（贴纸、眼镜框）则把数字扰动搬到实物上。

### 7.4.2 实现与可视化

```python
# fgsm.py —— 需要 pip install torch torchvision
# 用预训练 ResNet-18 做 FGSM 攻击并输出攻击前后预测对比。
import torch, torch.nn as nn
from torchvision import models, transforms
from PIL import Image
import numpy as np

model = models.resnet18(weights=models.ResNet18_Weights.IMAGENET1K_V1).eval()
tf = transforms.Compose([transforms.Resize(256), transforms.CenterCrop(224),
                         transforms.ToTensor()])
norm = transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
IMAGENET_LABELS = models.ResNet18_Weights.IMAGENET1K_V1.meta["categories"]

def predict(x_normed):
    with torch.no_grad():
        p = model(x_normed).softmax(-1)
    return int(p.argmax()), float(p.max())

def fgsm(x_img, eps, targeted=None):
    """x_img: [0,1] 未归一化输入。targeted: 目标类索引（定向攻击时给出）。"""
    x = x_img.clone().requires_grad_(True)
    loss_fn = nn.CrossEntropyLoss()
    logits = model(norm(x))
    if targeted is None:                     # 无目标：最大化真实损失
        loss = loss_fn(logits, logits.argmax(1))
    else:                                    # 有目标：最小化到目标类的损失
        loss = -loss_fn(logits, torch.tensor([targeted]))
    loss.backward()
    x_adv = torch.clamp(x + eps * x.grad.sign(), 0, 1)   # 投影回 [0,1]
    return x_adv.detach()

if __name__ == "__main__":
    # 实战：换成你的照片 img = tf(Image.open("cat.jpg")).unsqueeze(0)
    img = tf(Image.fromarray((np.random.rand(256, 256, 3) * 255).astype(np.uint8)))
    x = img.unsqueeze(0)
    cls0, conf0 = predict(norm(x))
    print(f"攻击前: 类别={IMAGENET_LABELS[cls0]} 置信度={conf0:.3f}")
    for eps in [0.01, 0.03, 0.1]:
        x_adv = fgsm(x, eps)
        cls1, conf1 = predict(norm(x_adv))
        noise = (x_adv - x).abs().max().item()
        print(f"eps={eps}: 攻击后 类别={IMAGENET_LABELS[cls1]} "
              f"置信度={conf1:.3f} 最大像素扰动={noise:.3f}")
    # 预期（真实照片）：eps=0.03 时类别通常已改变，且扰动在视觉上不可察觉
    # （最大扰动 0.03 ≈ 每通道 ±8/255 灰度级）。随机占位图上攻击无意义，
    # 请务必用真实照片观察现象。
```

### 7.4.3 防御的现实

- **对抗训练**：把 PGD 生成的对抗样本加入训练（Madry et al.），是至今最可靠的防御，代价是干净准确率下降与训练开销数倍；
- **输入变换类防御**（压缩去噪、随机化）：多数在自适应攻击（攻击者也模拟该变换）下失效——**自适应评估纪律**：任何防御必须在白盒自适应攻击下重新评估；
- **认证防御**：随机平滑（randomized smoothing）给出在 $L_2$ 球内的可证明鲁棒半径，代价是推理需要多次前向（衔接第 7.5 的效率约束）。

## 7.5 模型效率与端侧部署视角

### 7.5.1 四条压缩路线

| 路线 | 原理 | 典型收益 | 风险 |
|---|---|---|---|
| **量化（quantization）** | FP32 → INT8/INT4 权重与激活 | 4×/8× 存储；INT8 硬件 2–4× 吞吐 | 激活分布离群的层精度损失大；需校准集 |
| **剪枝（pruning）** | 删除低重要性权重/通道/层 | 稀疏化后依硬件可提速 | 非结构化稀疏在 GPU 上几乎不提速；需微调恢复 |
| **蒸馏（distillation）** | 大模型教小模型（第 5 章 DeiT） | 小模型逼近大模型精度 | 需要教师与训练管线；收益上限是教师 |
| **架构级** | 深度可分离卷积、重参数化（RepVGG）、神经架构搜索 | 训练/推理形态解耦 | 迁移性依算子支持而定 |

**量化的数学**：对称量化 $q = \operatorname{round}(x / s)$，$s = x_{\max}/127$；反量化 $x \approx s q$。误差来自舍入，理论上相对误差 $\sim 1/(127\sqrt{3})$；但离群激活会把 $s$ 撑大、压缩其他值的分辨率——这正是激活需要逐通道（per-channel）或校准（统计分位数）的原因。训练感知量化（QAT）在训练中模拟量化噪声，比训练后量化（PTQ）更稳。

### 7.5.2 端侧评估清单

精度之外，部署决策需要同时回答：**延迟**（单请求 P99，含预处理与后处理）、**吞吐**（batch 下的 QPS）、**显存/内存峰值**、**能耗**（电池设备的一等约束）、**精度–算力帕累托**（同一约束下比较多架构）。工具面：ONNX 导出与算子覆盖检查、TensorRT/OpenVINO 的图优化与精度基准、移动端 TFLite/Core ML。分析视角上，先测**算子耗时占比**（卷积 vs 归一化 vs 上采样 vs NMS——第 4 章的后处理在 CPU 上常是隐形大头），再做有针对性的优化；不要凭 FLOPs 直觉决策，因为 FLOPs 相同的模型延迟可差数倍（访存与并行度不同）。

## 7.6 关键公式速查

| 公式 | 名称 | 适用条件 / 说明 |
|---|---|---|
| $\kappa=\frac{p_o-p_e}{1-p_e}$ | Cohen's kappa | 二标注者；$p_e$ 按边际分布；$>0.8$ 近乎完美 |
| $\mathcal{L}=-\log\frac{\exp(f_y-\tau\log n_y)}{\sum_c\exp(f_c-\tau\log n_c)}$ | logit adjustment | 长尾训练；测试时按场景决定是否保留偏置 |
| $\delta=\varepsilon\cdot\operatorname{sign}(\nabla_x\mathcal{L})$ | FGSM | $L_\infty$ 威胁模型；一次反传 |
| $q=\operatorname{round}(x/s),\ s=x_{\max}/127$ | 对称 INT8 量化 | 离群值敏感；逐通道/校准缓解 |
| $\mathcal{L}(\theta,x+\delta)\approx\mathcal{L}+\nabla_x\mathcal{L}^{\top}\delta$ | 一阶攻击分析 | 高维下小扰动累积越界 |

## 7.7 示例与案例

### 案例 1：手算 Cohen's kappa

两名医生对 100 张胸片标注"肺炎/正常"，一致 82 张（都判肺炎 60、都判正常 22）。$p_o = 0.82$；边际：医生 A 判肺炎 70/正常 30，医生 B 判肺炎 65/正常 35，$p_e = 0.70 \times 0.65 + 0.30 \times 0.35 = 0.455 + 0.105 = 0.56$。

$$
\kappa = \frac{0.82 - 0.56}{1 - 0.56} = \frac{0.26}{0.44} \approx 0.591
$$

表面一致率 82% 看似不错，但类别不均衡抬高了随机一致率，$\kappa \approx 0.59$ 只到"中等一致"——需要复查规范中"边界阴影"的定义。这个例子说明为什么**必须用超额一致率**。

### 案例 2：FGSM 扰动可视化与参数扫描

```python
# fgsm_visual.py —— 需要 pip install torch torchvision matplotlib numpy
# 在真实图像上扫描 eps，绘制"eps vs 攻击成功率"并保存扰动可视化。
import torch, numpy as np, matplotlib.pyplot as plt
from torchvision import models, transforms
from PIL import Image

model = models.resnet18(weights=models.ResNet18_Weights.IMAGENET1K_V1).eval()
norm = transforms.Normalize([0.485,0.456,0.406], [0.229,0.224,0.225])
tf = transforms.Compose([transforms.Resize(256), transforms.CenterCrop(224),
                         transforms.ToTensor()])
img = tf(Image.open("cat.jpg")).unsqueeze(0)      # 实战需要一张真实照片
with torch.no_grad():
    true_cls = model(norm(img)).argmax(1)

def fgsm_one(x, eps):
    x = x.clone().requires_grad_(True)
    loss = nn.functional.cross_entropy(model(norm(x)), true_cls)
    loss.backward()
    return torch.clamp(x + eps * x.grad.sign(), 0, 1).detach()

eps_list = [0, 0.005, 0.01, 0.02, 0.05, 0.1, 0.2]
rates, l2s = [], []
for eps in eps_list:
    if eps == 0:
        adv = img; r = 0.0
    else:
        adv = fgsm_one(img, eps)
        r = float((model(norm(adv)).argmax(1) != true_cls).float())
        plt.imsave(f"noise_{eps}.png",
                   (adv - img).abs()[0].permute(1, 2, 0).numpy() / max(eps, 1e-8))
    rates.append(r)
    l2s.append(float((adv - img).norm()))
print("eps:      ", eps_list)
print("攻击成功率:", [round(r, 2) for r in rates])
print("L2 扰动:  ", [round(v, 2) for v in l2s])
# 预期（真实照片，ResNet-18）：eps=0.02 前后成功率从 0 快速跃升，
# eps=0.05 时通常 > 90%；noise_*.png 中扰动能量集中在边缘/纹理区。
# 结论记录：攻击成功率随 eps 单调上升；人眼在 eps<=0.05 时几乎无感。
```

### 案例 3：用 PSI 监控输入分布偏移

**群体稳定性指数（Population Stability Index, PSI）**是风控与 MLOps 中最常用的偏移标量指标：把特征的取值分桶后，比较训练期与线期各桶占比：

$$
\mathrm{PSI} = \sum_{b} (p_b^{(\mathrm{now})} - p_b^{(\mathrm{train})})\, \ln \frac{p_b^{(\mathrm{now})}}{p_b^{(\mathrm{train})}}
$$

经验判读：$\mathrm{PSI} < 0.1$ 无显著偏移，$0.1\text{–}0.25$ 需关注，$> 0.25$ 明显偏移（应触发人工复查或再训练）。

```python
# psi_monitor.py —— 需要 pip install numpy
import numpy as np

def psi(train_feat, now_feat, bins=10, eps=1e-6):
    """对单个特征计算 PSI。特征可以是亮度均值、预测类别直方图、嵌入的主成分等。"""
    edges = np.quantile(train_feat, np.linspace(0, 1, bins + 1))
    edges[0], edges[-1] = -np.inf, np.inf          # 首尾桶开放，容纳新值域
    p = np.histogram(train_feat, edges)[0] / len(train_feat) + eps
    q = np.histogram(now_feat, edges)[0] / len(now_feat) + eps
    return float(np.sum((q - p) * np.log(q / p)))

if __name__ == "__main__":
    rng = np.random.default_rng(0)
    train = rng.normal(110, 15, size=5000)         # 训练期图像亮度均值
    same = rng.normal(110, 15, size=2000)          # 线期同分布
    night = rng.normal(70, 20, size=2000)          # 线期出现大量夜间图像
    print("PSI(同分布)  =", round(psi(train, same), 3))
    # 预期: < 0.05（波动范围内）
    print("PSI(夜间偏移)=", round(psi(train, night), 3))
    # 预期: > 1.0（显著偏移，应触发告警）
```

**工程要点**：① 桶边界必须用**训练期**数据定（`np.quantile` 在线上数据上取边界是常见 bug，会掩盖偏移）；② PSI 可直接用于离散特征（预测类别直方图、各类别置信度分桶）；③ PSI 只检测 $P(X)$ 的偏移，对概念漂移（$P(Y|X)$ 变）天然盲——所以它只是第一道防线，准确率抽检（7.2.1）仍是最终裁决。

## 7.8 常见误区与陷阱

1. **用整体一致率代替 kappa**。类别不均衡时一致率虚高（案例 1 的 82% vs 0.59）。
2. **把验证集当部署分布**。验证集与训练集同源同分布，它的"良好泛化"对协变量偏移几乎零预测力；上线前必须构造至少一个"换相机/换场景/换医院"的偏移测试集。
3. **非自适应防御评估**。只测 FGSM 就声称鲁棒是最常见的错误：FGSM 是一阶、单步、最弱攻击；防御评估的最低标准是白盒 PGD + 自适应变体。
4. **量化前不看激活分布**。直接 PTQ 遇到离群激活（某些通道幅值远超其他）会掉点严重；先做 per-channel 直方图分析再选策略。
5. **长尾评估只看总体 mAP**。尾部类的 AP 可以是零而总体看起来体面；必须按头部/中部/尾部与最小样本类分别报告。
6. **混淆"公平性度量"与"价值判断"**。度量选择（parity vs calibration）本质是应用的成本权衡，不是数学上唯一正确的答案；结论必须连同所选度量一起报告。

## 7.11 进阶方向

1. **域泛化（DG）理论**：不变风险最小化（IRM）等表征不变性学习；需要补因果推断基础（衔接《知识表示与推理》）。
2. **认证鲁棒性**：随机平滑的 Neyman–Pearson 证明框架、de randomization；适合数学背景强的读者。
3. **测试时训练/适配**：TTT、TENT 只在推理阶段用自监督信号适配，是偏移应对的轻量级新范式。
4. **隐私与联邦视觉学习**：差分隐私训练与联邦学习把"数据不能集中"的合规现实纳入训练，衔接《模型部署与 MLOps》的合规部分。

## 7.12 课后思考与练习

1. **概念辨析**：用 $P(X)$、$P(Y|X)$ 的变化分别刻画三类分布偏移，并为每类举一个视觉实例；说明为什么概念漂移不能靠重加权解决。
2. **概念辨析**：FGSM 与 PGD 的差异是什么？为什么"抗 FGSM"不能作为鲁棒性结论？
3. **计算推导**：证明 logit adjustment 中 $\tau = 1$ 对应"测试时类先验均衡"假设下的贝叶斯最优决策；写出 $\tau$ 的一般形式（提示：训练与测试先验之比）。
4. **计算推导**：对称 INT8 量化下，均匀分布在 $[-s\cdot127, s\cdot127]$ 的舍入误差方差是多少？由此解释为什么 4-bit 量化（127→7）通常需要 QAT。（校验值：方差 $= s^2/12$。）
5. **编程实现**：构造一个双标注小数据集（可用合成规则生成两名"标注者"：一名严格一名宽松），计算观测一致率与 Cohen's kappa，验证不均衡类别下二者的差距。
6. **编程实现**：实现 logit adjustment（$\tau = 1$）训练一个长尾版 CIFAR-10（把每类样本按指数衰减截断），对比朴素交叉熵在头部/中部/尾部三段的每类准确率。
7. **编程实现**：在一张真实照片上运行 `fgsm.py`，扫描 $\varepsilon \in \{0.005, 0.01, 0.02, 0.05, 0.1\}$ 记录攻击成功率与 L2 扰动，并保存 $128\times$ 放大的扰动图，目视确认扰动集中在边缘纹理。
8. **开放思考**：你负责一个医院部署的胸片分类模型。设计一份"上线前偏移测试方案"（至少 3 个测试集维度）与一份"上线后监控指标清单"，标注每个指标分别检测哪类偏移。
9. **开放思考**：机会均等与校准为何不可兼得？构造一个两群体、阈值决策的数值反例说明冲突来源。
10. **挑战题**：阅读 randomized smoothing 原文，写出其认证半径 $\frac{\sigma}{2}(\Phi^{-1}(p_A) - \Phi^{-1}(p_B))$ 中各量的含义，并用蒙特卡洛估计在 MNIST 上给出一个样本的认证半径（校验：对 $\sigma=0.25$、平滑分类器置信 $p_A \approx 0.9$、次优 $p_B \approx 0.1$，半径约 0.31）。
