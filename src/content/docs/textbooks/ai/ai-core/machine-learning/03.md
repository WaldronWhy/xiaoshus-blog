## 3.1 决策树：CART

### 3.1.1 模型形态

决策树是一棵二叉（CART）或多叉（ID3/C4.5）树：内部节点做一次"判断"（如 $x_j \le 5.3$？），叶节点输出预测（分类：该区域多数类；回归：该区域均值）。它把输入空间递归划分成若干矩形区域 $R_m$，模型是**分段常数函数**：
$$
h(x) = \sum_{m=1}^{M} c_m\, \mathbb{1}[x \in R_m].
$$
优点：可解释、天然处理混合类型特征与缺失值、无需特征缩放、预测快。缺点：单棵树方差大（数据稍变、树形大变）、决策边界轴对齐。本节先讲"怎么长一棵树"，3.2 再解决"不稳定"。

### 3.1.2 怎么选划分：不纯度度量

精确最优树是 NP-hard 问题（树的划分组合爆炸），CART 用**贪心**：每个节点独立选择使"子节点不纯度加权平均"最小的特征与切分点（[数据结构·第6章](/xiaoshus-blog/textbooks/ai/programming/data-structures/06/)的贪心哲学）。

**信息熵与信息增益**。设节点中标签分布为 $p_1, \dots, p_K$，[熵](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/01/)为
$$
H(p) = -\sum_{k=1}^K p_k \log_2 p_k .
$$
熵度量"不确定性"：均匀分布最大（二类时 $=1$ bit），纯分布为 0。一次划分把样本按特征 $j$、阈值 $t$ 分成左右子集 $L, R$（占比 $q_L, q_R$），**信息增益**定义为划分前后的熵下降：
$$
IG = H(D_\text{node}) - \Big( q_L H(D_L) + q_R H(D_R) \Big).
$$
$IG$ 越大，这次划分越"值"。注意 $IG$ 其实就是**互信息** $I(Y; \text{分支指示变量})$（[概率统计·第3章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/03/)），划分等价于对标签的一次"观测"。

**基尼系数**（CART 默认）：$G(p) = 1 - \sum_k p_k^2 = \sum_k p_k (1 - p_k)$，即从节点中随机抽两个样本类别不同的概率。二类时 $G = 2p(1-p)$，与熵 $H = -p\log p - (1-p)\log(1-p)$ 形状几乎相同、都在 $p=1/2$ 处最大。基尼不用算对数、更快，实践中与熵选择的树差异极小。回归树用平方误差：选划分使 $\sum_{m} \sum_{i \in R_m} (y_i - c_m)^2$ 最小，$c_m$ 取均值。

**算法（CART 贪心生长）**：
1. 对每个特征 $j$，把该列取值排序，候选切分点取相邻不同值的中点，计算不纯度下降——单节点复杂度 $O(n d \log n)$（排序主导）；
2. 取全局最优 $(j, t)$ 分裂，递归左右子节点；
3. 停止条件：节点纯 / 达到最大深度 / 样本数低于阈值 / 增益低于阈值。

### 3.1.3 剪枝：对抗过拟合

树可以一直长到每个叶一个样本（训练误差 0，第 1 章的 $m\to n$ 过拟合对应物）。控制手段两类：

- **预剪枝**：提前停止（max_depth、min_samples_split、min_impurity_decrease）。快，但可能"目光短浅"——当前增益小不等于后续增益小。
- **后剪枝**：先生长到最大，再自底向上合并叶节点，用验证集（或带复杂度惩罚的训练目标 $J(T) = \sum_m N_m \, \text{impurity}(m) + \alpha |T|$，代价复杂度剪枝）决定保留哪棵子树。更可靠，代价更高。sklearn 的 `ccp_alpha` 即 $\alpha$。

## 3.2 Bagging 与随机森林：方差的手术

### 3.2.1 Bagging（Bootstrap AGGregatING）

单棵树高方差的根源：树对数据扰动极其敏感。**自助聚合（bagging）**：
1. 从训练集有放回抽 $n$ 个样本（bootstrap），重复 $B$ 次得 $B$ 个数据集；
2. 各训练一棵（深）树 $h_1, \dots, h_B$；
3. 回归取平均 $\hat h(x) = \frac1B \sum_b h_b(x)$，分类取多数票。

理论直觉：对 $B$ 个方差为 $\sigma^2$、两两相关系数 $\rho$ 的独立训练模型取平均，方差为
$$
\operatorname{Var}(\hat h) = \rho \sigma^2 + \frac{1 - \rho}{B}\, \sigma^2,
$$
（$B\to\infty$ 时收敛到 $\rho\sigma^2$，校验：$B=1$ 时回到 $\sigma^2$。）bagging 能消除 $1/B$ 项，但**消除不了 $\rho\sigma^2$**——bootstrap 抽样使树之间仍然高度相关。

### 3.2.2 随机森林：给 $\rho$ 也来一刀

随机森林（Breiman, 2001）= bagging + **每次分裂只从随机 $k$ 个特征中选最优**（分类常用 $k = \sqrt d$，回归 $k = d/3$）。特征随机化让树之间去相关，$\rho$ 显著下降，方差进一步降低。这是"注入随机性换泛化"的经典配方，深度学习的 dropout 是同一哲学。额外红利：**袋外（OOB, out-of-bag）估计**——每个样本约有 $1 - 1/e \approx 36.8\%$ 的树没见过它，用这些树的预测做免费验证，无需留出验证集。

### 3.2.3 特征重要性

森林自带特征重要性：按各特征带来的不纯度下降总量（MDI）或置换重要性（permutation importance，打乱该特征看验证误差涨多少）。**用置换重要性**：MDI 偏向高基数特征、有偏。这是 Kaggle 流程（3.6 节）的标准工具之一。

## 3.3 Boosting 总览与 AdaBoost

### 3.3.1 Boosting 思想

与 bagging 并行训练不同，boosting **串行**训练一串弱学习器 $h_1, \dots, h_M$（通常是浅树），每个都针对前面模型的错误。它主要压**偏差**——弱学习器单个偏差大，但加权和可以很强。与第 1 章的对应：Bagging 攻方差项，Boosting 攻偏差项。

### 3.3.2 AdaBoost 推导

设定：二分类 $y_i \in \{-1, +1\}$，弱分类器 $h_m(x) \in \{-1, +1\}$。AdaBoost 维护样本权重 $w_i^{(m)}$（初始均匀 $\frac1n$），训练出 $h_m$ 后按其错误率 $\epsilon_m = \sum_{i: h_m(x_i) \ne y_i} w_i^{(m)}$ 分配权重 $\alpha_m$，组合模型
$$
H(x) = \operatorname{sign}\Big( \sum_{m=1}^M \alpha_m h_m(x) \Big).
$$

**推导（指数损失的坐标下降视角）**。考虑加性模型 $F_M(x) = \sum_{m} \alpha_m h_m(x)$ 最小化指数损失 $J = \sum_i e^{-y_i F_M(x_i)}$。第 1 步固定 $\alpha_m$，第 $M$ 轮新增一项：令 $F_M = F_{M-1} + \alpha h$，
$$
J = \sum_i w_i^{(M)} e^{-y_i \alpha h(x_i)}, \qquad w_i^{(M)} := e^{-y_i F_{M-1}(x_i)} \ \text{(与 } h, \alpha \text{ 无关)}.
$$
第 2 步对 $h$ 优化：$e^{-y_i \alpha h(x_i)}$ 在 $h(x_i) = y_i$ 时取 $e^{-\alpha}$、否则 $e^{\alpha}$，故最优 $h$ 是**在权重 $w^{(M)}$ 下错误率最小的分类器**：
$$
h_M = \arg\min_h \sum_i w_i^{(M)} \mathbb{1}[h(x_i) \ne y_i].
$$
第 3 步对 $\alpha$ 优化：记 $\epsilon_M = \sum_{i: h_M \ne y_i} w_i^{(M)}$，
$$
J = e^{-\alpha}(1 - \epsilon_M) + e^{\alpha} \epsilon_M
\;\Longrightarrow\;
\frac{dJ}{d\alpha} = -e^{-\alpha}(1-\epsilon_M) + e^{\alpha}\epsilon_M = 0
\;\Longrightarrow\;
\boxed{\;\alpha_M = \frac12 \ln \frac{1 - \epsilon_M}{\epsilon_M}\;}
$$
（要求 $\epsilon_M < 1/2$，"比瞎猜好"，弱学习的含义。）第 4 步权重更新：$w_i^{(M+1)} = w_i^{(M)} e^{-\alpha_M y_i h_M(x_i)}$——分对的样本权重按 $e^{-\alpha_M}$ 缩小、分错的按 $e^{\alpha_M}$ 放大（再归一化）。**下一轮的弱学习器被迫盯住本轮的错误**。训练误差随 $M$ 指数下降（可证 $Z$-界 $\prod_m 2\sqrt{\epsilon_m(1-\epsilon_m)}$），且 AdaBoost 事后被 Freund–Schapire（1995/1997）证明具有.margin 理论支持的抗过拟合倾向。

## 3.4 梯度提升（GBDT）：完整原理

### 3.4.1 函数空间中的梯度下降

AdaBoost 只配对指数损失。Friedman（2001）把它推广为：**在前一轮模型的负梯度方向上，用一棵回归树去拟合**。给定可微损失 $\ell(\hat y, y)$（任意：平方、对数、Huber……），当前模型 $F_{m-1}(x)$。经验风险的"梯度"是逐样本的：
$$
r_i^{(m)} = -\Big[ \frac{\partial \ell(y_i, \hat y)}{\partial \hat y} \Big]_{\hat y = F_{m-1}(x_i)} .
$$
梯度下降把参数 $w$ 沿 $-\nabla J(w)$ 移动（[最优化·第2章](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/02/)）；GBDT 把**模型本身**当作变量，用一棵树 $g_m(x) \approx r^{(m)}(x)$ 来表示这个移动方向，再加步长 $\nu$（学习率）：
$$
F_m(x) = F_{m-1}(x) + \nu\, g_m(x), \qquad 0 < \nu \ll 1 .
$$
这就是**函数空间梯度下降**。它是本课程中"把最优化搬到函数空间"最重要的一次示范，深度学习的许多技术是它的近亲。

**两个具体损失**：
- 平方损失：$r_i = y_i - F_{m-1}(x_i)$（残差，最直觉）；
- 二分类对数损失（$F$ 输出 log-odds，$\hat p = \sigma(F(x))$）：$r_i = y_i - \hat p_i$——**又是"残差"形式**（第 2 章 2.2.3 的梯度模式第三次出现）。

### 3.4.2 GBDT 二分类完整算法

```
输入: 数据 (x_i, y_i), y ∈ {0,1}; 损失 = 对数损失; 学习率 ν; 树数 M
1. F_0(x) ≡ log(p(1)/(1-p(1)))        # 用先验正类率初始化 log-odds
2. for m = 1..M:
   a. r_i = y_i - σ(F_{m-1}(x_i))                # 伪残差
   b. 用回归树拟合 r_i (限制深度, 如 3), 得到叶区域 R_jm
   c. 每个叶算牛顿步长: γ_jm = Σ_{i∈R_jm} r_i / ( Σ_{i∈R_jm} p_i(1-p_i) + 正则 )
      —— 最小化 Σ_{i∈R_jm} [−y_i F + log(1+e^F)] 关于该叶共同输出 F 的一阶/二逼近
   d. F_m(x) = F_{m-1}(x) + ν Σ_j γ_jm 1[x ∈ R_jm]
3. 输出 p̂ = σ(F_M(x))
```

### 3.4.3 XGBoost 的改进要点

XGBoost（Chen & Guestrin, 2016）站在 GBDT 肩上，关键改动：

1. **目标函数显式带正则**：$\sum_i \ell(y_i, \hat y_i) + \sum_{j} \big( \gamma T_j + \frac12 \lambda \|w_j\|^2 \big)$，$T_j$ 是第 $j$ 棵树叶数、$w_j$ 是叶输出向量——"树太复杂"直接被惩罚（第 1 章容量控制的显式化）；
2. **二阶泰勒展开**：每轮不是只拟合负梯度 $g_i = \partial \ell / \partial \hat y_i$，而是同时用 Hessian $h_i = \partial^2 \ell / \partial \hat y_i^2$，叶输出有解析解 $w_j^\star = -\frac{\sum_{i \in R_j} g_i}{\sum_{i \in R_j} h_i + \lambda}$，分裂增益也有闭式打分（结构分数下降量）——分裂不再需要"先分裂再算步长"两步；
3. **近似分裂点算法**（按分位数提候选切分点）、列采样、**稀疏感知**（缺失值学习默认方向）、并行化与缓存优化；
4. 工程产物：LightGBM（直方图 + leaf-wise 生长，更快）、CatBoost（原生类别特征 + 有序提升对抗 target leakage）。使用建议：表格数据首选 LightGBM/XGBoost/CatBoost 三选一，深度模型（TabPFN/FT-Transformer 类）做对照，小数据（$n \lesssim$ 万级）时树模型通常仍占优。

## 3.5 关键公式速查

| 公式 | 名称 | 适用条件 |
|---|---|---|
| $H(p) = -\sum_k p_k \log_2 p_k$ | 熵（不纯度） | 概率分布 $p$；离散标签 |
| $IG = H(\text{node}) - q_L H(L) - q_R H(R)$ | 信息增益 | 二叉分裂；等价于互信息 |
| $G = 1 - \sum_k p_k^2$ | 基尼不纯度 | CART 默认；无对数开销 |
| $\operatorname{Var}(\text{平均}) = \rho\sigma^2 + (1-\rho)\sigma^2/B$ | Bagging 方差分解 | 成员两两相关系数 $\rho$；$B$ 棵树 |
| $\alpha_M = \frac12\ln\frac{1-\epsilon_M}{\epsilon_M}$ | AdaBoost 权重 | $\epsilon_M < 1/2$；指数损失 |
| $w_i^{(m+1)} \propto w_i^{(m)} e^{-\alpha_M y_i h_M(x_i)}$ | AdaBoost 样本权重 | 分错放大 $e^{\alpha}$，分对缩小 $e^{-\alpha}$ |
| $r_i^{(m)} = -[\partial \ell/\partial \hat y]_{\hat y = F_{m-1}(x_i)}$ | GBDT 伪残差 | 可微损失；$\nu \in (0,1]$ 学习率 |
| $w_j^\star = -\frac{\sum_{i\in R_j} g_i}{\sum_{i\in R_j} h_i + \lambda}$ | XGBoost 叶输出 | 二阶展开 + L2 叶正则 |

## 3.6 示例与案例

### 示例 1（手算）：信息增益 vs 基尼

节点 10 个样本：6 正 4 负。某切分后左 5 个（4 正 1 负）、右 5 个（2 正 3 负）。
- 划分前熵 $H = -0.6\log_2 0.6 - 0.4\log_2 0.4 \approx 0.971$；
- 左：$H_L = -0.8\log_2 0.8 - 0.2\log_2 0.2 \approx 0.722$；右：$H_R = 0.971$；
- $IG = 0.971 - 0.5(0.722 + 0.971) = 0.971 - 0.846 = \mathbf{0.125}$ bit。
- 基尼：前 $= 2(0.6)(0.4) = 0.48$；左 $= 2(0.8)(0.2)=0.32$，右 $=0.48$；下降 $= 0.48 - 0.5(0.32+0.48) = \mathbf{0.08}$。
- 结论：两个指标都在说"左子节点明显更纯、右几乎没变"，选择一致。

### 示例 2（代码）：从零 AdaBoost 与从零 GBDT，对拍 sklearn

```python
# ch3_ensembles.py
# 依赖: numpy, sklearn(仅用其弱学习器与对拍)
import numpy as np
from sklearn.datasets import make_moons
from sklearn.tree import DecisionTreeClassifier, DecisionTreeRegressor
from sklearn.ensemble import AdaBoostClassifier, GradientBoostingClassifier

X, y = make_moons(n_samples=300, noise=0.3, random_state=0)
y_pm = 2 * y - 1                     # AdaBoost 约定 y ∈ {-1, +1}
Xtr, Xte = X[:200], X[200:]
ytr_pm, yte_pm = y_pm[:200], y_pm[200:]

# ---------- 从零实现 AdaBoost(决策树桩为弱学习器) ----------
def adaboost(Xtr, ytr, M=50):
    n = len(ytr)
    w = np.full(n, 1 / n)
    stumps, alphas = [], []
    for m in range(M):
        h = DecisionTreeClassifier(max_depth=1).fit(Xtr, ytr, sample_weight=w)
        pred = h.predict(Xtr)
        err = w[pred != ytr].sum()               # 加权错误率
        alpha = 0.5 * np.log((1 - err) / max(err, 1e-16))
        w = w * np.exp(-alpha * ytr * pred)
        w = w / w.sum()                           # 归一化
        stumps.append(h); alphas.append(alpha)
    return stumps, alphas

stumps, alphas = adaboost(Xtr, ytr_pm, M=50)
F_te = sum(a * s.predict(Xte) for s, a in zip(stumps, alphas))
acc_my = (np.sign(F_te) == yte_pm).mean()   # 注意: 比较也必须用 ±1 标签

# sklearn 对照(算法配置与上式一致: SAMME 在两类时退化为同公式)
acc_sk = AdaBoostClassifier(
    DecisionTreeClassifier(max_depth=1), n_estimators=50, algorithm="SAMME",
    random_state=0).fit(Xtr, ytr_pm).score(Xte, yte_pm)
print(f"AdaBoost  从零: {acc_my:.3f}   sklearn: {acc_sk:.3f}")
# 预期输出: 两者都 ≈ 0.88~0.92, 差距 ≤ 0.02

# ---------- 从零实现 GBDT 二分类(3.4.2 算法; 使用 0/1 标签) ----------
ytr01, yte01 = y[:200], y[200:]
def gbdt_clf(Xtr, ytr, Xte, M=100, nu=0.1, depth=3):
    p0 = max(ytr.mean(), 1e-6)                 # 先验正类率
    F0 = np.log(p0 / (1 - p0))
    Ftr = np.full(len(ytr), F0)
    Fte = np.full(len(Xte), F0)
    trees = []
    for m in range(M):
        p = 1 / (1 + np.exp(-Ftr))
        r = ytr - p                            # 伪残差 = y - p̂
        h = p * (1 - p)                        # Hessian
        t = DecisionTreeRegressor(max_depth=depth).fit(Xtr, r)
        # 叶内牛顿步长(对应 3.4.2 步 c; λ=1.0)
        leaf = t.apply(Xtr)
        gamma = np.zeros(t.tree_.node_count)
        for j in np.unique(leaf):
            msk = leaf == j
            gamma[j] = r[msk].sum() / (h[msk].sum() + 1.0)
        step_tr, step_te = gamma[leaf], gamma[t.apply(Xte)]
        Ftr += nu * step_tr
        Fte += nu * step_te
        trees.append(t)
    return (Fte > 0).astype(int), trees

pred_my, _ = gbdt_clf(Xtr, ytr01, Xte)
acc_gbdt_my = (pred_my == yte01).mean()
acc_gbdt_sk = GradientBoostingClassifier(
    n_estimators=100, learning_rate=0.1, max_depth=3, random_state=0
).fit(Xtr, ytr01).score(Xte, yte01)
print(f"GBDT      从零: {acc_gbdt_my:.3f}   sklearn: {acc_gbdt_sk:.3f}")
# 预期输出: 两者都 ≈ 0.90~0.93, 差距 ≤ 0.03 (叶步长细节略有差别)

# ---------- 单棵树 vs 森林 vs 提升(第1章框架的直接应用) ----------
from sklearn.ensemble import RandomForestClassifier
for name, model in [
```

### 示例 3（案例）：Kaggle 风格表格竞赛完整流程

以"客户流失预测"（预测用户是否取消订阅，AUC 评测）为例的标准流程，把本章所有零件装进一条流水线：

1. **理解评测指标**：AUC（第 7 章）对阈值不敏感且重视排序 → 训练目标与验证指标都用对数损失 + AUC 双看。
2. **数据切分**：若存在时间因素（流失有时间性），按时间切分而非随机切分——防时间泄漏，这是表格竞赛最常见的翻车点。
3. **基线**：先跑 `LogisticRegression`（第 2 章）+ `RandomForest` + `LightGBM` 三条基线，各 10 分钟。**基线决定你后面所有努力是否有意义**。
4. **特征工程**（往往比换模型涨分更多）：分箱/交叉/目标编码（注意用折内统计防 target leakage）、聚合统计。每加一组特征用 OOF（out-of-fold）验证增量。
5. **调参**：LightGBM 优先调 `num_leaves / min_data_in_leaf / learning_rate + early_stopping`，用 Optuna 贝叶斯搜索（第 7 章）；`feature_fraction/bagging_fraction` 对应本章的随机森林化。
6. **集成**：树模型 + 线性模型 + 神经网络的概率平均，通常再涨 0.3–1 个 AUC 点——不同偏置的模型（NFL 定理的正面利用）错误模式不同。
7. **提交纪律**：本地 CV 与公榜分数应同向变化；一旦背离，先怀疑泄漏或切分方式，而不是继续调参。

## 3.7 常见误区与陷阱

1. **在随机森林上调"树的深度"**。森林靠平均降方差，树该深就深（sklearn 默认不限深是合理的）；要控制的是 `max_features` 与 `n_estimators`。
2. **GBDT 学习率过大**。$\nu > 0.3$ 时极易过拟合且抖动；标准做法 $\nu$ 小（0.05–0.1）+ 早停。
3. **目标编码泄漏**。用全量数据算"各类别的目标均值"再编码，等于把标签泄进特征，CV 分数虚高而线上崩盘。必须折内编码。
4. **AdaBoost 只在 $\epsilon_m < 0.5$ 下推导**。二分类下若弱学习器错误率 ≥ 0.5，$\alpha$ 为负或发散；应换更强的弱学习器或重采样。
5. **在时间序列数据上随机交叉验证**。用未来预测过去，验证分数无意义；用前向滚动验证。
6. **迷信特征重要性（MDI）**。高基数特征天然占优；用置换重要性或 SHAP 交叉印证。
