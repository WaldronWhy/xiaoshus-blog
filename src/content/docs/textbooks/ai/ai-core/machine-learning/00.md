# 机器学习 · 课程导览

> **课程定位**：这是"人工智能核心"模块的第一门课，也是整个专业体系的汇聚点——高等数学、线性代数、概率统计、最优化四门数学课与 Python、数据结构两门程序课的所有知识，将在这里第一次被**同时、成规模地调用**。它同时是《深度学习》《强化学习》《知识表示与推理》的方法论地基：之后你学到的每一个神经网络优化器、每一个策略梯度估计器，都能在本课程中找到它的"非神经祖先"。

## 0.1 这门课为什么是 AI 的核心

人工智能的三大技术支柱——机器学习、深度学习、强化学习——共享同一套底层问题框架：

1. **从数据中归纳规律，并保证规律在没见过的数据上依然成立（泛化，generalization）**；
2. **把"学"表述为一个优化问题或概率推断问题，然后用数学工具求解**；
3. **用严格的实验方法评估"学得好不好"，防止自欺**。

深度学习解决的是第 1、2 条在大规模参数化模型上的实例化，强化学习解决的是"数据由自己产生"时的实例化。但问题框架本身——假设空间、损失函数、经验风险、泛化误差、偏差-方差、正则化、对偶、EM、交叉验证——全部在本课程中建立。**先学机器学习再学深度学习，你会知道自己在"学什么"；反过来学，你只会一堆调参咒语。**

一个直观的例子：本课程第 2 章推导线性回归的最小二乘解与梯度下降；深度学习中训练神经网络的第一课仍是"定义损失、求梯度、迭代更新"，只是梯度改由反向传播（[线性代数·第5章](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/05/)）自动计算。数学没有变，只是模型变复杂了。

## 0.5 学习方法：从零实现每个模型

本教材的三条主线（见 [README](/xiaoshus-blog/textbooks/ai//)）在本课程中的落实方式非常具体：

1. **每个模型写两遍**。第一遍用纯 NumPy 从零实现（只允许用 numpy 的基本运算），这一遍的目的是理解机制；第二遍调用 scikit-learn 等成熟库，对照结果，学习工程接口设计。两遍都写，缺一不可。
2. **每个推导自己补全中间步**。本课程推导的关键步骤都给了依据，但"把依据用起来"的那一两步永远留给你。比如第 4 章的 SVM 对偶推导，正文给出拉格朗日函数，对 $w,b,\xi$ 求偏导并代回的过程请你亲手做一遍——这是对 [最优化·第4章](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/04/) 最好的复习。
3. **每个实验都设"对照组"**。不要只跑一个模型看准确率；至少比较两个复杂度不同的模型、两组超参数，并把误差曲线画出来。第 1 章的偏差-方差框架将贯穿你所有实验的设计。
4. **维护自己的"算法卡片"**。每个模型记录四件事：模型的数学形式、目标函数、优化算法、适用条件与失效场景。期末复习时它就是你的私教。

一个务实的提醒：本课程的代码**不许**用 PyTorch/TensorFlow（它们属于下一门课）；只允许 numpy、scipy、pandas、matplotlib、scikit-learn。scikit-learn 只能用于"对照验证"，不能替你完成"从零实现"部分的练习。

## 0.6 学完本课程你将到达哪里

- **向[《深度学习》](/xiaoshus-blog/textbooks/ai/ai-core/deep-learning/00/)**：第 2 章的梯度下降与正则化 → 神经网络训练与 weight decay/dropout；第 5 章的 EM/ELBO → VAE；第 1 章的泛化直觉 → 现代深度学习泛化理论的出发点。
- **向[《强化学习》](/xiaoshus-blog/textbooks/ai/ai-core/reinforcement-learning/00/)**：第 1 章的"学什么/怎么评"框架 → 策略评估；第 5 章的 EM 思想 → 期望最大化式的策略迭代；第 7 章的实验方法 → RL 实验的可复现性。
- **向[《知识表示与推理》](/xiaoshus-blog/textbooks/ai/ai-core/knowledge-reasoning/00/)**：第 5 章的生成式模型与条件独立假设 → 贝叶斯网络的因子分解。
- **向工程实践**：第 3 章 + 第 7 章的组合（树模型 + 严格评估）就是工业界表格数据问题的标准打法，也是你参加数据竞赛的最小完备工具集。

## 0.7 本课程使用的符号约定

| 符号 | 含义 |
|---|---|
| $D = \{(x_i, y_i)\}_{i=1}^n$ | 训练集，$x_i \in \mathcal{X}$ 输入，$y_i \in \mathcal{Y}$ 输出 |
| $h \in \mathcal{H}$ | 假设空间 $\mathcal{H}$ 中的一个假设（模型） |
| $\ell(h(x), y)$ | 损失函数，衡量预测与真值的差距 |
| $R(h),\ \hat{R}(h)$ | 期望风险（真实泛化误差）与经验风险（训练误差） |
| $\mathbb{E}_{p(x)}[\cdot]$ | 关于分布 $p(x)$ 的期望 |
| $\nabla f$ | 梯度（行向量或列向量遵循所引线性代数章的约定） |
| $\Sigma$ | 协方差矩阵 |
| $\lambda \ge 0$ | 正则化系数 |

开始之前，请确保你能独立完成以下"入场检查"：

1. 写出 $\nabla_x (a^\top x)$ 与 $\dfrac{\partial}{\partial X}\operatorname{tr}(AX)$（答案应在 [线性代数·第5章](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/05/) 的公式表中）。
2. 用贝叶斯公式把 $p(y\mid x)$ 展开成 $p(x\mid y)p(y)$ 的形式（[概率统计·第1章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/01/)）。
3. 说出强凸函数的梯度下降收敛率是 $O(\kappa^{-1})$ 还是 $O(\kappa)$，$\kappa$ 是什么（[最优化·第2章](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/02/)）。
4. 用 NumPy 在一行内计算矩阵 $X$ 每列的均值与标准差（[Python·第4章](/xiaoshus-blog/textbooks/ai/programming/python/04/)）。

若四题都能在 10 分钟内完成，欢迎进入第 1 章。
