# 综合项目：机器学习的实验场

> **本章定位**：本课程的收官实践章。三个综合项目分别打通"全流程方法论（第 1、7 章）""模型实现深度（第 2、3 章）""理论验证（第 1 章）"。每个项目给出任务分解、验收标准与提示；项目彼此独立，建议至少完成两个（其中项目三为必做——它是第 1 章理论唯一的完整数值闭环）。前置要求：对应项目的理论章节均已学习并跑通过章内示例。

## 0.0 项目总则

- **环境**：Python 3.9+，`numpy`、`matplotlib`、`scipy`、`scikit-learn`、`pandas`。禁止使用 PyTorch/TensorFlow（它们属于[《深度学习》](/xiaoshus-blog/textbooks/ai/ai-core/deep-learning/00/)）。
- **通用要求**：所有随机实验固定种子（如 `np.random.default_rng(42)`）；所有图有轴标签与图例；报告以"数据 → 图 → 结论"三段式呈现，结论必须回指课程定理（如"测试 MSE $\approx$ 偏差² + 方差 + 噪声，三项之和与直接测量差 < 5%"）。
- **交付物**：可运行的单文件脚本（或 notebook）+ 500–1000 字实验报告（Markdown）。
- **评分维度建议**：正确性（代码可复现、数值对得上理论）60%，分析深度（解释现象、连接课程概念）30%，呈现质量 10%。
- **诚信红线**：从零实现部分只允许 numpy 的基本运算（矩阵乘、逐元素运算、`linalg.solve/lstsq` 等线性代数原语）；发现直接调用被封印的 sklearn 估计器完成"从零"部分即不通过。

## 项目一：从零实现完整的 AutoML 流水线（交叉验证 + 特征选择 + 模型选择）

**一句话目标**：把第 1、2、3、7 章的知识拧成一条自动流水线：给定一个表格数据集，全自动完成特征选择、模型选择与超参数调优，并给出**无偏**的泛化性能估计。

### 1.1 背景与理论回顾

AutoML 的最小内核就是本课程的方法论：模型空间（候选模型 + 超参数网格，第 2、3 章）× 选择机制（交叉验证，第 7 章）× 防泄漏协议（嵌套 CV，第 7 章 7.3.3）。本项目不追求覆盖面，追求**协议严格性**——你实现的是"不会骗自己的最小 AutoML"。相关章节：第 1 章（过拟合诊断）、第 2 章（Lasso 特征选择、逻辑回归）、第 3 章（随机森林 / GBDT）、第 7 章（CV、指标、嵌套 CV、随机搜索）。

### 1.2 任务分解

1. **任务 A（数据与协议）**：选两个数据集——小数据 `sklearn.datasets.load_breast_cancer`（569 样本）与一个约 $10^4$ 样本的开放数据集（如 `fetch_openml("credit-g")` 或 Kaggle Titanic）。数据集划分采用**嵌套 CV**：外层 5 折估泛化，内层 3 折做全部选择。
2. **任务 B（特征选择器）**：实现两种，纳入候选——
   - 基于 L1 的选择：用第 2 章的 `lasso_cd`（或 `LassoCV` 的系数）按 $|\lambda|$ 阈值筛特征；
   - 基于模型的置换重要性（第 3 章 3.2.3）：在**内层训练折**上计算，绝不触碰验证折。
3. **任务 C（模型空间）**：至少四个候选，统一接口 `fit(X, y) / predict_proba(X)`：
   - 逻辑回归（L2，$\lambda \in$ 对数网格 5 点）；
   - 标准 KNN（$k \in \{1, 5, 15, 31\}$——它对特征缩放与维度灾难的敏感性是流水线价值的最好陪衬）；
   - 随机森林（`n_estimators=300`，`max_features ∈ {sqrt, 0.5}`）；
   - GBDT（可用 sklearn 实现，`max_depth ∈ {2, 3}`，学习率 $\in \{0.05, 0.1\}$）。
4. **任务 D（搜索器）**：实现网格搜索与随机搜索两种（第 7 章 7.3.1），在credit-g 上对比：相同预算（如 60 次评估）下两者的最优内层分数分布。
5. **任务 E（流水线整合）**：`automl.fit(X, y)` 依次执行：内层 CV 对每个（特征选择方案 × 模型 × 超参数）组合打分 → 选出最优组合 → 在全数据上重训最终模型。输出：选中配置、外层 CV 分数（AUC ± std）、各候选的内层分数表。
6. **任务 F（诚实验证）**：报告三个数字并解释它们的差异：(a) 内层最优分数；(b) 外层 CV 分数；(c) 若你把内层分数当泛化性能会高估多少。

### 1.3 验收标准

- [ ] 全程无泄漏：特征选择、标准化、调参全部只在内层训练折上完成（用人为注入的"标签泄漏特征"（如 $y$ 的加噪副本）自测：泄漏版外层分数应显著虚高而你的流水线外层分数不受影响——这一条是本项目的灵魂）；（校验目标：注入泄漏后，天真协议外层 AUC 上升 > 0.05，你的流水线上升 < 0.02）
- [ ] 嵌套 CV 完整实现并报告外层分数 ± 标准差；
- [ ] 至少在 credit-g 上复现"GBDT/RF ≥ 逻辑回归 ≥ KNN"的典型排序（允许个别反转，需解释）；
- [ ] 随机搜索 vs 网格搜索的对比图（同预算）；
- [ ] 报告含任务 F 的三个数字与解释。

### 1.4 提示

- 标准化器放进流水线内部（每折独立 fit），不要全局预处理后再 CV——这是最常见泄漏；
- KNN 的差表现不是 bug：结合第 1 章容量与第 7 章指标讨论"什么时候 KNN 反而强"（低维、决策面局部复杂、数据量小）；
- 想加分：加入校准环节（第 7 章 7.2.3，对 GBDT 分数做 isotonic 校准）并对比 Brier 分数。

## 项目二：从零实现二分类 GBDT，与 sklearn 正面对拍

**一句话目标**：亲手实现第 3 章 3.4.2 的完整算法（log-odds 初始化 → 伪残差 → 回归树 → 叶内牛顿步长 → 加权累加），在多个数据集上逼近 sklearn `GradientBoostingClassifier` 的精度，并复现学习率-树数的权衡曲线。

### 2.1 背景与理论回顾

GBDT 是"函数空间梯度下降"（第 3 章 3.4.1）：每轮的伪残差 $r_i = y_i - \sigma(F_{m-1}(x_i))$ 是对数损失在当前模型处的负梯度（第 2 章 2.2.3 的"梯度 = 残差"模式在函数空间的复现），叶内牛顿步长 $\gamma_j = \sum_{i \in R_j} r_i / \sum_{i \in R_j} p_i(1-p_i)$ 来自二阶信息（正是 XGBoost 二阶展开的雏形）。基学习器是一棵受限回归树（第 3 章 3.1，深度 $\le 3$）。你需要从零实现：CART 回归树（或用 `DecisionTreeRegressor` 作为基学习器——推荐先用它聚焦在 boosting 逻辑上，再加分项自写回归树）。

### 2.2 任务分解

1. **任务 A（核心训练循环）**：按 3.4.2 伪代码实现 `GBDTClassifier(n_estimators, learning_rate, max_depth, reg_lambda)`，包含：log-odds 初始化（按先验正类率）、每轮伪残差与 Hessian、基学习器拟合、叶内牛顿步长（带 $\lambda$ 正则）、log-odds 累加。
2. **任务 B（训练监控）**：每轮记录训练/验证的对数损失曲线，实现**早停**（验证损失 `patience=10` 轮不降即停）——这是 GBDT 实践的第一正则化。
3. **任务 C（对拍）**：在三个数据集（`make_moons(noise=0.3)`、`load_breast_cancer`、credit-g）上与 sklearn 同配置对拍（相同 $M$、$\nu$、深度），报告 AUC 差异。（校验目标：|AUC 差异| ≤ 0.02；小数据集上通常 ≤ 0.005）
4. **任务 D（权衡曲线）**：固定其他参数，扫描学习率 $\nu \in \{0.02, 0.05, 0.1, 0.3, 1.0\}$ × 树数 $M \in \{50, 100, 200, 500\}$，画验证 AUC 热力图。验证第 3 章 3.11 练习 4 的补偿关系：小 $\nu$ 配大 $M$ 才是好区域。
5. **任务 E（加分：自写回归树）**：实现基于平方误差的 CART 回归树（贪心分裂 + 最大深度），替换 `DecisionTreeRegressor`，重跑任务 C。注意排序找切分点的复杂度 $O(n d \log n)$。
6. **任务 F（加分：多分类）**：把 softmax + 逐类梯度推广到 3 类（Iris），验证 One-vs-All 或 softmax-GBDT 两种路线。

### 2.3 验收标准

- [ ] 对数损失在训练中单调下降（当 $\nu$ 小时）；任一轮上升即有 bug；
- [ ] 任务 C 的对拍达标（≤ 0.02 AUC）；
- [ ] 早停生效：与不开早停相比，在噪声数据（moons）上测试 AUC 不降、树数平均减少 > 30%；
- [ ] 任务 D 热力图 + 一段"$\nu$-$M$ 补偿"的文字论证；
- [ ] 报告解释你的实现与 XGBoost 的三点差距（提示：二阶分裂打分、行/列采样、直方图近似分裂）。

### 2.4 提示

- 叶内牛顿步长若省略（直接用叶残差均值），深树时性能明显劣化——请实证这个差别并解释（提示：对数损失下步长被 Hessian 缩放，$p$ 接近 0/1 时梯度步会过冲）；
- 数值稳定：$\sigma(F)$ 大值时 $p \to 1$，$p(1-p) \to 0$，分母加 $\lambda$（或 $\epsilon$）是刚需；
- 调试技巧：在纯线性可分数据上（`make_classification` 无噪声）设 $\nu = 1$、$M = 5$，训练误差应迅速归零；跑不过这一步先查残差方向。

## 项目三（必做）：偏差-方差-噪声三项分解的完整实验

**一句话目标**：在第 1 章 1.8 的基础上做出完整的定量研究：构造一个**已知真函数与噪声**的模拟环境，对多个模型家族（多项式 / kNN / 随机森林 / GBDT）与多组超参数，实测偏差²、方差、噪声三项，复现经典教科书图（ESL Fig. 7.x 风格），并验证总误差 = 三项之和的分解恒等式。

### 3.1 背景与理论回顾

第 1 章 1.4 的分解：$\mathbb{E}_D[(\hat f_D(x) - y)^2] = \text{bias}^2(x) + \text{variance}(x) + \sigma^2$。实验设计要点：$D$ 的随机性来自"重新采样训练集"（蒙特卡洛 $M \ge 200$ 次），固定测试网格 $x$ 上计算
$$
\widehat{\text{bias}}^2(x) = (\bar f(x) - f(x))^2, \quad
\widehat{\text{var}}(x) = \frac{1}{M}\sum_k (\hat f_k(x) - \bar f(x))^2, \quad
\bar f(x) = \frac1M \sum_k \hat f_k(x),
$$
再对 $x$ 积分（取均值）得全局三项。噪声项 $\sigma^2$ 已知（你自己设定的）。校验恒等式：三项之和应与直接蒙特卡洛测得的期望平方误差一致（差 < 蒙特卡洛误差）。

### 3.2 任务分解

1. **任务 A（模拟环境）**：真函数取两个难度——简单：$f(x) = \sin(2\pi x)$；困难：$f(x) = \sin(2\pi x) + 0.5\, x^2 - \mathbb{1}[x > 0.6]$（含跳变，考验树模型）。噪声 $\sigma^2 \in \{0.09, 0.25\}$。训练集大小 $n \in \{25, 100, 400\}$。
2. **任务 B（模型 × 超参数网格）**：
   - 多项式回归：次数 $m \in \{1, 3, 5, 9, 15\}$（第 1、2 章）；
   - kNN：$k \in \{1, 5, 15, 30\}$（回归版，预测取均值）；
   - 随机森林（回归版）：`max_features ∈ {1.0, 0.5, 0.2}`（观察"去相关降低方差"对分解的影响）；
   - GBDT（项目二的实现或 sklearn 回归版）：`max_depth ∈ {1, 2, 4}`。
3. **任务 C（蒙特卡洛分解）**：每个配置跑 $M = 200$ 个训练集，在 500 点网格上估计三项，输出：(i) 全局三项柱状图堆叠图（x 轴 = 配置，y 轴 = 三项堆叠 + 顶部标总误差）；(ii) 三项随 $m$ / $k$ 的曲线（经典 U 形图）。
4. **任务 D（恒等式校验）**：对每个配置验证 bias² + var + $\sigma^2$ ≈ 直接测得的期望误差，报告最大相对偏差。（校验目标：< 3%）
5. **任务 E（对照组实验，回答三个问题）**：
   - **Q1（数据量的作用）**：固定模型为 $m = 9$ 多项式，扫 $n$，证明方差项随 $n$ 下降而偏差²几乎不动（这是第 1 章 1.3"加数据治过拟合不治欠拟合"的数值证明）；
   - **Q2（bootstrap 的作用）**：对同一回归树做 bagging（$B = 50$），对比分解前后方差项的下降（bagging 攻方差的第一手证据）；
   - **Q3（噪声的作用）**：$\sigma^2$ 从 0.09 加倍到 0.25，观察最优容量（U 形谷底的 $m$/$k$）如何向小容量移动（噪声越大越要保守）。
6. **任务 F（分类扩展，加分）**：在 moons 数据上用 0-1 损失重复分解，验证"加性分解不再精确成立"（总误差 ≠ 三项简单相加），并解释差额去向。

### 3.3 验收标准

- [ ] 至少 4 个模型家族 × 各自超参数网格全部完成分解，两张核心图（堆叠柱状 + U 形曲线）；
- [ ] 任务 D 恒等式校验全部 < 3%；
- [ ] Q1 的"方差降、偏差不动"与 Q3 的"最优容量左移"均有数值证据；
- [ ] bagging 前后的方差对比表；
- [ ] 报告用第 1 章的语言解释每一个图（不许只贴图不解释）。

### 3.4 提示

- 蒙特卡洛误差与 $M$ 的关系是 $O(1/\sqrt M)$：先在单配置上画"估计值 vs $M$"曲线，确定 $M = 200$ 足够（方差项估计抖动 < 5%）再跑全网格——这本身是第 7 章实验方法论的应用；
- kNN 的偏差²在 $k$ 小时≈0、方差巨大；多项式的偏差²在 $m$ 小时巨大、方差在 $m$ 大时爆炸——两类模型的 U 形形态不同，值得对比讨论；
- 高次多项式在 $n = 25$、$m = 15$ 时数值病态（条件数极大），用 `np.linalg.lstsq`（SVD）而非 `inv`；偶发发散的重复可跳过（记录跳过率并在报告中说明）；
- 想加分：把"跳变函数"上的树模型与多项式对调对比——线性模型在跳变处偏差²巨大而树模型几乎无偏，这是"归纳偏置匹配问题结构"（第 1 章 NFL）最直观的数值演示。
