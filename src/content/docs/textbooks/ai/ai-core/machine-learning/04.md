# 第 4 章 SVM 与核方法

> **本章定位**：支持向量机（Support Vector Machine, SVM）是凸优化在机器学习中最漂亮的旗舰应用——本章的推导把[《最优化方法·第4章》](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/04/)的拉格朗日对偶与 KKT 条件完整地"用了一遍"，而不是教条地背诵。核技巧则把第 2 章"特征映射 + 线性模型"的骨架推到无限维，并引出核岭回归等一族核方法。

## 4.1 最大间隔与硬间隔 SVM

### 4.1.1 模型与间隔

二分类 $y_i \in \{-1, +1\}$，线性分类器 $h(x) = \operatorname{sign}(w^\top x + b)$。几何事实：超平面 $w^\top x + b = 0$ 的法向量为 $w$，任意点到它的（带符号欧氏）距离为
$$
d(x) = \frac{|w^\top x + b|}{\|w\|_2}.
$$
若所有训练点被正确分类且满足 $y_i(w^\top x_i + b) \ge 1$（缩放 $(w,b)$ 可规范化到最小值恰为 1），则**间隔（margin）**——最近点到超平面的距离——恰为 $1/\|w\|_2$。**最大间隔原则**：在所有能分开训练集的超平面中，选离两边最近样本最远的那个。直觉：训练集只是真实分布的样本，最大间隔的超平面"容忍"训练样本最大的扰动而不改变分类——这是对分布摄动的鲁棒性，也是第 1 章"泛化来自归纳偏置"的具体化。

### 4.1.2 原问题（硬间隔）

最大化 $1/\|w\|$ 等价于最小化 $\frac12\|w\|^2$（系数 $\frac12$ 纯为求导整洁）：
$$
\min_{w, b} \;\; \frac12 \|w\|_2^2 \qquad \text{s.t.} \;\; y_i (w^\top x_i + b) \ge 1, \;\; i = 1, \dots, n.
$$
这是二次目标 + 线性约束的**凸 QP**（[最优化·第1章](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/01/)），解唯一（强凸）。KKT 条件成立时：$y_i(w^\top x_i + b) - 1 = 0$ 只对部分样本取等——这些样本就是**支持向量**，它们（且只有它们）决定超平面；其余样本怎么动都不影响解。这就是 SVM 稀疏性的来源。

## 4.2 对偶问题推导（本章核心推导）

按[《最优化·第4章》](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/04/)的流程逐步执行。

**第 1 步：拉格朗日函数。** 约束写成 $g_i(w,b) = 1 - y_i(w^\top x_i + b) \le 0$，引入乘子 $\alpha_i \ge 0$：
$$
L(w, b, \alpha) = \frac12 \|w\|^2 - \sum_{i=1}^n \alpha_i \big[ y_i (w^\top x_i + b) - 1 \big].
$$

**第 2 步：对 $w, b$ 求偏导并置零。**
$$
\nabla_w L = w - \sum_i \alpha_i y_i x_i = 0 \;\Longrightarrow\; w = \sum_i \alpha_i y_i x_i,
\qquad
\frac{\partial L}{\partial b} = -\sum_i \alpha_i y_i = 0 \;\Longrightarrow\; \sum_i \alpha_i y_i = 0.
$$
第一个式子表明**最优解 $w$ 是训练样本的线性组合，系数是 $\alpha$**；第二个式子是对偶问题的一条约束。

**第 3 步：代回，消去 $w, b$。** 由 KKT 强对偶性（ Slater：线性约束凸 QP 必满足），原问题等价于
$$
\max_{\alpha \ge 0} \; \min_{w,b} L(w,b,\alpha).
$$
代入 $w = \sum_i \alpha_i y_i x_i$：
$$
\frac12 \|w\|^2 - \sum_i \alpha_i y_i w^\top x_i - b\underbrace{\sum_i \alpha_i y_i}_{=0} + \sum_i \alpha_i
= \frac12 \sum_{i,j} \alpha_i \alpha_j y_i y_j x_i^\top x_j - \frac12 \sum_{i,j} \alpha_i \alpha_j y_i y_j x_i^\top x_j + \sum_i \alpha_i,
$$
（第二项用 $w^\top x_j = \sum_i \alpha_i y_i x_i^\top x_j$。）两个二次项恰好相消，得到
$$
\max_\alpha \; \sum_i \alpha_i - \frac12 \sum_{i,j} \alpha_i \alpha_j y_i y_j \, x_i^\top x_j
\quad\text{s.t.}\quad
\sum_i \alpha_i y_i = 0, \;\; \alpha_i \ge 0 .
$$

**关键观察**：对偶问题中数据只以**内积** $x_i^\top x_j$ 的形式出现。这一观察是 4.4 核技巧的全部伏笔。

**第 4 步：解回原变量。** 解出 $\alpha^\star$（多数分量为 0），由 KKT 互补条件：$\alpha_i > 0 \Rightarrow y_i(w^\top x_i + b) = 1$，即 $\alpha_i > 0$ 的恰为支持向量；$b^\star$ 从任一支持向量解出：$b^\star = y_i - w^{\star\top} x_i$（数值上取所有支持向量的平均以稳健）。预测函数：
$$
h(x) = \operatorname{sign}\Big( \sum_{i \in SV} \alpha_i^\star y_i \, x_i^\top x + b^\star \Big).
$$

## 4.3 软间隔：松弛变量与 C

现实数据几乎不可线性完全可分（第 1 章的噪声！）。硬性要求分对会陷入不可行或被离群点绑架。引入**松弛变量（slack variables）** $\xi_i \ge 0$，允许"欠账"：
$$
\min_{w, b, \xi} \;\; \frac12\|w\|^2 + C \sum_{i=1}^n \xi_i
\quad\text{s.t.}\quad
y_i(w^\top x_i + b) \ge 1 - \xi_i, \;\; \xi_i \ge 0 .
$$
$\xi_i$ 的几何含义：样本 $i$ 违反间隔的量（$\xi_i > 0$ 落入间隔带，$\xi_i > 1$ 直接错边）。$C$ 是"欠账单价"：
- $C \to \infty$：退回硬间隔（方差大，第 1 章容量大）；
- $C \to 0$：间隔带随意宽，模型过简（偏差大）。
$C$ 与第 2 章的 $\lambda$ 是同一枚硬币：岭回归 $\lambda$ 加在参数上，SVM 的 $C$ 加在违反量上，$C \sim 1/\lambda$。软间隔对偶与硬间隔几乎相同，只把约束改为 $0 \le \alpha_i \le C$（由 $\xi_i$ 的最优性条件 $C - \alpha_i - \mu_i = 0$、$\mu_i \ge 0$ 推出）：
$$
\max_\alpha \; \sum_i \alpha_i - \frac12\sum_{i,j} \alpha_i\alpha_j y_i y_j x_i^\top x_j
\quad\text{s.t.}\quad
\sum_i \alpha_i y_i = 0, \;\; 0 \le \alpha_i \le C .
$$
此时支持向量分三档：$\alpha_i = 0$（间隔带外，无关紧要）、$0 < \alpha_i < C$（恰在间隔边界上，$\xi_i = 0$）、$\alpha_i = C$（违反者）。合页损失视角：软间隔 SVM 等价于最小化 $\sum_i \max(0, 1 - y_i(w^\top x_i + b)) + \frac{\lambda}{2}\|w\|^2$——合页损失（hinge loss）正是第 1 章 1.1 中 0-1 损失的凸代理家族成员，与第 2 章对数损失并列。

## 4.4 核技巧与 Mercer 条件

### 4.4.1 从特征映射到核函数

第 2 章 2.1.3 已经看到"特征映射 $\phi$ + 线性模型"的套路：$\phi(x) = (1, x, x^2, \dots)$。SVM 的对偶问题只用到 $\langle \phi(x_i), \phi(x_j) \rangle$。于是：**如果能找到一个函数 $K(x, z) = \langle \phi(x), \phi(z) \rangle$，就可以根本不显式计算 $\phi$**。经典例子：
$$
K(x, z) = (x^\top z)^2, \quad x, z \in \mathbb{R}^2:
$$
直接展开：$(x^\top z)^2 = (x_1z_1 + x_2z_2)^2 = x_1^2z_1^2 + 2x_1x_2z_1z_2 + x_2^2z_2^2 = \langle \phi(x), \phi(z) \rangle$，其中 $\phi(x) = (x_1^2, \sqrt2 x_1x_2, x_2^2) \in \mathbb{R}^3$。二维到三维只是小意思；核 $K(x,z) = (x^\top z + c)^m$ 隐式对应约 $\binom{d+m}{m}$ 维特征空间；**RBF 核（高斯核）**
$$
K(x, z) = \exp\big( -\gamma \|x - z\|^2 \big), \quad \gamma > 0
$$
对应**无限维**特征空间（可由 $e^{-\gamma\|x-z\|^2}$ 的泰勒展开验证）——在无限维空间里做线性分类，等价于在原空间做任意复杂度的分段局部分类。

### 4.4.2 什么样的 $K$ 是合法核：Mercer 条件

核矩阵 $K = [K(x_i, x_j)]_{n\times n}$。**Mercer 条件**（实用判据）：$K$ 合法 $\iff$ 对任意有限样本集，$K$ 对称半正定（PSD）。证明方向（一侧）：若 $K = \langle\phi(\cdot),\phi(\cdot)\rangle$，则对任意向量 $c$，$c^\top K c = \|\sum_i c_i \phi(x_i)\|^2 \ge 0$。常用**核的封闭运算**（合法核的组合仍合法）：常数倍、和、乘积、正定函数的复合 $K(x,z) = f(K_1(x,z))$（$f$ 多项式且系数非负/或 $f = e^{(\cdot)}$）。校验练习：$K(x,z) = -x^\top z$（核矩阵为负定方向）不合法；$K(x,z) = e^{-x^\top z}$ 合法（指数复合 + 注意符号：$e^{-s} = e^{f(s)}$ 中 $f(s) = -s$ 不是多项式非负系数——正确论证是把它写成高斯核与 $e^{0}$ 的推广：对固定数据集验证 PSD，或用 $e^{-x^\top z} = \lim_{\gamma \to 0} e^{-\gamma\|x\|^2/2} e^{\gamma x^\top z} e^{-\gamma\|z\|^2/2}$ 视为高斯核的极限情形，实际使用中以数据集 PSD 校验为准）。

**实际使用中的超参数**：RBF 核 $\gamma$ 控制局部性（大 $\gamma$ → 邻域小 → 模型复杂 → 第 1 章容量大；过拟合时减 $\gamma$）；与 $C$ 一起用交叉验证调（第 7 章）。

常用核速查表（工程选择的第一站）：

| 核 | 表达式 | 特征空间 | 适用场景 |
|---|---|---|---|
| 线性核 | $x^\top z$ | 原空间 | $d$ 大 $n$ 大（文本、稀疏特征）；`LinearSVC` |
| 多项式核 | $(\gamma\, x^\top z + r)^m$ | $\approx \binom{d+m}{m}$ 维 | 特征交互已知重要；$m$ 过大易数值不稳 |
| RBF 核 | $\exp(-\gamma\|x - z\|^2)$ | 无限维 | 通用默认；样本 $\lesssim 10^4$ |
| Sigmoid 核 | $\tanh(\gamma\, x^\top z + r)$ | —— | 并非所有参数下半正定，慎用；历史上与神经网络的类比 |

### 4.4.3 核方法与核岭回归

核技巧不止属于 SVM：**任何以 $x_i^\top x_j$ 形式使用数据的线性算法都可核化**。范式（表示定理，representer theorem 的特例）：最优解总可写成 $f(x) = \sum_i \alpha_i K(x_i, x)$。以岭回归为例（推导要点见练习 6）：
$$
\min_f \; \|y - K\alpha\|^2 + \lambda\, \alpha^\top K \alpha
\;\Longrightarrow\;
\alpha^\star = (K + \lambda I)^{-1} y,
\qquad
\hat f(x) = \sum_i \alpha_i^\star K(x_i, x).
$$
对比第 2 章的 $w^\star = (X^\top X + \lambda I)^{-1}X^\top y$：把 $X X^\top$（$n \times n$ 的 Gram 矩阵）换成 $K$ 即得——**核岭回归 = 在特征空间的岭回归**，$n$ 小 $d$ 大时核化更划算，$n$ 大时核矩阵 $O(n^2)$ 内存成为瓶颈。核化的通用配方还产生了核 PCA（第 6 章）。

## 4.5 SMO：对偶 QP 的分解求解

对偶问题是 $n$ 变量的 QP，通用内点法 $O(n^3)$ 不可承受。**SMO（Sequential Minimal Optimization, Platt 1998）**：每次只优化**两个**变量（两个是因为 $\sum_i \alpha_i y_i = 0$ 的等式约束要求至少两个一起动），其余固定，闭式求解该 2 变量子问题，循环直到 KKT 条件满足。单次更新（固定其余变量时 $\sum_{j \ne i}\alpha_j y_j = \zeta$ 恒定）：
$$
\alpha_j^{\text{new}} = \alpha_j - \frac{y_j (E_i - E_j)}{\eta}, \qquad
\eta = 2K_{ij} - K_{ii} - K_{jj},
$$
其中 $E_k = \sum_l \alpha_l y_l K(x_l, x_k) + b - y_k$ 是第 $k$ 个样本的"训练误差"，并把 $(\alpha_i, \alpha_j)$ 裁剪到箱式约束 $0 \le \alpha \le C$ 与等式约束决定的区间 $[L, H]$ 内；随后增量更新 $b$。选对策略：外层挑违反 KKT 最严重的 $\alpha_i$，内层选使 $|E_i - E_j|$ 最大的 $\alpha_j$（启发式，保证更新幅度大、收敛快）。直觉：SMO 就是"坐标下降（第 2 章 2.4）在对偶箱式约束上的两坐标版本"。

## 4.6 关键公式速查

| 公式 | 名称 | 适用条件 |
|---|---|---|
| $\min_{w,b} \frac12\|w\|^2$ s.t. $y_i(w^\top x_i + b) \ge 1$ | 硬间隔原问题 | 线性可分；凸 QP |
| $w = \sum_i \alpha_i y_i x_i,\ \sum_i \alpha_i y_i = 0$ | 对偶驻点条件 | KKT 置零偏导 |
| $\max_\alpha \sum_i \alpha_i - \frac12 \sum_{i,j}\alpha_i\alpha_j y_i y_j x_i^\top x_j$ | 对偶问题 | $0 \le \alpha_i \le C$（软间隔） |
| $K(x,z) = \langle \phi(x), \phi(z) \rangle$ | 核函数 | Mercer：核矩阵对称半正定 |
| $K(x,z) = \exp(-\gamma\|x-z\|^2)$ | RBF 核 | 对应无限维特征空间；$\gamma$ 控制容量 |
| $\alpha^\star = (K + \lambda I)^{-1} y$ | 核岭回归 | 数据以 Gram 矩阵 $K$ 进入；PSD |
| $\alpha_j \leftarrow \alpha_j - \frac{y_j(E_i - E_j)}{2K_{ij} - K_{ii} - K_{jj}}$ | SMO 两变量更新 | 其余 $\alpha$ 固定；裁剪到 $[L,H]$ |

## 4.7 示例与案例

### 示例 1（手算）：四个点的 SVM

二维数据：正类 $x_1 = (3, 3),\ x_2 = (4, 3)$；负类 $x_3 = (1, 1),\ x_4 = (2, 0)$。手推（对称性提示 $w_1 = w_2$）：
- 猜支持向量为最近的一对异类点 $x_1, x_3$。设 $w = (w, w)$，则约束取等：$3w + 3w + b = 1$ 与 $w + w + b = -1$。两式相减得 $4w = 2$，即 $w = 1/2$，代回得 $b = -2$。故 $w^\star = (1/2,\ 1/2),\ b^\star = -2$。
- 验证全部约束：$x_1$: $\frac12(6) - 2 = 1$ ✓（取等，支持向量）；$x_2$: $\frac12(7) - 2 = 1.5 \ge 1$ ✓；$x_3$: $\frac12(2) - 2 = -1$ ✓（取等，支持向量）；$x_4$: $\frac12(2) - 2 = -2 \le -1$ ✓。
- 数值求解对偶 QP 可得 $\alpha^\star = (0.25,\ 0,\ 0.25,\ 0)$——只有支持向量上 $\alpha$ 非零，且用 $w = \sum_i \alpha_i y_i x_i$ 验证：$0.25(3,3) - 0.25(1,1) = (0.5, 0.5) = w^\star$ ✓；$b$ 由支持向量得 $b = y_i - w^\top x_i = -2$ ✓。
- 点评：$x_2, x_4$ 无论怎么移动（只要不越过间隔边界）都不改变解——这就是 4.1.2 说的"其余样本怎么动都不影响解"。请用 4.7 示例 2 的 SMO 代码（改用线性核）在这组数据上复现 $\alpha^\star$。

### 示例 2（代码）：简化版 SMO 从零实现 + RBF 核对拍

```python
# ch4_svm_smo.py
# 依赖: numpy, sklearn(仅对拍)
import numpy as np
from sklearn.datasets import make_moons
from sklearn.svm import SVC

rng = np.random.default_rng(0)
X, y = make_moons(n_samples=200, noise=0.2, random_state=0)
y_pm = 2 * y - 1                          # 约定 y ∈ {-1, +1}
Xtr, Xte, ytr, yte = X[:150], X[150:], y_pm[:150], y[150:]

def rbf_kernel(X1, X2, gamma=1.0):
    d2 = np.sum(X1**2, 1)[:, None] + np.sum(X2**2, 1)[None, :] - 2 * X1 @ X2.T
    return np.exp(-gamma * np.maximum(d2, 0))

def train_smo(K, y, C=1.0, tol=1e-3, max_pass=100):
    """简化版 SMO: 外层全扫描, 内层随机选 j (Platt 简化版, 见 CS229 习题)."""
    n = len(y)
    alpha = np.zeros(n); b = 0.0
    f = lambda i: (alpha * y) @ K[:, i] + b            # 当前决策值 f(x_i)
    passes = 0
    while passes < max_pass:
        changed = 0
        for i in range(n):
            E_i = f(i) - y[i]
            if (y[i] * E_i < -tol and alpha[i] < C) or \
               (y[i] * E_i >  tol and alpha[i] > 0):   # 违反 KKT
                j = rng.integers(n)
                while j == i: j = rng.integers(n)
                E_j = f(j) - y[j]
                a_i_old, a_j_old = alpha[i], alpha[j]
                # 箱式 + 等式约束决定的 [L, H]
                if y[i] != y[j]:
                    L, H = max(0, alpha[j] - alpha[i]), min(C, C + alpha[j] - alpha[i])
                else:
                    L, H = max(0, alpha[i] + alpha[j] - C), min(C, alpha[i] + alpha[j])
                if L == H: continue
                eta = 2 * K[i, j] - K[i, i] - K[j, j]
                if eta >= 0: continue                  # 理论上应为负(PSD + 独立点)
                alpha[j] = min(H, max(L, alpha[j] - y[j] * (E_i - E_j) / eta))
                if abs(alpha[j] - a_j_old) < 1e-5: continue
                alpha[i] += y[i] * y[j] * (a_j_old - alpha[j])
                # 增量更新 b
                b1 = b - E_i - y[i]*(alpha[i]-a_i_old)*K[i,i] - y[j]*(alpha[j]-a_j_old)*K[i,j]
                b2 = b - E_j - y[i]*(alpha[i]-a_i_old)*K[i,j] - y[j]*(alpha[j]-a_j_old)*K[j,j]
                b = b1 if 0 < alpha[i] < C else (b2 if 0 < alpha[j] < C else (b1 + b2) / 2)
                changed += 1
        passes = passes + 1 if changed == 0 else 0      # 一整轮无更新才算收敛
    return alpha, b

Ktr = rbf_kernel(Xtr, Xtr, gamma=2.0)
alpha, b = train_smo(Ktr, ytr, C=1.0)
print(f"支持向量个数: {(alpha > 1e-6).sum()} / {len(ytr)}")   # 预期: 30~60 个
Kte = rbf_kernel(Xte, Xtr, gamma=2.0)
pred_my = np.sign(Kte @ (alpha * ytr) + b)
print(f"SMO 从零     测试精度: {(pred_my == yte).mean():.3f}")  # 预期: ≈0.96~1.00

# sklearn 对拍(同一超参数)
clf = SVC(C=1.0, kernel="rbf", gamma=2.0).fit(Xtr, ytr)
print(f"sklearn SVC  测试精度: {clf.score(Xte, yte):.3f}")       # 预期: ≈0.96~1.00
# 观察: 简化 SMO 与工业实现的决策值可能不同, 但分类面与精度接近;
# 工业版差异来自: 启发式选对、收敛判据、数值细节。

# ---------- 核岭回归(4.4.3 闭式解) 在回归问题上 ----------
n_tr = 40
xg = np.sort(rng.uniform(0, 1, n_tr)); yg = np.sin(2*np.pi*xg) + 0.1*rng.normal(size=n_tr)
Kg = rbf_kernel(xg[:, None], xg[:, None], gamma=5.0)
for lam in [1e-4, 1e-2, 1.0]:
    a = np.linalg.solve(Kg + lam * np.eye(n_tr), yg)     # alpha* = (K+λI)^{-1} y
    fit_err = np.mean((Kg @ a - yg) ** 2)
    print(f"KRR lam={lam:<6g} train_MSE={fit_err:.4f}")
# 预期输出形态: lam=1e-4 → ≈0.005(插值训练点); lam=1.0 → ≈0.30(欠拟合, 趋近均值预测)
# 与第1章多项式实验对照: γ 与 λ 分别控制核方法的两个容量旋钮
```

### 示例 3（案例）：核函数选择的工程流程

在手写数字（`sklearn.datasets.load_digits`，8×8 灰度）上比较线性核与 RBF 核：先用线性 SVM 建立基线（训练极快），若训练精度不足 → 换 RBF；在 $(\gamma, C)$ 的二维对数网格上做交叉验证（`sklearn.model_selection.GridSearchCV`，第 7 章将详细讲），典型最优在 $\gamma \in [10^{-3}, 1]$、$C \in [1, 100]$。经验法则：样本数 $n < 10^4$ 且特征 $\lesssim 10^3$ 时 SVM+RBF 是强基线；$n \gtrsim 10^5$ 后核矩阵 $O(n^2)$ 内存不可承受 → 换线性 SVM（`LinearSVC`）或树模型（第 3 章）。

## 4.8 常见误区与陷阱

1. **忘记缩放特征**。RBF 核的 $\|x - z\|^2$ 对量纲敏感，大尺度特征支配核值；标准化是前置步骤（同第 2 章）。
2. **把 $\gamma$ 当成"不重要的小参数"**。$\gamma$ 与 $C$ 同为容量旋钮；$(\gamma, C)$ 必须联合调。
3. **认为 SVM 输出的是概率**。决策值 $f(x)$ 不是概率；要用概率需额外做 Platt 缩放（`probability=True`），本质是第 2 章逻辑回归的再利用。
4. **对大样本硬上核 SVM**。核矩阵 $O(n^2)$ 存储、$O(n^3)$ 训练；$n = 10^5$ 时仅核矩阵就需约 80 GB（8 字节 × $10^{10}$）。
5. **手推对偶时丢掉 $\sum_i \alpha_i y_i = 0$**。这是第 2 步对 $b$ 求偏导的产物，漏掉则对偶问题无界。
6. **把支持向量数量当"模型大小"评价**。$\alpha_i = C$ 的"边界违反者"也是支持向量，数量多往往意味着 $C$ 太小或数据噪声大。
