# 第 5 章 概率模型与 EM 算法

> **本章定位**：把[《概率统计·第4章》](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/04/)的贝叶斯推断从"估计参数"升级为"建模整个数据生成过程"。生成式模型、隐变量、EM 算法与 ELBO 这一整套语言，是后续[《深度学习》](/xiaoshus-blog/textbooks/ai/ai-core/deep-learning/00/)变分自编码器（VAE）与[《知识表示与推理》](/xiaoshus-blog/textbooks/ai/ai-core/knowledge-reasoning/00/)概率图模型的共同祖先——学完本章，你将"认得出"那些高级模型的核心零件。

## 5.0 本章学习目标

学完本章，你能够：

1. 准确陈述判别式与生成式模型的定义（$p(y|x)$ vs $p(x, y)$），并说出各自的优缺点与适用场景；
2. 推导朴素贝叶斯的训练与预测公式，实现一个多项式/伯努利朴素贝叶斯文本分类器；
3. 写出高斯混合模型（GMM）的似然，解释它为什么不能直接用 MLE 闭式求解（隐变量 + 似然无界）；

5. 从零实现 GMM 的 EM 算法，验证对数似然单调上升；
6. 说出 EM 与后续 VAE 的对应关系（E 步 → 推断网络，M 步 → 生成网络）。

## 5.1 生成式 vs 判别式

### 5.1.1 两种建模哲学

由贝叶斯公式（[概率统计·第1章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/01/)）：
$$
p(y \mid x) = \frac{p(x, y)}{p(x)} = \frac{p(x \mid y)\, p(y)}{p(x)} .
$$

- **判别式模型（discriminative）**：直接建模 $p(y \mid x)$ 或决策函数 $h(x)$——逻辑回归（第 2 章）、SVM（第 4 章）、决策树（第 3 章）。不关心 $x$ 长什么样，只关心类别边界。
- **生成式模型（generative）**：建模完整的联合分布 $p(x, y) = p(x \mid y) p(y)$——朴素贝叶斯、高斯判别分析（LDA）、隐马尔可夫模型、以及深度学习中的 VAE/GAN/扩散模型。学会了 $p(x, y)$，原则上既能分类，也能"生成"新样本。

对比表（考试与工程高频考点）：

| | 判别式 | 生成式 |
|---|---|---|
| 建模对象 | $p(y\mid x)$ | $p(x, y)$ |
| 典型成员 | 逻辑回归、SVM、树 | 朴素贝叶斯、GMM、HMM |
| 样本效率 | 高（少数据也能学到边界） | 低（要学 $p(x\mid y)$ 的全部细节） |
| 收敛极限 | 通常更高精度（无需正确设定 $p(x)$） | 模型设定正确时可渐近最优 |
| 能力 | 只能分类/回归 | 可生成样本、处理缺失特征、做异常检测、多任务复用 |

经典结论（Ng & Jordan, 2002）：生成式的朴素贝叶斯与判别式的逻辑回归是"同一族模型"（对某些分布设定下渐近同一决策边界），但朴素贝叶斯**样本效率更高（少数据时先赢）、逻辑回归渐近误差更低（大数据时反超）**。

### 5.1.2 高斯判别分析（GDA，快速带过）

设 $p(x \mid y = k) = \mathcal{N}(\mu_k, \Sigma)$（各类高斯、共享协方差），则后验 $p(y=k \mid x) \propto p(x \mid y=k)\,p(y=k)$ 展开后恰好是 $x$ 的线性函数过 sigmoid——**GDA 与逻辑回归决策边界同形**，但 GDA 用的是高斯 MLE 的拟合。它回答了 5.1.1 表中"为什么判别式极限误差更低"：若真实 $p(x\mid y)$ 不是高斯，GDA 的模型偏了，而逻辑回归不假设 $x$ 的分布。注意共享 $\Sigma$ 是"线性边界"的关键；各类协方差不同（QDA）则边界是二次曲面。

## 5.2 朴素贝叶斯

### 5.2.1 模型与"朴素"假设

对特征向量 $x = (x_1, \dots, x_d)$，后验
$$
p(y = k \mid x) \;\propto\; p(y = k) \prod_{j=1}^d p(x_j \mid y = k),
$$
其中"朴素（naive）"指的是**给定类别，特征条件独立**（[概率统计·第3章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/03/)的条件独立性）。这个假设在现实中几乎从不严格成立（文本的词当然不独立），但朴素贝叶斯在文本分类上表现惊人地好——分类只需要"哪个类别的相对概率更大"，不需要绝对概率正确（NFL 定理的又一个注脚：偏置匹配了任务的主要结构）。

### 5.2.2 训练与预测

训练 = 各类别的 MLE/带平滑的频率统计（对伯努利特征）：
$$
\hat \pi_k = \frac{N_k}{n}, \qquad
\hat \theta_{jk} = \frac{\sum_{i: y_i = k} \mathbb{1}[x_{ij} = 1] + \alpha}{N_k + 2\alpha},
$$
$\alpha$ 是 Laplace/加一平滑（先验 $\text{Beta}(1,1)$ 的 MAP，衔接第 2 章 2.3.3 与[概率统计·第4章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/04/)——不加平滑时未见过的词使 $p = 0$，整个连乘归零，这是工程必踩的坑）。文本常用多项式朴素贝叶斯：以词频计数 $c_{jk}$ 代替 0/1，$\hat\theta_{jk} = (c_{jk} + \alpha)/(\sum_{j'} c_{j'k} + \alpha V)$。预测时连乘下溢，必须用**对数域**累加：
$$
\log p(y = k \mid x) = \log \hat\pi_k + \sum_{j=1}^d \log \hat\theta_{j k}^{x_j} (1 - \hat\theta_{jk})^{1 - x_j} + \text{const}.
$$
训练复杂度 $O(nd)$、预测 $O(dK)$，一次扫描即可——朴素贝叶斯是"第一分钟就该跑出来的基线"。

## 5.3 高斯混合模型与隐变量

### 5.3.1 模型

无监督聚类的概率视角：数据由 $K$ 个高斯混合而成。引入**隐变量（latent variable）** $z_i \in \{1, \dots, K\}$ 表示样本 $i$ 属于哪个分量：
$$
z_i \sim \text{Categorical}(\pi_1, \dots, \pi_K), \qquad
x_i \mid z_i = k \sim \mathcal{N}(\mu_k, \Sigma_k),
$$
边缘分布（对隐变量求和，[概率统计·第3章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/03/)的全概率公式）：
$$
p(x_i) = \sum_{k=1}^K \pi_k \, \mathcal{N}(x_i; \mu_k, \Sigma_k).
$$

### 5.3.2 为什么不能直接 MLE

对数似然 $\log p(X) = \sum_i \log \sum_k \pi_k \mathcal{N}(x_i; \mu_k, \Sigma_k)$ 中，"log 里面套 sum"——**对数把混合拆不开了**，对 $\mu_k$ 求梯度会得到一个耦合所有分量的复杂表达式，没有闭式解。更糟：若某个 $\Sigma_k \to$ 奇异（把一个分量"钉"在某个数据点上），似然趋于 $+\infty$——MLE 无界，普通优化还会撞向这些退化解。出路：如果**知道**每个样本的 $z_i$，似然立刻拆开成 $K$ 组独立高斯 + 一组分类频率，全部有闭式解。可是 $z_i$ 看不见。**EM 算法就是"先猜测 $z$（E 步），再当作已知做 MLE（M 步）"的严格化**。

## 5.4 EM 算法完整推导

### 5.4.1 从 Jensen 不等式到 ELBO

目标：最大化对数似然 $\log p(X \mid \theta)$，其中 $X$ 是观测、隐变量 $Z$ 未知（$\theta$ 泛指 $\pi, \mu, \Sigma$）。对任意分布 $q(Z)$（关于每个样本的 $z_i$ 独立取分布），写：
$$
\log p(X \mid \theta) = \log \sum_Z p(X, Z \mid \theta) \cdot \frac{q(Z)}{q(Z)}
= \log \, \mathbb{E}_{q(Z)} \!\left[ \frac{p(X, Z \mid \theta)}{q(Z)} \right].
$$
[《高等数学·第4章》](/xiaoshus-blog/textbooks/ai/math-foundations/calculus/04/)告诉我们 $\log$ 是凹函数，由 **Jensen 不等式**（凹函数下 $\log \mathbb{E}[\cdot] \ge \mathbb{E}[\log \cdot]$，等号当且仅当被平均的随机变量为常数）：
$$
\log p(X \mid \theta) \;\ge\; \underbrace{\mathbb{E}_{q(Z)}\!\left[ \log \frac{p(X, Z \mid \theta)}{q(Z)} \right]}_{=:\; \mathcal{L}(q, \theta)\ \text{（ELBO，证据下界）}} .
$$
第一步的变换：$\log\sum_Z p(X,Z\mid\theta) = \log \sum_Z q(Z)\, \frac{p(X,Z\mid\theta)}{q(Z)}$，是标准的"乘 $1$ 拆分"技巧。**ELBO（evidence lower bound）**把不可解的目标变成了可以分块优化的代理目标。整理差额：
$$
\log p(X\mid\theta) - \mathcal{L}(q, \theta) = \mathrm{KL}\big( q(Z) \,\|\, p(Z \mid X, \theta) \big) \ge 0,
$$
（KL 散度非负，见[概率统计·第3章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/03/)。）这说明：**ELBO 贴住真目标的充要条件是 $q(Z) = p(Z \mid X, \theta)$——后验分布**。两条路线由此清晰：

### 5.4.2 EM = ELBO 的坐标上升

- **E 步**：固定 $\theta$，最大化 $\mathcal{L}(q, \theta)$ 对 $q$——由上面的差额公式，最优 $q^\star(Z) = p(Z \mid X, \theta)$（后验），此时 KL $=0$，ELBO 紧贴对数似然。对 GMM，$q$ 就是"责任"（responsibility）：
$$
r_{ik} = q(z_i = k) = \frac{\pi_k \mathcal{N}(x_i; \mu_k, \Sigma_k)}{\sum_{k'} \pi_{k'} \mathcal{N}(x_i; \mu_{k'}, \Sigma_{k'})}.
$$
- **M 步**：固定 $q$，最大化 $\mathcal{L}$ 对 $\theta$。等价（可证）于最大化**期望完全数据对数似然** $Q(\theta) = \mathbb{E}_q[\log p(X, Z \mid \theta)]$。对 GMM，把 $r_{ik}$ 当作"软计数"代入，求导置零得闭式解：
$$
N_k = \sum_i r_{ik}, \qquad
\pi_k = \frac{N_k}{n}, \qquad
\mu_k = \frac{\sum_i r_{ik} x_i}{N_k}, \qquad
\Sigma_k = \frac{\sum_i r_{ik} (x_i - \mu_k)(x_i - \mu_k)^\top}{N_k}.
$$
（推导即"加权高斯 MLE"：对 $Q(\theta)$ 中第 $k$ 项 $\sum_i r_{ik}\big[\log \pi_k + \log \mathcal{N}(x_i;\mu_k,\Sigma_k)\big]$ 分别对 $\mu_k, \Sigma_k$ 求偏导，步骤与[概率统计·第5章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/05/)的多元高斯 MLE 相同，只是每个样本带权 $r_{ik}$。注意 $\pi$ 的约束 $\sum_k \pi_k = 1$ 要用拉格朗日乘子处理。）

### 5.4.3 单调性（收敛性说明）

**命题**：每一轮 $(q^{(t)}, \theta^{(t)}) \to (\text{E 步}, \text{M 步}) \to (q^{(t+1)}, \theta^{(t+1)})$ 后，
$$
\log p(X \mid \theta^{(t+1)}) \;\ge\; \mathcal{L}(q^{(t+1)}, \theta^{(t)}) \;\ge\; \mathcal{L}(q^{(t)}, \theta^{(t)}) \;=\; \log p(X \mid \theta^{(t)}).
$$
三段的依据依次为：E 步后 KL 项为零（ELBO 紧）、M 步不降低 ELBO（它最大化了它）、E 步后的相等。**因此对数似然单调不减且有上界，故收敛**（到驻点；不保证全局最优——ELBO 仍非凸）。这就是 5.7 示例 2 中"每轮似然必须上升"的理论保证，也是调试 EM 实现的第一试金石。收敛判据：$\log p^{(t+1)} - \log p^{(t)} < \varepsilon$ 或参数变化小于阈值。

### 5.4.4 EM 的实务要点

- **初始化**：EM 收敛到局部最优，结果强依赖初始化。标准做法：$K$-means 先聚类（第 6 章）再取各簇均值/协方差做初值，或多随机重启取最优。
- **协方差正则**：$\Sigma_k$ 加 $\epsilon I$ 防奇异（对应 5.3.2 的似然无界），sklearn 的 `reg_covar` 参数即此。
- **K 的选择**：BIC/AIC 或验证集似然（第 7 章模型选择思想的概率版）。
- **与坐标下降的关系**：EM 就是"块坐标上升"（[最优化·第2章](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/02/)的思想 + 5.4.2 的分块结构）：块 1 = 变分分布 $q$，块 2 = 参数 $\theta$。

### 5.4.5 通往 VAE 的桥（预告）

VAE 的场景里 $p(Z \mid X, \theta)$ 无法解析计算（编码器-解码器嵌套），E 步做不了精确后验。VAE 的解法：用参数为 $\phi$ 的神经网络 $q_\phi(Z\mid x)$ **近似**后验、对 $\phi$ 做梯度上升最大化 ELBO（重参数化技巧让 $q$ 可导）——M 步也换成对生成网络 $\theta$ 的梯度步。所以：**EM 的 E/M 两步 ↔ VAE 的推断/生成两个网络；ELBO 一词原封不动地传了下去**。你在这里建立的每个概念都将在那里复用。

## 5.5 关键公式速查

| 公式 | 名称 | 适用条件 |
|---|---|---|
| $p(y=k\mid x) \propto p(y{=}k)\prod_j p(x_j \mid y{=}k)$ | 朴素贝叶斯预测 | 条件独立假设；对数域防下溢 |
| $\hat\theta_{jk} = (\text{计数} + \alpha)/(\text{类计数} + 2\alpha)$ | 加一平滑 | Beta(1,1) 先验 MAP；稀疏特征必需 |
| $\log p(X\mid\theta) \ge \mathbb{E}_q[\log \frac{p(X,Z\mid\theta)}{q(Z)}]$ | ELBO（Jensen 不等式） | $q$ 任意分布；等号当 $q$=后验 |
| $\log p - \text{ELBO} = \mathrm{KL}(q \| p(Z\mid X,\theta))$ | ELBO 缺口 | KL 非负；EM/VAE 共用 |
| $r_{ik} = \frac{\pi_k \mathcal{N}(x_i;\mu_k,\Sigma_k)}{\sum_{k'} \pi_{k'}\mathcal{N}(x_i;\mu_{k'},\Sigma_{k'})}$ | E 步责任 | GMM；即后验 $p(z_i{=}k\mid x_i)$ |
| $\mu_k = \frac{\sum_i r_{ik} x_i}{N_k},\ \Sigma_k = \frac{\sum_i r_{ik}(x_i-\mu_k)(x_i-\mu_k)^\top}{N_k}$ | M 步更新 | 加权高斯 MLE；$N_k=\sum_i r_{ik}$ |
| 似然单调不减，收敛到驻点 | EM 收敛性 | 每轮 E/M 均精确最大化 |

## 5.6 示例与案例

### 示例 1（手算）：两分量一维 GMM 的一轮 EM

数据 $x = (0.0,\ 0.5,\ 4.0,\ 4.5)$，$K = 2$，初始 $\pi = (0.5, 0.5)$，$\mu_1 = 0, \mu_2 = 4$，$\Sigma_1 = \Sigma_2 = 1$。

E 步（计算 $r_{i1}$，$\sigma = 1$）：$\mathcal{N}(0;0,1) = \frac{1}{\sqrt{2\pi}} e^0 \approx 0.399$，$\mathcal{N}(0;4,1) = 0.399\, e^{-8} \approx 1.34\times10^{-4}$，
$$
r_{11} = \frac{0.5 \times 0.399}{0.5 \times 0.399 + 0.5 \times 1.34\times 10^{-4}} \approx 0.9997,
$$
同理 $r_{21} \approx 0.996$（$x=0.5$：$e^{-0.125}$ vs $e^{-12.5}$，比值 $e^{12.375} \approx 2.4\times10^5$）、$r_{31} \approx 0.0042$（对称于 $r_{21}$）、$r_{41} \approx 0.0003$。

M 步：$N_1 = 0.9997 + 0.996 + 0.0042 + 0.0003 \approx 2.000$，$N_2 \approx 2.000$；$\pi_1 \approx 0.5$；
$$
\mu_1 = \frac{0.9997(0) + 0.996(0.5) + 0.0042(4) + 0.0003(4.5)}{2.000} \approx \frac{0.498 + 0.0168 + 0.00135}{2} \approx 0.258,
$$
$$
\mu_2 = \frac{0.0003(0) + 0.004(0.5) + 0.9958(4) + 0.9997(4.5)}{2} \approx \frac{0.002 + 3.983 + 4.499}{2} \approx 4.242 .
$$
一轮 EM 后两个均值各自向自己的簇中心收紧。请用示例 2 的代码验证这些数（校验值：$\mu_1 \approx 0.2577,\ \mu_2 \approx 4.2423$）。

### 示例 2（代码）：从零朴素贝叶斯 + 从零 GMM-EM

```python
# ch5_probabilistic_models.py
# 依赖: numpy, scipy, sklearn(仅对拍与数据集)
import numpy as np
from scipy.special import logsumexp
from sklearn.datasets import load_breast_cancer

# ===================== A. 从零实现伯努利朴素贝叶斯 =====================
rng = np.random.default_rng(0)
X, y = load_breast_cancer(return_X_y=True)
Xb = (X > np.median(X, axis=0)).astype(float)      # 二值化特征
idx = rng.permutation(len(y)); ntr = 400
Xtr, Xte, ytr, yte = Xb[idx[:ntr]], Xb[idx[ntr:]], y[idx[:ntr]], y[idx[ntr:]]

def bernoulli_nb_fit(X, y, alpha=1.0):
    classes = np.unique(y)
    K, d = len(classes), X.shape[1]
    log_prior = np.log(np.array([(y == k).mean() for k in classes]))
    theta = np.zeros((K, d))                            # theta[ki, j] = P(x_j=1 | y=classes[ki])
    for ki, k in enumerate(classes):                    # Beta(alpha,alpha) 平滑 = MAP(5.2.2)
        Nk = (y == k).sum()
        theta[ki] = (X[y == k].sum(0) + alpha) / (Nk + 2 * alpha)
    return classes, log_prior, theta

def bernoulli_nb_predict(classes, log_prior, theta, X):
    # 对数域: log P(x|k) = Σ_j [ x_j log θ + (1-x_j) log(1-θ) ]
    logits = np.log(theta) @ X.T + np.log(1 - theta) @ (1 - X).T  # (K, n)
    return classes[np.argmax(logits + log_prior[:, None], axis=0)]

classes, log_prior, theta = bernoulli_nb_fit(Xtr, ytr, alpha=1.0)
acc_my = (bernoulli_nb_predict(classes, log_prior, theta, Xte) == yte).mean()
from sklearn.naive_bayes import BernoulliNB
acc_sk = BernoulliNB().fit(Xtr, ytr).score(Xte, yte)
print(f"朴素贝叶斯 从零: {acc_my:.3f}   sklearn: {acc_sk:.3f}")
# 预期输出: 两者完全一致(实现相同), ≈ 0.90~0.94

# ===================== B. 从零实现 GMM 的 EM =====================
def gmm_em(X, K=3, iters=100, seed=0):
    rng = np.random.default_rng(seed)
    n, d = X.shape
    # 初始化: 从数据中随机挑 K 个点作为均值
    mu = X[rng.choice(n, K, replace=False)].copy()
    Sigma = np.stack([np.eye(d) * X.var(0).mean()] * K)
    pi = np.full(K, 1 / K)
    for t in range(iters):
        # ---- E 步: 逐样本逐分量的对数联合 log π_k + log N(x_i | μ_k, Σ_k) ----
        log_r = np.zeros((n, K))
        for k in range(K):
            diff = X - mu[k]
            inv = np.linalg.inv(Sigma[k])
            maha = np.einsum('ni,ij,nj->n', diff, inv, diff)
            log_r[:, k] = np.log(pi[k]) - 0.5 * (d * np.log(2 * np.pi)
                       + np.log(np.linalg.det(Sigma[k])) + maha)
        # 对数似然(5.4.3: 每轮必须不减) + 对数域稳定化
        ll = logsumexp(log_r, axis=1).sum()
        r = np.exp(log_r - log_r.max(axis=1, keepdims=True))
        r /= r.sum(axis=1, keepdims=True)
        # ---- M 步: 责任作为软计数的加权 MLE ----
        Nk = r.sum(0)
        pi = Nk / n
        mu = (r.T @ X) / Nk[:, None]
        for k in range(K):
            diff = X - mu[k]
            Sigma[k] = (r[:, k][:, None] * diff).T @ diff / Nk[k] + 1e-6 * np.eye(d)
        if t % 10 == 0 or t == iters - 1:
            print(f"  iter {t:3d}  ll={ll:9.2f}  N=({Nk[0]:.0f},{Nk[1]:.0f},{Nk[2]:.0f})")
    return pi, mu, Sigma

# 生成三个高斯簇的数据
Xg = np.vstack([
    rng.normal([0, 0], 0.5, size=(150, 2)),
    rng.normal([4, 4], 0.8, size=(150, 2)),
    rng.normal([0, 5], 0.6, size=(150, 2)),
])
pi, mu, Sigma = gmm_em(Xg, K=3)
print("pi =", np.round(pi, 3))                       # 预期: ≈ [0.333, 0.333, 0.333]
print("mu =\n", np.round(mu, 2))                     # 预期: ≈ [[0,0], [4,4], [0,5]] 的排列
# 与 sklearn 对拍
from sklearn.mixture import GaussianMixture
gm = GaussianMixture(3, covariance_type="full", random_state=0).fit(Xg)
print("sklearn mu =\n", np.round(gm.means_, 2))       # 应与上面一致(按分量重排后)
```

读输出任务：`ll` 序列应当**逐轮增大**、增幅逐步缩小——这正是 5.4.3 单调性定理在你自己的实现上的现场验证；若某一轮下降了，说明 M 步实现有 bug。并把 `K` 改成 5 观察"分量重叠"现象（两个分量分同一个簇，$\pi$ 之和等于该簇占比）。

## 5.7 常见误区与陷阱

1. **概率连乘不取对数**。50 个词的连乘 $< 10^{-50}$ 直接下溢为 0；所有概率模型计算都必须在对数域。
2. **不做平滑**。测试样本出现训练集某类中从未见过的词 → 该类后验为 0，"一票否决"。加 $\alpha$（通常 1）是刚需。
3. **EM 不初始化直接跑**。收敛到坏局部最优（如两个分量重叠在同一个簇）；用 K-means 初始化或多重启。
4. **认为 EM 全局收敛**。ELBO 非凸，只保证到驻点；似然单调上升不代表分对簇了——监控的应是似然 + 下游任务指标。
5. **朴素贝叶斯的"独立性"当作真实假设去捍卫**。它是分类偏置不是世界模型；特征强相关时（如同一信号的两次测量）后果是后验过度自信（概率值不可信，排序仍可能有用）。
6. **协方差不加正则**。某分量塌缩到单点时数值崩溃（$\det \Sigma \to 0$）；`reg_covar`/`+εI` 是标配。

## 5.10 进阶方向

1. **变分推断（VI）**：后验不可解时的通用框架（CAVI、随机变分推断）；需要补指数族分布与共轭性（[概率统计·第4章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/04/)加深）。
2. **EM 的收敛速率**：EM 是"以条件数放大的梯度上升"，收敛可线性但速率受缺失信息比例支配（Dempster 等的 fragility 分析）；需要补矩阵微积分。
3. **贝叶斯非参数**：Dirichlet 过程混合（$K$ 无限，自动定簇数）；需要补测度论基础。
4. **生成模型的现代家族**：VAE/扩散模型/流模型的证据最大化统一视角；需要补《深度学习》。
