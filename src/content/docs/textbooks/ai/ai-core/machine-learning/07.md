# 第 7 章 模型评估、选择与理论基础

## 7.1 交叉验证：切数据的艺术

### 7.1.1 K 折交叉验证

第 1 章 1.2 已经给出"单一验证集方差大"的问题。$K$ 折 CV 的协议：把数据分为 $K$ 个互斥折，第 $j$ 轮用第 $j$ 折做验证、其余 $K-1$ 折训练，得误差 $e_j$；最终估计
$$
\hat R_{\text{CV}} = \frac1K \sum_{j=1}^K e_j, \qquad \text{标准误} \approx \operatorname{std}(e_j)/\sqrt K \ (\text{粗略，折间并不独立}).
$$
常见 $K = 5$ 或 10。权衡表：

| 方案 | 偏差 | 方差 | 计算量 | 备注 |
|---|---|---|---|---|
| 单一 hold-out | 高（训练数据少） | 取决于切法 | 1× | 大数据时完全够用 |
| $K$ 折 CV | 中 | 中 | $K\times$ | 标准默认 |
| 留一法 LOO（$K = n$） | 最低 | **最高**（训练集几乎全同，误差高度相关） | $n \times$ | 小数据 + 昂贵模型不划算 |

关键认知：**CV 估计的是"协议"的期望性能（用 $K-1$ 折训练的模型），不是最终模型的性能**。最终交付前应：用 CV 选定超参数 → 用全部数据以该超参数重训。两条线不要混。

### 7.1.2 三个必须做的变体

1. **分层抽样（stratification）**：每折保持类别比例（不平衡数据必须做），`StratifiedKFold`。
2. **按组切分（GroupKFold）**：同一病人/用户的多条样本必须整组进同一折，否则"病人信息泄漏"使估计乐观得离谱——这是医学/推荐数据最常见的翻车模式（与第 3 章 target leakage 同族）。
3. **时间序列（TimeSeriesSplit）**：只允许"过去训练、未来验证"（第 3 章已埋伏笔）。
4. **嵌套 CV**：外层估泛化、内层调参，见 7.4.3。

## 7.2 评价指标：选对尺子

### 7.2.1 混淆矩阵家族（二分类）

| | 预测正 | 预测负 |
|---|---|---|
| 真实正 | TP | FN |
| 真实负 | FP | TN |

$$
\text{准确率} = \frac{TP + TN}{TP + TN + FP + FN}, \quad
\text{精确率 P} = \frac{TP}{TP + FP}, \quad
\text{召回率 R} = \frac{TP}{TP + FN},
$$
$$
F1 = \frac{2PR}{P + R} = \frac{2TP}{2TP + FP + FN} \quad (\text{P 与 R 的调和平均}) .
$$
**准确率的陷阱**：99% 负样本的数据上，"全预测负"准确率 99% 却毫无用处。不平衡场景的标准配置：PR 曲线 / F1 / 召回率（漏诊代价高的场景）+ 语义化指标（如"每千次报警的真阳性数"）。精确率与召回率的取舍由**决策阈值**控制：阈值调高 → 精确率升、召回率降。F1 的调和平均惩罚"偏科"（$P=1, R=0$ 时 $F1 = 0$；算术平均会给出 0.5 的假象——校验：调和平均 $2(1\cdot0)/(1+0) = 0$）。

### 7.2.2 ROC 与 AUC

许多模型输出连续分数 $s(x)$，阈值只在使用时才定。**ROC 曲线**：阈值从 $+\infty$ 扫到 $-\infty$，每点画出（假正率 FPR $= FP/(FP+TN)$，真正率 TPR $= TP/(TP+FN)$）。**AUC（曲线下面积）**有精确的概率解释：
$$
\text{AUC} = P\big( s(X_+) > s(X_-) \big) \quad (\text{随机抽一个正样本与一个负样本，正样本得分更高的概率})
$$
（严格定义为含并列得分时的 $P(s_+ > s_-) + \frac12 P(s_+ = s_-)$。）这就是 **Mann–Whitney U 统计量**的归一化形式——AUC 是"排序质量"的度量，与阈值、类先验无关，因此**类平衡变化时 AUC 稳定而 PR 曲线剧烈变化**。选择建议：类严重不平衡且关心少数类检出 → PR-AUC；类先验会漂移、关心排序 → ROC-AUC。

### 7.2.3 校准：概率说出的"90%"要真是 90%

逻辑回归天然接近校准；SVM 决策值、梯度提升的原始分数、深度网络（现代网络普遍过自信）都需要校准。工具：
- **可靠性图（reliability diagram）**：把预测概率分桶，画每桶"平均预测概率 vs 实际正率"，理想为对角线；
- **Brier 分数** $= \frac1n \sum_i (\hat p_i - y_i)^2$（越小越好，可分解为"判别力 + 校准"两部分）；
- **校准方法**：Platt 缩放（在第 4 章已遇见——对决策值再跑一个逻辑回归）与等值回归（isotonic regression，非参数单调映射，数据 > 数千时更优）。

工程要点：**先在验证集上校准，再定阈值**；阈值本身也是超参数，按业务代价（FP 与 FN 的代价比）选定，不要默认 0.5。

### 7.2.4 回归指标

MAE（对离群点稳健、中位数意义）、RMSE（平方惩罚大误差、均值意义，且与第 1 章平方损失的偏差-方差理论直接对应）、$R^2 = 1 - \frac{\sum(\hat y - y)^2}{\sum(y - \bar y)^2}$（与基线"预测均值"比较的相对值）。选损失时想清楚你最终报的是哪个指标——最小化 RMSE 训练的模型报 MAE 是常见错配。

**多分类的两条平均路径**（$K$ 类时对每类分别算二类指标再汇总）：宏平均（macro，各类指标简单平均，每类同权——少数类不会被淹没，类别极不平衡时的首选）与微平均（micro，先汇总 TP/FP/FN 再算指标——等价于样本级准确率，多数类主导）。经验法则：报告宏观 F1 + 每类召回率，能同时看到整体水平与"哪一类被牺牲"。

## 7.3 超参数搜索

### 7.3.1 网格 vs 随机

- **网格搜索（grid search）**：穷举网格。缺陷高维爆炸：10 个超参数各 5 值 = $5^{10} \approx 10^7$ 组。
- **随机搜索（Bergstra & Bengio, 2012）**：从分布中抽样。核心洞察：**不是所有超参数都同等重要**——若目标只依赖少数几个参数，随机采样在同样预算下探索到的"重要参数"取值远多于网格（网格把预算浪费在无关参数的冗余组合上）。
- **早停式**：`Hyperband`/ successive halving——用极短训练淘汰 90% 差配置，把预算集中到幸存者。

### 7.3.2 贝叶斯优化与多臂老虎机思想

把"评估一组超参数"当作一个**昂贵黑盒函数** $f(\theta)$（每次评估 = 一次完整 CV）。贝叶斯优化循环：用概率代理模型（高斯过程 / TPE）拟合已观测的 $(\theta_i, f(\theta_i))$，再用**采集函数**（acquisition function）决定下一个采样点。最经典的 **UCB（Upper Confidence Bound）采集函数**：
$$
\mathrm{UCB}(\theta) = \mu(\theta) + \kappa\, \sigma(\theta),
$$
（最大化场景）$\mu$ 是代理模型对 $f(\theta)$ 的预测、$\sigma$ 是不确定度，$\kappa$ 控制探索-利用的比值。**探索（去不确定的地方试）vs 利用（去已知好的地方深挖）**——这正是多臂老虎机（multi-armed bandit）问题的核心权衡；UCB 算法在老虎机场景有 $\sum_t \text{regret} = O(\sqrt{T \log T})$ 的理论保证。实践工具：Optuna（TPE）、scikit-optimize（GP）。经验：$\le 10$ 个连续超参数、每次评估几分钟以上时，贝叶斯优化明显优于随机；代价是引入代理模型的超参数（如 $\kappa$）——方法论无限递归，好在这些"元超参数"不敏感。

### 7.3.3 无偏的模型选择：嵌套 CV

在一份 CV 内部"既调参又报分数"会使报告的分数偏乐观（调参过程把验证折的信息用掉了——第 1 章 1.2 铁律的 CV 版本）。**嵌套交叉验证**：外层 $K_{\text{out}}$ 折，每折内层做完整的 CV 调参、用外层折测试。代价 $K_{\text{out}} \times K_{\text{in}}$ 倍计算，但得到泛化性能的（近似）无偏估计。小数据 + 竞赛发论文场景必备。

## 7.4 统计显著性：两个模型真的不同吗

### 7.4.1 问题与陷阱

跑了两个模型，准确率 0.873 vs 0.861——差异是真实的还是切分运气？直觉反例：在第 1 章的模拟里你知道，$n = 200$ 的测试集上单次准确率的标准误约 $\sqrt{0.87 \times 0.13 / 200} \approx 0.024$——0.012 的差距完全在噪声以内。**单一切分上的比较几乎总是不可信的**。

更隐蔽的陷阱：对同一测试集上两模型的误差做普通 t 检验（paired t-test over test samples）——样本间不独立（同一模型对相邻样本的误差相关，且两模型共享训练集），方差被低估、假阳性暴涨（Dietterich 1998 的经典结论）。

### 7.4.2 5×2 交叉验证配对 t 检验（Dietterich, 1998）

协议：做 5 次重复的 2 折 CV。每次重复：随机把数据切成两半 $D_1, D_2$，两模型各在 $D_1$ 训练在 $D_2$ 测、再对调，得 4 个配对差值 $\Delta$（模型 A − 模型 B 的误差）；令
$$
p_1 = \Delta_{1}^{(D_1)}, \quad p_2 = \Delta_{1}^{(D_2)} \ (\text{第一次重复的两折差}), \qquad
\bar p = \frac{p_1 + p_2}{2}, \qquad s^2 = (p_1 - \bar p)^2 + (p_2 - \bar p)^2,
$$
统计量
$$
t = \frac{p_1}{\sqrt{(1/5)\sum_{k=1}^{5} s_k^2 + s_1^2}} \quad \text{(Dietterich 的推荐变体: } \sigma^2 = \textstyle\sum_k s_k^2\text{，} t = p_1 / \sqrt{\sigma^2/5 + s_1^2}\text{)}
$$
服从自由度 5 的 t 分布（近似）。选它的原因：2 折使两模型的训练集差异最大（训练集互斥，最小化重叠相关性），5 次重复提供足够的方差估计——Dietterich 的模拟显示它在"可接受的 I 类错误率"下检验功效最高。

### 7.4.3 协议建议（与《实验设计与评估》接轨）

1. 报告**均值 ± 标准差（跨多个种子/折）**，而不是单一数字；
2. 两模型比较用 5×2cv t 检验或 McNemar 检验（单一固定测试集上预测分歧的卡方检验，最省算力）；
3. 多模型比较报统计检验 + 效应量，做多重比较校正（Bonferroni / Friedman + Nemenyi 后检验）；
4. 记录并公开随机种子与完整配置——可复现性是硬通货；
5. 效应量小于一个标准误的差异，无论 $p$ 值如何，工程上视为"未决"。

一份最低标准的实验报告清单（本课程所有实验、以及第 99 章项目报告都按此自查）：

- [ ] 数据划分方式与随机种子全部写明（可复现）；
- [ ] 指标与任务语义匹配，且不止一个（如 AUC + 召回率）；
- [ ] 均值 ± 标准差来自多个折/种子，而非单次运行；
- [ ] 模型比较经过统计检验，未做多重比较校正时要声明；
- [ ] 基线（至少一个简单模型）在场，新方法的增量相对基线报告。

## 7.5 关键公式速查

| 公式 | 名称 | 适用条件 |
|---|---|---|
| $\hat R_{\text{CV}} = \frac1K \sum_j e_j$ | K 折 CV 估计 | 折间相关使标准误公式仅粗略 |
| $F1 = \frac{2TP}{2TP + FP + FN}$ | F1 | P、R 的调和平均；不平衡数据 |
| $\text{AUC} = P(s_+ > s_-) + \frac12 P(s_+ = s_-)$ | AUC 概率解释 | 分数无阈值依赖；Mann–Whitney |
| $\text{Brier} = \frac1n \sum_i (\hat p_i - y_i)^2$ | Brier 分数 | 概率输出；判别+校准的混合度量 |
| $\mathrm{UCB}(\theta) = \mu(\theta) + \kappa \sigma(\theta)$ | UCB 采集函数 | 贝叶斯优化/老虎机；$\kappa$ 控制探索 |
| $\sum_t \text{regret}(t) = O(\sqrt{T\log T})$ | UCB 遗憾界 | 老虎机；亚线性遗憾 |
| $t = p_1 / \sqrt{\sigma^2/5 + s_1^2}$，自由度 5 | 5×2cv t 检验 | 两模型比较；$\sigma^2 = \sum_k s_k^2$ |
| $\text{se}(\hat p) = \sqrt{\hat p (1 - \hat p)/n}$ | 准确率标准误 | 固定测试集；判断差距是否超噪声 |

## 7.6 示例与案例

### 示例 1（手算）：AUC 的构造与概率解释

6 个样本，得分与标签（1 正 0 负）：
$s = (0.9, 0.8, 0.7, 0.6, 0.4, 0.2)$，$y = (1, 0, 1, 0, 1, 0)$。
- 按阈值扫描画 ROC：阈值取每对相邻得分之间。$t > 0.9$：TPR=0, FPR=0（原点）；$0.8 < t \le 0.9$：TPR=$1/3$, FPR=0；$0.7 < t \le 0.8$：TPR=$1/3$, FPR=$1/3$；$0.6 < t \le 0.7$：TPR=$2/3$, FPR=$1/3$；$0.4 < t \le 0.6$：TPR=$2/3$, FPR=$2/3$；$0.2 < t \le 0.4$：TPR=$1$, FPR=$2/3$；$t \le 0.2$：TPR=1, FPR=1（右上角）。
- 面积计算（逐段梯形）：$\frac13(0 + \frac13)/2 \cdot$… 直接用概率解释更稳：3 正 × 3 负 = 9 个正负对。逐一比较得分：正 0.9 胜 0.8, 0.6, 0.4, 0.2 → 4 胜；正 0.7 胜 0.6, 0.4, 0.2，负于 0.8 → 3 胜；正 0.4 负于 0.8, 0.6，胜 0.2 → 1 胜。共 $4 + 3 + 1 = 8$ 胜 → $\text{AUC} = 8/9 \approx 0.889$。（校验值：0.889。）

### 示例 2（代码）：CV + 指标 + 5×2 检验的完整实验

```python
# ch7_evaluation.py
# 依赖: numpy, scipy, sklearn
import numpy as np
from scipy import stats
from sklearn.datasets import load_breast_cancer
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.metrics import roc_auc_score, roc_curve, brier_score_loss

X, y = load_breast_cancer(return_X_y=True)
X = (X - X.mean(0)) / X.std(0)

models = {
    "逻辑回归": LogisticRegression(max_iter=2000),
    "GBDT":    GradientBoostingClassifier(random_state=0),
}

# ---------- A. 分层 5 折 CV + 多指标 ----------
skf = StratifiedKFold(5, shuffle=True, random_state=0)
for name, model in models.items():
    aucs = cross_val_score(model, X, y, cv=skf, scoring="roc_auc")
    print(f"{name}: AUC = {aucs.mean():.4f} ± {aucs.std():.4f}")
# 预期输出形态:
#   逻辑回归: AUC ≈ 0.993 ± 0.007
#   GBDT:     AUC ≈ 0.994 ± 0.008      (差异在第4节检验之前不可下结论!)

# ---------- B. 从零验证 AUC = 成对比较概率 ----------
model = models["GBDT"].fit(X[:400], y[:400])
s = model.decision_function(X[400:])
yy = y[400:]
auc_sk = roc_auc_score(yy, s)
# 成对统计: 每个正样本与每个负样本比较
wins = sum((s[i] > s[j]) + 0.5 * (s[i] == s[j])
           for i in np.where(yy == 1)[0] for j in np.where(yy == 0)[0])
auc_manual = wins / ((yy == 1).sum() * (yy == 0).sum())
print(f"AUC sklearn = {auc_sk:.4f}   成对概率 = {auc_manual:.4f}")  # 应完全相等
# fpr/tpr 曲线的构造(7.2.2)
fpr, tpr, thr = roc_curve(yy, s)
print("ROC 采样点数 =", len(fpr))                       # ≈ 不同得分值个数 + 1

# ---------- C. 校准: 可靠性图数据 + Brier ----------
p = model.predict_proba(X[400:])[:, 1]
bins = np.minimum((p * 10).astype(int), 9)               # 概率分 10 桶
for b in range(10):
    msk = bins == b
    if msk.sum() > 0:
        print(f"  预测概率桶 {b/10:.1f}: 实际正率 = {yy[msk].mean():.3f} (n={msk.sum()})")
print("Brier =", round(brier_score_loss(yy, p), 4))      # 预期: ≈ 0.03~0.05
# 预期形态: 低桶(0.0-0.3)与高桶(0.7-1.0)的实际正率接近桶标称值 → 近似校准
# (GBDT 未专门校准, 中间桶可能有偏; 逻辑回归通常更接近对角线)

# ---------- D. 5×2 交叉验证配对 t 检验(7.4.2 协议) ----------
def paired_5x2cv(model_a, model_b, X, y, seed=0):
    rng = np.random.default_rng(seed)
    diffs2, s2 = [], []                                   # 第一次重复的差值与各重复方差
    for k in range(5):
        idx = rng.permutation(len(y))
        h1, h2 = idx[:len(y)//2], idx[len(y)//2:]
        d = []
        for tr, te in [(h1, h2), (h2, h1)]:               # 两折互换
            ea = 1 - model_a.fit(X[tr], y[tr]).score(X[te], y[te])
            eb = 1 - model_b.fit(X[tr], y[tr]).score(X[te], y[te])
            d.append(ea - eb)                             # Δ = err_A - err_B
        if k == 0: p1 = d[0]
        s2.append((d[0] - np.mean(d))**2 + (d[1] - np.mean(d))**2)
        diffs2.append(d)
    sigma2 = sum(s2)
    t_stat = p1 / np.sqrt(sigma2 / 5 + s2[0])
    p_value = 2 * (1 - stats.t.cdf(abs(t_stat), df=5))
    return t_stat, p_value

t_stat, p_value = paired_5x2cv(models["逻辑回归"], models["GBDT"], X, y)
print(f"5x2cv t = {t_stat:.3f}, p = {p_value:.3f}")
# 预期输出形态: p 值可能 > 0.05 —— 两个强模型在此数据上的差距不显著,
# 结论: "选哪个都行", 不要为 0.001 的 AUC 差异编故事。
```

## 7.7 常见误区与陷阱

1. **用 CV 选完超参数后直接报告 CV 分数**。调参消耗了验证信息，报告的分数偏乐观；要么嵌套 CV，要么留出最终测试集。
2. **不平衡数据上只看准确率或只看 ROC-AUC**。分别会漏掉"全预测多数类"和"少数类召回崩塌"两种失败；PR-AUC 与召回必须同看。
3. **在同一测试集上反复比较多个模型并挑 $p < 0.05$ 的**。多重比较的假阳性随比较次数膨胀；需校正。
4. **对 5 折 CV 的 5 个分数做普通 t 检验**。折间共享训练数据，独立性假设不成立（7.4.1），应换 5×2cv 或 McNemar。
5. **阈值默认 0.5**。类不平衡或代价不对称时 0.5 几乎必然不是最优；阈值应按业务代价在验证集上选。
6. **把贝叶斯优化的代理模型分数当真**。$\mu(\theta)$ 是估计不是测量；最终配置仍要在新鲜数据上完整评估。
7. **网格搜索线性扫描 $\lambda$ 或学习率**。这些参数横跨数量级，网格要设在对数刻度上（第 2 章已强调）。

## 7.10 进阶方向

1. **验证集方差的理论**：CV 方差的依赖结构（Bengio & Grandvalet 2004 的"无偏方差估计不存在"定理）；需要补 U-统计量。
2. **多保真优化与 Hyperband/BOHB**：用低成本代理（少 epoch）加速搜索；需要补成功率-资源分配理论。
3. **因果 A/B 测试与上下文老虎机**：在线评估的正确姿势；需要补因果推断（Rubin 因果模型）。
4. **模型校准的现代方法**：温度缩放（深度网络的单参数校准）与标签噪声下的校准；需要补《深度学习》。

4. 说出嵌套 CV 与"CV 后单测"两种协议的适用数据规模与代价。

**计算推导**

5. 证明 AUC 与 Mann–Whitney U 统计量的等价：$U = \#\{(i,j): s_i > s_j, y_i = 1, y_j = 0\} + \frac12\#\{s_i = s_j\}$，$\text{AUC} = U / (n_+ n_-)$。
6. 某测试集 $n = 500$，模型 A 准确率 0.862、模型 B 0.871。用标准误公式判断该差距是否超过 $1.96$ 倍联合标准误（近似取 $\text{se} = \sqrt{2 \times 0.13 \times 0.87 / 500}$）。（校验值：差距 0.009 vs 阈值 $\approx 0.030$，未超过。）
7. 推导 UCB 的遗憾直觉：若每轮都选当前均值最高的臂（纯利用），被低估的好臂可能永远不被发现；说明 $\kappa\sigma$ 项如何保证每个次优臂只被"有限次"选中（提示：真实均值 + 奖励均值的高置信区间随采样次数 $N_a$ 以 $O(1/\sqrt{N_a})$ 收缩）。

**编程实现**

8. 复现 7.6 示例 2，把 GBDT 的 `max_depth` 在 $\{1, 2, 3, 5\}$ 上做嵌套 CV（外 5 折 × 内 3 折），报告外层 AUC 均值 ± 标准差与每折选出的最优深度。目标输出：不同外层折可能选出不同深度——"最优超参数本身是随机的"。
9. 实现 McNemar 检验：在固定测试集上取两模型的预测，构造列联表 $[[n_{00}, n_{01}], [n_{10}, n_{11}]]$（行真值列预测不对——实际用两模型对齐的错误指标），用 `stats.binomtest(min(n01, n10), n01 + n10, 0.5)` 比较。目标输出：与 5×2cv 的结论方向一致。
10. 实现 UCB1 老虎机模拟：3 个臂，真实回报 $0.2/0.5/0.8$，跑 $T = 1000$ 轮，画出遗憾 $R_T = T \cdot \mu^\star - \sum r_t$ 随 $T$ 的曲线，验证亚线性增长（$T = 10^4$ 时 $R_T / T$ 明显小于 $T = 10^3$ 时）。（校验值：$R_{1000}$ 通常 $< 50$。）
