# 第 6 章 无监督学习：聚类与降维

> **本章定位**：从"有标签"跨入"无标签"的世界。无标签数据的两大基本问题——聚类（离散结构：数据分成几组？）与降维（连续结构：数据的本征维度是多少？）——都将在本章建立。降维的完整推导是[《线性代数》](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/00/)第 3、4 章（SVD 与特征分解）在机器学习中最重要的应用；谱聚类与 K-means 分别衔接第 4 章特征值与第 5 章的 EM。

## 6.0 本章学习目标

学完本章，你能够：

1. 实现并诊断 K-means，解释其目标函数（簇内平方和）与 EM 的关系，并用 k-means++ 解决初始化问题；
2. 陈述层次聚类的凝聚策略与树状图（dendrogram）的读法，比较单链/全链/平均链的形态差异；
3. 说明 DBSCAN 用密度定义簇的机制（核心点/边界点/噪声），以及它对 K-means 不擅长的任意形状簇的优势；
4. 给出谱聚类的相似度图 → 拉普拉斯矩阵 → 特征向量嵌入的流程，并解释"谱"从何而来（[线性代数·第4章](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/04/)）；
5. 用"最大方差"与"最小重构误差"两种视角完整推导 PCA，并证明两种视角等价；
6. 陈述 t-SNE 与 UMAP 的核心思想（局部相似度保持 + 重尾核），知道它们是"可视化工具"而非"降维算法"的边界。

## 6.1 聚类 I：K-means

### 6.1.1 目标函数与算法

给定无标签数据 $\{x_i\}_{i=1}^n$，$K$-means 寻找 $K$ 个簇中心 $\mu_1, \dots, \mu_K$ 与分配，最小化**簇内平方和（WCSS）**：
$$
\min_{\{r_{ik}\},\ \{\mu_k\}} \; J = \sum_{i=1}^n \sum_{k=1}^K r_{ik}\, \|x_i - \mu_k\|^2,
\qquad
r_{ik} \in \{0, 1\}, \;\; \textstyle\sum_k r_{ik} = 1 .
$$
联合优化是 NP-hard，但**固定一个优化另一个都有闭式解**（[最优化·第2章](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/02/)的坐标块思想，与第 5 章 EM 同构）：
- 固定 $\mu$：$r_{ik} = \mathbb{1}\big[k = \arg\min_{k'} \|x_i - \mu_{k'}\|\big]$（最近中心，"赢者通吃"）；
- 固定 $r$：$\mu_k = \frac{1}{N_k}\sum_i r_{ik} x_i$（簇均值，对 $J$ 求导置零）。

交替迭代，$J$ 单调不增且有下界 → 收敛。**与 EM 的关系**（衔接第 5 章 5.4）：把 GMM 限制为 $\Sigma_k = \epsilon I$ 且令 $\epsilon \to 0$，E 步的责任 $r_{ik} \to$ 硬分配、M 步 → 簇均值——K-means 就是等方差极限下的硬 EM。这也解释了 K-means 的隐含偏置：它假设簇是**各向同性、等方差**的球状簇。

### 6.1.2 初始化问题与 k-means++

$J$ 非凸，收敛到局部最优且强依赖初始中心。最差情况：两个初始中心落在同一真实簇内 → 该簇被劈开、另外两个簇被合并。**k-means++（Arthur & Vassilvitskii, 2007）**：第一个中心均匀随机；之后每个新中心以正比于 $D(x)^2$ 的概率选取（$D(x)$ = 到已选中心的最短距离）——离现有中心越远的点越可能成为新中心，天然把中心"撒"向不同簇。理论保证：解的期望不超过最优解的 $O(\log K)$ 倍（普通随机初始化无此界）。工程实践：`sklearn.KMeans(n_init=10)` 做 k-means++ + 多次重启。

### 6.1.3 怎么选 K

肘部法（WCSS 随 $K$ 的拐点）、轮廓系数（silhouette：样本到本簇平均距离与最近他簇平均距离的归一化差）、以及概率化的 BIC（衔接第 5 章 GMM 的模型选择）。没有银弹——$K$ 的选择本质是"聚类用于什么任务"的问题。

## 6.2 聚类 II：层次聚类与 DBSCAN

### 6.2.1 层次聚类（凝聚式，agglomerative）

不需要预先指定 $K$：初始每点自成簇，每轮合并"距离最近"的两簇，直到只剩一簇；合并历史构成**树状图**，在任意高度"切一刀"即得该粒度的聚类。关键设计在**簇间距离**的定义（[数据结构·第4章](/xiaoshus-blog/textbooks/ai/programming/data-structures/04/)的最小生成树视角：单链层次聚类 ≈ MST 的应用）：

| 簇间距离 | 定义 | 倾向 |
|---|---|---|
| 单链 single | 两簇最近点对的距离 | 链式效应，适合细长簇，怕噪声桥接 |
| 全链 complete | 最远点对 | 紧凑球状簇 |
| 平均链 average | 所有点对平均 | 折中，常用 |
| Ward | 合并带来的 WCSS 增量 | 与 K-means 目标一致，球状簇首选 |

复杂度 $O(n^3)$ 朴素实现（$O(n^2 \log n)$ 带优先队列），不适合 $n \gtrsim 10^4$。

### 6.2.2 DBSCAN：密度即簇

DBSCAN（Ester 等, 1996）的两个参数：邻域半径 $\epsilon$ 与最小点数 $m$。
- **核心点**：$\epsilon$-邻域内点数 $\ge m$ 的点；
- **边界点**：非核心点但落在某核心点的邻域内；
- **噪声点**：其余。
聚类过程：从某核心点出发，把彼此 $\epsilon$-可达的核心点连成簇，边界点挂到其邻域核心点的簇。

优势：能找**任意形状**的簇（两个月牙、环形），自动识别噪声，无需指定 $K$。弱点：对 $(\epsilon, m)$ 敏感（尤其特征尺度不一时）、密度差异大的数据难以用一个全局 $\epsilon$ 兼顾（后续 HDBSCAN 自适应解决）。与 K-means 的对照是本章最值得动手的实验（见 6.6 示例 2）。

## 6.3 聚类 III：谱聚类思想

### 6.3.1 从相似度图到嵌入

K-means 在欧氏空间"看得见"的是点坐标；谱聚类的洞察是：**先建图，再把"连通性"翻译回欧氏坐标**。流程：
1. 构建相似度图 $W$（$k$ 近邻图或全连接 + 高斯核 $W_{ij} = e^{-\|x_i - x_j\|^2/2\sigma^2}$）；
2. 度矩阵 $D_{ii} = \sum_j W_{ij}$，**图拉普拉斯** $L = D - W$（或归一化 $L_{\text{sym}} = I - D^{-1/2} W D^{-1/2}$）；
3. 取 $L$ 的**最小的 $K'$ 个特征值对应的特征向量**（通常去掉平凡的全 1 向量），按行堆成新表示 $y_i \in \mathbb{R}^{K'}$；
4. 在 $\{y_i\}$ 上跑 K-means。

### 6.3.2 为什么有效（衔接线代·第4章）

关键事实：图的连通分支个数 $=$ $L$ 的零特征值个数（[线性代数·第4章](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/04/)的谱定理保证 $L$ 对称半正定、特征向量正交）。两个完全分离的连通分支：指示向量（分支内取 1、外取 0）就是 $L$ 的零特征向量——特征向量天然给出"分支归属编码"。数据近似分离时，最小特征向量连续变形为这个编码——**特征向量把离散的图结构平滑地嵌入到 $\mathbb{R}^{K'}$，使原本非凸可分的簇变成 K-means 可分的团**。这就是它能切开两个月牙的原因：K-means 直接在 $x$ 空间做不到，但谱嵌入后的月牙各自"团圆"了。谱聚类 = 核方法（第 4 章）思想 + 图论 + K-means 的三重奏，其目标函数对应归一化割（normalized cut）的松弛。

## 6.4 降维：PCA 完整推导

### 6.4.1 问题设定

数据 $\{x_i\}_{i=1}^n$，$x_i \in \mathbb{R}^d$，已中心化（$\bar x = 0$）。目标：找低维线性表示。设正交投影方向 $u_1 \in \mathbb{R}^d$，$\|u_1\| = 1$。**两种等价的目标**：

### 6.4.2 视角一：最大投影方差

投影 $z_i = u_1^\top x_i$ 的样本方差：
$$
\frac1n \sum_i z_i^2 = \frac1n \sum_i u_1^\top x_i x_i^\top u_1 = u_1^\top \Big( \frac1n \textstyle\sum_i x_i x_i^\top \Big) u_1 = u_1^\top S u_1,
$$
其中 $S$ 是（中心化后的）样本协方差矩阵（[概率统计·第3章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/03/)）。最大化 $u_1^\top S u_1$ s.t. $\|u_1\| = 1$。拉格朗日函数 $u^\top S u - \lambda(u^\top u - 1)$，求导置零：
$$
S u_1 = \lambda u_1 .
$$
**最优方向是 $S$ 的特征向量**，目标值 = 对应特征值 $\lambda$。由瑞利商（Rayleigh quotient，[线性代数·第4章](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/04/)）：对称矩阵的瑞利商在特征向量处取最值，最大值为最大特征值 $\lambda_1$。故**第一主成分 = $S$ 的最大特征向量，其捕获的方差 = $\lambda_1$**。取前 $k$ 个最大特征向量 $U_k = [u_1, \dots, u_k]$（由对称矩阵特征向量的正交性依次正交），投影 $Z = X U_k \in \mathbb{R}^{n \times k}$。

### 6.4.3 视角二：最小重构误差

把 $x_i$ 投到 $k$ 维再投影回来：$\hat x_i = U_k U_k^\top x_i$，最小化重构平方误差：
$$
\min_{U_k} \; \frac1n \sum_i \|x_i - U_k U_k^\top x_i\|^2 .
$$
展开（用 $U_k^\top U_k = I$）：
$$
\|x_i\|^2 - 2 x_i^\top U_k U_k^\top x_i + x_i^\top U_k U_k^\top U_k U_k^\top x_i
= \|x_i\|^2 - x_i^\top U_k U_k^\top x_i ,
$$
于是最小化误差 $\iff$ 最大化 $\sum_i x_i^\top U_k U_k^\top x_i = n \cdot \operatorname{tr}(U_k^\top S U_k)$——与视角一完全相同（迹即投影方差之和）。**两种视角等价**；总重构误差 $= \sum_{j > k} \lambda_j$，即丢弃的每个方向贡献其特征值那么多误差——这是"选 $k$"的直接依据：让保留方差占比 $\sum_{j\le k}\lambda_j / \sum_j \lambda_j$（如 95%）。

### 6.4.4 与 SVD 的关系与工程实现

[《线性代数·第3章》](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/03/)已证明：中心化数据矩阵 $X \in \mathbb{R}^{n\times d}$ 的 SVD $X = V \Sigma W^\top$ 给出 $S = \frac1n X^\top X = W \frac{\Sigma^2}{n} W^\top$——**右奇异向量就是主成分，特征值 $= \sigma_j^2 / n$**。工程上不做协方差矩阵特征分解（$d$ 大时 $O(d^3)$ 且数值差），直接 `np.linalg.svd(X)`（`sklearn.decomposition.PCA` 内部即 SVD；`svd_solver="randomized"` 可做近似，$n, d$ 极大时用）。注意：PCA 之前必须中心化（否则第一主成分被均值方向支配）；通常还要标准化各特征（各向同性偏置）。

### 6.4.5 PCA 的边界与非线性延伸

PCA 是**线性**的、最大化全局方差（而非类可分性——无监督所以没有类）、对离群点敏感（平方损失）。延伸：kernel PCA（第 4 章核技巧直接套用到 $K = X X^\top$ 上，做非线性主成分——与 6.3 谱聚类在数学上同构）；概率 PCA/因子分析（衔接第 5 章生成式视角：$x = W z + \mu + \varepsilon$，$z \sim \mathcal{N}(0, I)$）。

## 6.5 降维 II：t-SNE 与 UMAP 思想

### 6.5.1 t-SNE

t-SNE（van der Maaten & Hinton, 2008）要保留的是**局部邻域关系**：
1. 高维空间：以高斯核把点对距离转成"相似度" $p_{j|i} \propto e^{-\|x_i - x_j\|^2 / 2\sigma_i^2}$（$\sigma_i$ 按目标困惑度 perplexity 逐点自适应），对称化后得 $p_{ij}$；
2. 低维空间：用**自由度为 1 的 t 分布** $q_{ij} \propto (1 + \|y_i - y_j\|^2)^{-1}$；
3. 最小化两个分布的 KL 散度（梯度下降）。

两个设计要点：重尾 t 分布允许低维中"远点"放得很远而不受重罚 → 类间空隙大、局部簇紧凑（视觉友好但**距离与密度信息不可信**）；KL 散度不对称 → 重视"高维近的点在低维也要近"，反之轻罚。**边界**：t-SNE 图上的簇大小、簇间距、局部密度都不可解读；它适合二维可视化与"有没有结构"的探索，不适合作为下游特征的通用降维（这一条每年都在误导大量论文插图）。

### 6.5.2 UMAP

UMAP（McInnes 等, 2018）同属"图 + 低维嵌入"范式：在高维建 $k$ 近邻加权图（模糊单纯集，权重由到第 $k$ 邻居的距离归一化），低维用交叉熵优化类似的图。与 t-SNE 的差别：保留一定全局结构、速度更快（近邻搜索用 NN-descent）、有理论框架（拓扑数据分析/流形假设），支持新样本点变换（`transform`）。经验法则：**探索可视化用 UMAP/t-SNE；进下游模型用 PCA（或监督式降维）**。

### 6.5.3 无监督方法选型速查

把本章方法的选择逻辑压缩成一张表（详细机制见各节）：

| 方法 | 需要指定 | 假设的簇/结构形态 | 主要弱点 |
|---|---|---|---|
| K-means | $K$ | 球状、等方差（硬 EM，6.1.1） | 任意形状簇失败；对初始化敏感 |
| 层次聚类 | 切割高度 | 由簇间距离定义决定 | $O(n^2)$ 起步；合并不可撤销 |
| DBSCAN | $\epsilon, m$ | 密度连通的任意形状 | 密度差异大时单一 $\epsilon$ 失效 |
| 谱聚类 | $K$, 图构造 | 图连通/流形结构 | $O(n^3)$ 特征分解；图参数敏感 |
| PCA | $k$ | 线性子结构、方差即信息 | 非线性结构；离群点敏感 |
| t-SNE/UMAP | perplexity / $k$ 邻居 | 局部邻域保持 | 距离与密度不可解读（仅可视化） |

## 6.6 关键公式速查

| 公式 | 名称 | 适用条件 |
|---|---|---|
| $J = \sum_{i,k} r_{ik}\|x_i - \mu_k\|^2$ | K-means 目标（WCSS） | 球状等方差簇假设；$J$ 单调不增 |
| $r_{ik} = \mathbb{1}[k = \arg\min \|x_i - \mu_k\|]$ | K-means 分配步 | 固定中心时最优 |
| $P(\text{取 } x \text{ 为新中心}) \propto D(x)^2$ | k-means++ | $D(x)$=到已有中心最小距离；$O(\log K)$-近似 |
| $L = D - W$ | 图拉普拉斯 | 零特征值个数 = 连通分支数 |
| $S u_1 = \lambda_1 u_1$ | PCA 特征方程 | 数据已中心化；$S = \frac1n X^\top X$ |
| 重构误差 $= \sum_{j>k} \lambda_j$ | PCA 误差 | 特征值降序；选 $k$ 的依据 |
| $X = V\Sigma W^\top,\ \lambda_j = \sigma_j^2/n$ | PCA-SVD 关系 | 数值上首选 SVD 实现 |
| $q_{ij} \propto (1 + \|y_i-y_j\|^2)^{-1}$ | t-SNE 低维核 | 重尾；低维距离不可信 |

## 6.7 示例与案例

### 示例 1（手算）：4 个点的 K-means 一轮迭代

点：$x_1 = 0, x_2 = 1, x_3 = 5, x_4 = 6$（一维），$K = 2$，初始中心 $\mu_1 = 0, \mu_2 = 1$。
- 分配步：$x_1 \to \mu_1$（距 0 < 1），$x_2 \to \mu_2$（1 vs 0），$x_3 \to \mu_2$（5 vs 4），$x_4 \to \mu_2$（6 vs 5）。簇 1 = $\{x_1\}$，簇 2 = $\{x_2, x_3, x_4\}$。
- 更新步：$\mu_1 = 0$，$\mu_2 = (1+5+6)/3 = 4$。
- 再分配：$x_2$ 距 0 为 1、距 4 为 3 → 换簇到 $\mu_1$；$x_3, x_4$ 仍归 $\mu_2$。更新：$\mu_1 = 0.5$，$\mu_2 = 5.5$。$J = 0.25 + 0.25 + 0.25 + 0.25 = 1$。
- 再迭代无变化 → 收敛。$J$ 从初始（$\mu=0,1$ 时 $J = 0 + 0 + 16 + 25 = 41$）单调降到 1——请留意每一次分配/更新后 $J$ 的变化都非负地改善，这是 6.1.1 收敛性的现场版。（校验值：收敛解 $\mu = (0.5, 5.5)$，$J = 1$。）

### 示例 2（代码）：K-means++、DBSCAN、谱聚类、PCA 全家桶

```python
# ch6_unsupervised.py
# 依赖: numpy, matplotlib, sklearn(对拍与数据集)
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons
from sklearn.cluster import KMeans, DBSCAN, SpectralClustering
from sklearn.decomposition import PCA

rng = np.random.default_rng(0)

# ============ A. 从零实现 K-means++ + K-means ============
def kmeans_pp_init(X, K, rng):
    centers = [X[rng.integers(len(X))]]                 # 第一个均匀随机
    for _ in range(1, K):
        d2 = np.min(((X[:, None] - np.array(centers)) ** 2).sum(-1), axis=1)
        p = d2 / d2.sum()                               # 正比于 D(x)^2
        centers.append(X[rng.choice(len(X), p=p)])
    return np.array(centers)

def kmeans(X, K, iters=100, seed=0):
    rng = np.random.default_rng(seed)
    mu = kmeans_pp_init(X, K, rng)
    for t in range(iters):
        # 分配步: 最近中心
        d2 = ((X[:, None] - mu) ** 2).sum(-1)           # (n, K)
        r = np.eye(K)[d2.argmin(1)]                     # one-hot 分配矩阵
        # 更新步: 簇均值(空簇保留原中心)
        Nk = r.sum(0) + 1e-12
        mu_new = (r.T @ X) / Nk[:, None]
        if np.allclose(mu_new, mu): break
        mu = mu_new
    J = ((X - mu[r.argmax(1)]) ** 2).sum()              # 目标值 WCSS
    return mu, r, J

X, y_true = make_moons(n_samples=300, noise=0.08, random_state=0)
mu, r, J = kmeans(X, K=2)
print(f"K-means WCSS = {J:.2f}")                        # 预期: ≈ 120~140 (月牙被拦腰切开!)
# 对照: 真实标签的"簇"对应 WCSS 也会不小 —— 说明欧氏 WCSS 不适配月牙形状

# sklearn 对拍(k-means++ 默认)
km = KMeans(2, n_init=10, random_state=0).fit(X)
print("sklearn inertia =", round(km.inertia_, 2))       # 应与从零实现接近(±5%)

# ============ B. DBSCAN 与谱聚类处理月牙 ============
db = DBSCAN(eps=0.2, min_samples=5).fit(X)
print("DBSCAN 簇标签:", np.unique(db.labels_))          # 预期: [0 1], 两月牙被完美分开(几乎无噪声点)
sc = SpectralClustering(2, affinity="nearest_neighbors", random_state=0)
pred_sc = sc.fit_predict(X)
print("谱聚类 vs 真实标签一致率:", (pred_sc == y_true).mean())  # 预期: > 0.95
print("K-means vs 真实标签一致率:",
      max((r.argmax(1) == y_true).mean(), (1 - r.argmax(1) == y_true).mean()))  # 预期: ≈ 0.6x

# ============ C. PCA 双视角对拍: 特征分解 vs SVD ============
Xg = rng.normal(size=(200, 5)) @ rng.normal(size=(5, 5))   # 5维相关数据
Xc = Xg - Xg.mean(0)
S = Xc.T @ Xc / len(Xc)
eigval, eigvec = np.linalg.eigh(S)                  # 对称矩阵特征分解(线代·第4章)
eigval = eigval[::-1]; eigvec = eigvec[:, ::-1]     # 降序
U, s, Vt = np.linalg.svd(Xc, full_matrices=False)   # SVD 路径
print("特征值 vs SVD λ:", np.round(eigval, 4), np.round(s**2 / len(Xc), 4))
# 预期: 两组数完全一致 —— 6.4.4 的 λ_j = σ_j^2/n 现场验证

pca = PCA().fit(Xg)
print("累计方差占比:", np.round(np.cumsum(pca.explained_variance_ratio_), 3))
# 预期形态: 前两三个主成分已占 > 0.95 —— 数据有效维度 < 5

fig, axes = plt.subplots(1, 3, figsize=(13, 4))
axes[0].scatter(*X.T, c=r.argmax(1), cmap="coolwarm"); axes[0].set_title("K-means")
axes[1].scatter(*X.T, c=db.labels_, cmap="coolwarm");  axes[1].set_title("DBSCAN")
Xp = pca.fit_transform(X)
axes[2].scatter(*Xp.T, c=y_true, cmap="coolwarm");     axes[2].set_title("PCA 投影")
plt.tight_layout(); plt.savefig("ch6_clusters.png", dpi=120)
```

## 6.8 常见误区与陷阱

1. **K-means 之前不做标准化**。量纲大的特征支配平方距离，聚类退化成"按一个特征分组"。
2. **单次随机初始化就下结论**。K-means 收敛到局部最优；至少 `n_init=10`。
3. **把 t-SNE 图上的簇间距/簇大小当真实结构**。重尾核 + KL 不对称使这些量不可解读；换 `perplexity` 或种子，簇可能重组。
4. **PCA 前忘记中心化**。第一主成分会指向均值而非最大方差方向。
5. **用 PCA"降维后再聚类"当万能预处理**。若方差大的方向与簇分离方向正交，PCA 反而抹掉簇结构；对聚类应考虑谱方法或直接在原空间做。
6. **DBSCAN 的 eps 拍脑袋**。先画 k-距离图（每个点到第 $k$ 近邻的距离排序曲线），取"肘部"对应的距离。
7. **认为谱聚类对大样本廉价**。需要 $n \times n$ 相似度矩阵的特征分解，$O(n^3)$；大样本用近似（Nyström、landmark）。
