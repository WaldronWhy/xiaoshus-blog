# 第 2 章 无模型方法：Monte Carlo 与时序差分

> **本章定位**：从"模型已知"走向"模型未知"——真实世界中转移概率 $P$ 几乎从不写给你看，数据只能靠交互采集。本章给出两条采样逼近贝尔曼方程的路线：Monte Carlo（等整条轨迹结束、用真实回报）与时序差分（每步即更新、用自举的估计），并在此基础上完成强化学习第一组"明星算法"：SARSA 与 Q-learning。第 1 章的贝尔曼方程在此从"要解的方程"变成"要采样的期望"。

## 2.0 本章学习目标

学完本章，你能够：

1. 说明免模型（model-free）设定与第 1 章 DP 设定的本质差异，以及"预测"与"控制"两个子问题的区别；
2. 实现 first-visit / every-visit MC 策略评估，并用大数定律解释其收敛性；
3. 推导 TD(0) 更新规则，从**偏差-方差**与**自举**两个维度系统对比 MC、TD 与 DP；
4. 实现 ε-greedy 控制下的 SARSA 与 Q-learning，说清 on-policy 与 off-policy 的区别及各自的收敛条件；
5. 在 Cliff Walking 上复现经典实验，用数据回答"为什么 Q-learning 学得更优但 SARSA 学得更稳"；
6. 将"期望用采样均值近似"这一思想回接到《概率统计》第 6 章的蒙特卡洛方法。

## 2.1 免模型学习的动机：当 $P$ 未知时

第 1 章的 DP 需要知道 $P(s' \mid s, a)$ 与 $r(s,a,s')$——对棋类成立（规则即模型），但对真实世界几乎从不成立：机器人不知道地面的摩擦系数模型，推荐系统不知道用户点击的生成机制，大模型更不知道"人类偏好"的概率分布。

免模型（model-free）学习的唯一信息来源是**交互数据**：$(s, a, r, s')$ 四元组流。关键洞察是：**贝尔曼方程两边都是期望，而期望可以用采样均值估计**——这正是[《概率统计》第 6 章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/06/)蒙特卡洛方法的核心思想在决策领域的复用：

$$v^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s] \approx \frac{1}{N}\sum_{i=1}^{N} G_t^{(i)} \quad (\text{从 } s \text{ 出发按 } \pi \text{ 采 } N \text{ 条轨迹}).$$

于是问题变成两个子问题：

- **预测（prediction / 策略评估）**：给定 $\pi$，估计 $v^\pi$ 或 $q^\pi$；
- **控制（control / 找最优策略）**：在估计的同时改进策略（广义策略迭代 GPI：评估与改进交错，不必各自完全收敛——第 1 章 1.5 的思想在此松绑）。

**一个马上要面对的矛盾**：要评估 $\pi$，得用 $\pi$ 生成的数据；要找到最优策略，又得探索 $\pi$ 不会走的地方。这就是**探索-利用权衡**（2.4 节）——监督学习里不存在这个问题，因为数据是给定的。

**与前面所有课程的对照**：此前的学习中，数据集是"命名好的常量"；从本章起，数据集是"你当前策略的函数"。这个视角转换之深刻，值得停留一分钟：它意味着学习目标、数据分布、评估标准三者彼此耦合——RL 中没有独立于学习的"测试集"，你评估的永远是"到目前探索过的地方"。第 3 章 replay、第 4 章 rollout buffer、第 5 章离线数据集，都是围绕"如何驾驭这个自我指涉的数据生成过程"展开的工程。

## 2.2 Monte Carlo 策略评估

**算法（first-visit MC 预测）**：按 $\pi$ 采完整条轨迹；对每个状态 $s$ **首次**出现的时刻 $t$，取回报 $G_t$，累进平均：

$$V(s) \leftarrow V(s) + \alpha \left( G_t - V(s) \right), \qquad \alpha = \frac{1}{N(s)} \ (\text{常数 } \alpha \text{ 则为 every-visit 常用变体}).$$

**收敛性**：由大数定律（[《概率统计》第 5 章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/05/)），first-visit 的 $G_t$ 是 $v^\pi(s)$ 的无偏估计、独立同分布，$N(s) \to \infty$ 时 $V(s) \to v^\pi(s)$（逐状态）。every-visit 的估计有偏但一致，实际表现相近。

**MC 的两个鲜明特点**：

- **无偏、大方差**。$G_t$ 是真实回报，无偏；但一条轨迹的回报混入了此后**所有**随机性（每步的转移、每步的动作），方差巨大——《机器学习》第 1 章的偏差-方差权衡在这里以"单样本质量"的面目出现：无偏但噪声大，意味着收敛慢。
- **必须等 episode 结束**。对长甚至无限的 episode（如持续控制的机器人）直接不可用；更新延迟也使在线适应不可能。

**增量式实现的推导**（也是一切在线学习算法的模板）：记 $V_{k+1}(s)$ 为第 $k+1$ 次访问后的估计，均值的朴素实现需要存储全部历史：

$$V_{k+1}(s) = \frac{1}{k}\sum_{i=1}^{k} G_i^{(s)} = \frac{1}{k}\Big( G_k^{(s)} + (k-1)\, V_k(s) \Big) = V_k(s) + \frac{1}{k}\Big( G_k^{(s)} - V_k(s) \Big).$$

括号里的结构"估计 + 步长 × 预测误差"与 TD 更新、随机梯度下降（《最优化方法》第 5 章）完全同形——这个三段式以后会以无数面目出现，请把它当作强化学习的"乘法口诀"记住。步长 $\alpha = 1/k$ 满足 Robbins-Monro 条件（估计严格收敛）；固定 $\alpha$ 则放弃严格收敛，换取对非平稳目标的持续追踪——与 RL 数据分布随策略漂移的现实呼应。

**MC 控制怎么做**：仿照第 1 章策略迭代，评估 $q^\pi$（注意控制必须学 $q$ 而非 $v$：改进策略时没有模型，无法由 $v$ 算出每个动作的价值），然后对 $\varepsilon$-greedy 改进。保证每状态每个动作被无限次访问是理论前提——实践中用探索起点（exploring starts）或软性策略（2.4 节）。

## 2.3 时序差分学习：自举的威力

### 2.3.1 TD(0) 更新

MC 要等真实回报 $G_t$；TD（temporal difference）的思路是：**不等终局，用当前的估计 $\color{#888}{V(S_{t+1})}$ 顶替 $\color{#888}{G_{t+1}}$**。由回报递归式 $G_t = R_{t+1} + \gamma G_{t+1}$，构造 TD 目标（TD target）：

$$\underbrace{R_{t+1} + \gamma V(S_{t+1})}_{\text{TD 目标 } \hat{G}_t} \qquad \Rightarrow \qquad \boxed{V(S_t) \leftarrow V(S_t) + \alpha \left[ R_{t+1} + \gamma V(S_{t+1}) - V(S_t) \right]}$$

括号里的量叫 **TD 误差** $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$——它是"账本不自洽"的局部信号（第 1 章 1.4.2 的自洽账本意象在此兑现）。TD(0) 的含义：只向后看一步。

### 2.3.2 MC vs TD vs DP：一张表看穿

| 维度 | Monte Carlo | TD(0) | DP（第 1 章） |
|---|---|---|---|
| 更新目标 | 真实回报 $G_t$ | 自举目标 $r + \gamma V(s')$ | 全期望 $\mathbb{E}[r + \gamma V(s')]$ |
| 需要模型？ | 否 | 否 | **是**（要 $P, r$） |
| 偏差 | 无偏 | **有偏**（依赖 $V$ 的准确性） | 无（精确期望） |
| 方差 | 大（整条轨迹的噪声） | 小（只带一步噪声） | 零 |
| 更新时机 | episode 结束 | 每步在线 | 全状态同步扫描 |
| 数据效率 | 低 | 高 | 不采数据 |

**偏差-方差的账**：TD 目标 $\hat{G}_t = R_{t+1} + \gamma V(S_{t+1})$ 中 $V(S_{t+1})$ 是估计而非真值，故有偏；但它的随机性只有一步的 $S_{t+1}, R_{t+1}$，方差远小于 $G_t$。**用偏差换方差**——这四个字将在第 3 章（目标网络稳定自举）与第 4 章（优势函数与 GAE）反复变奏。收敛性上，对固定策略与表格型表示，TD(0) 以概率 1 收敛到 $v^\pi$（步长满足 Robbins-Monro 条件 $\sum \alpha_t = \infty, \sum \alpha_t^2 < \infty$，与[《最优化方法》第 5 章](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/05/)随机逼近的条件同形）。

**自举（bootstrapping）**：用"自己的估计"更新"自己的估计"——名字借自"提着自己的靴子把自己拉起来"。它是 TD 的一切优点与一切麻烦的来源：优点是无需等终局、数据效率高；麻烦是估计误差会被自我强化（第 3 章致命三要素的伏笔）。

**一个立刻有用的推论**：MC 与函数近似组合是安全的（目标 $G_t$ 是外生数据，监督回归的收敛理论直接适用），而 TD + 函数近似在 off-policy 下会发散（第 3 章 3.3 节）。所以"是否自举"是比"on/off-policy"更根本的稳定性行情——第 4 章 PPO 的 critic 通常配合自举但保持 on-policy，正是在这两个危险因素之间走钢丝。用这个视角预览后面两章：DQN = 自举 + 函数近似 + off-policy（三要素全占，最危险）；REINFORCE = 不自举 + 函数近似 + on-policy（最安全，但方差最大）。**稳定性和样本效率的种种技巧，本质都是在这三个开关之间搬运代价**。

### 2.3.3 统一视角：三个方法都在逼近同一个方程

把三个方法放进同一个框架，你会看清它们只是对**同一个贝尔曼期望方程**的三种逼近方式：

$$v^\pi(s) = \mathbb{E}\big[ r + \gamma v^\pi(s') \big] \quad \Rightarrow \quad \begin{cases} \text{DP：右边用模型算全期望（精确但需模型）} \\ \text{TD：右边用单次采样 } r + \gamma V(s') \text{（自举）} \\ \text{MC：左边用完整采样 } G_t \text{（不自举）} \end{cases}$$

MC 只采样"左边"（把整个未来一次性采完），TD 只采样"右边"（把未知的未来换成当前估计）——自举与采样是两个**独立的开关**，MC = 采样开 + 自举关，DP = 采样关 + 自举开（DP 的目标也依赖 $V$，只是通过期望加权），TD = 两个都开。这个 2×2 视角（Sutton & Barto 图 7.2 的思想）能解释 n 步方法与 TD(λ) 为什么存在：它们只是把两个开关之间的滑块移动到中间某处。

### 2.3.4 n 步与 TD(λ)（一瞥）

一步自举（TD）与等终局（MC）之间可以插值：n 步目标 $G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^n V(S_{t+n})$。对 n 取指数加权几何平均得 TD(λ)，λ=0 退化为 TD(0)，λ=1（适当截断）近似 MC。本章只建立图景，细节见 Sutton & Barto 第 12 章。

## 2.4 ε-greedy 与探索-利用权衡

控制问题中策略必须持续探索。**ε-greedy**：以概率 $1-\varepsilon$ 贪心，以概率 $\varepsilon$ 均匀随机：

$$\pi(a \mid s) = \begin{cases} 1 - \varepsilon + \varepsilon / |\mathcal{A}|, & a = \arg\max_{a'} Q(s, a') \\ \varepsilon / |\mathcal{A}|, & \text{否则} \end{cases}$$

直觉：贪心兑现已知的好动作（利用），随机撞进未见的状态（探索）。**多臂老虎机**（bandit）是本问题的无状态特例——那里有著名的最优性遗憾（regret）理论与 UCB 算法；在完整 MDP 中没有封闭解，但两条经验法则稳定有效：

1. **衰减探索**：$\varepsilon$ 从 1.0 线性/指数衰减到 0.05 左右——早期广撒网、后期精收割（与《最优化方法》从全局探索到局部精化的学习率调度同构）；
2. **乐观初始化**：把 $Q$ 初值设得偏高（如目标奖励上界），逼着智能体把"看起来都很好"的动作各试一遍。机制：$Q$ 偏高 → 被选中的动作实测回报低于乐观预期 → $Q$ 下调 → 换下一个"看起来不错"的动作——乐观是一个自动的探索泵，且不需要显式的随机动作；
3. **不确定性感知（进阶预告）**：ε-greedy 的探索是"盲目均匀"的——它不知道自己**哪里**不确定。UCB 类方法按 $Q(s,a) + c\sqrt{\ln N(s) / N(s,a)}$ 选动作（访问次数少则估值加成），把探索预算精准花在欠采样的动作上；这个公式在 5.5 节的 MCTS 中将以树上形式再次登场。

**GLIE 条件**（Greedy in the Limit with Infinite Exploration）：$\varepsilon_t \to 0$ 且每个状态-动作对仍被无限次访问。ε-greedy 满足 GLIE 时，MC 控制 / SARSA 收敛到 $q^*$ 的理论条件即被满足。注意 ε-greedy 的软策略**永远不是** $\pi^*$（它带随机性），它只是通往 $\pi^*$ 的脚手架——部署时应使用从 $Q$ 读出的确定性贪心策略，训练中的软策略仅在"保证探索"这一职责上存在。

## 2.5 SARSA 与 Q-learning：on-policy 与 off-policy

### 2.5.1 两个算法，一字之差

**SARSA**（State-Action-Reward-State-Action，名字来自五元组 $(S_t, A_t, R_{t+1}, S_{t+1}, A_{t+1})$）：

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t) \right]$$

其中 $A_{t+1} \sim \pi$（**实际执行的那个下一步动作**）。评估的是"ε-greedy 自己"的价值，更新所用数据全部来自自己的行为——**on-policy**（在轨）。

**Q-learning**（Watkins, 1989）：

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma \max_{a'} Q(S_{t+1}, a') - Q(S_t, A_t) \right]$$

自举目标用 $\max$——**直接逼近 $q^*$ 的贝尔曼最优方程**，与"实际会怎么走"无关。行为策略只需保证充分探索（如 ε-greedy），而评估/改进的对象是贪心目标策略——**off-policy**（离轨）：行为与目标可以是两个策略。

**一字之差的深层含义**：SARSA 学的是"含探索成本的真实价值"，所以它知道"贴着悬崖走，ε 的随机性会让你偶尔掉下去"——于是学出**保守但安全**的策略；Q-learning 的 max 假设"下一步一定走最优"，把探索风险记在行为策略头上而不计入价值——于是学出**激进但最优**的策略。下一节实验将让这个抽象论述变成一张图。

### 2.5.2 收敛性讨论

- **Q-learning**：Watkins 证明——行为策略保证每个 $(s,a)$ 无限次访问、步长满足 Robbins-Monro 条件、折扣 $\gamma<1$ 时，$Q \to q^*$（概率 1）。核心机制：max 算子是压缩的（第 1 章定理 1.3 的随机采样版）。
- **SARSA**：收敛目标是 $q^{\pi}$（当前软策略的价值），要求策略在过程中满足 GLIE，才收敛到 $q^*$。若 ε 固定不衰减，SARSA 收敛到"ε-greedy 的最优"，而非全局最优——这不是 bug，是 on-policy 的定义使然。
- **两者的共同软肋（伏笔）**：以上收敛证明都依赖**表格表示**——每个 $(s,a)$ 独立存储、互不干扰。一旦用函数近似（第 3 章），数据不再独立、目标随参数漂移，"半梯度"与"致命三要素"接踵而至。

**广义策略迭代（GPI）视角的小结**：把本章所有控制算法放在同一张图上看——它们都是"评估"与"改进"两个过程的相互追赶：MC 控制 = 评估到轨迹级精度再改进；SARSA = 每步半评估半改进；Q-learning = 评估的对象直接就是"对当前值贪心的策略"（评估与改进合一）。第 1 章的策略迭代收敛论证在"两者都不完全收敛、但相互牵制"的松弛版本下依然成立——这张 GPI 的图景是理解一切 RL 算法（包括第 3、4 章）的元框架。

**最大化偏差（maximization bias）**：$\max_a Q(s,a)$ 用的是"带噪声估计的最大值"，噪声让 max 系统性偏高（$\mathbb{E}[\max_i \hat{X}_i] \ge \max_i \mathbb{E}[\hat{X}_i]$，Jensen 型不等式）。Double Q-learning 用两套独立估计互相解耦：$Q_A$ 选动作、$Q_B$ 估值——这个 2010 年的小技巧将在第 3 章升级为 Double DQN。

## 2.6 关键公式速查

| 公式 | 内容 | 适用条件 |
|---|---|---|
| $V(s) \leftarrow V(s) + \alpha(G_t - V(s))$ | MC 更新 | 轨迹终止，$G_t$ 为真实回报 |
| $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$ | TD 误差 | 任意 $V$（表格/函数） |
| $V(s) \leftarrow V(s) + \alpha\,\delta_t$ | TD(0) 更新 | 表格 + Robbins-Monro 步长 |
| SARSA 目标 $R_{t+1} + \gamma Q(S_{t+1}, A_{t+1})$ | on-policy TD 控制 | $A_{t+1}$ 来自行为策略 |
| Q-learning 目标 $R_{t+1} + \gamma \max_{a'} Q(S_{t+1}, a')$ | off-policy 控制 | 行为策略覆盖所有 $(s,a)$ |
| $\varepsilon$-greedy：以 $\varepsilon$ 均匀探索 | 软策略 | 保证 $\varepsilon>0$ 期间探索 |
| GLIE：$\varepsilon_t \to 0$ 且覆盖无限次 | 收敛条件 | SARSA/MC 控制 → $q^*$ |

## 2.7 示例与案例

### 2.7.0 手算算例：一次 Monte Carlo 评估

两个状态的小 MDP，按某策略采到两条轨迹：$s_A \to r{=}+1 \to s_B \to r{=}{+2} \to$ 终止；$s_B \to r{=}{-1} \to$ 终止。取 $\gamma = 0.9$，从零开始估计（first-visit）：

- 轨迹 1：$G(s_A) = 1 + 0.9 \times 2 = 2.8$，$G(s_B) = 2$。更新后 $V(s_A) = 2.8$，$V(s_B) = 2$；
- 轨迹 2：$G(s_B) = -1$。增量更新 $\alpha = 1/N(s_B) = 1/2$：$V(s_B) \leftarrow 2 + 0.5 \times (-1 - 2) = 0.5$。

注意 $s_A$ 的估计**不因轨迹 2 而动**（轨迹 2 没经过它）——MC 的更新完全由"实际走过的路"决定；而 TD 的更新会通过 $V(s_B)$ 的变化间接波及 $s_A$（下次经过 $s_A$ 时目标里含新的 $V(s_B)$）——**MC 的信息只能沿轨迹整体流动，TD 的信息随每步更新即时扩散**。这个差别在数据稀疏时（哪条路先被探索到）会放大成算法行为的天壤之别。

### 2.7.1 手算算例：一步 TD 更新

设 $\gamma = 0.9$，$\alpha = 0.1$，当前 $V(s) = 5.0$。执行一步得到 $r = -1$，到达 $s'$，$V(s') = 8.0$。则

$$\delta = -1 + 0.9 \times 8.0 - 5.0 = 1.2, \qquad V(s) \leftarrow 5.0 + 0.1 \times 1.2 = 5.12.$$

对比 MC：若从 $s$ 出发的整条轨迹最终真实回报 $G = 7.0$，则 MC 更新 $V(s) \leftarrow 5.0 + 0.1 \times (7.0 - 5.0) = 5.2$。两者方向一致（都认为 5.0 低估了），但幅度与依据不同：TD 信"邻居 + 这一步"，MC 信"整盘实账"。若 $V(s') = 8.0$ 本身严重高估，TD 会把误差传染给 $V(s)$——请记住这个机制，第 3 章它会放大成训练崩溃。

### 2.7.2 Cliff Walking：SARSA vs Q-learning 经典实验

Cliff Walking（Sutton & Barto 例 6.6）：$4 \times 12$ 网格，起点左下、目标右下，底边中间 10 格是悬崖——踏入即 $-100$ 并弹回起点，每步 $-1$。理论最优回报 $-13$（贴崖短路径）。下面从零实现环境与两个算法（不依赖 gymnasium，便于复用第 1 章的网格世界观）。

```python
# cliff_walking.py —— SARSA vs Q-learning（纯 numpy，可独立运行）
import numpy as np

class CliffEnv:
    """4x12 Cliff Walking。状态 s = row*12 + col，行 3 为底边。
    奖励：每步 -1；踏入悬崖列 1..10（行 3）得 -100 并回到起点；到达目标结束。"""
    def __init__(self):
        self.nR, self.nC = 4, 12
        self.start, self.goal = 36, 47          # (3,0) 与 (3,11)
        self.cliff = set(range(37, 47))         # (3,1) .. (3,10)
        self.actions = [(-1, 0), (0, 1), (1, 0), (0, -1)]  # 上右下左
        self.nS, self.nA = self.nR * self.nC, 4

    def reset(self): return self.start

    def step(self, s, a):
        r, c = divmod(s, 12); dr, dc = self.actions[a]
        nr, nc = min(max(r + dr, 0), 3), min(max(c + dc, 0), 11)
        ns = nr * 12 + nc
        if ns == self.goal: return ns, -1.0, True
        if ns in self.cliff: return self.start, -100.0, False
        return ns, -1.0, False

def eps_greedy(Q, s, eps, rng):
    if rng.random() < eps: return int(rng.integers(4))
    return int(np.argmax(Q[s]))             # 平手时取第一个动作（上），天然偏好离崖

def train(method, episodes=1000, alpha=0.2, gamma=1.0, eps=0.1, seed=0):
    env, rng = CliffEnv(), np.random.default_rng(seed)
    Q = np.zeros((env.nS, env.nA)); returns = []
    for _ in range(episodes):
        s, done, total, steps = env.reset(), False, 0.0, 0
        a = eps_greedy(Q, s, eps, rng)
        while not done and steps < 500:                  # 步数上限：防止策略未收敛时的死循环
            ns, r, done = env.step(s, a); total += r; steps += 1
            if method == "sarsa":
                na = eps_greedy(Q, ns, eps, rng)             # 先选下一步动作
                target = r + (0.0 if done else gamma * Q[ns, na])
                Q[s, a] += alpha * (target - Q[s, a])
            else:                                            # q_learning
                target = r + (0.0 if done else gamma * Q[ns].max())
                Q[s, a] += alpha * (target - Q[s, a])
                na = eps_greedy(Q, ns, eps, rng)             # 行为策略再选
            s, a = ns, na
        returns.append(total)
    return Q, np.array(returns)

def greedy_eval(Q, env, max_steps=500):
    s, total = env.reset(), 0.0
    for _ in range(max_steps):
        s, r, done = env.step(s, int(np.argmax(Q[s]))); total += r
        if done: return total
    return float("nan")  # 未到达目标（陷入绕圈），视为失败

if __name__ == "__main__":
    env = CliffEnv()
    for name in ["sarsa", "q_learning"]:
        Q, rets = train(name)
        print(f"{name:>10}: 训练后 100 轮平均回报 = {rets[-100:].mean():7.2f}, "
              f"贪心评估回报 = {greedy_eval(Q, env):6.1f}")
```

预期输出（随机性来自 ε-greedy 探索，不同种子数值有波动，但定性结论稳定；下表为种子 0 的结果）：

```text
     sarsa: 训练后 100 轮平均回报 =  -22.90, 贪心评估回报 =  -17.0
q_learning: 训练后 100 轮平均回报 =  -51.57, 贪心评估回报 =  -13.0
```

**读数解读**（这正是 Sutton & Barto 图 6.13 的故事）：

- **Q-learning 贪心评估 $= -13$**：它学到了贴崖的最短路径——因为它的目标函数里没有探索风险（max 假设每步都最优），奖励它胆大；
- **SARSA 贪心评估 $= -15 \sim -17$**：它学到的是"崖顶上方一格的安全长路"——因为它的 TD 目标里 $A_{t+1}$ 由 ε-greedy 采出，悬崖边缘状态的价值被探索跌落风险如实折价；
- **训练期平均回报 SARSA 显著更好（$-23$ vs $-52$）**：Q-learning 的策略贴着悬崖，训练时 ε 的随机性频繁把它摔下崖（回报瞬间 $-100$ 级别），曲线锯齿剧烈；SARSA 的安全路几乎不掉崖。这正是"Q-learning 学得更优、SARSA 学得更稳"的经典结论——**评估指标（贪心）与训练指标（含探索）给出相反的排名**；
- **实践启示**：部署期表现（纯贪心）与训练期表现（要考虑探索）是两个指标——安全攸关场景（机器人、医疗）偏好 SARSA 式的 on-policy 保守性；追求极致性能且探索可控时用 Q-learning/off-policy。把本实验的 `eps` 从 0.1 改成 0.01 再跑一遍，你会发现两者差距缩小——探索强度是决定这场"路线之争"胜负的手。

## 2.8 常见误区与陷阱

1. **忘掉 $A_{t+1}$ 的采样顺序**：SARSA 必须"先按行为策略选出 $A_{t+1}$ 再更新"；图省事先更新后选动作，就悄悄写成了 Q-learning。错法不报错、也能收敛，只是语义完全不同——这类"静默错误"在 RL 里最致命。
2. **off-policy ≠ 不需要探索**：Q-learning 收敛的行为策略条件是"每个 $(s,a)$ 无限次访问"；把 ε 设成 0，Q 值会停在初始化附近的幻觉里。
3. **用 $V$ 做无模型控制**：没有模型时无法从 $V(s)$ 推出"哪个动作好"（要 $\sum_{s'} P(s'|s,a)\,v(s')$），所以无模型控制一律学 $Q$。看到"用 $V$ 做 Q-learning"的代码直接判错。
4. **步长不衰减导致的"永不收敛"**：固定 $\alpha$ 时 Q 值在真值附近持续抖动（每步都被新噪声推一把）；这在小网格上无伤大雅，在第 3 章神经网络里会与自举误差共振。理论上需 Robbins-Monro 条件，实践中靠学习率调度折中。
5. **评估时混入 ε-greedy**：贪心评估（deploy 时的表现）必须 `argmax`；带着 ε 评估会把探索成本记进成绩，让 Q-learning 看起来"更差"。对比实验要明确报的是哪个指标。
6. **every-visit MC 的"独立样本"幻觉**：同一轨迹内多次访问同一状态的 $G_t$ 强相关，把这些样本当独立样本平均会低估方差、高估置信度（第 3 章经验回放会正式处理相关性问题）。

## 2.11 进阶方向

- **TD(λ) 与资格迹（eligibility traces）**：一步记忆的优雅推广，前向/后向视图等价性是漂亮的数学；
- **Q(λ) 与 Sarasa(λ)**：把资格迹带进控制问题；
- **Expected SARSA**：把 SARSA 的采样 $A_{t+1}$ 换成期望 $\sum_{a'} \pi(a'|s') Q(s',a')$——介于 SARSA 与 Q-learning 之间、方差更小；
- **平均奖励与 R-learning**：无折扣长程任务的 TD 家族（呼应第 1 章进阶方向）；
- **Off-policy 评估（OPE）**：只用行为策略的历史数据评估一个新策略的价值——第 5 章离线 RL 与 RLHF 评估的数学前置（重要性采样与第 4 章同源）。
