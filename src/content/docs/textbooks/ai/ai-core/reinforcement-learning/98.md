# 第 1 章 MDP 与动态规划（对应正文 1.12 节）

## 1-1 概念辨析：五元组的归属（对应 1.1–1.2 节）

> 题目：MDP 五元组中，哪两个元素是"环境"的属性、哪两个是"智能体"的属性、γ 属于谁？说明理由。

**标准答案要点**

- **环境的属性：转移核 $P(s'\mid s,a)$ 与奖励函数 $R$**。这两者刻画"世界如何回应你的动作"，智能体既不控制也无法（在免模型设定下）直接知道它们——第 2 章免模型学习的全部困难正是"$P$ 与 $R$ 不写给你看"。
- **智能体的属性：策略 $\pi$ 所操控的那一半——严格地说，本题问的"两个元素"指 $\mathcal{S}$ 与 $\mathcal{A}$ 之外的两项 $P,R$；而 $\mathcal{S},\mathcal{A}$ 是交互接口，由问题定义，但"状态里放什么、动作集里留什么"体现建模者（智能体一方）的设计自由**（正文 1.2 节："状态设计得好不好，直接决定问题是否（近似）马尔可夫"）。
- **$\gamma$ 属于智能体**：折扣率编码的是智能体对"未来 vs 眼前"的偏好（1.3 节"行为调节器"），同一个环境配不同的 $\gamma$ 就是不同的决策问题。它不出现在环境的状态转移定律里，而出现在智能体的目标（回报定义）里。

**常见错误答案为什么错**

- 把 $R$ 归给智能体（理由"奖励是智能体的目标"）：目标确实属于智能体，但**奖励信号本身是环境发出的回应**（$R_{t+1}$ 由环境在 $A_t$ 之后给出）。智能体拥有的是"追求累积奖励的偏好"（$\gamma$），不是"发放奖励的权力"。
- 把 $\gamma$ 归给环境：$\gamma$ 不改变环境任何一条转移与奖励，只改变智能体账本（$G_t$）的记法。
- 认为 $\mathcal{S},\mathcal{A}$ 一定是环境的：对 Atari，动作集由模拟器接口决定；但对机器狗，"用哪些关节控制量作为动作"是工程师（智能体一方）的建模选择。

## 1-2 建模练习：真实系统的 MDP（对应 1.1–1.2 节）

> 题目：举一个你熟悉的真实系统，指出状态、动作、奖励，并讨论马尔可夫性在哪个环节被破坏、如何补救。

**参考答案（以视频推荐系统为例）**

- 状态 $s$：用户最近 $k$ 次点击的物品类别序列、会话时长、当天时段、设备类型；
- 动作 $a$：从候选池中推荐哪一条视频（离散、大动作集）；
- 奖励 $r$：点击 $+1$、完播 $+2$、快速划走 $-1$（负奖励抑制"标题党"）。
- **马尔可夫性被破坏的环节**：① 用户的真实兴趣、疲劳度、账号长期画像不在 $s$ 里（部分可观测）；② 推荐系统自身的服务端状态（探索桶、A/B 配置）影响同一 $(s,a)$ 的呈现结果；③ 用户的"新鲜感饱和"依赖未观测的曝光历史。
- **补救**：把最近 $k$ 步历史打包进状态（第 3 章 DQN 堆 4 帧的同款思路）；加入"该物品对该用户的近 7 天曝光次数"作为状态分量（补救饱和效应）；工程上用信念状态/用户嵌入近似隐变量。若上述仍不满足，严格处理要上 POMDP 或记忆机制（第 5 章进阶方向）。

**评分要点**：状态、动作、奖励具体可操作（能写成代码里的字段），破坏点指到"哪个信息缺失"而不是空谈"现实中很复杂"。

## 1-3 计算：γ=0.95 的一维链条（对应 1.7.1 节）

> 题目：一维链条改为 γ=0.95，重算 v(0), v(1), v(2)（校验值：v(0)≈5.72）。

**完整推导**（右移是唯一合理动作，目标格 3 终止、进入得 +10，其余每步 −1）：

$$v(3)=10 \quad\text{（终止格，无后继）}$$
$$v(2)= -1 + 0.95\times v(3) = -1 + 9.5 = 8.5$$
$$v(1)= -1 + 0.95\times v(2) = -1 + 0.95\times 8.5 = -1 + 8.075 = 7.075$$
$$v(0)= -1 + 0.95\times v(1) = -1 + 0.95\times 7.075 = -1 + 6.72125 = 5.72125 \approx 5.72$$

**自洽性检验**（照抄 1.7.1 的做法）：若在 0 格引入"左移"（原地不动拿 −1），其备选值为 $-1+0.95\times 5.72125 = 4.435 < 5.721$，贪心仍选右移，账本自洽。

**与校验值对照**：$v(0)=5.72125\approx 5.72$，与正文一致（数值复核：Python 直算 $5.72125$）。注：这里每个 $v$ 是"净折价"的精确分数，如 $v(0) = -\frac{1-0.95^3}{0.05} + 0.95^3\cdot 10$，可用该闭式自查。

## 1-4 推导：从 v–q 关系导出贝尔曼期望方程（对应 1.4.1–1.4.2 节）

> 题目：从 $v^\pi(s)=\sum_a \pi(a|s)q^\pi(s,a)$ 与 $q^\pi$ 的贝尔曼方程出发，写出只含 $v^\pi$ 的方程，验证与定理 1.1 一致。

**推导（每步依据随行）**

已知 $q^\pi$ 的贝尔曼方程（1.4.2 节末式）：

$$q^\pi(s,a)=\sum_{s'} P(s'\mid s,a)\Big[ r(s,a,s') + \gamma \sum_{a'} \pi(a'\mid s')\, q^\pi(s',a') \Big]$$

**第 1 步**：识别内层和就是 $v$–q 关系在 $s'$ 处的取值：

$$\sum_{a'} \pi(a'\mid s')\, q^\pi(s',a') = v^\pi(s') \qquad \text{（1.4.1 节定义式，把 } s \text{ 换成 } s'\text{）}$$

**第 2 步**：代回 $q^\pi$ 方程：

$$q^\pi(s,a)=\sum_{s'} P(s'\mid s,a)\big[ r(s,a,s') + \gamma\, v^\pi(s') \big]$$

**第 3 步**：再代回 $v$–q 关系：

$$v^\pi(s)=\sum_a \pi(a\mid s)\sum_{s'} P(s'\mid s,a)\big[ r(s,a,s') + \gamma\, v^\pi(s') \big]$$

这正是定理 1.1。**注意推理方向**：正文 1.4.2 是从 $G_t$ 的递归式直接推 $v^\pi$；本题是反向——先承认 $q$ 方程与 $v$–q 关系，说明二者自洽。两条路合起来证明 $v$ 方程与 $q$ 方程是同一账本的两种记法。第 1 步用到的 $\pi$ 与 $P$ 均与时变无关（时不变性），第 3 步交换求和次序对有限集恒成立。

## 1-5 证明：策略改进定理（对应 1.5.1 节）

> 题目：证明单步不等式 $q^\pi(s,\pi'(s))\ge v^\pi(s)$ 如何推出 $v^{\pi'}(s)\ge v^\pi(s)$。

**证明**（设 $\pi'$ 是对 $q^\pi$ 贪心的确定性策略，即 $\pi'(s)=\arg\max_a q^\pi(s,a)$）

**第 1 步**（单步不等式）：由 argmax 的定义，
$$q^\pi(s,\pi'(s)) = \max_a q^\pi(s,a) \ge \sum_a \pi(a|s)q^\pi(s,a) = v^\pi(s).$$

**第 2 步**（把 $v^{\pi'}$ 拆成"一步 $q^\pi$ + 修正项"）：由 $v^{\pi'}$ 的贝尔曼期望方程（对 $\pi'$ 展开）与 $q^\pi(s,\pi'(s))$ 的定义（对 $\pi$ 的后继展开）：

$$v^{\pi'}(s)=\sum_{s'}P(s'|s,\pi'(s))\big[r(s,\pi'(s),s')+\gamma v^{\pi'}(s')\big]$$
$$q^\pi(s,\pi'(s))=\sum_{s'}P(s'|s,\pi'(s))\big[r(s,\pi'(s),s')+\gamma v^\pi(s')\big]$$

两式相减（前一项相同，消掉）：

$$v^{\pi'}(s)=q^\pi(s,\pi'(s))+\gamma\sum_{s'}P(s'|s,\pi'(s))\big[v^{\pi'}(s')-v^\pi(s')\big].$$

**第 3 步**（反复代入第 2 步的不等式，对 $k$ 归纳）：由第 1 步与第 2 步，

$$v^{\pi'}(s)\ \ge\ v^\pi(s)+\gamma\sum_{s'}P(s'|s,\pi'(s))\big[v^{\pi'}(s')-v^\pi(s')\big].$$

对右边第二项中的每个 $s'$ 重复第 1 步的不等式（$v^{\pi'}(s')\ge q^\pi(s',\pi'(s'))$），再像第 2 步那样展开，得

$$v^{\pi'}(s)\ \ge\ v^\pi(s)+\gamma\,\mathbb{E}_{\pi'}\big[v^{\pi'}(S_1)-v^\pi(S_1)\mid S_0=s\big]
\ \ge\ v^\pi(s)+\gamma\,\mathbb{E}_{\pi'}\Big[\gamma\,\mathbb{E}\big[v^{\pi'}(S_2)-v^\pi(S_2)\big]\Big]=v^\pi(s)+\gamma^2\mathbb{E}_{\pi'}\big[v^{\pi'}(S_2)-v^\pi(S_2)\big],$$

其中 $S_1,S_2$ 是按 $\pi'$ 从 $s$ 出发的轨迹状态；第二个不等号对轨迹逐段使用第 2 步的不等式（每次仍是"一步改进 + 折扣修正"）。归纳 $k$ 步：

$$v^{\pi'}(s)\ \ge\ v^\pi(s)+\gamma^{k}\,\mathbb{E}_{\pi'}\big[v^{\pi'}(S_k)-v^\pi(S_k)\mid S_0=s\big].$$

**第 4 步**（取极限）：价值函数有界（$|v|\le R_{\max}/(1-\gamma)$，1.3 节），故

$$v^\pi(s)\ \le\ v^{\pi'}(s)+\gamma^{k}\cdot\frac{2R_{\max}}{1-\gamma}\quad\forall k\ \xrightarrow{k\to\infty}\ v^\pi(s)\le v^{\pi'}(s).\qquad\blacksquare$$

**常见错误**：直接写 $v^{\pi'}(s)\ge q^\pi(s,\pi'(s))\ge v^\pi(s)$ 然后结束——第一段的 $\ge$ 事实上不成立（$v^{\pi'}$ 里含的是 $v^{\pi'}(s')$ 而不是 $v^\pi(s')$，除非已经知道结论）；必须像上面那样用"展开相减 + 归纳 + 截断取极限"。

## 1-6 证明：压缩映射的 Lipschitz 部分（对应 1.5.2 节，定理 1.3）

> 题目：证明 $\max_a f(a)-\max_a g(a)\le\max_a|f(a)-g(a)|$，并由此完成定理 1.3 的完整证明。

**第一部分：max 是 1-Lipschitz 的**

记 $a^*=\arg\max_a f(a)$。对任意 $a$ 有 $g(a)\le f(a)+|f(a)-g(a)|$，特别地

$$\max_a g \ \ge\ g(a^*)\ \ge\ f(a^*)-|f(a^*)-g(a^*)|\ =\ \max_a f - |f(a^*)-g(a^*)|\ \ge\ \max_a f-\max_a|f-g|.$$

移项即 $\max_a f-\max_a g\le\max_a|f-g|$。交换 $f,g$ 得对称式，故 $|\max f-\max g|\le\max|f-g|$。$\blacksquare$

**第二部分：$\mathcal{T}$ 是 γ-压缩**

定义 $(\mathcal{T}v)(s)=\max_a\sum_{s'}P(s'|s,a)[r(s,a,s')+\gamma v(s')]$。固定 $s$，记

$$h_v(a)=\sum_{s'}P(s'|s,a)\big[r(s,a,s')+\gamma v(s')\big],\qquad h_w(a)\text{ 同理（}v\text{ 换成 }w\text{）}.$$

由第一部分（把 $f,g$ 取为 $h_v,h_w$ 的切片再对 $s$ 取 max）：

$$\|\mathcal{T}v-\mathcal{T}w\|_\infty=\max_s\big|\max_a h_v(a)-\max_a h_w(a)\big|\ \le\ \max_s\max_a\big|h_v(a)-h_w(a)\big|.$$

而

$$|h_v(a)-h_w(a)|=\Big|\sum_{s'}P(s'|s,a)\,\gamma\big(v(s')-w(s')\big)\Big|\ \le\ \gamma\sum_{s'}P(s'|s,a)\,|v(s')-w(s')|\ \le\ \gamma\max_{s'}|v(s')-w(s')|,$$

最后一步用 $\sum_{s'}P(s'|s,a)=1$（凸组合不超最大分量）。对 $s,a$ 取 max 得 $\|\mathcal{T}v-\mathcal{T}w\|_\infty\le\gamma\|v-w\|_\infty$。

**第三部分：收敛性**（Banach 不动点论证，与《最优化方法》第 2 章迭代法同款）：$\mathbb{R}^{|\mathcal{S}|}$ 配 sup 范数是完备度量空间；$\mathcal{T}$ 是 $\gamma<1$ 的压缩，故有唯一不动点 $v^*$，且

$$\|v_k-v^*\|_\infty=\|\mathcal{T}v_{k-1}-\mathcal{T}v^*\|_\infty\le\gamma\|v_{k-1}-v^*\|_\infty\le\cdots\le\gamma^k\|v_0-v^*\|_\infty,$$

即线性收敛率 $\gamma$；达到 $\epsilon$ 精度需 $k\ge\frac{\log(1/\epsilon)}{1-\gamma}$ 次扫描（对数上界）。$\blacksquare$

## 1-7 挑战题：max 与期望的交换（对应 1.4.3 节）

> 题目：构造两个动作的决策问题，使 $\max_a\mathbb{E}[X_a]>\mathbb{E}[\max_a X_a]$（一次选定 vs 看结果再选），并解释贝尔曼最优方程为何在 MDP 中没有这个问题。

**⚠ 先勘误**：题面不等号方向**写反了**。对任意随机变量族，$\max_a X_a\ge X_a$（逐点），取期望得 $\mathbb{E}[\max_a X_a]\ge\max_a\mathbb{E}[X_a]$ 恒成立——"max_π E > E[max]"不可能构造出来。正文 1.4.3 节那句"对期望价值取 max，交换次序一般有 $\max_\pi \mathbb{E}[X]\ge\mathbb{E}[\max X]$ 的间隙"同样应更正为"$\max_\pi \mathbb{E}[X]\le\mathbb{E}[\max X]$，一般有严格间隙"（数值验证：随机模拟 $10^6$ 次可确认 $\mathbb{E}[\max]-\max\mathbb{E}\ge 0$ 恒成立）。

**正确方向的构造**（"一次选定"严格劣于"看结果再选"）：动作 1 得确定值 $X_1=0$；动作 2 得 $X_2=+1$ 或 $-1$，概率各 $1/2$。

- 一次选定（必须先承诺动作）：最优是选动作 1，$\max_a\mathbb{E}[X_a]=\max(0,0)=0$；
- 看结果再选（事后按实现值挑最好的）：$\mathbb{E}[\max(X_1,X_2)]=\mathbb{E}[\max(0,X_2)]=\tfrac12\cdot 1+\tfrac12\cdot 0=0.5$。

$0<0.5$：适应性选择严格更好。（数值验证：蒙特卡洛估计 $\mathbb{E}[\max]=0.500\pm 0.001$。）

**为什么贝尔曼最优方程在 MDP 中没有这个问题**：贝尔曼最优方程里的 max 恰好是"看结果再选"的那一侧——当前动作 $a$ 决定下一状态分布，**而未来的动作可以在看到 $s'$ 之后按 $\pi^*(\cdot|s')$ 再选**（$\gamma\max_{a'}q^*(s',a')$ 这个 max 在对 $s'$ 的期望**里面**）。也就是说，MDP 的序贯结构允许的承诺粒度恰好是"每步一选"，与方程中"外层 max 在内层期望之前、内层 max 在 $s'$ 之后"的次序完全匹配：

$$v^*(s)=\max_a\Big[r+\gamma\,\mathbb{E}_{s'}\big[\max_{a'}(\cdots)\big]\Big]$$

外层是"这一步必须先选"（max 在期望外），内层是"下一步看到 $s'$ 再选"（max 在期望内）——没有"现在就要为未来全部步骤一次性承诺"的 anticipativity 缺口。而 1-7 构造里的问题只有一步、"看结果再选"在物理上不合法，所以"合法最优"（0）低于"事后最优"（0.5）。

## 1-8 编程：带风的网格世界（对应 1.7.2 节）

> 题目：给 GridWorld 加"风"——在 col=2 这列，执行任意动作后额外向上飘一格（撞天花板除外）。修改后最优策略如何变化？V(起点) 变成多少（校验值：γ=0.99 时应小于 90.20）？

**参考实现（已运行验证）**

```python
# windy_gridworld.py —— 第 1 章练习 8：col=2 有上飘风的 4x4 网格世界
import numpy as np

class WindyGrid:
    """4x4：goal(3,3)=+100，pit(1,1)=-10，每步-1，撞墙原地。
    风规则：若当前格位于 col==2，执行动作后（若结果格非终止）额外上飘一格（撞天花板钳在 0 行）。"""
    def __init__(self):
        self.acts = [(-1, 0), (1, 0), (0, -1), (0, 1)]   # 上、下、左、右
        self.term = {15, 5}                              # goal(3,3)=15, pit(1,1)=5
    def step(self, s, a):
        if s in self.term: return s, 0.0, True
        r, c = divmod(s, 4); dr, dc = self.acts[a]
        nr, nc = min(max(r + dr, 0), 3), min(max(c + dc, 0), 3)
        ns = nr * 4 + nc
        if ns == 15: return ns, 100.0, True
        if ns == 5:  return ns, -10.0, True
        if c == 2:                                       # 风列：动作后上飘一格
            nr = max(nr - 1, 0); ns = nr * 4 + nc        # 撞天花板则不动
            if ns == 15: return ns, 100.0, True
            if ns == 5:  return ns, -10.0, True
        return ns, -1.0, False

def value_iteration(env, gamma=0.99, theta=1e-10):
    V = np.zeros(16)
    for k in range(5000):
        delta = 0.0
        for s in range(16):
            if s in env.term: continue
            q = [env.step(s, a)[1] + gamma * (0.0 if env.step(s, a)[2] else V[env.step(s, a)[0]])
                 for a in range(4)]
            delta = max(delta, abs(max(q) - V[s])); V[s] = max(q)
        if delta < theta: break
    return V, k + 1

V, k = value_iteration(WindyGrid())
print(f"V(起点) = {V[0]:.4f}, 收敛轮数 = {k}")
for r in range(4): print(" ".join(f"{V[r*4+c]:7.2f}" for c in range(4)))
```

**预期输出（实际运行结果）**

```text
V(起点) = 90.1980, 收敛轮数 = 7
  90.20   92.12   94.06   96.02
  92.12    0.00   94.06   98.00
  94.06   96.02   96.02  100.00
  96.02   98.00  100.00    0.00
```

最优策略变化：起点仍向下，但 $(0,1),(1,2),(2,2)$ 处由"↓"改为"→"——中间格列穿过风列会被吹回去，最优路线改为"沿行绕行、最后从 $(3,2)$ 一步进入目标（进入终止格不受风）"或"贴着 0 行走（天花板把风抵消）"。

**结论与勘误**：两种自然解释（风按"当前格在 col=2"或按"落点在 col=2"）下，$V(\text{起点})$ 都**保持 $90.1980$ 不变**——因为顶部一行有天花板护体、底部一行从 $(3,2)$ 进入目标那步是终止步不受风，最优路线总能绕开风的代价。正文"γ=0.99 时应小于 90.20"数值上成立（$90.198<90.20$），但并非严格变小；风真正改变的是中间格列的价值（如 $V(1,2)$：$96.02\to 94.06$，$V(2,2)$：$98.00\to 96.02$，各被吹掉约一步的折价）与策略箭头。另请对照附录 A 勘误 2：与本题相关的"88.296/88.30"锚点值是数错步数（7 步）的产物。

## 1-10 挑战题：修改版策略迭代（对应 1.5 节、GPI）

> 题目：实现"每轮评估只做 1 次 sweep"的混合算法，对比与标准价值迭代的总 sweep 次数与最终精度，写 200 字总结。

**参考实现**：在 1-8 的 `value_iteration` 基础上加一个外层策略保持循环——每轮先做 1 次同步 sweep 的"评估"（实现里直接用贪心 max 更新，等价于把评估与改进合成一步），再做策略提取，直到策略稳定：

```python
def modified_policy_iteration(env, gamma=0.99, theta=1e-10):
    V = np.zeros(16); pi = np.zeros(16, dtype=int); sweeps = 0
    for outer in range(500):
        for s in range(16):                       # 每轮仅 1 次 sweep（就地 Gauss–Seidel 更新）
            if s in env.term: continue
            V[s] = max(qvals(env, s, a, gamma, V) for a in range(4))
        sweeps += 1
        stable = all(pi[s] == int(np.argmax([qvals(env, s, a, gamma, V) for a in range(4)]))
                     for s in range(16) if s not in env.term)
        if stable: break                          # 策略不再变化 → 收敛
    return V, pi, sweeps
```

**实际运行结果**（4x4 网格世界，γ=0.99）：价值迭代收敛于 **7 次 sweep**，修改版策略迭代 **6 次 sweep**，两者最终 $V$ 的最大差为 $0.00$（同一收敛点）。

**200 字总结**：在本例上，修改版反而比标准价值迭代少 1 次 sweep，因为两者的 sweep 内容相同（贪心 max 更新），差别只在停止准则——价值迭代看 $\Delta<\theta$，修改版看策略稳定，后者在这张小网格上恰好更早满足。这个结果提醒我们：广义策略迭代（GPI）里"评估"与"改进"的边界本来就可以任意划——把评估做到完全收敛（策略迭代）、做一步（价值迭代/修改版）或做半步，只要两者互相追赶不脱节，最终都收敛到 $v^*,\pi^*$。sweep 次数不是算法优劣的本质：真正要比较的是"每次 sweep 的代价 × 次数"，以及在大问题上评估与改进谁能更早提供有用信号。当评估一次很贵（模型大）时，少评估多改进的截断式方案占优。

# 第 2 章 无模型方法：Monte Carlo 与时序差分（对应正文 2.12 节）

## 2-1 概念辨析：MC 无偏大方差 vs TD 有偏小方差（对应 2.3.2 节）

> 题目：从"目标中含多少随机量的真实值、多少估计值"的角度各写一句解释。

**标准答案要点**

- **MC**：更新目标 $G_t$ **100% 是真实采样值**——它不含任何估计量，所以条件在状态上的期望就是 $v^\pi(s)$（无偏）；但它的随机性包含从 $t$ 起每一步的动作采样与状态转移的**全部**随机量，方差 $\propto$ 剩余轨迹长度的平方量级（大方差）。
- **TD**：目标 $R_{t+1}+\gamma V(S_{t+1})$ 中只有 $R_{t+1},S_{t+1}$ 这**一步**是真实随机量，其余未来全部被当前估计 $V(S_{t+1})$ 顶替——估计值替换真值带来偏差（偏差 = $\gamma(V(S_{t+1})-v^\pi(S_{t+1}))$）；但随机量只剩一步，方差小得多。

**常见错误答案为什么错**

- "TD 无偏，因为 $V$ 最终会收敛到真值"：这是**渐近**性质；在收敛之前的每一步，目标里都含过时的 $V$，单步更新是**有偏**的。混淆"渐近无偏"与"单步无偏"是最常见的概念错误。
- "MC 有偏，因为只采样了一条轨迹"：采样导致的波动是**方差**不是偏差；样本均值对期望是无偏的（大数定律）。
- 反过来写"MC 方差小"：忽略了 $G_t$ 复合了整条轨迹的随机性。

## 2-2 手算：一步 TD 更新（对应 2.7.1 节）

> 题目：γ=0.9, α=0.2，V(s)=3.0，单步 r=+2 到 s′ 且 V(s′)=1.0。求 δ 与更新后的 V(s)（校验值：V(s)=2.98）。

**完整推导**

$$\delta = r + \gamma V(s') - V(s) = 2 + 0.9\times 1.0 - 3.0 = 2 + 0.9 - 3.0 = -0.1$$
$$V(s) \leftarrow V(s) + \alpha\,\delta = 3.0 + 0.2\times(-0.1) = 3.0 - 0.02 = \boxed{2.98}$$

**解读**：$\delta=-0.1<0$ 说明"这一步 +2、邻居自估 1.0"比当前账面 3.0 还要差一点——虽然拿到的即时奖励是正的，但下一状态的（自估）价值太低，账本朝下调 0.02。对比 2.7.1 的例子（$\delta=+1.2$ 向上调）：TD 误差的符号完全由"这一步甜头 + 折扣邻居"联合决定，**正的即时奖励不保证正的 TD 误差**。

**与校验值对照**：$2.98$，与正文一致（Python 复核：`2 + 0.9*1.0 - 3.0 = -0.1; 3.0 + 0.2*(-0.1) = 2.98`）。

## 2-3 为什么无模型控制必须学 q 而非 v（对应 2.2、2.4 节）

**答案要点**

- 策略改进需要 $\pi'(s)=\arg\max_a$ "先走 $a$ 再按现策略走下去"的价值，即 $q$。有模型时可以从 $v$ 算出它：$q(s,a)=\sum_{s'}P(s'|s,a)[r+\gamma v^\pi(s')]$（1.4 节 $v$–$q$ 关系）。**免模型时 $P,r$ 未知，这个和算不出来**——$v(s)$ 只是一个数，不含"不同动作后果"的信息，无法在动作之间比较。所以无模型控制一律学 $q$（2.8 节陷阱 3）。
- 若手头有环境模型，$v$ 又够用了：有了 $P,r$，一个状态的 $v^\pi(s)$ 就足以完成策略评估，而策略改进所需的 $q(s,a)$ 随时可以用模型的一步展开算出——这正是第 1 章策略迭代用 $v$ 的原因（模型已知）。
- 一句话：**$q$ 是"把动作选择权留在账本里"的记法；没有模型时只能用采样把它记下来，有模型时可以随时现算。**

## 2-4 证明：固定 ε 的 SARSA 收敛不到 π*，GLIE 如何修复（对应 2.4、2.5.2 节）

**证明**

设 $\pi_\varepsilon$ 为固定 $\varepsilon>0$ 的 ε-greedy 软策略。SARSA 是 on-policy 的 TD 控制，收敛目标是**当前行为策略的价值** $q^{\pi_\varepsilon}$（2.5.2 节），即其不动点满足

$$q^{\pi_\varepsilon}(s,a)=\sum_{s'}P(s'|s,a)\big[r+\gamma\,\mathbb{E}_{a'\sim\pi_\varepsilon(\cdot|s')}q^{\pi_\varepsilon}(s',a')\big].$$

第 2 步说明 $v^{\pi_\varepsilon}$ 一般严格劣于 $v^*$：在任一存在次优动作的状态 $s$（$q^*(s,a^\text{sub})<\max_{a'}q^*(s,a')$），$\pi_\varepsilon$ 以至少 $\varepsilon/|\mathcal{A}|>0$ 的概率选择次优动作，于是

$$v^{\pi_\varepsilon}(s)=\sum_a\pi_\varepsilon(a|s)q^{\pi_\varepsilon}(s,a)<\max_a q^{\pi_\varepsilon}(s,a)\le v^*(s),$$

（第一个 $<$ 因为概率质量分配在两个不同价值的动作上且 $\varepsilon>0$ 固定）。所以固定 ε 的 SARSA 收敛到"$\varepsilon$-greedy 的最优"而非全局最优——Cliff Walking 上它绕开悬崖正是这个机制的体现。$\blacksquare$

**GLIE 的修复**：GLIE 要求 (i) $\varepsilon_t\to 0$；(ii) 每个 $(s,a)$ 仍被无限访问。线性衰减 $\varepsilon_t=1/t$ 即满足。(i) 使软策略序列 $\pi_{\varepsilon_t}$ 逐点收敛到贪心策略 $\pi^*$（$\varepsilon\to 0$ 时随机质量消失）；(ii) 保证所有 $(s,a)$ 的 TD 误差持续被采样、估计不被冻结。两者合起来，SARSA 的不动点序列 $\{q^{\pi_{\varepsilon_t}}\}$ 逼近 $q^*$，从而收敛到 $q^*$，其贪心即 $\pi^*$。**注意**：即便收敛，训练中的软策略仍带随机性、永远不是 $\pi^*$ 本身（2.4 节："脚手架"比喻）——部署时用从 $Q$ 读出的确定性贪心。

## 2-5 最大化偏差的例子与 Double Q（对应 2.5.2 节）

> 题目：举一个具体状态-动作分布的例子，验证 $\mathbb{E}[\max(\hat X_1,\hat X_2)]\ge\max(\mathbb{E}\hat X_1,\mathbb{E}\hat X_2)$，并说明 Double Q-learning 如何消除它。

**例子**：两个动作真值均为 0，估计 $\hat X_1,\hat X_2$ 独立 $\sim\mathcal{N}(0,1)$。则 $\max(\mathbb{E}\hat X_1,\mathbb{E}\hat X_2)=0$，而

$$\mathbb{E}[\max(\hat X_1,\hat X_2)]=\mathbb{E}[\max(Z_1,Z_2)],\quad Z_i\ \text{iid}\ \mathcal{N}(0,1).$$

$\max(Z_1,Z_2)=(Z_1+Z_2+|Z_1-Z_2|)/2$，故 $\mathbb{E}[\max]=\frac{1}{2}\mathbb{E}|Z_1-Z_2|=\frac{1}{2}\cdot\frac{2}{\sqrt\pi}=\frac{1}{\sqrt\pi}\approx 0.564>0$。（数值复核：$10^6$ 次模拟得 $0.5642$；第 3 章 3.7.2 的 10 动作版本平均偏差 $+1.539$，动作越多、噪声越大，偏差越大。）

**Double Q 的修复——选择与评估分离**：维护两套独立估计 $Q_A,Q_B$，每步随机更新其一：

- 选动作：$a^*=\arg\max_a Q_A(s',a)$（用 $Q_A$ 的噪声做决定）；
- 定价值：目标用 $Q_B(s',a^*)$（评估权交给另一套独立噪声）。

由于 $a^*$ 的选择依赖 $Q_A$ 的噪声而 $Q_B(s',a^*)$ 的噪声与之**独立**，$\mathbb{E}[Q_B(s',a^*)]=q(s',a^*)$ 条件在 $Q_A$ 上仍无偏——"被噪声推上去的候选"不再"恰好是估值最高的那个"。第 3 章 Double DQN 把 $Q_A,Q_B$ 换成在线网络与目标网络，同一思想。若只有一套网络的两次独立前向仍相关（同一参数），消偏不彻底——这是 Double DQN 只"缓解"而非"根除"过估计的原因。

## 2-9 开放思考：医疗决策为何必须离线（对应 2.4、2.9 节；第 5 章预告）

**参考论证（要点分层）**

1. **on-policy 的定义性缺陷**：on-policy TD（SARSA/AC）的数据分布 = 当前行为策略的分布。它要学习就必须**持续用当前策略与环境交互**，而策略改进又要求不断尝试非贪心动作——在医疗里，"探索"= 对真实病人执行未经验证的诊疗。第 2 章 Cliff Walking 里探索的代价是 −100 分，医疗里是真实的伤害，**不可逆、不可回滚**。
2. **探索-利用权衡在此不可接受**：ε-greedy 的探索是"盲目均匀"的（2.4 节），医疗场景连"一次"次优动作都可能违反伦理/法规；on-policy 框架没有把"数据来自哪里"与"部署什么策略"分离的机制。
3. **离线路线的对应解法**：训练只用历史日志（既有诊疗记录），策略在数据集上学习（第 5 章 CQL 等）——分布偏移用保守价值估计兜底；评估用离线策略评估（OPE，重要性采样，2.11 节预告）预估上线效果，再用小规模灰度试验而非全量试错。
4. **残余问题（加分项）**：历史数据的策略与未来部署环境的混杂（治疗选择偏差）、覆盖不足时的外推风险——这正是第 5 章"数据质量决定上限"与 CQL 保守性的动机。

**评分要点**：必须点出 on-policy 的哪个性质不可接受——"学习数据必须由被评估/部署的策略生成（且要含探索动作）"，而不能只泛泛说"医疗不能试错"。

## 2-10 挑战题：Q-learning 收敛证明的三个关键步骤（对应 2.5.2 节；Watkins 1989 / S&B）

**解答路线（三步 + 表格表示的依赖点）**

1. **改写成随机逼近框架**：Q 更新 $Q(s,a)\leftarrow(1-\alpha)Q(s,a)+\alpha\big[r+\gamma\max_{a'}Q(s',a')\big]$ 是对贝尔曼**最优**算子 $\mathcal{T}q$ 的随机不动点迭代；$\alpha$ 满足 Robbins-Monro 条件（$\sum\alpha_t=\infty,\ \sum\alpha_t^2<\infty$）——与《最优化方法》第 5 章 SGD 收敛同骨架。
2. **压缩性**：贝尔曼最优算子是 γ-压缩（第 1 章定理 1.3），且 Q-learning 目标是该算子的**无偏采样**：$\mathbb{E}[r+\gamma\max_{a'}Q(s',a')\mid s,a]=\mathcal{T}Q(s,a)$（max 与期望交换在这里合法，因为转移由 $(s,a)$ 决定——第 1 章练习 7 的结构）。随机逼近 + 压缩 ⇒ $\|Q_t-q^*\|\to 0$ w.p.1。
3. **访问条件**：每个 $(s,a)$ 无限次被更新（行为策略充分探索），且奖励有界、$Q$ 的更新间不"过期"（$\alpha$ 对每对独立衰减）。否则某些 entry 停在初值附近，压缩论证只对被更新集合成立。

**在哪一步依赖表格表示**：第 2 步。表格情形下每个 $Q(s,a)$ 是独立存储的坐标，压缩映射在 $\mathbb{R}^{|\mathcal{S}||\mathcal{A}|}$ 的 sup 范数上逐坐标成立；用函数近似后，一次更新 $\mathbf{w}\leftarrow\mathbf{w}+\alpha\delta\nabla\hat q$ 通过参数共享**同时**改动所有状态的估值，"算子是压缩"不再对参数空间成立（目标还随 $\mathbf{w}$ 移动），且 off-policy 的数据分布与自举传播方向脱节时平均更新算子谱半径可超过 1——这正是第 3 章致命三要素（Baird 反例）的入口，需要重新论证或改用不依赖该论证的方法（第 4 章策略梯度）。

# 第 3 章 值函数近似与 DQN（对应正文 3.12 节）

## 3-1 概念辨析：去掉哪一个要素就安全（对应 3.3 节）

> 题目：(a) 监督回归；(b) 表格 Q-learning；(c) on-policy 线性 TD——各去掉致命三要素中的哪一个？

**标准答案要点**

- **(a) 监督回归：去掉"自举"**。标签 $y$ 是外生数据，不含任何自身估计；目标静止，SGD 收敛理论直接适用（自举=用自己当前的输出当标签的一部分，监督学习没有）。
- **(b) 表格 Q-learning：去掉"函数近似"**。每个 $(s,a)$ 独立存储，更新一个坐标不牵动别的坐标；加上每个 $(s,a)$ 无限访问，即回到第 2 章 Watkins 收敛定理（该定理本质不需要函数近似）。
- **(c) on-policy 线性 TD：去掉"off-policy"**。数据分布 μ = 当前策略的分布，自举的传播方向与数据权重匹配，Tsitsiklis & Van Roy (1997) 证明收敛到投影最优（3.2.2 节"近似损耗"）。

**共同结论**：三要素**两两基本无害，三者叠加**（DQN：自举 + 神经网络 + replay 的 off-policy 数据）才构成正反馈回路。**常见错误**：把 (b) 归因为"去掉 off-policy"——表格 Q-learning 恰恰是 off-policy 的却收敛，说明 off-policy 单独不致命；把 (c) 归因为"去掉自举"——on-policy TD 显然自举却收敛。

## 3-2 推导：线性半梯度 TD(0) 与 LMS 的异同（对应 3.2.2 节）

**推导**：$\hat v(s;\mathbf{w})=\mathbf{x}(s)^\top\mathbf{w}$，$\nabla_{\mathbf{w}}\hat v=\mathbf{x}(s)$。代入半梯度 TD(0) 更新

$$\mathbf{w}\leftarrow\mathbf{w}+\alpha\big[\underbrace{R_{t+1}+\gamma\,\mathbf{x}(S_{t+1})^\top\mathbf{w}-\mathbf{x}(S_t)^\top\mathbf{w}}_{\delta_t}\big]\mathbf{x}(S_t).$$

**与 LMS 的相同点**：形式同为"估计 ← 估计 + 步长 ×（目标 − 预测）× 特征"，都是单个样本的随机梯度式更新；取 $\gamma=0$ 且把 $R_{t+1}$ 视作固定标签时完全退化为 LMS。

**不同点（两条，缺一不可）**：

1. **目标随参数移动**：LMS 的标签 $y$ 是外生常量；TD 目标里的 $\gamma\,\mathbf{x}(S_{t+1})^\top\mathbf{w}$ 自己含 $\mathbf{w}$。半梯度**忽略**目标一侧的梯度项 $\gamma\,\mathbf{x}(S_{t+1})$——若不忽略，梯度应为 $\big[\delta_t-\gamma\,\mathbf{x}(S_{t+1})^\top\mathbf{w}+\ldots\big]$ 的完整展开（对复合目标 $(R+\gamma\hat v(s')-\hat v(s))^2$ 完整求导），那就不是对任何固定目标的下降方向。所以"半"= 不是任何一个固定目标函数的 SGD。
2. **收敛点不同**：LMS 收敛到最小均方解；on-policy 线性半梯度 TD 收敛到**投影最优** $\mathbf{w}^*$——$\mu$ 度量下最接近 $v^\pi$ 的线性投影（Tsitsiklis & Van Roy），不是 $v^\pi$ 本身（3.2.2 节"近似损耗"）。off-policy 时连这个结论也失效（3-9 题 Baird 反例）。

## 3-3 手算：线性半梯度更新（对应 3.7.1 节）

> 题目：把 3.7.1 的 α 改为 0.2、r 改为 −1，重算更新后的 w（校验值：w=[0.38, −0.24]ᵀ）。

**完整推导**：$\hat v(s)=\mathbf{x}(s)^\top\mathbf{w}=[1,2]^\top[1,1]=3$；$\hat v(s')=[0,1]^\top[1,1]=1$。

$$\delta = r+\gamma\hat v(s')-\hat v(s) = -1 + 0.9\times 1 - 3 = -3.1$$
$$\mathbf{w}\leftarrow[1,1]^\top + 0.2\times(-3.1)\times[1,2]^\top = [1-0.62,\ 1-1.24]^\top = \boxed{[0.38,\ -0.24]^\top}$$

**与校验值对照**：$[0.38,-0.24]$，与正文一致（Python 复核：`delta=-1+0.9*1-3=-3.1; w=[1,1]+0.2*(-3.1)*np.array([1,2])=[0.38,-0.24]`）。解读同 3.7.1：负的大 TD 误差把所有与 $s$ 特征相近状态的估值都拉低——泛化与误差扩散是同一件事。

## 3-4 经验回放与目标网络为何只"缓解"（对应 3.3–3.4 节）

**答案要点**

- **经验回放缓解了什么**：① 打破时序相关性，给 SGD 近 i.i.d. 批量；② 数据复用，样本效率；③ 平滑数据分布，抑制策略突变引起的分布漂移。**为什么不能根除**：三要素一个都没关掉——replay 里的数据仍然来自旧的自身策略（off-policy 本质未变，μ≠π）；TD 目标仍然由自己的（旧）估计生成（自举未断）；一次梯度更新仍通过共享参数牵动所有状态（函数近似仍在）。replay 只是让"喂给更新算子的分布"更平稳，没有改变更新算子本身。
- **目标网络为什么只"延缓"**：目标冻结期间，标签静止，问题退化成对固定目标的回归（安全）；但每隔 C 步（或按 τ 软更新）把在线参数接回目标——正反馈回路**周期性重新闭合**。同步瞬间目标突然跳变，误差不被消除而是被"限幅 + 延迟"。此外目标网络的滞后使目标系统性地"追赶"在线网络，即使收敛，收敛点也带有滞后偏差。**诚实结论（3.3 节）**：没有一般性定理保证深度 off-policy 自举收敛；DQN 的稳定是工程组合（回放 + 目标网络 + Huber + 裁剪 + 软更新）把发散速率压到训练可完成，不是理论消除。

## 3-6 编程：Double DQN（对应 3.5 节）

## 3-8 开放思考：DQN 的泛化危机（对应 3.1、3.3 节；Kirk et al. 2023）

**参考论述（约 300 字，三层归因）**

这是三个层面叠加的问题，权重依次是基准设计 > 社区文化 > 算法。**算法层面**：RL 的数据分布由当前策略生成，学习目标、表征与数据三者耦合（第 2 章开头的"自我指涉"论断），智能体天然会把容量花在"当前环境可利用的规律"上——DQN 甚至会过拟合到奖励函数的实现细节（分数与像素纹理的虚假相关）。但监督学习同样过拟合，算法并非独罪。**基准设计层面**（首要）：Atari 每个游戏是单一固定环境，训练=测试，"泛化"根本没被考核；Procgen、Bongard 类实验表明在训练环境的高分与真实能力可以完全脱钩（第 5 章 5.7 节），说明问题主要是**度量缺失**而非能力缺失。**社区文化层面**：排行榜导向导致逐环境调参、单种子报点、把基准分数当研究目标（Goodhart 定律在学术界同样生效），Kirk 等人的综述呼吁把"未见环境上的零样本/少样本表现"与种子方差写进默认报告协议。结论：DQN 同一套超参跨 49 局成功是"超参足够鲁棒"而非"会泛化"；要泛化，需要随机化环境族、跨任务评估协议与表征层面的归纳偏置——这三件事都首先是**评测问题**。

## 3-9 挑战题：Baird 反例最小复现（对应 3.3 节；S&B 例 11.4.1）

**精确结构**（注意特征矩阵的方向，这是复现成败的关键）：7 状态（上排 0–5 + 下方状态 6）；上排状态 $i$：实线动作 → 状态 6，虚线动作 → 均匀到上排；状态 6：实线 → 自环。奖励恒 0，$\gamma=0.99$。行为策略：虚线 $6/7$、实线 $1/7$（平稳分布 = 7 状态均匀）。目标策略 $\pi$：总走实线。特征（8 维）：上排 $\mathbf{x}(s_i)=2\mathbf{e}_i+\mathbf{e}_8$；状态 6：$\mathbf{x}=\mathbf{e}_7+2\mathbf{e}_8$。初值 $\mathbf{w}=(1,1,1,1,1,1,10,1)$——**上下状态的估值不对称（12 vs 3）是发散的驱动力**。

```python
# baird.py —— off-policy 半梯度 TD(0)（含重要性比 ρ，S&B 式 (11.2)）
import numpy as np
X = np.zeros((7, 8))
for i in range(6): X[i, i] = 2.0; X[i, 7] = 1.0     # 上排: 2e_i + e_8
X[6, 6] = 1.0; X[6, 7] = 2.0                         # 状态6: e_7 + 2e_8
g, w = 0.99, np.array([1., 1, 1, 1, 1, 1, 10, 1])
rng = np.random.default_rng(0); s = int(rng.integers(7))
for t in range(2000):
    a = 1 if rng.random() < 1/7 else 0               # 行为策略: 实线 1/7
    ns = 6 if a == 1 else int(rng.integers(6))       # 实线->状态6；虚线->均匀上排
    if a == 1:                                        # ρ = π(a|s)/b(a|s) = 1/(1/7) = 7
        w += 0.01 * 7.0 * (g * X[ns] @ w - X[s] @ w) * X[s]   # ρ=7 的实线步更新
    # 虚线步 ρ = 0（π 取虚线概率为 0），不更新
    s = ns
    if t % 200 == 0: print(t, round(np.linalg.norm(w), 1))
```

**实际运行结果**（off-policy，含 ρ）：


# 第 4 章 策略梯度与 Actor-Critic（对应正文 4.12 节）

## 4-1 概念辨析：样本效率 vs 动作空间（对应 4.1 节）

> 题目：值方法学 q、策略方法学 π——各用一个场景说明"谁的样本效率更高"与"谁的适用动作空间更大"。

**标准答案要点**

- **样本效率：值方法更高**。场景：Atari 游戏——DQN 用 replay buffer 把一条经验反复复用（off-policy），且自举目标让一步数据立刻产生跨状态的传播（第 2、3 章的结论链：off-policy 复用 + 自举 = 数据效率）；REINFORCE/PPO 是纯 on-policy，策略一更新旧数据作废，每批数据只用一次（PPO 的多 epoch 复用只是部分抢回，4.5 节）。
- **动作空间：策略方法更大**。场景：机械臂连续力矩控制——DQN 的 $\max_a\hat q(s,a)$ 要求枚举动作，连续动作下 max 本身是内嵌优化问题（每步代价高且不稳定）；高斯策略 $\pi_\theta(a|s)=\mathcal{N}(\mu_\theta(s),\sigma^2)$ 直接采样、梯度处处可微。离散大动作集（如词表）同理——softmax 采样天然可扩展。
- **一句话总结**：动作离散且数据贵 → 值方法/混合方法；动作连续或需要平滑随机策略 → 策略方法。**常见错误**：说"策略方法样本效率高因为直接优化目标"——直接性换来的是高方差，不是效率；说"值方法能做连续动作只要离散化"——维数灾难使离散化不可行。

## 4-2 推导补全：softmax 的 score 恒等式（对应 4.2 节）

> 题目：显式验证 $\mathbb{E}[\nabla\log\pi(a|s)]=0$。

**推导**：softmax 参数化 $\pi(a|s)=\dfrac{e^{h_\theta(s,a)}}{\sum_b e^{h_\theta(s,b)}}$，记 $\pi_a=\pi(a|s)$。分数函数：

$$\nabla_\theta\log\pi_\theta(a|s)=\nabla_\theta h_\theta(s,a)-\sum_b \pi_b\,\nabla_\theta h_\theta(s,b).$$

（第二项来自 $\log\sum_b e^{h_b}$ 的梯度：$\frac{\sum_b e^{h_b}\nabla h_b}{\sum_b e^{h_b}}=\sum_b\pi_b\nabla h_b$。）

对 $a\sim\pi$ 取期望：

$$\mathbb{E}_{a\sim\pi}\big[\nabla\log\pi(a|s)\big]=\sum_a \pi_a\Big[\nabla h_a-\sum_b\pi_b\nabla h_b\Big]=\underbrace{\sum_a\pi_a\nabla h_a}_{=\sum_b\pi_b\nabla h_b}-\underbrace{\Big(\sum_a\pi_a\Big)\sum_b\pi_b\nabla h_b}_{=\sum_b\pi_b\nabla h_b}=0.\ \blacksquare$$

**双动作数值验证**：$h=[1.0,0.0]$，$\pi=[0.731,0.269]$，$\nabla_h\log\pi(a_1)=[1-\pi_1,-\pi_2]=[0.269,-0.269]$，$\nabla_h\log\pi(a_2)=[-\pi_1,1-\pi_2]=[-0.731,0.731]$；期望 $0.731[0.269,-0.269]+0.269[-0.731,0.731]=[0,-0]$。恒等式成立——这就是引理 4.1（基线合法性）与"过去奖励不贡献梯度"论证共用的地基。

## 4-3 手算：换采样动作的一步 softmax 更新（对应 4.7.1 节）

> 题目：采样动作改为 $a_2$、$G=-1$（b 仍为 0.8），重算 Δh 与新概率 π（校验值：π₁≈0.91）。

**完整推导**：$h=[1.0,0.0]$，$\pi_1=\dfrac{e^1}{e^1+e^0}=0.731,\ \pi_2=0.269$。

对 $a_2$ 的分数函数（对照 4-2 题的通式）：$\nabla_h\log\pi(a_2|s)=[-\pi_1,\ 1-\pi_2]=[-0.731,\ 0.731]$。

优势：$G-b=-1-0.8=-1.8$。取 $\alpha=0.5$：

$$\Delta\mathbf{h}=0.5\times(-1.8)\times[-0.731,\ 0.731]=[+0.658,\ -0.658]$$
$$\mathbf{h}_{new}=[1.658,\ -0.658],\qquad \pi_1^{new}=\frac{e^{1.658}}{e^{1.658}+e^{-0.658}}=\frac{1}{1+e^{-2.316}}=0.9102$$

**与校验值对照**：$\pi_1=0.9102\approx 0.91$，与正文一致（Python 复核通过）。**解读**：$a_2$ 是坏动作（优势 −1.8），但其概率仍被"加强"了（0.269→0.0902 是 $\pi_2$ 下降，$\pi_1$ 从 0.731 升到 0.9102）——softmax 归一化下削弱 $a_2$ 必然推高 $a_1$；符号工程靠基线（负优势）保证了方向正确。这与 4.7.1 正例（$\pi_1:0.731\to 0.789$）对比还可见：负优势的更新幅度（2.316 的 logit 差变化）远大于正优势（0.322）——基线决定"步幅"，不只决定方向。

## 4-4 证明：基线引理与最优基线（对应 4.3.2–4.3.3 节）

**第一部分（引理 4.1）**：对任意与动作无关的 $b(s)$，

$$\mathbb{E}_{a\sim\pi_\theta}\big[\nabla\log\pi_\theta(a|s)\,b(s)\big]=b(s)\sum_a\pi_\theta(a|s)\frac{\nabla\pi_\theta(a|s)}{\pi_\theta(a|s)}=b(s)\sum_a\nabla\pi_\theta(a|s)=b(s)\,\nabla\sum_a\pi_\theta(a|s)=b(s)\,\nabla 1=0.\ \blacksquare$$

（$b(s)$ 对 $a$ 是常数可提出；最后一步是 softmax/score 恒等式的积分形式。）

**第二部分（$b^*$ 的分子分母各在"惩罚"什么）**：目标是最小化单个分量的方差 $\mathrm{Var}\big[(G-b)\,\mathbf{g}\big]$，$\mathbf{g}=\nabla\log\pi(a|s)$。把它写成 $\mathbb{E}\big[\|\mathbf{g}\|^2(G-b)^2\big]-\mathbb{E}\big[\|\mathbf{g}\|(G-b)\big]^2$ 后对 $b$ 求导置零（第二项期望恒为 $\nabla J$、不随 $b$ 变，导数为 0），得

$$b^*(s)=\frac{\mathbb{E}\big[\|\nabla\log\pi(a|s)\|^2\,G\ \big|\ s\big]}{\mathbb{E}\big[\|\nabla\log\pi(a|s)\|^2\ \big|\ s\big]}.$$

- **分子**：对"梯度范数大且回报高"的样本加权——分数函数敏感（范数大）的方向对方差贡献大，要用其回报去抵消，即"方差大的地方优先补偿"；
- **分母**：以梯度范数为权重的归一化——把"梯度不敏感（范数小）的样本"在基线中的话语权压低。

若忽略范数项（各方向灵敏度相近时近似成立），$b^*(s)\approx\mathbb{E}[G|s]=v^\pi(s)$——这就是"比平均好才加强"的优势函数来源。**常见错误**：把 $b^*$ 说成"使估计无偏的基线"——任何与动作无关的基线都无偏（第一部分），$b^*$ 是**方差最小**。

## 4-9 开放思考：PPO 的成功归因（对应 4.5 节；Engstrom et al. 2020）

**参考评述（约 300 字）**

PPO 的成功是"算法骨架"与"工程默认值"的乘积，且后者占比被系统性低估。从 4.5 节的推导看，PPO 真正的算法贡献只有一个思想：把 TRPO 的 KL 约束退化为对目标函数的分段截断——一阶方法、两行代码、保住"靠近时是原目标、跑远时是刹车"。但 Engstrom 等人的复现研究（Implementation Matters in Deep RL）表明，把 PPO 与朴素策略梯度拉开差距的关键里，相当一部分是代码级技巧：优势标准化、GAE(λ)、价值函数裁剪与学习率、熵奖励系数、梯度裁剪、 orthogonal 初始化、监控近似 KL 的 early stopping——逐项关闭这些默认值，PPO 的性能大幅下滑，某些设置下甚至低于被它替代的基线。反过来，只保留 clip 而抛弃其余（如很多"极简 PPO"复现）在基准上并不稳定。所以更准确的说法是：**clip 解决了"信任域"的算法问题，工程默认值解决了"深度学习训练的其余全部问题"**。这对学习者的启示有二：第一，读 RL 论文必须读参考实现，代码即论文的一部分；第二，评测新想法时要在"完整默认栈"上做消融（呼应 3-10 题的 Rainbow 方法论），否则归因失真。PPO 未必比它的祖先更好，但它把"不容易坏"做成了一揽子方案——这是它成为 RLHF 引擎的真正原因。

## 4-10 挑战题：GAE 与 λ 扫描（对应 4.3.3、4.7.3 节）

**实现**（替换单步优势为 λ-优势，δ 复用 TD 误差）：

$$\hat A_t=\sum_{l\ge0}(\gamma\lambda)^l\delta_{t+l},\qquad\delta_t=r_{t+1}+\gamma V(s_{t+1})-V(s_t)$$

```python
# gae.py —— 正文 4.7.3 已含此函数；此处明确其结构
def gae(rewards, values, dones, last_v, gamma=0.99, lam=0.95):
    adv = np.zeros_like(rewards); gae_t = 0.0; next_v = last_v
    for t in reversed(range(len(rewards))):
        delta = rewards[t] + gamma*next_v*(1-dones[t]) - values[t]   # δ_t
        gae_t = delta + gamma*lam*(1-dones[t])*gae_t                 # 指数加权累积
        adv[t] = gae_t; next_v = values[t]
    return adv + values        # 回报目标 = A + V（供 critic 回归）
```

λ=1 退化为蒙特卡洛优势（$\hat A_t=G_t-V(s_t)$，无偏高方差）；λ=0 退化为一步 TD（有偏低方差）。

**实际运行结果**（缩减版 PPO：roll 1024、10 epochs，单种子，达标=最近若干轮平均 ≥475）：

| λ | 达标迭代数 | 用时 |
|---|---|---|
| 0.9 | **33** | 28s |
| 0.95 | 62 | 50s |
| 1.0 | 62 | 50s |

**偏差-方差解释**：λ↑ → 目标里自举成分减少、蒙特卡洛成分增加 → 偏差减小、方差增大。CartPole 的 horizon 短（≤500 步）、critic 在低维状态上容易学准（偏差小），因此**低 λ（偏 TD 侧）的方差优势占上风**：λ=0.9 明显更快。若在长 horizon、价值难学的环境（如 Atari），趋势常常反转为 λ≈0.95 更稳。**方法论提醒**：上表是单种子结果，λ 间差异部分来自种子噪声——正式结论需 3–5 种子重复（呼应 4-6 题的方法论），扫描时应固定其余超参、只动 λ。

# 第 5 章 进阶主题：离线 RL 与前沿概览（对应正文 5.14 节）

## 5-1 概念辨析：在线 off-policy vs 离线 RL（对应 5.1 节）

> 题目：都"用旧数据学新策略"，本质区别是什么？用"发现外推错误的机制是否存在"回答。

**标准答案要点**

- **在线 off-policy（Q-learning + replay）**：replay 是**滚动的**——交互持续产生新数据把旧数据挤出缓冲，策略部署后的真实后果会回流成新的 $(s,a,r,s')$。若 $\max$ 目标在某动作上外推高估，在线交互迟早会把该高估"撞破"（采到该转移、发现回报低于预期、$Q$ 被拉回）——**存在一条从环境到估计器的纠错反馈回路**。
- **离线 RL**：训练期间**零交互**，数据集固定。OOD 动作上的外推高估**没有任何机制可以纠正**：数据里没有那个转移、没有环境反馈、估计器只能对着旧账本反复自举——错误被自举放大且永久固化（5.1 节"数据沙漠里的幻想绿洲"）。
- 一句话：**两者共享"分布 ≠ 当前策略"的数学结构，差别在于外部世界是否还会说话。** 这就是离线 RL 必须引入保守性（CQL 把 $Q$ 对 OOD 动作压成下界）而在线 off-policy 不必的原因。

**常见错误**：答"离线 RL 数据更旧"——新旧不是本质（replay 里也有几百万步前的数据）；答"离线 RL 不能用 max"——能用，但必须配上保守正则来补偿纠错机制的缺失。

## 5-2 CQL 正则的一压一抬与 α 的两个极限（对应 5.1 节）

**解答**

$$\mathcal{L}_{\text{CQL}}=\alpha\,\mathbb{E}_{s\sim\mathcal{D}}\Big[\underbrace{\log\sum_a e^{\hat q(s,a)}}_{\text{项一}}-\underbrace{\mathbb{E}_{a\sim\mathcal{D}(a|s)}\hat q(s,a)}_{\text{项二}}\Big]+\mathcal{L}_{\text{Bellman}}$$

- **项一（压）**：log-sum-exp 是 $\max_a\hat q$ 的光滑上界；最小化它 = 把"所有动作中最大的那个 $Q$"往下压——OOD 动作的虚高正是通过 max 进入贝尔曼误差的，压住它就掐断了"数据沙漠里的绿洲"。
- **项二（抬）**：它带负号，最小化整体时要把**数据中实际出现的动作**的 $Q$ 往上抬——保证保守只落在分布外，不把学到的策略价值一并压扁。一压一抬的净效果：$Q$ 对数据外动作成为**下界**。
- **$\alpha\to 0$**：正则消失，退化为普通 Q-learning——贝尔曼误差主导，OOD 外推高估回来了（在线交互本可纠错，但离线没有，所以裸 Q-learning 在离线设定下系统性失败）。
- **$\alpha\to\infty$**：贝尔曼误差可忽略，只优化保守项 → 解退化为"数据动作的 $Q$ 尽量高、其余尽量低"→ 策略趋于行为克隆（只敢贴着数据策略走），失去"从次优数据中提取更优策略"的能力。
- 结论：α 是"保守程度"的旋钮，两头各退化成 Q-learning 与 BC，中间才是离线 RL。

## 5-3 非平稳性：各自跑 DQN vs 自我博弈（对应 5.2 节）

**解答**

- **"每个智能体各自跑 DQN"为什么越学越差**：从任一智能体视角，其他智能体是环境的一部分，而它们也在学习——**环境转移"规则"随时间漂移**。第 2 章一切收敛定理的前提（平稳 MDP：$P,r$ 不随 $t$ 变）被破坏：$Q$ 追着一个自己也在移动的目标，别人的策略进步就是你环境的退化。多智能体相互适应时还可能出现循环（石头剪刀布式的策略轮转），表现为"训练曲线周期性崩塌"。
- **自我博弈为何能稳定进步**：自我博弈不是被动适应一个漂移的环境，而是**主动构造课程**——对手是自己的历史版本快照（对手池），难度随自身水平同步上升。在零和博弈中对手进步=自己挑战升级，进步可积累；理论支点是虚拟自我博弈（fictitious play）在零和博弈中收敛到纳什均衡（5.2 节），AlphaGo 系列是它的工程化极致。
- **环境假设差在哪里**：前者把"其他智能体"当作**不可控的非平稳噪声**吸收进环境；后者把"过去的自己"当作**可命名的学习对象**，并且零和结构保证了"更会应对历史对手"不含退化方向（对历史对手池的最优应对逼近对当前对手的均衡策略）。
- **加分**：非平稳场景也有正面解法——CTDE 让 critic 开天眼看联合动作（MADDPG/QMIX），本质是把非平稳问题转回平稳的"联合 MDP"学习。

## 5-4 Dyna vs MPC：预测跨度与失败模式（对应 5.3 节）

**解答**

- **Dyna**：模型只承担**一步预测** $(s,a)\to(s',r)$，长程价值交给 $Q$ 的自举（每真实步做 $N$ 次单步虚拟更新）。失败模式：**模型偏差 × 自举的复利**——单步模型错一点，自举会把它反复放大、传播到整个账本（"模型准 99% × 展开 20 步"只剩 82%，5.10 节陷阱 2），且策略会主动走向模型错误的区域进一步放大误差。
- **MPC**：模型承担**短程 H 步展望**（滚动时域），只执行最优序列的第一个动作，下步重规划；长程价值既不自举也不长程规划，交给"短视距 + 重规划"兜底。失败模式：① **视野有限**——超过 H 步的信用/惩罚不可见，长程权衡系统性短视；② 每步都要做一次序列优化（CEM 等），**计算昂贵**；③ H 变大时模型误差沿轨迹复合，长程展开不可靠。
- 对照记忆：Dyna 的模型偏差被**自举放大**（学习期问题），MPC 的模型偏差被**重规划纠正**但视野受限（执行期问题）；两者的第一超参分别是"虚拟更新次数 N"与"展望步长 H"。

## 5-5 编程：随机滑动迷宫中的 Dyna-Q（对应 5.9.1 节）

> 题目：给 Maze 加随机滑动（0.1 概率滑向相邻格），模型仍用确定性记录，观察 Dyna-Q 与纯 Q-learning 的差异。

**实现要点**（在 5.9.1 的 `Maze.step` 加滑动）：

```python
# slip_maze.py —— 在正文 5.9.1 的 Maze 上加打滑
def step(self, s, a):
    r, c = divmod(s, self.n); dr, dc = self.acts[a]
    if self.rng.random() < 0.1:                  # 10% 概率打滑
        dr, dc = (dc, dr) if self.rng.random() < 0.5 else (-dc, -dr)  # 滑向垂直方向之一
    ns = min(max(r+dr,0),self.n-1)*self.n + min(max(c+dc,0),self.n-1)
    return ns, (10.0 if divmod(ns,self.n)==self.goal else -1.0), divmod(ns,self.n)==self.goal
# Dyna 的 model[(s,a)]=(ns,r) 仍是无视打滑的确定性记录（有偏模型）
```

**实际运行结果与验证**：

1. 打滑迷宫的**精确**最优值可算（对真实随机动力学做价值迭代）：$v^*(0)=1.7234$（无滑动时为 2.53）；
2. 各配置学到的 $\max_a Q$ 与真实 $v^*$ 的平均绝对误差（3 种子，200 轮）：纯 Q-learning $1.69\pm0.52$；Dyna-10 $0.55\pm0.17$；Dyna-50 $0.94\pm0.33$；
3. 贪心评估（无滑动环境）：所有配置都能走出 8 步最优路径（未折扣回报 = −7+10 = 3.0）。

**解读**：① 规划把经验放大约 11 倍，价值传播快得多（Dyna-10 的误差远小于纯 Q-learning）；② 但把规划步数加到 50，确定性模型记录的偏差（它记录的是"最后一次滑动与否的结果"，且对每个 $(s,a)$ 只存一个去向）经更多次虚拟更新重新注入——**Dyna-50 比 Dyna-10 更差**，"模型偏差 × 规划"的放大效应被分离出来；③ 在这个 5x5 小迷宫上偏差不足以毁掉策略形状（贪心路径仍最优），但 $Q$ 值本身系统性偏离真实随机环境的 $v^*$——若拿这份 $Q$ 去做风险敏感决策（如医疗），低估值差就是错误决策。这正是正文"样本效率 ↔ 模型偏差"权衡的完整画像。

## 5-6 编程：奖励模型的噪声与维度（对应 5.9.2 节）

> 题目：噪声 scale 0.5→2.0、维度 4→64（true_w 稀疏化），报告准确率与方向恢复质量的变化，联系"RM 过拟合人类噪声"写 200 字。

**实现要点**：沿用 5.9.2 的构造，把 `rng.normal(scale=2.0, size=N)` 换噪声、把特征维数与稀疏真值换掉；其余（特征差 + 逻辑回归）不变。

**实际运行结果**（N=4000，seed=0；方向质量用恢复向量与真值的余弦相似度）：

| 设定 | 偏好预测准确率 | 方向余弦 |
|---|---|---|
| 噪声 0.5，dim=4（正文复现） | **0.941**（与正文一致） | 1.000 |
| 噪声 2.0，dim=4 | 0.802 | 0.999 |
| 噪声 2.0，dim=64，真值稀疏（4 维非零） | 0.803 | 0.985 |
| 噪声 2.0，dim=64，真值稠密 | 0.944 | 0.998 |

**200 字分析**：准确率由信噪比 $\|\mathbf{w}\|/\sigma$ 决定而非噪声绝对值——噪声 2.0 下 dim=64 稠密设定反而恢复到 0.944，因为真值范数变大使信号更强。真正危险的是**稀疏高维**设定：可辨识维度少、方向余弦降到 0.985，而**训练准确率（对含噪标签的拟合率）仍然虚高**——模型把一部分噪声当成了偏好模式记住了。这正是真实 RM 过拟合人类噪声的缩影：标注者不一致、隐式偏好（长度、格式、谄媚）作为"系统性噪声"被 RM 学成特征，PPO 又把 RM 分数当真值去最大化，把记错的模式放大成行为（长度作弊、格式套路，5.6 节）。缓解方向：标注协议去噪、RM 集成与不确定性估计、以"留出集准确率"而非训练集指标监控 RM。

## 5-7 AlphaZero 一个训练迭代的数据流图（对应 5.5 节）

```text
                     ┌────────────────────────────────────────────┐
                     │            网络参数 θ（第 k 轮）             │
                     └──────┬─────────────────────────┬───────────┘
                            │ p_θ(a|s)（先验）          │ v_θ(s)（局面价值）
                            ▼                          │
 ┌──────────┐  自我对弈棋局   ┌───────────────┐  搜索时估值叶节点
 │  自我博弈  │──────────────▶│     MCTS      │◀────────────┘
 │（当前 θ）  │               │ 500–800 次模拟 │
 └────┬─────┘               └──────┬────────┘
      │ 每步输出 π_k(a|s) ∝ N^{1/τ} │ 选择公式: argmax[Q/N + c·p_θ·√N_parent/(1+N)]
      │（改进后的策略，强于 p_θ）      │
      ▼                            │
 ┌──────────────┐   (s_t, π_k, z)  │
 │ 训练数据缓冲   │◀──── 记录每步 ───┘
 └──────┬───────┘        终局 z ∈ {+1,0,−1}（胜负）
        │ 采样 minibatch
        ▼
 ┌──────────────────────────────────────────┐
 │ 网络更新：min [ z − v_θ(s) ]² − π_k·log p_θ(a|s) + c‖θ‖²   │
 │ （价值回归 + 策略蒸馏自搜索结果）                          │
 └──────────────────────┬───────────────────┘
                        ▼
                θ 进入第 k+1 轮（飞轮：网络指导搜索，搜索改进网络）
```

每个箭头上流动的量：θ→MCTS 是先验 $p_\theta$ 与叶估值 $v_\theta$；自我博弈→MCTS 是待评估的局面 $s$；MCTS→自我博弈是每步的访问次数分布 $\pi_k$（策略改进）；自我博弈→缓冲是三元组 $(s_t,\pi_k,z)$；缓冲→更新是 minibatch；更新→下一轮是 θ。**回望**：MCTS 备份公式是第 1 章贝尔曼最优方程的搜索树版；选择公式是第 2 章 UCB；"$\pi_k$ 强于 $p_\theta$"是第 1 章策略改进定理的搜索版。

## 5-8 概念辨析：KL 惩罚 vs PPO clip（对应 5.6 节、4.5 节）

**标准答案要点**

- **两者约束的维度不同**：clip 约束的是**单轮更新内**新策略离**采样策略** $\pi_{\theta_{old}}$ 多远（局部、相对坐标、以重要性采样有效性为目的）；KL 惩罚约束的是**跨整轮训练**策略离**参考模型** $\pi^{\text{SFT}}$ 多远（全局、绝对坐标、以"别忘了预训练学到的一切"为目的）。
- **为什么两个都要**：只留 clip——单轮内稳定，但成千上万轮更新各自合法地小幅漂移，累积起来可以把模型漂到 RM 钻空子的区域（奖励黑客：长度作弊、谄媚），没有绝对锚点；只留 KL——防跑偏，但单轮内 $\pi_\theta$ 离 $\pi_{\theta_{old}}$ 太远会使重要性比爆炸、优势估计失真、训练崩溃（4.5.1 节朴素 off-policy 的老问题）。
- **公式对照**：clip 在 $L^{\text{CLIP}}$ 里（4.5.2），作用域是每个 minibatch；KL 逐 token 加进奖励 $r_t=-\beta\big(\log\pi_\theta(a_t|s_t)-\log\pi^{\text{SFT}}(a_t|s_t)\big)$（5.6 节），经优势估计渗进每一步的更新，作用域是整条训练曲线。
- **常见错误**：说"两者都是防训练崩溃"——KL 防的是**对齐崩溃**（能力遗忘、奖励黑客），clip 防的是**优化崩溃**（重要性采样失效）；说"KL 可以用 clip 替代"——clip 的参照系每轮都换，KL 的参照系（SFT）永远不动。

## 5-9 开放思考：奖励黑客的三个层面（对应 5.6 节、Goodhart 定律）

**参考答案（每层一条措施 + 残余风险）**

1. **数据来源层面**：扩大标注者与情境的多样性（不同背景标注者、对抗性红队用诱导性 prompt 采集偏好），并在协议中显式写明"长度/格式本身不加分"。残余风险：标注者仍会把"显得详尽"混进判断，多样性只稀释不消除系统性偏差；红队的对抗分布与真实用户分布不一致。
2. **模型结构层面**：RM 集成（多个不同种子/结构的 RM，取其分歧作为不确定性，对高分歧样本的奖励打折或拒绝更新）。残余风险：集成成员可能**共享同一偏差**（都从同源数据学出"长=好"），分歧度量对共模失灵是盲的；且集成加大推理成本。
3. **使用方式层面**：KL 惩罚调强 + 对 RM 分数曲线设 early stopping + 定期人工审计高分样本、迭代更新 RM（发现被钻空子就补标注）。残余风险：KL 太强则模型不敢离开 SFT（对齐收益消失）；审计只能覆盖采样到的小部分行为空间，新形态的黑客（组合已有漏洞）仍可能漏网；RM 迭代与策略优化构成新的博弈，可能把优化压力推向下一个最弱代理。
- **收束**：这三条是"延缓与暴露"而非"根治"——Goodhart 定律说的是代理指标与优化压力的结构性矛盾；唯一真正可靠的信号是 kept-out 的人工/真实评估，但它太贵，所以工程上永远是"代理 + 监控 + 迭代"的组合拳。

## 5-10 挑战题：3x3 井字棋的 AlphaZero-mini（对应 5.5 节；第 99 章项目三跳板）

**实现骨架（已完整实现并运行）**：网络 = 18 维输入（己方/对方棋子 one-hot）→ 64×2 隐层 → 双头（9 维策略 + tanh 价值）；MCTS 50 次模拟/步，PUCT 选择 $Q+c\cdot p\cdot\sqrt{N}/(1+N)$，根节点 Dirichlet(0.3) 噪声；自我博弈 40 迭代 × 8 局，前 4 步温度采样、之后贪心；损失 = 策略交叉熵（对搜索访问分布）+ 价值 MSE（对终局 z）；评估 vs 随机与 vs Minimax（完美对手）。

```python
# 核心三件套（完整可运行代码约 150 行，结构如下）
def search(b, p):                       # negamax 式递归 MCTS 一次模拟
    w = winner(b)
    if w != 0: return 1.0 if w == p else -1.0      # 终局：从行棋方视角
    if not legal(b): return 0.0                    # 平局
    key = (tuple(b), p)
    if key not in tree:                            # 叶节点：网络估值并入
        pr, v = net_eval(b, p); tree[key] = (pr, {}, 0)
    pr, edges, Nn = tree[key]
    a = argmax_a( Q(edges,a) + c*pr[a]*sqrt(Nn+1)/(1+N_a) )   # PUCT 选择
    val = -search(apply(b, a, p), -p)              # 递归，视角翻转
    edges[a][0] += 1; edges[a][1] += val           # backup
    return val
# 训练：loss = CE(pi_target, p_θ) + (z - v_θ)²
# 评估：与 Minimax 完美对手对局（negamax 带深度偏好：快赢慢输）
```

**实际运行结果**（40 迭代 × 8 局 = 320 局自我博弈，torch CPU 约 39 秒）：

| 对手 | 执子 | 结果（50/30 局） |
|---|---|---|
| 随机对手 | 执 X | **45 胜 5 平 0 负** |
| 随机对手 | 执 O | 21 胜 25 平 4 负 |
| Minimax 完美对手 | 执 X | 0 胜 0 平 30 负 |

**解读**：极小预算的自我博弈（320 局）已让模型从随机对手身上拿满先手胜率、执后手也极少输（先手随机对手占优时它有 25 平 4 负）——"搜索即策略改进 + 自我对弈课程"的核心机制在 3x3 上同样成立。但对完美 Minimax 全败是**诚实的预期**：井字棋完美先手至少必平，模型还没学到必须记住的防御模式——真实 AlphaZero 的力量来自百万局量级的自我博弈与搜索预算，而非架构差异。跑通本骨架后的两个升级方向（第 99 章项目三）：把 MCTS 模拟数从 50 提到 500 观察同等训练量下的胜率提升（搜索换样本）；把训练局数乘 100（用并行/批量推理）逼近完美均衡。

# 使用建议：如何用本答案册复盘

**总原则**：答案册的正确打开方式是"诊断器"，不是"练习册"。每道题按下面的错因分流，把出错点映射回正文的具体小节重读，比通读一遍正文高效得多。

1. **概念题做错** → 先判断错在哪一层：
   - 把归属/定义记混（如 1-1 五元组、3-1 三要素、5-8 KL vs clip）→ 回看对应**定义小节**（1.2、3.3、4.5/5.6），用"公式速查表"（各章第 6 节）默写一遍再对照；
   - 知道结论但给不出理由（如 2-3 为什么学 q、5-1 离线 vs off-policy）→ 重读该节**机制性段落**（1.4 节 v–q 关系、5.1 节"分布偏移"），并完成答案里给出的反例/对照构造；
   - 被"常见错误"命中 → 把答案册每题末尾的"常见错误为什么错"抄成自己的 checklist，一周后重测。
2. **计算/推导题做错** → 错误几乎总落在三种类型：**下标/幂次错位**（1-3、1-8、2-8 的校验值故事）、**期望与 max 的次序**（1-7、2-5、2-10）、**"半梯度/基线/优势"多一项少一项**（3-2、3-3、4-3、4-4）。对应回看 1.3–1.4（回报递归与贝尔曼）、2.3.1（TD 误差）、3.2.2（半梯度）、4.3（基线与优势）、4.5.2（clip 两情形）。做法：不看答案重推一遍，推到卡壳的那一行再查——那一行就是你的知识缺口。
3. **编程题跑不出/数值对不上** → 按此顺序排查：随机种子是否固定 → 终止与截断是否区分（3.8 节陷阱 1，CartPole 类问题的头号错误）→ 探索是否在关闭后还在更新目标（SARSA 的 $A_{t+1}$ 顺序，2.8 节陷阱 1）→ 目标网络是否同步（3.8 节陷阱 2）。若正文校验值与你的运行不符，先看**附录 A 勘误表**——本课程正文有 5 处已确认的勘误，不要把勘误当自己的 bug 反复排查。
4. **开放/挑战题**：先读答案的"解答路线"分层，再自己写一版提纲对照；挑战题的证明（1-5、1-6、2-4、4-4）建议默写骨架：每一步的依据（哪个定义、哪条引理）写不出就是没懂。Baird 反例（3-9）与井字棋（5-10）是第 99 章综合项目二的直接素材，跑通后保存代码。
5. **复习节奏**：学完每章 3 天内完成该章练习并对照；错题在题号旁标记"概念/推导/代码"与对应正文小节；期末总复习时只重做带标记的题。若某章错题超过一半，该章正文需要整体重读而不是零星修补。
