# 第 3 章 值函数近似与 DQN：深度强化学习的诞生

> **本章定位**：表格法的终结与深度学习的登场。状态空间一旦巨大或连续（图像、连续关节角），"每个状态存一个数"的表格既存不下也不会泛化——必须用参数化函数 $v_{\hat{\theta}}(s; \mathbf{w})$ 近似价值函数，而《深度学习》第 1–2 章的 MLP 正是那个函数。本章给出"半梯度"方法的数学、致命三要素的警告，以及把 Q-learning 神经网络化的 DQN 完整原理与其改进家族。

## 3.0 本章学习目标

学完本章，你能够：

1. 从状态空间规模、泛化能力两个维度说明表格法的局限，并针对具体任务（Atari、连续控制）选择合适的值函数表示；
2. 推导值函数近似的均方误差目标与半梯度 TD 更新，并解释"半"在何处、为何在实践中仍然有效；
3. 陈述致命三要素（自举、函数近似、off-policy）及其共同作用导致发散的机制（Baird 反例思想）；
4. 说出 DQN 的每个组件（经验回放、目标网络等）分别解决了哪个问题，并实现标准 DQN 在 CartPole 上稳定训练到满分；
5. 阐述 Double DQN、优先经验回放、Dueling 网络各自的动机与公式改动。

## 3.1 表格法的局限

第 1、2 章的方法共享同一个隐含奢侈：**为每个状态（-动作）单独维护一个数字**。算一下账：

- 西洋双陆棋：约 $10^{20}$ 个状态；围棋：约 $10^{170}$；Atari 游戏一帧 $210 \times 160$ 像素、颜色 128 种，原始状态数天文数字；
- CartPole：4 维连续观测——状态根本不可枚举，"表格"无从建起；
- 更本质的问题：**零泛化**。表格里 $V(s_1)$ 与 $V(s_2)$ 互不相干，哪怕 $s_1, s_2$ 只差一个像素。学过"这个棋形很好"，换一个镜像棋形就一无所知。样本效率随状态数线性爆炸。

**出路**：用参数化函数 $\hat{v}(s; \mathbf{w})$（线性特征、核方法或神经网络）把"相似状态共享价值"写进表示——这正是《机器学习》第 1、2 章函数近似的本行，只是现在"标签"不再来自数据集，而来自自举的 TD 目标。

## 3.2 值函数近似与半梯度方法

### 3.2.1 目标函数

沿用监督学习的套路，对固定策略 $\pi$ 定义均方值误差（MSVE）：

$$\mathrm{MSVE}(\mathbf{w}) = \sum_s \mu(s)\, \big[ v^\pi(s) - \hat{v}(s; \mathbf{w}) \big]^2,$$

其中 $\mu(s)$ 是 $\pi$ 下的状态分布权重。若 $\hat{v}$ 可微（MLP 天然如此），可用梯度下降——但有两个 RL 特有的麻烦：

1. **没有真标签**：$v^\pi(s)$ 未知，只能用采样回报（MC）或自举目标（TD）当"伪标签"；
2. **标签随参数移动**：TD 目标 $r + \gamma \hat{v}(s'; \mathbf{w})$ 自己含 $\mathbf{w}$——你不是在拟合静止的山，是在爬一座随你移动的山。这是本章一切不稳定的总根源。

### 3.2.2 半梯度 TD(0)：推导

真目标 $J(\mathbf{w}) = \mathbb{E}_\mu\big[(v^\pi(S) - \hat{v}(S;\mathbf{w}))^2\big]$ 的梯度本应包括两部分——$v^\pi$ 不依赖 $\mathbf{w}$，但采样版目标 $R_{t+1} + \gamma \hat{v}(S_{t+1}; \mathbf{w})$ 依赖。**忽略目标中 $\nabla_{\mathbf{w}} \hat{v}(S_{t+1};\mathbf{w})$ 那一半**，得到半梯度 TD(0)：

$$\mathbf{w} \leftarrow \mathbf{w} + \alpha \big[ \underbrace{R_{t+1} + \gamma \hat{v}(S_{t+1}; \mathbf{w}) - \hat{v}(S_t; \mathbf{w})}_{\delta_t \text{，TD 误差照旧}} \big] \nabla_{\mathbf{w}} \hat{v}(S_t; \mathbf{w}).$$

**为什么"半"**：严格做法是把 $J(\mathbf{w}) = \mathbb{E}_\mu\big[(R_{t+1} + \gamma \hat{v}(S_{t+1};\mathbf{w}) - \hat{v}(S_t;\mathbf{w}))^2\big]$ 当目标完整求导，多出 $\gamma \nabla_{\mathbf{w}}\hat{v}(S_{t+1})$ 项；半梯度扔掉它。**代价**：不再是对任何良定义目标的随机梯度下降；**收益**：目标计算不需二次反传（快、省显存），且在表格情形退化为标准 TD(0)。对线性近似 $\hat{v}(s;\mathbf{w}) = \mathbf{x}(s)^\top \mathbf{w}$（特征 $\mathbf{x}(s)$），on-policy + 步长条件下半梯度 TD 收敛到投影最优 $\mathbf{w}^* = $ 使 $\hat{v}$ 在 $\mu$ 度量下最接近 $v^\pi$ 的点（Tsitsiklis & Van Roy, 1997；投影误差不超过最优线性误差的 $\frac{1}{1-\lambda}$ 倍量级）——**它找到的不是 $v^\pi$，而是它的最佳线性投影**，这个"近似损耗"是函数近似的固有代价。

**控制版**：$\hat{q}(s, a; \mathbf{w})$ 替代 $\hat{v}$，配合 ε-greedy 得半梯度 SARSA（on-policy，相对稳定）；配合 max 目标得半梯度 Q-learning（off-policy，危险区）——下一节解释"危险"从何而来。

## 3.3 致命三要素（Deadly Triad）

Sutton & Barto 指出，以下三个要素**两两基本无害，三者叠加可能发散**：

1. **自举（bootstrapping）**：目标里含自己的估计（TD 家族）；
2. **函数近似（function approximation）**：参数共享——一个状态的更新会牵动其他状态；
3. **off-policy**：训练分布 ≠ 当前策略的分布（Q-learning 的 replay 数据、人类数据）。

**发散机制（Baird 反例的思想）**：构造一个 7 状态小 MDP，线性特征下按半梯度 off-policy TD 更新，权重会振荡放大到无穷。直觉链条：off-policy 的数据分布 $\mu$ 与"自举的传播方向"脱节 → 更新在某些状态方向上的误差被 $\hat{v}(s')$ 的误差**放大**而非平均 → 放大的误差经函数近似**扩散**到无关状态 → 再被自举取回来继续放大——正反馈回路闭环。形式上，平均后的更新算子的谱半径超过 1。对比：去掉任一要素回路即断——on-policy 线性 TD 收敛（无 3）；监督学习回归收敛（无 1，标签是外生的）；表格 Q-learning 收敛（无 2）。

**工程对策**（本节预告，DQN 一节兑现）：目标固定化（目标网络）、经验回放打散相关性、梯度裁剪、限制更新频率。但要诚实：**没有一般性定理保证深度 off-policy 自举收敛**——DQN 的稳定性是工程组合的胜利，不是理论的胜利。第 4 章的策略梯度路线（目标外生、不自举）从根上绕开三要素，这是它成为 RLHF 引擎的深层原因。

## 3.4 DQN：Q-learning 的神经网络化（Mnih et al., 2013/2015）

DQN（Deep Q-Network）把 3.2.2 的半梯度 Q-learning + CNN 搬上 Atari：输入最近 4 帧灰度图，输出每个动作的 $Q$ 值，目标是人类水平的 49 局游戏。**它的全部设计智慧都在回答一个问题：如何让"标签自己会动"的训练勉强稳定？**

### 3.4.1 损失函数

对经验转移 $(s, a, r, s')$，DQN 最小化 TD 残差：

$$L(\mathbf{w}) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}} \left[ \left( \underbrace{r + \gamma \max_{a'} \hat{q}(s', a'; \mathbf{w}^-)}_{\text{目标，由旧参数 } \mathbf{w}^- \text{ 计算}} - \hat{q}(s, a; \mathbf{w}) \right)^2 \right],$$

其中 $\mathbf{w}$ 是在线参数，$\mathbf{w}^-$ 是目标网络参数。梯度只对 $\hat{q}(s,a;\mathbf{w})$ 一侧计算（半梯度）；实践用 Huber 损失（|误差|>1 时线性）替代平方，防止 TD 误差爆炸时梯度爆炸——呼应《深度学习》第 2 章的鲁棒损失。

### 3.4.2 每个组件解决什么问题

| 组件 | 做什么 | 解决的问题（对应三要素/RL 特性） |
|---|---|---|
| **经验回放**（replay buffer，容量 ~10⁶） | 把交互存进环形缓冲，随机小批量采样训练 | ① 打破时序相关性——SGD 需要近 i.i.d. 批量（《最优化方法》第 5 章）；② 数据复用，样本效率；③ 平滑数据分布，抑制策略突变带来的分布漂移 |
| **目标网络**（target network，每 C 步硬同步或软更新） | 用旧参数 $\mathbf{w}^-$ 计算 TD 目标 | 把"移动的标签"冻结成"缓慢移动的标签"——切断自举正反馈回路，把问题变成"追一个慢目标"；对应三要素的缓解 |
| **奖励裁剪**（clip 到 $[-1, 1]$） | 统一不同游戏奖励尺度 | 一套超参跑所有游戏；也稳定 TD 目标量级 |
| **帧堆叠**（4 帧） | 补充速度方向信息 | 修复单帧观测的非马尔可夫性（第 1 章 1.2 的伏笔兑现） |
| ε-greedy 衰减（1.0 → 0.1） | 探索调度 | 第 2 章 2.4 的标准做法；Atari 训练初期 ε 高达 1.0 |
| RMSProp/Adam + 梯度裁剪 | 优化器 | 《深度学习》第 2 章的工具直接平移 |

**训练循环的心智模型**：采集（按 ε-greedy 与环境交互，存 replay）→ 学习（从 replay 采样，用目标网络算 target，反传一步）→ 周期性同步目标网络。采集与学习解耦——这正是"off-policy"的工程意义：学习用的数据不必来自当前策略。

**Atari 2015 版的完整超参表**（工程实现时的对照基准；CartPole 这类小任务不需要全部，但结构相同）：

| 超参 | 取值（Nature DQN） | 作用 |
|---|---|---|
| replay 容量 | 100 万帧 | 经验回放（见上表） |
| 目标网络同步 | 每 10,000 步硬拷贝 | 极慢的"标签冻结" |
| minibatch | 32 | SGD 批量 |
| 折扣 $\gamma$ | 0.99 | 第 1 章 1.3 节 |
| ε-greedy | 1.0 → 0.1，前 100 万帧线性衰减 | 探索调度 |
| 帧堆叠 / 帧跳步 | 4 帧 / 每 4 动作重复 | 马尔可夫性修复 + 计算省 4 倍 |
| 优化器 | RMSProp，lr 2.5e-4 | 《深度学习》第 2 章 |
| 奖励裁剪 | clip 到 $[-1, 1]$ | 跨游戏统一尺度 |

注意目标网络**每万步才同步一次**——比多数初学者想象的慢一个数量级。"标签冻结"要冻得足够久才有意义，这是调 DQN 时最常被忽视的单一超参。

### 3.4.3 为什么依然会崩

即便有以上护栏，DQN 的训练曲线仍以"突然崩溃"著称：某一刻 $Q$ 值集体飙升（overestimation 螺旋）或策略突然退化。原因可归结为：目标网络只延缓而非消除自举回路；max 算子的最大化偏差（第 2 章 2.5.2）在函数近似下被放大。对症药即下一节的改进家族。

## 3.5 DQN 改进家族

1. **Double DQN（van Hasselt et al., 2016）**：解耦"选择"与"评估"——目标改为
   $$y = r + \gamma\, \hat{q}\big(s', \arg\max_{a'} \hat{q}(s', a'; \mathbf{w});\ \mathbf{w}^-\big),$$
   在线网络选动作、目标网络定价值，直接消解 max 引入的过估计。这是第 2 章 Double Q-learning 思想的网络版，一行公式改动，普遍有效，**建议永远默认开启**。
2. **优先经验回放（PER, Schaul et al., 2016）**：均匀采样浪费了"信息量大"的转移。按 TD 误差 $\delta_i$ 的重要性采样：$p_i \propto (|\delta_i| + \epsilon)^\beta$，配合重要性权重 $(\frac{1}{N p_i})^\beta$ 纠偏。代价：多一次优先级维护，且引入新超参。
3. **Dueling 网络（Wang et al., 2016）**：把 $Q$ 分解为状态价值 + 优势：$Q(s,a) = V(s) + A(s,a) - \bar{A}(s,\cdot)$（减均值保证可辨识）。动机：很多状态"选哪个动作都行"——状态价值本身值得单独估计。网络改动，公式不变。
4. **Rainbow（Hessel et al., 2018）**：把上述三项 + 分布式 RL、多步学习、噪声网络叠加的系统消融研究——证明改进大部分**正交可加**。读它是学习"如何在 RL 里做严谨消融实验"的范本（衔接《实验设计与评估》）。

## 3.6 关键公式速查

| 公式 | 内容 | 适用条件 |
|---|---|---|
| $\mathrm{MSVE}(\mathbf{w}) = \sum_s \mu(s)[v^\pi(s) - \hat v(s;\mathbf w)]^2$ | 近似质量目标 | 固定策略 |
| $\mathbf{w} \leftarrow \mathbf{w} + \alpha\, \delta_t \nabla_{\mathbf{w}} \hat{v}(S_t; \mathbf{w})$ | 半梯度 TD(0) | 表格退化 = TD(0)；off-policy 时不保证收敛 |
| $L(\mathbf{w}) = \mathbb{E}[(r + \gamma \max_{a'} \hat{q}(s',a';\mathbf{w}^-) - \hat{q}(s,a;\mathbf{w}))^2]$ | DQN 损失 | replay 采样 + 目标网络 |
| $y^{Double} = r + \gamma\, \hat{q}(s', \arg\max_{a'} \hat{q}(s',a';\mathbf{w}); \mathbf{w}^-)$ | Double DQN 目标 | 两套参数 |
| $p_i \propto (|\delta_i| + \epsilon)^\beta$ | 优先回放采样分布 | 配重要性权重纠偏 |
| $Q(s,a) = V(s) + A(s,a) - \frac{1}{|\mathcal{A}|}\sum_{a'} A(s,a')$ | Dueling 分解 | 网络结构改动 |

## 3.7 示例与案例

### 3.7.1 手算算例：线性近似的半梯度更新

状态特征 $\mathbf{x}(s) = [1, 2]^\top$，权重 $\mathbf{w} = [1, 1]^\top$，故 $\hat{v}(s) = 3$。单步经验：$r = 0$，$\gamma = 0.9$，下一状态 $\mathbf{x}(s') = [0, 1]^\top$（$\hat{v}(s') = 1$），$\alpha = 0.1$。则 $\delta = 0 + 0.9 \times 1 - 3 = -2.1$，梯度 $\nabla_{\mathbf{w}} \hat{v} = \mathbf{x}(s) = [1,2]^\top$，更新 $\mathbf{w} \leftarrow [1,1]^\top + 0.1 \times (-2.1) \times [1,2]^\top = [0.79, 0.58]^\top$。注意 $\hat{v}$ 对**所有**与 $s$ 特征相近的状态都变了——泛化与误差扩散是同一件事（3.3 节机制的最小复现）。

### 3.7.2 最大化偏差的 30 秒演示（numpy）

DQN 家族改进的动机都可以浓缩成一个 numpy 两行实验：**带噪声估计的 max 系统性偏高**。

```python
# overestimation_demo.py —— 为什么 max_a Q 会高估（Double DQN 的动机）
import numpy as np
rng = np.random.default_rng(0)
truth = np.zeros(10)                       # 真值：所有动作价值都是 0
est = truth + rng.normal(0, 1, 10)         # 带噪声的估计（想象 Q 网络的输出）
print(f"真值的 max            = {truth.max():.2f}")
print(f"噪声估计的 max        = {est.max():.2f}")          # 想象 Q-learning 的目标 max_a Q(s',a')
print(f"单次实验偏差          = {est.max() - truth.max():+.2f}")
biases = [ (truth + rng.normal(0,1,10)).max() for _ in range(10000) ]
print(f"10000 次实验的平均偏差 = {np.mean(biases):+.3f}")   # 系统性为正（约 +1.5）
```

预期输出：

```text
真值的 max            = 0.00
噪声估计的 max        = 1.76
单次实验偏差          = +1.76
10000 次实验的平均偏差 = +1.538
```

10 个动作、估计噪声标准差 1 时，max 的期望偏高约 1.54——动作数越多、噪声越大，偏差越大（这与 2.5.2 节的 Jensen 型不等式一致）。Q-learning 的目标里嵌着一个这样的 max，而 DQN 的自举会把每一轮的偏高喂回下一轮——"过估计螺旋"。Double DQN 用两套网络解耦选择与评估，正是拆掉这个螺旋的第一级。

### 3.7.3 PyTorch 实现 DQN 训练 CartPole（完整代码）

环境：gymnasium CartPole-v1（4 维连续观测、2 个离散动作、每存活一步 $+1$，500 分封顶）。安装：`pip install gymnasium[classic-control] torch`。

```python
# dqn_cartpole.py —— 标准 DQN（经验回放 + 目标网络）训练 CartPole-v1
import random
from collections import deque
import numpy as np
import torch
import torch.nn as nn
import gymnasium as gym

class QNet(nn.Module):
    """MLP：观测(4) -> 64 -> 64 -> 各动作 Q 值(2)。即《深度学习》第 1 章的 MLP。"""
    def __init__(self, obs_dim=4, n_act=2, hid=64):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(obs_dim, hid), nn.ReLU(),
                                 nn.Linear(hid, hid), nn.ReLU(),
                                 nn.Linear(hid, n_act))
    def forward(self, x): return self.net(x)

def main(total_episodes=400, gamma=0.99, lr=5e-4, buffer_size=50000,
         batch_size=64, start_steps=500, tau=0.005, eps_hi=1.0, eps_lo=0.05):
    env = gym.make("CartPole-v1")
    dev = "cuda" if torch.cuda.is_available() else "cpu"
    online, target = QNet().to(dev), QNet().to(dev)
    target.load_state_dict(online.state_dict())          # 目标网络初始化为在线网络的拷贝
    opt = torch.optim.Adam(online.parameters(), lr=lr)
    replay, rng = deque(maxlen=buffer_size), random.Random(0)

    def act(obs, eps):
        if random.random() < eps: return env.action_space.sample()
        with torch.no_grad():
            return int(online(torch.tensor(obs, dtype=torch.float32, device=dev)).argmax())

    def learn():
        if len(replay) < start_steps: return             # 攒够初始经验再学
        batch = random.sample(replay, batch_size)
        s, a, r, s2, d = map(np.array, zip(*batch))
        s  = torch.tensor(s,  dtype=torch.float32, device=dev)
        a  = torch.tensor(a,  dtype=torch.int64,  device=dev).unsqueeze(1)
        r  = torch.tensor(r,  dtype=torch.float32, device=dev)
        s2 = torch.tensor(s2, dtype=torch.float32, device=dev)
        d  = torch.tensor(d,  dtype=torch.float32, device=dev)
        q_sa = online(s).gather(1, a).squeeze(1)                       # Q(s,a; w)
        with torch.no_grad():
            q_next = target(s2).max(dim=1).values                      # max_a' Q(s',a'; w-)
            y = r + gamma * (1.0 - d) * q_next                         # TD 目标
        loss = nn.functional.smooth_l1_loss(q_sa, y)                   # Huber 损失
        opt.zero_grad(); loss.backward()
        nn.utils.clip_grad_norm_(online.parameters(), 10.0)            # 梯度裁剪
        opt.step()

    eps, steps, recent = eps_hi, 0, deque(maxlen=10)
    for ep in range(1, total_episodes + 1):
        obs, done, total_r = env.reset(seed=ep)[0], False, 0.0
        while not done:
            eps = max(eps_lo, eps_hi - (eps_hi - eps_lo) * min(ep / 120, 1.0))  # ε：前 120 轮线性衰减
            a = act(obs, eps)
            obs2, r, term, trunc, _ = env.step(a)
            replay.append((obs, a, r, obs2, float(term)))              # trunc 不当终止
            obs, done, total_r, steps = obs2, term or trunc, total_r + r, steps + 1
            learn()
            with torch.no_grad():                                      # 目标网络软更新（Polyak 平均）
                for tp, op in zip(target.parameters(), online.parameters()):
                    tp.mul_(1 - tau).add_(op, alpha=tau)
        recent.append(total_r)
        if ep % 50 == 0:
            print(f"episode {ep:4d} | 最近10轮平均回报 = {np.mean(recent):6.1f} | eps = {eps:.2f}")
        if ep >= 100 and np.mean(recent) >= 475:
            print(f"在 episode {ep} 达到稳定高分(>=475)，提前结束"); break

if __name__ == "__main__":
    main()
```

预期输出（约 250–400 轮达到 475 分；若 500 轮仍未达标，先查 ε 衰减速度、$\tau$ 与学习率）：

```text

episode  100 | 最近10轮平均回报 =  170.0 | eps = 0.21
episode  150 | 最近10轮平均回报 =  126.2 | eps = 0.05
episode  200 | 最近10轮平均回报 =  199.9 | eps = 0.05
episode  250 | 最近10轮平均回报 =  198.9 | eps = 0.05
在 episode 292 达到稳定高分(>=475)，提前结束
```

**关于目标网络的两种更新方式**：Nature DQN 原版用"每 C 步硬拷贝"，但在 CartPole 这类每 episode 只有几十~几百步的小任务上，硬拷贝的同步节奏很难调（太频繁 → 标签跟着在线网络跑、训练震荡在 100–250 分；太稀疏 → 学习停滞），我们采用 DDPG/SAC 一脉的**软更新**（Polyak 平均 $\mathbf{w}^- \leftarrow (1-\tau)\mathbf{w}^- + \tau\mathbf{w}$，$\tau = 0.005$）——效果等价于"无限慢但连续的硬同步"，是现代深度 RL 的默认做法。把它改回硬同步并扫描同步频率，正是下面消融实验的一部分。

**消融实验建议**（10 分钟跑完，收益极大）：依次注释掉 (a) 目标网络（改为每步 `target = online`）、(b) replay（改为用当前步数据立刻学习）、(c) 梯度裁剪——你会亲眼看到 (a)(b) 让训练剧烈震荡或崩溃，直观体验致命三要素不是教科书恐吓。

## 3.8 常见误区与陷阱

1. **把终止与截断混为一谈**：`done` 要区分 terminated（真的终局，bootstrapping 为 0）与 truncated（时间到，仍应自举）。CartPole 500 步是截断——把 truncation 当 termination 会让目标系统性偏低。上面代码已用 `float(term)` 区分。
2. **目标网络忘了同步或同步太频繁**：每步都同步 = 没有目标网络（回到移动标签）；忘了同步 = 目标永远陈旧。同步频率是与学习率同量级的重要超参。
3. **在目标计算里忘了 `no_grad`**：对目标侧反传会把 $\nabla_{\mathbf{w}}\hat{q}(s')$ 也算进来——"半梯度"变"全梯度"反而可能不稳定，且浪费一倍显存与算力。
4. **过估计螺旋误判为收敛**：$Q$ 值稳步上涨不代表学得更好，可能是 max 偏差在自我放大；要看回报曲线与 $Q$ 的绝对量级。Double DQN 是第一反应。
5. **replay 太小或 batch 太大**：replay 小于几千时新旧数据强相关，"打散相关性"的作用名存实亡；batch 过大则单步更新次数变少，收敛反而慢。
6. **对离散与连续动作混用 DQN**：DQN 的 max 只对**离散**动作可行；连续控制需要策略梯度方法（第 4 章）或分布式最大化技巧——这是第 3、4 章分工的第一依据。

## 3.11 进阶方向

- **分布式价值（Distributional RL）**：学习回报的整个分布 $Z(s,a)$ 而非期望（C51、QR-DQN）——风险敏感决策与更强特征的入口；
- **软更新与目标策略（TD3/SAC 预告）**：连续控制下目标网络软更新 $\mathbf{w}^- \leftarrow \tau \mathbf{w} + (1-\tau)\mathbf{w}^-$ 与随机化 max（SAC 的软价值）是 DQN 家族在连续动作域的后裔；
- **离线 DQN 的过估计问题**：固定数据集上 max 目标的分布偏移——通往第 5 章 CQL 的桥；
- **可微近似 max**：连续动作的 $\max_a Q$ 不可枚举，需优化器内嵌或随机策略技巧——策略梯度方法的另一半动机。
