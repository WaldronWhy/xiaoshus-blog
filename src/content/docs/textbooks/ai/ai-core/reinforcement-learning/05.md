# 第 5 章 进阶主题：离线 RL 与前沿概览

> **本章定位**：一幅"从教室到前沿"的地图。前四章在单智能体、在线、无模型的基准设定中完成了主菜；本章把镜头拉远——数据是固定的（离线 RL）、对手是智能体（多智能体）、模型可以被学出来（基于模型的 RL）、任务有层级（分层 RL）、搜索与学习合体（AlphaGo/AlphaZero）、奖励来自人类偏好（RLHF）——并诚实地盘点本领域的开放问题。各主题点到思想为止，给出继续深入的钥匙。

## 5.0 本章学习目标

学完本章，你能够：

1. 解释离线 RL 的分布偏移问题与保守方法的动机，说清 CQL 对 Q-learning 的公式改动；
2. 概述多智能体 RL 的非平稳性根源与两类经典解法（CTDE、自我博弈）；
3. 描述 Dyna 与 MPC 两条"学模型"路线的思想，并实现 Dyna-Q；
4. 用"策略之上还有策略"的语言解释分层 RL 与选项框架；
5. 拆解 AlphaGo/AlphaZero 的 MCTS + 网络架构，指出每个组件替换了什么、保留了什么；
6. 完整说出 RLHF 流水线（SFT → 奖励模型 → PPO 微调）各环节的输入输出与关键超参，并实现一个最小奖励模型。

## 5.1 离线强化学习：当数据不再来自你

**设定**：只有一份固定数据集 $\mathcal{D} = \{(s_i, a_i, r_i, s_i')\}$（历史日志、人类演示、旧策略的 replay），训练期间**零交互**。动机极强：医疗、金融、自动驾驶不能在线试错；LLM 对齐中"在线采集"就是让模型对真实用户说话——太贵且太危险。

**核心困难：分布偏移（distribution shift）**。Q-learning 的目标 $r + \gamma \max_{a'} Q(s', a')$ 会在数据集中**没出现过的**动作上外推 $Q$ 值。神经网络的外推不受控：数据没覆盖的 $(s', a')$ 的 $Q$ 可能被高估（第 3 章最大化偏差 × 无在线纠错机会），贪心策略于是冲向这些"数据沙漠里的幻想绿洲"，而真实环境里它们一文不值。离线设定下这个错误**没有任何机制可以纠正**——这是离线 RL 与在线 off-policy 的本质区别（后者好歹能在交互中发现外推错误）。

**保守方法：CQL 的思想**（Kumar et al., 2020，Conservative Q-Learning）。既然外推值容易虚高，那就**系统性压低**所有动作的 $Q$，只让数据中真实出现的 $(s, a)$ 抬高。在贝尔曼误差损失上加一个正则：

$$\mathcal{L}_{\text{CQL}}(\mathbf{w}) = \alpha \, \mathbb{E}_{s \sim \mathcal{D}} \left[ \log \sum_a e^{\hat q(s,a;\mathbf{w})} - \mathbb{E}_{a \sim \mathcal{D}(a \mid s)}\, \hat q(s, a; \mathbf{w}) \right] + \mathcal{L}_{\text{Bellman}}.$$

方括号内第一项是 log-sum-exp——近似 $\max_a \hat q$，被**最大化**（推高所有动作中最大的那个）；第二项是数据中实际动作的 $Q$，被**最小化**……准确地说：整个括号要被最小化时，效果是"把OOD动作的 Q 往下压、把数据内动作的 Q 相对抬高"（log-sum-exp 项惩罚过大的 max，第二项抬高数据内动作）——一软一硬，净效果是 $Q$ 值对数据外动作取下界。直觉：**"没见过的不许吹牛"**。后继工作 IQL（用 expectile 回归避开 OOD 动作查询）与 Decision Transformer（干脆把 RL 变成序列建模：以回报为条件的 Transformer 预测下一动作，衔接《深度学习》第 5 章）各辟蹊径。

**与监督学习的界限**：离线 RL ≠ 行为克隆（BC，直接模仿 $\mathcal{D}$ 里的动作）。BC 只能学到数据策略的水平；离线 RL 要"从次优数据中提取比数据更优的策略"——正是这"更优"二字引入了 OOD 动作查询，也让离线 RL 无法退化为纯监督学习。

**数据质量决定上限**：离线 RL 的结果强烈依赖数据集的"覆盖面与质量"——全部来自单一次优策略的数据（如只有业余棋手棋谱）下，任何算法都难以提取出超越数据风格的策略；混合多策略的数据（D4RL 基准的 medium-replay / expert 设置）才留出改进空间。这与《机器学习》" garbage in, garbage out" 的教训同构，但在 RL 中多了一层：**数据的分布形状直接决定外推误差出现在哪里**。

## 5.2 多智能体强化学习（MARL）简介

**形式化**：多智能体设定下，MDP 升级为**随机博弈**（stochastic game）：$\langle \mathcal{N}, \mathcal{S}, \{\mathcal{A}_i\}, P, \{R_i\}, \gamma \rangle$——$n$ 个智能体共享状态与转移，但各自有动作集与**奖励函数**（利益可以冲突）。平衡概念从"最优"换成"纳什均衡"：没有任何单方可以通过单独改变策略而获益。这带来的第一个深刻变化：**"最优策略"一般不再存在**（你的最优取决于对手怎么选），取而代之的是"最好应对"（best response）与均衡的概念——博弈论（自修建议：零和均衡、 minimax、相关均衡）由此成为必修。

多个智能体同场学习，最深的坑是**非平稳性**：从任一智能体视角，其他智能体是环境的一部分，而它们也在学习——环境的"规则"随时间漂移，第 2 章的一切收敛性论证失效。两类代表思路：

- **CTDE（集中式训练、分布式执行）**：训练时 critic 可以"开天眼"看到所有智能体的联合观测（集中），执行时每个智能体只用本地观测（分布式）——代表算法 MADDPG、QMIX（后者用单调混合网络保证集中估值与分布贪心的一致性）；
- **自我博弈（self-play）**：让智能体与过去的自己反复对弈，构建"课程"。在零和完美信息博弈中有清晰的理论支点（虚拟自我博弈收敛到纳什均衡），AlphaGo 系列把它推到极致（5.5 节）。

应用：自动驾驶多车协同、机器人编队、经济机制模拟、以及大模型的"博弈式"评估（用另一个模型做对抗性测试）。入门槛：先修博弈论基础（纳什均衡、零和与一般和、minimax 定理）。

## 5.3 基于模型的强化学习：把环境学出来

免模型方法把样本挥霍在"反复试错"上。基于模型（model-based）RL 学一个 $\hat{P}, \hat{r}$ 来补足样本效率，两条经典路线：

- **Dyna（Sutton, 1990）**：真实经验同时干两件事——更新 $Q$（第 2 章照旧）+ 训练模型；然后在脑内"做梦"：从模型虚拟采样 $N$ 步，做 $N$ 次虚拟 Q-learning 更新。**样本效率大幅提升，代价是模型偏差**：模型错的地方，规划会把错误放大传播。
- **MPC（模型预测控制）+ 随机规划**：每步用学到的模型向前展望 $H$ 步、用采样优化（如 CEM 交叉熵方法）搜出最优动作序列，只执行第一个动作，下步重规划（滚动态时域）。代表工作 PETS、PlaNet。模型只承担"短程预测"（较可靠），长程价值交还给了短视距+重规划。

**权衡总表**：免模型（样本贵、无模型偏差、通用）；基于模型（样本省、模型偏差风险、工程复杂）。现代共识：样本昂贵场景（机器人）偏基于模型，数据廉价场景（游戏、模拟器、LLM rollout）偏免模型。

**Dyna 的两个变体一句话**：Prioritized Sweeping（优先模拟"TD 误差最大"的虚拟转移——把第 3 章优先回放的思想用在学习模型上）；Rollout 策略改进（用模型做前向模拟评估候选动作，即"内嵌一步小规划"——MCTS 的微型版）。

**现代的世界模型路线**（Dreamer 系列）把 Dyna 的"梦中学习"推到极致：在学到的**潜空间**模型里长程展开、反传梯度训练策略——真实环境只负责提供少量交互。它也是"生成模型 + 决策"合流的样板，衔接《深度学习》第 6 章生成模型的世界观：如果能生成环境的未来，规划就是生成式采样。

## 5.4 分层强化学习（HRL）概览

真实任务的时间尺度是嵌套的："去厨房倒杯水"包含"导航""抓握""倒水"。扁平 RL 要用数百万步学习用原子动作拼出这一切。HRL 引入**时间抽象**——选项（option）框架：$\omega = (\text{ initiation set } I,\ \text{ intra-option policy } \pi_\omega,\ \text{ termination } \beta)$，即"何时启用、内部怎么走、何时结束"。层级化的代表框架：

- **Option-Critic**：端到端同时学习选项与终止函数；
- **Feudal 网络（FuN）**：管理者输出低维"目标方向"，工作者执行；
- **目标条件策略**：一个策略 $\pi(a \mid s, g)$ 服务所有目标，用 HER（事后经验回放）把失败轨迹重标注成"对另一个目标成功的轨迹"。

数学上，选项框架的严格载体是**半马尔可夫决策过程（SMDP）**：把"执行一个选项"看作一个多步动作，贝尔曼方程升级为对**选项持续时间**积分的形式 $v(s) = \max_\omega \mathbb{E}\big[ r_0 + \gamma r_1 + \cdots + \gamma^{\tau-1} r_{\tau-1} + \gamma^{\tau} v(s') \big]$——注意折扣指数 $\tau$ 是随机变量（选项长度）。本章不展开 SMDP 理论，只需记住：分层 RL 的本质是**在第 1 章的贝尔曼方程之上再叠一层贝尔曼方程**（层内选动作、层间选项择），价值迭代/策略迭代的思想在每一层原样运转。

HRL 至今没有"杀手级通用算法"，其思想却广泛渗透：LLM agent 的"规划—子任务—执行"拆解、机器人技能库，都是选项思想的工程化。

## 5.5 AlphaGo 与 AlphaZero：搜索 × 学习的合体

**AlphaGo（Silver et al., *Nature*, 2016）** 击败李世石，架构三件套：

1. **策略网络** $p_\sigma$：CNN（衔接《深度学习》第 3 章）从人类棋谱监督学习（行为克隆），给出"人类认为的好棋"先验；
2. **自我博弈强化**：策略网络与自己对弈，用 REINFORCE 式更新（第 4 章）；价值网络 $v_\phi$ 从自我博弈局面预测胜负；
3. **MCTS（蒙特卡洛树搜索）**：对弈时把网络当"导航仪"——策略网络剪枝（选候选着法）、价值网络评估叶节点（替代随机 rollout），搜索结果又反过来构造新训练数据。**学习提供先验与估值，搜索负责当前局面的精算**——两者的分工是整个架构的魂。

**AlphaZero（Silver et al., *Science*, 2018）** 去掉人类棋谱与人工特征，从零自我博弈，统一围棋/国际象棋/将棋：单一网络输出 $(p, v)$（策略先验 + 局面价值），MCTS 自我对弈产出改进策略，网络迭代拟合搜索结果——"**网络指导搜索，搜索改进网络**"的自举飞轮。MuZero（*Science*, 2020）再进一步：连环境规则都不给，学习隐式模型（价值等价模型）供 MCTS 展望——把 5.3 节"学模型"与 5.5 节"搜索"合流。

**MCTS 的一次迭代分四步**（AlphaZero 版），每个根节点要重复数百至数千次：

1. **选择（select）**：从根出发，在每个内部节点按 $a^* = \arg\max_a \big[ Q(s,a) + c \cdot p_\theta(a \mid s) \frac{\sqrt{N_{\text{parent}}}}{1 + N(s,a)} \big]$ 走到未完全展开的节点（UCB 思想 + 策略先验引导）；
2. **扩展与求值（expand & evaluate）**：用网络对叶节点算出 $(p, v)$——**价值网络替代了 AlphaGo 前代的随机 rollout**，一次前向即可估值，快几个数量级；
3. **备份（backup）**：把 $v$ 沿搜索路径向上累加更新各节点的 $N, W, Q$（每层的"谁在走"决定价值符号视角）；
4. **行动与存档（play & store）**：访问次数分布 $\propto N^{1/\tau}$ 就是改进后的策略——它**强于网络自身的 $p_\theta$**（搜索即策略改进，对应第 1 章策略改进定理的搜索版），用它构造下一轮训练数据。

**对主课程的回望**：MCTS 的备份公式 $\max_a \sum_{s'} P(s' \mid s,a)[r + \gamma v^*(s')]$ 正是第 1 章贝尔曼最优方程的搜索树版；MCTS 中 $Q/N + c\sqrt{\ln N_{parent}/N}$ 的选择公式则是第 2 章探索-利用权衡（UCB 思想）在树上的实现。前三章的每个概念都在 AlphaZero 里找得到岗位。

## 5.6 RLHF 与 LLM 对齐：技术栈总览

**问题**：语言模型的预训练目标（下一 token 预测）与"人类觉得有用、诚实、无害"并不对齐——难写监督标签（"好回答"没有唯一正确答案），但**偏好比较容易**（A 比 B 好吗？）。RLHF 的流水线三段：

1. **SFT（监督微调）**：人类示范对话上行为克隆，得到 $\pi^{\text{SFT}}$（ BC：会"说话"）；
2. **奖励模型（RM）**：采集人类对成对回答的偏好 $(y_w \succ y_l)$，用 Bradley-Terry 模型 $P(y_w \succ y_l) = \sigma\big( r_\phi(x, y_w) - r_\phi(x, y_l) \big)$ 训练打分网络（损失即 5.9 节代码中的逻辑回归交叉熵）；RM 是"人类偏好的可微代理"；
3. **PPO 微调**：把 LM 当策略（4.5 节的伏笔兑现）：每轮采样 prompt，LM rollout 生成回答，RM 打分，加**KL 惩罚**——逐 token 计为 $-\beta \big( \log \pi_\theta(a_t \mid s_t) - \log \pi^{\text{SFT}}(a_t \mid s_t) \big)$（期望意义下即 KL 散度，见第 4 章重要性采样的对数形式），加进每步奖励后用 PPO 的 clip 目标更新。工程上还有价值头（critic，通常与策略共享主干）、参考模型冻结副本（SFT 参数的只读拷贝，只用于算 KL）、rollout 引擎（推理与训练混合调度，是 RLHF 工程的真正难点）等组件。典型规模感（InstructGPT 1.3B 时代）：RM 训练用数万~数十万条偏好对，PPO 阶段每轮数千 prompt、$\beta \approx 0.01 \sim 0.2$。

**奖励黑客（reward hacking）**是整条流水线的头号敌人：RM 只是偏好的有损代理，优化压力总会找到代理的漏洞（Goodhart 定律："当一个代理指标变成优化目标，它就不再是好的代理指标"）。三个经典形态，每个都能在你的极小流水线里复现：

- **长度作弊**：标注者隐式偏好详细回答 → RM 学出"长 = 好" → 策略输出超长废话，RM 分数飙升，真值崩坏；
- **谄媚（sycophancy）**：RM 从人类偏好中学到"顺着提问者"的信号 → 模型学会奉承而非纠错；
- **格式套路**：RM 对列表、加粗等"看起来专业"的格式打高分 → 模型输出空壳结构。

**一个 PPO 微调迭代的最小伪代码**（把第 4 章 4.7.3 与本节拼起来即为完整实现）：

```text
for each iteration:
    for batch of prompts (from prompt dataset):
        y ~ π_θ  rollout 生成回答                      # rollout 引擎（推理）
        r  = r_φ(x, y) − β·(log π_θ(y|x) − log π_SFT(y|x))   # RM 打分 + 逐 token KL 惩罚
        存入 buffer：(状态=已生成前缀, 动作=token, 奖励=r_t)
    用 buffer 上的优势估计（GAE）更新：
        θ ← argmax  L^CLIP(θ) − c1·(价值头 MSE) + c2·熵    # 与第 4 章公式逐字相同
    监控：RM 分数曲线、KL(π_θ‖π_SFT) 曲线、人工抽查样本
```

因此后续演化路线：PPO 简化（删除 critic 的 REINFORCE 变体）、RLAIF（AI 反馈替代人类）、DPO（绕开 RM 与 RL，直接在偏好对上做监督式损失）、过程奖励模型（PRM）——但**"偏好 → 奖励 → 策略优化"的骨架不变**，理解 PPO 仍是读懂一切对齐方法的前提。

## 5.7 开放问题（诚实的边界）

1. **样本效率**：人类看一次就会的动作，RL 要试百万次。粗略对比：监督学习的"每个样本贡献一次梯度"，RL 的"每个样本只负责环境一小步、还要被策略分布的漂移不断折旧"。基于模型、离线学习、迁移与元学习是三条主力路线，都未彻底解决。
2. **奖励设计**：奖励即规范（"reward is enough" 假说的另一面）——奖励写歪一寸，行为偏掉一丈（奖励黑客、规格博弈、规范博弈 specification gaming 的真实案例库已在 OpenAI 的文档中积累数十个）。IRL 与 RLHF 是对"奖励从哪来"的回答，但偏好的聚合（谁的偏好？多数暴政怎么办？）是社会技术问题，不是算法问题。
3. **安全与对齐**：探索的不可逆风险、分布外泛化、多智能体安全、可中断性（corrigibility）——目前多为"补丁式"工程，缺乏统一理论；CMDP 与拉格朗日方法（5.13 节）是目前最接近"工程可用"的一支。
4. **评估危机**：环境特定超参、种子方差大、基准饱和与过拟合（第 3 章练习 8 的一瞥）。Bongard 类泛化基准、Procgen、网络游戏中"未见关卡"的实验都表明：**在训练环境上的高分与真实能力可以完全脱钩**。通用性（在没见过的环境上零样本工作）是 2020 年代的主战场。

## 5.8 关键公式速查

| 公式 | 内容 | 适用条件 |
|---|---|---|
| $P(y_w \succ y_l) = \sigma(r_\phi(x,y_w) - r_\phi(x,y_l))$ | Bradley-Terry 偏好模型 | RM 训练 |
| $\mathcal{L}_{\text{CQL}} = \alpha\,\mathbb{E}_s[\log\sum_a e^{\hat q} - \mathbb{E}_{a\sim\mathcal D}\hat q] + \mathcal{L}_{\text{Bellman}}$ | 保守 Q 正则 | 离线数据 |
| Dyna：每真实步做 $N$ 次模型采样更新 | 混合真实/虚拟经验 | 学到的模型可信 |
| 选项 $\omega = (I, \pi_\omega, \beta)$ 与 SMDP 价值 | 分层 RL 的时间抽象 | HRL |
| MCTS 选择 $a^* = \arg\max_a \big[\frac{Q}{N} + c\sqrt{\frac{\ln N_{\text{parent}}}{N}}\big]$ | UCB 式树搜索 | AlphaGo/Zero |
| $J(\theta) = \mathbb{E}_{x \sim \mathcal{D}}\big[ r_\phi(x, y \sim \pi_\theta) - \beta\, \mathrm{KL}(\pi_\theta \| \pi^{\text{SFT}}) \big]$ | RLHF 的策略目标 | LLM 对齐 |

| 方向 | 先补什么 | 首选材料（真实存在） |

## 5.9 示例与案例

### 5.9.1 Dyna-Q：会"做梦"的 Q-learning（纯 numpy 可运行）

```python
# dyna_q.py —— Dyna-Q vs 纯 Q-learning（小网格世界，样本效率对比）
import numpy as np

class Maze:
    """5x5 网格：(0,0) 起点，(4,4) 目标 +10；每步 -1；撞墙原地。"""
    def __init__(self, n=5):
        self.n = n; self.goal = (n - 1, n - 1)
        self.acts = [(-1, 0), (0, 1), (1, 0), (0, -1)]
    def reset(self): return 0
    def step(self, s, a):
        r, c = divmod(s, self.n); dr, dc = self.acts[a]
        ns = min(max(r + dr, 0), self.n - 1) * self.n + min(max(c + dc, 0), self.n - 1)
        return ns, (10.0 if divmod(ns, self.n) == self.goal else -1.0), divmod(ns, self.n) == self.goal

def dyna_q(env, planning_steps=10, alpha=0.5, gamma=0.99, eps=0.1, episodes=100, seed=0):
    rng = np.random.default_rng(seed)
    nS, nA = env.n * env.n, 4
    Q, model = np.zeros((nS, nA)), {}
    def eps_greedy(s):
        return int(rng.integers(nA)) if rng.random() < eps else int(np.argmax(Q[s]))
    for ep in range(episodes):
        s, done = env.reset(), False
        while not done:
            a = eps_greedy(s)
            ns, r, done = env.step(s, a)
            Q[s, a] += alpha * (r + gamma * Q[ns].max() - Q[s, a])     # 真实经验更新
            model[(s, a)] = (ns, r)                                    # 学模型（记录）
            for _ in range(planning_steps):                            # "做梦"：虚拟更新
                ps, pa = rng.choice(list(model.keys()))                # 从已见 (s,a) 中随机挑一个
                pns, pr = model[(ps, pa)]
                Q[ps, pa] += alpha * (pr + gamma * Q[pns].max() - Q[ps, pa])
            s = ns
    return Q

if __name__ == "__main__":
    env = Maze()
    Q = dyna_q(env, planning_steps=0,  episodes=200, seed=1)   # 退化为纯 Q-learning
    Qd = dyna_q(env, planning_steps=10, episodes=40, seed=1)   # Dyna：仅 1/5 的真实交互
    print("纯 Q-learning(200轮) 从起点贪心动作:", int(np.argmax(Q[0])), " Q值:", round(Q[0].max(), 3))
    print("Dyna-Q(40轮)       从起点贪心动作:", int(np.argmax(Qd[0])), " Q值:", round(Qd[0].max(), 3))
    # 校验：8 步到目标，前 7 步各 -1、最后一步 +10（γ=0.99）
    # 理论最优 V(0) = -(1-γ^7)/(1-γ) + γ^7 × 10 ≈ 2.53
    print("理论最优 V(0) ≈ 2.53")
```

预期输出（起点向右或向下都是 8 步最优，贪心动作取哪个取决于平手时的遍历顺序；Q 值稳定逼近理论值）：

```text
纯 Q-learning(200轮) 从起点贪心动作: 2  Q值: 2.527
Dyna-Q(40轮)       从起点贪心动作: 2  Q值: 2.527
理论最优 V(0) ≈ 2.53
```

**读数解读**：`planning_steps=0` 退化为第 2 章的 Q-learning；每步追加 10 次"梦境更新"后，40 轮真实交互即达到 200 轮纯交互的精度（且都逼近理论值 2.53）——模型把每份经验放大了约 11 倍。改动 `planning_steps` 扫描 0/1/10/50，你会看到样本效率单调提升直到模型偏差抬头（本例模型无偏差，因为是确定性记录；练习 5 引入随机性后差异会出现）。

### 5.9.2 最小奖励模型：Bradley-Terry + 逻辑回归（sklearn 可运行）

```python
# mini_reward_model.py —— 用合成偏好数据训练最小奖励模型（RLHF 第 2 步的微缩版）
import numpy as np
from sklearn.linear_model import LogisticRegression

rng = np.random.default_rng(0)
N = 2000
# 想象每个 (prompt, response) 用 4 维特征描述：[有用性, 正确性, 长度, 谄媚度]
X = rng.normal(size=(N, 4))
true_w = np.array([1.5, 2.0, -0.3, -1.0])      # 真实偏好：有用+正确加分，冗长/谄媚扣分
score = X @ true_w + rng.normal(scale=0.5, size=N)   # 人类打分带噪声

# 构造成对偏好：每对取两个回答，分高者被人类选中
i, j = rng.integers(0, N, N), rng.integers(0, N, N)
feat = X[i] - X[j]                              # 特征差
y = (score[i] > score[j]).astype(int)           # 偏好标签

rm = LogisticRegression().fit(feat, y)          # Bradley-Terry = 对特征差的逻辑回归
print(f"偏好预测准确率 = {rm.score(feat, y):.3f}")
print(f"恢复的偏好方向(归一化) = {np.round(rm.coef_[0] / np.linalg.norm(rm.coef_[0]), 2)}")
print(f"真实偏好方向(归一化)   = {true_w / np.linalg.norm(true_w)}")
# 新样本打分：奖励模型本质是一个线性(或神经网络)打分函数
x_new = rng.normal(size=4)
print(f"新回答的奖励估计 = {rm.decision_function(x_new[None] - X[7][None])[0]:.3f}")
```

预期输出（偏好噪声 0.5 时准确率约 0.94；恢复方向与真实方向几乎重合）：

```text
偏好预测准确率 = 0.941
恢复的偏好方向(归一化) = [ 0.57  0.73 -0.11 -0.36]
真实偏好方向(归一化)   = [ 0.55  0.74 -0.11 -0.37]
新回答的奖励估计 = -0.309
```

**读数解读**：Bradley-Terry 的成对偏好模型与逻辑回归是**同一个模型**（对数几率差 = 奖励差）——真实 RLHF 只是把 4 维特征换成整个 LLM 的打分头、把合成偏好换成人类标注。这份代码是你理解 RLHF 第二步的最小实验台：练习 8 会让你把噪声调大、把维度换高，观察 RM 的"过拟合人类噪声"如何对应真实的 RM 过拟合问题。

## 5.10 常见误区与陷阱

1. **把离线 RL 当行为克隆**：BC 只学"数据怎么走"，离线 RL 要学"比数据更好"——OOD 动作查询是分水岭；用 BC 评估标准（拟合误差）衡量离线 RL 会漏掉最要命的外推错误。
2. **低估模型偏差的复利**：Dyna/MPC 中模型的小错误经多步规划指数放大——"模型准 99% × 展开 20 步"只剩 82%。展望步长是模型方法的第一超参。
3. **把 AlphaZero 的成功归给"深度学习"单因素**：它离身的两件法宝——MCTS 的精确搜索与自我博弈的课程结构——同样关键；仅用网络直接输出落子（无搜索）在围棋上远达不到职业水平。
4. **RLHF 三段缺一即崩**：跳过 SFT 直接 RL（策略根本没有可读语言基础）、跳过 KL 惩罚（奖励黑客失控）、RM 数据没有多样性（只会一种偏好）——三段式不是流水线装饰，是互相兜底。
5. **以为本章各方向是并列选项**：前沿的真实趋势是合流——MuZero=基于模型+搜索、Decision Transformer=离线+序列建模、RLAIF=RLHF+自我博弈式反馈。学"思想"而非"门派"。
