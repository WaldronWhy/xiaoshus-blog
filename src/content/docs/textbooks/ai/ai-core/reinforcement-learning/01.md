# 第 1 章 MDP 与动态规划：序贯决策的数学框架

> **本章定位**：全课程的地基。把《概率统计》第 3 章的条件期望与马尔可夫链升级为"智能体在随机环境中反复决策"的数学模型——马尔可夫决策过程（MDP），并完整推导整个强化学习的核心等式：贝尔曼方程。动态规划（策略迭代与价值迭代）是贝尔曼方程在"模型已知"情形下的精确解法，也是后续所有无模型方法（第 2 章）与深度方法（第 3、4 章）要逼近的参照系。

## 1.0 本章学习目标

学完本章，你能够：

1. 用五元组 $\langle \mathcal{S}, \mathcal{A}, P, R, \gamma \rangle$ 建模一个真实决策问题，并检验马尔可夫性是否（近似）成立；
2. 从定义出发，不看任何资料，完整推导状态价值函数与动作价值函数的贝尔曼期望方程与贝尔曼最优方程；
3. 用压缩映射论证价值迭代与策略迭代的收敛性，并说出两者在计算量与收敛方式上的差异；
4. 用纯 numpy 从零实现网格世界环境、策略迭代与价值迭代，并用 matplotlib 可视化价值函数与策略；
5. 解释"折扣因子 $\gamma$"的数学作用（保证回报有限）与行为作用（短期主义 vs 长期主义）。

## 1.1 智能体-环境交互：最小决策模型

在《机器学习》中，数据的形态是静态的：$\{(x_i, y_i)\}$ 给定，学习器被动接受。强化学习把学习者放进一个**会回应你动作的世界**：

- 在每个离散时刻 $t = 0, 1, 2, \dots$，智能体观测到环境状态 $S_t \in \mathcal{S}$，选择动作 $A_t \in \mathcal{A}$；
- 环境给出标量奖励 $R_{t+1} \in \mathbb{R}$ 和新状态 $S_{t+1}$；
- 循环往复，直到进入终止状态（episode 结束）或无限延续。

这条交互轨迹（trajectory）形如

$$S_0, A_0, R_1, S_1, A_1, R_2, S_2, \dots$$

**注意下标的约定**：$R_{t+1}, S_{t+1}$ 是对动作 $A_t$ 的回应——奖励与下一状态发生在"动作之后"，这个约定贯穿全课程与 Sutton & Barto 全书。

**智能体-环境边界（agent-environment boundary）在哪里？** 这不是物理问题而是建模问题：凡是智能体**无法直接控制**的东西都在"环境"一侧。对机器狗而言，腿部电机是智能体，地形与疲劳是环境；对下棋程序而言，棋盘与对手是环境，即使它们物理上"在同一个房间里"。同一套数学框架 $\mathcal{S}, \mathcal{A}, R$ 对两种情形一视同仁——这是 MDP 作为统一框架的威力。

## 1.2 MDP 五元组与马尔可夫性

**定义 1.1（马尔可夫决策过程，MDP）** 一个（有限）MDP 由五元组 $\langle \mathcal{S}, \mathcal{A}, P, R, \gamma \rangle$ 刻画：

- $\mathcal{S}$：状态集合（有限或可数）；
- $\mathcal{A}$：动作集合；
- $P: \mathcal{S} \times \mathcal{A} \times \mathcal{S} \to [0,1]$，转移核，$P(s' \mid s, a) = \Pr(S_{t+1} = s' \mid S_t = s, A_t = a)$；
- $R: \mathcal{S} \times \mathcal{A} \times \mathcal{S} \to \mathbb{R}$（或简化为 $r(s,a)$、$r(s)$），奖励函数，$r(s,a) = \mathbb{E}[R_{t+1} \mid S_t = s, A_t = a]$；
- $\gamma \in [0, 1]$：折扣因子（1.3 节）。

**马尔可夫性**：$P(s' \mid s, a)$ 只依赖当前状态与动作，不依赖更早的历史。形式化地说，对任意历史 $h_t = (s_0, a_0, \dots, s_t)$，

$$\Pr(S_{t+1} = s' \mid H_t = h_t, A_t = a) = \Pr(S_{t+1} = s' \mid S_t = s, A_t = a).$$

在[《概率统计》第 3 章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/03/)你已经见过马尔可夫链——它正是本定义中"动作退化成固定分布"的特例（$P(s' \mid s)$）。MDP = 马尔可夫链 + 控制权 + 奖励。

**马尔可夫性是建模假设而非物理定律**。下棋盘面天然马尔可夫（盘面即全部历史信息）；而部分可观测问题（如扑克：看不见对手手牌）严格来说不马尔可夫，实践中常用"把最近历史打包成状态"或信念状态近似处理（对应 POMDP 框架，本章练习 8）。**状态设计得好不好，直接决定问题是否（近似）马尔可夫——这是建模者的自由，也是责任**：第 3 章的 DQN 用最近 4 帧图像拼状态，正是在补救 Pong 看单帧不马尔可夫（球速方向不可见）的问题。

**策略（policy）**：智能体的行为准则，$\pi(a \mid s) = \Pr(A_t = a \mid S_t = s)$。强化学习的目标：找到一个策略 $\pi$，使某种"长期累积奖励"最大。

## 1.3 回报与折扣：给"长期"一个数

决策好坏不能只看单步奖励（为了吃一步棋牺牲整盘）。定义**回报（return）**为奖励的折扣累积：

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}.$$

$\gamma \in [0,1]$ 的三重身份：

1. **数学收银员**：若 $|R| \le R_{\max}$，则 $|G_t| \le \frac{R_{\max}}{1-\gamma}$，回报几乎必然有界——这使得期望存在，第 2 章的随机逼近收敛条件也需要它；
2. **递归结构制造者**（本章主角）：$G_t = R_{t+1} + \gamma G_{t+1}$——"总账"可以写成"这一步 + 打折后的总账"，贝尔曼方程全部威力源于这一行；
3. **行为调节器**：$\gamma \to 0$ 时智能体近视（只看眼前一步），$\gamma \to 1$ 时远视但学习更慢、方差更大。Atari 常用 $\gamma = 0.99$，棋类用 $\gamma = 1$（有限局）。

**分期付款的直觉**：把 $\gamma$ 理解为"明年的 1 元今天值多少"的利率倒数。$\gamma = 0.9$ 意味着 10 步之后的奖励只剩 $0.9^{10} \approx 0.35$ 倍——不是不重要，而是要乘一个时间折价。

## 1.4 价值函数与贝尔曼方程：完整推导

### 1.4.1 定义

给定策略 $\pi$，定义两个条件期望（条件期望的工具见[《概率统计》第 3 章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/03/)）：

$$v^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s], \qquad q^\pi(s, a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a],$$

分别叫**状态价值函数**与**动作价值函数**。$v^\pi(s)$ 回答"从 $s$ 出发一直按 $\pi$ 走，长期账面值多少"；$q^\pi(s,a)$ 回答"先试一步 $a$，之后按 $\pi$ 走呢"——它把"当前这一步的选择权"单独拎了出来，这正是第 2 章无模型方法都学 $q$ 的原因（评估一个动作不需要知道后续动作）。

两者关系（对 $\pi$ 下的动作取期望）：

$$v^\pi(s) = \sum_a \pi(a \mid s)\, q^\pi(s, a).$$

### 1.4.2 贝尔曼期望方程：五步推导

**定理 1.1（贝尔曼期望方程）** 对任意 MDP 与策略 $\pi$：

$$v^\pi(s) = \sum_a \pi(a \mid s) \sum_{s'} P(s' \mid s, a) \left[ r(s, a, s') + \gamma\, v^\pi(s') \right].$$

推导（每步依据随行标注）：

$$\begin{aligned}
v^\pi(s) 
&= \mathbb{E}_\pi[G_t \mid S_t = s] \\
&= \mathbb{E}_\pi\left[R_{t+1} + \gamma G_{t+1} \mid S_t = s\right] \qquad &\text{（回报的递归式，1.3 节恒等式）}\\
&= \mathbb{E}_\pi\left[R_{t+1} \mid S_t = s\right] + \gamma\, \mathbb{E}_\pi\left[G_{t+1} \mid S_t = s\right] \qquad &\text{（期望的线性性，《概率统计》第 3 章）}
\end{aligned}$$

对第一项，用全期望公式先对动作、再对下一状态展开：

$$\mathbb{E}_\pi[R_{t+1} \mid S_t = s] = \sum_a \pi(a \mid s) \sum_{s'} P(s' \mid s, a)\, r(s, a, s').$$

对第二项，关键是处理 $\mathbb{E}_\pi[G_{t+1} \mid S_t = s]$。$G_{t+1}$ 依赖的是 $S_{t+1}$ 及其之后的轨迹，而 $S_{t+1}$ 的分布由 $P$ 决定；给定 $S_{t+1} = s'$ 后，未来按 $\pi$ 演化，其条件期望正是 $v^\pi(s')$——这最后一步用到了**马尔可夫性**（未来与历史条件独立，给定当前状态）与**时不变性**（同样的 $v^\pi$ 定义适用于任何时刻）。于是：

$$\mathbb{E}_\pi\left[G_{t+1} \mid S_t = s\right] = \sum_{s'} P(s' \mid s, \pi(s))\, v^\pi(s') = \sum_a \pi(a \mid s) \sum_{s'} P(s' \mid s, a)\, v^\pi(s').$$

两项合并即得定理 1.1。对 $q^\pi$ 同理可得其贝尔曼方程：

$$q^\pi(s, a) = \sum_{s'} P(s' \mid s, a) \left[ r(s, a, s') + \gamma \sum_{a'} \pi(a' \mid s')\, q^\pi(s', a') \right].$$

**几何直觉**：贝尔曼方程说"我的价值 = 期望（这一步的甜头 + 打折后邻居们的价值）"。价值函数不是孤立数字，而是一张**自洽的账本**——每个格子的数必须等于邻居们的打折平均。这张"自洽账本"的意象请带着走完全课程：第 2 章 TD 学习的更新 $V(s) \leftarrow V(s) + \alpha(r + \gamma V(s') - V(s))$ 就是"发现账本不自洽就微调"，MC 则是"等整盘结束用真实总账修正"。

**求解视角**：把所有 $s$ 的贝尔曼方程摞在一起，是 $|\mathcal{S}|$ 个未知数、$|\mathcal{S}|$ 个（线性）方程的线性方程组 $v^\pi = r_\pi + \gamma P_\pi v^\pi$，其中 $P_\pi$ 是策略诱导的转移矩阵。故 $v^\pi = (I - \gamma P_\pi)^{-1} r_\pi$——解析解存在但求逆代价 $O(|\mathcal{S}|^3)$，实践中用迭代法（1.6 节）。

### 1.4.3 贝尔曼最优方程

换一种打法：我们不想要"某个 $\pi$ 的账本"，想要**最好的账本**。定义最优价值函数

$$v^*(s) = \max_\pi v^\pi(s), \qquad q^*(s, a) = \max_\pi q^\pi(s, a).$$

**定理 1.2（贝尔曼最优方程）**

$$v^*(s) = \max_a \sum_{s'} P(s' \mid s, a) \left[ r(s, a, s') + \gamma\, v^*(s') \right], \qquad q^*(s, a) = \sum_{s'} P(s' \mid s, a)\left[r(s,a,s') + \gamma \max_{a'} q^*(s', a')\right].$$

与期望方程唯一的区别：对外层动作求和换成了 $\max$——**最优策略在每一步都贪心地选当前最优动作**（以最优价值为参照的贪心不再是短视）。由 $q^*$ 可以一步读出最优策略：$\pi^*(s) = \arg\max_a q^*(s,a)$，且**最优策略总是存在的**（确定性贪心于 $q^*$ 即是）。

**为什么 $\max$ 后等式仍然成立**（不是显然的！）：对期望价值取 max，交换次序一般有 $\max_\pi \mathbb{E}[X] \ge \mathbb{E}[\max X]$ 的间隙；贝尔曼最优方程成立依赖于 MDP 的特殊结构——**当前动作完全决定下一状态分布，未来策略可以在看到 $s'$ 之后再选**（非 anticipativity 问题的特殊解法），加之 $v^*$ 的唯一性由压缩映射保证（1.6.2 节）。严格证明见 Sutton & Barto 3.6 节或练习 7 的提示。

## 1.5 动态规划总览：模型已知时的解法

当 $P$ 与 $r$ **已知**（如棋类规则、我们自建的环境），贝尔曼方程可以**直接迭代求解**——这就是动态规划（dynamic programming，DP），是《数据结构与算法》第 6 章"把大问题拆成自引用的小问题"在随机情形下的升级版。三个经典算法：

| 算法 | 迭代对象 | 更新规则 | 用途 |
|---|---|---|---|
| 策略评估 | $v^\pi$ | $v_{k+1}(s) = \sum_a \pi(a\mid s) \sum_{s'} P(s'\mid s,a)[r + \gamma v_k(s')]$ | 给定策略算价值 |
| 策略迭代 | $v^\pi \leftrightarrow \pi$ | 评估 + $\pi(s) = \arg\max_a q(s,a)$ 交替 | 求最优 |
| 价值迭代 | $v^*$ | $v_{k+1}(s) = \max_a \sum_{s'} P(s'\mid s,a)[r + \gamma v_k(s')]$ | 求最优（更快每步） |

### 1.5.1 策略迭代

策略迭代（policy iteration）在两个空间之间交替爬山：

1. **策略评估**：解（或迭代近似解）贝尔曼期望方程得到 $v^\pi$；
2. **策略改进**：构造贪心策略 $\pi'(s) = \arg\max_a \sum_{s'} P(s' \mid s, a)[r + \gamma v^\pi(s')]$。

**策略改进定理**：这样的 $\pi'$ 满足 $v^{\pi'}(s) \ge v^\pi(s)$ 对一切 $s$ 成立（证明是贝尔曼方程的简单不等式操作，练习 6）。由于有限 MDP 的策略只有有限个，且每轮改进要么严格变好要么已收敛，策略迭代**有限步内**终止于 $\pi^*$。

### 1.5.2 价值迭代与压缩映射收敛性

价值迭代（value iteration）干脆把"评估到收敛再改进"合并为一步：反复应用贝尔曼**最优**方程作为更新算子。

**定理 1.3（压缩映射收敛）** 定义算子 $(\mathcal{T}v)(s) = \max_a \sum_{s'} P(s' \mid s, a)[r(s,a,s') + \gamma v(s')]$。则 $\mathcal{T}$ 在 $\sup$ 范数下是 $\gamma$-压缩：

$$\|\mathcal{T}v - \mathcal{T}w\|_\infty \le \gamma \|v - w\|_\infty.$$

证明核心：$\max$ 是 1-Lipschitz 的（$\max_a f(a) - \max_a g(a) \le \max_a |f(a)-g(a)|$），而线性部分 $\sum_{s'} P \cdot \gamma(v - w)$ 的绝对值被 $\gamma \max_{s'}|v(s')-w(s')|$ 控制。由 Banach 不动点定理（《最优化方法》第 2 章迭代法收敛性的同款论证），$\mathcal{T}$ 有唯一不动点 $v^*$，且从任意 $v_0$ 出发以**线性收敛率 $\gamma$** 收敛：$\|v_k - v^*\|_\infty \le \gamma^k \|v_0 - v^*\|_\infty$。要达到精度 $\epsilon$ 需 $O\left(\frac{\log(1/\epsilon)}{1-\gamma}\right)$ 次扫描，每次扫描代价 $O(|\mathcal{S}|^2 |\mathcal{A}|)$。

**一句话比较**：策略迭代每轮更贵（要评估）但轮数少；价值迭代每轮便宜（一次扫描）但轮数多。$\gamma$ 接近 1 时价值迭代的收敛明显变慢（$1/(1-\gamma)$ 爆炸）——这个"折扣越接近 1 越难"的现象将在第 3、4 章以不同面目反复出现。

## 1.6 关键公式速查

| 公式 | 内容 | 适用条件 |
|---|---|---|
| $G_t = \sum_{k\ge0} \gamma^k R_{t+k+1}$，$G_t = R_{t+1} + \gamma G_{t+1}$ | 回报定义与递归 | $\gamma \in [0,1)$ 或有限终止 |
| $v^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$ | 状态价值定义 | 给定策略 $\pi$ |
| $v^\pi(s) = \sum_a \pi(a\mid s)\sum_{s'} P(s'\mid s,a)[r + \gamma v^\pi(s')]$ | 贝尔曼期望方程 | MDP，模型已知 |
| $q^\pi(s,a) = \sum_{s'} P(s'\mid s,a)[r + \gamma \sum_{a'} \pi(a'\mid s') q^\pi(s',a')]$ | $q$ 的贝尔曼期望方程 | 同上 |
| $v^\pi(s) = \sum_a \pi(a\mid s) q^\pi(s,a)$ | $v$ 与 $q$ 的关系 | 任意 $\pi$ |
| $v^*(s) = \max_a \sum_{s'} P(s'\mid s,a)[r + \gamma v^*(s')]$ | 贝尔曼最优方程 | 求最优 |
| $\pi^*(s) = \arg\max_a q^*(s,a)$ | 最优策略恢复 | $q^*$ 已知 |
| $\| \mathcal{T}v - \mathcal{T}w \|_\infty \le \gamma\|v-w\|_\infty$ | 压缩性 | 价值迭代算子 |

## 1.7 示例与案例

### 1.7.1 手算算例：一维链条上的贝尔曼方程

最简单的 MDP：一条 4 格链，状态 $\{0,1,2,3\}$，每步只能"右移"（最优情形），进入 3 号格（目标）获得 $+10$，其余每步 $-1$，$\gamma = 0.9$。逐格套用贝尔曼最优方程（右移是唯一合理动作）：

$$\begin{aligned}
v(3) &= 10 \quad \text{（终止，无后继）}\\
v(2) &= -1 + 0.9 \times v(3) = -1 + 9 = 8 \\
v(1) &= -1 + 0.9 \times v(2) = -1 + 7.2 = 6.2 \\
v(0) &= -1 + 0.9 \times v(1) = -1 + 5.58 = 4.58
\end{aligned}$$

自洽性检验：每个值恰好等于"一步甜头 + 打折邻居值"——账本自洽。若引入第二个动作"左移"，左移从 0 格出去原地不动拿 $-1$，则 $v(0)$ 的备选动作值为 $-1 + 0.9 v(0) = 3.122 < 4.58$，贪心仍选右移——策略不变，账本仍自洽。建议你把这个 4 格链条亲手在纸上迭代三遍：从 $v_0 \equiv 0$ 出发，观察 $v_k$ 如何一步步"从右向左"传播到收敛——这就是价值迭代的可视化雏形。

### 1.7.2 网格世界从零实现与可视化

下面用纯 numpy 实现一个 $4\times4$ 网格世界（起点左上、目标右下 $+100$、陷阱 $-10$、每步 $-1$、撞墙原地不动）以及价值迭代 + 策略迭代，并可视化。**这个环境类会在第 2 章直接复用**，请存好。

```python
# gridworld_dp.py —— 网格世界 + 策略迭代 + 价值迭代（纯 numpy，无第三方 RL 库）
import numpy as np

class GridWorld:
    """4x4 网格世界。状态用一维编号 s = row * 4 + col。
    奖励约定：每步 -1；进入目标(3,3)该步奖励 +100（含替代 -1，即净 +100）；
    进入陷阱(1,1)该步奖励 -10。撞墙原地不动（拿 -1）。"""
    def __init__(self, n=4, goal=(3, 3), pit=(1, 1),
                 step_reward=-1.0, goal_reward=100.0, pit_reward=-10.0):
        self.n, self.goal, self.pit = n, goal, pit
        self.step_reward, self.goal_reward, self.pit_reward = step_reward, goal_reward, pit_reward
        self.actions = [(-1, 0), (1, 0), (0, -1), (0, 1)]  # 上、下、左、右
        self.terminals = {self._idx(goal), self._idx(pit)}

    def _idx(self, pos): return pos[0] * self.n + pos[1]
    def _pos(self, s):   return divmod(s, self.n)

    def step(self, s, a):
        """确定性转移：返回 (next_state, reward, done)。这就是模型 P, r 已知的情形。"""
        if s in self.terminals:
            return s, 0.0, True
        r, c = self._pos(s); dr, dc = self.actions[a]
        nr, nc = min(max(r + dr, 0), self.n - 1), min(max(c + dc, 0), self.n - 1)
        ns = self._idx((nr, nc))
        if ns == self._idx(self.goal):  return ns, self.goal_reward, True
        if ns == self._idx(self.pit):   return ns, self.pit_reward, True
        return ns, self.step_reward, False

def value_iteration(env, gamma=0.99, theta=1e-10, max_iter=1000):
    nS, nA = env.n * env.n, len(env.actions)
    V = np.zeros(nS)
    for k in range(max_iter):
        delta = 0.0
        for s in range(nS):
            if s in env.terminals: continue
            q = np.array([env.step(s, a)[1] + gamma * (0.0 if env.step(s, a)[2] else V[env.step(s, a)[0]])
                          for a in range(nA)])
            new_v = q.max()
            delta = max(delta, abs(new_v - V[s])); V[s] = new_v
        if delta < theta: break            # 压缩映射：delta 每轮至少缩小 gamma 倍
    # 贪心恢复策略
    nS, nA = env.n * env.n, len(env.actions)
    pi = np.zeros(nS, dtype=int)
    for s in range(nS):
        if s in env.terminals: continue
        q = [env.step(s, a)[1] + gamma * (0.0 if env.step(s, a)[2] else V[env.step(s, a)[0]])
             for a in range(nA)]
        pi[s] = int(np.argmax(q))
    return V, pi, k + 1

def policy_iteration(env, gamma=0.99, theta=1e-10, max_iter=100):
    nS, nA = env.n * env.n, len(env.actions)
    pi = np.zeros(nS, dtype=int); V = np.zeros(nS)
    for outer in range(max_iter):
        # ---- 策略评估：解 v^pi 的贝尔曼期望方程（迭代到收敛）----
        while True:
            delta = 0.0
            for s in range(nS):
                if s in env.terminals: continue
                ns, r, done = env.step(s, pi[s])
                new_v = r + (0.0 if done else gamma * V[ns])
                delta = max(delta, abs(new_v - V[s])); V[s] = new_v
            if delta < theta: break
        # ---- 策略改进 ----
        stable = True
        for s in range(nS):
            if s in env.terminals: continue
            q = [env.step(s, a)[1] + gamma * (0.0 if env.step(s, a)[2] else V[env.step(s, a)[0]])
                 for a in range(nA)]
            best = int(np.argmax(q))
            if best != pi[s]: pi[s] = best; stable = False
        if stable: return V, pi, outer + 1   # 策略改进定理保证有限步收敛

def render(env, V, pi):
    arrows = ["↑", "↓", "←", "→"]
    for r in range(env.n):
        row_v, row_p = [], []
        for c in range(env.n):
            s = env._idx((r, c))
            if s == env._idx(env.goal): row_p.append("G")
            elif s == env._idx(env.pit): row_p.append("X")
            else: row_p.append(arrows[pi[s]])
            row_v.append(f"{V[s]:7.2f}")
        print(" ".join(row_v)); print(" ".join(f"{p:^7}" for p in row_p)); print()

if __name__ == "__main__":
    env = GridWorld()
    V, pi, k = value_iteration(env, gamma=0.99)
    print(f"价值迭代收敛于第 {k} 轮，V(起点) = {V[0]:.4f}")
    render(env, V, pi)
    V2, pi2, rounds = policy_iteration(env, gamma=0.99)
    print(f"策略迭代经 {rounds} 轮收敛，与价值迭代价值差 = {np.abs(V - V2).max():.2e}")
```

**读数检验**：起点 $(0,0)$ 到目标的曼哈顿距离为 6 步——前 5 步各 $-1$，最后一步进入目标拿 $+100$。最优回报 $= -\sum_{k=0}^{4}\gamma^k + \gamma^5 \times 100 = -4.901 + 95.099 = 90.198$——与代码输出一致。陷阱格与目标格是终止状态，其自身价值为 0（价值定义在"进入之前"的决策上）。收敛只用了 7 轮而非理论最坏界（$O(\frac{\log(1/\epsilon)}{1-\gamma})$），因为本实现采用**就地更新**（Gauss-Seidel 式）：同一次扫描中，后更新的状态直接用上先更新的邻居新值，信息沿"目标 $\to$ 起点"的反向索引路径一轮即可传遍全网格——这是同步扫描与异步扫描（Sutton & Barto 4.5 节）差异的活例子。这类"手工可算值"是调试 RL 代码最可靠的锚点（第 99 章项目二将要求你为自建环境写同样的单元测试）。

可视化（用 `matplotlib` 给 V 画热力图、给策略画箭头，代码约 10 行，留作练习 9）：你将看到价值从目标向外"衰减"、陷阱周围形成"洼地"——价值函数的地形图就是 MDP 的等高线图。平手时 `argmax` 取动作表中靠前者（上、下、左、右的顺序），所以多个等价最优路径中显示的是其中之一——把动作表顺序打乱重跑，策略箭头会变、价值不变，这本身就是对"最优价值唯一、最优策略不唯一"的一次免费实验。

## 1.8 常见误区与陷阱

1. **把 $R_{t+1}$ 写成 $R_t$**：奖励记于"动作之后"（对 $A_t$ 的回应是 $R_{t+1}, S_{t+1}$）。下标错一格，贝尔曼方程与代码全错且不易发现——建议在自写环境时用 `step()` 返回值顺序 `(s', r, done)` 强制自己理顺时序。
2. **混淆 $\max$ 与 $\mathbb{E}$ 的位置**：贝尔曼期望方程对动作求和（策略固定），最优方程对动作取 max（自由选）。把策略迭代的评估式里混入 $\max$，得到的不是 $v^\pi$ 而是别的东西。
3. **忘记 $\gamma$ 对应的幂次**：$G_t$ 中第 $k$ 步后的奖励折 $\gamma^k$；手算时数错步数（终点那一步算不算 $\gamma$）是高频错误。用 1.7.2 的 88.296 这类锚点值自查。
4. **以为 $\max_\pi \mathbb{E} = \mathbb{E}_{\max}$ 平凡成立**：贝尔曼最优方程的成立依赖 MDP 结构（动作决定转移），并非期望与 max 可无条件交换（练习 7）。
5. **实现策略迭代时用 $V$ 的旧值做策略改进**：策略改进必须基于**收敛后**的 $v^\pi$（或至少单调一致的中间值），否则可能振荡不终止。初学时宁可先做"评估到收敛"的朴素版本。
6. **$\gamma = 1$ + 环形结构 = 发散**：无终止状态时 $\gamma = 1$ 使回报期望可能无穷，价值迭代不收敛。自建环境务必检查"每个策略都能到达终止状态"（或固定 $\gamma < 1$）。
