# 第 1 章 逻辑基础：命题与一阶逻辑（练习出处：1.12 节）

## 基础题 1（对应 1.2.2–1.2.3：真值表与假言三段论）

> 用真值表验证：$(P \rightarrow Q) \land (Q \rightarrow R) \models P \rightarrow R$（假言三段论）。给出 8 行完整真值表。

**解答**：逻辑蕴含要求——凡是使前提 $(P \rightarrow Q) \land (Q \rightarrow R)$ 为真的赋值，必使结论 $P \rightarrow R$ 为真。逐行计算（T=真，F=假；$P \rightarrow Q$ 仅在 P 真 Q 假时为假）：

| $P$ | $Q$ | $R$ | $P{\to}Q$ | $Q{\to}R$ | $(P{\to}Q)\land(Q{\to}R)$ | $P{\to}R$ |
|---|---|---|---|---|---|---|
| T | T | T | T | T | **T** | T |
| T | T | F | T | F | F | F |
| T | F | T | F | T | F | T |
| T | F | F | F | T | F | F |
| F | T | T | T | T | **T** | T |
| F | T | F | T | F | F | T |
| F | F | T | T | T | **T** | T |
| F | F | F | T | T | **T** | T |

前提为真的行只有第 1、5、7、8 行（加粗），这 4 行结论 $P{\to}R$ 均为 T。没有任何一行"前提真而结论假"，故 $(P \rightarrow Q) \land (Q \rightarrow R) \models P \rightarrow R$。∎

**常见错误**：只比较"前提整体与结论的真值个数"而不检查逐行对应；或在第 2 行（P=T,Q=T,R=F）误判 $Q \to R$ 为真——务必记住蕴含只在"前件真、后件假"时为假。

## 基础题 2（对应 1.2.2：可满足性 / 有效性）

> 判断下列公式哪些可满足、哪些有效：(a) $(P \lor Q) \land \lnot P$；(b) $\lnot(P \rightarrow Q) \lor Q$；(c) $(P \rightarrow Q) \land P \land \lnot Q$。

**解答**（先化简再判，最后用真值表核对）：

- **(a)** $(P \lor Q) \land \lnot P$：$\lnot P$ 为真要求 $P{=}F$，此时 $P \lor Q \equiv Q$。故公式 $\equiv Q$。赋值 $(P{=}F, Q{=T})$ 使其为真，$(P{=}F, Q{=}F)$ 使其为假。→ **可满足、非有效**（与正文校验一致）。
- **(b)** $\lnot(P \rightarrow Q) \lor Q \equiv \lnot(\lnot P \lor Q) \lor Q \equiv (P \land \lnot Q) \lor Q$。若 $Q{=}T$ 为真；若 $Q{=}F$ 则 $\equiv P$。故公式 $\equiv P \lor Q$。赋值 $(F,T)$ 等使其为真，$(F,F)$ 使其为假。→ **可满足、非有效**。
- **(c)** $(P \rightarrow Q) \land P \land \lnot Q$：$P{=}T$ 且 $Q{=}F$ 使 $P \rightarrow Q$ 为假，而 $P \land \lnot Q$ 又强制恰好这个赋值。三条件互相矛盾，4 个赋值下全为假。→ **不可满足**（与正文校验一致）。

代码核验（真值表枚举，2 个原子共 4 行）：

```python
# (a) [F,T,F,F] -> 可满足非有效；(b) [F,T,T,T] -> 可满足非有效；(c) [F,F,F,F] -> 不可满足
```

**常见错误**：把 (b) 判成有效——它展开后是 $P \lor Q$，显然 $(F,F)$ 赋值下为假；把 (c) 判成"可满足（取 P=Q=T）"——漏掉了 $\lnot Q$ 这一支。

## 基础题 3（对应 1.3.1：化为 CNF）

> 把 $\lnot(P \land (Q \rightarrow R))$ 化为 CNF，写出每一步的变换依据。

**解答**（每步标注依据）：

1. 蕴含展开 $Q \rightarrow R \equiv \lnot Q \lor R$（正文 1.6 速查表"实质蕴含"）：
   $$\lnot\big(P \land (\lnot Q \lor R)\big)$$
2. 德摩根 $\lnot(A \land B) \equiv \lnot A \lor \lnot B$：
   $$\lnot P \lor \lnot(\lnot Q \lor R)$$
3. 德摩根 $\lnot(A \lor B) \equiv \lnot A \land \lnot B$ + 双重否定 $\lnot\lnot Q \equiv Q$：
   $$\lnot P \lor (Q \land \lnot R)$$
4. 分配律 $A \lor (B \land C) \equiv (A \lor B) \land (A \lor C)$（取 $A=\lnot P, B=Q, C=\lnot R$）：
   $$(\lnot P \lor Q) \land (\lnot P \lor \lnot R)$$

此即 CNF（两个子句的合取），与正文校验值 $(\lnot P \lor Q) \land (\lnot P \lor \lnot R)$ **一致**。用 1.7 求值器做等价性校验（3 个原子全枚举，两公式在全部 8 个赋值下真值相同）——代码验证输出 `练习3 CNF 等价校验: True`。

**常见错误**：第 3 步忘记双否消去，写成 $\lnot P \lor (\lnot\lnot Q \land \lnot R)$ 后卡住；或第 4 步分配时把 $\lnot P$ 漏配给第二个合取支。

## 基础题 4（对应 1.4.2：合一算法）

> 对 $Loves(x, y)$ 与 $Loves(y, x)$ 执行合一算法，逐步写出 $\theta$ 的演化。

**解答**：按 Robinson 递归算法（先应用已有代入、再逐对参数合一）执行，记 $\theta$ 初始为空：

1. `Unify(Loves(x,y), Loves(y,x), {})`：两者是复合项，谓词符相同（`Loves`）、参数个数相同（2），进入逐参数合一；
2. **第一对参数** `Unify(x, y, {})`：应用 $\theta={}$ 后仍为 $x, y$；二者不相同；$x$ 是变量 → 返回 $\theta_1 = \{x/y\}$（把 $x$ 替换为 $y$）。发生检查：$y$ 中不含 $x$，通过；
3. **第二对参数** `Unify(y, x, {x/y})`：先应用已有代入——$y\theta = y$（$y$ 不在 $\theta$ 的定义域中），$x\theta = y$；二者相同 → 直接返回当前 $\theta$；
4. 所有参数合一完毕，返回累积代入。

$$\text{MGU} = \{x/y\}$$

代入后两式都变成 $Loves(y, y)$。两点说明：

- **MGU 在换名意义下唯一**：对称地从第二对参数出发会得到 $\{y/x\}$（两式都变成 $Loves(x,x)$），它与 $\{x/y\}$ 只差约束变量的改名，是"同一个"MGU；
- **警惕自反合一**：本例把任意 $Loves(x,y)$ 都"卷"成自反形式，说明合一只关心语法结构、不知道"爱是反自反的"。工程实现中若先随机地合一了第二对参数（得 $\{y/x\}$），第一对参数随之自动满足——不同合一顺序会得到换名等价的结果，但若不做发生检查，$x$ 与 $f(x)$ 这类输入会让程序构造无限项并死循环（正文 1.8 误区 3）。

## 进阶题 5（对应 1.4.3：归结反演证明 $\exists x\, Mortal(x)$）

> 手工完成 1.4.3 节知识库下 "$\exists x\, Mortal(x)$" 的反演证明。

**解答**：

**第一步：子句化。** 知识库两条公理已接近子句形：

- (1) $\forall x\,(Human(x) \rightarrow Mortal(x))$ → 消蕴含 → $\lnot Human(x) \lor Mortal(x)$（全称量词隐去），子句 (1)：$\lnot Human(x) \lor Mortal(x)$；
- (2) $Human(socrates)$，子句 (2)。

**第二步：结论取反并子句化。** 待证 $\alpha = \exists x\, Mortal(x)$，取反：

$$\lnot \exists x\, Mortal(x) \;\equiv\; \forall x\, \lnot Mortal(x) \quad (\text{量词否定等价，正文 1.4.1})$$

注意一个细节：这里 $x$ 是**全称**量词约束的变量，子句化时只需变量标准化改名（避免与子句 (1) 的 $x$ 混淆），**不需要引入 Skolem 常量**——Skolem 化针对的是存在量词，而存在量词在取反后已经消失。（题目提示说"再 Skolem 化"，严格说此步无 Skolem 项可引入；若把待证结论换成含存在量词的形式才会出现。）

- (3) $\lnot Mortal(u)$（$u$ 为新变量）。

**第三步：归结，直到空子句。**

- 归结 (1) 与 (3)：互补对 $Mortal(x)$ 与 $\lnot Mortal(u)$，合一 $\text{MGU} = \{x/u\}$（两个变量合一，取最少约束替换），消去互补对，得
  $$(4)\quad \lnot Human(u)$$
- 归结 (4) 与 (2)：互补对 $Human(u)$ 与 $Human(socrates)$，合一 $\text{MGU} = \{u/socrates\}$，得
  $$(5)\quad \square \ (\text{空子句})$$

空子句意味着子句集 $\{(1),(2),(3)\}$ 不可满足，故原知识库 $\models \exists x\, Mortal(x)$。∎

**常见错误**：把待证结论 $\exists x\, Mortal(x)$ 直接加入子句集（那是在证明一致性，不是反演——正文 1.8 误区 5）；或在第二步把 $\lnot\exists$ 化成 $\exists\lnot$（方向搞反，正确方向是 $\lnot\exists \equiv \forall\lnot$）。

## 进阶题 6（对应 1.7 案例 2：求值器验证等价）

> 用 1.7 的求值器验证：$P \rightarrow Q$ 与 $\lnot Q \rightarrow \lnot P$ 逻辑等价（逆否律），并验证自选公式的等价类。

**解答**：逻辑等价的判定式：$f \equiv g$ 当且仅当 $f \leftrightarrow g$ 是重言式（等价地，在全部赋值下逐点比较）。参考实现与真实运行输出：

```python
# 运行环境：Python 3.8+，无第三方依赖
import itertools

def atoms(f):
    t = f[0]
    if t == 'atom': return {f[1]}
    if t == 'not':  return atoms(f[1])
    return atoms(f[1]) | atoms(f[2])

def evaluate(f, model):
    t = f[0]
    if t == 'atom':    return model[f[1]]
    if t == 'not':     return not evaluate(f[1], model)
    if t == 'and':     return evaluate(f[1], model) and evaluate(f[2], model)
    if t == 'or':      return evaluate(f[1], model) or evaluate(f[2], model)
    if t == 'implies': return (not evaluate(f[1], model)) or evaluate(f[2], model)
    if t == 'iff':     return evaluate(f[1], model) == evaluate(f[2], model)

def logically_equiv(f, g):
    """f ≡ g ⟺ f↔g 是重言式：对两个公式全部原子的所有赋值逐点比较。"""
    vs = sorted(atoms(f) | atoms(g))
    return all(evaluate(f, m) == evaluate(g, m)
               for m in (dict(zip(vs, bits))
                         for bits in itertools.product([False, True], repeat=len(vs))))

P, Q, R = ('atom','P'), ('atom','Q'), ('atom','R')
print("逆否律 P→Q ≡ ¬Q→¬P :", logically_equiv(('implies',P,Q),
                                             ('implies',('not',Q),('not',P))))
print("分配律 P∧(Q∨R) ≡ (P∧Q)∨(P∧R) :", logically_equiv(('and',P,('or',Q,R)),
                                                        ('or',('and',P,Q),('and',P,R))))
print("P→(Q∧R) ≡ (P→Q)∧(P→R) :", logically_equiv(('implies',P,('and',Q,R)),
                                                  ('and',('implies',P,Q),('implies',P,R))))
print("对照 P→Q ≡ Q→P :", logically_equiv(('implies',P,Q), ('implies',Q,P)))

# 预期输出（实际运行验证）：
# 逆否律 P→Q ≡ ¬Q→¬P : True
# 分配律 P∧(Q∨R) ≡ (P∧Q)∨(P∧R) : True
# P→(Q∧R) ≡ (P→Q)∧(P→R) : True
# 对照 P→Q ≡ Q→P : False
```

前三个"正例"均验证为等价，第四个"反例对照"（交换前后件）不为等价——说明判定器不是"什么都返回 True"。

**对原题校验语方的更正（勘误 3）**：原题"n=3 时共 218 个布尔函数中……"的数字有误。$n$ 个原子的布尔函数总数是 $2^{2^n}$：$n=2$ 时 $2^4=16$ 个，$n=3$ 时 $2^8=\mathbf{256}$ 个。原题自我修正为"验证自选公式的等价类"，上面三个等价类即为按此执行的答案。

## 进阶题 7（对应 1.3.2 / 1.7 案例 3：DPLL + 纯文字消除 + 3-SAT 相变）

> 给 1.7 的 DPLL 加入纯文字消除规则，并在随机生成的 3-SAT 实例（n=10,20,30，子句/变量比 4.3）上统计求解时间，观察"相变"现象附近耗时的陡增。

**解答**：完整可运行实现（固定随机种子，实际运行验证）：

```python
# 运行环境：Python 3.8+，无第三方依赖
import random, time

def substitute(clauses, lit):
    """对文字 lit 赋真值后化简子句集；返回 None 表示冲突（出现空子句）。"""
    out = []
    for cl in clauses:
        if lit in cl:                      # 子句被满足，删除
            continue
        neg = (lit[0], not lit[1])
        new = tuple(l for l in cl if l != neg)
        if not new:                        # 空子句 -> 冲突
            return None
        out.append(new)
    return out

def pure_literals(clauses):
    """纯文字：出现且仅以一种极性出现的符号。"""
    pos, neg = set(), set()
    for cl in clauses:
        for (s, p) in cl:
            (pos if p else neg).add(s)
    return [(s, True) for s in pos - neg] + [(s, False) for s in neg - pos]

def dpll(clauses, assign=None, use_pure=True):
    assign = assign or {}
    clauses = list(clauses)
    changed = True
    while changed:                         # 1. 单元传播
        changed = False
        for cl in clauses:
            if len(cl) == 1:
                lit = cl[0]
                clauses = substitute(clauses, lit)
                if clauses is None: return None
                assign[lit[0]] = lit[1]
                changed = True
                break
    if not clauses: return assign
    if use_pure:                           # 2. 纯文字消除（本次练习新增）
        for lit in pure_literals(clauses):
            clauses = substitute(clauses, lit)
            if clauses is None: return None
            assign[lit[0]] = lit[1]
        if not clauses: return assign
    sym = clauses[0][0][0]                 # 3. 决策 + 回溯
    for val in (True, False):
        res = dpll(substitute(clauses, (sym, val)), {**assign, sym: val}, use_pure)
        if res is not None: return res
    return None

def random_3sat(n, m, rng):
    """m 条随机 3-CNF 子句（每条取 3 个不同变量、随机极性）。"""
    return [tuple((f"x{v}", rng.random() < 0.5) for v in rng.sample(range(n), 3))
            for _ in range(m)]

rng = random.Random(0)
for n in (10, 20, 30):
    print(f"\n--- n={n} ---")
    print(f"{'ratio':>5} {'sat率':>6} {'平均时间(ms)':>12}")
    for ratio in (3.0, 3.6, 4.0, 4.3, 4.6, 5.0, 5.5, 6.0):
        m = int(n * ratio)
        trials, sat_cnt, t_total = 40, 0, 0.0
        for _ in range(trials):
            cls = random_3sat(n, m, rng)
            t0 = time.perf_counter()
            res = dpll(cls, use_pure=True)
            t_total += time.perf_counter() - t0
            if res is not None: sat_cnt += 1
        print(f"{ratio:>5.1f} {sat_cnt/trials:>6.2f} {t_total/trials*1000:>12.2f}")
```

**观察与解读**：

## 开放题 8（对应 1.5 节局限 2：封闭世界假设）

> 封闭世界假设下，"数据库中无 $Fly(tweety)$" 蕴含 $\lnot Fly(tweety)$。这如何在经典逻辑中不可表达？它与 LLM "用训练分布代替事实核查"的行为有何结构相似性？

**解答要点**（分三层）：

**（1）为什么不可表达。** 对**单个**命题写 $\lnot Fly(tweety)$ 当然可行；不可表达的是那条**规则本身**："对所有未在知识库中出现的原子 $p$，断言 $\lnot p$"。这条规则有两个逻辑上的拦路虎：

- **自指性**：规则引用了"知识库里有什么"，即以理论自身为谈论对象。经典一阶逻辑的公理谈论世界，不谈论公理集自己；要对知识库做内省需要元逻辑/可证性逻辑的装置，超出经典逻辑的表达范围；
- **单调性与 CWA 冲突**：经典逻辑是单调的——加前提不会撤销结论。CWA 的结论 $\lnot Fly(tweety)$ 却会在加入 $Fly(tweety)$ 后被撤销（非单调）。一阶逻辑的可靠推理规则（如归结）在单调语义下不可能导出这类"可被新信息撤销"的结论。形式化处理需要非单调逻辑（缺省逻辑、封闭世界数据补充等）或数据库的元级约定——它们都明确站在经典逻辑之外。

**（2）与 LLM 行为的结构相似性。** 参数化知识本质上是一个**隐式封闭世界**：训练分布中"高频共现"的角色近似于"知识库中存在"，未见/低频则被下一词分布边缘化。相似点有三：

- **把"缺席"当"否定"**：知识库无 $Fly(tweety)$ → 断言 Tweety 不会飞；训练数据中某事实稀疏 → 模型倾向给出"不符合事实"或"编一个符合分布的替代"的答案——都是 absence of evidence 被当成 evidence of absence；
- **非单调更新困难**：CWA 的结论会被新事实撤销；LLM 的参数化知识同样难以被单条新事实修正（5.3 节：改一条事实需重训练且可能牵连崩塌）；
- **缺元判断**：CWA 系统不区分"我知道没有"与"我不知道"；LLM 在"该查证"的位置上不产生查证信号，直接用流利语言填满（5.6 节：流利度与证成度解耦）。

**（3）对应解法也相似**：数据库世界用开放世界语义 + 显式的 negation-as-failure 标注；LLM 世界用检索注入（RAG/KG-RAG）把"缺席"外化为"库里没查到"的可审计陈述。两者都把"未知"从系统内部搬到可检视的边界上。

## 挑战题 9（对应 1.4.3：归结的可靠性与反驳完备性）

> 证明归结规则保真；进一步概述归结对命题逻辑的反驳完备性证明思路。

**第一部分：保真性（可靠性）证明。**

设子句 $C_1 = A \lor P$，$C_2 = B \lor \lnot P$，归结结论 $C = A \lor B$。任取使 $C_1, C_2$ 均为真的赋值 $I$，按 $P$ 在 $I$ 下的真值分情况：

- **情形 1：$I(P) = \text{T}$。** 则 $C_2$ 中的 $\lnot P$ 为假，而 $C_2 = B \lor \lnot P$ 为真，只能是 $B$ 为真（析取式为真且一支为假，另一支必真）。$B$ 真推出 $A \lor B$ 真；
- **情形 2：$I(P) = \text{F}$。** 则 $C_1$ 中的 $P$ 为假，$C_1 = A \lor P$ 为真推出 $A$ 为真，同样 $A \lor B$ 真。

两种情形下 $I \models C$，故 $\{C_1, C_2\} \models C$，归结规则保真。∎

一阶情形：先合一得 MGU $\theta$，基例化后即化为命题情形——由"$\text{MGU}$ 使两子句的例化互补"可知 $\{C_1, C_2\} \models (C_1\theta \lor C_2\theta 的消解)$，可靠性随例化继承。

推论（反演的合法性）：由保真性，从 $KB \cup \{\lnot\alpha\}$ 归结出的每条子句都被其蕴含；空子句被任何赋值弄假（空析取为假），故若能推出空子句，则 $KB \cup \{\lnot\alpha\}$ 不可满足，由对偶定理得 $KB \models \alpha$。

**第二部分：反驳完备性证明思路（命题情形）。**

目标：若子句集 $S$ 不可满足，则归结必能推出空子句。经典证明（Davis–Putnam 风格）按**基例（ground）情形 + 归纳 + 提升**三步走：

1. **基例归纳**：对 $S$ 中出现的不同原子个数 $k$ 归纳。
   - $k=0$：$S$ 只含空子句（无原子的子句只能是空子句），已成立；
   - 归纳步：取一个原子 $P$，把 $S$ 分为三类：含 $P$ 的子句集 $S_P$、含 $\lnot P$ 的 $S_{\lnot P}$、两者都不含的 $S_0$。构造 $S'$：把 $S_P$ 与 $S_{\lnot P}$ 中的 $P$（相应地 $\lnot P$）**直接删掉**（即对 $S$ 做关于 $P$ 的全部归结并把结果与 $S_0$ 合并）。关键引理：$S$ 不可满足 $\Rightarrow$ $S'$ 不可满足（若 $S'$ 有模型，按其在 $P$ 上的取值回填被删文字即可复原 $S$ 的模型，矛盾）。$S'$ 中出现的原子比 $S$ 少一个，由归纳假设 $S'$ 存在归结反驳；把该反驳中被"直接删掉"的步骤替换为对应的归结步骤（先与 $P$/$\lnot P$ 的子句归结，相当于把删除还原为消解），即得 $S$ 的归结反驳；
2. **提升（lifting）到含变量的子句**：提升引理——若两条基例化子句 $C_1\sigma_1, C_2\sigma_2$ 有归结式 $C'$，则原子句 $C_1, C_2$ 存在归结式（或其因子）使 $C'$ 是它的例化。于是基例层每一步反驳都能被一阶层的归结模拟；
3. **接通 Herbrand 定理**：一阶子句集不可满足 $\iff$ 其 Herbrand 域上的全部基例化实例集不可满足（Herbrand 定理）。由 1，基例层存在反驳；由 2，提升为一阶归结反驳。∎

细节难点（供进一步阅读时留意）：归纳步中需要**因子化**（factorization，合并子句内相同文字）处理 $P$ 在同一子句中出现多次的情况；完整证明见 Chang & Lee《Symbolic Logic and Mechanical Theorem Proving》第 4–5 章（正文 1.10 已列）。

## 挑战题 10（对应 1.3.1：Tseitin 变换）

> 实现 Tseitin 变换，把任意命题公式在线性时间内转为可满足性等价的 CNF，并用 1.7 求值器抽查 5 个公式的可满足性一致性。

**解答**：

**思想**：不为整式展开分配律（那会指数爆炸），而是给每个**子公式**（门）引入一个新变量 $g$，加"定义子句"强制 $g \leftrightarrow$ 子公式。每个联结词固定产生常数条子句，子句总数与公式节点数成线性。变换后 CNF 与原式**可满足性等价**（equisatisfiable）而非逻辑等价——CNF 有额外变量，限制到原变量上才还原原式语义。

各联结词的定义子句（设门变量 $g$，子结点 $a, b$）：

- $g \leftrightarrow \lnot a$：$(g \lor a) \land (\lnot g \lor \lnot a)$
- $g \leftrightarrow (a \land b)$：$(g \lor \lnot a \lor \lnot b) \land (\lnot g \lor a) \land (\lnot g \lor b)$
- $g \leftrightarrow (a \lor b)$：$(\lnot g \lor a \lor b) \land (g \lor \lnot a) \land (g \lor \lnot b)$
- $g \leftrightarrow (a \rightarrow b)$：$(\lnot g \lor \lnot a \lor b) \land (g \lor a) \land (g \lor \lnot b)$
- $g \leftrightarrow (a \leftrightarrow b)$：四条子句覆盖 $g,a,b$ 中偶数个否定的组合

最后加单元子句 $(root)$ 把整式钉为真。

```python
# 运行环境：Python 3.8+，无第三方依赖
import itertools

def atoms(f):
    t = f[0]
    if t == 'atom': return {f[1]}
    if t == 'not':  return atoms(f[1])
    return atoms(f[1]) | atoms(f[2])

def evaluate(f, model):
    t = f[0]
    if t == 'atom':    return model[f[1]]
    if t == 'not':     return not evaluate(f[1], model)
    if t == 'and':     return evaluate(f[1], model) and evaluate(f[2], model)
    if t == 'or':      return evaluate(f[1], model) or evaluate(f[2], model)
    if t == 'implies': return (not evaluate(f[1], model)) or evaluate(f[2], model)

def is_satisfiable_bruteforce(f):
    vs = sorted(atoms(f))
    return any(evaluate(f, dict(zip(vs, bits)))
               for bits in itertools.product([False, True], repeat=len(vs)))

def lit(name, positive=True):
    return (name, positive)

def tseitin(f):
    """返回 (cnf, 根变量)。每个子公式一个门变量；子句数 O(公式节点数)。"""
    counter, clauses = [0], []
    def enc(g):
        t = g[0]
        if t == 'atom':
            return g[1]                       # 原子直接用自身符号
        counter[0] += 1
        v = f"__g{counter[0]}"                # 门变量
        if t == 'not':
            a = enc(g[1])
            clauses.extend([(lit(v), lit(a)),                       # v ∨ a
                            (lit(v, False), lit(a, False))])        # ¬v ∨ ¬a
        else:
            a, b = enc(g[1]), enc(g[2])
            if t == 'and':
                clauses.extend([(lit(v), lit(a, False), lit(b, False)),
                                (lit(v, False), lit(a)),
                                (lit(v, False), lit(b))])
            elif t == 'or':
                clauses.extend([(lit(v, False), lit(a), lit(b)),
                                (lit(v), lit(a, False)),
                                (lit(v), lit(b, False))])
            elif t == 'implies':
                clauses.extend([(lit(v, False), lit(a, False), lit(b)),
                                (lit(v), lit(a)),
                                (lit(v), lit(b, False))])
            elif t == 'iff':
                clauses.extend([(lit(v), lit(a), lit(b)),
                                (lit(v), lit(a, False), lit(b, False)),
                                (lit(v, False), lit(a), lit(b, False)),
                                (lit(v, False), lit(a, False), lit(b))])
            else:
                raise ValueError(t)
        return v
    root = enc(f)
    clauses.append((lit(root),))          # 根门 = 真
    return clauses, root

def substitute(clauses, l):
    out = []
    for cl in clauses:
        if l in cl: continue
        new = tuple(x for x in cl if x != (l[0], not l[1]))
        if not new: return None
        out.append(new)
    return out

def dpll_cnf(clauses):
    clauses = list(clauses)
    while True:                            # 单元传播
        units = [cl[0] for cl in clauses if len(cl) == 1]
        if not units: break
        clauses = substitute(clauses, units[0])
        if clauses is None: return None
        if not clauses: return {}
    if not clauses: return {}
    sym = clauses[0][0][0]                 # 决策 + 回溯
    for val in (True, False):
        res = dpll_cnf(substitute(clauses, (sym, val)))
        if res is not None: return {**res, sym: val}
    return None

P, Q, R = ('atom','P'), ('atom','Q'), ('atom','R')
tests = [
    ("(P→Q)→(¬Q→¬P) [重言式]", ('implies', ('implies',P,Q), ('implies',('not',Q),('not',P)))),
    ("P∧¬P [矛盾]",             ('and', P, ('not', P))),
    ("(P∨Q)∧¬P [可满足非有效]", ('and', ('or',P,Q), ('not',P))),
    ("(P∧Q)∨(¬P∧¬Q) [可满足]", ('or', ('and',P,Q), ('and',('not',P),('not',Q)))),
    ("(P→Q)∧P∧¬Q [矛盾]",      ('and', ('implies',P,Q), ('and', P, ('not', Q)))),
]
for name, f in tests:
    brute = is_satisfiable_bruteforce(f)
    cnf, _ = tseitin(f)
    res = dpll_cnf(cnf)
    print(f"{name:<24} 暴力SAT={str(brute):<5} Tseitin+DPLL={str(res is not None):<5} "
          f"一致={ (res is not None) == brute }")

# 预期输出（实际运行验证）：
# (P→Q)→(¬Q→¬P) [重言式]   暴力SAT=True  Tseitin+DPLL=True  一致=True
# P∧¬P [矛盾]              暴力SAT=False Tseitin+DPLL=False 一致=True
# (P∨Q)∧¬P [可满足非有效]   暴力SAT=True  Tseitin+DPLL=True  一致=True
# (P∧Q)∨(¬P∧¬Q) [可满足]   暴力SAT=True  Tseitin+DPLL=True  一致=True
# (P→Q)∧P∧¬Q [矛盾]        暴力SAT=False Tseitin+DPLL=False 一致=True
# 全部一致。
```

**等价性论证**（为什么"可满足性等价"成立）：

- （→）若原式 $f$ 有模型 $M$，把每个门变量的值按其子公式在 $M$ 下的真值补齐，即满足全部定义子句与根单元子句——CNF 可满足；
- （←）若 CNF 有模型，根门为真，而定义子句逐门强制"门值 = 子公式真值"（每组定义子句恰好在门变量取对应真值时才可满足），归纳到根即 $f$ 在原变量限制下为真——原式可满足；
- **线性性**：公式有 $N$ 个节点（联结词+原子），产生至多 $N$ 个门、每个门常数条子句，总规模 $O(N)$——对比直接分配律展开的指数爆炸，这就是 CDCL 求解器一律吃 Tseitin CNF 的原因。

# 运行环境：pip install networkx
def out_rel(kg, entity, relation):
    """正向一跳：entity --relation--> ? 的全部尾实体。"""
    return [v for _, v, d in kg.out_edges(entity, data=True) if d['relation'] == relation]

def in_rel(kg, entity, relation):
    """反向一跳：? --relation--> entity 的全部头实体。"""
    return [h for h, _, d in kg.in_edges(entity, data=True) if d['relation'] == relation]

# 第 1 个固定跳调用：角色与其作品（?work 主角 ?character）
results = []
for role in in_rel(kg, "菩提祖师", "师从"):      # ?character 师从 菩提祖师
    for work in in_rel(kg, role, "主角"):        # ?work 主角 ?character
        if "小说" in out_rel(kg, work, "体裁"):   # ?work 体裁 "小说"（过滤）
            results += [(a, work) for a in in_rel(kg, work, "创作")]  # ?author 创作 ?work

print("查询结果(?author):", sorted({a for a, _ in results}))
# 预期输出（实际运行验证）：
# 查询结果(?author): ['吴承恩']
```

## 基础题 4（对应 2.2.1：URI 与实体歧义）

> 解释 URI 为什么能缓解同名实体问题，又为什么不能完全解决。

**解答要点**：

- **能缓解的原因**：URI 是**全局唯一标识符**（如 Wikidata 的 `Q151`），把"同名不同物"在标识层面分开——小说《西游记》与电视剧《西游记》可以各有一个 URI；"指向哪个实体"从字符串匹配（脆弱、有歧义）变成标识符比较（精确）。rdf:type 陈述再把每个 URI 挂到模式层类型上，为消歧提供类型检查依据；
- **不能完全解决的原因**（三层）：
  1. **识别问题依然存在**：文本 mention → URI 的映射（实体链接，2.3.3）是独立任务，字符串本身不带 URI，"这个'西游记'指哪个 URI"仍需候选生成 + 排序消歧，错误照旧发生；
  2. **URI 自身的碎片化**：同一现实实体可能被不同来源各发一个 URI（需要 `owl:sameAs` 对齐），反之同一 URI 也可能被错误复用——URI 唯一性是"约定"而非"事实"；
  3. **错误传播**：一旦对齐错误，该实体的全部边都会错连，且事后清理成本极高（正文 2.8 误区 3）。
- 一句话总结：**URI 解决"命名"问题，不解决"指称"（grounding）问题**；后者是对齐与验证的活。

    ("孙悟空", "师从", "菩提祖师"), ("六小龄童", "饰演", "孙悟空"),
    ("六小龄童", "职业", "演员"),
]
kg = nx.MultiDiGraph()
for h, r, t in triples:
    kg.add_edge(h, t, relation=r)

def paths_of_length(kg, src, k, allow_repeat_edges=True):
    """有向口径：枚举从 src 出发恰好 k 跳的关系路径。
       allow_repeat_edges=False 时不允许重复走过同一条有向边（trail）。"""
    results = []
    def dfs(node, path, used):
        if len(path) == k:
            results.append(list(path)); return
        for _, v, d in kg.out_edges(node, data=True):
            edge_id = (node, d['relation'], v)
            if not allow_repeat_edges and edge_id in used:
                continue
            path.append(edge_id); used.add(edge_id)
            dfs(v, path, used)
            used.discard(edge_id); path.pop()
    dfs(src, [], set())
    return results

print("有向、允许重复边:", len(paths_of_length(kg, "六小龄童", 3, True)))
print("有向、不重复边:  ", len(paths_of_length(kg, "六小龄童", 3, False)))
# 预期输出（实际运行验证）：
# 有向、允许重复边: 0
# 有向、不重复边:   0
```

**结果与勘误说明（勘误 2）**：**有向**口径下两个数字都是 **0**，且这不是 bug——从"六小龄童"出发 1 跳只能到 {孙悟空, 演员}，2 跳能到 {猴, 菩提祖师}（"演员"无出边），而这三个实体**都没有出边**，第 3 跳无路可走。正文"允许重复边与否会改变答案"的预期在本图的有向语义下不成立；只有把图当**无向**看（关系分析中常见做法），两种口径才会分化：

```python
ug = kg.to_undirected(as_view=False)
def rel(u, v):
    d = kg.get_edge_data(u, v) or kg.get_edge_data(v, u)
    return list(d.values())[0]['relation']

def undirected_paths(k, allow_repeat_edges):
    res = []
    def dfs(u, path, used):
        if len(path) == k:
            res.append(list(path)); return
        for v in ug.neighbors(u):
            eid = (u, rel(u, v), v)
            if not allow_repeat_edges and eid in used: continue
            path.append(eid); used.add(eid)
            dfs(v, path, used)
            used.discard(eid); path.pop()
    dfs("六小龄童", [], set())
    return res

print("无向、允许重复边（游走 walk）:", len(undirected_paths(3, True)))   # 9
print("无向、不重复边（迹 trail）:  ", len(undirected_paths(3, False)))   # 7
# 预期输出（实际运行验证）：
# 无向、允许重复边（游走 walk）: 9
# 无向、不重复边（迹 trail）:   7
```

9 条游走中，有 2 条需要重复走同一条边（`六小龄童--饰演-->孙悟空--饰演-->六小龄童--饰演-->孙悟空` 与 `六小龄童--职业-->演员--职业-->六小龄童--职业-->演员` 这类"往返"路径），trail 口径把它们剪掉，得 7。**复杂度提示**：路径数最坏 $O(b^k)$（$b$ 为平均出度），故工程上必须限制 $k$——与第 1 章 SAT 的组合爆炸同源。

## 进阶题 7（对应 2.3.2：远程监督的噪声）

> 远程监督为什么会产生噪声标注？举出两种噪声形态（假阴性/假阳性各一）与一种降噪思路。

**解答**：

**产生机制**：远程监督（distant supervision）用已有图谱的三元组**反向标注**语料——只要一个句子同时包含三元组的头尾实体，就把它弱标注为该关系。这个 "at-least-one" 假设把"实体共现"当成了"关系表达"，两者之间没有必然联系，于是产生系统性噪声：

- **假阳性（错误正例）**：句子提到两个实体但并未表达该关系。例：图谱里有（创作, 吴承恩, 西游记），于是"吴承恩纪念馆里陈列着《西游记》的连环画"也被标注为"创作"——句子只是让两个实体同框；
- **假阴性（漏标/错误负例）**：真实表达了关系、但表面形式不匹配的句子没有被标上。例："《西游记》的作者是明代的他"——用"作者"同义表达 + 代词回指"吴承恩"，两个实体字符串不同时出现，于是没有被标为"创作"；更糟的是若训练流程把"无标注句子"当负例，它还被当成了"非创作"证据；
- **一种降噪思路——多示例学习（multi-instance learning）**：不信任单句标注，改为" bags 级"假设——一个实体对的**所有**句子组成的袋中**至少一句**表达该关系；训练时对袋内句子取噪声鲁棒的聚合（如选置信度最高的句子、注意力加权聚合），让模型学会忽略袋内噪声句。其它可行思路：正例-未标注（PU）学习、用知识图谱侧一致性（值域/定义域校验）过滤、远程监督标注 + 人工抽查修正的结合。

## 开放题 8（对应 2.2.2 / 1.5：开放世界 vs 封闭世界在查询中的分歧）

> `SELECT` 查询无结果时，"没有这个事实"与"事实未知"在 SPARQL 语义下如何区分？这对 KG-RAG 回答用户问题时的措辞有何影响？

**解答要点**：

- **SPARQL 本身不区分**：SPARQL 的 `SELECT` 语义是图模式匹配——返回"所有使模式 ⊆ 图 的代入"。空结果只说明"图中没有匹配的三元组"，这是对**数据集**的陈述；RDF/OWL 的模型论是**开放世界**的（未断言 ≠ 否定），所以"没有这个事实"与"事实未知"在查询结果上**不可区分**。要区分必须靠额外的建模手段：
  1. **显式否定三元组**（OWL 2 的 `NegativePropertyAssertion`，或 N-ary 建模 `(某实体, 无此关系, 真值标注)`）——把否定作为断言写入图；
  2. **查询层元信息**：记录查询覆盖范围（该实体在该关系下被完整收录过吗），返回"未收录"标注；
  3. **闭合范围声明**：对计数/枚举类问题（"他获得过哪些奖"），用数据集的完备性元数据说明"本图已穷尽"；
- **对 KG-RAG 措辞的影响**：回答必须区分三种语气——
  - 有证据："根据知识库，姚明出生于上海（来源：三元组 ××）"；
  - 可推出：给出支撑路径（"姚明出生地上海，上海属于中国"）；
  - 无证据：说"**知识库中没有查到**关于 ×× 的记录"，而**不能**说"××不是这样"——除非图中有显式否定三元组。
- 混淆这两种措辞正是幻觉的一种形态（把"未检索到"生成成否定性断言）；5.4.2 的 `verify` + 5.9 案例 1 的"精确标出没有证据的位置"是工程上的对应解法。

## 挑战题 9（对应 2.7 案例 1：图模式查询小型引擎）

> 实现图模式查询引擎：给定由变量与常量组成的多三元组模式，返回全部代入。

**解答**：完整实现（按约束度排序模式 + 回溯代入，实际运行验证）：

```python
# 运行环境：pip install networkx
import networkx as nx

triples = [
    ("吴承恩", "创作", "西游记"), ("西游记", "体裁", "小说"),
    ("西游记", "主角", "孙悟空"), ("孙悟空", "物种", "猴"),
    ("孙悟空", "师从", "菩提祖师"), ("六小龄童", "饰演", "孙悟空"),
    ("六小龄童", "职业", "演员"),
]
kg = nx.MultiDiGraph()
for h, r, t in triples:
    kg.add_edge(h, t, relation=r)
spo = {(h, d['relation'], v) for h, v, d in kg.out_edges(kg.nodes, data=True)}  # SPO 索引

def is_var(x):
    return isinstance(x, str) and x.startswith('?')

def match_pattern(kg, pattern):
    """pattern: [(s, r, o), ...]。返回全部使 pattern ⊆ G 的代入 dict。
       策略：贪心选'绑定信息最多'的模式（常量多、与已绑定变量共享多者优先），
       逐个用 SPO 索引枚举候选并与部分代入做连接。"""
    order, bound, remaining = [], set(), list(range(len(pattern)))
    while remaining:                                   # 1. 模式排序
        best = max(remaining, key=lambda i: (
            sum(1 for x in pattern[i] if is_var(x) and x in bound)
            + sum(1 for x in pattern[i] if not is_var(x))))
        order.append(best); remaining.remove(best)
        bound |= {x for x in pattern[best] if is_var(x)}

    results = [{}]
    for idx in order:                                  # 2. 逐模式连接
        s, r, o = pattern[idx]
        new_results = []
        for theta in results:
            for h, rr, t in spo:                       # 3. 索引查找 + 代入检查
                if is_var(s) and s in theta and theta[s] != h:  continue
                if is_var(r) and r in theta and theta[r] != rr: continue
                if is_var(o) and o in theta and theta[o] != t:  continue
                if not is_var(s) and s != h: continue
                if not is_var(r) and r != rr: continue
                if not is_var(o) and o != t: continue
                nt = dict(theta)
                for var, val in ((s, h), (r, rr), (o, t)):
                    if is_var(var): nt[var] = val
                new_results.append(nt)
        results = new_results
        if not results: return []
    return results

print("测试1:", match_pattern(kg, [("?a", "饰演", "?c"), ("?c", "师从", "?m")]))
print("测试2:", match_pattern(kg, [("?character", "师从", "?master"),
                                   ("?work", "主角", "?character"),
                                   ("?work", "体裁", "小说"),
                                   ("?author", "创作", "?work")]))
print("测试3:", match_pattern(kg, [("孙悟空", "创作", "?x")]))
# 预期输出（实际运行验证）：
# 测试1: [{'?a': '六小龄童', '?c': '孙悟空', '?m': '菩提祖师'}]
# 测试2: [{'?work': '西游记', '?character': '孙悟空', '?master': '菩提祖师',
#          '?author': '吴承恩'}]
# 测试3: []
```

**与子图同构的复杂度对照**：无环模式（如测试 1、2）可以按拓扑序连接，最坏 $O(|P| \cdot |G|^{k})$（$k$=最大中间结果宽度），工程数据库用索引 + 连接顺序优化压到近线性；**含环**模式则嵌入子图同构问题，是 NP 完全的——"按约束度排序模式"正是把它当 CSP 求解的标准剪枝（先匹配常量多、度约束强的模式，尽早失败）。这与《数据结构与算法·第 4 章》子图同构一节是同一个问题。

## 挑战题 10（对应 Nickel 等 2016 综述第 3 节：统计关系学习 vs 符号图谱）

> 总结"统计关系学习"与本章"符号图谱"的三点本质差异，并预测哪些差异会被第 3 章的 KGE 弥合、哪些不会。

**解答要点**（分层）：

**三点本质差异**：

1. **真值语义：概率/软评分 vs 二值断言**。统计关系学习（马尔可夫逻辑网络、PSL 等）给每个可能事实一个概率或势函数值，同一事实可以有 0.7 的置信度；符号图谱的三元组要么在图中要么不在，无置信度。后果：前者可表达"冲突证据的折中"，后者必须靠清洗把不确定性赶出图外；
2. **泛化机制：相似性与统计规律 vs 严格匹配与演绎**。符号查询/推理要求精确的常量匹配与逻辑蕴含，查不到就是查不到；统计方法借助特征的相似性把已知边"外推"到未见实体对（归纳偏置），代价是可能产生"合理但错误"的补全；
3. **知识来源：数据驱动学习 vs 人工/半自动构建**。符号图谱的模式层（本体）与数据层都要人参与定义与清洗（知识获取瓶颈，第 1 章局限 3）；统计关系学习直接从数据中估计参数（甚至结构），可规模化但可解释性与可审计性弱（无 provenance、无逐条出处）。

**KGE 会弥合哪些**：差异 1 与差异 2 正是 KGE 的设计目标——打分函数给出连续置信度（差异 1），嵌入几何让"相似实体/关系"互相迁移、实现链接预测（差异 2）；第 3 章的链接预测、跨图实体对齐（最近邻）与可微检索都建立在这两点上。

**不会弥合的**：任何依赖**严格语义**的能力——可验证的演绎推理（第 1 章归结）、带出处的精确回答（provenance，开放题 8）、模式层公理的一致性保证（本题差异 3 的工程侧）。KGE 的打分没有概率语义（第 3 章练习 8），也偏离差 1 的"校准概率"还有距离；而本体约束、审计链属于符号侧的结构性资产，嵌入不承载它们。**结论**：KGE 弥合的是"表示层"的鸿沟，"验证与治理层"的鸿沟依然需要符号技术——这正是第 5 章双系统协作的分工依据。

## 基础题 2（对应 3.6 案例 1：手算 TransE 更新，判断 hinge 是否激活）

> 手算：$\mathbf{h}=(1,0)$，$\mathbf{r}=(0,1)$，$\mathbf{t}=(1,1)$，$\mathbf{t}'=(0,0)$，$\gamma=0.5$，$\eta=0.1$（平方距离 hinge）。写出一次更新的全部四个向量新值，并校验正例距离从 0 仍为 0。

**解答**：

1. 正例残差：$\mathbf{v} = \mathbf{h}+\mathbf{r}-\mathbf{t} = (1+0-1,\ 0+1-1) = (0,0)$，$d^2 = \lVert\mathbf{v}\rVert^2 = 0$；
2. 负例残差：$\mathbf{v}' = \mathbf{h}+\mathbf{r}-\mathbf{t}' = (1+0-0,\ 0+1-0) = (1,1)$，$d'^2 = 2$；
3. **判断 hinge 是否激活**：$\gamma + d^2 - d'^2 = 0.5 + 0 - 2 = -1.5 < 0$ → **未激活**；
4. hinge 未激活时损失 $[x]_+ = 0$、梯度全为零，**四个向量全部不更新**：

$$\mathbf{h} = (1,0),\quad \mathbf{r} = (0,1),\quad \mathbf{t} = (1,1),\quad \mathbf{t}' = (0,0)\ \text{（原值不变）}$$

5. 校验：正例距离保持 $d^2 = 0$ ✓。而且本题中间隔已经"超额满足"（正例比负例好 $2 - 0 = 2 \ge \gamma = 0.5$），本就不该更新——这正是 margin loss 与 SVM 的同构处：**只有"错得不够远"的三元组才有梯度**（正文 3.2.2）。若误把更新公式套上去（不做激活判断），会得到错误的非零更新——这是本题设置的检查点。

## 基础题 3（对应 3.3：TransE 不能表达对称关系的证明）

> 证明：若 $(h,r,t)$ 与 $(t,r,h)$ 都为真且 TransE 完美拟合，则 $\mathbf{r}=0$ 且 $\mathbf{h}=\mathbf{t}$。

**解答**：完美拟合即两个等式同时成立：

$$\mathbf{h} + \mathbf{r} = \mathbf{t} \quad (1) \qquad \mathbf{t} + \mathbf{r} = \mathbf{h} \quad (2)$$

把 (1) 代入 (2)：$(\mathbf{h} + \mathbf{r}) + \mathbf{r} = \mathbf{h}$，移项得 $2\mathbf{r} = \mathbf{0}$，即

$$\mathbf{r} = \mathbf{0}$$

代回 (1)：$\mathbf{h} + \mathbf{0} = \mathbf{t}$，即 $\mathbf{h} = \mathbf{t}$。∎

**推论与含义**：TransE 若要同时满足一对对称三元组（如"配偶"），唯一出路是把关系向量压成零、并把两端实体嵌成同一点——两个不同的人被挤到同一坐标，破坏了实体可分性；而把 $\mathbf{r}$ 留作非零则必然有一个方向的距离偏大。所以 TransE 对非平凡对称关系不可表达。这一缺陷的两种修复路线：TransH 用投影让实体在不同关系下取不同"身份"（对称时 $\mathbf{r}=0$ 且 $\mathbf{w}_r \perp (\mathbf{h}-\mathbf{t})$，允许 $\mathbf{h} \ne \mathbf{t}$）；ComplEx/RotatE 用复数域结构使打分天然可对称（实部对称、旋转 $\pi$ 对称）。练习 6 用实验证实了退化路线的存在。

**常见错误**：只写"对称关系要求 $\mathbf{h}+\mathbf{r}\approx\mathbf{t}$ 与 $\mathbf{t}+\mathbf{r}\approx\mathbf{h}$ 矛盾"而没给出 $2\mathbf{r}=\mathbf{0}$ 的代数步骤；或忽略"完美拟合"这一前提（近似拟合下结论只是"压向"而非"等于"）。

## 基础题 4（对应 3.4：MRR 与 Hit@k 计算）

> 某查询集上排名为 $[1, 3, 10, 2]$，求 MRR 与 Hit@3。

**解答**（逐步）：

$$\mathrm{MRR} = \frac{1}{4}\left(\frac{1}{1} + \frac{1}{3} + \frac{1}{10} + \frac{1}{2}\right) = \frac{1 + 0.3333 + 0.1 + 0.5}{4} = \frac{1.9333}{4} \approx 0.483 \ ✓$$

$$\mathrm{Hit@3} = \frac{1}{4}\big(\mathbb{1}[1\le3] + \mathbb{1}[3\le3] + \mathbb{1}[10\le3] + \mathbb{1}[2\le3]\big) = \frac{1+1+0+1}{4} = 0.75 \ ✓$$

与正文校验值（MRR ≈ 0.483、Hit@3 = 0.75）一致。注意排名 10 的查询对 MRR 贡献 0.1 却对 Hit@3 贡献 0——两个指标的互补性见进阶题 7。

## 进阶题 6（对应 3.6 案例 2：ComplEx 完整实现 + 对称关系实验）

> 完整实现 ComplEx 精简版（复数嵌入 + 逻辑损失 + 全候选排序），输出"接壤"两个方向的得分对比表。

**解答**：完整可运行实现（复数嵌入存实部/虚部两份实数组；逻辑损失即二元交叉熵，正例标签 1、负例标签 0；负采样过滤真三元组）：

```python
# 运行环境：pip install numpy
import numpy as np

triples_base = [
    ("北京","首都","中国"), ("东京","首都","日本"), ("巴黎","首都","法国"),
    ("柏林","首都","德国"), ("莫斯科","首都","俄罗斯"), ("堪培拉","首都","澳大利亚"),
    ("中国","位于","亚洲"), ("日本","位于","亚洲"), ("法国","位于","欧洲"),
    ("德国","位于","欧洲"), ("俄罗斯","位于","欧洲"), ("澳大利亚","位于","大洋洲"),
]
sym = [("中国","接壤","俄罗斯"), ("俄罗斯","接壤","中国"),
       ("德国","接壤","法国"),   ("法国","接壤","德国")]
triples = triples_base + sym
entities = sorted({e for h,_,t in triples for e in (h,t)})
relations = sorted({r for _,r,_ in triples})
e2i = {e:i for i,e in enumerate(entities)}
r2i = {r:i for i,r in enumerate(relations)}
nE, nR = len(entities), len(relations)
pos_set = set(triples)

dim, lr, epochs, seed = 16, 0.05, 801, 0
rng = np.random.default_rng(seed)
E_re = rng.normal(0,0.1,(nE,dim)); E_im = rng.normal(0,0.1,(nE,dim))
R_re = rng.normal(0,0.1,(nR,dim)); R_im = rng.normal(0,0.1,(nR,dim))

def score(h, r, t):
    """f_r(h,t)=Re(Σ h_i r_i conj(t_i))
       = Σ (h_re r_re + h_im r_im) t_re + (h_im r_re - h_re r_im) t_im"""
    return float(np.sum((E_re[h]*R_re[r] + E_im[h]*R_im[r]) * E_re[t]
                      + (E_im[h]*R_re[r] - E_re[h]*R_im[r]) * E_im[t]))

def sigmoid(x): return 1.0/(1.0+np.exp(-np.clip(x,-30,30)))

tr = [(e2i[h], r2i[r], e2i[t]) for h,r,t in triples]
for ep in range(epochs):
    for idx in rng.permutation(len(tr)):
        h, r, t = tr[idx]
        tn = int(rng.integers(0, nE))               # 负例过滤
        tries = 0
        while (entities[h], relations[r], entities[tn]) in pos_set and tries < 20:
            tn = int(rng.integers(0, nE)); tries += 1
        gp = sigmoid(score(h,r,t))  - 1.0           # 正例: ∂L/∂f = σ(f) − 1
        gn = sigmoid(score(h,r,tn))                 # 负例: ∂L/∂f = σ(f)
        # 梯度（对 f = Σ (h_re r_re + h_im r_im) t_re + (h_im r_re - h_re r_im) t_im）：
        #   ∂f/∂h_re = r_re t_re − r_im t_im;  ∂f/∂h_im = r_re t_im + r_im t_re
        #   ∂f/∂t_re = r_re h_re + r_im h_im;  ∂f/∂t_im = r_re h_im − r_im h_re
        #   ∂f/∂r_re = h_re t_re + h_im t_im;  ∂f/∂r_im = h_im t_re − h_re t_im
        def gpair(t_, g):
            return (g*(R_re[r]*E_re[t_]-R_im[r]*E_im[t_]),
                    g*(R_re[r]*E_im[t_]+R_im[r]*E_re[t_]),
                    g*(R_re[r]*E_re[h]+R_im[r]*E_im[h]),
                    g*(R_re[r]*E_im[h]-R_im[r]*E_re[h]),
                    g*(E_re[h]*E_re[t_]+E_im[h]*E_im[t_]),
                    g*(E_im[h]*E_re[t_]-E_re[h]*E_im[t_]))
        a = gpair(t, gp); b = gpair(tn, gn)
        for arr, i, da in ((E_re,h,a[0]),(E_im,h,a[1]),(E_re,t,a[2]),(E_im,t,a[3]),
                           (R_re,r,a[4]),(R_im,r,a[5]),
                           (E_re,tn,b[2]),(E_im,tn,b[3]),(R_re,r,b[4]),(R_im,r,b[5])):
            arr[i] -= lr*da

print(f"{'三元组':<26}{'ComplEx 得分':>14}")
for (h,r,t) in [("中国","接壤","俄罗斯"),("俄罗斯","接壤","中国"),
                ("德国","接壤","法国"),("法国","接壤","德国")]:
    print(f"({h}, {r}, {t})".ljust(26)+f"{score(e2i[h],r2i[r],e2i[t]):>14.3f}")
```

## 进阶题 7（对应 3.4：Hit@k 与 MRR 的矛盾排序）

> 构造一个 4 条查询的例子使模型 A 的 Hit@1 高而模型 B 的 MRR 高。

**解答**：构造 4 条查询的排名：

| 查询 | 模型 A 排名 | 模型 B 排名 |
|---|---|---|
| q1 | 1 | 2 |
| q2 | 1 | 2 |
| q3 | 100 | 1 |
| q4 | 100 | 2 |

计算：

- 模型 A：Hit@1 = (1+1+0+0)/4 = **0.50**；MRR = (1 + 1 + 0.01 + 0.01)/4 ≈ **0.505**；
- 模型 B：Hit@1 = (0+0+1+0)/4 = **0.25**；MRR = (0.5 + 0.5 + 1 + 0.5)/4 = **0.625**。

模型 A 的 Hit@1（0.50）高于 B（0.25），但模型 B 的 MRR（0.625）高于 A（0.505）——矛盾达成。

**机理**：A 是"两题满分、两题大崩"的排名分布，B 是"全部不错但很少第一"。Hit@1 只奖励**第一名**，MRR 对前几名都有衰减奖励（$1/\text{rank}$）。**评测目标决定该信谁**：下游只取 top-1（如自动补全直接替换）→ 用 Hit@1；下游取 top-k 列表供人/系统筛选（如 KG-RAG 召回候选）→ 用 MRR + Hit@k 组合，只报 Hit@10 会掩盖"排名 11 与 10 万"的差别（正文 3.4）。

## 开放题 8（对应 3.1 / 4.1：KGE 缺概率语义）

> KGE 的距离/打分没有概率语义，这会为"知识置信度"带来什么工程问题？与第 4 章概率图模型的概率语义对比。

**解答要点**：

**工程问题**（五条）：

1. **无绝对阈值**：$-\lVert\mathbf{h}+\mathbf{r}-\mathbf{t}\rVert$ 的分值只有相对意义（同一 (h,r) 下排序），"分数 > c 就算真"的 c 既无跨关系通用值也无跨模型通用值；
2. **不可跨模型比较**：TransE 距离、ComplEx 内积、RotatE 旋转距离的量纲与分布各不相同，多模型集成的分数无法直接融合；
3. **不可校准**：业务方问"这条补全有三成把握还是九成把握"没有答案；分数与真实命中率的关系（校准曲线）随关系类型、实体度数漂移；
4. **无贝叶斯更新**：新证据到来无法像 PGM 那样用贝叶斯规则修正信念，只能重训或重算；
5. **推理无组合语义**：多跳/多约束查询的分数聚合（min/sum/积）是启发式选择，没有"概率正确性"保证。

**与 PGM 的对比**：贝叶斯网络的每个查询 $P(Q \mid E=e)$ 是归一化概率，语义自明、可校准（可用校准图检验）、可贝叶斯更新、CPT 由专家或计数直接给出频率解释。代价是参数与结构需要人给出、精确推断可能指数。KGE 恰好相反：学习全自动、推断 $O(\lvert\mathcal{E}\rvert d)$ 极快，但语义是"几何 convenience"。**工程折中**：把 KGE 当"召回器 + 先验"，在其输出上接一层概率化（如对验证过的三元组做 Platt 缩放/保形预测，或并入 PGM 作为先验势）——这正是第 4 章与本章互补的接口，也是第 5 章缓解地图中"缺少置信度语义 → 概率化知识、校准"的具体含义。

## 挑战题 9（对应 3.3：RotatE 的表达力证明）

> 证明 RotatE 的旋转操作可以表达逆关系与组合关系，并给出三元关系模式 $r_1 \circ r_2 \Rightarrow r_3$ 在 TransE 与 RotatE 下的可表达性对比证明梗概。

**解答**：

**记号**：RotatE 中实体 $\mathbf{h}, \mathbf{t} \in \mathbb{C}^d$，关系是逐维单位复数 $\mathbf{r} = (e^{i\theta_1}, \dots, e^{i\theta_d})$，$\lvert r_i \rvert = 1$；打分 $f_r(h,t) = -\lVert \mathbf{h} \circ \mathbf{r} - \mathbf{t} \rVert$（$\circ$ 为逐元素复数乘法）。完美拟合即 $\mathbf{t} = \mathbf{h} \circ \mathbf{r}$（逐维 $\theta_t = \theta_h + \theta_r \pmod{2\pi}$）。

**（1）逆关系可表达**。定义逆关系 $\mathbf{r}^{-1}$ 为逐维共轭：$r^{-1}_i = \overline{r_i} = e^{-i\theta_i}$（模长仍为 1，是合法关系嵌入）。若 $(h, r, t)$ 完美拟合，即 $t_i = h_i r_i$，则

$$t_i \cdot r^{-1}_i = h_i r_i \overline{r_i} = h_i \lvert r_i \rvert^2 = h_i$$

即 $\mathbf{t} = \mathbf{h} \circ \mathbf{r}^{-1}$ 恰是 $(t, r^{-1}, h)$ 的完美拟合。所以"若 $r_2 = r_1^{-1}$（逆关系）"的模式被 RotatE 精确表达。∎

**（2）组合关系可表达**。设 $r_3 = r_1 \circ r_2$（逐维 $e^{i(\theta_1+\theta_2)}$，模长 1 合法）。若 $(h, r_1, m)$ 与 $(m, r_2, t)$ 都完美拟合：$m = h \circ r_1$，$t = m \circ r_2 = h \circ r_1 \circ r_2 = h \circ r_3$，即 $(h, r_3, t)$ 也被完美拟合——组合模式 $r_1 \circ r_2 \Rightarrow r_3$ 可表达。∎

**（3）与 TransE 的对比梗概**（参照 Sun et al. 2019 第 3 节 Table 1）：

- **组合模式**：TransE 中完美拟合给出 $m = h + r_1$、$t = m + r_2 \Rightarrow t = h + (r_1 + r_2)$，故取 $r_3 = r_1 + r_2$ 即可表达组合 ✓——TransE 与 RotatE 都能；
- **逆关系**：TransE 中 $t = h + r \Rightarrow h = t + (-r)$，取 $r^{-1} = -r$ ✓——两者也都能；
- **分野在"模式的组合共存"**：TransE 不能表达对称关系（基础题 3），而 RotatE 用旋转 $\pi$（$r_i = e^{i\pi} = -1$）表达对称：$h \circ r = -h = t$ 且 $t \circ r = h$，双向同时成立 ✓。对**混合模式**（如"$r_1$ 对称、且 $r_1 \circ r_2 \Rightarrow r_3$"同时要求），TransE 因对称缺陷会连带崩溃（$r_1 \to 0$ 迫使组合链中实体重合），RotatE 则因逐维旋转构成阿贝尔群（每维旋转角自由分配 $\theta_{r_3} = \theta_{r_1} + \theta_{r_2}$，对称即 $\theta_{r_1} = \pi$，互不冲突）而全部可表达。**证明要点**：把"可表达"形式化为"存在使全部模式同时完美拟合的嵌入"，再对每个模式给出满足/不满足的构造或反证（对称反证见基础题 3）。

# 第 4 章 概率图模型：贝叶斯网络与马尔可夫网络（练习出处：4.11 节）

## 基础题 1（对应 4.2.1：链式分解与参数计数）

> 写出浇草器网络的完整联合分解式，并数一数：完整联合分布 $2^4-1=15$ 个参数 vs 链式分解 9 个 CPT 参数——列出这 9 个参数。

**解答**：

$$P(C, S, R, W) = P(C)\, P(S \mid C)\, P(R \mid C)\, P(W \mid S, R)$$

参数计数（每个二值变量在其父节点配置下的"取真"概率，取假由归一化自动确定）：

| # | 参数 | 数量 |
|---|---|---|
| 1 | $P(C{=}t)$ | 1 |
| 2–3 | $P(S{=}t \mid C{=}t),\ P(S{=}t \mid C{=}f)$ | 2 |
| 4–5 | $P(R{=}t \mid C{=}t),\ P(R{=}t \mid C{=}f)$ | 2 |
| 6–9 | $P(W{=}t \mid S{,}R)$，$(t,t),(t,f),(f,t),(f,f)$ 四种父配置 | 4 |

合计 $1+2+2+4 = 9$ 个参数，对完整联合分布的 $2^4-1 = 15$ 个自由参数实现压缩。一般规律：参数量从 $O(2^n)$ 降到 $O(n \cdot 2^k)$（$k$ 为最大父节点数），压缩比例随 $n$ 指数增长——这正是"图结构是知识工程的核心投入"的定量含义。

## 基础题 2（对应 4.2.2 / 4.6 案例 2：链结构的 d-分离）

> 对"单箭头"网络 $A \to B \to C$：判定 $A \perp C \mid \{\}$ 与 $A \perp C \mid \{B\}$（道德图手画 + 结论），并用 4.6 的 `d_separated` 函数验证。

**解答**：

**道德图手画**：$A \to B \to C$ 只有一个链式接点 $B$（无汇结构），道德化不新增边（$B$ 只有一个父节点，无"共父连边"），去方向后得无向链 $A - B - C$。

- **$Z = \{\}$（空证据）**：删去空集后 $A$ 与 $C$ 仍经 $B$ 连通 → **不 d-分离**，即 $A \not\perp C \mid \{\}$。直觉：中介 $B$ 未观察，影响沿链流动（$A$ 的信息改变 $B$ 的信念，进而改变 $C$）；
- **$Z = \{B\}$**：删去 $B$ 及其边后 $A$ 与 $C$ 断开 → **d-分离**，即 $A \perp C \mid \{B\}$。直觉：观察中介后 $A$ 对 $C$ 的"信息通道"被阻断。

代码验证（`d_separated` 的实际运行输出）：

```text
A⊥C|{}  : False
A⊥C|{B} : True
```

两处结论与手画一致。**常见错误**：把"链"与"汇"的阻塞条件记反——链/叉是"观察到中间点才阻断"，汇是"观察到（或其后代被观察到）才打开"（正文 4.2.2 表格）。

## 基础题 3（对应 4.6 案例 1：换消元顺序求 $P(S{=}t \mid W{=}t)$）

> 用 4.6 案例 1 的中间因子计算 $P(S{=}t \mid W{=}t)$（消去顺序不同，$h$ 换成关于 $S$ 的因子）。

**解答**：证据 $W{=}t$ 代入 $f_W$；目标只留 $S$，故先消 $R$，再消 $C$（与正文"先消 $S$"的顺序相反）。

**第一步：消去 $R$**——合并 $f_R(R \mid C)$ 与代入后的 $f_W(S, R)$，对 $R$ 求和，得 $g(S, C)$：

$$g(t,t) = \underbrace{0.8}_{P(R=t \mid C=t)} \times 0.99 + \underbrace{0.2}_{P(R=f \mid C=t)} \times 0.90 = 0.792 + 0.180 = 0.972$$

$$g(t,f) = 0.2 \times 0.99 + 0.8 \times 0.90 = 0.198 + 0.720 = 0.918$$

$$g(f,t) = 0.8 \times 0.90 + 0.2 \times 0 = 0.720 \qquad g(f,f) = 0.2 \times 0.90 + 0.8 \times 0 = 0.180$$

**第二步：消去 $C$**——合并 $f_C(C)$、$f_S(S \mid C)$ 与 $g(S,C)$，对 $C$ 求和，得 $h(S)$：

$$h(t) = 0.5 \times 0.1 \times 0.972 + 0.5 \times 0.5 \times 0.918 = 0.0486 + 0.2295 = 0.2781$$

$$h(f) = 0.5 \times 0.9 \times 0.720 + 0.5 \times 0.5 \times 0.180 = 0.3240 + 0.0450 = 0.3690$$

**第三步：归一化**：

$$P(S{=}t \mid W{=}t) = \frac{0.2781}{0.2781 + 0.3690} = \frac{0.2781}{0.6471} \approx \mathbf{0.4298} \ ✓$$

与正文校验值 $\approx 0.430$ 一致，也与 4.6 代码输出的 0.4298 一致。**教学点**：换消元顺序改变了中间因子（$g$ 是 $2\times2$ 而非正文顺序的 $2\times2$、$h$ 从 $R$ 上的因子变成 $S$ 上的因子），但最终边缘分布不变（VE 的正确性不依赖顺序）；改变的只是**计算代价**（最大中间因子宽度）。

## 基础题 4（对应 4.2.3：朴素贝叶斯的隐含假设）

> 朴素贝叶斯分类器在 BN 语言中缺了什么独立性假设之外的隐含假设？把"特征相关性"加一条边的后果是参数量如何变化？

**解答**：

朴素贝叶斯的图结构是叉：$Y \to X_1, \dots, X_m$，声明 $X_i \perp X_j \mid Y$。在此之外它还隐含假设了：

1. **类别是特征相关的唯一来源（无隐变量）**：图中没有任何潜在共因。若特征间实际存在不由 $Y$ 引起的相关（如文本里"双词搭配"、传感器间的物理耦合），叉结构无法表达，分类时这些相关性被硬性丢弃——这正是"朴素之罪"，BN 的改进路径（TAN，树增广朴素贝叶斯）就是加回特征间树状边；
2. **生成式方向（特征依赖于类，而非相反）**：模型学的是 $P(X_i \mid Y)$ 并用贝叶斯规则反推 $P(Y \mid X)$；这与判别式模型直接学 $P(Y \mid X)$ 是不同的建模承诺，当特征强相关、训练量小时生成式的偏差会放大（相关特征被重复计数）；
3. **特征全观察**：BN 分类时所有 $X_i$ 都要取值（或专门处理缺失），隐节点缺失会破坏推断的简单性。

**加一条边的参数量变化**：设给 $X_j$ 增加一个父节点 $X_i$（$Y \to X_j$ 已存在）。原来 $P(X_j \mid Y)$ 有 $2 \times (2-1) = 2$ 个自由参数；加边后 $P(X_j \mid Y, X_i)$ 的父配置数从 2 变 4，自由参数 $4 \times (2-1) = 4$ 个——**净增 2 个**（二值变量）。一般地，给一个已有 $m$ 个二值父节点的变量再加一个二值父节点，参数增加 $2^{m+1} - 2^m = 2^m$ 个。TAN 给每个特征加一条入边，总增量 $O(m)$，远小于全贝叶斯网络的 $O(2^m)$——这就是"用最少边修最大的独立性错误"的工程哲学。

## 进阶题 5（对应 4.6：加"季节 T"节点）

> 给 4.6 的诊断系统加"季节 T"节点（影响多云与下雨），重新计算 $P(R{=}t \mid W{=}t)$，并验证"浇草器与下雨的独立性"在控制 T 后如何变化。

**解答**：新结构：$T \to C \to S$，$T \to R$，$C \to R$，$S \to W$，$R \to W$。CPT 设计（$T$=雨季）：$P(T{=}t)=0.5$；$P(C{=}t \mid T)=0.7/0.3$；$P(R{=}t \mid C,T)$：$(t,t){:}0.9,\ (t,f){:}0.6,\ (f,t){:}0.5,\ (f,f){:}0.1$；$P(S \mid C)$ 与 $P(W \mid S,R)$ 沿用原值。

```python
# 运行环境：Python 3.8+；pip install numpy（本练习实际只需标准库+itertools）
import itertools

CPT = {
    'T': {(): 0.5},
    'C': {(True,): 0.7, (False,): 0.3},
    'S': {(True,): 0.1,  (False,): 0.5},
    'R': {(True, True): 0.9,  (True, False): 0.6,   # (C, T)
          (False, True): 0.5, (False, False): 0.1},
    'W': {(True, True): 0.99, (True, False): 0.90,
          (False, True): 0.90, (False, False): 0.0},
}
PARENTS = {'T': [], 'C': ['T'], 'S': ['C'], 'R': ['C', 'T'], 'W': ['S', 'R']}
VARS = ['T', 'C', 'S', 'R', 'W']

def joint_prob(a):
    p = 1.0
    for v in VARS:
        key = tuple(a[pa] for pa in PARENTS[v])
        pt = CPT[v][key]
        p *= pt if a[v] else 1 - pt
    return p

def exact_inference(query, evidence):
    num = {True: 0.0, False: 0.0}
    hidden = [v for v in VARS if v not in evidence]
    for bits in itertools.product([True, False], repeat=len(hidden)):
        asg = dict(evidence); asg.update(dict(zip(hidden, bits)))
        num[asg[query]] += joint_prob(asg)
    return num[True] / (num[True] + num[False])

def p_cond(extra):
    tot, hidden = 0.0, [v for v in VARS if v not in extra]
    for bits in itertools.product([True, False], repeat=len(hidden)):
        asg = dict(extra); asg.update(dict(zip(hidden, bits)))
        tot += joint_prob(asg)
    return tot

def dep(cond, name):
    z = p_cond(cond)
    j  = p_cond({**cond, 'S': True, 'R': True}) / z
    ps = p_cond({**cond, 'S': True}) / z
    pr = p_cond({**cond, 'R': True}) / z
    print(f"P(S=t,R=t){name} = {j:.4f}  vs  P(S=t)P(R=t) = {ps*pr:.4f}  偏差 = {j-ps*pr:+.4f}")

print("P(下雨|草湿) =", round(exact_inference('R', {'W': True}), 4))
print("P(下雨|草湿, 雨季T=t) =", round(exact_inference('R', {'W': True, 'T': True}), 4))
print("P(下雨|草湿, 旱季T=f) =", round(exact_inference('R', {'W': True, 'T': False}), 4))
print("P(浇草器|草湿) =", round(exact_inference('S', {'W': True}), 4))
dep({},        "（无条件）")
dep({'T': True},  "（控制 T=t）")
dep({'T': False}, "（控制 T=f）")
dep({'C': True},  "（控制 C=t）")

# d-分离验证（沿用 4.6 的 d_separated，PARENTS 换成上面的）
# S⊥R|{}: False;  S⊥R|{C}: True;  S⊥R|{T}: False;  S⊥R|{C,T}: True   （实际运行验证）
```

**实际运行输出**：

```text
P(下雨|草湿) = 0.7195
P(下雨|草湿, 雨季T=t) = 0.9064
P(下雨|草湿, 旱季T=f) = 0.4384
P(浇草器|草湿) = 0.4246
P(S=t,R=t)（无条件）   = 0.0955  vs  P(S=t)P(R=t) = 0.1545  偏差 = -0.0590
P(S=t,R=t)（控制 T=t） = 0.1380  vs  P(S=t)P(R=t) = 0.1716  偏差 = -0.0336
P(S=t,R=t)（控制 T=f） = 0.0530  vs  P(S=t)P(R=t) = 0.0950  偏差 = -0.0420
P(S=t,R=t)（控制 C=t） = 0.0810  vs  P(S=t)P(R=t) = 0.0810  偏差 = -0.0000
```

**解读**：

1. **数值变化**：$P(R{=}t \mid W{=}t)$ 从原来的 0.7079 变为 0.7195（新 CPT 改变了 $R$ 的先验结构）；再观察 $T$ 后强烈分化（雨季 0.9064 vs 旱季 0.4384）——观察一个上游共因把后验拉开，这是 d-分离直觉的数值版；
2. **独立性的关键发现**：控制 $T$ 后 $S$ 与 $R$ **仍不独立**（偏差 −0.0336/−0.0420）——因为路径 $S \leftarrow C \to R$ 依然开放，$T$ 不是那条路径上的阻断点；d-分离验证：$S \perp R \mid \{C\}$ 在加 $T$ 后**仍成立**（True），而 $S \perp R \mid \{T\}$ 为 False；只有同时控制 $\{C, T\}$（或只控制 $\{C\}$）才真正阻断。**教训**："多控制变量更安全"是错的——d-分离逐条路径、逐接点判定（正文 4.7 误区 2）。

## 进阶题 6（对应 4.3.2 / 4.7 误区 4：拒绝采样 vs 似然加权）

> 实现拒绝采样，在证据 $\{W{=}t\}$ 与稀有证据（自造一个 $P=10^{-4}$ 的事件）上对比其与似然加权的样本效率（同预算下的标准误差）。

**解答**：构造稀有证据：在浇草器网络（含季节 $T$）后挂一条三节点的后果链 $W \to L \to M \to N$（每步 $P(\text{真} \mid \text{上游真}) = 0.05$、$P(\text{真} \mid \text{上游假}) = 0.001$），证据取 $\{W{=}t, L{=}t, M{=}t, N{=}t\}$，实测证据概率 $\approx 8.2 \times 10^{-5} \approx 10^{-4}$。查询 $P(R{=}t \mid \text{证据})$ 的精确值为 0.7195（链上节点与 $R$ 在给定 $W$ 后条件独立，精确值即 $P(R{=}t \mid W{=}t)$）。

```python
# 运行环境：pip install numpy
import itertools, numpy as np

# CPT/PARENTS/VARS：含季节 T 的浇草器网络（见练习5）+ 三节点后果链
CPT = {
    'T': {(): 0.5}, 'C': {(True,): 0.7, (False,): 0.3},
    'S': {(True,): 0.1,  (False,): 0.5},
    'R': {(True, True): 0.9, (True, False): 0.6,
          (False, True): 0.5, (False, False): 0.1},
    'W': {(True, True): 0.99, (True, False): 0.90,
          (False, True): 0.90, (False, False): 0.0},
    'L': {(True,): 0.05, (False,): 0.001},   # P(L=t|W)
    'M': {(True,): 0.05, (False,): 0.001},   # P(M=t|L)
    'N': {(True,): 0.05, (False,): 0.001},   # P(N=t|M)
}
PARENTS = {'T': [], 'C': ['T'], 'S': ['C'], 'R': ['C', 'T'], 'W': ['S', 'R'],
           'L': ['W'], 'M': ['L'], 'N': ['M']}
VARS = ['T', 'C', 'S', 'R', 'W', 'L', 'M', 'N']
EVIDENCE = {'W': True, 'L': True, 'M': True, 'N': True}
QUERY = 'R'
N, RUNS = 200000, 15

def rejection(query, evidence, n, rng):
    acc = {True: 0, False: 0}
    for _ in range(n):
        asg = {}
        for v in VARS:                     # 拓扑序前向采样
            pt = CPT[v][tuple(asg[pa] for pa in PARENTS[v])]
            asg[v] = bool(rng.random() < pt)
        if all(asg[k] == val for k, val in evidence.items()):
            acc[asg[query]] += 1           # 与证据不符的样本被丢弃
    tot = acc[True] + acc[False]
    return (acc[True] / tot if tot else float('nan')), tot

def likelihood_weighting(query, evidence, n, rng):
    w = {True: 0.0, False: 0.0}
    for _ in range(n):
        asg, weight = {}, 1.0
        for v in VARS:
            pt = CPT[v][tuple(asg[pa] for pa in PARENTS[v])]
            if v in evidence:
                asg[v] = evidence[v]
                weight *= pt if evidence[v] else 1 - pt   # 证据: 固定+加权
            else:
                asg[v] = bool(rng.random() < pt)
        w[asg[query]] += weight
    return w[True] / (w[True] + w[False]), n

rng = np.random.default_rng(0)
rej, acc_counts, lwv = [], [], []
for _ in range(RUNS):
    r, tot = rejection(QUERY, EVIDENCE, N, rng)
    if tot > 0: rej.append(r); acc_counts.append(tot)
for _ in range(RUNS):
    lwv.append(likelihood_weighting(QUERY, EVIDENCE, N, rng)[0])
import statistics as st
print(f"精确值 = 0.7195；证据概率 ≈ 8.2e-05")
print(f"拒绝采样: 每次接受样本数 {min(acc_counts)}~{max(acc_counts)}, "
      f"均值 {st.mean(rej):.4f}, 标准差 {st.stdev(rej):.4f}")
print(f"似然加权: 均值 {st.mean(lwv):.4f}, 标准差 {st.stdev(lwv):.4f}")

# 预期输出（seed=0，实际运行验证）：
# 精确值 = 0.7195；证据概率 ≈ 8.2e-05
# 拒绝采样: 每次接受样本数 10~23, 均值 0.6646, 标准差 0.1352
# 似然加权: 均值 0.7194, 标准差 0.0017
```

**结论**：同预算 20 万样本下——拒绝采样只接受 **10–23 个**样本（接受率 $\approx P(\text{证据}) \approx 10^{-4}$），估计均值 0.6646（还带着小样本离散性带来的偏差），15 次运行标准差 **0.1352**；似然加权用满全部样本，标准差 **0.0017**，约为拒绝采样的 **1/80**，且均值落在精确值 0.7195 上。这定量复现了正文 4.3.2 与 4.7 误区 4：证据概率低时拒绝采样 $O(1/P(e))$ 崩溃，应换似然加权或吉布斯采样。

## 进阶题 7（对应 4.3.1：min-fill 消元顺序）

> 实现"贪心最小填入（min-fill）"消元顺序选择，在一个 10 节点随机 DAG 上对比随机顺序与 min-fill 顺序的最大中间因子大小。

**解答**：VE 的代价由消元过程中**最大团的大小（宽度 $w$）**决定（中间因子是 $2^w$ 格表）。min-fill 贪心：每步选择"删掉它所需新增填充边数最少"的节点。

```python
# 运行环境：Python 3.8+，无第三方依赖
import itertools, random

def random_dag(n, p, rng):
    """随机 DAG：随机拓扑序 + 独立加边。"""
    order = list(range(n)); rng.shuffle(order)
    pos = {v: i for i, v in enumerate(order)}
    return {(u, v) for u in range(n) for v in range(n)
            if u != v and pos[u] < pos[v] and rng.random() < p}

def moralize(n, edges):
    """道德化：父连子、共父两两连边、去方向。"""
    und = {u: set() for u in range(n)}
    parents = {u: set() for u in range(n)}
    for u, v in edges:
        und[u].add(v); und[v].add(u); parents[v].add(u)
    for ps in parents.values():
        for p1, p2 in itertools.combinations(ps, 2):
            und[p1].add(p2); und[p2].add(p1)
    return und

def max_cluster(und, order):
    """按 order 消元，返回最大团大小（= 最大中间因子宽度）。"""
    g = {u: set(nb) for u, nb in und.items()}
    width = 0
    for v in order:
        width = max(width, len(g[v]))
        nb = [u for u in g[v] if u in g]
        for i in range(len(nb)):
            for j in range(i+1, len(nb)):
                g[nb[i]].add(nb[j]); g[nb[j]].add(nb[i])
        for u in nb: g[u].discard(v)
    return width

def min_fill_order(und, n):
    g = {u: set(nb) for u, nb in und.items()}
    remaining, order = set(range(n)), []
    while remaining:
        def fill(v):
            nb = [u for u in g[v] if u in remaining]
            return sum(1 for i in range(len(nb)) for j in range(i+1, len(nb))
                       if nb[j] not in g[nb[i]])
        best = min(remaining, key=fill)
        order.append(best); remaining.remove(best)
        nb = [u for u in g[best] if u in remaining]
        for i in range(len(nb)):
            for j in range(i+1, len(nb)):
                g[nb[i]].add(nb[j]); g[nb[j]].add(nb[i])
        for u in nb: g[u].discard(best)
    return order

rngpy = random.Random(0)
n, p, TRIALS = 10, 0.3, 20
mf_tot, rd_tot, wins = 0, 0, 0
for t in range(TRIALS):
    und = moralize(n, random_dag(n, p, rngpy))
    w_mf = max_cluster(und, min_fill_order(und, n))
    order = list(range(n)); rngpy.shuffle(order)
    w_rd = max_cluster(und, order)
    mf_tot += w_mf; rd_tot += w_rd; wins += (w_mf < w_rd)
    print(f"试验{t+1}: min-fill 宽度={w_mf}  随机顺序宽度={w_rd}")
print(f"\n平均宽度: min-fill={mf_tot/TRIALS:.1f}  随机={rd_tot/TRIALS:.1f}  "
      f"min-fill 更优 {wins}/{TRIALS}")

# 预期输出（seed=0，实际运行验证，逐试验数值见下）：
# 试验1: min-fill 宽度=3  随机顺序宽度=5
# 试验2: min-fill 宽度=4  随机顺序宽度=5
# ...（20 次试验）...
# 试验19: min-fill 宽度=2  随机顺序宽度=6
# 平均宽度: min-fill=3.9  随机=5.8  min-fill 更优 18/20
```

**结论**：20 个随机 10 节点 DAG 上，min-fill 平均宽度 3.9、随机顺序 5.8，min-fill 在 18/20 个实例上更优（其余 2 个打平，从未更差）。对 VE 的意义：中间因子大小是 $2^w$，宽度从 5.8 降到 3.9 意味着单因子从约 56 格降到约 15 格——**消元顺序是工程关键**（正文 4.6 末尾的提醒）。min-fill 是贪心启发式，不保证最优（最优消元顺序本身是 NP 难的），但实践中稳定有效。

## 进阶题 8（对应 4.4：Hammersley–Clifford 的正性条件）

> 为什么 Hammersley–Clifford 定理需要"严格为正"条件？构造一个非正分布的反例。

**解答**：

**反例构造**：取两个二值变量 $X, Y$，图结构为**两个孤立节点**（$X$ 与 $Y$ 之间无边）。令分布

$$P(X{=}t, Y{=}t) = P(X{=}f, Y{=}f) = 0.5, \qquad P(X{=}t, Y{=}f) = P(X{=}f, Y{=}t) = 0$$

（确定性约束 $X = Y$，且部分配置概率为零——不严格为正）。两个方向都失效：

1. **图 ⟹ 独立性失效**：图中 $X$ 与 $Y$ 被 $\emptyset$ 分隔（无边即无路径），全局马尔可夫性质断言 $X \perp Y$。但实际 $P(X{=}t, Y{=}t) = 0.5 \ne P(X{=}t) P(Y{=}t) = 0.25$——独立性被违反；
2. **团分解失效**：图中的团是 $\{X\}$ 与 $\{Y\}$，团分解要求 $P(X, Y) = \psi(X)\psi(Y)$，即联合分布的支撑必须是"矩形"（各变量边缘支撑的笛卡尔积）。本分布的支撑是对角线两点集，不是矩形，任何非负函数乘积都给不出它。∎

**为什么正性是解药**：严格为正的分布支撑是全空间，"条件化、消去、支撑收缩"这些推导步骤（Hammersley–Clifford 原证明沿着逐配置构造势函数比值 $\psi(x)/\psi(x')$）不会除以零、不会出现支撑破碎；支撑为全积空间时"分隔 ⟹ 独立"与"团分解"才能互为充要。零概率配置相当于引入了**硬约束**，硬约束携带的独立性/依赖性信息无法用无向图的无约束团结构忠实编码——要么放宽图为"标注了硬约束的图"，要么放弃等价性。这也是工程上的提醒：给马尔可夫网络填势函数时出现的"不可能配置"（势恒 0）会让基于图的独立性直觉失效。

## 开放题 9（对应 3.4 / 4.3：两种推断的可解释性）

> 把第 3 章 KGE 的链接预测视为一种推断，它和本章 BN 推断在"输出可解释性"上的本质差别是什么？若要求诊断系统"每一步可向医生解释"，你会分别怎么改造两种系统？

**解答要点**：

**本质差别**（三条）：

1. **贡献可分解性**：BN 后验 $P(Q \mid e) \propto \sum_{\text{hidden}} \prod_i \theta_i$ 的每一项都是**语义自明**的条件概率（"发烧患者 80% 有感染"），可以逐因子审计"哪个证据、哪条 CPT 把结论推到哪里"；KGE 的分数是几千维向量的距离/内积，无法分解出"因为症状 A 且指标 B，所以感染"式的因子贡献；
2. **证据-结论的显式路径**：BN 推断可以给出"哪些证据变量进入了计算"（证据集 + 马尔可夫毯），以及反事实灵敏度（"若无此证据，结论会怎样"）；KGE 链接预测只能事后追加解释（近邻实体、_extract 的规则、路径枚举），解释与打分过程**不同源**——是"构造出来的理由"而非"计算的真实依据"；
3. **不确定性的语义**：BN 输出是校准概率，医生可结合先验判断；KGE 排名分数无概率语义（第 3 章练习 8）。

**改造方案**：

- **KGE 系统**：不让 KGE 直接面对医生——把它降级为**召回层**：对每个高分补全，用第 2 章的路径枚举找回支撑路径，作为证据呈现（"推荐这个诊断，因为症状组合与病例库中路径 一致"）；再接一层概率校准（练习 8 的方案），并把"知识库中无此证据支撑"的输出明确标为不可解释、不进入医疗结论；
- **BN 系统**：天然接近可解释，补三点——CPT 用专家语言成文（每个参数有出处）；推断时输出**证据贡献分解**（对每个证据做留一灵敏度：$\Delta P = P(Q \mid e) - P(Q \mid e \setminus \{e_i\})$）；对高影响 CPT 行做敏感性分析并标注不确定性来源。这样"每一步可向医生解释"落实为"每个结论附证据贡献表 + 每个参数附来源"。

## 挑战题 10（对应 4.3.1 / 拓展阅读：树上的 VE 与连接树）

> 证明变量消元在树结构 BN 上（消元顺序取"从叶到根"）是多项式时间的。进一步：用 500 字概述连接树算法。

**第一部分：树上 VE 的多项式性证明**。

设 BN 的道德图 $G$ 是树（或森林）——这包括每节点至多一个父节点的链式 BN，也包括 $n$ 个叶子的星形朴素贝叶斯（其道德图是星形树）。

**命题**：按"从叶到根"的顺序消元，每个中间因子的定义域大小 $\le 2$，总时间 $O(n \cdot 2^2)$（对二值变量即 $O(n)$ 次常数规模的表操作）。

**证明**：对消元步数归纳。任一时刻的部分消元图仍是无向森林（从树中删点、并把被删点的邻居两两连边——但被删点是当前叶子，至多一个邻居，**无需新边**，故森林性质保持）。当前叶子 $v$ 的因子由它自身 CPT 因子与邻居传来的消息因子合并而成；由于 $v$ 在原树与当前森林中的邻居都恰是它的父节点 $p(v)$ 一个（叶性质），合并因子的定义域 $\subseteq \{v, p(v)\}$，大小 $\le 2$，表项 $\le 2^2 = 4$。对 $v$ 求和产生发给 $p(v)$ 的消息，定义域 $\subseteq \{p(v)\}$。每步的乘法与求和都在常数大小的表上进行，$n$ 个节点共 $n$ 步，故总时间 $O(n)$——多项式。∎

（推广：若树的最大度是 $\Delta$，一般消元顺序可能产生 $\Delta$ 维中间因子，代价 $O(n \cdot 2^\Delta)$；"从叶到根"的顺序让每步只需与单个邻居合并，是树上的最优实现。树结构 BP 的 $O(\text{边数})$ 消息传递（4.3.3）与本结论等价——两条路殊途同归。）

**第二部分：连接树算法 500 字概述**（Lauritzen & Spiegelhalter, 1988）。

变量消元的弱点是"一次查询一条顺序"：换查询、换证据就要重算。连接树（junction tree）把消元过程**编译成可复用的数据结构**，一次构建、多次查询。五个阶段：

1. **道德化**：把每个节点的父节点两两连边（"结为夫妻"），然后去掉所有方向——这一步把 BN 的 d-分离信息转写为无向图的分离信息，与 4.2.2 的道德图判定法是同一操作；
2. **三角化**：向道德图添加填充边，使每个长度 $\ge 4$ 的圈都有弦。填充边的选择决定团的大小——等价于选择一个好消元顺序（min-fill 练习 7 的贪心可直接用作三角化启发式），目标是最大团尽量小；
3. **收集极大团**：三角化后找出所有极大完全子图（团），每个团的表大小是 $O(2^{\text{团大小}})$；最大团的规模即树的宽度（tree-width），它是连接树推断复杂度的总闸门；
4. **组装连接树**：把团作为节点连成一棵树，要求满足**运行相交性质**——任何两个同时包含某变量的团，其路径上的所有团都包含它（用最大生成树、以团交集大小为边权构造即可满足）。每个 CPT 因子分派给一个包含其定义域的团；
5. **校准（消息传递）**：两轮消息——先从叶向根"收集"、再从根向叶"分发"——每个团把相邻团传来的因子乘入自己的表、对分隔变量求和后传出。两轮后，任意团表对其定义域求和即得对应变量的精确边际；查询 $P(Q \mid e)$ 只需把证据代入相应团再重新校准，全部查询共享同一结构。

复杂度：构建阶段 $O(n \cdot 2^{w})$（$w$ = 最大团大小），校准同理。它把"变量消元的一次性努力"变成"对任意查询都多项式（在 $2^w$ 固定时对 $n$ 线性）的引擎"——BN 推断从"按需计算"进化为"编译后查询"。$w$ 由图结构决定：树图 $w$ 小（呼应第一部分），稠密医疗网络 $w$ 大——推断的困难度本质上是**图宽**的函数。

## 基础题 2（对应 5.4.2：retrieve 的工程缺陷）

> 指出 5.4.2 代码中 `retrieve` 的两个工程缺陷并各给一个改进方案。

**解答**：

**缺陷 1：实体识别退化为"字符串包含"**。`seeds = [n for n in kg.nodes if n in question]` 有两类错误：

- **漏召（假阴性）**：问题用别名/别称时找不到种子——问"大姚出生在哪"无法命中节点"姚明"；外文、译名变体同理；
- **误召（假阳性）**：子串碰撞——节点"中国"会命中问题"中国移动的客服电话"里的子串，节点"休斯顿"会命中任何提到休斯顿的其他话题。

**改进方案**：把实体识别升级为"NER + 实体链接"流水线（《自然语言处理·第 3 章》的序列标注 + 2.3.3 的候选生成/排序消歧），辅以**别名表**（"大姚"→姚明）与 KGE 最近邻召回（第 3 章，把问题向量与实体嵌入比对，按相似度取 top-k 种子）。

**缺陷 2：种子为空时证据恒为空，导致对可回答的问题也永远拒答**。若实体识别失败（哪怕只因为同义词），`evidence == []`，`generate` 直接输出"知识库中没有可依据的事实（拒答）"——检索层的单点失败被放大成系统级拒答，且用户得不到"为什么答不了"的反馈。同时 `retrieve` 只沿**出边**扩展，反向问题（"休斯顿有什么球队？"需要 反查"位于→休斯顿"的入边）也会空手而归。

**改进方案**：(a) **降级检索链**：种子为空时先做 KGE 相似度宽松召回 → 仍为空时返回澄清式回应（"未能识别问题中的实体，请改写"），把"检索失败"与"知识缺失"分开报告；(b) **双向扩展**：出边 BFS 之外对入边也做 BFS（或用无向视图限跳数），并保留路径以便 `verify` 使用。

## 基础题 3（对应 5.9 案例 1：路径可推出的陈述）

> 手工对 5.9 案例 1 的 CoT 增加一条"可由路径推出但无直接三元组"的陈述，说明验证器如何用两跳路径证实它。

**解答**：增加陈述：**"姚明出生地的国家是中国"**。KG 中没有（姚明, 出生地国家, 中国）这条三元组，但存在两跳路径：

$$(\text{姚明},\ \text{出生于},\ \text{上海}) \quad\rightarrow\quad (\text{上海},\ \text{属于},\ \text{中国})$$

**验证器的扩展**：单条三元组检查（`kg.has_edge`）会把它误判为"无证据"；正确做法是把验证从"三元组匹配"升级为"有界路径存在性检查"——在 KG 上做深度受限（≤2 跳）DFS，检查是否存在从"姚明"出发、以"出生于"开头的路径到达"中国"：

```python
def verify_by_path(kg, head, tail, first_rel=None, max_hops=2):
    """检查 head 到 tail 是否存在不超过 max_hops 的关系路径
       （first_rel 可约束首跳关系）。路径存在即可证实该陈述。"""
    stack = [(head, [])]
    while stack:
        node, path = stack.pop()
        if len(path) >= max_hops:
            continue
        for _, v, d in kg.out_edges(node, data=True):
            new_path = path + [(node, d['relation'], v)]
            if v == tail and (first_rel is None or new_path[0][1] == first_rel):
                return True, new_path
            stack.append((v, new_path))
    return False, None

# 对 5.4.2 的 kg 实际运行：
ok, path = verify_by_path(kg, "姚明", "中国", first_rel="出生于")
print(ok, path)
# 预期输出（实际运行验证）：
# True [('姚明', '出生于', '上海'), ('上海', '属于', '中国')]
```

这正是"可由路径推出但无直接三元组"的情形：陈述为真不是"图中直接写着"，而是由两条边**复合**推出——即第 2 章"推理 = 在图上找路径"的验证化用法。注意边界：路径验证给出的是"有证据"，路径不存在仍是"无证据"而非"假"（开放世界，呼应第 2 章练习 8）。

## 基础题 4（对应 5.6：幻觉二分法）

> 定义区分：事实性幻觉与忠实性幻觉，各举一例，并说明 KG-RAG 对哪一类更有效、为什么。

**解答**：

- **事实性幻觉（factuality）**：生成内容与**客观世界**冲突。例：让模型介绍姚明，它答"姚明 1980 年出生于北京"——年份与出生地都与事实不符；或编造一篇不存在的论文；
- **忠实性幻觉（faithfulness）**：生成内容与**用户输入/给定文档**冲突。例：给模型一篇只提出一种方法的论文让它摘要，摘要写成"论文提出了三种方法"——错误不在于世界真相，而在于**违背了眼前证据**。

**KG-RAG 对事实性幻觉更有效**。理由：KG 恰好是"客观世界事实"的结构化外置（第 2 章），检索注入 + 约束生成 + 符号验证四步全部作用在"事实必须有库内依据"上——事实性幻觉的根源（参数化知识过期/缺失/纠缠）被外部知识源直接替代。而忠实性幻觉的"证据"是用户的自由文本输入：KG-RAG 只有在先把输入文档抽取成三元组入库后才能验证，否则符号验证器对自由文本主张无从核对；治理它需要的是抽取 + 文本蕴含（NLI）式的忠实性校验，而非 KG 检索。因此 KG-RAG 治"对世界错"，"对输入错"要靠对输入的接地验证——两种幻觉的缓解路径不同（5.6 缓解地图第一、二行 vs. 忠实性专属手段）。

## 进阶题 5（对应 5.4.2：多跳问题回答）

> 把 5.4.2 升级为"多跳问题回答"——对"姚明的球队所在城市"自动执行两跳检索并拼装答案。

**解答**：

```python
# 运行环境：pip install networkx（kg 沿用 5.4.2 的建图）
def answer_multi_hop(kg, seed_entity, rel_seq):
    """沿关系序列 rel_seq 多跳检索，返回全部完整路径。"""
    paths, stack = [], [(seed_entity, [])]
    while stack:
        node, path = stack.pop()
        if len(path) == len(rel_seq):
            if path: paths.append(path)
            continue
        r = rel_seq[len(path)]
        for _, v, d in kg.out_edges(node, data=True):
            if d['relation'] == r:
                stack.append((v, path + [(node, d['relation'], v)]))
    return paths

res = answer_multi_hop(kg, "姚明", ["效力过", "位于"])
for p in res:
    print("路径:", " -> ".join(f"{h} --{r}--> {t}" for h, r, t in p))
print("答案（路径终点）:", {p[-1][2] for p in res})

# 预期输出（实际运行验证）：
# 路径: 姚明 --效力过--> 休斯顿火箭 -> 休斯顿火箭 --位于--> 休斯顿
# 答案（路径终点）: {'休斯顿'}
```

## 进阶题 6（对应 5.7：带动作成本的规划）

> 给 5.7 的规划器加入动作成本（BFS 换 Dijkstra，move 成本 1、pickup/dropoff 成本 5），对比"取了再跑"与"空跑一趟"的计划差异。

**解答**：

```python
# 运行环境：Python 3.8+，无第三方依赖
import heapq

def dijkstra_plan(actions, init, goal):
    """动作带成本的 Dijkstra 前向搜索：返回 (最短成本, 动作序列)。"""
    init, goal = frozenset(init), frozenset(goal)
    if goal <= init: return 0, []
    dist = {init: 0}
    pq = [(0, init, [])]
    while pq:
        d, state, path = heapq.heappop(pq)
        if d > dist.get(state, float('inf')):
            continue
        if goal <= state:
            return d, path
        for name, pre, add, dele, cost in actions:
            if pre <= state:                          # 前置条件满足
                nxt = frozenset((state - dele) | add) # STRIPS 转移
                nd = d + cost
                if nd < dist.get(nxt, float('inf')):
                    dist[nxt] = nd
                    heapq.heappush(pq, (nd, nxt, path + [name]))
    return None, None

def move(a, b, cost=1):
    return (f"move({a}->{b})", {("at", a)}, {("at", b)}, {("at", a)}, cost)
def pickup(p, loc, cost=5):
    return (f"pickup({p}@{loc})", {("at", loc), ("pkg_at", p, loc)},
            {("in_bag", p)}, set(), cost)
def dropoff(p, loc, cost=5):
    return (f"dropoff({p}@{loc})", {("at", loc), ("in_bag", p)},
            {("pkg_at", p, loc)}, {("in_bag", p)}, cost)

init = {("at", "仓库"), ("pkg_at", "包裹1", "仓库")}
goal = {("pkg_at", "包裹1", "客户")}

# 场景1（教材原域，直接道路成本 1）
a1 = [move("仓库", "客户"), move("客户", "仓库"), move("仓库", "站点"),
      move("站点", "客户"), pickup("包裹1", "仓库"),
      dropoff("包裹1", "客户"), dropoff("包裹1", "站点")]
c, p = dijkstra_plan(a1, init, goal)
print("场景1 最优计划:", p, " 总成本 =", c)
# "取了再跑"成本 = 5+1+5 = 11；"空跑一趟再去取"成本 = 1+1+5+1+5 = 13（被自动排除）

# 场景2（新增"高速直达"成本 5 vs 经站点绕行各 1）
a2 = [move("仓库", "客户", cost=5), move("仓库", "站点", cost=1),
      move("站点", "客户", cost=1), move("客户", "仓库", cost=1),
      move("站点", "仓库", cost=1), pickup("包裹1", "仓库"),
      dropoff("包裹1", "客户"), dropoff("包裹1", "站点")]
c, p = dijkstra_plan(a2, init, goal)
print("场景2 最优计划:", p, " 总成本 =", c)

# 预期输出（实际运行验证）：
# 场景1 最优计划: ['pickup(包裹1@仓库)', 'move(仓库->客户)', 'dropoff(包裹1@客户)']  总成本 = 11
# 场景2 最优计划: ['pickup(包裹1@仓库)', 'move(仓库->站点)',
#                  'move(站点->客户)', 'dropoff(包裹1@客户)']  总成本 = 12
```

**对比结论**：

1. **"取了再跑" vs "空跑一趟"**：场景 1 中取了再跑成本 11，先空跑到客户再折返取件的"空跑一趟"成本 13——Dijkstra 依据累计成本自动排除后者；原 BFS 版本按"步数最少"两者同为 3 步与 5 步尚可区分，但一旦两条计划步数相同、成本不同，BFS 就会选错——**成本模型改变了最优解**；
2. **场景 2 是更尖锐的对照**：直达"高速"只有 1 跳但成本 5，绕行站点 2 跳成本 2。按跳数的 BFS 会选直达（3 步计划，成本 15）；Dijkstra 选绕行（4 步计划，成本 12）。经典规划里"最优"的定义必须显式声明是步数还是代价——把 BFS 换成 Dijkstra 正是把这一定义从"隐式"变成"参数"；
3. 对 LLM Agent 的启示：LLM 提议动作、确定性规划器按成本择优，"提议—执行—观察—修正"循环（5.7）里，成本函数就是环境反馈的一部分。

## 进阶题 7（对应 5.9 案例 2：DeepProbLog 最小示例的不可识别性）

> 运行 5.9 案例 2，报告学到的 9 个 parent 概率，并解释为什么 parent(a,c) 不能被唯一确定——这暴露了"符号规则 + 弱监督"的何种本质性质？

**解答**：实际运行（seed=0，2001 步梯度下降）学到的 9 个参数：

```text
学到的 P(parent)：
  parent(a,a)=0.637  parent(a,b)=1.000  parent(a,c)=0.041
  parent(b,a)=0.017  parent(b,b)=0.813  parent(b,c)=1.016
  parent(c,a)=0.607  parent(c,b)=0.729  parent(c,c)=0.544
```

与正文摘录一致（`parent(a,b)=1.000、parent(b,c)=1.016、parent(a,c)=0.041`）✓。

**为什么 `parent(a,c)` 不能被唯一确定**（三层原因）：

1. **梯度触不到它**：规则 `grandparent(A,C) :- parent(A,B), parent(B,C)` 的证明和是 $\sum_{b \ne a,c} P(\text{parent}(a,b)) P(\text{parent}(b,c))$。对监督事实 grandparent(a,c)，中间变量 $b$ 只能取 $b$——梯度只流经 `parent(a,b)` 与 `parent(b,c)` 两个参数；`parent(a,c)`（以及其余 6 个参数）**从不出现在任何证明路径里**，梯度恒为 0，数值停在随机初始化（0.041 恰是初始采样值）；
2. **约束欠定**：即使对被触及的两个参数，监督也只施加了一个等式约束 $P(\text{parent}(a,b)) \cdot P(\text{parent}(b,c)) \approx 1$——无穷多组解（0.5 与 2.0、1.0 与 1.0……）都同样满足；梯度下降停在哪个解取决于初始化与优化轨迹。且本实现未加 sigmoid 压缩，"概率"可以略超 1（正文括号里的提醒），说明输出的"概率"语义是软的；
3. **规则结构决定了可识别集合**：符号规则像一张"哪些参数与哪些监督事实相连"的二部图——不在图上的参数原则不可识别，在图上的参数组也常只是联合可识别（每个个体的值不唯一）。

**本质性质**："符号规则 + 弱监督"是**约束满足问题而非回归问题**：监督只约束"证明的聚合结果"，参数个体的真值没有定义；credit assignment 沿证明结构分配（这正是 DeepProbLog/NTP 的核心机制），代价是**证明之外的参数不可识别、证明之内的参数常常只可联合识别**。工程含义：想要每个神经谓词的输出可解释为真校准概率，仅靠逻辑弱监督不够，还需要额外的直接监督或先验（如对 parent 概率加先验/正则，或补充更多使参数进入证明的监督事实）。

## 进阶题 8（对应 5.5：self-consistency 的机理与失效）

> self-consistency 为什么能提升 CoT 正确率？它相当于用哪种经典推理技术（对照第 1 章 DPLL 的哪一步）？其失效场景是什么？

**解答**：

**为什么有效**：self-consistency（Wang et al., 2022）对同一问题采样多条温度 > 0 的思维链，对**最终答案**做多数投票。机理有三：

1. **正确路径的收敛性**：正确答案可以被多条不同的推理路径到达（"条条大路通罗马"），而错误往往各自错得五花八门——把答案分布的众数当预测，等于对推理路径做了**边缘化**（$P(\text{answer}) = \sum_{\pi} P(\text{answer} \mid \pi) P(\pi)$），单条链的偶然失误被平均掉；
2. **方差缩减/集成效应**：多条采样链构成一个隐式集成，等价于对"一步登天"式贪心解码的去噪；
3. **逃离局部错误分支**：贪心解码一旦早期 token 走偏就难以回头；采样让不同分支都有机会被探索，投票把少数走入歧途的分支压制。

**对应的经典推理技术**：DPLL 的**"决策 + 回溯"与随机重启**（第 1 章 1.3.2）。self-consistency 相当于：不押注单一分支决策（贪心解码 = 只走一条 DFS 路径），而是在决策点做多路采样探索，冲突时（答案不一致）"回溯"到分歧处重试——正是 SAT 求解器中 random restart + 回溯的统计化版本；区别在于 DPLL 用**逻辑冲突**（空子句）判定剪枝，self-consistency 用**投票一致性**做软判定。

**失效场景**（四条）：

1. **系统性偏差**：若模型的知识本身错了，多数路径会**一致地错到同一个答案**——投票放大而不是纠正错误（正确率低于 50% 且错误方向相关时，多数投票反而更糟）；
2. **表面模式偏置**：答案空间有偏（如数字题偏爱某个"看起来对"的值），众数可能被表面相似性而非推理质量决定；
3. **不忠实性遗传**：推理文本与真实计算过程不忠实（5.5.2），"答案对、理由错"的链也会投出正确票，掩盖错误推理——用于评估时反而不安全；
4. **成本与边际递减**：需要 $k$ 倍推理预算；路径多样性不足（温度过低或能力太强/太弱）时收益迅速饱和。

## 开放题 9（对应 5.7 / 第 2 章练习 8：开放世界下的条件性计划）

> 若要求 Agent 在"KG 不完整"的开放世界语义下做规划，如何改造 plan 函数以输出"条件性计划"？

**解答要点**（分层次给出设计路线与关键步骤）：

**问题本质**：STRIPS 的状态是闭世界的原子集合（不在集合 = 假，5.7），而 KG 是开放世界（不在图 ≠ 假，第 2 章练习 8）。冲突点：前置条件检查 `pre <= state` 对"KG 没写"的事实一律判假，会导致大量计划被误判为不可行；反之若一律判真，执行时会在未证实事实上崩塌。

**改造方案：三值原子 + 条件计划**。

1. **状态三值化**：原子取 $\{T, F, U\}$（真/假/未知）。初始状态来自 KG：图中有的原子为 $T$；图中有**显式否定**的为 $F$；其余为 $U$；
2. **动作标注证据需求**：每个动作的前置条件分成两部分——`pre_hard`（必须为 $T$，如机器人自身位置，由感知保证）与 `pre_soft`（可为 $U$，但执行前需验证，如"包裹在仓库"——KG 里有就 $T$，没有就 $U$）。转移规则：$s \xrightarrow{a} (s \setminus \mathrm{del}(a)) \cup \mathrm{add}(a)$ 照旧，但只有 $pre\_hard$ 满足的动作才直接可执行；含 $U$ 前置条件的动作成为**条件动作**；
3. **搜索算法**：把 BFS/Dijkstra 的节点从"确定状态"换成**信念状态**（belief state）：与 KG 一致的可能世界的集合的紧凑表示（对每个 $U$ 原子记一个"待验证"标记）。搜索产生两种边：验证边（对某 $U$ 原子发起 KG 查询/感知，把 $U$ 分裂为 $T$ 或 $F$ 两个分支）与动作边。输出的是**带分支的树**而非线性序列；
4. **输出的条件性计划**：每个节点标注——
   - `[已证实]` 前置条件全部为 $T$ 的步骤：无条件执行；
   - `[待验证]` 依赖某 $U$ 原子 $p$ 的步骤：写成 `IF verify(p) THEN ... ELSE <回退分支>`；回退分支可以是重规划调用、询问用户或保守默认动作；
   - 计划头部列出**全部未证实假设**（open assumptions 清单），供执行器与用户审计；
5. **实现骨架**（伪代码）：

```python
def conditional_plan(actions, init_kg, goal, depth=20):
    """init_kg: dict 原子 -> 'T'/'F'/'U'。返回条件计划树。"""
    frontier = [init_kg]
    for _ in range(depth):
        nxt = []
        for s in frontier:
            if goal_satisfied(s, goal):
                return s.plan                          # 到达目标
            for a in actions:
                if hard_pre_unsat(a, s):               # 硬前置为假 -> 剪枝
                    continue
                soft_unknown = [p for p in a.pre if s.get(p) == 'U']
                if not soft_unknown:                   # 无未证实假设：普通动作边
                    nxt.append(apply_action(s, a))
                else:                                  # 条件动作：插入验证分支
                    nxt.append(branch_on(apply_action(s, a), soft_unknown))
        frontier = nxt
    return None                                        # 深度内不可达
```

**与课程概念的衔接**：这本质上是**偶然性规划（contingent planning）/带感知的规划**的极简版；"验证动作"对应 KG-RAG 的检索步（5.4），"未证实假设清单"对应 5.9 案例 1 符号验证"精确标出没有证据的位置"的能力，开放世界语义与 STRIPS 闭世界的边界（5.10 误区 4）由此获得工程化的缝合。

| 无法验证生成内容 → 符号验证（第 1 章） | ④ | 每条声明必须三元组匹配或路径可推；unsupported 被精确标出（不是证伪，是"无证据"定位） |
| 缺少置信度语义 → 概率化、校准（第 4 章） | ⑤ | 异构分数（相似度、KGE、验证位）经校准模型融合为概率，驱动"答/降级/拒答"三档输出 |
| 相似实体混淆 → KGE 打分与消歧（第 3 章） | ①② | 实体链接用 KGE 最近邻消歧；子图召回按 KGE 排序，同名/近义实体区分开 |
| 多步推理失控 → 规划器 + 验证回路（5.7） | ②④ 的闭环 | 多跳问题分解为检索计划；每步检索结果过 ④ 验证后再进入下一步（条件性计划，见开放题 9） |

**仍然无法覆盖的残余风险**（必须如实声明）：

1. **KG 自身的不完整与错误**：开放世界下"无证据 ≠ 假"，验证器只能标位置不能证真（5.9 案例 1 的结论）；KG 的抽取噪声与过期条目直接成为系统的天花板；
2. **"何时该查库"的元判断**：模型可能对需要查证的问题不发起检索（该查没查），检索什么实体、几跳、何时停止，都是启发式；
3. **约束逃逸**：LLM 可能在证据覆盖不到的措辞层面自由发挥（忠实性幻觉），符号验证对自由文本声明无能为力（基础题 4）；
4. **校准的分布漂移**：置信度模型在新领域/新关系类型上可能失准，"低置信拒答"的阈值需要持续监控；
5. **实体链接错误的上游传播**：①错一个实体，后面整条链都在错误的子图上工作且看似自洽。

**结论**：该架构把幻觉从"系统 bug"降为"可定位、可标注、可降级的风险"——这正是本课程的核心论点：幻觉是知识表示的根本难题在生成模型上的再现，工程目标是**有据可查、无据可标、置信可校**，而非"修掉"。
