# 知识表示与推理 · 课程导览

> **课程定位**：这是"人工智能核心"模块的第六门课，也是整部教材中**符号主义（symbolicism）遗产**的主要承载者。当你学完《深度学习》《自然语言处理》，已经习惯"一切皆向量、一切皆梯度"之后，本课程要回答一个被大模型时代重新点燃的问题：**知识应当以什么形式存进机器，才能被严格地查、严格地推、严格地验证？** 前置要求是《机器学习》（尤其概率模型章）与《深度学习》；本章知识将在第 5 章汇入大语言模型的工程实践（检索增强、Agent 规划）。

## 0.1 这门课为什么在 2026 年重新重要

从 1956 年达特茅斯会议至今，人工智能一直存在两条路线：

- **连接主义（connectionism）**：智能来自大量简单单元的加权连接与学习。感知机、多层网络、Transformer 都属此列。它的知识**隐式**地分布在参数里。
- **符号主义（symbolicism）**：智能来自对显式符号的逻辑操作。定理证明、专家系统、知识图谱属此列。它的知识**显式**地写在那里，可以被人类阅读、审计与验证。

2012 年以后连接主义全面胜出，符号主义一度被视为"古董"。但大语言模型（LLM）的三个根本困难，让符号方法在 2020 年代强势回归：

1. **幻觉（hallucination）**：参数化知识是统计记忆而非数据库，模型会"一本正经地编造"不存在的文献、事实与推理步骤。幻觉没有概率意义上的"置信度"可供审计——而符号知识库每一条事实都有出处。
2. **系统 2 思考（System 2 thinking）**：心理学中的双过程理论区分快速的"系统 1"与缓慢、可检查、多步的"系统 2"。Transformer 的单次前向传播本质上是系统 1；思维链（chain-of-thought）、Agent 的"规划—执行—验证"循环，都是在给神经模型外挂一个符号化的系统 2。
3. **知识注入与更新**：模型训练完成后，修改一条事实需要昂贵的再训练，且可能牵一发动全身。外部知识库（知识图谱、数据库、规则库）可以即插即用地更新。

本课程的任务：先学会符号主义的"母语"（逻辑、知识图谱、概率图模型），再学会它与神经模型的"混合语法"（知识图谱嵌入、神经符号方法、KG-RAG），最后能在第 5 章与综合项目中把这些技术接回大模型工程。

本课程共 5 章正文 + 1 个综合项目，按"符号基础 → 结构化知识 → 向量化知识 → 概率化知识 → 神经符号融合"展开：

```mermaid
    CH5 --> PR
    PR --> LLM[大模型工程实践]
```

各章一句话摘要：

1. **第 1 章 逻辑基础**：命题逻辑的语法与语义、SAT 与 DPLL、一阶逻辑的量词与合一、归结原理。这是所有"严格推理"的原点。
2. **第 2 章 知识图谱**：把世界写成三元组。RDF 与 SPARQL、知识抽取流水线、用 networkx 做多跳查询。
3. **第 3 章 KGE**：把实体与关系嵌入向量空间（TransE → TransH/TransR/ComplEx/RotatE），链接预测与 Hit@k/MRR。
4. **第 4 章 概率图模型**：知识是有不确定性的。贝叶斯网络、d-分离、变量消元、采样推断、马尔可夫网络。
5. **第 5 章 神经符号与大模型**：参数化知识 vs 外部知识、KG-RAG、思维链的形式化讨论、幻觉的知识论分析、Agent 与 PDDL 规划。
6. **第 99 章 综合项目**：领域知识图谱 + KGE 链接预测、贝叶斯网络诊断系统、KG-RAG 原型。

## 0.5 学习方法

1. **两种表示，两套直觉**。本课程最大的认知挑战是在"离散符号"与"连续向量"两套世界观之间来回切换。建议为每个概念自问一次：它的符号形式是什么？它的向量/概率形式是什么？两者各丢失了什么信息？
2. **从零实现，但只实现一次**。命题求值器、TransE、变量消元都值得亲手写一遍——它们各只有一两百行。写完之后，工程上请立刻切换到成熟库（`rdflib`、`pykeen`、`pgmpy`），理解机制与掌握工程必须分开。
3. **用手算喂养直觉**。归结证明、d-分离判定、变量消元的消元顺序，都是"纸笔 10 分钟胜过读论文 1 小时"的典型。每章的"示例与案例"至少手算一个。
4. **始终挂着大模型这条线**。学每一章时都问：这个技术能如何修复 LLM 的某个具体缺陷（幻觉、过期知识、不可审计、不会规划）？第 5 章与综合项目会回收这些问题。
5. **交叉引用是路标不是装饰**。文中给出的相对路径指向你已学过的结论（如[概率统计·第 6 章](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/06/)的吉布斯采样）。遇到遗忘，请真的跳回去看 5 分钟，不要带着模糊的印象前进。
