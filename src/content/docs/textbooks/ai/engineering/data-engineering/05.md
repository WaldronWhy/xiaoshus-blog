# 第 5 章 面向 AI 的数据集构建

> **本章定位**：本课程的收官章。前三章处理"单个数据集怎么弄干净"，本章回答"怎样组织出真正能训练出好模型的数据集"：划分的工程决策、类不平衡、小数据策略、合成数据与隐私、以及大模型时代的语料构建（去重、质量过滤、数据配比）。它把第 1–4 章的全部技术串成"从原始数据到可训练数据集"的完整方法论，并直接为综合项目提供设计模板。

## 5.0 本章学习目标

- 能够依据数据的采集结构（时间、群体、无独立同分布）选择正确的 train/val/test 划分方式，并说出错误划分对应的泄漏类型。
- 能够用重采样、类权重、SMOTE 三种手段处理类不平衡，并说清各自对概率校准与决策边界的副作用。
- 能够解释主动学习的样本选择准则与数据增广的"保标签不变"原则，设计小数据场景的采集策略。
- 能够用 $\varepsilon$-差分隐私的语言解释"加了什么噪声、为什么能保护个体"，并说出合成数据不自动满足隐私的陷阱。
- 能够搭建一个文本语料构建流水线：去重（精确 + MinHash 近似）、质量过滤、数据配比，并量化每一步对下游模型的影响。

## 5.1 划分的工程决策：不止是 train/test split

《机器学习》第 7 章已讲过 K 折交叉验证与分层抽样，本节补齐**工程决策**视角——划分方式本质上是"对测试分布的一个选择"，错了就是最隐蔽的泄漏（第 1 章 1.6 节的五形态在此收口）：

- **随机划分**：适用于样本独立同分布（i.i.d.）且与未来线上分布同源。注意随机划分前先按类别分层（stratify），防止小类在测试集中缺失。
- **按时间划分**：一旦任务本质是"用过去预测未来"（销量预测、流失预测、金融风控），必须按时间切：训练集早于验证集早于测试集。随机划分会把未来信息泄入训练集（时间泄漏）。同时注意**时间缺口（gap）**：若标签要 $T+7$ 天才能回填，训练集与测试集间至少留 7 天缓冲，否则标签泄漏。
- **按群体划分（group split）**：同一用户/患者/设备的多条记录只能落在同侧。否则模型"记住这个用户"就能刷高指标（群体泄漏）。`GroupKFold` / `GroupShuffleSplit` 是标准工具。
- **按数据来源划分**：跨域评估（A 站训练、B 站测试）时，随机划分测的是同域记忆能力，会严重高估泛化。

工程决策清单：问四个问题——①线上推断时，未来数据的分布与历史一致吗？②同一实体是否贡献多条样本？③标签回填有延迟吗？④不同来源的数据是否会混合部署？四个答案共同决定划分方式。**测试集一旦定版就冻结**，配合第 4 章的 DVC 版本化与数据卡片，任何"测试集悄悄换版"都会被追溯。

划分之外还有一个更上游的问题：**选择偏差（selection bias）**——数据集本身就不是目标总体的随机样本。经典案例：1948 年美国总统选举前，《文学文摘》回收 240 万份问卷预测兰登大胜，结果罗斯福当选——问卷发放对象偏向富人。ML 版本比比皆是：仅用自愿评价的产品评论预测全体用户满意度、仅用能连通传感器的设备训练故障预测。选择偏差无法靠划分技巧修复（数据里根本没有缺失的人群），只能靠**明确声明覆盖范围**（写进数据卡片）与定向补充采集（主动学习的另一用武之地，见 5.3 节）。

## 5.2 类不平衡：三种武器的利与弊

划分方式在代码里落地时，`sklearn.model_selection` 的四个类几乎覆盖全部需求。以下是一份可直接改用的"划分配置"（把划分也变成可复现代码，而非手工拖拽 Excel）：

```python
# 依赖: numpy, scikit-learn
import numpy as np
from sklearn.model_selection import (GroupShuffleSplit, TimeSeriesSplit,
                                     train_test_split)

rng = np.random.default_rng(0)
n = 1000
X = rng.normal(size=(n, 4))
y_labels = (X[:, 0] > 0).astype(int)          # 类别不平衡(约 50/50, 演示用)
user_ids = rng.integers(0, 200, n)            # 每行所属的用户(群体标签)
order = np.argsort(rng.random(n))             # 模拟时间顺序
X, y_labels, user_ids = X[order], y_labels[order], user_ids[order]

# 1) 分层随机: 保持两类比例
tr, te = train_test_split(np.arange(n), test_size=0.2,
                          stratify=y_labels, random_state=0)
# 2) 时间划分: 前段训练, 后段测试, gap=标签回填延迟的缓冲天数
tscv = TimeSeriesSplit(n_splits=5, gap=7)
for tr_idx, te_idx in tscv.split(X):
    assert tr_idx.max() + 7 < te_idx.min()    # 缓冲期生效
# 3) 群体划分: 同一 user 的所有行同侧
gss = GroupShuffleSplit(n_splits=1, test_size=0.2, random_state=0)
tr_idx, te_idx = next(gss.split(X, groups=user_ids))
assert set(tr_idx) & set(te_idx) == set()     # 交集为空: 无群体泄漏
print("三种划分全部通过校验; 群体划分测试集含",
      len(np.unique(user_ids[te_idx])), "个用户(训练集未见)")
# 预期输出: 三种划分全部通过校验; 群体划分测试集含 40 个用户(训练集未见)
```

多数类碾压时，准确率毫无意义（《机器学习》第 7 章已给出 AUC、F1、PR 曲线等替代指标），但**训练过程本身**也需要干预。三种主流手段：

### 5.2.1 重采样（resampling）

- **过采样**：复制少数类样本。简单有效，但复制样本不加权地参与训练会加剧对少数类的过拟合；对测试集分布无影响（**只能动训练集，测试集永远保持原始分布**——重采样测试集等于伪造评估）。
- **欠采样**：丢弃多数类。信息损失；改进做法是先删除"边界不清/冗余"的多数类样本（如 Tomek links）。
- **SMOTE（Synthetic Minority Over-sampling Technique, Chawla et al. 2002）**：对少数类样本 $x_i$，在其 $k$ 近邻（同为少数类）中随机选 $x_j$，生成合成样本

$$x_{\text{new}} = x_i + \lambda (x_j - x_i), \qquad \lambda \sim U(0, 1),$$

即沿少数类内部连线插值。比复制更平滑，但有两个已知风险：若少数类样本本身含噪声，SMOTE 会**放大噪声**；在类别边界重叠区域可能生成"骑跨边界"的合成样本，反而模糊决策边界。

### 5.2.2 类权重（class weights）

在损失函数中给少数类更大权重：$L = -\frac{1}{N}\sum_i w_{y_i}\,\ell(\hat y_i, y_i)$，二分类常用 $w_c = \frac{N}{2 N_c}$（sklearn 的 `"balanced"` 策略）。优点：不改动数据、实现一行、对梯度下降类模型天然支持；缺点：改变输出概率的校准（《机器学习》第 7 章校准一节）——加权后模型输出的"0.9"不再是 90% 的真实发生率，上线需要重新校准或按业务重新选阈值。

### 5.2.3 阈值移动（threshold moving）

训练不动、推理时把正类判定阈值从 0.5 降下来。这是**唯一不影响概率校准**的手段，常与类权重联用。工程建议的默认次序：先类权重 + 阈值调整（简单、可控），不奏效再上 SMOTE，最后才是欠采样。

### 5.2.4 决策流程与业务指标

把三种手段放进一个决策流程：

1. **先确认不平衡是否"真"**：2% 的欺诈率可能就是真实业务先验。此时模型的任务是把少数类排到前面（排序问题，用 AUC/PR），不需要改分布。
2. **排序不够、要硬判类**（如实时拦截）：类权重 + 阈值扫描，以业务代价（漏放损失 vs 误拦成本）选工作点，而不是 F1。
3. **少数类样本充足但边界复杂**（上万条）：优先 SMOTE；样本极少（几十条）：SMOTE 的近邻估计不可靠，宁可过采样复制 + 更强的正则。
4. **永远在原始分布的测试集上评估**，并同时报告"排序指标 + 工作点指标"两套。

一个容易被忽略的工程细节：`class_weight="balanced"` 与欠采样在期望上近似等价（都是把损失按类别频率重新配平），但后者丢数据、前者不丢——所以工程默认选权重。等价性的精确表述：对以 $w_c$ 加权的期望损失做变量代换后，等价于在按 $w_c$ 重采样的分布上训练不加权损失。

## 5.3 小数据策略：让每个样本发挥最大价值

数据少时方差主导误差（《机器学习》第 1 章）。两条互补路线：

### 5.3.1 主动学习（active learning）

不是"有多少标多少"，而是**挑最有价值的样本去标注**。循环：用当前小标注集训练 → 模型在未标注池上给出不确定性 → 挑最不确定的样本（uncertainty sampling，如熵最大或决策边界附近）→ 人工标注 → 加入训练集。理论依据是版本空间/查询学习的样本复杂度分析（Settles, 2012 的综述是标准参考）。工程要点：不确定性准则对模型错误校准敏感；批模式（batch-mode）选择时要避免选中一批几乎相同的样本（多样性约束，可用聚类分桶）。主动学习与第 4 章的标注管理流水线无缝衔接：查询批直接进入标注队列。

### 5.3.2 数据增广（data augmentation）

对已有样本做**保持标签不变**的变换扩充训练集。《计算机视觉》课程将系统学习图像增广（翻转、裁剪、颜色扰动）；NLP 中的回译、同义替换要小心语义漂移；表格数据增广困难（插值/混合噪声可能生成不合法组合），这正是 SMOTE 在表格领域流行的原因。原则：**每个增广变换都是一条领域假设**（"水平翻转不改变猫的标签"），违背领域常识的增广是往数据里投毒。

### 5.3.3 两个补充手段

- **弱监督与程序化标注**：没有人工标签时，用规则、词典、已有模型打"弱标签"，再用 Snorkel 式的标签模型估计各弱标注源可靠性并融合——用工程手段替代稀缺的人工标注，代价是引入标注噪声（需在数据卡片中声明）。
- **迁移与预训练**：小数据场景的终极武器是"借用别人大数据学到的表示"——用预训练模型微调，把标注需求从"十万级"降到"百级"。严格说这是建模侧策略，但它反过来改变了数据侧的决策：标注预算应优先花在**测试集质量**与**分布覆盖**上，而不是堆训练量。

## 5.4 合成数据与隐私：差分隐私思想概览

合成数据（generative 模型生成的仿真样本）能缓解稀有场景缺数据、规避真实数据共享的限制。但必须警惕：**合成数据不自动保护隐私**——生成模型可能逐字复述训练集中的真实个体记录（记忆现象），复制了隐私却没带来多样性。

严格的技术框架是**差分隐私（differential privacy, DP）**（Dwork & Roth, 2014）：一个随机化机制 $\mathcal{M}$ 满足 $\varepsilon$-DP，当且仅当对任意两个只差一条记录的相邻数据集 $D, D'$ 与任意输出子集 $S$：

$$\Pr[\mathcal{M}(D) \in S] \le e^{\varepsilon}\, \Pr[\mathcal{M}(D') \in S].$$

直觉：任何单个个体的存在与否，几乎（$e^\varepsilon$ 倍以内）不改变输出分布——攻击者无论知道多少背景信息，都无法从输出中确认某个个体在数据集中。实现隐私最简单的机制之一是 **Laplace 机制**：对数值查询 $f(D)$（敏感度为 $\Delta$，即单条记录最多能改变多少查询结果），发布 $f(D) + \mathrm{Laplace}(0, \Delta/\varepsilon)$：

$$\Pr[f(D) + \eta = z] \propto \exp\!\left(-\frac{|z - f(D)|\,\varepsilon}{\Delta}\right).$$

训练神经网络的对应技术是 DP-SGD（Abadi et al., 2016）：对单样本梯度裁剪（限制 $\Delta$）后加高斯噪声，累积隐私预算。工程常识：$\varepsilon$ 越小越私密但效用越差，"$\varepsilon$ 是用效用买隐私的预算"；合成数据若想声称隐私保护，其生成过程必须本身满足 DP，且累计预算要记账。

顺带厘清 DP 与传统匿名化的层次差别。**k-匿名**（k-anonymity，任一记录的准标识符组合至少与另外 $k-1$ 条相同）是**语法性质**：它防"通过准标识符定位到人"，但不提供任何数学保证——攻击者若拥有外部背景知识（同质攻击、补充数据集），k-匿名可以被逐步击穿。差分隐私是**语义保证**：证明不依赖攻击者的能力假设，对任意背景知识成立。这也是为什么现代监管讨论（以及 Apple/Google 的实践）倾向于以 DP 为隐私宣称的金标准，而把 k-匿名类方法视为初步脱敏手段。

## 5.5 大模型时代的数据工程：语料构建流水线

大模型预训练把前四章的技术推到 TB 级文本。典型流水线（DataComp 式"设计数据配方、在固定模型与算力下比较"的评测思路，Gadre et al., 2023）：

1. **获取与提取**：从 Common Crawl 等海量网页快照出发，用解析器抽取正文、剥离模板与广告（对应第 1 章采集与清洗）。
2. **精确去重**：文档级哈希（第 3 章内容寻址的直用）与行级/段落级重复删除。网页语料中重复率常过半。
3. **近似去重**：海量文档的相似检测用 **MinHash + LSH**（Broker 的 MinHash 1997；Charikar 的 SimHash 2002）。原理：用 $h$ 个哈希函数对每个文档的词集合取最小值构成签名（MinHash），签名相同的概率约等于 Jaccard 相似度 $J(A, B) = |A \cap B| / |A \cup B|$：

$$\Pr[\mathrm{minhash}_k(A) = \mathrm{minhash}_k(B)] = J(A, B).$$

把签名按 LSH 分桶，同桶候选对再做精确签名比对——把 $O(n^2)$ 对比降到近似线性（《数据结构与算法》第 7 章 LSH 的直接落地）。
4. **质量过滤**：启发式规则（语言检测、文档长度、符号占比、停用词得分）+ 训练轻量分类器（如"维基百科 vs 随机网页"的 fastText 分类器，Gopher/RefinedWeb 采用）打分过滤。

启发式规则值得展开，因为它便宜、可解释、是流水线的第一道闸门。Gopher 论文公开的一组经典规则（中英文语料均适用，阈值为示例）：

| 规则 | 阈值示例 | 针对的问题 |
|---|---|---|
| 文档词数 | ≥ 50 且 ≤ 100,000 | 超短页（导航页）与超长页（sitemap/转储） |
| 符号占比 | 符号行数占比 < 10% | 代码/导航列表/乱码页 |
| 停用词覆盖 | 覆盖 ≥ 25% 常用停用词 | 关键词堆砌、随机词页 |
| 单词重复度 | 最大单句内重复词占比 < 20% | "the the the"式坏页 |
| 字母占比 | ≥ 80% | 编码错误页（乱码） |
| 省略号结尾行占比 | < 90% | 被截断的抓取 |

规则之间用"通过率漏斗"串联并**逐条记录删除量**（第 4 章断言式报告的直接应用）。分类器过滤器（质量打分模型）能力更强但有系统性风险：它会把语料分布拉向"长得像维基百科"的样本，长期用可能损害多样性——RefinedWeb 的实验表明，**严格的规则过滤 + 充分去重后，可以不用分类器**也训出好模型，这是一个重要的反直觉结论。
5. **数据配比（mixture / data curriculum）**：多源数据（网页、代码、书籍、学术）按比例混合，比例是重要超参——不同配比训练的模型能力侧重不同；DataComp 式评测把"配比+过滤规则"当作可优化的"数据配方"，在固定算力下按下游指标选择。
6. **评测污染防控**：对基准测试集做 n-gram 重叠审计（第 4 章进阶方向），从源头避免"考题进教材"。

现代实验的核心结论值得记住：**在固定算力下，更少但更好的数据可以胜过更多更脏的数据**（Chinchilla 的数据-参数缩放律与 RefinedWeb 等去重/过滤实验共同指向这一点）。"数据即超参数"——语料配方与模型架构同等重要。

## 5.6 关键公式速查

| 公式 | 含义 | 适用条件 |
|---|---|---|
| SMOTE：$x_{\text{new}} = x_i + \lambda(x_j - x_i)$，$\lambda \sim U(0,1)$ | 少数类插值合成 | $x_j$ 取自 $x_i$ 的同类 $k$ 近邻；注意噪声放大 |
| 类权重：$w_c = N/(2N_c)$（二分类） | 平衡损失贡献 | sklearn `"balanced"` 策略；会改变概率校准 |
| $\varepsilon$-DP：$\Pr[\mathcal{M}(D)\in S] \le e^\varepsilon \Pr[\mathcal{M}(D')\in S]$ | 个体级隐私保证 | $D, D'$ 为相邻数据集（差一条记录） |
| Laplace 机制：发布 $f(D) + \mathrm{Laplace}(0, \Delta/\varepsilon)$ | 满足 $\varepsilon$-DP 的数值查询 | $\Delta$ 为查询的 $L_1$ 敏感度 |
| MinHash：$\Pr[\text{签名相等}] = J(A,B)$ | 近似去重的相似度估计 | 大样本下频率收敛于 Jaccard |
| $J(A,B) = |A\cap B|/|A\cup B|$ | 集合相似度 | 近似去重的比对标准 |

## 5.7 示例与案例

### 案例 1（手算）：SMOTE 的一次插值与 MinHash 估计

**SMOTE 插值**：二维特征空间中，少数类样本 $x_i = (2, 2)$，其同类近邻 $x_j = (4, 6)$，抽到 $\lambda = 0.25$：

$$x_{\text{new}} = x_i + \lambda(x_j - x_i) = (2, 2) + 0.25\,(2, 4) = (2.5,\ 3.0).$$

**校验值：$(2.5, 3.0)$**。注意两点：①合成样本一定落在同类样本连线**内部**——若 $x_i$ 恰在类别边界上，插值可能生成越界样本，这正是 SMOTE 在类重叠场景失效的几何原因；②$\lambda \sim U(0,1)$ 保证合成的期望位置在连线中点，但方差不为零——多次运行同一对近邻会得到不同样本（增广的随机性来源）。

**MinHash 估计 Jaccard**：

文档 A 词集 $\{\text{cat}, \text{dog}, \text{bird}, \text{fish}\}$，文档 B 词集 $\{\text{dog}, \text{bird}, \text{cow}\}$。$J = |A\cap B| / |A\cup B| = 2/5 = 0.4$。取两个哈希函数（输入词输出整数），模拟一次：设 $h_1$ 对 A 中词的最小值落在 cat（哈希值 3），对 B 的最小值落在 bird（哈希值 3）→ 签名相等，记 1；$h_2$ 对 A 最小在 fish（7），对 B 最小在 cow（7）→ 相等，记 1。两函数估计 $\hat J = 2/2 = 1$？——单次签名相等/不等只有"撞对/撞错"的伯努利性，**用 $h$ 个函数的平均值估计 $J$**，$h$ 越大方差越小。本例 $J = 0.4$，取 $h = 50$ 个随机哈希函数，估计值的标准差约 $\sqrt{0.4\times0.6/50} \approx 0.07$。（**校验值：真值 $J = 0.4$，50 个签名估计的典型误差在 $\pm 0.14$ 内。**）

# 依赖: numpy, scikit-learn

from collections import Counter

X, y = make_classification(n_samples=4000, n_features=20, weights=[0.95, 0.05],
                           flip_y=0.02, random_state=0)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.25, stratify=y, random_state=0)

def fit_eval(model, tag):
    model.fit(Xtr, ytr)
    proba = model.predict_proba(Xte)[:, 1]
    print(f"{tag:<24s} AUC={roc_auc_score(yte, proba):.4f}  "
          f"AP={average_precision_score(yte, proba):.4f}")

fit_eval(HistGradientBoostingClassifier(random_state=0), "基线(无处理)")
fit_eval(LogisticRegression(class_weight="balanced", max_iter=2000), "类权重(逻辑回归)")
fit_eval(HistGradientBoostingClassifier(random_state=0, class_weight="balanced"),
         "类权重(GBDT)")

# ---- SMOTE: 从零实现插值公式(只作用于训练集!) ----
def smote(Xs, ys, k=5, target_ratio=0.5, seed=0):
    rng = np.random.default_rng(seed)
    xs = Xs[ys == 1]                                   # 少数类样本
    need = int(len(ys) * target_ratio) - len(xs)       # 补到目标占比
    nbrs = NearestNeighbors(n_neighbors=k + 1).fit(xs) # +1 是它自己
    nn_idx = nbrs.kneighbors(xs, return_distance=False)[:, 1:]
    syn = []
    for _ in range(need):
        i = rng.integers(len(xs))
        j = nn_idx[i][rng.integers(k)]                 # 同类近邻
        lam = rng.random()
        syn.append(xs[i] + lam * (xs[j] - xs[i]))      # 插值公式 x_i + λ(x_j - x_i)
    return (np.vstack([Xs, np.array(syn)]),
            np.concatenate([ys, np.ones(need, int)]))

Xs2, ys2 = smote(Xtr, ytr)
cnt = lambda c: {int(k): v for k, v in Counter(c).items()}
print("SMOTE 前:", cnt(ytr), "  后:", cnt(ys2))
sm = HistGradientBoostingClassifier(random_state=0).fit(Xs2, ys2)
proba = sm.predict_proba(Xte)[:, 1]
print(f"{'SMOTE(GBDT)':<24s} AUC={roc_auc_score(yte, proba):.4f}  "
      f"AP={average_precision_score(yte, proba):.4f}")
# 预期输出（随机种子固定，数值可复现）:
# 基线(无处理)          AUC=0.8924  AP=0.6370
# 类权重(逻辑回归)       AUC=0.8975  AP=0.4878
# 类权重(GBDT)          AUC=0.8876  AP=0.6807
# SMOTE 前: Counter({0: 2824, 1: 176})   后: Counter({0: 2824, 1: 1500})
# SMOTE(GBDT)           AUC=0.9021  AP=0.6576
# 观察: ①AUC 变化很小(排序能力), 变的主要是 AP(决策偏置)——正文的结论再现;
#      ②类权重在逻辑回归上把决策偏置推得过大, AP 反而下降——权重/阈值需要扫描调优,
#        "加大少数类权重"不是免费的;
#      ③在测试集上评估时从未做过任何重采样——SMOTE 只在训练集里发生。

下面是 MinHash 近似去重的最小实现（本课程综合项目三的核心构件）：

```python
# ch5_minhash_dedup.py
# 依赖: numpy
import numpy as np

def shingles(text: str, k: int = 5) -> set:
    """字符级 k-shingle 词集(演示用; 生产用词级 n-gram)。"""
    return {text[i:i + k] for i in range(len(text) - k + 1)}

def minhash_sig(s: set, n_perm: int = 64, seed: int = 0) -> np.ndarray:
    """MinHash 签名: 每个哈希函数取词集中哈希值的最小者。
    全程用 Python 整数运算, 避免 numpy 整型溢出。"""
    rng = np.random.default_rng(seed)
    hashes = rng.integers(1, 2**40, size=n_perm)          # n_perm 个随机哈希系数
    sig = []
    for h in hashes:
        vals = [((int(h) * int.from_bytes(w.encode(), "little")) % (2**61 - 1))
                for w in s]
        sig.append(min(vals))
    return np.array(sig)

def jaccard_est(sig_a: np.ndarray, sig_b: np.ndarray) -> float:
    return float((sig_a == sig_b).mean())                 # 签名相等频率 ≈ J(A,B)

docs = ["the quick brown fox jumps over the lazy dog",
        "the quick brown fox jumps over the lazy dog!",  # 近似重复
        "completely different topic about quantum physics"]
sigs = [minhash_sig(shingles(d)) for d in docs]
print("d0-d1 相似度估计:", round(jaccard_est(sigs[0], sigs[1]), 3))  # 预期 > 0.9
print("d0-d2 相似度估计:", round(jaccard_est(sigs[0], sigs[2]), 3))  # 预期 ≈ 0
# 实测输出: d0-d1 相似度估计: 0.984   d0-d2 相似度估计: 0.0
# 去重规则: 相似度 > 0.8 的候选对只保留一篇(如保留更早抓取的)
```

## 5.8 常见误区与陷阱

1. **对时间序列任务做随机划分**。指标好得可疑时第一个检查项。连同"测试集早于部分训练数据"的变体（跨样本标签回填延迟）一起排查。
2. **对测试集做重采样/SMOTE**。评估必须反映真实分布；SMOTE 只进训练折（且要在交叉验证的每个折内独立做，否则合成样本会把近邻信息跨折泄漏）。
3. **以为匿名化 = 隐私安全**。删掉姓名后仍可能被准标识符（邮编+生日+性别）重识别（Sweeney 的著名研究）；声称隐私保护必须走 DP 的定义路线，且记账累计预算。
4. **去重"宁滥勿缺"**。过度激进的近似去重会删掉合法的相似文档（同一事件的多篇不同报道），配比中被误删的子域可能正是模型需要的多样性。
5. **配比拍脑袋**。数据配比是超参数，要用 DataComp 式"固定模型与算力、扫描配比、以下游指标决策"的实验方法（衔接《实验设计与评估》）。
