# 第 5 章 参数估计与统计推断

> **本章定位**：统计推断的频率派主线，也是全课程与机器学习距离最近的一章：**最大似然估计（MLE）是几乎一切监督学习损失函数的统一来源**——线性回归的最小二乘、逻辑回归的交叉熵、语言模型的 next-token 预测全部是某种似然的最大化。本章同时给出评估估计量的三性质、Fisher 信息与 CRLB 下界、置信区间与假设检验的正确用法。前置：第 2 章（似然写法）、第 3 章（LLN/CLT、Jensen）、第 4 章（MAP 对比）。

## 5.1 统计模型与估计问题

**定义 5.1（统计模型）**：一族概率分布 $\{p(x\mid\theta):\theta\in\Theta\}$。数据 $D=\{x_1,\dots,x_n\}$ 假定 i.i.d. 采自其中某一个 $\theta^*$（真参数）。**参数估计**就是构造映射 $\hat\theta=\delta(D):\mathcal{D}\to\Theta$（估计量，estimator；对具体数据的取值叫估计值，estimate）。

问题立刻出现：$\hat\theta$ 是数据的函数，数据是随机的，所以**估计量本身是随机变量**——它的抽样分布（第 3 章的均值/方差/CLT 全部派上用场）刻画估计质量。评估估计量的三性质（5.3 节）全部围绕抽样分布展开。

参数空间是有限维（$\theta\in\mathbb{R}^d$）的模型叫**参数模型**；分布族本身无限维（如"一切连续分布"）的叫非参数问题——机器学习的神经网络本质上把 $d$ 做得极大，统计性质介于两者之间。

## 5.2 最大似然估计（MLE）：机器学习损失函数的统一来源

### 5.2.1 原理

**定义 5.2（似然函数）**：$L(\theta)=\prod_{i=1}^n p(x_i\mid\theta)$。注意角色反转：第 2 章中它是"$\theta$ 固定时数据的分布"；现在数据固定，把它看作 $\theta$ 的函数——衡量"哪个 $\theta$ 最可能让这套数据出现"。

**MLE 原理**：$\hat\theta_{\text{MLE}}=\arg\max_{\theta\in\Theta}L(\theta)$。由于 $L$ 是若干 $[0,1]$ 区间数连乘（数值下溢），且对数单调、不改变 argmax，实际总优化**对数似然**：

$$\ell(\theta)=\ln L(\theta)=\sum_{i=1}^n\ln p(x_i\mid\theta),\qquad \hat\theta_{\text{MLE}}=\arg\max_\theta\ \ell(\theta).$$

求和结构还带来可分解性：SGD 逐样本优化的正是每项 $-\ln p(x_i\mid\theta)$。**《深度学习》训练的分类损失（交叉熵）就是负对数似然（NLL）**：minimize NLL = maximize likelihood。

直觉论证（为什么最大化似然是合理的）：若数据真由某 $\theta^*$ 生成，则 $L(\theta^*)$ 大的概率高——事实上 $\ell(\theta^*)-\ell(\theta)=\sum_i\ln\frac{p(x_i|\theta^*)}{p(x_i|\theta)}$，由大数定律依概率收敛到 $n\,\mathbb{E}_{\theta^*}\left[\ln\frac{p(x|\theta^*)}{p(x|\theta)}\right]=n\,\mathrm{KL}(p_{\theta^*}\|p_\theta)\ge0$（KL 散度非负由 Jensen 不等式给出，第 3 章应用 2）。**MLE 在大样本下找到的 $\theta$ 使 KL 距离真分布最近**——这是 MLE 一致性的信息论证明骨架，也是"交叉熵最小化 = 学到真分布"的根据。

### 5.2.2 高斯 MLE 完整推导

模型：$x_i\stackrel{iid}{\sim}\mathcal{N}(\mu,\sigma^2)$，$\theta=(\mu,\sigma^2)$，估计两者。

**第一步：对数似然。**

$$\ell(\mu,\sigma^2)=\sum_{i=1}^n\left[-\frac12\ln(2\pi)-\frac12\ln\sigma^2-\frac{(x_i-\mu)^2}{2\sigma^2}\right]=-\frac n2\ln(2\pi)-\frac n2\ln\sigma^2-\frac{\sum_i(x_i-\mu)^2}{2\sigma^2}.$$

**第二步：对 $\mu$ 求偏导并置零。**

$$\frac{\partial\ell}{\partial\mu}=\frac{1}{\sigma^2}\sum_{i=1}^n(x_i-\mu)=0\ \Rightarrow\ \hat\mu=\frac1n\sum_i x_i=\bar x.$$

**第三步：对 $\sigma^2$ 求偏导并置零。**（$\sigma^2$ 视为整体变量，用 $\partial\ln\sigma^2/\partial\sigma^2=\frac{1}{\sigma^2}$）

$$\frac{\partial\ell}{\partial\sigma^2}=-\frac{n}{2\sigma^2}+\frac{\sum_i(x_i-\mu)^2}{2\sigma^4}=0\ \Rightarrow\ \widehat{\sigma^2}=\frac1n\sum_i(x_i-\hat\mu)^2.$$

**第四步：验证是最大值。** Hessian 在驻点处负定：$\frac{\partial^2\ell}{\partial\mu^2}=-\frac n{\sigma^2}<0$；对 $\sigma^2$ 的二阶导在驻点为 $-\frac{n}{2\hat\sigma^4}<0$；交叉偏导为 0（$\ell$ 中 $\mu$ 与 $\sigma^2$ 的耦合只在三次项层面）——驻点是局部极大，且边界（$\sigma^2\to0,\infty$）处 $\ell\to-\infty$ 或被支配，故为全局极大。$\blacksquare$

**第五步：审视有偏性（重要！）**：$\mathbb{E}[\widehat{\sigma^2}]=\frac{n-1}{n}\sigma^2\ne\sigma^2$——MLE 方差估计**有偏**。计算依据：$\sum_i(x_i-\bar x)^2=\sigma^2\cdot\chi^2_{n-1}$（$\chi^2$ 期望 $n-1$，因 $\bar x$ 消耗一个自由度），故 $\mathbb{E}[\widehat{\sigma^2}]=\frac{n-1}{n}\sigma^2$。修正：除以 $n-1$（样本方差 $s^2$）才是无偏的。**工程含义**：`np.var(x)` 默认除 $n$（MLE 版），`np.var(x, ddof=1)` 除 $n-1$（无偏版）——小样本时差一个 $1/n$ 因子不可忽略；深度学习里这种偏差通常无害（参数太多、数据淹没问题），但统计报告必须用 $n-1$。

（对比第 4 章：给 $(\mu,\sigma^2)$ 加先验后的 MAP 会把估计从 $\bar x$ 拉向 $\mu_0$——MLE = 先验无限弥散（无信息）时的 MAP 极限。）

### 5.2.3 伯努利/分类 MLE：交叉熵的诞生

模型：$x_i\in\{0,1\}\sim\text{Bern}(\theta)$。对数似然

$$\ell(\theta)=\sum_i\big[x_i\ln\theta+(1-x_i)\ln(1-\theta)\big],\qquad \frac{d\ell}{d\theta}=\frac{\sum_i x_i}{\theta}-\frac{n-\sum_i x_i}{1-\theta}=0\ \Rightarrow\ \hat\theta=\frac{\sum_i x_i}{n}=\text{经验频率}.$$

（二阶导 $-\frac{\sum x_i}{\theta^2}-\frac{n-\sum x_i}{(1-\theta)^2}<0$ 处处成立，故为全局最大。）

现在把参数换成**带输入的条件模型** $\theta(x)=\sigma(w^\top x)$（sigmoid）或 $\text{softmax}(Wx)$，每个样本的 NLL $-\ln p(y_i\mid x_i;w)$ 恰是第 2 章 2.4.1 的伯努利/分类交叉熵。于是：

| 机器学习对象 | 隐含似然假设 | MLE 目标 |
|---|---|---|
| 线性回归 + MSE | $y\mid x\sim\mathcal{N}(w^\top x,\sigma^2)$ | 最小化 $\lVert y-Xw\rVert^2$（$\mu$ 的 MLE 解与 $\sigma^2$ 无关） |
| 逻辑回归 | $y\mid x\sim\text{Bern}(\sigma(w^\top x))$ | 交叉熵（第 5.2.3 式的条件版） |
| softmax 多分类/语言模型 | $y\mid x\sim\text{Categorical}(\text{softmax}(Wx))$ | 交叉熵 = next-token NLL |
| VAE/扩散 | 复杂潜变量模型 | 证据下界（Jensen，第 3 章） |

**结论**：第 4 章（贝叶斯 MAP）与本章（MLE）合起来给出统一公式

$$\hat\theta=\arg\min_\theta\ \underbrace{-\ln p(D\mid\theta)}_{\text{数据项（NLL）}}+\underbrace{-\ln p(\theta)}_{\text{正则项}}\qquad(\text{MAP})，\qquad \text{去掉第二项即 MLE}.$$

机器学习的"损失 = 数据拟合 + 正则"从此不再是经验配方，而是概率推断的直接推论。

## 5.3 估计量的三性质：无偏、一致、有效

**无偏（unbiased）**：$\mathbb{E}[\hat\theta]=\theta^*$（对一切 $\theta^*\in\Theta$）。样本均值无偏；5.2.2 的 $\widehat{\sigma^2}$ 有偏。注意：无偏不是最高纲领——有时有偏估计量（如 James–Stein、岭回归）方差的降低远超偏差代价（偏差–方差权衡，《机器学习》第 2 章将严格化为期望泛化误差分解）。

**一致（consistent）**：$\hat\theta_n\to\theta^*$（依概率；i.i.d. 正则模型下 MLE 满足，证明用 5.2.1 的 KL 论证 + 紧性）。一致性是"数据多了就对"的底线要求，**不可牺牲**。

**有效（efficient）**：在无偏估计量中方差达到理论下界（CRLB，5.4 节）。样本均值对高斯均值有效；对其他分布只是渐近（大样本）有效。

## 5.4 Fisher 信息与 Cramér–Rao 下界

### 5.4.1 Fisher 信息的两种等价定义

直觉：似然面 $\ell(\theta)$ 在真值附近越"陡峭"，数据对 $\theta$ 越敏感，可估计性越强。曲率的期望即信息量：

$$I_n(\theta)=\mathbb{E}\left[-\frac{\partial^2}{\partial\theta^2}\ell(\theta)\right]\qquad\text{（曲率版）}，\qquad I_n(\theta)=\mathbb{E}\left[\left(\frac{\partial}{\partial\theta}\ell(\theta)\right)^2\right]\qquad\text{（得分版）}.$$

两式相等需正则条件（可在积分号下求导，见 Casella & Berger 第 7 章）。i.i.d. 数据加法性：$I_n(\theta)=n\,I_1(\theta)$——**信息随样本量线性累积**，这直接决定估计精度的 $1/\sqrt n$ 速率。

**例**：$x\sim\mathcal{N}(\mu,\sigma^2)$ 估 $\mu$：单样本得分 $\partial\ell/\partial\mu=\frac{x-\mu}{\sigma^2}$，$I_1=\mathbb{E}\left[\frac{(x-\mu)^2}{\sigma^4}\right]=\frac{1}{\sigma^2}$——"方差小 = 信息多"。

### 5.4.2 CRLB 与 MLE 的渐近有效性

**定理 5.1（Cramér–Rao 下界）**：任何无偏估计量满足 $\mathrm{Var}(\hat\theta)\ \ge\ \dfrac{1}{I_n(\theta)}$。

证明骨架（Cauchy–Schwarz 一行流）：设 $\hat\theta$ 无偏，则 $\mathbb{E}[\hat\theta\cdot S]=\theta$，其中得分 $S=\partial_\theta\ell$（在积分号下求导：$\mathbb{E}[S]=0$，$\mathbb{E}[\hat\theta S]=\int\hat\theta\,\partial_\theta p\,dx=\partial_\theta\int\hat\theta p\,dx=\partial_\theta\theta=1$）。于是 $\mathrm{Cov}(\hat\theta,S)=1$，由 $\mathrm{Var}(\hat\theta)\mathrm{Var}(S)\ge\mathrm{Cov}^2=1$ 得 $\mathrm{Var}(\hat\theta)\ge1/I_n$。$\blacksquare$

**MLE 的渐近正态性**（正则条件下）：

$$\sqrt n\,(\hat\theta_{\text{MLE}}-\theta^*)\ \Rightarrow\ \mathcal{N}\!\left(0,\ \frac{1}{I_1(\theta^*)}\right).$$

即 MLE 的渐近方差恰好等于 CRLB——**MLE 是渐近有效的**（达到无偏估计的精度极限）。这个 $1/\sqrt n$ 与 CLT 的速率（第 3 章）同源：MLE 本质是"得分函数的样本均值"=0 的解，得分函数成为 CLT 中的 i.i.d. 项。高斯的例子可以精确验证：$\mathrm{Var}(\bar x)=\sigma^2/n=1/(nI_1)$，样本均值在一切 $n$（不只渐近）达到 CRLB。

**工程含义**：CRLB 给出"数据里到底还有多少油水"的天花板——做传感器融合、实验设计时，先算 Fisher 信息判断某参数是否可辨识（信息接近 0 ⇒ 任何算法都救不了）。

## 5.5 置信区间与假设检验

### 5.5.1 置信区间：随机的是区间，固定的是参数

**定义 5.3**：若对一切 $\theta^*$，$P_{\theta^*}\big(L(D)\le\theta^*\le U(D)\big)=1-\alpha$，则 $[L(D),U(D)]$ 是 $1-\alpha$ 置信区间。

**语义（务必精确）**：95% 指的是**构造程序**的性质——重复抽样所得随机区间中约 95% 覆盖真值；**不是**"真值落在这个具体区间的概率是 95%"（参数不是随机的，第 4 章 4.8 节已对比）。单个区间要么含真值要么不含，95% 是对程序的长期频率陈述。

构造（大样本，借助 MLE 渐近正态）：$\hat\theta\pm z_{\alpha/2}\cdot\mathrm{SE}$，其中标准误 $\mathrm{SE}=\sqrt{\widehat{\mathrm{Var}}(\hat\theta)}$，$\widehat{\mathrm{Var}}\approx\frac{1}{I_n(\hat\theta)}$。均值情形（方差已知）：$\bar x\pm z_{\alpha/2}\frac{\sigma}{\sqrt n}$；方差未知时 $\sigma\to s$、$z\to t_{n-1}$（Student t，见 5.5.2）。

### 5.5.2 假设检验：反证法的统计版 + t 检验

逻辑：先假设原假设 $H_0$（如"$\mu=\mu_0$"），考察**若 $H_0$ 为真**，观测到当前（或更极端）数据的概率。这一概率即 p 值：

**定义 5.4（p 值）**：在 $H_0$ 为真的条件下，检验统计量取到与观测值一样极端或更极端值的概率。$p<\alpha$ 时拒绝 $H_0$（在 $\alpha$ 水平上"显著"）。

**单样本 t 检验**（$H_0:\mu=\mu_0$，方差未知、正态或大样本）：

$$t=\frac{\bar x-\mu_0}{s/\sqrt n}\ \sim\ t_{n-1}\ \text{（H}_0\text{ 为真时）}，$$

$t$ 分布是"标准正态除以（$\chi^2_{n-1}/(n-1)$ 的平方根）"——分子是 $\bar x$ 的标准化（含未知的 $s$），分母是方差估计的涨落，$t$ 分布比正态更厚尾以计入这层不确定性；$n\to\infty$ 时趋于正态。

**p 值的三种标准误读（面试与论文评审高频考点）**：

1. p 值 ≠ "$H_0$ 为真的概率"（贝叶斯后验才是，第 4 章；两者差一个先验比，即 prosecutor's fallacy 的统计版）；
2. p 值 ≠ 效应大小：$n$ 极大时任何微小效应都会显著——**显著 $\ne$ 重要**，务必同时报告效应量与置信区间；
3. 不显著 ≠ 证明 $H_0$：可能只是功效（power，$1-\beta$）不足。

另两条纪律：检验必须在看数据前定义（多重比较、可选终点会膨胀假阳性，需 Bonferroni 或 FDR 修正）；$\alpha=0.05$ 是约定不是自然律。

## 5.6 关键公式速查

| 公式 | 表达式 | 适用条件 |
|---|---|---|
| 对数似然 | $\ell(\theta)=\sum_i\ln p(x_i\mid\theta)$ | i.i.d. 数据、可微密度 |
| MLE 定义 | $\hat\theta=\arg\max\ell(\theta)$ | 一般参数模型 |
| 高斯 MLE | $\hat\mu=\bar x$，$\widehat{\sigma^2}=\frac1n\sum(x_i-\bar x)^2$（有偏，除 $n-1$ 修正） | 正态 i.i.d. |
| 伯努利 MLE | $\hat\theta=$ 经验成功频率 | Bern i.i.d. |
| MAP/MLE 统一 | $\arg\min\,\text{NLL}+(-\ln p(\theta))$ | MAP 有先验项；MLE 无 |
| 无偏/一致/有效 | $\mathbb{E}[\hat\theta]=\theta$；$\hat\theta_n\to\theta$；$\mathrm{Var}$ 达 CRLB | 估计量评估三档 |
| Fisher 信息 | $I_n(\theta)=\mathbb{E}[-\ell''(\theta)]=nI_1(\theta)$ | 正则条件 |
| CRLB | $\mathrm{Var}(\hat\theta)\ge1/I_n(\theta)$ | 无偏估计量 |
| MLE 渐近分布 | $\sqrt n(\hat\theta-\theta^*)\Rightarrow\mathcal{N}(0,1/I_1)$ | 正则模型，$n\to\infty$ |
| 均值置信区间 | $\bar x\pm z_{\alpha/2}\dfrac{\sigma}{\sqrt n}$（$\sigma$ 未知用 $s$ 与 $t_{n-1}$） | 正态或大样本 |
| t 统计量 | $t=\dfrac{\bar x-\mu_0}{s/\sqrt n}\sim t_{n-1}$ | 同上 |

## 5.7 示例与案例

### 案例 1（手算）：灯泡寿命的完整推断

10 只灯泡寿命（小时，已简化为整数）：`1000 1020 980 1010 995 1005 990 1015 985 1000`。假设正态。

1. MLE：$\hat\mu=\bar x=1000$；$\widehat{\sigma^2}=\frac1n\sum(x_i-\bar x)^2=150$（方差 MLE），无偏版 $s^2=\frac{10}{9}\times150\approx166.7$，$s\approx12.9$。
2. $\mu$ 的 95% 置信区间（$t_{9,0.975}=2.262$）：$1000\pm2.262\times\frac{12.9}{\sqrt{10}}=1000\pm9.2$，即 $[990.8,\ 1009.2]$。
3. 检验 $H_0:\mu=1010$：$t=\frac{1000-1010}{12.9/\sqrt{10}}\approx-2.45$，$|t|>2.262$ ⇒ 在 0.05 水平拒绝（p 值约 0.036）。注意 1010 恰在区间外、与检验结论一致——**置信区间与对应双尾检验等价**（区间包含 $\mu_0$ ⇔ 检验不拒绝）。

### 案例 2（代码）：MLE 的抽样分布与 CRLB 的数值验证

模拟"$\hat\mu=\bar x$ 的方差触及 CRLB"：

```python
import numpy as np

rng = np.random.default_rng(5)
theta_true, sigma, n, n_rep = 3.0, 2.0, 25, 100_000

# 重复实验: 每组 25 个样本, 记录 MLE(=样本均值)
hats = rng.normal(theta_true, sigma, size=(n_rep, n)).mean(axis=1)

var_emp = hats.var()          # 经验抽样方差
var_crlb = sigma**2 / n       # CRLB = 1/(n*I1) = sigma^2/n
print(f"empirical Var = {var_emp:.4f},  CRLB = {var_crlb:.4f}, "
      f"ratio = {var_emp/var_crlb:.3f}")          # 预期 ratio ≈ 1.00
print(f"bias = {hats.mean() - theta_true:+.4f}")   # 预期 |bias| < 0.01

# 渐近正态性: sqrt(n)*(hat-theta) 应近似 N(0, sigma^2)
z = np.sqrt(n) * (hats - theta_true)
print(f"std of z = {z.std():.3f} (theory {sigma:.3f})")
# 预期: std of z ≈ 2.00 —— MLE 渐近有效性被直接"看见"
```

### 案例 3（代码）：从零实现高斯与逻辑回归的 MLE

```python
import numpy as np
from scipy import optimize

rng = np.random.default_rng(0)

# ---- (a) 高斯 MLE, 用 scipy 数值优化对照解析解 ----
data = rng.normal(5.0, 2.0, 500)
def neg_loglik(params):
    mu, log_var = params                  # 用 log_var 保证方差>0 (无约束优化技巧)
    return 0.5*np.log(2*np.pi) + 0.5*log_var \
           + ((data-mu)**2).mean() / (2*np.exp(log_var))
res = optimize.minimize(neg_loglik, x0=[0.0, 0.0], method="BFGS")
print("numerical:", res.x, "\nanalytic :",
      [data.mean(), np.log(data.var())])   # 预期两行几乎一致

# ---- (b) 逻辑回归 = 伯努利 NLL 最小化 (从零实现, 对照 sklearn) ----
n, d = 400, 2
X = rng.normal(size=(n, d)); X1 = np.hstack([X, np.ones((n, 1))])
w_true = np.array([1.5, -2.0, 0.5])
p = 1/(1+np.exp(-(X1 @ w_true))); y = (rng.random(n) < p).astype(float)

def nll(w):                                # 交叉熵 = 伯努利负对数似然
    z = X1 @ w
    return np.mean(np.logaddexp(0, z) - y*z)   # log(1+e^z)-y*z, 数值稳定
def grad(w):
    z = X1 @ w
    return X1.T @ (1/(1+np.exp(-z)) - y) / n   # dNLL/dw = X^T(sigmoid(z)-y)/n

w = np.zeros(3)
for _ in range(2000):                      # 梯度下降 (《最优化》将换成更好的方法)
    w -= 0.5 * grad(w)
print("from-scratch w:", np.round(w, 3))   # 预期接近 [1.5, -2.0, 0.5]
```

案例 3(b) 值得反复咀嚼：你没有调用任何"分类器库"，只写了似然、求导、下降三件事——**逻辑回归就是最大化伯努利似然的 MLE**。《深度学习》把 (b) 的 $X_1$ 换成神经网络输出、用自动微分替代手写 `grad`，其余分毫未变。

## 5.8 常见误区与陷阱

1. **报告 MLE 方差用除 $n$ 版本**。统计报告用 $s^2$（$n-1$）；MLE 版只用于优化场景（如高斯参数的损失计算）。NumPy 的 `ddof` 参数差异是真实事故源。
2. **p 值误读三连**（5.5.2 详列）：当后验、当效应量、当"不显著=无差异"。论文审稿中最常见的统计学错误即前两条。
3. **在 $H_0$ 被拒绝后接着用同一份数据"寻找"显著因素**（HARKing / 多重比较）：假阳性率随检验次数膨胀，$20$ 个检验在 $\alpha=0.05$ 下至少一个假显著的概率约 $1-0.95^{20}\approx64\%$。
4. **MLE 逐字套用到重尾/边界参数**。如用 $\ell$ 的驻点方程估 $U(0,\theta)$ 的 $\theta$：MLE 是 $\max_i x_i$，不是任何导数为零的点（似然在边界跳变）——"求导置零"不是 MLE 的定义，只是常用手段。
5. **把渐近性质当有限样本保证**。$\sqrt n$ 渐近正态在 $n$ 小或参数近边界（方差→0、概率→0/1）时失真；此时改用 bootstrap（第 99 章项目三）或贝叶斯后验（第 4 章）。

## 5.11 进阶方向

- **渐近效率的精细版**：Le Cam 局部渐近正态（LAN）框架、Hájek-Le Cam 卷积定理——"MLE 渐近有效"的严格化；进入统计理论研究的门槛。
- **稳健统计（robust statistics）**：MLE 对模型误设敏感；M-估计、影响函数（influence function）度量单个污染点对估计量的最大影响，Huber 损失由此而来——深度学习中的损失裁剪同源。
- **经验贝叶斯与正则化的现代观**：James–Stein 收缩、$E[\lVert\hat\theta\rVert]$ 的超有效性；高维 ($d$ 与 $n$ 同阶) 下 CRLB 框架失效，Lasso 的误差界取而代之。
- **可辨识性与因果参数**：不是所有"参数"都能从数据估出（如混合模型的标签交换）；Fisher 信息奇异 ⇒ 参数不可辨识，这是《因果推断》中 do-效果与相关性区分的技术起点。
