# 第 1 章 概率空间与条件概率（对应 1.11 节，共 11 题）

## 题 1（概念辨析｜对应 1.4 节独立性、1.4.2 独立与互斥）

> (a) 若 $A\subset B$ 且 $P(A)>0$，$A$ 与 $B$ 可能独立吗？(b) $P(A)=P(B)=0.5$ 且 $A,B$ 互斥，$P(A\cup B)$ 是多少？$A,B$ 独立吗？

**(a) 标准答案**：一般不可能独立；唯一例外是退化的 $P(B)=1$。

推导：$A\subset B \Rightarrow AB=A$，故 $P(AB)=P(A)$。若 $A,B$ 独立，则 $P(AB)=P(A)P(B)$，于是

$$P(A)=P(A)P(B)\ \xRightarrow{P(A)>0}\ P(B)=1.$$

所以只要 $P(B)<1$（真正"有信息"的情形），包含关系与独立不相容。直觉：$A$ 发生必然推出 $B$ 发生——$A$ 携带了大量关于 $B$ 的信息，信息不更新才叫独立，矛盾。

**(b) 标准答案**：$P(A\cup B)=P(A)+P(B)-P(AB)=0.5+0.5-0=1$。**不独立**：$P(AB)=0\ne P(A)P(B)=0.25$。

**常见错误**：
- "互斥 = 独立"——错。互斥是 $P(AB)=0$（不能同时发生），独立是 $P(AB)=P(A)P(B)$（互不提供信息）。对 $P(A),P(B)>0$ 的事件，互斥必然**不**独立：知道 $A$ 发生立刻推出 $B$ 没发生，信息量极大。
- "包含关系与独立性无关"——错，见 (a) 的证明。
- 端点情形要会说：$P(A)=0$（或 $P(B)=0$）的事件与任何事件独立；$P(B)=1$ 时 $A\subset B$ 也可以独立。本题特意设 $P(A)>0$ 排除平凡情形。

## 题 2（概念辨析｜对应 1.3 节条件概率、1.6 案例 1）

> "检测准确率 99%"这句宣传至少歧义在几个量上？用条件概率把它们分别写出来。

**标准答案要点**："99%"至少可能指以下四个不同的条件概率，方向与条件集各不相同：

| 量 | 记号 | 名称 |
|---|---|---|
| 患者被检出 | $P(+\mid D)$ | 灵敏度（sensitivity） |
| 健康人被正确排除 | $P(-\mid D^c)=0.99$ | 特异度（specificity），等价于误报率 $P(+\mid D^c)=0.01$ |
| 阳性者真患病 | $P(D\mid +)$ | 阳性预测值 PPV（**取决于患病率先验**） |
| 阴性者真健康 | $P(D^c\mid -)$ | 阴性预测值 NPV（同样依赖先验） |

关键点：$P(+\mid D)$ 与 $P(D\mid+)$ 是**两个方向的完全不同的数**（正文案例 1 中相差约 50 倍：0.99 vs ≈0.019）；而 PPV/NPV 甚至不是检测器自身的属性——它们随人群患病率 $P(D)$ 变化。宣传语不指明方向与条件集，就是检察官谬误的温床。

**常见错误**：只答"灵敏度/特异度"两个量。PPV 与 NPV 也是"准确率"的日常误读对象，漏掉它们正是基率谬误发生的原因。

## 题 3（概念辨析｜对应 1.4.3 条件独立，Simpson 悖论）

> 证明：$A\perp B\mid C$ 与 $A\perp B\mid C^c$ 同时成立，**不能**推出 $A\perp B$。

**路线**：不用抽象证明，构造显式反例最有说服力（本课程反复强调"列出显式样本空间"）。

**反例（同一枚硬币投两次）**：先等概率选一枚硬币：$C=1$ 表示"偏币"（正面概率 $0.8$），$C=0$ 表示"正常币"（正面概率 $0.4$）。$A$=第一次投掷正面，$B$=第二次投掷正面。给定硬币类型，两次投掷独立，所以

$$A\perp B\mid C \quad\text{且}\quad A\perp B\mid C^c\quad\text{（按构造直接成立）}.$$

但边缘化之后（全概率公式，权各 $1/2$）：

$$P(AB)=\tfrac12(0.8^2+0.4^2)=\tfrac12(0.64+0.16)=0.40,$$
$$P(A)=P(B)=\tfrac12(0.8+0.4)=0.60,\qquad P(A)P(B)=0.36\ne0.40.$$

所以 $A,B$ **不独立**。$\blacksquare$

**为什么错得如此自然**：对 $C$ 边缘化（"不知道用的是哪枚币"）会把两个层内的独立混合成层间的正相关——知道第一次正面，你更相信拿到的是偏币，于是上调第二次正面的概率。这就是 Simpson 悖论的概率内核：**分层看与合并看，结论可以相反**；条件独立与（边缘）独立互不蕴含，在概率图模型里对应"划分不构成 d-分离"。

**常见错误**：试图用"$P(AB\mid C)=P(A\mid C)P(B\mid C)$ 两边对 $C$ 平均"直接推 $P(AB)=P(A)P(B)$——平均号会被 $P(C\mid A)$、$P(C\mid B)$ 这些后验权重搅乱，推不过去；上面的数字演示了推不过去的具体方式（$0.40$ vs $0.36$）。

## 题 4（计算推导｜对应 1.2.2、1.4.1）

> 三个引擎各自以 0.9 的概率独立正常工作，至少两个正常才能飞行，求飞行概率。（校验值：0.972）

设 $X$ 为正常引擎数，$X\sim\text{Bin}(3,0.9)$（三次独立伯努利）。"至少两个正常"与"至多一个故障"互为对立，用对立事件算更省：

$$P(\text{飞行})=1-P(X\le1)=1-\binom31(0.9)(0.1)^2-(0.1)^3.$$

逐步代入：

- 恰一个故障：$\dbinom31\cdot 0.9\cdot 0.01=3\times0.009=0.027$；
- 全故障：$0.001$；
- $P(\text{飞行})=1-0.027-0.001=0.972$。

正向验算：$P(X=2)+P(X=3)=\binom32(0.81)(0.1)+0.729=0.243+0.729=0.972$。一致。

> **校验对照**：解析值 $0.972$ = 正文校验值 ✓；题 7 的蒙特卡洛模拟给出 $0.9718$，吻合到小数点后 2 位 ✓。

## 题 5（计算推导｜对应 1.3.1 条件概率、1.3.2 全概率公式）

> 5 扇门后 1 车随机分布，你选门 1，主持人（知道答案）从其余门中打开 2 扇有羊的门。你随机换到剩下两扇未开之门之一，求中奖概率。（校验值：2/5）

**路线**：按"车是否在你最初选的门后"这个划分用全概率公式。设 $C_1$=车在门 1，$W$=换门后中奖。

**块 1**：$P(C_1)=\frac15$。此时其余 4 门全是羊，主持人任开 2 扇羊门，剩下的 2 扇未开门也全是羊，你换到哪扇都不中奖：$P(W\mid C_1)=0$。

**块 2**：$P(C_1^c)=\frac45$。车在门 2–5 之一。主持人从其余 4 扇（3 羊 1 车）中开 2 扇**羊门**——他的信息保证车不被打开，于是剩下的 2 扇未开门中**恰有一扇是车**。你均匀随机换一扇：$P(W\mid C_1^c)=\frac12$。

全概率公式：

$$P(W)=P(C_1)\cdot0+P(C_1^c)\cdot\tfrac12=\tfrac45\times\tfrac12=\boxed{\tfrac25}.$$

**对照标准 Monty Hall（3 门）**：那里换门中奖 $\frac23=\frac23\times1$（因为"其余门"里只剩 1 扇未开，换门必中其中唯一的车，条件概率为 1）。本变体里未开门有 2 扇，"主持人信息"只能保证车在其中，不能替你锁定，所以要打对折。规律：**换门中奖概率 = P(车不在初始门) × 1/(剩余未开门数)**。

> **校验对照**：$\frac45\times\frac12=\frac25$ = 正文校验值 ✓。

## 题 6（计算推导｜对应 1.3.2 全概率公式、1.3.3 贝叶斯公式）

> $P(A)=0.6$，$P(B\mid A)=0.5$，$P(B\mid A^c)=0.2$。求 $P(B)$、$P(A\mid B)$、$P(A\mid B^c)$。（校验值：0.38；约 0.789；约 0.484）

**(1) 全概率公式**：

$$P(B)=P(B\mid A)P(A)+P(B\mid A^c)P(A^c)=0.5\times0.6+0.2\times0.4=0.30+0.08=0.38.$$

**(2) 贝叶斯公式**：

$$P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B)}=\frac{0.30}{0.38}=\frac{15}{19}\approx0.7895.$$

**(3) 先求 $P(A\cap B^c)$**（用加法公式 $P(AB^c)=P(A)-P(AB)=0.6-0.3=0.3$），再除以 $P(B^c)=1-0.38=0.62$：

$$P(A\mid B^c)=\frac{P(A\cap B^c)}{P(B^c)}=\frac{0.3}{0.62}=\frac{15}{31}\approx0.4839.$$

语义检查：$B$ 的发生把 $A$ 的概率从 0.6 拉高到 0.789（因为 $P(B\mid A)>P(B\mid A^c)$）；$B^c$ 的发生把它压低到 0.484。两个方向自洽。

> **校验对照**：$0.38$；$0.789$；$0.484$ —— 与正文校验值全部一致 ✓。

## 题 7（编程实现｜对应 1.3 节、1.6 案例 2 的模拟方法）

> 用蒙特卡洛模拟验证题 4 与题 6 的解析结果：各生成 $10^6$ 组样本，比较频率与解析值（应吻合到小数点后 2 位）。

**思路**：题 4 直接对三台引擎的"正常/故障"布尔数组按行求和；题 6 用"分层采样"：先采 $A$，再按 $A$ 的真假从各自条件分布采 $B$——这正是乘法公式 $P(AB)=P(A)P(B\mid A)$ 的采样版。

```python
import numpy as np

rng = np.random.default_rng(42)
n = 1_000_000

# ---------- 题 4: 三个引擎, 每个 0.9 概率独立正常, 至少两个正常才能飞行 ----------
work = rng.random((n, 3)) < 0.9           # 每行是一个"实验": 三台引擎是否正常
k = work.sum(axis=1)                      # 正常引擎数
freq_4 = (k >= 2).mean()
print(f"题4  模拟 P(飞行) = {freq_4:.4f}   解析 = 0.972")

# ---------- 题 6: P(A)=0.6, P(B|A)=0.5, P(B|A^c)=0.2 ----------
A = rng.random(n) < 0.6                   # 先采 A
B = np.where(A, rng.random(n) < 0.5, rng.random(n) < 0.2)   # 再按条件采 B

P_B   = B.mean()
P_AgB = A[B].mean()                       # P(A | B) = 在 B 发生的样本中 A 的频率
P_AgBc = A[~B].mean()                     # P(A | B^c)
print(f"题6  模拟 P(B)    = {P_B:.4f}     解析 = 0.38")
print(f"题6  模拟 P(A|B)  = {P_AgB:.4f}   解析 ≈ 0.789")
print(f"题6  模拟 P(A|B^c)= {P_AgBc:.4f}  解析 ≈ 0.484")
```

**实际运行输出**（seed=42，$10^6$ 样本）：

```
题4  模拟 P(飞行) = 0.9718   解析 = 0.972
题6  模拟 P(B)    = 0.3799     解析 = 0.38
题6  模拟 P(A|B)  = 0.7892   解析 ≈ 0.789
题6  模拟 P(A|B^c)= 0.4842  解析 ≈ 0.484
```

四项频率与解析值全部吻合到小数点后 2 位 ✓。注意 $P(A\mid B)$ 的实现：**先按事件 $B$ 过滤样本，再在其中数 $A$ 的占比**——条件概率"缩样本空间"的直译。

## 题 8（编程实现｜对应 1.3.3 贝叶斯公式）

> 画 $P(A\mid B)$ 随先验 $P(A)$ 从 0 到 1 变化的曲线，标注 $P(A\mid B)=P(A)$ 的对角线与交点。

**先做一步解析分析（本题的"坑"）**：记先验为 $a$，后验

$$P(A\mid B)=\frac{0.5a}{0.5a+0.2(1-a)}.$$

与对角线 $P(A\mid B)=a$ 联立：对 $a>0$，$0.5a=a\,[0.5a+0.2(1-a)]=a(0.3a+0.2)$，约去 $a$ 得 $0.3a+0.2=0.5\Rightarrow a=1$。加上 $a=0$ 的平凡解，**交点只有两个端点**。原因：似然比 $\frac{P(B\mid A)}{P(B\mid A^c)}=\frac{0.5}{0.2}=2.5\ne1$——证据 $B$ 在 $A$ 下比在 $A^c$ 下"更容易出现"，所以对一切内部先验，$B$ 都把 $P(A)$ 往上拉；只有似然比 $=1$ 时曲线才与对角线在中间相交（那时证据无信息量）。

```python
import numpy as np
import matplotlib.pyplot as plt

# P(A|B) = 0.5a / (0.5a + 0.2(1-a)), a = P(A)
a = np.linspace(0, 1, 500)
post = 0.5 * a / (0.5 * a + 0.2 * (1 - a))

# 解析交点: 似然比 = 0.5/0.2 = 2.5 != 1, 曲线仅在 a=0 与 a=1 与对角线相交
print("曲线与对角线的交点: a=0 与 a=1 (似然比 2.5 != 1, 中间无平衡点)")
print(f"检查 a=0.6: P(A|B) = {0.5*0.6/(0.5*0.6+0.2*0.4):.4f} > 0.6")

plt.figure(figsize=(5, 4))
plt.plot(a, post, label="P(A|B) vs P(A)")
plt.plot(a, a, "k--", lw=1, label="diagonal")
plt.xlabel("prior P(A)"); plt.ylabel("posterior P(A|B)")
plt.legend(); plt.tight_layout()
plt.savefig("ch1_q8_bayes_curve.png", dpi=120)
print("saved ch1_q8_bayes_curve.png")
```

**实际运行输出**：

```
曲线与对角线的交点: a=0 与 a=1 (似然比 2.5 != 1, 中间无平衡点)
检查 a=0.6: P(A|B) = 0.7895 > 0.6
```

图形：后验曲线整段位于对角线上方，两端相触。若把数据换成 $P(B\mid A)=0.5,P(B\mid A^c)=0.5$（似然比 1），曲线与对角线完全重合——"证据无信息"的可视化。

## 题 9（开放思考｜对应 1.4.1 i.i.d. 的含义、1.8 节）

> 推荐系统估计"用户点击广告的概率"，举两个使 i.i.d. 失效的因素并说明失效方向。

**参考答案**（举两个即可，方向要答对）：

1. **同一用户的多次曝光相关**（用户今天点了，明天更可能再点；同一会话内兴趣连续）。逐条曝光当独立样本，实际有效信息量小于 $n$（对照第 3 章误区 5：正相关样本使 $\mathrm{Var}(\bar X)>\sigma^2/n$）。失效方向：**点估计尚可，但系统性低估点击率的不确定性 / 高估置信度**——置信区间过窄，A/B 判断容易翻车。
2. **曝光分配不随机（位置/时段/人群混杂）**：广告位靠前、活跃时段、特定人群被更频繁曝光，且这些因素同时影响点击率。样本不再是同分布（ mixture 分布被当成单一分布）。失效方向：估出的"平均点击率"是被曝光策略加权的混合量，对"目标人群自然点击率"这个真参数**有偏**；而且分群间方差被并入"样本内方差"时同样高估置信度。若把混杂方向反过来用（高点击人群被过度曝光后撤掉曝光），甚至会出现点击率估计的剧烈漂移。
3. （可再加）**新奇效应/广告疲劳**：时间趋势使分布缓慢漂移，旧样本与最新环境不同分布——用全历史平均会**滞后于真实点击率**。

方法论收尾：i.i.d. 是假设不是事实（第 1 章误区 4）；失效的通用对策是分层/加权（按用户聚簇评估）、按时间留出验证集。

## 题 10（开放思考｜对应 1.6 案例 1 基率谬误）

> 写一篇 300 字短文：从先验角度论证"检测策略与检测器必须联合设计"。

**参考范文（约 300 字）**：

同一个检测器，先验不同，价值天差地别。设灵敏度为 0.99、误报率 0.05 的检测器：在患病率 0.1% 的全员筛查中，阳性预测值只有约 2%——每 100 个阳性约 98 个是假阳性，追踪这些人产生的成本与焦虑可能远超过找到的真患者；而在患病率 20% 的高危人群中做同样的检测，阳性预测值升到约 83%，几乎每个阳性都值得干预。决定检测器价值的不是它自身，而是它被投放的先验环境。反过来，先验也约束检测器的设计目标：全员筛查追求低误报率（宁漏勿误），高危确诊辅助追求高灵敏度（宁误勿漏），两个场景的最优工作点（阈值）相反。因此"检测策略与检测器必须联合设计"：先由筛查策略确定目标人群与先验，再据此选择检测器灵敏度-特异度的折中；脱离先验单独宣传"准确率 99%"，正是第 1 章案例 1 揭示的基率谬误。

**给分要点**：① 用贝叶斯/全概率给出两个场景的 PPV 对比（2% vs 83%，计算见下）；② 指出阈值/工作点应随先验调整；③ 落到"联合设计"的结论。

数值备查：全员 $P(D\mid+)=\frac{0.99\times0.001}{0.99\times0.001+0.05\times0.999}\approx0.0194$；高危 $P(D)=0.2$ 时 $P(D\mid+)=\frac{0.198}{0.198+0.04}=\frac{0.198}{0.238}\approx0.832$。

## 题 11（挑战题｜对应 1.2.2 公理与性质 6；为第 3 章大数定律做准备）

> 证明从下连续性：$A_1\subseteq A_2\subseteq\cdots \Rightarrow P\left(\bigcup_n A_n\right)=\lim_{n\to\infty}P(A_n)$。

**证明**（按提示的分块法，一步不跳）：

**第一步：构造互斥块。** 约定 $A_0=\varnothing$，令 $B_n=A_n\setminus A_{n-1}$（$n\ge1$）。由于事件列递增，$B_1,\dots,B_n$ 两两互斥（$B_m\subseteq A_{m-1}$ 与 $B_n\subseteq A_n\setminus A_{n-1}$ 当 $m<n$ 时不相交，因为 $m\le n-1$）。由有限可加性（公理 3 的有限推论）：

$$P(A_n)=P\left(\bigcup_{k=1}^n B_k\right)=\sum_{k=1}^n P(B_k).$$

**第二步：并集的无缝覆盖。** 任意 $\omega\in\bigcup_n A_n$ 落在某个 $A_m$ 中；取最小的这样的 $m$（非空自然数集有最小元），则 $\omega\in B_m$。反之每 $B_k\subseteq A_k\subseteq\bigcup_n A_n$。故

$$\bigcup_{n=1}^\infty A_n=\bigcup_{k=1}^\infty B_k\qquad(\text{右端为互斥并}).$$

**第三步：用可数可加性 + 级数部分和。** 由公理 3，

$$P\left(\bigcup_{n}A_n\right)=\sum_{k=1}^\infty P(B_k)=\lim_{n\to\infty}\sum_{k=1}^n P(B_k)=\lim_{n\to\infty}P(A_n).\qquad\blacksquare$$

**如何使用**：第 3 章证明 Borel–Cantelli 引理（进而强大数定律）时，"对递增/递减事件列交换极限与 $P$"全部走这条路；对偶的从上连续性（$A_n\downarrow A$，要求 $P(A_1)<\infty$）对 $A_n^c$ 用本结论即得。

**(b)** $F(x)=\int_0^x 3t^2dt=x^3$（$0\le x\le1$；$x<0$ 为 0，$x>1$ 为 1）。

$$\mathbb{E}[X]=\int_0^1 x\cdot3x^2dx=3\int_0^1x^3dx=\frac34.$$

## 题 2（概念辨析｜对应 2.4.3 泊松分布）

> "$X$ 越偏离 $\lambda$ 越罕见"对吗？计算 $\lambda=10$ 时的 $P(X=\lambda)$ 与 $P(X=0)$。

**标准答案要点**：**大方向对，但不严格**。

先计算。$\lambda=10$：

$$P(X=10)=e^{-10}\frac{10^{10}}{10!}.$$

逐步：$e^{-10}\approx4.53999\times10^{-5}$；$10^{10}/10!=10^{10}/3628800\approx2755.73$；乘积 $\approx0.12511$。

$$P(X=0)=e^{-10}\approx4.5400\times10^{-5}.$$

所以 $P(X=10)\approx0.125$、$P(X=0)\approx4.5\times10^{-5}$，与正文校验值一致。

三点辨析：
1. **众数不唯一**：由相邻比值 $\frac{P(X=k+1)}{P(X=k)}=\frac{\lambda}{k+1}$ 可知 PMF 在 $k<\lambda-1$ 时上升、$k>\lambda$ 时下降；$\lambda$ 为整数时 $k=\lambda$ 与 $k=\lambda-1$ **并列众数**（本例 $P(X=9)=P(X=10)$）。所以"以 $\lambda$ 为唯一中心"的说法要修正。
2. **不是单调对称地衰减**：泊松右偏，右侧尾部比左侧"厚"，$P(X=15)$ 与 $P(X=5)$ 并不同（$0.0347$ vs $0.0378$ 量级的差别可自行验证）——"越偏离越罕见"只是粗糙近似。
3. **离散中心的"概率不高"**：即便在均值点，单点概率也只有 0.125；对连续分布对应的问题（$P(X=\mu)$）答案干脆是 0——"中心"是密度的峰、不是质量的堆。

**常见错误**：把"期望 = 最可能值"当成泊松的严格性质；忽略众数并列的情形。

## 题 3（概念辨析｜对应 2.5.2、2.7 案例 3）

> 为什么高斯没有"逆变换法"？Box–Muller 如何绕开？

**标准答案要点**：

1. 逆变换法需要 $X=F^{-1}(U)$ 中的 $F^{-1}$ **可显式计算**。标准正态的 CDF $\Phi(x)=\int_{-\infty}^x\varphi(t)dt$ 没有初等闭式（其反函数 $\Phi^{-1}$ 只能数值求解，如 erf 的有理逼近）。理论上 $\Phi^{-1}(U)$ 确实服从 $\mathcal{N}(0,1)$（概率积分变换的逆，第 2 章练习 2.11 与第 6 章定理 6.1），但"能定义"不等于"能便宜地计算"。
2. **Box–Muller 的绕行方式**：把问题升到二维。若 $Z_0,Z_1$ 独立标准正态，则 $R^2=Z_0^2+Z_1^2\sim\chi^2_2=\text{Exp}(1/2)$、$\Theta\sim U(0,2\pi)$ 且二者独立（高斯的旋转对称性）。这两个"径向/角向"分布都**可以**逆变换采样：$R=\sqrt{-2\ln U_1}$（指数分布的逆变换），$\Theta=2\pi U_2$。最后变换回直角坐标：

$$Z_0=\sqrt{-2\ln U_1}\cos(2\pi U_2),\qquad Z_1=\sqrt{-2\ln U_1}\sin(2\pi U_2).$$

核心思想：**一维上无解的 CDF 反演，借"联合分布的可逆二维变换（雅可比公式，2.5.2）"绕开**。这也是 normalizing flows 的雏形——好变换比好反解更重要。

**常见错误**：说"高斯 CDF 不可逆"——不严格，$\Phi$ 严格增故可逆，只是反函数无初等表达式。

## 题 4（计算推导｜对应 2.4.6 无记忆性、2.4.5 高斯）

> 证明指数分布无记忆性；证明高斯不具有无记忆性（$\mu=0,\sigma=1$，比较 $P(X>2\mid X>1)$ 与 $P(X>1)$）。

**指数分布（$X\sim\text{Exp}(\lambda)$，密度 $\lambda e^{-\lambda x}$，$x\ge0$）**：先用积分求生存函数

$$P(X>s)=\int_s^\infty\lambda e^{-\lambda x}dx=\left[-e^{-\lambda x}\right]_s^\infty=e^{-\lambda s}.$$

于是条件概率（$s,t\ge0$）：

$$P(X>s+t\mid X>s)=\frac{P(X>s+t)}{P(X>s)}=\frac{e^{-\lambda(s+t)}}{e^{-\lambda s}}=e^{-\lambda t}=P(X>t).\qquad\blacksquare$$

即"已等待 $s$ 秒"这条信息不改变剩余等待时间的分布——无记忆性。它是唯一具有该性质的连续分布。

**高斯反例（数值）**：$X\sim\mathcal N(0,1)$，记 $\Phi$ 为标准正态 CDF：

- $P(X>1)=1-\Phi(1)=1-0.841345=0.158655\approx0.159$；
- $P(X>2\mid X>1)=\dfrac{1-\Phi(2)}{1-\Phi(1)}=\dfrac{0.0227501}{0.1586552}=0.143434\approx0.144$.

两者不相等（$0.144\ne0.159$）：知道"已活过 1"之后，再活过 1（即超过 2）的概率**变小**了——高斯尾部比指数衰减更快，"高龄"本身是坏消息。故高斯无记忆性不成立。$\blacksquare$

> **校验对照**：$0.144$ 与 $0.159$ —— 与正文校验值一致 ✓。

## 题 5（计算推导｜对应 2.5.2 CDF 法，非单调变换）

> $X\sim U(-1,1)$，求 $Y=X^2$ 的 PDF。

$X$ 的密度 $f_X(x)=\frac12$（$-1\le x\le1$）。$Y=X^2\in[0,1]$，且 $g(x)=x^2$ **不是单调变换**（$x=\pm\sqrt y$ 两支映到同一 $y$），用 CDF 法最稳：

$$F_Y(y)=P(X^2\le y)=P(-\sqrt y\le X\le\sqrt y)=\int_{-\sqrt y}^{\sqrt y}\frac12dx=\frac12\cdot2\sqrt y=\sqrt y,\qquad 0<y\le1.$$

（即把两支的贡献**相加**：每支各贡献 $\frac12\sqrt y$。）求导：

$$f_Y(y)=F_Y'(y)=\frac{1}{2\sqrt y},\qquad 0<y\le1.$$

边界说明：$y\downarrow0$ 时 $f_Y\to\infty$（两支密度在 $x=0$ 处叠聚），但 $\int_0^1\frac{dy}{2\sqrt y}=\left[\sqrt y\right]_0^1=1$ 归一化成立——密度发散与概率为 1 并不矛盾。这正是正文 2.7 案例 2 中"跳过 $y\to0$ 奇异分箱"的原因。

> **校验对照**：$f_Y(y)=\frac{1}{2\sqrt y}$（$0<y\le1$）—— 与正文校验值一致 ✓。注意雅可比法也能做：每支贡献 $f_X(\pm\sqrt y)\cdot\frac{1}{2\sqrt y}=\frac{1}{4\sqrt y}$，两支相加得 $\frac{1}{2\sqrt y}$。

## 题 6（计算推导｜对应 2.4.2 二项分布、2.3 期望方差性质）

> 推导 $\text{Bin}(n,p)$ 的期望与方差：期望用示性变量分解，方差用独立性。

**分解**：$X=\sum_{i=1}^n X_i$，$X_i$ 为第 $i$ 次试验的示性变量（成功取 1），$X_i\stackrel{iid}{\sim}\text{Bern}(p)$。

**期望（只需线性性，无需独立）**：$\mathbb{E}[X_i]=p$，故

$$\mathbb{E}[X]=\mathbb{E}\Big[\sum_i X_i\Big]=\sum_i\mathbb{E}[X_i]=np.$$

**方差（需独立性）**：先算单项，$\mathbb{E}[X_i^2]=0^2(1-p)+1^2p=p$，故

$$\mathrm{Var}(X_i)=\mathbb{E}[X_i^2]-(\mathbb{E}X_i)^2=p-p^2=p(1-p).$$

独立时协方差全为零，方差可加：

$$\mathrm{Var}(X)=\mathrm{Var}\Big(\sum_i X_i\Big)=\sum_i\mathrm{Var}(X_i)+\sum_{i\ne j}\mathrm{Cov}(X_i,X_j)=np(1-p).$$

**独立性的用武之地**（说理）：$X_i$ 只取 0/1，故 $X_iX_j=X_i\cap X_j$ 的示性；独立性给出 $\mathbb{E}[X_iX_j]=p^2=\mathbb{E}X_i\mathbb{E}X_j$，协方差逐项为 0。若试验不独立（如无放回抽样），此项不为零，方差修正为有限总体公式——这正是"独立"假设换来的简化。

> **校验对照**：$np$；$np(1-p)$ —— 与正文校验值一致 ✓。

## 题 10（开放思考｜对应 2.4 分布选择、第 4 章 Beta 预告）

> 为"视频完播率"（$0\sim1$ 比例）建模，为什么伯努利/二项/高斯都不好？说明 Beta 为何合适（200 字）。

**参考答案（要点 + 范文）**：

- **伯努利/二项**建模特定的 0/1 事件或 $n$ 次试验的成功**计数**；完播率是一个连续比例参数，观测一次只得到一个 $[0,1]$ 内的数，没有"试验次数"结构，硬套二项要虚构 $n$。
- **高斯**支撑集是全实轴，会给出 $<0$ 或 $>1$ 的"完播率"；且边界附近对称钟形失真。
- **Beta 分布**支撑集恰为 $[0,1]$，密度 $p(\theta)\propto\theta^{\alpha-1}(1-\theta)^{\beta-1}$：$\alpha,\beta<1$ 时两端堆积（U 形，适合"要么看不完要么看完"的两极行为），$\alpha,\beta>1$ 时单峰内聚，$\alpha=\beta=1$ 退化为均匀；均值 $\frac{\alpha}{\alpha+\beta}$、集中度 $\alpha+\beta$ 分开控制位置与信心。加之它是二项似然的共轭先验（第 4 章 4.2.2），后验仍是 Beta、可以逐条在线更新，并自然导出拉普拉斯平滑式伪计数。故"比例的分布"应首选 Beta。

## 题 11（挑战题｜对应 2.5.2、6.2.1 的理论核心）

> 证明概率积分变换：若 $X$ 有连续严格增的 CDF $F$，则 $Y=F(X)\sim U(0,1)$。

**证明**：对 $y\in(0,1)$：

$$P(Y\le y)=P(F(X)\le y).$$

因 $F$ 连续严格增，其反函数 $F^{-1}:(0,1)\to\mathbb{R}$ 存在且严格增，故事件等价转化（严格增性保证 $\{F(X)\le y\}=\{X\le F^{-1}(y)\}$）：

$$P(F(X)\le y)=P\big(X\le F^{-1}(y)\big)=F\big(F^{-1}(y)\big)=y.$$

于是 $Y$ 的 CDF 在 $(0,1)$ 上恒等于 $y$，端点处 $F(Y)\in(0,1)$ 几乎必然（$F$ 严格增保证 $F(X)$ 不落在 0/1 上），故 $Y\sim U(0,1)$。$\blacksquare$

**两个层次的延伸**：

1. **去严格化**（深入方向）：$F$ 只连续不严格增时，把逆定义为 $F^{-1}(y)=\inf\{x:F(x)\ge y\}$，结论仍成立——这是第 6 章逆变换法实际使用的版本（离散/混合分布需要它）。
2. **校准的桥梁**：若模型对样本 $x_i$ 给出的预测概率 $p_i$ 校准良好（$p_i$ 等于真实条件概率），则把 $p_i$ 代入真实条件 CDF 后应"均匀化"——这就是概率校准检验（reliability diagram / calibration test）的理论依据：预测概率的变换值偏离均匀 ⇒ 校准有偏。

**常见错误**：直接写 $P(F(X)\le y)=F(F^{-1}(y))=y$ 却不说明事件等价性——严格增性（或广义逆的定义）正是这一步的合法性来源，必须点明。

# 第 3 章 多元分布与矩（对应 3.13 节，共 11 题）

## 题 1（概念辨析｜对应 3.2.1 相关系数、"不相关 ≠ 独立"）

> $X\sim U(-1,1)$，$Y=X^2$。求 $\mathrm{Cov}(X,Y)$ 并判断独立性与相关性。

**计算 $\mathrm{Cov}$**：$\mathrm{Cov}(X,Y)=\mathbb{E}[XY]-\mathbb{E}[X]\mathbb{E}[Y]$。$X$ 的密度关于 0 对称，故 $\mathbb{E}[X]=0$；$\mathbb{E}[X^3]=\int_{-1}^1x^3\cdot\frac12dx=0$（奇函数）；$XY=X^3$，所以

$$\mathrm{Cov}(X,Y)=\mathbb{E}[X^3]-0\cdot\mathbb{E}[Y]=0.$$

**独立性判断（不独立）**：$\mathrm{Cov}=0$ 只排除线性依赖，改用事件检验。取 $A=\{X>3/4\}$，$B=\{Y\le1/4\}=\{|X|\le1/2\}$：

$$P(A)=\frac18,\qquad P(B)=\frac12,\qquad P(AB)=0\ \ (X>3/4\Rightarrow Y>9/16>1/4).$$

$P(AB)=0\ne\frac18\times\frac12=\frac1{16}$，故不独立。事实上 $Y$ 由 $X$ 完全决定，是最强的依赖，只是这种依赖（$Y=X^2$）不沿任何直线方向，被只看"线性"的相关系数完全漏掉。

> **校验对照**：$\mathrm{Cov}=0$、不独立 —— 与正文校验值一致 ✓。"不相关但强依赖"成立。

**常见错误**：由 $\mathrm{Cov}=0$ 直接得出"独立"——这正是 3.9 节误区 1。特例记忆：多元高斯中二者等价，一般分布不等价。

## 题 2（概念辨析｜对应 3.9 误区 2 "边缘分布决定不了联合分布"）

> 边缘均为标准正态，能否断定二元正态？用反例说明并画散点图验证。

**标准答案**：不能。反例（正文 3.9 误区 2）：设 $X\sim\mathcal N(0,1)$，$S$ 与 $X$ 独立、以各 $\frac12$ 概率取 $\pm1$，令 $Y=SX$。

- **边缘**：$Y=SX$，在 $S=1$ 与 $S=-1$ 两分支下 $Y$ 分别为 $\mathcal N(0,1)$ 与 $-\mathcal N(0,1)=\mathcal N(0,1)$（高斯对称），混合后仍 $\mathcal N(0,1)$。$X$ 边缘当然也是 $\mathcal N(0,1)$。
- **联合**：样本全部落在直线 $y=x$ 与 $y=-x$ 的并上——任何真正的二元正态（除非退化）的支撑必须是全平面、等高线为椭圆。且 $\mathrm{Cov}(X,Y)=\mathbb{E}[SX^2]=\mathbb{E}[S]\mathbb{E}[X^2]=0$：不相关却强依赖（$|X|=|Y|$ 恒成立）。

验证代码（核心部分）：

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)
x = rng.standard_normal(5000)
s = rng.choice([-1.0, 1.0], size=5000)     # 与 x 独立的随机符号
y = s * x
# 1) 边缘正态性: 偏度/峰度近似 0/3, KS 检验 p 值不拒绝正态
from scipy import stats
print(stats.normaltest(y))                  # 两个边缘都"通过"正态检验
# 2) 但联合集中在两条对角线: |Y| = |X| 恒成立
print(np.allclose(np.abs(y), np.abs(x)))    # True
plt.scatter(x[::5], y[::5], s=3, alpha=0.3); plt.savefig("ch3_q2_counterex.png")
```

散点图呈"X 形"两条对角线，与任何椭圆等高线的二元正态截然不同。**含义**：VAE/扩散模型中"每维边缘像高斯"绝不等于联合建模正确——边缘直方图是诊断的起点而不是终点。

## 题 3（概念辨析｜对应 3.1.4 全方差公式）

> 用全方差公式解释：为什么"班级内方差"与"班级均值方差"都无法单独还原总方差。

**标准答案**：全方差公式 $\mathrm{Var}(Y)=\mathbb{E}[\mathrm{Var}(Y\mid X)]+\mathrm{Var}(\mathbb{E}[Y\mid X])$，取 $Y$=学生成绩、$X$=班级：总方差 = **组内平均方差** + **组间方差（班级均值方差）**，两项**相加**才是总方差。

数值小例：全校两个班等规模，班 1 成绩 $\sim\mathcal N(70,10^2)$，班 2 $\sim\mathcal N(90,10^2)$。则

- 组内平均方差 $\mathbb{E}[\mathrm{Var}(Y\mid X)]=100$；
- 组间方差 $\mathrm{Var}(\mathbb{E}[Y\mid X])=\mathrm{Var}(\{70,90\})=10^2=100$；
- 总方差 $=100+100=200$。

只报班内方差（100）或只报班间方差（100）都只有总方差的一半；两者大小还可以任意配比（把班均值拉远→组间主导；班内散布加大→组内主导）。**应用直觉**：bagging 的方差分解（成员平均消除组内方差、成员差异贡献组间方差）、混合模型的过离散（正文 3.1.4）都是这个加法的化身。

**常见错误**：以为"组间方差 ⊆ 总方差"可以相减得到另一项——若不知道两块的相对大小，任何一块单独都还原不了总数；公式说的是"和"，不是"包含"。

## 题 4（计算推导｜对应 3.1.1–3.1.4）

> $(X,Y)$ 联合密度 $f(x,y)=2e^{-(x+2y)}$（$x,y>0$）。求边缘、判断独立、求 $\mathbb{E}[Y\mid X=x]$。

**第一步（归一化检查）**：$\int_0^\infty\!\!\int_0^\infty 2e^{-x}e^{-2y}dxdy=2\cdot1\cdot\frac12=1$ ✓。

**第二步（边缘化）**：把 $y$ 积掉（对 $y$ 的积分恰是 $\text{Exp}(2)$ 归一化积分）：

$$f_X(x)=\int_0^\infty 2e^{-x}e^{-2y}dy=2e^{-x}\cdot\left[-\tfrac12e^{-2y}\right]_0^\infty=2e^{-x}\cdot\tfrac12=e^{-x},\quad x>0.$$

同理把 $x$ 积掉（$\int_0^\infty e^{-x}dx=1$）：

$$f_Y(y)=\int_0^\infty 2e^{-x}e^{-2y}dx=2e^{-2y},\quad y>0\qquad(\text{即 } Y\sim\text{Exp}(2)).$$

**第三步（独立性）**：对 $x,y>0$，

$$f(x,y)=2e^{-x}e^{-2y}=e^{-x}\cdot 2e^{-2y}=f_X(x)f_Y(y),$$

因子分解成立（支撑集为矩形也满足），故 $X\perp Y$。

**第四步（条件期望）**：独立性使条件分布等于边缘分布：

$$f(y\mid x)=\frac{f(x,y)}{f_X(x)}=f_Y(y)\ \Rightarrow\ \mathbb{E}[Y\mid X=x]=\mathbb{E}[Y]=\frac1{\lambda_Y}=\frac12.$$

> **校验对照**：独立；$f_X=e^{-x}$；$E[Y\mid X=x]=1/2$ —— 与正文校验值一致 ✓。

## 题 5（计算推导｜对应 3.4.2 MGF 求矩）

> 对 $X\sim\mathcal N(\mu,\sigma^2)$ 用 MGF 求 $\mathbb{E}[X^3]$。

高斯的 MGF（正文 3.4.2 配方得到）：

$$M(t)=\exp\!\Big(\mu t+\tfrac12\sigma^2t^2\Big).$$

逐阶求导（每一步都写出依据）：

1. 一阶：$M'(t)=(\mu+\sigma^2t)\,M(t)$（链式法则，指数的导数是 $\mu+\sigma^2t$）。
2. 二阶（乘积法则）：$M''(t)=\sigma^2M(t)+(\mu+\sigma^2t)^2M(t)=\big[\sigma^2+(\mu+\sigma^2t)^2\big]M(t)$。
3. 三阶（乘积法则，记 $u=\mu+\sigma^2t$）：
$$M'''(t)=\big[2\sigma^2u\big]M(t)+\big[\sigma^2+u^2\big]\,u\,M(t)=\big[2\sigma^2u+u^3+\sigma^2u\big]M(t)=\big[u^3+3\sigma^2u\big]M(t).$$

在 $t=0$ 处 $u=\mu$、$M(0)=1$：

$$\mathbb{E}[X^3]=M'''(0)=\mu^3+3\mu\sigma^2.$$

> **校验对照**：$\mu^3+3\mu\sigma^2$ —— 与正文校验值一致 ✓。（自检：$\mu=0$ 时 $\mathbb{E}[X^3]=0$，对称分布奇数阶中心矩为零 ✓；$\sigma\to0$ 时退化为 $\mu^3$ ✓。）

## 题 6（计算推导｜对应 3.6.2 LLN 证明的前置工具）

> 证明 Chebyshev 不等式：$P(|X-\mu|\ge\varepsilon)\le\mathrm{Var}(X)/\varepsilon^2$。

**第一步（Markov 不等式）**：对 $g\ge0$ 与 $a>0$，由示性函数的逐点不等式 $\mathbb{1}\{g(X)\ge a\}\le g(X)/a$（左边在事件上取 1、其余取 0，右边在事件上 $\ge1$、其余 $\ge0$），两边取期望：

$$P(g(X)\ge a)=\mathbb{E}\big[\mathbb{1}\{g(X)\ge a\}\big]\le\frac{\mathbb{E}[g(X)]}{a}.$$

**第二步（代入）**：取 $g(X)=(X-\mu)^2$（非负），$a=\varepsilon^2$：

$$P\big(|X-\mu|\ge\varepsilon\big)=P\big((X-\mu)^2\ge\varepsilon^2\big)\le\frac{\mathbb{E}\big[(X-\mu)^2\big]}{\varepsilon^2}=\frac{\mathrm{Var}(X)}{\varepsilon^2}.\qquad\blacksquare$$

**用途定位**：它不需要任何分布假设（只要二阶矩存在），因此是"最便宜的界"——代价是松弛。把它用于样本均值即得弱大数定律：$P(|\bar X_n-\mu|>\varepsilon)\le\frac{\sigma^2}{n\varepsilon^2}\to0$（正文 3.6.2 的一行证明）。进阶方向：指数型的 Chernoff 界用 MGF 替换二阶矩，可把界收紧若干个数量级。

## 题 10（开放思考｜对应 3.6.3 CLT 条件、3.9 误区 3）

> "梯度噪声近似高斯"何时合理、何时失效？如何支持"学习率大时用梯度裁剪"？（200 字）

**参考答案**：mini-batch 梯度 $g_B=\frac1m\sum_{i\in B}g_i$ 是 $m$ 个逐样本梯度的平均，若各 $g_i$ 近独立、方差有限，CLT 给出 $g_B\approx\nabla L+\mathcal N(0,\Sigma/m)$——**batch 大、步数多（收敛轨迹充分采样噪声）时近似合理**，且方差随 $1/m$ 缩小。**失效**：逐样本梯度重尾（个别困难样本/损失尖峰方差极大甚至无界，CLT 的 $\sigma^2<\infty$ 条件被破坏，极限进入稳定律吸引域）；样本相关（数据流重复）；学习率大时，参数一步内移动过远，"噪声围绕固定 $\nabla L$ 波动"的局部化假设失效，非线性被放大。梯度裁剪正是对"单步噪声远超高斯假设的典型幅度"的防御：把重尾样本造成的异常大梯度截断，使更新量回到 CLT 可描述的范围——统计失效模式（重尾）直接翻译成工程实践。

## 题 11（挑战题｜对应 3.6.3 CLT 的 MGF 证明）

> 用 MGF 完成 CLT 的完整证明骨架。

**设定简化**：不妨设 $\mathbb{E}X=0$、$\mathrm{Var}(X)=1$（一般情形用 $X^*=\frac{X-\mu}{\sigma}$ 归约，标准化和不变）。记 $M(t)=\mathbb{E}[e^{tX}]$，标准化和 $Z_n=\frac1{\sqrt n}\sum_{i=1}^nX_i$。

**第一步（独立和的 MGF 乘法）**：$Z_n$ 的各加项 $\frac{X_i}{\sqrt n}$ 独立，故

$$M_{Z_n}(t)=\prod_{i=1}^n M_X\!\left(\frac{t}{\sqrt n}\right)=\left[M\!\left(\frac{t}{\sqrt n}\right)\right]^n.$$

**第二步（MGF 在 0 处的 Taylor 展开）**：由 $M(0)=1$、$M'(0)=\mathbb{E}X=0$、$M''(0)=\mathbb{E}X^2=1$，二阶展开（带 Peano 余项）：

$$M(s)=1+\frac{s^2}{2}+o(s^2)\qquad(s\to0).$$

**第三步（取极限）**：令 $s=t/\sqrt n$（固定 $t$，$s\to0$）：

$$\ln M_{Z_n}(t)=n\ln\!\Big(1+\frac{t^2}{2n}+o\!\Big(\frac1n\Big)\Big)=n\Big(\frac{t^2}{2n}+o\Big(\frac1n\Big)\Big)\ \xrightarrow[n\to\infty]{}\ \frac{t^2}{2},$$

其中用了 $\ln(1+u)=u+o(u)$（$u\to0$）。故 $M_{Z_n}(t)\to e^{t^2/2}$——恰是 $\mathcal N(0,1)$ 的 MGF。$\blacksquare$

**第四步（所需的额外条件，本题要求说明）**："MGF 逐点收敛 ⇒ 分布收敛"不是无条件成立的，需要 **$M_X(t)$ 在 0 的某个邻域 $|t|\le\delta$ 内一致有限**（保证各阶矩存在且展开一致可控；收敛到连续极限 MGF 后用连续性定理/Fréchet–Shohat 定理升级为依分布收敛）。若 MGF 不存在（如重尾的 Cauchy、幂律尾），整条路线失效，须改用**特征函数**（总是存在）的 Lévy 连续性定理——这是 CLT 完整证明的标准路线，也解释了为什么"方差有限"是 CLT 的本质条件而非技术性假设。

# 第 4 章 贝叶斯推断（对应 4.12 节，共 11 题）

## 题 1（概念辨析｜对应 4.4 节、4.5.2 两派之争、4.8 误区 3）

> 用一句话分别解释"95% 可信区间"与"95% 置信区间"，并说明后者为何不能读成"参数在区间内的概率"。

**可信区间（贝叶斯）**：给定数据 $D$ 与模型，参数 $\theta$ 是随机变量，"$\theta$ 落在该区间内"的概率是 95%——概率命题直接关于**参数**。

**置信区间（频率派）**：区间端点是数据的函数（随机的是区间），若反复抽样并按同一程序构造区间，约 95% 的区间会覆盖真值——概率命题关于**构造程序**的长期频率。

**为什么后者不能读成参数的概率**：频率派把 $\theta$ 当**固定常数**，事件"真值在 $[L(D),U(D)]$ 内"在数据给定后要么真要么假，没有随机性可言；$P_\theta(L(D)\le\theta\le U(D))=0.95$ 中随机的是 $D$（故 $L,U$ 带下标 $D$），把覆盖概率转移到已算出的具体区间上，就犯了把"程序的长期性质"当成"单次陈述的概率"的范畴错误（第 4 章 4.8 误区 3、第 5 章 5.5.1 反复强调）。

## 题 2（计算推导｜对应 4.2.2 先验强度 = 伪计数）

> Beta(5,5) 的标准差是多少？该信念相当于多少样本量的把握？

Beta 方差公式：$\mathrm{Var}(\theta)=\dfrac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$。代入 $\alpha=\beta=5$：

$$\mathrm{Var}=\frac{25}{10^2\times11}=\frac{25}{1100}=0.022727\ \Rightarrow\ \sigma=\sqrt{0.022727}\approx0.1508\approx0.151.$$

**换算样本量**：$\text{Bin}(n,0.5)$ 均值的标准差为 $\frac12\sqrt{1/n}$（$\sqrt{p(1-p)/n}$ 在 $p=0.5$ 处）。令其等于 0.151：

$$\frac{0.5}{\sqrt n}=0.1508\ \Rightarrow\ \sqrt n=\frac{0.5}{0.1508}=3.316\ \Rightarrow\ n\approx11.$$

即 Beta(5,5) 的信念强度 ≈ **10–11 个样本量级**——恰与先验强度 $\alpha+\beta=10$ 一致 ✓（正文校验值：$\sigma\approx0.151$，约 10–11 个样本）。这就是"先验强度以伪计数计"的定量化：$\alpha+\beta$ 就是先验自带的"想象样本量"。

**常见错误**：以为 Beta(5,5) 的 $\sigma=0.151$ 意味着"弱先验"——相对 0.5 的均值，0.151 的标准差是相当强的信念（相当于已看过 ~10 个均匀样本）。

## 题 3（概念辨析｜对应 4.2.1 共轭动机、4.7 案例 3）

> 为什么"共轭先验"对在线学习至关重要？用案例 3 的递推式回答。

**标准答案要点**：贝叶斯更新的瓶颈是分母积分 $p(D)=\int p(D\mid\theta)p(\theta)d\theta$——每来一条新数据都要**重算**整个积分，高维下不可行。共轭把更新变成**参数代换**：Beta–Binomial 下后验仍是 Beta，只需两个计数器

$$a\leftarrow a+x,\qquad b\leftarrow b+(1-x),$$

每步 $O(1)$ 时间、$O(1)$ 内存（只存 $a,b$ 两个数），且**后验即新先验**——"当前信念"被完美压缩成两个统计量，历史数据可以丢弃。正文 4.7 案例 3 用这递推在 300 条数据流上在线画出后验均值轨迹；Thompson 采样（强化学习）正是"从当前后验采样 → 行动 → 递推更新"的循环，没有共轭就没有这种每步微秒级的流式学习。非共轭模型（神经网络似然）只能退到 MCMC/变分（第 6 章），更新代价高数个量级。

## 题 4（计算推导｜对应 4.3 正态均值的共轭后验）

> 完整推导正态均值后验（$\sigma^2$ 已知，先验 $\mathcal N(\mu_0,\tau_0^2)$），每步写明代数依据。

**第一步（写比例式）**：i.i.d. 数据的联合似然按条件独立分解，与先验相乘：

$$p(\theta\mid D)\propto p(D\mid\theta)\,p(\theta)=\prod_{i=1}^n\frac{1}{\sqrt{2\pi}\sigma}\exp\!\Big(-\frac{(x_i-\theta)^2}{2\sigma^2}\Big)\cdot\frac{1}{\sqrt{2\pi}\tau_0}\exp\!\Big(-\frac{(\theta-\mu_0)^2}{2\tau_0^2}\Big).$$

与 $\theta$ 无关的因子（$\frac{1}{\sqrt{2\pi}\sigma}$ 等）可丢——它们不改变关于 $\theta$ 的形状（依据：比例式的定义）。

**第二步（展开二次项）**：对 $n$ 个数据项的指数和，用平方分解（依据：$\sum_i(x_i-\theta)^2=\sum_i(x_i-\bar x)^2+n(\bar x-\theta)^2$，交叉项 $\sum_i(x_i-\bar x)(\bar x-\theta)=0$ 消失）：

$$-\frac{1}{2\sigma^2}\sum_i(x_i-\theta)^2=-\frac{n}{2\sigma^2}(\theta-\bar x)^2+C_1
=-\frac{n}{2\sigma^2}\theta^2+\frac{n\bar x}{\sigma^2}\theta+C_1'.$$

先验项展开：

$$-\frac{1}{2\tau_0^2}(\theta-\mu_0)^2=-\frac{1}{2\tau_0^2}\theta^2+\frac{\mu_0}{\tau_0^2}\theta+C_2.$$

**第三步（合并 $\theta$ 的二次式）**：$p(\theta\mid D)\propto\exp\Big(-\frac{A}{2}\theta^2+B\theta\Big)$，其中

$$A=\frac{n}{\sigma^2}+\frac{1}{\tau_0^2},\qquad B=\frac{n\bar x}{\sigma^2}+\frac{\mu_0}{\tau_0^2}.$$

（依据：同指数项合并；两个常数 $C_1',C_2$ 只影响归一化。）

**第四步（配方）**：$-\frac{A}{2}\theta^2+B\theta=-\frac{A}{2}\Big(\theta-\frac BA\Big)^2+\frac{B^2}{2A}$，末项与 $\theta$ 无关并入常数：

$$p(\theta\mid D)\propto\exp\!\Big(-\frac{(\theta-B/A)^2}{2/A}\Big).$$

**第五步（识别正态）**：与 $\mathcal N(\mu_n,\tau_n^2)$ 密度对比 $\theta^2$ 与 $\theta$ 的系数（或直接读出）：

$$\boxed{\ \frac{1}{\tau_n^2}=\frac{1}{\tau_0^2}+\frac{n}{\sigma^2}\ },\qquad \mu_n=\frac{B}{A}=\tau_n^2\Big(\frac{\mu_0}{\tau_0^2}+\frac{n\bar x}{\sigma^2}\Big)=\frac{\frac{1}{\tau_0^2}\mu_0+\frac{n}{\sigma^2}\bar x}{\frac{1}{\tau_0^2}+\frac{n}{\sigma^2}}.\ \blacksquare$$

**读法自检**：后验均值是先验 $\mu_0$ 与数据 $\bar x$ 按**精度**（方差倒数）的加权平均，权重和为 1（凸组合）；后验精度 = 先验精度 + 数据精度（精度可加），故 $\tau_n^2\le\min(\tau_0^2,\sigma^2/n)$——"信息只会增加"。

## 题 5（计算推导｜对应 4.2 共轭先验表）

> Poisson–Gamma 共轭：$x_i\sim\text{Pois}(\lambda)$，先验 $\text{Gamma}(\alpha,\beta)$（密度 $\propto\lambda^{\alpha-1}e^{-\beta\lambda}$）。证明后验为 $\text{Gamma}(\alpha+\sum x_i,\ \beta+n)$。

**第一步（似然）**：$n$ 个独立泊松观测的联合（丢弃与 $\lambda$ 无关的 $\prod x_i!$）：

$$p(D\mid\lambda)=\prod_{i=1}^n e^{-\lambda}\frac{\lambda^{x_i}}{x_i!}\ \propto\ e^{-n\lambda}\,\lambda^{\sum_i x_i}.$$

**第二步（先验）**：$p(\lambda)\propto\lambda^{\alpha-1}e^{-\beta\lambda}$（$\lambda>0$）。

**第三步（相乘合并指数）**：

$$p(\lambda\mid D)\propto\lambda^{\sum x_i}e^{-n\lambda}\cdot\lambda^{\alpha-1}e^{-\beta\lambda}
=\lambda^{(\alpha+\sum x_i)-1}\,e^{-(\beta+n)\lambda}.$$

**第四步（同族识别）**：右端恰是 $\text{Gamma}(\alpha',\beta')$（密度 $\propto\lambda^{\alpha'-1}e^{-\beta'\lambda}$）取 $\alpha'=\alpha+\sum x_i$、$\beta'=\beta+n$ 的未归一形状，故归一化常数自动为该族常数，无需积分：

$$\lambda\mid D\sim\text{Gamma}\Big(\alpha+\sum_i x_i,\ \beta+n\Big).$$

**第五步（后验均值的伪计数解释）**：Gamma 的均值为 $\alpha'/\beta'$：

$$\mathbb{E}[\lambda\mid D]=\frac{\alpha+\sum_i x_i}{\beta+n}.$$

读法：分子是"先验事件数 $\alpha$ + 观测事件总数"，分母是"先验时间强度 $\beta$ + 观测窗口数 $n$"——**单位时间的伪计数**更新，与 Beta–Binomial 的"成功数/总数"完全平行。$\blacksquare$

> **校验对照**：$E[\lambda\mid D]=\frac{\alpha+\sum x_i}{\beta+n}$ —— 与正文校验值一致 ✓。

## 题 6（计算推导｜对应 4.2.2 后验集中、"数据淹没先验"）

> 证明 Beta–Binomial 中 $n\to\infty$ 时后验方差 $\to0$ 且后验集中于 $s/n$。

**第一步（后验方差公式）**：后验为 $\text{Beta}(\alpha',\beta')$，$\alpha'=\alpha+s$、$\beta'=\beta+f$、$\alpha'+\beta'=\alpha+\beta+n$：

$$\mathrm{Var}(\theta\mid D)=\frac{\alpha'\beta'}{(\alpha'+\beta')^2(\alpha'+\beta'+1)}.$$

**第二步（频率稳定）**：数据由真值 $\theta^*$ 生成，$s$ 为 $n$ 次独立试验的成功数，由大数定律 $\frac sn\xrightarrow{P}\theta^*$，且 $\frac{\alpha}{n}\to0$、$\frac{\beta}{n}\to0$（固定先验）。故依概率：

$$\frac{\alpha'}{n}\to\theta^*,\qquad\frac{\beta'}{n}\to1-\theta^*,\qquad\frac{\alpha'+\beta'}{n}\to1.$$

**第三步（代入求极限）**：

$$\mathrm{Var}(\theta\mid D)=\frac{\big(n\cdot\frac{\alpha'}{n}\big)\big(n\cdot\frac{\beta'}{n}\big)}{\big(n\cdot\frac{\alpha'+\beta'}{n}\big)^2\big(\alpha+\beta+n+1\big)}
\approx\frac{n^2\theta^*(1-\theta^*)}{n^2\cdot n}=\frac{\theta^*(1-\theta^*)}{n}\ \longrightarrow\ 0.$$

（精确的说法：分子分母各乘除 $n$ 的幂，方差 $\sim\theta^*(1-\theta^*)/n$，与正文给的渐近式一致。）

**第四步（集中于 $s/n$）**：后验均值为

$$\mathbb{E}[\theta\mid D]=\frac{\alpha+s}{\alpha+\beta+n}=\frac{\frac sn+\frac{\alpha}{n}}{1+\frac{\alpha+\beta}{n}}\ \xrightarrow{P}\ \theta^*,$$

方差同时以 $O(1/n)$ 收缩，由 Chebyshev（第 3 章题 6）$P\big(|\theta-\mathbb{E}[\theta\mid D]|>\varepsilon\,\big|\,D\big)\le\frac{\mathrm{Var}}{\varepsilon^2}\to0$，后验质量收缩到 $\frac sn$（它本身收敛于 $\theta^*$）附近。$\blacksquare$

这就是"数据淹没先验"的定量化：先验只贡献 $O(1)$ 的伪计数，数据贡献 $O(n)$；后验宽度以 CLT 同款的 $1/\sqrt n$ 速率收缩。

## 题 7（编程实现｜对应 4.5.1 A/B 蒙特卡洛）

## 题 8（编程实现｜对应 4.1.3 后验预测分布）

> 从 Beta(8,4) 后验采 10000 个 $\theta$，每个 $\theta$ 生成未来 10 次试验的成功数直方图，与观测值 7 对比，报告 $P(\text{未来成功数}\ge7\mid D)$。

```python
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)
n_sim = 10_000
theta = rng.beta(8, 4, n_sim)            # 后验 Beta(8,4) (先验 Beta(1,1) + 7正3反)
succ = rng.binomial(10, theta)           # 每个 theta 生成未来 10 次试验

ks = np.arange(11)
emp = np.array([(succ == k).mean() for k in ks])
thy = stats.betabinom.pmf(ks, 10, 8, 4)  # 解析: Beta-Binomial(10, 8, 4)
print("k         :", ks)
print("empirical :", emp.round(3))
print("analytic  :", thy.round(3))
p_ge7 = (succ >= 7).mean()
print(f"P(未来成功数 >= 7 | D) = {p_ge7:.3f}   (解析 = {1 - stats.betabinom.cdf(6, 10, 8, 4):.3f})")

plt.figure(figsize=(6, 4))
plt.bar(ks, emp, alpha=0.6, label="posterior predictive")
plt.plot(ks, thy, "ro-", ms=4, label="Beta-Binomial(10,8,4)")
plt.axvline(7, color="k", ls="--", lw=1, label="observed 7")
plt.legend(); plt.tight_layout()

```

## 题 9（编程实现｜对应 4.7 案例 3 序贯更新）

> 5 条不同种子的序贯更新，画均值轨迹带，验证"轨迹收敛但围绕真值振荡"。

```python
import numpy as np
import matplotlib.pyplot as plt

true_p = 0.6
n_trials = 300
fig, ax = plt.subplots(figsize=(8, 4.5))
finals = []
for seed in range(5):
    rng = np.random.default_rng(seed)
    trials = rng.random(n_trials) < true_p
    a = b = 1.0
    means = []
    for x in trials:                     # 在线更新: 后验当新先验
        a += x
        b += (not x)
        means.append(a / (a + b))
    finals.append(a / (a + b))
    ax.plot(means, lw=1, alpha=0.8, label=f"seed {seed}")

ax.axhline(true_p, color="k", ls="--", label="true p")
ax.set_xlabel("trial"); ax.set_ylabel("posterior mean")
ax.legend(ncol=3); plt.tight_layout()
plt.savefig("ch4_q9_sequential.png", dpi=120)
print("final posterior means:", [round(v, 3) for v in finals])
```

**实际运行输出**：

```
final posterior means: [0.546, 0.596, 0.613, 0.579, 0.52]
```

五条轨迹全部收敛到 0.6 附近（终值 0.52–0.61），但路径彼此分叉、围绕真值振荡，波动幅度随 $t$ 以 $\sim1/\sqrt t$ 收窄（大数定律的可视化，正文 4.7 案例 3 注释）。这就是"轨迹带"：任何单条链都可能暂时偏离，多条链的包络才是对不确定性的诚实刻画。

## 题 10（开放思考｜对应 4.2.2 先验、4.8 误区 5 / 工程伦理）

> 团队用先验 Beta(20,5)（强信旧版更好）分析 A/B 测试：何时是知识注入、何时是操纵？设计至少 3 条"先验披露"规范。

**参考答案**：

**何时合理**：先验来自与本次实验**独立**的历史数据（如旧版过去一个季度的真实 CTR 分布，且实验环境未变）；或来自领域公认的不变约束（转化率必在 1%–5% 间）。此时 Beta(20,5)（均值 0.8，强度 25——相当强的信念，注意校验：$\sigma=\sqrt{20\cdot5/(25^2\cdot26)}\approx0.078$）只是把已有知识正式化，能降低小样本方差。

**何时是操纵**：先验由"希望 B 输"的立场反推；强度大到小样本下结论被锁死（$\alpha+\beta=25$ vs $n=100$ 的数据，先验权重占 20%）；先验与本次数据不独立（用包含本次流量在内的历史拟合）；未做敏感性分析就汇报单一后验。

**先验披露规范（实验平台强制）**：
1. **预注册**：实验开始前在平台登记先验族、参数、来源文档与拟定时点；开始后不可修改（防 HARKing 式的先验回填）。
2. **来源与独立性声明**：先验只能来自与本次数据不重叠的历史数据/外部研究，附数据集标识。
3. **敏感性分析强制输出**：平台自动在 {无信息, 弱信息, 登记先验} 三档下重跑，报告三档后验结论（如 $P(B>A)$）；若结论翻转，必须标注"先验敏感"。
4. **强度换算披露**：以伪计数/等效样本量报告先验强度，并给出"数据需多大才能淹没先验"的对照。

## 题 11（挑战题｜对应 4.5.2、Bernstein–von Mises）

> 陈述 BvM 现象并用 Beta–Binomial 数值验证。

**陈述**：正则模型 + $n\to\infty$ 时，后验分布在总变差距离下收敛到一个高斯：中心是 MLE、方差是 Fisher 信息的倒数 $I_1(\theta^*)/n$——与频率派 MLE 的抽样分布 $\sqrt n(\hat\theta-\theta^*)\Rightarrow\mathcal N(0,1/I_1)$ **重合**。因此大样本下"贝叶斯可信区间"与"频率派置信区间"数值上趋同（两派之争在渐近中消解）。

**验证脚本（已实际运行）**：

```python
import numpy as np
from scipy import stats

# Beta-Binomial, theta* = 0.3, n = 200, 5000 组重复
rng = np.random.default_rng(0)
theta_star, n, n_rep = 0.3, 200, 5000

# (a) 后验均值(=Beta(1+s,1+n-s) 的均值) 在重复实验下的经验分布
s = rng.binomial(n, theta_star, n_rep)
post_mean = (1 + s) / (n + 2)                 # Beta(1+s, 1+n-s) 均值
z = np.sqrt(n) * (post_mean - theta_star)     # 标准化
print(f"posterior-mean  z: std = {z.std():.3f} (BvM: sqrt(theta*(1-theta)) = "
      f"{np.sqrt(theta_star*(1-theta_star)):.3f}), skew = {stats.skew(z):+.3f}")

# (b) 单组数据的后验 vs 以 MLE 为中心的正态
s1 = rng.binomial(n, theta_star)
mle = s1 / n
grid = np.linspace(0.15, 0.45, 300)
post = stats.beta(1 + s1, 1 + n - s1).pdf(grid)
approx = stats.norm(mle, np.sqrt(mle*(1-mle)/n)).pdf(grid)
tv = 0.5 * np.abs(post - approx).sum() * (grid[1] - grid[0])
print(f"one dataset: MLE = {mle:.3f};  TV(post, normal approx) = {tv:.3f}")
```

**实际运行输出**：

```
posterior-mean  z: std = 0.457 (BvM: sqrt(theta*(1-theta)) = 0.458), skew = +0.082
one dataset: MLE = 0.335;  TV(post, normal approx) = 0.014
```

- (a) $\sqrt n(\text{后验均值}-\theta^*)$ 的经验标准差 0.457 vs Fisher 理论值 $\sqrt{\theta^*(1-\theta^*)}=0.458$——吻合到千分位；偏度 +0.08 ≈ 0。
- (b) 单组后验密度与 $\mathcal N(\hat\theta_{\text{MLE}},\hat\theta(1-\hat\theta)/n)$ 的总变差距离仅 0.014，几乎重合。

**200 字说明**：BvM 说的是"先验在 $n$ 大时被以 $n$ 量级增长的似然信息淹没，后验收缩到似然面最陡处"。它的两个数值表现：(a) 后验均值在重复实验下的分布 = MLE 的抽样分布（同一高斯）；(b) 单组后验形状 ≈ 以 MLE 为中心的正态。适用条件：参数在参数空间内部（不在 0/1 边界）、模型可识别、Fisher 信息非奇异、先验在真值邻域为正且光滑。边界参数（如 $\theta\to0$ 的罕见事件）、不可识别模型、先验在真值处为零时 BvM 失效——这正是小样本/边界情形贝叶斯与频率派结论分道扬镳的地方，也是为什么小样本下应保留完整后验而不是直接套正态近似。

# 第 5 章 参数估计与统计推断（对应 5.12 节，共 11 题）

## 题 1（概念辨析｜对应 5.3 估计量三性质）

> (a) 无偏估计一定一致吗？(b) 一致估计一定无偏吗？

**(a) 不一定。反例 $\hat\theta=x_1$**（只用第一个样本）：无偏性成立，$\mathbb{E}[x_1]=\theta$；但一致性不成立——无论 $n$ 多大，$\hat\theta_n$ 的分布始终是 $\mathcal N(\theta,\sigma^2)$（高斯情形），$P(|x_1-\theta|>\varepsilon)$ 是与 $n$ 无关的正常数，不收敛到 0。信息躺在数据里，估计量却视而不见。

**(b) 不一定。反例 $\hat\theta_n=\bar x+\frac1n$**：一致性成立（$\bar x\xrightarrow{P}\theta$，$\frac1n\to0$，和依概率收敛到 $\theta$）；但 $\mathbb{E}[\hat\theta_n]=\theta+\frac1n\ne\theta$，处处有偏（偏差随 $n$ 消失——**渐近无偏**）。

**要点提炼**：无偏描述"平均而言对"（对固定 $n$ 的抽样分布），一致描述"数据多了就对"（$n\to\infty$ 的极限行为），两者互不蕴含。工程上**一致性是底线**（不可牺牲——数据多了还错就无可救药），无偏可以让渡：有偏但方差更小的估计（岭回归、James–Stein）在均方误差上常更优（偏差–方差权衡，5.3 节）。

**常见错误**：认为"无偏是大样本性质的必要前提"。渐近无偏 + 方差 $\to0$ 就足以保证一致，严格无偏并非必需。

## 题 2（概念辨析｜对应 5.5.1 置信区间语义）

> 为什么"置信区间 $[990.8,1009.2]$ 包含真值 $\mu$ 的概率是 95%"是错的？重写正确表述。

**错误原因**：在频率派语义下 $\mu$ 是固定常数（不是随机变量），$[990.8,1009.2]$ 是数据实现后算出的**固定区间**——"真值是否在区间内"已无随机性可言，概率只能是 0 或 1（只是我们不知道是哪个）。95% 属于**构造程序**：若反复抽样、每次都按 $\bar x\pm t_{9,0.975}\,s/\sqrt{10}$ 构造区间，则长期看约 95% 的随机区间覆盖真值。把程序的长期覆盖率说成单个区间的概率，就是把第 4 章的可信区间语义偷运进频率派框架（4.8 误区 3）。

**正确表述**："若大量重复'抽 10 只灯泡 → 按同一公式构造区间'这一流程，约 95% 的区间会包含真寿命 $\mu$；对本次得到的 $[990.8,1009.2]$，我们不知道它是否属于那幸运的 95%，但它是由一个 95% 可靠的程序产生的。"（若想直接说"参数在此区间的概率是 95%"，请改用贝叶斯可信区间并声明框架。）

## 题 3（概念辨析｜对应 5.5.2 p 值的三种误读）

> 同一个实验，p 值 0.03 与 0.06 的区别本质上有多大？

**参考答案要点**：

1. **阈值任意性**：0.05 是约定不是自然律（5.5.2）。同一数据在 0.05 阈值下"显著"、在 0.06 阈值下"不显著"，但证据强度几乎没变。p 值是连续的证据度量，二值化"显著/不显著"丢失信息；跨过阈值的两侧（0.049 vs 0.051）更是毫无实质差别。
2. **共同语义**：两者都说"若 $H_0$ 为真，观测到这么极端的数据的概率是 3%（或 6%）"——都是**不太例外**的事件，对 $H_0$ 的支持/反对程度同属一个量级。
3. **该报告什么**：效应量与置信区间（与 p 值同报）。0.03 vs 0.06 可能对应完全相同的效应估计，只是抽样涨落；反过来，一个 p=0.03 的微小效应可能毫无实践价值（显著 ≠ 重要，误读 2），一个 p=0.06 的大效应可能只是样本不足（不显著 ≠ 无差异，误读 3）。
4. **结论**：本质区别很小；真正要紧的是效应大小、区间宽度与检验功效。把 0.03 与 0.06 当成"有/无发现"的分界，是 p 值三大误读之首（当真值概率用，误读 1）的变体。

## 题 4（计算推导｜对应 5.2 MLE 原理、5.8 误区 4）

> 推导 $U(0,\theta)$ 的 MLE，证明其有偏并构造无偏修正。（校验值：$E[\max_i x_i]=\frac{n}{n+1}\theta$）

**第一步（写似然，发现不可导）**：$x_1,\dots,x_n$ i.i.d. $U(0,\theta)$。联合似然

$$L(\theta)=\prod_{i=1}^n\frac1\theta\,\mathbb 1\{0\le x_i\le\theta\}=\theta^{-n}\,\mathbb 1\{\theta\ge x_{(n)}\},\qquad x_{(n)}=\max_i x_i.$$

示性函数说明：$\theta<x_{(n)}$ 时 $L=0$（数据落在支撑外，概率 0 的矛盾）；$\theta\ge x_{(n)}$ 时 $L=\theta^{-n}$ **单调递减**。似然在 $\theta=x_{(n)}$ 处跳变、不可导——**"求导置零"在这里根本不适用**（正文 5.8 误区 4 的原例）。

**第二步（读出 MLE）**：在可行域 $\theta\ge x_{(n)}$ 上 $L$ 递减，最大值在左端点取到：

$$\hat\theta_{\text{MLE}}=x_{(n)}=\max_i x_i.$$

**第三步（求 $E[x_{(n)}]$）**：先用 CDF 法求最大值的分布。对 $0\le x\le\theta$：

$$F_{x_{(n)}}(x)=P(x_1\le x,\dots,x_n\le x)=\Big(\frac x\theta\Big)^n\ \Rightarrow\ f_{x_{(n)}}(x)=\frac{n x^{n-1}}{\theta^n}.$$

期望（幂函数积分）：

$$\mathbb{E}[x_{(n)}]=\int_0^\theta x\cdot\frac{n x^{n-1}}{\theta^n}dx=\frac n{\theta^n}\cdot\frac{\theta^{n+1}}{n+1}=\frac{n}{n+1}\theta.$$

**第四步（偏差与修正）**：$\mathbb{E}[\hat\theta]=\frac{n}{n+1}\theta<\theta$——MLE 系统性低估（最大值不可能超过 $\theta$，"够不着上界"）。偏差 $=\theta/(n+1)$，放大 $\frac{n+1}{n}$ 倍恰好消去：

$$\tilde\theta=\frac{n+1}{n}\,x_{(n)},\qquad\mathbb{E}[\tilde\theta]=\theta\ (\text{无偏}).$$

> **校验对照**：$E[\max_i x_i]=\frac{n}{n+1}\theta$ —— 与正文校验值一致 ✓。（附注：$\tilde\theta$ 无偏但可能给出 $\tilde\theta>\max x_i$ 的"越界"值，小样本时 $\mathrm{Var}$ 也更大——无偏不是免费的。）

## 题 5（计算推导｜对应 5.4 Fisher 信息与 CRLB）

> 推导 $\text{Exp}(\lambda)$ 的 MLE 与 Fisher 信息，验证 CRLB 达成。（校验值：$\hat\lambda=1/\bar x$；$I_n=n/\lambda^2$）

**第一步（对数似然）**：密度 $\lambda e^{-\lambda x}$，$n$ 个 i.i.d.：

$$\ell(\lambda)=\sum_i(\ln\lambda-\lambda x_i)=n\ln\lambda-\lambda\sum_i x_i.$$

**第二步（求导置零）**：$\frac{d\ell}{d\lambda}=\frac n\lambda-\sum_i x_i=0\ \Rightarrow\ \hat\lambda=\frac n{\sum x_i}=\frac1{\bar x}$。

二阶导 $\frac{d^2\ell}{d\lambda^2}=-\frac n{\lambda^2}<0$ 恒成立 ⇒ 全局最大。

**第三步（Fisher 信息）**：单样本 $\ell_1=\ln\lambda-\lambda x$，$\ell_1''=-\frac1{\lambda^2}$（与 $x$ 无关！），故曲率版

$$I_1(\lambda)=\mathbb{E}\Big[-\ell_1''\Big]=\frac{1}{\lambda^2},\qquad I_n(\lambda)=\frac n{\lambda^2}.$$

（得分版自检：$\ell_1'=\frac1\lambda-x$，$\mathbb{E}[(\frac1\lambda-x)^2]=\mathrm{Var}(x)=\frac1{\lambda^2}$ ✓。）

**第四步（CRLB 与达成）**：CRLB 为 $\mathrm{Var}(\hat\lambda)\ge1/I_n=\lambda^2/n$。可精确计算（$\sum x_i\sim\text{Gamma}(n,\text{rate}\ \lambda)$，用 $\mathbb{E}[T^{-1}]=\frac{\lambda}{n-1}$、$\mathbb{E}[T^{-2}]=\frac{\lambda^2}{(n-1)(n-2)}$）：

$$\mathrm{Var}(\hat\lambda)=n^2\Big(\frac{\lambda^2}{(n-1)(n-2)}-\frac{\lambda^2}{(n-1)^2}\Big)=\frac{n^2\lambda^2}{(n-1)^2(n-2)}\ \xrightarrow[n\to\infty]{}\ \frac{\lambda^2}{n}.$$

即 $\hat\lambda$ **渐近**达到 CRLB（有限样本略高于下界——它甚至是有偏的：$\mathbb{E}[\hat\lambda]=\frac n{n-1}\lambda\ne\lambda$，但不影响渐近有效性与一致性）。

> **校验对照**：$\hat\lambda=1/\bar x$；$I_n=n/\lambda^2$ —— 与正文校验值一致 ✓。

## 题 6（计算推导｜对应 5.2.2 第五步，方差 MLE 的偏差）

> 证明 $\sum_i(x_i-\bar x)^2$ 的期望为 $(n-1)\sigma^2$，从而 $\widehat{\sigma^2}$ 的偏差为 $-\sigma^2/n$。

**第一步（平方分解）**：从恒等式出发，加减肥etzen项：

$$\sum_i(x_i-\mu)^2=\sum_i\big[(x_i-\bar x)+(\bar x-\mu)\big]^2=\sum_i(x_i-\bar x)^2+2(\bar x-\mu)\underbrace{\sum_i(x_i-\bar x)}_{=0}+n(\bar x-\mu)^2.$$

交叉项为零（$\sum_i(x_i-\bar x)=n\bar x-n\bar x=0$），得

$$\sum_i(x_i-\mu)^2=\sum_i(x_i-\bar x)^2+n(\bar x-\mu)^2.$$

**第二步（取期望，用线性性）**：左边 $\mathbb{E}\sum_i(x_i-\mu)^2=n\sigma^2$（每项方差 $\sigma^2$，均值项 $\mathbb{E}(x_i-\mu)=0$）。第三项 $\mathbb{E}(\bar x-\mu)^2=\mathrm{Var}(\bar x)=\frac{\sigma^2}n$（独立方差可加，第 2 章 2.3.2）。故

$$n\sigma^2=\mathbb{E}\Big[\sum_i(x_i-\bar x)^2\Big]+n\cdot\frac{\sigma^2}{n}\ \Rightarrow\ \mathbb{E}\Big[\sum_i(x_i-\bar x)^2\Big]=(n-1)\sigma^2.$$

**第三步（MLE 方差的偏差）**：$\widehat{\sigma^2}=\frac1n\sum_i(x_i-\bar x)^2$，故

$$\mathbb{E}\big[\widehat{\sigma^2}\big]=\frac{n-1}{n}\sigma^2=\sigma^2-\frac{\sigma^2}{n}\qquad(\text{偏差}=-\sigma^2/n).\ \blacksquare$$

与 $\chi^2_{n-1}$ 视角一致：$\sum_i(x_i-\bar x)^2/\sigma^2\sim\chi^2_{n-1}$，期望 $n-1$（$\bar x$ 消耗一个自由度）。除以 $n-1$ 的 $s^2$ 即无偏。工程含义：`np.var(x)`（除 $n$）vs `np.var(x, ddof=1)`（除 $n-1$）的差别在小样本统计报告中不可忽略（5.8 误区 1）。

## 题 7（编程实现｜对应 5.7 案例 2、5.4.2 渐近正态性）

> 母分布换成 $\text{Exp}(1)$ 估 $\lambda$（MLE $=1/\bar x$），验证 $\sqrt n(\hat\lambda-\lambda)\Rightarrow\mathcal N(0,\lambda^2)$（$n=30$ 与 $n=500$）。

```python
rng = np.random.default_rng(5)

    print(f"n={n:>3}: std of z = {z.std():.3f} (theory {lam:.3f}), "
          f"bias of z = {z.mean():+.3f}")
```

## 题 8（编程实现｜对应 5.2.3 MAP/MLE 统一、4.3 L2 正则）

> 从零逻辑回归追加 L2 正则（$\lambda=0.1$），对比正则前后权重范数与训练准确率。

```python
import numpy as np

rng = np.random.default_rng(0)
n, d = 400, 2
X = rng.normal(size=(n, d))
X1 = np.hstack([X, np.ones((n, 1))])
w_true = np.array([1.5, -2.0, 0.5])
p = 1/(1+np.exp(-(X1 @ w_true)))
y = (rng.random(n) < p).astype(float)

def nll(w):                                  # 伯努利负对数似然(均值形式)
    z = X1 @ w
    return np.mean(np.logaddexp(0, z) - y*z)
def grad_nll(w):
    z = X1 @ w
    return X1.T @ (1/(1+np.exp(-z)) - y) / n

def train(lam, steps=4000, lr=0.5):          # lam=0 即 MLE; lam>0 即 L2 正则(MAP)
    w = np.zeros(3)
    for _ in range(steps):
        g = grad_nll(w)
        g[:2] += lam * w[:2]                 # 截距不惩罚 (常见约定)
        w -= lr * g
    return w

def acc(w):
    return ((X1 @ w > 0) == (y == 1)).mean()

w_mle = train(0.0)
w_map = train(0.1)
print("MLE w      :", w_mle.round(3), " ||w||^2 =", (w_mle**2).sum().round(3),
      " acc =", acc(w_mle).round(3))
print("MAP w(L2)  :", w_map.round(3), " ||w||^2 =", (w_map**2).sum().round(3),
      " acc =", acc(w_map).round(3))
print("MAP/MLE 权重范数比 =", np.sqrt((w_map**2).sum()/(w_mle**2).sum()).round(3))
```

**实际运行输出**（seed=0）：

```
MLE w      : [ 1.641 -1.957  0.748]  ||w||^2 = 7.082  acc = 0.82
MAP w(L2)  : [ 0.71  -0.829  0.481]  ||w||^2 = 1.424  acc = 0.818
MAP/MLE 权重范数比 = 0.448
```

**解读（验证第 4 章 MAP 观点）**：目标加 $\frac{\lambda}{2}\lVert w\rVert^2$ 等价于对权重施加高斯先验（$\lambda=\sigma^2/\tau_0^2$，4.3 节）。数值上：权重范数平方从 7.08 收缩到 1.42（比 0.448），而训练准确率几乎不变（0.820 → 0.818）——正则在几乎不付精度代价的前提下把解拉向先验中心（这里是 0），这正是"高斯先验收缩权重"的直接展示，也是岭回归/权重衰减的贝叶斯身份证。

## 题 9（编程实现｜对应 5.5.2 假设检验、功效）

> 双样本 t 检验功效模拟（$n_1=n_2$，$\mu_1=0,\mu_2=0.5,\sigma=1$），$n=30$ 与 $n=200$。

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(7)
alpha, n_sim = 0.05, 2000
for n in (30, 200):
    rejects = 0
    for _ in range(n_sim):
        x1 = rng.normal(0.0, 1.0, n)
        x2 = rng.normal(0.5, 1.0, n)
        t, p = stats.ttest_ind(x1, x2)
        rejects += (p < alpha)
    power = rejects / n_sim
    # 解析近似: 非中心 t 分布, 非中心参数 = delta/sqrt(2/n)
    ncp = 0.5 / np.sqrt(2/n)
    tcrit = stats.t.ppf(1 - alpha/2, 2*n - 2)
    power_thy = stats.nct.sf(tcrit, 2*n-2, ncp) + stats.nct.cdf(-tcrit, 2*n-2, ncp)
    print(f"n={n:>3}: 模拟功效 = {power:.3f}   解析(非中心t) = {power_thy:.3f}")
```

**实际运行输出**：

```
n= 30: 模拟功效 = 0.485   解析(非中心t) = 0.478
n=200: 模拟功效 = 1.000   解析(非中心t) = 0.999
```

- $n=30$：功效 ≈ 0.48（预期约 0.48 ✓）——真实差异 0.5σ 存在时，仍有约一半的实验什么也发现不了；"不显著"极可能只是功效不足（p 值误读 3）。
- $n=200$：功效 ≈ 0.99（预期约 0.99 ✓）——几乎必然拒绝。**含义**：实验设计先算功效（或最小可检测效应），而不是事后拿"不显著"当"无差异"。

**参考设计**：

2. **统计量与检验**：若新旧模型在同一测试集上逐 token 评估，用**配对**设计：$d_i=\ell^{\text{old}}_i-\ell^{\text{new}}_i$，$t=\bar d/(s_d/\sqrt n)$。配对消掉 token 难度这个共同因子，功效远高于独立两样本 t。若只有汇总 loss，则退化为两独立均值之差的 z 检验（方差需各自估计或取保守值）。更稳的是**对 token 做 bootstrap/置换检验**：随机打乱新旧标签重算 $\bar d$ 的分布，不依赖正态假设。
3. **需要的假设与保守处理**：token 间独立——**这条最可疑**（同一序列内强相关，相邻 token 共享上下文）。保守处理：按序列分块、块级 bootstrap（或 Newey–West 型长滞后方差修正），等效样本量会远小于 $10^5$，SE 变大——结论若仍显著才算稳。
4. **同时报告效应量**：$\Delta=0.03$ nats/token 约等于困惑度下降 $e^{0.03}\approx3\%$——写清这个数，让"统计显著"与"工程重要"分开判断（p 值误读 2）。

## 题 11（挑战题｜对应 5.4.2 CRLB 的矩阵化）

> 证明多元 CRLB：$\mathrm{Cov}(\hat{\boldsymbol\theta})\succeq I(\boldsymbol\theta)^{-1}$（半正定意义），并讨论高斯线性回归的关系。

**证明（Schur 补 / 分块 Cauchy–Schwarz）**：

**第一步（联合协方差矩阵）**：记得分向量 $S=\nabla_\theta\ell$（$d$ 维），构造联合协方差

$$\Sigma=\mathrm{Cov}\begin{pmatrix}\hat{\boldsymbol\theta}\\ S\end{pmatrix}
=\begin{pmatrix}\mathrm{Cov}(\hat\theta) & C\\ C^\top & I(\theta)\end{pmatrix},$$

其中 $C=\mathrm{Cov}(\hat\theta,S)=\mathbb{E}[\hat\theta S^\top]-\mathbb{E}\hat\theta\,\mathbb{E}S^\top$。

**第二步（两个关键事实，标量版的推广）**：在积分号下求导（正则条件）：

$$\mathbb{E}[S]=\int\nabla_\theta p\,dx=\nabla_\theta\int p\,dx=\nabla_\theta 1=0,$$
$$\mathbb{E}[\hat\theta S^\top]=\int\hat\theta\,(\nabla_\theta p)^\top dx=\nabla_\theta\int\hat\theta\,p^\top dx=\nabla_\theta\,\mathbb{E}[\hat\theta]^\top=\nabla_\theta\theta^\top=I_d\quad(\text{无偏性}).$$

故 $C=I_d$（单位阵——注意这是 $\hat\theta$ 的**协方差阵与得分之间的互协方差**，不是单位矩阵巧合，而是"得分与任何无偏估计量的互协方差 = 单位阵"）。

**第三步（半正定性 + Schur 补）**：$\Sigma\succeq0$（协方差矩阵半正定：$\mathrm{Var}(u^\top\hat\theta+v^\top S)\ge0$）。$I(\theta)\succ0$（正则模型 Fisher 信息正定），故 Schur 补半正定：

$$\Sigma\succeq0\ \Longleftrightarrow\ \mathrm{Cov}(\hat\theta)-I^{-1}\succeq0\ \Longrightarrow\ \mathrm{Cov}(\hat\theta)\succeq I(\theta)^{-1}.\ \blacksquare$$

（半正定序的含义：对任意方向 $u$，$u^\top\mathrm{Cov}(\hat\theta)u\ge u^\top I^{-1}u$——任何线性组合的估计方差都不低于下界矩阵给出的值；取 $u$ 为坐标向量即回收标量 CRLB。）

**第四步（高斯线性回归的讨论）**：$y=Xw+\varepsilon$，$\varepsilon\sim\mathcal N(0,\sigma^2I)$，Fisher 信息矩阵

$$I(w)=\frac{X^\top X}{\sigma^2}.$$

最小二乘解 $\hat w=(X^\top X)^{-1}X^\top y$ 的精确协方差为

$$\mathrm{Cov}(\hat w)=\sigma^2(X^\top X)^{-1}=I(w)^{-1}$$

——**在一切 $n$（不只渐近）精确达到多元 CRLB**（高斯的特例：MLE = 样本均值类估计量天然有效，对应第 3 章 $\mathrm{Var}(\bar x)=\sigma^2/n$ 的多元版）。**设计矩阵的正交化**使 $X^\top X$ 对角化（各列正交），$I^{-1}$ 成为对角阵：每个参数的方差互不耦合、同时各自达到 CRLB；若列间相关（$X^\top X$ 病态），$I^{-1}$ 出现大对角元——个别参数的方差被联合不确定性撑大，这正是多重共线性危害的 Fisher 信息语言，也是《线性代数》第 3 章正交化练习的统计动机。

# 第 6 章 采样方法与蒙特卡洛（对应 6.11 节，共 12 题）

## 题 1（概念辨析｜对应 6.1.1 蒙特卡洛 vs 网格求积）

> 为什么 MC 的 $1/\sqrt n$ 速率不依赖维数，而网格求积随维数指数恶化？

**标准答案（每问一句）**：

- **蒙特卡洛**：误差来源是**随机误差**（样本均值的统计涨落），由 CLT 控制：$\mathrm{SE}=\sigma_f/\sqrt n$，与被积函数定义在几维空间无关——每个样本对整个积分贡献一次"无偏投票"，投票数 $n$ 就是全部代价；维数只进入方差 $\sigma_f^2$（常数因子），不改变 $1/\sqrt n$ 的速率。
- **网格求积**：误差来源是**确定性偏差**（离散化截断误差），要控制它必须让每个维度的网格间距 $h$ 都足够小；$d$ 维下点数 $=O(h^{-d})$——为了把偏差压低一档，点数按维数指数膨胀（维数灾难）。

一句话对比：MC 用"随机性"把误差从"逐点控制偏差"换成"统计平均"，从而把代价从 $O(m^d)$ 降到 $O(\varepsilon^{-2})$——这就是高维贝叶斯、物理模拟只有蒙特卡洛可用的原因。

## 题 2（概念辨析｜对应 6.5.1 MH 正确性、6.5.2 诊断）

> MH 证明中哪一步使归一化常数消失？只有 $\tilde p$ 时，trace plot 里的 $\log\tilde p$ 能否判断平稳？

**标准答案要点**：

1. **消失的位置**：接受概率 $\alpha=\min\!\big(1,\frac{\tilde p(x')q(x|x')}{\tilde p(x)q(x'|x)}\big)$ 是**比值**形式——细致平衡的验证只用到 $\tilde p(x')/\tilde p(x)$，任何归一化常数 $Z$（$\tilde p=Zp$）在分子分母同时出现、约掉。这正是 MH 能驾驭贝叶斯后验（$Z=p(D)$ 算不出）的原因。
2. **$\log\tilde p$ 能否判平稳：能**。平稳时链在"等密度面"间按正确比例分配时间，$\log\tilde p$ 的轨迹围绕一个稳定水平波动、无系统漂移；$Z$ 未知只是给曲线加了一个未知常数偏移，不影响"水平是否稳定/是否分段漂移"的判断。若 $\log\tilde p$ 长期上升或下降、或出现不同水平的长平台（多峰），即链未混合。注意局限：平稳的 $\log\tilde p$ 轨迹是必要非充分条件——单链"看似平稳"也可能漏掉另一峰（6.7 误区 2），要多链 $\hat R$ 佐证。

## 题 3（概念辨析｜对应 6.2.2 维数灾难、6.5.1 混合、6.7 误区 6）

> "拒绝采样一维好用、高维失效"与"随机游走 MH 高维慢"是同一个几何原因的两个表现。

**标准答案要点**：高维空间中，各向同性分布的质量集中在一个半径 $\approx\sqrt d$ 的**薄壳**里（每维方差 1 时，$\lVert x\rVert^2$ 集中在 $d$ 附近、相对宽度 $O(1/\sqrt d)$）——"典型集"体积占比极小但几乎承载全部概率质量。

- **拒绝采样失效**：提议分布 $g$（如均匀盒）要在整个盒子内铺点，盒子体积随 $d$ 指数大于典型集体积，于是几乎每次提议都落在薄壳之外的"荒地"，接受率 $1/M$ 随 $d$ 指数衰减——**全局提议打不进薄壳**。
- **随机游走 MH 变慢**：改为局部提议（小步长）后能待在典型集附近，但探索只能靠随机游走逐步扩散，混合时间随维数增长（步长须按 $d^{-1/3}$ 收缩、接受率压到 0.234，扩散穿过直径 $\sqrt d$ 的集合需 $O(d)$ 量级步数）——**局部提议进得来但走不远**。

两者是同一几何事实的两面：**高维中"随便打一枪"必脱靶，"挪一小步"又太慢**。HMC 的解法（用梯度沿等高线做长程定向飞行）正是绕开这两难，见 6.10 与挑战题 12。

## 题 4（计算推导｜对应 6.2.1 定理 6.1 逆变换法）

> 证明定理 6.1；推导 $X\sim U(0,1)$ 时 $X^{1/2}$、$X^{1/3}$ 的分布。

**定理 6.1 证明**：$U\sim U(0,1)$，$F$ 连续严格增，令 $X=F^{-1}(U)$。对任意 $x$（$F$ 严格增保证事件等价）：

$$P(X\le x)=P\big(F^{-1}(U)\le x\big)=P\big(U\le F(x)\big)=F(x),$$

末步用均匀分布的 CDF $P(U\le u)=u$（$0\le u\le1$）。故 $X$ 的 CDF 恰为 $F$。$\blacksquare$

**$X^{1/2}$**：令 $Y=\sqrt X\in[0,1]$（注意 $\sqrt{\cdot}$ 严格增，可用上式或直接算）：

$$F_Y(y)=P(\sqrt X\le y)=P(X\le y^2)=y^2\ \Rightarrow\ f_Y(y)=2y,\quad 0\le y\le1.$$

**$X^{1/3}$**：同理 $F_Y(y)=P(X\le y^3)=y^3\ \Rightarrow\ f_Y(y)=3y^2$。

一般规律：$X^{1/k}$ 的 CDF 为 $y^k$、密度 $ky^{k-1}$——即 $\text{Beta}(k,1)$ 分布；密度在 1 处堆积（$k$ 越大越向 1 集中），因为开高次根把 $(0,1)$ 内的均匀质量整体推向右端。

> **校验对照**：$F(x)=x^2$、密度 $2x$ —— 与正文校验值一致 ✓。

## 题 5（计算推导｜对应 6.5.1 MH 的细致平衡验证）

> 对对称提议分两种情况验证细致平衡。

**设置**：对称核 $q(x'|x)=q(x|x')$，接受概率 $\alpha(x\to x')=\min\big(1,\frac{\tilde p(x')}{\tilde p(x)}\big)$。要验证：对任意 $x\ne x'$，

$$\tilde p(x)\,q(x'|x)\,\alpha(x\to x')=\tilde p(x')\,q(x|x')\,\alpha(x'\to x)\qquad(\text{概率流相等}).$$

**情况 1：$\tilde p(x')\ge\tilde p(x)$（上坡）**。则 $\alpha(x\to x')=1$，$\alpha(x'\to x)=\frac{\tilde p(x)}{\tilde p(x')}$。正向流 $=\tilde p(x)\,q$；反向流 $=\tilde p(x')\,q\cdot\frac{\tilde p(x)}{\tilde p(x')}=\tilde p(x)\,q$。相等 ✓。

**情况 2：$\tilde p(x')<\tilde p(x)$（下坡）**。对称地，$\alpha(x'\to x)=1$、$\alpha(x\to x')=\frac{\tilde p(x')}{\tilde p(x)}$。正向流 $=\tilde p(x)\,q\cdot\frac{\tilde p(x')}{\tilde p(x)}=\tilde p(x')\,q$；反向流 $=\tilde p(x')\,q$。相等 ✓。

（$q$ 对称故两方向的 $q$ 相同；$\tilde p$ 的归一化常数 $Z$ 在所有比式中约掉。）细致平衡 $\Rightarrow\ \pi\propto\tilde p$ 是平稳分布（两边对 $x$ 求和即 $\pi^\top P=\pi$）；加上提议核正定性带来的不可约与非周期性，链收敛到 $\pi$。$\blacksquare$

## 题 6（计算推导｜对应 6.5.2 ESS 公式）

> 自相关 $\rho_k=\rho^k$（几何衰减），推导 $\mathrm{ESS}\approx n\frac{1-\rho}{1+\rho}$，并算 $\rho=0.9$ 时的 ESS/名义比。

**推导**：ESS 定义 $=\dfrac{n}{1+2\sum_{k\ge1}\rho_k}$。几何级数求和（$\sum_{k=1}^\infty\rho^k=\frac{\rho}{1-\rho}$）：

$$1+2\sum_{k\ge1}\rho^k=1+\frac{2\rho}{1-\rho}=\frac{1-\rho+2\rho}{1-\rho}=\frac{1+\rho}{1-\rho}.$$

取倒数：

$$\mathrm{ESS}=n\cdot\frac{1-\rho}{1+\rho}.$$

**代入 $\rho=0.9$**：

$$\frac{\mathrm{ESS}}{n}=\frac{0.1}{1.9}=0.0526\approx0.053.$$

即约 $\frac{1}{0.0526}\approx19$ 步才贡献一个独立样本——与正文校验值一致 ✓。**含义**：滞后 1 自相关高达 0.9 的链，名义 4 万步只有约 2000 个有效样本；报置信区间用 $n$ 会把 SE 低估 $\sqrt{19}\approx4.4$ 倍（6.7 误区 1 的定量版）。

## 题 8（编程实现｜对应 6.3.3 重要性采样的失效边界）

> 复现 6.3.3，把方案 C 换成 $\mathcal N(0,1.5^2)$，画 ESS 随提议方差（0.25→4）的曲线，标注安全区间。

```python
import numpy as np
import matplotlib.pyplot as plt

# 目标: 估计 P(|Z|>2), Z~N(0,1); 真值 0.0455
rng = np.random.default_rng(9)
n = 100_000
f = lambda x: (np.abs(x) > 2).astype(float)
target_pdf = lambda x: np.exp(-x**2/2) / np.sqrt(2*np.pi)

def stats_norm(x, sd):                   # N(0, sd^2) 密度
    return np.exp(-x**2/(2*sd**2)) / (sd*np.sqrt(2*np.pi))

sds = np.linspace(0.25, 4.0, 40)
ess_ratio, estimates = [], []
for sd in sds:
    z = rng.normal(0, sd, n)
    w = target_pdf(z) / stats_norm(z, sd)         # 权重 w = p/q
    ess_ratio.append((w.sum()**2 / (w**2).sum()) / n)   # ESS/n
    estimates.append(np.mean(f(z) * w))

print(f"sd=0.25 : ESS/n = {ess_ratio[0]:.4f}, est = {estimates[0]:.4f}  (爆炸)")
print(f"sd=1.00 : ESS/n = {ess_ratio[np.argmin(np.abs(sds-1.0))]:.4f}, "
      f"est = {estimates[np.argmin(np.abs(sds-1.0))]:.4f}")
print(f"sd=2.00 : ESS/n = {ess_ratio[np.argmin(np.abs(sds-2.0))]:.4f}, "
      f"est = {estimates[np.argmin(np.abs(sds-2.0))]:.4f}")
print("真值 P(|Z|>2) = 0.0455")
print(f"ESS/n >= 10% 的安全区间: sd ∈ [{sds[np.argmax(np.array(ess_ratio)>=0.1)]:.2f}, 4.00]")

plt.figure(figsize=(6, 4))
plt.plot(sds, ess_ratio, "b.-")
plt.axhline(0.1, color="r", ls="--", label="ESS/n = 0.1")
plt.axvline(1.0, color="k", ls=":", label="sd = 1 (= target)")
plt.xlabel("proposal std"); plt.ylabel("ESS / n")
plt.legend(); plt.tight_layout()
plt.savefig("ch6_q8_ess_curve.png", dpi=120)
```

**实际运行输出**（seed=9）：

```
sd=0.25 : ESS/n = 0.0009, est = 0.0000  (爆炸)
sd=1.00 : ESS/n = 0.9993, est = 0.0454
sd=2.00 : ESS/n = 0.6665, est = 0.0461
真值 P(|Z|>2) = 0.0455
ESS/n >= 10% 的安全区间: sd ∈ [0.63, 4.00]
```

**曲线形态与解读**：ESS/n 在 $\sigma_q=1$（恰为目标）附近接近 1，向右（$q$ 更宽）缓慢下降（权重 $p/q$ 的离散度增大但仍温和），向左断崖式崩塌——$\sigma_q=0.5$ 时估计已**系统偏大**（0.115 vs 真值 0.0455：尾部覆盖不足，$|x|>2$ 的贡献全靠少数巨权重样本），$\sigma_q=0.25$ 时 ESS/n≈0.001、估计直接归零。安全区间（ESS/n ≥ 10%）为 $\sigma_q\gtrsim0.63$。结论复述 6.3.2：**$q$ 必须在尾部覆盖 $p$；选错 $q$ 不是慢，是错**。

## 题 9（编程实现｜对应 6.5.3 最后一图的正确画法）

> 椭圆参数方程用半轴长 $c\sqrt{\lambda_1},c\sqrt{\lambda_2}$（$c=1,2,3$ 即 1/2/3σ 等值线），验证散点云与椭圆嵌套。

**修正点**：教材 6.5.3 代码中椭圆用 $2c\sqrt\lambda$，画出来的是 2/4/6σ 等值线；正确的 $c$-sigma 椭圆半轴长是 $c\sqrt{\lambda_i}$（由 $(x-\mu)^\top\Sigma^{-1}(x-\mu)=c^2$ 与谱分解直接读出，见 3.3.2）。完整可运行版本：

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(10)

Sigma = np.array([[2.0, 1.2], [1.2, 1.0]])
Sig_inv = np.linalg.inv(Sigma)
log_tilde_p = lambda x: -0.5 * x @ Sig_inv @ x

def mh_sample(x0, n_steps, eps=1.2):
    x, acc = np.array(x0, float), 0
    chain = np.empty((n_steps, 2))
    for t in range(n_steps):
        prop = x + eps * rng.standard_normal(2)      # 对称随机游走提议
        if np.log(rng.random()) < log_tilde_p(prop) - log_tilde_p(x):
            x = prop; acc += 1
        chain[t] = x
    return chain, acc / n_steps

chain, acc_rate = mh_sample(x0=[5.0, -5.0], n_steps=40_000, eps=1.2)
samples = chain[5_000:]
print(f"acceptance rate = {acc_rate:.2f}")            # 预期 ≈ 0.3

plt.figure(figsize=(5.5, 5.5))
plt.scatter(samples[::20, 0], samples[::20, 1], s=4, alpha=0.4)
t = np.linspace(0, 2*np.pi, 200)
L, V = np.linalg.eigh(Sigma)               # 升序特征值, V 列 = 单位特征向量
for c in (1, 2, 3):                        # 正确版本: 半轴长 c*sqrt(lambda_i)
    ell = (c*np.sqrt(L[1]) * np.cos(t)[:, None] * V[:, 1]
         + c*np.sqrt(L[0]) * np.sin(t)[:, None] * V[:, 0])
    plt.plot(ell[:, 0], ell[:, 1], "r-", lw=1.0)
plt.gca().set_aspect("equal")
plt.savefig("ch6_q9_mh_ellipse.png", dpi=120)
print("eigenvalues:", L.round(3), " -> semi-axes (c=1):", np.sqrt(L).round(3))
print("sample cov =\n", np.cov(samples.T).round(3))
```

## 题 10（编程实现｜对应 6.5.1 调参直觉、6.5.2 ESS 诊断）

> $\epsilon\in\{0.1,1.2,5.0\}$ 三档步长跑 MH，各报 ACF 与 ESS，找最优 $\epsilon$。

```python
import numpy as np
import matplotlib.pyplot as plt

Sigma = np.array([[2.0, 1.2], [1.2, 1.0]])
Sig_inv = np.linalg.inv(Sigma)
log_tilde_p = lambda x: -0.5 * x @ Sig_inv @ x

def mh_sample(x0, n_steps, eps, seed):
    r = np.random.default_rng(seed)
    x, acc = np.array(x0, float), 0
    chain = np.empty((n_steps, 2))
    for t in range(n_steps):
        prop = x + eps * r.standard_normal(2)
        if np.log(r.random()) < log_tilde_p(prop) - log_tilde_p(x):
            x = prop; acc += 1
        chain[t] = x
    return chain, acc / n_steps

def acf(x, max_lag):
    """FFT 加速的自相关函数 (零填充避免循环卷积)"""
    x = x - x.mean()
    n = len(x)
    nfft = 1 << (2 * n - 1).bit_length()
    f = np.fft.rfft(x, nfft)
    acov = np.fft.irfft(f * np.conj(f))[:max_lag] / n
    return acov / acov[0]

def ess(x, max_lag=2000):
    r = acf(x, max_lag)
    below = np.nonzero(np.abs(r) < 0.05)[0]
    cutoff = below[0] if len(below) else max_lag   # 永不跌破噪声 => 用全部滞后
    tau = max(1 + 2 * r[1:cutoff].sum(), 1.0)
    return len(x) / tau, tau, cutoff

for eps in (0.1, 1.2, 5.0):
    n_steps = 200_000 if eps < 0.5 else 60_000   # 小步长需要更长的链与 burn-in
    chain, acc = mh_sample([5.0, -5.0], n_steps, eps, seed=10)
    s = chain[n_steps // 6:]
    e, tau, cutoff = ess(s[:, 0])
    print(f"eps={eps:>3}: accept={acc:.2f}, tau={tau:7.1f}, "
          f"ESS={e:6.0f} / {len(s)}  (ESS/步 = {e/len(s):.4f})")
    print(f"         sample mean={s.mean(axis=0).round(2)}, "
          f"sample var={s.var(axis=0).round(2)}  (theory [0,0], [2,1])")
```

**实际运行输出**（seed=10）：

```

         sample mean=[-0.02 -0.02], sample var=[1.6 0.85]  (theory [0,0], [2,1])
eps=1.2: accept=0.36, tau=   23.3, ESS=  2141 / 50000  (ESS/步 = 0.0428)
         sample mean=[0.01 0.02], sample var=[1.94 0.96]  (theory [0,0], [2,1])
eps=5.0: accept=0.05, tau=   33.8, ESS=  1479 / 50000  (ESS/步 = 0.0296)
         sample mean=[-0.04 -0.02], sample var=[1.98 1.  ]  (theory [0,0], [2,1])
```

**两头吃亏的完整画像**：

- **$\epsilon=0.1$（太小）**：接受率 0.92 很"好看"，但每步只挪 0.1，集成自相关时间 $\tau\approx840$，ESS/步 崩到 0.001——**还有隐藏的第二重代价**：burn-in 也被拉长，即使 20 万步、burn-in 3.3 万，样本方差（1.6, 0.85）仍明显低于理论 (2, 1)，链尚未充分展开。
- **$\epsilon=5.0$（太大）**：提议常被打回（接受率 0.05），链长时间原地不动，$\tau\approx34$，ESS/步 0.030；好处是 burn-in 快、方差已对上理论值。
- **$\epsilon=1.2$（适中）**：接受率 0.36 落在经验区间 0.2–0.5，$\tau\approx23$、ESS/步 0.043 最高——**本问题最优**，与正文"调 $\epsilon$ 使接受率约 0.2–0.5"的法则一致。

方法论教训：看接受率（表层指标）不如看 ESS（本质指标）；小步长的"高接受率"是幻觉，真正的账要算 ESS/秒（含 burn-in）。

## 题 11（开放思考｜对应 6.4.2 平稳分布、谱视角；Diffusion 预告）

> 证明 Diffusion 前向过程 $q(z_t\mid z_{t-1})=\mathcal N(\sqrt{1-\beta}z_{t-1},\beta I)$ 的平稳分布是 $\mathcal N(0,I)$，并说明与 6.4.2 谱视角的对应（150 字）。

**证明**：递推 $z_t=\sqrt{1-\beta}\,z_{t-1}+\sqrt\beta\,\epsilon_t$，$\epsilon_t\sim\mathcal N(0,I)$ 独立。仿射高斯递推：若 $z_{t-1}\sim\mathcal N(\mu_{t-1},\Sigma_{t-1})$，则

$$z_t\sim\mathcal N\big(\sqrt{1-\beta}\,\mu_{t-1},\ (1-\beta)\Sigma_{t-1}+\beta I\big).$$

迭代展开（$\mu_0,\Sigma_0$ 为初始）：

$$\mu_t=(\sqrt{1-\beta})^{\,t}\mu_0\ \xrightarrow{t\to\infty}\ \mathbf 0\quad(\sqrt{1-\beta}<1),$$
$$\Sigma_t=(1-\beta)^t\Sigma_0+\big[1-(1-\beta)^t\big]I\ \xrightarrow{t\to\infty}\ I.$$

高斯由均值与协方差完全决定，故 $z_t\Rightarrow\mathcal N(0,I)$——它是不动点：代入 $\Sigma=I$ 得 $\Sigma_{t+1}=(1-\beta)I+\beta I=I$，不再变化。$\blacksquare$

**与 6.4.2 谱视角的对应（约 150 字）**：前向加噪是一个线性高斯马尔可夫链，其转移算子的第二特征值为 $\sqrt{1-\beta}$（协方差收缩因子 $(1-\beta)$ 的平方根）。谱视角断言误差以 $|\lambda_2|^t$ 几何衰减——这里恰好可见：均值以 $|\lambda_2|^t=(\sqrt{1-\beta})^t$ 消失，协方差误差 $(1-\beta)^t=|\lambda_2|^{2t}$ 同样受 $\lambda_2$ 支配。谱间隙 $1-\sqrt{1-\beta}$ 随 $\beta$ 增大而变大：每步加噪越狠，收敛到高斯平稳分布越快——Diffusion 调度表（$\beta_t$ 从小到大）正是在"混合速度"与"单步失真"之间做谱意义上的权衡。

## 题 12（挑战题｜对应 6.5.3、6.10 HMC）

> 实现 Gibbs 采样并与随机游走 MH 对比（同一二维相关高斯），解释"相关性越强 Gibbs 越慢"及 HMC 如何解决两者低效。

**实现骨架（已实际运行）**：

```python
import numpy as np

Sigma = np.array([[2.0, 1.2], [1.2, 1.0]])
s1, s2 = np.sqrt(Sigma[0,0]), np.sqrt(Sigma[1,1])
rho = Sigma[0,1] / (s1*s2)                       # = 0.849

# ---- Gibbs: 用条件分布轮流采样, 无拒绝 ----
# X1 | X2=x2 ~ N(rho*s1/s2*x2, s1^2*(1-rho^2));  X2 | X1 同理 (3.3.3 公式 2)
rng = np.random.default_rng(0)
x = np.zeros(2); chain = np.empty((40_000, 2))
c1, c2 = s1*np.sqrt(1-rho**2), s2*np.sqrt(1-rho**2)
for t in range(40_000):
    x[0] = rng.normal(rho*s1/s2*x[1], c1)        # 采 X1 | X2
    x[1] = rng.normal(rho*s2/s1*x[0], c2)        # 采 X2 | X1 (用刚更新的 x[0])
    chain[t] = x

# ---- 对照: 随机游走 MH (eps=1.2, 题 10 同款) ----
# 结果: Gibbs accept=1.00, tau≈6, ESS/步≈0.16;  MH accept=0.35, tau≈27, ESS/步≈0.04
```

**实际运行结果**（完整脚本运行验证）：

```
rho = 0.849
Gibbs: accept = 1.00 (无拒绝), tau = 6.1, ESS/步 = 0.1633
       sample cov ≈ [[1.98, 1.19], [1.19, 0.99]]  (理论 Sigma, 采样正确)
MH(eps=1.2): accept = 0.35, tau = 27.1, ESS/步 = 0.0369
```

在本例（$\rho=0.85$）中 Gibbs 的 ESS/步约为 MH 的 4.4 倍，且无拒绝、无步长要调。**为什么相关性越强 Gibbs 越慢**：Gibbs 的每步更新只能沿坐标轴方向移动（先横后竖），而强相关目标的概率质量集中在细长的对角"峡谷"里——沿单一坐标的条件步长只有 $O(\sqrt{1-\rho^2}\,\sigma)$，$\rho\to1$ 时趋于 0，链在峡谷内以"锯齿形随机游走"贴着脊线爬行，混合时间随 $\rho$ 急剧恶化。**HMC 如何同时解决**：HMC 用目标密度的梯度构造动能-势能动力学，提议沿等高线（势能不变的方向）做长程"飞行"，一步可跨越整个典型集——既不需要拒绝采样式的大步全局提议（免于维数灾难），也不被坐标轴束缚（沿相关方向直达），对强相关、高维目标是数量级的加速；代价是需要梯度（自动微分可用）与步长/步数调参（NUTS 自适应化）。
