## 6.1 蒙特卡洛：用随机求和逼近积分

### 6.1.1 核心思想

要算的量几乎总能写成某个分布下的期望（积分）：

$$I=\mathbb{E}_{X\sim p}[f(X)]=\int f(x)\,p(x)\,dx.$$

第 3 章大数定律给出直接方案：**从 $p$ 采 $n$ 个样本，用样本均值近似期望**：

$$\hat I_n=\frac1n\sum_{i=1}^n f(X_i),\qquad X_i\stackrel{iid}{\sim}p,\qquad \hat I_n\xrightarrow{P}I.$$

由 CLT（第 3 章定理 3.4），误差服从

$$\sqrt n(\hat I_n-I)\Rightarrow\mathcal{N}\!\left(0,\ \mathrm{Var}_p(f)\right)\ \Longrightarrow\ \hat I_n\approx I\pm\frac{\sigma_f}{\sqrt n},\qquad \sigma_f^2=\mathrm{Var}_p(f).$$

三点关键性质，全部来自第 3 章：

1. **速率与维数无关**：$1/\sqrt n$ 的误差率不随积分维数变差（对比网格求积：$d$ 维需 $O(m^d)$ 点）。这是蒙特卡洛在高维贝叶斯与物理模拟中不可替代的原因；
2. **标准误差（SE）免费获得**：用样本方差 $s_f^2$ 代入 $\sigma_f^2$，报告 $\hat I_n\pm1.96\,s_f/\sqrt n$ 即 95% 置信区间（第 5 章 5.5.1 的直接应用）；
3. **改进精度的代价指数**：误差减半需 4 倍样本——想提高精度先降 $\mathrm{Var}_p(f)$（重要性采样、控制变量等方差缩减技术），而不是盲目加样本。

**手算例**：估计 $\pi$（Buffon 投针的现代版）。取 $p=U([0,1]^2)$，$f=\mathbb{1}[x^2+y^2\le1]$，则 $I=\pi/4$，$\hat\pi=4\hat I_n$。

```python
import numpy as np
rng = np.random.default_rng(2)
n = 2_000_000
pts = rng.random((n, 2))
inside = (pts**2).sum(axis=1) <= 1.0
pi_hat = 4 * inside.mean()
se = 4 * np.sqrt(inside.mean()*(1-inside.mean())/n)   # 伯努利方差下的 SE
print(f"pi ≈ {pi_hat:.4f} ± {1.96*se:.4f}")   # 预期 3.14xx ± 0.0023
```

### 6.1.2 从"能算期望"到"能采样分布"

蒙特卡洛的两类任务：(a) 估期望（上面）；(b) **从分布 $p$ 直接采样**，供后验可视化、生成模型输出、强化学习动作选择使用。若能把目标密度 $p$ 变换到"可采样基分布"（第 2 章 2.5 节），则 (b) 有一系列通用构造——下面三节按"能用条件"从强到弱介绍。

## 6.2 逆变换法与拒绝采样

### 6.2.1 逆变换法

**定理 6.1（逆变换法）**：$U\sim U(0,1)$，$F$ 为目标 CDF（连续严格增），则 $X=F^{-1}(U)$ 服从 CDF 为 $F$ 的分布。

证明：$P(X\le x)=P(F^{-1}(U)\le x)=P(U\le F(x))=F(x)$（$F$ 严格增保证事件等价，末步用 $U$ 的均匀性）。$\blacksquare$

这就是第 2 章 2.5.2 节"概率积分变换 $F(X)\sim U(0,1)$"的逆过程。例：$F(x)=1-e^{-\lambda x}\Rightarrow x=-\frac1\lambda\ln(1-U)$——指数分布采样（与 2.5.2 的雅可比推导殊途同归）。**适用条件**：CDF 可显式求逆。高斯不满足（第 2 章练习 2.9 已讨论），离散分布把"累加 PMF 超过 $U$"即可。

### 6.2.2 拒绝采样（接受–拒绝法）

当 $p$ 的 CDF 求不出逆、但**密度可以逐点计算**时：

**设置**：找"提议分布（proposal）"$g$（容易采样，如均匀/高斯）与常数 $M$，使 $p(x)\le M\,g(x)$ 对一切 $x$（包络条件）。

**算法**：循环——(1) 从 $g$ 采 $X$；(2) 从 $U(0,1)$ 采 $U$；(3) 若 $U\le\dfrac{p(X)}{M\,g(X)}$ 接受 $X$，否则拒绝重采。

**定理 6.2**：接受样本的分布恰为 $p$，接受率为 $\dfrac{1}{M}$（设 $p,g$ 均归一）。

证明要点：接受事件下 $X$ 的密度 $\propto g(x)\cdot\frac{p(x)}{Mg(x)}=\frac{p(x)}{M}$，归一化后即 $p$；接受概率 $=\int g(x)\frac{p(x)}{Mg(x)}dx=\frac1M$。$\blacksquare$

**代价与维数灾难**：接受率 $1/M$，而包络常数 $M$ 通常随维数指数增长（$p$ 的"质量"集中体积相对 $g$ 的支撑收缩）。一维拒绝采样很好用，十维基本不可行——这一失效正是 MCMC（6.4 节）存在的理由。

### 6.2.3 代码：拒绝采样正态分布

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(4)
target = lambda x: np.exp(-x**2/2)/np.sqrt(2*np.pi)   # N(0,1) 密度
M = 1.0                                                # g=U(-4,4): M*1/8 >= p 的最小 M
# 包络检查: max p(x) = 0.399, M*g(x) = 1/8 = 0.125 —— 不够! 需要分段或换提议
# 改用 g = U(-4,4), M = 3.2 (3.2/8 = 0.4 >= 0.399, 勉强包住)
M = 3.2
n_target, accepted = 0, []
while len(accepted) < 20_000:
    x = rng.uniform(-4, 4, 4096)                       # 提议批量采样
    u = rng.random(4096)
    keep = u <= target(x) / (M / 8)                    # p(x)/(M*g(x)), g(x)=1/8
    accepted += list(x[keep])
accepted = np.array(accepted)
print(f"acceptance rate ≈ {1/M:.3f}")                  # 预期 0.313 (=1/M)
print(f"sample mean={accepted.mean():+.3f}, std={accepted.std():.3f}")
# 预期 mean≈0, std≈1.0

x = np.linspace(-4, 4, 200)
plt.hist(accepted, bins=60, density=True, alpha=0.6)
plt.plot(x, target(x), "r-"); plt.savefig("rejection_sampling.png", dpi=120)
```

观察接受率恰为 $\frac{1}{M}$、直方图贴合目标曲线。把提议换成 $g=U(-6,6)$（$M$ 需增大），验证接受率下降但结果仍正确——"提议不好只慢不错"。

## 6.3 重要性采样：换个分布算期望

### 6.3.1 方法与正确性

很多时候我们**能算** $\mathbb{E}_{q}[f(X)w(X)]$（$q$ 好采样），却难从 $p$ 直接采样，或想从一套样本估计多个 $p$ 下的期望。恒等变形（$p(x)>0\Rightarrow q(x)>0$ 的支撑条件）：

$$\mathbb{E}_p[f]=\int f(x)\frac{p(x)}{q(x)}\,q(x)dx=\mathbb{E}_q\!\left[f(X)\,\underbrace{\frac{p(X)}{q(X)}}_{\text{重要性权重 } w(X)}\right]\ \approx\ \frac1n\sum_{i=1}^n f(X_i)\,w(X_i),\qquad X_i\sim q.$$

密度未知比例版（贝叶斯常用：$p(\theta\mid D)\propto\tilde p(\theta)=p(D\mid\theta)p(\theta)$，归一化常数难算）——**自归一化重要性采样（SNIS）**：

$$\mathbb{E}_p[f]\approx\frac{\sum_i w_i f(X_i)}{\sum_i w_i},\qquad w_i=\frac{\tilde p(X_i)}{q(X_i)}.$$

**RLHF/强化学习中的直接对应**：PPO 的目标 $\mathbb{E}_{\pi_{\text{old}}}\!\left[\frac{\pi_\theta(a|s)}{\pi_{\text{old}}(a|s)}A(s,a)\right]$ 正是重要性采样——用旧策略的 rollout 样本估计新策略的期望，权重就是两个策略的概率比；比率偏离 1 太远（$\epsilon$ 裁剪）就是"权重方差爆炸"的工程防御。

### 6.3.2 方差分析：什么时候重要性采样爆炸

$\hat I$ 的方差由 $\mathrm{Var}_q[f\,w]$ 决定。若 $p$ 的尾部比 $q$ 厚（$q$ 在 $p$ 的重要区域概率质量不足），$w$ 偶尔巨大，方差爆炸甚至无穷（有效样本量趋近 1）。诊断量**有效样本量（ESS）**：

$$\mathrm{ESS}\approx\frac{\left(\sum_i w_i\right)^2}{\sum_i w_i^2}=\frac{n}{1+\mathrm{CV}(w)^2}.$$

权重变异系数（CV）大 ⇒ ESS 远小于名义样本量。**规则**：$q$ 必须覆盖 $p$（重尾方向上 $q$ 更厚），且监控 ESS/名义 $n$ 不低于某个比例（如 10%）。

### 6.3.3 代码：重要性采样及其失效演示

```python
import numpy as np

rng = np.random.default_rng(9)
f = lambda x: (np.abs(x) > 2).astype(float)   # 指示函数: |x|>2, 真值 P(|Z|>2)=0.0455
n = 100_000

# 方案 A: q = 标准正态 = 目标, 权重恒 1, 直接平均
z = rng.standard_normal(n)
print(f"direct  : {f(z).mean():.4f} (SE {f(z).std()/np.sqrt(n):.5f})")

# 方案 B: q = N(0, 2^2) 更宽 => 权重 = p/q, 尾部覆盖更好
z = rng.normal(0, 2, n)
w = np.exp(-z**2/2) / np.sqrt(2*np.pi) / (np.exp(-z**2/(2*4))/ (2*np.sqrt(2*np.pi)))
ess = w.sum()**2 / (w**2).sum()
print(f"import. : {np.mean(f(z)*w):.4f}, ESS/n = {ess/n:.2f}")

# 方案 C: q = N(0, 0.5^2) 太窄, 尾部覆盖不足 => 权重爆炸
z = rng.normal(0, 0.5, n)
w = np.exp(-z**2/2)/np.sqrt(2*np.pi) / (np.exp(-z**2/(2*0.25))/(0.5*np.sqrt(2*np.pi)))
ess = w.sum()**2 / (w**2).sum()
print(f"bad q   : {np.mean(f(z)*w):.4f}, ESS/n = {ess/n:.3f}  (大量样本无用)")
# 预期: direct≈0.0455; B 稳定; C 的 ESS/n 极小、估计大幅波动
```

真值 $P(\lvert Z\rvert>2)=0.0455$（$2\Phi(-2)$）。方案 C 印证 6.3.2：**重要性采样选错 $q$ 不是慢，是错**。

## 6.4 马尔可夫链与平稳分布

### 6.4.1 马尔可夫性

**定义 6.1（马尔可夫链，Markov chain）**：随机序列 $\{X_t\}$ 满足马尔可夫性（无记忆）：

$$P(X_{t+1}\mid X_t,X_{t-1},\dots,X_0)=P(X_{t+1}\mid X_t).$$

有限状态情形用**转移矩阵** $P=(P_{ij})$，$P_{ij}=P(X_{t+1}=j\mid X_t=i)$，行和为 1（随机矩阵）。连续状态（如 MCMC 的参数空间）用转移核（transition kernel）$T(x'\mid x)$——除"矩阵→核"外全部理论平行。

### 6.4.2 平稳分布：不变测度

**定义 6.2（平稳分布）**：分布 $\pi$ 满足 $\pi^\top P=\pi$（连续版 $\pi(x')=\int T(x'\mid x)\pi(x)dx$，即 detailed balance 的解之一）。

**定义 6.3（细致平衡，detailed balance）**：$\pi_i P_{ij}=\pi_j P_{ji}$ 对一切 $i,j$。它蕴含平稳性（两边对 $i$ 求和即得 $\pi^\top P=\pi$，请验证），是 MCMC 构造的核心——**只要设计出满足目标分布 $\pi$ 细致平衡的转移核，$\pi$ 就是其平稳分布**。

**各态历经（ergodicity）**：若链**不可约**（任意状态可达任意状态）且**非周期**，则链是遍历的：$\lim_{t\to\infty}P(X_t=j)=\pi_j$ 与初始分布无关，且时间平均收敛到空间平均 $\frac1T\sum_{t} f(X_t)\to\mathbb{E}_\pi[f]$（遍历定理，LLN 的马尔可夫版）。

**谱视角（衔接《线性代数》第 4 章）**：$\pi^\top P=\pi$ 说明 $1$ 是 $P^\top$ 的特征值、$\pi$ 是对应特征向量。随机矩阵的谱半径 $\le1$；遍历条件下特征值 1 单重，其余 $|\lambda|<1$，于是误差 $\lvert P^t(x,\cdot)-\pi\rvert$ 以速率 $\lvert\lambda_2\rvert^t$（第二特征值）几何衰减——$\lvert\lambda_2\rvert$ 越接近 1 收敛越慢（"混合慢"）。**谱间隙 $1-\lvert\lambda_2\rvert$ 是马尔可夫链收敛速度的完整刻画**——这是特征值理论最漂亮的应用之一。Diffusion 模型的前向加噪过程正是一个马尔可夫链，其设计保证 $t\to\infty$ 时收敛到易于采样的高斯平稳分布（反向过程学的是"逆转移核"）。

## 6.5 示例与案例：MCMC——Metropolis–Hastings 从零实现

### 6.5.1 算法构造

**目标**：从只知道"未归一化密度" $\tilde p(x)$ 的分布采样（贝叶斯后验正是如此：$\tilde p(\theta)=p(D\mid\theta)p(\theta)$，常数 $p(D)$ 算不出）。

**Metropolis–Hastings（MH）**：选一个易采样的提议核 $q(x'\mid x)$（如当前点的随机游走 $x'=x+\epsilon Z$），构造接受概率

$$\alpha(x\to x')=\min\!\left(1,\ \frac{\tilde p(x')\,q(x\mid x')}{\tilde p(x)\,q(x'\mid x)}\right).$$

**循环**：在 $x$ 处按 $q$ 提议 $x'$，以 $\alpha$ 接受（接受则移动，否则原地不动，**原地也算一步**）。

**为什么正确（证明骨架）**：对称提议（$q(x'|x)=q(x|x')$，随机游走即如此）时比率退化为 $\min(1,\tilde p(x')/\tilde p(x))$。任取两点 $x,x'$，从 $x$ 到 $x'$ 的"概率流"是 $\tilde p(x)q(x'|x)\alpha(x\to x')$，反向流 $\tilde p(x')q(x'|x)\alpha(x'\to x)$，代入场$\alpha$ 的定义可验证两流相等（分子分母交叉相乘后同式）——**细致平衡成立，$\pi\propto\tilde p$ 是平稳分布**；遍历性由提议核正定性保证。注意整个证明只用密度比 $\tilde p(x')/\tilde p(x)$——**归一化常数自动消掉**，这正是 MH 能驾驭贝叶斯后验的原因。

**调参直觉**：随机游走步长 $\epsilon$ 太小 → 每步都接受但移动极慢（高自相关）；太大 → 拒绝率高、链长时间不动。经验法则：调 $\epsilon$ 使接受率约 0.2–0.5（一维理想约 0.44，高维渐近 0.234，Roberts et al. 理论结果）。

### 6.5.2 收敛诊断

1. **Trace plot（轨迹图）**：画 $\log p$ 或各维取值随迭代的变化；健康的链像"毛毛虫"（快速遗忘初始、平稳波动），病态链有漂移或长平台。
2. **burn-in（预烧期）**：丢弃前 $B$ 步（从初始点走到平稳区域的过渡段）。
3. **自相关函数（ACF）**：$\rho_k=\mathrm{Corr}(X_t,X_{t+k})$。MCMC 样本**不独立**（第 3 章误区 5：$\mathrm{Var}(\bar X)\ne\sigma^2/n$），有效样本量
$$\mathrm{ESS}\approx\frac{n}{1+2\sum_{k\ge1}\rho_k}\qquad(\text{截断在 ACF 衰减到噪声处}).$$
4. **多链初始化（Gelman–Rubin $\hat R$）**：从相差很远的多个起点各跑一条链，比较链间方差与链内方差，$\hat R\approx1$（经验上 $\hat R<1.01$）表明混合充分。工程实践：**永远跑多链**。

### 6.5.3 从零实现：采样二维高斯并完整诊断

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(10)

# ---- 目标: 未归一化的二维高斯 (相关系数 0.6, 显著非对角) ----
Sigma = np.array([[2.0, 1.2], [1.2, 1.0]])
Sig_inv = np.linalg.inv(Sigma)
log_tilde_p = lambda x: -0.5 * x @ Sig_inv @ x   # 丢弃常数 (检验 MH 是否免疫)

def mh_sample(x0, n_steps, eps=1.2):
    x, acc = np.array(x0, float), 0
    chain = np.empty((n_steps, 2))
    for t in range(n_steps):
        prop = x + eps * rng.standard_normal(2)      # 对称随机游走提议
        # 接受率只用密度比, 无需归一化常数
        if np.log(rng.random()) < log_tilde_p(prop) - log_tilde_p(x):
            x = prop; acc += 1
        chain[t] = x
    return chain, acc / n_steps

chain, acc_rate = mh_sample(x0=[5.0, -5.0], n_steps=40_000, eps=1.2)
burn = 5_000
samples = chain[burn:]
print(f"acceptance rate = {acc_rate:.2f} (目标 0.2~0.5)")   # 预期 ≈ 0.3
print(f"sample mean = {samples.mean(axis=0).round(2)}")      # 预期 [0, 0]
print(f"sample cov  =\n{np.cov(samples.T).round(3)}")        # 预期 ≈ Sigma

# ---- 诊断 1: trace plot ----
fig, axes = plt.subplots(3, 1, figsize=(10, 7))
axes[0].plot(chain[:, 0], lw=0.3); axes[0].set_title("trace: x1 (含 burn-in)")
axes[1].plot(chain[:, 1], lw=0.3, color="orange"); axes[1].set_title("trace: x2")
# ---- 诊断 2: 自相关函数 (分批估计) ----
def acf(x, max_lag=60):
    x = x - x.mean()
    return np.array([np.corrcoef(x[:-k or None], x[k:])[0, 1] if k else 1.0
                     for k in range(max_lag)])
lags = np.arange(60)
axes[2].bar(lags, acf(samples[:, 0]), width=0.5); axes[2].set_title("ACF: x1")
plt.tight_layout(); plt.savefig("mh_diagnostics.png", dpi=120)

# ---- 诊断 3: 有效样本量 ----
r = acf(samples[:, 0], 100)
tau = 1 + 2 * r[1:(np.abs(r) < 0.05).argmax()].sum()   # 截断累积自相关
print(f"ESS ≈ {len(samples)/tau:.0f} (out of {len(samples)})")  # 预期 ~3-6 千

# ---- 诊断 4: 散点 vs 理论椭圆 ----
plt.figure(figsize=(5, 5))
plt.scatter(samples[::20, 0], samples[::20, 1], s=4, alpha=0.4)
t = np.linspace(0, 2*np.pi, 200)
L, V = np.linalg.eigh(Sigma)          # 《线性代数》第4章: 特征分解
for c in (1, 2, 3):
    ellipse = (2*c*np.sqrt(L[0]) * np.cos(t)[:, None] * V[:, 0]   # 主轴方向 v1
```

## 6.6 关键公式速查

| 公式/算法 | 表达式 | 适用条件 |
|---|---|---|
| 蒙特卡洛估计 | $\hat I_n=\frac1n\sum f(X_i)$，$X_i\sim p$ | 样本独立、$\mathrm{Var}_p(f)<\infty$ |
| MC 标准误差 | $\mathrm{SE}=s_f/\sqrt n$（95% CI：$\pm1.96\,\mathrm{SE}$） | 同上（CLT） |
| 逆变换法 | $X=F^{-1}(U)$，$U\sim U(0,1)$ | CDF 连续严格增可求逆 |
| 拒绝采样 | 接受当 $U\le\frac{p(x)}{Mg(x)}$；接受率 $\frac1M$ | 包络条件 $p\le Mg$ |
| 重要性采样 | $\mathbb{E}_p[f]=\mathbb{E}_q[f\,w]$，$w=\frac pq$ | 支撑包含：$p>0\Rightarrow q>0$ |
| 自归一化 IS | $\frac{\sum_i w_if(x_i)}{\sum_i w_i}$，$w_i=\frac{\tilde p}{q}(x_i)$ | 只有未归一化密度时 |
| ESS | $\mathrm{ESS}=n/(1+\mathrm{CV}^2(w))$（IS）；$n/(1+2\sum\rho_k)$（MCMC） | 权重/链自相关诊断 |
| 平稳分布 | $\pi^\top P=\pi$；充分条件：细致平衡 $\pi_iP_{ij}=\pi_jP_{ji}$ | 遍历（不可约+非周期）⇒ 收敛到 $\pi$ |
| MH 接受率 | $\alpha=\min\left(1,\frac{\tilde p(x')q(x|x')}{\tilde p(x)q(x'|x)}\right)$ | 任意提议核；对称提议时简化 |
| 谱收敛速率 | 误差 $\sim\lvert\lambda_2\rvert^t$ | 遍历有限链 |

## 6.7 常见误区与陷阱

1. **把 $1/\sqrt n$ 用在不独立样本上**。MCMC 链强自相关，名义 4 万步可能 ESS 只有几千；报置信区间必须用 ESS 而非 $n$（第 3 章误区 5 的 MCMC 版）。
2. **burn-in 之外忘掉链起点偏差**。多链 $\hat R$ 检查不是可选项：单链 trace 看起来平稳也可能只是没走到另一峰（多峰后验的经典灾难）。
3. **拒绝采样不做包络检查**。$M$ 偏小（包络被穿透）时样本分布**系统性错误**且无报错——实现后必须用直方图对照目标密度验收。
4. **重要性采样 $q$ 尾部不够厚**。权重爆炸、ESS 崩塌（6.3.3 方案 C）；RLHF 中对应"新旧策略差异过大导致训练崩溃"，PPO 的 clip 正是补丁。
5. **跳步自相关**（thinning）被当作提效手段。thinning 只丢样本不增信息，现代实践是保留全部样本、报告 ESS；只有存储受限时才跳步。
6. **MH 用于高维直接翻车**。随机游走 MH 的混合时间随维数急剧恶化（接受率被迫随 $d^{-1/3}$ 调步长）；高维需 HMC/NUTS（见 6.10 进阶方向）。

## 6.10 进阶方向

- **Hamiltonian Monte Carlo（HMC）**：借物理动能-势能模拟提出远距离提议，把随机游走的扩散式探索变成定向飞行，高维效率提升数量级；需要目标密度的梯度（贝叶斯神经网络的自动微分直接可用）。
- **序贯蒙特卡洛（SMC/粒子滤波）**：重要性采样 + 重采样的时序版，处理在线后验与隐状态模型；强化学习的粒子式状态估计。
- **变分推断 vs MCMC 的取舍**：MCMC 渐近精确但慢，变分快但近似有偏——贝叶斯深度学习里两者组合（如变分初始化 + MCMC 精修）是活跃方向。
- **方差缩减技术**：控制变量（control variates）、对偶采样、分层采样、Rao–Blackwellization；蒙特卡洛梯度（REINFORCE 与 pathwise gradient）的方差比较是 VAE 设计的核心问题。
