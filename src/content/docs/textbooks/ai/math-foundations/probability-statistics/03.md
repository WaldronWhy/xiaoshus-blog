# 第 3 章 多元分布与矩——高维世界的规律

> **本章定位**：概率论部分的顶点。真实数据从来不是一维的：一个样本是向量，一个模型的参数是上万维向量。本章把第 2 章的单变量理论升级到向量/矩阵语言（协方差矩阵、多元高斯），并给出概率论的两条极限定律——大数定律与中心极限定理——它们分别是"为什么样本均值可用"与"为什么高斯无处不在"的数学根据。Jensen 不等式则将在《深度学习》中被直接用于推导 VAE 的证据下界。前置：第 2 章、《线性代数》第 3–4 章（正定二次型、特征分解）。

## 3.0 本章学习目标

学完本章，你能够：

1. 从联合分布推导边缘分布与条件分布，并用条件期望做"分块平均"计算；
2. 用协方差矩阵统一描述多元分布的二阶结构，说明它与线性代数中正定二次型、特征分解的对应；
3. 写出多元高斯密度，解释协方差矩阵特征分解 $\Sigma=Q\Lambda Q^\top$ 如何决定等高线椭圆的主轴方向与长度；
4. 用矩母函数识别分布、证明高斯的线性变换封闭性与独立高斯和的封闭性；

6. 陈述 Jensen 不等式及其等号条件，并用它推导 $\mathrm{Var}(X)\ge0$ 与 ELBO 的雏形。

## 3.1 联合、边缘与条件分布

### 3.1.1 联合分布

**定义 3.1（联合 CDF）**：$F(x,y)=P(X\le x,\,Y\le y)$。离散情形用联合 PMF $p(x,y)=P(X=x,Y=y)$；连续情形用联合 PDF $f$，满足

$$F(x,y)=\int_{-\infty}^{x}\int_{-\infty}^{y}f(u,v)\,dv\,du,\qquad \iint_{\mathbb{R}^2}f(u,v)\,du\,dv=1.$$

几何图像：把第 2 章"密度=单位长度概率"推广为"密度=单位面积概率"，联合密度是 $\mathbb{R}^2$ 上体积为 1 的一张曲面——这正是《高等数学》第 6 章二重积分的标准应用场景。

### 3.1.2 边缘分布：对另一变量积分

$$p_X(x)=\sum_y p(x,y)\ \ \text{（离散）};\qquad f_X(x)=\int_{-\infty}^{+\infty}f(x,y)\,dy\ \ \text{（连续）}.$$

语义：边缘化（marginalization）= "忽略 $Y$，把它的所有取值按概率加权求和/积分"。这与第 1 章全概率公式是同一件事的连续版；《机器学习》中对隐变量 $z$ 求和 $p(x)=\sum_z p(x,z)$（混合模型）、对噪声积分，都是边缘化。**注意**：知道边缘推不出联合——联合比边缘多出"耦合方式"的信息（相关结构），这是 copula 方法（第 2 章进阶方向）存在的原因。

### 3.1.3 条件分布：降维后的分布

$$p(y\mid x)=\frac{p(x,y)}{p_X(x)};\qquad f(y\mid x)=\frac{f(x,y)}{f_X(x)}.$$

语义：固定 $X=x$ 后 $Y$ 的分布——"切一片、重新归一化"。**监督学习的形式化定义就此出现**：学习一个从输入到输出的映射，就是估计条件分布 $p(y\mid x)$ 或其期望 $\mathbb{E}[Y\mid X=x]$。分类器输出 softmax 概率向量是离散 $p(y\mid x)$；回归模型输出的则是条件期望的估计。

### 3.1.4 条件期望与全期望公式

条件期望 $\mathbb{E}[Y\mid X]$ 是 $X$ 的函数（每个 $x$ 对应一个数）。两个重要公式：

- **塔公式（law of total expectation）**：$\mathbb{E}[Y]=\mathbb{E}\big[\mathbb{E}[Y\mid X]\big]$。连续版：$\mathbb{E}[Y]=\iint y\,f(x,y)\,dx\,dy=\int\left(\int y f(y\mid x)dy\right)f_X(x)dx$。
- **全方差公式**：$\mathrm{Var}(Y)=\mathbb{E}\big[\mathrm{Var}(Y\mid X)\big]+\mathrm{Var}\big(\mathbb{E}[Y\mid X]\big)$。

全方差公式的语义：总方差 = 组内平均方差 + 组间方差。《机器学习》中 bagging 的方差分解、混合模型的过离散现象，都可用它精确解释。

## 3.2 协方差与相关系数：把线性代数请进来

### 3.2.1 协方差与相关系数

**定义 3.2（协方差，covariance）**：

$$\mathrm{Cov}(X,Y)=\mathbb{E}\big[(X-\mathbb{E}X)(Y-\mathbb{E}Y)\big]=\mathbb{E}[XY]-\mathbb{E}[X]\mathbb{E}[Y].$$

**定义 3.3（相关系数，correlation coefficient）**：$\rho(X,Y)=\dfrac{\mathrm{Cov}(X,Y)}{\sqrt{\mathrm{Var}(X)\mathrm{Var}(Y)}}\in[-1,1]$（界由 Cauchy–Schwarz 不等式保证）。

$\rho=\pm1$ 当且仅当 $Y$ 是 $X$ 的线性函数（几乎必然）。**核心警示：$\rho=0$（不相关）$\ne$ 独立**——独立性蕴含不相关，反之不成立（反例见练习 3.4）。相关系数只捕捉**线性**依赖；$Y=X^2$（$X$ 对称分布）时 $\rho=0$ 但强依赖。

### 3.2.2 协方差矩阵：多元分布的"二等公民身份证"

**定义 3.4**：随机向量 $\mathbf{X}=(X_1,\dots,X_d)^\top$ 的协方差矩阵

$$\Sigma=\mathbb{E}\big[(\mathbf{X}-\boldsymbol{\mu})(\mathbf{X}-\boldsymbol{\mu})^\top\big]\in\mathbb{R}^{d\times d},\qquad \Sigma_{ij}=\mathrm{Cov}(X_i,X_j).$$

性质（每条都能对应到一个线代结论）：

1. **对称**：$\Sigma^\top=\Sigma$（《线性代数》第 4 章：实对称矩阵必可正交对角化）；
2. **半正定**：对任意 $\mathbf{v}$，$\mathbf{v}^\top\Sigma\mathbf{v}=\mathrm{Var}(\mathbf{v}^\top\mathbf{X})\ge0$（二次型视角）；各分量方差独立变化时严格正定；
3. **谱分解** $\Sigma=Q\Lambda Q^\top$，$Q$ 正交、$\lambda_i\ge0$——特征向量为"波动主方向"，特征值为该方向方差；
4. 分量两两独立 $\Rightarrow$ $\Sigma$ 对角；$\Sigma$ 对角仅说明不相关，不能反推独立。

性质 1、2 你在《线性代数》第 3–4 章已经见过其确定性版本（实对称矩阵特征值全实、正定二次型），这里只是给矩阵装上了概率语义：**协方差矩阵就是"方向化的方差"**。

方差的双线性展开（第 5 章最小二乘与第 6 章蒙特卡洛误差分析都用）：

$$\mathrm{Var}(\mathbf{a}^\top\mathbf{X})=\mathbf{a}^\top\Sigma\,\mathbf{a}.$$

## 3.3 多元高斯分布：几何、分解与封闭性

### 3.3.1 定义与密度

**定义 3.5（多元高斯）**：$\mathbf{X}\sim\mathcal{N}(\boldsymbol{\mu},\Sigma)$，密度

$$f(\mathbf{x})=\frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}}\exp\!\left(-\frac12(\mathbf{x}-\boldsymbol{\mu})^\top\Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu})\right),$$

其中 $|\Sigma|$ 为行列式，指数部分是《线性代数》第 3 章的**正定二次型**。$\Sigma=I$ 且 $\boldsymbol\mu=\mathbf{0}$ 时为标准多元高斯，密度等值线是单位球面。

### 3.3.2 几何意义：等高线椭圆由谱分解完全决定

对指数部分的等值线

$$(\mathbf{x}-\boldsymbol{\mu})^\top\Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu})=c^2,$$

代入 $\Sigma=Q\Lambda Q^\top$（$Q=[\mathbf{q}_1,\dots,\mathbf{q}_d]$ 正交），令 $\mathbf{z}=Q^\top(\mathbf{x}-\boldsymbol{\mu})$，得

$$\sum_{i=1}^d \frac{z_i^2}{\lambda_i}=c^2.$$

这是主轴沿 $\mathbf{q}_i$、半轴长 $c\sqrt{\lambda_i}$ 的**椭球**。结论：**协方差矩阵的特征向量给出概率云的朝向，特征值的平方根给出各方向的伸展尺度**。对角 $\Sigma$ = 椭圆与坐标轴对齐（特征间不相关）；相关（非对角元素非零）= 椭圆倾斜。这个图像是《机器学习》PCA（主成分分析）的统计基础：数据的主方差方向 = 经验协方差矩阵的主特征向量。

采样生成也由分解给出：若 $\mathbf{Z}\sim\mathcal{N}(\mathbf{0},I)$，则

$$\mathbf{X}=\boldsymbol{\mu}+Q\Lambda^{1/2}\mathbf{Z}\ \sim\ \mathcal{N}(\boldsymbol{\mu},\Sigma),$$

（依据：仿射变换下的封闭性，3.3.4 节证明）。语义：**标准球面高斯 → 沿特征方向拉伸 $\sqrt{\lambda_i}$ 倍 → 旋转到位 → 平移到 $\boldsymbol\mu$**。第 99 章项目一将让你实现这条链。

### 3.3.3 边缘与条件：多元高斯的三个漂亮闭式

设 $\mathbf{X}\sim\mathcal{N}(\boldsymbol{\mu},\Sigma)$，分块 $\mathbf{X}=(\mathbf{X}_a,\mathbf{X}_b)$，$\Sigma$ 相应分块 $\begin{pmatrix}\Sigma_{aa}&\Sigma_{ab}\\\Sigma_{ba}&\Sigma_{bb}\end{pmatrix}$：

1. **边缘仍是高斯**：$\mathbf{X}_a\sim\mathcal{N}(\boldsymbol{\mu}_a,\Sigma_{aa})$；
2. **条件仍是高斯**：$\mathbf{X}_a\mid\mathbf{X}_b=\mathbf{x}_b\sim\mathcal{N}(\boldsymbol{\mu}_a+\Sigma_{ab}\Sigma_{bb}^{-1}(\mathbf{x}_b-\boldsymbol{\mu}_b),\ \Sigma_{aa}-\Sigma_{ab}\Sigma_{bb}^{-1}\Sigma_{ba})$；
3. **多元高斯中"不相关 = 独立"**（一般分布不成立的反例在此特例中成立）。

公式 2 的均值项 $\Sigma_{ab}\Sigma_{bb}^{-1}(\mathbf{x}_b-\boldsymbol{\mu}_b)$ 是线性回归系数的形式——**高斯条件期望就是线性回归**，这是《机器学习》线性回归与高斯过程回归（GPR）共享的内核：高斯过程把"无限维的高斯条件分布"用作函数上的先验。

### 3.3.4 封闭性与线性变换（证明，一步不跳）

**定理 3.1**：若 $\mathbf{X}\sim\mathcal{N}(\boldsymbol{\mu},\Sigma)$，$\mathbf{Y}=A\mathbf{X}+\mathbf{b}$（$A\in\mathbb{R}^{m\times d}$），则 $\mathbf{Y}\sim\mathcal{N}(A\boldsymbol{\mu}+\mathbf{b},\ A\Sigma A^\top)$。

证明：对任意 $\mathbf{a}\in\mathbb{R}^m$，标量 $S=\mathbf{a}^\top\mathbf{Y}=(A^\top\mathbf{a})^\top\mathbf{X}+\mathbf{a}^\top\mathbf{b}$ 是一元高斯（一元高斯的线性组合仍为一元高斯，可由卷积或 MGF 证明，见 3.4.2）。其均值 $\mathbf{a}^\top(A\boldsymbol{\mu}+\mathbf{b})$、方差 $\mathbf{a}^\top A\Sigma A^\top\mathbf{a}$。而多元分布由"一切线性投影 $\mathbf{a}^\top\mathbf{Y}$ 的边缘分布"唯一决定（Cramér–Wold 定理，可当黑盒使用），故 $\mathbf{Y}$ 的分布即均值 $A\boldsymbol\mu+\mathbf{b}$、协方差 $A\Sigma A^\top$ 的多元高斯。$\blacksquare$

推论（独立高斯之和）：$X\sim\mathcal{N}(\mu_1,\sigma_1^2)$，$Y\sim\mathcal{N}(\mu_2,\sigma_2^2)$ 独立，则 $X+Y\sim\mathcal{N}(\mu_1+\mu_2,\ \sigma_1^2+\sigma_2^2)$——取 $A=[1\ 1]$ 即得。

## 3.4 矩与矩母函数

### 3.4.1 矩唯一决定分布（温和条件下）

第 2 章 2.3.3 定义了各阶矩。**矩问题（moment problem）**：什么条件下分布由矩列 $\{m_k\}$ 唯一决定？充分条件之一：矩母函数在某开区间内有限。反例（对数正态分布）：各阶矩全部有限但存在其他分布与之共享全部矩——提醒"矩不全等于分布"。

### 3.4.2 矩母函数：把分布编码成一个函数

**定义 3.6（矩母函数，MGF，moment generating function）**：

$$M_X(t)=\mathbb{E}\big[e^{tX}\big].$$

若 $M_X(t)$ 在 $t=0$ 的某邻域内有限，则

$$m_k=\mathbb{E}[X^k]=M_X^{(k)}(0)\qquad(\text{在积分号下求 }k\text{ 阶导}).$$

验证：$M_X(t)=\mathbb{E}[\sum_{k\ge0}\frac{(tX)^k}{k!}]=\sum_k \frac{t^k}{k!}\mathbb{E}[X^k]$（Taylor 展开逐项求期望，需一致收敛性保证交换次序）——MGF 是矩的"指数生成函数"，系数里藏着全部矩。

**MGF 的杀手锏：处理独立和**。$X,Y$ 独立时

$$M_{X+Y}(t)=\mathbb{E}[e^{t(X+Y)}]=\mathbb{E}[e^{tX}]\,\mathbb{E}[e^{tY}]=M_X(t)M_Y(t).$$

**例（高斯的 MGF）**：$X\sim\mathcal{N}(\mu,\sigma^2)$，配方（completing the square，与第 3.3 节二次型同款技巧）得

$$M_X(t)=\exp\!\left(\mu t+\tfrac12\sigma^2t^2\right).$$

于是独立高斯和 $S=X+Y$ 的 MGF：$\exp((\mu_1+\mu_2)t+\frac12(\sigma_1^2+\sigma_2^2)t^2)$——恰是 $\mathcal{N}(\mu_1+\mu_2,\sigma_1^2+\sigma_2^2)$ 的 MGF。由"MGF 相同（邻域内）⇒ 分布相同"得和的分布。这也严格补全了定理 3.1 证明中引用的一元事实。

**常见分布 MGF 速查**：$\text{Bern}(p)$: $1-p+pe^t$；$\text{Bin}(n,p)$: $(1-p+pe^t)^n$；$\text{Pois}(\lambda)$: $\exp(\lambda(e^t-1))$；$\text{Exp}(\lambda)$: $\frac{\lambda}{\lambda-t}$（$t<\lambda$）；$U(a,b)$: $\frac{e^{tb}-e^{ta}}{t(b-a)}$。

### 3.4.3 标准化随机变量

$Z=\frac{X-\mu}{\sigma}$ 满足 $\mathbb{E}[Z]=0$、$\mathrm{Var}(Z)=1$（由第 2 章 2.6 表的仿射公式）。CLT 的陈述对象就是标准化和。

## 3.5 Jensen 不等式：凸性 × 期望

**定理 3.2（Jensen 不等式）**：$g$ 为凸函数时，$\mathbb{E}[g(X)]\ge g(\mathbb{E}[X])$；$g$ 严格凸时等号成立当且仅当 $X$ 几乎必然为常数。

证明（用凸性的切线定义，一步不跳）：凸函数在任意点 $a$ 处存在支撑线 $g(x)\ge g(a)+g'(a)(x-a)$（下凸 ⇒ 图像在切线上方）。取 $a=\mathbb{E}[X]$，两边取期望：$\mathbb{E}[g(X)]\ge g(\mathbb{E}X)+g'(\mathbb{E}X)\underbrace{(\mathbb{E}[X]-\mathbb{E}[X])}_{=0}=g(\mathbb{E}X)$。$\blacksquare$

三个立刻的应用：

1. 取 $g(x)=x^2$（凸）：$\mathbb{E}[X^2]\ge(\mathbb{E}X)^2$，即 $\mathrm{Var}(X)\ge0$——方差非负是 Jensen 的特例；
2. 取 $g(x)=-\ln x$（凸）：$\mathbb{E}[-\ln X]\ge-\ln\mathbb{E}[X]$，即 **AM–GM 不等式**的概率形式；
3. **变分推断的种子**：对任意分布 $q$，$\mathbb{E}_q[\ln p(x)] \le \ln\mathbb{E}_q[p(x)]$。《深度学习》VAE 的证据下界（ELBO）= 把 $p(x)=\mathbb{E}_{q(z|x)}\!\left[\frac{p(x,z)}{q(z|x)}\right]$ 代入 Jensen（$\ln$ 凹，方向翻转）得到的下界。强烈建议现在就动手推一遍 $p(x)\ge\mathbb{E}_q\left[\ln\frac{p(x,z)}{q(z|x)}\right]$ 的三行推导，《深度学习》VAE 一节将原样引用。

（注意 Jensen 中 $g$ 的凹凸方向：$\ln$ 是凹函数，不等号反向；本节为陈述统一取凸情形。）

## 3.6 两条极限定律：大数定律与中心极限定理

### 3.6.1 问题设定

设 $X_1,\dots,X_n$ i.i.d.，均值为 $\mu$、方差 $\sigma^2<\infty$。样本均值

$$\bar{X}_n=\frac{1}{n}\sum_{i=1}^n X_i.$$

由线性性 $\mathbb{E}[\bar X_n]=\mu$；由独立方差可加（3.2.2 性质 4 + 第 2 章 2.3.2）

$$\mathrm{Var}(\bar X_n)=\frac{\sigma^2}{n}.$$

均值是"越来越准的估计"。两条定律把"越来越准"精确化：LLN 说它**收敛到 $\mu$**，CLT 说它的**涨落形状**是高斯。

### 3.6.2 大数定律（LLN）

**定理 3.3（弱大数定律）**：对任意 $\varepsilon>0$，

$$P\big(|\bar X_n-\mu|>\varepsilon\big)\ \longrightarrow\ 0\quad(n\to\infty).$$

证明思路（Chebyshev 版，需要的不等式见练习 3.6）：$P(|\bar X_n-\mu|>\varepsilon)\le\frac{\mathrm{Var}(\bar X_n)}{\varepsilon^2}=\frac{\sigma^2}{n\varepsilon^2}\to0$。$\blacksquare$

语义：**频率稳定于概率**（第 1 章公理的经验合法性来源），**样本均值稳定于期望**（一切"用平均估计期望"的方法——包括第 6 章蒙特卡洛——的正确性保证）。更强的版本（Kolmogorov 强大数定律）把收敛升级为几乎必然收敛（$\bar X_n\to\mu$ a.s.），证明超出本章，见拓展阅读。

### 3.6.3 中心极限定理（CLT）

**定理 3.4（中心极限定理，central limit theorem）**：在上述设定下，对标准化和

$$Z_n=\frac{\bar X_n-\mu}{\sigma/\sqrt n}=\frac{\sum_{i=1}^n(X_i-\mu)}{\sigma\sqrt n},$$

有：对一切 $x$，$P(Z_n\le x)\to\Phi(x)$（标准正态 CDF），记作 $Z_n\Rightarrow\mathcal{N}(0,1)$（依分布收敛）。

工程形式：$\bar X_n\ \approx\ \mathcal{N}\!\left(\mu,\ \sigma^2/n\right)$（$n$ 大时）。注意三件事：

1. CLT 对**任何**方差有限的母分布成立——不论 $X$ 原本多歪多重尾，其均值（涨落部分）在极限中总是高斯。这是"高斯无处不在"的第一原理；
2. 收敛速率 $O(n^{-1/2})$：误差按 $1/\sqrt n$ 缩减，这是第 6 章蒙特卡洛误差率的理论来源（多采 100 倍样本只换来 10 倍精度）；
3. 条件是 $\sigma^2<\infty$：重尾（如方差无穷的幂律尾）样本均值不服从 CLT——第 2 章"常见误区"2 的延伸。

证明工具是 MGF：$M_{Z_n}(t)=\left[M_X\!\left(\frac{t}{\sigma\sqrt n}\right)e^{-\mu t/(\sigma\sqrt n)}\right]^n$，Taylor 展开取极限得 $e^{t^2/2}$（完整三行推导作为本章练习的挑战题，见 3.13 节第 11 题）。矩母函数在此完成了它的历史使命——这正是 3.4 节存在的理由。

### 3.6.4 模拟验证 CLT（代码）

三个母分布（指数、均匀、二项）的样本均值，在 $n$ 增大后都坍缩到同一钟形——亲手"看见"不变性：

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(7)
mu, sigma = 1.0, 1.0          # 用 Exp(1): 均值 1, 方差 1, 右偏明显
n_list, n_rep = [1, 4, 30, 200], 100_000

fig, axes = plt.subplots(1, 4, figsize=(16, 3.5), sharex=True)
z_grid = np.linspace(-4, 4, 300)
for ax, n in zip(axes, n_list):
    # 每行: 从母分布抽 n 个求均值, 重复 n_rep 次
    x = rng.exponential(scale=1.0, size=(n_rep, n))    # Exp(1)
    z = (x.mean(axis=1) - mu) / (sigma / np.sqrt(n))   # 标准化样本均值
    ax.hist(z, bins=80, density=True, alpha=0.6, label=f"n={n}")
    phi = np.exp(-z_grid**2/2)/np.sqrt(2*np.pi)        # 标准正态密度
    ax.plot(z_grid, phi, "r-", lw=2, label="N(0,1)")
    ax.set_title(f"n={n}"); ax.legend()
plt.tight_layout(); plt.savefig("clt_demo.png", dpi=120)

# 数值检验: n=200 时前四阶标准化矩逼近正态
x = rng.exponential(1.0, size=(100_000, 200))
z = (x.mean(axis=1) - 1.0) / (1.0 / np.sqrt(200))
print(f"mean={z.mean():+.3f}, std={z.std():.3f}")          # 预期 ≈ 0, ≈ 1
print(f"skew={((z**3).mean()):+.3f}")                      # 预期 ≈ 0 (指数偏度 2 在 n=200 时衰减为 2/sqrt(200)≈0.14)
print(f"excess kurt={((z**4).mean())-3:+.3f}")             # 预期 ≈ 0
```

观察要点：$n=1$ 时直方图是母分布的形状（右偏）；$n=4$ 已明显对称化；$n=30$ 起红色曲线几乎压住直方图——"统计学里 $n\ge30$ 用正态近似"的经验规则即源于此。把 `rng.exponential` 换成 `rng.uniform(-1,1)` 或 `rng.binomial(1,0.3)` 重跑，结论不变——这就是"中心"极限定理中"中心"的含义：极限只由方差与均值决定，与母分布细节无关。

## 3.7 关键公式速查

| 公式 | 表达式 | 适用条件 |
|---|---|---|
| 边缘化 | $f_X(x)=\int f(x,y)dy$ | 联合密度可积 |
| 条件分布 | $f(y\mid x)=f(x,y)/f_X(x)$ | $f_X(x)>0$ |
| 塔公式 | $\mathbb{E}[Y]=\mathbb{E}[\mathbb{E}[Y\mid X]]$ | 期望存在 |
| 全方差公式 | $\mathrm{Var}(Y)=\mathbb{E}[\mathrm{Var}(Y\mid X)]+\mathrm{Var}(\mathbb{E}[Y\mid X])$ | 二阶矩存在 |
| 协方差矩阵 | $\Sigma=\mathbb{E}[(\mathbf{X}-\boldsymbol\mu)(\mathbf{X}-\boldsymbol\mu)^\top]$ | 二阶矩存在；对称半正定 |
| 二次型方差 | $\mathrm{Var}(\mathbf{a}^\top\mathbf{X})=\mathbf{a}^\top\Sigma\mathbf{a}$ | 任意 |
| 多元高斯密度 | $\frac{1}{(2\pi)^{d/2}\lvert\Sigma\rvert^{1/2}}e^{-\frac12(\mathbf{x}-\boldsymbol\mu)^\top\Sigma^{-1}(\mathbf{x}-\boldsymbol\mu)}$ | $\Sigma\succ0$ |
| 高斯仿射变换 | $A\mathbf{X}+\mathbf{b}\sim\mathcal{N}(A\boldsymbol\mu+\mathbf{b},A\Sigma A^\top)$ | $\mathbf{X}$ 多元高斯 |
| MGF 求矩 | $m_k=M^{(k)}(0)$ | $M$ 在 0 邻域有限 |
| 独立和 MGF | $M_{X+Y}(t)=M_X(t)M_Y(t)$ | $X\perp Y$ |
| Jensen | $\mathbb{E}[g(X)]\ge g(\mathbb{E}[X])$ | $g$ 凸；等号 ⇒ $X$ 退化 |
| LLN | $P(\lvert\bar X_n-\mu\rvert>\varepsilon)\le\frac{\sigma^2}{n\varepsilon^2}\to0$ | i.i.d.、$\sigma^2<\infty$ |
| CLT | $\frac{\bar X_n-\mu}{\sigma/\sqrt n}\Rightarrow\mathcal{N}(0,1)$ | i.i.d.、$\sigma^2<\infty$，$n\to\infty$ |

## 3.8 示例与案例

### 案例 1（手算）：条件高斯闭式的数值验证

取 $\boldsymbol{\mu}=(0,0)$，$\Sigma=\begin{pmatrix}2&1.2\\1.2&1\end{pmatrix}$（相关系数 $\rho=1.2/\sqrt{2}\approx0.849$）。按 3.3.3 公式 2（$\mathbf{X}_a=X_1$，$\mathbf{X}_b=X_2$）：

$$\mathbb{E}[X_1\mid X_2=1]=0+\frac{1.2}{1}\times(1-0)=1.2,\qquad \mathrm{Var}(X_1\mid X_2=1)=2-\frac{1.2^2}{1}=0.56.$$

解读：知道 $X_2=1$（偏大）后，$X_1$ 的期望从 0 被拉到 1.2（正相关），方差从 2 缩到 0.56（$X_2$ 解释了 72% 的方差）。这个"缩多少"由 $\Sigma_{ab}\Sigma_{bb}^{-1}\Sigma_{ba}$ 决定——它正是 $X_1$ 对 $X_2$ 回归的 $R^2$ 乘以 $\mathrm{Var}(X_1)$，高斯条件下回归与线性回归是同一件事（第 5 章 5.9 节呼应）。

### 案例 2（代码）：用大规模采样验证条件分布闭式

```python
import numpy as np
rng = np.random.default_rng(21)
n = 2_000_000
X = rng.multivariate_normal([0, 0], [[2, 1.2], [1.2, 1]], size=n)

mask = np.abs(X[:, 1] - 1) < 0.05        # 条件化: X2 落在 1 附近的薄窗内
x1 = X[mask, 0]
print(f"sample size after conditioning: {mask.sum()}")
print(f"empirical mean = {x1.mean():.3f}, var = {x1.var():.3f}")
print(f"theory    mean = 1.200,        var = 0.560")
# 预期输出: empirical mean ≈ 1.20, var ≈ 0.56 (窗口带来的偏差与 O(1/sqrt(m)) 噪声内)
```

3.6.4 节的 CLT 模拟即本节的代码案例之二（极限定律的验证）；两个案例合起来覆盖了本章"分布结构"与"极限行为"两条主线。

## 3.9 常见误区与陷阱

1. **不相关当独立**。$\rho=0$ 只排除线性依赖。特例记忆：多元高斯中等价，一般分布不等价。
2. **边缘分布决定联合分布**。两个边缘都是高斯的联合分布可以高度非高斯（如 $X\sim\mathcal{N}(0,1)$，$Y=SX$，$S$ 为与 $X$ 独立的 $\pm1$ 等概率符号——边缘全正态、联合却集中在两条对角线上）。VAE 用高斯隐变量与高斯解码器时，"每维边缘像高斯"不代表联合建模正确。
3. **把 CLT 用在重尾数据上**。方差无限时 $\sqrt n$ 缩放律失效（进入稳定律吸引域）。对 loss、延迟类数据先做对数变换或检查尾部指数。
4. **Jensen 方向搞反**。$\ln$ 是凹函数：$\mathbb{E}[\ln X]\le\ln\mathbb{E}[X]$。ELBO 推导中符号写反会导致"优化一个上界"的隐蔽错误。
5. **独立样本均值方差套用到相关样本**。$\mathrm{Var}(\bar X_n)=\sigma^2/n$ 依赖独立；正相关样本（如时间序列）的有效样本量远小于 $n$，置信区间被系统性低估——第 6 章 MCMC 的"有效样本量（ESS）"诊断正为此而生。

## 3.12 进阶方向

- **依分布收敛与 Delta 方法**：若 $\sqrt n(\hat\theta_n-\theta)\Rightarrow\mathcal{N}(0,v)$，则 $g(\hat\theta_n)$ 渐近 $\mathcal{N}(g(\theta),\,v[g'(\theta)]^2/n)$——bootstrap（第 99 章项目三）的理论对照物。
- **Lindeberg–Feller 条件与非 i.i.d. CLT**：允许独立但不同分布的项，条件换成对"单点贡献占比"的控制；SGD 收敛分析中处理异质梯度噪声时需要。
- **稳定分布与广义 CLT**：方差无限时归一化因子与极限分布（Lévy $\alpha$-稳定族）更换——重尾建模的严格框架。
- **高斯过程**：把多元高斯推广到"任意有限点集上的函数值联合高斯"，是贝叶斯优化与不确定性量化的主力工具；入口材料 Rasmussen & Williams《Gaussian Processes for Machine Learning》（免费电子版）第 2 章。
