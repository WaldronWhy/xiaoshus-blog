# 第 99 章 综合项目——把概率统计变成手艺

> **本章定位**：本课程的收官实战。三个项目分别覆盖三条主线：MCMC（第 6 章 + 第 3 章高斯谱理论）、朴素贝叶斯分类器（第 1 章 + 第 4 章 + 《机器学习》前菜）、bootstrap 不确定性量化（第 5 章 + 第 6 章）。每个项目给出任务分解、验收标准与分档提示；只给方向不给完整答案。前置：至少完成第 1–5 章正文与练习，第 6 章可边做边学。

## 99.0 做项目的方法纪律

- **先写验收再写代码**：每完成一个任务分解块，立刻对照验收标准自测；不要攒到最后。
- **固定随机种子**：所有实验设 `np.random.default_rng(seed)`，保证结果可复现（可复现性是《实验设计与评估》一课的入学测验）。
- **每个数字都有误差条**：本课程的核心素养——报告任何估计时附带标准误或置信区间。
- 依赖仅限 `numpy / scipy / matplotlib`（项目二可用 `sklearn` 对照）。

## 99.1 项目一：从零实现 MCMC 采样二维高斯并诊断收敛

### 99.1.1 项目目标

不用任何采样库，实现 Metropolis–Hastings，从目标分布 $\mathcal{N}(\mathbf{0},\Sigma)$ 采样（$\Sigma=\begin{pmatrix}2&1.2\\1.2&1\end{pmatrix}$），并用 trace plot、自相关、ESS、多链 $\hat R$ 四种手段诊断收敛，最后与直接采样（第 3 章 3.3.2 谱分解法）对照验证正确性。

这个项目的教育价值：MCMC 的"正确"不是算法跑通，而是**能证明它收敛、能量化它还有多不准**——这正是使用 Stan/PyMC 等概率编程工具时被隐藏的判断力。

### 99.1.2 任务分解

1. **目标与参照**：写出 $\log\tilde p(\mathbf{x})$（未归一化对数密度）；用 `np.linalg.eigh` 得 $\Sigma=Q\Lambda Q^\top$，实现直接采样 $\mathbf{x}=\boldsymbol{\mu}+Q\Lambda^{1/2}\mathbf{z}$ 生成 10 万个"金标准"样本。
2. **MH 实现**：随机游走提议 $q(\mathbf{x}'|\mathbf{x})=\mathcal{N}(\mathbf{x},\epsilon^2I)$；接受判据用对数域（`log u < log_tilde_p(x') - log_tilde_p(x)`，防止数值下溢）；记录接受率。
3. **诊断套件**：
   - trace plot（含 burn-in 全程）；
   - ACF 曲线（自实现，参照第 6 章 6.5.3）；
   - ESS（截断累积自相关）；
   - 4 条不同远距离初值的链，实现 Gelman–Rubin $\hat R$（定义见提示 A）。
4. **步长实验**：$\epsilon\in\{0.05,0.5,1.5,5.0\}$，做出"步长—接受率—ESS/步"表格，找出最优 $\epsilon$。
5. **正确性对照**：比较 MCMC 样本与金标准样本的均值、协方差（逐元素相对误差）、边缘直方图与一维高斯密度叠加图。
6. **（进阶）Gibbs 对照**：实现条件分布轮流采样的 Gibbs，比较两者 ESS/步。

### 99.1.3 验收标准

- [ ] MH 代码不引用任何采样库函数（`rng.normal` 仅用于提议与均匀随机数）；
- [ ] 接受率落在 0.2–0.5，4 条链的 $\hat R<1.01$；
- [ ] 样本均值 $\lVert\hat{\boldsymbol\mu}\rVert<0.05$，样本协方差与 $\Sigma$ 逐元素相对误差 < 5%（burn-in 后 3 万样本）；
- [ ] ESS 报告正确（与 `arviz` 或手工 FFT 法交叉核对误差 < 20%，可不依赖库）；
- [ ] 步长实验表完整，能解释"两头吃亏"现象并指出本问题最优步长；
- [ ] 每张图有轴标签与标题；报告以"结论 + 误差条"句式书写。

### 99.1.4 提示

- **提示 A（$\hat R$ 定义）**：$m$ 条链各 $n$ 步，$B=n\cdot\mathrm{Var}(\bar\theta_{\cdot m})$（链间），$W=\mathrm{mean}_m(s_m^2)$（链内），$\widehat{\mathrm{Var}}^+=\frac{n-1}{n}W+\frac{B}{n}$，$\hat R=\sqrt{\widehat{\mathrm{Var}}^+/W}$。
- **提示 B（为什么用对数密度）**：二维高斯密度峰值 $\approx\frac{1}{2\pi\sqrt{|\Sigma|}}\approx0.08$ 看似安全，但高维/尖峰后验密度可小到 $10^{-300}$，线性域判据直接下溢为 0。
- **提示 C（谱直觉）**：链混合慢的"慢方向"是 $\Sigma$ 的最大特征方向（步长相对该方向方差偏小）；用 $\epsilon$ 实验数据验证这个猜想。
- **常见事故**：burn-in 未丢（均值被初值拉偏）；原地接受未计入链长（ESS 虚高）；比较协方差时用了 `np.cov(chain)` 而非 burn 后样本。

## 99.2 项目二：朴素贝叶斯垃圾邮件分类器 + 准确率的贝叶斯不确定性

### 99.2.1 项目目标

从零实现朴素贝叶斯垃圾邮件分类器（第 1 章 1.4.3 的完整工业版），再用贝叶斯方法（第 4 章 Beta–Binomial）给出其**准确率本身的后验分布**——回答"准确率 97.2% 的可信度有多大"，而不是只报一个点值。

### 99.2.2 任务分解

1. **数据**：使用经典 SMS Spam Collection（UCI 公开数据集，约 5574 条短信，5574 行 label+text）或任一中文垃圾邮件公开数据集；划分 70% 训练 / 30% 测试（固定种子）。
2. **特征与模型**：
   - 分词（英文按空白+小写化即可；中文可用 jieba 或按 2-gram，二选一并说明）；
   - 词表只取训练集；每类统计词频，得 $P(w\mid\text{spam})$、$P(w\mid\text{ham})$ 与类先验 $P(\text{spam})$；
   - 预测：$\arg\max_c \left[\ln P(c)+\sum_{w\in \text{邮件}}\ln P(w\mid c)\right]$（**对数域求和**）。
3. **平滑即先验**：实现两版——无平滑（暴露零概率 bug）与 Dirichlet 先验平滑 $P(w\mid c)=\frac{n_{w,c}+\alpha}{N_c+\alpha|V|}$（$\alpha=1$ 拉普拉斯、$\alpha=0.01$ Lidstone）；实验 $\alpha\in\{0,0.01,0.1,1\}$ 对测试准确率的影响并解释（第 4 章伪计数视角）。
4. **准确率的贝叶斯后验**：测试集判对数 $s$、判错数 $f$，取无信息先验 Beta(1,1)，后验 Beta$(1+s,1+f)$；报告后验均值、95% 可信区间，以及"$P(\text{准确率}>0.95\mid \text{数据})$"。
5. **对照与剖析**：
   - 用 `sklearn.naive_bayes.MultinomialNB` 复现，核对一致；
   - 做一次混淆矩阵 + 精确率/召回率分解，结合第 1 章 1.6 案例 1 讨论：垃圾邮件比例（类不平衡）如何影响"阳性的含义"；
   - 对 5 个被误分类的邮件做错误分析（前 10 大贡献词）。
6. **（进阶）贝叶斯版词概率**：把每个 $P(w\mid c)$ 也用 Beta 后验刻画（近似独立假设下），做后验预测采样 $p(\tilde x\mid D)$，估计"未来一条新邮件误分类率"的后验（对照第 4 章 4.1.3 预测分布思想）。

### 99.2.3 验收标准

- [ ] 测试准确率 ≥ 0.95（SMS 数据集上朴素贝叶斯的公允水平），且给出其 95% 可信区间（宽度应 < 0.03）；
- [ ] $\alpha=0$ 时能复现零概率导致大面积预测失败的现象并解释机制；
- [ ] 与 `MultinomialNB` 的测试集预测一致率 > 99%（差异仅来自实现细节时能指出哪一条）；
- [ ] 报告含混淆矩阵与精确率/召回率，并用基率语言解释为什么召回率比准确率更值得优化；
- [ ] 错误分析至少覆盖 3 类典型模式（如 URL、数字串、正常词被垃圾语义污染）。

### 99.2.4 提示

- **提示 A（下溢防护）**：一封邮件几百个词，$\prod P(w|c)$ 会下溢到 $10^{-500}$；一切计算用 $\sum\ln$。
- **提示 B（词表外词）**：测试集出现训练集没有的词时，两种处理——忽略该词，或按平滑公式计入 $|V|$+1 事件；选一种并说明对召回率的影响方向。
- **提示 C（可信区间宽度）**：$n\approx1670$ 条测试样本，Beta 后验区间宽约 $2\times1.96\sqrt{\hat p(1-\hat p)/n}\approx0.021$——先算理论值再对照蒙特卡洛（第 6 章方法）结果，两次独立验证。
- **常见事故**：用训练集准确率汇报（自欺）；平滑作用在先验 $P(c)$ 上（先验只有两类别，平滑无意义）；把 $\alpha$ 当超参数在**测试集**上调（应从训练集再切验证集——数据泄漏是《实验设计与评估》要根治的头号病）。

## 99.3 项目三：用参数自助法（bootstrap）量化 MLE 的不确定性

### 99.3.1 项目目标

对第 5 章的 MLE 理论做一次"计算实验学"检验：用 bootstrap 重采样估计 MLE 的抽样分布，与 Fisher 信息/CRLB 的解析预测对照；再推广到一个**没有闭式标准误**的估计量，体验 bootstrap 的真正卖点。

### 99.3.2 任务分解

1. **解析对照组**：从 $\mathcal{N}(\mu^*,\sigma^*)$ 采 $n=30$ 的样本；计算 $\hat\mu=\bar x$、$\hat\sigma=s$。
2. **参数 bootstrap**：由 $(\hat\mu,\hat\sigma^2)$ 生成参数化新样本 $B=5000$ 组，每组重算 MLE，得到 $\hat\mu^*,\hat\sigma^*$ 的经验分布；报告其标准差（bootstrap SE）与 95% 分位区间。
3. **理论对照**：解析 SE 为 $\sigma/\sqrt n$（$\hat\mu$）与 $\sigma/\sqrt{2n}$（$\hat\sigma$，由 Fisher 信息推出——作为练习先自己推导，校验值见提示 A）；报告"bootstrap SE / 解析 SE"比值（应 $\approx1$，$B=5000$ 时蒙特卡洛噪声约 ±2%）。
4. **重复实验分布**：把"采原始样本 → bootstrap"整个流程重复 500 次，画出 bootstrap SE 本身的分布——理解"bootstrap 估计的是本次数据下 SE 的估计，其自身也有涨落"。
5. **无闭式情形**：改为样本中位数与 $P(X>0)$（示性均值），bootstrap 它们的 SE 与置信区间（中位数解析 SE 为 $\frac{1}{2f(m)}\sqrt{1/n}$，用真密度核对；示性均值用 Wilson 区间对照）；体会"解析公式到头了，bootstrap 才开始"。
6. **失败案例剖析（必做）**：对 $U(0,\theta)$ 的 MLE $\hat\theta=\max_i x_i$ 做 bootstrap，与真值对照（$\hat\theta$ 有偏且极限分布非正态——非正则模型！），解释 bootstrap 为什么在此失效（重采样后最大值几乎总是变小）。写 300 字：非正则模型下 bootstrap 的适用边界。
7. **（进阶）与 MCMC 对照**：对高斯均值 + 无信息先验，用第 99 章项目一的 MH 采后验，对比"后验 95% 区间"与"bootstrap 95% 区间"（Bernstein–von Mises 预言两者大样本趋同）。

### 99.3.3 验收标准

- [ ] bootstrap SE 与解析 SE 比值在 $0.95\sim1.05$；
- [ ] 中位数与示性均值的 bootstrap 区间覆盖率经模拟验证 $\approx95\%$（重复 500 次实验统计覆盖，偏差 < 3%）；
- [ ] $U(0,\theta)$ 失效案例中能定量展示"bootstrap 区间系统性偏窄/偏低"并与理论偏差解释闭环；
- [ ] 全部图表自带误差条；报告区分"本次数据的 bootstrap 分布"与"跨数据集的重复分布"两层随机性。

### 99.3.4 提示

- **提示 A（校验值）**：$\hat\sigma$ 的渐近 SE 为 $\sigma/\sqrt{2n}$（$n=30$、$\sigma^*=2$ 时 $\approx0.258$）；中位数 SE 为 $\frac{1}{2}\sqrt{\frac{\pi}{2n}}\,\sigma$（正态，$n=30$ 时 $\approx0.237$）。
- **提示 B（分位区间）**：取 bootstrap 经验分布的 2.5% 与 97.5% 分位；样本量 $B$ 决定分位估计的蒙特卡洛误差（约 $\sqrt{0.25/B^2}$ 量级），$B=5000$ 足够。
- **提示 C（参数 vs 非参数 bootstrap）**：本项目主体是参数 bootstrap（从拟合模型采样）；对中位数可改做非参数 bootstrap（从原始样本有放回重采），对比两者在 $n=30$ 时的区间宽度，思考非参数版"让数据自己说话"的代价。
- **常见事故**：$B$ 太小就谈"bootstrap 分布的形状"；对 $\max$ 估计量照搬分位区间而不检查覆盖；把 bootstrap 区间读成贝叶斯可信区间（语义仍是频率派的程序覆盖，第 4 章 4.8 节）。

## 99.5 常见故障排查表

| 症状 | 最可能的根因 | 对应章节 |
|---|---|---|
| MCMC 均值明显偏离真值 | burn-in 未丢弃；或只有单链、卡在另一峰 | 第 6 章 6.7 误区 2 |
| MH 接受率 < 0.05 或 > 0.95 | 步长 $\epsilon$ 过大/过小 | 第 6 章 6.5.1 调参直觉 |
| 朴素贝叶斯全预测为一类 | 未取对数导致下溢；或零概率未平滑 | 第 1 章 1.7 误区 3、第 4 章伪计数 |
| 概率输出 $>1$ 或为负 | 变换后忘加雅可比因子；softmax 分母漏项 | 第 2 章 2.8 误区 4 |
| bootstrap SE 远小于解析 SE | 重采样时未放回；或 $B$ 过小；或估计量非正则（如 max） | 第 99 章 99.3 任务 6 |
| CLT 模拟直方图不贴合 | 母分布方差不存在（重尾）；或标准化用了错分母 | 第 3 章 3.9 误区 3 |

## 99.9 拓展阅读

1. **Gelman, A. et al., *Bayesian Data Analysis*, 3rd ed., CRC Press, 2013.** 第 11–12 章给出项目一诊断手段（$\hat R$、ESS）的权威定义与更多实例。
2. **Efron, B. & Tibshirani, R., *An Introduction to the Bootstrap*, Chapman & Hall, 1993.** bootstrap 的奠基教材；项目三的"何时失效"讨论（其第 3、13 章）远比本项目深入。
3. **Efron, B. & Hastie, T., *Computer Age Statistical Inference*, Cambridge University Press, 2016.** 把 bootstrap 放在"统计推断的计算机时代"演化线中讲述，适合项目完成后通读。
4. **MacKay, D. J. C., *Information Theory, Inference, and Learning Algorithms*, Cambridge University Press, 2003.** 项目二中"朴素贝叶斯的贝叶斯化"（给模型参数也加先验）在其第 24 章有完整示范。
5. **Almeida, T. A., Hidalgo, J. M. G. & Yamakami, A., "Contributions to the Study of SMS Spam Filtering: New Collection and Results", DocEng 2011.** SMS Spam Collection 数据集的原始论文（真实文献，引用数据集时请规范引用）。

## 99.10 进阶方向

- **把项目一升级为 HMC**：对同一目标实现哈密顿蒙特卡洛（需要梯度；二维高斯梯度手写即可），对比 ESS/梯度计算次数——Stan/NumPyro 内部机制白盒化。
- **把项目二升级为贝叶斯分类器**：词频用 Dirichlet 先验 + 后验预测采样（层次模型），对比点估计版在 100 条小训练集上的表现——小数据下贝叶斯优势的可测量演示。
- **把项目三升级为分层 bootstrap**：数据有聚类结构（同一用户多条记录）时朴素重采样失效，块 bootstrap/聚类 bootstrap 是《实验设计与评估》的正题。
- **概率编程复现**：用 PyMC 或 NumPyro 重做项目一的后验推断，对照自研 MH 的结果与耗时——体验"理解机制（自研）与掌握工具（库）"的完整闭环。
