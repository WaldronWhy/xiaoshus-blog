# 第 3 章 一元积分：累积与还原

> **本章定位**：本章给出定积分的严格定义（Riemann 和的极限）、牛顿-莱布尼茨公式、积分技巧与广义积分，并把积分确立为"连续求和=期望=概率"的数学工具。前置：第 1 章极限与夹逼定理、第 2 章导数与原函数概念。后续：第 6 章重积分、[概率论与数理统计](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/00/)的期望与归一化、[机器学习](/xiaoshus-blog/textbooks/ai/ai-core/machine-learning/00/)的期望风险定义都直接调用本章。

## 3.0 本章学习目标

- 能够陈述定积分的 Riemann 定义（分割-取样-求和-取极限四步），并解释"可积"意味着什么。
- 能够陈述牛顿-莱布尼茨公式，说明变上限积分与原函数的关系，并用它熟练计算定积分。
- 能够完成换元积分法（含定积分换限）与分部积分法，处理常见类型的积分。
- 能够判断广义积分的收敛性并计算基本类型（如 $\int_1^\infty x^{-2}\mathrm{d}x$、$\int_0^1 \frac{\mathrm{d}x}{\sqrt{x}}$）。
- 能够解释 $\mathbb{E}[X] = \int x f(x)\,\mathrm{d}x$ 中积分扮演的角色，并完成对简单密度（均匀、指数）的期望计算。
- 能够用数值积分（矩形/梯形/辛普森法则）复现手工积分结果，并说出各方法的误差阶。

## 3.1 为什么要"连续求和"

**直觉引入**。曲边梯形的面积：由 $y = f(x) \ge 0$、$x = a$、$x = b$ 与 $x$ 轴围成的区域，边是弯的，初等几何无能为力。处理弯的办法古已有之——**化整为零、以直代曲、无限累加**：

1. **分割**：把 $[a, b]$ 切成 $n$ 小段 $\Delta x_i = x_i - x_{i-1}$；
2. **取样**：每段上任取一点 $\xi_i$，用小矩形面积 $f(\xi_i)\Delta x_i$ 代替真实的小曲边面积（以直代曲）；
3. **求和**：$S_n = \sum_{i=1}^n f(\xi_i)\Delta x_i$，称为黎曼和（Riemann sum）；
4. **取极限**：让分割无限加细，若和式有极限，此极限即为面积。

这个过程你已经拥有理论工具：第 1 章的极限语言恰好能精确表述"无限加细时和式的极限"。定积分就是**写在积分号下的极限**。

AI 中的同构问题无处不在：损失函数 $\frac{1}{n}\sum_i \ell(f(x_i), y_i)$ 是"离散经验平均"；当数据来自连续分布时，其理论版本是积分 $\int \ell(f(x), y)\,\mathrm{d}P(x)$——**经验平均是黎曼和，期望是积分**，二者的关系正是大数定律陈述的内容。带着这个对应学习本章，每个定义都会"有两个身份"：几何的（面积）与概率的（期望）。

## 3.2 Riemann 积分的严格定义

**定义 3.2.1（分割与黎曼和）**。设 $f$ 定义在 $[a,b]$ 上。取分点 $a = x_0 < x_1 < \cdots < x_n = b$，记分割 $P = \{x_i\}$，最大小区间长度 $\|P\| = \max_i \Delta x_i$。在每个 $[x_{i-1}, x_i]$ 上任取 $\xi_i$，作和

$$
S(P, \xi) = \sum_{i=1}^n f(\xi_i)\,\Delta x_i .
$$

**定义 3.2.2（定积分）**。若存在常数 $I$，使得对任意 $\varepsilon > 0$ 存在 $\delta > 0$，只要 $\|P\| < \delta$（对任何分割方式与任何取样点选择）都有 $|S(P,\xi) - I| < \varepsilon$，则称 $f$ 在 $[a,b]$ 上**Riemann 可积**（integrable），记

$$
I = \int_a^b f(x)\,\mathrm{d}x .
$$

注意定义中的全称量词："任何取样点"都要给出同一极限——这排除了取样方式作弊的可能。与第 1 章 $\varepsilon$-$\delta$ 定义的结构完全同构，只是被逼近的对象从"数列的尾巴"换成了"分割足够细时的一切黎曼和"。

**定理 3.2.3（可积性）**。以下函数在闭区间 $[a,b]$ 上 Riemann 可积：连续函数；单调有界函数；只有有限个第一类间断点的有界函数。可积必有界。不可积的例子：Dirichlet 函数 $D(x) = \mathbf{1}[x \in \mathbb{Q}]$（任何取样点选择都让和式在 0 与 $b-a$ 之间跳变）。

**定理 3.2.4（基本性质）**。定积分是线性、区间可加的：$\int_a^b (\alpha f + \beta g) = \alpha\int_a^b f + \beta\int_a^b g$；$\int_a^c + \int_c^b = \int_a^b$。保序性：$f \le g$（在 $[a,b]$）$\Rightarrow \int_a^b f \le \int_a^b g$。绝对值估计：$\left|\int_a^b f\right| \le \int_a^b |f|$。约定 $\int_a^a f = 0$，$\int_a^b = -\int_b^a$。

**积分中值定理**。设 $f$ 在 $[a,b]$ 连续，则存在 $\xi \in [a,b]$ 使 $\int_a^b f\,\mathrm{d}x = f(\xi)(b-a)$：曲边梯形面积等于某个"平均高度"乘底边——$\frac{1}{b-a}\int_a^b f$ 正是**连续版本的加权平均**，这个观点在概率论中就是 $\mathbb{E}[f(X)]$。

## 3.3 微积分基本定理：还原与累积的互逆

定积分定义给出"是什么"，但没有给出"怎么算"。通向计算的钥匙是一个惊人的事实：**求积（累积）与求导（变化率）互为逆运算**。

**定理 3.3.1（变上限积分的连续性与可导性）**。设 $f$ 在 $[a,b]$ 连续，定义

$$
\Phi(x) = \int_a^x f(t)\,\mathrm{d}t ,
$$

则 $\Phi$ 在 $[a,b]$ 连续，且在 $f$ 的连续点处 $\Phi'(x) = f(x)$。

证明要点：$\frac{\Phi(x+h)-\Phi(x)}{h} = \frac{1}{h}\int_x^{x+h} f(t)\,\mathrm{d}t = f(\xi)$（积分中值定理，$\xi$ 介于 $x$ 与 $x+h$），令 $h\to 0$ 由连续性得 $f(x)$。**导数是"单位长度的累积量"**——这从另一个方向再次印证了微分与积分的互逆。

**定理 3.3.2（原函数存在定理）**。连续函数必有原函数，$\Phi(x) = \int_a^x f(t)\,\mathrm{d}t$ 就是一个。（注意：可积不含连续时原函数未必存在，见常见误区。）

**定理 3.3.3（牛顿-莱布尼茨公式 / 微积分基本定理）**。设 $f$ 在 $[a,b]$ 连续，$F$ 是 $f$ 的任意一个原函数（$F' = f$），则

$$
\int_a^b f(x)\,\mathrm{d}x = F(b) - F(a) = F(x)\Big|_a^b .
$$

证明：$\Phi$ 与 $F$ 都是 $f$ 的原函数，故 $\Phi - F = C$（同一区间上导数相同则相差常数，由 Lagrange 中值定理证明）；代 $x = a$ 得 $C = -F(a)$；代 $x = b$ 即得。$\blacksquare$

这个公式的意义远超"计算技巧"：它把无限过程（求和取极限）折叠成两个函数值的差，**整个定积分的计算从此降维为"找原函数"**。第 2 章的求导技术因此全部转化为积分技术。

**不定积分**。$f$ 的全体原函数记 $\int f\,\mathrm{d}x = F(x) + C$。基本积分表是求导表的镜像（要求默写）：

| $f(x)$ | $\int f(x)\,\mathrm{d}x$ | 备注 |
|---|---|---|
| $x^\mu$ | $\frac{x^{\mu+1}}{\mu+1} + C$ | $\mu \neq -1$ |
| $\frac1x$ | $\ln\|x\| + C$ | $x \neq 0$ |
| $\mathrm{e}^x$ | $\mathrm{e}^x + C$ | — |
| $\sin x$ | $-\cos x + C$ | — |
| $\cos x$ | $\sin x + C$ | — |
| $\sec^2 x$ | $\tan x + C$ | — |
| $\frac{1}{1+x^2}$ | $\arctan x + C$ | 高斯分布归一化相关 |
| $\frac{1}{\sqrt{1-x^2}}$ | $\arcsin x + C$ | — |

## 3.4 积分技巧：换元与分部

**定理 3.4.1（换元积分法，substitution）**。不定积分：设 $F' = f$，则 $\int f(g(x))g'(x)\,\mathrm{d}x = F(g(x)) + C$（链式法则的逆读）。定积分版本（换元必换限）：

$$
\int_a^b f(g(x))\,g'(x)\,\mathrm{d}x = \int_{g(a)}^{g(b)} f(u)\,\mathrm{d}u .
$$

**例 3.4.2**。$\int_0^1 x\,\mathrm{e}^{x^2}\,\mathrm{d}x$：令 $u = x^2$，$\mathrm{d}u = 2x\,\mathrm{d}x$；$x: 0\to1$ 对应 $u: 0\to1$，故原式 $= \frac12\int_0^1 \mathrm{e}^u\,\mathrm{d}u = \frac{\mathrm{e}-1}{2}$。

**例 3.4.3（概率中的标志性换元）**。$\int_{-\infty}^{\infty} \mathrm{e}^{-x^2/2}\,\mathrm{d}x$ 的计算需要二维技巧（第 6 章 6.5 节极坐标法），这里先算它的"亲戚"：令 $u = \sqrt{2}x$ 后与 $\int \mathrm{e}^{-u^2}\mathrm{d}u$ 等价——这正是标准正态分布密度 $\frac{1}{\sqrt{2\pi}}\mathrm{e}^{-x^2/2}$ 归一化常数出现 $\sqrt{2\pi}$ 的现场，答案将在第 6 章揭晓。

**定理 3.4.4（分部积分法，integration by parts）**。由乘积法则 $(uv)' = u'v + uv'$ 移项积分：

$$
\int u\,\mathrm{d}v = uv - \int v\,\mathrm{d}u .
$$

选取 $u, v$ 的经验法则（"反对幂指三"优先级）：让 $\int v\,\mathrm{d}u$ 比 $\int u\,\mathrm{d}v$ 更简单，通常让**对数、反三角**当 $u$（求导后变简单），**指数、三角**当 $\mathrm{d}v$（积分后可控）。

**例 3.4.5（期望计算的骨架）**。求 $\int_0^\infty x\,\mathrm{e}^{-x}\,\mathrm{d}x$。取 $u = x$（$\mathrm{d}u = \mathrm{d}x$），$\mathrm{d}v = \mathrm{e}^{-x}\mathrm{d}x$（$v = -\mathrm{e}^{-x}$）：

$$
\int_0^\infty x\,\mathrm{e}^{-x}\,\mathrm{d}x = \Big[-x\,\mathrm{e}^{-x}\Big]_0^\infty + \int_0^\infty \mathrm{e}^{-x}\,\mathrm{d}x = 0 + 1 = 1 .
$$

这个积分是**参数为 1 的指数分布的期望**（$\mathbb{E}[X] = \frac{1}{\lambda}$，$\lambda = 1$）；推广 $\int_0^\infty x^n \mathrm{e}^{-x}\mathrm{d}x = n!$ 给出 Gamma 函数 $\Gamma(n+1) = n!$，概率论中矩的计算反复使用。

**有理函数与三角换元（简述）**。$\frac{P(x)}{Q(x)}$ 型用部分分式分解；含 $\sqrt{a^2-x^2}$、$\sqrt{x^2+a^2}$ 分别用 $x = a\sin\theta$、$x = a\tan\theta$ 消根号。这两类技巧在概率密度变换（第 6 章雅可比行列式）中会以"换元必换微分"的形式重现。

## 3.5 广义积分：无限区间与无界函数

黎曼积分要求区间有限、函数有界。两者放松其一即**广义积分**（improper integral），本质是第 1 章极限的又一次出场。

**定义 3.5.1（无穷区间）**。$\int_a^\infty f\,\mathrm{d}x = \lim_{t\to\infty} \int_a^t f\,\mathrm{d}x$（极限存在称为收敛，否则发散）。同理定义 $\int_{-\infty}^{+\infty}$（要求两端独立收敛）。

**定义 3.5.2（瑕积分）**。$f$ 在 $b$ 处无界时，$\int_a^b f\,\mathrm{d}x = \lim_{t \to b^-} \int_a^t f\,\mathrm{d}x$。

**例 3.5.3（p-积分，必须记住的判别标尺）**。

$$
\int_1^\infty \frac{\mathrm{d}x}{x^p} = \begin{cases} \dfrac{1}{p-1}, & p > 1 \quad (\text{收敛})\\[2pt] \text{发散}, & p \le 1 \end{cases} \qquad\qquad \int_0^1 \frac{\mathrm{d}x}{x^p} = \begin{cases} \dfrac{1}{1-p}, & p < 1 \quad (\text{收敛})\\[2pt] \text{发散}, & p \ge 1 \end{cases}
$$

两图的分界线是 $p=1$（$\ln x$ 恰好温和地发散）。比较判别法：$0 \le f \le g$ 且 $\int g$ 收敛则 $\int f$ 收敛。**这些标尺直接决定概率分布的尾巴行为**：重尾分布（如 Pareto 分布 $f(x) \propto x^{-\alpha-1}$）是否存在有限均值/方差，取决于 $\alpha$ 与 p-积分分界线的相对位置——机器学习中重尾梯度、长尾数据的数学根源即此。

**例 3.5.4**。判断 $\int_0^\infty x\,\mathrm{e}^{-x^2}\,\mathrm{d}x$ 收敛性并求值：$\int_0^t x\mathrm{e}^{-x^2}\mathrm{d}x = \frac12(1 - \mathrm{e}^{-t^2}) \to \frac12$，收敛。对比 $\int_0^\infty x\,\mathrm{e}^{-x}\,\mathrm{d}x = 1$ 与 $\int_{-\infty}^{\infty} x\,\mathrm{e}^{-x^2}\,\mathrm{d}x = 0$（奇函数对称，对应标准正态的均值 0——积分的奇偶对称性是概率计算的高频 shortcut）。

## 3.6 数值积分：从零实现黎曼和

解析积分失败时（被积函数无初等原函数，如 $\mathrm{e}^{-x^2}$；或函数只以黑箱形式给定，如真实模型损失），数值积分是工程现实。误差阶可直接从黎曼和定义读出：

- 左端点矩形法：误差 $O(h)$，$h = \frac{b-a}{n}$；
- 中点矩形法：误差 $O(h^2)$（左右误差主部相消——第 4 章 $\mathrm{e}^{x}$ 泰勒展开可见）；
- 梯形法：误差 $O(h^2)$；
- 辛普森法（Simpson，过三点的抛物线代替曲线）：误差 $O(h^4)$。

```python
import numpy as np

def f(x):
    return np.exp(-x**2)          # 无初等原函数的经典函数

def rectangle(f, a, b, n, mode="left"):
    x = np.linspace(a, b, n + 1)
    w = (b - a) / n
    if mode == "left":
        return w * f(x[:-1]).sum()
    return w * f(0.5 * (x[:-1] + x[1:])).sum()     # 中点法

def trapezoid(f, a, b, n):
    x = np.linspace(a, b, n + 1)
    w = (b - a) / n
    return w * (0.5 * f(x[0]) + f(x[1:-1]).sum() + 0.5 * f(x[-1]))

def simpson(f, a, b, n):          # n 必须为偶数
    x = np.linspace(a, b, n + 1)
    w = (b - a) / n
    s = f(x[0]) + f(x[-1]) + 4 * f(x[1:-1:2]).sum() + 2 * f(x[2:-1:2]).sum()
    return s * w / 3

truth = np.sqrt(np.pi) * 0.5      # ∫_0^1 e^{-x^2} dx 的精确值 = sqrt(pi)/2 ≈ 0.8862269255
for n in [8, 64, 512, 4096]:
    print(f"n={n:>5}  中点误差={abs(rectangle(f,0,1,n,'mid')-truth):.2e}  "
          f"梯形误差={abs(trapezoid(f,0,1,n)-truth):.2e}  辛普森误差={abs(simpson(f,0,1,n)-truth):.2e}")
# 预期输出（注意每个方法误差随 n 的衰减速度不同）：
# n=    8  中点误差≈3.9e-03  梯形误差≈7.8e-03  辛普森误差≈1.1e-06
# n=   64  中点误差≈6.1e-05  梯形误差≈1.2e-04  辛普森误差≈4.4e-10
# n=  512  中点误差≈9.5e-07  梯形误差≈1.9e-06  辛普森误差≈1.7e-13
# n= 4096  中点误差≈1.5e-08  梯形误差≈3.0e-08  辛普森误差已达机器精度
```

请验证：$n$ 扩大 8 倍时，中点/梯形误差约缩小 8 倍（$O(h)$ 有效的梯形是 $O(h^2)$ 应缩 64 倍——请用输出自查各方法真实阶数），辛普森缩 4096 倍（$O(h^4)$）。误差阶不是背出来的，是用这张表打印出来的。

工程用法（调用成熟库）：`scipy.integrate.quad(f, 0, 1)` 基于 自适应高斯–Kronrod 求积，通常一行得到机器精度结果；`np.trapezoid(y, x)` 处理离散采样数据（对应经验平均到连续平均的插值过渡）。

## 3.7 积分作为期望：与概率课程的接口

**连续随机变量的核心公式**。设 $X$ 的概率密度函数（probability density function, PDF）为 $f_X$（非负、积分为 1），则

$$
P(X \in [a,b]) = \int_a^b f_X(x)\,\mathrm{d}x, \qquad \mathbb{E}[X] = \int_{-\infty}^{\infty} x\, f_X(x)\,\mathrm{d}x, \qquad \mathrm{Var}(X) = \int (x - \mu)^2 f_X(x)\,\mathrm{d}x .
$$

三个公式对积分的要求依次是：① 归一化（$\int f_X = 1$，一个广义积分收敛问题）；② 期望存在（$\int |x| f_X < \infty$，绝对收敛——重尾分布会失败）；③ 二阶矩存在。**每个公式都是本章技术的一次应用**：归一化常数用 3.4 的换元、期望用 3.4 的分部、存在性用 3.5 的 p-积分判别。

**手算示例**。指数分布 $f(x) = \lambda \mathrm{e}^{-\lambda x}$（$x \ge 0$）：

- 归一化：$\int_0^\infty \lambda \mathrm{e}^{-\lambda x}\mathrm{d}x = \lambda \cdot \frac{1}{\lambda} = 1$ ✓。
- 期望：分部积分（3.4 例 3.4.5 的一般化）得 $\mathbb{E}[X] = \frac{1}{\lambda}$。
- 方差：$\int_0^\infty x^2 \lambda\mathrm{e}^{-\lambda x}\mathrm{d}x = \frac{2}{\lambda^2}$，故 $\mathrm{Var} = \frac{2}{\lambda^2} - \frac{1}{\lambda^2} = \frac{1}{\lambda^2}$。

**均匀分布 $U[0,1]$**：$f = 1$，一切积分退化为区间长度——蒙特卡洛方法（99 章项目三）以它为基石：在 $[0,1]$ 上均匀撒点求平均，本质上就是"用离散黎曼和的随机版本逼近定积分"。

**大数定律的积分视角（预告）**。经验平均 $\frac1n\sum_i \ell(x_i)$ 随 $n \to \infty$ 收敛于积分 $\int \ell\,\mathrm{d}P$——这是[概率论与数理统计](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/00/)中大数定律的内容，而"机器学习的期望风险 $\mathcal{R}(f) = \mathbb{E}[\ell(f(X),Y)]$ 与经验风险 $\hat{\mathcal{R}}_n(f)$ 之差随 $n$ 减小"正是[机器学习](/xiaoshus-blog/textbooks/ai/ai-core/machine-learning/00/)泛化理论的第一句话。积分在这里不是计算工具，而是**把"有限数据"与"真实规律"连接起来的那座桥**。

## 3.8 关键公式速查

| 公式 / 定理 | 适用条件与备注 |
|---|---|
| $\int_a^b f = \lim_{\|P\|\to 0} \sum_i f(\xi_i)\Delta x_i$ | 对一切分割与取样一致成立；连续函数必可积 |
| 变上限求导 $\left(\int_a^x f(t)\mathrm{d}t\right)' = f(x)$ | $f$ 连续；原函数存在定理 |
| 牛顿-莱布尼茨 $\int_a^b f = F(b)-F(a)$ | $f$ 连续且 $F'=f$；可积但不连续时不保证 |
| 换元（定积分） $\int_a^b f(g)g'\,\mathrm{d}x = \int_{g(a)}^{g(b)} f(u)\mathrm{d}u$ | 换元必换限；$g$ 有连续导数 |
| 分部积分 $\int u\,\mathrm{d}v = uv - \int v\,\mathrm{d}u$ | $u,v$ 可导；选取让剩余积分更简 |
| p-积分判别（$[1,\infty)$ 与 $(0,1]$ 两版） | 分界均为 $p=1$；重尾分布分析标尺 |
| 积分中值定理 $\int_a^b f = f(\xi)(b-a)$ | $f$ 连续；$\frac{1}{b-a}\int f$ 是连续平均 |
| $\mathbb{E}[X] = \int x f_X(x)\,\mathrm{d}x$ | 密度非负、归一化；期望需绝对收敛 |
| 矩形/梯形/辛普森误差阶 $O(h)$/$O(h^2)$/$O(h^4)$ | 足够光滑的被积函数 |
| $\int_0^\infty x^n \mathrm{e}^{-x}\mathrm{d}x = n!$ | Gamma 函数特例；分部积分归纳可证 |

## 3.9 示例与案例

**案例 1（手算）：两条曲线围成的面积与"消费者剩余"式计算。**

求 $y = x^2$ 与 $y = \sqrt{x}$ 之间的区域面积。联立求交点：$x^2 = \sqrt{x} \Rightarrow x = 0, 1$。在 $(0,1)$ 内 $\sqrt{x} > x^2$，故

$$
A = \int_0^1 (\sqrt{x} - x^2)\,\mathrm{d}x = \left[\frac{2}{3}x^{3/2} - \frac{x^3}{3}\right]_0^1 = \frac{2}{3} - \frac13 = \frac13 .
$$

每步依据：交点确定积分限（保序性确定被积函数方向）、牛顿-莱布尼茨公式。这类"上减下"的计算是第 6 章二重积分化累次积分的雏形。

**案例 2（代码 + 解析）：用积分重现"深度学习中的期望损失"。**

以一维"连续数据的期望损失"为例：模型 $h_\theta(x) = \theta x$，输入 $X \sim U[0,1]$，损失 $\ell = \frac12 (h_\theta(X) - X)^2$。理论最优 $\theta^\ast$ 满足最小化期望损失 $\mathbb{E}[\ell]$，手工算：

$$
\mathbb{E}[\ell](\theta) = \int_0^1 \frac12 (\theta x - x)^2\,\mathrm{d}x = \frac{(\theta-1)^2}{2}\int_0^1 x^2\,\mathrm{d}x = \frac{(\theta-1)^2}{6} .
$$

显然 $\theta^\ast = 1$（模型系数应等于数据生成系数）。数值验证：

```python
import numpy as np

def expected_loss(theta, n=200_000, seed=0):
    """蒙特卡洛估计 E[0.5*(theta*X - X)^2]，X ~ U[0,1]。"""
    rng = np.random.default_rng(seed)
    x = rng.uniform(0, 1, n)
    return np.mean(0.5 * (theta * x - x) ** 2)

for theta in [0.5, 0.9, 1.0, 1.5]:
    mc = expected_loss(theta)
    exact = (theta - 1) ** 2 / 6
    print(f"theta={theta:<4} 蒙特卡洛={mc:.6f}  解析={exact:.6f}")
# 预期输出（蒙特卡洛在 1e-3 精度内复现解析值；theta=1 时两者均为 0 附近）：
# theta=0.5  蒙特卡洛≈0.020835  解析=0.020833
# theta=0.9  蒙特卡洛≈0.000333  解析=0.000333
# theta=1.0  蒙特卡洛≈0.000000  解析=0.000000
# theta=1.5  蒙特卡洛≈0.041660  解析=0.041667
```

这个 10 行实验是[机器学习](/xiaoshus-blog/textbooks/ai/ai-core/machine-learning/00/)"期望风险最小化"的最小完整样本，也是 99 章项目三（蒙特卡洛）的思想预演。

## 3.10 常见误区与陷阱

1. **把"可积"与"有原函数"混为一谈**。连续时二者等价（基本定理保证），但可积不连续的函数可以没有原函数（如符号函数在含 0 的区间上可积，但其"原函数"$|x|$ 的导数不还原它于 0 处）。牛顿-莱布尼茨公式的前提"$F' = f$ 处处成立"不可省略。
2. **换元不换限**。定积分换元后仍用旧限是最常见计算错误；换元必换限（3.4 定理），或换元后先回到原变量再代入旧限。
3. **分部积分方向选反**。让 $\int v\,\mathrm{d}u$ 变复杂则白做；$\int x\mathrm{e}^x\mathrm{d}x$ 中令 $u=\mathrm{e}^x$（应取 $u = x$）会得到 $\frac{x^2\mathrm{e}^x}{2}$ 型更难的积分。记口诀"反对幂指三"。
4. **广义积分的"看起来正常"**。$\int_1^\infty \frac{\mathrm{d}x}{x}$ 的被积函数处处有限、函数值趋于 0，但积分发散（对数慢发散）；"$f \to 0$"不是收敛条件。数值实验也会误导：$\int_1^{10^6}\frac{\mathrm{d}x}{x} \approx 13.8$，发散得极慢——重尾分布的样本方差在实践中"永远算不完"正是这种慢发散。
5. **奇偶对称性滥用**。$\int_{-\infty}^{\infty} x f = 0$ 需要奇函数 + 绝对收敛（或至少对称主值收敛）同时成立；对重尾密度先确认期望存在。
6. **数值积分盲目用大 $n$**。舍入误差随 $n$ 线性累积，$n$ 超过 $10^7$ 量级后误差可能不降反升；自适应方法（`scipy.integrate.quad`）通常优于暴力加密。

## 3.13 进阶方向

- **勒贝格积分与测度论**：Riemann 积分对 Dirichlet 型函数失效、极限与积分交换需要苛刻条件；勒贝格积分（控制收敛定理）修复这一切，是现代概率论的底座。需补：$\sigma$-代数、可测函数。

- **分布函数的随机分析**：Itô 积分与随机微分方程，强化学习连续时间模型与扩散生成模型的数学语言，需要测度论 + 泰勒展开（随机版本 Itô 引理）双重基础。
