# 第 1 章 极限与连续（对应正文 §1.13）

## 1.1（概念辨析｜对应 §1.3 定理 1.3.2）

> 判断并说明理由：若 $\lim_{n\to\infty} a_n b_n$ 存在，则 $\{a_n\}$、$\{b_n\}$ 中至少一个收敛。

**结论：错误。**

反例：取 $a_n = b_n = (-1)^n$。两个数列都在 $-1$ 与 $1$ 之间振荡、均发散，但乘积 $a_n b_n = (-1)^{2n} = 1$ 恒定，极限存在且为 $1$。

**常见错误答案为什么错**：很多同学引用四则运算法则（定理 1.3.2）"乘积的极限等于极限的乘积"。注意该法则的方向性：它说的是**由各因子极限存在**推出**乘积极限存在**，前提是 $\lim a_n = a$、$\lim b_n = b$ 都存在且有限。它不是等价刻画——"乘积极限存在"不能反推"因子极限存在"，因为相乘可以让振荡互相抵消（$(-1)^n \cdot (-1)^n$ 的相位对消），也可以用"一个因子趋于 0、另一个无界"（如 $a_n = 1/n$，$b_n = n$，乘积恒为 1，两个因子一个收敛一个发散——这说明甚至"至少一个收敛"里的那个收敛因子也不是必需的形态来源……注意本例中 $a_n=1/n$ 恰好收敛，所以它不构成反例；真正的反例是 $(-1)^n \times (-1)^n$，两个都不收敛）。

**要点记忆**：四则运算法则是单向充分条件，不是必要条件。

## 1.2（概念辨析｜对应 §1.5 定义 1.5.1、定义 1.5.2）

> "若 $f$ 在 $x_0$ 处极限存在，则 $f$ 在 $x_0$ 连续"——指出错误并给出反例。

**错误所在**：连续性的定义（定义 1.5.1）有三个要件——①极限 $\lim_{x\to x_0} f(x)$ 存在；② $f(x_0)$ 有定义；③二者相等。题述命题只保证了要件①，遗漏了②③。

**反例**：$f(x) = \dfrac{\sin x}{x}$（$x \neq 0$），在 $x=0$ 处无定义。我们有 $\lim_{x\to 0}\dfrac{\sin x}{x} = 1$（两个重要极限之一，§1.3），极限存在，但 $f$ 在 $0$ 处根本无定义，故不连续——这正是**可去间断点**（定义 1.5.2 第 1 类）的标准例子。

**进一步说明**：也可以构造"极限存在但函数值不等"的反例：$f(x) = \begin{cases}\frac{\sin x}{x}, & x\neq 0\\ 0, & x=0\end{cases}$，极限为 1 而 $f(0)=0$，同样间断。补定义 $f(0)=1$ 即可修复——"可去"的含义。

## 1.3（概念辨析｜对应 §1.5 一致连续、定理 1.5.7）

> （i）说明"处处连续、处处不一致连续"为什么不可能；（ii）举一个"在开区间连续但不一致连续"的例子。

**(i) 不可能的理由（Cantor 定理的直接推论）**。定理 1.5.7（Cantor 定理）：**闭区间上的连续函数必一致连续**。现在设 $f$ 在某区间 $I$ 上处处连续。任取 $x_0 \in I$，取一个含于 $I$ 的闭子区间 $[x_0 - r, x_0 + r]$（$r>0$，只要 $I$ 不是孤立点总能取到足够小的 $r$）。$f$ 在这个**有界闭区间**上连续，由 Cantor 定理 $f$ 在其上一致连续。所以"处处连续"的函数在每一点的任意小闭邻域内都一致连续——"处处不一致连续"（若理解为"在每一点的每个邻域上都不一致连续"）与 Cantor 定理矛盾，**不可能**。

若把"处处不一致连续"理解为"在整个定义域 $\mathbb{R}$ 上不一致连续"，那当然可能（如 $f(x)=x^2$、$f(x)=\sin x^2$），但它仍在每个有界闭子区间上一致连续——这正是本题想让你看清的：**一致连续是"局部可放大成一致"的性质，紧性（有界闭）是关键**。连续函数的"病态"只能在大范围（无界方向、开区间端点）出现，不能在每个小紧块里出现。

**(ii) 例子**：$f(x) = \dfrac{1}{x}$ 在开区间 $(0,1)$ 上连续（初等函数在定义区间内连续，定理 1.5.4），但不一致连续。证明（正文例 1.5.6 的完整版）：取 $x_n = \frac{1}{n}$，$y_n = \frac{1}{n+1}$，则 $|x_n - y_n| = \frac{1}{n(n+1)} \to 0$，但

$$|f(x_n) - f(y_n)| = |n - (n+1)| = 1 \not\to 0.$$

对 $\varepsilon = \tfrac12$，无论 $\delta$ 多小，取 $n$ 使 $\frac{1}{n(n+1)} < \delta$，即得两点距离小于 $\delta$ 而函数值差为 $1 > \varepsilon$。故不存在对所有点通用的 $\delta$，不一致连续。直观：函数在左端点附近"无限变陡"，任何固定 $\delta$ 在足够靠左处失效。

## 1.4（计算推导｜对应 §1.2 定义 1.2.1，例 1.2.2 的同型题）

> 用 $\varepsilon$-$N$ 定义证明 $\lim_{n\to\infty} \dfrac{n}{n+1} = 1$。

**证**：先做差（分析的核心是把"接近"翻译成显式不等式）：

$$\left|\frac{n}{n+1} - 1\right| = \left|\frac{n - (n+1)}{n+1}\right| = \frac{1}{n+1} < \frac{1}{n}.$$

任给 $\varepsilon > 0$。要 $\frac{1}{n+1} < \varepsilon$，只需 $n + 1 > \frac{1}{\varepsilon}$，即 $n > \frac{1}{\varepsilon} - 1$。由实数的阿基米德性质，取

$$N = \max\!\left(1,\ \left\lceil \frac{1}{\varepsilon} - 1 \right\rceil\right) \quad(\text{取 max 保证 } N \ge 1 \text{ 是正整数}),$$

则 $n > N$ 时 $n > \frac{1}{\varepsilon} - 1$，即 $n + 1 > \frac{1}{\varepsilon}$，故 $\left|\frac{n}{n+1} - 1\right| = \frac{1}{n+1} < \varepsilon$。由定义 1.2.1，$\lim_{n\to\infty} \frac{n}{n+1} = 1$。$\blacksquare$

**校验**：真值为 1，与题给校验一致。注意证明的固定套路（§1.2"找 $N$"三步）：任给 $\varepsilon$ → 反解出对 $n$ 的要求 → 取 $N$。$N$ 取法不唯一（取 $\lceil 1/\varepsilon\rceil$ 也行，因为 $\frac{1}{n+1} < \frac1n$），只需**存在**。

## 1.5（计算推导｜对应 §1.4 等价无穷小、§1.3 两个重要极限）

> （a）求 $\lim_{x\to 0}\dfrac{1-\cos x}{x\sin x}$；（b）求 $\lim_{n\to\infty}\left(\dfrac{n+1}{n-1}\right)^n$。

**(a)** $x \to 0$ 时分子分母均趋于 0（$\frac{0}{0}$ 型）。使用等价无穷小（§1.4 表）：$1 - \cos x \sim \dfrac{x^2}{2}$，$\sin x \sim x$。

- 分母 $x \sin x$ 是**乘积**，替换乘除因子合法（§1.9 误区 2 强调的边界）：$x\sin x \sim x \cdot x = x^2$。
- 于是

$$\lim_{x\to 0}\frac{1-\cos x}{x\sin x} = \lim_{x\to 0}\frac{\frac{x^2}{2}}{x^2} = \frac{1}{2}.$$

每步依据：等价无穷小替换（仅用于乘除因子）+ 约分。

**校验**：$\frac{1}{2}$，与正文一致。（第 4 章泰勒展开后可再看一遍：$1-\cos x = \frac{x^2}{2} - \frac{x^4}{24} + \cdots$，$\sin x = x - \frac{x^3}{6}+\cdots$，比值 $= \frac{x^2/2 + O(x^4)}{x^2(1+O(x^2))} \to \frac12$，且能看清下一阶修正为 0 的原因。）

**(b)** 化归为重要极限 $\lim(1+\frac1m)^m = \mathrm{e}$ 的形状。改写：

$$\left(\frac{n+1}{n-1}\right)^n = \left(1 + \frac{2}{n-1}\right)^n.$$

令 $m = \dfrac{n-1}{2}$（$n\to\infty \iff m\to\infty$），则 $\frac{2}{n-1} = \frac{1}{m}$，$n = 2m+1$，故

$$\left(1 + \frac{1}{m}\right)^{2m+1} = \left[\left(1+\frac{1}{m}\right)^{m}\right]^2 \cdot \left(1 + \frac{1}{m}\right).$$

由重要极限，中括号趋于 $\mathrm{e}$；最后一因子趋于 1（极限为 1 的数列的幂与乘积，用四则运算法则，定理 1.3.2）。故

$$\lim_{n\to\infty}\left(\frac{n+1}{n-1}\right)^n = \mathrm{e}^2 \cdot 1 = \mathrm{e}^2 \approx 7.389.$$

每步依据：代数恒等变形 + 幂运算法则 + 重要极限 + 四则运算法则。

**校验**：$\mathrm{e}^2$，与正文一致。

## 1.6（计算推导｜对应 §1.3 定理 1.3.3 夹逼定理）

> 用夹逼定理证明 $\displaystyle\lim_{n\to\infty}\sum_{k=1}^{n}\frac{1}{n^2+k} = 0$。

**证**：记 $S_n = \frac{1}{n^2+1} + \frac{1}{n^2+2} + \cdots + \frac{1}{n^2+n}$，共 $n$ 项。

**放缩**：对每个 $k = 1, \dots, n$，分母满足 $n^2 + 1 \le n^2 + k \le n^2 + n$，取倒数后不等号反向：

$$\frac{1}{n^2+n} \le \frac{1}{n^2+k} \le \frac{1}{n^2+1}.$$

对 $k$ 从 1 到 $n$ 求和（每项同乘 $n$ 不改变方向）：

$$n \cdot \frac{1}{n^2+n} \le S_n \le n\cdot\frac{1}{n^2+1},$$

即

$$\frac{n}{n^2+n} = \frac{1}{n+1} \le S_n \le \frac{n}{n^2+1} < \frac{1}{n}.$$

两端极限：$\lim_{n\to\infty}\frac{1}{n+1} = 0$，$\lim_{n\to\infty}\frac1n = 0$（例 1.2.2）。由夹逼定理（定理 1.3.3），$\lim S_n = 0$。$\blacksquare$

**校验**：0，与正文一致。

**方法注记**：这是"和式夹逼"的标准模板——**项数 $n$ 项 × 每项最大/最小值**。凡"每项都趋于 0 但项数也在增多"的和式，都先用这招。本题若试图逐项求极限（$n$ 项每项 $\to 0$，但项数 $\to \infty$）是非法的——这正是需要夹逼的原因。

## 1.7（编程实现｜对应 §1.5 介值定理、二分法）

> 用二分法在 $[0.5, 1.5]$ 内求 $\cos x = x$ 的根，要求区间宽度小于 $10^{-12}$，打印迭代次数与最终残差。

**解题路线**：把方程写成 $g(x) = \cos x - x = 0$。$g(0.5) = \cos 0.5 - 0.5 \approx 0.3776 > 0$，$g(1.5) = \cos 1.5 - 1.5 \approx -1.4293 < 0$；$g$ 连续，由介值定理（定理 1.5.5）$[0.5, 1.5]$ 内有根。二分法每次把含根区间对半，区间宽度按 $\times\frac12$ 收缩：从宽度 1 到 $10^{-12}$ 需 $\log_2 10^{12} \approx 40$ 次。

```python
import numpy as np

g = lambda x: np.cos(x) - x          # 求 g(x)=0，即 cos x = x
lo, hi = 0.5, 1.5                     # g(lo)>0, g(hi)<0：介值定理保证根在内
it = 0
while hi - lo > 1e-12:                # 区间宽度精度要求
    mid = 0.5 * (lo + hi)
    it += 1
    if g(lo) * g(mid) < 0:            # g 在 [lo, mid] 变号 -> 根在左半
        hi = mid
    else:                             # 否则根在右半 [mid, hi]
        lo = mid
print(f"根 = {mid:.12f}, 残差 g(mid) = {g(mid):.2e}, 迭代 {it} 次")
# 预期输出（实测）：
# 根 = 0.739085133216, 残差 g(mid) = -8.48e-13, 迭代 40 次
```

**校验**：根 $\approx 0.7390851332$，与正文一致（即"不动点余弦常数" $x^\ast = \cos x^\ast$）。残差约 $10^{-13}$ 量级而非 0：这是浮点极限（$\cos$ 求值本身有 $\sim 10^{-16}$ 相对舍入误差），再次印证 §1.9 误区 5——数值实验只能"支持"结论。

## 1.8（编程实现｜对应 §1.6 实验一、§1.8 案例 2）

> 对数列 $a_n = \left(1+\frac{1}{n}\right)^{n+1/2}$ 做误差阶实验，确认误差为 $O(1/n^2)$ 量级并给出比例常数。

**理论预测（先推导再实验）**：对 $\ln a_n = \left(n+\tfrac12\right)\ln\left(1+\tfrac1n\right)$ 做 Taylor 展开：

$$\ln\left(1+\tfrac1n\right) = \frac1n - \frac{1}{2n^2} + \frac{1}{3n^3} - O\!\left(\frac{1}{n^4}\right),$$

$$\left(n+\tfrac12\right)\ln\left(1+\tfrac1n\right) = \underbrace{n\cdot\frac1n}_{=1} + \underbrace{\tfrac12\cdot\frac1n - n\cdot\frac{1}{2n^2}}_{\text{相消为 }0} + \left(\frac{n}{3} - \frac14\right)\frac{1}{n^3} + O(n^{-4}) = 1 + \frac{1}{12n^2} + O(n^{-3}).$$

于是 $a_n = \mathrm{e}\,\mathrm{e}^{1/(12n^2)+O(n^{-3})} = \mathrm{e} + \dfrac{\mathrm{e}}{12n^2} + O(n^{-3})$：误差为 $O(1/n^2)$，比例常数 $\dfrac{\mathrm{e}}{12} \approx 0.2265$。对比 $a_n = (1+\frac1n)^n$ 的 $O(1/n)$（§1.8 案例 2）：加半个幂次恰好消去一阶误差项。

```python
import numpy as np

print("n            err = a_n - e     n^2 * err")
for n in [10, 100, 1000, 10**4]:
    a = (1.0 + 1.0 / n) ** (n + 0.5)
    err = a - np.e                    # 理论：err ~ e/(12 n^2) > 0
    print(f"n={n:>10d}  err={err:+.6e}  n^2*err={n*n*err:+.6f}")
print("e/12 =", np.e / 12)
# 预期输出（实测）：n^2*err 收敛到 e/12 ≈ 0.226523，验证 err = O(1/n^2)：
# n=        10  err=+2.058214e-03  n^2*err=+0.205821
# n=       100  err=+2.242794e-05  n^2*err=+0.224279
# n=      1000  err=+2.262969e-07  n^2*err=+0.226297
# n=     10000  err=+2.264709e-09  n^2*err=+0.226471
# e/12 = 0.22652348570492042
```

**校验与工程注记**：$n^2\cdot\text{err} \to \mathrm{e}/12 \approx 0.2265$，误差确实为 $O(1/n^2)$。**注意不要把 $n$ 加到 $10^6$ 以上**：实测 $n \ge 10^6$ 时误差反而被浮点污染（$1 + 1/n$ 本身只有约 $10^{-16}$ 的相对表示精度，经 $n$ 次幂放大后淹没真实的 $10^{-12}$ 量级差异）——理论误差阶与机器可分辨范围要一起管理（第 4 章例 4.3.2 的 U 形曲线是同一主题）。

## 1.9（开放思考｜对应 §1.3 柯西收敛准则）

> 为什么"相邻两次迭代差距很小"不足以保证逼近了真正的最优解？构造一个迭代序列使其相邻差趋于 0 但不收敛。

**核心区别**：柯西准则（§1.3）要求的是 $\forall \varepsilon > 0,\ \exists N$，使得**任意** $m, n > N$ 都有 $|a_m - a_n| < \varepsilon$——"尾部**两两**接近"。而算法里常用的停止条件 $\|x_{k+1} - x_k\| < \varepsilon$ 只检查**相邻一对**，是严格更弱的条件（柯西 ⟹ 相邻差小；反之不成立）。

**反例 1（最简单）**：$x_k = \sqrt{k}$。相邻差 $x_{k+1} - x_k = \sqrt{k+1} - \sqrt{k} = \dfrac{1}{\sqrt{k+1}+\sqrt{k}} \to 0$，但 $x_k \to +\infty$，不收敛到任何点。

**反例 2（发散级数视角）**：$x_k = \sum_{j=1}^{k} \frac1j$（调和级数部分和）。相邻差 $= \frac{1}{k+1} \to 0$，但 $x_k \sim \ln k \to \infty$。"每步只挪一小步，但步数无限，总位移可以任意大。"

**优化语境的解读**：设迭代沿一条"缓坡长廊"缓慢漂移（每步下降量 $\to 0$、步长 $\to 0$），停止条件触发时可能离任何驻点都很远；或者在高维损失面上沿一条平坦的谷底缓慢爬行，梯度范数与步长都小，却尚未到达谷底。**实践对策**：柯西条件本身没错，错在把它弱化成"只看相邻一项"——应同时监控梯度范数 $\|\nabla f\|$、目标函数的相对变化、以及（重要场合）从多个初值重启验证。柯西准则的理论合法性（§1.10）只保证"满足两两接近就收敛"（在完备空间中），不保证"相邻接近就两两接近"。

## 1.10（开放思考｜对应 §1.4 单侧极限、§2.1 预告）

> ReLU 在 0 处连续但不可导。框架在 0 处人为规定导数值（0 或 1），为什么实践中"几乎无害"？

**答题要点**（三个层次，从数学到工程）：

1. **测度论理由（最根本）**：ReLU 的不可导点只有孤立的单点 $x=0$。真实网络的输入、权重使预激活值**恰好等于 0** 的概率为零（连续分布中单点概率为 0——第 6 章 6.1 节的积分论根源：有限个点/一条曲线上的函数值不影响积分）。因此人为规定的导数值几乎从不被"真正用到"。
2. **数值理由**：即使预激活值极小但非零，梯度由 $x>0$ 或 $x<0$ 分支给出；浮点意义下"恰好为 0"的样本占比可忽略。反向传播中这一个样本的梯度分量对参数更新（mini-batch 平均）的影响是 $O(1/\text{batch size})$。
3. **优化/凸分析理由**：ReLU 在 0 处虽不可导，但它是凸函数，存在**次微分** $[0,1]$——取 0 或 1 都是合法的次梯度。一阶方法只需要"下降方向"信息（§2.6），次梯度满足这一要求；收敛性分析（第 5 章、最优化课程）对凸非光滑函数使用次微分而非导数，结论不变。

**延伸**：这解释了为什么 PyTorch/TensorFlow 都敢直接 `max(x, 0)` 配固定导数；也预告了最优化课程的"次梯度方法"与"光滑化技巧"（如 $\text{softplus} = \log(1+e^x)$ 作为光滑近似）。

## 1.11（挑战题｜对应 §1.5 一致连续、Cantor 定理）

> 证明：$f$ 在 $\mathbb{R}$ 上一致连续，且 $|f(x)| \le \frac{|x|}{2} + 1$，不借助 Cantor 定理直接用定义证明 $f$ 一致有界。

**勘误提示（重要）**：本题**按字面陈述是不成立的**——存在满足全部已知条件却不一致有界的反例：$f(x) = \dfrac{x}{2}$。它一致连续（Lipschitz：$|f(x)-f(y)| = \frac12|x-y|$，取 $\delta = 2\varepsilon$ 即可），且 $|f(x)| = \frac{|x|}{2} \le \frac{|x|}{2} + 1$，但 $f$ 显然无界。所以"一致连续 + 线性增长控制 $\Rightarrow$ 一致有界"这个推理链缺一环：**增长控制 $\frac{|x|}{2}+1$ 本身允许无界**。此题的正确形态（也正是题中提示"固定一个 $\delta$，在长度为 $\delta$ 的网格上分段控制"所证明的）是如下定理，我们完整证明它：

> **定理（一致连续 ⟹ 至多线性增长）**：设 $f$ 在 $\mathbb{R}$ 上一致连续，则存在常数 $A, B \ge 0$ 使得 $|f(x)| \le A|x| + B$ 对一切 $x \in \mathbb{R}$ 成立。

**证明（网格分段控制，只用定义）**：取 $\varepsilon = 1$。由一致连续性，存在 $\delta > 0$，使得

$$|x - y| < \delta \implies |f(x) - f(y)| < 1. \tag{$\ast$}$$

任取 $x \in \mathbb{R}$。不妨设 $x > 0$（$x<0$ 对称；$x=0$ 时 $|f(0)|\le|f(0)|$ 平凡）。把 $[0, x]$ 用步长 $\frac{\delta}{2}$ 分成网格，节点为 $t_j = \frac{j\delta}{2}$，$j = 0, 1, \dots, m$，其中 $m = \left\lceil \frac{2x}{\delta} \right\rceil$（末端 $t_m \ge x$，最后一段可能短于 $\frac\delta2$，不影响）。相邻节点间距 $\le \frac{\delta}{2} < \delta$，由 $(\ast)$：

$$|f(t_{j+1}) - f(t_j)| < 1, \qquad j = 0, \dots, m-1.$$

三角不等式逐段累加：

$$|f(t_m) - f(t_0)| \le \sum_{j=0}^{m-1} |f(t_{j+1}) - f(t_j)| < m \le \frac{2x}{\delta} + 1.$$

最后把 $t_m$ 换回 $x$：$|x - t_{m-1}| \le \frac\delta2 < \delta$，故 $|f(x) - f(t_{m-1})| < 1$，而 $t_{m-1} \le x$ 处用上式（对 $t_{m-1}$ 与 $0$ 之间的网格同样累加，段数 $\le \frac{2x}{\delta}$）：

$$|f(x)| \le |f(0)| + \left(\frac{2x}{\delta} + 1\right) + 1 = \frac{2}{\delta}\,|x| + |f(0)| + 2.$$

取 $A = \frac{2}{\delta}$，$B = |f(0)| + 2$，即得 $|f(x)| \le A|x| + B$。$\blacksquare$

**深入方向**：本定理说明一致连续函数的增长速度被"钉死"在至多线性；而 $f(x) = x/2$ 说明线性增长可以达到、无界不可避免。要得到**有界**，需要额外条件，例如：
- $f(x) \to 0$（当 $|x| \to \infty$）：则在 $[-R, R]$ 外 $|f| < 1$，在 $[-R,R]$ 上用 Cantor 定理（或最值定理）得全局界；
- 定义域是紧集（有界闭）：这正是 Cantor 定理（定理 1.5.7）的内容，也是本题原意"为什么不借助 Cantor"想对照的对象——Cantor 定理在紧集上一步给出一致连续 + 有界，而 $\mathbb{R}$ 非紧，两件事都必须另证，且"有界"这件事在不加衰减假设时**本来就是假的**。

**这一题的元教训**：做证明题先检验命题是否为真——找一个最小反例（$f(x)=x/2$）只需十秒，却能避免为假命题"找证明"的徒劳。

## 1.12（挑战题·阅读性｜对应 §1.3 柯西收敛准则、§1.5 不动点）

> 查阅 Rudin《数学分析原理》定理 3.11（柯西收敛准则），复述其证明中实数完备性出现在哪一步；并解释为什么在有理数系 $\mathbb{Q}$ 中柯西列可以不收敛（以 $a_n = (1+\frac1n)^n$ 为例）。

**Rudin 定理 3.11 的证明结构复述**（陈述：$\mathbb{R}$（或任意完备度量空间）中 $\{p_n\}$ 收敛 $\iff$ $\{p_n\}$ 是柯西列）：

- **"收敛 ⟹ 柯西"方向**：设 $p_n \to p$。任给 $\varepsilon > 0$，取 $N$ 使 $n > N$ 时 $|p_n - p| < \frac{\varepsilon}{2}$；则 $m, n > N$ 时 $|p_m - p_n| \le |p_m - p| + |p - p_n| < \varepsilon$。**这一步不需要完备性**，在任何度量空间成立。
- **"柯西 ⟹ 收敛"方向**分三步：
  1. **柯西列有界**：取 $\varepsilon = 1$，存在 $N$ 使 $m, n > N$ 时 $|p_m - p_n| < 1$；于是尾部所有项落在 $p_{N+1}$ 的 1-邻域内，加上有限个头部项，整体有界。
  2. **有界序列有收敛子列**（Bolzano–Weierstrass 定理）。**实数完备性正是在这一步进入**：B–W 定理的证明（区间套/二分法）依赖闭区间套定理，而后者依赖实数的**确界原理/单调有界原理**（§1.3 定理 1.3.6）——"单调有界必有上确界属于这个数系"。在 $\mathbb{Q}$ 中，单调有界的有理数列可以没有有理数的确界（见下），区间套可以套到一个"空点"上，B–W 失效。
  3. **子列的极限就是全列的极限**：柯西性 + 子列收敛（$\varepsilon/2$ 论证：$|p_n - p| \le |p_n - p_{n_k}| + |p_{n_k} - p|$）。这一步也是纯不等式，不需完备性。

**$\mathbb{Q}$ 中的遭遇**：取 $a_n = \left(1+\frac1n\right)^n$，每个 $a_n$ 都是**有理数**（$n$ 次幂的分子分母运算保持有理性）。在 $\mathbb{R}$ 中它收敛于 $\mathrm{e} = 2.71828\ldots$，因此它是柯西列（上面"收敛 ⟹ 柯西"方向在 $\mathbb{Q}$ 内部依然合法地成立）。但 $\mathrm{e}$ 是**无理数**（证明梗概：若 $\mathrm{e} = p/q$（既约），则 $N = q!\,\mathrm{e}$ 应为整数；但

$$N = \sum_{k=0}^{q} \frac{q!}{k!} + \sum_{k=q+1}^{\infty} \frac{q!}{k!},$$

第一和为整数，而剩余部分满足 $0 < \sum_{k \ge q+1} \frac{q!}{k!} < \frac{1}{q+1}\left(1 + \frac{1}{q+1} + \cdots\right) = \frac1q \le 1$，即 $N$ = 整数 + $(0,1)$ 中的数，矛盾）。于是 $a_n$ 是 $\mathbb{Q}$ 中的柯西列，却**在 $\mathbb{Q}$ 中没有极限**——"柯西 ⟹ 收敛"在 $\mathbb{Q}$ 中失效，因为第 2 步（B–W/完备性）不成立：$\{a_n\}$ 单调递增有上界（如上界 3），其"应该的"上确界 $\mathrm{e} \notin \mathbb{Q}$。

**意义**：这说明柯西准则**不是**极限定义的平凡改写，它等价于数系的完备性；也说明数值算法中"相邻差足够小"的停止条件的理论合法性，依赖于我们工作在 $\mathbb{R}$（浮点数 $\mathbb{F}$ 还更进一步——连柯西性都要受机器精度限制，见 §1.9 误区 5）。

# 第 2 章 一元微分（对应正文 §2.13）

## 2.1（概念辨析｜对应 §2.1 定理 2.1.3、§2.2）

> 判断对错：（a）若 $f$ 在 $x_0$ 连续，则存在 $x_0$ 的邻域使 $f$ 连续；（b）若 $f'$ 在 $x_0$ 存在，则 $f'$ 在 $x_0$ 连续。

**(a) 错误**。反例：$f(x) = \begin{cases} x, & x \in \mathbb{Q}\\ 0, & x \notin \mathbb{Q}\end{cases}$。在 $x_0 = 0$ 处：$|f(x)| \le |x|$，故 $\lim_{x\to 0} f(x) = 0 = f(0)$，$f$ 在 0 连续。但对任何 $x_0 \neq 0$：沿有理点 $f(x) \to x_0$，沿无理点 $f(x) \to 0$，二者不等，$f$ 在 $x_0$ 不连续。于是**不存在 0 的任何邻域使 $f$ 在其中处处连续**——连续是"一点一点"的性质，不自带邻域版。对比：若 $f$ 在 $x_0$ **可导**，则由 $f'$ 的定义需 $f$ 在 $x_0$ 的邻域内有定义，但仍不保证邻域内连续（见 (b) 的函数）。

**(b) 错误**。反例（§4.13 练习 4.1 会再次用到它）：$f(x) = x^2\sin\frac1x$（$f(0)=0$）。用定义：$f'(0) = \lim_{h\to0}\frac{h^2\sin(1/h)}{h} = \lim_{h\to0} h\sin\frac1h = 0$，导数存在。但 $x \neq 0$ 时 $f'(x) = 2x\sin\frac1x - \cos\frac1x$，其中第一项 $\to 0$、第二项在 $\pm1$ 间振荡无极限，故 $\lim_{x\to0} f'(x)$ 不存在，$f'$ 在 0 处不连续。

**要点**："$f'$ 存在"（可导）与"$f'$ 连续"（$C^1$）是严格不同的两个层级；教材理论结果中凡写"偏导/导数连续"处（如 §5.2 定理 5.2.5）都不可弱化为"存在"。

## 2.2（概念辨析｜对应 §2.3 定理 2.3.2）

> 设 $f$ 在 $[a,b]$ 上满足 Rolle 定理条件，满足 $f'(\xi) = 0$ 的 $\xi$ 一定唯一吗？

**不唯一**。Rolle 定理是**存在性**命题，对 $\xi$ 的个数不做任何断言。

反例 1：$f(x) = \sin x$ 在 $[0, 2\pi]$ 上：$f(0) = f(2\pi) = 0$，连续、可导条件全满足；$f'(x) = \cos x = 0$ 在 $\xi = \frac{\pi}{2}$ 与 $\xi = \frac{3\pi}{2}$ 两点成立——**两个** $\xi$。

反例 2（无穷多个）：$f \equiv c$（常数）满足一切条件，每一点都是 $\xi$。

**常见错误**：把定理叙述记成"存在唯一的 $\xi$"。中值定理族（Rolle / Lagrange / Cauchy / 积分中值定理）全部只保证存在性；这也是 §2.9 误区 2（"$\xi$ 不可用于精确计算"）的另一面。

## 2.3（概念辨析｜对应 §2.5 定理 2.5.4）

> "凸函数的驻点必为全局最小点"——写出完整证明，标明每一步用到的定理。

**命题**：设 $f$ 在区间 $I$ 上凸且可导，$x_0 \in I$ 满足 $f'(x_0) = 0$，则 $f(x) \ge f(x_0)$ 对一切 $x \in I$ 成立（全局最小点）。

**证明**：

1. 由 $f$ 凸且可导，使用**凸函数的一阶刻画（定理 2.5.4）**：对任意 $x, x_0 \in I$，

$$f(x) \ge f(x_0) + f'(x_0)(x - x_0).$$

（该定理的证明链条：凸性定义 2.5.2 ⟹ 割线斜率单调 ⟹ 用 **Lagrange 中值定理（定理 2.3.3）**控制差商 ⟹ 得切线是全局下界。）

2. 由驻点假设 $f'(x_0) = 0$，上式右端第二项为 0：

$$f(x) \ge f(x_0) + 0 = f(x_0), \qquad \forall x \in I. \qquad\blacksquare$$

**要点**：证明只用了一阶信息（凸 + 驻点），完全不需要二阶条件。这就是"凸优化好优化"的全部原因（§2.5 的正文强调处）：**任何一点的线性逼近都是全局下界，梯度为零使下界收紧到函数值本身**。对比非凸情形：$f(x) = x^3$ 的驻点 $x=0$ 不是极值点——一阶刻画失效的原因正是 $f$ 非凸，切线不再在函数下方。

## 2.4（计算推导｜对应 §2.1 定义 2.1.1）

> 用定义证明 $f(x)=\sqrt{x}$ 在 $x=1$ 处的导数为 $\frac12$。

**证**：按定义 2.1.1，

$$f'(1) = \lim_{h \to 0} \frac{f(1+h) - f(1)}{h} = \lim_{h \to 0} \frac{\sqrt{1+h} - 1}{h}.$$

$h$ 需满足 $1 + h > 0$（定义域），即 $h > -1$；$h \to 0$ 时无碍。**分子有理化**（不改变值，消去根号差）：

$$\frac{\sqrt{1+h} - 1}{h} = \frac{(\sqrt{1+h} - 1)(\sqrt{1+h} + 1)}{h\,(\sqrt{1+h} + 1)} = \frac{(1+h) - 1}{h(\sqrt{1+h}+1)} = \frac{h}{h\,(\sqrt{1+h}+1)} = \frac{1}{\sqrt{1+h} + 1}.$$

（$h \neq 0$ 时约去 $h$ 合法。）现在分母在 $h \to 0$ 时趋于 $\sqrt1 + 1 = 2$（$\sqrt{\cdot}$ 在 1 处连续），由极限四则运算法则（定理 1.3.2）：

$$f'(1) = \frac{1}{2}. \qquad\blacksquare$$

**校验**：$\lim_{h\to0}\frac{\sqrt{1+h}-1}{h} = \frac12$，与题给校验一致。（另法：$\sqrt{x}$ 是 $x^2$ 的反函数，用反函数求导定理 2.2.3：$(\sqrt{x})' = \frac{1}{2\sqrt x}$，代 $x=1$ 得 $\frac12$——两条路线互相印证。）

## 2.5（计算推导｜对应 §2.4 洛必达法则）

> （a）$\lim_{x\to0}\dfrac{\tan x - x}{x^3}$；（b）$\lim_{x\to0^+}(\ln x)^x$；（c）$\lim_{x\to+\infty} x^{1/x}$。

**(a)（$\frac00$ 型，洛必达或泰勒两条路线）**

*路线一（泰勒展开，§4.2 后回看更透）*：$\sin x = x - \frac{x^3}{6} + o(x^3)$，$\cos x = 1 - \frac{x^2}{2} + o(x^2)$，相除：

$$\tan x = \frac{x - \frac{x^3}{6} + o(x^3)}{1 - \frac{x^2}{2} + o(x^2)} = \left(x - \frac{x^3}{6}\right)\left(1 + \frac{x^2}{2}\right) + o(x^3) = x + \left(\frac12 - \frac16\right)x^3 + o(x^3) = x + \frac{x^3}{3} + o(x^3).$$

故 $\tan x - x = \frac{x^3}{3} + o(x^3)$，极限 $= \frac13$。

*路线二（洛必达，核对三条件）*：$\frac00$ 型 ✓；$(\tan x - x)' = \sec^2 x - 1 = \tan^2 x$，分母导数 $3x^2$ 在去心邻域内非零 ✓；于是

$$\lim_{x\to0}\frac{\tan x - x}{x^3} = \lim_{x\to0}\frac{\tan^2 x}{3x^2} = \frac13\left(\lim_{x\to0}\frac{\tan x}{x}\right)^2 = \frac13 \cdot 1 = \frac13,$$

其中 $\lim_{x\to0}\frac{\tan x}{x} = \lim \frac{\sin x}{x}\cdot\frac{1}{\cos x} = 1$（重要极限 + $\cos$ 连续）。每步都满足洛必达三条件（定理 2.4.1）。

**校验**：$\frac13$ ✓。

**(b)（$0^{-\infty}$…实为 $(-\infty)^0$ 型，标准处理：取对数）**：设 $y = (\ln x)^x$，则 $\ln y = x \ln(\ln x)$。当 $x \to 0^+$，$\ln x \to -\infty$，$\ln(\ln x) = \ln(-\ln x)$ 有意义但 $\to +\infty$；这是 $0 \cdot \infty$ 型，化归为 $\frac{\infty}{\infty}$：

$$x\ln(\ln x) = \frac{\ln(\ln x)}{1/x} = \frac{\ln(-\ln x)}{e^{-\ln x}\cdot(-1)\cdot} \; \text{（直接洛必达）}:\quad \lim_{x\to0^+}\frac{\ln(-\ln x)}{1/x} = \lim_{x\to0^+}\frac{\frac{1}{-\ln x}\cdot\left(-\frac1x\right)}{-1/x^2} = \lim_{x\to0^+}\frac{x}{-\ln x}.$$

（洛必达：分子导数 $\frac{d}{dx}\ln(-\ln x) = \frac{1}{-\ln x}\cdot(-\frac1x)$，分母导数 $-\frac{1}{x^2}$；比值 $= \frac{x}{-\ln x}$。）换元 $t = -\ln x \to +\infty$：$\dfrac{x}{-\ln x} = \dfrac{e^{-t}}{t} \to 0$（指数衰减压倒对数增长）。

故 $\lim \ln y = 0$，由指数函数连续性 $\lim y = \mathrm{e}^0 = 1$。

**校验**：1，与正文一致。**易错提醒（§4.9 误区 6）**：取对数后必须用 $\mathrm{e}$ 还原，本题收尾 $e^0 = 1$ 不能漏。

**(c)（$\infty^0$ 型）**：$x^{1/x} = \mathrm{e}^{\frac{\ln x}{x}}$。其中

$$\lim_{x\to+\infty}\frac{\ln x}{x} \;\overset{\frac{\infty}{\infty}\text{, 洛必达}}{=}\; \lim_{x\to+\infty}\frac{1/x}{1} = 0.$$

故 $\lim x^{1/x} = \mathrm{e}^0 = 1$。

**校验**：1，与正文一致。（数值感受：$10^{0.1} \approx 1.259$，$10^{6}$ 的 $10^{-6}$ 次幂 $\approx 1.0000138$——确实缓慢趋 1。）

## 2.6（计算推导｜对应 §2.3 Lagrange 中值定理）

> 用 Lagrange 中值定理证明：$x>0$ 时 $\dfrac{x}{1+x} < \ln(1+x) < x$。

**证**：令 $g(t) = \ln(1+t)$，它在 $[0, x]$（$x > 0$）上连续、在 $(0, x)$ 内可导（初等函数连续性，定理 1.5.4；导数 $g'(t) = \frac{1}{1+t}$）。由 **Lagrange 中值定理（定理 2.3.3）**：存在 $\xi \in (0, x)$ 使

$$\ln(1+x) - \ln 1 = g'(\xi)\,(x - 0) = \frac{x}{1+\xi}. \tag{$\ast$}$$

**估计 $\frac{1}{1+\xi}$**：由 $0 < \xi < x$，得 $1 < 1 + \xi < 1 + x$，取倒数（均为正数，不等号反向）：

$$\frac{1}{1+x} < \frac{1}{1+\xi} < 1.$$

三边同乘正数 $x$：

$$\frac{x}{1+x} < \frac{x}{1+\xi} < x.$$

代回 $(\ast)$ 即得

$$\frac{x}{1+x} < \ln(1+x) < x, \qquad x > 0. \qquad\blacksquare$$

**评注**：这就是最优化中"$\log$ 函数的上下界"的标准来源（例如 EM 算法、互信息下界中的 $\ln(1+t) \le t$）；右半边不等式等价于 $g$ 的切线在下方（$g$ 凸，对照 2.3 题），左半边来自曲率下界。$x\to0$ 时两边都 $\sim x$，本题给出的是**定量**的夹逼。

## 2.7（编程实现｜对应 §4.3 例 4.3.2 预告、§2.9 误区 6）

**解析导数**（乘积法则 + 链式法则，定理 2.2.1/2.2.2）：

$$f'(x) = -2x\,\mathrm{e}^{-x^2}\cos 3x - 3\,\mathrm{e}^{-x^2}\sin 3x = -\mathrm{e}^{-x^2}\left(2x\cos 3x + 3\sin 3x\right).$$

```python
import numpy as np

f  = lambda x: np.exp(-x**2) * np.cos(3*x)
df = lambda x: -np.exp(-x**2) * (2*x*np.cos(3*x) + 3*np.sin(3*x))
x0, true = 0.7, df(0.7)

print(f"true f'({x0}) = {true:.15f}")
best = (None, np.inf)
for k in range(1, 13):
    h = 10.0**(-k)

        best = (h, err)
    print(f"h=1e-{k:<2d}  err={err:.3e}")
print(f"best h = {best[0]:.0e}, min err = {best[1]:.3e}")

# best h = 1e-05, min err = 1.650e-11
```

**校验与解读**：误差曲线 U 形，谷底在 $h = 10^{-5}$、谷值 $\approx 1.65\times10^{-11}$，与理论（§4.3 例 4.3.2：截断误差 $\frac{M_3h^2}{6}$ 下降段 + 舍入误差 $\frac{\varepsilon_{\text{mach}}|f|}{h}$ 上升段，最优 $h^\ast \sim 10^{-5}$）一致。注意 $h=10^{-1}$ 到 $10^{-5}$ 误差每次约缩 100 倍——正是截断误差 $O(h^2)$ 的特征（$h$ 缩 10 倍、误差缩 100 倍）；$h < 10^{-5}$ 后趋势反转，舍入误差接管。

## 2.8（编程实现｜对应 §2.6 梯度下降一维原型）

> 在 $f(x) = x^4 - 4x^2$ 上运行一维梯度下降（梯度 $4x^3 - 8x$）：$\eta = 0.01$ 与 $\eta = 0.1$，从 $x_0 = 2.5$ 出发迭代 50 步；再取 $\eta = 0.2$ 观察发散。

**先做理论定位（很重要）**：驻点 $f'(x) = 4x^3 - 8x = 4x(x^2-2) = 0$ 给出 $x = 0, \pm\sqrt2$。$f'' = 12x^2 - 8$：$x = \pm\sqrt2$ 处 $f'' = 16 > 0$ 极小，$x=0$ 处 $f'' = -8 < 0$ 极大。**全局最小点为 $x = \pm\sqrt2 \approx \pm1.4142$，最小值 $f = 4 - 8 = -4$**。

> ⚠️ **勘误**：正文校验值"接近 $x = \pm 2$"有误——$x=\pm2$ 不是驻点（$f'(\pm2) = 32-16 = 16 \neq 0$）。正确目标为 $x = \pm\sqrt2$，下述运行结果与之相符。

```python
import numpy as np

grad = lambda x: 4*x**3 - 8*x          # f'(x)
fv   = lambda x: x**4 - 4*x**2         # f(x)

for eta in [0.01, 0.1, 0.2]:
    x = 2.5
    diverged = False
    for k in range(50):
        x = x - eta * grad(x)          # x_{k+1} = x_k - eta * f'(x_k)
        if abs(x) > 1e100:             # 发散检测
            print(f"eta={eta}: 在第 {k+1} 步发散, |x| = {abs(x):.2e}")
            diverged = True
            break
    if not diverged:
        print(f"eta={eta:<5} x_50 = {x:+.6f}  f(x_50) = {fv(x):+.6e}")
# 预期输出（实测）：
# eta=0.01  x_50 = +1.414279  f(x_50) = -4.000000e+00   -> 收敛到 +sqrt(2)
# eta=0.1   x_50 = -1.414214  f(x_50) = -4.000000e+00   -> 冲过极大点跳到 -sqrt(2)
# eta=0.2:  在第 6 步发散, |x| = 1.08e+174
```

**解读**：

- $\eta = 0.01$：$x_0 = 2.5$ 附近曲率 $f''(2.5) = 67$，$\eta \cdot \max|f''| < 2/L$ 条件（§2.6）满足，平稳收敛到右侧极小点 $+\sqrt2$。
- $\eta = 0.1$：第一步 $x_1 = 2.5 - 0.1 \times 42.5 = -1.75$——**一步跨过原点处的极大点**跳到左半轴，最终停在 $-\sqrt2$。两个极小点完全对称，落进哪个"盆地"由初值与大步长的耦合决定。
- $\eta = 0.2$：发散（6 步内 $|x|$ 爆到 $10^{174}$）——这是 §2.6 "学习率过大会爆炸/loss 变 NaN"的具体上演：局部 $\eta \cdot f'' > 2$ 时每步放大而非缩小。

**校验**：两者都收敛到 $f = -4$（全局最小值），位置 $x = \pm\sqrt2 \approx \pm1.41421$（正文"±2"为勘误，见上）。

## 2.9（开放思考｜对应 §2.6 下降量公式）

> 解释为什么 SGD（$g_k$ 是梯度的无偏估计）在期望意义下仍能收敛，但需要 $\eta$ 随 $k$ 衰减。

**推导路线（把 2.6 节的下降量公式逐项"加上噪声"）**。设 $|f''| \le L$（$L$-光滑），迭代 $x_{k+1} = x_k - \eta g_k$，其中 $\mathbb{E}[g_k \mid x_k] = f'(x_k)$（无偏）。对 $f(x_{k+1})$ 用 §2.6 的二次上界 $f(y) \le f(x) + f'(x)(y-x) + \frac{L}{2}(y-x)^2$，代入 $y = x_k - \eta g_k$：

$$f(x_{k+1}) \le f(x_k) - \eta g_k f'(x_k) + \frac{L\eta^2}{2} g_k^2.$$

对随机性取条件期望，用无偏性 $\mathbb{E}[g_k|x_k] = f'(x_k)$ 与 $\mathbb{E}[g_k^2|x_k] = [f'(x_k)]^2 + \sigma_k^2$（$\sigma_k^2$ 为梯度估计方差）：

$$\mathbb{E}[f(x_{k+1}) \mid x_k] \le f(x_k) - \eta\left(1 - \frac{L\eta}{2}\right)[f'(x_k)]^2 + \frac{L\eta^2}{2}\,\sigma_k^2.$$

**对比确定性情形（§2.6）**：多出最后一项 $\frac{L\eta^2}{2}\sigma_k^2$——**它只随 $\eta$ 消失，不随 $f'(x_k) \to 0$ 消失**。确定性证明"每步下降 $-\eta(1-\frac{L\eta}{2})[f']^2 < 0$"在 $f' \to 0$ 时下降量自然趋于 0、迭代停在驻点；而 SGD 中即使到达 $f' = 0$，噪声项仍以 $\frac{L\eta^2\sigma^2}{2}$ 的期望速率**抬高**损失——固定 $\eta$ 时迭代只能停在一个"噪声球"内（半径由 $\eta\sigma$ 决定），在驻点附近游荡而非收敛。

**因此需要 $\eta_k \to 0$**：让噪声项 $\frac{L\eta_k^2\sigma^2}{2} \to 0$ 快于优化项的累积。经典 Robbins–Monro 条件 $\sum_k \eta_k = \infty$（保证走得足够远）且 $\sum_k \eta_k^2 < \infty$（保证噪声能量有限）下，期望意义可收敛到驻点。收敛率也从确定性的 $O(1/k)$（第 4 章 4.5 节）退化为 $O(1/\sqrt{k})$（第 4 章练习 4.9 定性分析此点）。

**一句话总结**：无偏性保证"平均而言在往低处走"（期望下降量为正，只要 $0 < \eta < 2/L$ 且 $\|f'\|$ 不太小）；方差项保证"走不精确"——固定步长永远带着 $O(\eta)$ 的噪声地板，必须衰减步长才能让地板消失。

## 2.10（开放思考｜对应 §2.5 Fermat 引理、凸性）

> 非凸情形下"梯度为零"还意味着什么？什么信息丢失了？

**仍然成立的部分**：Fermat 引理（定理 2.3.1）只是必要条件，与凸性无关——可微函数的内部（局部）极值点必为驻点。所以"梯度为零"仍然意味着：**该点是局部极值/鞍点的候选**，且在极小的刻画里它是"一阶最优"——沿任何方向的线性变化率为 0，小步移动在一阶意义下不改变损失。

**丢失/失效的部分**：

1. **全局性丢失**。"凸 + 驻点 = 全局最优"依赖凸函数一阶刻画（定理 2.5.4，切线是全局下界）；非凸时切线可能穿到函数上方，驻点只是"碗底、山顶、或马鞍中心"三选一（第 5 章 5.4 节：由 Hessian 特征值符号区分）。
2. **局部极小性本身也不再保证**。$f(x) = x^3$ 在 0 处梯度为零但既非极大也非极小（§2.9 误区 1）——需要二阶（Hessian 正定/负定/不定）甚至更高阶信息，而深度网络的 Hessian 有 $n^2$ 个元素，$n \sim 10^{11}$ 时不可行。
3. **"哪个盆"的信息丢失**。非凸损失面有大量极小点，"梯度为零"不告诉你落在哪个盆地、该盆地泛化性能如何；经验上不同极小点的泛化差异可能很大。实践用训练动态（SGD 噪声、动量、学习率调度）而非静态一阶条件来"选盆"。
4. **深度学习的特殊地形**（第 5 章 5.4 节预告）：高维中**鞍点远多于局部极小**（驻点是极小要求 Hessian 全部 $n$ 个特征值为正，是低概率事件），所以"梯度为零"在实践中最常见的含义其实是"撞上鞍点"——这也解释了为什么训练后期 loss 长时间平台后突然下降。

**一句话**：一阶条件是"必要门票"，凸性是"全场通用 VIP"；非凸世界里门票只能入场，座位好坏要靠二阶信息（贵）或训练动力学（随机性）决定。

## 2.11（挑战题｜对应 §2.6 L-光滑与下降保证、§2.5 凸性）

> 设 $f$ 二阶可导且 $m \le f''(x) \le L$（$0 < m \le L$）。证明梯度下降（步长 $\eta \le \frac1L$）满足
> $f(x_k) - f(x^\ast) \le \dfrac{L\,\|x_0 - x^\ast\|^2}{2}\left(1 - \dfrac{m\eta}{L}\right)^k$。

这是最优化课程"强凸 + $L$-光滑 ⟹ 线性收敛"定理的一维版。证明分四步，全部工具来自本章。

**第 0 步（两个双向不等式，由 $f''$ 的上下界）**。

*(0a) $L$-光滑上界*：令 $h(y) = f(y) - \frac{L}{2}y^2$，则 $h''(y) = f''(y) - L \le 0$，$h$ 凹。凹函数的切线在图像**上方**（凸一阶刻画定理 2.5.4 的镜像）：$h(y) \le h(x) + h'(x)(y-x)$，即

$$f(y) \le f(x) + f'(x)(y-x) + \frac{L}{2}(y-x)^2. \tag{上界}$$

*(0b) 强凸下界*：令 $g(y) = f(y) - \frac{m}{2}y^2$，则 $g'' = f'' - m \ge 0$，$g$ 凸。由**凸函数一阶刻画（定理 2.5.4）**：$g(y) \ge g(x) + g'(x)(y-x)$，即

$$f(y) \ge f(x) + f'(x)(y-x) + \frac{m}{2}(y-x)^2. \tag{下界}$$

**第 1 步（PL 型不等式：梯度平方控制次优性）**。在下界中取 $y = x^\ast$（$f(x^\ast) = f^\ast$），记 $d = x - x^\ast$：

$$f^\ast \ge f(x) + f'(x)(x^\ast - x) + \frac{m}{2}d^2 = f(x) - f'(x)\,d + \frac{m}{2}d^2.$$

右端作为 $d$ 的二次函数，其最小值在 $d = \frac{f'(x)}{m}$ 处取得，值为 $-\frac{[f'(x)]^2}{2m}$。于是

$$f^\ast \ge f(x) - \frac{[f'(x)]^2}{2m} \quad\Longleftrightarrow\quad [f'(x)]^2 \ge 2m\,(f(x) - f^\ast). \tag{PL}$$

**第 2 步（每步期望/确定性下降）**。在**上界**中取 $y = x_{k+1} = x_k - \eta f'(x_k)$，记 $f'_k = f'(x_k)$，$y - x = -\eta f'_k$：

$$f(x_{k+1}) \le f(x_k) - \eta [f'_k]^2 + \frac{L\eta^2}{2}[f'_k]^2 = f(x_k) - \eta\left(1 - \frac{L\eta}{2}\right)[f'_k]^2.$$

**第 3 步（收缩递推）**。把 (PL)（在 $x = x_k$ 处）代入第 2 步：

$$f(x_{k+1}) - f^\ast \le f(x_k) - f^\ast - 2m\eta\left(1 - \frac{L\eta}{2}\right)\big(f(x_k) - f^\ast\big) = \rho\,\big(f(x_k) - f^\ast\big),$$

其中收缩因子 $\rho = 1 - 2m\eta\left(1 - \frac{L\eta}{2}\right)$。当 $0 < \eta \le \frac1L$ 时 $1 - \frac{L\eta}{2} \ge \frac12$，故 $2\eta(1 - \frac{L\eta}{2}) \ge \eta$，从而

$$\rho \le 1 - m\eta \le 1 - \frac{m}{L} < 1.$$

**第 4 步（初值锚定 + 递推展开）**。在**上界**中取 $x = x^\ast$（注意 $f'(x^\ast) = 0$）、$y = x_0$：

$$f(x_0) \le f^\ast + 0 + \frac{L}{2}\|x_0 - x^\ast\|^2 \quad\Longrightarrow\quad f(x_0) - f^\ast \le \frac{L\|x_0 - x^\ast\|^2}{2}.$$

对第 3 步递推 $k$ 次并代入初值界：

$$f(x_k) - f^\ast \le \left(1 - \frac{m}{L}\right)^k \big(f(x_0) - f^\ast\big) \le \frac{L\,\|x_0 - x^\ast\|^2}{2}\left(1 - \frac{m\eta}{L}\right)^k. \qquad\blacksquare$$

（最后一步用了 $\rho \le 1 - m\eta \le 1 - \frac mL$，与题给形式一致；取 $\eta = \frac1L$ 时收缩因子恰为 $1 - \frac mL$。）

**深入方向**：条件数 $\kappa = L/m$ 越大收敛越慢（$\rho \approx 1 - 1/\kappa$），这正是第 5 章 5.6 节病态曲率的一维根源；多元版本把 $f''$ 换成 $\lambda_{\min}(H), \lambda_{\max}(H)$，即最优化课程的核心收敛定理。

## 2.12（挑战题｜对应 §2.3 中值定理、§2.9 误区 1）

> 证明：若 $f$ 在 $(a,b)$ 可导且 $f'$ 单调，则 $f'$ 没有第一类间断点。由此说明不存在"导数在某点从 1 跳到 −1"的函数。

**证明分两步：先证 Darboux 定理（导函数有介值性），再用单调性排除跳跃。**

**第一步（Darboux 定理）**：设 $f$ 在 $(a,b)$ 可导，$a' < b'$ 为其中两点，$u$ 介于 $f'(a')$ 与 $f'(b')$ 之间；不妨设 $f'(a') < u < f'(b')$。令

$$g(x) = f(x) - u\,x, \qquad g'(x) = f'(x) - u.$$

则 $g'(a') = f'(a') - u < 0$，$g'(b') = f'(b') - u > 0$。

- $g$ 可导 ⟹ 连续 ⟹ 在 $[a', b']$ 上取得最小值（定理 1.5.5 最值定理）。
- 最小值不在端点：$g'(a') < 0$ 意味着 $h \to 0^+$ 时 $\frac{g(a'+h)-g(a')}{h} < 0$，故存在 $h$ 使 $g(a'+h) < g(a')$——$a'$ 不是最小点；同理 $g'(b') > 0$ 说明 $g(b'-h) < g(b')$，$b'$ 不是最小点。
- 设最小点为内点 $\xi \in (a', b')$。由 **Fermat 引理（定理 2.3.1）**：$g'(\xi) = 0$，即 $f'(\xi) = u$。

所以 $f'$ 取遍 $f'(a')$ 与 $f'(b')$ 之间的一切值（介值性）。$\blacksquare$

**第二步（单调 + 介值 ⟹ 连续）**：设 $f'$ 在 $(a,b)$ 上单调（不妨递增），任取 $x_0$。单调函数在每点有左右极限：

$$L_- = \sup_{x < x_0} f'(x) \le f'(x_0) \le \inf_{x > x_0} f'(x) = L_+.$$

反证：设 $L_- < f'(x_0)$（左侧跳起）。取 $c$ 使 $L_- < c < f'(x_0)$；再取 $b_1 < x_0$，则 $f'(b_1) \le L_- < c$。在 $[b_1, x_0]$ 上用 Darboux 定理：$c$ 介于 $f'(b_1)$ 与 $f'(x_0)$ 之间，故存在 $\xi \in (b_1, x_0)$ 使 $f'(\xi) = c$。但 $\xi < x_0$ 意味着 $f'(\xi) \le L_- < c$——矛盾。同理排除 $f'(x_0) < L_+$。故 $L_- = f'(x_0) = L_+$，$f'$ 在 $x_0$ 连续。$\blacksquare$

**结论**："导数在某点从 1 跳到 −1"是一个跳跃量 $= -2 \neq 0$ 的**第一类（跳跃）间断**，被上述定理禁止——不存在这样的可导函数。但注意：导函数可以有**第二类间断**：$f(x) = x^2\sin\frac1x$（$f(0)=0$）的导数在 0 处振荡无极限（2.1 题 (b)）。所以：

> **导数的间断与函数的间断"种类谱"不同**：一般函数可以有三类间断（可去/跳跃/第二类）；导函数凭 Darboux 介值性**不可能有可去与跳跃间断**（它们都要求"极限存在但 ≠ 函数值/单侧极限不等"，都会跳过中间值），只可能以第二类（振荡）方式不连续。

这也回扣 §1.5 间断点分类：单调函数若有介值性则连续——Darboux 定理恰好把"介值性"补给了一切导函数。

# 第 3 章 一元积分（对应正文 §3.14）

## 3.1（概念辨析｜对应 §3.2 定义 3.2.1/3.2.2）

> 用定义说明：改变 $f$ 在有限个点上的值不改变 Riemann 积分。

**设置**：设 $f$ 在 $[a,b]$ 上 Riemann 可积（故有界，记 $|f| \le M$），$g$ 与 $f$ 仅在 $k$ 个点 $p_1, \dots, p_k$ 处不同（$|f - g| \le 2M$ 处处成立）。要证 $g$ 可积且积分相同。

**证明（取样点计数法，直接从定义 3.2.1 出发）**：任取分割 $P$ 与取样点组 $\xi$，比较两个黎曼和：

$$|S_f - S_g| = \left|\sum_{i=1}^n \big[f(\xi_i) - g(\xi_i)\big]\Delta x_i\right|.$$

关键观察：**只有当取样点 $\xi_i$ 恰好落在坏点 $p_j$ 上时，该项才非零**。而每个坏点至多是一个小区间的取样点，故至多有 $k$ 个非零项；每项绝对值 $\le 2M \cdot \Delta x_i \le 2M\,\|P\|$。于是

$$|S_f - S_g| \le k \cdot 2M\,\|P\| = 2Mk\,\|P\|.$$

现在验证 $g$ 满足定义 3.2.2（极限为 $I = \int_a^b f$）：任给 $\varepsilon > 0$，当 $\|P\| < \delta$（$\delta$ 取得使 $|S_f - I| < \varepsilon/2$ 且 $2Mk\|P\| < \varepsilon/2$）时，对**任何**取样点组：

$$|S_g - I| \le \underbrace{|S_f - I|}_{<\,\varepsilon/2} + \underbrace{|S_g - S_f|}_{\le 2Mk\|P\| < \varepsilon/2} < \varepsilon.$$

所以 $g$ 可积且 $\int_a^b g = \int_a^b f$。$\blacksquare$

**对题目提示中疑虑的回应**："取样点可以避开坏点吗？——定义要求一切取样点。"答案是**不需要避开**：坏点被取到时，其影响被"至多 $k$ 项 × 每项宽度 $\le \|P\|$"锁死，随 $\|P\| \to 0$ 一致消失。有限个点的函数值对黎曼和的贡献是 $O(\|P\|)$ 级的，天然被极限吞掉。（用 Darboux 上和/下和也能证：坏点可被总长任意小的小区间覆盖，振幅贡献 $\to 0$。）

**概率视角**（§3.7、第 6 章 6.1 节）：这正预热了"连续分布中单点概率为零"——密度在可数零测集上怎么改，概率与期望都不变。

## 3.2（概念辨析｜对应 §3.2 定理 3.2.4 保序性）

> "若 $f$ 在 $[a,b]$ 可积、$f \ge 0$、$f \not\equiv 0$，则 $\int_a^b f > 0$。"对吗？

**不对**。反例：$f(x) = \begin{cases}1, & x = \frac{a+b}{2}\\ 0, & \text{其他}\end{cases}$（单点 1，其余全 0）。$f$ 有界、只有一个间断点，由定理 3.2.3 可积；$f \ge 0$，$f \not\equiv 0$；但由 3.1 题（或直接算黎曼和：取样点命中该点的项至多 1 个，贡献 $\le \|P\| \to 0$）：

$$\int_a^b f = 0.$$

**什么时候结论为真**：若 $f$ **连续**、$f \ge 0$、$f \not\equiv 0$，则存在 $x_0$ 使 $f(x_0) > 0$，由连续性存在小区间 $[x_0-\delta, x_0+\delta]$ 上 $f > \frac{f(x_0)}{2} > 0$，故 $\int_a^b f \ge \frac{f(x_0)}{2}\cdot 2\delta > 0$。**"正测度集合上取正值的连续函数积分必正；任意可积函数则可能只在零测集上非零"**——这是"测度"概念芽的第一次出现。

## 3.3（概念辨析｜对应 §3.3 牛顿-莱布尼茨公式）

> 为什么牛顿-莱布尼茨公式对含跳跃间断的 $f$ 不能直接使用？构造"错误使用后得到荒谬结果"的例子。

**原因**：NFT（定理 3.3.3）的前提是存在 $F$ 使 $F' = f$ **在 $[a,b]$ 上处处成立**。若 $f$ 有跳跃间断点 $x_0$，这样的 $F$ 根本不存在：由 Darboux 定理（见 2.12 题），导函数有介值性，而跳跃间断意味着 $f$ 跳过了中间值——任何函数的导数都不可能"跳"。实践中的错误做法是：找一个"分段原函数"（在跳跃点两侧分别满足 $F' = f$，但 $F$ 本身在 $x_0$ 处**不连续**），然后套 $F(b) - F(a)$。

**荒谬结果的具体例子**：取 $f$ = Heaviside 函数于 $[-1, 1]$：$f(x) = 0$（$x < 0$），$f(x) = 1$（$x \ge 0$）。真值：$\int_{-1}^1 f = 1$。

构造带跳的"假原函数"：

$$F(x) = \begin{cases} 0, & x < 0\\ 1 + x, & x \ge 0\end{cases}$$

则除 $x = 0$ 外处处 $F' = f$，但 $F$ 在 0 处向上跳了 1。错误套用 NFT：

$$F(1) - F(-1) = 2 - 0 = 2 \neq 1 = \int_{-1}^1 f.$$

**多算的 1 恰好是 $F$ 在 0 处的跳跃量**。NFT 的证明（$\Phi - F = C$ ⟹ $F(b)-F(a) = \Phi(b)-\Phi(a)$）要求 $F' = f$ 处处成立，从而 $F$ 连续、跳跃不存在；分段使用时必须**分段积分再相加**：

$$\int_{-1}^1 f = \underbrace{\int_{-1}^0 0\,dx}_{=0} + \underbrace{\int_0^1 1\,dx}_{=1} = 1. \checkmark$$

**对照**：若分段原函数拼接处连续（如 $F(x) = 0$（$x<0$），$F(x)=x$（$x\ge0)$），则 $F(1)-F(-1) = 1$ 恰好正确——跳跃是唯一的祸源，"连续拼接的分段原函数"可以安全使用（这正是广义 NFT 的内容）。

## 3.4（计算推导｜对应 §3.3 基本积分表、§3.4 换元、Gamma 公式）

> （a）$\int_0^{\pi/2}\sin^2 x\,\mathrm{d}x$；（b）$\int_0^1 \frac{x}{1+x^2}\mathrm{d}x$；（c）$\int_0^\infty x^2\mathrm{e}^{-2x}\mathrm{d}x$。

**(a)（降幂公式）**：$\sin^2 x = \dfrac{1 - \cos 2x}{2}$，故

$$\int_0^{\pi/2}\sin^2 x\,\mathrm{d}x = \frac12\int_0^{\pi/2} 1\,\mathrm{d}x - \frac12\int_0^{\pi/2}\cos 2x\,\mathrm{d}x = \frac{\pi}{4} - \frac12\left[\frac{\sin 2x}{2}\right]_0^{\pi/2} = \frac{\pi}{4} - 0 = \frac{\pi}{4}.$$

**校验**：$\frac{\pi}{4} \approx 0.7854$，与正文一致 ✓。

**(b)（换元必换限，定理 3.4.1）**：令 $u = 1 + x^2$，$\mathrm{d}u = 2x\,\mathrm{d}x$；$x: 0 \to 1$ 对应 $u: 1 \to 2$：

$$\int_0^1 \frac{x}{1+x^2}\,\mathrm{d}x = \frac12\int_1^2 \frac{\mathrm{d}u}{u} = \frac12\Big[\ln|u|\Big]_1^2 = \frac{\ln 2}{2}.$$

**校验**：$\frac12\ln 2 \approx 0.3466$ ✓。

**(c)（Gamma 公式 $\int_0^\infty x^n \mathrm{e}^{-\lambda x}\mathrm{d}x = \frac{n!}{\lambda^{n+1}}$）**：$n = 2$，$\lambda = 2$：

$$\int_0^\infty x^2\mathrm{e}^{-2x}\,\mathrm{d}x = \frac{2!}{2^3} = \frac{2}{8} = \frac14.$$

推导备查（连续两次分部积分，定理 3.4.4）：

$$\int_0^\infty x^2\mathrm{e}^{-2x}\mathrm{d}x = \Big[-\tfrac{x^2}{2}\mathrm{e}^{-2x}\Big]_0^\infty + \int_0^\infty x\,\mathrm{e}^{-2x}\mathrm{d}x = 0 + \tfrac12\int_0^\infty x\,\mathrm{e}^{-2x}\mathrm{d}x = \tfrac12\left(\tfrac12\int_0^\infty \mathrm{e}^{-2x}\mathrm{d}x\right) = \tfrac12\cdot\tfrac12\cdot\tfrac12 = \tfrac14,$$

（每步边界项因 $\mathrm{e}^{-2x}$ 在 $\infty$ 的压倒性衰减与多项式在 0 处为零而为 0。）

**校验**：$\frac14$，数值积分实测 $0.24999999999999997$ ✓（与正文校验一致）。

## 3.5（计算推导｜对应 §3.5 例 3.5.3 p-积分、换元）

> 判断收敛性：$\displaystyle\int_2^\infty \frac{\mathrm{d}x}{x\sqrt{\ln x}}$ 与 $\displaystyle\int_1^\infty \frac{\mathrm{d}x}{x\,\ln^2 x}$。

**第一个（发散）**：令 $u = \ln x$，$\mathrm{d}u = \frac{\mathrm{d}x}{x}$；$x: 2 \to \infty$ 对应 $u: \ln 2 \to \infty$：

$$\int_2^\infty \frac{\mathrm{d}x}{x\sqrt{\ln x}} = \int_{\ln 2}^\infty u^{-1/2}\,\mathrm{d}u = \Big[2\sqrt{u}\,\Big]_{\ln 2}^{\infty} = \infty.$$

这是（换元后的）p-积分，$p = \frac12 \le 1$，发散。✓ 与正文校验一致。

**第二个（按题面下限 $x=1$ 是瑕点；标准下限下收敛）**：同样换元 $u = \ln x$。

- **按题面 $\int_1^\infty$**：$x \to 1^+$ 时 $u \to 0^+$，被积函数化为 $u^{-2}$，而 $\int_0^{u_0} u^{-2}\mathrm{d}u$ 是 $(0,1]$ 型 p-积分（$p = 2 \ge 1$），**发散**——下限 $x=1$ 处 $\ln x = 0$ 是瑕点。
- **标准版本 $\int_2^\infty \dfrac{\mathrm{d}x}{x\ln^2 x}$**（经典例题）：$\int_{\ln 2}^\infty u^{-2}\,\mathrm{d}u = \left[-\frac1u\right]_{\ln 2}^{\infty} = \frac{1}{\ln 2} \approx 1.4427$，收敛（$p = 2 > 1$）。
- **若下限取 $\mathrm{e}$**：$\int_{\mathrm{e}}^\infty \frac{\mathrm{d}x}{x\ln^2 x} = \left[-\frac1{\ln x}\right]_{\mathrm{e}}^\infty = 1$。**正文校验值"收敛于 1"对应的正是下限 $\mathrm{e}$ 的版本**。

> ⚠️ **勘误**：正文写 $\int_1^\infty$ 而校验"收敛于 1"，两处不能同时成立——下限 1 时因瑕点 $x=1$（$\ln 1 = 0$）发散；值为 1 需下限 $\mathrm{e}$。做题时务必先检查积分区间内是否有 $\ln x = 0$ 的瑕点。

**方法总结**：$\int \frac{\mathrm{d}x}{x(\ln x)^p}$ 经 $u = \ln x$ 恰好化成 p-积分，分界线仍为 $p = 1$——这是比 $\frac{1}{x^p}$ 更"慢"一档的对数尺度标尺，第 4 章练习 4.6(c) 判别 $\sum\frac{1}{n\ln n}$ 时还会用到。

## 3.6（计算推导｜对应 §3.4 分部积分法）

> 用分部积分证明递推 $I_n = \int_0^{\pi/2}\sin^n x\,\mathrm{d}x = \frac{n-1}{n} I_{n-2}$，并写出 $n = 4$ 的值。

**递推证明（$n \ge 2$）**：把 $\sin^n x$ 拆成 $\sin^{n-1}x \cdot \sin x$，分部（定理 3.4.4）。取

$$u = \sin^{n-1}x \ \big(\mathrm{d}u = (n-1)\sin^{n-2}x\cos x\,\mathrm{d}x\big), \qquad \mathrm{d}v = \sin x\,\mathrm{d}x \ \big(v = -\cos x\big).$$

$$I_n = \Big[-\sin^{n-1}x\cos x\Big]_0^{\pi/2} + (n-1)\int_0^{\pi/2}\sin^{n-2}x\cos^2 x\,\mathrm{d}x.$$

边界项：$x = \frac\pi2$ 处 $\cos\frac\pi2 = 0$；$x = 0$ 处 $\sin 0 = 0$（$n \ge 2$），故边界项 $= 0$。用 $\cos^2 x = 1 - \sin^2 x$：

$$I_n = (n-1)\int_0^{\pi/2}\sin^{n-2}x\,(1 - \sin^2 x)\,\mathrm{d}x = (n-1)\big(I_{n-2} - I_n\big).$$

移项：$I_n + (n-1)I_n = (n-1)I_{n-2}$，即

$$I_n = \frac{n-1}{n}\,I_{n-2}. \qquad\blacksquare$$

**$n = 4$**：初值 $I_0 = \frac{\pi}{2}$（$\int_0^{\pi/2} 1\,\mathrm{d}x$）。递推两步：

$$I_2 = \frac{1}{2}I_0 = \frac{\pi}{4}, \qquad I_4 = \frac{3}{4}I_2 = \frac{3}{4}\cdot\frac{\pi}{4} = \frac{3\pi}{16}.$$

**校验**：$\frac{3\pi}{16} \approx 0.5890$，与正文一致 ✓。（递推分岔：$n$ 奇时终止于 $I_1 = 1$，如 $I_3 = \frac23$；偶时终止于 $I_0 = \frac\pi2$——这就是 Wallis 积分公式，Gamma/Beta 函数特例的雏形。）

## 3.7（编程实现｜对应 §3.6 数值积分）

> 用数值积分计算 $\int_0^2 \mathrm{e}^{-x}\sin(5x)\,\mathrm{d}x$（$n = 16, 128, 1024$），与 `scipy.integrate.quad` 比较，验证误差阶。

**解析真值（先手算，供对照）**：由 $\int \mathrm{e}^{ax}\sin bx\,\mathrm{d}x = \frac{\mathrm{e}^{ax}(a\sin bx - b\cos bx)}{a^2+b^2}$（两次分部积分可自行验证），取 $a=-1, b=5$：

$$\int_0^2 \mathrm{e}^{-x}\sin 5x\,\mathrm{d}x = \left[\frac{\mathrm{e}^{-x}(-\sin 5x - 5\cos 5x)}{26}\right]_0^2 = \frac{\mathrm{e}^{-2}(-\sin 10 - 5\cos 10) + 5}{26} \approx 0.21697712.$$

> ⚠️ **勘误**：正文校验值 "$\approx 0.19819$" 有误。用高精度 `quad` 与上述原函数闭式双重验证，真值为 **0.21697712**（两者一致到 $10^{-13}$）。

```python
import numpy as np
from scipy import integrate

f = lambda x: np.exp(-x) * np.sin(5*x)
F = lambda x: np.exp(-x) * (-np.sin(5*x) - 5*np.cos(5*x)) / 26   # 解析原函数
exact = F(2.0) - F(0.0)
quad_val, _ = integrate.quad(f, 0, 2)
print(f"解析真值 = {exact:.8f}   quad = {quad_val:.8f}")

def trapezoid(f, a, b, n):
    x = np.linspace(a, b, n + 1); w = (b - a) / n
    return w * (0.5*f(x[0]) + f(x[1:-1]).sum() + 0.5*f(x[-1]))

def simpson(f, a, b, n):                     # n 必须为偶数
    x = np.linspace(a, b, n + 1); w = (b - a) / n
    return (f(x[0]) + f(x[-1]) + 4*f(x[1:-1:2]).sum() + 2*f(x[2:-1:2]).sum()) * w / 3

for n in [16, 128, 1024]:
    print(f"n={n:<5d} 梯形误差={abs(trapezoid(f,0,2,n)-exact):.3e}  "
          f"辛普森误差={abs(simpson(f,0,2,n)-exact):.3e}")
# 预期输出（实测）：
# 解析真值 = 0.21697712   quad = 0.21697712
# n=16    梯形误差=7.194e-03  辛普森误差=1.636e-04
# n=128   梯形误差=1.118e-04  辛普森误差=3.878e-08
# n=1024  梯形误差=1.747e-06  辛普森误差=9.462e-12
```

**误差阶验证**：$n$ 扩大 8 倍时——梯形误差每次约缩 64 倍 $= 8^2$，符合 $O(h^2)$（$h \propto 1/n$）；辛普森每次约缩 $8^4 = 4096$ 倍，符合 $O(h^4)$。**校验**：`quad` 值 0.21697712（正文校验值 0.19819 为勘误，见上）。

## 3.8（编程实现｜对应 §3.2 积分中值定理）

> 对 $f(x) = \mathrm{e}^{-x^2}$ 在 $[0,1]$：求平均高度 $\bar f = \int_0^1 f$，再用二分法解 $f(\xi) = \bar f$，打印 $\xi$。

**手算先行**：$\bar f = \int_0^1 \mathrm{e}^{-x^2}\mathrm{d}x = \frac{\sqrt\pi}{2}\,\mathrm{erf}(1) \approx 0.7468241328$。解方程 $\mathrm{e}^{-\xi^2} = \bar f$ 有闭式：$\xi = \sqrt{-\ln \bar f} \approx 0.5403$。

> ⚠️ **勘误**：正文校验值 "$\xi \approx 0.6351$" 有误：$\mathrm{e}^{-0.6351^2} = 0.6681 \neq \bar f = 0.7468$。正确值为 **$\xi \approx 0.54030$**，下述代码以二分 + 闭式双重验证。

```python
import numpy as np
from scipy import integrate

g = lambda x: np.exp(-x**2)
fbar, _ = integrate.quad(g, 0.0, 1.0)
print(f"fbar = {fbar:.10f}")

# 二分法解 g(xi) = fbar；g 在 [0,1] 严格递减，g(0)=1 > fbar > g(1)=e^-1
lo, hi = 0.0, 1.0
for _ in range(200):
    mid = 0.5 * (lo + hi)
    if g(mid) < fbar:   # g 递减：中点函数值偏低 -> 根在左半
        hi = mid
    else:
        lo = mid
xi = 0.5 * (lo + hi)
print(f"xi(二分) = {xi:.10f},  残差 g(xi)-fbar = {g(xi)-fbar:.2e}")
print(f"xi(闭式) = {np.sqrt(-np.log(fbar)):.10f}   (= sqrt(-ln fbar))")
# 预期输出（实测）：
# fbar = 0.7468241328
# xi(二分) = 0.5403013538,  残差 g(xi)-fbar = 0.00e+00
# xi(闭式) = 0.5403013538   (= sqrt(-ln fbar))
```

**校验**：$\xi \approx 0.5403 \in [0, 1]$，与积分中值定理的存在性结论一致（正文校验值 0.6351 为勘误，见上）。几何意义：曲边梯形面积 = 高度 $\bar f$ × 底宽 1，$\xi$ 是"平均高度"实际被取到的地方。

## 3.9（开放思考｜对应 §3.1、§3.7 大数定律预告）

> 经验风险 $\frac1n\sum \ell(x_i)$ 是黎曼和吗？差异如何弥合？依赖哪条概率论定理？

**不是严格意义下的黎曼和**，差异有三：

1. **取样点随机**：黎曼和（定义 3.2.1）要求对固定分割、任意取样点一致收敛；经验风险的样本 $x_i$ 是 i.i.d. 随机变量，可能重复聚集，不会"均匀铺满"区间。
2. **非网格化**：黎曼和的权重 $\Delta x_i$ 由分割决定（确定性），经验风险每项权重同为 $\frac1n$，与样本位置的"区间宽度"无关——它是**经验分布** $\frac1n\sum\delta_{x_i}$ 对 $\ell$ 的积分。
3. **极限语义不同**：黎曼和的极限是分析极限（$\|P\|\to0$，对所有取样一致）；经验风险的极限是**概率极限**（$n\to\infty$，依概率/几乎必然）。

**弥合的桥梁——先猜名字：大数定律（Law of Large Numbers）**。当 $x_i$ i.i.d. $\sim P$ 且 $\ell$ 可积时，$\frac1n\sum \ell(x_i) \to \mathbb{E}_P[\ell] = \int \ell\,\mathrm{d}P$（弱形式依概率，强形式几乎必然；$P$ 有密度时即对密度积分）。定性理解：随机撒点是大网格的"随机化版本"，大数定律替代了"分割加细"的角色。更精细的版本（泛化理论真正需要的"对一切 $f$ 一致收敛"）是**一致大数定律 / Glivenko–Cantelli 引理 + Hoeffding 不等式**——到概率论与数理统计课程确认。

**一句话**：经验风险 = 黎曼和的随机化表兄；黎曼和靠"分割加细"收敛，经验风险靠"样本增多 + 大数定律"收敛，两者共享"积分 = 平均的极限"这一内核。

## 3.10（开放思考｜对应 §3.5 p-积分、§3.9 误区 4）

> 为什么重尾分布（$P(X > x) \sim x^{-\alpha}$，$\alpha$ 小）让"样本均值估计期望"在实践中不可靠？

**第一步：矩的存在性由 p-积分判别**。$P(X>x)\sim x^{-\alpha}$ ⟹ 密度 $f(x) \sim c\,x^{-\alpha-1}$（$x\to\infty$）。检查各阶矩（§3.5 例 3.5.3 标尺，$x^k f(x) \sim x^{k-\alpha-1}$）：

- $\mathbb{E}[X] = \int x f\,\mathrm{d}x$ 收敛 $\iff k - \alpha - 1 < -1\ (k=1) \iff \alpha > 1$；
- $\mathrm{Var}(X) = \int x^2 f\,\mathrm{d}x$ 收敛 $\iff \alpha > 2$。

**第二步：两种失败模式**。

- $\alpha \le 1$（期望不存在）：样本均值**不收敛**。截断积分 $\int_1^T x^{-\alpha}\mathrm{d}x \sim \frac{T^{1-\alpha}}{1-\alpha}$ 随 $T$ 幂律增长（$\alpha=1$ 时对数慢发散——§3.9 误区 4 的"慢发散"）：样本均值的数值表现是"看起来快稳了，再来一亿个样本又跳一截"，永远停不下来。
- $1 < \alpha \le 2$（期望存在、方差不存在）：期望可估，但样本均值方差的通常保证失效——方差无限 ⟹ 中心极限定理不适用，波动比 $1/\sqrt n$ 慢得多，单个极端样本可以主导整个估计（百万个正常值抵不过一个尾部巨值）。

**工程教训**：对重尾数据（长尾用户、财富分布、极端损失批次）：(i) 先做"矩存在性检查"（log-log 尾部图估计 $\alpha$）；(ii) 改用稳健统计量（中位数、截尾均值）或对数变换；(iii) 对基于有限方差的置信区间保持怀疑。

## 3.11（挑战题｜对应 §3.5 广义积分、§1.3 柯西准则）

> 证明广义积分的柯西收敛准则，并用它证明 $\int_1^\infty \frac{\sin x}{x}\mathrm{d}x$ 收敛（尽管不绝对收敛）。

**第一部分：准则及证明**。

> **命题**：$\int_a^\infty f\,\mathrm{d}x$ 收敛 $\iff$ $\forall \varepsilon > 0\ \exists M \ge a$，使得 $t_2 > t_1 > M \Rightarrow \left|\int_{t_1}^{t_2} f\right| < \varepsilon$。

记 $F(t) = \int_a^t f\,\mathrm{d}x$。按定义 3.5.1，$\int_a^\infty f$ 收敛即 $\lim_{t\to\infty} F(t)$ 存在。

- **（⟹）**：设 $F(t) \to I$。任给 $\varepsilon > 0$，取 $M$ 使 $t > M$ 时 $|F(t) - I| < \frac{\varepsilon}{2}$。则 $t_2 > t_1 > M$ 时

$$\left|\int_{t_1}^{t_2} f\right| = |F(t_2) - F(t_1)| \le |F(t_2) - I| + |I - F(t_1)| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon.$$

- **（⟸）**：设柯西条件成立。则 $F(t)$ 在尾部满足柯西条件，由**函数极限的柯西收敛准则（§1.3，其实数系版本依赖完备性）**，$F(t)$ 当 $t \to \infty$ 时有有限极限，即 $\int_a^\infty f$ 收敛。$\blacksquare$

（对照第 1 章练习 1.12：柯西准则 = 完备性的算法化表达；它不需要知道极限值 $I$ 就能判断收敛——这正是它适合做收敛性论证的原因。）

**第二部分：狄利克雷积分 $\int_1^\infty \frac{\sin x}{x}\mathrm{d}x$ 收敛**。

对 $B > A \ge 1$，分部积分（$u = \frac1x$，$\mathrm{d}v = \sin x\,\mathrm{d}x$，$v = -\cos x$）：

$$\int_A^B \frac{\sin x}{x}\,\mathrm{d}x = \left[-\frac{\cos x}{x}\right]_A^B - \int_A^B \frac{\cos x}{x^2}\,\mathrm{d}x = \frac{\cos A}{A} - \frac{\cos B}{B} - \int_A^B \frac{\cos x}{x^2}\,\mathrm{d}x.$$

逐项估计（$|\cos| \le 1$）：

$$\left|\int_A^B \frac{\sin x}{x}\,\mathrm{d}x\right| \le \frac1A + \frac1B + \int_A^B \frac{\mathrm{d}x}{x^2} \le \frac{2}{A} + \frac{1}{A} = \frac{3}{A}.$$

（最后用了 $\int_A^B x^{-2}\mathrm{d}x = \frac1A - \frac1B < \frac1A$。）于是任给 $\varepsilon$，取 $M = \frac3\varepsilon$：$t_2 > t_1 > M$ 时 $\left|\int_{t_1}^{t_2}\frac{\sin x}{x}\mathrm{d}x\right| \le \frac{3}{t_1} < \varepsilon$。由柯西准则，积分收敛。$\blacksquare$

**不绝对收敛**：$x > 0$ 时 $|\sin x| \ge \sin^2 x = \frac{1 - \cos 2x}{2}$，故

$$\int_1^T \frac{|\sin x|}{x}\,\mathrm{d}x \ge \frac12\int_1^T \frac{\mathrm{d}x}{x} - \frac12\int_1^T \frac{\cos 2x}{x}\,\mathrm{d}x.$$

右端第一项 $= \frac{\ln T}{2} \to \infty$；第二项有界（对 $\int_1^\infty \frac{\cos 2x}{x}\mathrm{d}x$ 重复上面的分部积分论证即知其收敛）。所以左端 $\to \infty$，$\int_1^\infty \frac{|\sin x|}{x}\mathrm{d}x$ 发散——**条件收敛**。几何直觉：正负瓣面积 $\sim \frac{2}{n\pi}$ 递减的"交错级数"，求和收敛；绝对值把所有瓣加正，发散如 $\sum\frac1n$。

## 3.12（挑战题｜对应 §3.3 变上限积分求导、§3.4 换元）

> 设 $f$ 连续且 $\int_0^x t\,f(x-t)\,\mathrm{d}t = \mathrm{e}^x - x - 1$。求 $f$。

**第一步（卷积换元，$u = x - t$）**：$t = x - u$，$\mathrm{d}t = -\mathrm{d}u$；$t: 0 \to x$ 对应 $u: x \to 0$（换元必换限，定理 3.4.1）：

$$\int_0^x t\,f(x-t)\,\mathrm{d}t = \int_x^0 (x-u)\,f(u)\,(-\mathrm{d}u) = \int_0^x (x-u)\,f(u)\,\mathrm{d}u = x\int_0^x f(u)\,\mathrm{d}u - \int_0^x u\,f(u)\,\mathrm{d}u.$$

（换元后 $x$ 是参数、$u$ 是积分变量；$f$ 连续保证一切积分存在。）

**第二步（对 $x$ 求导，用变上限求导公式定理 3.3.1）**：

$$\frac{\mathrm{d}}{\mathrm{d}x}\left[x\int_0^x f(u)\mathrm{d}u\right] = \int_0^x f(u)\,\mathrm{d}u + x f(x), \qquad \frac{\mathrm{d}}{\mathrm{d}x}\left[\int_0^x u f(u)\mathrm{d}u\right] = x f(x).$$

故左边导数 $= \int_0^x f(u)\,\mathrm{d}u + x f(x) - x f(x) = \int_0^x f(u)\,\mathrm{d}u$。右边求导：$\mathrm{e}^x - 1$。于是

$$\int_0^x f(u)\,\mathrm{d}u = \mathrm{e}^x - 1. \tag{$\ast$}$$

**第三步（再求导一次）**：$(\ast)$ 两边对 $x$ 求导（定理 3.3.1）：

$$f(x) = \mathrm{e}^x.$$

**第四步（代回验证，必须做）**：对 $f(u) = \mathrm{e}^u$：

$$\int_0^x t\,f(x-t)\,\mathrm{d}t = \int_0^x t\,\mathrm{e}^{x-t}\,\mathrm{d}t = \mathrm{e}^x\int_0^x t\,\mathrm{e}^{-t}\,\mathrm{d}t;$$

内层分部积分：$\int_0^x t\,\mathrm{e}^{-t}\mathrm{d}t = \Big[-t\,\mathrm{e}^{-t}\Big]_0^x + \int_0^x \mathrm{e}^{-t}\mathrm{d}t = -x\mathrm{e}^{-x} + 1 - \mathrm{e}^{-x}$。故原式

$$= \mathrm{e}^x\left(1 - \mathrm{e}^{-x} - x\,\mathrm{e}^{-x}\right) = \mathrm{e}^x - 1 - x. \checkmark$$

恒等式成立。

**校验**：$f(x) = \mathrm{e}^x$（数值复核：$x = 1$ 时左边数值积分 $= 0.7182818285 =$ 右边 $\mathrm{e} - 2 = 0.7182818285$ ✓；$x = 0.5, 2.0$ 同样吻合）。

> ⚠️ **勘误**：正文校验值 "$f(x) = \mathrm{e}^x - 1$" 有误——$\mathrm{e}^x - 1$ 是第一次求导后的中间结果 $\int_0^x f$（式 $(\ast)$ 的右端），不是 $f$ 本身。最终答案 $f(x) = \mathrm{e}^x$。

# 第 4 章 泰勒展开与级数（对应正文 §4.13）

## 4.1（概念辨析｜对应 §4.2 定理 4.2.1/4.2.2 的条件）

> $f(x)=x^2\sin\frac1x$（$f(0)=0$）在 0 处几阶可导？泰勒公式到哪一阶？说明"在一点 $n$ 阶可导"与"在邻域内 $n$ 阶可导"的差别。

**逐阶计算**：

- **$f'(0)$ 存在**：$f'(0) = \lim_{h\to0}\frac{h^2\sin(1/h) - 0}{h} = \lim_{h\to0} h\sin\frac1h = 0$（无穷小 × 有界量，夹逼）。
- **$f''(0)$ 不存在**：$x \neq 0$ 时 $f'(x) = 2x\sin\frac1x - \cos\frac1x$（乘积法则 + 链式法则），于是

$$\frac{f'(h) - f'(0)}{h} = \frac{2h\sin(1/h) - \cos(1/h)}{h} = 2\sin\frac1h - \frac{1}{h}\cos\frac1h,$$

$h\to0$ 时第一项振荡无极限、第二项无界振荡——极限不存在。故 **$f$ 在 0 处恰一阶可导、二阶不存在**（与正文校验一致）。

**泰勒公式到哪一阶**：带 Peano 余项的公式（定理 4.2.1）只能写到 $n = 1$：

$$f(x) = f(0) + f'(0)\,x + o(x) = o(x) \qquad (x \to 0).$$

（事实上 $f(x) = O(x^2)$，但这个信息不属于一阶泰勒公式——它来自 $f$ 的具体结构；二阶项系数 $\frac{f''(0)}{2}$ 不存在，无法写出更精细的"系数 + 余项"形式。带 Lagrange 余项的 $n \ge 1$ 阶公式在 $x_0 = 0$ 处**不可用**：它要求邻域内 $n+1 = 2$ 阶可导。）

**两个概念的差别**：

- **"在一点 $n$ 阶可导"**：只要求 $f^{(n)}(x_0)$ 作为差商极限存在（连带低阶导在 $x_0$ 附近有定义）。Peano 余项泰勒公式（定理 4.2.1）的精确条件就是它。
- **"在邻域内 $n$ 阶可导"**：$f^{(n)}$ 在整个邻域存在。Lagrange 余项泰勒公式（定理 4.2.2）需要邻域内 $n+1$ 阶可导（对辅助函数用中值定理，必须在中值点 $\xi$ 处求值 $f^{(n+1)}(\xi)$）。
- 本题正是分界案例：一阶 Peano 公式成立，而任何带 Lagrange 余项的公式（哪怕 $n=1$）都不成立。**两种余项的条件差异不是技术琐碎，而是"能不能定量"的分水岭**（§4.2 表格）。

## 4.2（概念辨析｜对应 §4.4 交错级数、绝对收敛）

> "若 $\sum a_n$ 收敛，则 $\sum a_n^2$ 收敛。"对吗？

**不对**。反例：$a_n = \dfrac{(-1)^n}{\sqrt n}$。

- $\sum a_n$ 收敛：Leibniz 判别法（§4.4）——$b_n = \frac{1}{\sqrt n}$ 单调递减趋于 0。
- $\sum a_n^2 = \sum \frac{1}{n}$：调和级数，发散（p-级数 $p = 1$ 的临界发散情形）。

**什么时候命题为真**（两组充分条件，供辨析）：

1. $a_n \ge 0$（正向级数）：由收敛必要条件 $a_n \to 0$，$n$ 充分大时 $0 \le a_n < 1$，于是 $a_n^2 \le a_n$，比较判别法得收敛。
2. $\sum a_n$ **绝对**收敛：$|a_n| \to 0$，最终 $a_n^2 \le |a_n|$，同样比较可得。

**反例的本质**：条件收敛级数的负项"补贴"了正项；平方抹掉正负号，拆掉补贴，暴露出本质发散。呼应 §4.4 的 Riemann 重排定理——条件收敛级数对"项的重组"极其敏感。

## 4.3（概念辨析｜对应 §4.4 定理 4.4.4、两种余项）

> 为什么 $\mathrm{e}^x$ 的泰勒级数对一切 $x$ 收敛到 $\mathrm{e}^x$，而 $\ln(1+x)$ 的只对 $x \in (-1, 1]$ 有效？

**判据（定理 4.4.4）**：泰勒级数等于原函数 $\iff$ 余项 $R_n(x) \to 0$。用 **Lagrange 余项**逐个验证。

**$\mathrm{e}^x$（对一切 $x \in \mathbb{R}$）**：$n$ 阶 Lagrange 余项

$$R_n(x) = \frac{\mathrm{e}^{\xi}}{(n+1)!}\,x^{n+1} \quad (\xi \text{ 介于 } 0 \text{ 与 } x), \qquad |R_n(x)| \le \frac{\mathrm{e}^{|x|}\,|x|^{n+1}}{(n+1)!}.$$

固定 $x$：$\mathrm{e}^{|x|}$ 是固定常数，而 $\frac{|x|^{n+1}}{(n+1)!} \to 0$——相邻项之比 $\frac{|x|^{n+2}}{(n+2)!}\Big/\frac{|x|^{n+1}}{(n+1)!} = \frac{|x|}{n+2} \to 0$（阶乘最终压倒任意固定幂）。故 $R_n \to 0$ 对**每个** $x$ 成立，级数处处还原 $\mathrm{e}^x$。$\blacksquare$

**$\ln(1+x)$（只在 $-1 < x \le 1$）**：$f^{(k)}(t) = \dfrac{(-1)^{k-1}(k-1)!}{(1+t)^k}$，故

$$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\,x^{n+1} = \frac{(-1)^{n}}{n+1}\cdot\frac{x^{n+1}}{(1+\xi)^{n+1}}, \qquad \xi \text{ 介于 } 0 \text{ 与 } x.$$

- $0 < x \le 1$：$\xi \in (0, x)$，$(1+\xi) \ge 1$，故 $|R_n| \le \frac{x^{n+1}}{n+1} \to 0$ ✓（$x = 1$ 时 $\le \frac{1}{n+1} \to 0$——交错调和级数收敛到 $\ln 2$ 的定量版）。
- $-1 < x < 0$：$\xi \in (x, 0)$，$(1+\xi) \ge 1 + x > |x|$，故 $\left(\frac{|x|}{1+\xi}\right)^{n+1} < 1$，$|R_n| \le \frac{1}{n+1} \to 0$ ✓。
- $x > 1$：级数一般项 $\left|(-1)^{n-1}\frac{x^n}{n}\right| = \frac{x^n}{n} \to \infty \neq 0$，**收敛必要条件（一般项趋于 0，§4.4）已破坏**，级数发散；部分和 $S_n$ 无界，而 $R_n = \ln(1+x) - S_n$，故 $R_n \not\to 0$。从余项公式看：$\xi$ 可以远离 $x$（靠近 0），此时 $\frac{x^{n+1}}{(n+1)(1+\xi)^{n+1}}$ 量级爆炸。

**结论**：收敛域 $(-1, 1]$（端点 $x=1$ 收敛、$x=-1$ 发散）。**深层原因预告（§4.12）**：收敛半径由复平面上最近的奇点决定——$\ln(1+x)$ 在 $x = -1$ 处有奇点（支点），距展开点 0 为 1，半径为 1；$\mathrm{e}^x$ 在复平面处处解析，半径无穷。

## 4.4（计算推导｜对应 §4.3 应用一、麦克劳林展开表）

> （a）$\lim_{x\to0}\dfrac{\cos x - 1 + \frac{x^2}{2}}{x^4}$；（b）$\lim_{x\to0}\left(\dfrac1x - \dfrac{1}{\mathrm{e}^x-1}\right)$。

**(a)**：展开 $\cos x = 1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} - \dfrac{x^6}{6!} + \cdots = 1 - \dfrac{x^2}{2} + \dfrac{x^4}{24} + o(x^4)$（取到 $x^4$，Peano 余项定阶足够）。分子：

$$\cos x - 1 + \frac{x^2}{2} = \left(1 - \frac{x^2}{2} + \frac{x^4}{24}\right) - 1 + \frac{x^2}{2} + o(x^4) = \frac{x^4}{24} + o(x^4).$$

$$\lim_{x\to0}\frac{\cos x - 1 + \frac{x^2}{2}}{x^4} = \lim_{x\to0}\frac{\frac{x^4}{24} + o(x^4)}{x^4} = \frac{1}{24}.$$

**校验**：$\frac{1}{24}$，与正文一致 ✓。（对照：洛必达要连用四次且越算越繁；展开法一次到位，还能看到主部来源 $\frac{1}{4!}$。）

**(b)（$\infty - \infty$ 型，先通分）**：

$$\frac1x - \frac{1}{\mathrm{e}^x-1} = \frac{\mathrm{e}^x - 1 - x}{x(\mathrm{e}^x - 1)}.$$

展开 $\mathrm{e}^x = 1 + x + \dfrac{x^2}{2} + \dfrac{x^3}{6} + o(x^3)$：

- 分子 $= \left(1 + x + \frac{x^2}{2} + \frac{x^3}{6}\right) - 1 - x + o(x^3) = \frac{x^2}{2} + \frac{x^3}{6} + o(x^3) = \frac{x^2}{2}\left(1 + \frac{x}{3}\right) + o(x^3)$；
- 分母 $= x\left(x + \frac{x^2}{2} + o(x^2)\right) = x^2\left(1 + \frac{x}{2}\right) + o(x^3)$。

故

$$\lim_{x\to0}\frac{\frac{x^2}{2}\left(1 + \frac{x}{3}\right) + o(x^3)}{x^2\left(1 + \frac{x}{2}\right) + o(x^3)} = \frac{1/2}{1} = \frac{1}{2}.$$

**校验**：数值实验 $x = 10^{-4}$ 时原式 $= +0.49999167$，$x = -10^{-3}$ 时 $= +0.50008333$——极限为 $+\frac12$。

> ⚠️ **勘误**：正文校验值 "$-\frac12$" 符号有误。$-\frac12$ 是**交换减法顺序**后的极限：$\lim_{x\to0}\left(\frac{1}{\mathrm{e}^x-1} - \frac1x\right) = -\frac12$。做题时看清谁减谁。

## 4.5（计算推导｜对应 §4.2 Lagrange 余项、§4.3 应用二）

> 写出 $f(x)=\ln x$ 在 $x=1$ 处的 $n$ 阶泰勒公式（Lagrange 余项），并据此证明 $\ln(1+t) \le t - \frac{t^2}{2} + \frac{t^3}{3}$（$0\le t\le1$）。

**泰勒公式**。逐阶求导：$f^{(k)}(x) = \dfrac{(-1)^{k-1}(k-1)!}{x^k}$（$k \ge 1$；归纳：每求一次导次数降一、符号翻转、多乘一个次数）。在 $x_0 = 1$：$f(1) = 0$，$f^{(k)}(1) = (-1)^{k-1}(k-1)!$，系数 $\frac{f^{(k)}(1)}{k!} = \frac{(-1)^{k-1}}{k}$。记 $t = x - 1$，**$n$ 阶 Lagrange 余项公式**：

$$\ln(1+t) = t - \frac{t^2}{2} + \frac{t^3}{3} - \cdots + (-1)^{n-1}\frac{t^n}{n} + R_n(t), \qquad R_n(t) = \frac{(-1)^n}{n+1}\cdot\frac{t^{n+1}}{\xi^{n+1}},$$

其中 $\xi$ 介于 $1$ 与 $1+t$ 之间（定理 4.2.2；条件 $t > -1$ 保证 $\ln$ 在区间内 $n+1$ 阶可导）。

**不等式证明（$0 \le t \le 1$）**：取 $n = 3$：

$$R_3(t) = \frac{(-1)^3}{4}\cdot\frac{t^4}{\xi^4} = -\frac{t^4}{4\xi^4} \le 0,$$

（$t \ge 0$ 时 $t^4 \ge 0$、$\xi \ge 1 > 0$。）代入 $n = 3$ 的公式：

$$\ln(1+t) = t - \frac{t^2}{2} + \frac{t^3}{3} + \underbrace{R_3(t)}_{\le\ 0} \le t - \frac{t^2}{2} + \frac{t^3}{3}. \qquad\blacksquare$$

（$t = 0$ 时两边同为 0，等号成立。）

**方法要点**：这是 §4.3"应用二"的骨架——**Lagrange 余项的正负控制**。本题 lucky 之处在于 $n = 3$ 时余项符号由 $(-1)^3 < 0$ 唯一确定（$\xi^4$ 恒正）；Peano 余项 $o(t^3)$ 做不了这件事（不告诉符号）。对照 $\sin x$ 不等式：那里 $n=3$ 的余项含 $\sin\xi$ 符号不定，需展开到 $x^5$ 让 $\cos\xi > 0$ 出场。

## 4.6（计算推导｜对应 §4.4 正项级数判别法、Leibniz 判别法）

> 判断收敛性并指出判别法：（a）$\sum \dfrac{2^n n!}{n^n}$；（b）$\sum \dfrac{1}{(\ln n)^n}$；（c）$\sum \dfrac{(-1)^n}{n\ln n}$（$n \ge 2$）。

**(a) 比值判别法（d'Alembert）**——含 $n!$ 与 $n^n$，比值最合适。$a_n = \frac{2^n n!}{n^n}$：

$$\frac{a_{n+1}}{a_n} = \frac{2^{n+1}(n+1)!}{(n+1)^{n+1}}\cdot\frac{n^n}{2^n n!} = 2\,(n+1)\cdot\frac{n^n}{(n+1)^{n+1}} = 2\left(\frac{n}{n+1}\right)^n = \frac{2}{\left(1 + \frac1n\right)^n} \longrightarrow \frac{2}{\mathrm{e}} \approx 0.7358 < 1.$$

（约分后用了重要极限 $\left(1+\frac1n\right)^n \to \mathrm{e}$。）$\rho = \frac2{\mathrm{e}} < 1$ ⟹ **收敛**。✓ 与正文校验一致。

**(b) 根值判别法（Cauchy）**——$(\cdots)^n$ 型。$a_n = (\ln n)^{-n}$：

$$\sqrt[n]{a_n} = \frac{1}{\ln n} \longrightarrow 0 < 1 \quad\Longrightarrow\quad \text{收敛}.$$

（$\ln n \to \infty$ 缓慢但坚定。）比值判别法在此会遇到 $\left(\frac{\ln n}{\ln(n+1)}\right)^n$ 这种棘手形态（等效 $\rho = 1$ 失效区），根值法一步到位——体现"选对判别法"的价值。✓ 收敛，与正文校验一致。

**(c) 交错级数，两步走**：$b_n = \frac{1}{n\ln n}$。

- **收敛性（Leibniz）**：$b_n > 0$；单调递减（$n \ln n$ 递增，$n \ge 2$）；$b_n \to 0$。三条件满足 ⟹ $\sum(-1)^n b_n$ 收敛。
- **非绝对收敛**：$\sum\frac{1}{n\ln n}$ 发散——积分判别法（与第 3 章 p-积分同一工具）：$\int_2^\infty \frac{\mathrm{d}x}{x\ln x} = \Big[\ln\ln x\Big]_2^\infty = \infty$。

⟹ **条件收敛**。✓ 与正文校验一致。

## 4.7（编程实现｜对应 §4.6 实验二、§4.3 例 4.3.2）

> 复现中心差分 U 形误差曲线，并对一阶（向前）差分做同样实验，验证其最优步长约 $10^{-8}$、谷底误差约 $10^{-8}$。

**理论预测**：一阶差分 $\frac{f(x+h)-f(x)}{h} = f'(x) + \frac{h}{2}f''(x) + O(h^2)$——截断误差 $O(h)$（中心差分因奇数阶项相消为 $O(h^2)$）；总误差 $\approx \frac{M_2 h}{2} + \frac{\varepsilon_{\text{mach}}|f|}{h}$，最优 $h^\ast \sim \sqrt{2\varepsilon_{\text{mach}}|f|/M_2} \approx 10^{-8}$，谷底误差 $\sim 10^{-8}$。

```python
import numpy as np

f  = lambda x: np.exp(-x**2) * np.cos(3*x)
df = lambda x: -np.exp(-x**2) * (2*x*np.cos(3*x) + 3*np.sin(3*x))
x0, true = 0.7, df(0.7)

bc, bf = (None, np.inf), (None, np.inf)
print("  h        central err   forward err")
for k in range(1, 13):
    h = 10.0**(-k)
    ec = abs((f(x0+h) - f(x0-h)) / (2*h) - true)   # 中心差分
    ef = abs((f(x0+h) - f(x0))    / h    - true)   # 一阶（向前）差分
    if ec < bc[1]: bc = (h, ec)
    if ef < bf[1]: bf = (h, ef)
    print(f"  1e-{k:<2d}   {ec:.3e}     {ef:.3e}")
print(f"central best: h={bc[0]:.0e} err={bc[1]:.2e};  forward best: h={bf[0]:.0e} err={bf[1]:.2e}")

#   1e-9    1.589e-08     9.916e-08
#   1e-10   1.547e-07     1.229e-07
#   1e-11   4.322e-07     2.343e-06
#   1e-12   1.431e-05     9.758e-05
# central best: h=1e-05 err=1.65e-11;  forward best: h=1e-08 err=2.30e-08
```

**校验**：向前差分最优步长 $h = 10^{-8}$、谷底误差 $\approx 2.3\times10^{-8}$，均与理论 $\sim10^{-8}$ 一致 ✓。对照两曲线：$h$ 从 $10^{-1}$ 降到谷底，向前差分误差每档缩 10 倍（$O(h)$ 截断），中心差分缩 100 倍（$O(h^2)$）；谷底之后两者都被 $\varepsilon/h$ 舍入误差接管、同步抬头。**"截断阶数差一阶，最优步长差三个数量级（$h^\ast \sim \varepsilon^{1/2}$ vs $\varepsilon^{1/3}$）"**——例 4.3.2 公式的数值验证。

## 4.8（编程实现｜对应 §4.6 实验三）

> 用部分和 $\sum_{k=0}^{N}\frac{1}{k!}$ 计算 $\mathrm{e}$，找出达到相对误差 $<10^{-16}$ 的最小 $N$；对比 $\left(1+\frac1n\right)^n$ 路线需要的 $n$。

```python
import numpy as np
from math import factorial

# --- 路线一：阶倒数级数（正项级数，余项 < 1/(N! * N)，阶乘速度衰减）---
s = 1.0
for N in range(1, 25):
    s += 1.0 / factorial(N)
    print(f"N={N}  rel err = {abs(s - np.e)/np.e:.3e}")

# --- 路线二：(1+1/n)^n ---
for n in [10**6, 10**8, 10**10, 10**15, 10**16]:
    a = (1.0 + 1.0 / n) ** n
    print(f"(1+1/n)^n  n=1e{int(round(np.log10(n))):<3d} rel err = {abs(a - np.e)/np.e:.3e}")
# 预期输出（实测）：
# N=15  rel err = 1.862e-14
# N=16  rel err = 9.802e-16
# N=17  rel err = 0.000e+00      <- 部分和已与浮点 e 完全一致：最小 N = 17
# (1+1/n)^n  n=1e6   rel err = 5.001e-07
# (1+1/n)^n  n=1e8   rel err = 1.108e-08   <- 谷底附近
# (1+1/n)^n  n=1e10  rel err = 8.269e-08   <- 反而变差（舍入误差接管）
# (1+1/n)^n  n=1e15  rel err = 1.165e-01
# (1+1/n)^n  n=1e16  rel err = 6.321e-01   <- 1+1/n 已无法与 1 区分
```

**结果解读（两层）**：

1. **数学层**：级数是正项级数，余项 $R_N = \sum_{k>N}\frac1{k!} < \frac{1}{N!}\cdot\frac{1}{N}\cdot\frac{N+1}{N}$（等比放缩），阶乘速度衰减。实测**最小 $N = 17$** 达到相对误差 $< 10^{-16}$（与正文校验 "$N \approx 17$–18" 一致 ✓）。而 $\left(1+\frac1n\right)^n$ 的截断误差 $\approx \frac{\mathrm{e}}{2n}$：纯数学上要 $1/(2n) < 10^{-16}$ 需 $n > 5\times10^{15}$。
2. **浮点层（关键！）**：上述 $n > 5\times10^{15}$ 在机器上**不可达**——$n$ 超过约 $4.5\times10^{15} = 2^{52}$ 后 $1 + 1/n$ 舍入后无法与 1 区分；实测该路线的相对误差在 $n \approx 10^8$ 处触底（$\approx 1.1\times10^{-8}$）后**反而回升**（$n = 10^{16}$ 时误差 0.63，几乎 $1+1/n = 1$ 导致的坍缩）。正文"约 $10^8$"应理解为：**这条路线在双精度浮点下实际能稳定达到的最优精度（$10^{-8}$ 量级）对应的 $n$**；它永远到不了 $10^{-16}$。

**结论**："同一个常数，不同的级数，天壤之别的计算成本"——级数 17 项 vs 幂极限 $10^8$ 次幂且仍差 8 个数量级，且大 $n$ 时路线二自身还有舍入误差问题（U 形曲线第二次现身）。这是"误差阶决定工程可行性"的最佳教学案例。

## 4.9（开放思考｜对应 §4.5 梯度法收敛率）

> 为什么 SGD 在凸情形下通常只能达到 $O(1/\sqrt k)$ 而非 $O(1/k)$？指出 4.5 节证明流程中失败的一步。

**回顾 4.5 节确定性证明的三个支柱**：① $L$-光滑上界 $f(x_{k+1}) \le f(x_k) - \frac{\eta}{2}[f'(x_k)]^2$（$\eta = 1/L$）；②（强凸时）梯度平方下界 $[f'(x_k)]^2 \ge 2m(f(x_k)-f^\ast)$，或（一般凸时）凸性下界 + Young 不等式技术性消去梯度项；③ 对 $k$ 求和（telescoping）得 $f(x_k) - f^\ast \le \frac{L\|x_0-x^\ast\|^2}{2k}$。

**SGD 中失败的是①→③的"无损 telescoping"**。用无偏梯度估计 $g_k = f'(x_k) + \xi_k$（$\mathbb{E}\xi_k = 0$，$\mathbb{E}\xi_k^2 = \sigma^2$）重做第①步（仿第 2 章练习 2.9）：

$$\mathbb{E}[f(x_{k+1})] \le \mathbb{E}[f(x_k)] - \frac{\eta}{2}\,\mathbb{E}[f'(x_k)^2] + \frac{L\eta^2\sigma^2}{2}.$$

多出的**方差项 $\frac{L\eta^2\sigma^2}{2}$ 是致命的**：第②步要把 $\mathbb{E}[f'(x_k)^2]$ 下界为 $c\cdot\mathbb{E}[f(x_k)-f^\ast]$ 再收缩，但方差项与 $f'(x_k)$ 无关——**迭代到达最优点（$f' = 0$）时它依然存在**。telescoping 后得到

$$\mathbb{E}[f(\bar x_k)] - f^\ast \le \underbrace{\frac{L\|x_0 - x^\ast\|^2}{2\eta k}}_{\text{优化项（}1/k\text{）}} + \underbrace{\frac{L\eta\sigma^2}{2}}_{\text{噪声地板（与 }k\text{ 无关）}}.$$

固定 $\eta$：误差停在 $O(\eta\sigma^2)$，永不归零。**平衡两步**：对 $\eta$ 优化 $\frac{A}{\eta k} + B\eta$，得 $\eta^\ast = \sqrt{A/(Bk)} \sim k^{-1/2}$，代回得

$$\mathbb{E}[f(\bar x_k)] - f^\ast = O\!\left(\frac{L\|x_0-x^\ast\|\,\sigma}{\sqrt{k}}\right) = O(1/\sqrt{k}).$$

**直觉总结**：确定性方法每步严格下降，可以直线降到 $1/k$；SGD 每步的期望下降被方差抵消一部分，"信噪比"随迭代衰减，步长必须按 $k^{-1/2}$ 缩小来压噪声，而步长缩小又拖慢优化项——两难的平衡点就是 $1/\sqrt k$。（方差缩减、动量、增大 mini-batch 的目标准确就是压低 $\sigma$。）

## 4.10（开放思考｜对应 §4.3 例 4.3.2、浮点误差）

> float32 → bfloat16 的主要风险？用 "$h^\ast \sim \varepsilon^{1/3}$" 解释为什么低精度下梯度校验与二阶方法更难做。

**精度参数**：float32 的机器精度 $\varepsilon \approx 1.2\times10^{-7}$（24 位尾数）；bfloat16 尾数只有 8 位，$\varepsilon \approx 2^{-8} \approx 3.9\times10^{-3}$——**相对精度劣化约 5 个数量级**（指数位不变、动态范围保留，这是 bf16 的设计选择）。

**用 $h^\ast \sim \varepsilon^{1/3}$ 推演（中心差分）**：例 4.3.2 给出总误差 $\frac{M_3h^2}{6} + \frac{\varepsilon|f|}{h}$，最优步长与谷底误差分别为

$$h^\ast \sim \left(\frac{3\varepsilon|f|}{M_3}\right)^{1/3}, \qquad \text{误差}(h^\ast) \sim \varepsilon^{2/3}.$$

- float32：$h^\ast \sim (10^{-7})^{1/3} \approx 5\times10^{-3}$，谷底误差 $\sim 10^{-5}$ 量级；
- bfloat16：$h^\ast \sim (4\times10^{-3})^{1/3} \approx 0.16$，谷底误差 $\sim (4\times10^{-3})^{2/3} \approx 2.5\times10^{-2}$。

**三个后果**：

1. **梯度校验（gradcheck）失效**：数值梯度要在 $h^\ast \approx 0.16$ 处采样——截断误差 $\frac{h}{2}f'' \sim 0.08 f''$ 已是巨量；gradcheck 的判据（相对误差 $< 10^{-6}$）在 bf16 下根本无法满足。调试自定义算子必须在高精度（fp32/fp64）下做。
2. **二阶方法更难**：牛顿法/拟牛顿依赖 Hessian 信息的**差异**（不同方向曲率对比、条件数），这些差异往往只有 $10^{-2}$–$10^{-3}$ 相对量级——低于 bf16 的 $\varepsilon \approx 4\times10^{-3}$ 时曲率差异直接淹没在舍入噪声里（两个本应不同的特征值在 bf16 下无法区分）。
3. **其他风险**：小梯度下溢（需要 loss scaling）；长求和的累加误差；阈值/符号判断在边界值附近翻转。

**总结**：$h^\ast\sim\varepsilon^{1/3}$ 揭示的普适规律——**舍入精度每降几个数量级，"可分辨的最小差异"按 $\varepsilon^{2/3}$ 塌缩**；一切依赖"数值差异可信"的技术（差分、曲率估计、小量比较）都要重新评估。混合精度训练的 master weights + fp32 累加器正是对它的工程回答。

## 4.11（挑战题｜对应 §4.2 泰勒定理、§3.4 分部积分）

> 证明泰勒余项的积分形式 $R_n(x) = \dfrac{1}{n!}\displaystyle\int_{x_0}^{x} f^{(n+1)}(t)\,(x-t)^n\,\mathrm{d}t$，并用分部积分对 $n$ 归纳；再说明由它立得 Lagrange 余项。

**基础（$n = 0$）**：$R_0(x) = f(x) - f(x_0)$，而牛顿-莱布尼茨公式（定理 3.3.3，$f'$ 连续保证可积）恰给

$$f(x) = f(x_0) + \int_{x_0}^{x} f'(t)\,\mathrm{d}t = f(x_0) + \frac{1}{0!}\int_{x_0}^x f^{(1)}(t)(x-t)^0\,\mathrm{d}t. \checkmark$$

**归纳步**。设 $n-1$ 阶积分余项公式成立：

$$f(x) = \sum_{k=0}^{n-1}\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k + R_{n-1}(x), \qquad R_{n-1}(x) = \frac{1}{(n-1)!}\int_{x_0}^x f^{(n)}(t)(x-t)^{n-1}\,\mathrm{d}t.$$

对 $R_{n-1}$ **分部积分**（定理 3.4.4），取

$$u = (x - t)^{n-1}\ \big(\mathrm{d}u = -(n-1)(x-t)^{n-2}\,\mathrm{d}t\big), \qquad \mathrm{d}v = f^{(n)}(t)\,\mathrm{d}t \ \big(v = f^{(n-1)}(t)\big):$$

$$R_{n-1}(x) = \frac{1}{(n-1)!}\left\{\Big[(x-t)^{n-1} f^{(n-1)}(t)\Big]_{t=x_0}^{t=x} - \int_{x_0}^x f^{(n-1)}(t)\,\mathrm{d}\big[(x-t)^{n-1}\big]\right\}.$$

其中 $\mathrm{d}[(x-t)^{n-1}] = -(n-1)(x-t)^{n-2}\mathrm{d}t$，故

$$R_{n-1}(x) = \frac{1}{(n-1)!}\Big\{0 - (x-x_0)^{n-1}f^{(n-1)}(x_0) + (n-1)\int_{x_0}^x f^{(n-1)}(t)(x-t)^{n-2}\,\mathrm{d}t\Big\}$$

$$= -\frac{f^{(n-1)}(x_0)}{(n-1)!}(x-x_0)^{n-1} + \frac{1}{(n-2)!}\int_{x_0}^x f^{(n-1)}(t)(x-t)^{n-2}\,\mathrm{d}t.$$

（边界项在 $t = x$ 处因 $(x - x)^{n-1} = 0$（$n \ge 2$）消失；$t = x_0$ 处给出负的 $\frac{f^{(n-1)}(x_0)}{(n-1)!}(x-x_0)^{n-1}$。）

代回展开式：前 $n-1$ 项和里的第 $n-1$ 项 $\frac{f^{(n-1)}(x_0)}{(n-1)!}(x-x_0)^{n-1}$ 与边界项**恰好相消**，得到

$$f(x) = \sum_{k=0}^{n-2}\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k + \frac{1}{(n-2)!}\int_{x_0}^x f^{(n-1)}(t)(x-t)^{n-2}\,\mathrm{d}t,$$

即从 $n-1$ 阶公式推得 $n-2$ 阶公式成立。由 $n = 0$ 基础起步，对任意 $n$ 正向读即得

$$f(x) = \sum_{k=0}^{n}\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k + \frac{1}{n!}\int_{x_0}^x f^{(n+1)}(t)\,(x-t)^n\,\mathrm{d}t. \qquad\blacksquare$$

（直观：每做一次分部积分，就把一个 $\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k$ 项从余项里"剥出来"放进多项式和。）

**由积分形式立得 Lagrange 余项**：设 $x > x_0$。被积函数中**权重 $(x-t)^n \ge 0$ 在 $[x_0, x]$ 上连续且不变号**（权重变号时不能用带权积分中值定理——这是非负性的用处）。由带权积分中值定理（§3.2 积分中值定理的带权版）：存在 $\xi \in [x_0, x]$ 使

$$R_n(x) = \frac{f^{(n+1)}(\xi)}{n!}\int_{x_0}^x (x-t)^n\,\mathrm{d}t = \frac{f^{(n+1)}(\xi)}{n!}\cdot\frac{(x-x_0)^{n+1}}{n+1} = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}.$$

这正是定理 4.2.2 的 Lagrange 余项（$x < x_0$ 时由对称性同理）。$\blacksquare$

**意义**：本题把第 3 章（积分）与第 4 章（泰勒）焊接：积分余项是**最精确**的余项表示——Lagrange 余项是它的粗化，Peano 余项是它的极限化；它也是证明多元泰勒公式（第 5 章 5.6 节沿射线切片法）的直接工具。

## 4.12（挑战题｜对应 §4.8 案例 1、softmax/log-sum-exp）

> 证明 $\dfrac{\partial}{\partial z_i}\log\sum_j \mathrm{e}^{z_j} = \mathrm{softmax}(z)_i$；并解释为什么稳定实现在极不平衡的 $z$（如 $z_1 - z_2 = 800$）下梯度依然稳定，而朴素实现前向就 NaN。

**证明（链式法则，定理 2.2.2）**：记 $S(z) = \sum_{j} \mathrm{e}^{z_j}$，$L(z) = \log S(z)$。固定 $i$，把 $L$ 看作 $z_i$ 的一元复合函数：内层 $g(z_i) = \mathrm{e}^{z_i}$（其余项与 $z_i$ 无关），外层 $f(S) = \log S$：

$$\frac{\partial L}{\partial z_i} = \frac{\mathrm{d}f}{\mathrm{d}S}\cdot\frac{\partial S}{\partial z_i} = \frac{1}{S}\cdot\mathrm{e}^{z_i} = \frac{\mathrm{e}^{z_i}}{\sum_j \mathrm{e}^{z_j}} = \mathrm{softmax}(z)_i. \qquad\blacksquare$$

（多元视角：$\nabla_z L = \frac{1}{S}\left(\mathrm{e}^{z_1}, \dots, \mathrm{e}^{z_n}\right)^\top$——LSE 的雅可比就是 softmax 向量，这正是交叉熵 + softmax 组合梯度如此干净的原因。）

**朴素实现的灾难（前向就 NaN）**：$z = (800, 0, -800)$ 时 $S = \mathrm{e}^{800} + 1 + \mathrm{e}^{-800}$。双精度浮点上限约 $1.8\times10^{308}$，而 $\mathrm{e}^{800} \approx 10^{347}$ **溢出为 `inf`**。实测（NumPy）：

- 前向：`np.log(np.sum(np.exp(z)))` = `inf`；softmax 前向 $\frac{\mathrm{e}^{800}}{\mathrm{e}^{800}} = \frac{\mathrm{inf}}{\mathrm{inf}} =$ **NaN**。
- 梯度输出实测：`[nan, 0., 0.]`——整个反向传播被 NaN 污染。

**稳定实现（减最大值 $M$）**：利用恒等式 $\frac{\mathrm{e}^{z_i}}{\sum_j \mathrm{e}^{z_j}} = \frac{\mathrm{e}^{z_i - M}}{\sum_j \mathrm{e}^{z_j - M}}$（分子分母同乘 $\mathrm{e}^{-M}$）与 $\log\sum_j \mathrm{e}^{z_j} = M + \log\sum_j \mathrm{e}^{z_j - M}$（§4.8 案例 1）：

```python
import numpy as np

def lse_stable_grad(x):
    m = np.max(x)                 # 减最大值：所有指数参数 <= 0，不溢出
    e = np.exp(x - m)             # 最大分量对应 e^0 = 1，最保险
    return e / e.sum()            # softmax，天然归一

z = np.array([800.0, 0.0, -800.0])
m = np.max(z)
print(m + np.log(np.sum(np.exp(z - m))))   # 稳定 logsumexp
print(lse_stable_grad(z))                  # 稳定 softmax 梯度
# 预期输出（实测）：
# 800.0
# [1. 0. 0.]
```

稳定前向：$z - M = (0, -800, -1600)$，$\mathrm{e}^{-800}$ 下溢为 0（可接受——它对和的贡献 $< 10^{-300}$，远低于浮点精度；"何时可安全忽略小项"的判据正是本章误差分析），$\sum = 1$，$\mathrm{LSE} = 800 + \log 1 = 800.0$；稳定梯度 $= (1, 0, 0)$，与数学极限 $\mathrm{softmax}(z) \to (1, 0, 0)$ 一致 ✓。

**梯度稳定性的深层原因**：减 $M$ 后梯度公式变为 $\frac{\mathrm{e}^{z_i - M}}{\sum_j \mathrm{e}^{z_j - M}}$——**所有中间量都落在 $[0,1]$ 内**：没有大数裸算、没有相近大数相减（第 1 章实验二与例 4.3.3 的灾难性消去都不出现）。信息损失仅在于：$z_2, z_3$ 相对 $z_1$ 的差距超过下溢极限后 softmax 分量归零——但这在数学上就是 $< 10^{-300}$ 的量，任何算法都无法也无需在双精度下分辨。**朴素实现丢的是全部信息（NaN），稳定实现丢的只是本来就低于机器分辨率的信息。**

# 第 5 章 多元微分：梯度与 Hessian（对应正文 §5.15）

## 5.1（概念辨析｜对应 §5.2 定义 5.2.3/5.2.4、反例）

> 构造一个在原点"方向导数存在但函数不连续"的函数，并由此说明方向导数存在为什么弱于可微。

**构造**：$f(x,y) = \begin{cases}\dfrac{x^2y}{x^4+y^2}, & (x,y)\neq(0,0)\\[4pt] 0, & (x,y)=(0,0)\end{cases}$

**第一步：所有方向导数在原点存在（且为 0）**。沿单位向量 $\mathbf{u} = (\cos\theta, \sin\theta)$：

$$\frac{f(t\mathbf{u}) - f(\mathbf{0})}{t} = \frac{1}{t}\cdot\frac{t^3\cos^2\theta\sin\theta}{t^4\cos^4\theta + t^2\sin^2\theta} = \frac{t\cos^2\theta\sin\theta}{t^2\cos^4\theta + \sin^2\theta}.$$

- $\sin\theta \neq 0$：$t \to 0$ 时分子 $\to 0$（一次）、分母 $\to \sin^2\theta$（非零常数），商 $\to 0$。
- $\sin\theta = 0$（沿 $x$ 轴）：$f(t, 0) = \frac{0}{t^4} = 0$，商恒为 0。

故所有方向导数存在且 $D_{\mathbf{u}}f(\mathbf{0}) = 0$。

**第二步：函数在原点不连续**。沿**抛物线** $y = kx^2$（$k \neq 0$）趋近原点（这不是直线方向，方向导数管不到它）：

$$f(x, kx^2) = \frac{x^2\cdot kx^2}{x^4 + k^2x^4} = \frac{k}{1+k^2}.$$

极限随 $k$ 变化（$k=1$ 得 $\frac12$，$k=-1$ 得 $-\frac12$），故 $\lim_{(x,y)\to(0,0)} f$ 不存在，$f$ 在原点**不连续**——更谈不上可微（可微 ⟹ 连续，定理 5.2.5）。

**结论（方向导数存在 ⟹ 弱于可微）**：方向导数只沿**射线**逐条检测函数行为；可微性（定义 5.2.4）要求线性逼近 $f(\mathbf{x}_0+\mathbf{h}) = f(\mathbf{x}_0) + \mathbf{a}^\top\mathbf{h} + o(\|\mathbf{h}\|)$ 对**一切趋近方式**（任意曲线、任意方向组合）一致成立。本题函数沿每条射线都是"平坦"的，却沿抛物线束呈现"高度 $\frac{k}{1+k^2}$ 的山脊"——若这是损失面，只看方向导数的算法会被彻底欺骗。这正是理论坚持"$C^1$"假设的原因。

## 5.2（概念辨析｜对应 §5.3 梯度、§5.4 定理 5.4.5）

> $f(x,y) = x^2 + xy + y^2$ 的梯度场有什么特点？说明为什么该函数是严格凸的（两种方法）。

**梯度场**：$\nabla f = (2x + y,\ x + 2y)^\top = A\mathbf{x}$，其中 $A = \begin{pmatrix}2 & 1\\ 1 & 2\end{pmatrix}$ 为对称正定矩阵。特点：

- 梯度场是**线性**的（二次函数的梯度是一次向量场），且处处指向"等值椭圆的外法向"；
- 等值线 $x^2+xy+y^2 = c$ 是**倾斜 45° 的椭圆族**（长轴沿 $(1,-1)/\sqrt2$ 方向——该方向 $f$ 增长最慢：$f(\frac{t}{\sqrt2}, -\frac{t}{\sqrt2}) = \frac{t^2}{2}$；短轴沿 $(1,1)/\sqrt2$：$f = \frac{3t^2}{2}$）；
- 由定理 5.3.2，梯度与等值线正交、指向最速上升，$\|\nabla f\| = \|A\mathbf{x}\|$ 是最大变化率。

**方法一（Hessian 正定，定理 5.4.5）**：$H = \begin{pmatrix}2 & 1\\ 1 & 2\end{pmatrix}$（常矩阵）。特征方程 $\det(H - \lambda I) = (2-\lambda)^2 - 1 = 0$，特征值 $\lambda_1 = 1, \lambda_2 = 3 > 0$——**处处正定** ⟹ $f$ 严格凸。（也可用顺序主子式：$2 > 0$，$4 - 1 = 3 > 0$。）

**方法二（配平方）**：

$$f(x,y) = x^2 + xy + y^2 = \left(x + \frac{y}{2}\right)^2 + \frac{3}{4}y^2.$$

两个非负平方项之和，且等号成立当且仅当 $(x,y) = (0,0)$。对任意 $\mathbf{p} \neq \mathbf{q}$ 与 $\lambda \in (0,1)$：定义 $g(s) = f(\mathbf{q} + s(\mathbf{p}-\mathbf{q}))$ 是 $s$ 的严格凸二次函数（二阶导 = 沿方向曲率 $= 2(\Delta x)^2 + 2\Delta x\Delta y + 2(\Delta y)^2 = 2\left[(\Delta x + \tfrac{\Delta y}{2})^2 + \tfrac{3}{4}\Delta y^2\right] > 0$，因 $(\mathbf{p}-\mathbf{q}) \neq \mathbf{0}$），故 $f(\lambda\mathbf{p} + (1-\lambda)\mathbf{q}) < \lambda f(\mathbf{p}) + (1-\lambda) f(\mathbf{q})$——定义 2.5.2 中不等号严格成立，**严格凸**。两条路线结论一致。

## 5.3（概念辨析｜对应 §5.4 定理 5.4.4、鞍点）

> 若驻点处 Hessian 某特征值恰为 0（退化鞍点），二阶条件失效。举一个具体函数说明此时还需要三阶信息判断。

**构造**：$f(x, y) = x^3 + y^2$。驻点：$\nabla f = (3x^2, 2y) = (0,0) \Rightarrow (0,0)$。Hessian：

$$H = \begin{pmatrix} 6x & 0\\ 0 & 2\end{pmatrix}, \qquad H(\mathbf{0}) = \begin{pmatrix} 0 & 0\\ 0 & 2\end{pmatrix}.$$

特征值为 $0$ 与 $2$——**半正定但不正定**：定理 5.4.4 的三个分支（正定⟹极小、负定⟹极大、不定⟹鞍点）全部不适用，二阶判别沉默。

**三阶信息决断**：看零特征值方向（$x$ 方向）上的一元切片 $f(x, 0) = x^3$：在 $x = 0$ 两侧变号（$x < 0$ 时 $f < 0$，$x > 0$ 时 $f > 0$），原点是**鞍点**（沿 $x$ 方向一侧下降一侧上升；沿 $y$ 方向是极小）。

**对照（同样 Hessian、不同命运）**：$g(x, y) = x^4 + y^2$ 在原点的 Hessian 与 $f$ **完全相同**（$g$ 的 Hessian $= \mathrm{diag}(12x^2, 2)$，在原点也是 $\mathrm{diag}(0, 2)$），但 $g(x,0) = x^4 \ge 0$ 恒不负，$(0,0)$ 是严格**极小点**。

**结论**：零特征值方向上，二阶信息（恒为 0）不携带任何判别力，必须看**更高阶项的奇偶性与符号**：最低阶非零项是奇数次（如 $x^3$）⟹ 两侧变号 ⟹ 鞍点；是偶数次且系数为正（如 $x^4$）⟹ 极小。（系数为负则极大。）这正是深度学习"退化鞍点/平台区"比普通鞍点更难检测的数学原因：随机 Hessian 分析（5.9 题）假定了非退化性，而训练后期损失面上的平坦区恰恰是退化的。

## 5.4（计算推导｜对应 §5.2/5.3 偏导、梯度、方向导数）

> 求 $f(x,y,z) = x^2 y + \sin(yz)$ 的梯度与 Hessian，并在 $(1, 2, \pi)$ 处写出 $D_\mathbf{u}f$ 的最大值与最大值方向。

**梯度（逐坐标求偏导，把其他变量当常数）**：

$$\frac{\partial f}{\partial x} = 2xy, \qquad \frac{\partial f}{\partial y} = x^2 + z\cos(yz), \qquad \frac{\partial f}{\partial z} = y\cos(yz).$$

$$\nabla f = \big(2xy,\; x^2 + z\cos(yz),\; y\cos(yz)\big)^\top$$

（与正文校验给出的公式一致 ✓。）

**Hessian（六个二阶偏导，由 Schwarz 定理 5.4.2 对称）**：

$$\frac{\partial^2 f}{\partial x^2} = 2y,\qquad \frac{\partial^2 f}{\partial x\partial y} = 2x,\qquad \frac{\partial^2 f}{\partial x\partial z} = 0,$$

$$\frac{\partial^2 f}{\partial y^2} = -z^2\sin(yz),\qquad \frac{\partial^2 f}{\partial y\partial z} = \cos(yz) - yz\sin(yz),\qquad \frac{\partial^2 f}{\partial z^2} = -y^2\sin(yz),$$

$$H = \begin{pmatrix} 2y & 2x & 0\\ 2x & -z^2\sin(yz) & \cos(yz) - yz\sin(yz)\\ 0 & \cos(yz) - yz\sin(yz) & -y^2\sin(yz) \end{pmatrix}.$$

**在 $(1, 2, \pi)$ 处**：$\sin(2\pi) = 0$，$\cos(2\pi) = 1$，故

$$\nabla f(1,2,\pi) = \big(4,\; 1 + \pi,\; 2\big)^\top \approx (4,\; 4.1416,\; 2)^\top, \qquad H(1,2,\pi) = \begin{pmatrix} 4 & 2 & 0\\ 2 & 0 & 1\\ 0 & 1 & 0\end{pmatrix}.$$

**方向导数最大化（定理 5.3.2）**：$D_\mathbf{u}f = \nabla f^\top \mathbf{u}$，对单位向量 $\mathbf{u}$ 的最大值为 $\|\nabla f\|$（Cauchy–Schwarz 等号条件：$\mathbf{u}$ 与 $\nabla f$ 同向）：

$$\|\nabla f\| = \sqrt{4^2 + (1+\pi)^2 + 2^2} = \sqrt{16 + 17.1528 + 4} = \sqrt{37.1528} \approx 6.0953,$$

$$\mathbf{u}^\ast = \frac{\nabla f}{\|\nabla f\|} \approx (0.6563,\; 0.6795,\; 0.3281).$$

**校验**：$\nabla f$ 公式与正文一致 ✓；最大方向导数 $\approx 6.10$。

> ⚠️ **勘误**：正文校验值 "$\|\nabla f\| \approx 8.83$" 有误（$8.83^2 = 77.97 \neq 37.15$，与 $\nabla f = (4,\ 1+\pi,\ 2)$ 的直接计算不符）。正确值为 **6.0953**。

## 5.5（计算推导｜对应 §5.6 多元泰勒展开）

> 对 $f(x, y) = \mathrm{e}^{x+2y}$，在 $\mathbf{x}_0 = (0,0)$ 处写出到二阶的泰勒展开，并用它与精确值比较 $\mathbf{h} = (0.1, -0.05)$ 时的误差。

**泰勒展开（定理 5.6.1，Peano 余项）**：各阶信息——

$$f(\mathbf{0}) = 1,\qquad \nabla f = \mathrm{e}^{x+2y}(1, 2)^\top \Rightarrow \nabla f(\mathbf{0}) = (1, 2)^\top,$$

$$H = \mathrm{e}^{x+2y}\begin{pmatrix}1 & 2\\ 2 & 4\end{pmatrix} \Rightarrow H(\mathbf{0}) = \begin{pmatrix}1 & 2\\ 2 & 4\end{pmatrix}, \qquad \tfrac12\mathbf{h}^\top H\mathbf{h} = \tfrac12(h_1 + 2h_2)^2.$$

$$\boxed{\ \mathrm{e}^{x+2y} = 1 + (x + 2y) + \frac{(x+2y)^2}{2} + o(\|\mathbf{h}\|^2)\ }$$

（本质是一元函数 $s = x + 2y$ 的 $\mathrm{e}^s$ 展开复合——$f$ 只通过线性组合 $s$ 依赖 $(x,y)$，Hessian 的秩为 1。）

**代入 $\mathbf{h} = (0.1, -0.05)$**：线性组合 $s = h_1 + 2h_2 = 0.1 - 0.1 = 0$。

- 精确值：$\mathrm{e}^{0} = 1$；
- 二阶截断：$1 + 0 + 0 = 1$；
- **误差 $= 0$（严格为 0）**。

**解释与勘误说明**：误差主部是三阶项 $\frac{s^3}{6}$（一元 $\mathrm{e}^s$ 展开的下一项），而本题的 $\mathbf{h}$ 恰好落在 $s = 0$ 的**特殊方向**上——所有阶的项同时消失，任意阶截断误差都是 0。Pe⁠ano 余项 $o(\|\mathbf{h}\|^2)$ 是"最坏方向的阶"，具体方向的误差可以远小于它，甚至为零。若取一般方向如 $\mathbf{h} = (0.1, 0.05)$（$s = 0.2$）：精确值 $\mathrm{e}^{0.2} = 1.221403$，二阶截断 $1 + 0.2 + 0.02 = 1.22$，误差 $= 1.40\times10^{-3}$，其中主部正是 $\frac{s^3}{6} = \frac{0.008}{6} = 1.33\times10^{-3}$ ✓——**正文校验"二阶截断误差约 $10^{-3}$ 量级"对应的是这类一般方向**；题给的 $\mathbf{h} = (0.1, -0.05)$ 落在零误差方向上（误差恒为 0），两个事实不矛盾。

## 5.6（计算推导｜对应 §5.7 拉格朗日乘数法）

> 用拉格朗日乘数法求原点到平面 $x + 2y + 2z = 9$ 的最短距离，并用点到平面公式独立验证。

**拉格朗日乘数法（定理 5.7.1）**：最小化 $f = x^2 + y^2 + z^2$（距离的平方，避免根号），约束 $g = x + 2y + 2z - 9 = 0$。

条件 $\nabla f = \lambda\nabla g$：

$$(2x, 2y, 2z) = \lambda(1, 2, 2) \quad\Longrightarrow\quad x = \frac{\lambda}{2},\quad y = \lambda,\quad z = \lambda.$$

代回约束：$\frac{\lambda}{2} + 2\lambda + 2\lambda = 9 \Rightarrow \frac{9\lambda}{2} = 9 \Rightarrow \lambda = 2$。于是最近点

$$(x, y, z) = (1, 2, 2),$$

最短距离 $= \sqrt{1 + 4 + 4} = \sqrt{9} = 3$。

**这是最小值（不是最大）的确认**：$f$ 严格凸（$H = 2I$ 正定，同 5.2 题方法），约束平面是凸集，凸函数在凸集上的驻点即全局最小（第 2 章练习 2.3 的推广）；且 $f \to \infty$ 当 $\|\mathbf{x}\| \to \infty$（沿平面），故驻点唯一且为最小。

**独立验证一（点到平面距离公式）**：平面 $n\cdot\mathbf{x} = 9$，$n = (1,2,2)$，$\|n\| = 3$。原点距离 $= \frac{|0 - 9|}{\|n\|} = 3$ ✓。最近点 $= \frac{9}{\|n\|^2}n = \frac{9}{9}(1,2,2) = (1,2,2)$ ✓。

**独立验证二（乘子的影子价格意义）**：把约束右端改为 $c$，最短距离平方为 $f^\ast(c) = \frac{c^2}{9}$（最近点 $\frac{c}{9}n$）。$\frac{\mathrm{d}f^\ast}{\mathrm{d}c} = \frac{2c}{9}$，在 $c = 9$ 处 $= 2 = \lambda$ ✓——**乘数 = 目标对约束放松的灵敏度**（定理 5.7.1 后正文的"影子价格"）。

**校验**：距离 3、最近点 $(1, 2, 2)$，与正文校验一致 ✓。

## 5.7（编程实现｜对应 §5.8 实验二、§4.8 案例 1）

> 对 $f(\mathbf{x}) = \log\sum_j \mathrm{e}^{x_j}$：手推梯度 = softmax，用中心差分验证；并测试 $\mathbf{x} = (800, 0, -800)$ 时朴素实现与减最大值实现的差异。

**手推**（详见第 4 章练习 4.12 的完整证明，链式法则）：$\dfrac{\partial f}{\partial x_i} = \dfrac{\mathrm{e}^{x_i}}{\sum_j \mathrm{e}^{x_j}} = \mathrm{softmax}(\mathbf{x})_i$。

```python
import numpy as np

def lse_val(x):                      # log-sum-exp 朴素前向（小数值下正常）
    return np.log(np.sum(np.exp(x)))

def lse_naive_grad(x):
    e = np.exp(x)                    # 可能溢出
    return e / e.sum()

def lse_stable_grad(x):
    m = np.max(x)                    # 减最大值：指数参数全部 <= 0
    e = np.exp(x - m)
    return e / e.sum()

# --- 1. 一般点：softmax vs 中心差分 ---
x = np.array([0.3, -1.2, 2.1, 0.0])
g_num = np.zeros_like(x); h = 1e-5
for i in range(len(x)):
    e = np.zeros_like(x); e[i] = 1.0
    g_num[i] = (lse_val(x + h*e) - lse_val(x - h*e)) / (2*h)   # 中心差分 O(h^2)
print("softmax(x)   =", lse_stable_grad(x))
print("central diff =", g_num)
print("max abs diff =", np.max(np.abs(g_num - lse_stable_grad(x))))

# --- 2. 极不平衡点 (800, 0, -800) ---
z = np.array([800.0, 0.0, -800.0])
print("naive  grad  =", lse_naive_grad(z))     # exp(800) 溢出 inf -> inf/inf
print("stable grad  =", lse_stable_grad(z))
print("stable LSE   =", np.max(z) + np.log(np.sum(np.exp(z - np.max(z)))))
# 预期输出（实测，含 overflow/invalid RuntimeWarning）：
# softmax(x)   = [0.12478793 0.02784395 0.75492296 0.09244517]
# central diff = [0.12478793 0.02784395 0.75492296 0.09244517]
# max abs diff = 2.1972645924961398e-11
# naive  grad  = [nan  0.  0.]
# stable grad  = [1. 0. 0.]
# stable LSE   = 800.0
```

**校验**：一般点上 softmax 与中心差分逐分量一致（最大差 $2.2\times10^{-11}$，即中心差分 $O(h^2)$ 精度，见第 4 章例 4.3.2）；$\mathbf{x} = (800, 0, -800)$ 时朴素版溢出得 NaN、稳定版梯度 $\approx (1, 0, 0)$——均与正文校验一致 ✓。这就是 PyTorch `gradcheck` 与 softmax 稳定实现（`F.log_softmax`）的数学内核。

## 5.8（编程实现｜对应 §5.6 牛顿步、条件数）

> 实现牛顿法最小化 Rosenbrock 函数 $f(x,y) = 100(y-x^2)^2 + (1-x)^2$（初始点 $(-1.2, 1)$），打印前 10 次迭代的 $f$ 值与 $\|\nabla f\|$，并与梯度下降 $\eta = 10^{-3}$ 对比。

**梯度与 Hessian**（链式法则 + Schwarz 定理）：

$$\nabla f = \big(-400x(y - x^2) - 2(1-x),\;\; 200(y - x^2)\big)^\top,$$

$$H = \begin{pmatrix} 1200x^2 - 400y + 2 & -400x\\ -400x & 200 \end{pmatrix}.$$

```python
import numpy as np

def f(p):
    x, y = p
    return 100.0*(y - x*x)**2 + (1.0 - x)**2

def grad(p):
    x, y = p
    return np.array([-400.0*x*(y - x*x) - 2.0*(1.0 - x), 200.0*(y - x*x)])

def hess(p):
    x, y = p
    return np.array([[1200.0*x*x - 400.0*y + 2.0, -400.0*x],
                     [-400.0*x, 200.0]])

p = np.array([-1.2, 1.0])
print("== plain Newton ==")
for k in range(10):
    H = hess(p)                       # 如需阻尼：H += 1e-4 * np.eye(2)
    p = p - np.linalg.solve(H, grad(p))   # 牛顿步 x_{k+1} = x_k - H^{-1} grad
    print(f"it{k+1:02d}  f={f(p):.6e}  |grad|={np.linalg.norm(grad(p)):.3e}  "
          f"x=({p[0]:+.4f},{p[1]:+.4f})")

print("cond(H) at start =", np.linalg.cond(hess(np.array([-1.2, 1.0]))),
      "  cond(H) at (1,1) =", np.linalg.cond(hess(np.array([1.0, 1.0]))))

# 梯度下降对比：eta = 1e-3
p = np.array([-1.2, 1.0]); k = 0
while f(p) > 1e-8 and k < 200000:
    p = p - 1e-3 * grad(p); k += 1
print(f"GD eta=1e-3: iterations to f<1e-8: {k}  final f = {f(p):.2e}")
# 预期输出（实测）：
# == plain Newton ==
# it01  f=4.731884e+00  |grad|=4.639e+00  x=(-1.1753,+1.3807)
# it02  f=1.411845e+03  |grad|=1.371e+03  x=(+0.7631,-3.1750)   <- 初期"发散"：f 暴涨
# it03  f=5.596552e-02  |grad|=4.731e-01  x=(+0.7634,+0.5828)
# it04  f=3.131891e-01  |grad|=2.503e+01  x=(+1.0000,+0.9440)   <- 再次震荡
# it05  f=1.852740e-11  |grad|=8.609e-06  x=(+1.0000,+1.0000)   <- 进入二次收敛区
# it06  f=3.432646e-20  |grad|=8.286e-09
# it07  f=0.000000e+00  |grad|=0.000e+00                        <- 收敛到 (1,1), f=0
# it08..10  f=0.000000e+00
# cond(H) at start = 63.74   cond(H) at (1,1) = 2508.01
# GD eta=1e-3: iterations to f<1e-8: 20829  final f = 1.00e-08
```

**校验与解读**：

- 最终解 $(1, 1)$、$f = 0$ ✓（与正文一致）。Rosenbrock 山谷的 Hessian 条件数很大（起点 64，谷底 2508——谷底处 $H = \begin{pmatrix}802 & -400\\ -400 & 200\end{pmatrix}$，特征值 $0.399$ 与 $1001.6$），这正是该函数被称为"病态优化试金石"的原因。
- **朴素牛顿初期确实"发散"**：第 2 步 $f$ 从 4.7 暴涨到 1411（牛顿步走得太远），第 4 步再次震荡——远离极小点时二次模型不可信，对应正文"朴素牛顿在该函数上初期可能发散" ✓；进入山谷后从 it03 起**二阶收敛**显现（误差近似每步平方：$0.056 \to 0.31 \to 1.9\mathrm{e}{-11} \to 3.4\mathrm{e}{-20} \to 0$）。
- **阻尼版**（$H + 10^{-4}I$ 正则化）轨迹几乎相同但更平滑，it05 误差 $1.5\times10^{-8}$——线搜索/信赖域（最优化课程内容）正是为修复初期发散设计的。
- **GD $\eta = 10^{-3}$ 需要 20829 步**才到 $f < 10^{-8}$，而牛顿 5 步——"一阶便宜但慢、二阶贵但快"（§4.5、§5.6）的定量注脚。

## 5.9（开放思考｜对应 §5.4 鞍点与深度学习）

> 为什么高维空间中"驻点大多是鞍点"？这对理解深度网络训练动力学意味着什么？

**概率论证（题给提示的展开）**。设某驻点处 Hessian 的特征值符号近独立、正负近似等概率（这是随机高斯场 Hessian 谱的典型行为，Bray–Dean 指标定理的定量结论：特征值中正号比例随维度 $n\to\infty$ 集中在 $\frac12$ 附近）。那么：

- 驻点是**极小** ⟺ 全部 $n$ 个特征值为正：$P \approx 2^{-n}$（指数级衰减；对 $n = 10^6$ 是 $10^{-301000}$ 量级）；
- 驻点是**极大**：同样 $2^{-n}$；
- 驻点是**鞍点**（有正有负）：$1 - 2\cdot 2^{-n} \to 1$。

一维/二维的直觉（"驻点不是极大就是极小"）在高维彻底翻转：**"有正有负"是压倒性大概率，"全正"是指数级小概率**（§5.4 正文）。指标定理进一步说明：目标函数值越高的驻点，鞍点占比越接近 1；只有损失值非常低的盆地底部才可能聚集真正的极小点。

**对深度学习训练动力学的含义**：

1. **训练的主要障碍是鞍点而非局部极小**：随机初始化后参数大概率停在高损失鞍点附近（那里梯度小、进展慢）。经典"plateau 后突然下降"的现象 = 沿鞍点的薄弱方向（正曲率小、负曲率方向逃逸）缓慢逃逸。
2. **噪声是功能而非缺陷**：SGD 的梯度噪声、动量的惯性都是"鞍点逃逸器"——确定性 GD 在鞍点测度零的初值集外不会逃离（一阶信息在驻点处消失），噪声提供逃逸所需的扰动。
3. **高维极小点稀少且往往不坏**：既然极小点指数级稀少，能找到的局部极小多半位于"好盆地"（经验上泛化差异不大），这缓解了"陷入坏局部最优"的担忧——但不消除退化鞍点/平坦区问题（5.3 题的零特征值情形，二阶判别失效）。

## 5.10（开放思考｜对应 §5.6 一步下降公式、$L$-光滑）

> 学习率 $\eta < 2/L$ 对应哪些工程实践？用下降公式解释为什么损失爆炸常发生在训练初期。

**下降公式回顾（§5.6 推论 1）**：

$$f(\mathbf{x} - \eta\nabla f) \le f - \eta\left(1 - \frac{L\eta}{2}\right)\|\nabla f\|^2,$$

其中 $L = \lambda_{\max}(H)$（沿下降方向的曲率上界）。若 $L\eta > 2$，括号为负，**每步期望上升**——损失爆炸/NaN 的数学原型。

**工程对应**：

1. **梯度裁剪（gradient clipping）**：限制 $\|\nabla f\|$ 本身。注意 $L$ 是曲率不是梯度，裁剪治标（防止单步 $\eta\nabla f$ 过大冲进高曲率区），与 $\eta < 2/L$ 互补。
2. **学习率预热（warmup）**：训练初期从很小的 $\eta$ 线性升到目标值。理由：初期参数远离好区域、损失面曲率大且方向多变（有效 $L$ 大 ⟹ $2/L$ 小），同时 Adam 类方法的二阶矩估计还未热身（有效 $\eta$ 波动大）；$\eta$ 先小后大保证初期 $L\eta < 2$。
3. **学习率范围测试 / 扫描（LR finder）**：$\eta$ 从小到大指数扫描，观测 loss 开始上升的拐点——这正是经验性地探测 $2/L$ 边界：越过它，一步下降公式变号。
4. **学习率衰减**：训练后期减小 $\eta$，确保在残余的高曲率方向上仍满足 $L\eta < 2$（并压低 SGD 噪声地板，第 4 章练习 4.9）。

**为什么爆炸多发生在初期**：初期 (i) $\|\nabla f\|$ 大——同样违反 $L\eta < 2$ 时，上升量 $\eta(L\eta/2 - 1)\|\nabla f\|^2$ 与 $\|\nabla f\|^2$ 成正比，被放大到可见；(ii) 参数处在曲率陡峭区域（有效 $L$ 大），$2/L$ 小，同样的 $\eta$ 更容易越界；(iii) 优化器状态（动量/二阶矩）未收敛，等效步长抖动。训练后期接近平坦极小区，$\lambda_{\max}(H)$ 小 ⟹ $2/L$ 大，同一个 $\eta$ 安全——**"曲率决定步长上限"**（§2.9 误区 5 的多元版），这就是为什么大模型训练把 warmup + 裁剪 + 调度视为标配。

## 5.11（挑战题｜对应 §5.5 多元链式法则）

> 从可微性定义出发证明 $\nabla_t L = J_{\mathbf{g}}^\top \nabla_g L$，处理两层 $o(\cdot)$ 复合与 $J_{\mathbf{g}}$ 中间点为零的技术细节。

**设定**：$\mathbf{g}: \mathbb{R}^m \to \mathbb{R}^n$ 在 $\mathbf{t}$ 可微，$f: \mathbb{R}^n \to \mathbb{R}$ 在 $\mathbf{g}(\mathbf{t})$ 可微，$L = f \circ \mathbf{g}$。

**第一步（两个一阶展开）**。由可微性定义 5.2.4：

$$\mathbf{g}(\mathbf{t}+\mathbf{h}) = \mathbf{g}(\mathbf{t}) + J_{\mathbf{g}}(\mathbf{t})\,\mathbf{h} + \mathbf{r}_1(\mathbf{h}), \qquad \|\mathbf{r}_1(\mathbf{h})\| = o(\|\mathbf{h}\|), \tag{A}$$

$$f(\mathbf{g} + \mathbf{k}) = f(\mathbf{g}) + \nabla f(\mathbf{g})^\top \mathbf{k} + r_2(\mathbf{k}), \qquad r_2(\mathbf{k}) = o(\|\mathbf{k}\|). \tag{B}$$

**第二步（复合，处理"分母可能为零"的陷阱）**。令 $\mathbf{k} = \mathbf{g}(\mathbf{t}+\mathbf{h}) - \mathbf{g}(\mathbf{t}) = J_{\mathbf{g}}\mathbf{h} + \mathbf{r}_1(\mathbf{h})$，代入 (B)：

$$L(\mathbf{t}+\mathbf{h}) = f(\mathbf{g}) + \nabla f^\top\big(J_{\mathbf{g}}\mathbf{h} + \mathbf{r}_1(\mathbf{h})\big) + r_2\big(J_{\mathbf{g}}\mathbf{h} + \mathbf{r}_1(\mathbf{h})\big).$$

**关键控制**（这正是避开一元链式法则"除以 $\Delta u$"陷阱的地方——第 2 章 2.2 节：当 $\Delta u$ 以更快的速度趋于 0 甚至取 0 时，商 $\frac{\Delta y}{\Delta u}$ 的分解失效；多元的对应陷阱是 $J_{\mathbf{g}}$ 奇异/中间增量太大太小。可微性定义用"$o(\cdot)$ 直接复合"绕开了除法）：

- 中间增量的大小：$\|\mathbf{k}\| \le \big(\|J_{\mathbf{g}}\| + 1\big)\|\mathbf{h}\|$（$\|\mathbf{h}\| \le 1$ 时 $\|\mathbf{r}_1\| \le \|\mathbf{h}\|$），故 $\|\mathbf{k}\| = O(\|\mathbf{h}\|)$；
- 交叉项：$\nabla f^\top \mathbf{r}_1(\mathbf{h}) \le \|\nabla f\|\,\|\mathbf{r}_1(\mathbf{h})\| = o(\|\mathbf{h}\|)$（Cauchy–Schwarz）；
- 复合余项：$r_2(\mathbf{k}) = o(\|\mathbf{k}\|) = o(\|\mathbf{h}\|)$（$\|\mathbf{k}\| = O(\|\mathbf{h}\|)$ 且 $r_2(\mathbf{0}) = 0$；严格地，$r_2(\mathbf{k}) = \varepsilon(\mathbf{k})\|\mathbf{k}\|$，$\varepsilon \to 0$，故 $|r_2(\mathbf{k})| \le \varepsilon(\mathbf{k})(\|J_{\mathbf{g}}\| + 1)\|\mathbf{h}\| = o(\|\mathbf{h}\|)$）。

**第三步（读出梯度）**。合并：

$$L(\mathbf{t}+\mathbf{h}) = L(\mathbf{t}) + \big(J_{\mathbf{g}}^\top \nabla f\big)^\top \mathbf{h} + o(\|\mathbf{h}\|).$$

（用转置恒等式 $\nabla f^\top J_{\mathbf{g}}\mathbf{h} = (J_{\mathbf{g}}^\top \nabla f)^\top \mathbf{h}$。）由可微性的**线性主部唯一性**（定义 5.2.4 中的 $\mathbf{a}$ 唯一：若两个线性主部都成立，其差是 $o(\|\mathbf{h}\|)$ 的线性函数，只能恒为 0——取 $\mathbf{h} = s\mathbf{e}_j$ 除以 $s$ 即证），

$$\nabla L(\mathbf{t}) = J_{\mathbf{g}}(\mathbf{t})^\top\, \nabla f(\mathbf{g}(\mathbf{t})). \qquad\blacksquare$$

**标量形式**（第 $j$ 分量）：$\frac{\partial L}{\partial t_j} = \sum_{i=1}^n \frac{\partial f}{\partial g_i}\frac{\partial g_i}{\partial t_j}$——"每条路径的贡献求和"，矩阵形式让求和自动完成（§5.9 误区 2）。

**与深度学习的连接**：$L$ 层网络即 $L$ 次复合，反复应用本定理得 $\nabla L = J_1^\top J_2^\top \cdots$（逆序连乘）——反向传播的字面来源；缓存各层前向中间量供 $o(\cdot)$ 展开与雅可比使用，即"训练比推理耗显存"的数学原因。

## 5.12（挑战题｜对应 §5.7 隐函数定理、隐式微分）

> 设 $\mathbf{z}^\ast(\theta)$ 满足 $\nabla_{\mathbf{z}} \phi(\mathbf{z}^\ast, \theta) = \mathbf{0}$。证明 $\dfrac{\mathrm{d}\mathbf{z}^\ast}{\mathrm{d}\theta} = -\left(\nabla^2_{zz}\phi\right)^{-1} \nabla^2_{z\theta}\phi$，并讨论 $\nabla^2_{zz}\phi$ 不正定时的风险。

**证明（隐函数定理的链式应用）**。设 $\phi$ 二阶连续可微，且在某 $(\mathbf{z}_0, \theta_0)$ 处：① $\nabla_{\mathbf{z}}\phi(\mathbf{z}_0, \theta_0) = \mathbf{0}$；② Hessian $H_{zz} = \nabla^2_{zz}\phi(\mathbf{z}_0, \theta_0)$ **可逆**。由多元隐函数定理（§5.7 定理的向量版：$n$ 个方程 $n$ 个未知量，Jacobi = $H_{zz}$ 非奇异），存在唯一的 $C^1$ 映射 $\theta \mapsto \mathbf{z}^\ast(\theta)$（$\theta_0$ 附近）使

$$\nabla_{\mathbf{z}}\phi\big(\mathbf{z}^\ast(\theta), \theta\big) \equiv \mathbf{0}.$$

对恒等式两边关于 $\theta$ 求全导数（多元链式法则，定理 5.5.2：复合 $\theta \mapsto (\mathbf{z}^\ast(\theta), \theta) \mapsto \nabla_z\phi$）：

$$\underbrace{\nabla^2_{zz}\phi\cdot \frac{\mathrm{d}\mathbf{z}^\ast}{\mathrm{d}\theta}}_{\text{对第一组变量的雅可比}} + \underbrace{\nabla^2_{z\theta}\phi\cdot \frac{\partial(\theta)}{\partial\theta}}_{=\ \nabla^2_{z\theta}\phi} = \mathbf{0},$$

其中 $\nabla^2_{z\theta}\phi$ 的 $(i,j)$ 元 $= \frac{\partial^2\phi}{\partial z_i \partial\theta_j}$。移项（$H_{zz}$ 可逆保证可解）：

$$\boxed{\ \frac{\mathrm{d}\mathbf{z}^\ast}{\mathrm{d}\theta} = -\big(\nabla^2_{zz}\phi\big)^{-1}\, \nabla^2_{z\theta}\phi\ }\qquad\blacksquare$$

（一维对照：$\phi(z, \theta)$、$\phi_z(z^\ast, \theta) = 0$ ⟹ $z^{\ast\prime} = -\phi_{z\theta}/\phi_{zz}$——正是 §5.7 隐函数求导公式 $g' = -F_x/F_y$ 的翻版。）

**$\nabla^2_{zz}\phi$ 不正定（或不可逆）时的风险**：

1. **可逆性 ⟹ 解的局部唯一性**：$H_{zz}$ 奇异时隐函数定理条件②失效——$\mathbf{z}^\ast(\theta)$ 可能根本不是 $\theta$ 的可微函数（分岔：一个 $\theta$ 对应多个内层解，或解消失），公式无意义。
2. **条件数爆炸 ⟹ 梯度爆炸**：接近奇异时 $\|H_{zz}^{-1}\| \to \infty$，即使解连续，超梯度 $\frac{\mathrm{d}\mathbf{z}^\ast}{\mathrm{d}\theta}$ 也会巨大且方向病态，外层优化不稳定。对策：加正则（内层目标 + $\epsilon\|\mathbf{z}\|^2$，等价于 $H_{zz} + \epsilon I$）、信赖域或选择良态的解支。
3. **不正定 ⟹ "内层最优"名不副实**：公式只用到驻点条件 $\nabla_z\phi = 0$；若 $H_{zz}$ 有负特征值，$\mathbf{z}^\ast$ 是内层问题的鞍点而非极小，外层"梯度"指向鞍点邻域的解支——对 DEQ 类模型（平衡点需要压缩性/收缩性保证）与双层优化（内层解需局部唯一极小）都要专门处理。

**应用定位**：这是超参数优化（对 $\theta$ 求验证损失的梯度）、隐式深度学习（DEQ 反传）与神经 ODE 平衡态的核心公式——隐式微分用"解一个线性方程组（$H_{zz}$ 的求解）"代替"展开全部迭代步骤"，与 5.6 节牛顿步的代价结构一脉相承。

# 第 6 章 多元积分与概率的连续语言（对应正文 §6.13）

## 6.1（概念辨析｜对应 §6.1、§6.3）

> 为什么"改变 $p(x,y)$ 在一条曲线上的值"不影响任何概率计算？由此解释 $P(X = a) = 0$ 的含义，及"零概率事件"与"不可能事件"的区别。

**积分论理由**：所有概率计算都是积分（§6.3 表格）：$P((X,Y)\in D) = \iint_D p\,\mathrm{d}A$、$p_X(x) = \int p\,\mathrm{d}y$、$\mathbb{E}[g] = \iint gp\,\mathrm{d}A$。设被改变的集合是一条曲线 $\Gamma$（或有限个点）。$\Gamma$ 可以被总**面积**任意小的有限条窄矩形带覆盖（宽 $\varepsilon$、总长 $L$ 的带子面积 $\le \varepsilon L \to 0$）——即 $\Gamma$ 的二维勒贝格/Jordan 测度为 0。若 $|p| \le M$，被改动区域上的积分贡献至多 $M \times(\text{面积}) \to 0$，其余区域两函数相同——故对任何 $D$，$\iint_D p_{\text{改}}\,\mathrm{d}A = \iint_D p\,\mathrm{d}A$（同第 3 章练习 3.1 的一维情形，二维版）。边缘密度同理：内层积分中曲线与直线 $x = x_0$ 至多交于可数个点，一维零测集，不影响积分。

**$P(X = a) = 0$ 的含义**：$\{a\}$ 是一维零测集（长度 0），$P(X = a) = \int_{\{a\}} f_X\,\mathrm{d}x = 0$——概率质量均匀摊在连续区间上，任何单点分不到"宽度"，自然分不到质量。这不是 $f_X(a)$ 的性质（$f_X(a)$ 可以很大），而是"测度=长度"的性质。

**零概率 ≠ 不可能**：

- **不可能事件** = 空集 $\varnothing$（或与样本空间无交集的事件），逻辑上不发生；
- **零概率事件**：测度为 0 但**可能发生**——事实上，每次从连续分布抽样的结果 $X = x_0$ 都是一个零概率事件！若"概率为零 ⟹ 不可能"，则任何抽样都"不可能发生"，矛盾。

正确的关系是单向蕴含：不可能 ⟹ 零概率；零概率 ⇏ 不可能。这是"概率是测度不是逻辑"的第一课，也是第 5 章 5.10 题（ReLU 不可导点几乎不被触发）的数学根基。

## 6.2（概念辨析｜对应 §6.2 累次积分、§6.4 换元）

> 证明：$f$ 连续、$D$ 关于 $y$ 轴对称、$f$ 关于 $x$ 为奇函数 ⟹ $\iint_D f = 0$。并举对称性条件不满足的反例。

**证明（换元法）**：考虑镜面映射 $T(x, y) = (-x, y)$。因 $D$ 对称，$T$ 是 $D \to D$ 的一一 $C^1$ 映射，雅可比矩阵 $\begin{pmatrix}-1 & 0\\ 0 & 1\end{pmatrix}$，行列式 $= -1$，$|\det J| = 1$。由换元公式（定理 6.4.1）：

$$I = \iint_D f(x,y)\,\mathrm{d}A = \iint_D f(-x, y)\,|\det J|\,\mathrm{d}A = \iint_D f(-x, y)\,\mathrm{d}A.$$

由 $f$ 关于 $x$ 奇：$f(-x, y) = -f(x, y)$，故

$$I = \iint_D -f(x,y)\,\mathrm{d}A = -I \quad\Longrightarrow\quad 2I = 0 \quad\Longrightarrow\quad I = 0. \qquad\blacksquare$$

（初等版证明：把 $D$ 分成左右对称两半 $D_+, D_-$，在 $D_-$ 上换元 $x \to -x$ 化到 $D_+$，两块积分相消。）

**反例（对称性失效）**：$f(x, y) = x$（关于 $x$ 奇），$D = [0,1]\times[0,1]$——$f$ 满足奇性，但 $D$ 不关于 $y$ 轴对称。此时

$$\iint_D x\,\mathrm{d}A = \int_0^1\!\!\int_0^1 x\,\mathrm{d}x\,\mathrm{d}y = \frac12 \neq 0.$$

换元论证的第一步"$T(D) = D$"失效：$T(D) = [-1, 0]\times[0,1] \neq D$，"相消"无从发生。**使用口诀：奇偶对称性 = 函数对称 + 区域对称，缺一不可。**

## 6.3（概念辨析｜对应 §6.4 换元公式）

> 变换公式中雅可比取绝对值，而行列式可为负——"负的缩放因子"对应什么几何操作？为什么概率与积分都不关心定向？

**负行列式的几何含义**：$\det J < 0$ 表示线性化映射 $J$ 不仅缩放面积（$|\det J|$ 倍），还**翻转平面定向**——典型操作是反射/镜像（如交换两个坐标轴、翻转一个轴）。一维对应：$x \to -x$ 的"$g' < 0$"（单调递减换元）。行列式的符号记录的是"小平行四边形的手性"（右手系变左手系），而非面积大小。

**为什么积分与概率不关心定向**：

1. **测的是大小不是朝向**：$\iint f\,\mathrm{d}A$ 是把区域切成小片求和，每片贡献 $f \cdot (\text{面积})$——面积是非负标量，天然是 $|\det J|\,\mathrm{d}u\,\mathrm{d}v$。若误用带符号的 $\det J$，镜像区域上的积分会得负面积，物理量（质量、概率）为负——荒谬。
2. **概率质量非负**：$P((X,Y) \in T(S)) = \int_S p(h(u,v))|\det J_T|\mathrm{d}u\mathrm{d}v \ge 0$ 必须成立；$|\cdot|$ 保证之（§6.5 二维变换公式）。
3. **定向在别处出场**：需要定向符号的是微分形式积分——第二类曲线/曲面积分、Green/Stokes 定理（"沿边界方向"），那里 $\det$ 的符号携带环流/通量的方向信息。二重积分（第一类）对定向不敏感。

**一维对照（§6.9 误区 5）**：变换公式 $p_Y(y) = p_X(h(y))|h'(y)|$ 中 $|\cdot|$ 同样来自"单调递减换元时 $\int_a^b$ 上下限自动反号、两次反号相消"——取绝对值正是把"限的反号"折进"微元的正性"。

## 6.4（计算推导｜对应 §6.2 交换积分次序）

> 交换次序并计算 $\int_0^1\!\!\int_{\sqrt x}^{1} \sin(\pi y^3)\,\mathrm{d}y\,\mathrm{d}x$。

**第一步：画区域**。原限：$0 \le x \le 1$，$\sqrt x \le y \le 1$。边界 $y = \sqrt x$（即 $x = y^2$）、$y = 1$、$x = 0$。区域（换序必须画图，§6.9 误区 2）：

$$D = \{(x,y): 0 \le x \le 1,\ \sqrt x \le y \le 1\} = \{(x,y): 0 \le y \le 1,\ 0 \le x \le y^2\}.$$

（"$x$ 从 0 到 $y^2$"：由 $\sqrt x \le y$ 解出 $x \le y^2$。）

**第二步：换序**。内层现在对 $x$ 积分，被积函数 $\sin(\pi y^3)$ 与 $x$ 无关，直接"积出宽度"：

$$\int_0^1\!\!\int_{\sqrt x}^{1} \sin(\pi y^3)\,\mathrm{d}y\,\mathrm{d}x = \int_0^1\!\left[\int_0^{y^2} \sin(\pi y^3)\,\mathrm{d}x\right]\mathrm{d}y = \int_0^1 y^2\sin(\pi y^3)\,\mathrm{d}y.$$

**第三步：换元收尾**。令 $u = \pi y^3$，$\mathrm{d}u = 3\pi y^2\,\mathrm{d}y$；$y: 0 \to 1$ 对应 $u: 0 \to \pi$：

$$\int_0^1 y^2\sin(\pi y^3)\,\mathrm{d}y = \frac{1}{3\pi}\int_0^{\pi}\sin u\,\mathrm{d}u = \frac{1}{3\pi}\Big[-\cos u\Big]_0^{\pi} = \frac{1}{3\pi}\,(1 + 1) = \frac{2}{3\pi}.$$

**校验**：$\frac{2}{3\pi} \approx 0.21221$；数值直接对原次序做二重数值积分（`dblquad`）得 $0.2122065908$，与 $\frac{2}{3\pi} = 0.2122065908$ 完全一致 ✓。

> ⚠️ **勘误**：正文校验值 "$\frac{1}{3\pi}$" 漏掉了因子 2——$\int_0^\pi \sin u\,\mathrm{d}u = 2$（不是 1）。正确答案为 **$\dfrac{2}{3\pi}$**。

**方法注记**：本题是"换序救积分"的标准案例：$\sin(\pi y^3)$ 没有初等原函数，原次序内层积不动；换序后内层积出 $y^2$ 因子，恰好凑成 $\mathrm{d}(\pi y^3)$ 的微分——"让内层变可行"是换序的唯一动机。

## 6.5（计算推导｜对应 §6.4 极坐标、§6.3 高斯积分、Gamma 函数）

> 用极坐标计算 $\iint_{\text{第一象限}} \mathrm{e}^{-(x^2+y^2)}\,\mathrm{d}A$，由此证明 $\Gamma(\frac12) = \sqrt\pi$。

**第一步：极坐标计算**。第一象限 $D: x \ge 0, y \ge 0$ 对应 $0 \le r < \infty$，$0 \le \theta \le \frac{\pi}{2}$；$\mathrm{d}A = r\,\mathrm{d}r\,\mathrm{d}\theta$（雅可比 $r$，例 6.4.2——**勿忘 $r$**，§6.9 误区 1）：

$$\iint_D \mathrm{e}^{-(x^2+y^2)}\,\mathrm{d}A = \int_0^{\pi/2}\!\!\int_0^\infty \mathrm{e}^{-r^2}\,r\,\mathrm{d}r\,\mathrm{d}\theta.$$

内层：令 $s = r^2$，$\mathrm{d}s = 2r\,\mathrm{d}r$：$\int_0^\infty \mathrm{e}^{-r^2}r\,\mathrm{d}r = \frac12\int_0^\infty \mathrm{e}^{-s}\mathrm{d}s = \frac12$。外层：$\int_0^{\pi/2}\frac12\,\mathrm{d}\theta = \frac{\pi}{4}$。故

$$\iint_{\text{Q1}} \mathrm{e}^{-(x^2+y^2)}\,\mathrm{d}A = \frac{\pi}{4}.$$

**第二步：接回一维高斯积分**。记 $I = \int_0^\infty \mathrm{e}^{-x^2}\mathrm{d}x$。由 $f(x,y) = \mathrm{e}^{-x^2}\mathrm{e}^{-y^2}$ 可分离 + 第一象限是矩形型区域（Fubini 定理 6.2.1）：

$$I^2 = \left(\int_0^\infty \mathrm{e}^{-x^2}\mathrm{d}x\right)\left(\int_0^\infty \mathrm{e}^{-y^2}\mathrm{d}y\right) = \iint_{\text{Q1}} \mathrm{e}^{-(x^2+y^2)}\,\mathrm{d}A = \frac{\pi}{4},$$

$I > 0$，故 $I = \frac{\sqrt\pi}{2}$（即正文例 6.3.1 平方技巧在半直线上的版本）。

**第三步：Gamma 函数**。由定义 $\Gamma(s) = \int_0^\infty t^{s-1}\mathrm{e}^{-t}\mathrm{d}t$，取 $s = \frac12$ 并换元 $t = u^2$（$\mathrm{d}t = 2u\,\mathrm{d}u$，$t^{ -1/2} = \frac1u$）：

$$\Gamma\!\left(\tfrac12\right) = \int_0^\infty t^{-1/2}\mathrm{e}^{-t}\,\mathrm{d}t = \int_0^\infty \frac{\mathrm{e}^{-u^2}}{u}\cdot 2u\,\mathrm{d}u = 2\int_0^\infty \mathrm{e}^{-u^2}\,\mathrm{d}u = 2\cdot\frac{\sqrt\pi}{2} = \sqrt\pi. \qquad\blacksquare$$

**校验**：与正文校验一致 ✓；这也正是第 3 章 Gamma 公式 $\int_0^\infty x^n\mathrm{e}^{-x}\mathrm{d}x = n!$ 在非整数 $n$ 处的推广点（$\Gamma(\frac12)\cdot\Gamma(\frac12) = \pi$ 是 Beta 函数 $B(\frac12,\frac12) = \pi$ 的镜像）。数值复核：$2\int_0^\infty \mathrm{e}^{-x^2}\mathrm{d}x = 1.7724538509 = \sqrt\pi$（实测）✓。

## 6.6（计算推导｜对应 §6.3 归一化、边缘密度）

> 设 $(X, Y)$ 密度 $p(x,y) = c\,(x^2 + y^2)$ 于单位圆盘。求 $c$ 与边缘密度 $p_X(x)$。

**第一步：归一化定 $c$（极坐标，$D$ 是圆盘）**：

$$1 = \iint_D c(x^2+y^2)\,\mathrm{d}A = c\int_0^{2\pi}\!\!\int_0^1 r^2\cdot r\,\mathrm{d}r\,\mathrm{d}\theta = c\cdot 2\pi\cdot\left[\frac{r^4}{4}\right]_0^1 = c\cdot\frac{\pi}{2} \quad\Longrightarrow\quad c = \frac{2}{\pi}.$$

**校验**：$c = \frac{2}{\pi}$，与正文校验一致 ✓。

**第二步：边缘密度（$|x| \le 1$；固定 $x$，$y$ 从 $-\sqrt{1-x^2}$ 到 $+\sqrt{1-x^2}$）**：

$$p_X(x) = \int_{-\sqrt{1-x^2}}^{\sqrt{1-x^2}} c\,(x^2 + y^2)\,\mathrm{d}y = c\left[x^2 y + \frac{y^3}{3}\right]_{-\sqrt{1-x^2}}^{\sqrt{1-x^2}} = 2c\left(x^2\sqrt{1-x^2} + \frac{(1-x^2)^{3/2}}{3}\right).$$

提出公因子 $\sqrt{1-x^2}$（注意 $(1-x^2)^{3/2} = (1-x^2)\sqrt{1-x^2}$）：

$$p_X(x) = \frac{4}{\pi}\sqrt{1-x^2}\left(x^2 + \frac{1-x^2}{3}\right) = \frac{4}{\pi}\sqrt{1-x^2}\cdot\frac{1 + 2x^2}{3} = \boxed{\ \frac{4}{3\pi}\,(1 + 2x^2)\sqrt{1-x^2}\ }, \quad |x| \le 1,$$

（$|x| > 1$ 时 $p_X = 0$。）

**验证归一化**：$\int_{-1}^1 p_X\,\mathrm{d}x = \frac{4}{3\pi}\left[\int_{-1}^1\sqrt{1-x^2}\,\mathrm{d}x + 2\int_{-1}^1 x^2\sqrt{1-x^2}\,\mathrm{d}x\right] = \frac{4}{3\pi}\left[\frac{\pi}{2} + 2\cdot\frac{\pi}{8}\right] = \frac{4}{3\pi}\cdot\frac{3\pi}{4} = 1$ ✓（用了 $\int_{-1}^1\sqrt{1-x^2} = \frac\pi2$——半圆面积——与 $\int_{-1}^1 x^2\sqrt{1-x^2}\,\mathrm{d}x = \frac{\pi}{8}$；数值积分复核 $= 1.0000000000$，实测）。

> ⚠️ **勘误**：正文校验值 $p_X(x) = \frac{4}{3\pi}(1-x^2)^{3/2}$ 有误——它在 $[-1,1]$ 上的积分 $= \frac{4}{3\pi}\cdot\frac{3\pi}{8} = \frac12 \neq 1$，不是归一化的密度（漏了 $x^2$ 部分的贡献 $2x^2\sqrt{1-x^2}$，它恰好让多出的质量补齐到 1）。正确边缘密度为 $\frac{4}{3\pi}(1+2x^2)\sqrt{1-x^2}$。

## 6.7（编程实现｜对应 §6.5 例 6.5.2、§6.6 实验三）

> 生成二维独立标准正态样本，检验极角 $\Theta$ 的均匀性，并估计 $P(R > 2)$ 与理论值 $\mathrm{e}^{-2}$ 比较。

**理论**（例 6.5.2）：$X, Y$ 独立标准正态时 $p_{R,\Theta}(r,\theta) = \left(r\mathrm{e}^{-r^2/2}\right)\cdot\frac{1}{2\pi}$ 因式分解 ⟹ $\Theta \sim U[0, 2\pi)$ 且与 $R$ 独立；$P(R > 2) = \int_2^\infty r\mathrm{e}^{-r^2/2}\mathrm{d}r = \mathrm{e}^{-2} \approx 0.1353$。

```python
import numpy as np

rng = np.random.default_rng(0)
n = 1_000_000
xy = rng.standard_normal((n, 2))          # 独立标准正态
theta = np.arctan2(xy[:, 1], xy[:, 0]) % (2*np.pi)   # 极角，折到 [0, 2pi)
R = np.sqrt((xy**2).sum(axis=1))          # 极径（瑞利分布）

# 1) 均匀性检验：12 个 bin 的卡方统计量（自由度 11，95% 分位 19.68）
cnt, _ = np.histogram(theta, bins=np.linspace(0, 2*np.pi, 13))
expected = n / 12
chi2 = np.sum((cnt - expected)**2 / expected)
print(f"chi2 = {chi2:.2f} (dof=11, 95% quantile = 19.68)")
print(f"bin counts: min={cnt.min()}, max={cnt.max()}, expected={expected:.0f}")

# 2) P(R > 2) 对比理论值
p_emp = np.mean(R > 2.0)
print(f"P(R>2) empirical = {p_emp:.5f}  theory e^-2 = {np.exp(-2):.5f}  "
      f"rel err = {abs(p_emp-np.exp(-2))/np.exp(-2)*100:.2f}%")
# 预期输出（实测，seed=0）：
# chi2 = 6.22 (dof=11, 95% quantile = 19.68)      <- 远小于临界值，均匀性不被拒绝
# bin counts: min=82850, max=83655, expected=83333
# P(R>2) empirical = 0.13509  theory e^-2 = 0.13534  rel err = 0.18%
```

**校验**：卡方统计量 6.22 ≪ 19.68（12 个 bin 计数在 $[82850, 83655]$，相对理论 83333 的波动为 $O(1/\sqrt{n}) \approx 0.3\%$——符合均匀性）；$P(R>2)$ 相对误差 0.18%，在 $10^6$ 样本 1% 量级之内——均与正文校验一致 ✓。这正是"二维高斯各向同性"的蒙特卡洛验证，也是 §6.6 实验三"$\pi$ 的估计"的思想近亲。

**校验**：所有 $r$ 处误差 $< 10^{-8}$（实际达机器精度 $10^{-16}$）✓。解读：$r = 3$ 时质量 $\approx 0.989$——正文案例 1 的"二维 3σ 规则"（$R$ 是瑞利分布，$R^2 \sim \mathrm{Exp}(\frac12)$，故 $P(R \le r) = 1 - \mathrm{e}^{-r^2/2}$ 精确成立）；$r = 4$ 时质量已达 $0.99966$。

## 6.9（开放思考｜对应 §6.4 n 维推广、维度灾难）

> 为什么"体积向薄壳集中"意味着高维高斯的质量集中在半径 $\sqrt{n-1}$ 至 $\sqrt{n+1}$ 的壳内？给出 kNN 失效的积分论解释。

**第一层：均匀分布的体积集中（积分论）**。$n$ 维半径 $R$ 球的体积 $V_n R^n$（$V_n = \frac{\pi^{n/2}}{\Gamma(\frac n2+1)}$，见 6.11 题）。半径 $(1-\delta)R$ 的内球与外壳的体积比：

$$\frac{V_n[(1-\delta)R]^n}{V_n R^n} = (1-\delta)^n \longrightarrow 0 \quad (\delta \text{ 固定},\ n \to \infty).$$

即**任意靠近边界的外壳占据几乎全部体积**——"薄壳集中"。直觉：体积是 $r^n$ 增长的，最外层的半径微小增幅对应最大的体积增量（与二维"圆环越靠外越宽"同一现象的 $n$ 维版，例 6.4.2 的 $r$ 因子）。

**第二层：高斯质量集中（概率论换算）**。$\mathbf{x} \sim N(\mathbf{0}, I_n)$ 时 $\|\mathbf{x}\|^2 = \sum_i x_i^2$，其中 $x_i^2$ i.i.d.、均值 1、方差 2，故

$$\mathbb{E}\|\mathbf{x}\|^2 = n, \qquad \mathrm{Var}\,\|\mathbf{x}\|^2 = 2n \ \Rightarrow\ \mathrm{sd} = \sqrt{2n}.$$

由 Chebyshev 不等式：$P\big(\big|\|\mathbf{x}\|^2 - n\big| > 2\sqrt{2n}\big) \le \frac{2n}{8n} = \frac14$，且随 $n$ 增大相对涨落 $\frac{\sqrt{2n}}{n} = \sqrt{2/n} \to 0$——**$\|\mathbf{x}\| = \sqrt n \cdot (1 + O(n^{-1/2}))$**，几乎全部质量集中在相对厚度 $\sim\frac1{\sqrt n}$ 的球壳 $\left[\sqrt{n - c\sqrt n},\ \sqrt{n + c\sqrt n}\right]$（$n$ 很大时即 $\sqrt{n-1}$ 至 $\sqrt{n+1}$ 量级的绝对宽度内）。与第一层呼应：高斯密度是径向对称的，其质量分布继承"体积壳"的几何。

**第三层：kNN 失效的解释**。考虑两个近似独立的随机点 $\mathbf{x}, \mathbf{y}$（各分量方差 1）：$\|\mathbf{x} - \mathbf{y}\|^2$ 的期望为 $2n$、方差 $O(n)$——相对涨落 $O(1/\sqrt n) \to 0$。于是**所有点两两之间的距离几乎相同**（都 $\approx \sqrt{2n}$）：最近邻与最远邻的距离比 $\to 1$，"距离的区分度"消失，基于欧氏距离的近邻投票失去依据。积分论语言：概率质量（数据点）全部摊在高维球壳上，"近"与"远"的径向差异被壳的厚度（$\sim\frac1{\sqrt n}$ 相对值）吞没。**对策预告**：改用角度/内积/学习到的度量、降维、或依赖流形结构——机器学习课程 kNN 与表示学习章节正面处理。

## 6.10（开放思考｜对应 §6.5 变换公式、VAE 重参数化）

> 用 6.5 节变换公式的语言解释重参数化技巧 $z = \mu + \sigma \odot \epsilon$（$\epsilon \sim N(0, I)$）为什么"数学上等价、优化上可行"。

**数学等价性（变换公式的正向使用）**。一维（逐维）记号：固定 $\mu, \sigma > 0$，映射 $z = g(\epsilon) = \mu + \sigma\epsilon$ 是 $\mathbb{R} \to \mathbb{R}$ 的一一 $C^1$ 变换，逆 $\epsilon = h(z) = \frac{z - \mu}{\sigma}$，$|h'(z)| = \frac1\sigma$。由 §6.5 一维变换公式：

$$p_Z(z) = p_\epsilon(h(z))\,|h'(z)| = \frac{1}{\sqrt{2\pi}}\,\mathrm{e}^{-(z-\mu)^2/(2\sigma^2)}\cdot\frac1\sigma = \frac{1}{\sqrt{2\pi}\,\sigma}\,\mathrm{e}^{-(z-\mu)^2/(2\sigma^2)},$$

这正是 $N(\mu, \sigma^2)$ 的密度。**即：从 $\epsilon \sim N(0,1)$ 采样再经确定性变换 $z = \mu + \sigma\epsilon$，与直接从 $p_\theta(z) = N(\mu, \sigma^2)$ 采样，分布完全相同**（概率质量守恒——雅可比因子 $\frac1\sigma$ 恰好补齐密度的缩放）。多维同理（对角 $\Sigma$，雅可比 $\det = \prod\sigma_i$）。

**优化可行性（期望的测度搬家）**。VAE 的目标是优化 $\mathbb{E}_{z \sim p_\theta}[f_\phi(z)]$。原形式的期望对 $p_\theta$ 取——**采样分布依赖参数 $\theta = (\mu, \sigma)$**，把梯度移进期望需要 score function $\nabla_\theta \log p_\theta(z)$（REINFORCE 估计，方差大）。重参数化后用变换公式把期望"搬家"：

$$\mathbb{E}_{z\sim p_\theta}[f_\phi(z)] = \mathbb{E}_{\epsilon\sim N(0,I)}\big[f_\phi(\mu + \sigma\odot\epsilon)\big].$$

右边的期望对**与 $\theta$ 无关的固定测度** $N(0, I)$ 取，随机性全部集中在 $\epsilon$ 上——于是梯度可以穿过确定性变换直接回传：

$$\nabla_\theta\, \mathbb{E}_{\epsilon}\big[f_\phi(\mu+\sigma\odot\epsilon)\big] = \mathbb{E}_\epsilon\left[\nabla_z f_\phi(z)\cdot\frac{\partial z}{\partial\theta}\right], \qquad \frac{\partial z}{\partial \mu} = 1,\ \ \frac{\partial z}{\partial\sigma} = \epsilon.$$

蒙特卡洛估计只需"采样 $\epsilon$ + 常规前向/反向"——就是一次普通的可微计算图执行。**一句话**：变换公式保证 $\epsilon$-空间与 $z$-空间概率质量一一对应（数学等价）；把随机性固定在 $\epsilon$、把参数放进确定性变换，使得 $\theta$ 的梯度表现为对固定分布的期望的普通链式法则（优化可行），且该估计（pathwise gradient）方差远小于 score-function 估计。

## 6.11（挑战题｜对应 §6.4 n 维推广的完整闭环）

> 用 $n$ 维高斯积分推导 $n$ 维单位球体积公式 $V_n = \dfrac{\pi^{n/2}}{\Gamma(\frac n2 + 1)}$。

**第一步：两种方式计算同一积分**。考虑

$$G_n = \int_{\mathbb{R}^n} \mathrm{e}^{-\|x\|^2}\,\mathrm{d}x.$$

*方式一（笛卡尔，逐维分离）*：$\|x\|^2 = x_1^2 + \cdots + x_n^2$，被积函数可分离，Fubini 定理（§6.2）逐次使用：

$$G_n = \prod_{i=1}^n \int_{-\infty}^{\infty} \mathrm{e}^{-x_i^2}\,\mathrm{d}x_i = \left(\sqrt\pi\right)^n = \pi^{n/2},$$

（一维高斯积分 $\int_{-\infty}^\infty \mathrm{e}^{-x^2}\mathrm{d}x = \sqrt\pi$，由 6.5 题的平方技巧。）

*方式二（球坐标，径向 + 球面）*：记 $S_{n-1}$ 为单位球面 $\{\|u\| = 1\}$ 的 $(n-1)$ 维面积。球坐标 $\mathrm{d}x = \rho^{n-1}\,\mathrm{d}\rho\,\mathrm{d}\sigma$（$\mathrm{d}\sigma$ 是球面面积元，含 $\rho^{n-1}$ 因子——§6.4 球坐标 $\rho^2\sin\varphi$ 的 $n$ 维推广）：

$$G_n = \int_0^\infty \mathrm{e}^{-\rho^2}\,\rho^{n-1}\,\mathrm{d}\rho \cdot S_{n-1}.$$

内层换元 $t = \rho^2$（$\mathrm{d}t = 2\rho\,\mathrm{d}\rho$，$\rho^{n-1}\mathrm{d}\rho = \frac12 t^{(n-2)/2}\mathrm{d}t = \frac12 t^{\frac n2 - 1}\mathrm{d}t$）：

$$\int_0^\infty \mathrm{e}^{-\rho^2}\rho^{n-1}\mathrm{d}\rho = \frac12\int_0^\infty t^{\frac n2 - 1}\mathrm{e}^{-t}\,\mathrm{d}t = \frac12\,\Gamma\!\left(\frac n2\right).$$

**第二步：解出球面面积**。令两式相等：

$$\pi^{n/2} = \frac12\,\Gamma\!\left(\frac n2\right) S_{n-1} \quad\Longrightarrow\quad S_{n-1} = \frac{2\pi^{n/2}}{\Gamma(\frac n2)}.$$

（校验：$n = 2$：$S_1 = \frac{2\pi}{\Gamma(1)} = 2\pi$ ✓ 单位圆周长；$n = 3$：$S_2 = \frac{2\pi^{3/2}}{\Gamma(3/2)} = \frac{2\pi^{3/2}}{\frac12\sqrt\pi} = 4\pi$ ✓ 球面积——$\Gamma(\frac12) = \sqrt\pi$（6.5 题）在此合流。）

**第三步：径向积分得体积**。单位球体积 = 半径从 0 到 1 的球壳累加：

$$V_n = \int_0^1 S_{n-1}\,\rho^{n-1}\,\mathrm{d}\rho = \frac{S_{n-1}}{n} = \frac{2\pi^{n/2}}{n\,\Gamma(\frac n2)}.$$

用 Gamma 递推 $\Gamma(s+1) = s\,\Gamma(s)$（分部积分一次即得，$s = \frac n2$）：$n\,\Gamma(\frac n2) = 2\cdot\frac n2\,\Gamma(\frac n2) = 2\,\Gamma(\frac n2 + 1)$，故

$$V_n = \frac{2\pi^{n/2}}{2\,\Gamma(\frac n2 + 1)} = \frac{\pi^{n/2}}{\Gamma(\frac n2 + 1)}. \qquad\blacksquare$$

**校验**：$n = 1$：$V_1 = \frac{\sqrt\pi}{\Gamma(3/2)} = \frac{\sqrt\pi}{\frac12\sqrt\pi} = 2$ ✓（$[-1,1]$ 长度）；$n = 2$：$V_2 = \frac{\pi}{\Gamma(2)} = \pi$ ✓ 圆面积；$n = 3$：$V_3 = \frac{\pi^{3/2}}{\Gamma(5/2)} = \frac{\pi^{3/2}}{\frac32\cdot\frac12\sqrt\pi} = \frac{4\pi}{3}$ ✓ 球体积（与 §6.4 球坐标直接积分一致）。**推论（6.9 题的伏笔）**：$V_n$ 先增后减趋于 0（Stirling：$\Gamma(n/2+1) \sim \sqrt{2\pi}(\frac n{2\mathrm e})^{n/2}$ 增长快于 $\pi^{n/2}$），体积向薄壳集中——维度灾难的积分论根源。

## 6.12（挑战题｜对应 §6.5 变换公式、最优传输初体验）

> 取 $p = N(0,1)$、$q = N(1, 2^2)$，推导单调传输映射 $T(x) = 1 + 2x$，用变换公式验证 $T\#p = q$，并数值验证 $\mathbb{E}_{X\sim p}[(T(X)-X)^2]$。

**第一步：推导 $T$**。一维分布函数 $F_p(x) = \Phi\!\left(\frac{x - 0}{1}\right) = \Phi(x)$，$F_q^{-1}(u) = 1 + 2\,\Phi^{-1}(u)$（$N(1, 4)$ 的分位函数）。单调传输映射（"最省力"映射，Caffarelli 一维定理）：

$$T = F_q^{-1} \circ F_p: \quad T(x) = 1 + 2\,\Phi^{-1}(\Phi(x)) = 1 + 2x.$$

**第二步：用 §6.5 变换公式验证 $T\#p = q$**（即 $Y = T(X)$ 的密度是 $q$）。$T$ 严格单调递增，逆 $h(y) = \frac{y-1}{2}$，$h'(y) = \frac12$：

$$p_Y(y) = p_X(h(y))\,\left|\frac{\mathrm{d}h}{\mathrm{d}y}\right| = \frac{1}{\sqrt{2\pi}}\,\mathrm{e}^{-\left(\frac{y-1}{2}\right)^2/2}\cdot\frac{1}{2} = \frac{1}{2\sqrt{2\pi}}\,\mathrm{e}^{-\frac{(y-1)^2}{8}}.$$

这正是 $N(1, 2^2)$ 的密度 ✓（变换公式的概率守恒：$\frac1{2}$ 的雅可比补偿了横轴拉伸 2 倍）。**注意方向**：$p_{U,V}$ 用的是**逆变换** $h$ 的雅可比（§6.9 误区 5）。

**第三步：计算 $\mathbb{E}_{X\sim p}[(T(X)-X)^2]$**。$T(X) - X = (1 + 2X) - X = 1 + X$，$X \sim N(0,1)$：

$$\mathbb{E}\big[(1+X)^2\big] = 1 + 2\,\mathbb{E}[X] + \mathbb{E}[X^2] = 1 + 0 + 1 = 2.$$

**与最优传输公式的对照**：Wasserstein-2 距离的平方 $W_2^2(p, q) = \mathbb{E}[(T(X)-X)^2]$，对位置-尺度族有闭式 $W_2^2 = (\mu_q - \mu_p)^2 + (\sigma_q - \sigma_p)^2 = 1^2 + 1^2 = 2$ ✓——**"均值差的平方 + 标准差之差的平方"**（正文括号提示正确，数值为 2）。蒙特卡洛复核（$10^6$ 样本）：实测 $2.0015$，与理论值 2 吻合到抽样误差。

> ⚠️ **勘误**：正文校验值 "$\mathbb{E}[(T(X)-X)^2] = 1$" 有误。$T(X) - X = 1 + X$ 含两个方差单位：位置平移贡献 $(\Delta\mu)^2 = 1$、尺度拉伸贡献 $(\Delta\sigma)^2 = (2-1)^2 = 1$，合计 **2**。若 $q = N(1, 1)$（$\sigma_q = \sigma_p = 1$）则恰为 1——正文可能按此情形口算。

**深入方向**：$T = F_q^{-1}\circ F_p$ 是一维最优传输的显式解（单调映射在凸成本下最省力）；高维的对应物是 Brenier 映射（某个凸函数的梯度），(normalizing flow 中的 autoregressive 变换、扩散模型的概率流 ODE 都是它的近亲——最优传输课程/进阶阅读处理)。

# 使用建议：如何用答案册复盘

**1. 复盘的最小闭环：错题 → 定位正文小节 → 重做同型题**。

每题题头的"对应正文 §x.x"就是你的回看地图。建议按错因分流：

- **概念题做错**（第 m 题第 1–3 题）→ 回看对应**定义**，并重读该章"常见误区与陷阱"一节的相邻条目。例：1.2 题错在"极限存在=连续" → 回看 §1.5 定义 1.5.1 的三个要件 + §1.9 误区 1；5.1 题错在"方向导数存在=可微" → 回看 §5.2 定义 5.2.4 与反例。
- **计算题做错**（每章第 4–6 题）→ 先判断错在哪一步（设错？代错？符号？），再回看对应**定理的精确条件**。例：4.4(b) 忘记通分 → 回看 §4.3 应用一；3.4(c) Gamma 公式记错 → 回看 §3.4 例 3.4.5 的推导而非死记公式。
- **编程题对不上数**（每章第 7–8 题）→ 三查：① 步长/参数是否落在理论最优区（中心差分 $h\sim10^{-5}$、GD $\eta < 2/L$）；② 是否混淆截断误差与舍入误差的支配区间（第 2、4 章 U 形曲线）；③ 随机实验是否固定了种子、样本量是否够（$O(1/\sqrt n)$ 误差）。

**2. 利用"两遍做题法"**：第一遍只看题做，卡住超过 15 分钟才看答案的**解题路线段**（开放题与挑战题的"先做什么、中间结论"），合上答案完成剩余步骤；第二遍（一周后）只重做错题。挑战题（每章第 11–12 题）允许只掌握证明骨架，但骨架必须能默写。

**3. 关注"校验值对照表"**：册末勘误表不只是纠错清单，它本身就是一节隐藏的习题——每个勘误都对应一类典型错误（漏因子、符号反向、下限瑕疵点、中间结果当最终结果、特殊方向特殊值）。建议把每个勘误当作"找茬练习"：先自己重算正文校验值，再对照本册。

**4. 把编程题答案当作模板库**：二分法求根（1.7）、误差阶实验（1.8/4.8）、梯度校验（2.7/5.7）、GD/牛顿对比（2.8/5.8）、蒙特卡洛验证分布（6.7/6.8）——这些 20–40 行的脚本覆盖了后续课程（最优化、深度学习、概率统计）反复出现的实验范式。修改目标函数重跑一遍，是最好的自查训练。

**5. 与前后章节串联**：许多题在多处"重逢"——柯西准则（1.9/1.12/3.11）、链式法则陷阱（2 章末/5.11）、数值步长（2.7/4.7/5.7/4.10）、变换公式（3.4/6.5/6.10/6.12）。复习时按"主题"而不是"章"再串一遍，构建本课程引言所说的"分析语言"网络。
