## 99.1 项目一（必做）：从零实现自动微分（naive autograd）

### 99.1.1 项目背景与目标

第 5 章证明了：反向传播就是多元链式法则 $\nabla_t L = J_{\mathbf{g}}^\top \nabla_g L$ 的逆序记账（5.5 节）。PyTorch 的 `autograd` 把这套记账自动化。本项目的目标是**亲手实现一个约 150 行的标量/向量 autograd 引擎**，让"神经网络框架"从魔法变成你的代码。

参考外部范本：Andrej Karpathy 的 micrograd（约 100 行，GitHub 公开）——建议先自己写，卡住再对照，而不是先抄。

### 99.1.2 任务分解

1. **Value 类与运算重载**：实现 `Value` 类，支持 `+`、`-`、`*`、`/`、`**`、`tanh`、`exp`、`log`、`neg`、`relu`。每个运算记录：输入子节点、局部导数（梯度回传函数）、反向拓扑序。
2. **前向与反向**：实现 `backward()`：拓扑排序所有节点，从输出出发，按链式法则把 `out.grad * 局部导数` 累加到每个输入的 `.grad`（注意是 **累加 +=**，不是赋值——一个变量被多处使用时梯度要汇总，对应第 5 章"所有路径求和"）。
3. **标量神经网络**：用 `Value` 搭一个 2-2-1 的 MLP（线性层 + tanh），在手工构造的小数据集（如 20 个点）上用梯度下降训练，使损失下降到阈值以下。
4. **梯度验证**：实现中心差分 `numerical_grad(f, x, h=1e-5)`，对每个参数比较解析梯度与数值梯度（相对误差 $< 10^{-6}$）。这就是 PyTorch `gradcheck` 的手写版。
5. **实验报告**：报告（Markdown 或 notebook）回答：为什么反向传播比"逐参数数值微分"快？梯度累加中 += 换成 = 会出现什么错误（构造一个变量被复用的例子演示）？

### 99.1.3 提示

- 拓扑排序用 DFS 或 Kahn 算法均可；`_backward` 闭包挂在节点上最简洁。
- `tanh` 的导数 $1 - \tanh^2 x$；`log` 的导数 $1/x$——都已在第 2 章导数表中。
- 常见陷阱：`a + a`（同一节点出现两次）、`a * b + a * c`（公因子）——先想清楚 += 为什么天然处理这两种情况（第 5 章 5.5 例 5.5.3 的多路径求和）。

### 99.1.5 提示代码骨架

```python
import math

class Value:
    """最小自动微分节点：值 + 梯度 + 父节点 + 反传闭包。"""
    def __init__(self, data, parents=(), label=""):
        self.data = data
        self.grad = 0.0
        self._prev = set(parents)
        self._backward = lambda: None
        self.label = label

    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other))
        def _backward():
            self.grad  += out.grad          # 链式法则：d/dself = 1（累加！）
            other.grad += out.grad
        out._backward = _backward
        return out

    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other))
        def _backward():
            self.grad  += other.data * out.grad   # 乘法法则：u'v + uv'
            other.grad += self.data * out.grad
        out._backward = _backward
        return out

    def tanh(self):
        out = Value(math.tanh(self.data), (self,))
        def _backward():
            self.grad += (1 - out.data**2) * out.grad   # 第 2 章导数表
        out._backward = _backward
        return out

    def backward(self):
        topo, visited = [], set()
        def build(v):
            if v not in visited:
                visited.add(v)
                for p in v._prev:
                    build(p)
                topo.append(v)
        build(self)
        self.grad = 1.0
        for node in reversed(topo):       # 逆序 = 从输出向输入传播
            node._backward()
        return self

# 其余算子（__sub__/__truediv__/__pow__/exp/log/relu）按同样模式补全。
```

## 99.2 项目二（选做一）：数值方法验证梯度公式与 Hessian

### 99.2.1 项目背景与目标

任何自己推导的梯度公式都可能错，且错误往往是"漏一条路径""符号反了""漏了 Hessian 项"。工程界的标准防线是**数值验证**（第 5 章 5.8 实验二的系统化）。本项目建立一套"解析 vs 数值"的梯度与 Hessian 验证流水线，并在三个真实函数族上运行它，其中包括一个故意埋错的实现供你诊断。

### 99.2.2 任务分解

1. **工具层**：实现中心差分梯度 `grad_num`（$O(h^2)$）与 Hessian 的差分估计：
   - 对角元：$\frac{f(x+h e_i) - 2f(x) + f(x - h e_i)}{h^2}$；
   - 非对角元：$\frac{f(x{+}h e_i{+}h e_j) - f(x{+}h e_i{-}h e_j) - f(x{-}h e_i{+}h e_j) + f(x{-}h e_i{-}h e_j)}{4h^2}$。
2. **被测函数族**（每个都要有"解析梯度 + 解析 Hessian"的手工推导，写进报告）：
   - log-sum-exp：$f(\mathbf{x}) = \log\sum_j \mathrm{e}^{x_j}$（梯度 = softmax，第 5 章练习 7）；
   - 高斯负对数似然：$f(\mathbf{x}) = \frac12\mathbf{x}^\top A \mathbf{x} + \mathbf{b}^\top\mathbf{x}$（Hessian $= A$，验证对称性与正定性判别）；
   - Rosenbrock 函数 $100(y - x^2)^2 + (1-x)^2$（病态曲率，条件数巨大）。
3. **步长扫描**：对每个函数、每个测试点，扫描 $h \in \{10^{-1},\dots,10^{-12}\}$，画出验证误差的 U 形曲线，标注理论谷底位置（第 4 章例 4.3.2：梯度验证 $h^\ast\sim10^{-5}$，Hessian 二阶差分更怕舍入，$h^\ast \sim \varepsilon^{1/4}$ 量级，理论推导写进报告）。
4. **埋错诊断**：给出三个"带 bug 的梯度实现"（如：漏掉复合项、Hessian 没对称化、softmax 用了不稳定算法导致 NaN），要求用你的验证流水线定位并修复。
5. **收敛率实验**：对二次函数 $f(\mathbf{x}) = \frac12\mathbf{x}^\top A\mathbf{x}$（$A$ 特征值取 $\{1, 10\}$ 与 $\{1, 100\}$）分别运行梯度下降（最优固定步长）与牛顿法，绘制误差下降曲线，验证第 5 章 5.6 的两个论断：收敛率由条件数控制、牛顿法对二次函数一步收敛。

### 99.2.3 提示

- Hessian 差分对舍入极其敏感：$h^2$ 出现在分母，$h = 10^{-6}$ 时 $\frac{\varepsilon_{\text{mach}}}{h^2} \approx 10^{-4}$——这就是"二阶信息的数值验证更难"的定量原因（第 4 章误差分析的直接应用）。
- 验证判据用**相对误差** $\frac{\|\nabla f_{\text{num}} - \nabla f_{\text{ana}}\|}{\|\nabla f_{\text{ana}}\| + 10^{-12}}$，避免"梯度本身接近零时假阳性"。
- Rosenbrock 上建议同时比较：梯度下降、牛顿法（带 $H + \epsilon I$ 正则）、以及**用真 Hessian 特征值范围选步长**的下降法，体会曲率信息的价值。

## 99.3 项目三（选做二）：蒙特卡洛积分估计 $\pi$ 与误差阶分析

### 99.3.1 项目背景与目标

蒙特卡洛（Monte Carlo）用随机采样逼近积分：

$$
I = \iint_D g(x,y)\,\mathrm{d}A \approx \frac{A_{\text{box}}}{n}\sum_{i=1}^n g(x_i, y_i), \qquad (x_i, y_i) \sim U(\text{box}),
$$

其中 box 是包含 $D$ 的矩形。估计 $\pi$：取 $D$ = 单位圆盘、box = $[-1,1]^2$、$g = \mathbf{1}[x^2+y^2 \le 1]$，则 $I = \pi$。这是第 3 章"黎曼和的随机版"、第 6 章"区域积分=概率质量"、第 4 章"误差阶"三条线的汇合点。

### 99.3.2 任务分解

1. **基础实现**：向量化 Monte Carlo 估计 $\pi$，$n = 10^2$ 到 $10^7$（对数均匀取点），每档做 $K = 100$ 次独立重复，记录估计值分布。
2. **误差阶测定**：对每档 $n$ 计算 100 次估计的标准差 $\hat\sigma_n$，在双对数坐标下拟合斜率，验证 $\hat\sigma_n \propto n^{-1/2}$（理论：$\hat\sigma_n = \frac{\sqrt{\pi(4-\pi)}}{2\sqrt n} \approx \frac{1.642}{\sqrt{n}}$——请自行由二项方差推导此常数，用第 6 章区域积分算 $\mathrm{Var}[\mathbf{1}]$）。
3. **置信区间**：用中心极限定理（[概率论与数理统计](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/00/)的核心定理，此处作为黑箱）构造 95% 置信区间，检验"真值 $\pi$ 落在区间内"的频率是否接近 95%（对 100 次重复统计覆盖率）。
4. **确定性方法对照**：同一 $\pi$（或 $\int_0^1 \frac{4}{1+x^2}\mathrm{d}x = \pi$）用辛普森法计算，比较"达到 $10^{-4}$ 精度各自需要的计算量"（MC 约 $10^8$ 采样 vs Simpson 约 100 个节点）。
5. **维度实验（选做）**：估计 4 维单位球体积 $V_4 = \frac{\pi^2}{2}$（公式见第 6 章 6.4 选读）用 MC；体验"MC 误差与维度无关"而确定性网格方法节点数随维度指数爆炸——维度灾难的另一面：高维积分反而是 MC 的主场。

### 99.3.3 提示

- 方差推导：落点指示函数 $Z = \mathbf{1}[x^2+y^2\le1]$ 在 box 上是 Bernoulli($p$)，$p = \frac{\pi}{4}$（第 6 章面积比）；$\hat\pi = 4\bar Z$，故 $\mathrm{Var}(\hat\pi) = 16\,\frac{p(1-p)}{n}$。
- 双对数拟合用 `np.polyfit(np.log10(n_list), np.log10(std_list), 1)`，预期斜率 $\approx -0.5$。
- 提高 MC 效率的两个经典改进（选做）：**重要性采样**（换密度降低方差，第 6 章 6.5 变换公式的随机版）与**对偶变量**（用 $1-u$ 与 $u$ 成对采样）。测量每个改进的实际方差缩减比。

| C1 | $n = 10^6$ 时估计值落在 $\pi \pm 0.005$ 内（99% 的随机种子下） | 多种子运行统计 |

```python
import numpy as np

rng = np.random.default_rng(0)

def mc_pi(n, seed=0):
    r = np.random.default_rng(seed)
    xy = r.uniform(-1, 1, size=(n, 2))            # 在 [-1,1]^2 均匀撒点
    inside = (xy**2).sum(axis=1) <= 1.0           # 指示函数 g
    return 4.0 * inside.mean()                    # A_box * 平均值 = 4 * p_hat

# 误差阶实验
K = 100
for n in [10**k for k in range(2, 8)]:
    ests = np.array([mc_pi(n, seed=s) for s in range(K)])
    std = ests.std(ddof=1)
    print(f"n=1e{int(np.log10(n))}  mean_err={abs(ests.mean()-np.pi):.2e}  "
          f"std={std:.2e}  std*sqrt(n)={std*np.sqrt(n):.3f}")
# 预期输出：std*sqrt(n) 各档都收敛到约 1.64（理论常数 sqrt(pi*(4-pi))/2*4/pi...
# 即 std(pi_hat) = 4*sqrt(p(1-p)/n), p=pi/4，常数 = 4*sqrt(pi/4*(1-pi/4)) ≈ 1.642）
# 例如：
# n=1e2  std≈1.6e-01  std*sqrt(n)≈1.6
# n=1e4  std≈1.6e-02  std*sqrt(n)≈1.6
# n=1e6  std≈1.6e-03  std*sqrt(n)≈1.6
```

## 99.4 示例与案例：项目一核心机制的端到端走查

在动手扩展之前，先用 20 行代码完整走通"前向 → 反向 → 数值验证"三步对照。设目标函数 $L(a, b) = \tanh(ab) + a$，手推梯度：$\frac{\partial L}{\partial a} = b\,(1-\tanh^2(ab)) + 1$，$\frac{\partial L}{\partial b} = a\,(1-\tanh^2(ab))$。

```python
from math import tanh

class V:
    """极简版 Value 节点（仅支持 *、+、tanh），演示核心机制。"""
    def __init__(self, data, parents=()):
        self.data, self.parents, self.grad = data, parents, 0.0
        self._backward = lambda: None
    def __mul__(p, q):
        out = V(p.data * q.data, (p, q))
        def _bw():  # 乘积法则：p'q + pq'
            p.grad  += q.data * out.grad
            q.grad  += p.data * out.grad
        out._backward = _bw
        return out
    def __add__(p, q):
        out = V(p.data + q.data, (p, q))
        def _bw():  # 加法法则：梯度直通并累加
            p.grad += out.grad; q.grad += out.grad
        out._backward = _bw
        return out
    def tanh(p):
        out = V(tanh(p.data), (p,))
        def _bw():  # tanh' = 1 - tanh^2（第 2 章导数表）
            p.grad += (1 - out.data**2) * out.grad
        out._backward = _bw
        return out
    def backward(p):
        topo, seen = [], set()
        def build(v):
            if v not in seen:
                seen.add(v)
                for q in v.parents: build(q)
                topo.append(v)
        build(p)
        p.grad = 1.0
        for v in reversed(topo): v._backward()   # 逆序 = 反向传播

a, b = V(0.7), V(-1.3)
t = a * b; h = t.tanh(); L = h + a        # L = tanh(a*b) + a
L.backward()
print(f"autograd : dL/da={a.grad:+.8f}  dL/db={b.grad:+.8f}")

eps = 1e-6                                 # 中心差分独立验证（第 4 章 4.3）
f  = lambda x, y: tanh(x * y) + x
da = (f(0.7 + eps, -1.3) - f(0.7 - eps, -1.3)) / (2 * eps)
db = (f(0.7, -1.3 + eps) - f(0.7, -1.3 - eps)) / (2 * eps)
print(f"数值差分 : dL/da={da:+.8f}  dL/db={db:+.8f}")
# 预期输出（两组数值在 1e-8 量级内一致；tanh(-0.91)≈-0.72050，1-tanh^2≈0.48088）：
# autograd : dL/da=+0.37486190  dL/db=+0.33661259
# 数值差分 : dL/da=+0.37486190  dL/db=+0.33661259
```

走查要点（对应"验收标准 A1/A3"）：① 反向只在拓扑序的逆序上各调用一次 `_backward`，总代价与前向同阶；② `a` 既直接进入 $L$ 又经 $ab$ 进入 $L$，两条路径的贡献在 `a.grad` 中**累加**（$1$ 来自加法直通、$-0.6251$ 来自链式法则，和为 $0.3749$）——把 `+=` 改成 `=` 试试，你会立刻看到 $1.0$ 或 $-0.6251$ 的错误答案；③ 数值差分与 autograd 的一致性就是"梯度公式正确"的工程证据，但它永远不能替代第 5 章定理 5.5.2 的数学保证。

## 99.5 项目常见误区与陷阱

1. **梯度累加写成赋值**。`self.grad = ...` 在变量被多处复用（如 $L = a\cdot a + a$）时会丢失路径贡献——正确实现必须 `+=`（第 5 章链式法则"所有路径求和"的代码化）。这是 naive autograd 第一大 bug 来源。
2. **验证用的步长一刀切**。梯形/中心差分对梯度验证 $h\sim10^{-5}$ 合适，对二阶差分（Hessian）应放大到 $10^{-3}$–$10^{-4}$ 量级；$h$ 太小时验证反而"失败"，误以为自己推导错了（实为舍入误差接管，第 4 章例 4.3.2）。
3. **用"单次运行结果接近真值"下结论**。项目三的核心训练是：单次 MC 估计无意义，必须报告标准差与置信区间；同理项目一的训练曲线至少换 3 个随机种子确认稳定。
4. **比较算法时不控制计算预算**。说"牛顿法比梯度下降快"必须同时报告每步的代价（Hessian 构造 $O(n^3)$）；公平比较要么固定迭代数、要么固定浮点运算量，并在报告中写明口径。
5. **数值溢出未设防**。项目二的 log-sum-exp、项目三的大 $n$ 求和都可能出现 `inf/NaN`；先用小规模数据跑通全流程，再放大规模（并且留意 `np.mean` 大数求和的浮点累积，必要时用 `dtype=np.float64` 或分块求和）。
6. **只测"好情况"**。埋错诊断环节的意义在于培养"怀疑自己的实现"的习惯：提交前主动用极端输入（零向量、巨大值、退化区域）轰击你的代码。

## 99.10 进阶方向

- **工业级自动微分**：PyTorch/JAX 的源码级理解——计算图、vmap、可微 GPU 内核；进阶读物是 JAX 的 autodiff 文档与 Griewank & Walther《Evaluating Derivatives》（SIAM, 2008）。
- **无梯度优化**：贝叶斯优化、CMA-ES、演化策略——当目标函数不可微（超参数搜索、强化学习奖励）时的替代方案，从"导数的重要性"反面加深理解。
- **高精度数值实验设计**：多重随机种子、Bootstrap 误差条、消融式基准——把项目三的重复实验思想制度化为[实验设计与评估](/xiaoshus-blog/textbooks/ai/engineering/experiment-design/00/)的方法论。
- **可微编程系统**：把物理仿真、渲染（可微渲染）、博弈求解器嵌入梯度流——可微编程是当前 AI 系统研究的前沿方向，其正确性保障正是本章的验证流水线。
