# 第 5 章 多元微分：梯度与 Hessian 矩阵

> **本章定位**：本章是全课程最重要的一章，把前四章的一元分析升维到 $\mathbb{R}^n$：偏导数、方向导数、梯度、Hessian、多元链式法则、多元泰勒展开、隐函数定理与拉格朗日乘数法。它是[最优化方法](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/00/)（梯度法、牛顿法、约束优化）与[深度学习](/xiaoshus-blog/textbooks/ai/ai-core/deep-learning/00/)（反向传播）的共同数学母体。前置：第 2 章导数与链式法则、第 4 章泰勒展开、[线性代数](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/00/)的向量与矩阵运算（建议并行）。

- 能够陈述偏导数与方向导数的定义，解释"可微 = 存在良好线性逼近"，并区分可微与"偏导存在"。
- 能够计算梯度，陈述梯度的三个几何性质（指向最速上升、垂直等值线、模长为最大变化率）。

- 能够写出多元泰勒展开（一阶与二阶），并用它推导梯度下降的一步下降公式与牛顿步。

## 5.1 从山丘到损失面：为什么需要多元

深度神经网络有数百万至数千亿个参数（GPT 级模型超过 $10^{11}$ 个）。训练即最小化损失函数 $L(\theta)$，其中 $\theta \in \mathbb{R}^n$ 是全部参数组成的巨大向量。一元微积分的"斜率"概念在这里必须升维：**在每个方向上都有变化率，而"朝哪里走最有效"成为首要问题**。

本章的思维转换只有一句话：**一元情形的"数"（导数值）在多元情形大多变成"向量或矩阵"，而所有公式保持形状不变。** 对照表（贯穿本章反复使用）：

| 一元 | 多元 | 备注 |
|---|---|---|
| $f'(x_0)$ | $\nabla f(x_0)$（梯度向量） | 5.3 节 |
| $f''(x_0)$ | $\nabla^2 f(x_0) = H$（Hessian 矩阵） | 5.4 节 |
| 链式法则 $f'(g)g'$ | 雅可比矩阵相乘 $J_f\, J_g$ | 5.5 节 |
| $f(x_0+h) \approx f(x_0) + f'h$ | $f(\mathbf{x}_0+\mathbf{h}) \approx f(\mathbf{x}_0) + \nabla f^\top \mathbf{h}$ | 一阶泰勒 |
| $f''>0$ 判极小 | $H$ 正定判极小 | 二阶条件 |
| 步长受 $\|f''\|$ 限制 | 步长受 $H$ 特征值限制 | 收敛率 |

建议此时打开[线性代数](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/00/)复习：向量内积、二次型、特征值与正定性（该课程第 2、5 章）。本章会用它们，但不重复推导。

## 5.2 偏导数、方向导数与可微性

**定义 5.2.1（偏导数，partial derivative）**。设 $f: D \subseteq \mathbb{R}^n \to \mathbb{R}$，$f$ 在 $\mathbf{x}_0 = (x_1^0,\dots,x_n^0)$ 的邻域内有定义。固定其余变量，令

$$
\frac{\partial f}{\partial x_i}(\mathbf{x}_0) = \lim_{h \to 0} \frac{f(x_1^0, \dots, x_i^0 + h, \dots, x_n^0) - f(x_1^0,\dots,x_n^0)}{h},
$$

若极限存在。它就是"只动一个坐标"的方向上的一元导数——计算上与一元求导无异（把其他变量当常数）。

**例 5.2.2**。$f(x,y) = x^2 y + \mathrm{e}^{xy}$：$\frac{\partial f}{\partial x} = 2xy + y\mathrm{e}^{xy}$，$\frac{\partial f}{\partial y} = x^2 + x\mathrm{e}^{xy}$（乘积法则 + 链式法则的直接移植）。

**定义 5.2.3（方向导数，directional derivative）**。设 $\mathbf{u}$ 为单位向量，则

$$
D_{\mathbf{u}} f(\mathbf{x}_0) = \lim_{h \to 0} \frac{f(\mathbf{x}_0 + h\mathbf{u}) - f(\mathbf{x}_0)}{h}
$$

是 $f$ 沿方向 $\mathbf{u}$ 的变化率。坐标方向的方向导数即偏导数；$D_{\mathbf{u}}f = \cos\theta \cdot$（斜率）型直观沿任何射线成立。

**关键辨析：偏导存在 $\neq$ 可微。**

**定义 5.2.4（可微性，differentiability）**。若存在向量 $\mathbf{a}$ 使

$$
f(\mathbf{x}_0 + \mathbf{h}) = f(\mathbf{x}_0) + \mathbf{a}^\top \mathbf{h} + o(\|\mathbf{h}\|) ,
$$

则称 $f$ 在 $\mathbf{x}_0$ 可微，$\mathbf{a}^\top\mathbf{h}$ 称为全微分。可微时 $\mathbf{a}$ 必为偏导数组，即 $\mathbf{a} = \nabla f(\mathbf{x}_0)$（见 5.3）。可微 = **存在一个对所有方向一致生效的线性逼近**，误差是 $o(\|\mathbf{h}\|)$——比"每个偏导单独存在"强得多。

**反例**（高频考点，也是理解"梯度为何要要求可微"的钥匙）：

$$
f(x,y) = \begin{cases} \dfrac{xy}{x^2+y^2}, & (x,y) \neq (0,0)\\ 0, & (x,y)=(0,0)\end{cases}
$$

在原点两个偏导都存在（沿坐标轴 $f \equiv 0$，均为 0），但沿 $\mathbf{u} = (\frac{1}{\sqrt2}, \frac{1}{\sqrt2})$ 方向 $f(h\mathbf{u}) = \frac12$，方向导数为 $\frac{1}{2h} \cdot h$ 极限……具体地 $f(h\mathbf{u}) = \frac{h^2/2}{h^2} = \frac12$，故 $D_\mathbf{u}f(0) = \lim_{h\to0}\frac{1/2 - 0}{h}$ 不存在（发散）。**函数在坐标方向平坦、在对角方向悬崖**——若这个函数是损失面，只看偏导的算法会被欺骗。所以理论工作坚持"可微"或更强的"$C^1$"（偏导连续）假设。

**定理 5.2.5（充分条件）**。偏导数在某邻域内存在且连续（$C^1$）$\Rightarrow$ 可微。可微 $\Rightarrow$ 连续（用 $\varepsilon$-$\delta$：$\|\mathbf{h}\|<\delta$ 时 $|f(\mathbf{x}_0+\mathbf{h})-f(\mathbf{x}_0)| \le |\mathbf{a}^\top\mathbf{h}| + o(\|\mathbf{h}\|) \to 0$，正是第 1 章取小原则的向量版）。

## 5.3 梯度：最速上升方向与等值线

**定义 5.3.1（梯度，gradient）**。$f$ 可微时，$\nabla f(\mathbf{x}) = \left(\frac{\partial f}{\partial x_1}, \dots, \frac{\partial f}{\partial x_n}\right)^\top$。

**定理 5.3.2（方向导数的内积表示）**。$f$ 可微时，对任意单位向量 $\mathbf{u}$：

$$
D_{\mathbf{u}} f(\mathbf{x}) = \nabla f(\mathbf{x})^\top \mathbf{u} = \|\nabla f(\mathbf{x})\| \cos\langle \nabla f, \mathbf{u}\rangle .
$$

由 Cauchy-Schwarz 不等式（[线性代数](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/00/)），立即得到**梯度的三重几何意义**：

1. **最速上升方向**：$\mathbf{u}$ 与 $\nabla f$ 同向时方向导数最大（$= \|\nabla f\|$）；反向时最小（$= -\|\nabla f\|$，最速下降）。梯度下降 $x_{k+1} = x_k - \eta\nabla f(x_k)$ 的"负梯度方向"由此获得合法性。
2. **垂直等值线**：沿等值线 $f = c$ 移动时 $f$ 不变（方向导数为 0），故梯度与等值线的切向量正交。
3. **模长即最陡坡度**：$\|\nabla f\|$ 是最大瞬时变化率。

**例 5.3.3（最小可运行梯度下降）**。$f(x,y) = \frac12(x^2 + 2y^2)$，$\nabla f = (x, 2y)^\top$。从 $(2, 1)$ 出发，$\eta = 0.1$：

```python
import numpy as np

x = np.array([2.0, 1.0])
eta = 0.1
for k in range(12):
    grad = np.array([x[0], 2 * x[1]])         # ∇f = (x, 2y)
    x = x - eta * grad
    print(f"k={k:2d}  x=({x[0]:+.4f}, {x[1]:+.4f})  f={0.5*(x[0]**2 + 2*x[1]**2):.4f}")
# 预期输出：两坐标以不同速度衰减（x 分量按 0.9^k，y 分量按 0.8^k）
# f 值单调下降并趋于 0 —— 病态曲率（2 vs 1）造成"zigzag"趋势的雏形
```

注意 $y$ 分量衰减更快（曲率 2 > 1）：**不同方向曲率不同导致迭代路径曲折**，这一现象的定量版本（条件数决定收敛率）是[最优化方法](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/00/)的核心结论之一，其根源就是 Hessian 的各向异性（5.4 节）。

## 5.4 Hessian 矩阵与二阶分析

**定义 5.4.1（Hessian 矩阵）**。$f$ 二阶可导时，

$$
\nabla^2 f(\mathbf{x}) = H(\mathbf{x}) = \begin{pmatrix} \frac{\partial^2 f}{\partial x_1^2} & \cdots & \frac{\partial^2 f}{\partial x_1 \partial x_n}\\ \vdots & & \vdots \\ \frac{\partial^2 f}{\partial x_n \partial x_1} & \cdots & \frac{\partial^2 f}{\partial x_n^2}\end{pmatrix}.
$$

**定理 5.4.2（Schwarz / Young 定理）**。混合偏导连续时 $\frac{\partial^2 f}{\partial x_i \partial x_j} = \frac{\partial^2 f}{\partial x_j \partial x_i}$，故 Hessian 是对称矩阵。这个"求导顺序可交换"的性质是深度学习中参数共享与二阶方法低秩近似的理论基础。

**例 5.4.3**。$f(x,y) = \frac12(x^2 + 2y^2)$：$H = \mathrm{diag}(1, 2)$——常矩阵；特征值就是各方向的曲率。一般地，$H$ 的特征向量给出"曲率主轴"，特征值给出对应曲率（由谱定理，[线性代数](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/00/)）。

**定理 5.4.4（极值的二阶条件）**。设 $f$ 二阶连续可微，$\mathbf{x}_0$ 为驻点（$\nabla f = \mathbf{0}$）：

- $H(\mathbf{x}_0)$ **正定**（所有特征值 $> 0$）$\Rightarrow$ 极小值点；
- $H(\mathbf{x}_0)$ **负定** $\Rightarrow$ 极大值点；
- 特征值有正有负 $\Rightarrow$ **鞍点**（saddle point）：沿正特征向量方向是极小、沿负特征向量方向是极大。

证明核心是二阶泰勒展开（5.6 节）：$f(\mathbf{x}_0 + \mathbf{h}) \approx f(\mathbf{x}_0) + \frac12 \mathbf{h}^\top H \mathbf{h}$，二次型的符号由特征值决定。

**鞍点与深度学习**。$f(x,y) = x^2 - y^2$ 在原点是典型鞍点：$\nabla f = (2x, -2y)$ 在原点为零，但它既非极大也非极小。高维损失面中**鞍点远多于局部极小**（一个驻点是极小要求 $H$ 全部 $n$ 个特征值为正，随机情况下是低概率事件，而"有正有负"是大概率事件）——这是理解"深度学习为什么不太怕局部极小、更怕鞍点"的第一块数学拼图，完整论证见[深度学习](/xiaoshus-blog/textbooks/ai/ai-core/deep-learning/00/)优化章节。

**定理 5.4.5（凸性判别）**。$f$ 二阶可导时：$f$ 凸 $\iff H(\mathbf{x})$ 半正定对所有 $\mathbf{x}$ 成立（一元情形 $f''\ge0$ 的矩阵化；证明用二阶泰勒 + 二次型性质）。$f(x,y) = x^2 + 2y^2$ 凸（$H$ 恒正定），$x^2 - y^2$ 非凸（$H$ 不定）。凸 + 梯度为零 = 全局最优，这一"最优性的免费午餐"在最优化课程将正式成为公理化的出发点。

## 5.5 多元链式法则：反向传播的数学本体

**问题设定**。设 $\mathbf{g}: \mathbb{R}^m \to \mathbb{R}^n$（中间层），$f: \mathbb{R}^n \to \mathbb{R}$（损失），复合 $L(\mathbf{t}) = f(\mathbf{g}(\mathbf{t}))$。要知道 $L$ 对输入 $\mathbf{t}$ 的敏感度，怎么办？

**定义 5.5.1（雅可比矩阵，Jacobian）**。向量值函数 $\mathbf{g}: \mathbb{R}^m \to \mathbb{R}^n$ 的雅可比是 $n \times m$ 矩阵：$(J_{\mathbf{g}})_{ij} = \frac{\partial g_i}{\partial t_j}$。它是"一元导数 = 线性逼近系数"的矩阵版：$\mathbf{g}(\mathbf{t}_0 + \mathbf{h}) \approx \mathbf{g}(\mathbf{t}_0) + J_{\mathbf{g}}(\mathbf{t}_0)\,\mathbf{h}$。

**定理 5.5.2（多元链式法则）**。各层可微时：

$$
\nabla L(\mathbf{t}) = J_{\mathbf{g}}(\mathbf{t})^\top \nabla f(\mathbf{g}(\mathbf{t})) \qquad (\text{矩阵形式}),
$$

或标量形式：$\frac{\partial L}{\partial t_j} = \sum_{i=1}^n \frac{\partial f}{\partial g_i}\frac{\partial g_i}{\partial t_j}$。

标量形式是"每条路径的贡献求和"，矩阵形式是"雅可比转置乘梯度"。**为什么是转置？** 因为 $\mathbf{g}(\mathbf{t}+\mathbf{h}) - \mathbf{g}(\mathbf{t}) \approx J_{\mathbf{g}}\mathbf{h}$，一阶泰勒代入：$L(\mathbf{t}+\mathbf{h}) \approx f(\mathbf{g} + J_{\mathbf{g}}\mathbf{h}) \approx f(\mathbf{g}) + \nabla f^\top J_{\mathbf{g}}\mathbf{h}$，对比 $\nabla L^\top \mathbf{h}$ 的系数即得。

**例 5.5.3（手算一个两层"网络"）**。设 $\mathbf{t} = (t_1, t_2)$，$g_1 = t_1 t_2$，$g_2 = t_1 + t_2$，$L = g_1^2 + g_2$。前向：$\mathbf{g}(\mathbf{t})$；雅可比 $J_{\mathbf{g}} = \begin{pmatrix} t_2 & t_1\\ 1 & 1\end{pmatrix}$；$\nabla_g L = (2g_1, 1)^\top$。链式法则：

$$
\nabla_t L = J_{\mathbf{g}}^\top \nabla_g L = \begin{pmatrix} t_2 & 1\\ t_1 & 1 \end{pmatrix}\begin{pmatrix} 2t_1t_2\\ 1\end{pmatrix} = \begin{pmatrix} 2t_1t_2^2 + 1\\ 2t_1^2t_2 + 1 \end{pmatrix}.
$$

注意计算顺序：先算最外层梯度 $\nabla_g L$，再乘 $J^\top$ 逐层向内——**"先算损失对输出的梯度，再逐层向输入传播"正是反向传播（backpropagation）的字面含义**。深度网络的层数只是把"两层"换成 L 层，每层的雅可比（线性层是权重矩阵转置，激活函数是逐元素对角阵）连乘；中间结果 $\nabla_g L$ 必须缓存下来供向后使用，这就是训练比推理更耗显存的数学原因。

**代价对比（反向传播存在的理由）**。$L$ 层网络、每层 $O(n^2)$ 参数：朴素"对每个参数单独求差分"需 $O(n^2)$ 次前向传播；反向传播一次前向 + 一次反向即得**全部** $n^2$ 个偏导，代价 $\approx$ 几次前向。[深度学习](/xiaoshus-blog/textbooks/ai/ai-core/deep-learning/00/)课程将给出完整的计算图视角；[99 章综合项目](/xiaoshus-blog/textbooks/ai/math-foundations/calculus/99/)项目一要求你从零实现这个记账系统。

## 5.6 多元泰勒展开：二阶世界

**定理 5.6.1（多元泰勒展开，二阶截断）**。设 $f$ 二阶连续可微，则对 $\mathbf{x}, \mathbf{x}_0 \in \mathbb{R}^n$：

$$
f(\mathbf{x}) = f(\mathbf{x}_0) + \nabla f(\mathbf{x}_0)^\top (\mathbf{x}-\mathbf{x}_0) + \frac12 (\mathbf{x}-\mathbf{x}_0)^\top H(\boldsymbol{\xi}) (\mathbf{x}-\mathbf{x}_0),
$$

其中 $\boldsymbol{\xi}$ 在 $\mathbf{x}$ 与 $\mathbf{x}_0$ 之间（Lagrange 型余项）；或带 Peano 余项：

$$
f(\mathbf{x}_0+\mathbf{h}) = f(\mathbf{x}_0) + \nabla f(\mathbf{x}_0)^\top\mathbf{h} + \frac12 \mathbf{h}^\top H(\mathbf{x}_0)\mathbf{h} + o(\|\mathbf{h}\|^2).
$$

证明：沿射线 $\boldsymbol{\varphi}(t) = \mathbf{x}_0 + t\mathbf{h}$ 定义一元函数 $g(t) = f(\boldsymbol{\varphi}(t))$，$g'(t) = \nabla f^\top \mathbf{h}$，$g''(t) = \mathbf{h}^\top H\mathbf{h}$（链式法则 + Schwarz 定理），对 $g$ 用一元泰勒公式即得——**多元泰勒是一元泰勒沿射线的切片**，这个技巧本身也值得记住。

**两个直接推论**（对应第 4 章的多元升级）：

1. **梯度下降的一步下降**：代入 $\mathbf{h} = -\eta\nabla f$，用 Peano 版：

$$
f(\mathbf{x} - \eta\nabla f) = f - \eta\|\nabla f\|^2 + \frac{\eta^2}{2}\nabla f^\top H \nabla f + o(\eta^2) \le f - \eta\left(1 - \frac{L\eta}{2}\right)\|\nabla f\|^2,
$$

其中最后一步用 $\nabla f^\top H\nabla f \le L\|\nabla f\|^2$（$H \preceq L I$，即最大特征值 $\le L$）。**多元 $L$-光滑性 $\Rightarrow$ 步长 $\eta < 2/L$ 时每步下降**——与一元公式完全同构，只是 $f''$ 换成 $H$ 的最大特征值。

2. **牛顿步**：用二阶展开的最小化代替原问题（局部二次模型）：$\min_{\mathbf{h}}\ \nabla f^\top\mathbf{h} + \frac12 \mathbf{h}^\top H\mathbf{h}$，对 $\mathbf{h}$ 求驻点得 $\mathbf{h}^\ast = -H^{-1}\nabla f$，即牛顿迭代

$$
\mathbf{x}_{k+1} = \mathbf{x}_k - H(\mathbf{x}_k)^{-1}\nabla f(\mathbf{x}_k).
$$

若 $H$ 正定，二次模型是完美碗形，牛顿步直达碗底——对二次函数**一步收敛**。代价：构造并求逆 $H$（$O(n^3)$），$n = 10^{11}$ 时彻底不可行，于是有拟牛顿、L-BFGS、K-FAC 等廉价替身（[最优化方法](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/00/)）。

**条件数与病态曲率**。设 $H$ 的特征值范围为 $[\mu, L]$（$\mu > 0$）。梯度下降在二次函数上的收敛率由 $\kappa = L/\mu$（条件数）决定：最优步长下误差按 $\left(\frac{\kappa-1}{\kappa+1}\right)^k$ 收敛——$\kappa$ 越大越慢，且迭代路径在最陡方向与最平方向间"之字形"震荡（5.3 节实验的定量版）。特征值与二次型的细节在[线性代数](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/00/)谱定理处闭环。

## 5.7 隐函数定理与拉格朗日乘数法（初步）

**隐函数定理（简介）**。方程 $F(x, y) = 0$ 通常不能显式解出 $y$，但局部能否把 $y$ 视为 $x$ 的函数？答案由线性化给出：若 $F(x_0, y_0) = 0$ 且 $\frac{\partial F}{\partial y}(x_0,y_0) \neq 0$，则在 $(x_0,y_0)$ 附近存在唯一的可微函数 $y = g(x)$ 使 $F(x, g(x)) \equiv 0$，且

$$
g'(x) = -\frac{F_x}{F_y} .
$$

证明思想：对恒等式用链式法则（$F_x + F_y g' = 0$）得到导数公式；存在唯一性部分需要压缩映射（第 1 章进阶方向预告过 Banach 不动点）。深度学习中的同款操作：分类器 $p_\theta(y|x)$ 经常以隐式定义出现（如通过最优化的解 $x^\ast(\theta)$），对 $\theta$ 求导正是隐函数定理的链式应用（如超参数优化与隐式微分）。

**约束优化与拉格朗日乘数法**。实际优化常带约束：$\min f(x, y)$ s.t. $g(x, y) = 0$。无约束条件（$\nabla f = 0$）失效，因为在可行曲线上我们只能沿切向移动，极值点处只需**切向导数为零**。

**定理 5.7.1（拉格朗日乘数法，Lagrange multipliers）**。设 $f, g$ 连续可微，$\nabla g \neq 0$ 于约束曲线上。若 $(x_0, y_0)$ 是约束问题的局部极值点，则存在实数 $\lambda$ 使

$$
\nabla f(x_0, y_0) = \lambda\, \nabla g(x_0, y_0), \qquad g(x_0, y_0) = 0 .
$$

**几何解读**：极值点处 $f$ 的等值线与约束曲线**相切**（若横穿则沿曲线还能上升/下降，与极值矛盾；两条曲线相切 = 法向量平行 = 梯度平行）。$\lambda$ 称为拉格朗日乘子，其经济/物理意义是"约束每放松一单位，最优值变化多少"（灵敏度/影子价格）。

**例 5.7.2（手算）**。求 $f(x,y) = xy$ 在约束 $x + y = 1$（$x, y > 0$）下的最大值。$\nabla f = (y, x)$，$\nabla g = (1, 1)$，条件：$y = \lambda,\ x = \lambda$，故 $x = y = \frac12$，$f = \frac14$。（校验：均值不等式 $xy \le \left(\frac{x+y}{2}\right)^2 = \frac14$，一致。）

n 维与多约束版本：$\nabla f = \sum_k \lambda_k \nabla g_k$，构造拉格朗日函数 $\mathcal{L}(\mathbf{x}, \boldsymbol{\lambda}) = f(\mathbf{x}) - \boldsymbol{\lambda}^\top\mathbf{g}(\mathbf{x})$ 后令 $\nabla_{\mathbf{x}}\mathcal{L} = 0, \mathbf{g} = 0$ 联立求解。**SVM 的对偶问题、KKT 条件、正则化的约束解释**全部从这里出发；含不等式约束时需要 KKT 条件（乘子 $\lambda \ge 0$ 与互补松弛），这是[最优化方法](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/00/)对偶理论的核心章节，本章只建立"等式约束 + 相切几何"的直觉底座。

**实验二：中心差分验证梯度公式**（梯度公式的"单元测试"思维，也是 99 章项目二的内核）。

```python
import numpy as np

rng = np.random.default_rng(0)
x = rng.normal(size=4)

def f(x):
    return np.exp(x @ x / 2)                       # f = exp(||x||^2 / 2)

def grad_analytic(x):
    return f(x) * x                                # 链式法则手工结果

def grad_numeric(x, h=1e-5):
    """中心差分逐坐标逼近偏导数。"""
    g = np.zeros_like(x)
    for i in range(len(x)):
        e = np.zeros_like(x); e[i] = 1.0
        g[i] = (f(x + h * e) - f(x - h * e)) / (2 * h)
    return g

g1, g2 = grad_analytic(x), grad_numeric(x)
print("解析梯度 :", g1)
print("数值梯度 :", g2)
print("最大相对误差:", np.max(np.abs(g1 - g2) / (np.abs(g1) + 1e-12)))
# 预期输出：两者逐分量一致，最大相对误差 < 1e-8（中心差分 O(h^2) 误差，见第 4 章 4.3.2）
```

工程对应：PyTorch 的 `torch.autograd.gradcheck` 正是用这个思路对自动微分做正确性验证；以后你实现任何自定义算子，都应附上这个"梯度测试"。

## 5.9 关键公式速查

| 公式 / 定理 | 适用条件与备注 |
|---|---|
| 偏导数定义（单坐标差商极限） | 只保证坐标方向信息；$C^1$ 才可靠 |
| 可微性 $f(\mathbf{x}_0+\mathbf{h}) = f(\mathbf{x}_0) + \nabla f^\top\mathbf{h} + o(\|\mathbf{h}\|)$ | 强于偏导存在；线性逼近对全方向一致 |
| $D_\mathbf{u}f = \nabla f^\top\mathbf{u}$，最大 $=\|\nabla f\|$ | $f$ 可微、$\|\mathbf{u}\|=1$；Cauchy-Schwarz |
| 梯度 $\perp$ 等值线 | 等值线上方向导数为零 |
| $H$ 对称（Schwarz 定理） | 二阶偏导连续 |
| 二阶条件：驻点处 $H$ 正定 $\Rightarrow$ 极小；不定 $\Rightarrow$ 鞍点 | 驻点 + 二阶连续可微 |
| 凸 $\iff H$ 处处半正定 | 二阶可导；凸 + $\nabla f=0$ = 全局最优 |
| 链式法则 $\nabla_t L = J_{\mathbf{g}}^\top \nabla_g L$ | 各层可微；反向传播的数学形式 |
| 多元泰勒 $f(\mathbf{x}_0+\mathbf{h}) = f + \nabla f^\top\mathbf{h} + \frac12\mathbf{h}^\top H\mathbf{h} + o(\|\mathbf{h}\|^2)$ | 二阶连续可微 |
| 一步下降 $f(\mathbf{x}-\eta\nabla f) \le f - \eta(1-\frac{L\eta}{2})\|\nabla f\|^2$ | $\lambda_{\max}(H) \le L$，$0<\eta<2/L$ |
| 牛顿步 $\mathbf{x}_{k+1} = \mathbf{x}_k - H^{-1}\nabla f$ | $H$ 正定；二次函数一步收敛 |
| 隐函数求导 $g'(x) = -F_x/F_y$ | $F_y \neq 0$ 于局部解邻域 |
| 拉格朗日乘数 $\nabla f = \lambda\nabla g$ + 约束 | 等式约束；梯度平行（相切几何） |

## 5.10 示例与案例

**案例 1（手算）：完整分析 $f(x,y) = x^3 - 3x + y^2$。**

- 梯度：$\nabla f = (3x^2 - 3,\ 2y)$；驻点：$(\pm 1, 0)$。
- Hessian：$H = \begin{pmatrix} 6x & 0\\ 0 & 2\end{pmatrix}$。
- 在 $(-1, 0)$：$H = \mathrm{diag}(-6, 2)$ 不定 → **鞍点**。在 $(1, 0)$：$H = \mathrm{diag}(6, 2)$ 正定 → **极小值点**，$f(1,0) = -2$。
- 凸性：$x < -\frac12$ 时 $H_{11} < 0$，函数非凸（但 $(1,0)$ 附近局部凸）。
- 沿 $x$ 轴的一元切片 $f(x, 0) = x^3 - 3x$ 正是第 2 章 2.5 节的例题——多元分析 = 一元切片的系统化，请体会升维后"鞍点"这个新物种如何出现。

**案例 2（代码）：反向传播的最小重演——从零手写三层标量链。**

```python
import numpy as np

# 复合函数：L = sigma(w2 * sigma(w1 * x))，sigma 为 tanh，标量情形
# 目标：求 dL/dw1, dL/dw2（数值对照手推链式法则）

def forward(w1, w2, x):
    a1 = w1 * x                      # 第一层线性
    h = np.tanh(a1)                  # 第一层激活
    a2 = w2 * h                      # 第二层线性
    L = 0.5 * a2 ** 2                # 损失（此处即平方输出）
    cache = (a1, h, a2)
    return L, cache

def backward(w1, w2, x, cache):
    """逆序应用链式法则：从 dL/dL=1 出发逐层向输入回传。"""
    a1, h, a2 = cache
    dL_da2 = a2                                  # d(0.5 a2^2)/da2
    dL_dw2 = dL_da2 * h                          # a2 = w2 * h
    dL_dh  = dL_da2 * w2                         # 链式：经 a2 = w2*h
    dL_da1 = dL_dh * (1 - h**2)                  # tanh' = 1 - tanh^2
    dL_dw1 = dL_da1 * x                          # a1 = w1 * x
    return dL_dw1, dL_dw2

w1, w2, x = 0.7, -1.3, 2.0
L, cache = forward(w1, w2, x)
g1, g2 = backward(w1, w2, x, cache)

h_eps = 1e-6                                  # 数值对照（中心差分）
La, _ = forward(w1 + h_eps, w2, x); Lb, _ = forward(w1 - h_eps, w2, x)
g1_num = (La - Lb) / (2 * h_eps)
La, _ = forward(w1, w2 + h_eps, x); Lb, _ = forward(w1, w2 - h_eps, x)
g2_num = (La - Lb) / (2 * h_eps)

print(f"解析: dL/dw1={g1:+.8f}  dL/dw2={g2:+.8f}")
print(f"数值: dL/dw1={g1_num:+.8f}  dL/dw2={g2_num:+.8f}")
# 预期输出：解析与数值在 1e-9 量级内一致（w1=0.7, w2=-1.3, x=2.0 时）
# 手算核对：h = tanh(1.4) ≈ 0.885352，dL/dw1 ≈ +0.6469，dL/dw2 ≈ -1.0190
```

这份 30 行代码是所有自动微分框架的核心逻辑（[99 章综合项目](/xiaoshus-blog/textbooks/ai/math-foundations/calculus/99/)项目一将把它扩展成支持任意计算图的 autograd）。

## 5.11 常见误区与陷阱

1. **把"偏导数存在"当"可微"**。5.2 节反例（坐标方向平坦、对角方向悬崖）说明只查偏导会漏掉真正的病态；理论结论（梯度垂直等值线、方向导数公式）都需要可微性。
2. **链式法则丢路径**。标量形式要"对中间变量的所有路径求和"；漏掉间接路径（如 $t_1$ 经 $g_1$ 又经 $g_2$ 影响 $L$）是最常见的手推错误。用矩阵形式 $J^\top\nabla$ 可以让求和自动完成。
3. **Hessian 不对称就继续往下算**。数值上有限精度可能破坏对称性；正确做法是先 $H \leftarrow (H + H^\top)/2$ 再特征分解。理论根源：Schwarz 定理保证对称，浮点误差是唯一的破坏者。
4. **对"梯度下降会找到全局最优"过度乐观**。本章只证明了"每步下降"与"收敛到驻点"；非凸时驻点可能是鞍点或局部极大。凸性（5.4 定理 5.4.5）才是全局最优性的担保。
5. **拉格朗日乘数法解出所有驻点就交卷**。乘数法给的是必要条件，还须代入约束比较各候选点的函数值（或检查二阶条件）定出最大/最小；漏掉边界（约束集合的"角落"）同样丢解。
6. **数值梯度的 $h$ 设得太小**。见第 4 章例 4.3.2：中心差分 $h$ 取 $10^{-5}$ 附近，取 $10^{-12}$ 时 U 形曲线抬头，验证代码假阴性。
