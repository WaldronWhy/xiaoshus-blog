# 第 1 章 极限与连续：分析的起点

> **本章定位**：本章是整部教材的数学起点，给出严格分析语言（$\varepsilon$-$\delta$、$\varepsilon$-$N$）与连续性概念。不依赖任何前置章节；后续所有章的极限运算、泰勒展开的 $o(\cdot)$ 记号、级数收敛判别、概率论中的分布收敛，都建立在本章之上。

## 1.0 本章学习目标

- 能够用 $\varepsilon$-$N$ 语言写出 $\lim_{n\to\infty} a_n = a$ 的定义，并对简单数列（如 $a_n = \frac{1}{n}$、$a_n = q^n$）完成完整的证明。
- 能够用 $\varepsilon$-$\delta$ 语言证明 $\lim_{x\to 2} x^2 = 4$ 这类基本极限。
- 能够陈述并使用极限的四则运算法则、夹逼定理与两个重要极限，计算常见极限。
- 能够区分连续与一致连续，并能举出"连续但不一致连续"的反例。
- 能够通过数值实验观察极限过程与收敛速度，理解 $O(\cdot)$ 与 $o(\cdot)$ 记号的含义。
- 能够解释为什么连续性是"迭代算法有不动点"类论证的第一块基石。

## 1.1 从"无限接近"谈起：为什么需要严格定义

**直觉引入**。考虑复利问题：本金 1 元，年利率 $100\%$，每期结算一次本息。一年结算 $n$ 次时年末总额为

$$
a_n = \left(1 + \frac{1}{n}\right)^n .
$$

结算次数越多，总额越大吗？会无限增大吗？数值实验给出答案：

| $n$ | $1$ | $10$ | $10^2$ | $10^3$ | $10^6$ |
|---|---|---|---|---|---|
| $a_n$ | 2 | 2.593742... | 2.704814... | 2.716924... | 2.718280... |

数值上 $a_n$ 似乎"越来越接近"一个介于 2.71 与 2.72 之间的数（这正是自然对数的底 $\mathrm{e} = 2.71828\,1828\,45\cdots$，将在 1.5 节严格定义）。"越来越接近"是每个人都能理解的直觉，但直觉无法回答更精细的问题：

- 接近到什么程度算"达到了极限"？是否存在到达极限的"最后一步"？
- 两个数列逐项相加、相乘后极限如何变化？为什么？
- 函数 $f(x) = \frac{\sin x}{x}$ 在 $x=0$ 处无定义，凭什么说它"在 $0$ 附近的极限是 1"？

这些问题在 17–19 世纪困扰了数学家近两百年（牛顿的"最初与最终比"、贝克莱主教的"消失量的幽灵"批评），直到 19 世纪由柯西（Cauchy）与魏尔斯特拉斯（Weierstrass）用不等式语言彻底解决。**核心思想：把"无限接近"翻译成"任意接近"——一个可以有限验证的陈述。**

**从零实现的数值观察**。先写代码"看见"极限：

```python
import numpy as np

# 观察数列 a_n = (1 + 1/n)^n 的极限过程
for n in [1, 10, 10**2, 10**3, 10**4, 10**6]:
    a_n = (1 + 1.0 / n) ** n
    print(f"n = 10^{int(np.log10(n)):>2d}  a_n = {a_n:.10f}  误差 = {np.e - a_n:.3e}")

# 预期输出（误差单调减小，且减小的"速度"本身值得观察）：
# n = 10^ 0  a_n = 2.0000000000  误差 = 7.183e-01
# n = 10^ 1  a_n = 2.5937424601  误差 = 1.245e-01
# n = 10^ 2  a_n = 2.7048138294  误差 = 1.360e-02
# n = 10^ 3  a_n = 2.7169239322  误差 = 1.358e-03
# n = 10^ 6  a_n = 2.7182804691  误差 = 1.360e-06
```

注意误差大约是 $\frac{\mathrm{e}}{2n}$ 的量级：极限"存在"之外，"多快到达"同样是分析学的核心问题，这一线索将在第 4 章（泰勒展开）正式展开。

## 1.2 数列极限：$\varepsilon$-$N$ 定义

**定义 1.2.1（数列极限）**。设 $\{a_n\}$ 为数列，$a \in \mathbb{R}$。若对任意 $\varepsilon > 0$，存在正整数 $N$，使得当 $n > N$ 时恒有 $|a_n - a| < \varepsilon$，则称数列 $\{a_n\}$ 收敛（converge）于 $a$，记作 $\lim_{n\to\infty} a_n = a$；不收敛的数列称为发散（diverge）。

逐句解读这个定义的逻辑结构（这是本章最重要的阅读训练）：

- "$\varepsilon$ 任意"：挑战者可以提出任意苛刻的精度要求（$0.1$、$0.001$、$10^{-100}$……）。
- "$N$ 存在"：应对者必须针对每个 $\varepsilon$ 给出一个门槛 $N$；$N$ 依赖 $\varepsilon$，常写作 $N(\varepsilon)$。
- "$n > N$ 时 $|a_n - a| < \varepsilon$"：越过门槛后，数列的所有项都落在 $a$ 的 $\varepsilon$-邻域 $(a-\varepsilon, a+\varepsilon)$ 内。注意只要求"最终"所有项，前面有限多项可以任意捣乱。

**例 1.2.2**。证明 $\lim_{n\to\infty} \frac{1}{n} = 0$。

证：任给 $\varepsilon > 0$。要 $|\frac{1}{n} - 0| = \frac{1}{n} < \varepsilon$，只需 $n > \frac{1}{\varepsilon}$。由实数的阿基米德性质（Archimedean property），取 $N = \lceil \frac{1}{\varepsilon} \rceil$（上取整），则 $n > N$ 时 $n > \frac{1}{\varepsilon}$，即 $|\frac{1}{n} - 0| < \varepsilon$。证毕。$\blacksquare$

注意证明的固定套路："任给 $\varepsilon$ → 反解出对 $n$ 的要求 → 取 $N$"。这个套路叫"找 $N$"。

**例 1.2.3**。设 $|q| < 1$，证明 $\lim_{n\to\infty} q^n = 0$。

证：若 $q = 0$ 显然。设 $0 < |q| < 1$，则 $q^n = |q|^n$。令 $c = 1/|q| > 1$，由伯努利不等式（$c \ge 1$ 时 $(1+(c-1))^n \ge 1 + n(c-1)$），有

$$
|q^n - 0| = \frac{1}{c^n} \le \frac{1}{1 + n(c-1)} < \frac{1}{n(c-1)} .
$$

于是对任意 $\varepsilon > 0$，取 $N = \max\!\left(1, \left\lceil \frac{1}{\varepsilon (c-1)} \right\rceil\right)$，当 $n > N$ 时 $|q^n| < \varepsilon$。证毕。$\blacksquare$

**定义 1.2.4（无穷小与记号 $o(\cdot)$、$O(\cdot)$）**。若 $\lim_{n\to\infty} \alpha_n = 0$，称 $\{\alpha_n\}$ 为无穷小量（infinitesimal）。设 $\{\alpha_n\}$ 为无穷小，$\{x_n\}$ 为数列：

- 若 $\lim_{n\to\infty} \frac{x_n}{\alpha_n} = 0$，记 $x_n = o(\alpha_n)$：$x_n$ 比 $\alpha_n$ 更快地趋于零。
- 若存在常数 $C > 0$ 与 $N$，使 $n > N$ 时 $|x_n| \le C|\alpha_n|$，记 $x_n = O(\alpha_n)$：$x_n$ 与 $\alpha_n$ 同阶或有界。

这两个记号是全书量级语言的基础：第 4 章泰勒余项写成 $o(x^k)$ 或 $O(x^{k+1})$，梯度下降收敛率写成 $O(1/k)$，都源自此处。

## 1.3 极限的性质与运算法则

以下定理说明极限运算与代数运算在温和条件下可以交换顺序，这是所有"先取极限再计算"合法性的来源。

**定理 1.3.1（唯一性与有界性）**。收敛数列的极限唯一；收敛数列必有界（存在 $M$ 使 $|a_n| \le M$ 对所有 $n$ 成立）。反之不成立：$a_n = (-1)^n$ 有界但不收敛。

**定理 1.3.2（四则运算法则）**。设 $\lim a_n = a$，$\lim b_n = b$，则

$$
\lim (a_n \pm b_n) = a \pm b, \qquad \lim (a_n b_n) = ab, \qquad \lim \frac{a_n}{b_n} = \frac{a}{b} \ (b \neq 0).
$$

**定理 1.3.3（夹逼定理 / squeeze theorem）**。若从某项起 $a_n \le c_n \le b_n$，且 $\lim a_n = \lim b_n = a$，则 $\lim c_n = a$。

**例 1.3.4**。用夹逼定理证明 $\lim_{n\to\infty} \sqrt[n]{a} = 1$（$a > 1$）。设 $a = 1 + h$（$h>0$），由 $\sqrt[n]{a} = (1+h)^{1/n} \le 1 + \frac{h}{n}$（伯努利不等式反向使用：$1+h \le (1+\frac{h}{n})^n$），故 $1 \le \sqrt[n]{a} \le 1 + \frac{h}{n}$，两端极限均为 1，得证。

**两个重要极限**（后续一切三角、指数函数求导的基石，第 2 章推导 $(\sin x)' = \cos x$ 时会回头引用）：

$$
\lim_{x \to 0} \frac{\sin x}{x} = 1, \qquad \lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = \mathrm{e}.
$$

第一个极限的几何证明思路：单位圆中，扇形面积介于内接与外接三角形面积之间，即 $\sin x < x < \tan x$（$0 < x < \frac{\pi}{2}$），取倒数夹逼即得。

**例 1.3.5（计算练习）**。求 $\lim_{n\to\infty} \left(1 + \frac{2}{n}\right)^{3n}$。令 $m = n/2$，则原式 $= \left(1+\frac{1}{m}\right)^{6m} = \left[\left(1+\frac{1}{m}\right)^m\right]^6 \to \mathrm{e}^6$。中间每一步用到的都是"幂运算法则 + 重要极限"，这正是运算法则配合使用的方式。

**单调有界原理与实数完备性**。以下定理需要实数系的完备性（completeness），是"极限确实存在"的存在性保证：

**定理 1.3.6（单调有界原理）**。单调递增且有上界的数列必收敛。

由它可以建立**区间套定理**、**玻尔查诺–魏尔斯特拉斯定理**（有界数列必有收敛子列）与**柯西收敛准则**（数列收敛 $\iff$ 它是柯西列：任给 $\varepsilon>0$，存在 $N$，$m,n>N$ 时 $|a_m - a_n| < \varepsilon$）。柯西准则的价值在于**不依赖极限值本身**即可判断收敛——数值算法中"相邻两次迭代之差足够小"的停止条件，其理论合法性正来自这里。

## 1.4 函数极限与 $\varepsilon$-$\delta$ 语言

数列是离散的，但 AI 中更常见的是连续变量上的函数：学习率随时间的衰减 $\eta(t)$、激活函数 $\sigma(x)$、损失曲面 $L(w)$ 附近的行为。需要把极限概念搬到函数上。

**定义 1.4.1（函数极限）**。设函数 $f$ 在点 $x_0$ 的某个去心邻域内有定义，$A$ 为常数。若对任意 $\varepsilon > 0$，存在 $\delta > 0$，使得当 $0 < |x - x_0| < \delta$ 时恒有 $|f(x) - A| < \varepsilon$，则称 $x \to x_0$ 时 $f(x)$ 收敛于 $A$，记作 $\lim_{x\to x_0} f(x) = A$。

与 $\varepsilon$-$N$ 定义的对照（务必并排记忆）：

| | 数列 $\varepsilon$-$N$ | 函数 $\varepsilon$-$\delta$ |
|---|---|---|
| 自变量的"接近" | 离散：$n > N$ | 连续：$0 < \|x - x_0\| < \delta$ |
| 精度要求 | $|a_n - a| < \varepsilon$ | $|f(x) - A| < \varepsilon$ |
| 应对方式 | 给出门槛 $N(\varepsilon)$ | 给出邻域半径 $\delta(\varepsilon)$ |
| 关键细节 | 前有限项无关紧要 | $x_0$ 本身可以无定义（去心邻域） |

**例 1.4.2**。证明 $\lim_{x \to 2} x^2 = 4$。

证：任给 $\varepsilon > 0$。不妨设 $|x - 2| < 1$（先限制 $x$ 落在 2 附近），则 $|x^2 - 4| = |x-2|\,|x+2| < 5|x-2|$。于是取 $\delta = \min\!\left(1, \frac{\varepsilon}{5}\right)$：当 $0 < |x-2| < \delta$ 时，$|x^2-4| < 5\delta \le \varepsilon$。证毕。$\blacksquare$

这个证明展示了 $\varepsilon$-$\delta$ 技巧中最重要的两招：**先验限定**（不妨设 $|x-2|<1$，把 $|x+2|$ 钉死成常数 5）与**取小原则**（$\delta = \min$ 合并多个约束）。第 5 章证明"可微必连续"时会再次使用同样的手法。

**单侧极限与自变量趋于无穷**。$\lim_{x\to x_0^-} f$（左极限）、$\lim_{x\to x_0^+} f$（右极限）、$\lim_{x\to +\infty} f$ 定义方式类似。重要事实：$\lim_{x\to x_0} f = A \iff$ 左右极限都存在且等于 $A$。分段函数（如深度学习中的 ReLU、阶跃函数）在分段点处常需检查单侧极限：

$$
\lim_{x \to 0^-} \mathrm{ReLU}(x) = \lim_{x\to 0^-} 0 = 0, \qquad \lim_{x \to 0^+} \mathrm{ReLU}(x) = \lim_{x\to 0^+} x = 0,
$$

所以 $\lim_{x\to 0}\mathrm{ReLU}(x) = 0 = \mathrm{ReLU}(0)$：ReLU 在 0 处连续。这为第 2 章讨论"连续但不可微"埋下伏笔。

**无穷大与无穷小**。$\lim_{x\to x_0} f(x) = \infty$ 有严格的定义（对任意 $M>0$ 存在 $\delta>0$，使 $|f(x)| > M$），无穷大不是"一个很大的数"，而是一种趋势描述；无穷小与无穷大互为倒数（在取值非零的范围内）。等价无穷小替换是求极限的利器：$x \to 0$ 时

$$
\sin x \sim x, \quad \tan x \sim x, \quad 1 - \cos x \sim \frac{x^2}{2}, \quad \ln(1+x) \sim x, \quad \mathrm{e}^x - 1 \sim x, \quad (1+x)^\alpha - 1 \sim \alpha x .
$$

使用条件：替换只能用于**乘除因子**，不能随意用于加减项——这是高频错误，详见"常见误区"一节。（这些等价关系将在第 4 章由泰勒展开统一导出，届时不再是需要死记的表格。）

## 1.5 连续性

**定义 1.5.1（连续）**。若 $\lim_{x \to x_0} f(x) = f(x_0)$（即极限存在、等于函数值，且 $f$ 在 $x_0$ 有定义），称 $f$ 在 $x_0$ 连续（continuous）。用 $\varepsilon$-$\delta$ 语言：对任意 $\varepsilon > 0$，存在 $\delta > 0$，当 $|x - x_0| < \delta$ 时 $|f(x) - f(x_0)| < \varepsilon$。在区间上每点连续称为在该区间连续。

连续意味着"自变量的微小变化只引起函数值的微小变化"，且**变化幅度可以用一致的方式控制**。三个要点：极限存在（左右极限相等）、函数值存在、二者相等——连续性破坏的三个典型位置对应间断点的三种分类：

**定义 1.5.2（间断点分类）**。设 $x_0$ 是 $f$ 的间断点：

1. **第一类·可去间断点**：左右极限存在且相等，但 $\neq f(x_0)$（或 $f(x_0)$ 无定义）。例：$f(x) = \frac{\sin x}{x}$ 在 $x=0$。补定义 $f(0)=1$ 即"修复"。
2. **第一类·跳跃间断点**：左右极限存在但不相等。例：符号函数 $\mathrm{sgn}$ 在 $0$ 处。
3. **第二类间断点**：左右极限至少一个不存在。例：$\frac{1}{x}$ 在 $0$ 处（趋于无穷）；$\sin\frac{1}{x}$ 在 $0$ 处（振荡无极限）。

**定理 1.5.3（连续函数的运算）**。连续函数的和、差、积、商（分母非零）连续；连续函数的复合连续；严格单调连续函数的反函数连续。

**定理 1.5.4（初等函数连续性）**。多项式、$\sin x$、$\cos x$、$\exp$、$\ln$、幂函数在其定义域内连续；初等函数在其定义区间内连续。因此对初等函数，"求极限"常退化为"代入"：$\lim_{x\to 0} \mathrm{e}^{\sin x^2} = \mathrm{e}^0 = 1$。

**定理 1.5.5（闭区间上连续函数的性质）**。设 $f$ 在闭区间 $[a,b]$ 上连续，则：

1. **有界性定理**：$f$ 在 $[a,b]$ 上有界。
2. **最值定理**：$f$ 在 $[a,b]$ 上取得最大值与最小值。
3. **介值定理（intermediate value theorem）**：对介于 $f(a)$ 与 $f(b)$ 之间的任意 $\mu$，存在 $\xi \in [a,b]$ 使 $f(\xi) = \mu$。特别地，若 $f(a) f(b) < 0$，则存在根。

介值定理是**二分法求根**的理论依据，也是最优化中"一维搜索区间必含极小点"类论证的原型：数值实验里"看到符号变号就断定有根"，背后正是它。

```python
import numpy as np

# 介值定理的工程化身：二分法求根
def f(x):
    return x**3 - x - 2.0        # 在 [1, 2] 上变号

lo, hi = 1.0, 2.0
for it in range(50):
    mid = 0.5 * (lo + hi)
    if f(lo) * f(mid) < 0:
        hi = mid
    else:
        lo = mid
    if hi - lo < 1e-12:
        break
print(f"根 ≈ {mid:.12f}, 残差 f(mid) = {f(mid):.2e}, 迭代 {it+1} 次")
# 预期输出：根 ≈ 1.521379706805, 残差 f(mid) ≈ 8.88e-16 附近, 迭代 40 次左右
```

**一致连续简介**。仔细比较两个定义：

- 在 $x_0$ 连续：对每个点 $x_0$ 与每个 $\varepsilon$，存在 $\delta$——**$\delta$ 可以依赖 $x_0$**。
- 在区间 $I$ 上一致连续（uniformly continuous）：对每个 $\varepsilon$，存在一个**对所有点通用的 $\delta$**，使得只要 $x, y \in I$ 且 $|x-y| < \delta$，就有 $|f(x)-f(y)| < \varepsilon$。

**例 1.5.6**。$f(x) = \frac{1}{x}$ 在 $(0, 1)$ 上连续但不一致连续：取 $x = \frac{1}{n}$，$y = \frac{1}{n+1}$，两点距离趋于 0，但 $|f(x)-f(y)| = 1$ 不趋于 0。直观上，函数在区间左端"越来越陡"，任何固定的 $\delta$ 都会在足够靠左的位置失效。

**定理 1.5.7（Cantor 定理）**。闭区间上的连续函数必一致连续。

一致连续在本书的价值：它保证**对区间上所有点可以用同一套步长控制误差**——数值积分的误差控制（第 3 章）、有限差分近似梯度的精度（第 5 章、99 章综合项目）都隐含使用这一性质。在更一般的度量空间上，它还是不动点迭代（如 Banach 压缩映射原理）收敛证明的中间台阶。

**不动点与迭代收敛（选学，服务最优化）**。设映射 $\varphi$ 连续，若 $x^\ast = \varphi(x^\ast)$，称 $x^\ast$ 为不动点（fixed point）。若 $|\varphi'(x^\ast)| < 1$（第 2 章定义导数后回看），则迭代 $x_{k+1} = \varphi(x_k)$ 在 $x^\ast$ 附近局部收敛。现在仅用连续性说清楚"极限候选点"的存在：迭代序列若收敛到 $x^\ast$，则对 $x_{k+1} = \varphi(x_k)$ 两边取极限，由连续性得 $x^\ast = \varphi(x^\ast)$——**"取极限穿过函数符号"的合法性正是连续性**。这一论证模式将在梯度法收敛性分析（[最优化方法](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/00/)）中反复出现。

## 1.6 数值实验：三个极限过程

**实验一：$\left(1+\frac{1}{n}\right)^n \to \mathrm{e}$ 与收敛速度**。1.1 节的代码已展示误差 $\approx \frac{\mathrm{e}}{2n}$。把 $n$ 加倍，误差减半——这是一阶（线性）收敛，记号上叫 $O(1/n)$。对比实验：改用中心化的表达式 $\left(1+\frac{1}{n}\right)^{n+1/2}$，误差降为 $O(1/n^2)$ 量级，同样是趋于 $\mathrm{e}$，速度截然不同。

**实验二：$\lim_{x\to 0}\frac{\sin x}{x} = 1$ 与浮点灾难**。

```python
import numpy as np

xs = np.array([1e-1, 1e-4, 1e-8, 1e-12], dtype=np.float64)
print(np.sin(xs) / xs)   # 预期输出: [0.99833417 1.         1.         1.        ]
```

表面上看这个实验"成功"了——但注意 $x = 10^{-12}$ 时结果恰好为 1：真正的极限值与 1 相差约 $x^2/6 \approx 1.7 \times 10^{-25}$，早已超出双精度浮点的相对精度（约 $10^{-16}$），是舍入误差掩盖了真实差距。**数值实验只能"支持"而不能"证明"极限结论**；同时它预告了一个工程主题：当表达式涉及相近大数相减（如 $1 - \cos x$）时，会遭遇灾难性消去（catastrophic cancellation），补救手段（泰勒展开重写）在第 4 章详述。

**实验三：用柯西准则目测收敛**。对迭代 $x_{k+1} = \frac{1}{2}\left(x_k + \frac{2}{x_k}\right)$（巴比伦开平方，求 $\sqrt{2}$）：

```python
x = 1.0
for k in range(1, 8):
    x = 0.5 * (x + 2.0 / x)
    print(f"k={k}  x={x:.15f}  |x^2-2|={x*x-2:.3e}")
# 预期输出：k=1 x=1.500000000000000 |x^2-2|=2.500e-01
#           k=2 x=1.416666666666667 |x^2-2|=6.944e-03
#           k=3 x=1.414215686274510 |x^2-2|=2.124e-06
#           k=4 x=1.414213562374690 |x^2-2|=2.220e-13
#           k=5 起误差已被浮点极限吞没（残差 ~ 0）
```

误差每步大约平方——这是二阶收敛（quadratic convergence），它的解释工具（泰勒展开）在第 4 章给出，并且它就是牛顿法（第 4 章、[最优化方法](/xiaoshus-blog/textbooks/ai/math-foundations/optimization/00/)）收敛率的原型。

## 1.7 关键公式速查

| 公式 / 定义 | 适用条件与备注 |
|---|---|
| $\lim_{n\to\infty} a_n = a \iff \forall \varepsilon>0\ \exists N,\ n>N \Rightarrow \|a_n-a\|<\varepsilon$ | 收敛的定义；$N$ 依赖 $\varepsilon$ |
| $\lim_{x\to x_0} f(x)=A \iff \forall \varepsilon>0\ \exists \delta>0,\ 0<\|x-x_0\|<\delta \Rightarrow \|f(x)-A\|<\varepsilon$ | 去心邻域；$x_0$ 处 $f$ 可无定义 |
| 四则运算法则 | 要求各极限分别存在；商要求分母极限非零 |
| 夹逼定理 | 需要从某项起恒成立的不等式链 |
| $\lim_{x\to 0}\frac{\sin x}{x}=1$ | $x$ 用弧度制；由几何夹逼证明 |
| $\lim_{x\to\infty}\left(1+\frac{1}{x}\right)^x=\mathrm{e}$ | $1^\infty$ 型未定式的模板 |
| 单调有界原理 | 需要实数完备性；给出存在性 |
| 柯西收敛准则 | 收敛 $\iff$ 柯西列；不依赖极限值 |
| 介值定理 | 闭区间 + 连续；二分法的理论依据 |
| 一致连续：$\forall \varepsilon>0\ \exists \delta$ 对所有点通用 | 闭区间上连续 $\Rightarrow$ 一致连续（Cantor） |
| 等价无穷小（$x\to 0$）：$\sin x\sim x$，$\ln(1+x)\sim x$，$\mathrm{e}^x-1\sim x$ 等 | 仅可替换乘除因子 |
| $o(\cdot)$、$O(\cdot)$ 记号 | $o$：比值趋于 0；$O$：比值有界 |

## 1.8 示例与案例

**案例 1（手算）：求 $\lim_{x\to 0} \frac{\mathrm{e}^{2x}-1}{\ln(1+3x)}$。** $x \to 0$ 时分子分母均趋于 0（$\frac{0}{0}$ 型未定式）。用等价无穷小：$\mathrm{e}^{2x}-1 \sim 2x$，$\ln(1+3x) \sim 3x$，于是

$$
\lim_{x\to 0} \frac{\mathrm{e}^{2x}-1}{\ln(1+3x)} = \lim_{x\to 0} \frac{2x}{3x} = \frac{2}{3}.
$$

每步依据：等价无穷小替换（乘除因子允许）+ 约分。（第 4 章将用泰勒展开得到同样结果，并解释为什么替换合法。）

**案例 2（代码）：数值逼近 $\mathrm{e}$ 并估计误差阶。**

```python
import numpy as np

def approx_e(n):
    """返回 (1+1/n)^n 及其与 e 的误差。"""
    a = (1.0 + 1.0 / n) ** n
    return a, np.e - a

for n in [10**k for k in range(1, 7)]:
    a, err = approx_e(n)
    # 检验误差是否近似 e/(2n)：err * n 应趋于常数 e/2 ≈ 1.359
    print(f"n={n:>8d}  err={err:.6e}  n*err={n*err:.6f}")
# 预期输出（n*err 收敛到约 1.359，验证 err = O(1/n)）：
# n=      10  err=1.245394e-01  n*err=1.245394
# n=     100  err=1.357897e-02  n*err=1.357897
# n=    1000  err=1.357893e-03  n*err=1.357893
# n= 1000000  err=1.357892e-06  n*err=1.357892
```

这个"把误差乘上 $n$ 看是否趋于常数"的手法是识别误差阶的通用实验方法，在综合项目（99 章）中会多次用到。

## 1.9 常见误区与陷阱

1. **把"极限存在"当成"函数有定义"**。$\lim_{x\to 0}\frac{\sin x}{x}=1$ 与 $f(0)$ 是否有定义无关；去心邻域是定义的关键细节。
2. **等价无穷小用于加减项**。$x\to 0$ 时 $\tan x - \sin x$：若把 $\tan x$、$\sin x$ 都换成 $x$ 会得 0，但真值是 $\frac{x^3}{2}+o(x^3)$。加减时主部相消，必须保留更高阶项（第 4 章泰勒展开后此题两行解决）。
3. **认为收敛数列的项单调递减地逼近极限**。$a_n = \frac{(-1)^n}{n}$ 收敛于 0 但上下穿越；$a_n = \left(1+\frac{1}{n}\right)^n$ 单调递增趋于 $\mathrm{e}$，只是特例。
4. **混淆"连续"与"一致连续"**。$\frac{1}{x}$ 在 $(0,1)$ 连续但不一致连续；"开区间上连续"不保证一致连续，闭区间才行（Cantor 定理的条件不可省略）。
5. **数值上"看起来收敛了"就直接断言**。浮点精度约 $10^{-16}$（相对），低于此尺度的差异不可分辨；实验只能支持猜想，证明必须用分析语言完成。
6. **$1^\infty$、$0\cdot\infty$ 型未定式直接代入**。这些必须先化归（取对数、等价替换或洛必达——第 2 章），不能套用四则运算法则（其前提是各极限存在且有限）。
