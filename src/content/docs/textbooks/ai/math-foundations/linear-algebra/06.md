## 6.1 浮点数系统：计算机里"实数"的真相

**IEEE 754 double 格式**：64 位 = 1 符号位 + 11 指数位 + 52 尾数位，表示形如

$$x = \pm(1 + f)\times 2^{e}, \qquad f \in [0, 1) \text{（52 位二进制小数）}.$$

关键常数：可表示的最大数约 $1.8\times10^{308}$（超过则 `inf`，溢出），最小正规数约 $2.2\times10^{-308}$（低于则下溢为非规格化数或 0），**机器精度（machine epsilon）** $\varepsilon = 2^{-52} \approx 2.22\times10^{-16}$——即 1 与"下一个可表示的数"的间隔。

**舍入误差**：任何不能精确表示的实数被舍入到最近浮点数，相对误差不超过 $\varepsilon/2$。**但误差会传播**：

```python
import numpy as np

print(0.1 + 0.2 == 0.3)                    # 预期输出: False
print(repr(0.1 + 0.2))                     # 预期输出: 0.30000000000000004
print(np.finfo(float).eps)                 # 预期输出: 2.220446049250313e-16

# "大数吃小数": 把小数加到很大的数上会丢失
s = 1e16
for _ in range(10000):
    s += 1.0
print(s == 1e16)                           # 预期输出: True —— 加了一万次 1 却纹丝不动!
# 正确姿势: 小数先累加(或用 math.fsum / Kahan 求和), 再并入大数
print(np.sum([1.0] * 10000) + 1e16 > 1e16) # 预期输出: True
```

**两个衡量误差的量**（设 $x^*$ 真值、$\hat x$ 计算值）：绝对误差 $|\hat x - x^*|$；相对误差 $\frac{|\hat x - x^*|}{|x^*|}$。数值分析几乎只用相对误差——它与"有效数字位数"直接对应：相对误差 $10^{-k}$ 约等于 $k$ 位有效数字。

### 6.1.1 求和与累积：小误差如何长大

朴素求和从左到右累加，第 $i$ 步引入 $\varepsilon/2$ 级相对舍入；$n$ 项之后最坏总误差按 $\varepsilon \cdot n$ 增长——一亿次加法即可吃掉约一半有效数字。三种工程对策：

1. **成对求和（pairwise summation）**：先两两相加再逐层合并，误差降为 $\varepsilon \log_2 n$——NumPy 的 `np.sum` 默认即此；
2. **Kahan 补偿求和**：用一个"误差回收"变量把每步被丢掉的低位捡回来，误差几乎与 $n$ 无关：

```python
import numpy as np

N = 10_000_000
vals = np.concatenate([[1.0], np.full(N, 1e-8)])   # 1 个大数 + 一千万个 1e-8
# 真实和 = 1 + N * 1e-8 = 1.1

s_naive = 0.0
for v in vals:                       # 朴素顺序累加
    s_naive += v
s_pair = np.sum(vals)                # NumPy 成对求和

def kahan_sum(vals):
    s, c = 0.0, 0.0
    for v in vals:
        y = v - c                    # 减去上一步回收的误差
        t = s + y
        c = (t - s) - y              # 本步被丢弃的低位(代数上恰为 -c 之补)
        s = t
    return s

print("真值:  1.1")
print("朴素:", s_naive, "|误差| =", abs(s_naive - 1.1))
print("成对:", s_pair,  "|误差| =", abs(s_pair - 1.1))
print("Kahan:", kahan_sum(vals), "|误差| =", abs(kahan_sum(vals) - 1.1))
# 预期输出(量级): 朴素误差 ~6e-10(每步 ~1e-16 的舍入累积一千万次),
# 成对 ~4e-16, Kahan 本例完全精确(误差 0) —— 误差与求和顺序强相关
```

3. **改变运算顺序**：把小数先加在一起、大数分开处理（分桶/排序后累加）。"误差与运算顺序有关"是浮点世界与数学世界的第一个根本差异——它也是同一模型在不同 GPU 上结果不严格一致的根源（《模型部署与 MLOps》的可复现性话题）。

**向前误差与向后误差**：$\hat x$ 与真解的距离是向前误差；使 $\hat x$ 成为**某个**扰动问题 $\tilde f(x) = \hat x$（$\|\tilde x - x\| \le \varepsilon_{\text{back}}$）的精确解的扰动大小是向后误差。**数值稳定的算法 = 向后误差小**（它解对了"隔壁"一个近似问题）。这个观念转变（从"结果准"到"问题对"）是数值线性代数的哲学核心。

## 6.2 条件数：问题本身的敏感度

**定义 6.1（条件数）** 一个问题的条件数 = 输入相对扰动的最坏放大倍数。对线性方程组 $Ax = b$（$A$ 可逆）：

$$\kappa(A) = \frac{\sigma_{\max}(A)}{\sigma_{\min}(A)} = \frac{\lambda_{\max}}{\lambda_{\min}} \ \text{（对称正定时）}, \qquad \kappa(A) \ge 1, \ \kappa(I) = 1.$$

**定理 6.1（扰动界）** 解方程组 $Ax = b$，若 $A$ 或 $b$ 有相对扰动 $\delta$，则解的相对误差满足（一阶近似）

$$\frac{\|\delta x\|}{\|x\|} \ \lesssim\ \kappa(A)\cdot \frac{\|\delta b\|}{\|b\|} \quad\text{或}\quad \kappa(A)\cdot\frac{\|\delta A\|}{\|A\|}.$$

**解读**：$\kappa = 10^k$ 意味着**大约丢 $k$ 位有效数字**。double 有约 16 位有效数字，故 $\kappa \approx 10^{12}$ 时结果只剩 4 位可信，$\kappa \approx 10^{17}$ 时全毁。经验法则（Trefethen 的工程版）：$\log_{10}\kappa$ 是你"烧掉"的十进制位数。

**条件数刻画"问题"而非"算法"**：换算法救不了病态问题本身（只能避免病态化操作，如 6.4 节的平方放大）；真正病态的问题要靠正则化或重新建模。

**几何直观**：$\kappa$ 大 = 矩阵把单位球压成极扁的椭球（最大/最小伸缩比悬殊）。$A = \mathrm{diag}(100, 0.01)$ 的 $\kappa = 10^4$：沿第一条轴测量的误差到输出端被放大 $10^4$ 倍。第 4 章的奇异值语言在此变现为工程预言。

**例 6.1（Vandermonde：教科书式病态）** 多项式拟合 $A_{ij} = t_i^{j-1}$ 的条件数随次数指数增长（等距节点下 $\kappa \sim O(2^n)$ 量级经验规律）：

```python
import numpy as np

for n in [4, 8, 12, 16, 20]:
    t = np.linspace(-1, 1, n)
    A = np.vander(t, n, increasing=True)      # A[i,j] = t_i^j
    print(f"n={n:2d}, cond(V) = {np.linalg.cond(A):.3e}")
# 预期输出(量级):
# n= 4, cond(V) ≈ 8.0e+00
# n= 8, cond(V) ≈ 5.4e+02
# n=12, cond(V) ≈ 4.1e+04
# n=16, cond(V) ≈ 3.3e+06
# n=20, cond(V) ≈ 2.7e+08  —— 指数增长, 高次多项式拟合天生病态
```

这就是"高次多项式插值不可靠/要用正交多项式或样条"的数值根源，也是《机器学习》特征工程"多项式特征别一上来就升到 20 次"的隐性理由。

## 6.3 病态问题的三个来源与工程对策

1. **平方放大**：正规方程构造 $A^\top A$，条件数平方化 $\kappa(A^\top A) = \kappa(A)^2$（第 3 章练习 6 的实验在此理论化）。对策：QR 或 SVD 直接作用于 $A$。
2. **近共线特征**：特征/变量高度相关（如"身高(cm)"与"身高(m)"两列）→ $A$ 列近似线性相关 → $\sigma_{\min} \to 0$ → $\kappa \to \infty$。对策：特征去相关/降维（第 3 章 SVD、PCA），或岭正则化（下节）。
3. **尺度悬殊**：一列数值 $10^6$、另一列 $10^{-6}$（未归一化的原始数据）。对策：列缩放/标准化（《机器学习》特征缩放的第一动机就是数值，其次才是收敛速度）。

## 6.4 奇异矩阵、伪逆与正则化

**奇异/秩亏时怎么办？** $A^\top A$ 不可逆，正规方程失效；最小二乘解不唯一（可加 $\mathcal{N}(A)$ 中任意元素）。SVD 给出两个互补答案：

1. **伪逆 $A^+ = V\Sigma^+ U^\top$**（第 3 章 3.4 节）：在解集中挑**最小范数解** $\hat x = A^+b$。数值实现必须截断：把 $\sigma_i < \text{tol}\cdot\sigma_1$ 的分量当作零处理（`np.linalg.pinv(A, rcond=...)`），否则 $1/\sigma_i$ 的噪声放大直接摧毁结果——**伪逆的数值定义本身就是"条件数管理"**。
2. **Tikhonov / 岭正则化**：改为解 $\min_x \|Ax - b\|^2 + \lambda^2\|x\|^2$。正规方程变成 $(A^\top A + \lambda^2 I)x = A^\top b$。SVD 视角下，第 $i$ 个模态的响应从 $1/\sigma_i$ 变成 $\frac{\sigma_i}{\sigma_i^2 + \lambda^2}$——**$\sigma_i$ 很小时响应被钳位到 $\approx 1/\lambda$ 而不是爆炸**。这就是"正则化 = 数值稳定化"的精确含义，岭回归在《机器学习》中的双重身份（统计正则 + 数值稳定）由此统一。

```python
import numpy as np

rng = np.random.default_rng(0)
U, _ = np.linalg.qr(rng.standard_normal((200, 6)))
V, _ = np.linalg.qr(rng.standard_normal((10, 6)))
sigma = np.logspace(0, -8, 6)             # 奇异值从 1 跨到 1e-8 => kappa(A) = 1e8
A = (U * sigma) @ V.T                     # 200 x 10 的受控病态矩阵
b = rng.standard_normal(200)

x_qr   = np.linalg.lstsq(A, b, rcond=None)[0]         # SVD 内核, 自动截断
x_ne   = np.linalg.solve(A.T @ A, A.T @ b)            # 正规方程
x_pinv = np.linalg.pinv(A) @ b                        # 截断伪逆

print("QR   vs 伪逆 相对差:", np.linalg.norm(x_qr - x_pinv) / np.linalg.norm(x_qr))
print("正规方程 vs 伪逆 相对差:", np.linalg.norm(x_ne - x_pinv) / np.linalg.norm(x_pinv))
# 预期输出(量级): QR   vs 伪逆 相对差 ≈ 1e-15
#                 正规方程 vs 伪逆 相对差 ≈ 0.76 —— 解已完全失真:
#                 kappa(A^T A) = kappa(A)^2 = 1e16, 恰好吃光 double 的全部 16 位数字

lam = 1e-4
x_ridge = np.linalg.solve(A.T @ A + lam**2 * np.eye(10), A.T @ b)
print("岭解与 QR 解相对差:", np.linalg.norm(x_ridge - x_qr) / np.linalg.norm(x_qr))
# 预期输出: 接近 1 —— 岭解与普通最小二乘解确实不同!
# 这不是 bug 而是正则化的本义: lambda^2 = 1e-8 远大于 sigma_6^2 = 1e-16,
# 最小奇异值模态被钳位(sigma_i -> sigma_i/(sigma_i^2+lambda^2)), 牺牲噪声主导的
# 模态, 换来解的有界与稳定 —— "正则化 = 数值稳定化"的直观呈现
```

## 6.5 数值稳定性案例研究

### 案例 A：最小二乘三法对比（本课程压轴实验）

对 $A \in \mathbb{R}^{m\times n}$ 随 $\kappa$ 变化，比较三种解法对"真解"的误差：

| 方法 | 数学操作 | 条件数暴露 | 复杂度 | 实测表现 |
|---|---|---|---|---|
| 正规方程 | $\mathrm{solve}(A^\top A, A^\top b)$ | $\kappa^2$ | $O(mn^2 + n^3)$ | $\kappa \gtrsim 10^8$ 后迅速劣化 |
| QR（Householder） | $R\hat x = Q^\top b$ | $\kappa$ | $O(mn^2)$ | 良好 |
| SVD / lstsq | $A^+ b$ + 截断 | $\kappa$（可控截断） | $O(mn^2)$（大常数） | 最佳，且给出秩诊断 |

结论（工程规则）：**默认用 `lstsq`；想要速度且确认良态用 QR；正规方程只出现在手推公式与教科书里。** 完整实验脚本见 99 章项目三。

### 案例 B：softmax 的减最大值技巧

朴素 softmax 直接计算 $e^{z_i}/\sum e^{z_k}$ 有双重溢出风险：$z_i = 1000$ 时 $e^{1000} \approx 10^{434}$ 远超 float64 上限 $10^{308}$（`inf`，得 NaN）；$z$ 全为 $-1000$ 时全体下溢为 0（分母为零）。**平移不变性**是救命稻草：$\mathrm{softmax}(z) = \mathrm{softmax}(z - c)$ 对任意常数 $c$ 成立（分子分母同乘 $e^c$）。取 $c = \max_i z_i$：

$$p_i = \frac{e^{z_i - z_{\max}}}{\sum_k e^{z_k - z_{\max}}},$$

指数参数被压进 $(-\infty, 0]$，分子最大为 1，绝不溢出；全 $-1000$ 情形分母 $\ge 1$（至少有一项为 $e^0 = 1$）。**这个三行技巧是深度学习框架 softmax 的标配实现**，也是"数学恒等式 = 数值救命术"的最佳教材。配套技巧：`logsumexp`（对数域求和）与交叉熵的 log-softmax 融合（PyTorch 的 `cross_entropy` 不先算 softmax，防上溢也防 $\log 0$）。

```python
import numpy as np

z = np.array([1000.0, 999.0, 998.0])
try:
    e = np.exp(z); p = e / e.sum()          # 朴素版
except Warning:
    pass
print("朴素 softmax:", p)                    # 预期输出: [nan nan nan]  (inf/inf)

z_shift = z - z.max()
e = np.exp(z_shift); p = e / e.sum()
print("稳定 softmax:", p)                    # 预期输出: [0.6652 0.2447 0.0900] 附近
```

### 案例 C：迭代与累积误差

幂法/LU 的每步浮点误差以受控方式传播（向后稳定），但**长迭代序列**需要监控：残差 $\|Ax - b\|$ 与 $\|x_{t+1} - x_t\|$ 是廉价哨兵。第 4 章幂法用 Rayleigh 商残差判定收敛、PageRank 每步重新归一化防漂移，都是本章原则的提前兑现。

### 案例 D：log-sumexp —— 大数值域里的"安全通道"

softmax 的姊妹问题是**连乘与对数似然**：语言模型要对 $T$ 个 token 的概率连乘 $p_1 p_2 \cdots p_T$，$T = 2048$ 时即使每个 $p \approx 0.9$，乘积也下溢为 0，"困惑度"直接算不出来。标准解法是对数域计算：

$$\log \prod_i p_i = \sum_i \log p_i \quad\text{（连乘下溢 $\to$ 求和精确）}，$$

而 $\log p_i = z_i - z_{\max} - \log\sum_k e^{z_k - z_{\max}}$ 中又遇到 $\log\sum e^{(\cdot)}$，用 **log-sumexp** 稳定化：

$$\mathrm{LSE}(z) = z_{\max} + \log\sum_k e^{z_k - z_{\max}}.$$

三件套（减最大值的 softmax、log-softmax、LSE）合称"数值稳定的大数律"。它们解释了一个工程事实：**PyTorch 的 `cross_entropy` 接收 logits 而不是概率**——不是因为接口偏好，而是"先 softmax 再取 log"在数值上是错误的实现。第 6 章练习 7 让你亲手验证这一点。

## 6.6 关键公式速查

| 公式 | 含义 | 条件 |
|---|---|---|
| $\varepsilon = 2^{-52} \approx 2.2\times10^{-16}$ | double 机器精度 | IEEE 754 |
| $\kappa(A) = \sigma_{\max}/\sigma_{\min}$ | 条件数 | 恒成立（用 2-范数） |
| $\frac{\|\delta x\|}{\|x\|} \lesssim \kappa(A)\frac{\|\delta b\|}{\|b\|}$ | 解方程扰动界 | $A$ 可逆，一阶 |
| $\kappa(A^\top A) = \kappa(A)^2$ | 平方放大 | 列满秩 |
| $(A^\top A + \lambda^2 I)^{-1}A^\top b$，响应 $\frac{\sigma_i}{\sigma_i^2+\lambda^2}$ | 岭正则化的 SVD 解释 | $\lambda > 0$ |
| $A^+ = V\Sigma^+U^\top$（含截断容差） | 伪逆 | 数值秩由容差定 |
| $p_i = \frac{e^{z_i - z_{\max}}}{\sum_k e^{z_k - z_{\max}}}$ | 稳定 softmax | 恒等变换，恒成立 |

## 6.7 示例与案例

**案例（条件数 vs 解误差：一张实验表定生死）**：

```python
import numpy as np

rng = np.random.default_rng(3)
print(f"{'kappa':>10} | {'正规方程误差':>14} | {'QR误差':>10}")
for kappa_target in [1e2, 1e6, 1e10, 1e14]:
    n = 30
    U, _ = np.linalg.qr(rng.standard_normal((n, n)))
    V, _ = np.linalg.qr(rng.standard_normal((n, n)))
    s = np.logspace(0, -np.log10(kappa_target), n)   # sigma_1/sigma_n = kappa
    A = U @ np.diag(s) @ V.T
    x_true = rng.standard_normal(n)
    b = A @ x_true                                    # 无噪声, 误差纯来自算法

    x_ne = np.linalg.solve(A.T @ A, A.T @ b)
    x_qr = np.linalg.lstsq(A, b, rcond=None)[0]
    e_ne = np.linalg.norm(x_ne - x_true) / np.linalg.norm(x_true)
    e_qr = np.linalg.norm(x_qr - x_true) / np.linalg.norm(x_true)
    print(f"{kappa_target:10.0e} | {e_ne:14.2e} | {e_qr:10.2e}")
# 预期输出(seed=3, 量级):
#      1e+02 |        ~1e-13 |    ~1e-15
#      1e+06 |        ~3e-06 |    ~1e-11
#      1e+10 |        ~3e+00 |    ~1e-07
#      1e+14 |        ~2e+01 |    ~1e-04
# 规律: 正规方程误差按 eps * kappa^2 恶化, kappa >= 1e10 时相对误差超过 1(解完全失真);
#       QR 误差按 eps * kappa 恶化, 慢一个平方量级 —— 精确印证理论
```

## 6.8 常见误区与陷阱

1. **"结果看起来对就是对的"。** 病态问题的错误输出可能在"合理范围"内（如回归系数差 20%）而无任何报错。防范手段：报告 $\kappa$、残差、并做数据扰动敏感性检查（第 14 门课的稳健性思想）。
2. **以为 float64 万能。** 16 位数字在 $\kappa = 10^{16}$ 时归零；深度学习训练用 float16/bfloat16（8 位尾数，$\varepsilon \approx 0.008$）——所以框架里才有 loss scaling、LayerNorm 这类稳定结构。第 5 章 softmax 案例在半精度下更加生死攸关。
3. **把"数值秩"当"精确秩"。** 含噪声数据矩阵满秩但大奇异值之后有噪声地板；聚类/PCA 选 $k$ 看谱的断崖（第 3 章），程序里用 `rcond` 截断。
4. **灾难性抵消（catastrophic cancellation）**：相近数相减吃掉高位有效数字。例：用 $\sqrt{x+1} - \sqrt{x}$ 求 $x = 10^8$ 的差，直接算得 0（真值 $5\times10^{-5}$）；对策是恒等变形（乘共轭 $(\sqrt{x+1}+\sqrt{x})^{-1}$）。方差计算"先算 E[X²] 再减 (E[X])²"是同一陷阱（《概率论》会再敲警钟）。
5. **忽略 dtype 与累积顺序。** NumPy 默认 float64 但输入可能 float32；`np.sum` 用成对求和已较稳，但 `np.cumsum` 型长累积与手写循环求和仍需警惕。金融/物理仿真中"Kahan 求和"是标准补丁。

## 6.9 与前后章节的联系

**依赖的已学内容**：第 2 章 LU 复杂度与"分解一次多次回代"；第 3 章 SVD、伪逆、正规方程与 QR 的推导（本章给它们做数值审判）；第 4 章奇异值/特征值与 Rayleigh 商（条件数的语言）；第 5 章 Hessian 条件数与梯度法收敛的预告。

**向后的输出**：

- 条件数与收敛率 → 《最优化方法》：梯度法迭代数 $\propto \kappa$（病态碗震荡）、预条件思想（把问题变成良态再解）；
- 数值稳定技巧 → 《深度学习》：混合精度训练、LayerNorm/残差连接的数值副作用、log-sum-exp、softmax 温度实现；
- 岭正则化/SVD 截断 → 《机器学习》岭回归与 PCA 降噪；伪逆 → 《模型部署与 MLOps》中量化误差与低秩替代的误差预算；
- 向后误差观 → 《实验设计与评估》的可复现性讨论（不同 BLAS/硬件的 1e-16 级漂移与随机种子管理）。

- **Lloyd N. Trefethen & David Bau III, *Numerical Linear Algebra*, SIAM, 1997**——本章的最佳平行教材：条件数、稳定性、QR/SVD 的数值视角讲解极清晰（40 讲结构，与 18.06 互补）；想深究第 6.7 节实验背后的定理就读它。

- **Nicholas J. Higham, *Accuracy and Stability of Numerical Algorithms*, 2nd ed., SIAM, 2002**——误差分析的百科全书；遇到"这个算法到底稳不稳"的争论时，查它裁决。
- **MIT 6.33J / 18.335 (Introduction to Numerical Methods) 公开课**（OCW 免费）——Trefethen 主讲，与本章同步的第 1–10 讲。

## 6.11 进阶方向

- **低精度与混合精度计算**：float16/bfloat16/int8 量化训练与推理的误差理论（scaling、stochastic rounding）；通往《模型部署与 MLOps》。
- **随机化与通信避免算法**：随机化 SVD/Sketching 把"条件数管理"与"计算量管理"统一；混合精度 LU（HPL-AI 基准）。
- **自动精度分析**：区间算术与浮点形式化验证（IEEE 754 形式语义），用于安全关键系统。
- **迭代法的收敛理论**：Krylov 方法（GMRES/共轭梯度）的收敛谱理论、预条件子设计；需第 4 章谱理论 + 《最优化方法》。

## 6.12 课后思考与练习

**基础题**

1. 用 Python 验证：(a) `(1e16 + 1) - 1e16` 的结果及原因；(b) 找出最小的正整数 $n$ 使 `1.0 + 1/n == 1.0` 为 True。（校验值：$n = 10^{17}$ 时必 True；临界值与 $\varepsilon$ 同量级，实际约为 $9\times10^{15}$。）
2. 概念：解释"向后误差小 = 数值稳定"为什么比"向前误差小"更可操作。（提示：真解未知，但扰动后问题的精确解可定义。）
3. 手算：$A = \mathrm{diag}(10^3, 10^{-3})$ 的条件数是多少？把 $b = (1, 1)$ 中第二个分量扰动 $10^{-6}$ 相对量，解的第二个分量相对变化多少？（校验值：$\kappa = 10^6$，解扰动 $10^{-6}$；请再用 $b=(1,0)$ 情形体会方向依赖性。）
4. 概念：为什么 softmax 平移不变性成立？写出 $\mathrm{softmax}(z - c) = \mathrm{softmax}(z)$ 的一行证明。

**进阶题**

5. 编程：实现朴素方差公式 $\frac{1}{n}\sum x_i^2 - \bar x^2$ 与两遍算法 $\frac{1}{n}\sum (x_i - \bar x)^2$，在 $x = 10^9 + \text{小噪声}$ 数据上对比（Welford 单遍算法可作加餐）。输出目标：朴素公式误差 $> 10\%$ 或为负，两遍算法正常。
6. 编程：用 6.7 节实验框架，加入第三种方法"正规方程 + 岭正则化（$\lambda = \sigma_{\min}$ 量级）"，观察 $\kappa = 10^{14}$ 时岭解与 QR 解的接近程度，并解释小奇异值模态被正则化"牺牲"换稳定的权衡。
7. 概念：第 5 章 softmax 交叉熵在实现中为何要输出 $\log p$ 而不是 $p$ 再取 $\log$？（提示：$p$ 下溢为 0 后 $\log 0 = -\infty$；log-softmax 用 log-sum-exp 一次算出，既有界又无损。）
8. 编程：测量 `np.linalg.solve` 与 `inv(A) @ b` 在 $n = 2000$ 随机良态矩阵上的时间与误差差；再人为放大条件数，观察两者误差差距如何随 $\kappa$ 拉开。输出目标：时间比约 2–4 倍、误差比随 $\kappa$ 增大。

**挑战题**

9. （研究生层次）证明定理 6.1 的上界：$\frac{\|\delta x\|}{\|x\|} \le \kappa(A)\frac{\|\delta b\|}{\|b\|}$（$b$ 扰动情形），并构造例子说明"≳ 可达"（即界是紧的）。
10. （研究生层次）复现半精度训练的一个最小实验：把第 5 章两层网络的 NumPy 实验改为 float32，再模拟 bfloat16（8 位尾数，可用 `np.round` 到 8 位尾数模拟），对比 (a) 直接 softmax+CE 与 (b) log-sum-exp 融合版在 logits 平移 100 时的损失值差异。撰写 500 字实验报告，说明"数值稳定结构"在大规模训练中为何不是可选项。
