# 第 4 章 特征值与对角化 —— 谱视角

> **本章定位**：前两章回答"如何变换、如何拟合"；本章回答更深层的问题——一个矩阵（映射）**固有的方向与增益**是什么。特征值/特征向量、谱定理、正定性、Rayleigh 商与幂法构成"谱视角"，是《机器学习》谱聚类、《深度学习》梯度爆炸/初始化分析、图神经网络归一化方案的数学源头。上一章的 SVD 也在此获得最深的理解（$\sigma_i^2$ 是 $A^\top A$ 的特征值）。

## 4.1 特征值与特征向量：映射的固有方向

**定义 4.1（特征值与特征向量）** $A \in \mathbb{R}^{n \times n}$，若存在非零向量 $v$ 与标量 $\lambda$ 使

$$Av = \lambda v,$$

则 $\lambda$ 称为特征值（eigenvalue），$v$ 称为对应的特征向量（eigenvector）。

几何图像：$A$ 一般把向量"转向 + 缩放"；特征向量是**方向不被改变**的特殊向量，矩阵对它们只做纯伸缩，伸缩比即特征值。$\lambda > 0$ 同向放大、$\lambda < 0$ 反向、$|\lambda| > 1$ 放大、$|\lambda| < 1$ 收缩、$\lambda = 0$ 压扁进低维（并入零空间——第 3 章的视角）。

**求法**：$Av = \lambda v \iff (A - \lambda I)v = 0$ 有非零解 $\iff \det(A - \lambda I) = 0$。这个 $n$ 次多项式称为**特征多项式**。

**例 4.1（手算 2 阶）** $A = \begin{pmatrix} 4 & 1 \\ 2 & 3 \end{pmatrix}$。$\det(A - \lambda I) = (4-\lambda)(3-\lambda) - 2 = \lambda^2 - 7\lambda + 10 = (\lambda - 2)(\lambda - 5)$，特征值 $\lambda = 2, 5$。$\lambda = 5$：$(A - 5I)v = 0 \Rightarrow v_1 = v_2$，取 $v = (1, 1)$；$\lambda = 2$：$2v_1 + v_2 = 0$，取 $v = (1, -2)$。校验：$A(1,1)^\top = (5, 5) = 5(1,1)$ ✓。

**基本事实**：$A$ 的全部特征值之积 $= \det A$，之和 $= \mathrm{tr}(A) = \sum a_{ii}$（迹，trace）。三角形矩阵的特征值就是其对角元。相似矩阵（$B = S^{-1}AS$）特征值相同——所以特征值是"映射本身"的性质，不是"坐标系"的性质。这一句话正是 4.2 节对角化的动机：**找一个坐标系，让映射显出纯伸缩的本相**。

**复特征值**：实矩阵可有复特征值（成对共轭出现），如旋转矩阵 $\begin{pmatrix} 0 & -1 \\ 1 & 0\end{pmatrix}$ 的特征值为 $\pm i$——几何上"所有方向都在转"，没有实的不动方向。复特征值对应动力系统中的**振荡**（螺旋收缩/发散），第 6 章讨论数值方法时也会碰到。

## 4.2 对角化与矩阵幂

**定义 4.2（可对角化）** $A$ 可对角化若存在可逆 $P$ 与对角阵 $\Lambda = \mathrm{diag}(\lambda_1, \dots, \lambda_n)$ 使 $A = P\Lambda P^{-1}$，等价于 $AP = P\Lambda$——$P$ 的列恰是 $n$ 个**线性无关**的特征向量。

**定理 4.1（对角化判据）** $A$ 可对角化 $\iff$ $A$ 有 $n$ 个线性无关的特征向量 $\iff$ 每个特征值 $\lambda_i$ 的几何重数（特征空间维数）等于其代数重数（在特征多项式中的重数）。

**例 4.2（不可对角化的反例）** $A = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$（Jordan 块）。特征多项式 $(1-\lambda)^2$，$\lambda = 1$ 代数重数 2；但 $(A - I)v = 0$ 只有 $v_2 = 0$ 一维解，几何重数 1 < 2，不可对角化。这类"缺陷矩阵"在对角化框架下需要 Jordan 标准形，但**对称矩阵永远不会**（4.3 节）。

**矩阵幂**：$A^k = P\Lambda^k P^{-1}$，即把"重复施加映射"化成"在特征坐标系里做 $k$ 次标量幂"。三步法：$x_0 \xrightarrow{P^{-1}}$ 特征坐标 $\xrightarrow{\Lambda^k}$ 缩放 $\xrightarrow{P}$ 回原坐标。

**应用：动力系统**。$x_{t+1} = Ax_t$ 的解为 $x_t = c_1\lambda_1^t v_1 + \cdots + c_n \lambda_n^t v_n$（把 $x_0$ 分解到特征基上）。长期行为由 $|\lambda|_{\max}$ 主导：

- $|\lambda_{\max}| < 1$：一切收敛到 0（稳定）；
- $|\lambda_{\max}| > 1$：沿主特征方向指数增长（$c_1 \ne 0$ 时）；
- $|\lambda_{\max}| = 1$：临界，其余分量衰减，系统趋向主特征方向——**幂法与 PageRank 的全部原理**。

**例 4.3（斐波那契）** $\begin{pmatrix} F_{t+1} \\ F_t \end{pmatrix} = \begin{pmatrix}1 & 1 \\ 1 & 0\end{pmatrix}\begin{pmatrix} F_t \\ F_{t-1}\end{pmatrix}$。特征值 $\varphi = \frac{1+\sqrt5}{2}$ 与 $-\varphi^{-1}$，于是 $F_t$ 是 $\varphi^t$ 与 $(-\varphi^{-1})^t$ 的组合（Binet 公式）——"黄金比例"就是斐波那契矩阵的主特征值。

## 4.3 对称矩阵的谱定理

**定理 4.2（谱定理，spectral theorem）** 若 $A = A^\top$（实对称），则：(i) 所有特征值为实数；(ii) 存在 $n$ 个**相互正交**的特征向量构成 $\mathbb{R}^n$ 的标准正交基；(iii) $A = Q\Lambda Q^\top$，$Q$ 正交、$\Lambda$ 实对角。

**为什么重要？** 三个层面：

1. **理论**：对称映射没有"缺陷"（例 4.2 的现象不可能发生），且特征方向自动正交——**任意对称映射 = 一组相互垂直的方向上的独立伸缩**。这是"谱"（spectrum，物理学的借词：把矩阵像光一样分解成纯色）一词的由来。
2. **与 SVD 的对接**：对称半正定矩阵的 SVD 与特征分解重合（$U = V = Q$，$\sigma_i = \lambda_i$）。一般矩阵的 SVD 证明正是靠对称化：$A^\top A = V\Lambda V^\top$（谱定理保证特征基正交且 $\lambda_i = \sigma_i^2 \ge 0$），再定义 $u_i = Av_i / \sigma_i$。第 3 章 3.4 节欠掉的证明在此补全。
3. **计算**：正交矩阵数值性质完美（不放大误差，$\kappa(Q) = 1$，第 6 章），对称特征问题的算法（如 QR 算法、Jacobi 法）因此最稳定、最快——`np.linalg.eigh` 就是为对称阵特化的例程。

**对称 vs 一般矩阵对照**：

| 性质 | 对称 $A = A^\top$ | 一般方阵 |
|---|---|---|
| 特征值 | 全实 | 可复 |
| 特征向量 | 可选正交基 | 一般不正交 |
| 对角化 | $A = Q\Lambda Q^\top$ 恒可 | 需无缺陷（定理 4.1） |
| 数值算法 | 稳定（eigh） | 较稳（eig） |

**例 4.4（手算 3 阶对称矩阵）** $A = \begin{pmatrix} 2 & -1 & 0 \\ -1 & 2 & 0 \\ 0 & 0 & 3 \end{pmatrix}$。特征多项式：沿第三行展开 $\det(A - \lambda I) = (3 - \lambda)\big[(2-\lambda)^2 - 1\big] = (3-\lambda)(1-\lambda)(3-\lambda)$，特征值 $\lambda = 1, 3, 3$（重根！）。$\lambda = 3$：$(A - 3I)v = 0$ 给出 $-v_1 - v_2 = 0$ 与 $0 = 0$——二维解空间，几何重数 2 = 代数重数 ✓（对称矩阵的必然，定理 4.2 即将给出原因）。取正交基 $v_1 = \frac{1}{\sqrt2}(1, -1, 0)$，$v_2 = (0,0,1)$；$\lambda = 1$：$v_1 + v_2 = 0$ 且 $2v_3 = 0$，取 $v_3 = \frac{1}{\sqrt2}(1, 1, 0)$。三个特征向量两两正交，$A = Q\Lambda Q^\top$ 成立——谱定理的一次完整预演。

### 谱定理在 AI 中的三处现身

1. **参数初始化**。把权重矩阵初始化为（近）正交阵时，$W^\top W = I$ 意味着信号前向传播与梯度反向传播的范数都严格保持（$Q$ 是等距算子）——Xavier/He 初始化想逼近的理想状态。深度网络训练前的"信号传播分析"本质上是随机矩阵谱的问题（4.11 进阶方向）。
2. **二阶信息与曲率**。损失函数的 Hessian 对称（第 5 章定理），其谱 = 各方向的曲率。训练动力学的"尖锐/平坦极小值"讨论、学习率上界 $1/\lambda_{\max}(H)$、谱归一化（约束权重矩阵的最大奇异值），全部以谱定理为语法。
3. **协方差与核矩阵**。PCA 的主成分、核方法的 Gram 矩阵、高斯过程的协方差函数——它们都是对称（半）正定阵，谱定理保证"可以放心地特征分解"，而特征值非负这一事实正是"方差/能量"解释的来源。

## 4.4 正定矩阵与二次型

**定义 4.3（正定）** 对称矩阵 $A$ **正定（positive definite）**，记 $A \succ 0$，若 $x^\top A x > 0$ 对一切 $x \ne 0$；半正定 $A \succeq 0$ 若 $\ge 0$（允许 $= 0$ 于非零 $x$）。

$x^\top A x$ 是二次齐次多项式，称**二次型**。例：$A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$，$x^\top A x = 2x_1^2 + 2x_1x_2 + 2x_2^2$，配方 $= (\sqrt2 x_1 + \tfrac{1}{\sqrt2}x_2)^2 \cdot 2$ 型正项和（严格配方：$2(x_1 + \tfrac{x_2}{2})^2 + \tfrac32 x_2^2 > 0$），故正定。

**定理 4.3（正定的等价刻画）** 对称 $A$，以下等价：① $A \succ 0$；② 全部特征值 $> 0$；③ 存在 $R$ 满秩使 $A = R^\top R$（Cholesky 因子）；④ 所有顺序主子式 $> 0$（Sylvester 判据）；⑤ 极小范数意义下 $A$ 定义了内积。

谱定理下的解释：$x^\top A x = \sum_i \lambda_i y_i^2$（$y = Q^\top x$）——正定就是"沿每个特征方向都是正的碗"。

**与 AI 的三个连接**：

1. **凸性**：$f(x)$ 的 Hessian 处处半正定 $\iff f$ 凸。最小二乘的 $A^\top A$（第 3 章练习 5）半正定、列满秩时正定——正规方程的全局最优性由此严格化。《最优化方法》全书建立在此之上。
2. **协方差矩阵**：多元正态 $\mathcal{N}(\mu, \Sigma)$ 要求 $\Sigma \succeq 0$；《概率论》的 Mahalanobis 距离 $d^2 = (x-\mu)^\top\Sigma^{-1}(x-\mu)$、PCA 的方差最大化都发生在 $\Sigma$ 的谱上（第 3 章已见）。
3. **核矩阵**：核方法要求任意点集的 Gram 矩阵半正定——"valid kernel"的代数定义。

## 4.5 Rayleigh 商与谱的极值刻画

**定义 4.4（Rayleigh 商）** 对称 $A$：

$$R(x) = \frac{x^\top A x}{x^\top x}, \quad x \ne 0.$$

它是对称矩阵最锋利的分析工具，三条性质：

1. **齐次**：$R(cx) = R(x)$——只看方向，不看长度；
2. **范围**：$\lambda_{\min} \le R(x) \le \lambda_{\max}$，等号恰在对应特征向量取得（由谱定理：$R(x) = \sum \lambda_i y_i^2 / \sum y_i^2$ 是特征值的加权平均）；
3. **平稳性**：$\nabla R(x) = 0 \iff x$ 是特征向量（第 5 章矩阵微积分的现成练习）。

于是得到谱的极小极大刻画（Courant–Fischer 定理的特例）：

$$\lambda_{\max} = \max_{x \ne 0} \frac{x^\top A x}{x^\top x}, \qquad \lambda_{\min} = \min_{x \ne 0} \frac{x^\top A x}{x^\top x}.$$

PCA 的"方差最大化"正是 Rayleigh 商最大化：第一主成分 = 协方差矩阵主特征向量（第 3 章 3.5 节的谱叙述在此闭环）。此外 $\|A\|_2 = \sqrt{\lambda_{\max}(A^\top A)}$（谱范数）与条件数 $\kappa(A) = \sigma_{\max}/\sigma_{\min}$（第 6 章主角）都由 Rayleigh 商的语言承载。

## 4.6 幂法与 PageRank

### 4.6.1 幂法（power method）

**思想**：反复乘 $A$，任何初始向量中主特征方向成分按 $|\lambda_1|^t$ 相对增长：

$$A^t x_0 = \lambda_1^t \sum_i c_i \left(\frac{\lambda_i}{\lambda_1}\right)^t v_i \ \approx\ c_1 \lambda_1^t v_1 \quad (t \to \infty,\ |\lambda_1| > |\lambda_2|).$$

每步归一化防溢出。要求：$|\lambda_1| > |\lambda_2|$（主特征值严格占优）、$c_1 \ne 0$（随机初值几乎必然满足）。收敛率 $O((|\lambda_2/\lambda_1|)^t)$——谱隙越大越快。变体：对 $A^{-1}$ 幂法（配合解方程）得最小特征值；位移 $A - \mu I$ 可瞄准任意目标谱段；块状版本成为现代 SVD 求解器（第 3 章 sklearn randomized_svd 的内核之一）。

### 4.6.2 PageRank：谱方法改变世界

**问题**：网页 $j$ 的权威度 = 指向它的网页的权威度的加权和。设 $M \in \mathbb{R}^{n \times n}$，$M_{ij} = 1/\mathrm{outdeg}(j)$（若 $j$ 链接到 $i$），列和为 1（列随机矩阵）。权威度向量 $\pi$ 满足自洽方程 $M\pi = \pi$——**$\pi$ 是 $M$ 特征值 1 的特征向量**。

**两个坑与修补**：(1) 蜘蛛陷阱（部分节点构成吸收团）与死端（无出链）使 $M$ 不再把概率质量守恒；(2) 仅有特征值 1 不保证唯一与可达。Google 的解法是**随机跳转**：

$$G = \beta M + (1 - \beta)\frac{1}{n}\mathbf{1}\mathbf{1}^\top, \qquad \beta = 0.85,$$

$G$ 成为每列和为 1、所有元素为正的**列随机矩阵**。Perron–Frobenius 定理（对正矩阵：主特征值单、正、对应正特征向量，其余 $|\lambda| < \lambda_1$）保证 $\pi$ 存在唯一且幂法收敛——而且 $\beta$ 直接制造了谱隙（$G$ 的其余特征值绝对值 $\le \beta$，故收敛率 $O(\beta^t)$）。

**概率视角**（与《概率论》的呼应）：$\pi$ 是"随机游走者长期分布"——在任意页面随机选链接跳转（概率 $\beta$）或随机跳到任意页面（概率 $1-\beta$）的平稳分布。矩阵幂法 = 马尔可夫链收敛，两种语言说的是同一件事。

### 4.6.3 从幂法到现代特征求解器

幂法是整个现代特征值算法家族的"种子"：

1. **逆迭代（inverse iteration）**：对 $A - \mu I$ 做幂法但每步**解方程**（LU 分解一次、回代多次——第 2 章的经济性原则），收敛到离 $\mu$ 最近的特征值。位移 $\mu$ 取当前 Rayleigh 商时收敛速度二次化（Rayleigh 商迭代），是浮点世界里"指数收敛"的罕见例子。
2. **块幂法与正交迭代**：同时迭代 $k$ 个向量并每步正交化（Gram-Schmidt，第 3 章），得到整个主导不变子空间而非单个向量——第 3 章 `randomized_svd` 的内核即此。
3. **Krylov 子空间方法（Lanczos/Arnoldi）**：记住并复用全部历史向量 $\{x_0, Ax_0, A^2x_0, \dots\}$ 张成的小空间，在其中解一个小特征问题——用 $O(nk)$ 内存换"远快于幂法的收敛"。它是 `scipy.sparse.linalg.eigsh` 的引擎，也是《最优化方法》共轭梯度法的近亲。
4. **QR 算法**：对角化的工业标准（`np.linalg.eig`/`eigsh` 的底层），可以理解为"幂法 + 每步正交化 + 隐式位移"的集大成者——Golub & Van Loan 第 7–8 章是其完整理论。

一句话总结谱方法的工程哲学：**我们几乎从不想要全部 $n$ 个特征对**（那是 $O(n^3)$ 的奢侈），我们想要的是"最大的几个"或"最小的几个"——而幂法家族正是为此而生。

**例 4.5（谱隙决定收敛速度：数值体会）** 用两个谱隙悬殊的对称矩阵对比幂法的迭代数：

```python
import numpy as np

rng = np.random.default_rng(11)
def power_method(A, tol=1e-10, max_iter=200000):
    v = rng.standard_normal(A.shape[1]); v /= np.linalg.norm(v)
    lam = v @ A @ v
    for it in range(max_iter):
        w = A @ v
        v = w / np.linalg.norm(w)
        lam_new = v @ A @ v
        if abs(lam_new - lam) < tol:
            return lam_new, it
        lam = lam_new
    return lam, max_iter

Q, _ = np.linalg.qr(rng.standard_normal((50, 50)))
A_big_gap = Q @ np.diag(np.linspace(10, 1, 50)) @ Q.T     # l1=10, l2≈9.82
A_small_gap = Q @ np.diag(np.concatenate([[10.], np.linspace(9.99, 1, 49)])) @ Q.T
                                                            # l1=10, l2≈9.99
for name, A in [("谱隙大", A_big_gap), ("谱隙小", A_small_gap)]:
    lam, it = power_method(A)
    s = np.abs(np.linalg.eigvalsh(A))
    print(f"{name}: |l2/l1| = {s[-2]/s[-1]:.4f}, 迭代 {it} 次")
# 预期输出(量级): 谱隙大: |l2/l1| ≈ 0.98, 迭代 ~461 次;
#                 谱隙小: |l2/l1| ≈ 0.999, 迭代 ~7000 次 —— 收敛率 O((l2/l1)^t)
```

## 4.7 关键公式速查

| 公式 | 含义 | 适用条件 |
|---|---|---|
| $Av = \lambda v$ | 特征方程 | 方阵 |
| $\prod \lambda_i = \det A$，$\sum \lambda_i = \mathrm{tr}\,A$ | 特征值与行列式/迹 | 方阵 |
| $A^k = P\Lambda^kP^{-1}$ | 矩阵幂 | $A$ 可对角化 |
| $A = Q\Lambda Q^\top$ | 谱定理 | $A$ 对称 |
| $A \succ 0 \iff \lambda_i > 0 \iff A = R^\top R \iff$ 主子式 $> 0$ | 正定判据 | $A$ 对称 |
| $\lambda_{\max/\min} = \max/\min_{x\ne0} \frac{x^\top Ax}{x^\top x}$ | Rayleigh 商极值 | $A$ 对称 |
| $x_{t+1} = Ax_t \Rightarrow x_t = \sum c_i\lambda_i^t v_i$ | 动力系统 | $A$ 可对角化 |
| $G = \beta M + (1-\beta)\frac{1}{n}11^\top$, $G\pi = \pi$ | PageRank | 列随机 $M$，$\beta = 0.85$ |

## 4.8 示例与案例

**案例 1（从零实现幂法并与 eigh 对照）**：

```python
import numpy as np

def power_method(A, tol=1e-12, max_iter=10000, seed=0):
    """对称矩阵幂法：返回主特征值与主特征向量。"""
    rng = np.random.default_rng(seed)
    v = rng.standard_normal(A.shape[1])
    v /= np.linalg.norm(v)
    lam = v @ A @ v                     # 当前 Rayleigh 商估计
    for it in range(max_iter):
        w = A @ v
        v_new = w / np.linalg.norm(w)
        lam_new = v_new @ A @ v_new     # 用 Rayleigh 商作特征值估计
        if abs(lam_new - lam) < tol * max(1.0, abs(lam)):
            return lam_new, v_new, it + 1
        v, lam = v_new, lam_new
    return lam, v, max_iter

rng = np.random.default_rng(7)
B = rng.standard_normal((6, 6))
A = (B + B.T) / 2                                  # 对称化
lam, v, it = power_method(A)
lams = np.linalg.eigvalsh(A)                       # 对称专用精确求解
print(f"幂法: lam={lam:.8f}, 迭代 {it} 次")
print(f"eigh 主特征值(按模最大): {lams[np.argmax(np.abs(lams))]:.8f}")
# 预期输出(量级): 两者 lam 一致到 1e-10 级; 注意主特征值可以是负的
# —— 幂法找的是 |lambda| 最大者, 迭代次数约百次量级(取决于谱隙 |l2/l1|)
print("残差 |Av - lam v| =", np.linalg.norm(A @ v - lam * v))   # 预期输出: ~1e-5 或更小
```

**案例 2（小型 Web 图上的 PageRank）**：

```python
import numpy as np

# 5 个页面的链接图: links[i] = i 链接到的页面集合
links = {0: [1, 2], 1: [2], 2: [0, 3], 3: [3], 4: [0, 2]}
n = 5
M = np.zeros((n, n))
for j, outs in links.items():
    if outs:
        for i in outs:
            M[i, j] = 1 / len(outs)
    # 注意: 页面 3 只链接自己(蜘蛛陷阱), 无页面 4 被链接会丢失质量 => 需要 Beta 跳转

beta = 0.85
G = beta * M + (1 - beta) / n * np.ones((n, n))    # Google 矩阵: 列和均为 1
print("列和 =", G.sum(axis=0))                     # 预期输出: [1. 1. 1. 1. 1.]

# 幂法求平稳分布
pi = np.ones(n) / n
for _ in range(200):
    pi = G @ pi
    pi /= pi.sum()                                 # 数值上保持归一
print("PageRank(幂法) =", np.round(pi, 4))
print("PageRank(eig)  =", end=" ")
lam, vec = np.linalg.eig(G)
k = np.argmax(lam.real)
print(np.round(np.abs(vec[:, k]) / np.abs(vec[:, k]).sum(), 4))
# 预期输出(两法一致, 保留 4 位):
# PageRank ≈ [0.1078 0.0758 0.153  0.6334 0.03  ]
# —— 页面 3 只链接自己(自环陷阱), beta=0.85 的跳转率限制了它的吸收能力,
#    但它仍夺得最高权重 0.63 —— 这正是"必须加跳转"的直观证据;
#    页面 2 被 0、1、4 三个页面指向, 在非陷阱节点中权重最高 (0.153)
```

## 4.9 常见误区与陷阱

1. **以为每个矩阵都有一组正交特征向量**。只有（正规矩阵，尤其对称/正交阵）才保证；一般矩阵的特征向量可以高度病态（接近平行），甚至不可对角化（例 4.2）。数值代码对一般阵用 `eig`、对称阵用 `eigh`，后者又快又稳。
2. **混淆代数重数与几何重数**。$\lambda$ 重复 $k$ 次不代表有 $k$ 维特征空间；Jordan 块就是"重根但没有足够的特征向量"。
3. **对非对称矩阵用幂法不加处理**。可能不收敛（复特征值导致振荡）或收敛到错误对；工程上要用 Krylov 子空间方法（`scipy.sparse.linalg.eigs`，基于 Arnoldi 迭代）。
4. **PageRank 忘记处理死端与陷阱**。不加 $\beta$ 跳转时，平稳分布可能不存在或依赖初值；$\beta$ 不是魔法参数，它同时修复概率守恒、唯一性与谱隙（收敛速度）。
5. **把对称矩阵的正交对角化 $Q\Lambda Q^\top$ 与 SVD 混为一谈**。对称**正定**时二者一致；对称不定时 SVD 要对 $|\lambda|$ 排序并翻转负特征值列的符号；非对称时完全不同。混淆会在"取最大奇异向量 = 取主特征向量"时出错（仅对半正定对称阵成立，如协方差矩阵）。

## 4.12 进阶方向

- **Krylov 子空间方法**：Lanczos（对称）与 Arnoldi（一般）迭代是幂法的"聪明升级"，是现代大规模特征问题与共轭梯度法的共同骨架；《最优化方法》将用到其近亲。
- **谱图论与图神经网络**：图拉普拉斯的谱、Cheeger 不等式、谱聚类与 GCN 谱视角的关系；需补图论与《深度学习》GNN 章节。
- **Perturbation theory（扰动理论）**：特征值对矩阵扰动的敏感度（Davis–Kahan $\sin\theta$ 定理），是"子空间估计何时可信"的现代答案，统计学与分布式优化的基础工具。
- **随机矩阵谱**：大维随机矩阵特征值分布（Marchenko–Pastur 律），解释高维神经网络的"谱异常"与初始化设计；需测度论与概率极限理论。
