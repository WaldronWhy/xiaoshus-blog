# 第 99 章 综合项目 —— 把六章串成一套功夫

> **本章定位**：本课程的收官实战。三个项目分别对应第 3 章（SVD/PCA）、第 4 章（谱方法/PageRank）、第 6 章（数值对比实验），每个项目都要求"从零实现 + 库对照 + 实验报告"。完成它们即完成从"看懂"到"会做"的跨越，并直接预热《机器学习》课程的相关实验。

## 0.0 学习目标

完成本章全部项目后，你能够：

1. 独立从零实现一个机器学习经典算法（PCA），并用可视化验证其数学性质；
2. 在真实图结构上实现谱迭代算法（PageRank）并分析其收敛行为；
3. 设计并执行对照实验，用数据回答"哪种数值算法更好、好在哪、为什么"；
4. 按工程规范组织代码：模块化、随机种子、断言自检、结果可复现。

**统一工程要求**（三个项目共同遵守）：

- Python 3.10+，只依赖 numpy / scipy / matplotlib / scikit-learn；
- 每个随机实验固定 `seed` 并在报告中说明；
- 关键步骤用断言自检（如 `assert np.allclose(...)`）；
- 每个项目产出一个 `report.md`（≤ 2 页）与可运行脚本；
- "从零实现"意味着不得调用对应的 `np.linalg`/`sklearn` 高层函数完成主体算法，但**必须**调用它们做对照验证。

## 项目一：从零实现 PCA 并在手写数字数据集上可视化

**对应章节**：第 3 章 3.4–3.5（SVD、低秩近似、Eckart–Young）、第 4 章 4.5（Rayleigh 商）、第 6 章 6.3（中心化与缩放）。

### 任务分解

1. **数据准备**：`sklearn.datasets.load_digits`（1797 个样本 × 64 维）。**先去均值**（每列减均值），可选按标准差缩放；对比"未中心化直接做 SVD"的第一主成分——它会被什么方向霸占？为什么？（第 3 章陷阱 4 的兑现。）
2. **从零实现**：只允许用 `np.linalg.svd` 获取奇异值/向量（也可以更进一步：用第 4 章幂法 + 收缩（deflation）自行求前 $k$ 个奇异对，作为挑战层）。输出：主成分矩阵 $V_k$、投影坐标 $X_c V_k$、解释方差比 $\sigma_i^2 / \sum_j \sigma_j^2$。
3. **性质验证**（断言 + 打印）：
   - 投影坐标的两两协方差近似为零（主成分互不相关——为什么必然？提示：$V_k$ 正交）；
   - 前 2 个主成分的解释方差比之和打印出来（预期约 0.28–0.32）；
   - 截断秩 $r$ 重构的相对误差与 $\sqrt{\sum_{i>r}\sigma_i^2}/\|X_c\|_F$ 一致（Eckart–Young 实证）。
4. **可视化**：(a) 前 2 主成分散点图，按数字 0–9 着色，观察哪些数字可分、哪些混叠；(b) 前 8 个主成分的"特征图"（把 $v_i$ reshape 成 8×8 灰度图）——它们像不像笔画原型？(c) 取 $k = 1, 2, 4, 8, 16, 32$ 的重构图像拼图。
5. **库对照**：用 `sklearn.decomposition.PCA` 复算投影坐标，与你的实现做符号对齐后比对（注意主成分符号不唯一，第 3 章陷阱 2），要求 `np.allclose` 在列符号翻转后成立。

### 验收标准

- [ ] 脚本可一键运行，固定 seed，所有断言通过；
- [ ] 报告包含：解释方差谱图（肘部在几？）、2D 散点图、重构误差 vs 秩曲线（与 Eckart–Young 理论线重合）；
- [ ] 能口头回答：为什么"协方差矩阵特征向量"与"数据矩阵右奇异向量"等价？（第 3 章 3.4 + 第 4 章谱定理）。

### 提示与台阶

- 投影协方差为零的证明：$\mathrm{Cov}(XV_k) = V_k^\top (X_c^\top X_c) V_k / (m-1) = \Lambda_k/(m-1)$ 是对角阵；
- 挑战层（幂法版）：每求出一个主成分，从数据中减去其外积投影再继续（deflation）；注意数值误差累积，迭代 10 步内重正交化（修正 Gram-Schmidt，第 3 章案例 1）。

## 项目二：从零实现幂法迭代求 PageRank

**对应章节**：第 4 章 4.6（幂法、PageRank、Perron–Frobenius）、第 6 章 6.5 案例 C（收敛监控）。

### 任务分解

1. **图数据**：(a) 内置玩具图（本章代码的 5 节点图，用于对答案）；(b) 生成一个 $n = 2000$ 的随机有向图（每对节点以 $p = 0.01$ 概率连边，另加 10% 的"热门节点"被所有人链接）；(c) 挑战层：下载真实数据集，如 Stanford SNAP 的 wiki-Vote（约 7115 节点、10 万边）。
2. **从零实现**：输入邻接结构，构造列随机矩阵 $M$（处理死端：无出链节点按均匀分布摊派），加 $\beta$ 跳转得 $G$；**稀疏实现**（`scipy.sparse`，不要构造稠密 $G$——$n=2000$ 稠密还行，wiki-Vote 稠密就要 400MB×3）；幂法迭代 $\pi_{t+1} = G\pi_t$，每步归一化，残差 $\|G\pi_t - \pi_t\|_1 < 10^{-10}$ 停止。
3. **验证与实验**：
   - 与 `np.linalg.eig(G)`（玩具图）和 `networkx.pagerank`（大图，若安装了 networkx）对照，最大绝对差 $< 10^{-8}$；
   - 记录每步残差，画半对数收敛曲线；对 $\beta = 0.5, 0.85, 0.95, 0.99$ 各跑一次，验证斜率 $\approx \log_{10}\beta$（谱隙 = $\beta$ 的实证）；
   - 报告 Top-10 节点及其入链数，解释"链接多 ≠ 排名高"的例子（链接来源的权威度也重要——递归定义的胜利）。
4. **消融实验**：去掉 $\beta$ 跳转会发生什么？构造一个含吸收团（如两个互链的死端节点）的图，展示朴素随机游走的质量去向，说明 Google 矩阵修补的两个问题。

### 验收标准

- [ ] 玩具图结果与手算/`eig` 一致；
- [ ] $n = 2000$ 图上幂法在 200 次迭代内收敛（$\beta = 0.85$），稀疏内存占用有数字记录；
- [ ] 收敛曲线与理论斜率定量吻合（报告拟合斜率 vs $\log_{10}\beta$ 的表）；
- [ ] 报告回答：幂法每步代价是多少（$O(\mathrm{nnz})$）？为什么比直接特征分解（$O(n^3)$）现实？

### 提示与台阶

- 稀疏幂法核心一行：`pi_new = beta * (M @ pi) + (1 - beta) / n`（$M$ 稀疏、$pi$ 稠密向量——永远不要稠密构造 $G$）；
- 死端处理建议单独一列函数，输出处理前后的列和诊断；
- 挑战层：把 PageRank 扩展为个性化 PageRank（跳转分布换成某节点集合的指示分布），这是《知识表示与推理》知识图谱与图特征抽取（如 PinSage、GraphSAGE 的邻居采样权重）的常用组件。

## 项目三：正规方程 / QR / 梯度下降三解最小二乘的精度与速度对比

**对应章节**：第 2 章（复杂度）、第 3 章（正规方程与 QR）、第 5 章（梯度下降的梯度公式）、第 6 章（条件数与浮点现实）——三门课的会师点。

### 任务分解

1. **实验设计**：生成受控数据 $A = U\,\mathrm{diag}(s)\,V^\top$（$m = 500, n = 50$），通过 $s$ 的跨度精确控制 $\kappa(A) \in \{10^2, 10^4, 10^6, 10^8, 10^{10}, 10^{12}\}$；真解 $x^* \sim \mathcal{N}(0, I)$，$b = Ax^* + \epsilon$（噪声水平 0 与 $10^{-3}$ 两档各做）。
2. **三种解法**：
   - 正规方程：`np.linalg.solve(A.T @ A, A.T @ b)`；
   - QR：`scipy.linalg.qr` 后三角回代（或从零实现 MGS-QR，调用第 3 章代码）；
   - 梯度下降：固定步长 $t = 1/L$，$L = \|A\|_2^2$（用最大奇异值估计），迭代至梯度范数 $< 10^{-10}$ 或 10 万步上限；记录迭代数。
3. **测量指标**：解误差 $\|\hat x - x^*\|/\|x^*\|$、目标函数值 $\|A\hat x - b\|$、墙钟时间（取 10 次中位数）、（GD）迭代数。
4. **预期图景**（你的实验应复现它，否则先查 bug）：
   - $\kappa \le 10^6$、无噪声：三法误差都 $\lesssim \kappa\varepsilon$；
   - $\kappa \ge 10^8$：正规方程误差开始 $\approx \kappa^2\varepsilon$ 恶化，QR 保持 $\approx \kappa\varepsilon$；
   - GD 误差以 $O(\rho^t)$ 速率收敛，$\rho = \frac{\kappa - 1}{\kappa + 1}$——$\kappa = 10^{12}$ 时几乎不收敛（这正是《最优化方法》讲共轭梯度/预条件的动机）；
   - 速度：正规方程最快（$O(mn^2)$ 但对小 $n$ 常数小）、QR 次之、GD 最慢（迭代数 $\propto \kappa$）——**"快而脆 vs 慢而稳"的完整光谱**。
5. **报告要求**：一张 $\kappa \times$ 方法 的误差热力图（`matplotlib imshow`，对数色标）、一张"GD 迭代数 vs $\kappa$"的对数图（理论斜率 $\log_{10}\rho$ 对照）、300 字结论段：给工程实践写出三条决策规则。

### 验收标准

- [ ] 六个条件数 × 2 噪声档 × 3 方法 = 36 组结果齐全且可复现（seed 固定）；
- [ ] 误差-条件数关系与理论线（$\varepsilon\kappa$、$\varepsilon\kappa^2$）在图上定量吻合（相差不超过一个数量级）；
- [ ] 结论段包含何时可用正规方程的明确判断（例如：$n$ 小、$\kappa$ 已知 $\le 10^6$、且只是一次性计算）；
- [ ] 挑战层：把 GD 换成 Nesterov 加速或共轭梯度法，展示迭代数下降并解释其复杂度意义（《最优化方法》的前菜）。

### 提示与台阶

- GD 的步长上界：凸二次最小二乘的收敛要求 $0 < t < 2/L$；取 $t = 1/L$ 时收敛率恰为 $\rho$；
- $L$ 的估计用幂法求 $\|A\|_2 = \sigma_{\max}$（项目二的代码复用！）——三个项目在此互相调用；
- 对照实验要控制变量：三种方法用同一份 $(A, b, x^*)$；时间测量排除首次 BLAS 热身（先跑一次丢弃）。
