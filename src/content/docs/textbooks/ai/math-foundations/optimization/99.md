# 综合项目：最优化方法的实验场

> **本章定位**：本课程的收官实践章。三个综合项目分别打通"确定性优化（第 2、3 章）""随机优化与调参（第 5 章）""约束优化与对偶（第 4 章）"。每个项目给出任务分解、验收标准与提示；项目彼此独立，可按学过的章节顺序依次做，也可选做两个以上。前置要求：至少完成第 2 章与对应项目的理论章节。

## 0.0 项目总则

- **环境**：Python 3.9+，`numpy`、`matplotlib`、`scipy`、`scikit-learn`；项目三另需 `cvxpy`（`pip install cvxpy`）。
- **通用要求**：所有随机实验固定种子；所有图有轴标签与图例；报告以"数据 → 图 → 结论"三段式呈现，结论必须回指课程定理（如"经验收敛因子 0.95，与定理 2.5 的 $1-1/\kappa = 0.95$ 一致"）。
- **交付物**：可运行的单文件脚本（或 notebook）+ 300–800 字实验报告（Markdown）。
- **评分维度建议**：正确性（代码可复现、数值对得上理论）60%，分析深度（解释现象、连接课程概念）30%，呈现质量 10%。

## 项目一：在 Rosenbrock 函数上对比 GD / 动量 / Adam / BFGS 的轨迹与收敛速度

**一句话目标**：在著名的"香蕉谷"函数上让四种优化器同场竞技，用轨迹图 + 收敛曲线 + 步数表讲清"曲率信息的价值"。

### 1.1 背景与理论回顾

Rosenbrock 函数：

$$
f(x, y) = (1-x)^2 + 100\,(y - x^2)^2, \qquad \text{全局最优 } x^\star = (1, 1),\; f^\star = 0.
$$

它是测试优化器的标准地形：谷底弯曲（病态且曲率沿谷变化）、谷壁陡峭（限制步长）、最优在一个"香蕉形"峡谷深处。相关章节：第 2 章（梯度法与线搜索）、第 3 章（动量/NAG/拟牛顿）、第 5 章（Adam 的确定性退化版本：小批量梯度换成全量梯度）。

### 1.2 任务分解

1. **任务 A（基础设施）**：实现 $f$、$\nabla f$（手推并用有限差分验证：$\|\nabla_{\text{数值}} - \nabla_{\text{解析}}\|_\infty < 10^{-6}$）。
2. **任务 B（四种优化器）**：各自实现，统一接口 `opt(theta0, f, grad, K) -> thetas`：
   - GD：固定步长 + 回溯线搜索两个版本（对比）；
   - 动量（重球法，式 3.1）：$\eta = 10^{-3}$，$\beta \in \{0.5, 0.9, 0.99\}$；
   - Adam（式 5.12，用全量梯度）：$\eta = 0.01$ 或 $0.1$，标准 $\beta_1, \beta_2$；
   - BFGS：可用 `scipy.optimize.minimize(method='BFGS')` 并用 callback 记录轨迹（也可手写秩二更新，加分项）。
3. **任务 C（实验）**：统一起点 $(-1.2, 1.0)$，预算 $K = 10^4$ 次梯度求值（BFGS 按其函数求值数计）；记录每次迭代的 $f$、$\|x_k - x^\star\|$、梯度求值次数。
4. **任务 D（可视化）**：
   - 等高线（$\log_{10} f$）+ 四条轨迹叠加图；
   - 半对数收敛曲线 $f(x_k) - f^\star$ vs 迭代次数（另一张 vs 梯度求值次数——体现"每步代价"差异）。
5. **任务 E（分析）**：回答——(a) 为什么 GD/动量在弯谷中 zigzag 而 BFGS 几十步直达？(b) Adam 的自适应步长在确定性 Rosenbrock 上表现如何，与第 5 章"Adam 适合随机场景"的说法是否一致？(c) 动量 $\beta$ 从 0.5 调到 0.99 发生了什么（结合 $1/(1-\beta)$ 有效记忆解释）？

### 1.3 验收标准

- [ ] 梯度解析式通过有限差分验证；
- [ ] 至少一种配置（如 BFGS 或调好的动量）达到 $f < 10^{-10}$；
- [ ] GD（固定步长）在默认 $\eta = 10^{-3}$ 下 $10^4$ 步仍未达 $10^{-4}$（应能复现"谷底蠕动"）；
- [ ] 两张图（轨迹 + 收敛曲线）信息完整、可读；
- [ ] 报告至少引用 2 个课程定理/公式解释观察到的现象。

### 1.4 提示

- Rosenbrock 谷壁曲率极大（Hessian 特征值可超 1000），固定步长上限约为 $10^{-3}$ 量级——这正是"谷壁限制步长"的直接体现；
- 动量在弯谷中可能出现"冲出谷壁"的爆炸：把 $\eta$ 与 $\beta$ 一起缩放（$\beta$ 越大 $\eta$ 越小）是常见对策；
- 想画"每步实际步长"曲线（$\|x_{k+1} - x_k\|$）观察 BFGS 的大步与 GD 的小步对比，非常直观。

## 项目二：从零实现 Adam，在逻辑回归上与 SGD 对比并做调参敏感性分析

**一句话目标**：亲手实现 Adam 的五条更新式，用受控实验回答"Adam 到底比 SGD 好在哪、何时反而不如"。

### 2.1 背景与理论回顾

第 5 章式 (5.12)。实验对象：二分类逻辑回归（凸、光滑但可能病态），数据用 `sklearn.datasets`（`make_classification` 或手造高斯），损失与梯度见第 1 章例 1.2 与第 5 章 5.8.2。要求**从零实现**（不许调 `torch.optim`），以理解每个部件。

### 2.2 任务分解

1. **任务 A（基准实现）**：SGD、SGD+Momentum、Adam 三个优化器 + 逻辑回归损失/梯度/全量损失评估；实现"每个 epoch 记录一次全量损失与训练精度"的评估钩子。
2. **任务 B（Adam 部件消融）**：实现四个变体并同图对比（各跑 3 个种子取均值 ± 标准差）：
   - 完整 Adam；
   - 无偏差修正的 Adam；
   - 无二阶矩的 Adam（即 SGD+动量，$s \equiv 1$）；
   - 无一阶矩的 Adam（即 RMSProp，$m = g$）。
   目标：把 5.5.3 节"每个部件的目的"变成你自己的实验证据。
3. **任务 C（超参敏感性）**：对 SGD 与 Adam 各扫描 $\eta \in \{10^{-4}, 10^{-3}, 10^{-2}, 10^{-1}, 1\}$（Adam 的 $\eta$ 与 SGD 的 $\eta$ 不可直接比较——解释为什么），画"最终 epoch 损失 vs $\eta$"折线；对 Adam 再扫 $\beta_2 \in \{0.9, 0.99, 0.999, 0.9999\}$（构造一个梯度稀疏/尖峰的合成数据集放大差异）。
4. **任务 D（批量-学习率）**：固定 epoch 数，跑 $(B, \eta) \in \{(32, \eta_0), (128, 4\eta_0), (512, 16\eta_0)\}$ 验证线性缩放 (5.13)，再外推两档观察失效；实现一个简单的 warmup 并对比。
5. **任务 E（分析报告）**：用课程语言总结——Adam 的"绝对步长"性质（5.5.3）如何在你的 $\eta$ 敏感性图中体现；噪声地板（5.2.1）在固定 $\eta$ 长跑中是否出现。

### 2.3 验收标准

- [ ] 自实现 Adam 与 `scipy` 参考解（L-BFGS 求出的最优损失）差距在相同 epoch 预算下可解释；
- [ ] 消融图清晰显示：无偏差修正的 Adam 前期明显偏慢；无二阶矩版本对 $\eta$ 更敏感；
- [ ] $\eta$ 敏感性图上 SGD 与 Adam 的"稳定窗"宽度对比明显（并给出量化：如最大可用 $\eta$ 之比）；
- [ ] 线性缩放在前两档成立（最终损失差 < 5%）、在过外推档发散或变差；
- [ ] 报告包含至少一张"均值 ± 标准差"图（3 种子以上）。

### 2.4 提示

- 造病态数据：给特征乘不同量纲（$10^{-2} \sim 10^{2}$），病态让自适应方法优势凸显；再全部标准化重跑，看优势缩小——连接第 1 章例 1.1 与第 2 章 2.2 的条件数讨论；
- 验证 Adam 实现正确性的快速测试：把 $g_k$ 固定为常数向量 $g$，检查 $\theta$ 每步位移是否恒为 $\eta \cdot g/\sqrt{g^2}$（即符号梯度行为，5.5.3 的"量级守恒"性质）；
- 尖峰数据构造：1% 样本的标签随机翻转或特征尺度 ×100，观察 $\beta_2$ 大记忆效应。

## 项目三：用凸优化库求解 SVM 对偶问题，并手写验证 KKT 条件

**一句话目标**：把第 4 章 4.5 节的推导变成代码：cvxpy 解对偶 QP，恢复 $(w^\star, b^\star)$，逐条验证 KKT，并做"影子价格"实验。

### 3.1 背景与理论回顾

硬间隔对偶（式 4.11）：

$$
\max_{\lambda}\; \sum_i \lambda_i - \frac{1}{2}\sum_{i,j} \lambda_i \lambda_j y_i y_j\, x_i^\top x_j \quad \text{s.t.}\quad \sum_i \lambda_i y_i = 0,\;\; 0 \le \lambda_i\ (\text{硬});\ 0 \le \lambda_i \le C\ (\text{软}).
$$

KKT 四条见式 (4.6)；支持向量 = 互补松弛挑出的非零乘子样本；影子价格解释见 4.4.4 与 4.8.2 代码。

### 3.2 任务分解

1. **任务 A（数据与对偶建模）**：构造二维线性可分数据（建议每类 20–50 点，类中心距离可控）；用 cvxpy 按式 (4.11) 建模（注意 Gram 矩阵用 `psd_wrap` 或对称化处理数值细节），求解并报告 $d^\star$。
2. **任务 B（解的恢复与对照）**：由 $\lambda^\star$ 恢复 $w^\star$（式 4.9）与 $b^\star$（任一支持向量），与 `sklearn.svm.SVC(kernel='linear', C=很大)` 的结果对照（$\|w\|$ 相对误差 < $10^{-3}$，容差设置要匹配）。
3. **任务 C（KKT 逐条验证）**：打印四条各自的违例量：(a) 函数间隔 $\min_i y_i(w^\top x_i + b) \ge 1$；(b) $\lambda \ge 0$；(c) 互补松弛 $\lambda_i (1 - y_i(w^\top x_i + b)) \approx 0$ 的最大违例；(d) 平稳性（由构造自动满足，写明原因）。标出支持向量个数及其在图中的位置。
4. **任务 D（影子价格实验）**：对每个支持向量，沿 $w$ 方向把该点移动 $\delta \in \{0.01, 0.05, 0.1\}$（分别向内/向外），重解对偶，画"$\Delta d^\star$ vs $\delta$"并与预测 $\Delta d^\star \approx -\lambda_i^\star \delta$（符号按约束方向）对照；对非支持向量重复（应近似无变化）。
5. **任务 E（软间隔扩展，选做加分）**：加盒约束 $0 \le \lambda_i \le C$，扫 $C \in \{0.01, 0.1, 1, 10\}$，画"间隔宽度、支持向量个数、训练错分数 vs $C$"三条曲线，并验证分段互补松弛（第 4 章练习 5）。
6. **任务 F（核化预演，选做加分）**：把 Gram 矩阵换成 $k(x_i, x_j) = (x_i^\top x_j + 1)^2$（二次多项式核），重解对偶；由于 $w$ 不再显式存在，实现基于支持向量的预测函数 $h(x) = \operatorname{sign}\big(\sum_{i \in SV} \lambda_i y_i k(x_i, x) + b\big)$，与线性可分数据上用 `make_moons` 造的不可分数据的线性 SVM 对比准确率——亲手体会"对偶形式使核化零成本"。

### 3.3 验收标准

- [ ] 对偶 QP 求解收敛且 $d^\star$ 与 sklearn 对照的间隔一致；
- [ ] KKT 四条违例均在 $10^{-6}$ 量级（写明所用求解器容差）；
- [ ] 支持向量数量合理（远小于样本数）且图上标出；
- [ ] 影子价格图：支持向量上 $\Delta d^\star$ 与 $\delta$ 近似线性且斜率 $\approx \lambda_i^\star$（按方向定号），非支持向量上近似平坦；
- [ ] （选做 E/F 完成者）曲线与预测的单调性/准确率差异得到解释。

### 3.4 提示

- 数值容差是本项目的第一陷阱：判定支持向量用 `lam > 1e-5` 类阈值（第 4 章误区 4）；
- Gram 矩阵构造 `K = (X * y[:, None]) @ (X * y[:, None]).T` 后，除数值对称化外还要检查条件数（`np.linalg.cond`）——数据过近会导致 QP 病态、求解器报警；
- 影子价格的符号约定：约束 $1 - y_i(w^\top x_i + b) \le 0$ 的乘子 $\lambda_i$ 满足"放松约束（把点向对方推）使 $p^\star$ 下降"。做实验前先把方向约定写在报告里；
- 任务 F 中 `make_moons` 需要 $C$ 有限（软间隔）才能得到有意义的解——这正好把 E 与 F 串起来。

## 进阶变体库（在任一项目达标后选用）

**项目一的变体**：

1. **高维 Rosenbrock**（$d = 50, 100$）：验证 BFGS 内存瓶颈 → 自然引出 L-BFGS（可调 `scipy` 的 `maxcor` 参数看记忆长度 $m$ 的影响）；
2. **$\kappa$ 扫描**：把目标换成可控病态的二次函数族，画"达标步数 vs $\kappa$"双对数图，验证 GD 斜率 1 / NAG 斜率 0.5（对应课后思考挑战题 5）；
3. **线搜索对比**：Armijo vs 精确线搜索 vs 固定 $1/L$，三者在 Rosenbrock 上的每步开销与总步数权衡。

**项目二的变体**：

1. **合成可控数据**：手工设置 $X^\top X$ 的特征值谱（用正交矩阵混合对角阵，复习《线性代数》第 4 章），精确控制 $\kappa$，验证"自适应方法的优势随 $\kappa$ 增长"；
2. **稀疏场景**：90% 特征恒为零的样本（模拟词向量场景），复现 AdaGrad 的原始优势（Duchi 等 2011 的图 1 情境）；
3. **非凸延伸**：换一层隐层的神经网络 + `make_moons`，检验第 5 章结论哪些延续（Adam 初期更快）哪些反转（最终泛化），衔接第 6 章。

**项目三的变体**：

1. **SMO 实现**（替代 cvxpy）：按 Platt 1998 实现简化版 SMO（每次优化两个乘子），在 $n = 10^4$ 上与通用 QP 求解器比耗时；
2. **对偶间隙监控**：在对偶问题上加"原始点重建 + 次优性评估"，实现一个原始-对偶双重停机准则（对应第 4 章弱对偶的工程用途）；
3. **多分类扩展**：one-vs-rest 或 Crammer-Singer 结构，检验 KKT 验证代码的通用性。

每个变体都遵循同样的交付标准：可复现脚本 + 与课程理论的定量对照 + 一段分析。

4. 三个项目都要求固定随机种子。从"实验可信度"角度写 150 字：种子固定解决什么问题、不解决什么问题（提示：与《实验设计与评估》课程的假设检验衔接）。
5. **挑战题**：把项目一的四优化器对比做成对"病态度可控"的函数族（$f_\kappa = \frac{1}{2}(\mu x^2 + \kappa\mu y^2)$ 加弯曲项）的系统实验：画"达到 $10^{-6}$ 精度所需步数 vs $\kappa$"的双对数图，验证 GD 斜率 ≈ 1、动量/NAG 斜率 ≈ 1/2（对应 $\kappa$ 与 $\sqrt\kappa$ 依赖）——这是对第 3 章理论的定量复现。
6. **挑战题**：阅读 Bottou 等 2018 综述第 3 节，把项目二的实验协议升级为"按样本处理量归一"的公平比较，写一页方法论说明。

## 0.5 实验报告写作模板

每份报告按以下七段组织（300–800 字 + 图表）：

1. **目标与假设**：一句话复述实验目标；明确写下你预测会发生什么（带着预测做实验，才能被惊讶到）。
2. **实验设置**：数据/函数、优化器与超参数（以表格列出，注明默认值来源是课程哪一节）、随机种子、运行环境。
3. **结果**：图表按"先主后辅"排列；每图配一句"这张图说明什么"的图注。
4. **与理论对照**：把数值填进课程定理的公式（如理论收敛因子 vs 经验收敛因子），一致则确认、不一致则深究。
5. **异常与排查**：记录所有与预期不符的现象及你的排查过程（这部分往往是最有价值的）。
6. **结论**：不超过五条，每条要么回答任务中的分析问题，要么给出一个可操作的建议。
7. **复现说明**：一条命令能跑出全部结果（`python proj1.py --seed 0`），这是工程素养的一部分。

**反模式清单**（出现即扣分）：只贴图不解读；把"loss 下降了"当结论；超参数没写全；用"显然"代替验证；用训练集表现谈泛化。

## 0.6 常见故障排查速查表

| 症状 | 可能原因 | 诊断动作 | 对应章节 |
|---|---|---|---|
| 损失变 NaN/Inf | 步长过大；梯度未裁剪；$\log$/$\div$ 未做数值稳定 | 打印梯度范数历史，找爆炸起点；检查 `logaddexp` 类实现 | 第 2 章 2.3、第 5 章 5.9 |
| 损失降到某水平后不再下降（震荡） | 噪声地板；固定 $\eta$ | 换衰减调度重跑，对比曲线 | 第 5 章 5.2.1 |
| 损失长时间完全不动 | 鞍点/对称陷阱；死激活；$\eta$ 过小 | 检查梯度范数是否 ≈ 0 且方向不乱；加噪声/扰动重跑 | 第 6 章 6.1.3、6.2 |
| loss 剧烈锯齿但趋势向下 | 批量太小噪声大；正常现象 | 增大批量或加动量，看是否平滑且更快 | 第 5 章 5.4 |
| KKT 检查违例很大 | 支持向量判定阈值太紧；$b$ 恢复用了错样本；QP 未收敛 | 放宽阈值到 $10^{-5}$；用间隔上的样本求 $b$；检查求解器状态 | 第 4 章 4.8.2、4.9 |
| cvxpy 报 DCP error | 目标/约束违反凸性组合规则 | 检查是否"凸 - 凸"、对凹函数取了 max 等；用上镜图变形 | 第 1 章 1.5、1.1.3 |
| Adam 跑着跑着步长骤停 | 梯度尖峰进入二阶矩长记忆 | 调小 $\beta_2$（如 0.95）或加梯度裁剪 | 第 5 章 5.9 |
| 线性缩放外推直接发散 | 超过临界批量仍放大 $\eta$；缺 warmup | 加 warmup 或停止放大 $\eta$ | 第 5 章 5.6 |

## 0.11 代码与协作规范（小组完成时）

- 每人认领明确的模块（如优化器实现 / 实验脚本 / 可视化），接口先于实现：先冻结 `opt(theta0, f, grad, K) -> thetas` 这类签名；

## 0.12 项目 FAQ

**Q1：可以用 PyTorch/JAX 里的现成优化器吗？**
项目二明确要求从零实现（理解机制）；项目一的 BFGS 允许调 `scipy`（工程用法对照是规范第三条的另一半）。原则：课程考察的"实现目标"逐项目写明，其余鼓励"从零 + 调库"双轨对照。

**Q2：结果和理论对不上，先怀疑理论还是代码？**
先代码（用热身任务的梯度检查器排除 90% 的错误），再查理论适用条件（凸？强凸？步长范围？L 的取值？），最后才考虑"理论不刻画的现象"（如非凸地形效应）——这个排查顺序本身就是课程想要训练的推理习惯。

**Q3：实验图太多怎么取舍？**
报告正文最多 3–4 张图：一张主结果（收敛曲线）、一张轨迹/可视化、一张敏感性对比，其余放附录。图服务于论点，不是工作量证明。

**Q4：三个项目只做完两个够吗？**
按 0.4 节的考核建议，两个（含任务全部必做项）即达标；三个全做且含各一个选做扩展，可作为课程满分的作品集。

**Q5：需要 Git/版本管理吗？**
单人完成可用"每次实验一个目录 + 结果文件带参数摘要"的最简方案；小组完成必须用 Git（见 0.11 节）。这正是《模型部署与 MLOps》课程的预演。

**Q6：图是用 matplotlib 还是别的？**
课程统一 matplotlib（规范要求的零门槛依赖）；会用 seaborn/plotly 者可用，但交付物必须能在纯 matplotlib 环境复现。
