# 第 4 章 约束优化与对偶理论

> **本章定位**：从无约束走向约束。建立拉格朗日函数、对偶问题、弱/强对偶、Slater 条件与 KKT 条件的完整理论，并以硬间隔 SVM 为贯穿案例（原问题 → 对偶问题 → KKT → 支持向量）。对偶与 KKT 是《机器学习》SVM/核方法章的数学地基。前置：第 1 章凸性（切线不等式 (1.3) 与凸函数库反复出场）；《高等数学》第 5 章拉格朗日乘数法初步（本章是其完整版与升级版）。

## 4.0 本章学习目标

学完本章，你能够：

1. 对给定约束优化问题写出拉格朗日函数与对偶问题，并独立证明弱对偶性；

## 4.1 回顾与升级：从拉格朗日乘数法到一般约束问题

《高等数学》第 5 章你学过：等式约束问题 $\min f_0(x)$ s.t. $h_j(x) = 0$ 的驻点满足 $\nabla f_0 = \sum_j \nu_j \nabla h_j$（拉格朗日乘数法）。本章处理第 1 章式 (1.1) 的完整问题：

$$
\min_{x}\; f_0(x) \quad \text{s.t.}\quad f_i(x) \le 0\ (i=1,\dots,m), \qquad h_j(x) = 0\ (j=1,\dots,p). \tag{4.1}
$$

记可行域 $D$、最优值 $p^\star$（primal，原问题）。约定 $D \ne \emptyset$（否则 $p^\star = +\infty$）。

### 4.1.1 拉格朗日函数

引入**拉格朗日乘子（Lagrange multipliers）** $\lambda = (\lambda_1, \dots, \lambda_m)$（不等式约束）与 $\nu = (\nu_1, \dots, \nu_p)$（等式约束），定义**拉格朗日函数（Lagrangian）**：

$$
\mathcal{L}(x, \lambda, \nu) \;=\; f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{j=1}^p \nu_j h_j(x), \qquad \lambda_i \ge 0. \tag{4.2}
$$

关键约定是 $\lambda \ge 0$：对可行点（$f_i(x) \le 0$），每项 $\lambda_i f_i(x) \le 0$，因此对一切可行 $x$ 与一切 $\lambda \ge 0$：

$$
\mathcal{L}(x, \lambda, \nu) \;\le\; f_0(x). \tag{4.3}
$$

即**拉格朗日函数是目标函数在可行域上的下界族**——乘子每取一个值，就得到一个（可能很松的）下界。整个对偶理论就是"如何把这套下界收紧"的故事。

## 4.2 对偶函数与对偶问题

### 4.2.1 对偶函数：最好的下界

**定义 4.1（对偶函数，dual function）**。把拉格朗日函数对 $x$ 取下确界：

$$
g(\lambda, \nu) \;=\; \inf_{x \in \mathbb{R}^n} \mathcal{L}(x, \lambda, \nu). \tag{4.4}
$$

由式 (4.3)，对一切 $\lambda \ge 0$、$\nu$ 任意：$g(\lambda, \nu) \le \inf_{x \in D} f_0(x) = p^\star$。即**每个 $(\lambda, \nu)$ 都给出 $p^\star$ 的一个下界**。

两个立即可得的性质（都调用第 1 章凸函数库）：

1. **$g$ 恒为凹函数**（无论原问题是否凸）：$g$ 是 $\mathcal{L}$（仿射于 $(\lambda,\nu)$ 的函数族）的逐点下确界，由第 1 章 1.5 节运算 4（偏最小化保持凸性、其镜像版本保持凹性）得到。这解释了为什么对偶问题总是一个凸优化问题。
2. **$g$ 可以取 $-\infty$**：当 $\mathcal{L}$ 对 $x$ 无下界时。所以对偶问题的可行域自带"淘汰无效乘子"的机制。

### 4.2.2 对偶问题：下界的最大化

既然每个乘子给一个下界，自然要找**最好的下界**：

$$
\boxed{\;d^\star = \max_{\lambda, \nu}\; g(\lambda, \nu) \quad \text{s.t.}\quad \lambda \ge 0\;} \tag{4.5}
$$

这是**对偶问题（dual problem）**。它是一个凸问题（最大化凹函数 $g$，约束仿射）。由上面的推导立得：

**定理 4.2（弱对偶性，weak duality）**。$d^\star \le p^\star$，恒成立，与凸性无关。

差值 $p^\star - d^\star \ge 0$ 称为**对偶间隙（duality gap）**。弱对偶性的两个即时应用：（a）任何可行 $(\lambda, \nu)$ 给出最优值的可验证下界与停机准则（工程中求解器打印的 "gap" 就是它）；（b）证明某些问题无解（$p^\star = +\infty$ 时对偶不可行，反之亦然）。

**例 4.3（对偶函数的计算）**。约束问题 $\min e^{-x}$ s.t. $x^2 + y^2 \le 1$（非凸约束！）。拉格朗日函数 $\mathcal{L} = e^{-x} + \lambda(x^2 + y^2 - 1)$。对 $x$、$y$ 分别取下确界：$\inf_y (x^2 + y^2 - 1)$ 在 $y=0$ 处为 $x^2 - 1$，所以

$$
g(\lambda) = \inf_x \big(e^{-x} + \lambda x^2 - \lambda\big) = -\lambda + \inf_x \big(\lambda x^2 + e^{-x}\big).
$$

内层问题（$\lambda > 0$）可导：$\lambda' \colon 2\lambda x = e^{-x}$，故 $x = -\frac{1}{2}W(2/\lambda)$（Lambert W 函数）。可见即使原问题非凸，对偶函数也常常是光滑好算的——"对偶比原问题好解"是对偶的重要工程动机。

## 4.3 强对偶与 Slater 条件

**定义 4.4（强对偶性，strong duality）**。若 $d^\star = p^\star$（对偶间隙为零），称强对偶成立。

强对偶**不是普适的**，但有一类易于验证的充分条件：

**定理 4.5（Slater 条件）**。若原问题是凸问题（$f_0, f_i$ 凸、$h_j$ 仿射），且存在严格可行点 $\tilde{x}$：$f_i(\tilde{x}) < 0$（不等式约束严格满足；仿射等式只需可行），则强对偶成立，且对偶最优值可在某组乘子处取到。

直觉解释（几何版）：凸函数 $f_0$ 的图像与非凸可行域之外的区域之间存在一条**分离超平面**；Slater 条件保证两集合不"贴死"，从而这条超平面存在有限斜率——其斜率恰是乘子 $(\lambda^\star, \nu^\star)$。深层的代数表述是凸分析中的 Fenchel 对偶与分离定理（Boyd & Vandenberghe 第 5 章），本课程接受定理叙述并聚焦其应用。

注意细节：对仿射不等式约束（如线性规划），Slater 可以减弱为"可行即可"；SVM 的硬间隔问题恰属于这类（等式/仿射约束为主），见 4.5 节。

## 4.4 KKT 条件：完整推导

### 4.4.1 条件的内容

对凸问题（假设 4.5 成立，即强对偶 + 乘子可达），称 $x^\star$ 与 $(\lambda^\star, \nu^\star)$ 满足 **Karush–Kuhn–Tucker（KKT）条件**：

$$
\begin{aligned}
&\text{(a) 原始可行：} && f_i(x^\star) \le 0,\quad h_j(x^\star) = 0; \\
&\text{(b) 对偶可行：} && \lambda_i^\star \ge 0; \\
&\text{(c) 互补松弛：} && \lambda_i^\star\, f_i(x^\star) = 0, \quad i = 1, \dots, m; \\
&\text{(d) 拉格朗日平稳：} && \nabla_x \mathcal{L}(x^\star, \lambda^\star, \nu^\star) = \nabla f_0(x^\star) + \sum_i \lambda_i^\star \nabla f_i(x^\star) + \sum_j \nu_j^\star \nabla h_j(x^\star) = 0.
\end{aligned} \tag{4.6}
$$

### 4.4.2 必要性推导（$x^\star$ 最优 $\Rightarrow$ KKT）

设强对偶、$x^\star$ 与 $(\lambda^\star, \nu^\star)$ 分别达到 $p^\star$ 与 $d^\star$。

**第一步**。由 $g(\lambda^\star, \nu^\star) \le \mathcal{L}(x^\star, \lambda^\star, \nu^\star) \le f_0(x^\star) = p^\star = d^\star = g(\lambda^\star, \nu^\star)$，全链条必须取等。于是 $\mathcal{L}(x^\star, \lambda^\star, \nu^\star) = f_0(x^\star)$。

**第二步（得互补松弛）**。$\mathcal{L}(x^\star, \lambda^\star, \nu^\star) = f_0(x^\star) + \sum_i \lambda_i^\star f_i(x^\star) + \sum_j \nu_j^\star \cdot 0$（$h_j(x^\star) = 0$）。与 $f_0(x^\star)$ 相等要求 $\sum_i \lambda_i^\star f_i(x^\star) = 0$；而每一项都 $\le 0$（式 4.3），非负数求和为零 $\Rightarrow$ 每一项为零，即条件 (c)。

**第三步（得平稳性）**。由全链条取等还知：$x^\star$ 达到 $g(\lambda^\star, \nu^\star) = \inf_x \mathcal{L}(x, \lambda^\star, \nu^\star)$ 的下确界。又因 $\mathcal{L}(\cdot, \lambda^\star, \nu^\star)$ 是凸函数（$f_0, f_i$ 凸、$h_j$ 仿射的加权和），由第 1 章练习 4（凸函数全局最优判据），极小点满足梯度为零，即条件 (d)。$\blacksquare$

### 4.4.3 充分性推导（KKT $\Rightarrow$ $x^\star$ 全局最优）

设 $(x, \lambda, \nu)$ 满足 (a)–(d)，问题凸。对任意可行 $z$：

$$
f_0(z) \;\overset{(1)}{\ge}\; \mathcal{L}(z, \lambda, \nu) \;\overset{(2)}{\ge}\; \mathcal{L}(x, \lambda, \nu) \;\overset{(3)}{=}\; f_0(x).
$$

依据：(1) 式 (4.3)（$z$ 可行、$\lambda \ge 0$）；(2) $\mathcal{L}(\cdot, \lambda, \nu)$ 凸且在 $x$ 处梯度为零（条件 d）$\Rightarrow$ $x$ 是其全局极小点；(3) 互补松弛 (c) 使罚项消失。故 $x$ 全局最优。$\blacksquare$

**结论**：对 Slater 正则的凸问题，KKT 是**充要的**全局最优刻画——把"解优化问题"转化为"解方程组/不等式组"。这是凸优化的第一重要性所在。

### 4.4.4 几何解释与影子价格

互补松弛的几何语言：$\lambda_i^\star > 0$ 当且仅当第 $i$ 个约束在最优解处**贴紧**（$f_i(x^\star) = 0$，称为**紧约束/积极约束**，active constraint）；松约束（$f_i(x^\star) < 0$）对应 $\lambda_i^\star = 0$——**不挡路的约束不收费**。

经济学解释：$\lambda_i^\star = -\frac{\partial p^\star}{\partial b_i}$ 型的敏感度（当约束写成 $f_i(x) \le b_i$ 时，可证 $\partial p^\star / \partial b_i = -\lambda_i^\star$，在可微情形）。$\lambda_i^\star$ 是"放松第 $i$ 个约束一个单位，目标能改善多少"——**影子价格（shadow price）**。例如"预算约束"的乘子告诉你多一元钱能多赚多少；"算力上限约束"的乘子告诉你再买一张卡值不值。这正是对偶在运筹学/经济学中的独立价值，与机器学习中的核化（4.6.2）并列为对偶的两大用途。

## 4.5 贯穿案例：硬间隔 SVM 的完整链条

### 4.5.1 原问题

训练数据 $\{(x_i, y_i)\}_{i=1}^n$，$y_i \in \{\pm 1\}$，线性可分。几何目标：找分离超平面 $w^\top x + b = 0$，使两侧**间隔（margin）**最大。间隔为 $2/\|w\|_2$（《线性代数》第 1 章：点到超平面的距离），最大化间隔等价于最小化 $\frac{1}{2}\|w\|^2$，得到**原问题（P）**：

$$
\min_{w, b}\; \frac{1}{2}\|w\|^2 \quad \text{s.t.}\quad y_i(w^\top x_i + b) \ge 1,\; i = 1, \dots, n. \tag{4.7}
$$

整理成标准形式：目标凸（严格凸，强凸参数即 1），约束函数 $f_i(w, b) = 1 - y_i(w^\top x_i + b) \le 0$ 是仿射函数——**仿射约束下 Slater 减弱为可行即可**（线性可分保证可行），故强对偶成立、KKT 充要。这是一个二次规划（QP）。

### 4.5.2 拉格朗日函数与对偶问题

$$
\mathcal{L}(w, b, \lambda) = \frac{1}{2}\|w\|^2 - \sum_{i=1}^n \lambda_i\big[y_i(w^\top x_i + b) - 1\big], \qquad \lambda_i \ge 0. \tag{4.8}
$$

对偶函数 $g(\lambda) = \inf_{w, b} \mathcal{L}$。$\mathcal{L}$ 对 $w, b$ 是凸二次，取极小即梯度置零：

$$
\nabla_w \mathcal{L} = w - \sum_i \lambda_i y_i x_i = 0 \;\Rightarrow\; w = \sum_i \lambda_i y_i x_i; \qquad
\frac{\partial \mathcal{L}}{\partial b} = -\sum_i \lambda_i y_i = 0. \tag{4.9}
$$

代回式 (4.8)（逐项展开：$\frac{1}{2}\|\sum_i \lambda_i y_i x_i\|^2 - \sum_i \lambda_i y_i (\sum_j \lambda_j y_j x_j)^\top x_i - b\sum_i \lambda_i y_i + \sum_i \lambda_i$，前两项相差一个因子 2 而相消，$b$ 项由第二个条件消去）：

$$
g(\lambda) = \sum_{i=1}^n \lambda_i - \frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \lambda_i \lambda_j y_i y_j\, x_i^\top x_j . \tag{4.10}
$$

于是**对偶问题（D）**：

$$
\max_{\lambda}\; \sum_i \lambda_i - \frac{1}{2}\sum_{i,j} \lambda_i \lambda_j y_i y_j\, x_i^\top x_j \quad \text{s.t.}\quad \sum_i \lambda_i y_i = 0,\;\; \lambda_i \ge 0. \tag{4.11}
$$

### 4.5.3 从对偶读出 SVM 的三大特征

对式 (4.10)/(4.11) 逐条审视，SVM 的著名性质全部浮现：

1. **数据只以内积 $x_i^\top x_j$ 出现**：整个对偶问题只依赖 Gram 矩阵 $K_{ij} = x_i^\top x_j$。于是把 $x$ 换成任意特征映射 $\phi(x)$，只需把 $x_i^\top x_j$ 换成 $k(x_i, x_j) = \phi(x_i)^\top \phi(x_j)$（核函数）——**对偶形式是 SVM 可核化的原因**。这将在《机器学习》核方法章全面展开（Mercer 条件、核技巧、高斯核）。
2. **解是支持向量的展开**：由式 (4.9)，$w^\star = \sum_i \lambda_i^\star y_i x_i$——最优超平面是训练样本的线性组合，权重是乘子。
3. **互补松弛挑出支持向量**：$\lambda_i^\star[y_i(w^{\star\top} x_i + b) - 1] = 0$。乘子非零的样本恰好贴着间隔边界（$y_i(w^\top x_i + b) = 1$），称为**支持向量（support vectors）**；远离边界的样本乘子为零、对解无贡献。间隔中间的点、错分点（软间隔情形）也都对应正乘子。

$b^\star$ 由任一支持向量代入 $y_i(w^{\star\top}x_i + b^\star) = 1$ 求出。求解对偶 QP（SMO 算法或通用 QP 求解器）后即可预测：$h(x) = \operatorname{sign}\big(\sum_{i \in SV} \lambda_i^\star y_i\, k(x_i, x) + b^\star\big)$。

**软间隔（C-SVM）一句话版**：把约束放松为 $y_i(w^\top x_i + b) \ge 1 - \xi_i$、$\xi_i \ge 0$，目标加 $\frac{C}{1}\sum \xi_i$，重复本节推导得对偶 (4.11) 加上盒约束 $0 \le \lambda_i \le C$，KKT 互补松弛变为分段形式（$\lambda_i = 0 \Leftrightarrow$ 正分样本；$0 < \lambda_i < C \Leftrightarrow$ 恰在间隔上；$\lambda_i = C \Leftrightarrow$ 间隔内/错分）。完整推导见《机器学习》SVM 章，本章挑战题给出验证任务。

## 4.6 对偶的价值

### 4.6.1 影子价格与敏感度分析

4.4.4 节的敏感度解释在工程中无处不在：资源分配（预算/算力/带宽约束的乘子）、通信网络（拥塞价格 = 对偶乘子，互联网 TCP 拥塞控制可用对偶分解解释）、电力市场（节点电价 = 经济调度问题的拉格朗日乘子）。共性：**当约束系统需要与"价格信号"交互时，对偶不只是算法手段，而是建模语言**。大规模问题的**对偶分解**（dual decomposition）把耦合约束的乘子当作各子系统之间的"内部价格"做分布式协调——强化学习中的资源分配、联邦学习中的约束都用到。

### 4.6.2 核化：对偶打开的机器学习之门

4.5.3 节已看到：SVM 的一切学习信息浓缩在核矩阵 $K$ 中。更普遍的规律：**当算法的解与目标可以写成样本内积的函数时，它就可以被核化**。对偶是"把算法改写成只依赖内积"的系统方法——原问题含显式 $w$（在特征空间可能无穷维），对偶问题只含内积，有限维障碍消失。这解释了为什么 SVM 文献中"对偶"如此核心，而线性回归（其解 $w^\star = (X^\top X)^{-1}X^\top y$ 本身就是内积表达）则不需要走对偶。核化的边界也来自对偶：核矩阵 $n \times n$ 的内存与计算代价，决定了 SVM 难以扩展到百万级样本——工程取舍的根源。

## 4.8 示例与案例

### 4.8.1 手算算例：一个小 QP 的完整对偶链

问题：$\min_x\; \frac{1}{2}(x_1 - 1)^2 + \frac{1}{2}(x_2 - 2)^2$ s.t. $x_1 + x_2 \le 1$。（无约束最优 $(1, 2)$ 不可行，最优解必在约束边界上。）

**拉格朗日函数**：$\mathcal{L} = \frac{1}{2}(x_1-1)^2 + \frac{1}{2}(x_2-2)^2 + \lambda(x_1 + x_2 - 1)$，$\lambda \ge 0$。

**对偶函数**（$x_1$、$x_2$ 两项独立配方）：

- $\inf_{x_1}\big[\frac{1}{2}(x_1-1)^2 + \lambda x_1\big]$：驻点 $x_1 = 1 - \lambda$，代入值得 $\frac{\lambda^2}{2} + \lambda(1-\lambda) = \lambda - \frac{\lambda^2}{2}$；
- $\inf_{x_2}\big[\frac{1}{2}(x_2-2)^2 + \lambda x_2\big]$：驻点 $x_2 = 2 - \lambda$，值为 $2\lambda - \frac{\lambda^2}{2}$；
- 常数项 $-\lambda$。

故 $g(\lambda) = \big(\lambda - \frac{\lambda^2}{2}\big) + \big(2\lambda - \frac{\lambda^2}{2}\big) - \lambda = -\lambda^2 + 2\lambda$。

**对偶问题**：$\max_{\lambda \ge 0}\, -\lambda^2 + 2\lambda$，解 $\lambda^\star = 1$，$d^\star = 1$。

**KKT 恢复原解**：平稳性给出 $x_1^\star = 1 - \lambda^\star = 0$，$x_2^\star = 2 - \lambda^\star = 1$。验证：约束贴紧（$x_1^\star + x_2^\star = 1$）；$p^\star = \frac{1}{2}(0-1)^2 + \frac{1}{2}(1-2)^2 = 1 = d^\star$——强对偶、对偶间隙为零，KKT 全部成立。此例展示了"凸 + 仿射约束 → 强对偶 → 解一维对偶方程即可得原问题全局最优"的完整流程；影子价格为 $\lambda^\star = 1$（把约束放宽为 $x_1 + x_2 \le 1 + \epsilon$，$p^\star$ 恰好下降约 $\epsilon$，可自行验证）。

### 4.8.2 代码示例：cvxpy 求解 SVM 对偶并验证 KKT

```python
"""第 4 章：用 cvxpy 求解硬间隔 SVM 对偶问题，并用 numpy 逐条验证 KKT 条件。
运行环境：numpy, cvxpy（pip install cvxpy）。"""
import numpy as np
import cvxpy as cp

rng = np.random.default_rng(0)
# 构造线性可分的二维数据
n = 40
X_pos = rng.normal(loc=[2, 2], scale=0.7, size=(n // 2, 2))
X_neg = rng.normal(loc=[-2, -2], scale=0.7, size=(n // 2, 2))
X = np.vstack([X_pos, X_neg])
y = np.concatenate([np.ones(n // 2), -np.ones(n // 2)])

# ---------- 对偶问题 (4.11) ----------
lmbda = cp.Variable(n)
K = (X * y[:, None]) @ (X * y[:, None]).T        # Gram 矩阵 (y_i x_i)(y_j x_j)^T
obj = cp.Maximize(cp.sum(lmbda) - 0.5 * cp.quad_form(lmbda, cp.psd_wrap(K)))
cons = [lmbda >= 0, cp.sum(cp.multiply(lmbda, y)) == 0]
prob = cp.Problem(obj, cons)
prob.solve(solver=cp.CLARABEL)                   # 也可换 ECOS/SCS
lam = lmbda.value
print("对偶最优值 d* =", prob.value)             # 预期: >0 的有限值

# ---------- 从对偶解恢复原问题解 ----------
w = ((lam * y)[:, None] * X).sum(axis=0)         # w* = sum lambda_i y_i x_i
sv = lam > 1e-5                                   # 互补松弛：非零乘子 = 支持向量
b = np.mean(y[sv] - X[sv] @ w)                    # 由支持向量解 b*
print(f"支持向量个数 = {sv.sum()} / {n}")          # 预期: 远小于 n（如 4~8）
print("margin = 2/||w|| =", 2 / np.linalg.norm(w))

# ---------- KKT 条件逐条验证 ----------
# (a) 原始可行: y_i (w^T x_i + b) >= 1
print("KKT(a) 最小函数间隔 =", (y * (X @ w + b)).min())        # 预期 ≈ 1
# (b) 对偶可行: lambda >= 0
print("KKT(b) min lambda =", lam.min())                        # 预期 ≈ 0（数值容差内）
# (c) 互补松弛: lambda_i * (1 - y_i(w^T x_i + b)) ≈ 0
viol_c = np.abs(lam * (1 - y * (X @ w + b)))
print("KKT(c) 互补松弛最大违例 =", viol_c.max())               # 预期 < 1e-6
# (d) 平稳性: 由构造 (w = sum λ y x) 自动满足；等价检查梯度条件
print("KKT(d) ||w - sum lam_i y_i x_i|| =", np.linalg.norm(w - ((lam * y)[:, None] * X).sum(axis=0)))

# ---------- 影子价格演示：收紧一个数据点的约束会怎样 ----------
# 把某个支持向量略微"推离"边界，观察对偶值变化 ≈ λ_i × 扰动量
i0 = np.argmax(lam)
delta = 0.05
X2 = X.copy(); X2[i0] += delta * y[i0] * w / np.linalg.norm(w)  # 沿 w 方向推开
K2 = (X2 * y[:, None]) @ (X2 * y[:, None]).T
prob2 = cp.Problem(cp.Maximize(cp.sum(lmbda) - 0.5 * cp.quad_form(lmbda, cp.psd_wrap(K2))), cons)
prob2.solve(solver=cp.CLARABEL)
print(f"第 {i0} 点乘子 λ={lam[i0]:.3f}，对偶值变化 {prob2.value - prob.value:+.4f}")
# 预期: 变化量 ≈ λ_i × delta（影子价格的一阶近似）
```

预期现象：支持向量个数远小于样本总数（稀疏解）；KKT 四条全部在数值容差内成立；最后一个实验直接"摸到"影子价格——单个约束的乘子预测了扰动后最优值的变化。

## 4.9 常见误区与陷阱

1. **"凸问题一定强对偶"是错的**。弱对偶恒成立，但存在对偶间隙不为零的凸问题（可行域不闭或 Slater 失败的情形）。正确记忆：凸 + Slater ⇒ 强对偶。
2. **互补松弛看错方向**。$\lambda_i^\star f_i(x^\star) = 0$ 是"乘子与约束违反量"成对为零，不是"$\lambda$ 全为零"。SVM 里"所有 $\lambda_i = 0$"意味着 $w^\star = 0$，显然非最优——检查一下你的对偶求解是否坏了。
3. **把 KKT 当"万能必要性"用在非凸问题**。非凸问题中 KKT 只是局部最优的一阶必要条件（还需约束规范 qualification），且满足 KKT 的点可能是鞍点/极大点。SVM 推导的每一步都应注明"凸 + 仿射约束"这个前提。
4. **数值上把 $10^{-8}$ 的乘子当成支持向量**。互补松弛检验必须配容差（如 `lam > 1e-5`），否则浮点噪声会"制造"成百上千个支持向量。
5. **对偶问题可解 ≠ 原问题解可直接读出**。$w^\star$ 由式 (4.9) 重建；但某些问题（如对偶解不唯一时）重建需要特殊处理。工程上要验证重建解满足原问题可行性（如上面代码的 KKT(a) 检查）。
