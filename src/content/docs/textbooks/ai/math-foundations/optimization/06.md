# 第 6 章 非凸优化与现代视角

> **本章定位**：本课程从凸世界走向真实世界——神经网络的损失函数是大规模非凸函数。本章回答：非凸到底难在哪（鞍点/平坦区/坏初始化）、为什么 SGD 的噪声反而有益（逃离鞍点）、深度学习的损失景观长什么样（过参数化与隐式偏差），并给出超参数搜索的现代概览。前置：第 2 章条件数、第 5 章噪声地板；去向：《深度学习》初始化/正则化/泛化各章。

## 6.0 本章学习目标

学完本章，你能够：

1. 用 Hessian 的谱把驻点分类（局部极小/局部极大/鞍点），解释非凸问题中鞍点比坏局部极小更常见的几何理由；
2. 说明"严格鞍点附近 SGD 以高概率逃离"的机制（噪声把轨迹踢出不稳定方向），并与 GD 会驻留鞍点对照；
3. 描述深度学习损失景观的实证图像（过参数化下坏局部极小罕见、解连通、平坦度与泛化的相关性）及其局限；
4. 解释隐式偏差的概念与典型例子（小批量噪声/初始化偏向"平坦"与"简单"解），以及它为什么使优化与泛化纠缠；
5. 概述网格/随机/贝叶斯优化三类超参数搜索的原理与适用边界，并说明调参与优化的关系。

## 6.1 非凸问题的真正难点在哪里

### 6.1.1 驻点的谱分类

在驻点 $x^\star$（$\nabla f = 0$）处做二阶泰勒展开（《高等数学》第 4 章）：$f(x) \approx f(x^\star) + \frac{1}{2}(x - x^\star)^\top H (x - x^\star)$，$H = \nabla^2 f(x^\star)$。由《线性代数》第 4 章，$H$ 的特征值符号决定局部地形：

- 全部特征值 $> 0$（$H \succ 0$）：**严格局部极小**（碗底）；
- 全部特征值 $< 0$：局部极大（非凸问题中比极小罕见——高维函数"几乎处处是谷"的对称论证，见 6.1.2）；
- 兼有正负特征值：**鞍点（saddle point）**——某些方向是谷、另一些方向是脊；
- 特征值为零（$H$ 奇异）：**退化点（degenerate）**，二阶信息失效，可能是平坦区、monkey saddle 或高阶极小。

### 6.1.2 为什么高维中鞍点占主导

一个经典的随机论证（Bray & Dean 2007 的或其简化版）：随机高斯场中，Hessian 特征值分布近似对称，$n$ 个特征值全为正的概率随 $n$ 指数衰减（约 $2^{-n}$ 量级，若各方向独立）。于是：

- **低维（$n = 2, 3$）**：局部极小与鞍点共存，"卡在坏局部极小"是真实风险；
- **高维（$n \sim 10^6$，神经网络）**：随机驻点几乎必然是鞍点，严格局部极小指数级罕见。

这颠覆了入门者对"非凸 = 会被坏局部极小困住"的想象。**深度学习的实证结论（见 6.3）也一致：坏局部极小不是主要矛盾，鞍点、平坦高原与病态才是**。另一个高维特有现象：不同的局部极小往往**函数值几乎相同**（对称性：神经网络的神经元置换不变性天然制造指数多个等价极小），"哪个极小"不重要，"什么样的极小"（平坦/尖锐）才重要。

### 6.1.3 平坦区与坏初始化

除驻点类型外，还有两类"非驻点的慢区"：

1. **平坦高原（plateau）**：梯度接近零但不为零的广阔区域（常见于饱和激活、死亡 ReLU、sigmoid 饱和区）。GD 在此每步前进 $O(\eta\|\nabla f\|)$，极其缓慢；Adam 的二阶矩缩放（除以小的 $\sqrt{s}$）天然"放大高原上的小梯度"，这是它在此类场景常优于 SGD 的机制之一。缓解手段清单：换激活函数（ReLU 家族避开饱和）、诊断并处理死 ReLU（调低学习率/换初始化/leaky 变体）、用动量积累速度穿过小坡（第 3 章）、或用自适应方法放大微弱梯度（第 5 章）。
2. **坏初始化**：初始点落在极端病态区或对称陷阱（如所有神经元初始相同 → 梯度完全对称 → 永远相同，即"对称性破坏失败"）。这直接解释了深度学习的核心工程之一——**初始化方案**（Xavier/He 初始化：让每层激活与梯度的方差在各层近似守恒，从源头避免信号消失/爆炸与对称陷阱）的数学动机，细节在《深度学习》前向/反向传播章展开。

## 6.2 为什么 SGD 能逃离鞍点（而 GD 不能）

### 6.2.1 确定性 GD 会被鞍点吸附

在鞍点附近，把 $f$ 近似为二次型：沿负曲率方向 $v$（$v^\top H v < 0$），梯度法是"被推离"的不稳定动力学（$\dot{v} = -\lambda_{\min} v$ 型，$\lambda_{\min} < 0$ 时指数放大偏离）；但若初始位置恰好**精确落在**稳定流形上（所有正曲率方向张成的低维面上，测度为零的集合），GD 将渐近停在鞍点。数值上由于浮点对称性（如完全对称初始化），这种"巧合"在实现中真的会发生——GD + 对称初始化的训练在实践中确实会卡死。

### 6.2.2 噪声打破测度零的陷阱

SGD 的更新是 $\theta_{k+1} = \theta_k - \eta g_B(\theta_k)$，其中 $g_B$ 带随机性。在鞍点 $\theta_s$ 附近，即使 $\mathbb{E}[g_B] = 0$，随机项仍以正概率把参数踢出稳定流形——一旦离开，负曲率方向的"不稳定动力学"反过来**指数级放大**这次踢动（这是好事：鞍点附近噪声被负曲率方向放大成快速逃离）。理论结论（Pemantle 1990 的一般框架；Ge, Lee, Ma 2015；Jin 等 2017）：

> 对满足**严格鞍点性质**（每个鞍点至少存在一个显著负曲率方向）的光滑函数，SGD（步长按 Robbins–Monro 衰减、噪声持续）以概率 1 避免收敛到任何鞍点，最终只能停在局部极小（或退化点的小邻域）。

这就是"**噪声的积极作用**"：第 5 章里噪声是收敛的敌人（噪声地板），在非凸世界里它是逃离鞍点的朋友。小批量噪声、dropout、数据打乱都在扮演这个角色。推论：SGD 无法保证找到"最好的"局部极小，但能保证不"困死"在鞍点——对深度学习，这已足够（见 6.1.2）。

**工程信号对照**：训练长时间卡在较高 loss 且梯度范数极小、但稍微加大批量噪声或注入扰动后迅速下降——这是"卡在鞍点/平原"的典型指纹；反之若梯度范数不小、loss 高频震荡——那是病态或步长问题（第 2 章 2.9），两种卡住的药方完全不同。

### 6.2.3 确定性版本：扰动梯度法与随机重启

噪声的功劳是否必须依赖"随机性"？部分可以去掉。两条确定性/半确定性路线：

1. **扰动梯度法（perturbed GD，Jin 等 2017）**：每隔若干步注入一次人工扰动（幅值与流形宽度匹配的球面随机扰动），配合"缓慢衰减"调度，可在多项式时间内以高概率逃离所有严格鞍点——把 SGD 的"持续小噪声"换成"间隔性大扰动"，理论上更可控，工程上是随机重启的系统化版本。
2. **随机重启（random restarts）与退火**：从多个随机初始点分别跑 GD，取最优结果——简单、可并行，是多峰低维问题（如经典测试函数、分子构型）的实用标配；其"多起点"思想也是超参数搜索（6.5）与集成学习（《机器学习》bagging）的共同祖先。

此外还有纯确定性路线：利用负曲率方向本身（在鞍点附近额外解一个 Hessian 最小特征向量问题，如 Cubic-Newton / CURL 型算法），代价是需要二阶信息。**总结成一张地图**：逃离鞍点 = "噪声注入（SGD/扰动 GD）"或"负曲率探测（二阶法）"两条路，前者便宜、后者精准。

### 6.2.4 对比表：两种优化器在非凸地形上的行为

| 地形 | GD（确定性） | SGD（带噪声） |
|---|---|---|
| 严格鞍点（非对称初始化） | 渐近逃离（负曲率方向不稳定） | 更快逃离 |
| 鞍点 + 对称初始化 | **永久卡住** | 打破对称，逃离 |
| 平坦高原 | 缓慢爬行 | 缓慢 + 随机游走，略快 |
| 尖锐极小 | 稳定收敛（若 $\eta < 1/L_{\text{局部}}$） | 大 $\eta$ 时被噪声弹出（"正则化"效应） |
| 平坦极小 | 稳定收敛 | 稳定收敛 |

最后一行的"尖锐/平坦"差异是现代泛化理论的重要线索：$\eta \sigma^2$ 大的噪声会系统性地**偏好平坦极小**（线性稳定性分析，Wu 等 2018）——优化算法与泛化由此纠缠。

## 6.3 神经网络的损失景观简介

**损失景观（loss landscape）**指 $\theta \mapsto L(\theta)$ 在亿万维参数空间中的地形。直接可视化不可能，研究手段有三类：（a）低维投影/切片（沿两条随机方向 $\theta(\alpha, \beta) = \theta^\star + \alpha u + \beta v$ 剖面，Li 等 2018 的 filter-normalized 可视化）；（b）Hessian 谱的数值估计（Lanczos/幂迭代近似，Papyan 2018：谱呈现"块结构"，大部分方向近零曲率、少数方向高曲率）；（c）模式连通性实验（Garipov 等 2018：不同随机种子的极小点之间存在低损失"通道"，可用简单曲线连接）。

**损失景观研究方法一览**：

| 方法 | 看到什么 | 主要局限 |
|---|---|---|
| 低维随机切片 | 单个方向剖面的地形 | 方向选取强影响结果；必须 filter-normalize |
| Hessian 谱估计（幂迭代/Lanczos） | 曲率的分布（多少陡方向/平方向） | 只看最优点邻域；大网络代价高 |
| 模式连通性实验 | 不同极小之间的路径形状 | 路径存在性 ≠ 地形全局性质 |
| 训练动态统计（曲率爬升、轨迹曲率） | 优化器与地形的相互作用 | 现象丰富但理论整理尚在早期 |
| 重参数化敏感性 | 同一函数换参数化后"平坦度"改变 | 提示平坦度结论要注明参数化（Dinh 等 2017） |

**实证图像**（以过参数化网络为主）：

1. **过参数化（参数数 $\gg$ 训练样本数）下，可达到零训练损失的极小点大量存在且彼此连通**——优化难度大幅下降（很多"路"都是好路）；
2. Hessian 谱表明有效曲率集中在极少数方向，多数方向平坦——landscape 像"高维峡谷中的宽平原"，病态但不崎岖；
3. **平坦度与泛化相关**（Hochreiter & Schmidhuber 1997 的 MDL 直觉；Keskar 等 2017 的大批量/尖锐极小实验）：同样的训练损失，平坦极小通常泛化更好。注意这是相关性与启发性论证，不是定理（Dinh 等 2017 给出反例），本课程标注其争议性。

**现代插值（interpolation）图景**。上述现象可以放进一条统一的曲线：**双下降（double descent，Belkin 等 2019）**。以模型容量（参数数/网络宽度）为横轴、误差为纵轴：经典区间呈 U 形（欠拟合→过拟合，偏差-方差权衡，《机器学习》泛化理论章的主角）；在"插值阈值"（参数数 ≈ 样本数）附近误差飙升；**越过阈值进入过参数化区后，测试误差再次下降**——因为此时存在大量零训练损失的解，而（隐式偏差引导的）优化过程能挑到其中泛化较好的那些。这个"优化更容易"与"泛化更好"在过参数化区并存的图景，是理解现代大模型"越大越好训"的第一层数学解释；其完整理论（ benign overfitting）是当前统计学习理论的前沿。

理论补充（选读）：过参数化的两层 ReLU 网络在特定初始化尺度下，训练动态可由**神经正切核（NTK）**近似——网络退化为核回归、优化近乎凸，这解释了"为什么深度网络竟能被 SGD 可靠地优化"的一部分（Lee 等 2019）。完全理论仍在发展中。

## 6.4 隐式偏差：优化算法在选择解

过参数化使"零损失解"构成一个巨大流形——**优化算法最终停在哪个解，主要由算法自身决定，而非目标函数**。这个现象叫**隐式偏差/隐式正则化（implicit bias / implicit regularization）**：

- **SGD 的隐式偏差**：噪声与轨迹动力学偏向平坦、低范数的解（上述 6.2.3）；全批量 GD 停在初始点邻域内"最近"的解；
- **梯度下降在最小范数解上的收敛**：对欠定的最小二乘（无穷多解），从 $\theta_0 = 0$ 出发的 GD 恰好收敛到**最小欧氏范数解**（可用《线性代数》SVD 证明：GD 迭代只在行空间内添加分量，见练习 6）。这是"优化即隐式正则化"最干净的数学实例；
- **深度网络的隐式偏差**：对特定结构（如深度线性网络收敛到最小范数解、ReLU 网络偏向最大间隔方向解）有一系列部分结果（Ji & Telgarsky 2019 等）。

一个可动手体会的最小实验（进 99 章项目二的延伸）：在两组完全等价的数据（同一批样本复制并把每份乘一个不同常数、标签不变）上训练同一线性模型——最优解集合完全相同，但 SGD（小批量噪声）与全批量 GD 会收敛到**不同的解**，且 SGD 版本的解的范数结构对噪声水平敏感。这说明"算法"而不仅是"问题"在决定你拿到哪个模型。

**概念后果**：深度学习中"优化器选择"不只是"多快找到解"，而是"找到哪种解"——学习率、批量、动量都通过隐式偏差影响泛化。这把第 2、5 章的"步长"从纯粹的收敛参数升格为**建模参数**。一句话记忆：**在过参数化模型里，"你用什么优化"和"你得到什么模型"是同一个问题的两面**——这也是为什么本课程把优化当作 AI 的基础课而非工具课。

## 6.5 超参数搜索与自动调参概览

超参数（学习率、批量、正则系数、网络宽度……）的外层优化通常不可微、评估昂贵（每次评估 = 完整训练）、带噪声——这是一个"昂贵黑箱优化"问题。

1. **网格搜索（grid search）**：穷举笛卡尔积。维度灾难（$m$ 个超参各 $l$ 个取值 → $l^m$ 次训练），仅在 1–2 维有意义。
2. **随机搜索（random search）**：从分布中采样（Bergstra & Bengio 2012）。关键洞察：**重要超参数只占少数**——在"重要维度"上随机搜索的期望覆盖率远高于同预算网格（网格在重要维度上只试 $l$ 个值，随机搜索试 $N$ 个不同值）。简单、可并行、强基线。
3. **贝叶斯优化（Bayesian optimization）**：维护目标函数的概率代理模型（高斯过程或 TPE），按"采集函数"（expected improvement 等）平衡探索/利用地选下一个评估点（Snoek 等 2012）。样本效率最高，但实现复杂、高维（$> 20$ 维）时高斯过程本身吃力。代表工具：Optuna、Hyperopt、scikit-optimize。
4. **其他现代路线**：Hyperband/ASHA（多保真度：早停没希望的训练、把预算留给好的）；基于种群的方法（PBT，用于 RL 的超参在线演化）。

**统一的数学视角：双层优化（bilevel optimization）**。调参形式上是一个外层问题：$\min_{\lambda}\; L_{\text{val}}\big(\theta^\star(\lambda)\big)$，其中内层 $\theta^\star(\lambda) = \operatorname{argmin}_\theta L_{\text{train}}(\theta; \lambda)$ 是一次完整训练。外层不可微、内层昂贵——这解释了所有实用方法的形态：随机/贝叶斯搜索把内层当黑箱；**超梯度（hypergradient）方法**则通过展开内层迭代或隐函数定理求出 $\partial \theta^\star / \partial \lambda$，实现学习率的在线自适应。《深度学习》中的学习率自适应技巧与元学习（MAML）都是这个双层视角的实例。

**何时可以少调参**：在深度双下降区间（过参数化充分大）工作的模型，对 $\eta_0$ 与模型规模的敏感度显著下降——"大力出奇迹"有其数学依据（6.3 节）；反之，接近插值阈值的模型对所有超参数都极其敏感。判断自己处于哪个区间（参数量 vs 样本量）本身就是重要的调参前信息。

**调参的元层次**。注意一个容易忽视的层次：调度器的形状参数（余弦调度的周期、warmup 步数、衰减时点）本身也是超参数。它们与 $\eta_0$ 强耦合（warmup 长了需要更小的 $\eta_0$ 起步、衰减早了等效于更小的总学习预算），因此实践中不应把 5 个调度参数与 $\eta$、$B$ 一起盲目丢进贝叶斯优化——先用理论框定（5.3 节 + 本章 6.2.3 的尖锐极小风险），再对"少量真正敏感的组合"做搜索。这与《实验设计与评估》课程的"先分层后搜索"原则一致。

**与本课程主线的连接**：调参的对象（$\eta$、$B$、$\beta$）正是第 2、5 章的理论参数——理论能缩小搜索空间（如 5.6 节把 $(B, \eta)$ 联合律降为一维搜索），搜索负责理论的残余不确定性。**"理论先验 + 随机/贝叶斯搜索"是现代调参的标准姿势**。

## 6.6 关键公式速查

| 对象 | 结论 | 条件 |
|---|---|---|
| 驻点分类 | $H \succ 0$ 极小；$H$ 不定 = 鞍点；$H$ 奇异 = 退化 | $\nabla f = 0$，$H = \nabla^2 f$ |
| 随机驻点 | 特征值全正的概率随 $n$ 指数衰减 | 随机高斯场模型 |
| 严格鞍点性质 | 每个鞍点存在方向 $v$：$v^\top H v \le -c\|\nabla^2 f\|$ | Ge–Lee–Ma 2015 框架的前提 |
| SGD 逃离 | $\Pr(\text{收敛到鞍点}) = 0$ | 严格鞍点 + Robbins–Monro 步长 + 持续噪声 |
| 最小范数解 | 从 $\theta_0 = 0$ 起 GD 收敛到欠定最小二乘的最小 $\ell_2$ 范数解 | 欠定、满行秩；SVD 证明 |
| 随机搜索优势 | 重要维度上的采样数 $N \gg l$（同预算网格） | 少数超参数主导（Bergstra–Bengio 模型） |
| 临界批量 | 见第 5 章 (5.13) 与 5.6.2 | 与本章"大批量-尖锐极小"实验呼应 |
| 双下降 | 测试误差在插值阈值后随容量再降 | 过参数化区（Belkin 等 2019） |
| 双层优化 | 调参 = $\min_\lambda L_{\text{val}}(\theta^\star(\lambda))$ | 外层黑箱（搜索）或超梯度（可微） |

## 6.7 示例与案例

### 6.7.1 手算算例：一个标准鞍点的解剖

取 $f(x, y) = x^2 - y^2$（原点是典型鞍点）。$\nabla f = (2x, -2y)$，$H = \operatorname{diag}(2, -2)$——正负特征值各一。GD（$\eta = 0.1$）从 $(\epsilon, 0)$ 出发：$x$ 分量按 $0.8^k$ 衰减（被吸向鞍点），$y$ 分量保持为 0——**精确卡死在鞍点**。从 $(\epsilon, \epsilon)$ 出发：$y$ 分量按 $1.2^k$ 指数逃逸。从 $(\epsilon, 10^{-8})$ 出发：逃离约需 $k \approx \log(1/\epsilon')/\log 1.2$ 步才显影——**初始偏离越小，逃离的"潜伏期"越长**，这解释了 GD 实验中"看似停滞实则潜伏"的轨迹。SGD 在同样设置下每步给 $y$ 注入随机扰动，潜伏期被噪声截断。

### 6.7.2 代码示例：GD 卡死鞍点 vs SGD 逃离 + 损失景观切片

```python
"""第 6 章：(A) 在鞍点函数上对比 GD 与 SGD 的逃离行为；
(B) 沿随机二维切片可视化一个非凸损失景观。
运行环境：numpy, matplotlib。"""
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)

# ---------- (A) 鞍点实验：f(x,y) = x^2 - y^2 + 0.05*(x^2+y^2)^2 ----------
# 原点是鞍点；远处由四次项兜底（保证有全局极小，避免轨迹跑飞）
def f(p):
    x, y = p
    return x*x - y*y + 0.05*(x*x + y*y)**2

def grad(p):
    x, y = p
    r2 = x*x + y*y
    return np.array([2*x + 0.2*x*r2, -2*y + 0.2*y*r2])

def run(noise, k=300, eta=0.02, x0=(1e-6, 0.0), seed=0):
    r = np.random.default_rng(seed)
    p = np.array(x0, float); traj = [p.copy()]
    for _ in range(k):
        g = grad(p)
        if noise > 0:                      # SGD：模拟小批量梯度噪声（各向同性简化）
            g = g + noise * r.normal(size=2)
        p = p - eta * g
        traj.append(p.copy())
    return np.array(traj)

traj_gd  = run(noise=0.0)
traj_sgd = run(noise=0.05, seed=1)
print("GD  终点:", traj_gd[-1],  "|f| =", f(traj_gd[-1]))   # 预期: ≈ (0,0)，卡在鞍点
print("SGD 终点:", traj_sgd[-1], "|f| =", f(traj_sgd[-1]))  # 预期: 逃到 y 方向的极小 y≈±sqrt(10)
# （f 的极小在 x=0, y^2 = 10 处，f = -25 + …；SGD 借噪声离开鞍点后被负曲率+兜底项捕获）

# ---------- (B) 损失景观切片：一个小神经网络的二维剖面 ----------
# 用 sklearn 的 MLP 拟合简单数据，取训练后的权重 θ*，沿两条随机方向切片
from sklearn.datasets import make_moons
from sklearn.neural_network import MLPClassifier
X, y01 = make_moons(200, noise=0.2, random_state=0)
clf = MLPClassifier((16, 16), max_iter=2000, random_state=0).fit(X, y01)
theta_star = np.concatenate([c.ravel() for c in clf.coefs_] + [c.ravel() for c in clf.intercepts_])

def set_theta(clf, theta):
    i = 0; shapes = [c.shape for c in clf.coefs_] + [c.shape for c in clf.intercepts_]
    for attr, sh in zip(["coefs_"] * len(clf.coefs_) + ["intercepts_"] * len(clf.intercepts_), shapes):
        n = int(np.prod(sh)); clf.__dict__[attr] = theta[i:i+n].reshape(sh); i += n

u = rng.normal(size=theta_star.size); u /= np.linalg.norm(u)   # 随机方向（真实做法需 filter-normalize）
v = rng.normal(size=theta_star.size); v /= np.linalg.norm(v)
a = np.linspace(-2, 2, 80); b = np.linspace(-2, 2, 80)
Z = np.zeros((80, 80))
for i, av in enumerate(a):
    for j, bv in enumerate(b):
        set_theta(clf, theta_star + av*u + bv*v)
        Z[i, j] = 1 - clf.score(X, y01)          # 训练误差作为剖面
set_theta(clf, theta_star)                        # 恢复
plt.figure(figsize=(6, 5))
plt.contourf(a, b, Z, levels=30, cmap="magma")
plt.colorbar(label="train error"); plt.title("2-D random slice of MLP loss")
plt.xlabel("alpha"); plt.ylabel("beta")
plt.tight_layout(); plt.savefig("ch6_slice.png", dpi=150)
```

预期现象：(A) 中 GD 轨迹精确停在 $(0,0)$（浮点意义上永久驻留），SGD 在几十步内被噪声踢出并滑向 $y$ 方向的深谷；(B) 剖面显示一个"主体平坦 + 若干谷"的非凸地形。**注意事项与动手实验**：(B) 的切片用了未归一化的随机方向，真实论文（Li et al. 2018）必须按层的范数归一化否则剖面会被大范数层主导——试着去掉归一化看看剖面如何变形；把 (A) 的 `noise` 调成 0.005 观察逃离潜伏期变长。

**读图三问**（对任何优化可视化都适用）：这条轨迹在前 10% 的时间里完成了多少下降（初期动力学 vs 后期精修）？折返发生的方向对应 Hessian 的哪个特征方向？若把步长放大一倍，轨迹会先在哪里出问题？带着这三问看图，几何观察就自动接回了第 2、3 章的谱分析。

## 6.8 常见误区与陷阱

1. **"SGD 找到的一定是全局最优"是错的**。SGD 避开鞍点、但也只是停在某个（往往平坦的）局部极小或近平稳区；"全局最优"在深度学习中通常既不可达也不必要。
2. **把"卡住"一律归因于局部极小**。实际更常见的原因：鞍点/平原（看梯度范数：极小附近 $\|\nabla\|$ 大方向杂乱、平原 $\|\nabla\| \approx 0$）、坏初始化、学习率过大在尖锐区震荡。诊断顺序：先画梯度范数与 loss 曲线，再下结论。
3. **"过参数化 = 一定能零损失"不严谨**。NTK 式的良性结果依赖特定初始化尺度与步长条件；有限宽度、坏初始化下训练仍会失败（对称陷阱、死 ReLU）。
4. **把平坦度当泛化的充分条件**。平坦-泛化相关性在归一化参数化（BN）下有重参数化歧义（Dinh 等 2017）；它是有用启发，不是定理。
5. **贝叶斯优化不是免费午餐**：其样本效率优势在高维空间与"评估便宜"场景会被代理模型开销吞噬；低维昂贵目标才是它的主场。
6. **切片可视化的滤镜效应**：未做 filter-normalize 的随机切片几乎必然把景观画成"深谷"假象（方向范数不匹配所致）——读此类图先查方法。
