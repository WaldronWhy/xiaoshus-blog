# 第 1 章 优化问题建模与凸性

## 概念辨析

### 1.1 判断并说明理由：凸集之并、$e^{f}$、$\log f$、严格凸之和

**对应正文**：1.3 节（定义 1.2/1.3）、1.5 节（保持凸性的运算）。

**(a) 有限个凸集的并是凸集——错。**
反例：$[0,1]$ 与 $[2,3]$ 都是凸集，但取 $x=0.5,\ y=2.5,\ \theta=0.75$：$\theta x+(1-\theta)y=1.0+0.25=0.875\notin[0,1]\cup[2,3]$……直接算：$0.75\times0.5+0.25\times2.5=0.375+0.625=1.0$，取 $\theta=0.5$ 得 $1.5\notin$ 并集。保持凸性的集合运算是**交**（任意交），不是并。
*常见错误*：把"凸集的交凸"误记成"并凸"；或以为"有限个"比"无穷个"性质更好——方向反了，任意交都凸，有限并都不凸。

**(b) $f$ 凸 $\Rightarrow$ $e^{f}$ 凸——对。**
$h(t)=e^t$ 凸且**单调不减**，由 1.5 节复合规则（$h$ 凸不减、$f$ 凸 $\Rightarrow h\circ f$ 凸）立得。也可直接验证定义：$e^{f(\theta x+(1-\theta)y)}\le e^{\theta f(x)+(1-\theta)f(y)}\le\theta e^{f(x)}+(1-\theta)e^{f(y)}$，第一、二步分别用 $f$ 的凸性与 $e^t$ 的凸性。
*常见错误*：只背"复合规则"却忽略单调性前提。反例（$h$ 凸但不减不成立时）：$h(t)=(t-1)^2$ 凸但非单调，取 $f(x)=x$（凸），$h(f(x))=(x-1)^2$ 恰好仍凸（碰巧）；构造真正反例需要 $h$ 非单调且 $f$ 跨越 $h$ 的极小点两侧，如 $h(t)=t^2-4t+5$（凸，在 $t=2$ 处最小），$f$ 取遍 $[0,4]$ 的凸函数时复合可能出现下凹段——所以"凸复合凸必凸"是错的，关键就是单调性。而 $e^t$ 恰好严格不减，故 (b) 无例外地成立。

**(c) $f$ 凹且取正值 $\Rightarrow$ $\log f$ 凹——对。**
$h(t)=\log t$ 是**凹**且**单调不减**的函数（$t>0$），$f$ 凹，故 $h\circ f=\log f$ 凹（复合规则的凹-凹对偶版本：$h$ 凹不减、$f$ 凹 $\Rightarrow h\circ f$ 凹）。直接验证：$\log f(\theta x+(1-\theta)y)\ge\log\big(\theta f(x)+(1-\theta)f(y)\big)\ge\theta\log f(x)+(1-\theta)\log f(y)$，两步分别用 $f$ 凹（$\log$ 不减保证方向）与 $\log$ 凹。
*常见错误*：忘记"取正值"前提——$\log$ 在 $t\le0$ 无定义，$f$ 变号时命题根本无意义；把"不减"弄反（$\log$ 不减是必要条件，若是 $\exp$ 作用于凹函数则不保任何性）。

**(d) 两个严格凸函数之和严格凸——对。**
设 $f_1,f_2$ 严格凸，$x\ne y$，$\theta\in(0,1)$：
$$f_1(\theta x+(1-\theta)y)<\theta f_1(x)+(1-\theta)f_1(y),\qquad f_2(\cdot)\ \text{同理（严格）}.$$
两不等式相加即得 $f_1+f_2$ 严格凸。
*常见错误*：以为"一严格一非严格之和可能不严格"——恰恰相反，一严格 + 任意凸之和**必**严格（把上面第二个不等式改成 $\le$ 相加仍严格）；真正容易出错的是反向命题："严格凸函数减去一个凸函数仍严格凸"——不成立（如 $x^2$ 严格凸，$x^2-(x^2)=0$ 不严格）。

### 1.2 举一个"目标凸、可行域非凸"的问题，并说明定理 1.6 为何失效

**对应正文**：1.2 节（定义 1.1）、1.6 节（定理 1.6 及其证明）、1.9 节误区 5。

**例子（一维即可）**：
$$\min_{x\in\mathbb{R}}\ x^2 \quad\text{s.t.}\quad x\in\{-2\}\cup[0.4,\,0.6].$$
目标 $x^2$ 凸；可行域是两个不相交集合的并，非凸。$x=-2$ 是**局部最优**：取 $r=0.5$，可行集在 $(-2.5,-1.5]$ 内只有 $-2$ 一点，故 $f(-2)=4\le f(x)$ 对邻域内一切可行 $x$ 成立。但它不是全局最优：$f(0.5)=0.25<4$。

**定理 1.6 失效的机制**：其证明的关键一步是"由 $D$ 凸，$z_\theta=\bar x+\theta(y-\bar x)\in D$ 对任意 $\theta\in(0,1)$ 成立"——即可以在 $\bar x$ 与更优点 $y$ 之间任意插值而保持可行。可行域非凸时这条连线会跑出可行域，于是"更优点会在 $\bar x$ 附近制造下降点"的反证构造失败，局部最优与全局最优脱钩。

**另一类典型例子（等式约束非仿射）**：$\min\ -x^2$ s.t. $x^2-1=0$。等式约束函数 $h(x)=x^2-1$ 非仿射，可行集 $\{-1,1\}$ 非凸——这解释了正文 1.9 节误区 5 的警告：**"目标凸"不等于"问题凸"，等式约束必须仿射、不等式约束函数必须凸**。

### 1.3 强凸一定严格凸吗？严格凸一定强凸吗？

**对应正文**：1.3.2 节（$\mu$-强凸定义）、1.9 节误区 2。

**强凸 $\Rightarrow$ 严格凸：对。** 设 $f$ 为 $\mu$-强凸（$\mu>0$），$x\ne y$，$\theta\in(0,1)$。由强凸定义（$f(x)-\frac{\mu}{2}\|x\|^2$ 凸）逐字写出：
$$f(\theta x+(1-\theta)y)\ \le\ \theta f(x)+(1-\theta)f(y)\ -\ \frac{\mu}{2}\,\theta(1-\theta)\,\|x-y\|^2\ <\ \theta f(x)+(1-\theta)f(y),$$
末项 $>0$（$\mu>0$、$x\ne y$、$\theta\in(0,1)$），故严格。

**严格凸 $\Rightarrow$ 强凸：不对。** 反例 $f(x)=e^x$（一维，严格凸，$f''=e^x>0$）：若它是 $\mu$-强凸，则由二阶刻画 $\nabla^2 f(x)-\mu I\ge0$ 要求 $e^x\ge\mu$ 对一切 $x\in\mathbb R$ 成立，但 $x\to-\infty$ 时 $e^x\to0$，任何固定 $\mu>0$ 都被违反。（提示中的 $x^4$ 同理：$f''=12x^2\to0$。）直观：强凸要求函数"处处至少像抛物线那样弯"，$e^x$ 左尾完全展平，不满足。

**附带说明**：强凸是比严格凸严格更强的性质，且强凸刻画（$\nabla^2 f\succeq\mu I$）与"最优解唯一 + 线性收敛率（第 2 章）"直接挂钩，这是第 2 章把它单列出来的原因。

## 计算推导

### 1.4 零梯度判据：$f$ 可微凸时 $x^\star$ 全局最优 $\iff$ $\nabla f(x^\star)=0$

**对应正文**：1.4.1 节（定理 1.4 切线不等式）。

**充分性（$\nabla f(x^\star)=0\Rightarrow$ 全局最优）**。切线不等式 (1.3) 用于点对 $(x^\star, y)$：对一切 $y$
$$f(y)\ \ge\ f(x^\star)+\nabla f(x^\star)^\top(y-x^\star)\ =\ f(x^\star)+0\ =\ f(x^\star).\qquad\blacksquare$$

**必要性（全局最优 $\Rightarrow\nabla f(x^\star)=0$）**。反设 $g:=\nabla f(x^\star)\ne0$，取 $y=x^\star-tg$（$t>0$）。由 $f$ 在 $x^\star$ 可微：
$$f(y)=f(x^\star)+\nabla f(x^\star)^\top(-tg)+o(t)=f(x^\star)-t\|g\|^2+o(t).$$
当 $t>0$ 足够小时 $-t\|g\|^2+o(t)<0$（因 $o(t)/t\to0$），故 $f(y)<f(x^\star)$，与 $x^\star$ 全局最优矛盾。$\blacksquare$

**比一般驻点条件强在哪**：
1. **充分性**。对一般（非凸）可微函数，$\nabla f=0$ 只是局部极值的必要条件，驻点可能是极大点或鞍点（如 $x^3$、$x^2-y^2$）；对凸函数它是**全局**最优的充要条件。
2. **全局性**。判据不需要任何"局部"限定词，一个等式 $\nabla f(x^\star)=0$ 同时解决了"是不是极值、是不是全局"两个问题——它是**可验证的证书**：任何人算出梯度为零即可宣称全局最优，这正是第 4 章 KKT 条件 (d)（拉格朗日平稳）能充当最优性判据的原因。

### 1.5 岭回归损失的梯度、Hessian 与强凸参数

**对应正文**：1.4.2 节（定理 1.5、例 1.1）、2.2 节（$\mu,L$ 的谱刻画）。

> **勘误（本册勘误索引 2）**：题面写 $f(w)=\frac12\|Xw-y\|_2^2+\frac{\lambda}{2}\|w\|_2^2$，但其"校验"给出 Hessian $=X^\top X/n+\lambda I$——这只在目标含 $1/n$（即 $f(w)=\frac{1}{2n}\|Xw-y\|^2+\frac{\lambda}{2}\|w\|^2$，与 1.8.2 代码及第 2 章 2.2 节的"典型实例"一致）时成立。下面按**含 $1/n$ 的版本**求解，并在最后给出不含 $1/n$ 版本的对应结果。

**梯度**。记 $r(w)=Xw-y$，$f(w)=\frac{1}{2n}r^\top r+\frac{\lambda}{2}w^\top w$。逐分量（或用《线性代数》第 5 章矩阵微分）：
$$\nabla f(w)=\frac{1}{n}X^\top(Xw-y)+\lambda w=\Big(\frac{1}{n}X^\top X+\lambda I\Big)w-\frac{1}{n}X^\top y.$$
**Hessian**：
$$\nabla^2f(w)=\frac{1}{n}X^\top X+\lambda I\qquad(\text{与 } w \text{ 无关，常数矩阵}).$$

**强凸的充要条件**。$f$ 强凸 $\iff\nabla^2f\succeq\mu I$ 对某个 $\mu>0$ 成立 $\iff\lambda_{\min}\big(\tfrac1n X^\top X\big)+\lambda>0$。由于 $\lambda_{\min}(X^\top X)\ge0$：
- 若 $\lambda>0$：**恒强凸**（无需 $X$ 满秩），且 $\mu=\dfrac{\lambda_{\min}(X^\top X)}{n}+\lambda\ \ge\ \lambda$，$L=\dfrac{\lambda_{\max}(X^\top X)}{n}+\lambda$；
- 若 $\lambda=0$：强凸 $\iff X$ 列满秩（$\lambda_{\min}(X^\top X)>0$），此时 $\mu=\lambda_{\min}(X^\top X)/n$。

**校验对照**：Hessian $=X^\top X/n+\lambda I$ ✓；最小特征值 $=\lambda_{\min}(X^\top X)/n+\lambda\ge\lambda$ ✓。与正文一致。
（若按题面字面无 $1/n$：$\nabla f=X^\top(Xw-y)+\lambda w$，$\nabla^2f=X^\top X+\lambda I$，$\mu=\lambda_{\min}(X^\top X)+\lambda\ge\lambda$，结论形状相同、常数差 $n$ 倍。）

### 1.6 log-sum-exp 函数的凸性证明与"方差"解读

**对应正文**：1.5 节函数库、例 1.2 的验证链、1.8.1(b)。

设 $f(x)=\log\sum_k e^{x_k}$，$p_k=\dfrac{e^{x_k}}{\sum_j e^{x_j}}$（softmax）。

**一阶导**：$\dfrac{\partial f}{\partial x_i}=\dfrac{e^{x_i}}{\sum_j e^{x_j}}=p_i$，即 $\nabla f=p$。

**二阶导**：对 $p_i$ 再求 $\partial/\partial x_l$。注意 $p_i$ 是"分子/分母"型：
$$\frac{\partial p_i}{\partial x_l}=p_i(\delta_{il}-p_l)\quad(\text{分子分母同乘 }1/\sum e^{x_j}\text{ 后逐项求导；}\delta_{il}\text{ 为 Kronecker delta}).$$
故
$$\nabla^2f=\operatorname{diag}(p)-pp^\top.$$

**半正定性验证**。对任意 $v\in\mathbb R^n$：
$$v^\top\nabla^2f\,v=\sum_k p_kv_k^2-\Big(\sum_kp_kv_k\Big)^2.$$
把 $v_k=(v_k-\bar v)+\bar v$（$\bar v:=p^\top v=\sum_kp_kv_k$）代入展开，一阶交叉项与常数项恰好消去：
$$\sum_kp_k(v_k-\bar v)^2\ \underbrace{+\ 2\bar v\sum_kp_k(v_k-\bar v)}_{=\ 2\bar v(\bar v-\bar v)=0}\ \underbrace{+\ \bar v^2\sum_kp_k}_{=\ \bar v^2}-\bar v^2\ =\ \sum_kp_k(v_k-\bar v)^2.$$
所以
$$\boxed{\ v^\top\nabla^2f\,v=\sum_k p_k\,(v_k-p^\top v)^2\ \ge 0\ }$$
（$p_k\ge0$ 且 $\sum p_k=1$），故 $f$ 凸。

**这个平方和形式还告诉我们什么**：若随机变量 $V$ 服从 $\Pr(V=v_k)=p_k$（即 softmax 输出被解释为类别分布），则
$$\operatorname{Var}[V]=\mathbb E[V^2]-\mathbb E[V]^2=\sum_kp_kv_k^2-(p^\top v)^2=v^\top\nabla^2f\,v.$$
即 **log-sum-exp 的 Hessian 就是 softmax 分布下坐标的协方差矩阵**。两个推论：(i) $v=\mathbf 1$ 时 $v^\top\nabla^2f\,v=0$——log-sum-exp 沿全 1 方向是线性的（$f(x+c\mathbf 1)=f(x)+c$），因此它**永远不是强凸的**；(ii) 当某个 $p_k\to1$（softmax 饱和）时协方差 $\to0$——Hessian 退化，这正是深度学习中交叉熵损失在"接近收敛/极端置信"时梯度与曲率同时消失的数学根源。

### 1.7 强凸版切线不等式：$f(y)\ge f(x)+\nabla f(x)^\top(y-x)+\frac{\mu}{2}\|y-x\|^2$

**对应正文**：1.3.2 节强凸定义、2.2 节定义 2.2（式 2.3 的原型）。

**证明**。设 $f$ 可微且 $\mu$-强凸，即 $g(x):=f(x)-\frac{\mu}{2}\|x\|^2$ 是凸函数（强凸定义的直接改写）。$g$ 可微且 $\nabla g(x)=\nabla f(x)-\mu x$。对 $g$ 用普通切线不等式 (1.3)（点对 $(x,y)$）：
$$g(y)\ \ge\ g(x)+\nabla g(x)^\top(y-x).$$
代入定义：
$$f(y)-\frac{\mu}{2}\|y\|^2\ \ge\ f(x)-\frac{\mu}{2}\|x\|^2+\big(\nabla f(x)-\mu x\big)^\top(y-x).$$
移项整理：
$$f(y)\ \ge\ f(x)+\nabla f(x)^\top(y-x)-\mu x^\top(y-x)+\frac{\mu}{2}\big(\|y\|^2-\|x\|^2\big).$$
关键代数步：把后两项配方——
$$-\mu x^\top(y-x)+\frac{\mu}{2}\big(\|y\|^2-\|x\|^2\big)=\frac{\mu}{2}\Big(\|y\|^2-2x^\top y+\|x\|^2\Big)=\frac{\mu}{2}\|y-x\|^2.$$
（第一项 $-\mu x^\top y+\mu\|x\|^2$ 与 $\frac\mu2\|y\|^2-\frac\mu2\|x\|^2$ 合并：$\frac\mu2\|y\|^2-2\cdot\frac\mu2 x^\top y+\frac\mu2\|x\|^2$。）故
$$f(y)\ \ge\ f(x)+\nabla f(x)^\top(y-x)+\frac{\mu}{2}\|y-x\|^2.\qquad\blacksquare$$

**反向也成立**：若可微 $f$ 满足此不等式，对 $y$ 求导取极限（或直接比较定义）可推出 $f-\frac\mu2\|\cdot\|^2$ 凸，故它就是 $\mu$-强凸的等价刻画——第 2 章定义 2.2 直接采用这一形式，式 (2.10)（梯度单调性的强凸版）由它对 $y$ 求导得到。

## 编程实现

### 1.8 平方对数损失的凸性体检（含对正文提示的勘误）

**对应正文**：1.8.2 代码、1.5 节复合规则。

> **勘误（本册勘误索引 1）**：练习提示暗示"平方后的对数损失可能不凸"。**实测违例数为 0，且解析验证表明它确实仍是凸函数**——提示不成立，理由如下。

**解析分析**。记 $g(z)=\log(1+e^{-z})$（凸，$g''(z)=\frac{e^{-z}}{(1+e^{-z})^2}>0$，且 $g(z)>0$ 恒成立）。考察 $h(z)=g(z)^2$：
$$h'(z)=2g(z)g'(z),\qquad h''(z)=2\big(g'(z)\big)^2+2g(z)g''(z).$$
三项符号：$(g')^2\ge0$、$g>0$、$g''>0$，故 $h''(z)>0$ **恒成立**——$h$ 严格凸。逐样本损失 $h(y_ix_i^\top w)$ 是凸函数与仿射函数的复合（1.5 节运算 2），非负和仍凸（运算 1），所以整个损失**是凸的**。

**正确的"凸函数平方未必凸"反例**：$(x^2-1)^2$ 不凸（$h''=12x^2-4$，在 $|x|<1/\sqrt3$ 为负）。与本题的关键差别：$x^2-1$ **取负值**；而对**非负**凸函数 $g\ge0$，$g^2$ 必凸（上面的 $2(g')^2+2gg''\ge0$ 论证不要求 $g$ 具体是什么，只要 $g\ge0$）。对数损失恰好非负，所以平方"安全"。

**参考实现（已运行验证，固定种子）**：

```python
import numpy as np

rng = np.random.default_rng(0)
n, d = 200, 2
X = rng.normal(size=(n, d))
y_reg = X @ np.array([1.5, -2.0]) + 0.3 * rng.normal(size=n)
y_cls = np.sign(y_reg); y_cls[y_cls == 0] = 1

def loss_logistic_sq(w):
    z = y_cls * (X @ w)
    return (np.logaddexp(0, -z) ** 2).mean()   # 平方后的对数损失

def convexity_check(loss, num=20000, tol=1e-12):
    viol = 0
    for _ in range(num):
        w1, w2 = rng.normal(size=d) * 3, rng.normal(size=d) * 3
        theta = rng.uniform(0, 1)
        lhs = loss(theta * w1 + (1 - theta) * w2)
        rhs = theta * loss(w1) + (1 - theta) * loss(w2)
        viol += (lhs > rhs + tol * max(1, abs(rhs)))
    return viol

print(convexity_check(loss_logistic_sq))
# 实际输出: 0   （20000 次随机割线检验零违例 —— 平方对数损失仍凸）

# 数值扫描 h''(z) = 2(g')^2 + 2 g g'' 的符号
zs = np.linspace(-20, 20, 4001)
g  = np.logaddexp(0, -zs)
gp = -1/(1+np.exp(zs))                       # g'(z) = -sigmoid(z)
gpp = np.exp(-zs)/(1+np.exp(-zs))**2
print((2*gp**2 + 2*g*gpp).min())
# 实际输出: ~1.7e-17 （网格上的最小值非负, 与解析结论 h''>0 一致）
```

**结论**：违例数不变化（凸情形与原损失同为 0）。若把题目改成真正的"平方破坏凸性"实验，可对**允许取负值的凸函数**（如逐样本损失的线性部分 $-y_ix_i^\top w$）平方，违例将显著出现。等高线图上平方对数损失仍是同心碗状（比原损失"更陡"），没有多谷结构。

### 1.9 对角占优 vs 半正定：充分而非必要（200 个随机 $2\times2$ 对称阵）

**对应正文**：1.4.2 节（定理 1.5）、《线性代数》Gershgorin 圆盘定理。

```python
import numpy as np
rng = np.random.default_rng(1)
N = 200
cnt_psd = cnt_dd = 0
for _ in range(N):
    A = rng.normal(size=(2, 2)); A = (A + A.T) / 2      # 随机对称阵
    if np.linalg.eigvalsh(A).min() >= -1e-12: cnt_psd += 1
    if abs(A[0,0]) >= abs(A[0,1]) and abs(A[1,1]) >= abs(A[0,1]): cnt_dd += 1
print(cnt_psd/N, cnt_dd/N)
# 实际输出: 0.14 0.44
```

**运行结果与解读**：200 个随机对称阵中半正定占 14.0%，对角占优占 44.0%。两者都不是包含关系，实验的价值在于"比例不等 + 可构造单侧反例"：

- **对角占优（配非负对角元）$\Rightarrow$ 半正定**：Gershgorin 圆盘定理给出 $\lambda_{\min}\ge\min_i\big(a_{ii}-\sum_{j\ne i}|a_{ij}|\big)\ge0$。
- **充分而非必要的两个反例**：
  - 对角占优但不半正定：$A=\operatorname{diag}(5,-1)$。两行都满足 $|a_{ii}|\ge\sum_{j\ne i}|a_{ij}|$（$5\ge0$，$1\ge0$），但 $\lambda_{\min}=-1<0$——占优定义本身不管对角元符号（加上"对角非负"才成为 PSD 的充分条件）；
  - 半正定但不对角占优：$A=\begin{pmatrix}1&0.8\\0.8&0.65\end{pmatrix}$，$\det=0.65-0.64=0.01>0$、迹 $>0$，故 $\lambda_{\min}=0.05>0$；但第二行 $0.65<0.8$ 不占优。

**结论**：对角占优（含符号条件）是半正定的**充分**条件，检验便宜（$O(n^2)$ 无需特征分解），但会漏判大量半正定阵——这正是数值线性代数中"快速筛查 vs 精确判定"的典型权衡。

### 1.10 建模自由度 vs 优化可保证性（约 200 字论述）

**参考范文**：

> 什么样的任务值得用凸模型？当问题的**结构先验已经明确**、且我们更需要**可靠的保证**而非表达自由时——参数估计（线性/逻辑回归）、带安全或资源约束的决策（SVM、组合优化、控制）、需要唯一解与可解释对偶（影子价格）的场景。凸模型给的是"工程合同"：局部即全局（定理 1.6）、对偶下界可验证、解对扰动稳定。
> 什么样的任务必须用非凸模型？当**输入到输出的映射本身高度复杂**——图像、语言、多模态表示——其函数族天然非凸（深度网络）。这里我们用"可保证性"换取"表达能力"，并用过参数化、隐式偏差与随机优化（第 5、6 章）把不可保证性压缩到可接受的程度。
> 判断准则：先问"失败一个解的代价是什么"。代价高（医疗、控制、金融）优先凸建模或凸松弛；代价低且迭代快的任务（推荐、内容生成）放手用非凸模型，用工程手段补保证。

**要点核对**：①凸=保证（局部即全局、对偶、唯一性）；②非凸=表达；③决策变量是任务的风险结构而非个人偏好；④中间路线（凸松弛、核方法、SDP）值得点名。

## 挑战题

### 1.11（研究生层次）偏最小化：$f(x,y)$ 联合凸 $\Rightarrow g(x)=\inf_y f(x,y)$ 凸

**对应正文**：1.5 节运算 4；这也是第 4 章对偶函数凹性（运算 4 的镜像）的基础。

**第一步（定义域凸）**。$\operatorname{dom} g=\{x:\exists y,\ (x,y)\in\operatorname{dom}f\}$，即 $\operatorname{dom}f$ 到 $x$-坐标的**投影**。设 $x_1,x_2\in\operatorname{dom}g$，存在 $y_1,y_2$ 使 $(x_i,y_i)\in\operatorname{dom}f$。$\operatorname{dom}f$ 凸（$f$ 凸的定义要求），故 $\big(\theta x_1+(1-\theta)x_2,\ \theta y_1+(1-\theta)y_2\big)\in\operatorname{dom}f$，于是 $\theta x_1+(1-\theta)x_2\in\operatorname{dom}g$。投影保持凸性，$\operatorname{dom}g$ 凸。

**第二步（凸性不等式）**。取任意 $x_1,x_2\in\operatorname{dom}g$、$\theta\in[0,1]$，记 $x_\theta=\theta x_1+(1-\theta)x_2$。用 **$\varepsilon$-下确界论证**（下确界未必取到，不能直接"取 $y_i=\arg\min$"）：对任意 $\varepsilon>0$，取 $y_i$ 使
$$f(x_i,y_i)\ \le\ g(x_i)+\varepsilon,\qquad i=1,2.$$
由 $f$ 的联合凸性与 $\operatorname{dom}f$ 凸：
$$f(x_\theta,\ \theta y_1+(1-\theta)y_2)\ \le\ \theta f(x_1,y_1)+(1-\theta)f(x_2,y_2)\ \le\ \theta g(x_1)+(1-\theta)g(x_2)+\varepsilon.$$
左端的点 $(x_\theta,\cdot)$ 属于 $\operatorname{dom}f$，而 $g(x_\theta)=\inf_y f(x_\theta,y)$ 不超过任何具体 $y$ 处的值：
$$g(x_\theta)\ \le\ \theta g(x_1)+(1-\theta)g(x_2)+\varepsilon.$$
$\varepsilon>0$ 任意，令 $\varepsilon\to0^+$ 即得凸性不等式。$\blacksquare$

**技术要点**：(i) 不得假设下确界取到（$g$ 可以只是正常凹/凸的 extends infimum 未达，例如 $e^{xy}$ 型），$\varepsilon$-论证是标准手段；(ii) 若 $f$ 强凸于 $y$ 则下确界取到、$g$ 光滑（部分梯度 $\nabla_x g=\nabla_x f(x,y^\star(x))$，包络定理）——这是第 4 章对偶函数可微性的来源。

### 1.12（研究生层次）投影的特征不等式：$(x_0-P_C(x_0))^\top(y-P_C(x_0))\le0$

**对应正文**：1.6 节、Boyd & Vandenberghe 2.2/3.2（分离超平面）；这是第 4 章投影梯度法的理论核心。

**证明（变分法，比分离超平面更直接；两条路线都给出）**。

记 $p:=P_C(x_0)$（$C$ 非空闭凸，投影存在唯一——存在性由 $C$ 闭 + 下水平集紧，唯一性由 $\|\cdot\|$ 严格凸）。$p$ 是 $\min_{z\in C}\|x_0-z\|^2$ 的解。反设存在 $y\in C$ 使
$$(x_0-p)^\top(y-p)>0.$$
考虑 $z_\theta=p+\theta(y-p)\in C$（$C$ 凸，$\theta\in(0,1)$）。直接展开：
$$\|x_0-z_\theta\|^2=\|x_0-p-\theta(y-p)\|^2=\|x_0-p\|^2-2\theta\,(x_0-p)^\top(y-p)+\theta^2\|y-p\|^2.$$
因 $(x_0-p)^\top(y-p)>0$，当 $\theta\in\big(0,\ 2(x_0-p)^\top(y-p)/\|y-p\|^2\big)$ 时上式 $<\|x_0-p\|^2$，与 $p$ 是 $C$ 上投影矛盾。故不等式对一切 $y\in C$ 成立。$\blacksquare$

**与分离超平面的联系**：把不等式改写为 $(p-x_0)^\top\big(y-p\big)\ge0$——超平面 $\{z:(p-x_0)^\top(z-p)=0\}$（过 $p$、以 $x_0-p$ 为法向）把 $C$ 整体与 $x_0$ 分在两侧，这正是点与闭凸集的**支撑超平面**，是分离定理的最简实例。

**两个等价推论（第 4 章要用）**：(i) 取 $y=P_C(x')$ 得投影算子的**非扩张性** $\|P_C(x)-P_C(x')\|\le\|x-x'\|$；(ii) 取 $y$ 为 $C$ 中任意点并令 $x_0=x$，得投影梯度法的可行性修正不等式。

## 概念辨析

### 2.1 一句话向工程师解释 $O(1/k)$ vs $O(1/\sqrt k)$

**对应正文**：2.4 节"读懂数字"、2.5 节。

**参考回答**：训练预算翻倍（迭代数 $k\to2k$）时，$O(1/k)$ 算法的误差**减半**（$1/k\to1/(2k)$），而 $O(1/\sqrt k)$ 算法的误差只降为原来的 $1/\sqrt2\approx70\%$；换算成"再降一个数量级要多少预算"：前者约 10 倍，后者约 **100 倍**——所以 $O(1/\sqrt k)$ 的方法（SGD）通常只用来拿"中等精度"，高精度要靠衰减步长、方差缩减或二阶/加速方法。

*常见错误*：把"亚线性"统一当成慢——$1/k$ 与 $1/\sqrt k$ 同属亚线性但相差一个 $\sqrt{k}$ 因子；也须结合每步代价读（SGD 每步便宜 $n/B$ 倍，见第 5 章误区 1）。

### 2.2 定理 2.4 证明中凸性用在哪一步？非凸时结论如何？

**对应正文**：2.4 节证明三步曲。

**凸性只用了一次**：第二步里用切线不等式 (1.3)（点对 $(x_k,x^\star)$）得到 $\nabla f(x_k)^\top(x_k-x^\star)\ge f(x_k)-f^\star$。第一步（式 2.6 下降引理）**只依赖 $L$-光滑**，对非凸函数同样成立（把式 (2.2) 中 $y$ 取为 $x_k-\frac1L\nabla f(x_k)$，不需要凸性）。
（勘误注：正文 2.4 节第二步提到"再经 Cauchy–Schwarz 的逆向使用"，容易让人以为还有一步额外论证；实际就是切线不等式的直接使用，无其他输入。）

**非凸时的结局**：(2.6) 仍成立 → 函数值序列单调下降、$\|\nabla f(x_k)\|\to0$（若下水平集紧）——即收敛到**驻点**。但定理 2.4 的最终结论不成立：非凸函数可能有多个驻点/极小，"到 $x^\star$ 的距离"这个量本身失去意义（收敛到哪个点依赖初值），且 $f(x_k)-f^\star$ 可以停在任何局部极小处。$O(1/k)$ 的正确非凸替身是：$\min_{k\le K}\|\nabla f(x_k)\|^2\le O(1/K)$（梯度平方平均衰减）。

### 2.3 强凸参数 $\mu$ 的三重作用

**对应正文**：2.2、2.5 节。

**(a) 最优解唯一性**。强凸 $\Rightarrow$ 唯一最优解。证明：设 $x\ne y$ 都是全局最优，$f(x)=f(y)=p^\star$。取中点 $z=\frac{x+y}{2}$，由强凸性不等式（1.7 题的加强版，$\theta=\frac12$）：
$$f(z)\ \le\ \frac{f(x)+f(y)}{2}-\frac{\mu}{8}\|x-y\|^2\ =\ p^\star-\frac{\mu}{8}\|x-y\|^2\ <\ p^\star,$$
矛盾。（只有凸性时最优解集是凸集但可以是一整段——第 1 章误区 4；强凸把集合压成单点。）

**(b) 收敛因子**。定理 2.5：$\rho=1-\mu/L=1-1/\kappa$。$\mu$ 越大（碗越弯）因子越小、收敛越快；$\mu\to0^+$ 时因子 $\to1$，退化为 $O(1/k)$。

**(c) 条件数**。$\kappa=L/\mu$：$\mu$ 增大直接压低 $\kappa$，缓解"陡方向限制步长、缓方向龟速"的病态几何（2.6 节）——特征标准化的本质就是把各方向的曲率拉平、抬高有效 $\mu$。

### 2.4 病态二次函数上的精确迭代（校验值核对）

**对应正文**：2.6.2 节谱分析、2.8.1 手算算例。

设 $f(x)=\frac12(\mu x_1^2+Lx_2^2)$，$\nabla f=(\mu x_1,\ Lx_2)$，$\eta=1/L$，$x_0=(1,1)$。梯度法两坐标**解耦**（$A=\operatorname{diag}(\mu,L)$ 已对角）：
$$x_{1,k+1}=(1-\eta\mu)\,x_{1,k}=\Big(1-\frac{\mu}{L}\Big)x_{1,k},\qquad
x_{2,k+1}=(1-\eta L)\,x_{2,k}=0\cdot x_{2,k}.$$
精确解：
$$x_{1,k}=\Big(1-\frac{\mu}{L}\Big)^k,\qquad x_{2,k}=0\ (k\ge1),\qquad \|x_k\|=\Big(1-\frac{\mu}{L}\Big)^k\ (k\ge1).$$
（$x_2$ 一步即达最优——$\eta=1/L$ 恰是陡方向的单步最优步长。）

### 2.5 由 $L$-光滑（凸）推出梯度的 Lipschitz 连续性

**对应正文**：2.2 节定义 2.1、2.5 节式 (2.11)。
（注：正文提示文字有残缺（"对 $f$ 与 $-f$…不对…"），下面给出完整正确思路：先证 co-coercivity，再用 Cauchy–Schwarz。）

**第一步：构造"扣除线性"的辅助函数**。固定 $y$，令 $\varphi(z)=f(z)-\nabla f(y)^\top z$。由 $f$ 凸：$\varphi$ 凸；由 $f$ $L$-光滑（式 2.2 的 Hessian 刻画与线性项无关）：$\varphi$ 仍 $L$-光滑。且 $\nabla\varphi(y)=\nabla f(y)-\nabla f(y)=0$，故 $y$ 是 $\varphi$ 的全局最小点（1.4 题零梯度判据），$\varphi(y)=\min_z\varphi(z)$。

**第二步：对 $\varphi$ 用抛物线帽并最小化两端**。式 (2.2) 用于 $(x,z)$：对一切 $z$
$$\varphi(z)\ \le\ \varphi(x)+\nabla\varphi(x)^\top(z-x)+\frac{L}{2}\|z-x\|^2.$$
右端是 $z$ 的凸二次函数，其最小值在 $z^\star=x-\frac1L\nabla\varphi(x)$ 处取得，最小值为 $\varphi(x)-\frac{1}{2L}\|\nabla\varphi(x)\|^2$（《高等数学》配方，或代入展开）。左端取下确界 $\varphi(y)$，得
$$\varphi(y)\ \ge\ \varphi(x)-\frac{1}{2L}\|\nabla f(x)-\nabla f(y)\|^2,$$
即
$$f(y)-f(x)-\nabla f(y)^\top(y-x)\ \le\ \frac{1}{2L}\|\nabla f(x)-\nabla f(y)\|^2. \tag{$\ast$}$$

**第三步：交换 $x,y$ 并相加**。把 $(\ast)$ 中 $x,y$ 互换（$f$ 的假设对称）：
$$f(x)-f(y)-\nabla f(x)^\top(x-y)\ \le\ \frac{1}{2L}\|\nabla f(x)-\nabla f(y)\|^2.$$
两式相加，左端函数值项消去：
$$\big(\nabla f(x)-\nabla f(y)\big)^\top(x-y)\ \ge\ \frac{1}{L}\|\nabla f(x)-\nabla f(y)\|^2.\qquad(\text{co-coercivity})$$

**第四步：Cauchy–Schwarz 收尾**。记 $\Delta=\nabla f(x)-\nabla f(y)$：
$$\frac{1}{L}\|\Delta\|^2\ \le\ \Delta^\top(x-y)\ \le\ \|\Delta\|\,\|x-y\|.$$
若 $\Delta\ne0$，两边除以 $\|\Delta\|$：$\|\Delta\|\le L\|x-y\|$；$\Delta=0$ 时显然。$\blacksquare$

**顺带收获**：第三步的 co-coercivity 是比 Lipschitz 更强的性质（常数 $1/L$），第 5 章部分 SGD 分析用它；第二步的"最小化抛物线帽"技巧在第 3 章 proximal/第 4 章对偶构造中反复出现。

### 2.6 最优固定步长的收敛因子与迭代数计算

**对应正文**：2.6.2 节。

**谱分析证明**。二次函数 $f(x)=\frac12x^\top Ax-b^\top x$（$A\succ0$），误差 $e_k=x_k-x^\star$ 满足 $e_{k+1}=(I-\eta A)e_k$。$A$ 对称正定可正交对角化（《线性代数》第 4 章），各特征方向独立衰减，因子 $1-\eta\lambda_i$。误差范数的最坏衰减因子为
$$\rho(\eta)=\max_i|1-\eta\lambda_i|=\max\big(|1-\eta\lambda_{\min}|,\ |1-\eta\lambda_{\max}|\big).$$
最优 $\eta$ 让两端的 $|1-\eta\lambda|$ 相等（一个取正、一个取负，中点平衡）：$1-\eta\lambda_{\min}=-(1-\eta\lambda_{\max})$，解得
$$\eta^\star=\frac{2}{\lambda_{\min}+\lambda_{\max}},\qquad \rho^\star=1-\eta^\star\lambda_{\min}=\frac{\lambda_{\max}-\lambda_{\min}}{\lambda_{\max}+\lambda_{\min}}=\frac{\kappa-1}{\kappa+1}.$$
（$\rho^\star$ 关于 $\eta$ 是两段绝对值折线的下凸交点，极小必在交点处——一元极值。）✓

**迭代数计算**。要求 $\rho^{\star k}\le10^{-6}$，$\kappa=10^4$：
$$k=\frac{\ln10^{-6}}{\ln\rho^\star}=\frac{-6\ln10}{\ln\dfrac{\kappa-1}{\kappa+1}}.$$
由 $\ln\frac{\kappa-1}{\kappa+1}=\ln\big(1-\frac{2}{\kappa+1}\big)\approx-\frac{2}{\kappa+1}$（$\kappa$ 大时泰勒一阶近似，相对误差 $\sim\frac{1}{\kappa}$）：
$$k\approx\frac{6\ln10\,(\kappa+1)}{2}\approx3\ln10\cdot\kappa\approx6.91\times10^4.$$
**校验对照**：精确计算 $\ln\frac{9999}{10001}=-2.0002\times10^{-4}$，$k=13.8155/2.0002\times10^{-4}=69077.6$，与正文"约 $0.5\kappa\ln10^6\approx6.9\times10^4$ 步"一致 ✓（$0.5\kappa\ln10^6=0.5\times10^4\times13.8155=69077.5$）。

## 编程实现

### 2.7 最优步长 GD 与共轭梯度法（CG）对比

**对应正文**：2.6.2 节、3.8.2 代码框架。

**参考实现（已运行验证，`rng(0)`，$\kappa=10^3$，$d=50$）**：

```python
import numpy as np
rng = np.random.default_rng(0)
d = 50
Q, _ = np.linalg.qr(rng.normal(size=(d, d)))
lam = np.sort(np.concatenate([np.logspace(0, 1.5, d//2),
                              np.logspace(-1.5, 0, d - d//2)]))   # 谱铺满 [0.0316, 31.6]
A = Q @ np.diag(lam) @ Q.T            # 条件数 kappa = 1000 的对称正定阵
b = rng.normal(size=d)
xs = np.linalg.solve(A, b)            # 精确解
L, mu_ = lam.max(), lam.min()

# ---- (1) 最优固定步长 GD: eta* = 2/(mu+L) ----
eta = 2.0/(mu_ + L)
x = np.zeros(d); hit = None
for k in range(1, 500001):
    x = x - eta*(A @ x - b)
    if np.linalg.norm(x - xs) <= 1e-8*np.linalg.norm(xs):
        hit = k; break
print(hit)    # 实际输出: 8393   (理论最坏情形 0.5*kappa*ln(2e8)≈9210, 本初值略快)

# ---- (2) 共轭梯度法 (标准五式) ----
x = np.zeros(d); r = b.copy(); p = r.copy(); rs = r @ r
bn = np.linalg.norm(b); kcg = None
for k in range(1, d + 3):
    Ap = A @ p
    alpha = rs / (p @ Ap)                 # 步长 = |r|^2 / p'Ap
    x = x + alpha * p
    r = r - alpha * Ap                    # 残差 = -梯度
    rs_new = r @ r
    if np.linalg.norm(x - xs) <= 1e-8*np.linalg.norm(xs):
        kcg = k; break
    p = r + (rs_new / rs) * p             # 共轭方向修正
    rs = rs_new
print(kcg)    # 实际输出: 91    (d=50: "有限步收敛"的浮点体现, 比 GD 快两个数量级)
# 补充: 以相对残差为判据时, CG 在 79/91/100/102 步达到 1e-6/1e-8/1e-10/1e-12,
#        同精度下 GD(eta*) 需要 6037/8339/10642 步。
```

**结果解读**：
- **CG 的"有限步收敛"**：精确算术下，CG 的残差落在 Krylov 子空间 $\mathcal K_k=\operatorname{span}\{b,Ab,\dots,A^{k-1}b\}$ 中，$k=d$ 时子空间张满 $\mathbb R^d$、残差必须为零（共轭方向两两 $A$-正交、极小化 $A$-范数误差）。$d=50$ 的实测 91 步（而非 50）体现了浮点舍入对正交性的破坏（损失正交性使有限终止被"延迟"），但两个数量级的差距（8393 vs 91）毫无悬念。小规模自检：$d=5$、5 个不同特征值时本实现恰在第 5 步达 $10^{-16}$——有限步收敛在无舍入干扰时精确成立。
- **为什么 CG 快**：CG 在第 $k$ 步极小化误差的 $A$-范数于 $\mathcal K_k$ 上，等价于对谱做最优多项式逼近——其收敛因子由 $\frac{\sqrt\kappa-1}{\sqrt\kappa+1}$ 控制（条件数开平方），正是第 3 章"加速"主题的先声。

### 2.8 病态尺度特征下的岭回归：标准化前后对比

**对应正文**：2.2 节"典型实例"、2.6.1 节"特征标准化"的几何解释。

```python
import numpy as np
from sklearn.datasets import make_regression

Xr, yr = make_regression(n_samples=200, n_features=10, n_informative=10,
                         noise=10.0, random_state=0)
scales = np.logspace(-3, 3, 10)          # 各列尺度从 1e-3 到 1e3
Xs = Xr * scales
lam = 0.01

def ridge_iters(X, y, lam, maxit=200000, tol=1e-10):
    n, d = X.shape
    A = X.T @ X / n + lam*np.eye(d)
    c = X.T @ y / n
    w_star = np.linalg.solve(A, c)
    Lm = np.linalg.eigvalsh(A).max()
    w = np.zeros(d)
    for k in range(1, maxit+1):
        w = w - (A @ w - c)/Lm           # 步长 1/L
        if np.linalg.norm(w - w_star) <= tol*max(1.0, np.linalg.norm(w_star)):
            return k, Lm/np.linalg.eigvalsh(A).min()
    return maxit, Lm/np.linalg.eigvalsh(A).min()

k_raw, kap_raw = ridge_iters(Xs, yr, lam)
Xn = (Xs - Xs.mean(0)) / Xs.std(0)
k_nor, kap_nor = ridge_iters(Xn, yr, lam)
print(k_raw, kap_raw)   # 实际输出: 200000 1.001e+08  (未达标, 打满上限)
print(k_nor, kap_nor)   # 实际输出: 26     1.764
```

**结果解读**：未标准化时各列尺度跨 6 个数量级，$X^\top X$ 的特征值跨度被推高到 $\kappa\approx1.0\times10^8$，梯度法 20 万步仍未达 $10^{-10}$ 相对精度（按 $(1-1/\kappa)^k$ 的速率需要约 $\kappa\ln(1/\varepsilon)\sim1.8\times10^9$ 步）；标准化（减均值除标准差）后 $\kappa$ 降到 1.76，**26 步**收敛。这正是 2.6.1 节"峡谷→圆碗"的定量版本：标准化没有改变问题解，只改变了碗的形状——优化速度由条件数而非问题本身决定。

## 开放思考

### 2.9 "学习率 0.1 会炸、0.01 太慢"的定量解释框架

**对应正文**：2.3.1 节步长四区间、2.6 节病态几何。

**框架**：局部曲率上界 $L_{\text{local}}$（可由损失 Hessian 的最大特征值或幂迭代估计）决定四个区间：
1. $\eta<1/L$：单调下降（曲线平滑）；
2. $\eta=1/L$：陡方向一步到谷底（理想）；
3. $1/L<\eta<2/L$：震荡但收敛（loss 曲线锯齿、折返）；
4. $\eta>2/L$：沿最大曲率方向发散（loss → NaN 或暴涨）。

**诊断信号 → 区间定位**：
| 观察到的现象 | 诊断 |
|---|---|
| loss 单调下降但缓慢、梯度范数各分量尺度悬殊 | 区间 1 + 高 $\kappa$（峡谷），该调的是预处理/标准化/动量，而非步长 |
| loss 下降中高频折返（zigzag）、梯度范数不降 | 区间 3，步长在 $(1/L,2/L)$，减半即可回到区间 1 |
| loss 暴涨/NaN，通常发生在训练初期 | 区间 4，$\eta>2/L$；或梯度异常值（clip 检查） |
| loss 卡在平台、$\|\nabla\|\approx0$ | 不是步长问题（第 6 章鞍点/平原/饱和），先看梯度范数再下结论 |

**"0.1 炸、0.01 慢"的定量口径**：设 $L_{\text{local}}\approx25$（常见于未标准化的中小网络），则 $2/L=0.08<0.1$——0.1 落在发散区；0.01 落在区间 1 但有效因子 $1-\eta\mu$（$\mu$ 可能 $\ll1$）接近 1，沿缓方向每步只前进 $\eta\mu$ 比例，故慢。**实践动作**：先标准化/白化抬高 $\mu$、压低 $L$，再在区间 1 上半段取 $\eta$，配合 warmup 覆盖初期 $L$ 估计不准的风险（第 5 章）。

### 2.10 线搜索为何在 SGD 中缺席

**对应正文**：2.3 节、5.2 节。

**(a) 目标不匹配**：线搜索比较的是"完整目标 $f$"沿方向的取值，但 SGD 每步只有小批量子集 $f_B$。以 $f_B$ 判 Armijo 条件，其右端 $\alpha\eta\|g_B\|^2$ 是与噪声同量级的信号——噪声（方差 $\sigma^2/B$）会淹没充分下降量的判断：可能接受实际上升的步（伪下降）、也可能拒绝好步（浪费）。要让判据可靠，$B$ 必须随精度提高而增大——这恰是 SGD 想避免的。

**(b) 代价结构**：SGD 的优势是每步 $O(B)$ 便宜；回溯线搜索每次试探要重算 $f_B$（前向全量代价）甚至梯度，多次试探直接抵消随机化的速度红利，且线搜索得到的"精确步长"在下一个数据点上立刻失效（$f$ 换了）。

**实践替代**：调度式衰减（step/cosine/warmup）+ 可信的 $\eta_0$（lr range test，第 5 章 5.6.2）——把"每步自适应"换成"按预算自适应"。全批量或方差已缩减（SVRG 类，第 5 章进阶）场景下线搜索才重新可用。

## 挑战题

### 2.11（研究生层次）Nesterov 下界思想的证明骨架

**对应正文**：2.12 节进阶方向 1、Nesterov 书 2.1.2。

**要证**：存在 $L$-光滑凸函数类中的一个函数，使任何"只用梯度信息"的一阶方法满足 $f(x_k)-f^\star\ge\frac{L\|x_0-x^\star\|^2}{2(k+1)^2}$ 型下界（对 $k$ 小于某规模）。

**骨架（五步）**：
1. **对抗函数构造**。在 $\mathbb R^{k+1}$ 上定义分段二次"病态链"：
$$f_k(x)=\frac{L}{4}\Big[\frac12 x_1^2+\sum_{i=1}^{k}(x_i-x_{i+1})^2\Big]-\frac{L}{4}x_1\quad(\text{Nesterov 2.1.2 的形式})，$$
光滑常数恰为 $L$，且 $x^\star$ 各分量是等差（$\frac{k+1-i}{k+2}$ 型），$\|x^\star\|^2\approx\frac{k}{3}$ 量级、$f^\star\approx-\frac{L}{4}\cdot\frac{k}{k+2}$。
2. **信息集论证（关键）**。一阶方法从 $x_0=0$ 出发，每步的迭代都是历史梯度的线性组合，故 $x_k$ 只落在 $\mathcal S_k=\operatorname{span}\{\nabla f(x_0),\dots,\nabla f(x_{k-1})\}$——一个至多 $k$ 维子空间。而上述 $f_k$ 设计成：其负梯度方向序列把"发现 $x_1$ 方向上的改进"推迟，使任何 $\mathcal S_k$ 中的点 $x$ 满足 $\|x-x^\star\|^2\ge\frac{1}{(k+1)^2}\|x^\star\|^2$ 型下界（由坐标金字塔结构逐层归纳）。
3. **光滑性换函数值**。由 $L$-光滑的下界 $f(x)\ge f^\star+\frac{\mu_k}{2}\|x-x^\star\|^2$（对该函数局部强凸，$\mu_k\approx L/(k+1)^2$ 段落），把距离下界翻译成 $f(x_k)-f^\star\ge\frac{L\|x^\star\|^2}{c(k+1)^2}$。
4. **降维一致性**。对 $n\le k$，把 $f_n$ 嵌入 $\mathbb R^k$ 的前 $n$ 个坐标；方法在 $k$ 步内表现不会优于其在 $\mathbb R^{k+1}$ 上的表现——即"维数增长不断供"，下界对所有 $n$ 成立。
5. **结论与上界对齐**。$\Theta(1/k^2)$ 是一阶方法在该函数类的精确复杂度；GD 的 $1/k$ 差一个 $k$ 因子，NAG 恰达下界（其 $O(1/k^2)$ 与本下界同阶）→ NAG 是**最优**一阶方法。

**关键技巧词**：抵抗性函数（resisting oracle）、信息集维数、分段二次的"逐层延迟"、最坏初值 $x_0=0$。完整细节见 Nesterov 书 2.1.2 或 Bubeck《Convex Optimization: Algorithms and Complexity》3.2 节。

### 2.12（研究生层次）黄金步长 $\eta=\frac{2}{\mu+L}$ 的最优收敛因子 $\frac{\kappa-1}{\kappa+1}$

**对应正文**：2.5 节定理 2.5、2.6.2 节。

**第一步：插值型强凸-光滑不等式**。对 $\mu$-强凸且 $L$-光滑的 $f$，任意 $x,y$：
$$\big(\nabla f(x)-\nabla f(y)\big)^\top(x-y)\ \ge\ \frac{\mu L}{\mu+L}\|x-y\|^2+\frac{1}{\mu+L}\|\nabla f(x)-\nabla f(y)\|^2.\tag{$\dagger$}$$
**证明**：令 $h(x)=f(x)-\frac{\mu}{2}\|x\|^2$，则 $h$ 凸且 $(L-\mu)$-光滑。对 $h$ 用 2.5 题证得的 co-coercivity：
$$\big(\nabla h(x)-\nabla h(y)\big)^\top(x-y)\ \ge\ \frac{1}{L-\mu}\|\nabla h(x)-\nabla h(y)\|^2.$$
代入 $\nabla h=\nabla f-\mu x$，记 $\Delta=\nabla f(x)-\nabla f(y)$、$v=x-y$：
$$\Delta^\top v-\mu\|v\|^2\ \ge\ \frac{1}{L-\mu}\big(\|\Delta\|^2-2\mu\Delta^\top v+\mu^2\|v\|^2\big).$$
整理（把含 $\Delta^\top v$ 的项并到一侧，系数 $1+\frac{2\mu}{L-\mu}=\frac{L+\mu}{L-\mu}$；$v$ 侧系数 $\mu+\frac{\mu^2}{L-\mu}=\frac{\mu L}{L-\mu}$）：
$$\Delta^\top v\ \ge\ \frac{\mu L}{L+\mu}\|v\|^2+\frac{1}{L+\mu}\|\Delta\|^2.\qquad\blacksquare$$

**第二步：距离收缩**。$x^\star$ 处 $\nabla f=0$。记 $v=x_k-x^\star$，$u=\eta\nabla f(x_k)$，则 $x_{k+1}-x^\star=v-u$：
$$\|x_{k+1}-x^\star\|^2=\|v\|^2-2v^\top u+\|u\|^2=\|v\|^2-2\eta\,\Delta^\top v+\eta^2\|\Delta\|^2\qquad(\Delta=\nabla f(x_k)).$$
用 $(\dagger)$（$y=x^\star$）替换 $\Delta^\top v$：
$$\|x_{k+1}-x^\star\|^2\ \le\ \Big(1-\frac{2\eta\mu L}{\mu+L}\Big)\|v\|^2+\Big(\eta^2-\frac{2\eta}{\mu+L}\Big)\|\Delta\|^2.$$
取 $\eta=\dfrac{2}{\mu+L}$：第二个括号 $=\dfrac{4}{(\mu+L)^2}-\dfrac{4}{(\mu+L)^2}=0$（$\|\Delta\|^2$ 项被精确消去——这就是黄金步长的"金"），故
$$\|x_{k+1}-x^\star\|^2\ \le\ \Big(1-\frac{4\mu L}{(\mu+L)^2}\Big)\|v\|^2.$$
而 $1-\frac{4\mu L}{(\mu+L)^2}=\frac{(\mu+L)^2-4\mu L}{(\mu+L)^2}=\frac{(L-\mu)^2}{(L+\mu)^2}=\Big(\frac{\kappa-1}{\kappa+1}\Big)^2$，即
$$\|x_{k+1}-x^\star\|\ \le\ \frac{\kappa-1}{\kappa+1}\,\|x_k-x^\star\|.\qquad\blacksquare$$
对比定理 2.5 的 $1-\mu/L=\Theta(1-1/\kappa)$：$\frac{\kappa-1}{\kappa+1}$ 在 $\kappa$ 大时约为 $1-\frac{2}{\kappa}$，迭代数减半——这与 2.6.2 节二次谱分析一致（那里已见 $\eta^\star=2/(\lambda_{\min}+\lambda_{\max})$ 给出同因子）。

**数值验证（已运行）**：取 $\mu=1,L=100$（$\kappa=100$），$\eta=2/101$，从 $(1,1)$ 跑 GD：经验因子 $\|e_{201}\|/\|e_{200}\|=0.98019802$，理论 $(\kappa-1)/(\kappa+1)=99/101=0.98019802$——**逐位吻合**。再取 $\kappa=10^3$ 的随机谱 QR 矩阵（$d=50$）：达到 $10^{-8}$ 相对误差需 7622 步（最坏情形理论 9210 步；实测更快是因为初值误差未对齐最慢特征方向，收缩因子是逐方向的 $|1-\eta\lambda_i|$ 的加权组合）。

# 第 3 章 无约束优化的加速与二阶方法

## 概念辨析

### 3.1 为什么动量能把条件数依赖从 $\kappa$ 降到 $\sqrt\kappa$，而调小步长不能？

**对应正文**：3.1.2–3.1.3 节、2.6.2 节。

**三句话回答**：
1. 调小步长是**各方向同比例**缩小位移——陡方向更稳了，但缓方向按 $1-\eta\mu$ 衰减得更慢，快慢方向的"比例差" $\kappa$ 一点没变，最坏因子仍由 $1-\eta\lambda_{\min}\approx1-\frac{2}{\kappa+1}$ 决定（2.6.2 节的最优平衡就是这个极限）。
2. 动量对每个特征方向做的是**各自的二阶递推**，其阻尼比依赖 $\eta\lambda_i$：陡方向梯度逐点变号、被指数平均抵消（等效阻尼放大），缓方向梯度同号、被累积（等效步长放大 $\frac{1}{1-\beta}$）——等于给每个方向单独配步长，即**用一阶信息做软性预处理**。
3. 调好 $(\eta,\beta)$ 后最坏因子变为 $\frac{\sqrt\kappa-1}{\sqrt\kappa+1}\approx1-\frac{2}{\sqrt\kappa}$——条件数开平方的本质是"每个方向按自己的曲率匹配步长"而不是"全体迁就最大曲率"。

### 3.2 NAG 的"提前刹车"与最敏感地形

**对应正文**：3.2.1–3.2.2 节、3.8.2 代码。

重球法的梯度取在"已经滑出去"的位置 $x_k$（历史速度已包含上一段的加速度），惯性大时会冲过谷底才被新梯度拉回；NAG 在前瞻点 $y_k=x_k+\gamma_k(x_k-x_{k-1})$ 处取梯度——**预演了"如果继续滑会到哪"再测坡度**：若前方上坡，前瞻点梯度已经反向，速度在冲过谷底**之前**就开始衰减。数学上：两者特征方程不同，NAG 的根在复平面上被放到阻尼更优的位置（3.2.2 节直觉 (b)）。
**差异最明显的地形**：(i) 共振型病态（重球法在某些 $(\eta,\beta)$ 下发散而 NAG 不发散，见 3.12 题）；(ii) 弯曲峡谷（Rosenbrock：重球冲进谷后震荡，NAG 显著更稳，见 3.8.2 的预期输出）。在光滑圆碗上两者几乎无差别。

### 3.3 L-BFGS 记忆长度 $m$ 的两端权衡

**对应正文**：3.4.3 节。

- **$m$ 太小**（如 $m=1\sim2$）：可用曲率信息只有最近一两步的梯度差，$H_k$ 重建质量差，行为退化为带缩放的梯度法，收敛逼近 $O(1/k)$ 型，失去"学曲率"的优势。
- **$m$ 太大**（如 $m\to n$）：内存 $O(mn)$ 与每步 $O(m^2n)$ 递推代价上升，逼近完整 BFGS；且陈旧 $(s_i,y_i)$ 对来自远离当前点的区域，在弯曲谷底（曲率随位置变化快）这些过时信息会污染方向——**记忆的价值前提是"最近的历史代表现在的曲率"**。
- 实践：$m=5\sim20$ 几乎总是够用；曲率随位置变化剧烈时宁可调小 $m$ 并靠线搜索保证每步质量。

### 3.5 牛顿法在二次函数上一步到位；为何非二次失效

**对应正文**：3.3.1 节、3.9 节误区 3。

**推导**。$f(x)=\frac12x^\top Ax-b^\top x$（$A\succ0$），$\nabla f(x)=Ax-b$，$\nabla^2f=A$。牛顿步：
$$s=-A^{-1}\nabla f(x)=-A^{-1}(Ax-b)=-\big(x-A^{-1}b\big).$$
迭代：$x_{k+1}=x_k+s=x_k-x+A^{-1}b=A^{-1}b=x^\star$。**一步到位**，与 $x_0$ 无关。✓

**非二次上为何失效**。牛顿步是"二阶泰勒二次模型 $m_k(s)=f(x_k)+\nabla f_k^\top s+\frac12s^\top H_ks$"的极小点，两个前提在非二次函数上都会坏：
1. **局部性**：$m_k\approx f$ 只在 $s$ 小时成立。远离 $x^\star$ 时模型极小点可能远离真实函数的下降区（模型外涨），一步跨出有效范围——需阻尼/线搜索/信任域限制。
2. **曲率失真**：$H_k$ 沿途变化（Lipschitz Hessian 的 $M\|s\|$ 误差），且在非凸区 $H_k$ 不定——模型可能没有极小（鞍型），解出的 $s$ 甚至满足 $\nabla f^\top s>0$（上升方向，3.9 节误区 3），需要 $H+\tau I$ 正则化。

### 3.6 BFGS 的割线方程验证与正定性保持（含正文勘误）

**对应正文**：3.4.1–3.4.2 节。

> **勘误（本册勘误索引 4）**：正文式 (3.6) 写"$y_k\approx\nabla^2f(x_{k+1})s_k\iff H_{k+1}s_k=y_k$（对逆 Hessian $H$）"。后半箭头方向有误：若 $H\approx\nabla^2f^{-1}$，由 $\nabla^2f(x_{k+1})s_k\approx y_k$ 两边左乘 $\nabla^2f^{-1}$ 得 $s_k\approx\nabla^2f^{-1}y_k=Hy_k$。**正确割线方程组**为
> $$B_{k+1}s_k=y_k\ \ (\text{对 } B\approx\nabla^2f),\qquad H_{k+1}y_k=s_k\ \ (\text{对 } H\approx\nabla^2f^{-1}).$$
> 数值证伪：随机对称正定 $H$、随机 $(s,y)$（$y^\top s>0$），按式 (3.7) 更新后 $\|H_{k+1}s-y\|=5.5$（不成立），而 $\|H_{k+1}y-s\|=4.5\times10^{-16}$（成立）；$B$-更新满足 $\|B_{k+1}s-y\|=9.1\times10^{-16}$。故本练习按**正确方向**验证。

**（a）$H_{k+1}y_k=s_k$（代入验证）**。记 $\gamma=y_k^\top s_k>0$，$U=I-\dfrac{y_ks_k^\top}{\gamma}$，式 (3.7) 即 $H_{k+1}=U^\top H_kU+\dfrac{s_ks_k^\top}{\gamma}$。算 $Uy_k=y_k-\dfrac{s_k(y_k^\top y_k)}{\gamma}$……先算关键的 $y_k^\top s_k=\gamma$：
$$Uy_k=y_k-\frac{y_k(s_k^\top y_k)}{\gamma}=y_k-\frac{y_k\gamma}{\gamma}=0.$$
于是第一项消失：
$$H_{k+1}y_k=U^\top H_k\underbrace{(Uy_k)}_{=0}+\frac{s_k\big(s_k^\top y_k\big)}{\gamma}=0+\frac{s_k\gamma}{\gamma}=s_k.\qquad\blacksquare$$
（对称地，$B_{k+1}s_k=B_ks_k+y_k-\frac{B_ks_k(s_k^\top B_ks_k)}{s_k^\top B_ks_k}=B_ks_k+y_k-B_ks_k=y_k$。）

**（b）$y_k^\top s_k>0\Rightarrow H_{k+1}$ 对称正定**。对称性显然（$U^\top H U$ 与 $ss^\top/\gamma$ 都对称）。对任意 $z\ne0$，记 $c=\dfrac{z^\top s_k}{\gamma}$，$w=z-c\,y_k$（即 $w=Uz$）：
$$z^\top H_{k+1}z=(Uz)^\top H(Uz)+\frac{(z^\top s_k)^2}{\gamma}=w^\top H_kw+c^2\,\gamma,$$
末步用 $(z^\top s_k)^2/\gamma=c^2\gamma$。$H_k\succ0\Rightarrow w^\top H_kw\ge0$；$\gamma>0\Rightarrow c^2\gamma\ge0$。若 $z^\top H_{k+1}z=0$，则两项同时为零：$c=0$ 且 $w=0$，即 $z=c\,y_k+y_k\cdot0=z\cdot0\Rightarrow z=0$，与 $z\ne0$ 矛盾（细看：$w=z-cy_k=0$ 且 $c=0\Rightarrow z=0$）。故 $z^\top H_{k+1}z>0$ 对一切 $z\ne0$。$\blacksquare$
（直观：第一项是"被 $y_k$ 方向剪切后的二次型"，剪切恰把 $y_k$ 方向的分量抹零，而秩一项 $s_ks_k^\top/\gamma$ 专门补上 $y_k$ 方向的能量 $c^2\gamma$——这就是"曲率记忆 + 沿最新方向保底"的结构。$y_k^\top s_k>0$ 正是凸函数沿线搜索的必然结果：$\int_0^1\nabla^2f\ \mathrm ds$ 型平均曲率沿位移的方向分量。）

## 编程实现

### 3.7 Rosenbrock：回溯 GD 与阻尼牛顿法的二次收敛验证

**对应正文**：3.8.2 代码、3.3.2 节定理 3.5。

```python
import numpy as np

def f(p):
    x, y = p
    return (1-x)**2 + 100.0*(y-x*x)**2
def grad(p):
    x, y = p
    return np.array([-2*(1-x) - 400*x*(y-x*x), 200*(y-x*x)])
def hess(p):
    x, y = p
    return np.array([[2 + 400*(3*x*x - y), -400*x], [-400*x, 200.0]])
xstar = np.array([1.0, 1.0])

# ---- (1) 回溯线搜索 GD ----
x = np.array([-1.2, 1.0])
for k in range(2000):
    g = grad(x); e = 1.0
    while f(x - e*g) > f(x) - 0.3*e*(g@g):     # Armijo 充分下降
        e *= 0.5
    x = x - e*g
    if np.linalg.norm(x - xstar) < 1e-8: break
print(k)     # 实际输出: 600   (回溯GD 达到 1e-8 需要 600 步)

# ---- (2) 阻尼牛顿: 先 GD 走 80 步, 再切纯牛顿观察二次收敛 ----
x = np.array([-1.2, 1.0])
for _ in range(80):                              # GD 80 步, 误差约 1.5e-3
    g = grad(x); e = 1.0
    while f(x - e*g) > f(x) - 0.3*e*(g@g): e *= 0.5
    x = x - e*g
errs = [np.linalg.norm(x - xstar)]
for k in range(6):                               # 纯牛顿步 + Armijo
    g = grad(x)
    s = np.linalg.solve(hess(x), -g)             # H 正定区可直接解
    e = 1.0
    while f(x + e*s) > f(x) + 0.3*e*(g@s): e *= 0.5
    x = x + e*s
    errs.append(np.linalg.norm(x - xstar))
print([f"{e:.3e}" for e in errs])
# 实际输出: ['1.529e-03', '1.252e-06', '7.637e-11', '0.000e+00', ...]
print([f"{errs[i+1]/errs[i]**2:.3f}" for i in range(2)])
# 实际输出: ['0.536', '48.700']   (比值有界: 误差有效位数每步翻倍)
```

**结果解读（校验对照）**：
- 回溯 GD 600 步达 $10^{-8}$；牛顿法从误差 $1.5\times10^{-3}$ 出发：$1.5\times10^{-3}\to1.3\times10^{-6}\to7.6\times10^{-11}\to0$（机器零）——误差的**有效位数每步翻倍**（$10^{-3}\to10^{-6}\to10^{-11}\to10^{-16}$），即二次收敛 $\|e_{k+1}\|\le\frac{M}{\mu}\|e_k\|^2$ 的直接体现 ✓。
- 比值 $e_{k+1}/e_k^2$ 打印为 $0.536\to48.7\to0$：常数化被两个因素扰动——第一步 Armijo 接受了收缩步（$e<1$），且 Rosenbrock 的 $M/\mu$ 量级很大、两步内就打穿机器精度，样本不足以展示"趋于常数"；误差序列本身才是二次收敛的干净证据。
- 若加 $H+\tau I$ 正则（$\tau$ 从 $10^{-2}$ 退火到 0），前几步更稳，近末端须 $\tau\to0$ 才能看到上述序列。

### 3.8 高斯-牛顿拟合 $y=a e^{bx}$

**对应正文**：3.5 节。

```python
import numpy as np
from scipy.optimize import least_squares

rng = np.random.default_rng(0)
n = 100
t = np.linspace(0.1, 2.0, n)
a_true, b_true = 2.5, -1.3
ydata = a_true*np.exp(b_true*t) + 0.01*rng.normal(size=n)   # 小噪声

def r_vec(p):      # 残差向量
    a, b = p
    return a*np.exp(b*t) - ydata
def J_mat(p):      # 雅可比 J[i,:] = [dr_i/da, dr_i/db]
    a, b = p
    return np.column_stack([np.exp(b*t), a*t*np.exp(b*t)])

p = np.array([1.0, 0.5])
for k in range(30):
    r, J = r_vec(p), J_mat(p)
    delta = np.linalg.solve(J.T @ J, -J.T @ r)   # GN 步: 正规方程
    p = p + delta
    if np.linalg.norm(delta) < 1e-12: break
print(k+1, p)    # 实际输出: 7 [2.496193 -1.296222]

res = least_squares(r_vec, np.array([1.0, 0.5]), method='lm')
print(res.x, res.nfev)   # 实际输出: [2.496193 -1.296222] 7
```

**结果解读（校验对照）**：GN **7 步**收敛（相邻迭代差 $<10^{-12}$），scipy 的 LM 给出完全相同的解、同样 7 次函数求值——满足校验"小噪声下 GN 约 5–10 步收敛"✓。拟合值 $a=2.4962,\ b=-1.2962$ 与真值 $(2.5,-1.3)$ 的差由噪声（0.01）决定，不是算法误差。注意 GN 步在初值 $(1.0,0.5)$ 处就"走对路"的原因：$J^\top J\succ0$（本例两列线性无关），方向自动下降；若初值很远或残差大，需要 LM 阻尼 $\lambda I$（$\lambda$ 大退化为梯度步）。

## 开放思考

### 3.9 深度学习为何不用 L-BFGS（三句理由）

**对应正文**：3.9 节误区 5、5.6 节。

(a) **噪声结构**：小批量梯度差 $y_k=g_{k+1}-g_k$ 的"曲率信息"被梯度估计噪声（方差 $\sigma^2/B$）污染，割线方程的假设失效——L-BFGS 累积的是"噪声差"而非"Hessian 作用"，记忆对 $(s_i,y_i)$ 越多越不可靠；要降噪就得加大批量，回到全批量的代价。
(b) **在线/流式数据**：目标随数据流漂移，历史 $(s_i,y_i)$ 对应的是"旧目标"的曲率，二阶记忆过期即失效；SGD 家族无状态（或短记忆），天然适配非平稳。
(c) **非凸导航**：L-BFGS 是确定性下降类方法，在鞍点/平坦区与 GD 一样会被吸附（无噪声逃离机制，第 6 章）；深度学习恰恰需要噪声的探索性与"大步穿越平原"的隐式正则。此外 $O(mn)$ 内存虽省，但亿级参数下每步双循环 + 严格线搜索的工程负担仍远高于一次性 $-\eta v$ 更新。

### 3.10 动量系数 $\beta$ 的调整依据

**对应正文**：3.1.1 节（$1/(1-\beta)$ 记忆）、5.4 节（随机降噪）。

**调大 $\beta$（$0.95\sim0.99$）**：梯度方向**自相关时间长**的任务——大批量（噪声小、方向一致）、低学习率后期精修、深网络长 valley；记忆长，等效步长放大 $1/(1-\beta)\uparrow$，降噪比 $(1-\beta)/(1+\beta)\downarrow$。
**调小 $\beta$（$0.5\sim0.8$）**：梯度方向**频繁翻转**的场景——小批量强噪声、RL 策略梯度（不同 trajectory 方向杂乱）、训练初期冷启动（warmup 阶段常配小动量）；此时长记忆会累积噪声甚至共振发散（3.1.2 节稳定域变窄）。
**判据**：监测相邻迭代梯度的余弦相似度 $\cos(g_k,g_{k-1})$ 的时均——持续为正说明方向自相关长，宜大 $\beta$；在 0 附近震荡说明噪声主导，宜小 $\beta$。另一个实操信号：loss 曲线在谷底附近的高频震荡幅度。

## 挑战题

### 3.11（研究生层次）Nesterov 估计序列证明（定理 3.3）骨架

**对应正文**：3.2.2 节直觉 (c)、Nesterov 书 2.2 节、Bubeck 书 3.3 节。

**目标**：凸 $L$-光滑、$\eta=1/L$、$\gamma_k=k/(k+3)$ 下 $f(x_k)-f^\star\le\frac{2L\|x_0-x^\star\|^2}{(k+1)^2}$。

**骨架（五步）**：
1. **维护下界函数族**。定义"估计序列" $\phi_k(x)=\lambda_k\big(f(x)-f^\star\big)+\frac{L}{2}\|x-v_k\|^2$（$\lambda_0=1$），它是 $f$ 的抛物线型下界的加权和；$v_k$ 是辅助点（"想象中的极小"）。
2. **两条递推**。每步选择 $\gamma_k$ 并更新 $v_{k+1}=y_k-\frac{1}{L}\nabla f(y_k)$（即 NAG 的前瞻点处一步），要求 $\lambda_{k+1}=(1-\gamma_k)\lambda_k$ 与 $\gamma_k^2=\gamma_{k-1}$… 型关系（具体取 $\gamma_k^2L=\lambda_k\gamma_k$ 的配平方案），使 $\lambda_k\ge\frac{(k+1)^2}{4}$ 型增长。
3. **关键引理（一步收缩）**。用 $L$-光滑与凸性证明：$A_{k+1}:=\lambda_{k+1}(f(x_{k+1})-f^\star)+\frac L2\|x_{k+1}-v_{k+1}\|^2\le A_k$，即势函数 $A_k$ 单调不增。证明核心是把 $f(x_{k+1})$ 的下降引理、$f(y_k)$ 的切线不等式与 $\|v_{k+1}-v_k\|^2$ 的配方逐项对消——三段能量恰好平衡（这是估计序列法最精巧的一步）。
4. **从势函数到目标**。$A_0=\frac L2\|x_0-v_0\|^2=\frac L2\|x_0-x^\star\|^2$（$v_0=x_0$），而 $\frac L2\|x_{k+1}-v_{k+1}\|^2\ge0$，故 $\lambda_{k+1}\big(f(x_{k+1})-f^\star\big)\le A_{k+1}\le A_0$，代入 $\lambda_k\sim\frac{(k+1)^2}{4}$ 得式 (3.4)（常数按具体配平方案为 2）。
5. **与 GD 的对照**：同一框架若用普通梯度步（$\gamma=0$）只能得 $\lambda_k\le k$ 级增长 → $O(1/k)$；NAG 的前瞻步把"势函数中二次项的驻点"前移，使 $\lambda$ 能二次增长——这就是"看一步再走"在证明层的化身。

**复现建议**：先按 Bubeck 3.3 的记号推一遍不变量，再用 3.8.2 的病态二次函数数值验证 $\lambda_k(f(x_k)-f^\star)$ 的单调性。

### 3.12（研究生层次）重球法的发散参数区与稳定性三角

**对应正文**：3.1.2 节、Lessard 等 2016。

**理论侧（先框定再实验）**。二次函数 $f=\frac12x^\top Ax$ 上重球法沿特征方向 $i$ 满足标量二阶递推 $y_{k+1}=(1+\beta-\eta\lambda_i)y_k-\beta y_{k-1}$，特征方程 $r^2-(1+\beta-\eta\lambda_i)r+\beta=0$。由 **Jury 稳定判据**（二阶多项式 $r^2+a_1r+a_0$ 的根全在单位圆内 $\iff$ $1+a_1+a_0>0$、$1-a_1+a_0>0$、$1-a_0>0$；此处 $a_0=\beta\in(0,1)$ 自动满足第三条）：
$$\eta\lambda_i>0\ \text{（自动）},\qquad \eta\lambda_i<2(1+\beta).$$
故对 $\lambda_i\in\{\mu,L\}$，稳定域为 $\eta<2(1+\beta)/L$——**边界随 $\beta$ 上移**（动量允许更大步长）。但收敛**速度**的谱结构出现共振：特征根从双实根变复根的位置 $\eta\lambda_i=(1\pm\sqrt\beta)^2$ 附近，阻尼比骤变，形成 "resonance staircase"——这就是三角图中层状条纹的来源（Lessard 等用 IQC 把二次结论推广到一般凸函数）。

**实验骨架（已验证判据公式）**：
```python
import numpy as np
mu, L, K = 1.0, 20.0, 300
stable = lambda eta, beta: eta*L < 2*(1+beta)      # Jury 判据(最坏方向)
for eta in np.linspace(0.001, 0.15, 30):
    row = ""
    for beta in np.linspace(0.0, 0.99, 40):
        x = np.array([8.0, 8.0]); v = np.zeros(2)
        for _ in range(K):
            v = beta*v - eta*np.array([mu*x[0], L*x[1]]); x = x + v
            if np.linalg.norm(x) > 1e3: break
        row += "." if np.linalg.norm(x) < 1e-4 else ("o" if np.linalg.norm(x) < 1e3 else "X")
    print(row)
# 预期图样: 左下角大片 "."(收敛); 右上边界附近 "X"(发散),
# 边界位置 eta≈2(1+beta)/L 随 beta 增大而右移; 收敛区内可见收敛速率的阶梯条纹(resonance)。
```
**要点**：(i) 收敛判据要在足够多步数后按"误差 $<10^{-4}$"而非"不发散"判定（存在收敛极慢区）；(ii) 把 $L$ 换成 25/50 看边界横坐标按 $2(1+\beta)/L$ 缩放；(iii) 与 GD（$\beta=0$ 列）对照：稳定域 $\eta<2/L$，与第 2 章 2.3.1 的结论一致。

# 第 4 章 约束优化与对偶理论

## 概念辨析

### 4.1 弱对偶"恒成立"为何仍重要（停机准则 + 可行性/无解证明）

**对应正文**：4.2.1–4.2.2 节（定理 4.2）、4.9 节误区 1。

**为什么"恒成立"是价值而非废话**：弱对偶的推导只用了两步——式 (4.3)（可行点上 $\mathcal L\le f_0$）与"下确界不超过任何取值"——因此它对**任何**优化问题、**任何**可行乘子 $(\lambda\ge0,\nu)$ 无条件成立。这使它成为唯一"不需要先解题就能用"的证书：强对偶要等凸性 + Slater + 求解成功，弱对偶立刻可用。

**工程用法 1（停机准则/最优性证书）**。同时维护原可行点 $x_k$ 与对偶可行点 $(\lambda_k,\nu_k)$，则
$$g(\lambda_k,\nu_k)\ \le\ p^\star\ \le\ f_0(x_k),$$
两端都是**可计算的数**，其差 $f_0(x_k)-g(\lambda_k,\nu_k)$ 是真实对偶间隙的上界。内点法、ADMM、分支定界打印的 "gap" 全部由此而来：gap 小于容差即可停机并宣称"$x_k$ 至多比最优差 $\varepsilon$"——这是**双向证书**（原问题给上界、对偶给下界），比"目标值不再下降"这类启发式可靠得多。

**工程用法 2（无解/不可行证明）**。弱对偶的逆否使用：若对偶问题无界（$\sup g=+\infty$），则 $p^\star=+\infty$——**原问题不可行**。线性规划中判定不可行的 Farkas 引理本质上就是一组"见证乘子"：找到它即完成不可行性证明，而寻找它的系统方法恰是解对偶。

*常见错误*：以为"间隙大 ⇒ 对偶没用"。间隙大只说明**这一组**乘子松；弱对偶提供的是"下界机制"而非"具体下界"，收紧靠最大化 $g$（这正是对偶问题本身）。另一个极端是默认间隙为零——非凸或 Slater 失败时间隙可严格为正（4.9 误区 1），此时对偶解只是"最乐观的下界"，用它当停机准则会提前退出。

### 4.2 互补松弛哪个方向是精确命题；SVM 用的是哪一侧

**对应正文**：4.4.1 条件 (c)、4.4.4、4.5.3、4.9 误区 2/4。

**精确命题是"乘子为正 $\Rightarrow$ 约束贴紧"**（等价的逆否形式："松约束 $\Rightarrow$ 乘子为零"）。它是互补松弛 $\lambda_i^\star f_i(x^\star)=0$ 的单向分解：两项乘积为零只保证"至少一个为零"，配合 $\lambda_i^\star\ge0$、$f_i(x^\star)\le0$ 的**符号结构**才得到蕴含方向。而"约束贴紧 $\Rightarrow$ 乘子可能为正"不是精确命题——**贴紧的约束乘子可以严格为零**（该约束在最优解处活跃但不"挡路"：把它微调 $b_i$ 不改变 $p^\star$，多重最优乘子的退化情形）。4.8.1 的例子里唯一约束既贴紧又 $\lambda^\star=1>0$，两个方向碰巧同时成立，不能当作一般证据。

**SVM 的"支持向量"定义用的是"乘子为正"这一侧**：$SV:=\{i:\lambda_i^\star>0\}$。由精确方向立即得 $SV\subseteq\{$函数间隔恰为 1 的样本$\}$；反向不成立——**恰在间隔边界上的样本乘子可能是零**（几何上"贴着边界"但推动它不改变最优解）。工程含义：(i) 实现中先解对偶、用 $\lambda_i>0$（配容差，4.9 误区 4 的 `lam > 1e-5`）挑 SV——这个集合是"对解有贡献"的精确定义；(ii) 想从几何（在边界上）反推 SV 会多挑样本；(iii) 教材里"间隔边界上的点都是支持向量"是经验表述，KKT 层面的定义始终是乘子。

### 4.3 对偶函数恒凹与"对偶问题总凸"的好处

**对应正文**：4.2.1 性质 1、第 1 章 1.5 节运算 4 与 1.11 题。

**证明（两行）**。固定 $x$，$\mathcal L(x,\lambda,\nu)$ 是 $(\lambda,\nu)$ 的**仿射函数**；$g(\lambda,\nu)=\inf_x\mathcal L(x,\lambda,\nu)$ 是仿射函数族的逐点下确界。对 $\theta\in[0,1]$、任意 $z_1,z_2$：
$$g\big(\theta z_1+(1-\theta)z_2\big)=\inf_x\big[(1-\theta)\mathcal L(x,z_1)+\theta\mathcal L(x,z_2)\big]\ \ge\ (1-\theta)\inf_x\mathcal L(x,z_1)+\theta\inf_x\mathcal L(x,z_2),$$
中间一步用"下确界的次可加"$\inf(A+B)\ge\inf A+\inf B$。这正是第 1 章 1.11 题"偏最小化保持凸性"的镜像（把 $-\mathcal L$ 对 $(\lambda,\nu)$ 偏最小化），**证明没有用到 $f_i$ 的任何凸性**——原问题非凸照样成立（例 4.3 的约束 $x^2+y^2\le1$ 非凸，$g$ 依然凹且光滑）。

**三个实际好处**：
1. **算法统一**：无论原问题多病态，"最大化 $g$"是凸问题，可用内点法在可预估的迭代数内解到全局最优（4.12 节进阶 2）——非凸原问题也能得到**可验证的全局下界**；
2. **数值可靠**：凸求解器的行为有理论保证（自和谐理论），工程上"对偶几乎总能解"是对偶作为信赖工具的原因；
3. **建模语言**：影子价格、对偶分解、核化都建立在"$g$ 好算且凹"之上——例如 LASSO 的对偶把变量从 $d$ 维 $w$ 换成 $n$ 维 $\lambda$，在 $n\ll d$ 时更好解。

*常见错误*：把"对偶是凸问题"听成"对偶解 = 原问题解"。凸性只保证**对偶本身好解**；它是否等于 $p^\star$ 由弱/强对偶决定（4.3 节）。

## 计算推导

### 4.4 小 QP 的独立对偶推导与"约束松掉"的变体

**对应正文**：4.8.1、4.4.4（影子价格）。

**（a）复核正文算例**。问题 $\min\ \frac12(x_1-1)^2+\frac12(x_2-2)^2$ s.t. $x_1+x_2\le1$。

$\mathcal L=\frac12(x_1-1)^2+\frac12(x_2-2)^2+\lambda(x_1+x_2-1)$，$\lambda\ge0$。对 $x_1,x_2$ 独立求下确界（两项均为凸二次，梯度置零）：
- $\partial/\partial x_1=(x_1-1)+\lambda=0\Rightarrow x_1=1-\lambda$，代回：$\frac12\lambda^2+\lambda(1-\lambda)=\lambda-\frac{\lambda^2}{2}$；
- $\partial/\partial x_2=(x_2-2)+\lambda=0\Rightarrow x_2=2-\lambda$，代回：$\frac12\lambda^2+2\lambda-\lambda^2=2\lambda-\frac{\lambda^2}{2}$；
- 常数项 $-\lambda$。

$$g(\lambda)=\Big(\lambda-\tfrac{\lambda^2}2\Big)+\Big(2\lambda-\tfrac{\lambda^2}2\Big)-\lambda=-\lambda^2+2\lambda=1-(\lambda-1)^2.$$

对偶问题 $\max_{\lambda\ge0}\,1-(\lambda-1)^2$：$\lambda^\star=1$，$d^\star=1$。KKT 平稳性恢复 $x^\star=(1-1,\ 2-1)=(0,1)$；逐条检验：原始可行（$0+1=1\le1$）✓、对偶可行 ✓、约束贴紧 ✓、$p^\star=\frac12(0-1)^2+\frac12(1-2)^2=1=d^\star$ ✓。全部中间量与题给校验一致。

**（b）约束放宽为 $x_1+x_2\le4$**。拉格朗日只有常数项变化（$-\lambda$ 变 $-4\lambda$）：
$$g(\lambda)=\Big(\lambda-\tfrac{\lambda^2}2\Big)+\Big(2\lambda-\tfrac{\lambda^2}2\Big)-4\lambda=-\lambda^2-\lambda.$$
对一切 $\lambda\ge0$：$g(\lambda)=-\lambda^2-\lambda\le0$ ✓（校验）。且 $g'(\lambda)=-2\lambda-1<0$ 在 $\lambda\ge0$ 恒成立，故对偶最优在左端点 $\lambda^\star=0$、$d^\star=0$。而新问题的无约束最优 $(1,2)$ 满足 $1+2=3\le4$、可行，故 $p^\star=0=d^\star$——强对偶保持，但**乘子为零**。

**影子价格解读**：$\lambda^\star=-\partial p^\star/\partial b|_{b=4}=0$——这条约束"不挡路"（预算过剩），放松到 5、6 目标不会再改善，每单位预算的边际价值为零。与 (a) 的对照最有说服力：(a) 中 $b=1$ 处乘子为 1（每放宽 1 单位、目标改善 1），(b) 中归零。**"松约束零收费"（互补松弛）与影子价格是同一件事的两种说法**。

**附（敏感度公式的显式暖身，为 4.6 题）**：对 $b\le3$ 沿边界最优化：$\varphi(x_1)=\frac12(x_1-1)^2+\frac12(b-x_1-2)^2$，$\varphi'=2x_1-b+1=0\Rightarrow x_1=\frac{b-1}2$、$x_2=\frac{b+1}2$，于是
$$p^\star(b)=\Big(\tfrac{3-b}{2}\Big)^2,\qquad \frac{\partial p^\star}{\partial b}=-\frac{3-b}{2}\ \xrightarrow{b=1}\ -1=-\lambda^\star.\ \checkmark$$

### 4.5 软间隔 SVM 的分段互补松弛与三种几何位置

**对应正文**：4.5.3 末段、4.4.1 条件 (c)。

软间隔原问题：
$$\min_{w,b,\xi}\ \frac12\|w\|^2+C\sum_i\xi_i\quad\text{s.t.}\quad y_i(w^\top x_i+b)\ge1-\xi_i,\ \ \xi_i\ge0.$$
引入两套乘子 $\lambda_i\ge0$（间隔约束）与 $\mu_i\ge0$（$\xi_i\ge0$ 约束——**每个不等式一个乘子，漏掉 $\mu$ 是本题最常见错误**）：
$$\mathcal L=\frac12\|w\|^2+C\sum_i\xi_i-\sum_i\lambda_i\big[y_i(w^\top x_i+b)-1+\xi_i\big]-\sum_i\mu_i\xi_i.$$
平稳性：$\nabla_w\mathcal L=0\Rightarrow w=\sum_i\lambda_iy_ix_i$；$\partial_b\mathcal L=0\Rightarrow\sum_i\lambda_iy_i=0$；$\partial_{\xi_i}\mathcal L=0\Rightarrow C-\lambda_i-\mu_i=0$。最后一式与 $\mu_i\ge0$ 结合给出**盒约束 $0\le\lambda_i\le C$**——软间隔对偶中 $C$ 的来源。互补松弛两条：
$$\lambda_i\big[y_i(w^\top x_i+b)-1+\xi_i\big]=0,\qquad \mu_i\xi_i=(C-\lambda_i)\,\xi_i=0.$$

**三种情形的几何**（对样本 $i$）：
1. **$\lambda_i=0$**：第二式 $\mu_i=C>0\Rightarrow\xi_i=0$；第一式自动满足。函数间隔 $y_i(w^\top x_i+b)\ge1$——分类正确且在间隔带**外（或恰在边界上）**。
2. **$0<\lambda_i<C$**：$\lambda_i>0\Rightarrow y_i(w^\top x_i+b)=1-\xi_i$；同时 $C-\lambda_i>0\Rightarrow\xi_i=0$。两者联立 $y_i(w^\top x_i+b)=1$——**恰在间隔边界上** ✓（与校验一致）。
3. **$\lambda_i=C$**：$\mu_i=0$，$\xi_i\ge0$ 不再被强制为零，$y_i(w^\top x_i+b)=1-\xi_i\le1$——样本落在间隔带**内**（$0<$ 间隔 $<1$）或被**错分**（间隔 $\le0$）。它是"广义支持向量"：惩罚额度被顶满。

*常见错误*：只引入 $\lambda$ 得不出 $\lambda_i\le C$、也分不清情形 2/3；把情形 3 说成"恰在间隔上"（那是情形 2 的专属刻画）。

### 4.6 敏感度公式 $\partial p^\star/\partial b_i=-\lambda_i^\star$ 的证明

**对应正文**：4.4.4、4.6.1。

**设定**：凸问题 $\min f_0(x)$ s.t. $f_i(x)\le b_i$，强对偶成立，$(x^\star(b),\lambda^\star(b))$ 是扰动后问题的最优原始-对偶对，相关函数可微。记 $p^\star(b)$ 为最优值函数。

**第一步（把 $p^\star$ 写成对偶最优值）**。强对偶：$p^\star(b)=d^\star(b)=\max_{\lambda\ge0}g(\lambda;b)$，最大值在 $\lambda^\star(b)$ 取到，其中
$$g(\lambda;b)=\inf_x\Big[f_0(x)+\sum_i\lambda_i\big(f_i(x)-b_i\big)\Big]=h(\lambda)-\lambda^\top b,\qquad h(\lambda):=\inf_x\Big[f_0(x)+\sum_i\lambda_if_i(x)\Big]$$
与 $b$ **无关**（$b$ 只出现在显式的 $-\lambda^\top b$ 项）——这是整个证明的支点。

**第二步（包络定理：对 $\lambda^\star(b)$ 的依赖消失）**。对 $p^\star(b)=g(\lambda^\star(b);b)$ 求全导：
$$\frac{\partial p^\star}{\partial b_i}=\underbrace{\nabla_\lambda g(\lambda^\star;b)^\top\frac{\partial\lambda^\star}{\partial b_i}}_{=\,0}+\frac{\partial g}{\partial b_i}(\lambda^\star;b).$$
第一项为零的理由：$\lambda^\star(b)$ 是内层最大化问题（$\lambda\ge0$ 约束下）的**最优解**——沿"最优解随参数移动的轨迹"求导，一阶项相消（内点最优时 $\nabla_\lambda g=0$；边界最优时对可行方向用方向导数论证，结论相同）。这就是提示所说的"包络定理思想"。

**第三步（读出显式项）**。$\dfrac{\partial g}{\partial b_i}=-\lambda_i$。代入：
$$\boxed{\ \frac{\partial p^\star}{\partial b_i}=-\lambda_i^\star\ }\qquad\blacksquare$$

**两点说明**：(i) 可微性要求紧约束集（active set）在扰动下不变（非退化）；若最优乘子不唯一，$p^\star(b)$ 可能只有方向导数，此时公式对可微点处的任一 $\lambda^\star$ 成立；(ii) 已用 4.4 题的显式例子核对（$p^\star(b)=(3-b)^2/4$，$b=1$ 处导数 $-1=-\lambda^\star$ ✓）。**直觉**：$\lambda^\star$ 是影子价格；$b_i$ 越大约束越松、$p^\star$ 越低，故导数为负、乘子非负——"价格 = 放松约束的边际收益"。

## 编程实现

### 4.7 软间隔 SVM：$C$ 扫描与两条曲线的单调性

**对应正文**：4.8.2 代码、4.5.3 末段。

**参考实现（已运行验证，数据与 4.8.2 完全相同，`rng(0)`）**：

```python
import numpy as np
import cvxpy as cp

rng = np.random.default_rng(0)
n = 40
X_pos = rng.normal(loc=[2, 2], scale=0.7, size=(n//2, 2))
X_neg = rng.normal(loc=[-2, -2], scale=0.7, size=(n//2, 2))
X = np.vstack([X_pos, X_neg])
y = np.concatenate([np.ones(n//2), -np.ones(n//2)])
YX = X * y[:, None]; K = YX @ YX.T          # Gram 矩阵

print(f"{'C':>8} {'SV数':>6} {'间隔2/||w||':>14} {'d*':>10}")
for C in [0.01, 0.1, 1.0, 10.0, 100.0]:
    lmbda = cp.Variable(n)
    obj = cp.Maximize(cp.sum(lmbda) - 0.5*cp.quad_form(lmbda, cp.psd_wrap(K)))
    cons = [lmbda >= 0, lmbda <= C, cp.sum(cp.multiply(lmbda, y)) == 0]
    prob = cp.Problem(obj, cons); prob.solve(solver=cp.CLARABEL)
    lam = lmbda.value; w = YX.T @ lam
    print(f"{C:>8} {int((lam > 1e-5).sum()):>6} {2/np.linalg.norm(w):>14.4f} {prob.value:>10.4f}")
# 实际输出:
#        C   SV数    间隔2/||w||         d*
#     0.01     20        5.3456     0.1135
#     0.1       6        3.2629     0.2266
#     1.0       3        2.8123     0.2529
#     10.0      3        2.8123     0.2529
#     100.0     3        2.8123     0.2529
```

**单调性解读**：
- **$d^\star(C)$ 单调不减**——这是定理而非经验：$C$ 增大只放宽对偶可行域（盒约束 $[0,C]$ 变宽），最大化问题的最优值自然不降；$C\to\infty$ 时趋于硬间隔值 0.2529。
- **间隔 $2/\|w\|$ 随 $C$ 单调不增**：$C$ 小 = 强正则 = 宁可容忍训练误差也要短 $\|w\|$（宽间隔），$C$ 大 = 逼近硬间隔的最短 $\|w\|$。
- **SV 个数随 $C$ 增大而减少**（$20\to6\to3$）：$C$ 大时"顶满" $\lambda_i=C$ 的间隔内/错分样本消失（4.5 题情形 3 退化），只剩真正的边界支持向量。注意这**不保证对一切数据集逐点单调**（SV 数是整数、可能跳变），但"小 $C$ 制造更多间隔内样本 ⇒ 更多非零乘子"的机制是普适的。
- $C\ge10$ 后三列完全不变——数据线性可分时 $C$ 超过某阈值后软间隔与硬间隔同解（没有样本需要"赦免"）。

### 4.8 手写投影梯度法解原问题 (4.7)：与对偶解对比

**对应正文**：4.5.1–4.5.2（式 4.7/4.9）、第 1 章 1.12 题（投影特征不等式）、4.9 误区 5。

**方法设计**。原问题 $\min\frac12\|w\|^2$ s.t. $y_i(w^\top x_i+b)\ge1$：变量 $z=(w,b)\in\mathbb R^3$，可行集是 $n$ 个**半空间** $\{z:a_i^\top z\ge1\}$（$a_i=y_i[x_i;1]$）之交——每个半空间的投影有闭式解；到**交集**的精确投影用 **Dykstra 算法**（循环投影 + 修正项；普通循环投影会停在交集中"任意"一点而非离起点最近的一点，不满足本题求最小范数点的需要——这比题面提示的"向最近违反点的次梯度步近似"更精确）。目标 $F(w,b)=\frac12\|w\|^2$ 的梯度为 $(w,0)$，光滑常数 $L=1$，投影梯度迭代：
$$z\ \leftarrow\ P_C\big(z-\nabla F(z)\big)=P_C\big((1-\eta)w,\ b\big),\qquad \eta=1.$$

```python
import numpy as np
import cvxpy as cp

rng = np.random.default_rng(0)
n = 40
X = np.vstack([rng.normal(loc=[2,2], scale=0.7, size=(n//2,2)),
               rng.normal(loc=[-2,-2], scale=0.7, size=(n//2,2))])
y = np.concatenate([np.ones(n//2), -np.ones(n//2)])
YX = X * y[:, None]; K = YX @ YX.T

# ---- 对偶参考解 ----
lmbda = cp.Variable(n)
prob = cp.Problem(cp.Maximize(cp.sum(lmbda) - 0.5*cp.quad_form(lmbda, cp.psd_wrap(K))),
                  [lmbda >= 0, cp.sum(cp.multiply(lmbda, y)) == 0])
prob.solve(solver=cp.CLARABEL)
lam = lmbda.value; w_d = YX.T @ lam
sv = lam > 1e-5; b_d = np.mean(y[sv] - X[sv] @ w_d)
print("对偶  ||w|| =", np.linalg.norm(w_d))            # 0.7111673103

# ---- 投影梯度法（Dykstra 内层精确投影）----
A = np.column_stack([X, np.ones(n)]) * y[:, None]      # 约束 a_i^T z >= 1
def project_C(z0, iters=5000, tol=1e-15):
    z = z0.copy(); P = np.zeros_like(A)                # Dykstra 修正项
    for _ in range(iters):
        zp = z.copy()
        for i in range(len(A)):
            wi = z + P[i]; v = A[i] @ wi
            yn = wi if v >= 1.0 else wi + (1.0-v)/(A[i]@A[i])*A[i]
            P[i] = wi - yn; z = yn
        if np.linalg.norm(z - zp) < tol: break
    return z
z = np.zeros(3)
for k in range(30):                                    # 外层投影梯度, 步长 1/L = 1
    z = project_C(z - np.concatenate([z[:2], [0.0]]))
print("投影法||w|| =", np.linalg.norm(z[:2]))          # 0.7111673088
print("||w|| 相对误差 =", abs(np.linalg.norm(z[:2])-np.linalg.norm(w_d))/np.linalg.norm(w_d))
# 实际输出: 2.02e-09   (校验要求 < 1e-3 ✓)
print("b_投影 =", z[2], " b_对偶 =", b_d)              # 均为 -0.24713 (一致)
print("min 函数间隔 =", (y*(X @ z[:2] + z[2])).min())  # 1.0 (可行性满足)
```

**结果与三个值得说的点**：
1. **校验达成**：$\|w\|$ 相对误差 $2\times10^{-9}$，远小于 $10^{-3}$；且 $b$ 与对偶重建值（支持向量平均）一致到 $10^{-9}$。$b$ 一致并非巧合：硬间隔最优解处**两类都必有支持向量**（若非零乘子全在同一类，$\sum_i\lambda_iy_i=0$ 不可能成立；全零则 $w=0$、约束无解），两类支持向量分别给出 $b=1-w^\top x_i$ 与 $b=-1-w^\top x_j$，把固定 $w^\star$ 下可行 $b$ 的区间**夹成一点**——所以任何正确方法得到的 $b$ 都相同。
2. **外层两步就收敛**（误差 $6.6\times10^{-2}\to4.6\times10^{-9}$）：目标只含 $w$、步长 $\eta=1$ 时投影梯度等价于"向可行集收缩再投影"，对这类最小范数型问题收敛极快；真正的计算量在 Dykstra 内层（半空间投影极便宜，$O(n)$ 每次）。
3. **为什么不用罚函数/次梯度**：把约束换成 $C\sum_i\max(0,1-y_i(\cdot))$ 的罚函数法需要 $C\to\infty$ 才精确（实测 $C=10^6$ 时 $\|w\|$ 偏差 $O(1)$，严重病态）——投影法把"满足约束"变成算子的精确性质。这正是 4.9 误区 5"要验证重建解的可行性"的数值版教训。

## 开放思考

### 4.9 $n$ 与 $d$ 的相对大小：解原问题还是对偶？

**对应正文**：4.6.2、4.12 节。

**变量维数与代价对比**：原问题变量 $d+1$ 个、$n$ 条约束；对偶变量 $n$ 个、1 条等式约束 + 盒约束。通用 QP 求解器的代价粗略按"变量数的立方"增长，于是：

| 场景 | 推荐 | 理由 |
|---|---|---|
| $d$ 小、$n$ 大（如 $d=100$、$n=10^7$） | 原问题（或线性 SVM 专用一阶法，如 Pegasos） | 对偶有 $10^7$ 变量 + 核矩阵 $10^{14}$ 格内存，均不可行 |
| $d$ 大、$n$ 小（如 $d=10^5$、$n=10^3$） | 对偶 | 对偶仅 $10^3$ 变量；原问题 $10^5$ 维 |
| $d$ 大、$n$ 大 | 线性原问题 + 一阶法（不求精确解），或近似核（Nyström/随机特征） | 两侧都不可行，改换问题设定 |
| 需要非线性（核化） | **必须对偶** | 见下 |

**与核化的关系是"同一枚硬币的两面"**：对偶 (4.10) 只含内积 $x_i^\top x_j$，把内积换成 $k(x_i,x_j)$ 后算法其余部分不变——核化是对偶形式的**副产品**；原问题的显式变量 $w$ 属于（可能无穷维的）特征空间，无法显式存储，核化之路被堵死。反过来，核化的代价恰是对偶的代价：$n\times n$ 核矩阵的 $O(n^2)$ 内存决定了"能核化就不能大样本"。一句话：**想核化 → 走对偶（变量数 = 样本数 = 核矩阵规模）；样本巨大 → 回原问题的 $w$**。这不是巧合：对偶把模型的"自由度"从输入维数 $d$ 搬到了样本数 $n$，两种视角各覆盖一个可行象限。

### 4.10 影子价格：GPU 显存约束的乘子告诉你什么

**对应正文**：4.4.4、4.6.1。

**吞吐量最大化示例**。设决策变量 $x$（批大小、梯度检查点比例、重分片策略等），目标 $\max T(x)$（吞吐量），约束"峰值显存 $M(x)\le M_{\max}$"。乘子 $\lambda^\star$ 的单位是**吞吐量/GB**，它回答三个问题：
1. **边际问题**："显存再加 1 GB，吞吐量能提多少？"（$\partial T^\star/\partial M_{\max}=\lambda^\star$，4.6 题的公式）；
2. **采购决策**：若租 1 GB 显存的金钱成本折算的吞吐代价低于 $\lambda^\star$，升级硬件划算；
3. **内部定价**：多任务共享一卡时，$\lambda^\star$ 就是显存的"内部价格"——各任务按 $\lambda^\star$ 为占用付费，总分配自动均衡（对偶分解；4.6.1 节 TCP 拥塞控制的同一机制）。

**身边问题的拉格朗日表述（模板）**：预算 $B$ 内选活动组合 $\max\sum_i u_i(x_i)$ s.t. $\sum_i c_ix_i\le B$、$x_i\ge0$。KKT 给 $u_i'(x_i^\star)=\lambda^\star c_i$——**所有活动的"边际效用/价格"在最优时相等、都等于 $\lambda^\star$**（等边际原理）。例子：每周学习时间在各科目间的分配（$\lambda^\star$ = 一小时时间的边际绩点价值）、云 quota 在团队间的分配、缓存空间在各数据集间的分配。**判断一个约束"值多少钱"，常比解出 $x^\star$ 本身更具决策价值**——这是对偶视角超越算法工具的地方。

## 挑战题

### 4.11 （研究生层次）Fenchel 共轭重推 SVM 对偶

**对应正文**：4.12 进阶 1、4.5.2、Boyd & Vandenberghe 3.3。

**第一步：hinge/ReLU 共轭的精确形式**。$\phi(u)=\max(0,u)$（ReLU）：
$$\phi^*(y)=\sup_u\big[yu-\max(0,u)\big]=\begin{cases}0, & 0\le y\le1,\\ +\infty, & \text{否则；}\end{cases}$$
（$u\ge0$ 段 $u(y-1)$ 在 $y\le1$ 时上确界为 $u=0$ 处的 0；$u<0$ 段 $yu$ 在 $y\ge0$ 时上确界 0、$y<0$ 时发散。）对以 $z$ 为自变量的 hinge $\psi(z)=\max(0,1-z)=\phi(1-z)$：
$$\psi^*(y)=\sup_z\big[yz-\max(0,1-z)\big]=\begin{cases}y, & -1\le y\le0,\\ +\infty, & \text{否则。}\end{cases}$$
（$z\le1$ 段 $z(y+1)-1$ 与 $z\ge1$ 段 $yz$ 的斜率都必须 $\le0$，联立得 $y\in[-1,0]$，值 $y$。边界验证：$y=0$ 给 0、$y=-1$ 给 $-1$ ✓。）——题面提示说共轭是"max(0,y) 型分段线性"，精确形式如上：**定义域是盒子 $[-1,0]$，域内等于 $y$，域外 $+\infty$**（"分段线性"没错，但它是带指示域的函数，不是处处有限的 $\max(0,y)$）。

**第二步：软间隔原问题的共轭对偶推导**。原问题（4.5 题的等价无 $\xi$ 形式）：
$$\min_{w,b}\ \frac12\|w\|^2+C\sum_i\phi\big(1-y_i(w^\top x_i+b)\big),\qquad\phi=\max(0,\cdot).$$
引入辅助变量 $u_i=1-y_i(w^\top x_i+b)$，并对这组**等式**约束（注意：无符号要求，$\theta\in\mathbb R^n$）：
$$\mathcal L(w,b,u,\theta)=\frac12\|w\|^2+C\sum_i\phi(u_i)+\sum_i\theta_i\big(y_i(w^\top x_i+b)+u_i-1\big).$$
逐块取下确界：
- $\inf_u$：$\inf_{u_i}\big[C\phi(u_i)+\theta_iu_i\big]=-C\,\phi^*(-\theta_i/C)$，有限 $\iff-\theta_i/C\in[0,1]\iff\theta_i\in[-C,0]$，值为 0；
- $\inf_w$：$\frac12\|w\|^2+(X^\top Y\theta)^\top w$ 的极小值 $=-\frac12\|X^\top Y\theta\|^2$；
- $\inf_b$：$\big(\sum_i\theta_iy_i\big)b$ 有限 $\iff\sum_i\theta_iy_i=0$；
- 常数 $-\sum_i\theta_i$。

$$g(\theta)=-\frac12\theta^\top K\theta-\mathbf 1^\top\theta,\qquad \operatorname{dom}g=\Big\{\theta:\ \textstyle\sum_i\theta_iy_i=0,\ -C\le\theta_i\le0\Big\}.$$
代 $\lambda=-\theta\in[0,C]$（等式约束变号不变）：
$$\max_\lambda\ \sum_i\lambda_i-\frac12\lambda^\top K\lambda\quad\text{s.t.}\quad\sum_i\lambda_iy_i=0,\ \ 0\le\lambda_i\le C,$$
**恰为软间隔对偶 (4.11) + 盒约束** ✓（对照式 (4.11) 与 4.5 题的 $0\le\lambda_i\le C$）。

**第三步（对照与评价）**：两条路线的分工——拉格朗日路线（正文 4.5.2 + 4.5 题）中 $C$ 从 $\partial_{\xi_i}\mathcal L=0$ 变成盒约束上界；共轭路线中 $C$ 从共轭定义域的缩放 $-C\phi^*(-\theta/C)$ 中读出——**同一个 $C$，前者是"乘子的价格上限"，后者是"共轭定义域的缩放"**。共轭观点的额外收益：它把"损失函数 → 对偶正则项"变成查表运算（绝对值、熵、softmax 各有共轭对），推导任何"损失 + 正则"型问题的对偶不必再逐字写 KKT。

### 4.12 （研究生层次）Slater 定理特例的证明

**对应正文**：4.3 节定理 4.5、Boyd & Vandenberghe 5.2.3。

**命题**：凸问题 $\min f_0(x)$ s.t. $f_i(x)\le0$、$h_j(x)=0$（$f_0,f_i$ 闭凸、$h$ 仿射），若存在 $\tilde x$ 使 $f_i(\tilde x)<0$（所有 $i$）且 $h(\tilde x)=0$，则 $d^\star=p^\star$，且对偶最优值在某组 $(\lambda^\star,\nu^\star)$ 处取到（$p^\star$ 有限时）。

**证明骨架（五步，关键步给全细节）**：

1. **构造凸集 $A$（问题的"上图扩张"）**：
$$A=\Big\{(u,r,t)\in\mathbb R^m\times\mathbb R^p\times\mathbb R:\ \exists x,\ f_i(x)\le u_i\ \forall i,\ h(x)=r,\ f_0(x)\le t\Big\}.$$
$A$ 凸：设两点分别由 $x,x'$ 实现，则凸组合由 $\theta x+(1-\theta)x'$ 实现——$f_0,f_i$ 凸给出 $f_i(\theta x+(1-\theta)x')\le\theta u_i+(1-\theta)u_i'$ 等（与第 1 章 1.11 题同型论证）。注意定义只要求"存在一个 $x$"——这正是 $\varepsilon$-下确界技巧的几何化身。

2. **识别边界点**：$p^\star=\min\{t:(0,0,t)\in A\}$，且 $(0,0,p^\star)\in\partial A$——对一切 $\varepsilon>0$ 有 $(0,0,p^\star+\varepsilon)\in A$（最优 $x^\star$ 实现），而 $(0,0,p^\star-\varepsilon)\notin A$（否则与最优性矛盾）。

3. **Slater 点给出内点**：$\tilde x$ 严格可行 $\Rightarrow(-\varepsilon\mathbf 1,\,0,\,f_0(\tilde x))\in\operatorname{int}A$ 对足够小 $\varepsilon>0$——每个 $f_i(\tilde x)<0$ 严格，把 $u_i$ 稍抬高仍可由该 $x$（或其微扰）实现；$r$ 方向因 $h$ 仿射可任意微扰（仿射映射在其像上是开映射）。

4. **分离/支撑超平面**：$(0,0,p^\star)$ 在凸集 $A$ 的边界上、$A$ 有一列内点逼近它，故存在非零 $(\lambda,\nu,\beta)$ 使
$$\lambda^\top u+\nu^\top r+\beta t\ \ge\ \beta p^\star\qquad\text{对一切 }(u,r,t)\in\overline A.$$

5. **读出乘子并归一化（Slater 的真正用武之地）**：
   - **$\lambda\ge0$**：$A$ 中任一分量 $u_i$ 可任意变大（同一个 $x$ 仍实现），故 $\lambda_i<0$ 时左端趋于 $-\infty$，矛盾。
   - **$\beta>0$（关键一步）**：反设 $\beta=0$。把 $x=\tilde x$ 代入（$u_i=f_i(\tilde x)$、$r=0$）：$\lambda^\top f(\tilde x)\ge0$；但 $\lambda\ge0$ 且 $f_i(\tilde x)<0$ 严格，除非 $\lambda=0$。若 $\lambda=0,\beta=0$，超平面只剩 $\nu^\top r\ge0$——而 $A$ 的 $r$ 坐标充满一个仿射子空间（$h$ 仿射），$r$ 微扰即可变号，矛盾。故 $\beta>0$，归一化 $\beta=1$。
   - **关键不等式**：对任意 $x$，点 $(f(x),h(x),f_0(x))\in A$，代入支撑不等式：
$$f_0(x)+\sum_i\lambda_if_i(x)+\sum_j\nu_jh_j(x)\ \ge\ p^\star\qquad\text{对一切 }x.$$
   - **收尾**：左边对 $x$ 取下确界即 $g(\lambda,\nu)\ge p^\star$；结合弱对偶 $g\le d^\star\le p^\star$，全部取等：$g(\lambda,\nu)=d^\star=p^\star$。**强对偶成立且对偶最优值在某组乘子处取到**。$\blacksquare$

**复现要点**：(i) 第 3 步"内点"与第 5 步"$\beta>0$"是 Slater 真正被消费的地方——没有严格可行点，会出现 $p^\star$ 在边界达成但乘子"逃逸到无穷"的反例（如 $\min e^{-x}$ s.t. $x\le0$：对偶最优取不到）；(ii) 完整细节（闭性、凸集不交version、反例）见 Boyd & Vandenberghe 5.2.3 与 5.3.2，本骨架覆盖主线的每一步依据。

# 第 5 章 随机优化与 SGD 家族

## 概念辨析

### 5.1 期望风险与经验风险之差是谁的研究对象；"SGD 解 (5.2) 但在意 (5.1)"

**对应正文**：5.1.1 节、5.9 误区 1。

$L(\theta)-\hat L_n(\theta)$ 是**泛化理论**的研究对象（《机器学习》泛化章的主角——训练误差与真实误差之差）。

**"SGD 解 (5.2)、在意 (5.1)"的三层含义**：
1. **优化的对象**：SGD 的 $g_B$ 是 $\nabla\hat L_n$ 的无偏估计（性质 5.1），迭代全程不知道 $L$ 的存在；定理 5.3 与式 (5.8) 的收敛分析全部关于 $\hat L_n$；
2. **评估的对象**：上线后面对新样本，性能由 $L$ 决定。其差 $L-\hat L_n$ 不受优化算法控制，由泛化理论决定；
3. **两者的接口（为什么没有错）**：总误差 = 优化误差（$\hat L_n(\hat\theta)-\min\hat L_n$）+ 泛化误差。深度学习的核心经验是：过参数化区把优化误差压到零（插值）通常不伤害甚至改善总误差——因为隐式偏差（第 6 章 6.4）使 SGD 挑中的插值解偏向泛化好的那一类（6.3 节现代插值图景）。**"解一个与真实目标不同的代理问题"在经典统计里是错的（过拟合），在过参数化 + 隐式偏差下可以是对的**——这正是第 5、6 章必须连读的原因。

*常见错误*：把 $\hat L_n$ 的噪声地板当成 $L$ 的噪声地板（两者量级同为 $\eta\sigma^2/(2B)$ 型，但 $\sigma^2$ 的含义不同）；把"泛化差距"误诊为"优化失败"。

### 5.2 用式 (5.5) 解释：增大批量让曲线平滑却未必更快

**对应正文**：5.1.2 性质 5.2、5.2.1、5.6 节。

**式 (5.5) 说了什么**：$\mathrm{Var}[g_B]=\sigma^2/B$——批量只出现在**噪声方差**里；期望 $\mathbb E[g_B]=\nabla\hat L$（漂移速度）与 $B$ 无关。因此增大批量：
- **改变的**：loss 曲线毛刺（$\propto\eta\sqrt{\sigma^2/B}$）按 $1/\sqrt B$ 平滑；噪声球半径 $\propto\sqrt{\eta\sigma^2/B}$ 收缩。
- **不改变的**：每步确定性位移 $-\eta\nabla\hat L$；且每 epoch 样本处理量固定时，$B$ 增大 $B$ 倍 → 每 epoch 更新次数少 $B$ 倍 → 每 epoch 的**确定性进展不变**。

**"未必更快"的两个机制**：(i) 若训练处在信号主导区（5.2.1 regime 1），进度由确定性漂移决定，加大批量毫无收益，还丢失噪声的探索/正则作用；(ii) 只有接近噪声地板（regime 2）时，大批量才通过压低地板 $\propto\eta\sigma^2/(2B)$ 帮助收敛——而同样的效果用"衰减 $\eta$"即可达成，不必增加每步通信/计算。工程推论：**平滑不等于进展**；读曲线要看滑动平均的斜率，不是毛刺的幅度。

### 5.3 AdaGrad 停滞 vs SGD 噪声地板

**对应正文**：5.5.2、5.2.1、5.9 误区 2。

| | AdaGrad 停滞 | SGD 噪声地板 |
|---|---|---|
| 数学本质 | **确定性**：$s_k$ 单调增 ⇒ 每坐标步长 $\eta/\sqrt{s_k}\to0$，更新本身消失 | **随机稳态**：步长正常，参数在极小点附近做 OU 型扩散，$\mathbb E\|\theta_k\|^2$ 有非零稳态 |
| 发生位置 | 任何"历史梯度累计大"的坐标，无论离最优点多远 | 只在极小点邻域（信号 $\to0$ 噪声才主导） |
| loss 表现 | 曲线持续变平、最后几乎不动（且未必在 $L^\star$ 附近） | 曲线在 $L^\star+O(\eta\sigma^2/(2B))$ 水平**持续波动**、均值不降 |
| 诊断信号 | $\|\theta_{k+1}-\theta_k\|\to0$（位移消失） | 位移不小但 loss 均值不动；减 $\eta$ 后均值立刻下降 |
| 修复 | RMSProp/Adam：把累计和换成滑动平均（遗忘）；或重置 $s$ | Robbins–Monro 衰减 $\eta_k$（5.3 节调度）；或增大 $B$ |

*常见错误*：两者混为一谈（都是"loss 不降了"）。**判别实验**：$\eta$ 减小 10 倍再跑——地板情形 loss 均值下降（$\propto\eta$）且位移变小但显著；AdaGrad 停滞情形几乎无变化（$s_k$ 已很大，$\eta$ 不是瓶颈）。

## 计算推导

### 5.4 协方差版本 $\mathrm{Cov}[g_B]=\Sigma/B$ 与独立性假设

**对应正文**：5.1.2 性质 5.2。

**设定**：$g_B=\frac1B\sum_{i\in S}\nabla\ell_i(\theta)$；$S$ 为从 $\{1,\dots,n\}$ **有放回** i.i.d. 抽取的 $B$ 个下标。记
$$\Sigma=\operatorname{Cov}[\nabla\ell_i(\theta)]=\frac1n\sum_{j=1}^n\big(\nabla\ell_j-\nabla\hat L_n\big)\big(\nabla\ell_j-\nabla\hat L_n\big)^\top.$$

**推导**。令 $Z_i=\nabla\ell_{I_i}(\theta)$（$I_i$ i.i.d. 均匀），则 $\mathbb E[Z_i]=\nabla\hat L_n$、$\operatorname{Cov}[Z_i]=\Sigma$。由 i.i.d.（**交叉项逐个消失**）：
$$\operatorname{Cov}[g_B]=\operatorname{Cov}\Big[\frac1B\sum_{i=1}^BZ_i\Big]=\frac1{B^2}\sum_{i=1}^B\operatorname{Cov}[Z_i]+\frac1{B^2}\sum_{i\ne j}\underbrace{\operatorname{Cov}[Z_i,Z_j]}_{=0}=\frac1B\Sigma.\qquad\blacksquare$$

**用到的假设清单**：(i) 有放回 i.i.d. 抽样（交叉项消失的唯一依据）；(ii) 各 $\nabla\ell_i$ 二阶矩有限；(iii) 固定 $\theta$（对抽样取条件）。**放宽 (i)**：实践中的随机置换（无放回）给有限总体校正
$$\operatorname{Cov}[g_B]=\frac{n-B}{n-1}\cdot\frac{\Sigma}{B}\ \le\ \frac{\Sigma}{B},$$
即无放回噪声略小、$B=n$ 时严格为零（全批量无噪声）✓；$B\ll n$ 时与 (5.5) 无法区分。对迹取期望即得标量式 (5.5)（$\sigma^2=\operatorname{tr}\Sigma$ 量级）。

### 5.5 强凸二次 SGD 的递推、稳态与噪声地板

**对应正文**：5.2.1（噪声地板）、Bottou–Curtis–Nocedal 2018。

**设定**：$\hat L(\theta)=\frac\mu2\|\theta\|^2$（$\theta\in\mathbb R^d$），更新 $\theta_{k+1}=\theta_k-\eta(\mu\theta_k+\xi_k)$，$\xi_k$ 零均值、$\operatorname{Cov}[\xi_k]=\sigma^2I$（单坐标梯度噪声方差 $\sigma^2$），$\xi_k$ 与 $\theta_k$ 独立。

**递推**。展开平方，交叉项因独立性消失：
$$\mathbb E\|\theta_{k+1}\|^2=\mathbb E\|(1-\eta\mu)\theta_k\|^2-2\eta(1-\eta\mu)\,\mathbb E[\theta_k]^\top\underbrace{\mathbb E[\xi_k]}_{=0}+\eta^2\mathbb E\|\xi_k\|^2=(1-\eta\mu)^2\,\mathbb E\|\theta_k\|^2+\eta^2d\sigma^2.$$
（第二步用 $\xi_k\perp\theta_k$。注意 $\mathbb E\|\xi_k\|^2=\operatorname{tr}(\sigma^2I)=d\sigma^2$。）这是线性递推，不动点即稳态：
$$\mathbb E\|\theta_k\|^2\ \xrightarrow{k\to\infty}\ \frac{\eta^2d\sigma^2}{1-(1-\eta\mu)^2}\ \approx\ \frac{d\,\eta\sigma^2}{2\mu}\qquad(\eta\mu\ll1,\ \text{分母}\approx2\eta\mu).$$
稳态损失（噪声地板）：
$$\mathbb E[\hat L(\theta_\infty)]=\frac\mu2\,\mathbb E\|\theta_\infty\|^2\ \approx\ \frac{d\,\eta\sigma^2}{4}.$$

**量级核对与约定说明**：题面"地板 $\approx\eta\sigma^2/(2\mu)$ 量级"对应**单坐标**（$d=1$）或"把 $\sigma^2$ 理解为总噪声能量 $\mathbb E\|\xi\|^2$"的约定（此时 $\mathbb E\|\theta_\infty\|^2\approx\eta\sigma^2/(2\mu)$ ✓）。两种约定只差维度因子 $d$；量级结构（线性于 $\eta$、反比于 $\mu$）完全相同。

**校验**：(i) $\eta\to0$：地板 $\propto\eta\to0$，回到确定性收敛 $\theta_k\to0$ ✓（与确定性理论一致）；(ii) **数值验证**（$d=3$、$\mu=0.5$、$\eta=0.1$、$\sigma=1$，$2\times10^5$ 步后半程平均）：仿真 $\mathbb E\|\theta\|^2=0.3039$，精确公式 $\eta^2d\sigma^2/(1-(1-\eta\mu)^2)=0.3077$，近似式 $d\eta\sigma^2/(2\mu)=0.30$——三者吻合 ✓。

**顺带**：递推读出"双时间尺度"——初期按 $(1-\eta\mu)^k$ 线性衰减（与确定性 GD 同率，5.2.3 对照表末行），后期在稳态球内扩散（半径 $\propto\sqrt\eta$）。

### 5.6 Adam 偏差修正的无偏性证明（及其边界）

**对应正文**：5.5.3、5.8.1。

**命题**：$g_1,g_2,\dots$ i.i.d.，$m_0=0$，$m_k=\beta_1m_{k-1}+(1-\beta_1)g_k$，则 $\mathbb E\big[m_k/(1-\beta_1^k)\big]=\mathbb E[g]$ 对一切 $k\ge1$。

**第一步（闭式展开，归纳证明）**。断言 $m_k=(1-\beta_1)\sum_{i=1}^k\beta_1^{k-i}g_i$。$k=1$：$m_1=(1-\beta_1)g_1$ ✓。归纳：$m_k=\beta_1(1-\beta_1)\sum_{i=1}^{k-1}\beta_1^{k-1-i}g_i+(1-\beta_1)g_k=(1-\beta_1)\sum_{i=1}^k\beta_1^{k-i}g_i$ ✓。

**第二步（期望与权重归一）**。由 i.i.d.，$\mathbb E[g_i]=\mathbb E[g]$ 对一切 $i$：
$$\mathbb E[m_k]=(1-\beta_1)\,\mathbb E[g]\sum_{i=1}^k\beta_1^{k-i}=(1-\beta_1)\,\mathbb E[g]\cdot\frac{1-\beta_1^k}{1-\beta_1}=(1-\beta_1^k)\,\mathbb E[g].$$
权重和 $(1-\beta_1)\sum_{i=1}^k\beta_1^{k-i}=1-\beta_1^k$ 正是"指数平均对零初始化的欠账"的精确表达式——除以 $1-\beta_1^k$ 恰好补齐。$\blacksquare$

**两点边界（避免过度解读）**：
1. 该证明只保证**一阶矩分子**无偏。完整更新 $\eta\,\hat m_k/(\sqrt{\hat s_k}+\varepsilon)$ 是两个量的**比值**，比值的无偏性不成立（期望与非线性函数不可交换）。偏差修正的真实含义是"把 $m,s$ 各自变成无偏估计"，而非"整个更新无偏"——这与勘误索引 5 及 5.9 题直接相关：不做修正时更新量的净变化是**变大 3.16 倍**而非"只剩 1/10"。
2. 二阶矩版本同理：$\mathbb E[s_k/(1-\beta_2^k)]=\mathbb E[g^2]$（对 $g_i^2$ 用同一归纳；i.i.d. 保证 $\mathbb E[g_i^2]$ 相同）。$\beta_2=0.999$ 时 $1-\beta_2^k$ 到 $k\approx2300$ 才达 0.9——定量支持 5.8.1 "二阶矩偏差持续到 $10^3$ 步量级"的说法。

### 5.7 学习率调度对比：噪声地板的"突破"实验

**对应正文**：5.3、5.2.1、5.8.2。

**实验设计的关键教训（先讲结论）**：要在图上**看清**"衰减突破噪声地板"，需要地板显著高于 $L^\star$，即 $\eta\sigma^2/B$ 相对 $L^\star$ 可观。5.8.2 的逻辑回归数据太"容易"（实测 $L^\star=0.0684$；固定 $\eta=0.05,B=32$ 的地板只比 $L^\star$ 高约 0.002），3000 步内衰减方案的终值（余弦 0.0744、阶梯 0.0778）反而**高于**固定步长（0.0699）——过早衰减拖慢主下降段，而地板本来就薄。因此补充一个地板有解析值的二次函数演示（把 5.5 题的推导变成可见的数），再如实报告逻辑回归结果。

**参考实现（已运行验证，固定种子）**：

```python
import numpy as np
rngq = np.random.default_rng(0)
mu, sigma, d, K, eta0, B = 0.5, 1.0, 5, 6000, 0.1, 32

def run_quad(mode, K, eta0, seed=0):
    r = np.random.default_rng(seed); th = np.zeros(d); h = []
    for k in range(1, K+1):
        g = mu*th + sigma/np.sqrt(B)*r.normal(size=d)   # 梯度 = mu*theta + 噪声(方差 sigma^2/B)
        eta = eta0 if mode == 'fixed' else eta0/2*(1+np.cos(np.pi*k/K))
        th = th - eta*g; h.append(0.5*mu*th@th)
    return np.array(h)

hf = run_quad('fixed', K, eta0); hc = run_quad('cos', K, eta0)
print("理论地板 d*eta*sigma^2/(4B) =", d*eta0*sigma**2/(4*B))   # 0.003906 (精确式 0.004006)
print("固定eta 最后1000步均值 =", hf[-1000:].mean())             # 0.00378  ← 停在地板上
print("余弦退火 最后1000步均值 =", hc[-1000:].mean())           # 0.00024  ← 穿透地板
print("余弦退火 终值 =", hc[-1])                                 # 0.000154
```

**结果解读**：固定 $\eta$ 的长期均值 0.00378 与理论地板 0.0039–0.0040 吻合（5.5 题 $\mathbb E\|\theta\|^2$ 稳态乘 $\mu/2$）；余弦退火把 $\eta$ 降为零、地板随 $\eta$ 线性收缩，终值 0.000154——**低于地板 25 倍**，"衰减后突破噪声地板"被直接验证 ✓。

**逻辑回归上的如实报告**（5.8.2 设置，$K=3000$、$B=32$）：固定 $\eta=0.05$ 终值 0.0699（末 1000 步均值 0.0708）；余弦 0.0744；阶梯 0.0778。衰减方案没赢——原因如上（$L^\star=0.0684$，地板只厚 0.002；预算短时衰减的代价 > 收益）。**实践结论**：训练预算内 loss 仍在大步下降时不要急着衰减（5.3 节"调参次序"的另一种表述）；地板现象是否可见，取决于 $\eta\sigma^2/B$ 与 $L^\star$ 的相对大小。

### 5.8 线性缩放实验：$(B,\eta)$ 联动与偏离

**对应正文**：5.6.1–5.6.2、5.9 误区 4。

**参考实现（已运行验证；按题意固定 epoch 数 = 30，置换采样，固定种子）**：

```python
import numpy as np
from sklearn.datasets import make_classification
rng = np.random.default_rng(0)
X, y01 = make_classification(n_samples=2000, n_features=20, random_state=0)
Xb = np.hstack([X, np.ones((len(X), 1))]); y = (y01*2 - 1).astype(float)
n, d = Xb.shape
def loss(w): return np.logaddexp(0, -y*(Xb@w)).mean()
def run_epochs(eta, EPOCHS, B, seed=0, warmup=0):
    r = np.random.default_rng(seed); w = np.zeros(d)
    steps = int(EPOCHS*n/B)
    for k in range(steps):
        e = eta*(k+1)/warmup if warmup and k < warmup else eta
        idx = r.choice(n, size=B, replace=False)
        p = 1/(1+np.exp(-(Xb[idx]@w)))
        w = w - e*(Xb[idx].T@(p-(y[idx]+1)/2)/B)
    return steps, loss(w)
for B, e in [(32, 0.05), (256, 0.4), (1024, 1.6)]:
    s, l = run_epochs(e, 30, B)
    print(f"B={B}, eta={e}: 30 epochs = {s} 步, final loss = {l:.4f}")
# 实际输出:
# B=32,   eta=0.05: 30 epochs = 1875 步, final loss = 0.0727
# B=256,  eta=0.4 : 30 epochs =  234 步, final loss = 0.0722
# B=1024, eta=1.6 : 30 epochs =   58 步, final loss = 0.0724
# B=1024, eta=1.6 + warmup20步: 58 步, final loss = 0.0740
```

**结果解读（与校验对照）**：
- **三组最终 loss 几乎相同**（0.0727 / 0.0722 / 0.0724，差在噪声水平内）——线性缩放法则 (5.13) 在本数据上连"临界区"都成立，前两组接近的校验 ✓ 且更强。
- **第三组 $(1024,1.6)$ 未发散**：校验说的是"**可能**发散或变差"，本数据集没有发生，且可以定量解释：逻辑回归 Hessian $\preceq\frac14\cdot\frac1nX^\top X$，实测 $\lambda_{\max}=0.69$、确定性稳定上界 $2/L\approx2.9$，而 $\eta=1.6<2.9$——步长未达危险区；另外 sigmoid 饱和使实际轨迹上的曲率更低（"自稳定"，即第 6 章 Edge of Stability 的机制——实测本问题全批量 $\eta=6.4$ 甚至 $20$ 都不发散）。注意 $B=1024>1/2\,n$ 后每 epoch 只更新约 2 次，"大批量+大 $\eta$"的实际风险在这个小问题上无法触发。
- **偏离的真正条件**：发散需要 $\eta\gtrsim2/L_{\text{轨迹}}$。把特征尺度放大 10 倍（$L$ 增大百倍，$2/L\approx0.029$）后复测：$(1024,1.6)$ 的 loss 恶化到 0.45（近发散震荡），加 200 步 warmup 改善到 0.28——**warmup 的保护作用只在步长逼近上界时显现**，与 5.6.1"大批量必须配 warmup"的机理一致。
- **结论**：线性缩放的适用判据有两条——(i) 仍在小批量区（噪声随 $B$ 下降）；(ii) $\eta(mB)$ 不触碰 $2/L$。触界后继续放大 $B$ 只剩统计收益递减（临界批量，5.6.2），并叠加第 6 章的大批量-尖锐极小风险。

### 5.9 有/无偏差修正的 Adam：净更新比与初期行为（含勘误）

**对应正文**：5.5.3、5.8.1（本册勘误索引 5）。

> **勘误**：正文 5.8.1 说"不做修正时，Adam 第一步的有效步长只有名义的 1/10"。**1/10 只描述了一阶矩分子 $m_1=0.1g$**；但更新量是比值 $m/\sqrt s$，二阶矩被低估得更狠（$\sqrt{s_1}=\sqrt{0.001}\,|g|=0.0316|g|$），净效果恰相反：
> $$\frac{m_1/\sqrt{s_1}}{\hat m_1/\sqrt{\hat s_1}}=\frac{(1-\beta_1)/\sqrt{1-\beta_2}}{1}=\frac{0.1}{\sqrt{0.001}}\approx3.16,$$
> 即**不做修正时初期步长约为名义的 3.16 倍（不是 1/10）**。下面用实验证实。

**参考实现（已运行验证，固定种子）**：

```python
import numpy as np
from sklearn.datasets import make_classification
rng = np.random.default_rng(0)
X, y01 = make_classification(n_samples=2000, n_features=20, random_state=0)
Xb = np.hstack([X, np.ones((len(X), 1))]); y = (y01*2-1).astype(float)
n, d = Xb.shape
def loss(w): return np.logaddexp(0, -y*(Xb@w)).mean()
def grad_batch(w, B, r):
    idx = r.choice(n, size=B, replace=False)
    p = 1/(1+np.exp(-(Xb[idx]@w)))
    return Xb[idx].T @ (p-(y[idx]+1)/2)/B
def train_adam(eta, K, B, bias=True, seed=0):
    r = np.random.default_rng(seed); w = np.zeros(d)
    m = np.zeros(d); s = np.zeros(d); hist = []
    for k in range(1, K+1):
        g = grad_batch(w, B, r)
        m = 0.9*m + 0.1*g; s = 0.999*s + 0.001*g*g
        if bias: mh = m/(1-0.9**k); sh = s/(1-0.999**k)
        else:    mh, sh = m, s
        w = w - eta*mh/(np.sqrt(sh)+1e-8); hist.append(loss(w))
    return np.array(hist)
h_b = train_adam(0.05, 50, 32, bias=True)
h_n = train_adam(0.05, 50, 32, bias=False)
for k in [1, 2, 5, 10, 20, 50]:
    print(k, round(h_b[k-1],4), round(h_n[k-1],4))
# 实际输出 (步数 | 有修正 | 无修正):
#  1 | 0.6527 | 0.6071
#  2 | 0.6162 | 0.5275
#  5 | 0.5154 | 0.2703
# 10 | 0.3835 | 0.1316
# 20 | 0.2322 | 0.1002
# 50 | 0.1140 | 0.0848
```

**结果解读**：
- **无修正反而更快**：第 5 步 loss 0.27 vs 0.52，与 3.16 倍净步长比的预测一致 ✓（等效于初期用了 $\eta\approx0.16$ 的 Adam）。前 50 步 loss 曲线放大图中"无修正"整体在下方。
- **那偏差修正图什么？** 三点：(i) **首步尺度的正确性**——有修正时第一步更新恰为 $\eta\cdot\mathrm{sign}(g)$（$\hat m_1=g$、$\sqrt{\hat s_1}=|g|$），即"每坐标走 $\eta$"，这正是 5.5.3 节"Adam 的 $\eta$ 是绝对量"设计意图的兑现；无修正时首步 $3.16\eta$，遇陡峭初始区（大 $L$）可能直接跳出稳定域；(ii) **与 $\varepsilon$ 的相互作用**——无修正时 $\sqrt{s_1}=0.0316|g|$，小梯度坐标（如偏置）的 $\varepsilon$ 占比失真；(iii) **调参语义稳定**——修正后前几步的等效步长不随 $\beta_1,\beta_2$ 漂移，warmup 与 $\eta_0$ 的配合（5.3 节）才有确定含义。
- 一句话总结：**偏差修正不是为了"更快"，是为了"步长尺度从一开始就正确"**；本题的实验恰好证明"更慢"是错误直觉。

### 5.10 固定总样本量比较批量：实验框架与决策规则

**对应正文**：5.6.1–5.6.2、第 6 章 6.3。

**实验框架（控制变量只剩 $B$）**：
1. **预算锚定**：每配置处理相同样本量（如 30 epochs），$\eta(B)$ 用统一策略：小批量 lr range test 定 $\eta_0$，按线性缩放 (5.13) 外推，同时用 $2/L$ 估计封顶；
2. **三层记录**：最终训练 loss（优化能力）、验证 loss（泛化）、wall-clock 与吞吐（硬件效率）；
3. **重复 3–5 个种子**报均值±标准差（小批量随机性大）；
4. **附加诊断**：记录 $\|\nabla\hat L\|$ 滑动平均与 loss 毛刺幅度（$\propto\sqrt{\eta\sigma^2/B}$），定位该 $B$ 是否已进临界区；梯度噪声尺度法（McCandlish 2018）在线估计 $B_{\text{crit}}\approx\sigma^2/\|\nabla L\|^2$。

**推荐批量的决策规则（决策树）**：
- 验证 loss 随 $B$ 变差而训练 loss 不变 → 已过临界批量且大 $B$ 伤泛化（尖锐极小风险，第 6 章）→ 取"验证 loss 不变差的最大 $B$"再除以 2–4；
- 各 $B$ 验证 loss 相同 → 纯硬件效率问题 → 取吞吐量最大（通常越大越好，配 warmup）；
- 小 $B$ 验证 loss 显著更好 → 保留小 $B$（噪声正则化在起作用），省下的算力换更长训练或更多种子。
**经验起点**：$B\in\{16,\dots,256\}$ 起扫；$B$ 超过 $B_{\text{crit}}$ 的 1/4–1/2 后收益递减的信号是"loss 毛刺已不明显、加大 $B$ 不再允许更大 $\eta$"。

### 5.11 "最后几个 epoch 换 SGD"的合理性与风险

**对应正文**：5.5.4 对比表、5.2.3、第 6 章 6.2.4/6.4。

**主张的合理内核（两条）**：
1. **噪声谱与隐式偏差差异**：SGD 的更新噪声各向同性、位移按曲率缩放，后期是"低通"探索，偏好平坦极小（6.2.4 末行的线性稳定性分析）；Adam 的更新 $\eta\hat m/(\sqrt{\hat s}+\varepsilon)$ 是"信噪比归一"，其隐式偏差与 SGD 不同，可能停在更尖锐的解。若验证 gap 大且诊断出尖锐极小（$\lambda_{\max}$ 大、切片窄），换 SGD+小 $\eta$ 有理论依据。
2. **$\beta_2$ 长记忆问题**：后期遇 loss 尖峰时 $s$ 被大梯度"污染"约 $10^3$ 步（5.9 误区 3），步长骤缩；SGD 无此机制。

**风险（三条）**：
1. **尺度不可换算**：Adam 步长是绝对量（每坐标 $\sim\eta$），SGD 步长是 $\eta\|g\|$ 量级——切换点的 $\eta_{\text{SGD}}$ 无法从 $\eta_{\text{Adam}}$ 直接换算：选大立即震荡、选小停滞，切换本身是新的超参搜索；
2. **证据混杂**："Adam 泛化差"的早期结论在 AdamW（解耦权重衰减）与合理调度后常消失；把优化器差异当泛化差距主因，须先排除正则配置不同的混淆；
3. **无诊断就切换是无的放矢**：应先测量（切片平坦度、$\lambda_{\max}$、gap 对 $(\eta,B)$ 的响应）确认"确实停在尖锐区"。

**执行建议**（若决定试）：放在调度的最后 10–20%；$\eta_{\text{SGD}}$ 用"Adam 末段每步位移范数 ÷ 当前 $\|g\|$"反推等效值；切换前后各跑若干种子对比验证 loss 的分布而非单点——把它当受控实验。

### 5.12 （研究生层次）凸光滑 SGD 的 $O(D/\sqrt K)$ 界（平均版完整推导）

**对应正文**：5.2.2 定理 5.3、Bottou–Curtis–Nocedal 2018 §4.2、Bubeck 书 5.2。

**假设**：(A1) $\hat L$ 凸、可微；(A2) $\hat L$ 是 $L$-光滑（用第 2 章式 (2.2)）；(A3) 无偏：$\mathbb E_k[g_k]=\nabla\hat L(\theta_k)$；(A4) 二阶矩有界：$\mathbb E_k\|g_k\|^2\le G^2$；(A5) $g_k$ 与 $\theta_k$ 条件独立（$\mathbb E_k$ 表示给定 $\theta_k$ 的条件期望）。记 $D=\|\theta_0-\theta^\star\|$。

**第一步（一步下降不等式）**。对 $\theta_{k+1}=\theta_k-\eta g_k$ 用 $L$-光滑（式 (2.2) 中 $y$ 取 $\theta_{k+1}$）：
$$\hat L(\theta_{k+1})\le\hat L(\theta_k)+\nabla\hat L(\theta_k)^\top(-\eta g_k)+\frac L2\eta^2\|g_k\|^2.$$
两边取 $\mathbb E_k$：(A3) 给 $\mathbb E_k[\nabla\hat L(\theta_k)^\top g_k]=\|\nabla\hat L(\theta_k)\|^2$；(A4)(A5) 给末项。再取全期望：
$$\mathbb E[\hat L(\theta_{k+1})]\le\mathbb E[\hat L(\theta_k)]-\eta\,\mathbb E\|\nabla\hat L(\theta_k)\|^2+\frac{L\eta^2G^2}{2}.\tag{$\ast$}$$

**第二步（凸性把梯度范数换成函数值间隙）**。对 $\|\theta_{k+1}-\theta^\star\|^2=\|\theta_k-\theta^\star-\eta g_k\|^2$ 取 $\mathbb E_k$（交叉项用 (A3)(A5)）：
$$\mathbb E\|\theta_{k+1}-\theta^\star\|^2\le\mathbb E\|\theta_k-\theta^\star\|^2-2\eta\,\mathbb E\big[\nabla\hat L(\theta_k)^\top(\theta_k-\theta^\star)\big]+\eta^2G^2.$$
凸性切线不等式 (1.3) 用于 $(\theta_k,\theta^\star)$：$\hat L(\theta_k)-L^\star\le\nabla\hat L(\theta_k)^\top(\theta_k-\theta^\star)$，代入：
$$\mathbb E\|\theta_{k+1}-\theta^\star\|^2\le\mathbb E\|\theta_k-\theta^\star\|^2-2\eta\,\mathbb E\big[\hat L(\theta_k)-L^\star\big]+\eta^2G^2.$$

**第三步（望远镜求和）**。对 $k=0,\dots,K-1$ 求和，距离项相消：
$$2\eta\sum_{k=0}^{K-1}\mathbb E\big[\hat L(\theta_k)-L^\star\big]\ \le\ D^2+K\eta^2G^2
\ \Longrightarrow\
\frac1K\sum_{k=0}^{K-1}\mathbb E\big[\hat L(\theta_k)-L^\star\big]\ \le\ \frac{D^2}{2K\eta}+\frac{\eta G^2}2.$$

**第四步（选步长并收尾）**。取常数 $\eta=\dfrac{D}{G\sqrt K}$：两项分别 $=\dfrac{DG}{2\sqrt K}$，相加：
$$\mathbb E\big[\hat L(\bar\theta_K)\big]-L^\star\ \le\ \frac1K\sum_k\mathbb E\big[\hat L(\theta_k)-L^\star\big]\ \le\ \frac{DG}{\sqrt K},\qquad \bar\theta_K=\frac1K\sum_k\theta_k,$$
末步用凸性（平均点的函数值 $\le$ 函数值的平均）或直接取 $K$ 步中最优迭代。$\blacksquare$

**讨论**：(i) **每步依据清单**：(2.2) 光滑、(1.3) 凸性、独立性消交叉项、凸性换平均点——无一步用强凸，故 $\Theta(1/\sqrt K)$ 在该假设类内不可改进（2.11 题下界的随机版）；(ii) **最后迭代版**：取 $\eta_k=D/(G\sqrt k)$ 型递减步长，重复第一、二步后望远镜（$\sum\eta_k\approx2D\sqrt K/G$、$\sum\eta_k^2\approx D^2(\ln K)/G^2$ 对数项），得 $\mathbb E[\hat L(\theta_K)-L^\star]\le O(DG\ln K/\sqrt K)$ 级——平均版更干净，这也是 Polyak–Ruppert 平均的价值；(iii) 与式 (5.8) 的关系：这里 $DL_g$ 与 $\sigma^2$ 两项被 (A4) 的 $G^2$ 打包；分离信号与噪声可得更细的常数（Bottou 综述完整版）。

### 5.13 （研究生层次）Adam 不收敛反例与 AMSGrad：简化复现与机理分析

**对应正文**：5.5.3、5.9 误区 3、Reddi–Kale–Kumar ICLR 2018。

**实验（简化变体，已运行验证）**。Reddi 等的反例是分段线性函数的**对抗性时间序列**（大梯度罕见出现）；我们用光滑确定性变体复现同一失效模式：
$$f(x)=\begin{cases}\dfrac C2x^2,&x<0\ (\text{陡侧}),\\[4pt]\dfrac12x^2,&x\ge0\ (\text{缓侧}),\end{cases}\qquad x^\star=0.$$

```python
import numpy as np
def grad(x, C=50.0): return C*x if x < 0 else x
def adam(C, eta=0.05, b1=0.9, b2=0.999, K=4000, x0=1.0, amsgrad=False):
    x, m, v, vh = x0, 0.0, 0.0, 0.0; traj = [x]
    for k in range(1, K+1):
        g = grad(x, C)
        m = b1*m + (1-b1)*g; v = b2*v + (1-b2)*g*g
        sh = max(vh, v) if amsgrad else v
        if amsgrad: vh = sh
        x = x - eta*(m/(1-b1**k))/(np.sqrt(sh/(1-b2**k))+1e-8)
        traj.append(x)
    return np.array(traj)
for name, ams in [("Adam", False), ("AMSGrad", True)]:
    t = adam(50.0, amsgrad=ams)
    print(f"{name}: 终值={t[-1]:+.6f}, 后2000步振荡幅度={t[-2000:].max()-t[-2000:].min():.4f}")
# 实际输出:
# Adam   : 终值=+0.000000, 后2000步振荡幅度=0.3130   ← 永久极限环, 不收敛
# AMSGrad: 终值=+0.000000, 后2000步振荡幅度=0.0000   ← 收敛
# C 扫描: C=10 两者都收敛(振荡 0); C=30/50/100 时 Adam 振荡 0.318/0.313/0.294, AMSGrad 恒 0
```

**现象**：$C\ge30$ 后 Adam 不收敛到 $x^\star$，而是进入幅度 $\approx0.31$ 的**永久极限环**（陡缓两侧间大幅震荡）；AMSGrad（$v\leftarrow\max(v_{\text{hist}})$ 的单调化）在所有 $C$ 下收敛。轨迹机制：从缓侧 ($x>0$) 逼近 0 时梯度小、$v$ 按 $\beta_2=0.999$ 的记忆指数衰减；越过 0 进入陡侧瞬间遇到 $C|x|$ 的大梯度而 $v$ 尚小 → 巨步深冲进 $x<0$；在陡侧自归一化步长（$\approx\eta$）缓慢折返、$v$ 被撑大又再次衰减……循环往复。

**为什么滑动平均（而非累计和）破坏了单调性论证（一页分析）**：
1. **证明需要什么**：在线梯度式的 regret 证明中，自适应步长 $\eta_t\propto1/\sqrt{V_t}$（$V_t=\sum_{s\le t}g_s^2$ **累计和**）的关键恒等式是
$$\sum_{t=1}^K\frac{g_t^2}{\sqrt{V_t}}\ \le\ \sum_{t=1}^K\frac{V_t-V_{t-1}}{\sqrt{V_t}}\ \le\ 2\big(\sqrt{V_K}-\sqrt{V_0}\big)=O(\sqrt K),$$
其中 $\frac{g_t^2}{\sqrt{V_t}}\le\frac{V_t-V_{t-1}}{\sqrt{V_t}}\le2(\sqrt{V_t}-\sqrt{V_{t-1}})$ 逐项望远镜——**$V_t$ 单调增是前提**。它把"累计曲率"折算成 regret 的 $O(\sqrt K)$ 项，配合凸性即收敛。
2. **Adam 的 $v_t$ 不单调**：$v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2$ 在大梯度后**指数遗忘**（每 $1/(1-\beta_2)=1000$ 步衰减约 $e$ 倍），望远镜恒等式逐项失效：$\frac{g_t^2}{\sqrt{v_t}}$ 不再被 $\sqrt{v_t}$ 的增量控制。Reddi 原文的构造正是"静默期 + 尖峰"的循环：罕见大梯度 $M$ 对 $v$ 的贡献在 $T\gg1000$ 步后衰减殆尽，下一个大梯度到达时 $\sqrt v$ 很小、步长 $\eta m/\sqrt v$ 不受历史曲率约束——$\sum_t g_t^2/\sqrt{\hat v_t}$ 随 $K$ 无界增长，regret 下界 $\Omega(K)$，Adam 发散到边界。
3. **AMSGrad 的修复 = 恢复单调性**：$\hat v_t=\max_{s\le t}v_s$ 强制单调，望远镜恒等式复活——代价是"永不遗忘"的保守步长（对 $C=50$ 的曲线它确实更慢但收敛）。
4. **工程注脚**：这解释了 5.9 误区 3 的"$\beta_2$ 降到 0.95–0.98"（缩短遗忘时间，让尖峰后步长更快恢复——"接受非单调、管理其风险"的路线）与 warmup（覆盖 $v$ 尚未建立的初期）的互补关系；也说明 Adam 原论文证明的漏洞是**结构性**的（滑动平均与自适应步长证明的根本张力），不是笔误。

# 第 6 章 非凸优化与现代视角

## 概念辨析

### 6.1 "深度学习的主要优化障碍是坏局部极小"错在哪

**对应正文**：6.1.2、6.3、6.8 误区 2。

**反驳一（6.1.2 的概率论证）**：随机高斯场模型中，驻点 Hessian 的特征值分布近似对称，$n$ 个特征值全为正的概率随 $n$ 指数衰减（$\sim2^{-n}$ 量级）。深度网络的 $n\sim10^6\text{–}10^{11}$，随机驻点几乎必然是鞍点——**"坏局部极小"是指数级稀有的对象，不可能是"主要障碍"**。正确的困难清单：鞍点（数量上占主导）、平坦高原（非驻点的慢区）、病态（条件数）、坏初始化（对称陷阱）。

**反驳二（6.3 的实证证据）**：如果坏局部极小主导，不同随机种子/初始化的最终 loss 应有显著差异（掉进"好"与"坏"盆地）。实证恰恰相反：(i) 过参数化网络普遍达到（近）零训练损失；(ii) 不同种子的极小点之间存在低损失通道（模式连通性，Garipov 2018）——极小点彼此连通，"坏盆地"缺乏存在空间；(iii) 真正与结果相关的是极小的**平坦度**（与泛化相关），不是"掉进哪个极小"。

**附带辨析**：这句话的流行有历史原因——低维可视化（2D 曲面确实多峰）与早期小网络经验。教学要点：**高维非凸的直觉不能从低维图像外推**——这本身是本章最重要的"反直觉"训练。

### 6.2 同一随机项：第 5 章的敌人、本章的朋友（200 字调和）

**参考范文**：
> 同一个 $\eta(g_B-\nabla L)$，角色取决于目标集合的几何。强凸/凸场景的极小点吸引全空间，噪声唯一的长期效果是阻止轨迹收缩到点——把参数约束在半径 $\propto\sqrt{\eta\sigma^2/B}$ 的噪声球内，制造 $O(\eta\sigma^2/(2B))$ 的地板，是"收敛的敌人"；解药是衰减 $\eta$ 或加大 $B$。非凸场景的鞍点拥有测度为零的稳定流形：一般初值的确定性轨迹本来就会离开，但对恰好落在流形上的轨迹（对称初始化），持续的横向扰动是把它踢出流形的唯一机制，踢出后负曲率方向的不稳定动力学把偏离**指数放大**——扰动成了"逃离的朋友"。统一判据：**噪声球半径与目标集合吸引域宽度之比**。吸引域是全空间（强凸极小）→ 噪声有害；吸引域是零测集（鞍点）→ 噪声必要且廉价（再小的扰动也会被指数放大）。工程结论：凸任务后期压噪声求精度；非凸任务保留噪声直到收敛末期，必要时用周期扰动（6.2.3）替代持续噪声。

### 6.3 隐式偏差使优化器超参数具有正则化含义

**对应正文**：6.4、6.2.4。

**逻辑链**：过参数化 ⇒ 零损失解构成高维流形 ⇒ 算法（而非目标函数）决定停在流形上哪一点 ⇒ 优化超参（$\eta,B,\beta$、初始化）通过改变动力学**选择解** ⇒ 选不同的解 = 施加不同的隐式正则 ⇒ "优化器超参"获得正则化的语义——在过参数化模型里，"你用什么优化"与"你得到什么模型"是同一个问题的两面（6.4 节原话）。

**两个可据此解释的工程现象**：
1. **"小批量/大学习率泛化更好"**：$\eta\sigma^2$ 越大，噪声对尖锐方向的"弹出"越强，能被训练动力学稳定驻留的解必须平坦（6.2.4 末行的线性稳定性分析）；这解释了线性缩放尽头再增大批量时验证 loss 变差的经典观察（第 5 章 5.6.2 临界批量 + 本章 6.2.4）。
2. **weight decay 与学习率的耦合（AdamW 的动机）**：$L_2$ 正则的效果要通过优化动力学兑现——Adam 的自适应缩放使 $L_2$ 惩罚的实际"每步衰减率"与 $\eta$ 纠缠；AdamW 把衰减改成功率归一（每步乘 $(1-\eta\lambda)$ 型），把正则强度从 $\eta$ 中解耦——本质上是承认"超参通过动力学起作用，所以要把它们正交化"。

（其他可选：早停 = 以迭代数为正则参数的隐式正则；dropout 与小批量噪声的可替代性；初始化尺度决定 GD 收敛到最小范数解邻域的哪个点——6.4 节最小实验。）

## 计算推导

### 6.4 双阱 + 碗：驻点分类与 GD 的宿命

**对应正文**：6.1.1、6.2.1。

$f(x,y)=x^4-2x^2+y^2$。$\nabla f=(4x^3-4x,\ 2y)$，$\nabla^2f=\begin{pmatrix}12x^2-4&0\\0&2\end{pmatrix}$。

**驻点**：$4x(x^2-1)=0\Rightarrow x\in\{0,\pm1\}$；$y=0$。三个驻点：
- $(0,0)$：$H=\operatorname{diag}(-4,\,2)$ 不定——$x$ 方向极大、$y$ 方向极小，**鞍点** ✓（校验）；
- $(\pm1,0)$：$H=\operatorname{diag}(8,\,2)\succ0$，严格局部极小；$f(\pm1,0)=-1$。全局性：$x^4-2x^2=(x^2-1)^2-1\ge-1$ 对一切 $x$ 成立，且 $y^2\ge0$，故 $f\ge-1$ 且在 $(\pm1,0)$ 取到——**两个全局极小** ✓（对称性 $x\to-x$ 解释它们成对）。

**GD 从 $x_0\in(-1,1)$、$y_0=0$ 出发**：梯度的 $y$ 分量 $=2y=0$，故 $y_k\equiv0$——轨迹**锁死在 $y=0$ 线**（鞍点的稳定流形）上。一维动力学
$$x_{k+1}=x_k-\eta\,(4x_k^3-4x_k)=x_k\big(1-4\eta(1-x_k^2)\big):$$
$\eta<1/4$ 时对 $|x_k|<1$ 收缩因子 $\in(1-4\eta,\,1)$，$|x_k|$ 单调下降趋于 0——**GD 收敛到鞍点 $(0,0)$**，尽管两侧一步之遥就是全局极小。这正是 6.2.1 的"精确落在稳定流形上"：$y_0=0$ 是零测事件，但对称初始化会真实制造它；任何 $y_0\ne0$ 都会被 $1.2^k$（$\eta=0.1$ 时）指数放大，最终落入某个全局极小（正负由初始噪声决定）。

### 6.5 GD 收敛到欠定最小二乘的最小范数解

**对应正文**：6.4、6.6 速查表、《线性代数》SVD 四子空间。

**设定**：$X\in\mathbb R^{m\times n}$ 满行秩（$m<n$），解集 $\{\theta:X\theta=y\}$ 非空仿射集。迭代 $\theta_{k+1}=\theta_k-\eta X^\top(X\theta_k-y)$，$\theta_0=0$，$\eta<2/\sigma_{\max}^2$。

**第一步（行空间不变性，归纳）**。记 $R=\operatorname{row}(X)=\operatorname{range}(X^\top)$、$N=\ker X$，$\mathbb R^n=R\oplus N$（正交直和）。断言 $\theta_k\in R$ 对一切 $k$：$\theta_0=0\in R$；若 $\theta_k\in R$，则更新量 $-\eta X^\top(X\theta_k-y)\in\operatorname{range}(X^\top)=R$，故 $\theta_{k+1}\in R$。$\blacksquare$（"GD 只在行空间里添加分量"——它连 $N$ 方向的一步都从不迈出，初始化 $\theta_0=0$ 里没有的分量永远不会出现。）

**第二步（极限可行）**。收敛性：误差 $e_k=\theta_k-\theta^\star_{\min}$（$\theta^\star_{\min}=X^\top(XX^\top)^{-1}y$ 为最小范数解）满足 $e_{k+1}=(I-\eta X^\top X)e_k$；$e_k\in R$（两处都在行空间），而 $X^\top X$ 限制在 $R$ 上特征值为 $\sigma_i^2>0$，收缩因子 $|1-\eta\sigma_i^2|<1$，故 $e_k\to0$。取极限得 $X^\top(X\theta_\infty-y)=0$；由 $X$ 满行秩，$X^\top$ 是单射（$\ker X^\top=\{0\}$），故 $X\theta_\infty=y$——$\theta_\infty$ 可行。

**第三步（它就是最小范数解）**。$\theta^\star_{\min}=X^\top(XX^\top)^{-1}y$：可行（$X\theta^\star_{\min}=XX^\top(XX^\top)^{-1}y=y$，用满行秩下 $XX^\top$ 可逆）且 $\in\operatorname{range}(X^\top)=R$；行空间内的可行解**唯一**（若 $\theta_1,\theta_2\in R$ 且 $X\theta_1=X\theta_2$，则 $\theta_1-\theta_2\in R\cap N=\{0\}$）。故 $\theta_\infty=\theta^\star_{\min}$。又任何解 $\theta=\theta^\star_{\min}+n$（$n\in N$），正交性给 $\|\theta\|^2=\|\theta^\star_{\min}\|^2+\|n\|^2\ge\|\theta^\star_{\min}\|^2$——它确实范数最小。$\blacksquare$

**注**：这是"优化即隐式正则化"最干净的实例——目标里没有正则项，GD 的动力学（初始化在 0 + 更新在行空间）替目标"选"了最小范数解。SVD 版本还能读出**谱偏**：$\theta_k=\sum_i\big(1-(1-\eta\sigma_i^2)^k\big)\frac{u_i^\top y}{\sigma_i}v_i$，各奇异分量按 $\sigma_i$ 从大到小逐个学习。

### 6.6 逃离潜伏期的精确计算（含正文校验勘误）

**对应正文**：6.7.1（本册勘误索引 6）。

**推导**。$f=x^2-y^2$，$\eta=0.1$：$y_{k+1}=y_k-\eta(-2y_k)=(1+2\eta)\,y_k=1.2\,y_k$（$x$ 分量按 $0.8^k$ 衰减，与逃逸无关）。$|y_k|=\delta\cdot1.2^k>1$ 要求
$$k>\frac{\ln(1/\delta)}{\ln 1.2}=\frac{18.4207}{0.18232}=101.03\ \Longrightarrow\ k_{\min}=102.$$
（逐步核验：$1.2^{101}\times10^{-8}=0.9945<1$，差半步；$1.2^{102}\times10^{-8}=1.19>1$ ✓。）

> **勘误（本册勘误索引 6）**：正文校验"$\delta=10^{-8}$ 时 $k\approx145$ 步量级"有误。解析值 $k=102$；数值复算（迭代至 $|y_k|>1$）恰为 **102** ✓。另测 $\delta=10^{-10}$：解析 126.3、数值 127 ✓——公式 $\lceil\ln(1/\delta)/\ln(1+2\eta)\rceil$ 两例全对，正文的 145 无对应参数（若反推，$\delta\approx1.2^{-145}\approx3\times10^{-12}$，疑为量级笔误）。

**一般规律与量纲感**：$k\approx\ln(1/\delta)/\ln(1+2\eta)$——初始偏离每小 10 倍，潜伏期加 $\ln10/\ln1.2\approx12.6$ 步；潜伏期结束后 $|y|$ 每步增 20%，约 10 步内完全"显影"。这解释了 6.7.1 的"看似停滞实则潜伏"：loss 曲线前 100 步的平台其实是 $y$ 方向的指数孵化期——**"卡住"与"孵化"在 loss 曲线上不可区分，必须看参数分量本身**。

## 编程实现

### 6.7 GD / SGD / GD+周期重启：三种逃离策略对比

**对应正文**：6.7.2(A)、6.2.2–6.2.3、Jin et al. 2017。

```python
import numpy as np
def f(p):
    x, y = p; return x*x - y*y + 0.05*(x*x + y*y)**2
def grad(p):
    x, y = p; r2 = x*x + y*y
    return np.array([2*x + 0.2*x*r2, -2*y + 0.2*y*r2])
# 极小点: (0, ±sqrt(10)), f* = -10 + 5 = -5
def run(noise, k=300, eta=0.02, x0=(1e-6, 0.0), seed=0, restart_every=0):
    r = np.random.default_rng(seed); p = np.array(x0, float); traj = [p.copy()]
    for i in range(k):
        g = grad(p)
        if noise > 0: g = g + noise*r.normal(size=2)
        p = p - eta*g
        if restart_every and (i+1) % restart_every == 0:
            p = p + 1e-3*r.normal(size=2)          # 周期性微小扰动
        traj.append(p.copy())
    return np.array(traj)
def first_escape(t, thr=0.5):
    yy = np.abs(t[:, 1]); idx = np.argmax(yy > thr)
    return int(idx) if yy[idx] > thr else -1
tg = run(0.0); ts = run(0.05, seed=1); tr = run(0.0, seed=2, restart_every=50)
print("GD             :", tg[-1], first_escape(tg))
print("SGD noise=0.05 :", ts[-1], f(ts[-1]), first_escape(ts))
print("GD+重启(每50步):", tr[-1], f(tr[-1]), first_escape(tr))
```

**实际输出与解读**：

| 策略 | 终点 | $f$ | 首次 $|y|>0.5$ 步数 |
|---|---|---|---|
| GD | $(4.8\times10^{-12},\,0)$ | $0$（鞍点） | 永不（$-1$） |
| SGD（noise=0.05） | $(0.005,\ 3.165)$ | $-4.9999$ | 148 |
| GD+重启（每 50 步，$10^{-3}$） | $(9.9\times10^{-4},\ -3.108)$ | $-4.9943$ | 214 |

- GD 终点即鞍点（浮点意义上永久驻留）——6.2.1 的预言 ✓；SGD 终值 $y\approx3.165$、$f\approx-5$ 与解析极小 $(0,\pm\sqrt{10})$、$f^\star=-5$ 吻合 ✓。
- **重启的潜伏期可以解析预告**：本实验 $\eta=0.02$，鞍点邻域 $y$ 方向每步乘 $1+2\eta=1.04$；单次 $10^{-3}$ 扰动长到 $|y|>0.5$ 需 $\ln(500)/\ln(1.04)\approx158$ 步——**超过 50 步的重启间隔**，所以单次重启不足以逃离；但各次扰动的贡献在 $y$ 方向**累积**：4 次重启（第 50/100/150/200 步）后 $|y|\approx10^{-3}\times(1.04^{150}+1.04^{100}+1.04^{50}+1)\approx10^{-3}\times(359+50+7+1)\approx0.42$，越过 0.5 只需再等约 14 步——与实测的 214 步定量吻合 ✓。
- **算不算"确定性逃离"的可行方案**：算**半确定性**——训练动力学无噪声，但扰动仍是随机抽样。Jin et al. 2017 的扰动 GD 证明"间隔性随机扰动（幅值匹配流形宽度）+ 多项式步数"以高概率逃出所有严格鞍点，本实验是其二维演示。纯确定性的替代是把扰动换成固定符号/交替模式，或负曲率探测（6.2.3 路线 2，需二阶信息但无潜伏期随机性）。**实践结论**：周期重启便宜可行，代价是潜伏期不可控（本例要 4 次重启才逃出）与幅度需要调——这正是 6.7.1"潜伏期随扰动变小而对数增长"的另一面。

### 6.8 牛顿法遇上鞍点：一步跳走还是被吸住？

**对应正文**：6.2.1–6.2.2、3.3.1、6.7.1 的 $f$。

```python
import numpy as np
from scipy.optimize import minimize
def f(p):
    x, y = p; return x*x - y*y + 0.05*(x*x+y*y)**2
def grad(p):
    x, y = p; r2 = x*x+y*y
    return np.array([2*x + 0.2*x*r2, -2*y + 0.2*y*r2])
def hess(p):
    x, y = p
    return np.array([[2 + 0.2*(3*x*x+y*y), 0.4*x*y],
                     [0.4*x*y, -2 + 0.2*(x*x+3*y*y)]])
for x0 in [np.array([1e-3, 0.0]), np.array([1e-3, 1e-3]), np.array([0.5, 0.1])]:
    res = minimize(f, x0, jac=grad, hess=hess, method="Newton-CG")
    print(x0, "->", res.x, "f =", round(f(res.x), 4), "nit =", res.nit)
# 实际输出:
# [0.001 0.   ] -> [ 2.0e-10  0.0e+00]  f =  0.0   nit = 2   ← 收敛到鞍点!
# [0.001 0.001] -> [-1.1e-14  3.16228 ]  f = -5.0   nit = 8   ← 逃到极小
# [0.5   0.1  ] -> [-4.8e-11  3.16228 ]  f = -5.0   nit = 5   ← 逃到极小
```

**结论（与 6.2 节对照）**：
1. **牛顿法是"驻点收集器"，不是"极小收集器"**：它的不动点是 $\nabla f=0$ 的点，不区分极小/极大/鞍点。从 $y=0$（稳定流形）出发，牛顿 2 步收敛到鞍点本身——和 GD 一样"被吸住"，甚至更快（鞍点处牛顿方向直接指向鞍点）。
2. **从 $y\ne0$ 出发跳到极小是"运气"不是"机制"**：Hessian 在鞍点邻域不定，Newton-CG 依赖 Wolfe 线搜索过滤上升步，加上四次兜底项把轨迹引向极小；换一个初值或不定性更强的 $H$，牛顿步可能指向极大甚至发散（3.9 误区 3 的"上升方向"问题）。提示说"取决于 Hessian 处理方式"——实测结论更准确地说：**取决于初值相对稳定流形的位置与线搜索的补救能力**；只有显式修改 Hessian 的使用（正则化 $H+\tau I$、信赖域、三次正则）才把"逃离"变成机制。
3. **系统化对照**：三次正则/信赖域牛顿在检测到负曲率时显式沿负曲率方向走——这正是 6.2.3 总结地图的"负曲率探测"路线：**噪声（SGD）便宜但随机，负曲率探测精准但需要二阶信息**；裸牛顿两条都不占。

### 6.9 filter-normalize 切片：归一化前后的剖面对比（含 `set_theta` 修正）

**对应正文**：6.7.2(B)、6.8 误区 6（本册勘误索引 7）。

> **勘误（本册勘误索引 7）**：正文 6.7.2 的 `set_theta` 有 bug——它把**单个数组**直接赋给 `clf.coefs_`（sklearn 要求**列表**），且循环里 `coefs_` 被覆写两次；原样运行在第一次 `clf.score` 时报形状错误（`matmul: size 1 is different from 2`，已实测复现）。正确写法：按属性**分别收集成列表**再整体赋值，见下面代码。

```python
import numpy as np
from sklearn.datasets import make_moons
from sklearn.neural_network import MLPClassifier
Xm, y01m = make_moons(200, noise=0.2, random_state=0)
clf = MLPClassifier((16, 16), max_iter=2000, random_state=0).fit(Xm, y01m)  # 训练精度 0.875
coefs = [c for c in clf.coefs_] + [c for c in clf.intercepts_]
theta_star = np.concatenate([c.ravel() for c in coefs])
shapes = [c.shape for c in coefs]   # 各层参数范数: 2.37, 4.40, 1.86, 1.40, 1.17, 0.22

def set_theta(clf, theta):          # 修正版: coefs_/intercepts_ 各自收集成列表
    i = 0; cs = []; inters = []
    for c in clf.coefs_:
        n = c.size; cs.append(theta[i:i+n].reshape(c.shape)); i += n
    for c in clf.intercepts_:
        n = c.size; inters.append(theta[i:i+n].reshape(c.shape)); i += n
    clf.coefs_ = cs; clf.intercepts_ = inters

rng = np.random.default_rng(0)
us = [rng.normal(size=sh) for sh in shapes]
vs = [rng.normal(size=sh) for sh in shapes]
def norm_perlayer(dirs, thetas):    # 每层方向范数 → 该层参数范数
    return [d_*(np.linalg.norm(t)/np.linalg.norm(d_)) for d_, t in zip(dirs, thetas)]
us_n = norm_perlayer(us, coefs); vs_n = norm_perlayer(vs, coefs)
def flat(ds): return np.concatenate([d.ravel() for d in ds])

def slice_err(u_flat, v_flat, G=30):
    a = np.linspace(-2, 2, G); b = np.linspace(-2, 2, G); Z = np.zeros((G, G))
    for i, av in enumerate(a):
        for j, bv in enumerate(b):
            set_theta(clf, theta_star + av*u_flat + bv*v_flat)
            Z[i, j] = 1 - clf.score(Xm, y01m)
    set_theta(clf, theta_star)
    return Z

Zu = slice_err(flat(us), flat(vs)); Zn = slice_err(flat(us_n), flat(vs_n))
for name, Z in [("未归一化", Zu), ("filter-normalize", Zn)]:
    print(f"{name}: range=[{Z.min():.3f},{Z.max():.3f}], 中心区域均值={Z[7:23,7:23].mean():.3f}, 误差>0.2占比={(Z>0.2).mean():.2f}")
# 实际输出:
# 未归一化        : range=[0.120,0.860], 中心区域均值=0.405, 误差>0.2占比=0.94
# filter-normalize: range=[0.095,0.720], 中心区域均值=0.207, 误差>0.2占比=0.58
```

**对比解读**：
- **未归一化的剖面系统性"更差"**：94% 的网格训练误差超过 0.2、中心区域均值 0.405——而真实点 $\theta^\star$ 的训练误差只有 0.125！原因：随机方向的各层范数与对应参数层范数严重不匹配（本例从 0.22 到 4.40 相差 20 倍），大范数层的位移主导前向计算，把网络推离有效工作区，画出深谷/悬崖假象——6.8 误区 6 与 Li et al. 2018 强调 filter-normalize 的定量版证据。
- **归一化后**：中心均值降到 0.207、高误差区占比 58%——地形读数变得可信：主体平坦（$\theta^\star$ 附近误差缓升）、存在方向性峡谷，而非处处悬崖。
- **方法注**：本实现是**逐层**归一化（练习指定的简化）；Li et al. 原法逐 filter（权重矩阵每行）归一化，能进一步消除层内失衡。方向一致：**先修"滤镜"再读地形**。

**流程（标注每步的章节依赖）**：
1. **定位容量区间**：估计参数量/样本量之比，判断是否靠近插值阈值——阈值附近所有超参都敏感，应优先加宽/加数据再调参（**本章** 6.3 双下降）；
2. **批量上限 $=\min$(显存上限， 临界批量的几分之一)**：显存由硬件定；临界批量用梯度噪声尺度在线估计（**第 5 章** 5.6.2）；但"超过临界批量继续加大"有泛化风险（大批量-尖锐极小），对验证敏感的任务主动压低 $B$（**本章** 6.2.4/6.3）；
3. **$\eta_0$**：lr range test 定初值 + 线性缩放随 $B$ 调整（**第 5 章** 5.6.1）；上界意识：$2/L$ 与 Edge of Stability——大 $\eta$ 下后期 sharpness 自组织到 $2/\eta$、loss 转非单调，此时不是"炸了"而是进入 EoS 区，可容忍但需监控（**本章** 挑战 13 / 6.11 进阶 3）；
4. **调度**：warmup（覆盖初期曲率未探明 + Adam 矩偏差）+ 余弦衰减（**第 5 章** 5.3）；调度参数与 $\eta_0$ 强耦合，不要一起盲搜（**本章** 6.5"调参元层次"）；
5. **优化器**：AdamW 默认；loss 尖峰频发时 $\beta_2$ 降 0.95–0.98（**第 5 章** 5.9 误区 3）；
6. **验收诊断**：训练/验证 gap、切片平坦度、多 seed 方差——gap 大且极小尖锐 → 回到第 2 步压低 $B$ 或提高噪声（**本章** 6.2.4 + 6.4）。

**依赖本章而非第 5 章的三处**：第 1 步（双下降定位）、第 2 步的"尖锐极小风险封顶"、第 3 步的 EoS 监控与第 6 步的平坦度诊断。分工：**第 5 章回答"多快收敛"，本章回答"收敛到哪里、拿到什么样的解"**。

### 6.12 （研究生层次）负曲率方向上扰动的指数放大：一维化推导

**对应正文**：6.2.2、Ge–Lee–Ma 2015。

**一维模型**：$x_{k+1}=x_k-\eta\lambda x_k+\eta\xi_k$，$\lambda<0$（负曲率方向），$\xi_k$ 零均值方差 $\sigma^2$、与历史独立。记 $\rho=1-\eta\lambda=1+\eta|\lambda|>1$。

**一阶矩**：$\mathbb E[x_{k+1}]=\rho\,\mathbb E[x_k]\Rightarrow\mathbb E[x_k]=\rho^k\mathbb E[x_0]$——均值本身已指数放大。

**二阶矩递推（关键步）**：展开 $x_{k+1}^2=\rho^2x_k^2+2\eta\rho x_k\xi_k+\eta^2\xi_k^2$，取期望；交叉项因 $\xi_k\perp x_k$（独立性假设）为零：
$$\mathbb E[x_{k+1}^2]=\rho^2\,\mathbb E[x_k^2]+\eta^2\sigma^2
\ \Longrightarrow\
\mathbb E[x_k^2]=\rho^{2k}\,\mathbb E[x_0^2]+\eta^2\sigma^2\,\frac{\rho^{2k}-1}{\rho^2-1}\quad(\text{等比求和}).$$

**下界增长解读**：两项都以 $\rho^{2k}=(1+\eta|\lambda|)^{2k}$ 增长——每步方差至少乘 $1+2\eta|\lambda|+O(\eta^2)$，即**振幅的指数增长率为 $\ln(1+\eta|\lambda|)\approx\eta|\lambda|$，时间常数 $1/(\eta|\lambda|)$ 步**。从扰动 $\delta$ 长到 $O(1)$（离开鞍点的二次邻域）需
$$k^\star\approx\frac{\ln(1/\delta)}{\ln(1+\eta|\lambda|)}$$
——与 6.6 题的 $\ln(1/\delta)/\ln1.2$ 在 $\eta|\lambda|=0.2$ 时完全一致 ✓（同一条物理：不稳定方向的动力学把初始扰动指数放大）。

**Ge–Lee–Ma 框架的证明骨架（从一维到定理）**：
1. **局部化**：严格鞍点性质（存在 $v$：$v^\top\nabla^2f\,v\le-c\|\nabla^2f\|$）+ 光滑性保证鞍点小邻域内动力学被二次型一致控制——正曲率方向收缩、负曲率方向按上面的 $\rho>1$ 放大；
2. **分块分析**：把误差分解到正/负曲率子空间。正块用下降性约束（迭代点不能长期停留在"处处正曲率"的收紧区）；负块用上面的方差下界 + **反集中论证**（噪声在负曲率方向的分量以常数概率不小于 $\sigma$ 的常数倍，故不能指望"恰好抵消"）——给出"以 $\ge1-$poly 小概率、poly$(n,L,1/|\lambda_{\min}|)$ 步内离开邻域"；
3. **离开之后**：接回标准下降分析（$L$-光滑下函数值下降，直到下一个鞍点邻域）；
4. **归纳收尾**：对所有鞍点重复（有限个或可数覆盖 + 概率 union bound），得"以概率 1 不收敛到任何严格鞍点"。SGD 的持续噪声扮演 $\xi_k$；扰动 GD（Jin 2017）把 $\xi_k$ 换成间隔性人工扰动并显式匹配幅值（$\sim\sqrt\eta$ 量级），保证"一击脱离"而无需等待噪声慢慢积累。

### 6.13 （研究生层次）Edge of Stability 迷你复现

**对应正文**：6.11 进阶 3、第 2 章 2.3.1、Cohen et al. 2021 (arXiv:2103.00065)。

**实验（numpy 全批量 GD + 有限差分 HVP + 幂迭代，已运行验证）**：两层 tanh 网络（1-8-1，25 参数）拟合 $\sin(3x)$（$n=60$，MSE），$\eta=0.5$；每步用幂迭代跟踪损失 Hessian 的 $\lambda_{\max}$（Hessian–向量积由中心差分 $Hv\approx[\nabla f(\theta+\epsilon v)-\nabla f(\theta-\epsilon v)]/(2\epsilon)$ 计算）。

```python
import numpy as np
rng = np.random.default_rng(0)
n = 60; X = np.linspace(-1, 1, n).reshape(-1, 1)
Y = np.sin(3*X) + 0.05*rng.normal(size=(n, 1))
H = 8
def unpack(p):
    return p[:H].reshape(1,H), p[H:2*H], p[2*H:3*H].reshape(H,1), p[3*H:3*H+1]
def loss(p):
    W1,b1,W2,b2 = unpack(p); r = np.tanh(X@W1+b1)@W2+b2-Y
    return 0.5*(r*r).mean()
def grad(p):
    W1,b1,W2,b2 = unpack(p)
    a = np.tanh(X@W1+b1); r = a@W2+b2-Y
    da = (r@W2.T)*(1-a*a)
    return np.concatenate([(X.T@da/n).ravel(), da.mean(0), (a.T@r/n).ravel(), r.mean(0)])
def hvp(p, v, eps=1e-5): return (grad(p+eps*v)-grad(p-eps*v))/(2*eps)
def lambda_max(p, iters=15):
    v = np.random.default_rng(2).normal(size=p.size); v /= np.linalg.norm(v); lam = 0.0
    for _ in range(iters):
        w = hvp(p, v); nw = np.linalg.norm(w)
        if nw < 1e-13: break
        v = w/nw; lam = nw
    return lam
eta = 0.5
p = 0.3*np.random.default_rng(1).normal(size=3*H+1)
for k in range(2001):
    lm = lambda_max(p)
    if k % 400 == 0: print(k, round(loss(p), 5), round(lm, 3))
    p = p - eta*grad(p)
# 实际输出 (step, loss, lambda_max):
#    0  0.63135  1.609
#  400  0.00761  3.126
#  800  0.00550  4.438
# 1200  0.00533  4.360
# 1600  0.00532  4.285
# 2000  0.00537  4.206
# 末500步: lambda_max 均值 = 4.018 (2/eta = 4.0); loss 存在回升步(非单调) = True
```

**报告要点（对照 $2/\eta=4.0$）**：
1. **渐进锐化（progressive sharpening）**：$\lambda_{\max}$ 从初值 1.61 稳步爬升（loss 从 0.63 降到 0.008 与曲率爬升**并行**）——训练动态主动"把碗磨尖"；
2. **驻留与自稳定**：末 500 步 $\lambda_{\max}$ 均值 4.018——**精确驻留在 $2/\eta=4.0$ 上**（在 3.5–4.4 间振荡，对应原论文的 "dipping" 行为：越过边界 → 沿顶特征方向发散一步 → loss 回升 → 参数被推回临界内侧）；
3. **loss 转非单调**：末段存在回升步（实测 True），训练进入"大步震荡中缓慢下降"的 EoS 形态——此时第 2 章"$\eta<2/L$ 才单调下降"的前提被打破，但训练并未发散；
4. **与第 2 章的对照**：定理 2.4/2.5 的 $2/L$ 是"**给定** $L$ 时的稳定性上界"；EoS 的发现是"$L$ 不是常数——训练动态会把 $L$ 推到边界"，而**上界本身依然精确成立**（这正是驻留值收敛到 $2/\eta$ 的原因），失效的只是"$L$ 固定"这一隐含假设。一句话：**步长上界不是约束，而是吸引子**；
5. **局限**：本复现用全批量 GD、小网络、有限差分 HVP（精度 $\sim10^{-3}$）；原论文在大网络（Transformer/ResNet）上用 Lanczos 跟踪谱、并区分 mini-batch 与 full-batch 行为。定性结论（锐化 + $2/\eta$ 驻留 + 非单调 loss）一致，定量常数（如锐化速度）不可直接外推。
