# 第 1 章 优化问题建模与凸性

> **本章定位**：全课程的第一章，负责建立"优化语言"。前接《高等数学》第 5 章（梯度/Hessian/极值条件）与《线性代数》第 4 章（正定性）；后续第 2 章的收敛率分析、第 4 章的对偶理论、第 5 章的机器学习损失函数，全部建立在"把问题写成标准形式 + 认出它的凸性"这一能力之上。

## 1.0 本章学习目标

学完本章，你能够：

1. 把一个实际问题（线性回归、逻辑回归、SVM）写成优化问题的标准形式，指明决策变量、目标函数与约束；
2. 陈述凸集与凸函数的定义，用一阶条件（梯度单调性）与二阶条件（Hessian 半正定）判别给定函数的凸性；
3. 证明"凸问题的局部最优即全局最优"，并解释这一性质为何使凸优化成为一门可保证的科学；
4. 识别常用凸函数库（仿射、二次型、范数、指数和、log-sum-exp、负熵等）与保持凸性的运算（非负加权和、仿射复合、逐点最大等）；
5. 看懂 cvxpy 等凸建模语言中 "DCP 规则" 背后的数学，并亲手验证典型机器学习损失函数的凸性。

## 1.1 一般优化问题的标准形式

### 1.1.1 三要素

一个优化问题由三部分组成：**决策变量**（decision variables，我们有权选择的量）、**目标函数**（objective，衡量选择好坏的函数）、**约束**（constraints，选择的可行范围）。标准形式为：

$$
\min_{x \in \mathbb{R}^n} \; f_0(x) \quad \text{s.t.} \quad f_i(x) \le 0,\; i = 1, \dots, m; \qquad h_j(x) = 0,\; j = 1, \dots, p. \tag{1.1}
$$

其中 "s.t."（subject to）读作"约束为"。称

$$
D \;=\; \{\, x : f_i(x) \le 0\ (i=1,\dots,m),\; h_j(x) = 0\ (j=1,\dots,p) \,\}
$$

为**可行域（feasible set）**。两条约定：最大化问题 $\max g(x)$ 一律写成 $\min(-g(x))$；约束一律整理成 "$\le 0$" 或 "$= 0$"。当 $m = p = 0$ 时称为**无约束优化（unconstrained optimization）**——深度学习训练表面上是这一类（第 5、6 章），但正则化、投影、硬约束会把它变成真约束问题（第 4 章）。

### 1.1.3 等价变形：上镜图技术与建模技巧

同一个优化问题有无穷多种"写法"，求解器的效率甚至可行性高度依赖写法。三个常用的等价变形（"等价"指最优解可互相恢复）：

1. **上镜图变形（epigraph form）**：$\min_x f_0(x)$ 等价于 $\min_{x, t}\; t$ s.t. $f_0(x) \le t$——多一个变量 $t$，但把不可微目标"藏进"约束。例如 $\min_x \|x\|_\infty$（逐点最大，不可微）变为 $\min_{x,t}\; t$ s.t. $-t \le x_i \le t\ (\forall i)$——目标变成线性的、约束全是仿射的（线性规划）。cvxpy 报错"目标必须凸"时，第一反应就应该是上镜图变形。
2. **消元**：等式约束能解出某变量时直接代入消去（如第 4 章 SVM 对偶推导中对 $b$ 的处理）。
3. **变量替换**：$\min \sum_i e^{x_i}$ 上取对数得到 $\min \log\sum_i e^{x_i}$——两者同解但最优**值**不同（单调变换保解不保值），报告结果时必须写清在哪一个尺度上。

这些技巧的共同数学基础是 1.3.3 节的上镜图视角：约束优化本质上是在 $(x, t)$ 空间中"切"上镜图。掌握它们后你会发现，"把实际问题写成凸问题"一半的工作量在变形，而非判别凸性。

### 1.1.2 最优值与最优解

记最优值 $p^\star = \inf_{x \in D} f_0(x)$（允许 $+\infty$，即不可行）。达到 $p^\star$ 的 $x^\star$ 称为**最优解（optimal solution）**；最优解未必存在（如 $\min e^x$ 无最优解，$p^\star = 0$ 只能在 $x \to -\infty$ 处逼近），也未必唯一（如 $\|x\|_2^2$ 加上对称约束）。工程上常退而求其次求 **$\varepsilon$-次优解**：$f_0(x) \le p^\star + \varepsilon$。这个区分在非凸优化（第 6 章）会变得至关重要：神经网络训练几乎从不找到 $p^\star$，我们只关心"足够好的解"。

## 1.2 局部最优与全局最优

**定义 1.1（局部/全局最优）**。称 $\bar{x}$ 是**局部最优**（local optimum），若存在 $r > 0$ 使 $f_0(\bar{x}) \le f_0(x)$ 对一切 $\|x - \bar{x}\| \le r \cap D$ 中的 $x$ 成立；若此不等式对一切 $x \in D$ 成立，则 $\bar{x}$ 是**全局最优**（global optimum）。

《高等数学》第 5 章你学过：可微函数的局部极值点满足 $\nabla f = 0$（驻点）。但驻点不一定是极小点（可能是极大点或鞍点），且局部极小不一定是全局极小。对一般非凸函数，找到全局最优是 NP-难的；而下面将看到，**凸性彻底改变了这一局面**。

## 1.3 凸集与凸函数

### 1.3.1 凸集

**定义 1.2（凸集，convex set）**。集合 $C \subseteq \mathbb{R}^n$ 是凸的，若对任意 $x, y \in C$ 与 $\theta \in [0, 1]$，有 $\theta x + (1-\theta) y \in C$。即：集合内任意两点的连线段仍在集合内。

常见的凸集：$\mathbb{R}^n$ 本身、超平面 $\{x : a^\top x = b\}$、半空间 $\{x : a^\top x \le b\}$、球 $\{x : \|x - x_c\|_2 \le r\}$、椭球 $\{x : (x-x_c)^\top A^{-1} (x - x_c) \le 1\}$（$A \succ 0$）、多面体、半正定锥 $\mathbb{S}^n_+$。凸集的交仍是凸集——这是构造复杂凸可行域的基本手段（SVM 的可行域正是若干半平面的交，见 1.6.3）。

### 1.3.2 凸函数

**定义 1.3（凸函数，convex function）**。$f: \mathbb{R}^n \to \mathbb{R}$ 是凸的，若定义域为凸集，且对任意 $x, y$ 与 $\theta \in [0,1]$：

$$
f(\theta x + (1-\theta) y) \;\le\; \theta f(x) + (1-\theta) f(y). \tag{1.2}
$$

几何意义：**割线恒在图像上方**（或：函数图像位于任一切线的上方，见 1.4.1 的一阶条件）。若式 (1.2) 对 $x \ne y$ 严格成立，称**严格凸**；若存在 $\mu > 0$ 使 $f(x) - \frac{\mu}{2}\|x\|^2$ 仍是凸函数，称 **$\mu$-强凸**（$\mu$-strongly convex）。强凸比严格凸更强：它要求函数"至少像 $\frac{\mu}{2}\|x\|^2$ 那样弯"，这是第 2 章线性收敛率的关键假设。

直观图像：凸函数像一个"碗"。线性函数、$\|x\|$、$x^2$、$e^x$、$x \log x$（在 $x>0$）都是凸的；$x^3$、$\sin x$、$\log(1+e^{-x})$（注意：这个是凸的！见例 1.2）需要逐一验证。

### 1.3.3 上镜图视角（选读）

$f$ 的**上镜图（epigraph）** $\operatorname{epi} f = \{(x, t) : f(x) \le t\}$ 是 $\mathbb{R}^{n+1}$ 中的集合。核心事实：**$f$ 凸 $\iff$ $\operatorname{epi} f$ 是凸集**。这把"函数的凸性"统一到"集合的凸性"之下，也是现代凸分析把约束优化与函数性质统一处理的起点（Boyd & Vandenberghe 第 3 章）。

## 1.4 凸性判别：一阶与二阶条件

### 1.4.1 一阶条件：切线不等式

**定理 1.4（一阶条件）**。设 $f$ 可微、定义域为凸集，则 $f$ 凸 $\iff$ 对任意 $x, y$：

$$
f(y) \;\ge\; f(x) + \nabla f(x)^\top (y - x). \tag{1.3}
$$

即：**函数图像恒在任一点切平面的上方**。式 (1.3) 是全课程最重要的不等式，昵称"切线不等式"：

- 第 2 章证明梯度法 $O(1/k)$ 收敛率的第一步就是把它用在 $(x_k, x^\star)$ 这一对点上；
- 第 4 章对偶问题的构造（对 $f_0$ 用切线不等式下界）与 Jensen 不等式同源。

**证明思路**（一维情形，多元用降维化归）：必要性：在式 (1.2) 中取 $y = x + t(y-x)$，令 $t \to 0^+$，左端作泰勒展开 $f(x + t(y-x)) = f(x) + t \nabla f(x)^\top (y-x) + o(t)$，两端除以 $t$ 取极限即得。充分性：对 $z = \theta x + (1-\theta) y$ 分别对 $(z, x)$ 与 $(z, y)$ 使用式 (1.3)，加权相加消去 $\nabla f(z)$ 项即得式 (1.2)。$\blacksquare$

由式 (1.3) 立即得到**梯度单调性**：$f$ 凸 $\iff$ $(\nabla f(x) - \nabla f(y))^\top (x - y) \ge 0$ 对一切 $x, y$ 成立（把式 (1.3) 对 $(x,y)$ 与 $(y,x)$ 各写一次相加）。一维时即 $f'$ 单调不减。

### 1.4.2 二阶条件：Hessian 半正定

**定理 1.5（二阶条件）**。设 $f$ 二阶可微、定义域为凸的开集，则 $f$ 凸 $\iff$ $\nabla^2 f(x) \succeq 0$（半正定）对定义域内一切 $x$ 成立；若 $\nabla^2 f(x) \succ 0$ 恒成立，则 $f$ 严格凸（反之不然，如 $x^4$ 在 0 处 Hessian 为 0）。

这直接调用《线性代数》第 4 章：对称矩阵半正定 $\iff$ 全部特征值 $\ge 0$。**这是实战中最常用的判别法**——算出 Hessian、看特征值符号即可。强凸的二阶刻画：$f$ 是 $\mu$-强凸 $\iff$ $\nabla^2 f(x) \succeq \mu I$ 恒成立，即 Hessian 的最小特征值处处 $\ge \mu$（第 2 章的 $\mu$ 与最大曲率 $L$ 之比给出条件数 $\kappa = L/\mu$）。

**例 1.1**。$f(w) = \frac{1}{2}\|Xw - y\|_2^2$（线性回归损失）。$\nabla^2 f = X^\top X \succeq 0$ 恒成立，故 $f$ 凸；当 $X$ 列满秩时 $X^\top X \succ 0$，强凸，且 $\mu = \lambda_{\min}(X^\top X)$、$L = \lambda_{\max}(X^\top X)$——这正是第 2 章分析该问题收敛率时条件数的来源。

**例 1.2**。$f(w) = \sum_{i=1}^n \log(1 + e^{-y_i w^\top x_i})$（逻辑回归损失，$y_i \in \{\pm 1\}$）。单个样本的损失 $g(z) = \log(1+e^{-z})$ 满足 $g''(z) = \frac{e^{-z}}{(1+e^{-z})^2} > 0$（sigmoid 的方差函数，恒正），而 $z = y_i w^\top x_i$ 是 $w$ 的仿射函数，仿射复合保持凸性（见 1.5），凸函数非负和保持凸性。故逻辑回归是**无约束凸问题**——这是它成为机器学习"标准起点"的数学原因。

## 1.5 常见凸函数库与保持凸性的运算

背熟下面两张"元件表"，你就能像搭积木一样判别绝大多数机器学习目标的凸性。

**凸函数库**（$f$ 凸，定义域凸）：

| 函数 | 定义域 | 备注 |
|---|---|---|
| 仿射函数 $a^\top x + b$ | $\mathbb{R}^n$ | 既凸又凹 |
| 二次型 $\frac{1}{2} x^\top P x + q^\top x + r$ | $\mathbb{R}^n$ | 凸 $\iff P \succeq 0$ |
| 范数 $\|x\|$（任意范数） | $\mathbb{R}^n$ | 含 $\ell_1$（$\sum\|x_i\|$）、$\ell_2$、$\ell_\infty$；$\ell_1$ 在原点不可导，是稀疏正则（LASSO）的基础 |
| 指数 $e^{ax}$ | $\mathbb{R}$ | $a$ 任意 |
| 幂函数 $x^a$ | $x > 0$ | 凸 $\iff a \ge 1$ 或 $a \le 0$；凹 $\iff 0 \le a \le 1$ |
| $x \log x$（负熵） | $x > 0$ | 凸；扩展定义 $0\log 0 = 0$ 后在 $x \ge 0$ 凸 |
| $-\log x$ | $x > 0$ | 凸（对数障碍函数的核心） |
| log-sum-exp $\log \sum_k e^{x_k}$ | $\mathbb{R}^n$ | 凸；softmax 的"光滑 max"，深度学习中数值稳定交叉熵的来源 |
| 负对数似然 $\log(1 + e^{-z})$ | $\mathbb{R}$ | 凸（例 1.2） |

**保持凸性的运算**（$f, g$ 凸，则下列仍凸）：

1. **非负加权和**：$\alpha f + \beta g$（$\alpha, \beta \ge 0$）。注意"凸 + 凹"不一定凸。
2. **仿射复合**：$f(Ax + b)$ 凸。
3. **逐点最大**：$\max(f_1, \dots, f_m)$ 凸；上确界 $\sup_{y \in C} f(x, y)$ 凸。Hinge 损失 $\max(0, 1 - z)$ 是两个凸函数的逐点最大，故凸——SVM 目标的凸性来源。
4. **偏最小化（部分变量消去）**：$g(x) = \inf_y f(x, y)$ 凸（若 $f$ 对 $(x,y)$ 联合凸）。第 4 章构造对偶函数时用的正是它。
5. **复合规则**（一般情形）：$h(f(x))$，若 $h$ 凸且**不减**、$f$ 凸，或 $h$ 凸且**不增**、$f$ 凹，则复合凸。这条解释了"$\exp(f)$ 凸（$f$ 凸）"但"$\exp(g)$ 凹不一定"等现象。

这两张表正是 cvxpy 的 DCP（Disciplined Convex Programming）规则的雏形：cvxpy 不做任意符号推理，而是要求你只用凸函数库 + 上述运算来写目标——一旦违规立即报错。理解了本节，你就能读懂 cvxpy 的报错信息并修正建模。

## 1.6 为什么凸性重要：局部即全局

**定理 1.6（凸问题的局部最优即全局最优）**。设 $f_0$ 凸、$D$ 凸，$\bar{x} \in D$ 是局部最优，则 $\bar{x}$ 是全局最优。

**证明**。反设存在 $y \in D$ 使 $f_0(y) < f_0(\bar{x})$。由 $D$ 凸，对任意 $\theta \in (0, 1)$，点 $z_\theta = \bar{x} + \theta (y - \bar{x}) \in D$。由凸性（式 1.2）：

$$
f_0(z_\theta) \;\le\; (1-\theta) f_0(\bar{x}) + \theta f_0(y) \;<\; f_0(\bar{x}).
$$

当 $\theta$ 足够小时 $z_\theta$ 落在 $\bar{x}$ 的任意小邻域内，与 $\bar{x}$ 是局部最优矛盾。$\blacksquare$

这个几行的证明是全课程最具杠杆性的结论：

- **算法意义**：对凸问题，任何找到局部最优的算法自动解决全局问题。梯度法在凸问题上没有"卡在坏局部极小"的风险（第 2 章）；牛顿法、内点法同样如此。
- **理论意义**：凸问题可以给出**对偶下界**（第 4 章）与**收敛率保证**（第 2 章）——"保证"（certificate）二字只对凸问题普遍成立。
- **实践意义**：所以我们要努力把问题**建模成**凸的。线性回归、逻辑回归、SVM、LASSO 全部是刻意选择/证明出来的凸模型；深度学习放弃了凸性，换来表达能力，代价就是第 6 章要讨论的全部复杂性。

**注意区分**：局部即全局说的是"点"的性质；凸问题还可能有不止一个最优解，但**最优解集合一定是凸集**，且目标值沿该集合恒为 $p^\star$。

## 1.8 示例与案例

### 1.8.1 手算算例：验证切线不等式与逻辑回归凸性

**（a）切线不等式的数值验证**。取 $f(x) = x^2$，$x = 1$，则切线为 $f(1) + f'(1)(y - 1) = 1 + 2(y-1) = 2y - 1$。取 $y = 3$：$f(3) = 9 \ge 2 \times 3 - 1 = 5$；取 $y = -2$：$f(-2) = 4 \ge -5$。均成立，与定理 1.4 一致。可以证明对 $x^2$，切线不等式即 $(y-x)^2 \ge 0$——许多著名不等式（AM-GM、Cauchy–Schwarz）都是某个凸函数切线不等式的化身。

**（b）逻辑回归的凸性验证链**。写出 Hessian。记 $X \in \mathbb{R}^{n \times d}$（各行是样本 $x_i^\top$），$y \in \{\pm 1\}^n$，$s = \sigma(Xw)$（$\sigma$ 为 sigmoid）。损失 $\hat{L}(w) = \sum_i \log(1 + e^{-y_i x_i^\top w})$。对单个样本求导：$\frac{\partial}{\partial w}\log(1+e^{-y_i x_i^\top w}) = -y_i (1 - s_i) x_i$，二阶导为 $s_i(1-s_i)\, x_i x_i^\top$。故

$$
\nabla^2 \hat{L}(w) \;=\; X^\top \operatorname{diag}\big(s_i (1 - s_i)\big)\, X.
$$

对任意 $v$：$v^\top \nabla^2 \hat{L} v = \sum_i s_i(1-s_i) (x_i^\top v)^2 \ge 0$（因 $s_i \in (0,1)$ 使权重非负）。故 $\hat{L}$ 凸。注意 $s_i(1-s_i) \le 1/4$：sigmoid 饱和时曲率趋零——逻辑回归损失是凸的但**不一定强凸**（$X$ 不满秩或样本线性可分到无穷时），这解释了"线性可分时逻辑回归权重会跑到无穷大"的经典现象。

**（c）切线不等式的"不等式工厂"角色**。取 $f(x) = e^x$，切线不等式 $e^y \ge e^x(1 + y - x)$；令 $x = 0$ 得 $e^y \ge 1 + y$（指数不等式）。又如 $\log x \le x - 1$ 是凸函数 $-\log x$ 的切线不等式，由 $\log$ 的凹性（图像在切线下方）可得 $\log\frac{a+b}{2} \ge \frac{1}{2}(\log a + \log b) = \log\sqrt{ab}$——这正是 AM-GM 不等式。许多著名不等式本质上是某个凸/凹函数的切线不等式；这个视角在《概率统计》的 Jensen 不等式（期望版切线不等式）中全面展开，而 Jensen 正是第 4 章构造对偶函数（对期望目标使用切线下界）的工具。

### 1.8.2 代码示例：三个机器学习问题的优化表述 + 凸性数值体检

```python
"""第 1 章：把线性回归/逻辑回归/SVM 写成优化问题，并数值验证凸性。
运行环境：numpy, matplotlib（无其他依赖）。"""
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)
n, d = 200, 2                       # 样本数与特征维数（取 d=2 便于画等高线）
X = rng.normal(size=(n, d))
y_reg = X @ np.array([1.5, -2.0]) + 0.3 * rng.normal(size=n)      # 回归目标
y_cls = np.sign(y_reg)                                            # 分类标签 {±1}
y_cls[y_cls == 0] = 1

# ---- 问题 A：线性回归  min_w (1/2n) ||Xw - y||^2  （凸：X^T X >= 0）----
def loss_ridge(w, lam=0.1):                       # 加 L2 正则（岭回归），仍凸
    r = X @ w - y_reg
    return (r @ r) / (2 * n) + lam * (w @ w)

# ---- 问题 B：逻辑回归  min_w (1/n) sum log(1+exp(-y_i x_i^T w)) （凸）----
def loss_logistic(w):
    z = y_cls * (X @ w)
    return np.logaddexp(0, -z).mean()             # log(1+exp(-z)) 的数值稳定实现

# ---- 问题 C：SVM（hinge + L2） min_w (lam/2)||w||^2 + (1/n) sum max(0, 1-y_i x_i^T w) ----
def loss_svm(w, lam=0.1):
    z = y_cls * (X @ w)
    return lam * (w @ w) / 2 + np.maximum(0, 1 - z).mean()

# ---- 凸性"体检"：在网格上随机取两点，验证割线不等式 (1.2) ----
def convexity_check(loss, num=20000, tol=1e-12):
    """随机采样检验 f(θx+(1-θ)y) <= θf(x)+(1-θ)f(y)。凸函数应零违例。
    注意：数值检验不能证明凸性，只能发现明显的非凸（如多极小值）。"""
    viol = 0
    for _ in range(num):
        w1, w2 = rng.normal(size=d) * 3, rng.normal(size=d) * 3
        theta = rng.uniform(0, 1)
        lhs = loss(theta * w1 + (1 - theta) * w2)
        rhs = theta * loss(w1) + (1 - theta) * loss(w2)
        viol += (lhs > rhs + tol * max(1, abs(rhs)))
    return viol

print("线性回归违例数:", convexity_check(loss_ridge))    # 预期输出: 0
print("逻辑回归违例数:", convexity_check(loss_logistic)) # 预期输出: 0
print("SVM      违例数:", convexity_check(loss_svm))     # 预期输出: 0

# ---- 反例：一个真正的非凸损失（如 1+sin 的复合），违例会显著出现 ----
loss_nonconvex = lambda w: 1.0 + np.sin(2 * w[0]) + (w[1] ** 2)
print("非凸例子违例数:", convexity_check(loss_nonconvex, num=2000))  # 预期输出: >0

# ---- 等高线图：直观对比凸与非凸的损失景观 ----
g = np.linspace(-3, 3, 200)
W1, W2 = np.meshgrid(g, g)
fig, axes = plt.subplots(1, 2, figsize=(10, 4))
for ax, loss, title in [(axes[0], loss_logistic, "logistic (convex)"),
                        (axes[1], loss_nonconvex, "nonconvex")]:
    Z = np.array([[loss(np.array([a, b])) for a in g] for b in g])
    ax.contourf(W1, W2, Z, levels=30, cmap="viridis")
    ax.set_title(title)
plt.tight_layout()
plt.savefig("ch1_convexity.png", dpi=150)
```

预期现象：凸损失等高线是"同心碗状"（可能拉长成椭圆，对应第 2 章的病态），非凸损失出现多个谷底。**注意**：随机采样式数值体检是启发式的（严格凸性证明靠定理 1.4/1.5），它的价值在于培养你对损失景观的手感。

## 1.9 常见误区与陷阱

1. **"两个凸函数的和一定凸，但差的保号性要看系数"**。$f - g$（$f, g$ 凸）一般不凸；岭回归 $\|Xw-y\|^2 + \lambda\|w\|^2$ 凸是因为 $\lambda > 0$ 使第二项权重非负。许多人把"加正则项仍凸"错误外推到"减去任何项仍凸"。
2. **"Hessian 半正定 $\Rightarrow$ 严格凸"是错的**。$x^4$ 的 Hessian 在 $x=0$ 处为 $0$（半正定而非正定），但 $x^4$ 严格凸。正确表述：Hessian 处处正定 $\Rightarrow$ 严格凸；严格凸 + 二阶可导只保证 Hessian 处处半正定。
3. **凸函数的定义域必须一起检查**。$1/x$ 在 $x \ne 0$ 上二阶导 $2/x^3$，在 $x > 0$ 凸、$x < 0$ 凹；脱离定义域谈凸性没有意义。建模时（如 $-\log x$、$x \log x$）务必带上定义域约束。
4. **"凸函数只有一个极小点"是错的**。凸函数的最优**值**唯一、最优**解集**是凸集但可以是一整段（如 $\max(0, |x| - 1)$ 在 $[-1, 1]$ 上都取到最小值 0）。SVM 的解 $w^\star$ 唯一（因强凸），但对偶乘子不一定唯一——这会在第 4 章再次出现。
5. **把"目标凸"误当成"问题凸"**。凸问题的完整要求是：目标凸 + 可行域凸（等式约束必须仿射、不等式约束函数必须凸）。目标凸但约束非凸（如 $h(x) = x^2 - 1 = 0$）的问题仍是非凸问题。
