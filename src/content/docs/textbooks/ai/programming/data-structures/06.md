# 第 6 章 动态规划与贪心——优化的两种哲学

> **本章定位**：前几章回答"如何高效地查找与组织"，本章回答"如何在指数级的选择空间中找到最优解"。动态规划（DP）与贪心是两个互补的设计哲学：DP 用空间换最优性保证，贪心用证明换线性时间。本章的编辑距离是 NLP 评测指标 WER 的基石，将给出完整推导；DP 的思想也是《强化学习》值迭代的骨架。前置要求：第 1 章（复杂度、递推）、第 4 章（DAG 上的最短路——DP 的图视角）。

## 6.1 从指数到多项式：重叠子问题与最优子结构

以最短路径的递归视角开场（衔接第 4 章 Bellman-Ford）：无负环图中，$s \to t$ 的最短路满足

$$d(t) = \min_{(u,t) \in E}\ \{d(u) + w(u, t)\}.$$

直接递归计算会发生什么？同一个 $d(u)$ 会被指数多次求值（每条路径重复展开）——这就是**重叠子问题（overlapping subproblems）**。两种对策：

- **记忆化（memoization）**：递归 + 哈希表缓存已算过的子问题（第 2 章哈希表的直接应用），"自顶向下"；
- **制表（tabulation）**：按依赖序迭代填表，"自底向上"，无递归栈、可空间滚动优化。

DP 可行的另一半前提是**最优子结构（optimal substructure）**：原问题的最优解由子问题的最优解构成——最短路满足（最短路的子路径仍是最短的，第 4 章已用），但"最长路"在带环图中不满足（最长路定义良好当且仅当 DAG，恰是拓扑排序的用武之地）。**DP 本质上是在 DAG 上按拓扑序求不动点**——这个统一视角把第 4 章与本章连成一体。

斐波那契是最小化例：

```python
import functools

def fib_naive(n):                       # Θ(1.618^n)：重叠子问题全裸奔
    return n if n < 2 else fib_naive(n-1) + fib_naive(n-2)

@functools.lru_cache(maxsize=None)      # 记忆化：Python 一行解决
def fib_memo(n):                        # Θ(n) 时间、Θ(n) 空间
    return n if n < 2 else fib_memo(n-1) + fib_memo(n-2)

def fib_tab(n):                         # 制表 + 滚动变量：Θ(n) 时间 O(1) 空间
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

print(fib_memo(50), fib_tab(50))        # 12586269025 12586269025
# fib_naive(50) 在本机需数十秒至数分钟——三种写法语义相同、复杂度天壤之别
```

## 6.2 状态设计四步法

新问题如何下手？机械执行四步：

1. **定义状态**：`dp[i][j]` 是什么（一句话说清，通常 = "前 i 个……与 前 j 个……的最优值"）。状态是**子问题的完整描述**，少了信息就推不出转移。
2. **列出转移**：最后一步的选择有哪些？`dp[i][j] = f(更小的 dp)`。转移枚举的是"最优解的最后一步"。
3. **遍历序与边界**：保证算 `dp[i][j]` 时所有依赖已算好（等价于依赖图的拓扑序）；空输入/单元素等边界显式给出。
4. **读答案与回溯**：答案常在表角；需要具体方案时记 parent 指针回溯（或从表中反向重推）。

**验证工具**：写完 DP，用 $O(2^n)$ 暴力搜索对拍小规模数据（$n \le 15$）——这是《实验设计与评估》"用低效但显然正确的方法验证高效方法"的思想。

## 6.3 最长公共子序列（LCS）

**问题**：两序列的最长公共子序列（不要求连续）。**为什么重要**：序列对齐的原型——DNA 序列比对（生物信息）、译文-参考译文的匹配、diff 工具。

**四步设计**：

1. 状态：$dp[i][j]$ = $a$ 的前 $i$ 个字符与 $b$ 的前 $j$ 个字符的 LCS 长度。
2. 转移：末位相同时 $dp[i][j] = dp[i-1][j-1] + 1$；不同时 $dp[i][j] = \max(dp[i-1][j],\ dp[i][j-1])$（丢掉 $a[i]$ 或丢掉 $b[j]$，至少一个不在最优 LCS 中——反证：若两者都在且末位不同，则 LCS 末位不可能同时匹配两个不同字符）。
3. 边界：$dp[0][j] = dp[i][0] = 0$（空序列无公共子序列）。
4. 答案：$dp[m][n]$；回溯 $O(m+n)$ 得具体子序列。

复杂度 $O(mn)$ 时间；空间可滚动到 $O(\min(m,n))$（若只要长度）。

## 6.4 编辑距离：WER 的基石（完整推导）

**定义（编辑距离 / Levenshtein 距离）**：把字符串 $a$ 变成 $b$ 所需的最少单字符操作数，操作为：插入（insert）、删除（delete）、替换（substitute），各代价 1。

**四步设计**：

1. 状态：$dp[i][j]$ = 把 $a[:i]$ 变为 $b[:j]$ 的最少操作数。
2. 转移：考虑 $a[:i]$ 变成 $b[:j]$ 的**最后一步**：

$$dp[i][j] = \begin{cases} dp[i-1][j-1] & a[i-1] = b[j-1]\ (\text{末字符已匹配，免费})\\[2pt] 1 + \min\begin{cases} dp[i-1][j] & \text{删除 } a[i-1]\\ dp[i][j-1] & \text{插入 } b[j-1]\\ dp[i-1][j-1] & \text{替换 } a[i-1] \to b[j-1] \end{cases} & a[i-1] \ne b[j-1] \end{cases}$$

3. 边界：$dp[i][0] = i$（全删）、$dp[0][j] = j$（全插）。
4. 答案：$dp[m][n]$。

**正确性论证**（关键一步，不跳步）：最优变换序列的最后一次操作只涉及 $a$ 的末字符与 $b$ 的末字符，分三类——

- 最后一步与两串末字符都无关（先变换 $a[:i]$ 到 $b[:j-1]$ 再插入 $b[j-1]$）：代价 $dp[i][j-1] + 1$；
- 或先删 $a[i-1]$ 再把 $a[:i-1]$ 变到 $b[:j]$：代价 $dp[i-1][j] + 1$；
- 或把 $a[:i-1]$ 变到 $b[:j-1]$ 后处理末位：相同则免费（代价 $dp[i-1][j-1]$），不同则替换（$dp[i-1][j-1]+1$）。

最优解必属其一，取最小即转移式。重叠子问题显然（$dp[i-1][j-1]$ 被多个转移引用），最优子结构由上述分类穷举保证。复杂度 $O(mn)$ 时间、$O(\min(m,n))$ 空间（滚动行）。

**与 WER 的关系**：词错误率（Word Error Rate，语音识别与机器翻译评测的核心指标）定义为

$$\mathrm{WER} = \frac{\text{插入} + \text{删除} + \text{替换}}{\text{参考句词数}} = \frac{D(s_{\text{识别}}, s_{\text{参考}})}{|s_{\text{参考}}|},$$

**分母以词为原子、分子就是编辑距离本身**——把"字符"换成"词"重跑 6.4 的 DP 即得。CER（字符错误率）同理。理解 WER 必须先理解编辑距离，这就是本节存在的原因。

```python
def edit_distance(a, b):
    """完整 DP 表版（教学版）：O(mn) 时间、O(mn) 空间，支持回溯对齐。"""
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1): dp[i][0] = i     # 全删
    for j in range(n + 1): dp[0][j] = j     # 全插
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i-1] == b[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(dp[i-1][j],      # 删除
                                   dp[i][j-1],      # 插入
                                   dp[i-1][j-1])    # 替换
    return dp, dp[m][n]

def align(dp, a, b):
    """从表回溯一个最优对齐（WER 逐词归因的依据）。"""
    i, j, ops = len(a), len(b), []
    while i > 0 or j > 0:
        if i > 0 and j > 0 and a[i-1] == b[j-1] and dp[i][j] == dp[i-1][j-1]:
            ops.append(("=", a[i-1])); i -= 1; j -= 1
        elif i > 0 and j > 0 and dp[i][j] == dp[i-1][j-1] + 1:
            ops.append(("s", a[i-1], b[j-1])); i -= 1; j -= 1
        elif i > 0 and dp[i][j] == dp[i-1][j] + 1:
            ops.append(("d", a[i-1])); i -= 1
        else:
            ops.append(("i", b[j-1])); j -= 1
    return ops[::-1]

dp, dist = edit_distance("intention", "execution")
print(dist)                        # 5（Levenshtein 的经典例子）
for op in align(dp, "intention", "execution")[:6]:
    print(op)
# 预期输出：5，以及形如 ('i','e') ('s','i','x') ('s','n','e') 的对齐序列
```

手算表（$a=$ `inten`，$b=$ `exec` 的左上角局部）可用练习 3 校验。

## 6.5 背包：从 0/1 到完全

**0/1 背包**：$n$ 个物品，重量 $w_i$、价值 $v_i$，容量 $C$，每件至多选一次，最大化总价值且不超容。

- 状态：$dp[i][c]$ = 只考虑前 $i$ 件、容量 $c$ 时的最大价值；
- 转移：$dp[i][c] = \max(dp[i-1][c],\ dp[i-1][c - w_i] + v_i)$（不选 / 选）——**第二项必须是 $i-1$ 行**，保证每件只用一次；
- 边界：$dp[0][\cdot] = 0$；答案 $dp[n][C]$；$O(nC)$ 时间、$O(C)$ 空间（**一维滚动时 $c$ 必须倒序遍历**，否则 $dp[c-w_i]$ 已被本行更新，等价于物品可复用）。

**完全背包**（每件无限件）：一维滚动 + **$c$ 正序遍历**即可——正序时 $dp[c-w_i]$ 已含"已选当前物品"的信息，恰好允许复用。**一个遍历方向之差，区分了两种背包**——这是 DP 空间优化中最著名的细节。

```python
def knapsack_01(weights, values, C):
    """0/1 背包，一维滚动。O(nC) 时间 O(C) 空间。"""
    dp = [0] * (C + 1)
    for w, v in zip(weights, values):
        for c in range(C, w - 1, -1):      # 倒序：保证每件只选一次
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[C]

def knapsack_complete(weights, values, C):
    """完全背包：正序即允许复用。"""
    dp = [0] * (C + 1)
    for w, v in zip(weights, values):
        for c in range(w, C + 1):          # 正序：允许重复选取
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[C]

print(knapsack_01([2, 3, 4, 5], [3, 4, 5, 6], 8))      # 10（选 w=3,v=4 与 w=5,v=6，恰装满）
print(knapsack_complete([2, 3], [3, 4], 8))            # 12（四件 w=2,v=3，重 8 价值 12）
```

（校验：0/1 背包枚举 16 个子集，最优为 $\{w{=}3, w{=}5\}$：重 $8\le 8$、价值 $4+6=10$。完全背包允许复用，四件 $w=2$ 重 8、价值 $4\times3=12$。两题手算过程见练习 4。）

**伪多项式警示**：$O(nC)$ 中 $C$ 是**数值**而非输入长度（输入长度 $\log C$），故背包是伪多项式时间——$C = 10^9$ 时此表不可行，需转投贪心近似（FPTAS）或分支限界。这与"DP 不是万能药"呼应：**状态空间是指数的、枚举的是其中的多项式子集**；当那个子集本身爆炸时，DP 失效。

## 6.6 贪心：交换论证与找零反例

**贪心算法**：每步做局部最优选择，不回溯。它**没有万能正确性**，正确的贪心需要证明。最常用的证明武器是**交换论证（exchange argument）**：

> 设贪心解 $G$、任意最优解 $O$。若 $G \ne O$，找到第一处不同，把 $O$ 中该处换成贪心的选择（交换），证明交换后仍最优且与 $G$ 更接近；归纳得 $G$ 最优。

**例 6.1（区间调度，可贪）**：活动互斥、求最多活动数。贪心：按**结束时间**排序，依次选不冲突的。交换论证：设最优解第一个活动为 $o$、贪心第一个为 $g$，有 $\text{end}(g) \le \text{end}(o)$；把 $O$ 的第一个换成 $g$，其余活动仍不冲突（都不晚于原第一个的结束），解仍最优。归纳。$O(n\log n)$（排序主导）。

**例 6.2（找零，反例）**：币值 $\{1, 5, 10, 25\}$，找 30 分：贪心（先大后小）得 $25+5$，2 枚，恰好最优。但币值 $\{1, 5, 11\}$ 找 15：贪心得 $11+1+1+1+1$（5 枚），最优为 $5+5+5$（3 枚）。**贪心失效，因为"先拿大币"破坏了余数的可组合性**——退回 DP：$dp[x] = \min_{\text{coin}} dp[x - \text{coin}] + 1$。

**DP 与贪心的边界**（本课最重要的判断力之一）：

| 维度 | 贪心 | DP |
|---|---|---|
| 正确性 | 需要可证明的贪心选择性质 + 最优子结构 | 最优子结构 + 无后效性即可 |
| 复杂度 | 通常 $O(n\log n)$ 或 $O(n)$ | 状态数 × 转移数，可能很高 |
| 换来的 | 速度 | 最优性保证 |
| 典型 | 区间调度、MST、Dijkstra、Huffman | LCS、编辑距离、背包、Viterbi |

经验法则：**若"局部最优可被证明全局安全"（存在交换论证），贪心；若选择之间强耦合（拿 A 会改变 B 的价值），DP。** 第 4 章的 Dijkstra/MST 正是"贪心 + 证明"的范例，本章给出证明技术的出处。

## 6.7 关键公式速查

| 结论 | 适用条件 |
|---|---|
| DP = 记忆化或制表，代价 = 状态数 × 转移数 | 重叠子问题 + 最优子结构 |
| LCS：$dp[i][j] = dp[i-1][j-1]+1$（相同）或 $\max(dp[i-1][j], dp[i][j-1])$ | $O(mn)$ |
| 编辑距离：$1 + \min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])$（不同时） | $O(mn)$；WER = 距离/参考词数 |
| 0/1 背包一维滚动 **倒序**；完全背包 **正序** | 遍历方向 = 是否允许复用 |
| 背包 $O(nC)$ 是伪多项式 | $C$ 为数值，输入长 $\log C$ |
| 交换论证：换一处不劣 + 归纳 | 贪心正确性证明 |
| 区间调度按结束时间贪心，$O(n\log n)$ | 互斥活动最大化 |
| 最短路递推 $d(t)=\min_u d(u)+w(u,t)$ | Bellman-Ford/DAG DP 同构 |

## 6.8 示例与案例

### 案例 1（手算）：编辑距离表的完整填充

求 `"cat"` 与 `"cut"` 的编辑距离。初始化第一行/列为 $0,1,2,3$：

| | "" | c | u | t |
|---|---|---|---|---|
| **""** | 0 | 1 | 2 | 3 |
| **c** | 1 | **0** | 1 | 2 |
| **a** | 2 | 1 | **1** | 2 |
| **t** | 3 | 2 | 2 | **1** |

逐格说明：$dp[1][1]$：`c=c` 免费取左上 0；$dp[1][2]$：`c≠u`，$1+\min(1,2,0)=1$（把 `c` 替换为 `u`）；$dp[2][2]$：`a≠u`，$1+\min(2,1,0)=1$（插入 `u`）；$dp[3][3]$：`t=t` 免费取左上 2？——**此处须仔细**：$dp[3][3]$ 处 `t=t`，取 $dp[2][2]=1$，故最终距离为 1（把 `a` 替换为 `u`）。表中加粗对角线即回溯路径。**结论：`cat → cut` 距离 1，对齐为 `c=c, a→u, t=t`。**

### 案例 2（代码）：WER 计算（词级编辑距离 + 归因）

```python
"""词错误率 WER：NLP/语音评测的基石（《自然语言处理》评测一节直接使用）。
   支持代价加权（替换代价可设 2 或 1，业界两种口径都存在）。"""
def wer(ref, hyp, sub_cost=1):
    """ref/hyp: 词列表。返回 (wer, 操作计数, 对齐)。"""
    m, n = len(ref), len(hyp)
    dp = [[0]*(n+1) for _ in range(m+1)]
    for i in range(m+1): dp[i][0] = i
    for j in range(n+1): dp[0][j] = j
    for i in range(1, m+1):
        for j in range(1, n+1):
            if ref[i-1] == hyp[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = min(dp[i-1][j] + 1,          # 删（漏词）
                               dp[i][j-1] + 1,          # 插（多词）
                               dp[i-1][j-1] + sub_cost) # 替换（错词）
    # 回溯统计
    i, j, D = m, n, {"del": 0, "ins": 0, "sub": 0}
    ops = []
    while i > 0 or j > 0:
        if i > 0 and j > 0 and ref[i-1] == hyp[j-1] and dp[i][j] == dp[i-1][j-1]:
            i -= 1; j -= 1
        elif i > 0 and j > 0 and dp[i][j] == dp[i-1][j-1] + sub_cost:
            D["sub"] += 1; ops.append(("SUB", ref[i-1], hyp[j-1])); i -= 1; j -= 1
        elif i > 0 and dp[i][j] == dp[i-1][j] + 1:
            D["del"] += 1; ops.append(("DEL", ref[i-1])); i -= 1
        else:
            D["ins"] += 1; ops.append(("INS", hyp[j-1])); j -= 1
    return dp[m][n] / m, D, ops[::-1]

ref  = "the cat sat on the mat".split()
hyp1 = "the cat sat on a mat".split()
hyp2 = "the cat on mat".split()
print(wer(ref, hyp1)[0])   # 1/6 ≈ 0.1667（the→a 一个替换）
print(wer(ref, hyp2)[:2])
# 预期输出：0.16666666666666666
#           0.3333333333333333 {'del': 1, 'ins': 0, 'sub': 1}（漏 sat、错 on the→on）
```

### 案例 3（代码）：0/1 背包对拍与"遍历方向"实验

```python
"""用暴力枚举对拍背包 DP（四步法第 5 步：验证）。"""
from itertools import product

def brute_knapsack(ws, vs, C):
    n = len(ws)
    best = 0
    for bits in product([0, 1], repeat=n):
        w = sum(b * wi for b, wi in zip(bits, ws))
        v = sum(b * vi for b, vi in zip(bits, vs))
        if w <= C: best = max(best, v)
    return best

def knapsack_01(ws, vs, C):
    dp = [0] * (C + 1)
    for w, v in zip(ws, vs):
        for c in range(C, w - 1, -1):      # 倒序：0/1
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[C]

ws, vs, C = [2, 3, 4, 5], [3, 4, 5, 6], 8
print(brute_knapsack(ws, vs, C), knapsack_01(ws, vs, C))   # 10 10
# 反例实验：把倒序改成正序会发生什么？
def knapsack_01_wrong(ws, vs, C):
    dp = [0] * (C + 1)
    for w, v in zip(ws, vs):
        for c in range(w, C + 1):          # 正序：物品可复用 → 变成完全背包
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[C]
print(knapsack_01_wrong(ws, vs, C))        # 12（四件 w=2,v=3 可复用）
# 预期输出：10 10 12 —— 方向错误使 0/1 背包悄悄变成完全背包
```

## 6.9 常见误区与陷阱

1. **状态定义缺信息**：如"最长无重复子串"只记结尾下标不够，需配哈希表记字符最近位置；"打家劫舍"若状态不含"上一家是否偷"则转移不封闭。状态 = 子问题的**完整**描述。
2. **记忆化的缓存键不可哈希/遗漏参数**：`lru_cache` 的参数必须完整刻画子问题；列表参数需转元组。
3. **0/1 背包滚动数组方向写反**（见案例 3）：结果"看起来更大更漂亮"实则语义已变，且不易察觉——**DP 的 bug 是静默的**，务必对拍。
4. **给贪心找反例无果就当贪心正确**：找不到反例不等于不存在；小规模暴力对拍是最低标准的验证。
5. **编辑距离的代价口径不一致**：WER 的替换代价有 1 与 2 两种业界口径（替换 = 删+插 vs 独立操作），跨论文比较指标时必须核对。
6. **O(mn) 表对长文档直接爆内存**：语音识别整篇转写的 WER 通常逐句计算再累加，而不是算全文编辑距离——注意指标语义与工程实现的边界。

## 6.12 进阶方向

- **区间 DP 与树形 DP**：矩阵链乘、石子合并的 $O(n^3)$ 框架与 Knuth 优化（决策单调性）；语法解析（CYK）与句法树即树形/区间 DP（衔接《自然语言处理》）。
- **DP 优化技术**：斜率优化、Wquadrangle 不等式、SMAWK——把 $O(n^2)$ 转移压到 $O(n\log n)$/$O(n)$；竞赛与编解码器（如 optimal bit allocation）实用。
- **近似与随机化 DP**：FPTAS（背包 $O(n^2/\varepsilon)$ 近似）、随机剪枝的 beam search——大状态空间下的"最优性-时间"拨盘（衔接《模型部署与MLOps》解码延迟控制）。
- **强化学习中的动态规划**：值迭代/策略迭代的收敛性（$\gamma$ 折扣下的压缩映射），把本章递推升级为随机转移 + 不动点迭代（《强化学习》第 4 章的预习路径）。
