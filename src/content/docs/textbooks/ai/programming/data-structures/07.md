## 7.1 近邻搜索：从 $O(nD)$ 到亚线性

**问题设定**：库中有 $n$ 个 $D$ 维向量（图像/文本的 embedding），查询向量 $q$，找距离最近（或相似度最高）的 $k$ 个。暴力法：$n \cdot D$ 次乘加 + Top-K。算一笔账（第 1 章 1.6 节的标准应用）：$n = 10^7$、$D = 768$、FP32，一次查询约 $7.7\times10^9$ FLOPs——即便 GPU 也要毫秒级，CPU 上是秒级；而向量库要求**毫秒内、每秒数千次查询**。必须降阶。

### 7.1.1 空间划分树：KD 树与球树

**KD 树**：BST 思想（第 3 章）推广到 $k$ 维——每层选一个维度、按**中位数**划分（中位数选取即第 5 章快速选择），交替维度递归。查询时先沿树下行到叶，再回溯检查"另一个子树是否可能藏着更近点"（用查询点到划分超平面的距离剪枝）。

- 低维（$D \lesssim 20$）：查询平均 $O(\log n)$，剪枝有效；
- **维数灾难**：$D$ 大时"点到超平面距离"与"点到点距离"同量级，剪枝失效，退化为近暴力（$O(n)$ 且常数更差）。**这是 KD 树在大模型 embedding 时代淡出的原因。**

**球树（ball tree）**：改用嵌套超球（每节点存外接球半径），剪枝判据是"查询点与球心距离 - 球半径 ≥ 当前最优"→ 整棵子树剪掉。对球状簇更鲁棒，但同样受维数灾难限制。sklearn 的 `NearestNeighbors(algorithm='kd_tree'|'ball_tree')` 即工业实现，适合**中小规模、低中维、需要精确解**的场景。

### 7.1.2 局部敏感哈希（LSH）：概率化的"分桶"

**思想**：放弃精确，设计一族哈希函数，使**相似向量以高概率落入同一桶、不相似向量以低概率**，查询只比对同桶（及邻近桶）候选。典型构造（随机超平面 LSH，适配余弦相似度）：每条哈希取随机超平面 $r$，$h(v) = \text{sign}(r \cdot v)$；两向量同位概率 $p = 1 - \theta/\pi$（$\theta$ 为夹角）——**碰撞概率随相似度单调**，这正是"局部敏感"的含义。用 $L$ 张表、每表 $k$ 位哈希，放大区分度：成为候选的概率约 $1 - (1 - p^k)^L$。

- 复杂度：建索引 $O(nLkD)$，查询 $O(L \cdot \text{桶均大小} \cdot D)$，亚线性；
- 代价：**概率性漏检**（假阴性）——这是 ANN 的第一课：用召回率换速度，且交易是显式可调的（$k, L$ 旋钮）。

### 7.1.3 HNSW：分层可导航小世界图（向量数据库的主流索引）

**思想**（跳表思想 + 贪心 + 优先队列，前 6 章的集大成）：

1. 每个点是一个图节点，向若干"近邻"连边（建图时启发式选取，保证图的"可导航性"）；
2. 节点按抛硬币式概率 $\propto e^{-\ell}$ 分配到 $\ell$ 层——顶层稀疏（长程边），底层全量（细粒度边）；
3. **查询**：从顶层入口做贪心下降（每步移向邻点中离 $q$ 最近者，局部最优即停），逐层下沉到底层，底层用带优先队列（第 3 章）的束搜索收集 Top-K。

效果：查询约 $O(\log n)$ 量级、召回率-速度曲线可调（参数 `ef` 即束宽）；内存换索引（边表开销）。Faiss 的 `IndexHNSWFlat`、各类向量数据库（Milvus、Qdrant、pgvector 的 hnsw 索引）均以此为主力索引。**综合项目 1 将实现其简化版并与暴力检索对比召回率/速度。**

| 方法 | 查询复杂度 | 精确/近似 | 适用 |
|---|---|---|---|
| 暴力 + Top-K | $O(nD)$ | 精确 | $n$ 小（$\le 10^5$）或离线批处理 |
| KD 树/球树 | 平均 $O(\log n)$（低维） | 精确 | $D \lesssim 20$，中小 $n$ |
| LSH | 亚线性 | 近似（可漏） | 超大规模、内存敏感、流式插入 |
| HNSW | 约 $O(\log n)$ | 近似（可漏） | 高维 embedding，在线低延迟（主流） |

## 7.2 矩阵稀疏存储与稀疏运算

**动机算账**：大模型词表 Embedding $\mathbf{E} \in \mathbb{R}^{|V|\times d}$，$|V| = 250{,}000$、$d = 4096$、FP16，稠密存储约 2 TB 级？——$2.5\times10^5 \times 4096 \times 2$ B $\approx 2$ GB，尚可；但知识图谱邻接矩阵 $10^8 \times 10^8$ 稠密存储是 $10^{16}$ 字节 = 10 PB，**而其非零元只有约 $10^9$ 个（稀疏度 $10^{-7}$）**。稀疏存储（sparse storage）把空间从 $O(n^2)$ 压到 $O(\text{nnz})$。

**CSR（压缩行存储）**：三个数组 `data`（非零值）、`indices`（列号）、`indptr`（每行在 data 中的起止）——行切片 $O(1)$ 定位、SpMV（稀疏矩阵×稠密向量）$O(\text{nnz})$。**COO**：`(row, col, val)` 三元组流，适合增量构建（第 4 章的边集数组）。GNN 消息传递、推荐系统的交互矩阵、TF-IDF 文本矩阵全部跑在这些格式上（`scipy.sparse`）。

```python
"""稀疏矩阵：从零实现 CSR 的 SpMV，再用 scipy 验证。"""
import numpy as np

def csr_spmv(data, indices, indptr, x):
    """y = A @ x，A 以 CSR 给出。O(nnz)。"""
    y = np.zeros(len(indptr) - 1)
    for i in range(len(indptr) - 1):
        s = data[indptr[i]:indptr[i+1]] @ x[indices[indptr[i]:indptr[i+1]]]
        y[i] = s
    return y

# A = [[1,0,2],[0,0,0],[3,0,4]]  nnz = 4
data   = np.array([1.0, 2.0, 3.0, 4.0])
indices = np.array([0,  2,  0,  2])
indptr = np.array([0, 2, 2, 4])
x = np.array([1.0, 1.0, 1.0])
print(csr_spmv(data, indices, indptr, x))    # [3. 0. 7.]

from scipy.sparse import csr_matrix
A = csr_matrix((data, indices, indptr), shape=(3, 3))
print(A @ x)                                  # [3. 0. 7.]（一致）
print(f"稠密 9 元素 → 稀疏 {A.nnz} 非零")
```

**工程要点**：稀疏不是"省内存的魔法"——SpMV 是**内存带宽受限**操作（每非零元只做 2 FLOPs 却要读 ~12 字节），性能取决于 `data/indices` 的缓存命中与格式选择（CSR 行遍历、CSC 列遍历、块稀疏 BSR 对 GPU 更友好）。第 4 章图算法的邻接结构在 `scipy.sparse` 里就是 CSR——图与矩阵在此汇合（邻接矩阵 = 图）。

## 7.3 流式算法：数据大到来不及看第二遍

数据工程（《数据工程》主题）的常态：数据流过一次、内存装不下全集、只要近似统计。流式算法（streaming algorithms）给出**次线性空间**的解。

### 7.3.1 Count-Min Sketch：近似频次计数

**问题**：流中 $10^9$ 个 key，要回答"key $x$ 出现多少次"（Top-K 词、热点 URL、重尾 token 统计）。精确哈希计数需 $O(\text{distinct keys})$ 内存。

**结构**：$d$ 行、每行 $w$ 列的计数矩阵 + 每行一个独立哈希函数。插入 $x$：每行把 $h_r(x)$ 列计数 +1。查询 $x$：取各行对应列的**最小值**（过估计因最小化而被压制）。空间 $O(dw)$、更新/查询 $O(d)$。

**误差界**：设总流量 $N$、行数 $d$、列数 $w$，单 key 计数满足 $\hat{c} \le c + \varepsilon N$（$\varepsilon = e/w$）至少以概率 $1 - \delta$ 成立（$d = \ln(1/\delta)$）。**可证明的过估计、永不高估为负**——与布隆过滤器同属"单侧误差"家族。

```python
"""Count-Min Sketch：实现与误差实验。"""
import numpy as np

class CountMinSketch:
    def __init__(self, w=2048, d=5, seed=0):
        rng = np.random.default_rng(seed)
        self.w, self.d = w, d
        self.table = np.zeros((d, w), dtype=np.int64)
        self.seeds = rng.integers(0, 2**31, size=d)

    def _cols(self, x):
        return [hash((s, x)) % self.w for s in self.seeds]

    def add(self, x, c=1):
        for r, j in enumerate(self._cols(x)):
            self.table[r, j] += c

    def count(self, x):
        return int(min(self.table[r, j] for r, j in enumerate(self._cols(x))))

cms = CountMinSketch()
truth = {}
rng = np.random.default_rng(1)
keys = [f"k{i}" for i in range(1000)]
for _ in range(100_000):                    # 重尾：少数 key 极热
    k = keys[int(rng.paretovariate(1.5) * 100) % 1000]
    cms.add(k); truth[k] = truth.get(k, 0) + 1

errs = [(cms.count(k) - truth[k]) / sum(truth.values()) for k in keys]
print("真实 Top-1 频次:", max(truth.values()))
print("CMS 对 Top-1 的估计:", cms.count(max(truth, key=truth.get)))
print("平均相对过估计:", f"{np.mean(errs):.2e}")
# 预期输出（示例）：Top-1 真实约 25000+，CMS 估计略高（过估计），平均过估计 < 1e-3
# 结论：热 key 估计很准（分母 N 大、噪声占比小），冷 key 相对误差大 —— 与误差界一致
```

### 7.3.2 蓄水池采样：未知总量的等概率抽样

**问题**：从长度未知的流中等概率抽 $k$ 个样本（DataLoader 的数据配比、A/B 流量采样、语料子集构建）。

**算法（Algorithm R）**：前 $k$ 个直接入池；第 $i$（$i>k$）个以概率 $k/i$ 替换池中随机一个。

**证明（等概率）**：第 $i$ 个元素最终在池中的概率 = 它入池后未被替换的概率。第 $i+1, \dots, n$ 个元素替换它的概率共为 $\prod_{t=i+1}^{n}\left(1 - \frac{k \cdot \frac1t}{k}\right) = \prod_{t=i+1}^n \frac{t-1}{t} = \frac{i}{n}$，故在池概率 $= \frac{k}{i}\cdot\frac{i}{n} = \frac{k}{n}$，与 $i$ 无关。$\blacksquare$ 每个元素等概率 $k/n$，$O(n)$ 时间、$O(k)$ 空间、单遍。

## 7.4 随机化算法：蒙特卡洛与布隆过滤器

第 5 章快排的随机基准已经展示过随机化的第一种用法——**拉斯维加斯式**（结果总对、时间随机）；本节是**蒙特卡洛式**（时间固定、结果以可控概率出错）。

**蒙特卡洛方法**：用随机采样估计期望。估计 $\pi$：向单位方形撒 $N$ 个均匀点，落在四分之一圆内的比例 $\approx \pi/4$，误差 $O(1/\sqrt N)$（中心极限定理，详见《概率论与数理统计》）。这是《实验设计与评估》中"多次重复取均值与置信区间"的算法版。

**布隆过滤器（Bloom filter）**：判断"元素**一定不在**集合中 / **可能**在"的位图结构。$m$ 位位数组、$k$ 个哈希函数：插入置位 $k$ 位；查询查 $k$ 位全 1 则"可能在"（可能误报）、任一为 0 则"**一定不在**"（无误报）。

**假阳性率**：$m$ 位、$n$ 个元素后任一位仍为 0 的概率 $\approx e^{-kn/m}$，故

$$p_{\text{fp}} \approx (1 - e^{-kn/m})^k \approx 0.6185^{m/n} \quad (k = \tfrac{m}{n}\ln 2 \text{ 时最优}).$$

**工程地位**：爬虫 URL 去重、缓存穿透防护（查询不存在 key 前先过过滤器，避免打穿数据库）、SSTable/LSM 存储引擎的"块内可能含此 key"判断——**第 2 章哈希表的"省内存版"**，代价是假阳性与不支持删除（计数布隆可删但费空间）。

```python
"""布隆过滤器：实现 + 假阳性率实测 vs 理论。"""
import math, hashlib

class BloomFilter:
    def __init__(self, m=8192, k=3):
        self.m, self.k = m, k
        self.bits = bytearray(m // 8 + 1)

    def _positions(self, x):
        h = hashlib.sha256(str(x).encode()).digest()
        return [int.from_bytes(h[i*4:(i+1)*4], "big") % self.m for i in range(self.k)]

    def add(self, x):
        for p in self._positions(x):
            self.bits[p // 8] |= 1 << (p % 8)

    def __contains__(self, x):
        return all(self.bits[p // 8] >> (p % 8) & 1 for p in self._positions(x))

bf = BloomFilter()
import random
added = {f"url{i}" for i in range(1000)}
for u in added: bf.add(u)
fp = sum(1 for i in range(10000) if f"no{i}" in bf) / 10000
m_over_n = bf.m / len(added)
k_opt = m_over_n * math.log(2)
theo = (1 - math.exp(-len(added) * bf.k / bf.m)) ** bf.k
print(f"实测假阳性率: {fp:.4f}  理论: {theo:.4f}")
# 预期输出：实测约 0.01~0.03，理论约 0.021 —— 同量级即验证成功
```

## 7.5 关键公式速查

| 结论 | 适用条件 |
|---|---|
| 暴力近邻 $O(nD)$；KD 树查询平均 $O(\log n)$ | KD 树仅低维（$D\lesssim20$）有效 |
| 维数灾难：$D$ 大时空间剪枝失效 | 高维一律转 ANN |
| LSH 候选概率 $1-(1-p^k)^L$，$p=1-\theta/\pi$ | 随机超平面 LSH，余弦相似度 |
| HNSW：分层图 + 贪心下行 + 束搜索 Top-K | 近似，召回-速度由 ef 调 |
| CSR SpMV $O(\text{nnz})$，空间 $O(\text{nnz}+n)$ | 稀疏度高的矩阵 |
| CMS：$\hat c \le c + \varepsilon N$ 概率 $\ge 1-\delta$，$\varepsilon=e/w,\ d=\ln(1/\delta)$ | 只过估计、不低估计 |
| 蓄水池：每元素入选概率 $k/n$ | 单遍、$O(k)$ 空间、未知 $n$ |
| 布隆假阳性 $(1-e^{-kn/m})^k \approx 0.6185^{m/n}$ | 最优 $k=\frac{m}{n}\ln2$ |
| 蒙特卡洛误差 $O(1/\sqrt N)$ | 独立采样，方差有界 |

## 7.6 示例与案例

### 案例 1（手算）：KD 树的一次查询与剪枝

二维点集 $\{(2,3), (5,4), (9,6), (4,7), (8,1), (7,2)\}$。建树：根取 $x$ 维中位数——排序 $x$ 值 $2,4,5,7,8,9$，中位取 $(7,2)$（或 $(5,4)$，取法影响形状不影响的正确性）。左子树含 $x \le 7$ 的点、右含其余；下一层换 $y$ 维交替。查询 $q=(9,2)$：下行到叶 $(8,1)$，距离 $\sqrt2$；回溯：兄弟子树最小界（到划分线 $x=7$ 的距离 $2$）$> \sqrt2$，剪枝成立，不用访问；最终最近点 $(8,1)$。**每一次"剪枝成立"都省掉一个子树的全部比较**——低维时这类剪枝频繁发生，高维时几乎从不发生，这就是 7.1.1 节维数灾难的具体画面。

### 案例 2（代码）：蒙特卡洛验证蓄水池采样的等概率性

```python
"""实现蓄水池采样，并用蒙特卡洛重复实验验证每个元素入选概率相等。
   两个算法一章的主题在一个实验里相遇。"""
import random
from collections import Counter

def reservoir_sample(stream, k, rng=None):
    rng = rng or random
    pool = []
    for i, x in enumerate(stream):
        if i < k:
            pool.append(x)
        else:
            j = rng.randint(0, i)      # [0, i] 均匀
            if j < k:
                pool[j] = x
    return pool

rng = random.Random(42)
N, k, trials = 10, 3, 200_000
counts = Counter()
for _ in range(trials):
    counts.update(reservoir_sample(range(N), k, rng))
freq = [counts[i] / trials for i in range(N)]
print([f"{f:.3f}" for f in freq])
# 预期输出：10 个频率都约 0.300（理论值 k/N = 0.3，波动 ~1e-3）
# 常见错误实现（用 randrange(k) 替换）会得到前几个元素频率偏高——试改后观察。
```

### 案例 3（代码）：Mini-ANN——网格哈希近似近邻检索（LSH 思想的最小实现）

```python
"""用随机超平面 LSH 做近似近邻：与暴力法对比召回率与速度。
   综合项目 1（HNSW 简化版）的前置练习。"""
import time
import numpy as np

rng = np.random.default_rng(0)
n, D, Q, k = 20_000, 32, 100, 10
X = rng.normal(size=(n, D)); X /= np.linalg.norm(X, axis=1, keepdims=True)
Qs = rng.normal(size=(Q, D)); Qs /= np.linalg.norm(Qs, axis=1, keepdims=True)

def brute_topk(X, q, k):
    sims = X @ q
    return np.argpartition(-sims, k)[:k]      # 第 5 章快速选择（库版）

t0 = time.perf_counter()
truth = [set(brute_topk(X, q, k).tolist()) for q in Qs]   # 金标准
t_brute = time.perf_counter() - t0

L, kbits = 8, 12                                  # 8 张表、12 位哈希
planes = rng.normal(size=(L, kbits, D))
tables = []
for l in range(L):
    codes = (X @ planes[l].T) > 0                 # (n, kbits) 布尔码
    table = {}
    for idx in range(n):
        table.setdefault(codes[idx].tobytes(), []).append(idx)
    tables.append(table)

t0 = time.perf_counter()
hits = 0
for qi, q in enumerate(Qs):
    cand = set()
    for l in range(L):
        code = ((q @ planes[l].T) > 0).tobytes()  # 只查同码桶
        cand.update(tables[l].get(code, []))
    if cand:
        cand_list = list(cand)
        sims = X[cand_list] @ q                   # 候选内精确重排
        top = set(np.array(cand_list)[np.argsort(-sims)[:k]].tolist())
        hits += len(top & truth[qi])
recall = hits / (Q * k)
print(f"暴力: {t_brute:.3f}s  LSH 查询: {time.perf_counter()-t0:.3f}s")
print(f"召回率@{k}: {recall:.2f}")
# 预期输出（示例）：LSH 快 3~10 倍，召回率 0.4~0.8 —— 调大 L / 调小 kbits 可升召回
```

（注：本案例刻意保持代码直白；生产实现请用 Faiss `IndexLSH`/`IndexHNSWFlat`——机制在自己手里跑通一遍，调库时才有判断力。）

## 7.7 常见误区与陷阱

1. **高维数据上用 KD 树**：$D > 20$ 后剪枝近乎失效，比暴力还慢；先问维度再选结构。
2. **把 ANN 的召回率当 100%**：RAG 系统的"漏检"首先排查索引参数（`ef`/`nprobe`）而非模型；离线评估必须用暴力法做金标准（案例 3 的做法）。
3. **稀疏矩阵当"省内存玩具"**：混用 CSR/CSC 导致隐式转换（scipy 会警告 `SparseEfficiencyWarning`）、用 Python 循环逐元素访问稀疏矩阵——两者都可能比稠密慢。
4. **CMS 当精确计数用**：它只会**多报**不会少报，冷 key 误差相对很大；Top-K 场景要配合"重击者（heavy hitter）先粗筛"的两级方案。
5. **布隆过滤器的假阳性率没算账就上**：$m/n$ 太小（如 $<8$）时假阳性率不可接受；扩容需全量重建（不支持缩容）。
6. **把随机化算法的误差当 bug**：蒙特卡洛 $O(1/\sqrt N)$ 意味着精度翻倍要 4 倍采样；写报告时给出置信区间而不是单次结果（《实验设计与评估》的标准）。

## 7.10 进阶方向

- **图 ANN 与乘积量化（PQ）**：IVF-PQ 把向量压缩 8–32 倍再做 ADC 距离计算，Faiss 十亿级索引的支柱；从 HNSW 出发补"量化误差与召回"的权衡分析。
- **流式图算法与时序概要**：动态图上的连通性/三角计数（HyperLogLog 计基数、GSketch），衔接《数据工程》实时特征。
- **HyperLogLog 与分布估计**：$O(\log\log n)$ 空间估计基数，是 CMS 的姊妹篇；误差 $\pm 1.04/\sqrt m$ 可推导。
- **学习型索引/学习型 ANN**：用模型预测向量分位（衔接《机器学习》），如 ScaNN 的各向异性量化；从"打分函数即学习目标"切入。
