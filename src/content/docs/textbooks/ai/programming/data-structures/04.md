# 第 4 章 图算法——关系与结构

> **本章定位**：图是"任意二元关系"的通用语言。前几章的结构各司其职，图把它们连成网络：DFS/BFS 是树遍历的推广，Dijkstra 消费第 3 章的优先队列，并查集与拓扑排序将在本章直接服务于深度学习的计算图与知识图谱。前置要求：第 2 章邻接表、第 3 章堆。本章是《知识表示与推理》的直接地基，《深度学习》的自动微分一节会回引本章 4.4 节。

## 4.1 图的表示：先算账再选结构

**定义（图）**：$G = (V, E)$，$|V| = n$ 个节点、$|E| = m$ 条边。有向/无向、带权/无权、稀疏（$m \ll n^2$）/稠密（$m = \Theta(n^2)$）。AI 数据中绝大多数真实图是**稀疏**的（社交网络平均度几十、知识图谱平均出度个位数），这一事实决定了下表的选择。

| 表示法 | 空间 | 查边 $(u,v)$ | 枚举 $u$ 的邻居 | 适用 |
|---|---|---|---|---|
| 邻接矩阵（`numpy` 数组） | $\Theta(n^2)$ | $O(1)$ | $O(n)$ | 稠密图、矩阵幂/谱方法 |
| 邻接表（`list[list]` 或 `dict`） | $\Theta(n+m)$ | $O(\deg u)$ | $O(\deg u)$ | 稀疏图、BFS/DFS |
| 边集数组 | $\Theta(m)$ | $O(m)$ | $O(m)$ | Kruskal、流式读边 |

```python
"""三种表示法的最小示例。"""
import numpy as np

n = 4
edges = [(0, 1, 2.0), (0, 2, 5.0), (1, 2, 1.0), (2, 3, 3.0)]  # (u, v, w)

# 1) 邻接矩阵（带权有向）
M = np.zeros((n, n))
for u, v, w in edges:
    M[u, v] = w
print(M[0, 2])                        # 5.0

# 2) 邻接表（dict + list，第 2 章哈希表的直接应用）
adj = {u: [] for u in range(n)}
for u, v, w in edges:
    adj[u].append((v, w))
print(adj[0])                         # [(1, 2.0), (2, 5.0)]

# 3) 边集
print(sorted(edges, key=lambda e: e[2]))   # 按权排序，Kruskal 的准备动作
```

一个 AI 语境的对照：**注意力矩阵**就是稠密图——$n$ 个 token 的全连接图，权重为相似度；而**知识图谱**是稀疏图——百亿三元组、平均度个位数。前者用矩阵乘（GPU 擅长），后者用邻接表/稀疏矩阵（第 7 章）。"图算法选型"的第一问永远是：这张图稠吗？

## 4.2 BFS 与 DFS：两种遍历，两种哲学

**BFS（广度优先，队列）**：从源点出发按"距离层数"逐层扩散。**性质 4.1**：在无权图中，BFS 首次到达某节点的层数即最短跳数——因为队列保证先处理完距离 $d$ 的全部节点才处理 $d+1$。复杂度 $O(n + m)$（每节点入队一次、每边看一次）。

**DFS（深度优先，栈/递归）**：一条路走到黑，回溯换路。复杂度同为 $O(n + m)$。DFS 擅长"结构性"问题：连通分量、环检测、拓扑序、割点桥。递归版注意第 3 章提到的栈深限制，深图用显式栈。

```python
from collections import deque

def bfs_dist(adj, src):
    """无权图单源最短跳数。O(n+m)。"""
    dist = {src: 0}
    q = deque([src])
    while q:
        u = q.popleft()
        for v, _ in adj[u]:
            if v not in dist:          # 首次到达 = 最短
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

def dfs_components(adj, nodes):
    """无向图连通分量个数与划分。O(n+m)。"""
    seen, comps = set(), []
    for s in nodes:
        if s in seen: continue
        comp, stack = [], [s]          # 显式栈，防递归爆栈
        seen.add(s)
        while stack:
            u = stack.pop()
            comp.append(u)
            for v, _ in adj[u]:
                if v not in seen:
                    seen.add(v)
                    stack.append(v)
        comps.append(comp)
    return comps

adj = {0: [(1, 1.0), (2, 1.0)], 1: [(3, 1.0)], 2: [(3, 1.0)],
       3: [], 4: [(5, 1.0)], 5: []}
print(bfs_dist(adj, 0))        # {0: 0, 1: 1, 2: 1, 3: 2}
print(dfs_components(adj, range(6)))
# [[0, 2, 3, 1], [4, 5]] —— 两个连通分量（栈序导致顺序不定）
```

**AI 语境**：知识图谱的多跳查询（"A 的合作者的导师是谁"= 2 跳 BFS）；GNN 的邻居采样是"受限的随机 BFS"；引用网络、分子图（CV/NLP 之外的图神经网络输入）的预处理都是本章遍历的变体。

## 4.3 拓扑排序：依赖即 DAG

**定义**：DAG（有向无环图）的拓扑序是一个线性排列，使每条边 $(u,v)$ 都有 $u$ 排在 $v$ 前。**定理 4.2**：图有拓扑序 $\iff$ 无有向环。

**Kahn 算法（BFS 式）**：反复摘除入度为 0 的节点。$O(n+m)$。若摘不完（剩余节点入度全 > 0），说明有环。

```python
from collections import deque

def topo_sort(adj, nodes):
    indeg = {u: 0 for u in nodes}
    for u in nodes:
        for v, _ in adj[u]:
            indeg[v] += 1
    q = deque(sorted(u for u in nodes if indeg[u] == 0))  # 稳定：可加优先队列
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v, _ in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    if len(order) != len(nodes):
        raise ValueError("graph has a cycle")
    return order

adj = {0: [(2, 1)], 1: [(2, 1)], 2: [(3, 1)], 3: []}
print(topo_sort(adj, range(4)))     # [0, 1, 2, 3]（另一合法解 [1,0,2,3]）
```

**核心 AI 案例：计算图与反向传播。** 《深度学习》开篇就会讲：框架把你的模型代码记录为一张计算图——前向求值必须按拓扑序（先算叶子 $x, w$，再算 $z = wx$，再算损失）；反向传播求梯度时，链式法则要求"梯度先于依赖它的节点的下游到达"，即按**逆拓扑序**遍历：

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial z}\cdot\frac{\partial z}{\partial w} \quad \text{要求 } \partial L/\partial z \text{ 已算好。}$$

PyTorch 的动态图在每次 forward 时按拓扑序构建节点、backward 时逆序执行——你现在可以精确说出框架"自动"背后在做什么：**一次拓扑排序 + 一次逆序遍历，每边一次乘加，总代价 $O(\text{节点数} + \text{边数})$，与前向同阶。** 这也解释了"反向传播让训练只比推理贵约 2–3 倍"的复杂度根源。

## 4.4 最短路径：Dijkstra 与 Bellman-Ford

**单源最短路（SSSP）**：给定源 $s$，求到所有节点的最短带权距离。设 $d[v]$ 为当前估计。

**Dijkstra（贪心）**：维护优先队列，每次取出 $d$ 最小的未定节点 $u$ 并"定型"（finalized），松弛其出边 $d[v] \leftarrow \min(d[v], d[u] + w)$。

**定理 4.3（Dijkstra 正确性，非负权）**：只要所有 $w \ge 0$，则每次取出的最小 $d[u]$ 已是最短距离。证明要点：若存在更短路径 $P$ 到 $u$，$P$ 必经过某个"未定型"节点 $y$；而 $P$ 的前缀到 $y$ 的长度 $\ge d[y] \ge d[u]$（堆中 $y$ 尚未弹出），且 $P$ 后段非负，故到 $u$ 的路径长 $\ge d[u]$，与"更短"矛盾。$\blacksquare$ **注意 $w \ge 0$ 用在哪里：贪心定型依赖于"往后走不会更便宜"。** 负权边会破坏它，此时用 Bellman-Ford。

**复杂度**：二叉堆 + 懒惰删除：$O((n + m)\log m)$（堆内至多 $m$ 项）。稠密图（$m \approx n^2$）可用朴素 $O(n^2)$ 数组版（每次线性找最小）。

**Bellman-Ford（动态规划视角）**：定义 $d_k[v]$ = 至多 $k$ 条边的最短路，递推 $d_{k+1}[v] = \min_u d_k[u] + w(u,v)$，做 $n-1$ 轮全边松弛即收敛，$O(nm)$；第 $n$ 轮若仍能松弛则存在负环。**它证明了"无负环则最短路至多 $n-1$ 条边"**——这个结构性事实本身比算法更重要（第 6 章 DP 与《强化学习》的值迭代同源）。

```python
import heapq

def dijkstra(adj, src):
    """二叉堆 + 懒惰删除。O((n+m) log m)。"""
    dist = {src: 0.0}
    pq = [(0.0, src)]                     # (距离, 节点)
    done = set()
    while pq:
        d, u = heapq.heappop(pq)
        if u in done:                     # 过期条目：跳过
            continue
        done.add(u)
        for v, w in adj[u]:
            nd = d + w
            if nd < dist.get(v, float("inf")):
                dist[v] = nd
                heapq.heappush(pq, (nd, v))   # 旧条目留在堆里自然作废
    return dist

def bellman_ford(edges, n, src):
    """edges: (u,v,w)。返回 dist；检测负环。O(nm)。"""
    dist = [float("inf")] * n
    dist[src] = 0.0
    for _ in range(n - 1):
        changed = False
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                changed = True
        if not changed:
            break
    for u, v, w in edges:                 # 第 n 轮
        if dist[u] + w < dist[v]:
            raise ValueError("negative cycle reachable")
    return dist

edges = [(0, 1, 2.0), (0, 2, 5.0), (1, 2, 1.0), (2, 3, 3.0), (1, 3, 7.0)]
adj = {u: [] for u in range(4)}
for u, v, w in edges: adj[u].append((v, w))
print(dijkstra(adj, 0))          # {0: 0.0, 1: 2.0, 2: 3.0, 3: 6.0}
print(bellman_ford(edges, 4, 0)) # [0.0, 2.0, 3.0, 6.0]
```

手算验证 `dijkstra`：到 1 最短 $0+2=2$；到 2 取 $\min(5,\ 2+1)=3$；到 3 取 $\min(2+7,\ 3+3)=6$。与输出一致。

**AI 语境**：A* 是 Dijkstra 加启发函数（《强化学习》/路径规划）；RAG 系统中"知识图谱子图检索 + 路径打分"用最短路/最短路变体（如两跳内最相关实体路径）；序列标注中的 Viterbi（第 6 章）就是 DAG 上的最短路。

## 4.5 并查集：连通性的增量维护

**并查集（Union-Find / DSU）**：维护若干不相交集合，支持 `find(x)`（找代表元）与 `union(x,y)`（合并）。实现：父指针森林 + 两大优化——**路径压缩**（find 时把沿途节点直接挂到根）与**按秩/按大小合并**（小树挂大树）。

**定理 4.4（Tarjan）**：同时使用两大优化，$n$ 次 find/union 的总代价为 $O(n\,\alpha(n))$，$\alpha$ 为反阿克曼函数，实践中 $\le 4$——**视为常数**。这是"摊还 + 非平凡势能分析"的著名案例（证明超出本章，见 CLRS 第 21 章）。

```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        root = x
        while self.parent[root] != root:
            root = self.parent[root]
        while self.parent[x] != root:       # 路径压缩（两遍法，迭代无递归）
            self.parent[x], x = root, self.parent[x]
        return root

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry: return False           # 已连通
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx                # 小挂大
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
        return True

d = DSU(6)
for a, b in [(0,1), (1,2), (3,4)]:
    d.union(a, b)
print(d.find(0) == d.find(2), d.find(0) == d.find(3))   # True False
d.union(2, 3)
print(d.find(0) == d.find(4))                            # True
```

## 4.6 最小生成树：Kruskal 与 Prim

**定义**：连通无向带权图中，连接全部 $n$ 个节点、总权最小的 $n-1$ 条边的树（MST）。

**Kruskal（边贪心 + 并查集）**：边按权排序，逐条尝试加入"不构成环"的边（用 DSU 判连通）。$O(m\log m)$（排序主导）。**正确性 = 切割性质**：对任一把点集分成两半的割，横跨该割的最小权边必在某棵 MST 中（交换论证，第 6 章将系统学习这一证明技术）。

**Prim（点贪心 + 堆）**：从任一点出发，每步把"连接树内外的最小权横跨边"的另一端拉进树。用惰性堆实现 $O(m \log m)$。**正确性 = 同一切割性质**（每步的横跨最小边安全）。

```python
def kruskal(n, edges):
    """edges: (w, u, v)。返回 MST 权与边集。O(m log m)。"""
    dsu, total, picked = DSU(n), 0.0, []
    for w, u, v in sorted(edges):
        if dsu.union(u, v):
            total += w
            picked.append((u, v, w))
    return total, picked

mst_edges = [(2.0, 0, 1), (1.0, 1, 2), (5.0, 0, 2), (3.0, 2, 3)]
total, picked = kruskal(4, mst_edges)
print(total, picked)
# 6.0 [(1.0, 1, 2), (2.0, 0, 1), (3.0, 2, 3)]
```

**AI 语境（图聚类）**：单链聚类（single-linkage clustering）= 逐步做 Kruskal、在总权达到阈值（或剩 $k$ 棵树）时停止——聚成 $k$ 个簇即保留 MST 中最大的 $k-1$ 条边并断开。综合项目 3 将让你完整实现它并与 K-Means（见《机器学习》）对比"簇形状"的差异（单链可找任意形状但怕链式误差）。

## 4.7 关键公式速查

| 结论 | 适用条件 |
|---|---|
| 邻接矩阵 $\Theta(n^2)$ 空间；邻接表 $\Theta(n+m)$ | 稠密/稀疏选型 |
| BFS/DFS 总代价 $O(n+m)$ | 邻接表 |
| BFS 首达距离 = 无权最短路 | FIFO 保证按层处理 |
| 拓扑序存在 $\iff$ DAG；Kahn/DFS 均 $O(n+m)$ | 有向图 |
| 反向传播 = 前向拓扑序 + 梯度逆拓扑序，$O(V+E)$ | 计算图为 DAG |
| Dijkstra $O((n+m)\log m)$，贪心定型正确 | **全部边权非负** |
| Bellman-Ford $O(nm)$；$n$ 轮仍可松弛 $\Rightarrow$ 负环 | 可有负权，不可有可达负环 |
| 最短路至多 $n-1$ 条边 | 无可达负环 |
| DSU + 路径压缩 + 按秩：$O(n\,\alpha(n))$ 摊还 | $\alpha \le 4$，视为常数 |
| Kruskal/Prim $O(m\log m)$；切割性质保证贪心安全 | 连通无向带权图 |

### 案例 1（手算）：Dijkstra 的完整执行轨迹

图：边 $(s,a,2),(s,b,5),(a,b,1),(a,c,6),(b,c,2)$。执行表（每行 = 一次定型）：

| 轮 | 弹出 | 定型 $d$ | 松弛后堆内容 |
|---|---|---|---|
| 1 | $s$ | $d[s]=0$ | $(2,a),(5,b)$ |
| 2 | $a$ | $d[a]=2$ | $(3,b)$ 新、$(5,b)$ 旧、$(8,c)$ |
| 3 | $b$（3） | $d[b]=3$ | $(5,c)$ 新、$(5,b)$ 旧、$(8,c)$ |

注意第 3 轮堆里有两个 $b$（3 和 5）——**懒惰删除**：弹出 $(3,b)$ 时 $(5,b)$ 作废。这正是第 3 章"`heapq` 无 decrease-key 怎么办"的标准答案。

### 案例 2（代码）：计算图的前向拓扑求值与反向梯度

```python
"""迷你自动微分：拓扑排序前向求值 + 逆拓扑序反向传播。
   《深度学习》"反向传播"一节的机制层预演（那里会给出更完整的推导）。"""
from collections import defaultdict, deque

class Graph:
    def __init__(self):
        self.nodes = {}                    # name -> (op, inputs, grad_fn)
        self.adj = defaultdict(list)       # 依赖图（DAG）

    def add(self, name, op, inputs, grad_fn):
        self.nodes[name] = (op, inputs, grad_fn)
        for inp in inputs:
            self.adj[inp].append(name)

    def topo(self, outputs):
        indeg = {u: 0 for u in self.nodes}
        for u, vs in self.adj.items():
            for v in vs:
                indeg[v] += 1
        q = deque(u for u in self.nodes if indeg[u] == 0)
        order = []
        while q:
            u = q.popleft()
            order.append(u)
            for v in self.adj[u]:
                indeg[v] -= 1
                if indeg[v] == 0: q.append(v)
        return order

    def forward(self, leaf_values, outputs):
        val = dict(leaf_values)
        for name in self.topo(outputs):        # 前向：拓扑序
            op, inputs, _ = self.nodes[name]
            val[name] = op(*[val[i] for i in inputs])
        return val

    def backward(self, leaf_values, output):
        val = self.forward(leaf_values, [output])
        grads = {output: 1.0}                   # dL/dL = 1
        for name in reversed(self.topo([output])):   # 反向：逆拓扑序
            if name not in grads: continue
            op, inputs, grad_fn = self.nodes[name]
            for i, g in zip(inputs, grad_fn(grads[name], val)):
                grads[i] = grads.get(i, 0.0) + g    # 多路径梯度累加
        return grads

g = Graph()
g.add("z",  lambda x, w: x * w, ["x", "w"],
      lambda gz, val: [gz * val["w"], gz * val["x"]])   # dz/dx=w, dz/dw=x
g.add("L",  lambda z: (z - 3) ** 2, ["z"],
      lambda gL, val: [2 * (val["z"] - 3) * gL])        # dL/dz
leaf = {"x": 2.0, "w": 1.0}
val = g.forward(leaf, ["L"])
print("L =", val["L"])                                  # L = (2*1-3)^2 = 1.0
grads = g.backward(leaf, "L")
print("dL/dx =", grads["x"], "dL/dw =", grads["w"])
# z = 2, dL/dz = 2*(2-3) = -2；dL/dx = -2*1 = -2；dL/dw = -2*2 = -4
# 预期输出：dL/dx = -2.0 dL/dw = -4.0（与手算链式法则一致）
```

### 案例 3（代码）：知识图谱上的两跳查询

```python
"""知识图谱：三元组 (头实体, 关系, 尾实体)。
   邻接表建图 + BFS 两跳查询（衔接《知识表示与推理》多跳推理）。"""
from collections import defaultdict, deque

triples = [
    ("姚明", "出生于", "上海"), ("上海", "属于", "中国"),
    ("姚明", "效力过", "火箭队"), ("火箭队", "位于", "休斯顿"),
    ("休斯顿", "属于", "美国"), ("中国", "首都", "北京"),
]
kg = defaultdict(list)
for h, r, t in triples:
    kg[h].append((r, t))

def two_hop(kg, entity):
    """返回 entity 两跳内可达的 (路径, 终点)。O(出度^2)。"""
    out, q = [], deque([(entity, [])])
    seen = {entity}
    for _ in range(2):                     # 限深 BFS
        nxt = deque()
        while q:
            cur, path = q.popleft()
            for r, t in kg[cur]:
                if t not in seen:
                    seen.add(t)
                    out.append((path + [r], t))
                    nxt.append((t, path + [r]))
        q = nxt
    return out

for path, dst in two_hop(kg, "姚明"):
    print(" -".join(path), "->", dst)
# 预期输出（顺序随遍历序）：
#  -出生于 -> 上海
#  -效力过 -> 火箭队
#  -出生于-属于 -> 中国
#  -效力过-位于 -> 休斯顿
```

## 4.9 常见误区与陷阱

1. **在可能有负权边时用 Dijkstra**：结果可能既错又"看起来合理"。判定规则：边权来自距离/时间/损失（非负）才敢用；有负权（如收益、对数概率）用 Bellman-Ford 或 Johnson。
2. **把无向图的 DFS 树上"回到父亲"当环**：判断环必须区分"回父边"（合法）与"回真祖先"（成环）。用"邻接计数"或给 DFS 记录 parent。
3. **用邻接矩阵处理大稀疏图**：$n=10^7$ 的图矩阵占 $10^{14}$ 单元，内存瞬间爆炸。凡是"节点多、边少"的图一律邻接表（或 `scipy.sparse`，第 7 章）。
4. **Kahn 算法用普通队列还以为是"唯一序"**：拓扑序一般不唯一；需要确定性输出时用编号最小的节点优先（堆替代队列）。
5. **并查集漏掉按秩合并**：只做路径压缩仍可接受，但只做按秩不压缩、或都不做，最坏会退化；两者结合才是 $O(\alpha(n))$。
6. **图节点用不可哈希对象作 dict 键**：邻接表 `dict[node]` 要求节点可哈希且稳定——第 2 章的可变键陷阱在图上的再现。

## 4.12 进阶方向

- **最短路工程化**：Contraction Hierarchies 与 A* + Landmarks，把大陆级路网查询压到毫秒级；从本章 Dijkstra 出发补"预处理 + 捷径收缩"思想即可入门。
- **最大流与匹配**：Ford–Fulkerson/ Dinic，任务分配、二分图匹配；需要补残余网络与增广路概念（衔接《知识表示与推理》的逻辑推理应用）。
- **图挖掘与 GNN 系统层**：动态图（时序知识图谱）的增量遍历、图划分（METIS）与分布式图存储；从邻接表出发补"图划分最小化切边"目标。
- **谱图理论**：拉普拉斯矩阵、随机游走与 PageRank；需要《线性代数》特征分解与《概率论》马尔可夫链（谱聚类、GNN 的理论底座）。
