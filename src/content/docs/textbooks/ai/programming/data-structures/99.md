# 综合项目——把算法变成可验证的工程作品

> **本章定位**：本课程的收官实践章。三个项目分别贯穿第 7/6/4 章（并回引第 1–5 章的全部工具），每个项目都要求"从零实现 + 对照金标准 + 定量评估"——这正是《实验设计与评估》的方法论预演。建议以两周一个项目的节奏完成，可单人或 2 人组队。

## 9.0 本章学习目标

完成本章后，你能够：

1. 独立实现一个近似近邻索引（HNSW 简化版），并用召回率/查询延迟曲线做出**量化的算法权衡报告**。
2. 把编辑距离从 DP 表扩展为生产可用的拼写纠错器（Trie 剪枝 + 词频先验），并用真实错误样本评估。
3. 组合并查集、最小生成树与图遍历完成图聚类实验，解释其与 K-Means 的结果差异。
4. 为自己的实现写出复杂度声明与对拍/基准测试脚本——"声明复杂度、证明它、测出它"的闭环。

所有项目只依赖 Python 3.10+ 标准库与 numpy（可选 matplotlib、scipy），无需 GPU。

## 9.1 项目一：HNSW 简化版 vs 暴力检索（对应第 7 章，回引第 1/3/5 章）

### 9.1.1 任务描述

实现一个**简化版 HNSW** 索引，对随机向量集与查询集，与暴力 Top-K 检索对比**召回率@K** 与**单查询延迟**，并绘制权衡曲线。

简化约定（相对原论文 Malkov & Yashunin 2018）：

- 距离用余弦相似度（向量归一化后即内积）；
- 层分配：每个点以概率 $p = 0.5$ 逐层向上（层数 $\ell \sim$ 几何分布），顶层只有入口点附近；
- 建图：每点在每层与 $M$ 个**启发式选出的**近邻连边（简化启发式：按距离取最近 $M$ 个，进阶要求实现论文的"选边多样性"启发式）；
- 查询：顶层贪心下降（每步移向更近邻点，无改进即停），底层用宽度 `ef` 的束搜索（优先队列，第 3 章）取 Top-K。

### 9.1.2 任务分解

1. **数据与金标准**：生成 $n = 20{,}000$ 个 $D = 64$ 维归一化随机向量、100 个查询；用暴力 + `np.argpartition`（第 5 章）得到 Top-10 金标准。
2. **图结构**：节点类（向量、各层邻接表——第 2 章 `list`/`dict`）；层分配函数（验证层数分布 $\approx$ 几何分布）。
3. **贪心搜索**（单层）：从入口出发，循环找更近的邻点；正确性自测——对"只有一层的退化 HNSW"，结果应与暴力在小 $n$ 上一致。
4. **建图插入**：逐点插入，先自顶向下贪心定位、再在每层找 $M$ 个近邻连边。
5. **束搜索查询**：候选堆（最小堆按距离）+ 已访问集合（哈希表）+ 结果堆（第 3 章对顶堆思想）。
6. **评估**：召回率@10 = 交集大小 / 10（对 100 个查询取均值）；延迟用 `time.perf_counter` 分位数（P50/P99，第 5 章快速选择）。
7. **实验矩阵**：`ef ∈ {10, 20, 50, 100, 200}` × `M ∈ {8, 16, 32}`，画召回率-延迟曲线（matplotlib，log 横轴）。

### 9.1.3 验收标准

- [ ] 在 $n=20{,}000, D=64$ 上，`M=16, ef=50` 时召回率@10 $\ge 0.9$ 且单查询延迟 $\le$ 暴力法的 1/5；
- [ ] 召回率-延迟曲线单调合理：`ef` 增大召回升、延迟升；给出你观察到的"性价比拐点"；
- [ ] 层分布的直方图与几何分布理论值吻合（每个点层数期望 $\approx 1/(1-p)$）；
- [ ] 代码含复杂度声明注释（建图 $O(n\log n \cdot M)$ 量级、查询 $O(\text{ef}\cdot M\cdot\log n)$ 量级）与 200 字权衡结论。

### 9.1.4 提示与陷阱

- 先做"单层 HNSW"（即 NSW），验证召回率可行再加分层——分层主要贡献是**降低贪心陷入局部最优的概率**，可对比单层/多层召回率差；
- 已访问集合用 `set` 而不是 list（第 2 章）；束搜索的候选堆允许重复入堆、弹出时检查（第 3 章"懒惰删除"）；
- 余弦距离下先归一化所有向量（含查询），把相似度化为内积，距离比较才正确；
- 进阶：实现论文启发式选边（候选 $e$ 入选条件：$e$ 比已选点都更接近 $q$，否则跳过），对比朴素选边在同一 `ef` 下的召回率差——这正是课后挑战题 10 的内容。

## 9.2 项目二：编辑距离与拼写纠错器（对应第 6 章，回引第 2/3/5 章）

### 9.2.1 任务描述

构建一个英语（或中文拼音）拼写纠错器：输入可能拼错的词，输出按"编辑距离 + 词频先验"排序的 Top-5 候选；要求在万级词表上**毫秒级响应**——朴素"对每个词算编辑距离"是 $O(|V| \cdot L^2)$，必须用算法手段降下来。

### 9.2.2 任务分解

1. **词表与词频**：用任意开源词频表（如 norvig.com/big.txt 自行统计，或 NLTK 语料），得到 `dict[word] = freq`（第 2 章哈希表）。
2. **基线**：对查询词对词表**每个**词算词级编辑距离（第 6 章 DP，两行滚动优化），取距离最小、频次最高的 Top-5。记录此基线延迟。
3. **加速一：距离上限剪枝**：只考虑编辑距离 $\le 2$ 的候选。用第 3 章 **Trie + 剪枝 DFS**：沿 Trie 下行时维护 DP 的当前行，若 $\min(\text{当前行}) > 2$ 则整棵子树剪掉（这是经典的 Levenshtein automaton 思想）。验证剪枝后结果与基线完全一致。
4. **加速二（可选）：编辑距离 $\le 1$ 的生成法**：对查询词生成全部删除/插入/替换/换位的邻词（Norvig 拼写纠正器思路），在哈希表中直接查。对比两种加速的延迟与覆盖面。
5. **排序准则**：候选按 $-\text{dist}$ 为主、$\log(\text{freq}+1)$ 为次排序（第 5 章多关键字排序的稳定实现）；或设计加权分 $s = -\alpha\,\text{dist} + \beta\log\text{freq}$ 并做小规模网格搜索。
6. **评估**：构造 200 个错误样本（对真实词随机做 1–2 次编辑操作，模拟真实 typo 分布），报告 Top-1/Top-5 命中率与平均延迟。

### 9.2.3 验收标准

- [ ] 基线与 Trie 剪枝版输出完全一致（对拍通过）；
- [ ] 词表 $\ge 20{,}000$ 词时，单查询 P99 延迟 $\le 5$ ms（普通笔记本）；相对基线加速比 $\ge 50\times$；
- [ ] 人工编辑距离 $\le 2$ 的样本上 Top-5 命中率 $\ge 0.8$；给出 3 个失败案例分析（例如：错误词恰是另一个真实词时纯距离法为何失效、词频先验如何救/不救）；
- [ ] 报告包含：`WER = 编辑距离/参考长度` 与本纠错器的天然联系一段话（衔接《自然语言处理》评测）。

### 9.2.4 提示与陷阱

- Trie 剪枝的 DP 行要按 Trie 深度更新，而不是按查询词位置——先在纸上画出 6.8 案例 1 的表，把"沿 Trie 下行"理解为"逐行填表 + 沿前缀分支复制行"；
- 词频先验对"高频词的低距离 typo"是救命稻草，但对专有名词可能引入偏置——报告里要讨论；
- 中文场景可换成"拼音串纠错"或"句子级错别字"，编辑距离以字为原子即可复用全部代码。

## 9.3 项目三：并查集 + 最小生成树做图聚类（对应第 4 章，回引第 1/2/5 章）

### 9.3.1 任务描述

在带权图上实现**单链层次聚类**：构建近邻图（或直接给图），用 Kruskal + 并查集按边权升序合并，在合并到 $k$ 个分量（或边权超过阈值 $\tau$）时停止，分析聚类结果并与 K-Means（sklearn）对比。

### 9.3.2 任务分解

1. **数据生成**：二维人工数据 3 组设计——(a) 三团高斯（K-Means 友好）；(b) 两个月牙/环形簇（K-Means 失败、单链成功）；(c) "桥接"数据：两大团之间用一条细链相连（单链的经典失败案例：链式效应把两团并成一簇）。每组 $n = 2{,}000$ 点。
2. **近邻图构建**：$k$-近邻图（对每点找 $k = 10$ 近邻——直接第 5 章快速选择；进阶用第 7 章 KD 树），边权 = 欧氏距离，图无向化（取并）。
3. **Kruskal + DSU**：按边权排序（第 5 章），DSU 合并（第 4 章），到 $k$ 分量停止；实现"阈值版"：只合并边权 $< \tau$ 的边。
4. **评估**：(a)(b) 用调整兰德指数 ARI（`sklearn.metrics.adjusted_rand_score`）对真值；(c) 可视化着色并用 matplotlib 输出三组数据的聚类对比图。
5. **对比与解释**：同一份数据跑 K-Means（sklearn，$K=2$ 或 3），表格化 ARI 对比；写 300 字解释"单链聚类 = MST 的连通语义、K-Means = 球形方差语义"，并指出两者失败模式互补。

### 9.3.3 验收标准

- [ ] DSU 通过对拍（与 NetworkX 连通分量或自写 DFS 在 100 组随机图上一致）；
- [ ] 数据 (b)：单链 ARI $\ge 0.9$ 而 K-Means $\le 0.6$；数据 (c)：单链把两桥接团并簇（ARI 低），能解释并给出"k 近邻图去掉长边 / 全链 vs 单链"的至少一种修复；
- [ ] Kruskal 总耗时在 $n=2000, k=10$ 图上 $< 0.5$ s，且复杂度声明 $O(m\log m)$ 与实测吻合（用第 1 章倍率法验证）；
- [ ] 报告含三图对比与聚类语义讨论。

### 9.3.4 提示与陷阱

- 单链聚类对**噪声点**敏感（一个噪声桥能把两簇串起来）——第 7 章的"排序后截断长边"即 $\tau$ 阈值版；
- $k$-近邻图要保证**对称化**（$i$ 的邻居含 $j$ 但 $j$ 不含 $i$ 时取并），否则可能不连通；不连通分量各自做 MST 再合并即可（森林语义）；
- 进阶：把 (c) 的修复做成实验——对每条边减去"两端局部平均距离"（相对距离），桥接边权相对变大后单链能否分开两团？

        pred = set(index.search(q, k, ef))
        hits += len(pred & truth[qi])
    return hits / (len(Qs) * k)

5. 没有在循环里做 $O(n)$ 的操作（`pop(0)`、循环内建堆/建表）；
6. 哈希表键全部不可变；
7. 计时用 `time.perf_counter` 并报告 P50/P99，不只报均值；
8. 图表有轴标签、图例与标题，参数扫描范围在图题中说明；
9. 报告中每个结论都有对应的数据或图表编号支撑；
10. 失败案例至少 3 个，且各自有归因（不是"效果不好"三个字）；
11. 未使用的依赖已移除，`requirements.txt` 可一键安装；
12. README 三行：怎么装、怎么跑测试、怎么复现图表。

## 9.6 进阶方向

- **真实数据升级**：把项目一的数据换成真实 embedding（如 `sentence-transformers` 编码 1 万条短文本，见《深度学习》），检验 ANN 在各向异性分布上的表现与均匀随机的差异。
- **检索 + 纠错联合系统**：项目二的纠错器接到项目一的向量检索前，构成"文本拼写归一 → 语义检索"的迷你 RAG（衔接《模型部署与MLOps》）。
- **分布式与持久化**：把 DSU/Kruskal 搬到磁盘图（CSR 存储，第 7 章）上做外存版，体会 I/O 复杂度与内存版的差距（衔接《数据工程》）。
- **开源贡献**：为一个小型开源项目（如 `hnswlib` 的文档/基准）提交一条 issue 或 benchmark PR——把课程能力转化为社区可见的作品。
