# Python 程序设计 · 课程导览

> **本文件定位**：本文件是《Python 程序设计》课程的总入口，说明课程定位、知识地图、与教材中其他课程的依赖关系、建议学时与学习方法。开始学习任何一章之前，请先读完本文件。

## 一、课程定位：Python 是 AI 的通用语

在整个人工智能知识体系中，数学（模块一）回答"为什么成立"，程序设计（模块二）回答"如何算出来"。而在这"如何算出来"之中，Python 是事实上的通用语言（lingua franca）：

- 科研复现：几乎所有顶会论文的开源实现都以 Python 为主语言（PyTorch、TensorFlow、JAX、scikit-learn、Hugging Face 等生态全部围绕 Python 构建）。
- 工业落地：从数据清洗、模型训练、评估到服务化部署（FastAPI、Ray、MLflow），Python 贯穿机器学习生命周期的每一环。
- 胶水属性：Python 本身性能不高，但它把 C/C++/CUDA 写成的高性能内核（NumPy、BLAS、cuDNN）"粘"在一起——**用 Python 的语法，享受编译级代码的速度**。这正是本课程要建立的核心心智模型。

**本课程不是语法课。** 假设你已经能读懂 if/for/函数这类任何语言都有的结构（若不能，请先用 1–2 周自学任意一本 Python 入门教程的语法部分）。本课程的目标是：为后续的《机器学习》《深度学习》《数据工程》课程准备**完整的工程能力**，具体包括三层：

1. **语言层（第 1–3 章）**：真正理解 Python 的对象模型、函数式与面向对象两种组织方式、迭代器/生成器/上下文管理器这些"AI 框架源码中随处可见"的机制。读不懂 `nn.Module` 的 `__init__`/`__call__`、DataLoader 的迭代协议、装饰器注册机制，就无法真正读懂框架源码。
2. **科学计算层（第 4–6 章）**：NumPy 的向量化与"轴"的心智模型是深度学习张量操作（`torch.Tensor` 的 API 几乎是 NumPy 的超集）的直接基础；Pandas 与可视化是实验分析、写论文画图的日常工具。
3. **工程层（第 7 章与综合项目）**：测试、日志、项目组织、Git、依赖管理——这些是《实验设计与评估》《模型部署与 MLOps》的先修能力，也是"科研代码"与"可靠软件"的分界线。

## 五、学习方法

1. **多写**。编程是手艺：每章至少完成 3 道课后练习，所有示例代码必须亲手运行、亲手改坏再修好。只读不写等于没学。
2. **多读源码**。本课程刻意选取了若干"AI 生态真实源码片段"式的例子（如简化的 `nn.Module`、`DataLoader`）。学完第 3 章后，建议开始定期阅读：`numpy` 的广播文档、`sklearn.linear_model` 的实现、PyTorch 的 `torch/utils/data` 源码。读源码是本科阶段性价比最高的能力投资。
3. **从零实现与调库并举**。每章都同时提供"手写以理解机制"和"调用成熟库以掌握工程用法"两类代码。先用库做出来，再用从零实现解释它为什么快/为什么对。
4. **建立实验记录**。从第 5 章起，所有实验（性能对比、数据分析）都要求用 Jupyter Notebook + Git 保存，为《实验设计与评估》的复现性要求做准备。
5. **错题本机制**。每章"常见误区与陷阱"一节来自真实工程事故（如张量意外共享内存导致训练静默出错）。建议把这些陷阱当作检查清单（checklist），写代码后自查。

```
numpy  pandas  matplotlib  seaborn  scipy  scikit-learn  pytest  mypy
```

## 七、拓展阅读

- Luciano Ramalho, *Fluent Python* (2nd ed.), O'Reilly, 2022. —— 本课程第 1–3 章的语言深度标杆，学完后再读收获最大。
- Wes McKinney, *Python for Data Analysis* (3rd ed.), O'Reilly, 2022. —— Pandas 作者亲自写的书，第 5 章的延伸首选。
- Jake VanderPlas, *Python Data Science Handbook*, O'Reilly, 2016（开源免费）。 —— 第 4–6 章（NumPy/Pandas/Matplotlib）最贴合的免费参考。
- Brett Slatkin, *Effective Python* (3rd ed.), Addison-Wesley, 2024. —— 90 条惯用法建议，第 3、7 章的习题素材来源。
- Software Carpentry（software-carpentry.org）—— 免费的科研计算软件工程课程，第 7 章的原始出处之一。
- NumPy 官方文档 "NumPy: the absolute basics for beginners" 与 Broadcasting 章节 —— 第 4 章必读配套。
