## 6.1 Matplotlib 的面向对象 API：fig 与 ax

### 6.1.1 两层对象模型

Matplotlib 有两个 API 入口：`pyplot` 的**全局状态机**（隐式"当前图"）与**面向对象 API**。专业代码只用后者，因为它显式、无全局状态、可测试：

- **Figure**：整个画布，可含多个子图；
- **Axes**：一个子图（坐标系 + 数据 + 装饰），是绘图的真正载体。

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 2 * np.pi, 200)
fig, axes = plt.subplots(1, 2, figsize=(9, 3.5), constrained_layout=True)

axes[0].plot(x, np.sin(x), label=r"$\sin x$")       # 标题/图例支持 LaTeX 片段
axes[0].set(title="三角函数", xlabel="x", ylabel="y")
axes[0].legend()

axes[1].plot(x, np.exp(-(x / 3) ** 2) * np.cos(5 * x), color="tab:red")
axes[1].set(title="衰减振荡", xlabel="x", ylabel="y", yscale="symlog")

fig.savefig("demo.svg")        # 矢量图：论文用（PDF/SVG）；位图用 dpi=300 的 PNG
```

`plt.subplots` 一行同时建画布与轴数组；`constrained_layout=True` 自动排布避免标签重叠；`r"..."` 原始字符串里的 `$...$` 由 Matplotlib 内置的数学排版渲染（与教材 LaTeX 语法同源）。

### 6.1.2 常用图表选择

| 目的 | 图 | Axes 方法 |

## 6.5 scipy：数值算法的标准库

scipy 在 NumPy 之上提供成熟数值算法（底层多为 Fortran/C 的经典实现）。本节按课程衔接介绍三件套。

### 6.5.1 optimize：求根与最小化（衔接《最优化方法》）

```python
import numpy as np
from scipy import optimize

# 例 1：一维最小化——Rosenbrock 香蕉函数（优化算法的标准试验台）
rosen = lambda w: (1 - w[0]) ** 2 + 5 * (w[1] - w[0] ** 2) ** 2
res = optimize.minimize(rosen, x0=[-1.0, 1.0], method="BFGS")
print(res.x.round(4))     # 预期输出: [1. 1.]（ Rosenbrock 全局极小点）
print(res.fun.round(6))   # 预期输出: 0.0

# 例 2：求根——解方程 x = cos(x)
root = optimize.brentq(lambda x: x - np.cos(x), 0, 1)
print(round(root, 6))     # 预期输出: 0.739085（Dottie 数）
```

`minimize` 的 `method` 对应《最优化方法》的算法谱系：`BFGS`（拟牛顿）、`Newton-CG`（牛顿+共轭梯度）、`L-BFGS-B`（大边界约束）；传 `jac=` 显式梯度（NumPy 手写或自动微分）可大幅加速——这正是"梯度下降收敛率"章节的实验工具。

### 6.5.2 interpolate 与 stats

```python
import numpy as np
from scipy import interpolate, stats

# 插值：稀疏实验点 -> 平滑曲线
xs = np.array([0.0, 1.0, 2.0, 4.0])
ys = np.array([0.0, 1.1, 3.9, 15.8])          # 近似 y = x^2
f = interpolate.CubicSpline(xs, ys)
print(f(3.0).round(2))                        # 预期输出: 8.99（真值 9）

# 统计检验：两组实验准确率是否有显著差异（《概率统计》假设检验）
a = np.array([87.1, 86.9, 87.0, 87.3])        # 模型 A 多种子
b = np.array([88.5, 88.1, 88.3, 88.6])        # 模型 B 多种子
t, p = stats.ttest_ind(a, b)
print(f"t={t:.2f}, p={p:.4f}")                # 预期输出: t=-15.19, p=0.0001（近似量级）
print(stats.norm.cdf(1.96).round(4))          # 预期输出: 0.975（标准正态的熟悉数值）
```

`stats` 覆盖分布、抽样、检验（t 检验、Wilcoxon、卡方）；《概率统计》的每个经典分布都有对应对象 `stats.norm/expon/binom`，方法统一为 `pdf/cdf/rvs/fit`。

## 6.6 示例与案例

### 案例 1：手算误差棒（数值算例）

某模型 5 个随机种子的准确率：`[91.0, 90.5, 91.5, 91.2, 90.8]`。

- 均值 $\bar x = \frac{1}{5}\sum x_i = 91.0$；
- 样本标准差 $s = \sqrt{\frac{1}{n-1}\sum (x_i - \bar x)^2} = \sqrt{0.13} \approx 0.361$；
- 均值的标准误 $s/\sqrt{n} \approx 0.161$；
- 95% 置信区间（t 分布，$t_{0.975,4} \approx 2.776$）：$91.0 \pm 2.776 \times 0.161 \approx 91.0 \pm 0.45$。

```python
import numpy as np
from scipy import stats

acc = np.array([91.0, 90.5, 91.5, 91.2, 90.8])
print(acc.mean().round(3))          # 预期输出: 91.0
print(acc.std(ddof=1).round(3))     # 预期输出: 0.361
print(acc.std(ddof=1) / np.sqrt(5)) # 预期输出: 0.161（标准误）
ci = stats.t.interval(0.95, df=4, loc=acc.mean(), scale=stats.sem(acc))
print(np.round(ci, 3))              # 预期输出: [90.547 91.453]
```

校验点：手算标准误 0.161 与 `stats.sem` 一致。**报告图表时必须写明画的是 std、SEM 还是 95% CI**——三者相差 $\sqrt{n}$ 与 t 分位数的倍数，混用是实验报告最常见的方法学错误。

### 案例 2：复现一条带误差棒的实验对比曲线

任务：对比"模型 A/B 在不同训练数据量下的准确率"（学习曲线），每个数据量 3 个种子。数据生成 → 统计 → 绘图全流程，可直接运行：

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

rng = np.random.default_rng(seed=7)

# ---- 1. 合成实验数据（真实场景：来自多组训练运行的日志）----
sizes = np.array([100, 300, 1000, 3000, 10000])          # 训练样本数
def run_experiment(model: str, n: int) -> float:
    """模拟一次训练运行：B 模型高 2 个点、数据越多越准、种子带来噪声。"""
    base = 100 / (1 + np.exp(-(np.log10(n) - 2.2) * 1.8))   # 饱和曲线（sigmoid of log n）
    boost = 2.0 if model == "B" else 0.0
    return float(np.clip(base + boost + rng.normal(0, 0.8), 50, 99))

rows = [(m, n, run_experiment(m, n))
        for m in ["A", "B"] for n in sizes for _ in range(3)]

# ---- 2. 用第 5 章的 groupby 统计（跨章衔接）----
import pandas as pd
df = pd.DataFrame(rows, columns=["model", "n", "acc"])
summary = df.groupby(["model", "n"])["acc"].agg(["mean", "std", "count"]).reset_index()

# ---- 3. 绘图：OO API + rcParams + 误差棒 + 对数横轴 ----
plt.rcParams.update({"font.size": 11, "axes.spines.top": False,
                     "axes.spines.right": False, "figure.constrained_layout.use": True})

fig, ax = plt.subplots(figsize=(5.5, 3.8))
for i, model in enumerate(["A", "B"]):
    sub = summary[summary.model == model]
    sem = sub["std"] / np.sqrt(sub["count"])            # 标准误：均值的不确定性
    ax.errorbar(sub["n"], sub["mean"], yerr=sem, fmt="o-",
                capsize=3, label=f"模型 {model}",
                color=f"tab:{'blue' if i == 0 else 'orange'}")

ax.set(xscale="log", xticks=sizes,
       xlabel="训练样本数", ylabel="准确率 (%)",
       title="学习曲线（每点 3 个随机种子，误差棒为 ±1 标准误）")
ax.legend()
fig.savefig("learning_curve.svg")      # 论文插入用；PNG 则 dpi=300
plt.show()

# ---- 4. 报告辅助：最大数据量下两模型差异是否显著（《概率统计》t 检验）----
a = df[(df.model == "A") & (df.n == 10000)]["acc"]
b = df[(df.model == "B") & (df.n == 10000)]["acc"]
t, p = stats.ttest_ind(a, b)
print(f"n=10000: t={t:.2f}, p={p:.4f}")
# 预期输出: n=10000: t=-5.60, p=0.0126（量级；B 显著优于 A）
```

预期图形：两条单调上升、逐渐饱和的曲线，B 在 A 上方约 2 个点；横轴对数刻度；每个点带小误差棒。这条"学习曲线 + 误差棒 + 显著性检验"就是《实验设计与评估》论文实验章的标准图 1。

## 6.7 常见误区与陷阱

1. **用 pyplot 全局状态写库/多图代码**。`plt.plot` 作用于"当前图"，多子图/循环出图时相互污染；一切通过 `fig, ax` 显式传递。
2. **误差棒语义不明**。把 std、SEM、95% CI 混着画还不注明；样本量不同时（种子数不同）尤其要写清 `n`。
3. **纵轴不从 0 / 不标注单位**（对条形图是硬伤；折线图可非零但要在 caption 说明），或双轴图不说明刻度对应关系——都会夸大或掩盖差异。
4. **Notebook 乱序执行**。结果单元格展示的不是当前代码的输出；提交前 Restart & Run All 是底线。
5. **把 seaborn 的默认置信区间当标准差**。seaborn 线图/条形图的误差条默认是 bootstrap 95% CI；想要 ±1 std 需显式 `errorbar="sd"`。

## 6.8 关键公式速查

| # | 规则/公式 | 适用条件与备注 |
|---|---|---|
| 1 | Figure ⊃ Axes；绘图作用于 `ax`，保存作用于 `fig` | OO API；`plt.subplots(n, m)` 返回轴数组 |
| 2 | 均值标准误 $SEM = s / \sqrt{n}$ | 独立同分布样本；报告图须注明误差棒种类与 $n$ |
| 3 | 95% CI：$\bar x \pm t_{0.975,\,n-1} \cdot SEM$ | 小样本用 t 分布；$n$ 大时趋于 $\pm 1.96\,SEM$ |
| 4 | Rosenbrock 全局极小点 $(1, 1)$、方程 $x=\cos x$ 的根 $0.739085$ | scipy.optimize 的标准校验用例 |
| 5 | 长格式（tidy）DataFrame 是 seaborn 的输入 | 每行一个观测、每列一个变量——第 5 章 `melt`/`groupby` 的产物 |
| 6 | Jupyter 交稿前 Restart & Run All | notebook 的执行顺序必须可从头复现 |
