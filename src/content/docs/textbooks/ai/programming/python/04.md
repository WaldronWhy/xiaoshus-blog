## 4.1 ndarray：三要素与视图

### 4.1.1 shape、dtype、stride

ndarray = 一块连续（通常）内存 + 元数据。三个元数据决定一切：

- **shape**：各维度长度，如 `(2, 3)`；
- **dtype**：元素类型，统一且固定（`float32`、`int64`……）——同质化是向量化提速的前提；
- **stride**：每个维度上"走一步"需要跳过的字节数。stride 允许为负或不连续——**转置、切片视图都不移动数据，只改元数据**。

```python
import numpy as np

a = np.arange(6, dtype=np.int64).reshape(2, 3)
print(a)
# 预期输出:
# [[0 1 2]
#  [3 4 5]]
print(a.shape, a.dtype, a.strides)
# 预期输出: (2, 3) int64 (24, 8)   外层走一步跳 24 字节（3 个 int64），内层 8 字节
print(a.T.strides)      # 预期输出: (8, 24) —— 转置只交换 stride，零拷贝
```

### 4.1.2 视图 vs 拷贝（呼应第 1 章）

| 操作 | 返回 | 示例 |
|---|---|---|
| 基本切片 `a[1:3]`、`a[:, 0]` | **视图**（共享内存） | 修改波及原数组 |
| 整数数组索引（花式索引）、布尔掩码 | **拷贝** | 修改不波及原数组 |
| `.reshape()`（连续时）、`.T`、`squeeze` | 视图 | 只改元数据 |
| `.copy()`、算术运算结果 | 拷贝 | 独立内存 |

```python
a = np.arange(6).reshape(2, 3)
v = a[:, 1:3]        # 视图
v[0, 0] = 99
print(a[0, 1])       # 预期输出: 99 —— 原数组被改

f = a[[0, 1], [1, 2]]  # 花式索引 -> 拷贝
f[0] = -1
print(a[0, 1])       # 预期输出: 99 —— 原数组不受影响

print(v.base is a)   # 预期输出: True —— 用 base 追查共享（第 1 章案例 2 的工具）
```

## 4.2 形状与广播规则

### 4.2.1 广播规则（背下来）

两个数组做二元运算时，NumPy 从**最后一维向前**逐维对齐，每维满足以下之一才兼容：

1. 两维长度相等；或
2. 其中一个长度为 1（该维被"拉伸"复制——逻辑上复制，不真复制内存）；或
3. 其中一个数组该维**不存在**（左补 1）。

结果形状 = 逐维取最大值。若任一维既不相等也无一为 1，报 `ValueError`。

### 4.2.2 逐步推导几个例子

```
(3, 4) + (4,)    ->  (3, 4) + (1, 4)   ->  (3, 4)      OK（最常见：每行加同一向量）
(3, 4) + (3, 1)  ->  (3, 4)            OK（每列加同一数，即"按行归一化"的基础）
(3, 4) + (3,)    ->  (3, 4) + (1, 3)   ->  右对齐比较 4 vs 3 -> 不兼容 -> ValueError
(2, 3, 4) + (4,) ->  (2, 3, 4)         OK
(2, 3, 4) + (3, 4) -> (2, 3, 4)        OK
(3, 4) + (4, 3)  ->  ValueError（4 vs 4 OK，但 3 vs 3 在错误的位置？不——
                     左对齐 (3,4) 与 (4,3)：最末维 4 vs 3 失败 -> ValueError）
```

最后一个例子是新手重灾区：想"两两相加所有行对"得到 `(3, 3, 4)`，正确写法是 `a[:, None, :] + b[None, :, :]`，得到 `(3, 1, 4) + (1, 3, 4) -> (3, 3, 4)`。

```python
a = np.ones((3, 4))
row = np.arange(4.0)          # (4,)
print((a + row).shape)        # 预期输出: (3, 4)

col = np.arange(3.0).reshape(3, 1)
print((a + col).shape)        # 预期输出: (3, 4)

try:
    a + np.arange(3.0)        # (3,) 想按列加
except ValueError as e:
    print(e)                  # 预期输出: operands could not be broadcast together
                              #          with shapes (3,4) (3,)
```

### 4.2.3 广播的几何直觉

把"长度为 1 的维"想象成一根可以任意拉长的橡皮筋：`(3, 1)` 竖着拉成 `(3, 4)`，`(1, 4)` 横着拉。**广播不会真正复制内存**（stride 设为 0 即可），因此没有空间与时间开销——这是"逻辑复制"与 `np.tile` 的本质区别。

### 4.2.4 广播三类高频错误

1. **忘了升维**：想按列加 `(n,)` 向量到 `(n, m)` 矩阵的每一列，直接 `A + v` 会广播到行上（形状对不上时才报错，若 `m == n` 则静默加错！）。正确：`A + v[:, None]` 或 `A + v.reshape(-1, 1)`。
2. **利用了"恰好相等"的静默错误**：`(n, n) + (n,)` 合法但语义可能是错的（加到了行上而你想要列）。n×n 情况是数值代码里最阴险的 bug。
3. **以为广播产生了新数组拷贝**：`A[:, None, :]` 只是视图（stride  trick），无成本；但 `np.tile`/`np.repeat` 真复制，大数据集上能吃光内存。

## 4.3 花式索引与布尔掩码

### 4.3.1 布尔掩码：向量化筛选

```python
rng = np.random.default_rng(seed=0)
scores = rng.normal(loc=70, scale=10, size=8).round(1)
print(scores)                # 预期输出: [64.9 69.1 79.4 57.3 69.1 65.6 72.5 78.5]（量级）

mask = scores >= 70
print(mask)                  # 预期输出: [False False  True False False False  True  True]
print(scores[mask])          # 预期输出: [79.4 72.5 78.5] —— 掩码筛选，返回拷贝
scores[scores < 60] = 0      # 掩码置零：数据清洗常用
print(scores)                # 预期输出: [64.9 69.1 79.4  0.  69.1 65.6 72.5 78.5]
print(((scores >= 60) & (scores < 75)).sum())  # 预期输出: 4 —— 条件组合用 & | ~，不是 and/or
```

**陷阱**：数组条件必须用 `&`、`|`、`~` 且加括号（Python 的 `and`/`or` 会试图对整个数组做真值判断而报错）。

### 4.3.2 花式索引与 arg 系函数

整数数组索引允许任意重排、重复取元素；`argsort`/`argmax` 把"找值"变成"找下标"，是 top-k、排序、对齐操作的基石：

```python
x = np.array([3.0, 1.0, 4.0, 1.5, 2.5])
order = np.argsort(x)                # 升序排列的下标
print(order)                         # 预期输出: [1 3 4 0 2]
print(x[order])                      # 预期输出: [1.  1.5 2.5 3.  4. ]
print(x[order[-3:]])                 # 预期输出: [2.5 3.  4. ] —— top-3（无序下标）
print(np.argmax(x))                  # 预期输出: 2

# 二维花式索引：同时给出行、列下标，逐点配对（不是笛卡尔积！）
m = np.arange(9).reshape(3, 3)
print(m[[0, 1, 2], [2, 1, 0]])       # 预期输出: [2 4 6] —— 取 (0,2),(1,1),(2,0)
```

要取"前 k 行"这类矩形区域，用 `m[order[:k], :]`（行下标是数组、列下标是切片——一个花式一个切片时结果是原布局的拷贝）。

## 4.4 聚合与轴的心智模型

### 4.4.1 轴是什么

ndarray 的 `shape = (2, 3, 4)` 中，`axis=0` 是第 0 维。**聚合（reduce）的统一规则：沿 axis 聚合后，该维度消失（或变成长度 1）**：

```python
a = np.arange(24).reshape(2, 3, 4)
print(a.sum(axis=0).shape)   # 预期输出: (3, 4)   axis 0 被消掉
print(a.sum(axis=1).shape)   # 预期输出: (2, 4)
print(a.sum(axis=2).shape)   # 预期输出: (2, 3)
print(a.sum(axis=1, keepdims=True).shape)  # 预期输出: (2, 1, 4) —— 保留该维以便广播回去
```

两个互补的心智模型：

- **"消维"模型**（上面）：`axis=k` 指定**被消掉**的维。`sum(axis=0)` 是跨行求和、得到每列的和。
- **"沿该轴切片"模型**：`axis=k` 表示"沿第 k 维方向切片，对每个切片做一次完整聚合"。`a.sum(axis=1)` 对 `a[i, :, j]` 这种一维条带求和。

验证一下数值（用简单数组手算）：

```python
b = np.array([[1., 2., 3.],
              [4., 5., 6.]])
print(b.sum(axis=0))   # 预期输出: [5. 7. 9.]  —— 每列求和（跨行），shape (3,)
print(b.sum(axis=1))   # 预期输出: [6. 15.]     —— 每行求和（跨列），shape (2,)
print(b.mean(axis=1, keepdims=True))
# 预期输出: [[2.]
#            [5.]]  —— (2,1)，可直接广播回 (2,3) 做按行标准化
```

`axis=None`（默认）对**全部元素**聚合成标量。`keepdims=True` 的存在只有一个理由：聚合结果要与原数组广播（如按行除以均值做标准化、softmax 分母），此时维度数必须一致。

### 4.4.2 轴在 AI 中的对应

| NumPy | 深度学习等价物 | 典型用途 |
|---|---|---|
| `a.mean(axis=0)` | `x.mean(dim=0)` | 批统计量、特征中心化 |
| `a.sum(axis=-1)` | `logits.sum(dim=-1)` | 每个样本/序列位置的归约 |
| `keepdims=True` + 广播 | softmax 分母、LayerNorm | 逐样本归一化 |
| `a[:, None, :]` | `x.unsqueeze(1)` | 升维以对齐广播（注意力打分 $QK^\top$） |

第 4 节作业会让你实现一个 softmax，那里 `keepdims` 缺失会让 `(n,)` 的分母广播到错误的维度上。

## 4.5 向量化 vs 循环：性能实验

### 4.5.1 为什么快

Python 循环每步都要：解释字节码、给对象装箱/拆箱（int ↔ PyObject）、动态查类型与分发。NumPy 把循环下放到 C：**一次解释、原地类型、SIMD 友好的连续内存**。数学表达：向量化把每元素开销从 $O(\text{解释器开销})$ 降到 $O(\text{机器指令})$，两者相差 1–3 个数量级。

### 4.5.2 基准测试（可直接运行）

```python
import numpy as np
import time

def bench(fn, *args, repeat=3):
    best = float("inf")
    for _ in range(repeat):
        t0 = time.perf_counter()
        fn(*args)
        best = min(best, time.perf_counter() - t0)
    return best

n = 10_000_000
a = np.arange(n, dtype=np.float64)
b = np.arange(n, dtype=np.float64)

def loop_add(a, b):                 # 纯 Python 循环 + list
    out = [0.0] * n
    for i in range(n):
        out[i] = a[i] + b[i]
    return out

def numpy_add(a, b):                # 向量化
    return a + b

t_loop = bench(lambda: loop_add(a, b))
t_vec = bench(numpy_add, a, b)
print(f"循环:  {t_loop:.3f} s")
print(f"NumPy: {t_vec * 1000:.2f} ms")
print(f"加速比: {t_loop / t_vec:.0f}x")
# 预期输出（典型量级，因机器而异）:
# 循环:  3.8 s
# NumPy: 12.35 ms
# 加速比: 300x
```

再对比"写得像 NumPy 但不是向量化"的两种常见写法：

```python
def pycomp_add(a, b):               # 列表推导：比显式 for 快约 2x，仍远慢于 NumPy
    return [x + y for x, y in zip(a, b)]

t_comp = bench(lambda: pycomp_add(a, b))
print(f"列表推导加速比 vs NumPy: {t_comp / t_vec:.0f}x")
# 预期输出: 列表推导加速比 vs NumPy: 60x（量级）
```

结论的量级（2020 年代中期常见桌面 CPU，真实可信）：

| 实现 | 相对 NumPy 耗时 |
|---|---|
| 纯 Python for 循环 | 200–500x |
| 列表推导 | 40–80x |
| NumPy 向量化 | 1x（基准） |
| NumPy + 多线程 BLAS（大矩阵乘法） | 快于单线程基准（并行化再乘一个核数因子） |

注意两个前提：① 数组要够大（`n < 1000` 时固定开销可能反超）；② 避免"伪向量化"——在循环里逐个调用只处理标量的 ufunc 没有任何收益。当向量化的控制流表达不了（复杂分支、递归），用 `numba.jit` 或 Cython 编译，而不是回退到 Python 循环。

## 4.6 随机数生成器

### 4.6.1 现代 API：`default_rng`

旧的全局 API（`np.random.seed` / `np.random.rand`）从 NumPy 1.17 起被推荐替换为显式的 **Generator** 对象：状态独立、算法（PCG64）更好、可并行安全：

```python
rng = np.random.default_rng(seed=42)      # 显式种子 -> 可复现实验
print(rng.normal(loc=0.0, scale=1.0, size=3))   # 预期输出: [ 0.3047 -1.0400  0.7505]（近似，量级）
print(rng.integers(0, 10, size=5))              # 预期输出: [9 3 7 9 2]（近似）
print(rng.choice(["a", "b", "c"], size=4))      # 预期输出: ['c' 'a' 'c' 'b']（近似）

rng2 = np.random.default_rng(seed=42)
print(np.array_equal(rng.normal(size=1000), rng2.normal(size=1000)))
# 预期输出: True —— 同种子产生完全相同序列（《实验设计与评估》的复现性基石）
```

### 4.6.2 分布采样与洗牌

```python
rng = np.random.default_rng(seed=0)
w = rng.normal(size=(3, 4))          # 初始化权重：深度学习第一步
idx = rng.permutation(10)            # 洗牌下标（第 3 章 DataLoader 的 shuffle 内核）
sub = rng.choice(100, size=5, replace=False)   # 无放回抽样（ train/test 划分的思想）
print(idx)        # 预期输出: [7 9 3 5 6 0 1 8 4 2]（近似，量级）
print(sub)        # 预期输出: [77 65 44 38 19]（近似）
```

## 4.7 关键公式速查

| # | 规则/公式 | 适用条件与备注 |
|---|---|---|
| 1 | ndarray 三要素：shape、dtype、stride；视图只改元数据 | 切片/`.T`/`reshape`（连续时）零拷贝；花式索引与掩码产生拷贝 |
| 2 | 广播：从末维向前对齐，每维"相等或其一为 1 或缺席" | 结果逐维取最大；`(n,)` 加到 `(n,m)` 是按行不是按列 |
| 3 | 沿 axis 聚合后该维消失：`shape (d0..dk..) --sum(axis=k)--> (d0..d\hat{k}..)` | `keepdims=True` 保留长度 1 维以便广播回原形 |
| 4 | 布尔掩码条件组合用 `& | ~` 并加括号 | `and/or` 触发数组真值歧义错误 |
| 5 | 向量化加速 1–2 个数量级（大数组） | 前提：数组足够大、无逐元素 Python 回调 |
| 6 | `default_rng(seed)` 显式随机流 | 同种子同序列；不要再用全局 `np.random.seed` 写新代码 |

## 4.8 示例与案例

### 案例 1：手算广播与轴聚合（数值算例）

给定 $A = \begin{pmatrix}1 & 2 & 3\\ 4 & 5 & 6\end{pmatrix}$，$v = (10, 20, 30)$。先手算，再验证：

1. $A + v$：$v$ 形状 $(3,)$ 右对齐到 $(2,3)$ 的末维，逐行加上 $v$，结果 $\begin{pmatrix}11 & 22 & 33\\ 14 & 25 & 36\end{pmatrix}$；
2. $A + v[:, None]$：$v$ 变为 $(3,1)$，广播到 $(2,3)$ 需与 $(2,3)$ 右对齐比较——末维 3 vs 1 OK、次维 2 vs 3 失败，**报错**（这正是 4.2.4 错误 1 的现场）；
3. $A \cdot \mathbb{1}^\top$ 风格的按行均值：`A.mean(axis=1, keepdims=True)` 得 $(2,1)$，`A - A.mean(axis=1, keepdims=True)` 得按行中心化的矩阵 $\begin{pmatrix}-1 & 0 & 1\\ -1 & 0 & 1\end{pmatrix}$。

```python
A = np.array([[1., 2., 3.], [4., 5., 6.]])
v = np.array([10., 20., 30.])
print(A + v)
# 预期输出:
# [[11. 22. 33.]
#  [14. 25. 36.]]
centered = A - A.mean(axis=1, keepdims=True)
print(centered)
# 预期输出:
# [[-1.  0.  1.]
#  [-1.  0.  1.]]
```

### 案例 2：从零实现 softmax（轴 + 广播 + 数值稳定性的综合应用）

softmax 是深度学习每个分类模型都在用的函数，也是"轴心智模型"的完美试金石：

$$\mathrm{softmax}(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

数值稳定性：直接算 $e^{z_i}$ 在 $z_i$ 很大时溢出，利用 $\mathrm{softmax}(z) = \mathrm{softmax}(z - \max z)$ 减去最大值后再取指数。

```python
import numpy as np

def softmax(z: np.ndarray, axis: int = -1) -> np.ndarray:
    """数值稳定的 softmax。z: 任意形状；沿 axis 归一化。"""
    z = z - z.max(axis=axis, keepdims=True)          # 平移不变性，防溢出
    e = np.exp(z)
    return e / e.sum(axis=axis, keepdims=True)       # keepdims 让分母可广播

# 情形 1：单个样本（batch 版本）
logits = np.array([[2.0, 1.0, 0.1]])      # (1, 3)
p = softmax(logits, axis=-1)
print(p.round(4))                          # 预期输出: [[0.659 0.2424 0.0986]]
print(p.sum(axis=-1))                      # 预期输出: [1.]

# 情形 2：批量（4 个样本 x 3 类），沿最后一维（类维）归一化
rng = np.random.default_rng(seed=0)
batch_logits = rng.normal(size=(4, 3)) * 10   # 放大数值压力
pb = softmax(batch_logits, axis=-1)
print(pb.sum(axis=-1).round(6))            # 预期输出: [1. 1. 1. 1.] —— 每行和为 1
print(np.abs(pb).max() <= 1.0)             # 预期输出: True —— 无溢出（都是合法概率）

# 反例：丢掉 keepdims 会发生什么
try:
    bad = np.exp(batch_logits - batch_logits.max(axis=-1))
    _ = bad / bad.sum(axis=-1)
except ValueError as e:
    print(e)   # 预期输出: operands could not be broadcast together
               #          with shapes (4,3) (4,)
```

### 案例 3：数据清洗流水线（掩码 + 花式索引 + 聚合的综合）

```python
import numpy as np

rng = np.random.default_rng(seed=1)
n_students = 1000
hours = rng.uniform(0, 40, size=n_students)          # 每周学习时长
scores = (25 + 1.5 * hours + rng.normal(0, 8, n_students)).clip(0, 100)
missing = rng.random(n_students) < 0.05              # 5% 数据缺失
scores[missing] = np.nan                             # NaN 表示缺失

valid = ~np.isnan(scores)                            # 布尔掩码找有效样本
print(f"有效率: {valid.mean():.2%}")                  # 预期输出: 有效率: 95.10%（近似 95%）

clean_h, clean_s = hours[valid], scores[valid]       # 掩码筛选（拷贝，安全）
# 手动实现最小二乘斜率（呼应第 2 章案例 2，闭式解见《最优化方法》）：
x, y = clean_h - clean_h.mean(), clean_s - clean_s.mean()
slope = (x @ y) / (x @ x)
print(f"每小时学习提升分数: {slope:.2f}")             # 预期输出: 每小时学习提升分数: 1.51（接近真值 1.5）
print(f"时长前 10% 学生的平均分: {np.sort(clean_s)[-50:].mean():.1f}")  # 花式索引 top-k
# 预期输出: 时长前 10% 学生的平均分: 87.9（量级）
```

## 4.9 常见误区与陷阱

1. **切片当副本用**（第 1 章案例 2 的延续）。`train = data[:800]` 是视图；随后对 `data` 的任何原地操作（如归一化）会同步改掉 `train`。划分数据集后立刻 `train = data[:800].copy()` 是成本极低的安全带。
2. **`(n,)` 向量加到 `(n, m)` 上想按列加**。语义错位或恰好 `n == m` 时静默加错方向。判断口诀：想"每列加同一个数"就用 `[:, None]` 把向量立在列位置。
3. **`and/or/not` 接数组**。报 `The truth value of an array with more than one element is ambiguous`。用 `& | ~` 并给每个条件加括号。
4. **聚合后丢掉 keepdims 再除**。softmax/LayerNorm 类归一化的分母维度与分子不一致，轻则报广播错误，重则（恰好可广播时）按错误轴归一化——模型能训练但精度诡异。
5. **整数溢出与 dtype 静默截断**。`np.array([1, 2], dtype=np.int8) + 100` 得到 `-127`（溢出回绕）；`np.array([1.7, 2.3]).astype(np.int64)` 直接截断为 `[1, 2]`。跨 dtype 运算前显式 `astype(np.float64)` 是安全习惯。

## 4.13 课后思考与练习

1. **概念辨析**：`a[:, 0]` 与 `a[:, 0:1]` 的 shape 分别是什么？谁是谁的视图？为什么深度学习代码更常用后者？
2. **概念辨析**：`np.vstack([a, b])` 与 `a[None] + b[None]` 各自得到什么形状？哪个复制了内存？
3. **计算推导**：对 shape `(8, 4, 5)` 的数组，分别写出 `sum(axis=0)`、`max(axis=2)`、`mean(axis=(0, 2), keepdims=True)` 的结果 shape（校验值依次：`(4,5)`、`(8,4)`、`(1,4,1)`）。
4. **编程实现**：不使用 `np.linalg.norm`，用一次向量化计算矩阵 `X (n,d)` 每行的欧氏范数，并验证与 `np.linalg.norm(X, axis=1)` 逐元素一致（误差 < 1e-12）。
5. **编程实现**：实现成对欧氏距离矩阵 $D_{ij} = \|x_i - x_j\|_2$：先用双层循环写 `dist_loops`（n=200），再用广播 `x[:, None, :] - x[None, :, :]` 写 `dist_vec`，用 4.5 节的 `bench` 测加速比并验证两者 `allclose`。校验值：n=200 时加速比应达 10x 以上。
6. **编程实现**：给 4.8 节案例 3 补上"用中位数替代缺失值"的版本（`np.nanmedian`），对比两种填充策略下斜率估计的差异并解释原因。
7. **编程实现**：实现函数 `standardize(X: np.ndarray) -> np.ndarray`：按列标准化（减均值除标准差），处理全零列（标准差置 1），并用 mypy/注解标明输入输出 shape 约定。构造含一列常数的数据验证不产生 NaN。
8. **开放思考**：为什么 `a.T @ a`（`a` 为 1000×1000）比 `sum(a[:, i] * a[:, j] for ...)` 快三个数量级？从内存布局（连续 vs strided）、解释器开销、BLAS 并行三个角度各写一句话。
9. **挑战题**：实现带数值稳定性的 log-softmax：`log_softmax(z) = z - max(z) - log(sum(exp(z - max(z))))`，并用 $\log(\mathrm{softmax}(z))$ 与直接调用你的函数在 $z \sim 1000$ 量级下对比（直接版应产生 `-inf`/NaN，稳定版正常）。交叉熵损失（`-log_softmax(z)[y]`）即《深度学习》分类任务的核心。
