# 第 5 章 Pandas 与数据整理

> **本章定位**：真实世界的数据从不以干净的 ndarray 出现——有缺失、有重复、有混合类型、有分组结构。Pandas 是把"脏表格"变成"可计算数组"的标准工具，也是实验记录分析（《实验设计与评估》）与特征工程（《数据工程》）的日常语言。前置要求：第 4 章 NumPy（DataFrame 底层即 ndarray 块）；本章为第 6 章（可视化消费 DataFrame）与《数据工程》铺垫。

## 5.0 本章学习目标

学完本章，你能够：

3. 系统处理缺失值（检测、删除、填充）并说明每种选择的统计代价；

6. 用方法链风格完整清洗分析一个真实风格的实验数据集，产出可复现的报告数据。

## 5.1 Series 与 DataFrame

### 5.1.1 两个核心对象

- **Series**：一列数据 = ndarray 值 + Index（行标签）。Index 是 Pandas 区别于 NumPy 的核心：数据可按标签对齐，而非仅按位置。
- **DataFrame**：共享同一 Index 的多列 Series 的字典。每列 dtype 可不同（对比 ndarray 的同质性）。

```python
import pandas as pd
import numpy as np

s = pd.Series([1.5, 2.5, 3.5], index=["a", "b", "c"], name="depth")
print(s)
# 预期输出:
# a    1.5
# b    2.5
# c    3.5
# Name: depth, dtype: float64

df = pd.DataFrame({
    "model": ["A", "B", "C"],
    "acc": [0.91, 0.87, 0.93],
    "latency_ms": [12.1, 3.4, 25.7],
})
print(df.dtypes)
# 预期输出:
# model         object
# acc          float64
# latency_ms   float64
# dtype: object
```

索引对齐是 Pandas 最强的暗能力：两个 Series 相加按**标签**对齐，标签不重合处产生 NaN——这在合并多个实验日志时是自动对齐的天使，在无意混用不同索引时是悄悄生产 NaN 的魔鬼（陷阱 3）。

### 5.1.2 索引与选择：loc / iloc / []

| 操作 | 语义 | 示例 |
|---|---|---|
| `df.loc[行标签, 列标签]` | 按**标签**（含切片含端点） | `df.loc[0:2, ["model", "acc"]]` |
| `df.iloc[行位置, 列位置]` | 按**整数位置**（切片不含端点） | `df.iloc[0:2, 0:2]` |
| `df[布尔Series]` | 布尔过滤 | `df[df.acc > 0.9]` |
| `df["acc"]` / `df.acc` | 取列（Series） | 注意 `df.acc` 在列名与方法名冲突时失效 |

```python
print(df.loc[df.acc > 0.9, "model"])
# 预期输出:
# 0    A
# 2    C
# Name: model, dtype: object

print(df.iloc[-1])              # 预期输出: model         C \n acc       0.93 ...（一行 Series）
print(df.assign(ratio=df.acc / df.latency_ms).round(3))
# 预期输出（新增列 ratio）:
#   model   acc  latency_ms  ratio
# 0     A 0.91        12.1  0.075
# 1     B 0.87         3.4  0.256
# 2     C 0.93        25.7  0.036
```

**铁律**：链式索引 `df[df.acc > 0.9]["model"] = "X"` 修改的可能只是临时副本（`SettingWithCopyWarning`）；赋值必须一步到位：`df.loc[df.acc > 0.9, "model"] = "X"`。这是 Pandas 头号经典坑。

## 5.2 缺失值处理

### 5.2.1 检测与机制

Pandas 用 `NaN`（浮点）与 `pd.NA`（可空扩展类型）表示缺失；`isna()`/`notna()` 检测，聚合函数默认**跳过** NaN（`skipna=True`）。

```python
raw = pd.DataFrame({
    "run": [1, 2, 3, 4, 5],
    "acc": [0.90, np.nan, 0.88, 0.92, np.nan],
    "gpu_hours": [1.2, 1.1, np.nan, 1.3, 1.0],
})
print(raw.isna().sum())
# 预期输出:
# run          0
# acc          2
# gpu_hours    1
# dtype: int64
```

### 5.2.2 三种策略与统计代价

1. **删除** `dropna()`：无偏但损失样本；缺失率低（<5%）且随机时安全，缺失与结果相关时会引入偏差。
2. **填充** `fillna(v)` / `interpolate()`：常数填充歪曲分布；均值填充压低方差；时序数据用前向填充 `ffill` 或插值更合理。
3. **标记**：新增 `is_missing` 布尔列，让下游模型自己学习"缺失模式"（《机器学习》特征工程的正规做法）。

```python
print(raw.dropna())
# 预期输出: 只剩 run=1,4 两行
print(raw.assign(acc_missing=raw.acc.isna()).fillna({"acc": raw.acc.mean()}).round(3))
# 预期输出: acc 缺失处填均值 0.90；新增标记列 [False, True, False, False, True]
```

原则（《实验设计与评估》将展开）：**填充策略必须在训练集上统计、再应用到验证/测试集**，否则造成数据泄漏。

## 5.3 groupby：拆分-应用-合并

### 5.3.1 心智模型与基本用法

`groupby` 实现统一的 **split-apply-combine**：按键拆分行 → 对每组应用聚合/变换/过滤 → 合并结果。

```python
df = pd.DataFrame({
    "model": ["A", "A", "B", "B", "B"],
    "seed": [0, 1, 0, 1, 2],
    "acc": [0.91, 0.89, 0.87, 0.88, 0.86],
})
g = df.groupby("model")["acc"]
print(g.mean())
# 预期输出:
# model
# A    0.90
# B    0.87
# Name: acc, dtype: float64

print(g.agg(["mean", "std", "count"]).round(4))
# 预期输出:
#        mean       std  count
# model
# A     0.90  0.014142      2
# B     0.87  0.010000      3
```

`std` 直接给出"多种子实验的标准差"——第 6 章误差棒的数据来源。

### 5.3.2 transform 与 filter：组内操作

`agg` 把每组缩成一个数；`transform` 输出与原表同长（组内广播）；`filter` 丢弃整组：

```python
df["acc_z"] = df.groupby("model")["acc"].transform(lambda x: (x - x.mean()) / x.std())
print(df.round(3))
# 预期输出（组内 z 分数列）:
#   model  seed   acc  acc_z
# 0     A     0  0.91  0.707
# 1     A     1  0.89 -0.707
# 2     B     0  0.87  0.000
# 3     B     1  0.88  1.000
# 4     B     2  0.86 -1.000
```

## 5.4 merge 与 join

### 5.4.1 连接类型

```python
runs = pd.DataFrame({"run_id": [1, 2, 3], "model": ["A", "B", "A"]})
hparams = pd.DataFrame({"model": ["A", "B", "C"], "lr": [1e-3, 1e-4, 1e-2]})

print(runs.merge(hparams, on="model", how="left"))
# 预期输出:
#    run_id model      lr
# 0       1     A  0.0010
# 1       2     B  0.0001
# 2       3     A  0.0010

print(runs.merge(hparams, on="model", how="inner"))
# 预期输出: 与上例相同（C 无 run 记录被剔除）

print(runs.merge(hparams, on="model", how="outer"))
# 预期输出: 额外出现 model=C、run_id=NaN 的一行
```

- `how="left"`：保留左表全部（"每条实验记录都带上超参数"的默认选择）；
- `how="inner"`：只留交集（谨慎：静默丢数据）；
- `how="outer"`：并集（补 NaN）。
- 键重名时用 `suffixes=("_train", "_test")`；两表键不唯一时 merge 会**笛卡尔积式爆炸**——merge 前先 `duplicated()` 检查键唯一性。

### 5.4.2 `concat` 与索引对齐

`pd.concat([df1, df2])` 纵向堆叠（多轮实验日志合并），`axis=1` 横向拼接（按 Index 对齐——不是按行位置！），`ignore_index=True` 重排行号。

## 5.5 时间序列基础

实验日志与传感器数据都带时间戳。Pandas 的三件套：

```python
ts = pd.DataFrame({
    "time": pd.date_range("2026-01-01", periods=6, freq="D"),
    "value": [1.0, 2.0, np.nan, 4.0, 5.0, 60.0],
}).set_index("time")

print(ts.index.freq)                    # 预期输出: <Day>
print(ts["value"].interpolate().round(2))
# 预期输出: 缺失处线性插值为 3.0
print(ts["value"].rolling(3).mean().round(2))
# 预期输出: 前 2 个 NaN，随后 [2.33, 3.5, 4.5, 23.0]（含 60 这个离群值）

# 重采样：按 3 天窗口取均值（降采样）
print(ts["value"].resample("3D").mean().round(2))
# 预期输出: [2.0, 4.5, 60.0]（第三窗只有 60 本身）
```

要点：`set_index` 后时间成为 Index，`resample`（分组聚合的时序版）、`rolling`（滑动窗口）、`shift`（取昨日值，构造滞后特征）覆盖了时序特征工程 80% 的日常需求。离群值检测（如 60）可先 `describe()` 观察，再用分位数截断。

## 5.6 方法链风格

把嵌套调用写成从上到下的"流水线"，每步一行、可读可注释——Pandas 社区推荐的风格（灵感来自 R 的 dplyr）：

```python
result = (
    raw
    .assign(acc_filled=lambda d: d.acc.fillna(d.acc.mean()))
    .query("gpu_hours > 1.0")
    .groupby("run", as_index=False)
    .agg(acc_mean=("acc_filled", "mean"), gpu=("gpu_hours", "first"))
    .sort_values("acc_mean", ascending=False)
    .reset_index(drop=True)
)
```

配套技巧：`query("acc > 0.9")` 替代布尔长表达式；`assign` 替代多步 `df["new"] = ...`；`.pipe(fn)` 接入自定义函数。**风格约定**：方法链中不要有隐式副作用（就地修改），保证每个中间结果可单独检查——这也是第 7 章可测试性的前提。

## 5.7 关键公式速查

| # | 规则 | 适用条件与备注 |
|---|---|---|
| 1 | Series = ndarray + Index；运算按标签对齐 | 索引不重合处产生 NaN；合并日志前先统一索引 |
| 2 | 赋值只用一步式 `df.loc[mask, col] = v` | 链式索引赋值触发 `SettingWithCopyWarning`，可能静默失败 |
| 3 | 聚合默认 `skipna=True` | 全 NaN 列的 `mean` 结果为 NaN 而非报错；`dropna` 前先看缺失率与缺失机制 |
| 4 | groupby：`agg` 缩短、`transform` 保长、`filter` 丢组 | 组内标准化/占比用 `transform` |
| 5 | merge 的 `how` 决定行存活；键不唯一则行数爆炸 | merge 前对两表键做 `duplicated()` 检查 |
| 6 | 时序三件套 `resample`/`rolling`/`shift` | 需要 DatetimeIndex；重采样统计的是每窗聚合值 |

## 5.8 示例与案例

### 案例 1：手算一次 groupby-merge 流程（数值算例）

给定两张表（先在纸上算，再运行验证）：

```
scores:  student subject score        weights: subject  weight
         s1      math    80                      math      0.6
         s1      eng     90                      eng       0.4
         s2      math    60
         s2      eng     70
```

加权总分 = merge 后按学生分组、对 `score*weight` 求和：s1 = 80×0.6 + 90×0.4 = **84**；s2 = 60×0.6 + 70×0.4 = **64**。

```python
import pandas as pd

scores = pd.DataFrame({
    "student": ["s1", "s1", "s2", "s2"],
    "subject": ["math", "eng", "math", "eng"],
    "score": [80, 90, 60, 70],
})
weights = pd.DataFrame({"subject": ["math", "eng"], "weight": [0.6, 0.4]})

out = (
    scores.merge(weights, on="subject")
    .assign(weighted=lambda d: d.score * d.weight)
    .groupby("student", as_index=False)["weighted"].sum()
)
print(out)
# 预期输出:
#   student  weighted
# 0      s1      84.0
# 1      s2      64.0
```

### 案例 2：完整清洗分析一个真实风格的实验数据集

模拟一份"乱"的模型对比实验日志：多个模型 × 多个种子，含缺失、重复行、字符串数字、时间戳。以下代码自足可运行：

```python
import io
import pandas as pd
import numpy as np

csv_text = """timestamp,model,seed,accuracy,latency_ms,notes
2026-06-01 10:00,ResNet,0,91.2,12.1,
2026-06-01 11:00,ResNet,1,90.8,11.9,
2026-06-02 09:00,ResNet,2,,12.5,gpu crash
2026-06-02 10:00,ViT,0,93.4,"28,0",        <- 千分位逗号
2026-06-02 11:00,ViT,1,93.9,27.8,
2026-06-03 09:00,ViT,1,93.9,27.8,           <- 整行重复
2026-06-03 10:00,MLP,0,87.1,2.2,
2026-06-03 11:00,MLP,1,86.9,2.1,
"""

df = pd.read_csv(io.StringIO(csv_text), parse_dates=["timestamp"])

clean = (
    df
    .drop_duplicates()                                  # 去重复行
    .assign(
        latency_ms=lambda d: pd.to_numeric(
            d.latency_ms.astype(str).str.replace(",", ""), errors="coerce"),
    )
    .dropna(subset=["accuracy"])                        # 目标列缺失则删（本例删 1 行）
    .query("100 >= accuracy >= 0")                      # 合法性检查
    .reset_index(drop=True)
)
print(clean[["model", "seed", "accuracy", "latency_ms"]])
# 预期输出（8 行去 2 行剩 6 行）:
#     model  seed  accuracy  latency_ms
# 0  ResNet   0.0      91.2        12.1
# 1  ResNet   1.0      90.8        11.9
# 2     ViT   0.0      93.4        28.0
# 3     ViT   1.0      93.9        27.8
# 4     MLP   0.0      87.1         2.2
# 5     MLP   1.0      86.9         2.1

summary = (
    clean
    .groupby("model")
    .agg(acc_mean=("accuracy", "mean"),
         acc_std=("accuracy", "std"),
         latency=("latency_ms", "mean"),
         n=("accuracy", "count"))
    .assign(acc_std=lambda d: d.acc_std.fillna(0).round(3),   # 单种子组 std 为 NaN
            efficiency=lambda d: (d.acc_mean / d.latency).round(3))
    .sort_values("acc_mean", ascending=False)
    .reset_index()
)
print(summary)
# 预期输出:
#     model  acc_mean  acc_std  latency     n  efficiency
# 0     ViT      93.65    0.354  27.9000     2       3.357
# 1  ResNet      91.00    0.283  12.1667     2       7.479
# 2     MLP      87.00    0.141  2.1500     2      40.465
```

`summary` 表正是第 6 章误差棒曲线（`acc_mean ± acc_std`）的直接输入，也是《实验设计与评估》"消融实验报告表"的雏形。注意清洗决策都留下了**痕迹**（每步一行、可单独检查），这是可复现性的最低要求。

## 5.9 常见误区与陷阱

1. **链式赋值静默失败**。`df[df.a > 0]["b"] = 1` 改的是临时副本，原表不变且只给一个 warning。一律用 `df.loc[mask, "b"] = 1`。
2. **迭代代替向量化**。`for i, row in df.iterrows(): total += row.x` 比 `df.x.sum()` 慢 100–1000x（iterrows 每行构造一个 Series）。能用列运算/`agg` 就不要逐行循环。
3. **忘记索引对齐**。两个来自不同日志的 DataFrame 相加/concat 时，Index 不重合处自动补 NaN；合并前 `reset_index(drop=True)` 或确认 Index 语义，是比事后 `dropna` 更可靠的习惯。
4. **merge 键不唯一**。左表 5 行 × 右表某键出现 3 次 = 该键生成 15 行。现象是"行数比输入多"，检查 `len(before) vs len(after)` 与 `validate="one_to_one"` 参数。
5. **在清洗中泄漏测试集信息**。用全表均值填充缺失、用全表统计做归一化，把测试集信息带进了训练（《机器学习》数据泄漏一节的主题）。正确流程：`fit` 在 train、`transform` 应用到 val/test——sklearn 的 `ColumnTransformer` 把这个纪律固化成了 API。

1. **概念辨析**：`df.loc[2]`、`df.iloc[2]` 在默认 RangeIndex 下结果相同，何时不同？构造一个 Index 为 `["a","b","c"]` 的例子说明。
2. **概念辨析**：为什么 `df.groupby("model")["acc"].transform("mean")` 的结果行数与 `df` 相同而 `.agg("mean")` 不同？各适合什么任务？
3. **计算推导**：对案例 2 的 `summary`，手算 ViT 的 `acc_std`（样本标准差，除以 $n-1$）。校验值：约 0.354。
4. **编程实现**：构造含缺失值的两列 DataFrame，分别用"删除行""均值填充""组内中位数填充（groupby + transform）"三种策略处理，输出三种策略下的列均值与方差对比表。
5. **编程实现**：把 5.8 节案例 2 的清洗管道封装为函数 `clean_experiment_log(csv_path: str) -> pd.DataFrame`，并用人为构造的脏输入（重复行、缺失、千分位逗号）断言：输出行数、无 NaN 目标列、latency 全为正数。
6. **编程实现**：用 5.5 节的时间序列数据，构造滞后特征 `value_lag1 = value.shift(1)` 与 3 日滚动均值特征，输出前 6 行验证。
7. **编程实现**：两表 merge：订单表（1000 行，customer_id 可重复）与客户表（500 行唯一）。用 `validate="many_to_one"` 防呆，并故意把客户表造出重复键，观察 merge 报错信息并粘贴为输出。
8. **开放思考**：案例 2 中"目标列 accuracy 缺失即删行"与"特征列缺失即填充"是两种不同决策。说明为什么目标缺失通常删、特征缺失可填（提示：训练时目标缺失的样本无法提供监督信号）。
9. **挑战题**：实现分块读取下的全局均值：`read_csv(chunksize=...)` 逐块累加 $n$ 与 $\sum x$，最后合成均值；再证明分块方差合并公式 $s^2 = \frac{\sum_i (n_i - 1)s_i^2 + \sum_i n_i(\bar x_i - \bar x)^2}{N-1}$ 并编程验证（与全量 `var()` 一致，误差 < 1e-9）。
10. **挑战题**：用 Polars 或 DuckDB 重写案例 2 的清洗汇总管道，对 1000 万行合成数据对比 Pandas 与其耗时/内存（预期：列式引擎快 2–5x），写 200 字总结何时值得迁移。
