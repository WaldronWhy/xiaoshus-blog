## 14.1 竞赛工具选型决策

### 14.1.1 三件工具的画像

| 维度 | MATLAB | LINGO | Python（见第 15 章） |
|---|---|---|---|
| 强项 | 矩阵计算、微分方程数值解、图像处理、仿真 | 线性/整数规划建模效率极高，灵敏度报告开箱即用 | 数据清洗、机器学习、爬虫、可视化、生态最全 |
| 弱项 | 机器学习代码冗长；授权体积大 | 只做优化，数据处理和绘图能力弱 | 优化求解器默认精度/性能弱于商业求解器（可接 Gurobi/COPT） |
| 典型题型 | 微分方程/物理过程类（A 型题）、图像类（C 题数据）、蒙特卡洛 | 资源分配/选址/排班等纯优化题（B/C 型题） | 数据分析类（C 题）、统计与机器学习题 |
| 上手时间 | 有 C 语言基础约 2 天 | 半天（语法接近数学式子） | 已有 Python 基础约 2 天 |

### 14.1.2 选型决策树

拿到赛题后按以下顺序判断（可与[第 17 章](/xiaoshus-blog/textbooks/modeling/04-practice/17/)的三人分工配合）：

1. **模型是优化问题且以线性/整数约束为主？** → LINGO 最快：数学式子几乎可以直接抄进去，且灵敏度报告是论文"模型检验"环节的现成素材。
2. **模型核心是微分方程、图像处理、控制过程或大规模数值仿真？** → MATLAB：`ode45/ode15s`、图像工具箱、PDE 工具箱没有同等效率的替代品。
3. **题目给了大量数据要清洗、统计、机器学习建模？** → Python（第 15 章）：pandas + sklearn 的工作流最顺。
4. **混合情形（最常见）**：数据用 Python 清洗导出 CSV，优化核心用 LINGO/MATLAB 求解，出图用 MATLAB 或 Python。**不要强求单一工具**，但每个子任务的输入输出格式要事先约定。

> **实战经验**：评委不看你用什么软件，只看模型与结果。选型的唯一标准是"哪个工具能让队伍在剩余 40 小时内最可靠地得到可验证的结果"。队伍赛前应统一主工具并各自练熟，赛场上换工具是大忌。

### 14.1.3 交叉验证：竞赛中的"双求解器"习惯

对同一核心模型，最好用两个工具各求解一次：结果一致则可放心写进论文；不一致则说明至少一方建模有错（常见于约束符号、单位换算）。本章 14.5 节的主案例就是"同一问题、两个求解器"的完整对照。第 5 章已给出同一问题的 Python（`scipy.optimize.linprog`）实现，可作第三方验证。

## 14.2 MATLAB 速成

### 14.2.1 矩阵操作与向量化

MATLAB 的名字即"矩阵实验室"（Matrix Laboratory），一切变量默认是矩阵。竞赛中最常用的操作：

```matlab
%% MATLAB 语法示例（需 MATLAB 环境）
A = [2 1 1; 1 3 2; 1 0 4];      % 分号换行、空格/逗号分隔列
b = [8; 13; 12];
x = A \ b;                       % 左除：解 Ax=b，等价于 inv(A)*b 但更快更稳
A .* A                           % 逐元素乘（点运算）：务必区分 * 与 .*
A(1, :)                          % 第 1 行；A(:, 2) 第 2 列；end 表示末尾
A(A > 2) = 0                     % 逻辑索引：一行完成"把大于 2 的元素置零"
C = [A, b]                       % 拼接矩阵（逗号横向、分号纵向）
```

**向量化（vectorization）**是 MATLAB 提速与简洁的关键：能不用 for 循环就不用。

```matlab
%% 反例：for 循环算 1..n 的平方和（慢、啰嗦）
s = 0; for k = 1:1e6, s = s + k^2; end
%% 正解：向量化（快一个数量级以上）
n = 1e6; s = sum((1:n).^2);      % .^ 是逐元素幂
%% 建模场景：n 个配送点两两距离矩阵（无循环）
pts = [0 0; 3 4; 1 1];           % 3 个点
D  = sqrt(sum((permute(pts,[1 3 2]) - permute(pts,[3 1 2])).^2, 3));
```

微分方程、偏微分方程数值解的 MATLAB 用法见[第 2 章](/xiaoshus-blog/textbooks/modeling/01-foundations/02/)（`ode45` 求解传染病模型）与[第 13 章](/xiaoshus-blog/textbooks/modeling/02-methods/13/)（蒙特卡洛仿真）。

### 14.2.2 脚本与函数

- **脚本（script）**：`main.m`，从上到下顺序执行，适合一次性分析。
- **函数（function）**：文件名必须与函数名一致，首行 `function [输出] = 名(输入)`，适合被多处调用的模型模块（如目标函数、灵敏度子程序）。

```matlab
%% 文件 profit.m（需 MATLAB 环境）
function pi = profit(d, Q, p, c, s)
% 单日报纸/奶茶利润：d 实际需求, Q 订货量（被第 15 章主案例的报童模型使用）
sold = min(d, Q);  over = max(0, Q - d);
pi = p * sold + s * over - c * Q;
end
```

竞赛建议：一个赛题一个文件夹，`main.m` 串联全部流程，子函数分文件存放；论文附录只贴 `main.m` 与核心函数。

### 14.2.3 常用工具箱

**（1）Optimization Toolbox**——对应第 5 章全部规划模型：

```matlab
%% 线性规划（需 MATLAB + Optimization Toolbox）
% min c'x  s.t.  A_ub x <= b_ub, A_eq x = b_eq, lb <= x <= ub
c = [-3; -5]; A_ub = [0 2; 3 2; 1 0]; b_ub = [12; 18; 4];
opts = optimoptions('linprog', 'Algorithm', 'dual-simplex');
[x, fval, exitflag, output] = linprog(c, A_ub, b_ub, [], [], zeros(2,1), [], opts);
% 注意：linprog 只做最小化，最大化问题目标系数取负（同 scipy，见第 5 章 例 5.2）
% lambda 为对偶变量（影子价格）：output 结构之外用
% [x, fval, lambda] = linprog(...) 后读 lambda.ineqlin

%% 整数规划：分支定界 + 割平面
intcon = 1:2;                          % 哪些变量取整数
[x, fval] = intlinprog(c, intcon, A_ub, b_ub, [], [], zeros(2,1), [], opts);

%% 非线性规划：fmincon（梯度类算法，SQP/内点）
% min f(x) s.t. c(x)<=0, ceq(x)=0, lb<=x<=ub
fun = @(x) (x(1)-2)^2 + (x(2)-2)^2;
nlc  = @(x) deal(x(1) + x(2) - 3, []);           % 非线性约束需返回 [c, ceq]
x0 = [0; 0];
[x, fval] = fmincon(fun, x0, [], [], [], [], zeros(2,1), [], nlc);
```

## 14.3 LINGO 建模语言

LINGO 的最大特点是**建模语言接近数学书写**：你几乎把论文里的模型原样敲进去，它负责生成并调用单纯形/分支定界求解。完整模型由四段组成，顺序为：

```
MODEL:
  TITLE 标题;
  SETS:       ! 集合段——定义下标对象（相当于数学模型的 Σ、∀ 的下标）;
  ENDSETS
  DATA:       ! 数据段——给集合属性赋值（参数与数据分离，改数据不改模型）;
  ENDDATA
  [INIT: ... ENDINIT]          ! 可选：初值段
  目标函数与约束;               ! 目标与约束段——直接写数学式
END
```

### 14.3.1 集合段（SETS）与数据段（DATA）

LINGO 的核心抽象是**集合（set）**。派生集合（derived set）由基本集合派生，天然表达"二维下标" $c_{ij}$ 这类结构：

```lingo
! 需 LINGO 环境 —— 运输问题（产地-销地）模型骨架
MODEL:
SETS:
  PLANT /1..3/: CAP;            ! 基本集合：3 个产地，属性 CAP(产量)
  SHOP  /1..4/: DEM;            ! 基本集合：4 个销地，属性 DEM(需求)
  LINKS(PLANT, SHOP): C, X;     ! 派生集合：单位运价 C(i,j) 与运量 X(i,j)
ENDSETS
DATA:
  CAP = 30 25 20;
  DEM = 15 17 22 12;
  C   = 6 2 6 7
        4 9 5 3
        8 8 1 5;
ENDDATA
```

### 14.3.2 目标与约束段：@SUM 与 @FOR

集合运算函数 `@SUM`（求和）与 `@FOR`（逐元素约束）负责把数学式的 $\sum$ 与 $\forall$ 翻译成代码：

```lingo
! 接上例 —— 目标：min 总运费 Σ_i Σ_j c_ij x_ij
MIN = @SUM(LINKS(i,j): C(i,j) * X(i,j));
! 约束 1：各产地运出量不超过产量
@FOR(PLANT(i): @SUM(SHOP(j): X(i,j)) <= CAP(i));
! 约束 2：各销地到货量满足需求
@FOR(SHOP(j):  @SUM(PLANT(i): X(i,j)) >= DEM(j));
END
```

注意 LINGO 默认变量非负，故不必写 `X >= 0`。常用集合函数还有 `@MAX`、`@MIN`、`@SIZE`；常用整数界定函数：`@BIN(x)`（0-1 变量）、`@GIN(x)`（整数变量）、`@BND(L, x, U)`（上下界）。

### 14.3.3 线性规划实例

将第 5 章例 5.2 的生产计划模型（max z = 3x₁ + 5x₂，设备 2x₂ ≤ 12，原料 3x₁ + 2x₂ ≤ 18，市场 x₁ ≤ 4）原样写入 LINGO：

```lingo
! 需 LINGO 环境 —— 例 5.2 工厂生产计划（与第 5 章 scipy 结果对照）
MODEL:
TITLE 生产计划;
MAX = 3*X1 + 5*X2;              ! 目标：max z = 3x1 + 5x2;
2*X2 <= 12;                     ! 设备台时;
3*X1 + 2*X2 <= 18;              ! 原料;
X1 <= 4;                        ! 市场容量;
END
```

运行后在 **Solution Report** 中得到：`Objective value: 36.00000`，`X1 = 2.000000, X2 = 6.000000`——与第 5 章 `scipy.optimize.linprog` 的结果完全一致（x\* = [2, 6]，z\* = 36）。

### 14.3.4 整数规划实例与"四舍五入"陷阱

LINGO 用 `@GIN`/`@BIN` 声明整数变量。下面是经典反例（Taha《运筹学导论》同款）：**LP 松弛解四舍五入不可行**，展示为什么整数规划必须用分支定界（第 5.4 节）：

```lingo
! 需 LINGO 环境 —— 整数规划：LP 松弛解舍入不可行
MODEL:
TITLE LP松弛陷阱;
MAX = 40*X1 + 90*X2;
9*X1 + 7*X2  <= 56;
7*X1 + 20*X2 <= 70;
@GIN(X1);  @GIN(X2);            ! 整数变量;
END
```

- 去掉 `@GIN` 两行（LP 松弛）：最优解 x\* = (4.809, 1.817)，z\* = 355.876；
- 四舍五入 (5, 2)：违反第一条约束（45 + 14 = 59 > 56），**不可行**；
- 整数最优：x\* = (4, 2)，z\* = 340。

另一个 0-1 规划骨架（选址/背包常用）：

```lingo
! 需 LINGO 环境 —— 0-1 背包：n 件物品选总重不超 W、价值最大
MODEL:
SETS:
  ITEM /1..8/: W, V, Y;         ! Y(i)=1 表示选第 i 件;
ENDSETS
DATA:
  W = 3 5 2 7 4 1 6 3;
  V = 9 12 5 17 8 2 14 6;
  CAP = 15;
ENDDATA
MAX = @SUM(ITEM(i): V(i) * Y(i));
@SUM(ITEM(i): W(i) * Y(i)) <= CAP;
@FOR(ITEM(i): @BIN(Y(i)));
END
```

> **注意**：含整数变量的模型，LINGO **不输出灵敏度报告**（对偶信息在整数情形不再有效），只在纯 LP 中输出——这是竞赛论文里常见的低级失误来源。

### 14.3.5 灵敏度报告解读

纯 LP 求解后，菜单 **LINGO → Range**（或 SOLUTION 窗口勾选 Ranges）给出两张表。以上述生产计划模型为例，报告形如：

```text
Objective value:                36.00000
Variable          Value        Reduced Cost
   X1            2.000000           0.000000
   X2            6.000000           0.000000
Row              Slack or Surplus   Dual Price
   1             36.00000           1.000000      (目标行)
   2             0.000000           1.500000      (设备台时)
   3             0.000000           1.000000      (原料)
   4             2.000000           0.000000      (市场容量)
Ranges in which the basis is allowed to change:
Row       Current Coef   Allowable Increase   Allowable Decrease
   X1          3.000000          INFINITY           1.000000
   X2          5.000000          INFINITY           2.000000
   2          12.000000          8.000000           3.000000
   3          18.000000          2.000000           3.000000
   4           4.000000          INFINITY           2.000000
```

**逐项解读**（与第 5.2.3–5.2.4 节对偶理论一一对应）：

- **Dual Price（对偶价格）**：即影子价格。约束行 2（设备台时）的对偶价格 1.5 表示：设备台时上限 12 每增加 1，总利润增加 1.5；行 3（原料）为 1.0；行 4 的松弛量为 2（市场还剩 2 的余量），是不紧约束，影子价格 0——"紧缺的资源才值得付钱"。这与第 5 章 scipy 代码计算的影子价格 (1.5, 1.0, 0.0) 完全一致。
- **Reduced Cost（检验数/缩减成本）**：非基变量进基一个单位时目标的恶化量；最优基变量均为 0。
- **Allowable Increase / Decrease**：在不改变最优基的前提下，该行右端项（或目标系数）允许的增减幅度，即第 5.2.4 节"影子价格的有效区间"。例如原料行 18 的 Allowable Increase = 2：原料从 18 增到 20 之前影子价格恒为 1.0；超过 20 后最优基改变，需重新求解。第 5 章代码用参数扫描验证过同一区间（b₂ ∈ [15, 20]）。

论文写法建议：把影子价格解释成"资源的边际价值"并用一行经济含义说明（如"每增加 1 单位原料可增利 1 元，但最多增 2 单位"），这就是评委想看的"模型检验"。

## 14.4 关键公式与方法速查

| 方法/命令 | 适用场景 | 关键公式/调用 | 优缺点/坑 |
|---|---|---|---|
| `linprog` (MATLAB) | 线性规划 | `linprog(c, A_ub, b_ub, A_eq, b_eq, lb, ub)` | 只做最小化，max 需取负；`optimoptions` 选 dual-simplex 可给对偶 |
| `intlinprog` (MATLAB) | 整数/0-1 规划 | `intlinprog(c, intcon, ...)` | 整数解无灵敏度报告；Gap 容差默认 1e-4 需注意 |
| `fmincon` (MATLAB) | 非线性规划 | `fmincon(fun, x0, ...)`，初值 x0 敏感 | 凸性未知时需多初值（第 5.3 节） |
| `fit` (Curve Fitting) | 曲线拟合 | `fit(x, y, fittype, 'StartPoint', ...)` | 初值不当会收敛到坏解；先目测数据定初值 |
| LINGO 集合段 | 批量下标对象 | `SETS: P /1..n/: X;` | 派生集合才表达二维下标 |
| `@SUM/@FOR` (LINGO) | Σ 与 ∀ | `@SUM(LINKS(i,j): C*X)` | 约束漏写 `@FOR` 是新手第一坑 |
| `@BIN/@GIN` (LINGO) | 0-1/整数变量 | `@FOR(ITEM: @BIN(Y));` | 加整数变量后无 Range 报告 |
| LINGO Dual Price | 影子价格 | SOLUTION → Ranges | 仅纯 LP 有效；解释为资源边际价值 |
| `A\b` (MATLAB) | 解线性方程组 | `x = A\b` | 不要用 `inv(A)*b`（数值不稳定） |

## 14.5 典型例题与样例程序：同一优化问题的 MATLAB/LINGO 完整对照

按竞赛八股走一遍。本案例是[第 5 章例 5.2](/xiaoshus-blog/textbooks/modeling/02-methods/05/) 的"工具篇续集"：模型不再推导，重点展示两个工具的完整工程实现与结果交叉验证。

### 问题重述

某工厂每周生产甲、乙两种产品，消耗设备台时与原料，均有周上限；甲产品市场容量有限。问两种产品各生产多少，使周总利润最大。

### 模型假设与符号说明

（1）产量可分且线性关系成立（LP 假设，第 5 章已讨论其合理性）；（2）价格、单耗、上限在周内不变。设 $x_1, x_2$ 为甲、乙周产量（件），$z$ 为周利润（元）。

### 模型建立

$$\max z = 3x_1 + 5x_2,\qquad \text{s.t.}\;\; 2x_2 \le 12,\;\; 3x_1 + 2x_2 \le 18,\;\; x_1 \le 4,\;\; x_1, x_2 \ge 0.$$

### 求解（方案 A：MATLAB）

```matlab
%% 文件 case_ch11_matlab.m —— 例5.2 生产计划（需 MATLAB + Optimization Toolbox）
% 预期输出：x* = [2, 6]，z* = 36，影子价格 (1.5, 1.0, 0.0)
c    = [-3; -5];                          % max -> min 取负
A_ub = [0 2; 3 2; 1 0];  b_ub = [12; 18; 4];
lb   = zeros(2,1);
opts = optimoptions('linprog', 'Algorithm', 'dual-simplex');
[x, fval, exitflag, ~, lambda] = linprog(c, A_ub, b_ub, [], [], lb, [], opts);

fprintf('最优产量: 甲 %.4f 件, 乙 %.4f 件\n', x(1), x(2));
fprintf('最大周利润: %.4f 元\n', -fval);            % 取负还原
fprintf('影子价格(设备,原料,市场): %.2f %.2f %.2f\n', ...
        lambda.ineqlin);                          % 对偶变量即影子价格

% 灵敏度：原料上限 18 -> 19，利润应增加 lambda(2) = 1.0 元
b_ub2 = b_ub;  b_ub2(2) = 19;
[~, fval2] = linprog(c, A_ub, b_ub2, [], [], lb, [], opts);
fprintf('原料+1 后利润增量: %.4f 元（应等于原料影子价格）\n', -fval2 + fval);
```

### 求解（方案 B：LINGO）

```lingo
! 需 LINGO 环境 —— 文件 case_ch14.lg4
MODEL:
TITLE 工厂周生产计划;
MAX = 3*X1 + 5*X2;
! 约束可命名，便于灵敏度报告阅读;
[EQP] 2*X2   <= 12;       ! 设备台时;
[RAW] 3*X1 + 2*X2 <= 18;  ! 原料;
[MKT] X1     <= 4;        ! 市场容量;
END
```

### 结果与检验

两个工具输出对照表（论文可直接引用这种"交叉验证表"）：

| 项目 | MATLAB (`linprog`) | LINGO | 第 5 章 scipy `linprog` |
|---|---|---|---|
| 最优解 $(x_1^*, x_2^*)$ | (2, 6) | (2, 6) | (2, 6) |
| 目标值 $z^*$ | 36 | 36 | 36 |
| 影子价格（设备/原料/市场） | 1.5 / 1.0 / 0.0 | 1.5 / 1.0 / 0.0 | 1.5 / 1.0 / 0.0 |
| 原料 +1 的利润增量 | 1.0 | 1.0 | 1.0 |

三方面检验：（1）三工具结果一致，排除录入错误；（2）影子价格与"原料 +1 → 利润 +1"的扰动实验一致，验证对偶解释；（3）LINGO Range 报告显示原料行允许增加 2（18→20 内影子价格不变），与第 5 章参数扫描区间 [15, 20] 一致。

### 模型评价

优点：模型简单、影子价格有直接经济解释，可用于向厂方建议"值不值得买原料/租设备"。缺点：产量连续假设对不可分产品（整机）不成立——应加 `@GIN`/`intcon` 变成整数规划，但那时灵敏度报告失效，需改用扰动实验做灵敏度分析（成本：多花 10 分钟，收益：结论稳健）。改进方向：多产品多资源的情形用集合段（LINGO）或矩阵化约束（MATLAB/Python）组织，避免逐条手写约束。

## 14.6 常见误区与竞赛扣分点

1. **只给最终数字，不给求解工具与设置**。论文应注明求解器与关键选项（如"LINGO 19.0 求解，全局容差 1e-6"），否则不可复现。
2. **把 LP 的影子价格搬到整数规划里解释**。整数模型没有灵敏度报告；影子价格只对 LP（或 LP 松弛）有效。
3. **LINGO 约束漏写 `@FOR`**：把 `@FOR(PLANT(i): ...)` 写成单条约束，模型悄悄错解——LINGO 不报错，但答案全错。写完逐条对照数学式检查 ∀。
4. **非线性规划只跑一个初值**。`fmincon` 局部收敛，非凸问题必须多初值并行试（或用 `MultiStart`），论文中说明"取 100 个随机初值中最优"。
5. **没有交叉验证**。单一求解器的数值结果可能因建模笔误而错；双求解器对照（如本章 14.5）是最便宜的保险。
6. **图是截图的**。MATLAB 出图必须用 `exportgraphics` 导出矢量/300 dpi，直接截图在评委端放大即糊（图表规范详见第 16 章）。
7. **整数规划的"规模盲区"**：变量上千的 0-1 规划 LINGO 可能跑不完，提前测试规模，必要时改启发式/分解（与第 8 章网络优化结合）。

## 14.7 拓展延伸

- **MATLAB 全局优化工具箱**：`ga`（遗传算法）、`particleswarm`、`simulannealbnd`，用于非凸、不可导的目标（与第 13 章仿真模型联用）。
- **MATLAB App：Optimization / Curve Fitting App**：交互式拟合可在赛前快速探索数据形态，导出代码后并入脚本。
- **LINGO 概率函数**：`@PEB`（排队论 Erlang B）等内置概率函数可直接做排队系统容量设计，与[第 13 章](/xiaoshus-blog/textbooks/modeling/02-methods/13/)排队论衔接。
- **与 Python 融合**：MATLAB 官方提供 Python 接口（`matlab.engine`）；LINGO 可通过 `lingo.exe` 命令行 + `.lg4` 文件批处理调用，实现"Python 编排 + LINGO 求解"的流水线。
- **商业求解器**：Gurobi/COPT 均有 MATLAB/Python 接口，大规模 MILP 上远快于默认求解器；国赛规模一般用不到，美赛大数据题可考虑。
