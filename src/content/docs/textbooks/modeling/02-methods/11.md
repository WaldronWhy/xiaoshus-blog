# 第 11 章 主成分分析与降维

> **本章定位**：降维是处理"指标太多、彼此相关"的利器——竞赛里常遇到几十个评价指标、几十个影响因素，直接塞进模型会共线性爆炸、权重不可解释。主成分分析（Principal Component Analysis, PCA）把相关的多指标压缩成少数几个"综合指标"，既去冗余又保留大部分信息，是[第 6 章](/xiaoshus-blog/textbooks/modeling/02-methods/06/)综合评价的前处理标配，也是高维数据可视化的第一步。前置要求：协方差矩阵与特征值（[第 3 章](/xiaoshus-blog/textbooks/modeling/01-foundations/03/)）、标准化与回归基础（[第 4 章](/xiaoshus-blog/textbooks/modeling/01-foundations/04/)）。数据光滑见[第 9 章](/xiaoshus-blog/textbooks/modeling/02-methods/09/)。

## 11.0 本章学习目标

学完本章，你应当能够：

1. 解释 PCA 的几何直觉——"沿方差最大的方向投影"，并说清为什么要先标准化；
2. 走通算法全流程：标准化 → 协方差矩阵 → 特征值分解 → 主成分得分 → 按累计贡献率选 $k$；
3. 用 `sklearn.decomposition.PCA` 得到各主成分贡献率、载荷矩阵与样本综合得分；
4. 把 PCA 用于两处竞赛场景：① 降维后接 TOPSIS/聚类；② 直接由主成分贡献率构造客观权重；
5. 用碎石图（scree plot）和"85%/90% 累计贡献率"阈值决定保留几个主成分；
6. 指出 PCA 的局限：线性、主成分含义需谨慎解释、对异常值敏感。

## 11.1 为什么要降维

多指标数据常有两大毛病：

- **冗余**：指标之间高度相关（如"GDP"与"工业产值"），塞进模型浪费自由度还引发共线性；
- **维度灾难**：维数高时样本在空间中变得稀疏，距离度量失效、模型过拟合。

降维目标：在**尽可能少损失信息**的前提下把 $p$ 维压成 $k\ll p$ 维。PCA 是其中**无监督、线性**的代表方法。

## 11.2 主成分的思想：方差最大化

设标准化后的数据矩阵 $X\in\mathbb R^{n\times p}$（$n$ 样本、$p$ 变量，每列均值 0、方差 1）。PCA 寻找一组正交方向（主成分）使得投影后的方差依次最大：

- 第 1 主成分方向 $\mathbf w_1$ 是使 $\mathrm{Var}(X\mathbf w_1)$ 最大、且 $\|\mathbf w_1\|=1$ 的单位向量；
- 第 2 主成分在与前者正交的方向上方差最大，依此类推。

数学上，$\mathbf w_j$ 正是**样本协方差矩阵** $\Sigma=\frac1{n-1}X^TX$ 的第 $j$ 大特征值对应的单位特征向量。于是：

- 特征值 $\lambda_j$ 越大 → 该主成分承载的方差越多；
- **贡献率** $\eta_j=\lambda_j/\sum_i\lambda_i$，**累计贡献率** $\sum_{j=1}^k\eta_j$ 衡量前 $k$ 个主成分保留了多少总信息；
- 样本在第 $j$ 主成分上的**得分**为 $X\mathbf w_j$。

> 为什么先标准化？若量纲不同（如"人口(万)"与"增长率(%)"），协方差会被大数量级变量主导，PCA 退化成"谁数值大听谁的"。标准化让每个变量同尺度竞争。

## 11.3 算法步骤

1. **标准化**：$z_{ij}=(x_{ij}-\bar x_j)/s_j$，得到 $Z$；
2. **协方差矩阵**：$\Sigma=\frac1{n-1}Z^TZ$（标准化后也等于相关系数矩阵）；
3. **特征值分解**：$\Sigma\mathbf w_j=\lambda_j\mathbf w_j$，按 $\lambda_1\ge\lambda_2\ge\cdots$ 排序；
4. **选 $k$**：取使累计贡献率 $\ge 85\%$（常用阈值，也可 90%）的最小 $k$；
5. **算得分**：第 $i$ 样本主成分得分 $T_i=Z_i\mathbf W_{:,1:k}$，可进一步用贡献率加权得到综合得分 $S_i=\sum_{j=1}^k\eta_j T_{ij}$。

> **适用性检验（论文加分项）**：正式做 PCA 前建议先报告两项检验——**Bartlett 球形检验**（$H_0$：相关阵为单位阵，$p<0.05$ 说明变量间确有相关性、适合降维）与 **KMO 度量**（衡量偏相关强弱，一般 $>0.6$ 较宜）。若检验不通过，说明指标间相关性太弱，强行降维反而丢信息——评委常在这一步追问。

## 11.4 与综合评价结合

两条主线（与[第 6 章](/xiaoshus-blog/textbooks/modeling/02-methods/06/)衔接）：

- **降维后接评价**：把 $k$ 个主成分得分当新指标，再做 TOPSIS/聚类，规避共线性；
- **PCA 权重**：以各主成分贡献率为权重，对主成分得分加权得综合得分，作为客观评价排序依据（注意：这是"综合信息量"权重，不等同于 AHP/熵权的"重要性"权重，语义不同）。

## 11.5 关键公式与方法速查

| 项 | 公式 / 调用 | 说明 |
|---|---|---|
| 标准化 | $z=(x-\bar x)/s$ | 必须做，否则量纲主导 |
| 协方差阵 | $\Sigma=\frac1{n-1}Z^TZ$ | 标准化后=相关阵 |
| 主成分方向 | $\Sigma\mathbf w_j=\lambda_j\mathbf w_j$ | 特征向量 |
| 贡献率 | $\eta_j=\lambda_j/\sum\lambda$ | 越大越重要 |
| 累计贡献率 | $\sum_{j=1}^k\eta_j$ | $\ge85\%$ 选 $k$ |
| sklearn | `PCA().fit(Z)` | `explained_variance_ratio_`, `components_` |

## 11.6 典型例题与样例程序

**题目**：构造一个含 3 个潜在因子、映射成 8 个观测指标的数据集（指标间天然相关），用 PCA 提取主成分，确定保留个数，输出载荷矩阵并画出碎石图，最后算出每个样本的综合得分用于排序。

**模型假设**：8 个观测指标由 3 个潜在因子线性生成并叠加小幅噪声（模拟"指标高度相关"的真实评价场景）；样本独立同分布。

**符号说明**：$F\in\mathbb R^{60\times3}$ 为潜因子阵，$W\in\mathbb R^{3\times8}$ 为生成载荷阵，$X\in\mathbb R^{60\times8}$ 为观测阵，$Z$ 为标准化阵，$\eta_j$ 为第 $j$ 主成分贡献率。

```python
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
plt.rcParams["font.sans-serif"] = ["SimHei", "Microsoft YaHei"]  # 中文字体
plt.rcParams["axes.unicode_minus"] = False
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

np.random.seed(0)
F = np.random.randn(60, 3)                       # 3 个潜在因子
W = np.array([[0.9, 0.8, 0.1, 0.2, 0.7, 0.6, 0.3, 0.4],
              [0.1, 0.2, 0.9, 0.8, 0.3, 0.4, 0.7, 0.6],
              [0.2, 0.3, 0.1, 0.2, 0.1, 0.2, 0.1, 0.2]])
X = F @ W + np.random.randn(60, 8) * 0.05       # 8 个相关指标

Xs = StandardScaler().fit_transform(X)          # 先标准化
pca = PCA().fit(Xs)
evr = pca.explained_variance_ratio_

print("各主成分贡献率 =", np.round(evr, 3).tolist())
print("累计贡献率     =", np.round(np.cumsum(evr), 3).tolist())

k = 2                                            # 前 2 个主成分累计已极高
scores = Xs @ pca.components_[:k].T             # 样本主成分得分
w = evr[:k] / evr[:k].sum()                     # 贡献率加权
composite = scores @ w                          # 综合得分

print("前2主成分累计贡献率 =", round(float(np.cumsum(evr)[k - 1]), 4))
print("综合得分(前5样本)   =", np.round(composite[:5], 3).tolist())

loadings = pca.components_[:k]                  # 载荷矩阵：2 个主成分 × 8 个原变量
print("载荷矩阵(主成分×原变量) =")
print(np.round(loadings, 2))

# 碎石图：观察贡献率"骤降拐点"，辅助选 k
plt.figure(figsize=(6, 3.5))
plt.plot(range(1, 9), evr, "o-", label="单主成分贡献率")
plt.plot(range(1, 9), np.cumsum(evr), "s--", label="累计贡献率")
plt.axhline(0.85, color="gray", ls=":", lw=1)
plt.text(6.2, 0.87, "85% 阈值", fontsize=9, color="gray")
plt.xlabel("主成分序号"); plt.ylabel("贡献率")
plt.legend(); plt.tight_layout()
plt.savefig("ch11_scree.png", dpi=120)
print("碎石图已保存 ch11_scree.png")
```

**预期输出**（Python 3.13 / numpy 2.x / scikit-learn 1.x，取整后）：

```
各主成分贡献率 = [0.795, 0.199, 0.004, 0.001, 0.0, 0.0, 0.0, 0.0]
累计贡献率     = [0.795, 0.994, 0.998, 0.999, 0.999, 0.999, 1.0, 1.0]
前2主成分累计贡献率 = 0.9942
综合得分(前5样本)   = [2.544, 4.606, 0.456, 0.876, 0.826]
载荷矩阵(主成分×原变量) =
[[ 0.32  0.35  0.31  0.34  0.37  0.39  0.37  0.39]
 [-0.48 -0.38  0.5   0.4  -0.29 -0.16  0.3   0.13]]
碎石图已保存 ch11_scree.png
```

**结果解读**：前 2 个主成分就解释了 99.4% 的总方差，8 个冗余指标被压成 2 个综合维度——这正是降维价值。综合得分可直接用于样本排序或与 TOPSIS 衔接。碎石图（见生成的 `ch11_scree.png`）在第 2 个主成分处骤降、其后趋平，"拐点"与累计 85%/90% 阈值相互印证，是选 $k$ 的直观依据。载荷矩阵显示：第 1 主成分在全部 8 个变量上载荷同号且量级接近（0.31–0.39），可解读为"整体水平"因子；第 2 主成分在前 4 个与后 4 个变量上载荷符号相反（-0.48/-0.38/-0.5/-0.4 对 0.3/0.13 等），可谨慎解读为"两组指标的对比"维度——这正是 11.7 误区 3 所说的"看 $|\mathbf w_j|$ 大的变量、措辞留余地"。

**模型评价**：优点——数据生成机制已知（3 个潜因子），降维结果 2 维与之吻合，方法有效性有"标准答案"可对照；流程覆盖标准化、选 $k$、得分、载荷解读全链路，可直接迁移到真实赛题。缺点——合成数据相关性"过于干净"，真实数据累计贡献率不会如此整齐；未做 Bartlett/KMO 适用性检验。改进——对真实多指标数据先做 11.3 的适用性检验，再比较 PCA 降维前后 TOPSIS 排名的稳健性。

## 11.7 常见误区与竞赛扣分点

1. **不做标准化直接用 PCA**：量纲大的变量会"吞掉"其他变量，结论失真。先 `StandardScaler`。
2. **机械卡 85%/90%**：阈值应结合碎石图"拐点"与业务解释力，并非越大越好；有时为可解释性保留更少主成分更有说服力。
3. **硬解释主成分含义**：主成分是原变量的线性组合，载荷正负混合时强解"第 1 主成分代表 XX"易牵强。需要时看载荷矩阵 $|\mathbf w_j|$ 大的原变量，但措辞要留余地。
4. **把 PCA 权重当重要性权重**：PCA 权重反映"信息量占比"，与 AHP 的"专家重要性"、熵权的"区分度"语义不同，混用会自相矛盾（见[第 6 章](/xiaoshus-blog/textbooks/modeling/02-methods/06/)）。
5. **对异常值无防护**：PCA 基于二阶矩，离群点会严重拉偏方向；必要时先去异常值或用稳健 PCA。
6. **忽略主成分得分符号不唯一**：特征向量 $\mathbf w_j$ 与 $-\mathbf w_j$ 都是合法解，不同软件/版本可能给出符号相反的主成分得分，综合得分随之整体变号。排序结论（谁高谁低）不受影响，但**绝对分值与"正分=好"之类的解读会翻转**——论文中若报告综合得分，须固定符号约定（如规定第 1 主成分载荷之和为正）后再解读。

## 11.8 拓展延伸

- **核 PCA（Kernel PCA）**：处理非线性流形，适用于数据明显沿曲线/曲面分布；
- **因子分析 vs PCA**：因子分析假设"变量=公因子+特有因子"并建模误差，更偏"找潜在构念"；PCA 是纯方差压缩，竞赛里多为后者；
- **t-SNE / UMAP**：仅用于**可视化**的流形降维，不保证全局距离、不可用于后续建模输入——别把"能画图"当成"能降维建模"；
- **与聚类/评价组合**：PCA 降维 → K-Means 聚类 / TOPSIS 评价，是竞赛高频组合拳（见[第 9 章](/xiaoshus-blog/textbooks/modeling/02-methods/09/)前处理与[第 6 章](/xiaoshus-blog/textbooks/modeling/02-methods/06/)）。
