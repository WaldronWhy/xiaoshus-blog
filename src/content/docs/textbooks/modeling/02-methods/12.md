# 第 12 章 组合优化与启发式算法（TSP / VRP）

> **本章定位**：当赛题变成"安排走访所有城市的最短路线""调度若干车辆配送""排产调度"时，本质是**组合优化**——决策变量是离散的排列/分配，可行解数量随规模指数爆炸（NP-hard）。[第 5 章](/xiaoshus-blog/textbooks/modeling/02-methods/05/)的线性/整数规划与[第 8 章](/xiaoshus-blog/textbooks/modeling/02-methods/08/)的最短路/匹配能解小规模精确解，但一到几十个城市就力不从心。本章给出"建模 + 启发式"的竞赛解法：先用整数规划把问题写清楚，再用最近邻、2-opt、模拟退火、遗传算法在合理时间内拿到高质量解。前置要求：整数规划与 0-1 变量（[第 5 章](/xiaoshus-blog/textbooks/modeling/02-methods/05/)）、图的基本概念（[第 8 章](/xiaoshus-blog/textbooks/modeling/02-methods/08/)）。

## 12.0 本章学习目标

学完本章，你应当能够：

1. 识别赛题中的组合优化结构（TSP、VRP、调度、分配），并写出其整数规划形式；
2. 解释为什么精确法在 NP-hard 问题上会"算不动"，以及启发式/元启发式的取舍；
3. 实现最近邻（构造）+ 2-opt（局部搜索）+ 模拟退火（逃逸局部最优）三级递进的 TSP 解法；
4. 用"最优间隙（gap）"评估解质量：给出下界（如 TSP 的 1-树/线性规划松弛）或已知最优对比；
5. 把 VRP 建模为"多车辆 + 容量约束"的 TSP 变体，并说明其求解思路；
6. 指出竞赛常见坑：初始解太差、参数没调、不报解质量、把 NP-hard 当 LP 硬解。

## 12.1 问题界定：为什么需要启发式

**旅行商问题（TSP）**：给定 $n$ 个城市与两两距离 $d_{ij}$，求访问每个城市恰好一次并回到起点的最短回路。可行解数为 $(n-1)!/2$，$n=20$ 时已是 $10^{17}$ 量级，穷举不可能。

**车辆路径问题（VRP）**：多辆车从 depot 出发，服务若干客户，受车辆容量/时间窗约束，使总里程或总成本最小。是 TSP 的推广，更难。

这类问题的特征：**精确最优在大规模下不可得**，但"足够好且可证明不太差"的解在竞赛里完全够用——这就是启发式（heuristic）与元启发式（meta-heuristic，如模拟退火、遗传算法、禁忌搜索）的用武之地。

## 12.2 建模：TSP 与 VRP 的数学形式

**TSP 的 0-1 整数规划**（赋权完全图）：

$$
\min\sum_{i}\sum_{j\ne i} d_{ij}x_{ij}\quad\text{s.t.}\quad
\sum_{j\ne i}x_{ij}=1,\ \sum_{i\ne j}x_{ij}=1,\ \forall i;\quad
\text{消除子环（subtour elimination）}
$$

其中 $x_{ij}=1$ 表示路径从 $i$ 直连 $j$。子环消除有两种经典做法：**MTZ 约束**——引入排序变量 $u_i$（$u_1=1$，$2\le i\le n$），要求
$$
u_i-u_j+n\,x_{ij}\le n-1,\qquad 2\le i\ne j\le n,
$$
仅 $O(n^2)$ 条约束、便于直接交给求解器，但线性松弛较松；或**子环消除约束族** $\sum_{i\in S}\sum_{j\in S,\,j\ne i}x_{ij}\le|S|-1$（对每个真子集 $S$）——约束紧致但指数级，规模稍大即不可解，这正是必须用启发式的原因。

**容量约束 VRP（CVRP）** 在 TSP 基础上加：每辆车容量 $Q$、客户需求量 $q_i$、每辆车从 depot 出发并返回，约束 $\sum_{i\in\text{该车路线}}q_i\le Q$。建模为"多条容量受限回路"的联合优化。

## 12.3 启发式算法

| 算法 | 类型 | 思想 | 竞赛角色 |
|---|---|---|---|
| 最近邻（Nearest Neighbor） | 构造启发式 | 从一城出发，永远走到最近的未访城市 | 快速初始解 |
| 2-opt | 局部搜索 | 反复反转路径中的一段，直到不再变短 | 在初始解上精修 |
| 模拟退火（SA） | 元启发式 | 以概率接受变差解，温度递减逃出局部最优 | 求高质量解 |
| 遗传算法（GA） | 元启发式 | 种群交叉变异 + 选择，全局搜索 | 多起点、并行探索 |

实践铁律：**"最近邻拿初解 → 2-opt 精修 → SA/GA 再提升"** 三级递进，几乎总优于单用任一方法。

> **GA 求解 TSP 的三个核心算子**（配合上表使用）：① **编码**——路径直接用城市排列表示，如 `[3,0,7,...]`；② **交叉**——普通单点交叉会产生重复城市，须用**顺序交叉（OX）**：复制父代一段，另一父代按原顺序填入剩余城市；③ **变异**——随机交换两城或做一次 2-opt 反转。选择用锦标赛即可。竞赛中时间紧张时可只写 SA（实现最短），GA 作为对比方法在论文里陈述思路即可。

## 12.4 求解与检验：报告"解质量"

启发式只给近似解，评委要看到你**知道解有多好**：

- **下界（lower bound）**：如 TSP 的 1-树（1-tree）下界、线性规划松弛，给出"最优解至少多长"。1-树的构造：任取一个参考点，对**其余** $n-1$ 个点求最小生成树，再把参考点与它在生成树外最近的两个点相连——所得"树 + 两边"结构总权必不超过最优巡回，故是合法下界；
- **最优间隙** $\text{gap}=\frac{\text{你的解}-\text{下界}}{\text{下界}}$；若能拿到精确最优（小规模用 `scipy`/OR-Tools），用真实最优当基准；
- 多次随机重启取最好，报告均值与最优，体现稳健性。

## 12.5 关键公式与方法速查

| 方法 | 适用 | 关键调用/实现 | 坑 |
|---|---|---|---|
| 最近邻 | 任意 TSP 初解 | 贪心选最近邻 | 初解可能很差 |
| 2-opt | TSP 精修 | 反转子段 | 只逃不出局部最优 |
| 模拟退火 | TSP/VRP 高质量 | 接受准则 $\exp(-\Delta/T)$ | 温度/降温率要调 |
| OR-Tools | 中小规模精确/近似 | `pywrapcp` Routing | 大规模仍慢 |

## 12.6 典型例题与样例程序

**题目（问题重述）**：平面上随机分布 10 个城市，求访问每城恰好一次并回到起点的最短巡回路线。要求分别用最近邻、2-opt、模拟退火求解，并报告各解相对精确最优的 gap。

**模型假设**：城市位于欧氏平面上，距离取直线距离（对称 TSP）；不考虑路况、单向通行等现实因素。

**符号说明**：城市坐标 $(x_i,y_i)$；距离矩阵 $D=[d_{ij}]$；巡回 $\pi$ 为城市排列，长度 $L(\pi)=\sum_i d_{\pi_i,\pi_{i+1}}$（下标按模 $n$ 回绕）；精确最优 $L^*$，gap $=\dfrac{L_{\text{启发式}}-L^*}{L^*}$。

**求解算法**：三级递进——最近邻构造初解 → 2-opt 精修到局部最优 → 模拟退火以"段反转"为邻域、按 $\exp(-\Delta/T)$ 接受准则进一步逃逸，做 5 次随机重启取最优。10 城规模可穷举 $9!=362880$ 条路线（固定城市 0 在首位以消除旋转等价），从而拿到精确最优 $L^*$ 并计算 gap。

```python
import numpy as np, math, random
from itertools import permutations

np.random.seed(42)
cities = np.random.rand(10, 2)                 # 10 个城市坐标

def dist(a, b):
    return math.hypot(a[0] - b[0], a[1] - b[1])

D = [[dist(cities[i], cities[j]) for j in range(10)] for i in range(10)]

def tour_len(t):
    return sum(D[t[i]][t[(i + 1) % len(t)]] for i in range(len(t)))

# 1) 最近邻：从城市 0 出发，每步走向最近的未访城市
unvisit = list(range(1, 10)); tour = [0]
while unvisit:
    cur = tour[-1]
    nxt = min(unvisit, key=lambda j: D[cur][j])
    tour.append(nxt); unvisit.remove(nxt)
nn_len = tour_len(tour)

# 2) 2-opt：反复反转路径中的一段，直到不再变短
def two_opt(t):
    best = list(t); improved = True
    while improved:
        improved = False
        for i in range(len(best) - 1):
            for j in range(i + 1, len(best)):
                if j - i == 1:
                    continue
                new = best[:i] + best[i:j + 1][::-1] + best[j + 1:]
                if tour_len(new) < tour_len(best) - 1e-9:
                    best = new; improved = True
    return best

opt2 = two_opt(tour); opt2_len = tour_len(opt2)

# 3) 模拟退火：以概率接受变差解，温度递减；5 次随机重启取最优
def sim_anneal(init, seed, iters=20000, T0=1.0, cool=0.9995):
    rng = random.Random(seed)
    cur = list(init); curL = tour_len(cur)
    best = list(cur); bestL = curL
    T = T0
    for _ in range(iters):
        i, j = rng.sample(range(10), 2)
        new = cur[:i] + cur[i:j + 1][::-1] + cur[j + 1:] if i < j \
              else cur[:j] + cur[j:i + 1][::-1] + cur[i + 1:]
        newL = tour_len(new)
        if newL < curL or rng.random() < math.exp((curL - newL) / max(T, 1e-9)):
            cur, curL = new, newL
            if curL < bestL:
                best, bestL = list(cur), curL
        T *= cool
    return bestL

sa_runs = [sim_anneal(tour, seed=s) for s in range(5)]
sa_best = min(sa_runs); sa_mean = sum(sa_runs) / len(sa_runs)

# 4) 精确最优：10 城可穷举（固定城市 0 在首位，9! = 362880 条路线）
opt_exact = min(tour_len((0,) + p) for p in permutations(range(1, 10)))

print("最近邻   路线长 =", round(nn_len, 4))
print("2-opt    路线长 =", round(opt2_len, 4))
print("模拟退火 最优  =", round(sa_best, 4), "  5次均值 =", round(sa_mean, 4))
print("穷举精确最优    =", round(opt_exact, 4))
print("2-opt  gap =", round((opt2_len - opt_exact) / opt_exact * 100, 2), "%")
print("SA最优 gap =", round((sa_best - opt_exact) / opt_exact * 100, 2), "%")
```

**预期输出**（Python 3.13 / numpy 2.x，种子固定）：

```
最近邻   路线长 = 3.1224
2-opt    路线长 = 2.9831
模拟退火 最优  = 2.9031   5次均值 = 2.9031
穷举精确最优    = 2.9031
2-opt  gap = 2.76 %
SA最优 gap = 0.0 %
```

**结果与检验**：最近邻初解 3.12，2-opt 精修到 2.98（gap 2.76%），模拟退火 5 次重启全部达到 2.9031——与穷举精确最优完全一致（gap 0%）。检验有两层：① 与 $L^*$ 对比的 gap 直接量化了解质量；② 5 次重启的均值与最优相同，说明 SA 参数在本问题上稳健，不是"碰运气"碰到的最优。规模超过 ~12 城后穷举不可行，可改用 1-树下界或 OR-Tools 精确解做基准。

**模型评价**：优点——三级递进每一步都有量化收益；gap 闭环让"解有多好"有据可答；多重启设计体现稳健性意识。缺点——邻域（段反转）与降温方案都较朴素，更大规模需自适应降温或 Or-opt 等更强邻域；穷举基准只在极小规模可行。改进——大规模时用"聚类分车 + 各车 TSP"分解（见练习 4），并用 1-树下界替代穷举做检验。VRP 只需把"单回路"改成"多容量受限回路"，算法框架（构造+局部搜索+元启发式）完全复用。

## 12.7 常见误区与竞赛扣分点

1. **把 NP-hard 当线性规划硬解**：几十个城市直接写 TSP 整数规划让求解器跑，往往超时或内存爆；应先声明问题难度、上启发式。
2. **只给一个解、不报质量**：评委无法判断 2.90 是好是坏。务必给下界/最优对比与 gap。
3. **初始解太差又不精修**：纯随机初解 + 单次 SA 容易卡在坏区域；用最近邻做初解、2-opt 预精修是性价比最高的组合。
4. **参数瞎设**：SA 的初温、降温率、迭代数要试；GA 的交叉/变异率同理。报告里写清参数与"多次重启取优"。
5. **混淆 TSP 与 VRP**：把"多车配送"当成"单车巡回"，漏掉容量/时间窗约束——审题先把问题归类（见[第 5 章](/xiaoshus-blog/textbooks/modeling/02-methods/05/)建模三要素）。

## 12.8 拓展延伸

- **与图论衔接**：TSP 是在完全图上的"最小权哈密顿回路"，最短路/匹配（[第 8 章](/xiaoshus-blog/textbooks/modeling/02-methods/08/)）是子问题工具；
- **精确下界**：1-树（1-tree）下界、分支定界（branch-and-bound）可在中等规模拿到精确最优；
- **VRP 变体**：带时间窗 VRP（VRPTW）、带回程取货（VRPB）、多 depot——建模框架一致，约束不同；
- **现代求解器**：OR-Tools 的 Routing 求解器（`pywrapcp`）、Gurobi/CPLEX 的 MIP 求解，中小规模可在秒级给出近优甚至精确最优，竞赛可直接调用并报告 gap。
