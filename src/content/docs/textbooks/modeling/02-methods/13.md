# 第 13 章 模拟与仿真模型

> **本章定位**：当系统复杂到**写不出公式解**——排队服务、随机工期、交通流、火灾蔓延、疫情干预政策比较——仿真就是"造一个可以在计算机里做实验的系统"。它是国赛/美赛出场率最高的兜底方法：任何含随机性的赛题都可以用它给出带置信区间的定量结论。前置要求：第 4 章概率论基础（分布、期望、方差、中心极限定理）。

## 13.0 本章学习目标

学完本章，你应当能够：

2. 规范地管理随机种子（`np.random.default_rng`），让论文结果**可复现**，并解释为什么可复现与"随机"不矛盾；

## 13.1 仿真建模的思想与适用场景

### 13.1.1 什么是仿真

**仿真（simulation）**：给真实系统建一个计算机上的"数字孪生"，让随机过程在机器里跑成千上万遍，用统计方法从运行结果中提炼结论。它与前面各章的关系：

- 解析模型（第 2 章微分方程、第 5 章规划、本章排队公式）给出**精确解**，但要求模型结构规整；
- 仿真给出**统计意义下的近似解**，但几乎不限制系统结构——随机性、非线性、离散与连续混合、复杂逻辑，都能处理。

**决策准则**（赛场上 30 秒判断）：

| 情形 | 选择 |
|---|---|
| 系统能写成稳态方程/规划/ODE 且假设可接受 | 解析模型优先（评委更认可） |
| 随机因素主导且无法解析（排队网络、随机工期、复杂分布叠加） | 蒙特卡洛仿真 |
| 大量个体 + 简单局部规则 + 涌现现象（交通、火灾、人流） | 元胞自动机 / 多智能体 |
| 存量—流量—反馈回路的管理系统（人口、库存、疫情政策） | 系统动力学 |
| 解析模型有解，但想检验假设放松后结论是否稳健 | 仿真做敏感性实验（绝佳的检验章节素材） |

### 13.1.2 与第 4 章概率基础的关系

仿真的每一步"随机"都来自第 4 章的分布理论：到达间隔~指数分布（泊松过程）、服务时长~正态/指数、任务工期~三角/PERT 贝塔分布。反过来，仿真又是第 4 章极限定理的现场演绎：**样本均值的分布随 $N$ 增大而正态化**（中心极限定理），这正是置信区间 $\bar x\pm 1.96\,s/\sqrt N$ 成立的原因。可以说：第 4 章告诉你随机变量怎么"算"，本章告诉你随机系统怎么"跑"。

### 13.1.3 随机数与种子管理（论文可复现性的生死线）

计算机生成的是**伪随机数**：由确定性算法从种子（seed）出发生成的看起来随机的序列。**固定种子 = 结果可复现 = 论文表格数字跑第二遍不变**。规范写法：

```python
import numpy as np
rng = np.random.default_rng(2026)      # 新版 Generator API，全书统一用这个
x = rng.normal(0, 1, 5)                # 正态
y = rng.exponential(1/0.8, 5)          # 指数（均值 = 1/lambda）
z = rng.triangular(2, 3, 6, 5)         # 三角分布（PERT 工期的常用替代）
u = rng.random(5)                      # [0,1) 均匀——一切分布的原料（逆变换法）
```

多实验并行时给每个实验独立种子（`rng` 对象互不干扰）；重复实验用不同种子（`seed=s, s+1, ...`）做**多重独立重复（replication）**取平均——这是降低仿真方差最朴素有效的手段，13.4 节会实际使用。

## 13.2 蒙特卡洛方法

### 13.2.1 原理：用频率逼近期望

**蒙特卡洛（Monte Carlo, MC）** 方法的通用形态：把待求量 $\theta$ 写成某个随机变量的期望 $\theta=E[g(X)]$，$X\sim p(x)$，然后抽样求均值：

$$
\hat\theta_N=\frac{1}{N}\sum_{i=1}^N g(x_i)\ \xrightarrow{N\to\infty}\ \theta\ (\text{大数定律}),
\qquad
\mathrm{SE}(\hat\theta_N)=\frac{\hat\sigma}{\sqrt N}\approx\frac{\hat\sigma}{\sqrt N}\ (\text{中心极限定理}).
$$

95% 置信区间（CI）：$\hat\theta_N\pm 1.96\,\hat\sigma/\sqrt N$。**两条铁律**：(1) 误差只按 $1/\sqrt N$ 收敛——精度提高 10 倍，样本量要扩大 100 倍；(2) **没有置信区间的蒙特卡洛结果是不完整的**，评委视为"只跑了一次没做统计"。

### 13.2.2 三类基本用法

1. **定积分估计（样本均值法）**：$I=\int_a^b g(x)\mathrm{d}x=(b-a)\cdot E[g(U)]$，$U\sim U(a,b)$。
2. **概率估算（投点法/直接计数）**：事件 $A$ 的概率 = 频率 $\hat p=n_A/N$，标准误 $\sqrt{\hat p(1-\hat p)/N}$。
3. **策略比较**：对每个候选策略跑仿真、算指标分布、比较均值与分位数——这是赛题中"方案评估"的通用引擎。

### 13.2.3 经典案例：三人循环挑战赛的冠军概率

**规则**：甲乙先赛；胜者守擂迎战丙；此后"胜者守擂、败者下场休息"；先连胜两局者夺冠。设甲胜乙概率 0.5、乙胜丙 0.6、丙胜甲 0.4——注意胜负关系**非传递**（甲能赢乙、乙能赢丙，但丙不输甲太多）。

这种带吸收状态的随机过程，手算需要解马尔可夫链方程组（见检验环节），而仿真 20 行就能跑出来——这正是仿真的效率优势。

```python
# -*- coding: utf-8 -*-
"""经典案例：三人循环挑战赛冠军概率（蒙特卡洛模拟 + 吸收马尔可夫链精确解交叉验证）
规则：甲乙先赛，胜者守擂迎战丙，此后"胜者守擂、败者下场休息"，先连胜两局者夺冠。
"""
import numpy as np
from itertools import permutations

rng = np.random.default_rng(7)
NAMES = ['甲', '乙', '丙']
# 胜负概率（注意非传递性：甲乙五五开，乙略胜丙，丙反而略胜甲）
P = {('甲', '乙'): .5, ('乙', '甲'): .5,
     ('乙', '丙'): .6, ('丙', '乙'): .4,
     ('甲', '丙'): .6, ('丙', '甲'): .4}

# ---------------- 方法一：蒙特卡洛模拟 ----------------
def simulate_once():
    p1, p2, rest = '甲', '乙', '丙'      # 当前局 p1 对 p2，rest 本轮休息
    prev_w, streak = None, 0
    while True:
        w = p1 if rng.random() < P[(p1, p2)] else p2
        streak = streak + 1 if w == prev_w else 1
        if streak >= 2:                  # 连胜两局 -> 夺冠
            return w
        prev_w = w
        loser = p2 if w == p1 else p1
        p1, p2, rest = w, rest, loser    # 胜者守擂，休息者上场，败者休息

N = 200_000
wins = {n: 0 for n in NAMES}
for _ in range(N):
    wins[simulate_once()] += 1
print("=== 蒙特卡洛模拟（N = %d）===" % N)
for n_ in NAMES:
    est = wins[n_] / N
    se = np.sqrt(est * (1 - est) / N)
    print(f"  {n_} 夺冠频率 = {est:.4f}  (95% CI [{est-1.96*se:.4f}, {est+1.96*se:.4f}])")

# ---------------- 方法二：吸收马尔可夫链精确解（用于检验模拟） ----------------
# 瞬态状态 (h, r)：h = 守擂者（已连胜 1 局），r = 休息者，挑战者 = 第三人
# 转移：h 胜挑战者（概率 P[h,c]）-> 连胜两局，吸收于 h；挑战者胜 -> 新状态 (c, h)
trans = list(permutations(NAMES, 2))               # 6 个瞬态
ti = {st: i for i, st in enumerate(trans)}
Q = np.zeros((6, 6)); R = np.zeros((6, 3))
for (h, r), i in ti.items():
    c = (set(NAMES) - {h, r}).pop()
    R[i, NAMES.index(h)] = P[(h, c)]               # 吸收：h 夺冠
    Q[i, ti[(c, h)]]     = P[(c, h)]               # 转移：挑战者成为守擂者
fund = np.linalg.inv(np.eye(6) - Q) @ R            # 吸收概率矩阵，行 = 瞬态，列 = 冠军
print("\n=== 吸收马尔可夫链精确解 ===")
# 第一局：甲对乙。甲胜 -> 状态（守擂甲，休息乙）；乙胜 -> 状态（守擂乙，休息甲）
p0 = np.zeros(6)
p0[ti[('甲', '乙')]] = P[('甲', '乙')]
p0[ti[('乙', '甲')]] = P[('乙', '甲')]
champ = p0 @ fund
for n_, p_ in zip(NAMES, champ):
    print(f"  {n_} 夺冠概率 = {p_:.4f}")
print("  概率合计 =", round(champ.sum(), 6))
```

实际输出：

```text

**蒙特卡洛模拟（N = 200000）**

  甲 夺冠频率 = 0.4090  (95% CI [0.4068, 0.4111])
  乙 夺冠频率 = 0.4087  (95% CI [0.4065, 0.4108])
  丙 夺冠频率 = 0.1823  (95% CI [0.1807, 0.1840])


**吸收马尔可夫链精确解**

  甲 夺冠概率 = 0.4091
  乙 夺冠概率 = 0.4091
  丙 夺冠概率 = 0.1818
  概率合计 = 1.0
```

模拟频率全部落入精确解的置信区间，且甲乙完全对称（先赛两人胜率五五开，地位对称）——**"仿真 + 解析"交叉验证**是仿真类论文检验环节的黄金搭配。

### 13.2.4 积分估计与收敛阶

```python
# -*- coding: utf-8 -*-
"""蒙特卡洛基础：圆周率估计 + 定积分估计（含随机种子管理与置信区间）"""
import numpy as np

rng = np.random.default_rng(2024)                # 固定种子：结果可复现（论文可复现性的关键）

# ---- 1. 投点法估计圆周率 ----
N = 100_000
u = rng.random((N, 2))                           # 单位正方形内均匀投点
hits = np.sum(u[:, 0]**2 + u[:, 1]**2 <= 1.0)    # 落在四分之一圆内的次数
pi_hat = 4 * hits / N
p = hits / N
se = 4 * np.sqrt(p * (1 - p) / N)                # 二点分布标准误 sqrt(p(1-p)/N)
print(f"投点法: pi ≈ {pi_hat:.5f}, 标准误 ≈ {se:.5f}, "
      f"95% CI = [{pi_hat - 1.96*se:.5f}, {pi_hat + 1.96*se:.5f}]")

# ---- 2. 平均值法（样本均值法）估计定积分 I = ∫0^1 e^x dx ----
N = 200_000
x = rng.random(N)
I_hat = np.mean(np.exp(x))
var_f = np.var(np.exp(x), ddof=1)
se_I = np.sqrt(var_f / N)
print(f"样本均值法: I ≈ {I_hat:.5f} (真值 e-1 = {np.e - 1:.5f}), "
      f"95% CI = [{I_hat - 1.96*se_I:.5f}, {I_hat + 1.96*se_I:.5f}]")

# ---- 3. 收敛阶验证：误差 ~ 1/sqrt(N) ----
print("\nN        估计值      |误差|")
for N in [1_000, 10_000, 100_000, 1_000_000]:
    x = rng.random(N)
    est = np.mean(np.exp(x))
    err = abs(est - (np.e - 1))
    print(f"{N:>8d}  {est:.6f}  {err:.6f}")
```

实际输出：

```text
投点法: pi ≈ 3.14852, 标准误 ≈ 0.00518, 95% CI = [3.13837, 3.15867]
样本均值法: I ≈ 1.71688 (真值 e-1 = 1.71828), 95% CI = [1.71472, 1.71903]

N        估计值      |误差|
    1000  1.709048  0.009234
   10000  1.707693  0.010589
  100000  1.721035  0.002753
 1000000  1.718180  0.000102
```

**读结果**：两个真值（$\pi$ 与 $e-1$）都落在各自 95% CI 内。注意误差列**不是**单调下降的（10000 的误差比 1000 还大）——这是单次实验的正常现象，$1/\sqrt N$ 是统计意义上的趋势；要看到平滑的收敛曲线，应固定误差估计方式或做多重独立重复。论文中呈现"均值 + 置信区间 + 收敛表"三件套，仿真才算严谨。

## 13.3 排队论：解析与仿真的正面交手

### 13.3.1 排队系统的标准记号

Kendall 记号 $A/B/c$：到达过程 / 服务时长分布 / 服务台数。$M$ 表示马尔可夫（泊松到达、指数服务）。核心指标：

- $L$：系统内平均顾客数；$L_q$：平均队长（排队中，不含服务中）；
- $W$：平均逗留时间；$W_q$：平均等待时间；
- **Little 公式**（无论分布如何都成立）：$L=\lambda W,\quad L_q=\lambda W_q$。

### 13.3.2 M/M/1 稳态公式

服务强度 $\rho=\lambda/\mu<1$（否则队伍爆炸）。由生灭过程的平稳分布 $\pi_k=(1-\rho)\rho^k$：

$$
L=\frac{\rho}{1-\rho},\quad L_q=\frac{\rho^2}{1-\rho},\quad
W=\frac{1}{\mu-\lambda},\quad W_q=\frac{\lambda}{\mu(\mu-\lambda)} .
$$

注意 $W_q$ 对 $\rho$ 的非线性：$\rho:0.9\to 0.95$，$W_q$ 从 9 分钟翻倍到 19 分钟——**排队系统没有"温和的超载"**，这是服务类赛题的核心洞察。

### 13.3.3 M/M/c 稳态公式（Erlang C）

$c$ 个并行服务台，$\rho=\lambda/(c\mu)<1$，话务量 $a=\lambda/\mu$：

$$
P_0=\Bigl[\sum_{k=0}^{c-1}\frac{a^k}{k!}+\frac{a^c}{c!}\cdot\frac{1}{1-\rho}\Bigr]^{-1},\qquad
L_q=\frac{P_0\,a^c\rho}{c!\,(1-\rho)^2},\qquad W_q=\frac{L_q}{\lambda},\ W=W_q+\frac{1}{\mu}.
$$

### 13.3.4 离散事件仿真：验证解析解

解析公式依赖"泊松到达 + 指数服务"两大假设；现实中到达往往不泊松（高峰潮汐）、服务时长非指数——这时仿真才是唯一出路。先验证仿真器写对了（对得上解析解），再替换成真实分布使用，这是仿真类论文的标准作业流程。

```python
# -*- coding: utf-8 -*-
"""排队论：M/M/1 与 M/M/c 稳态公式 + 离散事件仿真验证"""
import numpy as np
import math

# ---------------- 1. M/M/1 解析公式 ----------------
lam, mu = 0.8, 1.0        # 到达率（人/分钟）、服务率；要求 rho = lam/mu < 1
rho = lam / mu
L  = rho / (1 - rho)                # 系统内平均人数
Lq = rho**2 / (1 - rho)             # 平均排队长度（不含正在服务者）
W  = 1 / (mu - lam)                 # 平均逗留时间
Wq = lam / (mu * (mu - lam))        # 平均等待时间
print("=== M/M/1 解析解（lambda=%.1f, mu=%.1f, rho=%.1f）===" % (lam, mu, rho))
print(f"L={L:.4f}  Lq={Lq:.4f}  W={W:.4f}  Wq={Wq:.4f}")

# ---------------- 2. M/M/1 离散事件仿真验证 ----------------
def mm1_sim(lam, mu, T=20000, warmup=2000, seed=42):
    """事件驱动 M/M/1 仿真。事件 = {到达, 离开}；指数分布由 default_rng 生成，
    固定 seed 保证可复现。warmup 之前的统计量丢弃（消除初始瞬态）。"""
    r = np.random.default_rng(seed)
    t = 0.0
    next_arr = r.exponential(1 / lam)      # 下一到达时刻
    next_dep = np.inf                      # 下一离开时刻（服务器初始空闲）
    queue, in_svc = [], None               # 排队者到达时刻表；正在服务的顾客信息
    area_n = area_q = 0.0                  # 时间加权积分（用于 L, Lq）
    last, rec = 0.0, False
    wait_sum = syst_sum = 0.0; served = 0
    while True:
        t_new = min(next_arr, next_dep)
        area_n += (len(queue) + (1 if in_svc else 0)) * (t_new - last)
        area_q += len(queue) * (t_new - last)
        last = t_new; t = t_new
        if t >= warmup and not rec:        # 预热结束：清零统计量
            rec, area_n, area_q, wait_sum, syst_sum, served = True, 0.0, 0.0, 0.0, 0.0, 0
        if t >= warmup + T: break
        if next_arr < next_dep:                              # --- 到达事件 ---
            queue.append(t)
            next_arr = t + r.exponential(1 / lam)
            if in_svc is None:                               # 服务器空闲 -> 立即服务
                a = queue.pop(0)
                st = r.exponential(1 / mu)
                in_svc = (a, t, st)
                wait_sum += t - a
                next_dep = t + st
        else:                                                # --- 离开事件 ---
            a, _, _ = in_svc
            in_svc = None
            syst_sum += t - a; served += 1
            if queue:                                        # 队首顾客进入服务
                a2 = queue.pop(0)
                st2 = r.exponential(1 / mu)
                in_svc = (a2, t, st2)
                wait_sum += t - a2
                next_dep = t + st2
            else:
                next_dep = np.inf
    return dict(L=area_n / T, Lq=area_q / T, W=syst_sum / served, Wq=wait_sum / served)

# 多次独立重复实验（不同种子）取平均，降低单次仿真的随机波动
reps = [mm1_sim(lam, mu, seed=s) for s in range(1, 6)]
sim = {k: float(np.mean([d[k] for d in reps])) for k in reps[0]}
print("\n=== M/M/1 仿真（5 次独立重复实验均值）===")
print({k: round(v, 4) for k, v in sim.items()}, "（应与解析解吻合）")

# ---------------- 3. M/M/c 解析公式（Erlang C）----------------
def mmc_metrics(lam, mu, c):
    rho = lam / (c * mu)
    if rho >= 1: return None
    a = lam / mu                                           # 话务量
    s = sum(a**k / math.factorial(k) for k in range(c)) + \
        a**c / math.factorial(c) / (1 - rho)
    P0 = 1 / s
    Lq = P0 * a**c * rho / (math.factorial(c) * (1 - rho)**2)
    Wq = Lq / lam
    return dict(P0=P0, Lq=Lq, Wq=Wq, W=Wq + 1 / mu)

# ---------------- 4. M/M/c 仿真验证（c 个并行服务台） ----------------
def mmc_sim(lam, mu, c, T=50000, warmup=5000, seed=42):
    r = np.random.default_rng(seed)
    busy = np.zeros(c)                     # 各服务台释放时刻
    t, next_arr = 0.0, r.exponential(1 / lam)
    wait_sum, served, rec = 0.0, 0, False
    while next_arr < warmup + T:
        t = next_arr
        if t >= warmup and not rec:
            rec, wait_sum, served = True, 0.0, 0
        j = int(np.argmin(busy))           # 空闲（最早释放）的服务台
        start = max(t, busy[j])
        wait_sum += start - t
        busy[j] = start + r.exponential(1 / mu)
        served += 1
        next_arr = t + r.exponential(1 / lam)
    Wq = wait_sum / served
    return dict(Wq=Wq, Lq=lam * Wq)        # Lq 由 Little 公式 lam*Wq 得到

print("\n=== M/M/c（lambda=6, mu=1, c=8, rho=0.75）===")
print("解析:", {k: round(v, 4) for k, v in mmc_metrics(6, 1, 8).items()})
print("仿真:", {k: round(v, 4) for k, v in mmc_sim(6, 1, 8).items()})

# ---------------- 5. rho -> 1 时等待时间爆炸（拥堵的临界现象） ----------------
print("\n=== 服务强度 rho 对 Wq 的影响（c=1, mu=1）===")
for rho in (0.5, 0.7, 0.8, 0.9, 0.95):
    l = rho
    print(f"rho={rho:.2f}  Wq = {l / (1 * (1 - l)):.2f} 分钟")
```

## 13.4 元胞自动机：简单规则的涌现

### 13.4.1 思想

**元胞自动机（cellular automaton, CA）**：规则网格，每个元胞取有限状态，按**只依赖邻居的局部规则**同步更新。它回答的问题是：宏观复杂现象（火灾蔓延成团、高速路堵车自发出现）能否从微观简单规则中"涌现"？CA 的价值不在算得多准，而在**机制解释与政策实验**（赛前封闭一条车道会怎样？开辟防火带呢？）。

### 13.4.2 森林火灾（Drossel–Schwabl 模型简化版）

规则只有两条：空格以概率 $p$ 长树；树以概率 $f$ 被雷击起火，火烧掉整个四连通树簇。长期运行下系统进入**自组织临界（SOC）**态：火灾面积分布呈幂律——小火灾频繁、大火灾罕见但必然，森林覆盖率自我维持在临界值。对应急管理赛题的含义：只统计"平均火灾大小"会严重低估风险，**幂律尾部才是重点**。

### 13.4.3 Nagel–Schreckenberg 交通流模型

单车道环形道路，每车速度 $v\in\{0,\dots,v_{max}\}$，每步四条规则：

1. **加速**：$v\leftarrow\min(v+1,\ v_{max})$；
2. **防撞减速**：$v\leftarrow\min(v,\ \text{gap})$，gap 为与前车空格数；
3. **随机慢化**：以概率 $P$ 执行 $v\leftarrow\max(v-1,\ 0)$（驾驶员反应过度、路况干扰）；
4. **前进**：位置 $\leftarrow$ 位置 $+v$。

就这四条，第 3 条随机慢化让模型涌现出与真实高速一致的**基本图**（流量–密度曲线）与"幽灵堵车"（无事故的自发拥堵波）。

```python
# -*- coding: utf-8 -*-
"""元胞自动机：森林火灾模型 + Nagel-Schreckenberg 交通流模型"""
import numpy as np

# ================= 1. 森林火灾模型（Drossel-Schwabl 简化版） =================
# 规则：树(1)以概率 p 生长；闪电以概率 f 击中任一格，烧毁该树及其连通树簇（简化：烧本格及四邻扩散）
rng = np.random.default_rng(3)
L, T = 100, 300            # 网格边长、模拟步数
p, f = 0.01, 0.00002       # 生长概率、雷击概率
grid = (rng.random((L, L)) < 0.3).astype(np.int8)   # 初始：30% 有树

def burn(grid, x, y):
    """从 (x,y) 起火，深度优先烧掉整个四连通树簇，返回烧毁面积"""
    stack, burned = [(x, y)], 0
    while stack:
        i, j = stack.pop()
        if 0 <= i < L and 0 <= j < L and grid[i, j] == 1:
            grid[i, j] = 0; burned += 1
            stack += [(i+1, j), (i-1, j), (i, j+1), (i, j-1)]
    return burned

total_burned = []
for t in range(T):
    hit = rng.random((L, L)) < f                    # 本步雷击位置
    for x, y in zip(*np.where(hit)):
        if grid[x, y] == 1:
            total_burned.append(burn(grid, x, y))
    grow = rng.random((L, L)) < p
    grid = np.maximum(grid, grow.astype(np.int8))   # 空地以概率 p 长树
avg = np.mean(total_burned[max(0, len(total_burned)-100):])
print("=== 森林火灾模型（L=100, p=0.01, f=2e-5, T=300 步）===")
print(f"火灾总次数 = {len(total_burned)}, 后期平均每次烧毁面积 = {avg:.1f} 格")
print(f"森林覆盖率(终态) = {grid.mean():.3f}（自组织临界：面积分布呈幂律）")

# ================= 2. Nagel-Schreckenberg 单车道交通流 =================
# 规则（每步）：1) 加速 v->min(v+1, v_max)  2) 减速 v->min(v, gap)  3) 以概率 P 随机慢化  4) 前进 v 格
road_len, n_cars, v_max, P_slow, T = 200, 60, 5, 0.3, 500   # 密度 = 60/200 = 0.3
cells = -np.ones(road_len, dtype=int)                        # -1 空，否则存速度

def step(cells):
    v = cells.copy()
    occupied = np.where(v >= 0)[0]
    new = -np.ones(road_len, dtype=int)
    if len(occupied) == 0:
        return new
    for k, i in enumerate(occupied):
        i_next = occupied[(k + 1) % len(occupied)]       # 前车位置（环形道路）
        gap = (i_next - i) % road_len - 1                # 与前车的空格数
        v[i] = min(v[i] + 1, v_max)                      # 加速
        v[i] = min(v[i], gap)                            # 防撞减速
        if rng.random() < P_slow: v[i] = max(v[i] - 1, 0)  # 随机慢化
    for i in occupied:
        new[(i + v[i]) % road_len] = v[i]
    return new

def run(dens, T=500, warmup=200, seed=11):
    """给定密度跑一次仿真，返回稳态平均流量"""
    r = np.random.default_rng(seed)
    n = int(dens * road_len)
    cells = -np.ones(road_len, dtype=int)
    cells[np.sort(r.choice(road_len, n, replace=False))] = v_max // 2
    flows = []
    for t in range(T):
        cells = step(cells)
        if t >= warmup:
            flows.append(cells[cells >= 0].sum() / road_len)  # 流量 = 平均速度 x 密度
    return float(np.mean(flows))

print("\n=== Nagel-Schreckenberg 基本图（流量-密度关系，v_max=5, P=0.3）===")
for dens in (0.05, 0.10, 0.15, 0.20, 0.30, 0.50):
    q = run(dens)
    print(f"密度 {dens:.2f}  流量 q = {q:.4f}  平均速度 v = {q/dens:.2f}")
print("（流量先升后降：峰值即道路通行能力，之后进入拥塞分支——自发涌现的相变）")
```

## 13.5 系统动力学概览

### 13.5.1 存量与流量

**系统动力学（System Dynamics, SD）** 把系统看成**存量（stock）—流量（rate）—反馈回路**的网络：存量是积累量（人口、库存、感染人数），流量是存量的变化速率，信息反馈回流量构成闭环。数学上就是一个耦合常微分方程组（第 2 章的领地）：

$$
\frac{\mathrm{d}S(t)}{\mathrm{d}t} = \text{流入}(t) - \text{流出}(t).
$$

用 SIR 传染病写一张存量流量图（箭头：→ 表示影响，▷ 表示存量间的流量）：

```text
                     感染率 β·S·I/N
   ┌──────┐  ▷▷▷▷▷▷▷   ┌──────┐  ▷▷▷▷▷▷▷   ┌──────┐
   │ 易感 S │            │ 感染 I │            │ 移除 R │
   └──────┘            └──────┘            └──────┘
      ▲                    │  感染人数 I
      │                    ▼  (反馈信息)
      └──────── 反馈：I 越大，S 被感染越快 ─────────┘
   流入：出生/移入          流出：康复 μ·I、死亡
```

### 13.5.2 SD 在竞赛中的用法

SD 的竞赛价值主要在**表达与结构分析**而非求解（求解就是第 2 章的 ODE 数值方法，`scipy.integrate.solve_ivp` 即可）：

1. 用存量流量图向评委**展示系统结构**（政策如何通过反馈回路起作用）；
2. 做情景实验：改参数（隔离系数 β）跑不同情景，比较存量曲线——"政策沙盘"；
3. 与蒙特卡洛结合：参数本身带不确定性时，对参数抽样、对结果出置信带（联动本章方法）。

## 13.6 关键公式与方法速查

| 方法 | 适用场景 | 关键公式 | 优缺点/坑 |
|---|---|---|---|
| 蒙特卡洛积分 | 高维/复杂积分 | $I\approx(b-a)\bar g$，SE $=\sigma_g/\sqrt N$ | 收敛慢 $O(1/\sqrt N)$；必报 CI |
| MC 概率估算 | 小概率/复杂事件 | $\hat p\pm1.96\sqrt{\hat p(1-\hat p)/N}$ | 小概率事件需极大 $N$（或重要性抽样） |
| 随机种子管理 | 一切仿真 | `default_rng(seed)` + 多重独立重复 | 不设种子 = 结果不可复现 = 致命 |
| M/M/1 | 单台排队 | $L=\frac{\rho}{1-\rho},\ W=\frac{1}{\mu-\lambda}$ | 仅当 $\rho<1$；分布假设需检验 |
| M/M/c（Erlang C） | 多台排队 | $L_q=\frac{P_0a^c\rho}{c!(1-\rho)^2}$ | 同上；扩台决策用公式扫描即可 |
| Little 公式 | 一切稳态排队 | $L=\lambda W,\ L_q=\lambda W_q$ | 分布无关，检验仿真的利器 |
| 离散事件仿真 | 排队/服务/流程 | 事件表 + 时间加权统计 | 必须预热丢弃瞬态；多重重复报均值 |
| 元胞自动机（火灾/交通） | 涌现现象、政策实验 | 局部规则 + 同步更新 | 是机制模型不是精确预测；参数要标定 |
| NaSch 基本图 | 交通评估 | $q=\rho\cdot\bar v$ | 流量峰值 = 通行能力；注意拥塞分支 |
| 系统动力学 | 存量-流量-反馈系统 | $\mathrm{d}S/\mathrm{d}t=\text{in}-\text{out}$ | 求解即 ODE 数值积分；价值在结构表达 |

## 13.7 典型例题与样例程序：软件开发项目工期风险蒙特卡洛评估

### （1）问题重述

某软件公司承接一个含 7 项活动（A 需求分析 → B/C 设计并行 → D/E 开发并行 → F 集成测试 → G 发布）的项目，合同工期 26 周。各项活动工期不确定，专家给出乐观/最可能/悲观三值估计。要求：(a) 估计项目总工期的分布与期望；(b) 计算逾期违约概率；(c) 找出对工期风险影响最大的关键活动，为赶工决策提供依据。

### （2）模型假设

1. 各活动工期相互独立（简化；真实项目存在资源共享导致的正相关，见评价）；每项活动工期用三角分布 $\mathrm{Tri}(a,m,b)$ 刻画——相对标准 PERT 的贝塔分布更稳健、不产生不可能极端值，竞赛中两者结论接近；
2. 活动间逻辑关系确定（无返工循环）：$A$ 完成后 $B,C$ 并行；$E$ 需 $B,C$ 均完成；$F$ 需 $D,E$ 均完成；
3. 不考虑资源冲突与加班赶工的工期压缩（可作为拓展情景）；
4. 关键路径按每次抽样的实现动态判定——这正是必须用仿真的原因：**关键路径本身是随机的**。

### （3）符号说明

| 符号 | 含义 |
|---|---|
| $a_k,m_k,b_k$ | 活动 $k$ 的乐观/最可能/悲观工期（周） |
| $D_k$ | 活动 $k$ 的随机工期，$D_k\sim\mathrm{Tri}(a_k,m_k,b_k)$ |
| $T_{\text{proj}}$ | 项目总工期 = 关键路径长度（每次实现重新计算） |
| $\hat F$ | 经验分布函数；$N$ 为模拟次数 |
| $r_k$ | 活动 $k$ 的关键率（成为关键路径一员的频率） |

### （4）模型建立

**项目网络 + 随机工期 + 关键路径法（CPM）的组合模型**。对第 $i$ 次抽样：从各三角分布抽取工期 $D_k^{(i)}$，沿网络正推（forward pass）计算最早开始/结束：

$$
ES_k=\max_{p\in\mathrm{pred}(k)}EF_p,\qquad EF_k=ES_k+D_k,\qquad T_{\text{proj}}^{(i)}=EF_{\text{末}}.
$$

逆推（backward pass）得最迟时间 $LF_k$，浮动为零者 $LF_k=EF_k$ 即本次实现的关键活动。$N$ 次抽样后得到 $T_{\text{proj}}$ 的经验分布，均值、分位数、违约概率 $\hat P(T_{\text{proj}}>26)$ 及其置信区间全部由样本统计给出；关键率 $r_k$ 频率近似概率，构成风险排序。

### （5）求解程序

```python
# -*- coding: utf-8 -*-
"""案例：软件开发项目工期风险蒙特卡洛评估（PERT 三点估计 + 活动网络）
流程：问题重述 -> 假设 -> 符号 -> 模型建立（网络 + 分布） -> 求解（抽样模拟）
      -> 检验（收敛性 + 置信区间） -> 评价
"""
import numpy as np
import math

# ---------------- 1. 项目活动网络（PERT 三点估计 a, m, b：乐观/最可能/悲观，单位：周） ----------------
# 活动：(代号, 紧前活动, a, m, b)   网络为串并联结构，关键路径随抽样而变 -> 必须模拟
tasks = [
    ("A", [],     2, 3, 5),    # 需求分析
    ("B", ["A"],  3, 4, 8),    # 总体设计
    ("C", ["A"],  2, 3, 6),    # 数据库设计（与 B 并行）
    ("D", ["B"],  4, 6, 11),   # 模块开发1
    ("E", ["B", "C"], 5, 7, 12),  # 模块开发2
    ("F", ["D", "E"], 2, 3, 5),   # 集成测试
    ("G", ["F"],  1, 2, 4),    # 发布部署
]
dur = {t[0]: (t[2], t[3], t[4]) for t in tasks}
preds = {t[0]: t[1] for t in tasks}

def sample_durations(rng):
    """按 PERT 三点估计抽样各活动工期（三角分布：稳健、竞赛常用）"""
    return {k: rng.triangular(a, m, b) for k, (a, m, b) in dur.items()}

def project_duration(d):
    """关键路径法（CPM）计算总工期：每个活动的最早开始 = max(紧前活动最早结束)"""
    finish = {}
    for k in dur:                      # tasks 已按拓扑序排列
        start = max([finish[p] for p in preds[k]], default=0.0)
        finish[k] = start + d[k]
    return finish["G"]

# ---------------- 2. 求解：蒙特卡洛模拟 ----------------
rng = np.random.default_rng(2026)
N = 100_000
durs = np.array([project_duration(sample_durations(rng)) for _ in range(N)])
mean, std = durs.mean(), durs.std(ddof=1)
se = std / math.sqrt(N)
print("=== 工期模拟结果（N = %d 次实现）===" % N)
print(f"平均工期 μ̂ = {mean:.3f} 周，标准差 σ̂ = {std:.3f}")
ci = (mean - 1.96 * se, mean + 1.96 * se)
print(f"平均工期 95% 置信区间 = [{ci[0]:.3f}, {ci[1]:.3f}]")

deadline = 26.0                                     # 合同工期 26 周
p_late = (durs > deadline).mean()
se_p = math.sqrt(p_late * (1 - p_late) / N)
print(f"\n超过 {deadline} 周违约的概率 ≈ {p_late:.3f}  (95% CI [{p_late-1.96*se_p:.3f}, {p_late+1.96*se_p:.3f}])")
print("工期分位数: P50 = %.1f, P80 = %.1f, P95 = %.1f 周" % tuple(np.percentile(durs, [50, 80, 95])))

# ---------------- 检验 A：活动关键率（出现在关键路径上的频率） ----------------
def key_rates_exact(n_sub=20_000):
    """每次实现做完整正推/逆推（forward/backward pass），
    统计各活动浮动为零（位于关键路径）的频率 -> 风险排序"""
    succ = {k: [] for k in dur}
    for k, ps in preds.items():
        for p in ps: succ[p].append(k)
    order = [t[0] for t in tasks]
    cnt = {k: 0 for k in dur}
    for _ in range(n_sub):
        d = sample_durations(rng)
        ES, EF = {}, {}
        for k in order:
            ES[k] = max([EF[p] for p in preds[k]], default=0.0); EF[k] = ES[k] + d[k]
        Ttot = EF[order[-1]]
        LF = {}
        for k in reversed(order):
            LF[k] = min([LF[s] - d[s] for s in succ[k]], default=Ttot)
        for k in order:
            if abs(LF[k] - EF[k]) < 1e-9:
                cnt[k] += 1
    return {k: v / n_sub for k, v in cnt.items()}

print("\n=== 活动关键率（出现在关键路径上的频率，子样本 N=20000）===")
for k, r in key_rates_exact().items():
    print(f"  活动 {k}: {r:.3f}")

# ---------------- 检验 B：收敛性分析（标准误随 N 的下降） ----------------
print("\n=== 收敛性分析 ===")
print("   N     μ̂      标准误 1.96*se")
for n in (1_000, 10_000, 100_000):
    d2 = np.array([project_duration(sample_durations(rng)) for _ in range(n)])
    m2, s2 = d2.mean(), d2.std(ddof=1)
    print(f"{n:>8d}  {m2:.4f}  {1.96 * s2 / math.sqrt(n):.4f}")
print("（N 扩大 100 倍 -> 置信区间宽度约缩小为 1/10，符合 O(1/√N) 收敛律）")
```

### （6）结果与检验

1. **结论**：期望工期 22.5 周（95% CI [22.49, 22.52]，极窄——$N=10^5$ 的威力），P95 分位 25.9 周；违约概率约 4.4%（CI [4.3%, 4.5%]）。管理层语言："十次项目约半次超过 22.5 周，二十次中约一次逾期。"
2. **收敛性检验**：半宽从 0.12（N=10³）降到 0.012（N=10⁵），$N$ 扩百倍、半宽缩十倍，严格符合 $O(1/\sqrt N)$——证明结果已收敛，精度不再是瓶颈。
3. **风险结构**：关键率显示 $E$（0.699）远高于 $D$（0.301），$B$ 与 $C$ 的竞争为 0.87 : 0.13——**传统单一关键路径（A-B-E-F-G）忽略了 D 路径约 30% 的"抢班夺权"可能**；赶工资源应优先投向 $E$，其次是 $B$。这是确定性 CPM 给不出来的结论，也是本模型的灵魂。
4. **模型校验**：可另用 PERT 经典均值公式 $\frac{a+4m+b}{6}$ 逐活动求期望、走单条最长路径做近似对比（约 22.3 周，略低于仿真均值——因为 PERT 近似忽略了并行路径的次关键效应），两者的差异本身可作为论文讨论点。

### （7）模型评价

- **优点**：不依赖分布假设的解析可行性；输出完整分布（分位数）而非单点估计；关键率给出可操作的风险排序；收敛性与置信区间完备。
- **缺点**：独立性假设低估真实项目活动的相关性（正相关会使总工期方差更大、尾部更肥）；三角分布三点估计本身带专家主观性。
- **改进方向**：用 Copula 或共享随机因子引入活动间相关（相关会显著抬高 P95，方向可以预判）；对违约概率做重要性抽样加速小概率估计；将工期分布换成第 4 章实测数据拟合的对数正态分布。

## 13.8 常见误区与竞赛扣分点

1. **没有置信区间的蒙特卡洛**。只报"模拟均值为 22.5 周"而不给标准误/CI、不谈收敛，等于告诉评委"我不知道这数有多可靠"。
2. **不设随机种子**。论文数字无法复现，或者答辩现场重跑结果变了——直接怀疑建模真实性。
3. **不预热就统计**。排队仿真从初始空系统开始统计，瞬态污染稳态估计；必须丢弃 warmup 期或至少说明影响可忽略。
4. **单次仿真下结论**。不同种子的结果波动可能很大（尤其 $\rho$ 接近 1 的排队系统），多重独立重复取均值是底线操作。
5. **解析有解偏用仿真**。M/M/1 有闭式解却硬仿真，评委认为"不会解析方法"；反过来排队网络复杂、真实分布下硬套 M/M/1 公式，则是"乱用公式"。正确姿势如 13.3.4：**先验证仿真器，再用仿真处理解析到不了的场景**。
6. **元胞自动机参数无标定**。NaSch 的 $P$、火灾模型的 $p,f$ 若不与真实数据（流量观测、火灾统计）对标，模型就是"数字游戏"；至少要做参数敏感性分析。
7. **把 CA/SD 的仿真曲线当精确预测**。这些是机制/情景模型，论文措辞应是"在情景 X 下系统表现出 Y 行为"，而非"预测 Y 值为 Z"。
8. **小概率事件的抽样不足**。违约概率 0.1% 量级的事件，$N=10^4$ 的模拟里平均只出现 10 次，CI 巨大；要么加大 $N$，要么用重要性抽样，并在论文里说明。

## 13.9 拓展延伸

- **与[第 4 章概率统计方法](/xiaoshus-blog/textbooks/modeling/01-foundations/04/)的联动**：仿真输入分布的确定就是第 4 章的参数估计与拟合优度检验（K-S 检验、卡方检验）——"先拟合输入、再仿真输出、最后检验收敛"构成完整统计闭环。
- **与[第 2 章微积分与微分方程方法](/xiaoshus-blog/textbooks/modeling/01-foundations/02/)的联动**：系统动力学 = ODE 的结构化表达；SIR 的 $\mathcal{R}_0$ 分析（第 2 章）给出仿真参数选择的解析锚点，两者互证。
- **与[第 5 章优化模型](/xiaoshus-blog/textbooks/modeling/02-methods/05/)的联动**：仿真 + 优化 = **随机仿真优化（simulation-based optimization）**——目标函数没有解析式时，外层用遗传算法/贝叶斯优化提参数，内层仿真评估；排队系统"开几个窗口"的决策即此类（费用 = 服务台成本 + 等待成本，均含随机项）。
- **与[第 8 章图论与网络模型](/xiaoshus-blog/textbooks/modeling/02-methods/08/)的联动**：随机故障下的网络可靠性（拆除若干节点后连通率）= 蒙特卡洛 + 图算法；应急疏散 = 元胞自动机在路网上运行。
- **方差缩减技术（进阶必修）**：对偶变量、条件期望、重要性抽样、分层抽样——精度不够时的正规军，而非无脑堆 $N$。
- **延伸阅读**：Law, *Simulation Modeling and Analysis*（离散事件仿真的圣经，第 1、2、11 章最相关）；司守奎《数学建模算法与应用》随机模拟章节；Drossel & Schwabl (1992) 森林火灾模型原始论文；Nagel & Schreckenberg (1992) 交通模型原始论文。
