# 第 10 章 统计与机器学习模型

> **本章定位**：当赛题是"**一堆样本 + 一堆指标**"——客户分群（聚类）、指标降维（主成分）、类别判别（分类）、评价体系瘦身（因子分析）——统计学习与机器学习是主战场。前置要求：第 4 章概率统计方法（分布、假设检验、回归基础）；与第 7 章预测模型（回归预测那一半）互为表里。

## 10.0 本章学习目标

学完本章，你应当能够：

1. 拿到无标签数据时，在 **K-means / 层次聚类 / DBSCAN** 之间做出有理由的选型，并用轮廓系数、ARI 评价聚类质量；
2. 用 **主成分分析（PCA）** 把几十个相关指标压成少数综合指标，并解释主成分的物理含义；
3. 面对分类任务，按"样本量—特征类型—可解释性"三要素在**逻辑回归 / 决策树 / SVM / 集成方法**中选型；
4. 正确执行 **$k$ 折交叉验证 + 网格搜索（GridSearchCV）** 调参，绝不用测试集调参；
5. 区分**插值**（精确过点）与**拟合**（容忍误差找趋势），并在拉格朗日插值、三次样条、最小二乘间选型；
6. 按竞赛八股完成一个含"模型对比—调参—检验—解释"全流程的分类案例。

## 10.1 从统计到机器学习：一条连续的光谱

第 4 章的回归分析、假设检验关心的是**推断**（系数是否显著、关系是否真实）；本章的方法更关心**预测与结构发现**（分类准确率、簇的结构），两者共享同一套数学底座（极大似然、最小二乘、贝叶斯），竞赛中常常混用在同一篇论文里：先用聚类"看清结构"，再用分类器"固化规则"，最后用统计检验"确认显著"。

机器学习方法的两大分野，决定了你在赛场上的第一步：

- **无监督学习（unsupervised learning）**：数据没有标签，目标是发现结构——聚类、降维。典型赛题：客户细分、评价指标体系压缩、"数据的自然分组"。
- **有监督学习（supervised learning）**：数据带标签 $y$，目标是学映射 $f:X\to y$——分类（离散 $y$）、回归（连续 $y$，与第 7 章预测模型衔接）。典型赛题：判别品种/等级/风险类别、特征重要性排序。

## 10.2 无监督学习（一）：聚类方法族

### 10.2.1 K-means：原型聚类的主力

**思想**：给定簇数 $k$，最小化簇内平方和（WCSS，又称惯性 inertia）

$$
J=\sum_{c=1}^{k}\sum_{x_i\in C_c}\lVert x_i-\mu_c\rVert^2,\qquad
\mu_c=\frac{1}{|C_c|}\sum_{x_i\in C_c}x_i .
$$

算法交替执行"分配（点到最近质心）—更新（质心取均值）"直到收敛（Lloyd 迭代，单调下降必收敛，但只到**局部最优**——所以 `n_init` 跑多次取最优）。**前提假设**：簇是球形、大小相近、密度相近；对离群点敏感。

### 10.2.2 层次聚类：先看清树状图再定簇数

**凝聚式（agglomerative）**：每个点自成一簇，反复合并最近的两簇，得到树状图（dendrogram），在任意高度"横切"即得聚类结果——**不需要预设 $k$，适合探索阶段**。合并"最近"的定义由连接方式（linkage）决定：ward（方差最小，簇大小均衡）、single（最近点距离，能拉长链、可找非凸簇但对噪声敏感）、complete、average。

### 10.2.3 DBSCAN：密度聚类，自动识别离群点

**思想**：由密度可达性扩张簇。两个参数：邻域半径 $\varepsilon$ 与最小点数 MinPts。**优点**：簇形状任意、自动把低密度点标为噪声（$-1$ 类）、无需预设簇数。**缺点**：对 $\varepsilon$ 敏感；密度差异大的数据表现差。$\varepsilon$ 的经验选法：画 k-距离图（每点到第 MinPts 近邻距离的排序曲线）取拐点。

### 10.2.4 聚类选型表与实验对比

| 方法 | 需预设 | 擅长 | 崩溃场景 |
|---|---|---|---|
| K-means | 簇数 $k$ | 球形簇、大数据快 | 环形/月牙形非凸簇；离群点 |
| 层次聚类 | 连接方式（可后切） | 小样本（$n\lesssim 2000$）探索、树状图展示 | 大数据 $O(n^2)$ 内存；single 连接对噪声敏感 |
| DBSCAN | $\varepsilon$, MinPts | 任意形状 + 噪声识别 | 簇密度差异大；高维距离失效 |

聚类质量评价（无标签时与有标签时各有一套）：

- **轮廓系数（silhouette）** $s(i)=\frac{b(i)-a(i)}{\max\{a(i),b(i)\}}\in[-1,1]$，$a(i)$=点到本簇平均距离，$b(i)$=点到最近他簇平均距离；越大越凝聚分离。
- **ARI（调整兰德指数）**：有真标签时的外部一致性指标，修正了随机划分的期望值。
- **肘部法**：画 WCSS–$k$ 曲线取"肘"（配合轮廓系数更稳）。

```python
# -*- coding: utf-8 -*-
"""9-1 三大聚类算法对比实验：K-means / 层次聚类 / DBSCAN"""
import os
os.environ["OMP_NUM_THREADS"] = "3"   # 规避 Windows + MKL 下 KMeans 的线程警告
import numpy as np
from sklearn.datasets import make_blobs, make_moons
from sklearn.cluster import KMeans, AgglomerativeClustering, DBSCAN
from sklearn.metrics import silhouette_score, adjusted_rand_score
from sklearn.preprocessing import StandardScaler

# ---- 实验 1：球形簇（K-means 的主场）----
X, y = make_blobs(n_samples=600, centers=4, cluster_std=1.0, random_state=42)
X = StandardScaler().fit_transform(X)
for name, model in [("K-means(k=4)", KMeans(n_clusters=4, n_init=10, random_state=42)),
                    ("层次聚类(ward)", AgglomerativeClustering(n_clusters=4, linkage="ward")),
                    ("DBSCAN(eps=0.3,min_samples=5)", DBSCAN(eps=0.3, min_samples=5))]:
    lab = model.fit_predict(X)
    n_cl = len(set(lab)) - (1 if -1 in lab else 0)
    print(f"[球形簇] {name:32s} 簇数={n_cl}  轮廓系数={silhouette_score(X, lab):.3f}  ARI={adjusted_rand_score(y, lab):.3f}")

print()
# ---- 实验 2：月牙形（非凸结构，K-means 失效）----
Xm, ym = make_moons(n_samples=600, noise=0.05, random_state=42)
Xm = StandardScaler().fit_transform(Xm)
for name, model in [("K-means(k=2)", KMeans(n_clusters=2, n_init=10, random_state=42)),
                    ("层次聚类(单链)", AgglomerativeClustering(n_clusters=2, linkage="single")),
                    ("DBSCAN(eps=0.3,min_samples=5)", DBSCAN(eps=0.3, min_samples=5))]:
    lab = model.fit_predict(Xm)
    n_cl = len(set(lab)) - (1 if -1 in lab else 0)
    print(f"[月牙形] {name:32s} 簇数={n_cl}  轮廓系数={silhouette_score(Xm, lab):.3f}  ARI={adjusted_rand_score(ym, lab):.3f}")

print()
# ---- 肘部法 + 轮廓系数选 k ----
inertias, sils = [], []
for k in range(2, 9):
    km = KMeans(n_clusters=k, n_init=10, random_state=42).fit(X)
    inertias.append(km.inertia_)
    sils.append(silhouette_score(X, km.labels_))
print("k      :", list(range(2, 9)))
print("SSE    :", [round(s, 1) for s in inertias])
print("轮廓系数:", [round(s, 3) for s in sils])
```

**读结果**：球形数据上 K-means 与 ward 几乎完美（ARI≈0.996），DBSCAN 因 $\varepsilon$ 偏小把两簇粘连只找到 3 簇；月牙形数据上 K-means 彻底失效（ARI 0.462），DBSCAN 与单链层次聚类完美还原。**"哪种算法最好"取决于数据形状——这个实验本身就是论文中"方法选型依据"小节的写法。** 轮廓系数在 $k=4$ 处最大（0.795），与真值一致；SSE 曲线的"肘"也在 $k=4$ 附近。

## 10.3 无监督学习（二）：主成分与因子分析做指标降维

### 10.3.1 主成分分析（PCA）

$p$ 个相关指标 $x_1,\dots,x_p$（标准化后）想压成少数综合指标。**建模的一步**：找线性组合 $z=w^\top x$ 使其方差最大——因为方差大 = 信息多。这等价于样本协方差矩阵（相关系数矩阵）$R$ 的特征值分解：

$$
R = W\Lambda W^\top,\qquad z_j = w_j^\top x,\quad \lambda_1\ge\lambda_2\ge\dots\ge\lambda_p\ge 0 .
$$

第 $j$ 主成分的**方差贡献率** $\lambda_j/\sum_i\lambda_i$；保留使累计贡献率达到 80%–90% 的前 $m$ 个主成分（竞赛惯例，需说明取值依据）。**主成分解释**：看载荷向量 $w_j$ 中绝对值大的原始指标，给主成分起"物理名字"（如"综合营养水平"）——这一步做不好，评委的评语常是"降维了但不知道降出了什么"。

### 10.3.2 与因子分析的分工

**因子分析（FA）**假设指标由少数潜在公共因子 + 特有因子生成（$x=Af+\epsilon$），可通过因子旋转（varimax）获得更可解释的结构；**PCA 是纯数学投影，FA 是带模型的统计推断**。竞赛中指标体系降维打分（如"综合发展水平排名"）常用"PCA 算权重 + 载荷解释"，或与第 6 章熵权法对比佐证。注意：PCA 的主成分得分方差大者权重高，与第 6 章"熵权法按离散度赋权"思想同源，可互相印证。

```python
# -*- coding: utf-8 -*-
"""9-2 PCA 主成分分析：方差贡献率、累计贡献率与载荷解释"""
import os; os.environ["OMP_NUM_THREADS"] = "3"
import numpy as np
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

X, y = load_wine(return_X_y=True)          # 178 个葡萄酒样本，13 项理化指标，3 个品种
feat_names = load_wine().feature_names

Xs = StandardScaler().fit_transform(X)     # 量纲不同，必须先标准化！
pca = PCA().fit(Xs)
r = pca.explained_variance_ratio_
print("=== PCA 主成分方差贡献率 ===")
print("前 5 个主成分贡献率:", np.round(r[:5], 3))
print("累计贡献率         :", np.round(np.cumsum(r[:5]), 3))
print("累计 85% 需要的主成分数 =", int(np.argmax(np.cumsum(r) >= 0.85)) + 1)
load = pca.components_[0]
print("PC1 主要载荷:", {n: round(float(v), 2) for n, v in zip(feat_names, load) if abs(v) > 0.35})
```

实际输出：

```text

前 5 个主成分贡献率: [0.362 0.192 0.111 0.071 0.066]
累计贡献率         : [0.362 0.554 0.665 0.736 0.802]
累计 85% 需要的主成分数 = 6
PC1 主要载荷: {'total_phenols': np.float64(0.39), 'flavanoids': np.float64(0.42), 'od280/od315_of_diluted_wines': np.float64(0.38)}
```

PC1 的主载荷全部落在"酚类物质"相关指标上，可命名为"**酚类综合水平**"——13 维指标压缩到 6 维仍保留 85% 信息，且第一主成分有清晰物理含义，这就是论文里"指标体系重构"一节的完整素材。

## 10.4 有监督学习（一）：三大基础分类器与竞赛选型

### 10.4.1 逻辑回归（Logistic Regression）：可解释的基准线

对二分类，对"类别 1 的概率"做 logit 变换后建立线性模型：

$$
P(y=1\mid x)=\frac{1}{1+e^{-(\beta_0+\beta^\top x)}} .
$$

参数用极大似然估计（等价于交叉熵损失最小化）。**竞赛价值**：系数 $\beta_k$ 直接给出"指标 $x_k$ 增加一单位，对数几率（log-odds）变化多少"——评委喜欢这种可解释性；多分类用 softmax 推广（多项逻辑回归）。它是任何分类任务的**第一基准**：准得离谱的复杂模型 + 讲不清的机制，往往不如"逻辑回归 + 系数解读"得分高。

### 10.4.2 决策树：规则化的白盒模型

按特征阈值递归划分样本空间，每个叶节点一个类别。划分准则用信息增益（ID3）、增益率（C4.5）或**基尼指数（CART）**：

$$
\mathrm{Gini}(D)=1-\sum_k p_k^2\quad(\text{越小说明节点越"纯"}).
$$

**优点**：规则可读（"若指标 A>13 且指标 B>3 则判为品种 1"）；**缺点**：单树易过拟合，需限深（`max_depth`）、剪枝或干脆用集成（10.5 节）。

### 10.4.3 支持向量机（SVM）：小样本高维的利器

找最大间隔超平面 $\{x: w^\top x+b=0\}$，即

$$
\min_{w,b}\ \frac{1}{2}\lVert w\rVert^2
\quad\text{s.t.}\quad
y_i(w^\top x_i+b)\ge 1-\xi_i,\ \xi_i\ge 0 ,
$$

$\xi_i$ 是软间隔松弛（容忍少量分错），惩罚系数 $C$ 控制"分错代价"。**核技巧（kernel trick）**：$K(x_i,x_j)=\langle\phi(x_i),\phi(x_j)\rangle$ 隐式映射到高维实现非线性分界，RBF 核 $K=\exp(-\gamma\lVert x_i-x_j\rVert^2)$ 最常用——**先标准化再上 SVM，否则大尺度特征主导距离**。适用：中小样本（$n\lesssim 10^4$）、特征多、边界非线性；不适用：超大数据、需要概率输出（可近似但要另算）。

### 10.4.4 竞赛选型三问

1. **样本量多大？** 百级 → 逻辑回归/决策树/SVM 都可；万级以上 → 随机森林/XGBoost 或逻辑回归（SVM 训练 $O(n^2)$ 起步，慢）。
2. **要解释还是只要准？** 要解释 → 逻辑回归/浅决策树 + 特征重要性；只要准 → 集成方法。
3. **特征什么类型？** 高维稀疏文本 → 线性模型；混合类型 + 未标准化 → 树模型天然免疫量纲；数值连续 + 边界复杂 → SVM(RBF)。

## 10.5 有监督学习（二）：集成方法与特征重要性

### 10.5.1 随机森林（Random Forest）

Bagging 思想：有放回抽样造多棵树 + 每次分裂随机选部分特征，投票（回归取均值）表决。方差被平均后大幅下降，几乎"开箱即用"，**是竞赛分类任务的默认起手式之一**。

### 10.5.2 XGBoost 与梯度提升

Boosting 思想：串行训练，每棵新树拟合前面所有树的残差（负梯度）。XGBoost 在此之上加了二阶泰勒展开的正则化目标：

$$
\mathcal{L}=\sum_i l\bigl(y_i,\hat y_i\bigr)+\sum_j\Omega(f_j),\qquad
\Omega(f)=\gamma T+\frac{\lambda}{2}\lVert w\rVert^2 ,
$$

$T$ 为叶子数。表格数据上 XGBoost/LightGBM 常是精度天花板，**代价是超参数多、需要调参**（`n_estimators, max_depth, learning_rate` 是三大旋钮）。

### 10.5.3 特征重要性：从"黑盒"里抢救解释性

树集成给出特征重要性（分裂增益加权），XGBoost 还有 `plot_importance`。论文写法：**"重要性 Top-k 特征 + 这些特征的领域含义"**——既展示模型精度，又回答"为什么"，这是用机器学习做竞赛与调包侠的区别。

## 10.6 交叉验证与调参：把"运气"关进笼子

**$k$ 折交叉验证（$k$-fold CV）**：训练集均分 $k$ 份，轮流用 1 份验证、$k-1$ 份训练，取平均性能。它回答的问题是："这个分数是模型的实力还是切分方式的运气？"分类任务用**分层抽样**（StratifiedKFold）保持各类比例。

**GridSearchCV**：参数网格 × 交叉验证 = 穷举寻优，自动选出 CV 分数最高的参数组合；网格外的进阶有随机搜索（RandomizedSearchCV）与贝叶斯优化。

**铁律：测试集只准用一次。** 调参、选模型都只能在训练集内部通过 CV 完成；测试集分数在论文里只能出现一次作为最终报告——用测试集反复调参属于数据泄漏，是评委最重扣分点之一。

完整实验（选型对比 + 调参 + 集成 + 重要性）：

```python
# -*- coding: utf-8 -*-
"""9-3 有监督分类选型 + PCA 降维 + 集成方法 + GridSearchCV 调参"""
import os; os.environ["OMP_NUM_THREADS"] = "3"

from sklearn.model_selection import train_test_split, cross_val_score, StratifiedKFold, GridSearchCV

from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.svm import SVC

from sklearn.metrics import accuracy_score

# ---------------- 数据：葡萄酒理化指标（13 个特征，3 个品种，178 样本）----------------
X, y = load_wine(return_X_y=True)
feat_names = load_wine().feature_names

# ---- PCA：指标降维 ----
Xs = StandardScaler().fit_transform(X)
pca = PCA().fit(Xs)
r = pca.explained_variance_ratio_
print("=== PCA 主成分方差贡献率 ===")
print("前 5 个主成分贡献率:", np.round(r[:5], 3))
print("累计贡献率         :", np.round(np.cumsum(r[:5]), 3))
print("累计 85% 需要的主成分数 =", int(np.argmax(np.cumsum(r) >= 0.85)) + 1)
load = pca.components_[0]
print("PC1 主要载荷:", {n: round(float(v), 2) for n, v in zip(feat_names, load) if abs(v) > 0.35})

# ---- 模型对比（统一 5 折分层交叉验证）----
print("\n=== 5 折分层交叉验证（标准化管线）===")
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, stratify=y, random_state=42)
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
```

## 10.7 插值与拟合：一对最容易混用的词

| 工具 | 回答的问题 | 数学形态 | 什么时候用 |
|---|---|---|---|
| 拉格朗日插值 | "过点"（节点处误差必须为 0） | $L(x)=\sum_i y_i\prod_{j\ne i}\frac{x-x_j}{x_i-x_j}$ | 节点少（≤10）、函数光滑、数据精确 |
| 三次样条 | "过点 + 平滑" | 分段三次多项式，节点处一、二阶导连续 | 数据精确但点多；要求光滑曲线（等高线、轨迹） |
| 最小二乘 | "趋势"（允许残差，$m\ll n$） | $\min\sum_i (y_i-f(x_i))^2$ | 数据有噪声；外推预测（衔接第 7 章） |

两个必须知道的陷阱：

1. **Runge 现象**：等距节点的高次多项式插值在端点附近剧烈振荡——**节点多时永远不要用整段高次插值**，改三次样条或分段低次。
2. **过拟合**：拟合次数越高训练误差越小，但测试误差先降后爆——判断标准是**训练误差与测试（或 CV）误差对比**，而不是训练误差本身。

```python
# -*- coding: utf-8 -*-
"""9-4 插值与拟合三件套：拉格朗日插值 / 三次样条 / 最小二乘选型对比"""
import warnings
from numpy.exceptions import RankWarning
warnings.simplefilter("ignore", RankWarning)  # 高次拟合本就病态，演示过拟合用途
import numpy as np
from scipy.interpolate import lagrange, CubicSpline
from numpy.polynomial import polynomial as P

rng = np.random.default_rng(0)

# ---- 1. Runge 现象：高次等距拉格朗日插值发散，样条稳定 ----
f = lambda x: 1 / (1 + 25 * x**2)               # Runge 函数
x_r = np.linspace(-1, 1, 15)                    # 15 个等距节点
L_r = lagrange(x_r, f(x_r))                     # 14 次多项式
cs_r = CubicSpline(x_r, f(x_r))                 # 三次样条
x_rf = np.linspace(-1, 1, 400)
print("Runge 函数 15 节点插值最大误差：")
print("  14 次拉格朗日 =", round(np.max(np.abs(L_r(x_rf) - f(x_rf))), 3), "（高次插值在端点附近剧烈振荡！）")
print("  三次样条      =", round(np.max(np.abs(cs_r(x_rf) - f(x_rf))), 5), "（分段低次，稳定）")

# ---- 2. 稀疏精确节点下的拉格朗日 ----
x_n = np.array([0., 1., 2., 3., 4., 5.])
L = lagrange(x_n, np.sin(x_n))
print("\n6 节点 sin 拉格朗日插值最大误差 =", round(float(np.max(np.abs(L(np.linspace(0,5,101)) - np.sin(np.linspace(0,5,101))))), 4),
      "（节点少、函数光滑时低次插值即可用）")

# ---- 3. 最小二乘：训练误差 vs 测试误差识别过拟合 ----
x = np.linspace(0, 3, 20)                        # 20 个含噪观测
y = np.exp(0.5 * x) * np.cos(2 * x) + rng.normal(0, 0.1, x.size)
x_te = np.linspace(0, 3, 500)                    # 密集"真值"参考（忽略噪声后的趋势）
y_true = np.exp(0.5 * x_te) * np.cos(2 * x_te)
print("\n不同拟合次数的误差对比：")
print(f"{'次数':>4s} {'训练RMSE':>10s} {'测试RMSE':>10s}")
for d in (3, 5, 9, 15, 19):
    c = P.polyfit(x, y, d)
    e_tr = np.sqrt(np.mean((P.polyval(x, c) - y)**2))
    e_te = np.sqrt(np.mean((P.polyval(x_te, c) - y_true)**2))
    print(f"{d:4d} {e_tr:10.3f} {e_te:10.3f}" + ("   <- 训练误差最小但测试误差爆炸：过拟合" if d == 19 else ""))
```

## 10.8 关键公式与方法速查

| 方法 | 适用场景 | 关键公式 | 优缺点/坑 |
|---|---|---|---|
| K-means | 球形簇、大数据 | $\min\sum_c\sum_{x_i\in C_c}\lVert x_i-\mu_c\rVert^2$ | 只到局部最优（多跑 n_init）；非凸簇失效 |
| 层次聚类 | 小样本探索、树状图 | ward/single/... 连接合并 | $O(n^2)$ 内存；切树高度需论证 |
| DBSCAN | 任意形状 + 噪声 | $\varepsilon$-邻域密度可达 | $\varepsilon$ 敏感；密度差异数据差 |
| 轮廓系数 | 聚类内部评价 | $s(i)=\frac{b(i)-a(i)}{\max(a(i),b(i))}$ | 与业务含义对不上时要回到真实标签 |
| PCA | 相关指标降维 | $R=W\Lambda W^\top$，贡献率 $\lambda_j/\sum\lambda$ | 必须标准化；主成分要解释 |
| 因子分析 | 潜因子结构、量表 | $x=Af+\epsilon$，可旋转 | 样本量要求高；因子命名要专业 |
| 逻辑回归 | 二分类基准、要解释 | $P(y=1\mid x)=(1+e^{-(\beta_0+\beta^\top x)})^{-1}$ | 线性决策边界；系数=对数几率 |
| 决策树/CART | 规则白盒 | Gini $=1-\sum p_k^2$ | 单树过拟合，限深/剪枝 |
| SVM(RBF) | 中小样本、非线性 | $\min\frac12\lVert w\rVert^2+C\sum\xi_i$ | 必须标准化；大样本慢；$C,\gamma$ 要调 |
| 随机森林 | 表格数据默认起手 | Bagging + 随机特征 | 重要性偏向高基数特征 |
| XGBoost | 精度天花板 | 正则化梯度提升目标 | 参数多要调；小数据易过拟合 |
| $k$ 折 CV / GridSearchCV | 模型评估与调参 | 分层 $k$ 折 + 网格穷举 | 测试集只用一次（铁律） |
| 拉格朗日插值 | 少节点精确过点 | $\sum_i y_i\prod_{j\ne i}\frac{x-x_j}{x_i-x_j}$ | 高次等距 = Runge 灾难 |
| 三次样条 | 多节点精确 + 光滑 | 分段三次、$C^2$ 连续 | 不适合外推 |
| 最小二乘 | 含噪数据找趋势 | $\min\sum(y_i-f(x_i))^2$ | 次数高了过拟合；外推需谨慎 |

## 10.9 典型例题与样例程序：基于理化指标的葡萄酒品种鉴别

### （1）问题重述

某检测机构获得 178 份葡萄酒样本，每份测定了 13 项理化指标（酒精度、苹果酸、灰分、酚类、色度等），其中 124 份的品种已知（3 个品种，比例约 1 : 1.3 : 1），54 份待判别。要求：(a) 建立"指标 → 品种"的判别模型并评估可靠性；(b) 指出哪些指标对判别贡献最大；(c) 对待判样本给出品种预测与置信度。

### （2）模型假设

1. 13 项指标的测量误差远小于品种间的真实差异，可直接作为判别特征；
2. 待判样本与训练样本来自同一总体（同产地、同工艺），分布无漂移；
3. 各品种在指标空间中可用平滑边界划分（由探索性分析：同品种样本指标相近，故假设合理）；
4. 品种先验比例与已知样本一致，判别用后验概率最大原则。

### （3）符号说明

| 符号 | 含义 |
|---|---|
| $X\in\mathbb{R}^{n\times p}$ | 指标矩阵，$n=178$，$p=13$ |
| $y_i\in\{1,2,3\}$ | 样本 $i$ 的品种标签 |
| $\hat P(y=k\mid x)$ | 模型给出的后验概率（判别置信度） |
| $C$ | 混淆矩阵，$C_{kl}$ = 真实 $k$ 判为 $l$ 的样本数 |
| CV 准确率 | 5 折分层交叉验证平均准确率 |

### （4）模型建立

**三阶段流程**：

1. **预处理**：指标量纲悬殊（酒精度约 13，脯氨酸约 1000），统一 z-score 标准化 $x'=(x-\mu)/\sigma$（放进 pipeline 防止数据泄漏）；
2. **模型族**：$\hat y(x)=\arg\max_k \hat P(y=k\mid x)$，候选后验模型三个——多项逻辑回归（线性边界 + 可解释系数）、RBF 核 SVM（非线性边界，$\hat P$ 由 Platt 缩放近似）、随机森林（规则集成 + 特征重要性）；
3. **选型与调参协议**：训练集内 5 折分层 CV 比较三族，对最优族做 GridSearchCV 精调；测试集只在最后评估一次。

**评价设计**：类别基本均衡，以准确率为主指标，辅以宏平均 precision/recall（防止单类表现掩盖）、混淆矩阵（看具体混在哪两类）、OvR AUC（看概率排序质量）、学习曲线（判断样本量是否足够）。

### （5）求解程序

```python
# -*- coding: utf-8 -*-
"""案例：基于理化指标的葡萄酒品种鉴别（分类建模全流程）
流程：问题重述 -> 模型假设 -> 符号说明 -> 模型建立(多模型选型+调参) -> 求解 -> 检验 -> 评价
"""
import os; os.environ["OMP_NUM_THREADS"] = "3"
import numpy as np
from sklearn.datasets import load_wine
from sklearn.model_selection import train_test_split, cross_val_score, StratifiedKFold, GridSearchCV, learning_curve
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.linear_model import LogisticRegression
from sklearn.svm import SVC
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import (confusion_matrix, classification_report, roc_auc_score)

# ================= 0. 数据获取（对应"问题重述"：13 项理化指标 -> 3 个品种） =================
wine = load_wine()
X, y = wine.data, wine.target
names = wine.feature_names
print(f"样本数 n = {X.shape[0]}, 指标数 p = {X.shape[1]}, 类别数 K = {len(np.unique(y))}")
print("类别分布:", np.bincount(y).tolist(), "（比例约 1:1.3:1，基本均衡，用准确率+宏平均合理）")

# ================= 1. 数据划分与预处理 =================
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, stratify=y, random_state=42)
cv = StratifiedKFold(5, shuffle=True, random_state=42)

# ================= 2. 模型建立：三个候选模型统一在同一交叉验证下选型 =================
candidates = {
    "逻辑回归": make_pipeline(StandardScaler(), LogisticRegression(max_iter=5000)),
    "SVM(RBF)": make_pipeline(StandardScaler(), SVC(probability=True, random_state=42)),
    "随机森林": make_pipeline(StandardScaler(), RandomForestClassifier(n_estimators=300, random_state=42)),
}
print("\n=== 模型选型（5 折分层交叉验证）===")
for name, pipe in candidates.items():
    s = cross_val_score(pipe, Xtr, ytr, cv=cv, scoring="accuracy")
    print(f"{name:8s} CV准确率 {s.mean():.3f} ± {s.std():.3f}")

# ================= 3. 求解：对最优族（SVM）做 GridSearchCV 精调参 =================
param = {"svc__C": [0.1, 1, 10, 100], "svc__gamma": [0.001, 0.01, 0.1, 1]}
gs = GridSearchCV(candidates["SVM(RBF)"], param, cv=cv, scoring="accuracy")
gs.fit(Xtr, ytr)
best = gs.best_estimator_
print("\n=== 调参结果 ===")
print("最优参数:", {k.split("__")[1]: v for k, v in gs.best_params_.items()},
      " CV准确率 =", round(gs.best_score_, 3))

# ================= 4. 检验：测试集一次评估 + 混淆矩阵 + ROC-AUC =================
yhat = best.predict(Xte)
proba = best.predict_proba(Xte)
print("\n=== 测试集检验 ===")
print("混淆矩阵（行=真实品种1/2/3，列=预测）:")
print(confusion_matrix(yte, yhat))
print(classification_report(yte, yhat, target_names=wine.target_names, digits=3))
auc = roc_auc_score(yte, proba, multi_class="ovr", average="macro")
print("宏平均 OvR AUC =", round(auc, 3))

# 学习曲线：判断偏差/方差，回应"样本量是否够"
tr_sizes, tr_sc, cv_sc = learning_curve(best, Xtr, ytr, cv=cv, train_sizes=np.linspace(0.3, 1.0, 5))
print("学习曲线（最后一点）: 训练", round(tr_sc[-1].mean(), 3), " CV", round(cv_sc[-1].mean(), 3),
      "（两线接近且高 -> 偏差主导，样本量已基本充分）")

# ================= 5. 模型解释：随机森林特征重要性（评委关心的"物理意义"） =================
rf = RandomForestClassifier(n_estimators=300, random_state=42).fit(Xtr, ytr)
top = sorted(zip(names, rf.feature_importances_), key=lambda t: -t[1])[:5]
print("\n随机森林特征重要性 Top5（辅助解释）:")
for n, v in top: print(f"  {n:22s} {float(v):.3f}")

# ================= 6. 应用：对 3 个"未知来源"样本给出品种判别与概率 =================
Xnew = Xte[:3]                                   # 演示：以测试集前 3 条充当新样本

    print(f"样本{i}: 判为品种{c+1}({wine.target_names[c]})，概率 = {np.round(p, 3)}")
```


### （6）结果与检验

1. **选型结论**：SVM(RBF) 以 CV 准确率 0.992±0.016 胜出，调参后 $C=1,\gamma=0.1$；测试集准确率 0.981，唯一错误发生在品种 2/3 之间（混淆矩阵第三行）——与化学常识吻合（这两类酚类指标接近）。
2. **多重检验**：AUC=1.0 说明概率排序完美；学习曲线训练/CV 双高且接近 → 不是过拟合也不是欠拟合，样本量对本问题已充分。
3. **解释性检验**：随机森林重要性 Top4（色度、黄酮、脯氨酸、酒精度）与逻辑回归大系数指标基本重合，两个异构模型交叉印证 → 结论可信；这也回应了"为什么判错只在 2/3 类"。
4. **稳健性说明**：随机森林测试集 1.000 vs SVM 0.981 的差异在 54 个测试样本下不具有统计显著性（差 1 个样本即 0.019），论文中应说明选择 SVM 是基于 CV 均值与方差，而非单次测试集数字——这正是"测试集只用一次"原则的示范。

### （7）模型评价

- **优点**：多模型同台 CV 选型，结论有说服力；管线化预处理杜绝泄漏；评价体系多维（准确率/宏平均/混淆矩阵/AUC/学习曲线）互相印证；特征重要性给出领域解释。
- **缺点**：样本量小（178），CV 方差仍不可忽略；SVM 概率输出是近似（Platt 缩放），置信度仅供参考；假设分布无漂移，跨产地推广未验证。
- **改进方向**：加入 SHAP 值做样本级解释；不平衡严重时改用类别权重或 SMOTE 重采样；与本例思路一致的无标签场景可先用 10.2 节聚类预分组再对齐标签（半监督）。

## 10.10 常见误区与竞赛扣分点

1. **不划分训练/测试集就报准确率**（用训练数据评估模型）——最经典的致命伤；或者反过来，**用测试集反复调参**（数据泄漏）。正确姿势：CV 调参 + 测试集终评一次。
2. **聚类前不标准化、SVM/逻辑回归前不标准化**：量纲大的特征主导一切，聚类结果与距离度量失真。
3. **K-means 硬套非凸簇**：拿到环形/流形数据先画散点或用轮廓系数检验，而不是无脑 `KMeans(n_clusters=3)`。
4. **主成分不解释**：报了 6 个主成分却一个载荷都不看，评委评语"降维目的不明"。载荷矩阵 + 命名是必需品。
5. **混淆"准确率"与"分类好坏"**：不平衡数据（欺诈率 1%）下全预测多数类也有 99% 准确率——必须补 precision/recall/F1、AUC 或 PR 曲线。
6. **插值当预测用**：插值保证节点间过点，**不做外推**；用 14 次多项式外推未来数据是教科书级错误（Runge 现象）。
7. **过度信任单一指标**：只报一个最高分的模型（如 XGBoost 1.000）而不给方差与对比，缺乏说服力；多模型同台 + 均值±标准差是基本礼貌。
8. **忽视随机性**：不设 `random_state` 导致结果不可复现；论文中的表格数字跑第二遍就变，评审直接质疑。

## 10.11 拓展延伸

- **与[第 4 章概率统计方法](/xiaoshus-blog/textbooks/modeling/01-foundations/04/)的衔接**：逻辑回归 = 广义线性模型（GLM）家族成员，系数显著性可用统计检验（statsmodels 的 `summary`）补足；聚类结果的簇间差异可用 ANOVA/多元方差分析确认——"机器学习找结构，统计检验下结论"是稳妥的论文组合。
- **与[第 6 章评价与决策模型](/xiaoshus-blog/textbooks/modeling/02-methods/06/)的联动**：PCA/熵权/CRITIC 都是客观赋权，可在论文中并列计算、相互验证权重的一致性。
- **与[第 7 章预测模型](/xiaoshus-blog/textbooks/modeling/02-methods/07/)的衔接**：本章的回归视角（最小二乘、树回归）+ 第 7 章的时间序列结构（滞后特征、ARIMA）= 特征工程框架下的预测建模；XGBoost 做时序预测时务必按时间顺序切分（TimeSeriesSplit），不可随机打乱。
- **与[第 8 章图论与网络模型](/xiaoshus-blog/textbooks/modeling/02-methods/08/)的联动**：谱聚类 = 拉普拉斯矩阵特征分解 + K-means，把图结构变成可聚类的向量。
- **进阶主题**：GBDT 家族对比（XGBoost/LightGBM/CatBoost）、概率校准（CalibratedClassifierCV）、可解释机器学习（SHAP/PDP）、不平衡学习（SMOTE、代价敏感）；深度学习场景（图像/文本）超出国赛常规需求，见配套 AI 教材对应课程。
- **延伸阅读**：Hastie, Tibshirani & Friedman, *The Elements of Statistical Learning*（第 4、9–10、14 章）；司守奎《数学建模算法与应用》统计学习章节；scikit-learn 官方文档的 model selection 与 clustering 教程。

3. 把 10.9 案例的逻辑回归系数与随机森林重要性做对比表；再用 statsmodels 拟合二值化问题（品种 1 vs 其他），指出哪些系数在 5% 水平显著，并解释"显著"与"重要"的区别。

5. **（真题改编，2016 国赛 C 网购评价类）** 对电商评论文本做特征化（TF-IDF）后：先聚类看评论自然分为几类，再构建"好评/差评"分类器，报告混淆矩阵与宏平均 F1；讨论：聚类结果与真实标签对齐吗？错位说明什么？
