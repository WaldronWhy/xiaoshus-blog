## 1.1 变分法：从"求函数的极值"到"求函数的函数的极值"

### 1.1.1 泛函与变分：问题的提出

**本科章已建立**：对函数 $f(x)$ 求极值，令 $\mathrm{d}f/\mathrm{d}x = 0$。**本章加深**：许多物理问题要求极小化的对象是一个**泛函（functional）**——以整条函数曲线为自变量的"函数的函数"：

$$J[y] = \int_{x_1}^{x_2} f\big(y(x),\, y'(x),\, x\big)\,\mathrm{d}x$$

（定义式；记号 $J[y]$ 的方括号强调"自变量是函数 $y$"。）典型问题：两点之间什么曲线最短？最速降线（brachistochrone，伽利略 1638 提出、Bernoulli 1697 解决：答案是一条摆线）？悬链的形状为何是悬链线？**化学中同样的数学**：构象能量极小化是在 $3N$ 维坐标空间找"最低的谷"（泛函自变量是坐标函数）；过渡态理论中把 splitting surface 变分优化（变分过渡态理论，VTST）；而最重要的应用是量子力学的能量极小化——1.1.4 节。

变分的操作对象是曲线的整体形状：让 $y(x)$ 变形为 $y(x) + \varepsilon\,\eta(x)$，其中 $\eta(x)$ 是任意光滑函数且**端点不动** $\eta(x_1) = \eta(x_2) = 0$，$\varepsilon$ 是小参数。极值条件是 $J$ 对 $\varepsilon$ 的一阶导数为零，记作 $\delta J = 0$——与函数极值 $\mathrm{d}f = 0$ 的类比一目了然。

### 1.1.2 Euler–Lagrange 方程的完整推导

**第 1 步（写出扰动后的泛函）**：

$$J[\varepsilon] = \int_{x_1}^{x_2} f\big(y + \varepsilon\eta,\; y' + \varepsilon\eta',\; x\big)\,\mathrm{d}x$$

**第 2 步（对 $\varepsilon$ 求导）**：链式法则逐项求导（依据：$\frac{\mathrm{d}}{\mathrm{d}\varepsilon}f(y+\varepsilon\eta) = \frac{\partial f}{\partial y}\eta$，因为 $\frac{\partial}{\partial\varepsilon}(y+\varepsilon\eta) = \eta$）：

$$\frac{\mathrm{d}J}{\mathrm{d}\varepsilon}\bigg|_{\varepsilon=0} = \int_{x_1}^{x_2}\left(\frac{\partial f}{\partial y}\,\eta + \frac{\partial f}{\partial y'}\,\eta'\right)\mathrm{d}x$$

**第 3 步（分部积分消灭 $\eta'$）**：对第二项用 $\int u\,\mathrm{d}v = [uv] - \int v\,\mathrm{d}u$，取 $u = \frac{\partial f}{\partial y'}$、$\mathrm{d}v = \eta'\,\mathrm{d}x$（即 $v = \eta$）：

$$\int_{x_1}^{x_2}\frac{\partial f}{\partial y'}\,\eta'\,\mathrm{d}x = \underbrace{\left[\frac{\partial f}{\partial y'}\,\eta\right]_{x_1}^{x_2}}_{=\,0\ \text{（端点}\ \eta=0\text{）}} - \int_{x_1}^{x_2}\frac{\mathrm{d}}{\mathrm{d}x}\left(\frac{\partial f}{\partial y'}\right)\eta\,\mathrm{d}x$$

（边界项为零正是"固定端点"条件的用途——若端点自由，这一项保留并给出自然边界条件。）

**第 4 步（引理）**：合并得 $\delta J = \int_{x_1}^{x_2}\left[\dfrac{\partial f}{\partial y} - \dfrac{\mathrm{d}}{\mathrm{d}x}\dfrac{\partial f}{\partial y'}\right]\eta\,\mathrm{d}x$。由于 $\eta(x)$ **任意**，若方括号在任一点非零，总可选 $\eta$ 只在该点附近非零使积分为正——故极值曲线必须逐点满足：

$$\boxed{\ \frac{\partial f}{\partial y} - \frac{\mathrm{d}}{\mathrm{d}x}\left(\frac{\partial f}{\partial y'}\right) = 0\ }\qquad\text{（Euler–Lagrange 方程，一般为一个二阶 ODE）}$$

**校验例（平面最短线）**：$f = \sqrt{1 + y'^2}$（弧长微元）。$\partial f/\partial y = 0$；$\dfrac{\partial f}{\partial y'} = \dfrac{y'}{\sqrt{1+y'^2}}$，令其对 $x$ 的导数为零（E–L）⇒ $y' = $ 常数 ⇒ 直线。数学自洽 ✓。更深的经典结果（推导可套 Beltrami 首积分，见下）：最速降线为摆线 $x = a(\theta - \sin\theta)$，$y = a(1-\cos\theta)$；均匀重力场悬链为悬链线 $y = a\cosh(x/a)$。

**Beltrami 首积分**：当 $f$ 不显含 $x$（$\partial f/\partial x = 0$）时，把 $f - y'\dfrac{\partial f}{\partial y'}$ 对 $x$ 求全导（依据：乘积法则与 $f$ 的全微分 $\frac{\mathrm{d}f}{\mathrm{d}x} = f_y y' + f_{y'}y'' + f_x$）：

$$\frac{\mathrm{d}}{\mathrm{d}x}\left(f - y'\frac{\partial f}{\partial y'}\right) = (f_y y' + f_{y'}y'') - y''f_{y'} - y'\frac{\mathrm{d}}{\mathrm{d}x}f_{y'} + f_x = y'\underbrace{\left(f_y - \frac{\mathrm{d}}{\mathrm{d}x}f_{y'}\right)}_{=\,0\ \text{（E–L）}} + f_x = 0$$

故 $f - y'\,\partial f/\partial y' = $ 常数——把二阶方程降为一阶。这个量在经典力学里正是哈密顿量（能量），也是 1.1.3 节"变分原理 = 物理定律"的枢纽。

### 1.1.3 变分原理：为什么"自然律是极值律"

把 Beltrami 量的物理身份看清：对力学体系取 $f = L(q, \dot q, t)$（Lagrange 函数 $L = T - V$），E–L 方程成为

$$\frac{\mathrm{d}}{\mathrm{d}t}\frac{\partial L}{\partial \dot q} - \frac{\partial L}{\partial q} = 0$$

正是 Lagrange 运动方程（推导：把 $y \to q$、$x \to t$ 代入 1.1.2，逐字翻译）。即**哈密顿原理** $\delta\int L\,\mathrm{d}t = 0$：真实运动使作用量泛函取驻值。光走光程极值（Fermat 原理）、平衡态热力学取 $G$ 极小（$T, p$ 固定，[模块四第 6 章](/xiaoshus-blog/textbooks/chemistry/04-physical/01/)）、能量面驻点定义反应物与过渡态——"求泛函驻点"是贯穿物理化学的元原理。化学家的直接受益：

- **构象搜索 = 在 $3N$ 坐标上极小化势能泛函**（分子力学/DFT 几何优化都以此为数学骨架）；
- **变分过渡态理论（VTST）**：把分割面位置变分以最小化穿越通量，得到不高于传统 TST 的速率上界（Truhlar 学派），衔接[第 7 章 过渡态理论](/xiaoshus-blog/textbooks/chemistry/04-physical/02/)；
- **量子变分法**（下节）——本章的主线。

### 1.1.4 与量子力学变分法的数学衔接（预告模块五进阶）

**变分定理**：设 $\hat H$ 的本征态与能量为 $\hat H|\psi_n\rangle = E_n|\psi_n\rangle$（$E_0 \le E_1 \le \cdots$）。对任意归一化试探函数 $\Phi$（$\langle\Phi|\Phi\rangle = 1$）：

$$\langle \hat H \rangle \equiv \langle\Phi|\hat H|\Phi\rangle \ \ge\ E_0$$

**证明（不跳步）**：把 $\Phi$ 用本征态完备基展开：$\Phi = \sum_n c_n\psi_n$，则归一化给出 $\sum_n |c_n|^2 = 1$（依据：本征态正交归一 $\langle\psi_m|\psi_n\rangle = \delta_{mn}$）。代入能量期望（依据：$\hat H$ 的本征值方程）：

$$\langle\hat H\rangle = \sum_{m,n} c_m^* c_n \langle\psi_m|\hat H|\psi_n\rangle = \sum_{m,n} c_m^* c_n E_n \delta_{mn} = \sum_n |c_n|^2 E_n$$

由 $E_n \ge E_0$ 对一切 $n$ 成立：$\sum_n |c_n|^2 E_n \ge \sum_n |c_n|^2 E_0 = E_0$。证毕。**等号当且仅当所有 $n > 0$ 的 $c_n = 0$，即 $\Phi$ 恰为基态。**

这给出一条不需要精确解的能量上界路线：构造含参数 $\alpha$ 的试探函数 $\Phi_\alpha$，计算 $\langle\hat H\rangle(\alpha)$，令 $\partial\langle\hat H\rangle/\partial\alpha = 0$（这正是变分法：$\langle\hat H\rangle$ 是 $\alpha$ 的函数，不是泛函——泛函极值问题被参数化后退化为本章 1.1.1 的普通极值）。例题 1-1 完整演示。

**与矩阵特征值的衔接**：若把试探函数限制在基函数 $\{\chi_i\}$ 的线性组合 $\Phi = \sum_i c_i\chi_i$ 上变分，得到的不是标量方程而是**广义本征值问题**

$$\mathbf{H}\mathbf{c} = E\,\mathbf{S}\,\mathbf{c},\qquad H_{ij} = \langle\chi_i|\hat H|\chi_j\rangle,\quad S_{ij} = \langle\chi_i|\chi_j\rangle$$

（推导思路与 1.1.2 相同：$\delta(\langle\Phi|\hat H|\Phi\rangle - E\langle\Phi|\Phi\rangle) = 0$ 对每个 $c_i^*$ 求偏导。）

这正是[第 1 章 1.3.2 节](/xiaoshus-blog/textbooks/chemistry/01-foundations/01/)"久期方程"的来源。**Hartree–Fock 就是把试探函数限制为单个 Slater 行列式的最优解**：能量是精确基态能量的上界，且随基组增大单调下降（变分原理保证）；密度泛函理论的 Hohenberg–Kohn 定理同样以能量泛函极小为基本结构。完整的 HF 自洽场方程推导与基组技术见[第 9 章 量子化学基础](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/01/)及其进阶章（模块五进阶：HF/DFT 与电子相关）——本节的任务是让你明白：**量子化学计算软件每次自洽迭代，都是在执行一次 1.1.2 节的变分极小化。**

## 1.2 定态微扰论：当精确解不存在时的系统性展开

### 1.2.1 非简并定态微扰：一阶与二阶的完整推导

**本科章已建立**：精确可解模型（势箱、谐振子、氢原子，[第 9 章](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/01/)正式展开）。**本章加深**：真实分子与"精确模型"之间永远差一项——外加电场（Stark 效应）、分子间作用、非谐性。微扰论（perturbation theory）回答：**若 $\hat H = \hat H^{(0)} + \lambda\hat V$（$\lambda\ll 1$），如何用 $\hat H^{(0)}$ 的已知解系统性修正能量与波函数？**

设 $\hat H^{(0)}|n^{(0)}\rangle = E_n^{(0)}|n^{(0)}\rangle$，$\hat V$ 厄米。把能级与态矢展开为 $\lambda$ 的幂级数：

$$E_n = E_n^{(0)} + \lambda E_n^{(1)} + \lambda^2 E_n^{(2)} + \cdots,\qquad |n\rangle = |n^{(0)}\rangle + \lambda|n^{(1)}\rangle + \lambda^2|n^{(2)}\rangle + \cdots$$

采用**中间归一化**约定 $\langle n^{(0)}|n\rangle = 1$，即 $\langle n^{(0)}|n^{(k\ge1)}\rangle = 0$（波函数修正与零阶态正交，只是归一化选择，不损失一般性）。

**第 1 步（代入本征方程并按 $\lambda$ 幂次配平）**：

$$\big(\hat H^{(0)} + \lambda\hat V\big)\big(|n^{(0)}\rangle + \lambda|n^{(1)}\rangle + \lambda^2|n^{(2)}\rangle + \cdots\big) = \big(E_n^{(0)} + \lambda E_n^{(1)} + \lambda^2 E_n^{(2)} + \cdots\big)\big(|n^{(0)}\rangle + \lambda|n^{(1)}\rangle + \cdots\big)$$

逐幂比较（依据：等式对任意小 $\lambda$ 成立 ⇒ 各幂次系数分别相等）：

- $\lambda^0$：$\big(\hat H^{(0)} - E_n^{(0)}\big)|n^{(0)}\rangle = 0$ ✓（零阶方程，自动满足）
- $\lambda^1$：$\big(\hat H^{(0)} - E_n^{(0)}\big)|n^{(1)}\rangle = \big(E_n^{(1)} - \hat V\big)|n^{(0)}\rangle$
- $\lambda^2$：$\big(\hat H^{(0)} - E_n^{(0)}\big)|n^{(2)}\rangle = \big(E_n^{(1)} - \hat V\big)|n^{(1)}\rangle + E_n^{(2)}|n^{(0)}\rangle$

**第 2步（一阶能量）**：用 $\langle n^{(0)}|$ 左乘 $\lambda^1$ 式。左端为零（依据：$\hat H^{(0)}$ 厄米 ⇒ $\langle n^{(0)}|\hat H^{(0)} = E_n^{(0)}\langle n^{(0)}|$，两相抵消）：

$$0 = E_n^{(1)}\underbrace{\langle n^{(0)}|n^{(0)}\rangle}_{=1} - \langle n^{(0)}|\hat V|n^{(0)}\rangle \quad\Longrightarrow\quad \boxed{E_n^{(1)} = V_{nn} = \langle n^{(0)}|\hat V|n^{(0)}\rangle}$$

（一阶能移 = 微扰在未微扰态上的平均值——"微扰平均多大，能级就移多少"。）

**第 3 步（一阶波函数）**：用 $\langle m^{(0)}|$（$m \ne n$）左乘 $\lambda^1$ 式：

$$\big(E_m^{(0)} - E_n^{(0)}\big)\langle m^{(0)}|n^{(1)}\rangle = E_n^{(1)}\underbrace{\langle m^{(0)}|n^{(0)}\rangle}_{=0} - V_{mn} \quad\Longrightarrow\quad \langle m^{(0)}|n^{(1)}\rangle = \frac{V_{mn}}{E_n^{(0)} - E_m^{(0)}}$$

故（中间归一化下 $|n^{(1)}\rangle$ 无 $|n^{(0)}\rangle$ 分量）：

$$|n^{(1)}\rangle = \sum_{m\ne n}\frac{V_{mn}}{E_n^{(0)} - E_m^{(0)}}\,|m^{(0)}\rangle$$

**物理图像**：微扰把其他态按"近邻更沾光"的比例混入——分母是能隙，**能隙越小的态混入越多**；这就是分子在外场中"被极化"的微观机制（外场混合不同宇称态，产生诱导偶极）。

**第 4 步（二阶能量）**：用 $\langle n^{(0)}|$ 左乘 $\lambda^2$ 式：

$$0 = E_n^{(1)}\underbrace{\langle n^{(0)}|n^{(1)}\rangle}_{=0} - \langle n^{(0)}|\hat V|n^{(1)}\rangle + E_n^{(2)} \quad\Longrightarrow\quad E_n^{(2)} = \langle n^{(0)}|\hat V|n^{(1)}\rangle$$

把 $|n^{(1)}\rangle$ 的展开代入（依据：完备性 $\sum_m|m^{(0)}\rangle\langle m^{(0)}| = \hat 1$；$m = n$ 项因正交性为零）：

$$\boxed{\ E_n^{(2)} = \sum_{m\ne n}\frac{|V_{mn}|^2}{E_n^{(0)} - E_m^{(0)}}\ }$$

（$V_{nm}V_{mn} = |V_{mn}|^2$，用了 $\hat V$ 厄米。）

**两条立即可得的推论**：① **基态二阶能移恒为负**（$E_n^{(0)} > E_m^{(0)}$ 对一切激发态成立 ⇒ 每项分母为负）——微扰把基态"压得更低"；② **能级排斥（level repulsion）**：两个能级在微扰下互相远离，近者被推下、远者被推上——光谱学中避免交叉（avoided crossing）的根源。

### 1.2.2 适用判据与失效警告

整套展开的有效性要求**逐项收敛**，实用判据是一阶波函数修正远小于 1：

$$\left|\frac{V_{mn}}{E_n^{(0)} - E_m^{(0)}}\right| \ll 1\quad(\forall m\ne n)$$

两个失效模式必须在动笔前排查：

1. **简并**：$E_n^{(0)} = E_m^{(0)}$ 使分母为零——必须先做简并微扰（1.2.3）；
2. **强耦合**：即便无简并，$\lambda$ 大到级数发散时公式失效。微扰级数通常是**渐近级数**（asymptotic series）：取前几项精度提高、项数多到某阶后反而恶化。例题 1-2 的数值演示：$\lambda = 0.1$ 时一+二阶误差 1.9%，$\lambda = 1$ 时二阶截断已给出**符号错误**的结果。

### 1.2.3 简并微扰：在简并子空间内对角化

设零阶有 $g$ 重简并：$\hat H^{(0)}|a\rangle = E^{(0)}|a\rangle$，$a = 1,\dots,g$。1.2.1 的推导在 $m,n$ 同属简并子空间时分母为零——数学上的病灶是"简并态的选择不唯一"。**正确处理**：真正的零阶态应是简并子空间内的某种线性组合 $|\psi^{(0)}\rangle = \sum_a c_a|a\rangle$，选择标准是**让 $\hat V$ 在子空间内对角**。

**推导**：把 $\lambda^1$ 方程向简并子空间投影（用 $\langle b^{(0)}|$，$b$ 属于该子空间）：

$$0 = \langle b^{(0)}|\big(E^{(1)} - \hat V\big)|\psi^{(0)}\rangle = E^{(1)}c_b - \sum_a V_{ba}c_a \quad\Longrightarrow\quad \sum_a V_{ba}c_a = E^{(1)}c_b$$

非平凡解条件是**久期方程**（与[第 1 章 1.3.2 节](/xiaoshus-blog/textbooks/chemistry/01-foundations/01/)的特征值方程完全同构）：

$$\boxed{\ \det\big(\mathbf{V}^{(g)} - E^{(1)}\mathbf{I}\big) = 0\ }$$

解出 $g$ 个 $E^{(1)}_\alpha$ 与组合系数 $c_a^{(\alpha)}$；若 $\hat V$ 已把简并完全解除（$g$ 个根互异），则各 $\alpha$ 支再按 1.2.1 的非简并公式做二阶修正（此时求和只含子空间外的态，不再发散）。

**为什么必须这样**：想象从"简并微扰"连续过渡到"非简并微扰"——给零阶哈密顿加一点 $\delta$ 把简并劈开 $E_m^{(0)} - E_n^{(0)} = \delta\to 0$：非简并公式中 $V_{mn}/\delta\to\infty$，唯一自洽的出路是 $\lambda$ 修正与 $\delta$ 同量级、不可分先后，即必须整体对角化。**这一"先对角化、后展开"思想在简并分子轨道、晶体场分裂、Jahn–Teller 畸变（[第 4 章 4.6.2 节](/xiaoshus-blog/textbooks/chemistry/02-inorganic/02/)）中反复出现。**

### 1.2.4 Stark 效应：贯穿算例线

把电场微扰 $\hat V = -\hat{\boldsymbol{\mu}}\cdot\mathbf{F} = eF\hat z$（电子电荷取 $-e$、沿 $z$ 加场，$\hat{\boldsymbol{\mu}} = -e\hat z$ 为偶极算符）加到氢原子上。

**基态（非简并）**：$E_{1s}^{(1)} = -eF\langle 1s|\hat z|1s\rangle = 0$（依据：$|1s\rangle$ 宇称偶、$z$ 宇称奇 ⇒ 被积函数为奇函数，积分为零——**球对称原子无永久偶极**）。二阶求和（对 $np$ 态）的解析值（经典结果，见 Landau–Lifshitz《量子力学》§76）：

$$\Delta E_{1s}^{(2)} = -\frac{9}{4}\,a_0^3 F^2$$

与极化率定义 $\Delta E = -\tfrac12\alpha F^2$ 比较，得氢原子静极化率 $\alpha = 4.5\,a_0^3$（换算见例题 1-3 讨论）。**外场把基态压低**（1.2.1 推论①的直接体现）。

**$n = 2$ 激发态（四重简并 $2s, 2p_0, 2p_{\pm1}$）**：一阶修正非零——这是简并微扰的标准算例，完整推导见**例题 1-3**：久期方程在 $\{2s, 2p_0\}$ 子空间给 $E^{(1)} = \pm 3ea_0F$，$2p_{\pm1}$ 不动。分裂 $\propto F$ 一次方（**线性 Stark 效应**），1913 年 Stark 在氢 Balmer 线上观测到并获 1919 年诺贝尔物理学奖。基态无近简并反宇称伙伴，只有 $\propto F^2$ 的**二次 Stark 效应**——简并结构决定响应阶次，这是"对称性控制物理"的漂亮示范。

## 1.3 线性响应与涨落：关联函数的化学

### 1.3.1 Kubo 响应公式（完整推导）

平衡系综（密度算符 $\hat\rho_0$）在 $t = -\infty$ 起受微扰 $\hat H'(t) = -f(t)\hat B$（$f$ 为广义力场，$\hat B$ 为与之耦合的力学量）作用，问可观测量 $\hat A$ 如何响应。**本科章已建立**：定态微扰（1.2 节，离散能级语言）。**本章加深**：热平衡多体系统的**时域**响应——这正是光谱学的理论骨架。

**第 1 步（相互作用图景）**：把演化拆为 $\hat H_0$ 部分（并入算符）与 $\hat H'$ 部分（并入态矢）。一阶修正的态矢：$|\psi(t)\rangle_{\mathrm{I}} = |\psi_0\rangle - \frac{i}{\hbar}\int_{-\infty}^{t}\hat H_{\mathrm I}'(t')|\psi_0\rangle\,\mathrm{d}t'$（依据：一阶 Dyson 展开；$\hat H_{\mathrm I}'(t') = e^{i\hat H_0t'/\hbar}\hat H'e^{-i\hat H_0t'/\hbar}$）。

**第 2 步（期望值到一阶）**：$\delta\langle A(t)\rangle = \langle\psi^{(1)}|\hat A_{\mathrm I}(t)|\psi_0\rangle + \langle\psi_0|\hat A_{\mathrm I}(t)|\psi^{(1)}\rangle$。代入 $|\psi^{(1)}\rangle$（厄米共轭注意 $i\to-i$）：

$$\delta\langle A(t)\rangle = \frac{i}{\hbar}\int_{-\infty}^{t}\mathrm{d}t'\,\langle\psi_0|\hat H_{\mathrm I}'(t')\hat A_{\mathrm I}(t)|\psi_0\rangle - \frac{i}{\hbar}\int_{-\infty}^{t}\mathrm{d}t'\,\langle\psi_0|\hat A_{\mathrm I}(t)\hat H_{\mathrm I}'(t')|\psi_0\rangle = \frac{i}{\hbar}\int_{-\infty}^{t}\mathrm{d}t'\ \langle[\hat H_{\mathrm I}'(t'),\, \hat A_{\mathrm I}(t)]\rangle_0$$

**第 3 步（代入 $\hat H' = -f\hat B$ 并用平稳性）**：平衡关联函数只依赖时间差（time-translation invariance）：$\langle \hat B(t')\hat A(t)\rangle_0 = \langle\hat B(0)\hat A(t - t')\rangle_0$。换元 $\tau = t - t'$（$\tau\in[0,\infty)$，注意 $\mathrm{d}t' = -\mathrm{d}\tau$、上下限翻转）：

$$\delta\langle A(t)\rangle = \int_0^\infty \chi_{AB}(\tau)\, f(t-\tau)\,\mathrm{d}\tau,\qquad \boxed{\ \chi_{AB}(t) = \frac{i}{\hbar}\,\theta(t)\,\langle[\hat A(t),\, \hat B(0)]\rangle_0\ }$$

（$\theta(t)$ 为阶跃函数，保证因果性：现在的外力不影响过去的响应。）$\chi_{AB}$ 称**响应函数**（response function），其傅里叶分量 $\chi_{AB}(\omega)$ 的虚部 $\chi''(\omega)$ 正比于系统对频率 $\omega$ 扰动的**吸收**——红外、拉曼、介电损耗谱的强度全部由它给出。

### 1.3.2 涨落–耗散定理（FDT）

响应（耗散）与自发涨落不是独立的两件事。定义经典关联函数 $C(t) = \langle A(t)A(0)\rangle_0$ 及其谱密度 $S(\omega) = \int e^{i\omega t}C(t)\,\mathrm{d}t$，则**经典极限**（$\hbar\omega \ll k_{\mathrm B}T$）下：

$$\boxed{\ \chi''(\omega) = \frac{\omega}{2k_{\mathrm B}T}\,S(\omega)\ }$$

（量子版本：对称化谱密度 $S_{\mathrm{sym}}(\omega) = \hbar\coth\!\big(\hbar\omega/2k_{\mathrm B}T\big)\,\chi''(\omega)$；$T\to0$ 时右端趋于 $\hbar|\omega|\,\chi''$ 的形式体现零点涨落——低温下涨落不消失。）**读法**：系统对驱动"吸收多少"（$\chi''$），完全由它在无驱动时"自己怎么晃"（$S$）决定。特例与化学落点：

- **Einstein 关系** $D = \mu k_{\mathrm B}T$（迁移率 × 涨落）：布朗粒子扩散（扩散 = 涨落）与摩擦（= 耗散）被同一温度锁定——[第 1 章 1.6.2 节](/xiaoshus-blog/textbooks/chemistry/01-foundations/01/)的 Stokes–Einstein 方程是它在流体力学中的化身。
- **Green–Kubo 公式**：$D = \int_0^\infty \langle v(0)v(t)\rangle\,\mathrm{d}t$——分子动力学模拟中扩散系数的标准算法（对速度自关联函数积分），把 1.3.1 的形式理论变成可执行的程序。
- **谱学**：红外吸收线形 $I(\omega)\propto \chi''_{\mu\mu}(\omega)$，即偶极自关联函数的谱；液相振动的退相位时间（dephasing）、NMR 的 $T_1$（Bloembergen–Purcell–Pound 理论：$1/T_1$ 由谱密度在 Larmor 频率处的取值决定）都是"关联函数衰减多快"的量。

> **前向**：FDT 是非平衡统计的入口；[模块四进阶（非平衡态热力学与反应网络动力学）](/xiaoshus-blog/textbooks/chemistry/04-physical/02/)与 1.4 节的随机过程在"涨落"这个关键词下会师。

### 1.3.3 化学中的关联函数速览

| 关联函数 | 测什么 | 谱学/实验落点 |
|---|---|---|
| $\langle\boldsymbol\mu(t)\boldsymbol\mu(0)\rangle$ | 偶极涨落 | IR 吸收线形、介电弛豫（Debye） |
| $\langle\alpha_{ij}(t)\alpha_{ij}(0)\rangle$（极化率） | 电子云涨落 | 拉曼/Rayleigh 散射 |
| $\langle v(t)v(0)\rangle$ | 速度涨落 | Green–Kubo 扩散、中子散射 |
| $\langle I(t)I(0)\rangle - \langle I\rangle^2$ | 荧光强度涨落 | 荧光相关谱 FCS（单分子扩散与缔合） |
| $\langle M(t)M(0)\rangle$ | 磁化涨落 | NMR $T_1/T_2$（BPP 理论） |

共同语法：**谱 = 涨落的傅里叶像**。记住这一句，第 5、10 章的谱学就不再是一堆孤立的经验规则。

## 1.4 化学中的随机过程：从平均行为到涨落实相

### 1.4.1 为什么确定性速率方程不够用

[第 1 章 1.2 节](/xiaoshus-blog/textbooks/chemistry/01-foundations/01/)的速率方程 $\mathrm{d}[\mathrm{A}]/\mathrm{d}t = -k[\mathrm{A}]$ 是**确定性**的：给定初值，未来唯一确定。它的隐含前提是分子数巨大——随机涨落按 $\sigma/\langle N\rangle \sim 1/\sqrt{\langle N\rangle}$ 相对收缩（大数定律）。但在活细胞里，一个基因的转录因子拷贝数可以是**个位数**（大肠杆菌 LacI 约 10 个分子/细胞）：$\sigma/\langle N\rangle \sim 30\%$ 的涨落不是"测量误差"，而是**物理实在**——同样的基因型表达出不同的表型（抗生素抗性的"幸存者"往往就是噪声的产物）。本节把速率方程升级为对**概率分布** $P(\mathbf{x}, t)$（$\mathbf{x}$ 为各物种分子数向量）的描述。

### 1.4.2 化学主方程（chemical master equation, CME）

**马尔可夫假设**：未来分布只依赖当前状态（分子无记忆）。定义倾向性函数：

$$a_j(\mathbf{x})\,\mathrm{d}t \equiv P\big(\text{反应}\ j\ \text{在}\ (t, t+\mathrm{d}t)\ \text{内发生}\ \big|\ \mathbf{X}(t) = \mathbf{x}\big)$$

（定义式；$a_j$ 正比于反应物组合数 $h_j(\mathbf{x})$ 与随机速率常数 $c_j$，见 1.4.5。）反应 $j$ 使 $\mathbf{x} \to \mathbf{x} + \boldsymbol\nu_j$。**概率守恒（进出账）**给出一般 CME：

$$\frac{\partial P(\mathbf{x}, t)}{\partial t} = \sum_j\Big[a_j(\mathbf{x} - \boldsymbol\nu_j)\,P(\mathbf{x} - \boldsymbol\nu_j, t)\ -\ a_j(\mathbf{x})\,P(\mathbf{x}, t)\Big]$$

（推导：流入 = 从 $\mathbf{x}-\boldsymbol\nu_j$ 经反应 $j$ 跳到 $\mathbf{x}$ 的概率流；流出 = 当前态经任意反应离开的概率；每项乘 $\mathrm{d}t$ 后取极限。）

**标准算例：单分子异构化 $\mathrm A \rightleftharpoons \mathrm B$（封闭系，$N_A + N_B = N$）**。令 $n = N_B$，则倾向性 $a_+(n) = k_1(N - n)$（A→B）与 $a_-(n) = k_{-1}n$（B→A）。逐态记账（$n$ 从 $n-1$ 经 A→B 流入：该态下 A 有 $N-(n-1)$ 个；从 $n+1$ 经 B→A 流入：该态下 B 有 $n+1$ 个；流出项 $(N-n)k_1 + nk_{-1}$）：

$$\frac{\mathrm{d}P_n}{\mathrm{d}t} = (N - n + 1)k_1 P_{n-1} + (n+1)k_{-1}P_{n+1} - \big[(N-n)k_1 + n k_{-1}\big]P_n$$

这是一个线性 ODE 组（[第 1 章 1.3 节](/xiaoshus-blog/textbooks/chemistry/01-foundations/01/)矩阵特征的用武之地：转移矩阵的**特征值 = 弛豫速率谱**）。解析结果（推导见例题 1-4）：每分子独立做两态马尔可夫过程，$P_n(t)$ 为参数随时间变化的**二项分布**，均值方程与确定性速率方程**完全一致**，方差有独立方程（闭合）。一般体系（含双分子反应）均值方程会耦合到高阶矩（矩层级不闭合）——这正是需要 SSA（1.4.5）的原因。

### 1.4.3 化学 Langevin 方程（chemical Langevin equation, CLE）

CME 精确但高维难解；确定性 ODE 丢掉涨落。Gillespie（2000）证明：当时间步 $\tau$ 同时满足（i）足够大，使各反应发生多次（$a_j\tau \gg 1$，中心极限定理启动）；（ii）足够小，使 $a_j$ 基本不变——则 $P_j$ 近似泊松分布，且泊松噪声可用高斯白噪声替代。分子数成为**随机微分方程**（SDE）：

$$\mathrm{d}X_i(t) = \sum_j \nu_{ij}\,a_j(\mathbf{x})\,\mathrm{d}t + \sum_j \nu_{ij}\sqrt{a_j(\mathbf{x})}\,\mathrm{d}W_j(t)$$

（$\mathrm{d}W_j$ 为独立 Wiener 增量，$\langle \mathrm{d}W_j\rangle = 0$、$\langle \mathrm{d}W_j^2\rangle = \mathrm{d}t$。）**读法**：漂移项就是确定性速率方程（$\sum\nu_{ij}a_j$ 恰为 $\mathrm{d}x_i/\mathrm{d}t$ 的化学计量组合），噪声幅度 $\sqrt{a_j}$ 随反应越快越吵——**快反应自带大噪声**，这是 Poisson 涨落 $\sigma^2 = \langle N\rangle$ 的直接翻译。CLE 是确定性图像与全随机图像之间的桥梁：数值上用 Euler–Maruyama 格式积分即可。

### 1.4.4 Fokker–Planck 方程（简介）

与 SDE 等价的概率密度方程（Itô 解释下）：

$$\frac{\partial P(x, t)}{\partial t} = -\frac{\partial}{\partial x}\big[A(x)P\big] + \frac{1}{2}\frac{\partial^2}{\partial x^2}\big[B(x)P\big]$$

（$A$ 为漂移系数、$B$ 为扩散系数；CLE 的 $A_i = \sum_j\nu_{ij}a_j$、$B_{ij} = \sum_j\nu_{ij}\nu_{kj}a_j$。）特例：$A = 0$、$B = 2D$ 时退化为扩散方程。稳态求解用**零流条件**（概率流 $J = AP - \tfrac12\partial(BP)/\partial x = 0$）可解析得到平衡分布（练习 1-7 对基因表达 birth–death 过程执行一遍，稳态恰为 Poisson 分布——与 CME 精确稳态一致）。FPE 的价值在于把"分布演化"变成一个**线性偏微分方程**，可用[第 1 章](/xiaoshus-blog/textbooks/chemistry/01-foundations/01/)的算子/特征值语言处理；系统处理见 van Kampen 与 Gardiner 的专著（1.9 节）。

### 1.4.5 Gillespie 随机模拟算法（SSA）：完整推导

**目标**：从 CME 的精确解中抽出**样本轨迹**（每次模拟一条"假想实验室"的分子数时间线）。Gillespie（1977）的直接法（direct method）不含时间步长近似，是**精确**的蒙特卡洛算法（与[AI教材·采样方法与蒙特卡洛](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/06/)的重要性抽样思想同源）。

**第 1 步（倾向性函数的组成）**：$a_j(\mathbf{x}) = c_j\,h_j(\mathbf{x})$。$h_j$ 是反应 $j$ 的**反应物组合数**：$\mathrm A + \mathrm B \to$ 时 $h_j = N_A N_B$；$2\mathrm A \to$ 时 $h_j = N_A(N_A-1)/2$（依据：分子不可分辨，从 $N_A$ 个里取有序对去一半）。$c_j$ 为**随机速率常数**，与[第 7 章](/xiaoshus-blog/textbooks/chemistry/04-physical/02/)的宏观速率常数 $k$ 的换算依赖体积 $V$：单分子 $c_j = k$；$\mathrm A+\mathrm B$ 型 $c_j = k/V$；$2\mathrm A$ 型 $c_j = 2k/V$（因子 2 来自 $h_j$ 中的 $1/2$ 与宏观速率 $-\mathrm{d}[A]/\mathrm{d}t = 2k[\mathrm A]^2$ 的系数约定对齐；量纲检查：$c_j$ 单位使 $a_j$ 为 $\mathrm{s^{-1}}$ ✓）。**常见错误就是不做这个换算直接把 $k$ 当 $c_j$ 用**（见 1.7 节）。

**第 2 步（"下一步反应"的联合分布）**：定义 $P(\tau, j\,|\,\mathbf{x}, t)$ = 下一次反应在 $t+\tau$ 之后 $\mathrm{d}\tau$ 内发生、且恰为反应 $j$ 的概率密度。关键分解：$\tau$ 与"谁先发生"互相独立（无记忆性）。先求"到 $\tau$ 时刻仍无任何反应"的概率 $P_0(\tau)$：在 $\mathrm{d}t$ 内不发生反应的概率为 $1 - a_0(\mathbf{x})\mathrm{d}t$（$a_0 = \sum_j a_j$，依据：互斥事件概率相加），故

$$P_0(\tau + \mathrm{d}\tau) = P_0(\tau)\big(1 - a_0\,\mathrm{d}\tau\big)\ \Longrightarrow\ \frac{\mathrm{d}P_0}{\mathrm{d}\tau} = -a_0 P_0\ \Longrightarrow\ P_0(\tau) = e^{-a_0\tau}$$

于是 $P(\tau, j)\,\mathrm{d}\tau = \underbrace{e^{-a_0\tau}}_{\text{此前无事}}\cdot\underbrace{a_j\,\mathrm{d}\tau}_{\text{反应}\ j\ \text{发生}}$，即 $P(\tau, j) = a_j e^{-a_0\tau}$。边缘分布 $P(\tau) = a_0e^{-a_0\tau}$（指数分布），条件分布 $P(j\,|\,\tau) = a_j/a_0$（**反应越快越常被抽中**）。

**第 3 步（均匀随机数反演抽样）**：取独立均匀随机数 $u_1, u_2 \in (0,1)$。对指数分布做反变换：$P(\tau \le T) = 1 - e^{-a_0T} = u_1 \Rightarrow \tau = \frac{1}{a_0}\ln\frac{1}{u_1}$（对数宗量无因次 ✓）。对离散分布：选最小的 $j$ 使 $\sum_{j'=1}^{j} a_{j'} > u_2 a_0$。

**第 4 步（算法框）**：

```text
SSA（直接法）：
1. 初始化：物种分子数 x、t = 0；
2. 计算各倾向性 a_j(x) 与总和 a0；
3. 抽 u1, u2 ∈ (0,1)：τ = ln(1/u1)/a0；按累积 a_j/a0 选反应 j；
4. 更新 x → x + ν_j，t → t + τ；
5. 若 t < t_final 返回第 2 步。
```

**性质与代价**：每条轨迹是 CME 的**精确**样本（无时间离散化误差）；代价是每步 $O(\mathrm{耗}a_0)$ 且步长随 $a_0$ 增大而变小——高浓度体系步数爆炸，此时用 $\tau$-leaping（Gillespie 2001，即 CLE 的泊松 leap 离散化）折中。多轨迹统计（均值、方差、双峰直方图）就是 1.4.2 分布的蒙特卡洛估计——**例题 1-5 用它研究基因开关**。

## 1.6 典型例题与解题思路

### 例题 1-1（基础计算）变分法：氢原子基态的能量上界

**题**：取试探函数 $\Phi_\alpha = \big(\alpha^3/\pi\big)^{1/2}e^{-\alpha r}$（已归一化，$\alpha > 0$ 为变分参数），计算 $\langle\hat H\rangle(\alpha)$ 并求极小；说明结果与实验电离能 1312 kJ/mol 的关系。

**解题思路**：算 $\langle T\rangle$ 与 $\langle V\rangle$ 各自的 $\alpha$ 依赖 → 极值条件 → 与精确值比较 → 强调"上界"含义。

**解**：动能项需要 $\nabla^2\Phi$。对球对称函数 $\nabla^2 = \frac{1}{r^2}\frac{\mathrm{d}}{\mathrm{d}r}\big(r^2\frac{\mathrm{d}}{\mathrm{d}r}\big)$：$\frac{\mathrm{d}\Phi}{\mathrm{d}r} = -\alpha\Phi$，$r^2\frac{\mathrm{d}\Phi}{\mathrm{d}r} = -\alpha r^2\Phi$，再求导得 $\frac{\mathrm{d}}{\mathrm{d}r}(-\alpha r^2\Phi) = (-2\alpha r + \alpha^2 r^2)\Phi$，故

$$\nabla^2\Phi_\alpha = \big(\alpha^2 - 2\alpha/r\big)\Phi_\alpha$$

$$\langle T\rangle = \int\Phi\left(-\frac{\hbar^2}{2m_e}\nabla^2\right)\Phi\,\mathrm{d}\tau = -\frac{\hbar^2}{2m_e}\big(\alpha^2 - 2\alpha\langle 1/r\rangle\big)$$

位势项需要 $\langle 1/r\rangle$（球积分 $\mathrm{d}\tau = 4\pi r^2\mathrm{d}r$，依据：径向函数已含 $(4\pi)^{-1/2}$）：

$$\langle 1/r\rangle = \frac{\alpha^3}{\pi}\cdot 4\pi\int_0^\infty r\,e^{-2\alpha r}\,\mathrm{d}r = 4\alpha^3\cdot\frac{1}{(2\alpha)^2} = \alpha$$

（依据：$\int_0^\infty r e^{-\beta r}\mathrm{d}r = 1/\beta^2$。）代回：

$$\langle T\rangle = -\frac{\hbar^2\alpha^2}{2m_e} + \frac{\hbar^2\alpha^2}{m_e} = \frac{\hbar^2\alpha^2}{2m_e},\qquad \langle V\rangle = -\frac{e^2}{4\pi\varepsilon_0}\langle 1/r\rangle = -\frac{e^2\alpha}{4\pi\varepsilon_0}$$

$$\langle \hat H\rangle(\alpha) = \frac{\hbar^2\alpha^2}{2m_e} - \frac{e^2\alpha}{4\pi\varepsilon_0}$$

极值条件 $\partial\langle\hat H\rangle/\partial\alpha = \frac{\hbar^2\alpha}{m_e} - \frac{e^2}{4\pi\varepsilon_0} = 0 \Rightarrow \alpha = \frac{m_e e^2}{4\pi\varepsilon_0\hbar^2} = \frac{1}{a_0}$（恰为玻尔半径的倒数；二阶导 $\hbar^2/m_e > 0$ 确认极小）。代入：

$$E_{\min} = \frac{\hbar^2}{2m_e a_0^2} - \frac{e^2}{4\pi\varepsilon_0 a_0} = -\frac{me^4}{2(4\pi\varepsilon_0)^2\hbar^2} = -13.606\ \mathrm{eV}$$

**量纲检查**：$\frac{\hbar^2\alpha^2}{2m_e}$：$\frac{\mathrm{J^2\cdot s^2}\cdot \mathrm{m^{-2}}}{\mathrm{kg}} = \frac{\mathrm{kg^2\,m^4\,s^{-2}}\cdot \mathrm{m^{-2}}}{\mathrm{kg}\cdot \mathrm{s^2}} = \mathrm{J}$ ✓；$-13.606\ \mathrm{eV}\times 96.485\ \mathrm{kJ\cdot mol^{-1}\cdot eV^{-1}} = -1312\ \mathrm{kJ\cdot mol^{-1}}$ ✓。

**讨论**：本例试探函数族 $\{e^{-\alpha r}\}$ 恰好包含精确基态（$\alpha = 1/a_0$），故上界"够得着"精确值。换任何别的族（如 $e^{-\alpha r^2}$），极小值必**高于** $-13.606$ eV——变分原理把"猜波函数"变成有保障的系统性竞赛。这就是[第 9 章](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/01/)变分法一节与 HF 理论（模块五进阶）的全部数学许可。

### 例题 1-2（综合应用）定态微扰：非谐四次项的一阶与二阶能移

**题**：哈密顿 $\hat H = \frac{\hat p^2}{2m} + \frac12 m\omega^2\hat x^2 + \lambda \hat x^4$（$\lambda$ 小）。求基态能移至二阶（用升降算符，全程不跳步），并取自然单位 $\hbar = m = \omega = 1$、$\lambda = 0.1$ 与精确对角化值 $E_0 = 0.559146$ 比较。

**解题思路**：$\hat x = \sqrt{\hbar/2m\omega}\,(\hat a + \hat a^\dagger)$ → 把 $\hat x^4|0\rangle$ 显式作用出来 → 一阶取对角元、二阶只留 $|0\rangle\langle0|$ 以外的分量 → 数值核对与失效讨论。

**解**：**第 1 步（逐次作用）**。记 $\beta = \sqrt{\hbar/2m\omega}$，用 $\hat a|n\rangle = \sqrt n|n-1\rangle$、$\hat a^\dagger|n\rangle = \sqrt{n+1}|n+1\rangle$：

$$\big(\hat a + \hat a^\dagger\big)^2|0\rangle = \underbrace{\hat a^2|0\rangle}_{0} + \underbrace{\hat a\hat a^\dagger|0\rangle}_{|0\rangle} + \underbrace{\hat a^\dagger\hat a|0\rangle}_{0} + \underbrace{\hat a^{\dagger 2}|0\rangle}_{\sqrt2|2\rangle} = |0\rangle + \sqrt2\,|2\rangle$$

再作用一次：$\big(\hat a + \hat a^\dagger\big)\big(|0\rangle + \sqrt2|2\rangle\big) = |1\rangle + \sqrt2\big(\sqrt2|1\rangle + \sqrt3|3\rangle\big) = 3|1\rangle + \sqrt6|3\rangle$。

第三次：$\big(\hat a+\hat a^\dagger\big)\big(3|1\rangle + \sqrt6|3\rangle\big) = 3\big(|0\rangle + \sqrt2|2\rangle\big) + \sqrt6\big(\sqrt3|2\rangle + 2|4\rangle\big) = 3|0\rangle + 6\sqrt2\,|2\rangle + 2\sqrt6\,|4\rangle$。

于是

$$\hat x^4|0\rangle = \beta^4\Big(3|0\rangle + 6\sqrt2|2\rangle + 2\sqrt6|4\rangle\Big)$$

（只有 $n = 0, 2, 4$ 被混入——宇称守恒：$\hat x^4$ 是偶算符。）

**第 2 步（一阶）**：

$$E_0^{(1)} = \lambda\langle0|\hat x^4|0\rangle = 3\lambda\beta^4 = 3\lambda\left(\frac{\hbar}{2m\omega}\right)^2$$

**第 3 步（二阶）**。与基态耦合的非零矩阵元：$V_{20} = 6\sqrt2\,\lambda\beta^4$，$V_{40} = 2\sqrt6\,\lambda\beta^4$；能隙 $E_0^{(0)} - E_2^{(0)} = -2\hbar\omega$，$E_0^{(0)} - E_4^{(0)} = -4\hbar\omega$。代入二阶公式：

$$E_0^{(2)} = \frac{\big(6\sqrt2\lambda\beta^4\big)^2}{-2\hbar\omega} + \frac{\big(2\sqrt6\lambda\beta^4\big)^2}{-4\hbar\omega} = -\frac{72\lambda^2\beta^4}{2\hbar\omega} - \frac{24\lambda^2\beta^4}{4\hbar\omega} = -42\,\frac{\lambda^2\beta^4}{\hbar\omega} = -\frac{21}{8}\,\frac{\lambda^2\hbar^3}{m^4\omega^5}$$

（$\beta^4 = \hbar^4/16m^4\omega^4$；$42/16 = 21/8$；$\lambda^2$ 的量纲是 $\mathrm{J\cdot m^{-4}}$，乘 $\beta^4/\hbar\omega$ 的 $\mathrm{m^4/J}$ 后为纯数 ✓。）

**第 4 步（数值）**。自然单位（$\hbar = m = \omega = 1$，$\beta = 1/\sqrt2$）：

$$E_0 \approx \frac12 + \frac34\lambda - \frac{21}{8}\lambda^2 = 0.5 + 0.075 - 0.02625 = 0.54875\quad(\lambda = 0.1)$$

与精确对角化（数值求解 60 维截断矩阵，Python `numpy.linalg.eigvalsh`）$E_0^{\mathrm{exact}} = 0.559146$ 相比，误差 $1.9\%$。**失效演示**：同公式在 $\lambda = 1$ 给 $0.5 + 0.75 - 2.625 = -1.375$，而精确值为 $0.803771$——强耦合下二阶截断连符号都错，验证 1.2.2 的"渐近级数"警告。

**讨论**：$E_0^{(2)} < 0$ 是 1.2.1 推论①的实例；被混入的 $|2\rangle, |4\rangle$ 态就是"外场/非谐性引起的极化"的量子图像。

### 例题 1-3（综合应用）简并微扰：氢原子 $n=2$ 的线性 Stark 效应

**题**：沿 $z$ 加弱静电场 $F$。（i）完整计算矩阵元 $\langle 2s|\,eFz\,|2p_0\rangle$；（ii）建立并对角化简并子空间内的久期方程，给出 4 个能级的一阶 Stark 位移；（iii）取 $F = 5.0\times10^{8}\ \mathrm{V\cdot m^{-1}}$ 给出数值。

**解题思路**：径向积分 + 角向积分分离 → 明确 $\langle 2s|z|2p_{\pm1}\rangle = 0$（磁量子数）→ 2×2 矩阵对角化 → 数值换算（J → eV → cm⁻¹）。

**解**：（i）氢原子波函数（$Z = 1$）：

$$R_{20} = \frac{1}{2\sqrt2}\,a_0^{-3/2}\left(2 - \frac{r}{a_0}\right)e^{-r/2a_0},\qquad R_{21} = \frac{1}{2\sqrt6}\,a_0^{-3/2}\,\frac{r}{a_0}\,e^{-r/2a_0}$$

$$\psi_{200} = R_{20}Y_{00},\quad Y_{00} = \frac{1}{\sqrt{4\pi}};\qquad \psi_{210} = R_{21}Y_{10},\quad Y_{10} = \sqrt{\frac{3}{4\pi}}\cos\theta$$

**角向积分**（$\mathrm{d}\Omega = \sin\theta\,\mathrm{d}\theta\,\mathrm{d}\varphi$；被积函数不含 $\varphi$）：

$$\int Y_{00}^*\cos\theta\,Y_{10}\,\mathrm{d}\Omega = \frac{\sqrt3}{4\pi}\int\cos^2\theta\,\mathrm{d}\Omega = \frac{\sqrt3}{4\pi}\cdot\frac{4\pi}{3} = \frac{1}{\sqrt3}$$

**径向积分**：令 $\rho = r/a_0$（$r^3\mathrm{d}r = a_0^4\rho^3\mathrm{d}\rho$；依据：$\int_0^\infty \rho^n e^{-\rho}\mathrm{d}\rho = n!$）：

$$\int_0^\infty R_{20}R_{21}\,r^3\,\mathrm{d}r = \frac{a_0}{4\sqrt{12}}\int_0^\infty (2-\rho)\rho^4 e^{-\rho}\,\mathrm{d}\rho = \frac{a_0}{8\sqrt3}\big(2\cdot4! - 5!\big) = \frac{a_0}{8\sqrt3}(48 - 120) = -3\sqrt3\,a_0$$

合并（$z = r\cos\theta$，径向与角向分离）：

$$\langle 200|z|210\rangle = \frac{1}{\sqrt3}\times\big(-3\sqrt3 a_0\big) = -3a_0\quad\Longrightarrow\quad V_{2s,2p_0} = -3ea_0F$$

（量纲检查：$e\,a_0 F$：$\mathrm{C\cdot m\cdot V\cdot m^{-1}} = \mathrm{J}$ ✓。）

（ii）磁量子数守恒：$\hat z$ 不含 $\varphi$ ⇒ $\Delta m = 0$ ⇒ $2p_{\pm1}$ 与 $2s$ 无耦合，$\langle 200|z|2p_{\pm1}\rangle = 0$。子空间 $\{2s, 2p_0\}$ 的微扰矩阵：

$$\mathbf V = -3ea_0F\begin{pmatrix}0 & 1\\ 1 & 0\end{pmatrix}\quad\Longrightarrow\quad \det\begin{pmatrix}-E^{(1)} & -3ea_0F\\ -3ea_0F & -E^{(1)}\end{pmatrix} = 0\ \Rightarrow\ E^{(1)} = \pm 3ea_0F$$

本征矢 $\big(|2s\rangle \mp |2p_0\rangle\big)/\sqrt2$。**四个能级**：$-3ea_0F$、$0$（$2p_{+1},2p_{-1}$，二重）、$+3ea_0F$；最外两条相距 $6ea_0F$。**反宇称简并态的存在使位移 $\propto F$ 一次方**（对比基态的 $F^2$）。

（iii）数值（$F = 5.0\times10^8\ \mathrm{V\cdot m^{-1}}$）：

$$3ea_0F = 3\times1.602\times10^{-19}\ \mathrm{C}\times5.2918\times10^{-11}\ \mathrm{m}\times5.0\times10^{8}\ \mathrm{V\cdot m^{-1}} = 1.272\times10^{-20}\ \mathrm{J} = 79.4\ \mathrm{meV} = 6.40\ \mathrm{cm^{-1}}$$

**量纲检查**：$\mathrm{J}\times\frac{1}{hc} = \mathrm{m^{-1}}$，$\times10^{-2}$ 得 $\mathrm{cm^{-1}}$ ✓。这一分裂量级（数个 $\mathrm{cm^{-1}}$）正是 Stark 当年在 Balmer-$\alpha$ 谱线上分辨出的量级。

**讨论**：基态只有二次效应 $\Delta E_{1s}^{(2)} = -\tfrac94 a_0^3F^2$，由此定义的极化率 $\alpha_{\mathrm H} = 4.5\,a_0^3$ 换算为体积单位 $4.5\times(0.52918\ \mathrm{\AA})^3 = 0.667\ \mathrm{\AA^3}$——分子极化率（第 10 章拉曼强度、第 5 章折射率法）的量子出发点。

### 例题 1-4（拓展）化学主方程解析：异构化的精确解与涨落标度

**题**：$N$ 个独立分子做 $\mathrm A \underset{k_{-1}}{\stackrel{k_1}\rightleftharpoons} \mathrm B$。初始全为 A。（i）推导 $P_n(t)$（$n = N_B$）的显式解；（ii）推导均值与方差的演化方程并求稳态；（iii）取 $N = 20$、$k_1 = 2\ \mathrm{s^{-1}}$、$k_{-1} = 3\ \mathrm{s^{-1}}$ 给出稳态均值、方差与相对涨落，并讨论 $N\to$ 大时的确定性极限。

**解题思路**：单分子两态过程 → 每分子独立 → 二项分布 → 参数随时间变化；均值/方差直接对 CME 求矩。

**解**：（i）**每分子视角**：任一分子在 $t$ 时刻处于 B 的概率 $p(t)$ 满足两态速率方程 $\frac{\mathrm{d}p}{\mathrm{d}t} = k_1(1-p) - k_{-1}p$，$p(0) = 0$。解（[第 1 章 1.2.2 节](/xiaoshus-blog/textbooks/chemistry/01-foundations/01/)积分因子法，$k_1 + k_{-1}$ 为衰减率）：

$$p(t) = p_\infty\big(1 - e^{-(k_1 + k_{-1})t}\big),\qquad p_\infty = \frac{k_1}{k_1 + k_{-1}}$$

$N$ 个分子**相互独立**，且每分子只贡献 0 或 1 ⇒ $n$ 服从参数随时间变化的二项分布：

$$P_n(t) = \binom{N}{n}\,p(t)^n\big(1 - p(t)\big)^{N-n}$$

（自洽验证：它精确满足 1.4.2 节的主方程——二项分布的生成函数逐项核对主方程右端，此处从略，练习 1-6 要求完成一次。）

（ii）**均值**：对主方程两边求 $\sum_n n\cdot$（依据：交换求和序，逐项配对 $P_{n\pm1}$ 的系数）：

$$\frac{\mathrm{d}\langle n\rangle}{\mathrm{d}t} = k_1\big(N - \langle n\rangle\big) - k_{-1}\langle n\rangle$$

——与确定性速率方程**逐字相同**（单分子反应矩方程闭合）。稳态 $\langle n\rangle_{\mathrm{ss}} = Np_\infty$。**方差**：定义 $v = \langle n^2\rangle - \langle n\rangle^2$，同法对 $\sum_n n^2\cdot$ 主方程求矩并代入均值方程（中间代数：$\langle n^2\rangle$ 的演化出现 $\langle n\rangle$ 与 $\langle n^3\rangle$，单分子跳变幅度为 $\pm1$ 使三阶矩被 $\langle n^2\rangle, \langle n\rangle$ 表出，故闭合）：

$$\frac{\mathrm{d}v}{\mathrm{d}t} = k_1\big(N - \langle n\rangle\big) + k_{-1}\langle n\rangle - 2(k_1 + k_{-1})\,v$$

稳态（代入 $\langle n\rangle_{\mathrm{ss}} = Np_\infty$；依据 $p_\infty(1-p_\infty) = \frac{k_1k_{-1}}{(k_1+k_{-1})^2}$）：

$$v_{\mathrm{ss}} = \frac{k_1(N - Np_\infty) + k_{-1}Np_\infty}{2(k_1+k_{-1})} = N\,\frac{k_1k_{-1}}{(k_1+k_{-1})^2} = N\,p_\infty(1 - p_\infty)$$

——正是二项分布的方差，交叉验证 ✓。

（iii）**数值**：$p_\infty = 2/5 = 0.4$；$\langle n\rangle_{\mathrm{ss}} = 8$；$v_{\mathrm{ss}} = 20\times0.4\times0.6 = 4.8$；$\sigma = 2.19$；相对涨落 $\sigma/\langle n\rangle = 27.4\%$。若 $N = 2\times10^{6}$：相对涨落 $0.09\%$。

**讨论**：均值随 $t$ 按 $e^{-(k_1+k_{-1})t}$ 弛豫（弛豫谱 = [第 1 章 1.3 节](/xiaoshus-blog/textbooks/chemistry/01-foundations/01/)转移矩阵特征值的最简单实例）；涨落按 $1/\sqrt{N}$ 收缩——**确定性化学动力学是 $N\to\infty$ 的极限**；单分子荧光实验看到的"开–关闪烁"就是 $N = 1$ 端的同一方程。

### 例题 1-5（拓展）Gillespie 模拟：基因表达开关网络的 bistability 与噪声切换

**题**：两条基因互相编码抑制对方的转录因子（双负反馈 = 正反馈），是最小的"细胞记忆开关"（Gardner–Cantor–Collins, Nature 403, 339 (2000)）。模型（对称，时间单位 min）：蛋白 A 的生成倾向 $a_1 = k_p\big/(1 + (B/K)^2) + \beta$、降解 $a_2 = \gamma A$；蛋白 B 对称（$a_3 = k_p/(1+(A/K)^2) + \beta$、$a_4 = \gamma B$）。取 $k_p = 50$、$\beta = 0.5$（渗漏表达）、$K = 8$、$n_{\mathrm H} = 2$（Hill 系数）、$\gamma = 1\ \mathrm{min^{-1}}$。（i）写出 SSA 代码；（ii）给出确定性稳态与 1000 条随机轨迹（$t = 200$ min）的终态分布；（iii）讨论噪声切换。

**解题思路**：倾向性 → SSA 抽样循环 → 多轨迹统计 → 与确定性不动点对照。

**解**：（i）代码（直接法，1.4.5 节逐条对应；随机种子固定以保证可复现）：

```python
import random, math

KP, BETA, K, GAM = 50.0, 0.5, 8.0, 1.0     # 参数
TFIN, NTRAJ = 200.0, 1000                  # 仿真时长与轨迹数

def ssa_once(rng):
    A = B = 0; t = 0.0                     # 初始无蛋白
    while t < TFIN:
        a1 = KP/(1.0 + (B/K)**2) + BETA    # A 生成（B 抑制）
        a2 = GAM*A                         # A 降解
        a3 = KP/(1.0 + (A/K)**2) + BETA    # B 生成（A 抑制）
        a4 = GAM*B                         # B 降解
        a0 = a1 + a2 + a3 + a4
        t += -math.log(1.0 - rng.random())/a0        # τ = ln(1/u1)/a0
        r = rng.random()*a0
        if   r < a1:            A += 1
        elif r < a1 + a2:       A -= 1
        elif r < a1 + a2 + a3:  B += 1
        else:                   B -= 1
    return A, B

rng = random.Random(2026)
hi, lo = [], []
for _ in range(NTRAJ):
    A, B = ssa_once(rng)
    (hi if A > B else lo).append((A, B))
```

（ii）**确定性稳态**：解 $\mathrm{d}A/\mathrm{d}t = 0$、$\mathrm{d}B/\mathrm{d}t = 0$ 的不对称不动点（定点迭代 $A = g(B), B = g(A)$，$g(y) = k_p/(1+(y/K)^2) + \beta$）得 $(A, B) = (47.9,\ 1.85)$ 及其镜像；对称点 $(A = B)$ 不稳定（Hill 系数 $2 > 1$ 是双稳性的必要条件）。**随机结果**（1000 条轨迹，$t = 200$ min，种子 2026）：终态落入 A-高态 497 条（49.7%）、B-高态 503 条（50.3%）；两态群集分别为

$$A\text{-高态}: A = 45.9 \pm 8.2,\quad B = 2.1 \pm 1.7;\qquad B\text{-高态镜像}$$

群集均值与确定性不动点一致（涨落 $\sqrt{\langle A\rangle}\approx 6.9$ 与实测 8.2 同量级，Poisson + 抑制涨落放大），而**随机对称破缺**使每条轨迹"掷硬币"式选择命运——确定性 ODE 从初值 $(0,0)$ 只会走到不稳定的对称点，无法描述这一分布。

（iii）**噪声切换**：把时长加到 3000 min，单条轨迹可在两态间自发切换（本组参数下 10 条长轨迹观测到切换次数 0–4 次，均值约 1.3 次）。切换由生成–降解的复合泊松涨落驱动：低表达态蛋白数少（$\langle B\rangle\approx 2$），渗漏生成的涨落偶尔压过抑制，把系统推过鞍点。这正是单细胞生物学"相同基因型、不同命运"的化学根源；参数（$k_p, K, n_{\mathrm H}, \gamma$）与切换频率的定量关系可用本代码直接扫描研究。

**量纲检查**：$a_j$ 均为 $\mathrm{min^{-1}}$（$k_p, \beta$ 与 $\gamma A$ 同为分子数每分钟——这里把"每细胞"作为体积单位，$c_j = k_j$，无换算问题）；$\tau$ 为 min ✓。

## 1.7 常见误区与易错点

1. **变分定理当"万能上界"**：它只保证对**基态**的上界（且要求 $\hat H$ 有下界、试探函数可归一）。对激发态必须附加与低态正交的约束，否则可能低于真实激发态（甚至低于基态能级的绝对值比较都会误导）。
2. **简并体系直接套非简并公式**：分母 $E_n^{(0)} - E_m^{(0)} = 0$ 不是"数值很大忽略"，而是"公式失效，必须先在简并子空间对角化"（例题 1-3 的正确姿势）。同理，能级"近乎简并"（准简并）时也要谨慎——这是避免交叉与 Jahn–Teller 的领域。
3. **把微扰级数当收敛幂级数**：高阶项不一定更准（例题 1-2 的 $\lambda = 1$ 反例）。二阶之后要不要继续，应与精确数值或实验值对照，而不是默认"多阶更高级"。
4. **FDT 里丢 $\omega/2k_{\mathrm B}T$ 或把 $S(\omega)$ 当量子谱密度**：量子涨落在 $T\to0$ 不消失（零点运动），经典公式在 $\hbar\omega \gtrsim k_{\mathrm B}T$（室温下约 $200\ \mathrm{cm^{-1}}$ 以上）系统性低估——低频模式（构象、扩散）用经典式安全，高频振动（$>1000\ \mathrm{cm^{-1}}$）必须用量子版。
5. **SSA 中 $k$ 与 $c_j$ 混用**：宏观速率常数是浓度语言（$\mathrm{mol\cdot L^{-1}\cdot s^{-1}}$），倾向性是分子数语言（$\mathrm{s^{-1}}$）。A+B 型 $c = k/V$、2A 型 $c = 2k/V$，漏换算的模拟"看起来在跑、结果错一倍"。
6. **把涨落当待消除的误差**：$1/\sqrt{N}$ 的相对涨落是统计物理的内禀属性；在单细胞尺度它是**功能**（命运分岔、适应性进化），在测量中它设定了任何"提高精度"努力的天花板。

## 1.10 思考练习题

（全部题目解答见本模块 [99-进阶习题答案册](/xiaoshus-blog/textbooks/chemistry/01-foundations/99/)；正文仅给最终校验值。建议：每道计算题先做量纲检查，再动笔。）

1. **概念辨析**：陈述变分定理并说明其证明中"哪里用了 $\hat H$ 的本征展开、哪里用了 $E_n \ge E_0$"；为什么 Hartree–Fock 能量必为精确基态能量的上界？（要点校验值：展开系数模方加权平均 $\ge$ 最小权重 $\times E_0$；等号 iff 纯基态。）
2. **计算（变分法）**：对一维谐振子取高斯试探函数 $\Phi_\alpha = (2\alpha/\pi)^{1/4}e^{-\alpha x^2}$，证明 $\langle\hat H\rangle = \frac{\hbar^2\alpha}{2m} + \frac{m\omega^2}{8\alpha}$，求极小并解释为何恰得精确解。（校验值：$\alpha_{\mathrm{opt}} = m\omega/2\hbar$，$E_{\min} = \hbar\omega/2$。）
3. **计算（一阶微扰）**：一维无限深势箱（$0 < x < L$）基态受均匀微扰 $V'(x) = \varepsilon x$：求一阶能移并判断二阶能移的符号。（校验值：$\Delta E^{(1)} = \varepsilon L/2$；$\Delta E^{(2)} < 0$。）
4. **计算（二阶微扰数值）**：例题 1-2 中取 $\lambda = 0.1$：写出 $E_0$ 的一+二阶近似值，并与精确值 0.559146 比较给出百分比误差。（校验值：0.54875，误差约 1.9%。）
5. **计算（极化率）**：由 $\Delta E_{1s}^{(2)} = -\frac94 a_0^3F^2$ 求（i）氢原子极化率（$\mathrm{\AA^3}$）；（ii）$F = 1.0\times10^{9}\ \mathrm{V\cdot m^{-1}}$ 时的基态能移（meV）。（校验值：$\alpha = 0.667\ \mathrm{\AA^3}$；$\Delta E \approx -0.232\ \mathrm{meV}$。）
6. **计算（主方程）**：$N = 10$ 个独立分子、$p_\infty = 0.4$ 的异构化稳态：求最概然 $n$ 与 $P(n=4)$；说明 $P_n$ 是哪种分布。（校验值：$n^* = 4$；$P_4 = \binom{10}{4}0.4^4 0.6^6 \approx 0.251$，二项分布。）
7. **计算（Fokker–Planck/泊松稳态）**：基因表达 birth–death 过程（生成速率 $k = 12\ \mathrm{min^{-1}}$、降解 $\gamma x$、$\gamma = 2\ \mathrm{min^{-1}}$）：由 CME 精确稳态求 $\langle X\rangle$、$\sigma$、$P(X = 0)$ 与相对涨落。（校验值：$\langle X\rangle = 6$，$\sigma = \sqrt6$，$P_0 = e^{-6} \approx 2.48\times10^{-3}$，相对涨落 40.8%。）
8. **挑战（SSA 实现与解析对照）**：纯衰变 $\mathrm A \to \mathrm B$（单分子，$c = k = 0.1\ \mathrm{s^{-1}}$），初始 $N_A = 100$。（i）推导 $t = 10\ \mathrm{s}$ 时剩余 A 分子数的精确分布、均值与标准差；（ii）写 SSA 代码验证（建议 $10^4$ 条轨迹）并报告你的模拟均值/标准差；（iii）讨论 $N_0 \to \infty$ 时如何与确定性速率方程一致。（校验值：二项分布 $B\big(100, e^{-1}\big)$；均值 36.8，$\sigma = 4.8$。）
