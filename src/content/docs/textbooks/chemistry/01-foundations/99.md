# 模块一·进阶章 1（进阶）高等数理方法（1.10 节思考练习题）

## 1-1【概念辨析】变分定理的证明结构与 Hartree–Fock 的上界保证

**对应正文**：1.1.4 节。

**标准答案要点**：

1. **定理陈述**：对归一化任意 $\Phi$，$\langle\Phi|\hat H|\Phi\rangle \ge E_0$（$E_0$ 为 $\hat H$ 的基态能量）。
2. **证明结构拆解**：
   - *哪里用了本征展开*：把 $\Phi = \sum_n c_n\psi_n$ 展开需要 $\{\psi_n\}$ 是**完备正交归一基**（完备性保证展开可行；正交归一使 $\langle\Phi|\Phi\rangle = \sum_n|c_n|^2 = 1$ 且 $\hat H$ 的对角化 $E_n\delta_{mn}$ 成立）。
   - *哪里用了 $E_n \ge E_0$*：把每个权重 $|c_n|^2$ 都换成 $|c_n|^2$ 后能量变为 $\sum_n|c_n|^2E_n \ge E_0\sum_n|c_n|^2 = E_0$——这是唯一用到能级排序的一步，也是"上界"的全部来源。
   - **等号条件**：所有 $n > 0$ 的 $c_n = 0$，即 $\Phi$ 本身就是（比例于）基态。
3. **HF 为何是上界**：HF 把试探函数限制在"单个 Slater 行列式"这一子空间内取极小。子空间中的最优解仍是全体试探函数中的一员，故 $E_{\mathrm{HF}} \ge E_0$；且基组增大时子空间单调扩大，$E_{\mathrm{HF}}$ 单调下降（变分原理保证不反弹），趋于 HF 完备基极限（仍 $\ge E_0$，差值即电子相关能）。
4. **常见错误辨析**：
   - *把定理外推到激发态*：无约束试探函数的最小值只锁基态；对激发态必须附加"与更低态正交"的约束，否则可能得到介于 $E_0$ 与 $E_1$ 之间的无意义值。
   - *把 Kohn–Sham 轨道能当上界成员*：DFT 的**能量泛函**极小值是基态能量的上界（Hohenberg–Kohn），但 KS 本征值不是，二者不可混谈。
   - *忽略前提*：$\hat H$ 需有下界、$\Phi$ 需可归一（在平方可积函数空间内）。

## 1-2【计算】谐振子高斯试探函数的变分极小

**对应正文**：1.1.4 节、例题 1-1 的方法。

**完整解**：

**第 1 步（两个期望值）**。$\psi = (2\alpha/\pi)^{1/4}e^{-\alpha x^2}$，$|\psi|^2 = (2\alpha/\pi)^{1/2}e^{-2\alpha x^2}$。用 Gauss 积分 $\int e^{-\beta x^2}\mathrm{d}x = \sqrt{\pi/\beta}$、$\int x^2e^{-\beta x^2}\mathrm{d}x = \frac{1}{2}\sqrt{\pi/\beta^3}$（$\beta = 2\alpha$）：

$$\langle x^2\rangle = \left(\frac{2\alpha}{\pi}\right)^{1/2}\cdot\frac12\sqrt{\frac{\pi}{(2\alpha)^3}} = \frac{1}{4\alpha}$$

动能：$\psi'' = (4\alpha^2x^2 - 2\alpha)\psi$，故

$$\langle T\rangle = -\frac{\hbar^2}{2m}\big(4\alpha^2\langle x^2\rangle - 2\alpha\big) = -\frac{\hbar^2}{2m}\big(\alpha - 2\alpha\big) = \frac{\hbar^2\alpha}{2m}$$

位能：$\langle V\rangle = \frac12 m\omega^2\langle x^2\rangle = \frac{m\omega^2}{8\alpha}$。

$$\langle\hat H\rangle(\alpha) = \frac{\hbar^2\alpha}{2m} + \frac{m\omega^2}{8\alpha}$$

**第 2 步（极小）**：$\dfrac{\mathrm{d}}{\mathrm{d}\alpha} = \dfrac{\hbar^2}{2m} - \dfrac{m\omega^2}{8\alpha^2} = 0 \Rightarrow \alpha_{\mathrm{opt}}^2 = \dfrac{m^2\omega^2}{4\hbar^2} \Rightarrow \alpha_{\mathrm{opt}} = \dfrac{m\omega}{2\hbar}$（二阶导 $> 0$ 确认极小）。

**第 3 步（代回）**：$E_{\min} = \dfrac{\hbar^2}{2m}\cdot\dfrac{m\omega}{2\hbar} + \dfrac{m\omega^2}{8}\cdot\dfrac{2\hbar}{m\omega} = \dfrac{\hbar\omega}{4} + \dfrac{\hbar\omega}{4} = \boxed{\dfrac{\hbar\omega}{2}}$。

**为何恰得精确解**：精确基态为 $\psi_0 \propto e^{-m\omega x^2/2\hbar}$，即 $e^{-\alpha x^2}$ 形式且 $2\alpha = m\omega/\hbar$——$\alpha_{\mathrm{opt}} = m\omega/2\hbar$ 的试探函数**就在**精确基态所在的函数族内，变分原理保证此时上界"够到"精确值。（数值验证：自然单位 $\hbar = m = \omega = 1$ 下对 $E(\alpha) = \alpha/2 + 1/8\alpha$ 扫描，极小在 $\alpha = 0.500$、$E = 0.500000$ ✓。）

**量纲检查**：$\alpha$ 量纲 $\mathrm{m^{-2}}$（$e^{-\alpha x^2}$ 宗量无因次）；$\hbar^2\alpha/2m$ 与 $m\omega^2/8\alpha$ 均为 J ✓。

**常见错误**：① 高斯"宽度参数"约定混乱——$e^{-\alpha x^2}$ 与 $e^{-\alpha x^2/2}$ 的 $\alpha_{\mathrm{opt}}$ 差 2 倍，写结果必须连同试探函数一起声明；② 极小化只对 $\langle T\rangle$ 或只对 $\langle V\rangle$ 做。

## 1-3【计算】势箱基态的均匀微扰：一阶能移与二阶符号

**对应正文**：1.2.1 节（一阶公式）、1.2.1 推论①。

**完整解**：无限深势箱（$0 < x < L$）基态 $\psi_1 = \sqrt{2/L}\sin(\pi x/L)$，$E_1^{(0)} = \pi^2\hbar^2/2mL^2$。微扰 $V'(x) = \varepsilon x$（均匀电场的势能，$\varepsilon = qF$）。

**一阶**：

$$\Delta E^{(1)} = \langle 1|\varepsilon x|1\rangle = \frac{2\varepsilon}{L}\int_0^L x\sin^2\frac{\pi x}{L}\,\mathrm{d}x$$

利用对称性：$\sin^2(\pi x/L)$ 关于 $x = L/2$ 镜像对称，$x$ 相对该点反对称，故 $\langle x\rangle = L/2$（数值积分验证：0.500000 ✓），

$$\Delta E^{(1)} = \varepsilon L/2$$

（物理解读：粒子"平均位置"在箱中心，均匀场的势能以此为准——任何 $n$ 的 $\langle x\rangle = L/2$，一阶能移均同。）

**二阶符号**：

$$\Delta E^{(2)} = \sum_{n\ge2}\frac{|\varepsilon\langle n|x|1\rangle|^2}{E_1^{(0)} - E_n^{(0)}}$$

分母 $E_1 - E_n < 0$ 对一切 $n \ge 2$，分子非负 ⇒ $\Delta E^{(2)} < 0$（3.2.1 推论①：基态被微扰压低）。

**量纲检查**：$\varepsilon\,x$：$\mathrm{J\cdot m^{-1}\times m = J}$ ✓；$\varepsilon L$：J ✓。

**常见错误**：① 硬算积分而不用对称性（$\int_0^L x\sin^2(\pi x/L)\mathrm{d}x = L^2/4$，直接代入也可）；② 把二阶能移当可正可负——对**基态**它必为负。

## 1-4【计算】四次微扰振子的数值：微扰 vs 精确

**对应正文**：例题 1-2。

**完整解**：自然单位（$\hbar = m = \omega = 1$）：

$$E_0 \approx \underbrace{\frac12}_{E^{(0)}} + \underbrace{\frac34\lambda}_{E^{(1)}} - \underbrace{\frac{21}{8}\lambda^2}_{E^{(2)}} = 0.5 + 0.075 - 0.02625 = \boxed{0.54875}\quad(\lambda = 0.1)$$

精确对角化（60 维谐振子基截断，`numpy.linalg.eigvalsh`）：

$$E_0^{\mathrm{exact}} = 0.559146,\qquad \text{误差} = \frac{|0.54875 - 0.559146|}{0.559146}\times100\% = 1.86\%$$

**讨论**：误差中三阶项 $\sim\lambda^3$ 量级（数值上约 $+0.01$）占主导——$\lambda = 0.1$ 时二阶截断已相当好；同一公式在 $\lambda = 1$ 给 $-1.375$（精确值 0.803771），符号都错——**渐近级数**的行为：只在 $\lambda$ 足够小时"项数越多越好"。

**常见错误**：① 用 $\lambda = 1$ 检验后断言"微扰论错了"——错的是"超出适用范围使用"，不是理论本身；② 忘记例题 1-2 的矩阵元（$6\sqrt2/4$ 与 $2\sqrt6/4$，即 $\beta^4$ 约定）而把数值凑错。

## 1-5【计算】氢原子极化率与强场能移

**对应正文**：1.2.4 节。

**完整解**：

（i）由 $\Delta E_{1s}^{(2)} = -\dfrac94 a_0^3F^2$ 与极化率定义 $\Delta E = -\dfrac12\alpha F^2$ 比较：

$$\alpha = \frac92\,a_0^3 = 4.5\times(0.529177\ \mathrm{\AA})^3 = 4.5\times0.148185\ \mathrm{\AA^3} = \boxed{0.667\ \mathrm{\AA^3}}$$

（量纲检查：$a_0^3$ 为体积，$\alpha$ 以体积为单位——静电制约定下的"体积极化率"；SI 制还要乘 $4\pi\varepsilon_0$，教材常用体积制。）

（ii）$F = 1.0\times10^{9}\ \mathrm{V\cdot m^{-1}}$。原子单位换算：$F_{\mathrm{au}} = \dfrac{F}{5.1422\times10^{11}\ \mathrm{V\cdot m^{-1}}} = 1.9447\times10^{-3}$：

$$\Delta E = -\frac94 F_{\mathrm{au}}^2\ \mathrm{a.u.} = -2.25\times(1.9447\times10^{-3})^2\ \mathrm{a.u.} = -8.51\times10^{-6}\ \mathrm{a.u.}$$

$$\times\,27.2114\ \mathrm{eV/a.u.} = -2.32\times10^{-4}\ \mathrm{eV} = \boxed{-0.232\ \mathrm{meV}}$$

**讨论**：$10^9\ \mathrm{V/m}$ 已是强实验室场，能移仅 $0.2$ meV（$<2\ \mathrm{cm^{-1}}$）——氢原子极化率之小与 1.2.4 例题 1-3 的线性 Stark（$n = 2$，$F = 5\times10^8\ \mathrm{V/m}$ 给 ±79 meV）形成"简并结构决定响应量级"的对照。

**常见错误**：① 丢掉 $\Delta E = -\frac12\alpha F^2$ 的 $1/2$，把 $\alpha$ 算成 9 a₀³；② 原子单位场强换算用错（1 a.u. 场强 = 5.142×10¹¹ V/m，不是 5.142×10⁹）。

## 1-6【计算】两态主方程的稳态分布：最概然值与概率

**对应正文**：1.4.2 节、例题 1-4。

**完整解**：$N = 10$ 个独立单分子（各自两态、$p_\infty = 0.4$）⇒ $n = N_B$ 服从**二项分布** $B(N, p_\infty)$（不是 Poisson——分子数有限且每分子只有两个状态）：

$$P_n = \binom{10}{n}\,0.4^{\,n}\,0.6^{\,10-n}$$

**最概然值**：令 $P_{n+1}/P_n = \dfrac{(N-n)}{n+1}\cdot\dfrac{p}{1-p} \ge 1$ 的临界点：$n^* = \lfloor(N+1)p\rfloor = \lfloor 4.4\rfloor = 4$。

**概率**：

$$P_4 = \binom{10}{4}\,0.4^4\,0.6^6 = 210\times0.0256\times0.046656 = \boxed{0.251}$$

（均值 $\langle n\rangle = 4$、方差 $10\times0.4\times0.6 = 2.4$、$\sigma = 1.55$；与正文例题 1-4 的 $N = 20$ 情形同型。）

**常见错误**：① 用 Poisson 分布（Poisson 是 birth–death **开系**或 $N\to\infty$ 二项极限，本题封闭且 $N$ 小）；② $0.6$ 的指数写成 $10-n$ 以外的数（分布归一性依赖它）；③ 最概然值用 $\langle n\rangle$ 直接四舍五入（应判 $P_{n+1}/P_n$ 比值）。

## 1-7【计算】基因表达 birth–death 过程的泊松稳态

**对应正文**：1.4.4 节（零流条件）、1.4.2 节（CME 稳态）。

**完整解**：反应：$\mathrm{nil} \xrightarrow{k} X$、$X \xrightarrow{\gamma} \mathrm{nil}$。CME（单变量）：

$$\frac{\mathrm{d}P_n}{\mathrm{d}t} = k\,P_{n-1} + \gamma(n+1)P_{n+1} - (k + \gamma n)P_n$$

**稳态逐态递推**（稳态 $\mathrm{d}P_n/\mathrm{d}t = 0$，从 $n = 0$ 起：$kP_0 = \gamma P_1$；归纳可得逐态概率流为零——birth–death 链无环、稳态必详细平衡）：

$$\gamma P_1 = kP_0 \Rightarrow P_1 = \frac{k}{\gamma}P_0;\qquad \gamma\cdot2P_2 = kP_1 \Rightarrow P_2 = \frac{k^2}{2!\gamma^2}P_0;\ \cdots$$

$$P_n = \frac{(k/\gamma)^n}{n!}P_0$$

归一化 $\sum_n P_n = P_0e^{k/\gamma} = 1 \Rightarrow P_0 = e^{-k/\gamma}$——**泊松分布**，$\langle X\rangle = k/\gamma = 12/2 = 6$。

**数值**：$\langle X\rangle = 6$；$\sigma = \sqrt6 = 2.45$；$P_0 = e^{-6} = 2.48\times10^{-3}$；相对涨落 $\sigma/\langle X\rangle = 40.8\%$。（正文的例题 1-4 与本题为同一物理在"封闭 $N$ 分子/开放生成–降解"两种边界下的体现：二项 vs 泊松。）

**量纲检查**：$k/\gamma$：$\mathrm{min^{-1}/min^{-1}} = 1$（无因次均值）✓；指数宗量无因次 ✓。

**常见错误**：① 稳态递推漏掉 $\gamma(n+1)$ 的"+"号（从 $n+1$ 跳下来）；② 把"泊松"与"二项"张冠李戴——**开系生成–降解 = Poisson，封闭两态 = 二项**，判据是分子数有没有上限。

## 1-8【挑战】纯衰变 SSA：解析分布、代码验证与确定性极限

**对应正文**：1.4.5 节（SSA 推导）、1.4.1 节（大数极限）。

**（i）解析解**：$N_0 = 100$ 个独立分子，每个分子在 $t$ 内未衰变的概率 $p = e^{-kt} = e^{-1} = 0.3679$。剩余 A 分子数 $N_A(t)$ 服从**二项分布** $B(100,\ e^{-1})$：

$$\langle N_A\rangle = N_0e^{-kt} = 100\times0.3679 = \boxed{36.8}$$

$$\mathrm{Var} = N_0e^{-kt}\big(1 - e^{-kt}\big) = 100\times0.3679\times0.6321 = 23.25,\qquad \sigma = \boxed{4.8}$$

**（ii）SSA 验证代码**（单反应，$a = cN_A$，$c = k = 0.1\ \mathrm{s^{-1}}$——单分子 $c_j = k_j$ 无体积换算）：

```python
import random, math
rng = random.Random(11)
K, N0, TFIN, NTRAJ = 0.1, 100, 10.0, 10_000
finals = []
for _ in range(NTRAJ):
    N = N0; t = 0.0
    while t < TFIN and N > 0:
        a0 = K*N
        t += -math.log(1.0 - rng.random())/a0   # τ = ln(1/u)/a0
        N -= 1                                   # 唯一反应：A → B
    finals.append(N)
m = sum(finals)/NTRAJ
sd = (sum((x-m)**2 for x in finals)/NTRAJ)**0.5
print(m, sd)   # 典型输出：36.8, 4.8（均值的标准误 ≈ 4.8/√10000 ≈ 0.05）
```

模拟结果应落在均值 $36.8 \pm 0.1$、标准差 $4.8 \pm 0.1$ 内（对照解析值 36.79/4.82 ✓；若偏差超出，优先检查 τ 抽样公式与循环终止条件）；与正文例题 1-4 的两态分布、例题 1-5 的 SSA 代码同根。

**（iii）确定性极限讨论**：确定性速率方程 $\mathrm{d}N/\mathrm{d}t = -kN$ 给 $N(t) = N_0e^{-kt} = 36.79$——恰为随机均值的**精确**表达式（纯衰变的矩方程闭合：均值无涨落修正）。相对涨落 $\sigma/\langle N_A\rangle = \sqrt{(1-e^{-kt})/(N_0e^{-kt})} = 13.1\%$（$N_0 = 100$），随 $N_0$ 按 $1/\sqrt{N_0}$ 收缩：$N_0 \sim 10^{20}$ 时相对涨落 $\sim10^{-10}$，分布宽度远小于任何测量分辨率——**确定性动力学是大数极限下分布峰的轨迹**（3.4.1 节的 $1/\sqrt{N}$ 标度）；反之，单分子/单细胞实验（$N_0 = 1$）中分布就是物理本身。

**常见错误辨析**：① 把 $\sigma$ 写成 $\sqrt{\langle N\rangle} = 6.1$（Poisson 公式）——错，本体系有上界 $N_0$，是二项（$\sigma^2 = N_0p(1-p) < N_0p$）；② SSA 中固定步长 $\mathrm{d}t$ 递减 $N$——那变成近似 $\tau$-leaping 而非精确 SSA，且在 $N$ 小时偏差显著；③ 用指数分布均值 $1/a_0$ 当固定 $\tau$（丢失涨落，轨迹过度平滑）。
