# 第 1 章 化学中的数理工具衔接

> **本章定位**：全书的数理地基。把化学各分支将要使用的微积分、常微分方程、线性代数、群论初步、概率统计与量纲分析按"化学怎么用"来组织，每个工具配一个化学情境的完整算例；前置要求为高中数学与物理基础，后续所有模块均直接或间接依赖本章。

## 1.0 本章学习目标

学完本章，你应当能够：

1. 对任意化学表达式执行量纲检查，并说明 SI 基本单位与其 2019 年新定义的思想。
2. 把"反应速率 = 浓度对时间的导数""偏摩尔量 = 体积对物质的量的偏导数"这类化学定义翻译成微积分语言，并完成积分速率方程的推导。
3. 用可分离变量法与积分因子法完整求解一级、二级速率方程及带源项的一阶线性方程。
4. 用矩阵（含克莱姆法则与逆矩阵）求解多组分光度分析方程组，并说出久期方程 $|\mathbf{H}-E\mathbf{S}|=0$ 与之的同构性。
5. 对常见分子（H₂O、NH₃、BF₃、苯等）识别对称元素并判定点群，解释为什么谱学需要群论。
6. 对一组平行测定数据计算平均值、标准偏差、最小二乘拟合直线与 95% 置信区间。

## 1.1 微积分在化学中的用法

### 1.1.1 导数：变化率的语言——反应速率

化学反应的快慢本质上是浓度随时间的变化率。对反应

$$a\mathrm{A} + b\mathrm{B} \longrightarrow y\mathrm{Y} + z\mathrm{Z}$$

若直接写 $r = -\mathrm{d}[\mathrm{A}]/\mathrm{d}t$，用 A 与 B 算出的"速率"会因计量系数不同而不一致（推导依据：B 的消耗速率是 A 的 $b/a$ 倍，因为每一份反应进度同时消耗 $a$ 份 A 与 $b$ 份 B）。因此化学定义**反应速率（reaction rate）**时先除以计量系数：

$$r = -\frac{1}{a}\frac{\mathrm{d}[\mathrm{A}]}{\mathrm{d}t} = -\frac{1}{b}\frac{\mathrm{d}[\mathrm{B}]}{\mathrm{d}t} = \frac{1}{y}\frac{\mathrm{d}[\mathrm{Y}]}{\mathrm{d}t} = \frac{1}{z}\frac{\mathrm{d}[\mathrm{Z}]}{\mathrm{d}t}$$

（定义式；量纲：$[\mathrm{A}]$ 的单位 $\mathrm{mol\cdot L^{-1}}$ 除以时间 $\mathrm{s}$，故 $r$ 的单位为 $\mathrm{mol\cdot L^{-1}\cdot s^{-1}}$。）这样定义后，无论跟踪哪个物种，算出的都是同一个 $r$。这一"除以计量系数"的细节在 1.2.3 节还将与反应进度 ξ（第 2 章 2.3.2 节）统一。

**偏导数：一次只放开一个旋钮。** 化学体系的状态函数（如体积 $V$）通常依赖多个变量：$V = V(T, p, n_{\mathrm{A}}, n_{\mathrm{B}}, \dots)$。我们关心"固定其他一切、只改变一个变量"的变化率，这就是**偏导数（partial derivative）**，记法中必须写明固定什么：

$$\left(\frac{\partial V}{\partial n_{\mathrm{B}}}\right)_{T,\,p,\,n_{\mathrm{A}}}$$

**例（偏摩尔量的引入，第 6 章化学势的雏形）**：在 20 °C 把 50.0 mL 乙醇倒入 50.0 mL 水中，总体积约 97 mL 而不是 100.0 mL（分子间形成氢键导致堆积更紧密，体积收缩）。说明"溶液的体积 ≠ 各组分体积之和"，每个组分对体积的贡献必须用**偏摩尔体积（partial molar volume）**

$$\bar{V}_{\mathrm{B}} = \left(\frac{\partial V}{\partial n_{\mathrm{B}}}\right)_{T,\,p,\,n_{\mathrm{A}}\cdots}$$

来度量（定义式）。理想气体的 $\bar{V} = \partial V/\partial n = RT/p$（推导：$V = nRT/p$，$T,p$ 固定时 $V$ 与 $n$ 成正比），298.15 K、101.325 kPa 下 $\bar{V} = 24.47\ \mathrm{L\cdot mol^{-1}}$（计算见例题 1-3）。

> **将在哪一章用到**：偏导数是热力学的母语——化学势 $\mu_{\mathrm{B}} = (\partial G/\partial n_{\mathrm{B}})_{T,p,n_{\mathrm{A}\neq\mathrm{B}}}$、Gibbs–Duhem 方程、麦克斯韦关系式全部由偏导数构成（[第 6 章 热力学](/xiaoshus-blog/textbooks/chemistry/04-physical/01/)）；偏摩尔量的实验测定（截距法）也在该章给出。

### 1.1.2 积分：累积的语言——从速率到浓度

已知速率求浓度随时间的演化，是一个反问题：给定导数还原原函数。以零级反应为例（速率与浓度无关，$-\mathrm{d}[\mathrm{A}]/\mathrm{d}t = k$）：

$$\int_{[\mathrm{A}]_0}^{[\mathrm{A}]} \mathrm{d}[\mathrm{A}] = -k\int_0^t \mathrm{d}t \quad\Longrightarrow\quad [\mathrm{A}] = [\mathrm{A}]_0 - kt$$

（推导依据：定积分上下限对应状态量 $[\mathrm{A}]$ 的初末值，被积函数为常数。）更一般的分离变量技巧见 1.2 节。积分的另一化学用法是**从谱图取信息**：峰面积正比于物种总量（色谱定量、NMR 定量都基于 $\int y\,\mathrm{d}x$），这一思想在第 5 章色谱与核磁定量中正式展开。

### 1.1.3 化学情境完整算例：由速率数据求转化时间

设某反应对 A 为零级，$k = 2.5\times10^{-3}\ \mathrm{mol\cdot L^{-1}\cdot s^{-1}}$，$[\mathrm{A}]_0 = 0.30\ \mathrm{mol\cdot L^{-1}}$。（i）A 消耗一半需多长时间？（ii）量纲检查。

**解**：（i）由 $[\mathrm{A}] = [\mathrm{A}]_0 - kt$，令 $[\mathrm{A}] = [\mathrm{A}]_0/2$：

$$t_{1/2} = \frac{[\mathrm{A}]_0}{2k} = \frac{0.30\ \mathrm{mol\cdot L^{-1}}}{2\times 2.5\times10^{-3}\ \mathrm{mol\cdot L^{-1}\cdot s^{-1}}} = 60\ \mathrm{s}$$

（ii）量纲检查：$\dfrac{\mathrm{mol\cdot L^{-1}}}{\mathrm{mol\cdot L^{-1}\cdot s^{-1}}} = \mathrm{s}$，结果为时间，通过。注意零级半衰期**正比于初始浓度**，与一级（无关）、二级（反比）形成对照——完整对照表见 1.2.4 节，定量应用见 [第 7 章 化学动力学](/xiaoshus-blog/textbooks/chemistry/04-physical/02/)。

## 1.2 常微分方程求解

化学动力学的几乎所有"浓度–时间曲线"都来自常微分方程（ODE）。本节给出化学中最常用到的两种解法：可分离变量法与积分因子法，并完整求解一级与二级速率方程。

### 1.2.1 可分离变量法

形如 $\dfrac{\mathrm{d}y}{\mathrm{d}x} = f(x)g(y)$ 的方程可改写为 $\dfrac{\mathrm{d}y}{g(y)} = f(x)\mathrm{d}x$ 后两边分别积分。

**一级速率方程的完整求解**。设反应 $\mathrm{A} \to$ 产物为一级（first-order），速率定律（实验测得，第 7 章讲如何测）：

$$-\frac{\mathrm{d}[\mathrm{A}]}{\mathrm{d}t} = k[\mathrm{A}], \qquad k:\ \mathrm{s^{-1}}$$

**第 1 步（分离变量）**：把含 $[\mathrm{A}]$ 的项移到左边、含 $t$ 的项移到右边：

$$\frac{\mathrm{d}[\mathrm{A}]}{[\mathrm{A}]} = -k\,\mathrm{d}t$$

**第 2 步（两边积分）**：从初始态 $(t=0,\ [\mathrm{A}]=[\mathrm{A}]_0)$ 到任意时刻 $(t,\ [\mathrm{A}])$：

$$\int_{[\mathrm{A}]_0}^{[\mathrm{A}]} \frac{\mathrm{d}[\mathrm{A}]}{[\mathrm{A}]} = -k\int_0^t \mathrm{d}t$$

**第 3 步（执行积分）**：左端为 $\ln[\mathrm{A}]\big|_{[\mathrm{A}]_0}^{[\mathrm{A}]} = \ln\frac{[\mathrm{A}]}{[\mathrm{A}]_0}$（依据：$\int x^{-1}\mathrm{d}x = \ln x$；因为 $[\mathrm{A}]_0,[\mathrm{A}]$ 同为浓度，对数括号内无单位），右端为 $-kt$。故

$$\ln\frac{[\mathrm{A}]}{[\mathrm{A}]_0} = -kt \quad\Longleftrightarrow\quad \boxed{[\mathrm{A}] = [\mathrm{A}]_0\,e^{-kt}}$$

**第 4 步（半衰期）**：令 $[\mathrm{A}] = [\mathrm{A}]_0/2$，得

$$t_{1/2} = \frac{\ln 2}{k} = \frac{0.693}{k}$$

与初始浓度无关——这是一级反应的判据性特征（放射性衰变因而是地质/考古测年的钟，见 [第 4 章](/xiaoshus-blog/textbooks/chemistry/02-inorganic/02/) 核化学一节）。

**二级速率方程的完整求解**。设 $\mathrm{A}+\mathrm{A} \to$ 产物型二级（second-order）反应，$-\mathrm{d}[\mathrm{A}]/\mathrm{d}t = k[\mathrm{A}]^2$，$k:\ \mathrm{L\cdot mol^{-1}\cdot s^{-1}}$。

分离变量：$\dfrac{\mathrm{d}[\mathrm{A}]}{[\mathrm{A}]^2} = -k\,\mathrm{d}t$；积分（依据：$\int x^{-2}\mathrm{d}x = -x^{-1}$）：

$$-\frac{1}{[\mathrm{A}]}\bigg|_{[\mathrm{A}]_0}^{[\mathrm{A}]} = -kt \quad\Longrightarrow\quad \boxed{\frac{1}{[\mathrm{A}]} - \frac{1}{[\mathrm{A}]_0} = kt}$$

半衰期：令 $[\mathrm{A}]=[\mathrm{A}]_0/2$，得 $t_{1/2} = \dfrac{1}{k[\mathrm{A}]_0}$，与初始浓度成反比。三种级数的对照表：

| 级数 | 微分式 | 积分式 | $t_{1/2}$ | $k$ 的单位 |
|---|---|---|---|---|
| 0 | $-\mathrm{d}[\mathrm{A}]/\mathrm{d}t = k$ | $[\mathrm{A}]_0 - [\mathrm{A}] = kt$ | $[\mathrm{A}]_0/2k$ | $\mathrm{mol\cdot L^{-1}\cdot s^{-1}}$ |
| 1 | $-\mathrm{d}[\mathrm{A}]/\mathrm{d}t = k[\mathrm{A}]$ | $\ln([\mathrm{A}]_0/[\mathrm{A}]) = kt$ | $\ln 2/k$ | $\mathrm{s^{-1}}$ |
| 2 | $-\mathrm{d}[\mathrm{A}]/\mathrm{d}t = k[\mathrm{A}]^2$ | $1/[\mathrm{A}] - 1/[\mathrm{A}]_0 = kt$ | $1/(k[\mathrm{A}]_0)$ | $\mathrm{L\cdot mol^{-1}\cdot s^{-1}}$ |

这张表是 [第 7 章](/xiaoshus-blog/textbooks/chemistry/04-physical/02/) 的入场券：那里的"图解法定级数"（$\ln[\mathrm{A}]$ 对 $t$ 作图成直线 ⇒ 一级）就建立在积分方程的线性形式上。

### 1.2.2 一阶线性方程与积分因子法

可分离变量法要求变量能拆开，但许多化学方程带"源项"。典型例子：光化学反应中 A 以恒定速率 $j$ 生成、同时以一级速率 $k[\mathrm{A}]$ 分解：

$$\frac{\mathrm{d}[\mathrm{A}]}{\mathrm{d}t} = j - k[\mathrm{A}]$$

右边无法写成 $f(t)g([\mathrm{A}])$ 的乘积，改用**积分因子（integrating factor）**。对方程 $\dfrac{\mathrm{d}y}{\mathrm{d}x} + P(x)y = Q(x)$，乘以积分因子 $e^{\int P\,\mathrm{d}x}$ 后左边成为某函数的导数（依据：乘积求导法则 $\frac{\mathrm{d}}{\mathrm{d}x}(ue^{v}) = e^{v}\frac{\mathrm{d}u}{\mathrm{d}x} + ue^{v}\frac{\mathrm{d}v}{\mathrm{d}x}$）。

**第 1 步**：移项为标准形 $\dfrac{\mathrm{d}[\mathrm{A}]}{\mathrm{d}t} + k[\mathrm{A}] = j$，此处 $P(t) = k$（常数），积分因子为

$$\mu(t) = e^{\int k\,\mathrm{d}t} = e^{kt}$$

**第 2 步**：两边乘 $\mu$：

$$e^{kt}\frac{\mathrm{d}[\mathrm{A}]}{\mathrm{d}t} + ke^{kt}[\mathrm{A}] = je^{kt}$$

**第 3 步**：左边恰是 $\dfrac{\mathrm{d}}{\mathrm{d}t}\left([\mathrm{A}]e^{kt}\right)$（乘积法则，见上），于是

$$\frac{\mathrm{d}}{\mathrm{d}t}\left([\mathrm{A}]e^{kt}\right) = je^{kt}$$

**第 4 步**：从 0 到 $t$ 积分：$[\mathrm{A}]e^{kt} - [\mathrm{A}]_0 = \dfrac{j}{k}\left(e^{kt} - 1\right)$，整理得

$$\boxed{[\mathrm{A}](t) = \underbrace{\frac{j}{k}}_{\text{稳态值}} + \left([\mathrm{A}]_0 - \frac{j}{k}\right)e^{-kt}}$$

**第 5 步（物理检验）**：$t\to\infty$ 时 $[\mathrm{A}] \to j/k$，正是"生成速率 = 分解速率"的稳态（steady state），$[\mathrm{A}]_{\mathrm{ss}} = j/k$；量纲检查：$j$ 为 $\mathrm{mol\cdot L^{-1}\cdot s^{-1}}$，$k$ 为 $\mathrm{s^{-1}}$，比值 $j/k$ 为 $\mathrm{mol\cdot L^{-1}}$，通过。稳态近似是第 7 章处理复杂机理（链反应、酶催化）的核心武器，本例是它的最简单定量预演。

### 1.2.3 二阶方程预告与第 9 章的衔接

谐振子方程 $\dfrac{\mathrm{d}^2x}{\mathrm{d}t^2} + \omega^2 x = 0$ 与量子化学中的 Schrödinger 方程同属二阶微分方程。本章不展开（需要先建立特征值思想，见 1.3.3），只提醒：[第 9 章 量子化学基础](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/01/) 中"能量量子化不是假设，而是微分方程 + 边界条件的必然结果"这一关键图像。

## 1.3 线性代数

### 1.3.1 矩阵与线性方程组：化学平衡与多组分分析

大量化学计算归结为线性方程组 $\mathbf{A}\mathbf{x} = \mathbf{b}$：多组分分光光度测定、元素平衡约束、Hückel 久期方程等。以二维为例，若 $\det\mathbf{A} = a d - bc \neq 0$，则

$$\mathbf{A} = \begin{pmatrix} a & b \\ c & d \end{pmatrix},\qquad \mathbf{A}^{-1} = \frac{1}{\det\mathbf{A}}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix},\qquad \mathbf{x} = \mathbf{A}^{-1}\mathbf{b}$$

（克莱姆法则 $x = \dfrac{\begin{vmatrix} \mathbf{b} & \mathbf{B}\end{vmatrix}}{\det\mathbf{A}}$ 与上式等价。）**方程组有唯一解的判据是 $\det\mathbf{A}\neq 0$**——在化学上这就是"所选波长必须使两组分的吸光系数向量线性无关"的数学表述，实用含义见例题 1-4 与 [第 5 章 定量分析](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/)。

矩阵乘法的化学身份：**变换**。对称操作（旋转、反映）作用于分子 = 矩阵作用于坐标向量，这正是群论能矩阵化（1.4 节）与正则振动分析能机器化的原因（第 10 章）。

### 1.3.2 特征值与特征向量

对 $n\times n$ 方阵 $\mathbf{A}$，满足 $\mathbf{A}\mathbf{c} = \lambda\mathbf{c}$（$\mathbf{c}\neq\mathbf{0}$）的标量 $\lambda$ 称**特征值（eigenvalue）**，$\mathbf{c}$ 称特征向量；$\lambda$ 由久期方程（secular / characteristic equation）

$$\det(\mathbf{A} - \lambda\mathbf{I}) = 0$$

给出。为什么化学如此在乎特征值？因为"系统在某算符作用下只发生整体缩放"恰恰对应**定态与本征模式**：分子轨道能量、振动频率、转动常数在数学上都是某个哈密顿/动力学矩阵的特征值。完整的矩阵理论（对角化、SVD 及其在数据科学中的角色）见 [AI教材·特征值与对角化](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/04/)。

### 1.3.3 Hückel 预告：特征值=分子轨道能级（第 9、10 章正式展开）

Hückel 分子轨道法把共轭 $\pi$ 体系的轨道系数写成线性方程组 $\mathbf{H}\mathbf{c} = E\mathbf{S}\mathbf{c}$，近似 $\mathbf{S} = \mathbf{I}$ 后就是标准特征值问题 $\mathbf{H}\mathbf{c} = E\mathbf{c}$。以苯（6 个 C 原子，$\alpha$ 为库仑积分、$\beta$ 为共振积分）为例，能级解为

$$E = \alpha + 2\beta,\ \ \alpha + \beta(\text{二重简并}),\ \ \alpha - \beta(\text{二重简并}),\ \ \alpha - 2\beta$$

6 个 $\pi$ 电子按能量从低到高填入前三个成键轨道（$\beta<0$ 时 $\alpha+2\beta$ 最低），与 1.4 节的对称性分析一起，构成 [第 9 章](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/01/) Hückel 一节与 [第 10 章](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/02/) "对称性降低简并/解除简并"论述的骨架。此处只需记住：**解一次特征值问题，就得到一整套能级**。

## 1.4 群论初步

### 1.4.1 对称元素与对称操作

**对称操作（symmetry operation）**是使分子经变换后与自身不可区分的动作；操作所依据的几何实体（点、线、面）称**对称元素（symmetry element）**。二者一一配对，切勿混用（元素是"东西"，操作是"动作"）：

| 记号 | 对称元素 | 对称操作 | 化学实例 |
|---|---|---|---|
| $E$ | （恒等） | 不动 | 一切分子 |
| $C_n$ | $n$ 重对称轴 | 绕轴旋转 $2\pi/n$ | 苯：$C_6$；NH₃：$C_3$ |
| $\sigma$ | 镜面 | 平面反映 | H₂O：2 个 $\sigma$ 面 |
| $i$ | 对称中心 | 反演 | 苯、CO₂、SF₆：有；H₂O：无 |
| $S_n$ | 映轴 | 旋转后反映 | 甲烷的 $S_4$ |

**判定一个分子的点群（point group）**按系统流程：先看是否线性和高对称（$C_{\infty v}$、$D_{\infty h}$、$T_d$、$O_h$、$I_h$），再找最高阶主轴 $C_n$，然后查有无 $n$ 个垂直 $C_2$ 轴（有 → $D_n$ 系，再看镜面定 $D_{nh}/D_{nd}$），无则查 $\sigma_h$、$\sigma_v$ 定 $C_{nh}/C_{nv}$，全无则为 $C_n$ 或 $C_s/C_i/C_1$。

**常见分子点群速查表**（第 10 章将给出完整特征标表）：

| 点群 | 关键对称元素 | 代表分子 |
|---|---|---|
| $C_1$ | 只有 $E$ | CHFClBr |
| $C_s$ | 仅一个镜面 | 甲酸 HCOOH |
| $C_{2v}$ | $C_2 + 2\sigma_v$ | H₂O、SO₂、H₂CO |
| $C_{3v}$ | $C_3 + 3\sigma_v$ | NH₃、CH₃Cl |
| $C_{\infty v}$ | 轴向、无 $\sigma_h$、无 $i$ | CO、HCl |
| $D_{\infty h}$ | 轴向 + $\sigma_h$ + $i$ | CO₂、N₂、乙炔 |
| $D_{2h}$ | $3C_2 + \sigma_h + i$ | 乙烯、N₂O₄ |
| $D_{3h}$ | $C_3 + 3C_2' + \sigma_h$ | BF₃、PCl₅ |
| $D_{4h}$ | $C_4 + 4C_2' + \sigma_h + i$ | XeF₄、PtCl₄²⁻ |
| $D_{6h}$ | $C_6$ 系列 + $i$ | 苯 |
| $T_d$ | $4C_3 + 3S_4 + 6\sigma_d$ | CH₄、SO₄²⁻ |
| $O_h$ | $4C_3$ 系列 + $i$ | SF₆ |
| $I_h$ | $I_h$ 二十面体对称 | C₆₀ |

### 1.4.2 为什么谱学需要群论

分子振动模式数：非线性分子 $3N-6$，线性分子 $3N-5$。H₂O（$N=3$，非线性）有 3 种振动模式。**哪些模式能在红外光谱中出现？**红外吸收的强度取决于振动是否改变偶极矩，数学表述是：振动模式的对称性须与 $x$、$y$ 或 $z$ 的对称性相同（因为偶极矩分量 $\mu_x,\mu_y,\mu_z$ 按 $x,y,z$ 变换）。H₂O 属 $C_{2v}$，$x,y,z$ 三个方向的变换都"存在"于该点群中，故 3 种模式**全部红外活性**；而苯（$D_{6h}$）30 种振动中只有部分模式具有 $x,y,z$ 的对称性，其余红外禁阻。群论的作用是把"该不该出现谱峰"从经验猜测变成**对称性计算**：

1. 用分子的点群把 $3N$ 个自由度分解为不可约表示（第 10 章给方法）；
2. 与 $x,y,z$（红外）或二次函数 $x^2, xy,\dots$（拉曼）的不可约表示比对，直接读出活性模式数；
3. 中心对称分子还有**互斥规则**：IR 活性的模式必非拉曼活性，反之亦然（依据：$D_{nh}$ 群中 $x,y,z$ 与二次函数属于不同宇称的表示）——这本身就是判断分子有无对称中心的谱学证据，见 [第 10 章 分子光谱](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/02/)。

此外，群论还预言简并（$C_{3v}$ 中 NH₃ 的面内弯曲振动二重简并）并解释简并度（如 1.3.3 节苯能级的二重简并对应 $D_{6h}$ 的二维表示）。**本节目标仅是"会判定点群 + 明白对称性如何决定谱学"；特征标表与投影算符的严格处理在第 10 章。**

## 1.5 概率统计与数据处理

### 1.5.1 测量误差与正态分布

无限多次平行测定的随机误差服从**正态分布（normal distribution）**（大样本近似；小样本用 $t$ 分布，见 1.5.3）：

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}}\exp\left[-\frac{(x-\mu)^2}{2\sigma^2}\right]$$

$\mu$ 为真值（总体均值），$\sigma$ 为总体标准偏差。三个最常用的区间概率（推导见 [AI教材·随机变量](/xiaoshus-blog/textbooks/ai/math-foundations/probability-statistics/02/)）：

$$P(\mu-\sigma \le x \le \mu+\sigma) = 68.3\%,\quad P(\mu\pm2\sigma) = 95.4\%,\quad P(\mu\pm3\sigma) = 99.7\%$$

**系统误差 vs 随机误差**：前者使均值整体偏移（如砝码未校准、滴定管读数视线不水平），增大平行测定次数**不能**消除，须用对照试验/校准消除；后者围绕真值涨落，可通过增加测定次数按 $1/\sqrt{n}$ 收缩。这一区分是 [第 5 章 定量分析](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/) 误差理论的第一课。

### 1.5.2 最小二乘法：校准曲线的数学

分析化学大量依赖**校准曲线（calibration curve）**：配制 $n$ 个浓度 $x_i$ 已知的标准溶液，测得响应 $y_i$（吸光度、峰面积等），拟合直线 $y = bx + a$。**最小二乘法（least squares）**选取使残差平方和 $S = \sum_i (y_i - bx_i - a)^2$ 最小的 $b,a$。

**推导**（一元情形完整推导，多元与 SVD 观点见 [AI教材·正交性与最小二乘](/xiaoshus-blog/textbooks/ai/math-foundations/linear-algebra/03/)）：$S$ 对 $b$、$a$ 分别取偏导并令为零（依据：极值必要条件）：

$$\frac{\partial S}{\partial b} = -2\sum_i x_i(y_i - bx_i - a) = 0,\qquad \frac{\partial S}{\partial a} = -2\sum_i (y_i - bx_i - a) = 0$$

由第二式得 $a = \bar{y} - b\bar{x}$（$\bar{x},\bar{y}$ 为均值），代回第一式展开（依据：分配律与求和下标平移）：

$$\sum_i x_i y_i = b\sum_i x_i^2 + (\bar{y} - b\bar{x})\sum_i x_i \quad\Longrightarrow\quad b = \frac{\sum_i x_i y_i - n\bar{x}\bar{y}}{\sum_i x_i^2 - n\bar{x}^2}$$

等价记忆式 $b = \dfrac{\sum (x_i-\bar{x})(y_i-\bar{y})}{\sum (x_i-\bar{x})^2}$。拟合优度用决定系数 $R^2 = 1 - \dfrac{\sum (y_i - \hat y_i)^2}{\sum (y_i-\bar y)^2}$ 衡量（$\hat y_i$ 为拟合值）。**警告**：$R^2$ 高不代表线性假设正确，更禁止把校准曲线外推到浓度范围之外（例题 1-3 有具体展示）。

### 1.5.3 置信区间与 t 分布

有限次测定的样本均值 $\bar{x}$ 的精密度用**标准误** $s/\sqrt{n}$ 度量（$s$ 为样本标准偏差，$s = \sqrt{\dfrac{\sum (x_i-\bar x)^2}{n-1}}$，分母用 $n-1$ 是因为均值本身已消耗 1 个自由度）。真值 $\mu$ 的 **$100(1-\alpha)\%$ 置信区间（confidence interval）**：

$$\mu = \bar{x} \pm \frac{t_{\alpha,\,n-1}\,s}{\sqrt{n}}$$

$t_{\alpha, n-1}$ 由 $t$ 分布表查得（自由度 $\nu = n-1$；小样本时 $t$ 分布比正态分布"更胖"，是对 $\sigma$ 用 $s$ 估计这一额外不确定性的补偿）。常用值：$\nu=4$ 时 $t_{0.05}=2.776$（双侧 95%），$\nu=9$ 时 $2.262$。显著性检验（t 检验、F 检验、Q 检验剔除离群值）的完整逻辑在第 5 章。

### 1.5.4 化学情境完整算例

见例题 1-3（最小二乘）与例题 1-5 已含统计口径；综合统计算例（置信区间）安排在练习题 1-7，完整解法在答案册。

## 1.6 量纲分析与 SI 单位制

### 1.6.1 SI 基本单位与 2019 年新定义

国际单位制（SI）有 7 个基本单位：米（m）、千克（kg）、秒（s）、安培（A）、开尔文（K）、摩尔（mol）、坎德拉（cd）。2019 年 5 月 20 日起，SI 改为**用基本常数定义**：千克由普朗克常数 $h = 6.62607015\times10^{-34}\ \mathrm{J\cdot s}$（精确值）定义，摩尔由阿伏加德罗常数 $N_{\mathrm{A}} = 6.02214076\times10^{23}\ \mathrm{mol^{-1}}$（精确值）定义，开尔文由玻尔兹曼常数 $k_{\mathrm{B}} = 1.380649\times10^{-23}\ \mathrm{J\cdot K^{-1}}$（精确值）定义。化学中另有若干基本常数（非精确值，含不确定度）：$R = N_{\mathrm{A}}k_{\mathrm{B}} = 8.314\ \mathrm{J\cdot mol^{-1}\cdot K^{-1}}$，$F = N_{\mathrm{A}}e = 96485\ \mathrm{C\cdot mol^{-1}}$，$e = 1.602\times10^{-19}\ \mathrm{C}$。

**摩尔的使用纪律**：mol 必须指明基本单元（"1 mol 氧"有歧义，须写 1 mol O₂ 或 1 mol O）。这是第 2 章 2.3 节反应计算的入口纪律。

### 1.6.2 量纲齐次性与量纲检查

一切正确物理等式的每一项必有相同量纲（量纲齐次性原理）。**量纲检查作为解题习惯**的固定流程：

1. 每个物理量写出其量纲式（如浓度 $[c] = \mathrm{L^{-3}N}$，能量 $[E] = \mathrm{ML^2T^{-2}}$）；
2. 等式两侧逐项核对；
3. 对数与指数函数的宗量必须**无因次**（如 $e^{-E_a/RT}$ 中 $E_a/RT$ 无因次——$E_a$ 与 $RT$ 都是每摩尔的能量，这正是 Arrhenius 式能成立的结构性原因）。

**用无量纲化反推关系式（Buckingham π 定理思想）**：若一个现象涉及 $n$ 个物理量、$k$ 个独立量纲，则可组织成 $n-k$ 个无量纲数。化学实例：流体–颗粒体系中把斯托克斯阻力 $F = 6\pi\eta r v$ 两边作量纲核对（$[\eta] = \mathrm{M\,L^{-1}T^{-1}}$，故 $6\pi\eta r v$ 量纲为 $\mathrm{M L T^{-2}}$ = 力，通过），而 Stokes–Einstein 扩散系数

$$D = \frac{k_{\mathrm{B}}T}{6\pi\eta r}$$

量纲为 $\dfrac{\mathrm{M L^2 T^{-2}}}{\mathrm{M L^{-1} T^{-1}\cdot L}} = \mathrm{L^2 T^{-1}}$，正是扩散系数应有的量纲（第 8 章用此式由扩散系数反测分子半径）。

### 1.6.3 化学情境完整算例：van der Waals 方程的单位自洽

实际气体方程 $(p + a n^2/V^2)(V - nb) = nRT$ 中，修正项 $a n^2/V^2$ 必须与 $p$ 同量纲、$nb$ 必须与 $V$ 同量纲（依据：量纲齐次性）。由

$$[a]\frac{n^2}{V^2} = [p] \implies [a] = \frac{[p]\,V^2}{n^2} = \mathrm{Pa\cdot m^6\cdot mol^{-2}},\qquad [b] = \frac{V}{n} = \mathrm{m^3\cdot mol^{-1}}$$

实测：CO₂ 的 $a = 0.3640\ \mathrm{Pa\cdot m^6\cdot mol^{-2}}$，$b = 4.267\times10^{-5}\ \mathrm{m^3\cdot mol^{-1}}$（即 $42.67\ \mathrm{cm^3\cdot mol^{-1}}$，约为 CO₂ 分子自身占位）。单位核对通过后，方程才可用于计算——这类"由方程结构读出参数单位"的技巧在第 6 章气体一章会反复用到。

## 1.8 典型例题与解题思路

### 例题 1-1（基础计算）一级反应：N₂O₅ 的分解

25 °C 下气相（CCl₄ 溶剂中）反应 $2\,\mathrm{N_2O_5} \to 4\,\mathrm{NO_2} + \mathrm{O_2}$ 对 N₂O₅ 为一级，$k = 3.38\times10^{-5}\ \mathrm{s^{-1}}$（经典实测值）。求（i）半衰期；（ii）24 h 后 N₂O₅ 的剩余分数。

**解题思路**：识别级数 → 选积分式 → 代入 → 半衰期与分数各用一次 → 量纲检查。

**解**：（i）一级半衰期与初始浓度无关：

$$t_{1/2} = \frac{\ln 2}{k} = \frac{0.6931}{3.38\times10^{-5}\ \mathrm{s^{-1}}} = 2.05\times10^{4}\ \mathrm{s} \approx 5.70\ \mathrm{h}$$

（ii）由 $[\mathrm{A}]/[\mathrm{A}]_0 = e^{-kt}$，$t = 24.0\ \mathrm{h} = 86400\ \mathrm{s}$：

$$\frac{[\mathrm{N_2O_5}]}{[\mathrm{N_2O_5}]_0} = e^{-3.38\times10^{-5}\times 86400} = e^{-2.920} = 0.0539$$

即 24 h 后仅剩约 **5.4%**。

**量纲检查**：$k$（$\mathrm{s^{-1}}$）× $t$（s）= 无因次，可作指数；通过。

**注意**：虽然计量系数是 2，但"对 N₂O₅ 为一级"指 $-\mathrm{d}[\mathrm{N_2O_5}]/\mathrm{d}t = k[\mathrm{N_2O_5}]$，积分式不受系数 2 影响（系数只影响用 $r$ 表达时的写法）。

### 例题 1-2（综合应用）二级反应：乙酸乙酯皂化

25 °C 下皂化反应 $\mathrm{CH_3COOC_2H_5} + \mathrm{OH^-} \to \mathrm{CH_3COO^-} + \mathrm{C_2H_5OH}$ 的速率常数 $k \approx 0.11\ \mathrm{L\cdot mol^{-1}\cdot s^{-1}}$。若两反应物初始浓度均为 $0.050\ \mathrm{mol\cdot L^{-1}}$，求（i）半衰期；（ii）转化 90% 所需时间。

**解题思路**：等初始浓度 ⇒ 可用等浓度二级积分式 $1/[\mathrm{A}] - 1/[\mathrm{A}]_0 = kt$；先算 $t_{1/2}$ 再算 90% 转化点。

**解**：（i）等浓度二级：

$$t_{1/2} = \frac{1}{k[\mathrm{A}]_0} = \frac{1}{0.11\times 0.050}\ \mathrm{s} = 182\ \mathrm{s} \approx 3.0\ \mathrm{min}$$

（ii）转化 90% ⇒ $[\mathrm{A}] = 0.1[\mathrm{A}]_0 = 0.0050\ \mathrm{mol\cdot L^{-1}}$：

$$t = \frac{1/[\mathrm{A}] - 1/[\mathrm{A}]_0}{k} = \frac{200 - 20}{0.11\ \mathrm{L\cdot mol^{-1}\cdot s^{-1}}}\ \mathrm{mol^{-1}\cdot L} = 1.64\times10^{3}\ \mathrm{s} \approx 27\ \mathrm{min}$$

**量纲检查**：$\dfrac{\mathrm{mol^{-1}\cdot L}}{\mathrm{L\cdot mol^{-1}\cdot s^{-1}}} = \mathrm{s}$，通过。**对比一级**（例题 1-1）：二级的 $t_{1/2}$ 依赖初始浓度，浓度越稀反应越"相对越慢"——这是判断级数的实验线索（第 7 章）。

### 例题 1-3（综合应用）最小二乘：紫外–可见校准曲线

分光光度法测某显色配合物（1.000 cm 比色皿，空白校正后）：

| $c$ / ($10^{-5}\ \mathrm{mol\cdot L^{-1}}$) | 0 | 2 | 4 | 6 | 8 |
|---|---|---|---|---|---|
| $A$ | 0.000 | 0.191 | 0.391 | 0.584 | 0.783 |

求拟合直线、摩尔吸光系数 $\varepsilon$ 并评价线性。

**解题思路**：朗伯–比尔定律 $A = \varepsilon l c + a$（截距 $a$ 反映系统偏差，理想为 0）⇒ 最小二乘求 $b,a$ ⇒ $\varepsilon = b/l$ ⇒ 用 $R^2$ 评价。

**解**：$\bar{x} = 4$，$\bar{y} = 1.949/5 = 0.3898$；$\sum x_i y_i = 11.714$，$\sum x_i^2 = 120$，$n = 5$。

$$b = \frac{11.714 - 5\times4\times0.3898}{120 - 5\times16} = \frac{3.918}{40} = 0.09795\ \text{per}\ (10^{-5}\ \mathrm{mol\cdot L^{-1}})$$

$$a = \bar{y} - b\bar{x} = 0.3898 - 0.3918 = -0.002 \approx 0 \quad(\text{理想})$$

$$\varepsilon = \frac{b}{l} = \frac{0.09795}{1.000\times10^{-5}\ \mathrm{cm}} = 9.80\times10^{3}\ \mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$$

计算 $R^2 = 0.99995$（残差平方和 $8\times10^{-5}$ 量级 vs 总平方和 0.384），线性极好。**单位量纲检查**：$A$ 无因次，$b/A$ 单位链 $\mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$ 与 $\varepsilon$ 定义一致，通过。

**讨论**：若某未知液测得 $A = 1.60$，能否用外推求浓度？$A=1.60$ 对应约 $1.63\times10^{-4}\ \mathrm{mol\cdot L^{-1}}$，**已是最高标样的两倍**，且可能偏离比尔定律线性区（吸光 >1 时杂散光误差剧增），正确做法是稀释后重测——这就是"禁止外推"的具体含义（第 5 章）。

### 例题 1-4（综合应用）矩阵法：双组分同时测定

某溶液含 X、Y 两组分，1.000 cm 比色皿下摩尔吸光系数（$\mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$）为：$\lambda_1$ 处 $\varepsilon_{\mathrm{X}} = 1200$、$\varepsilon_{\mathrm{Y}} = 300$；$\lambda_2$ 处 $\varepsilon_{\mathrm{X}} = 400$、$\varepsilon_{\mathrm{Y}} = 1500$。测得两波长总吸光度 $A_1 = 0.420$，$A_2 = 0.620$。求 $c_{\mathrm{X}}, c_{\mathrm{Y}}$。

**解题思路**：吸光度加和性 ⇒ $\mathbf{A} = \boldsymbol{\varepsilon}\mathbf{c}$ 是 2×2 线性方程组 ⇒ 用行列式/逆矩阵求解 ⇒ 回代验证。

**解**：方程组（吸光度加和性：$A = \varepsilon_{\mathrm{X}} l c_{\mathrm{X}} + \varepsilon_{\mathrm{Y}} l c_{\mathrm{Y}}$，$l = 1.000$ cm）：

$$\begin{pmatrix} 1200 & 300 \\ 400 & 1500 \end{pmatrix}\begin{pmatrix} c_{\mathrm{X}} \\ c_{\mathrm{Y}} \end{pmatrix} = \begin{pmatrix} 0.420 \\ 0.620 \end{pmatrix}$$

$$\det\mathbf{A} = 1200\times1500 - 300\times400 = 1.68\times10^{6} \neq 0 \quad(\text{有唯一解，波长选择合格})$$

$$c_{\mathrm{X}} = \frac{0.420\times1500 - 300\times0.620}{1.68\times10^{6}} = \frac{444}{1.68\times10^{6}} = 2.64\times10^{-4}\ \mathrm{mol\cdot L^{-1}}$$

$$c_{\mathrm{Y}} = \frac{1200\times0.620 - 0.420\times400}{1.68\times10^{6}} = \frac{576}{1.68\times10^{6}} = 3.43\times10^{-4}\ \mathrm{mol\cdot L^{-1}}$$

**回代验证**：$\lambda_1$：$1200(2.643\times10^{-4}) + 300(3.429\times10^{-4}) = 0.317 + 0.103 = 0.420$ ✓；$\lambda_2$：$0.106 + 0.514 = 0.620$ ✓。

**量纲检查**：$\varepsilon$（$\mathrm{L\cdot mol^{-1}\cdot cm^{-1}}$）× $l$（cm）× $c$（$\mathrm{mol\cdot L^{-1}}$）= 无因次 = $A$ ✓。若 $\det\mathbf{A}\to 0$（两组分光谱形状几乎相同），测量误差被行列式放大，这就是"光谱正交性/选择性"的数学根源（第 5 章多组分分析、第 9 章久期方程同构）。

### 例题 1-5（拓展）积分因子法：光化学稳态

某光化学反应中 A 以恒速 $j = 1.0\times10^{-8}\ \mathrm{mol\cdot L^{-1}\cdot s^{-1}}$ 生成，同时按一级速率 $k = 2.0\times10^{-4}\ \mathrm{s^{-1}}$ 分解，初始 $[\mathrm{A}]_0 = 0$。求（i）$[\mathrm{A}](t)$ 表达式；（ii）达到稳态浓度一半所需时间。

**解题思路**：方程带源项，不可直接分离变量 ⇒ 积分因子 $e^{kt}$ ⇒ 用 1.2.2 节通解 ⇒ "达到稳态一半"即 $[\mathrm{A}] = [\mathrm{A}]_{\mathrm{ss}}/2$。

**解**：（i）由 1.2.2 节通解：

$$[\mathrm{A}](t) = \frac{j}{k}\left(1 - e^{-kt}\right),\qquad [\mathrm{A}]_{\mathrm{ss}} = \frac{j}{k} = \frac{1.0\times10^{-8}}{2.0\times10^{-4}} = 5.0\times10^{-5}\ \mathrm{mol\cdot L^{-1}}$$

（ii）令 $[\mathrm{A}](t) = [\mathrm{A}]_{\mathrm{ss}}/2$，即 $1 - e^{-kt} = 1/2$：

$$t = \frac{\ln 2}{k} = \frac{0.6931}{2.0\times10^{-4}\ \mathrm{s^{-1}}} = 3.47\times10^{3}\ \mathrm{s} \approx 58\ \mathrm{min}$$

**量纲检查**：$j/k$ 量纲 $\mathrm{(mol\cdot L^{-1}\cdot s^{-1})/s^{-1} = mol\cdot L^{-1}}$ ✓；$kt$ 无因次 ✓。**物理讨论**：到达稳态一半的时间只由 $k$ 决定（与 $j$ 无关），"趋稳快慢"与"稳态高低"是两个独立参数——这一直觉在理解第 7 章稳态近似、第 8 章电极双层充放电时都有用。

### 例题 1-6（拓展）量纲分析：由方程结构反推参数单位

（i）写出 Arrhenius 方程 $k = A e^{-E_a/RT}$ 中 $A$ 与 $E_a$ 的单位；（ii）用 Stokes–Einstein 方程，25 °C 水中（$\eta = 8.90\times10^{-4}\ \mathrm{Pa\cdot s}$）测得某球形蛋白 $D = 7.0\times10^{-11}\ \mathrm{m^2\cdot s^{-1}}$，估算其半径。

**解题思路**：（i）指数宗量无因次 ⇒ $E_a/RT$ 无因次 ⇒ $E_a$ 与 $RT$ 同量纲；$A$ 与 $k$ 同量纲。（ii）把公式反解 $r = k_{\mathrm{B}}T/(6\pi\eta D)$ 再量纲检查后代数。

**解**：（i）$E_a$：$\mathrm{J\cdot mol^{-1}}$（与 $RT$ 同量纲）；$A$：与 $k$ 同量纲（一级为 $\mathrm{s^{-1}}$）。$E_a/RT$ 无因次 ✓。

（ii）

$$r = \frac{k_{\mathrm{B}}T}{6\pi\eta D} = \frac{1.381\times10^{-23}\ \mathrm{J\cdot K^{-1}}\times 298.15\ \mathrm{K}}{6\pi\times 8.90\times10^{-4}\ \mathrm{Pa\cdot s}\times 7.0\times10^{-11}\ \mathrm{m^2\cdot s^{-1}}}$$

分子 $= 1.381\times10^{-23}\times298.15\ \mathrm{J} = 4.12\times10^{-21}\ \mathrm{J}$；分母中 $\mathrm{Pa\cdot s\times m^2\cdot s^{-1} = Pa\cdot m^3 = N\cdot m^{-2}\cdot m^3 = N\cdot m = J}$，故分母 $= 6\pi\times8.90\times10^{-4}\times7.0\times10^{-11}\ \mathrm{J} = 1.17\times10^{-12}\ \mathrm{J}$。

$$r = \frac{4.12\times10^{-21}\ \mathrm{J}}{1.17\times10^{-12}\ \mathrm{J}} = 3.5\times10^{-9}\ \mathrm{m} = 3.5\ \mathrm{nm}$$

**量纲检查**：$\dfrac{\mathrm{J}}{\mathrm{Pa\cdot s\cdot m^2\cdot s^{-1}}} = \dfrac{\mathrm{J}}{\mathrm{J\cdot m^{-1}}} = \mathrm{m}$，结果为长度 ✓。

## 1.9 常见误区与易错点

1. **速率定义漏除计量系数**：$-\mathrm{d}[\mathrm{A}]/\mathrm{d}t$ 不是反应速率 $r$，除非 $a=1$。写 $r$ 必须除以系数；用 $[\mathrm{A}]$ 直接积分时（例题 1-1 注意事项）则不需要。
2. **把"半衰期与初始浓度无关"当普遍规律**：只有一级如此。零级正比、二级反比于初始浓度；用半衰期法判级数时须改变 $[\mathrm{A}]_0$ 做实验。
3. **统计误用三连**：对系统误差用增加平行次数来"消除"（无效）；用 $R^2$ 高证明线性模型正确（$R^2$ 只在模型给定后衡量拟合优度）；把校准曲线外推到标样范围之外。
4. **置信区间分母写错**：是 $s/\sqrt{n}$（标准误），不是 $s$；自由度是 $n-1$，查表用错行是最高频错误。
5. **对称操作与对称元素混写**：$C_2$ 是元素（一根轴），旋转 $\pi$ 是操作；说"分子具有 C₂v"指对称元素集合，不是某个操作。
6. **偏导数不写固定变量下标**：$(\partial V/\partial n_{\mathrm{B}})_T$ 与 $(\partial V/\partial n_{\mathrm{B}})_{T,p}$ 是不同的量；热力学中丢下标 = 丢物理条件，第 6 章麦克斯韦关系式推导时尤其致命。

## 1.12 思考练习题

1. **概念辨析**：说明"反应速率 $r$"与"$-\mathrm{d}[\mathrm{A}]/\mathrm{d}t$"的区别；为什么定义 $r$ 时要除以计量系数？（校验值要点：$r$ 与所选物种无关；除以系数使各物种给出的速率一致。）
2. **计算**：某一级反应 $k = 0.0231\ \mathrm{min^{-1}}$。求半衰期与转化 90% 所需时间。（校验值：$t_{1/2} = 30.0\ \mathrm{min}$；$t_{90\%} = 99.7\ \mathrm{min}$。）
3. **计算**：等浓度二级反应 $k = 0.75\ \mathrm{L\cdot mol^{-1}\cdot s^{-1}}$，$[\mathrm{A}]_0 = 0.100\ \mathrm{mol\cdot L^{-1}}$。求半衰期。（校验值：13.3 s。）

5. **线性代数**：用逆矩阵解 $\begin{pmatrix} 2 & 1 \\ 1 & 3 \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} 5 \\ 10 \end{pmatrix}$。（校验值：$x = 1$，$y = 3$。）
6. **群论**：判定下列分子点群：BF₃、CH₄、H₂O₂（非平面构象）、CO₂、PtCl₄²⁻（平面正方形）。（校验值：$D_{3h}$、$T_d$、$C_2$、$D_{\infty h}$、$D_{4h}$。）
7. **统计**：5 次平行滴定耗液 25.06、25.02、25.08、25.04、25.05 mL。求平均值、标准偏差与 95% 置信区间（$t_{0.05,4} = 2.776$）。（校验值：$\bar x = 25.05\ \mathrm{mL}$，$s = 0.022\ \mathrm{mL}$，置信区间 $25.05 \pm 0.028\ \mathrm{mL}$。）
