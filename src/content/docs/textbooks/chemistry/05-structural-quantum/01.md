## 9.1 量子力学的实验基础

19 世纪末，经典物理学（Newton 力学 + Maxwell 电磁学）在三个看似平常的实验面前彻底失效。每一次失效都逼出一条新的量子假说。

### 9.1.1 黑体辐射与能量量子化

**实验事实**：黑体（blackbody，吸收全部入射辐射的理想物体，其辐射只与温度有关）的辐射强度随波长分布在高温段出现极大值；但 Rayleigh–Jeans 用经典统计（能量连续可取，每个模式均分 $k_BT$）推导出的谱强度在短波发散——史称"紫外灾难"。

**Planck 的量子假说（1900）**：谐振子的能量不能连续取值，只能取分立值

$$E = nh\nu, \quad n = 0, 1, 2, \dots$$

其中 $h = 6.62607015\times10^{-34}\ \mathrm{J\cdot s}$ 为 Planck 常量（SI 定义常数）。由此插值推出的 Planck 辐射定律与实验完全吻合，并给出两条可检验的极限规律：

- Wien 位移定律：$\lambda_{\max}T = 2.898\times10^{-3}\ \mathrm{m\cdot K}$（太阳表面约 5800 K，辐射峰在可见区约 500 nm——演化出人眼敏感波段的原因）。
- Stefan–Boltzmann 定律：总辐射通量 $M = \sigma T^4$，$\sigma = 5.67\times10^{-8}\ \mathrm{W\cdot m^{-2}\cdot K^{-4}}$。

**化学视角**：$E = nh\nu$ 是"能级量子化"的第一次出场——它是谐振子能级 $E_v=(v+\frac12)h\nu$（9.3.3 节）的零阶近似，也是红外光谱的物理基础。

### 9.1.2 光电效应与光子

**实验事实**：光照射金属表面可击出电子，但存在临界频率 $\nu_0$：低于 $\nu_0$ 时光再强也无电子逸出；高于 $\nu_0$ 时电子最大动能与光强无关，只随频率线性增加。

**Einstein 的光子假说（1905）**：光本身由能量 $h\nu$ 的量子（光子，photon）组成。光电方程：

$$K_{\max} = h\nu - \Phi$$

其中 $\Phi$ 为金属的逸出功（work function，如 Cs 约 2.1 eV，Zn 约 4.3 eV）。Millikan 实验（1916）验证了直线的斜率恰为 $h$。光子的动量 $p = h/\lambda$（Compton 散射实验证实）。

### 9.1.3 氢原子光谱与分立能级

**实验事实**：氢原子发射光谱是**分立的线状谱**，各谱线频率满足经验公式（Balmer 系在可见区）：

$$\tilde{\nu} = \frac{1}{\lambda} = R_{\mathrm{H}}\left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right), \quad R_{\mathrm{H}} = 1.09678\times10^{7}\ \mathrm{m^{-1}},\ n_2 > n_1$$

$n_1 = 1,2,3,4$ 分别称 Lyman、Balmer、Rydberg、Brackett 系。经典电磁学预言加速电子会螺旋坠入核并发出连续谱——完全错误。

**Bohr 模型（1913，过渡性但直观）**：电子绕核作圆周运动，但角动量量子化 $L = n\hbar$（$\hbar = h/2\pi$），由此给出能级

$$E_n = -\frac{\mu e^4}{32\pi^2\varepsilon_0^2\hbar^2}\cdot\frac{1}{n^2} = -\frac{13.606\ \mathrm{eV}}{n^2} = -\frac{1312\ \mathrm{kJ\cdot mol^{-1}}}{n^2}$$

其中 $\mu = \dfrac{m_e m_N}{m_e + m_N}$ 为约化质量（约化质量解释了为何氘的谱线略短移——Urey 1932 年正是这样发现氘的）。谱线公式 $\tilde\nu = (E_{n_2}-E_{n_1})/hc$ 与 Rydberg 公式严格对应，$R_{\mathrm{H}}$ 与 Rydberg 常量 $R_\infty = 1.09737\times10^7\ \mathrm{m^{-1}}$ 之比来自 $\mu \neq m_e$。Bohr 模型的"定态不辐射"无法解释多电子原子谱线强度与 Zeeman 效应——完整答案要等波动力学。

### 9.1.4 实物粒子的波粒二象性

de Broglie（1924）把 Planck–Einstein 关系反用到实物粒子上：动量为 $p$ 的粒子伴随波长 $\lambda = h/p$ 的物质波。Davisson–Germer 电子衍射（1927）证实：电子经镍单晶散射出现衍射极大，波长实测与 de Broglie 关系一致。这就是电子衍射、中子衍射能测结构的原因，也是薛定谔方程的物理出发点——**如果电子是波，它就该有波动方程**。

> **回引第 2 章**：第 2 章 2.1 节用"原子轨道"概念组织周期律，当时它是经验图像；本章 9.3.5 节将把它变成波动方程的严格解。

## 9.2 波函数与薛定谔方程：五大公设

公设（postulate）是无法从更基本原理推导、只能靠实验检验的基本假设。以下给出与化学最相关的表述形式。

### 9.2.1 公设一：态函数

微观体系的状态由**波函数**（wave function）$\Psi(q, t)$ 完全描述（$q$ 为全部坐标）。Born 概率诠释：$|\Psi(q,t)|^2\,\mathrm{d}q$ 是在 $t$ 时刻于 $q$ 附近 $\mathrm{d}q$ 内找到粒子的概率。因此要求波函数**单值、连续、平方可积**，通常归一化：

$$\int |\Psi|^2\, \mathrm{d}q = 1$$

**化学示例**：$\Psi$ 本身没有直接物理意义，但 $|\Psi|^2$ 就是"电子云"；分子的形状、反应位点，都由 $|\Psi|^2$（及由 $\Psi$ 派生的密度、键级）决定。

### 9.2.2 公设二：力学量用算符表示

每个可观测力学量对应一个线性厄米算符（operator）：

| 力学量 | 经典表达式 | 量子算符 |
|---|---|---|
| 位置 | $x$ | $\hat{x} = x$（直接乘） |
| 动量 | $p_x$ | $\hat{p}_x = -i\hbar\,\dfrac{\partial}{\partial x}$ |
| 动能 | $p^2/2m$ | $\hat{T} = -\dfrac{\hbar^2}{2m}\nabla^2$ |
| 势能 | $V(x)$ | $\hat{V} = V(x)$（直接乘） |
| 总能量（Hamilton 量） | $T+V$ | $\hat{H} = -\dfrac{\hbar^2}{2m}\nabla^2 + \hat{V}$ |

> 回引第 1 章 1.4 节：厄米性（$\int f^*\hat{A}g\,\mathrm{d}\tau = \int(\hat{A}f)^* g\,\mathrm{d}\tau$）保证本征值为实数——可观测量的基本要求。

### 9.2.3 公设三：本征值与测量结果

对态 $\Psi$ 测量力学量 $\hat{A}$，可能得到的值只能是 $\hat{A}$ 的**本征值**（eigenvalue）：$\hat{A}\Psi = a\Psi$。测量得到本征值 $a_i$ 的概率由 $\Psi$ 在本征函数基上的展开系数决定。若 $\Psi$ 本身是本征函数，则测量**必然**得该本征值——这是"定态"概念的根源。

### 9.2.4 公设四：平均值

对处于 $\Psi$ 的体系重复测量 $\hat{A}$，平均值为

$$\langle A \rangle = \frac{\int \Psi^*\hat{A}\Psi\,\mathrm{d}\tau}{\int \Psi^*\Psi\,\mathrm{d}\tau} \quad(\text{已归一化时分母为 }1)$$

**化学示例**：氢原子 1s 态 $|\psi_{1s}|^2$ 在核处最大，但平均半径 $\langle r\rangle = \tfrac32 a_0$（例题 9-4 将验证）——概率密度与平均值的区别是初学者最常混淆的点。

### 9.2.5 定态与（定态）薛定谔方程

含时薛定谔方程 $\hat{H}\Psi = i\hbar\dfrac{\partial \Psi}{\partial t}$。当势场不显含时间时，分离变量 $\Psi(q,t) = \psi(q)\,e^{-iEt/\hbar}$，得**定态薛定谔方程**：

$$\hat{H}\psi = E\psi, \qquad \left[-\frac{\hbar^2}{2m}\nabla^2 + V\right]\psi = E\psi$$

定态下 $|\Psi|^2$ 不随时间变化，能量有确定值 $E$。**化学讨论的全部"能级"都来自这个方程的解**。对多粒子体系（如分子），坐标含所有电子与核；Born–Oppenheimer 近似（核质量约为电子的 $10^3$–$10^5$ 倍、运动慢得多）允许先固定核坐标解电子问题，势能面（potential energy surface）概念即由此而来——这是 9.7 节计算化学的总纲。

### 9.2.6 公设五：全同粒子与泡利原理

全同粒子不可分辨，交换任意两个粒子时波函数只允许对称或反对称变换：

$$\Psi(\dots q_i \dots q_j \dots) = \pm\Psi(\dots q_j \dots q_i \dots)$$

- **费米子**（fermion，自旋为半整数，如电子 $s=\tfrac12$）：取 $-$ 号（反对称）。
- **玻色子**（boson，自旋为整数，如光子）：取 $+$ 号（对称）。

电子反对称的直接推论即**泡利不相容原理**：两个自旋相同的电子不能占据同一空间轨道（若两电子坐标完全相同，反对称波函数为零）。多电子波函数必须写成 **Slater 行列式**（9.4.3 节），这是理解元素周期律与化学键饱和性的根基。

## 9.3 精确可解体系：化学家的三类能级

薛定谔方程只有少数几个模型体系可精确求解，但它们恰好覆盖了化学家使用的所有能级类型：

| 模型 | 对应真实运动 | 对应光谱/性质 |
|---|---|---|
| 一维势箱 | 共轭链上 π 电子的平动 | 紫外–可见吸收（HOMO–LUMO） |
| 谐振子 | 键的伸缩振动 | 红外/拉曼峰位 → 力常数 |
| 刚性转子 | 分子整体转动 | 微波/远红外谱 → 键长 |
| 氢原子 | 电子绕核运动 | 原子光谱 → 原子轨道 |

> 回引模块四：统计热力学中平动、振动、转动配分函数 $q_\mathrm{t}, q_\mathrm{v}, q_\mathrm{r}$ 的能级表达式，正是下面四个体系的解——"配分函数需要能级，能级来自量子力学"在此闭环。

### 9.3.1 一维无限深势箱（完整推导）

**模型**：粒子（质量 $m$）限制在 $0 < x < L$ 内自由运动，箱外势能无穷大，故 $\psi = 0\ (x\le 0, x\ge L)$。箱内 $V = 0$，定态方程为

$$-\frac{\hbar^2}{2m}\frac{\mathrm{d}^2\psi}{\mathrm{d}x^2} = E\psi$$

**第一步**：改写为 $\dfrac{\mathrm{d}^2\psi}{\mathrm{d}x^2} + k^2\psi = 0$，其中 $k^2 \equiv \dfrac{2mE}{\hbar^2}$（$E>0$，定义依据）。这是第 1 章 1.2.3 节预告的二阶常系数线性方程，通解为

$$\psi(x) = A\sin kx + B\cos kx$$

**第二步（边界条件，量子化的来源）**：波函数须连续，箱内解在边界必须与箱外零值衔接：

- $x=0$：$\psi(0) = B = 0$，只剩 $\psi = A\sin kx$。
- $x=L$：$\psi(L) = A\sin kL = 0$。$A\neq0$（否则无粒子），故 $\sin kL = 0$，即 $kL = n\pi$，$n = 1, 2, 3, \dots$

**注意**：$n=0$ 给出 $\psi\equiv0$（无粒子，舍去）；负整数与正整数给出同一线性相关解。**量子化不是方程的属性，而是边界条件的属性**——这一步是全章最重要的逻辑。

**第三步（能级）**：由 $k = n\pi/L$ 与 $E = \hbar^2k^2/2m$：

$$\boxed{E_n = \frac{n^2\pi^2\hbar^2}{2mL^2} = \frac{n^2h^2}{8mL^2}}, \quad n=1,2,3,\dots$$

**第四步（归一化求 A）**：$\displaystyle\int_0^L A^2\sin^2\frac{n\pi x}{L}\,\mathrm{d}x = A^2\cdot\frac{L}{2} = 1$，得 $A = \sqrt{2/L}$：

$$\psi_n(x) = \sqrt{\frac{2}{L}}\sin\frac{n\pi x}{L}$$

**物理讨论**：
- 能级随 $n^2$ 增大、间隔 $\Delta E = (2n+1)h^2/8mL^2$ 随 $L$ 增大而变小——宏观箱体（$L\to\infty$）时能级密到连续，经典极限自然恢复（对应原理）。
- 基态能量 $E_1 = h^2/8mL^2 > 0$（零点能）：粒子不可能静止于箱底，这是不确定原理 $\Delta x\Delta p \ge \hbar/2$ 的必然（$\Delta x$ 被 $L$ 限制，$\Delta p$ 必须不为零）。
- 节点数 $= n-1$：能级越高节点越多；相邻态的正交性 $\int_0^L\psi_m\psi_n\,\mathrm{d}x = 0\ (m\neq n)$ 可直接积分验证（练习题 9.13 第 8 题的孪生结论）。

### 9.3.2 应用：共轭多烯的 HOMO–LUMO 吸收

共轭多烯的 $N$ 个 π 电子可近似看作在"一维分子势箱"（两端各外延约半个键长）中的自由电子，每条能级填 2 个自旋相反的电子。$N$ 个电子占据 $n = 1 \dots N/2$，最高占据轨道 HOMO $n = N/2$，最低未占轨道 LUMO $n = N/2 + 1$。最低跃迁能量：

$$\Delta E = \left[\left(\tfrac{N}{2}+1\right)^2 - \left(\tfrac{N}{2}\right)^2\right]\frac{h^2}{8mL^2} = \frac{(N+1)h^2}{8mL^2}, \qquad \lambda = \frac{hc}{\Delta E}$$

**关键图像：共轭链越长（$L$ 越大），HOMO–LUMO 间隙越小，吸收越红移**——这就是胡萝卜素显橙红色、视黄醛感受可见光的分子原理，也是第 12 章芳香性与发色团理论的种子。定量示例见例题 9-1。

### 9.3.3 谐振子（振动能级与零点能）

**模型**：双原子键近似为刚度 $k$ 的弹簧，约化质量 $\mu = m_1m_2/(m_1+m_2)$，$V = \tfrac12 kx^2$。定态方程

$$-\frac{\hbar^2}{2\mu}\frac{\mathrm{d}^2\psi}{\mathrm{d}x^2} + \frac12 kx^2\psi = E\psi$$

引入 $\omega = \sqrt{k/\mu}$，经幂级数法（或阶梯算符法）求解。解存在的条件是波函数在 $|x|\to\infty$ 收敛，这**再次由边界条件逼出量子化**：

$$\boxed{E_v = \left(v+\frac12\right)h\nu = \left(v+\frac12\right)\hbar\omega}, \quad v = 0, 1, 2, \dots \qquad \nu = \frac{1}{2\pi}\sqrt{\frac{k}{\mu}}$$

波函数为 Hermite 多项式乘高斯函数，例如 $\psi_0 \propto e^{-\alpha x^2/2}$，$\alpha = \mu\omega/\hbar$。

**化学要点**：
- **零点能** $E_0 = \tfrac12 h\nu \neq 0$：即使冷却到 0 K，分子仍在振动。同位素效应直接可见：D 比 H 重 2 倍，$\nu \propto \mu^{-1/2}$，D–X 键的零点能更低、解离更难——这就是动同位素效应（第 7 章动力学）的量子根源。
- 选律 $\Delta v = \pm 1$（谐振子水平），基频 $\nu_0\to\nu_1$ 的峰位即 $\tilde\nu = \nu/(c\cdot100)$（以 cm⁻¹ 计）——第 10 章 IR 谱解析的"词典"。
- 真实键是非谐振子（Morse 势），能级 $E_v = (v+\tfrac12)\tilde\nu_e hc - (v+\tfrac12)^2\tilde\nu_e x_e hc$：能级间隔随 $v$ 收缩，这是第 10 章由倍频峰求解离能 $D_e \approx \tilde\nu_e^2/(4\tilde\nu_e x_e)$ 的依据。

### 9.3.4 刚性转子（转动能级与转动谱）

**模型**：键长 $r$ 固定的双原子分子，绕质心转动，转动惯量 $I = \mu r^2$。薛定谔方程在球坐标下解出（角度部分即球谐函数 $Y_J^m$）：

$$\boxed{\varepsilon_J = \frac{J(J+1)\hbar^2}{2I}}, \quad J = 0, 1, 2, \dots \qquad \text{简并度 } g_J = 2J+1$$

光谱学中以波数表示：$F(J) = \dfrac{\varepsilon_J}{hc} = B J(J+1)$，转动常数

$$B = \frac{h}{8\pi^2 c I}\quad(\mathrm{cm}^{-1})$$

纯转动跃迁选律 $\Delta J = \pm1$（经典图像：转动的偶极矩变化才能与电磁波耦合，故**有永久偶极的分子才有纯转动红外/微波谱**——N₂、O₂ 没有，这是第 10 章拉曼光谱出场的原因）。相邻谱线间距：

$$\tilde\nu(J\to J+1) = F(J+1)-F(J) = 2B(J+1)$$

即**等间距 2B**——转动谱最显著的特征，从间距立得键长（例题 9-2）。

### 9.3.5 氢原子：原子轨道的严格来源

**分离变量**：$V(r) = -e^2/(4\pi\varepsilon_0 r)$ 只依赖 $r$，故在球坐标下 $\psi(r,\theta,\phi) = R(r)\,Y(\theta,\phi)$，径向与角度方程分离。解的完整形式：

$$\psi_{n l m}(r,\theta,\phi) = R_{nl}(r)\,Y_l^m(\theta,\phi), \qquad E_n = -\frac{\mu e^4}{32\pi^2\varepsilon_0^2\hbar^2 n^2} = -\frac{13.6\ \mathrm{eV}}{n^2}$$

**径向解的图像**（$a_0 = 52.92\ \mathrm{pm}$ 为 Bohr 半径）：

- $R_{10}(r) = 2a_0^{-3/2}e^{-r/a_0}$（1s）：无节点、指数衰减。
- $R_{20}(r) \propto (2 - r/a_0)e^{-r/2a_0}$（2s）：一个径向节点（$r = 2a_0$ 处 $R=0$）。
- $R_{21}(r) \propto r\,e^{-r/2a_0}$（2p）：核处为零（$l\neq0$ 时离心"壁垒"使电子"钻"不进核）。

**径向分布函数** $D(r) = 4\pi r^2|\psi|^2$（球壳内概率）：1s 态 $D(r) \propto r^2e^{-2r/a_0}$ 在 $r = a_0$ 处极大——虽然 $|\psi|^2$ 在核处最大，但半径 $r$ 的球壳体积 $4\pi r^2\mathrm{d}r$ 随 $r$ 增大，竞争结果极大值在 $a_0$（挑战题 9.13 第 8 题证明）。这澄清了"电子云最密"与"最可能找到电子的球壳"的区别。

**角度部分与轨道形状**：$Y_l^m$ 决定 s（球形）、p（哑铃形）、d（四叶/环形）的角度花样；实波函数是复函数 $Y_l^{\pm m}$ 的线性组合，如 $p_x \propto \tfrac{1}{\sqrt2}(Y_1^{1} - Y_1^{-1}) \propto \sin\theta\cos\phi$。**实波函数（$p_x, p_y, p_z, d_{x^2-y^2}, \dots$）是化学键方向的载体**——杂化轨道（第 11 章）就是它们的线性组合。

**量子数体系**（第 2 章经验符号的严格化）：

| 量子数 | 取值 | 决定 | 数目 |
|---|---|---|---|
| 主量子数 $n$ | $1, 2, 3, \dots$ | 能级与"壳层"大小 | — |
| 角量子数 $l$ | $0, 1, \dots, n-1$（s, p, d, f） | 轨道形状与角动量 $\sqrt{l(l+1)}\hbar$ | $n$ 个 |
| 磁量子数 $m_l$ | $-l, \dots, +l$ | 角动量方向（简并） | $2l+1$ 个 |
| 自旋量子数 $m_s$ | $\pm\tfrac12$ | 自旋方向 | 2 |

每个 $n$ 壳层容纳电子数 $\sum_l 2(2l+1) = 2n^2$。注意 $E_n$ 只依赖 $n$（简并 $n^2$ 重，不计自旋）——**这只在库仑场成立**，多电子场中 $l$ 也进入能量（9.4 节）。

## 9.4 多电子原子：屏蔽、钻穿与周期律的量子解释

### 9.4.1 中心力场近似

氦及更重的原子中电子–电子排斥项 $\sum_{i<j} e^2/(4\pi\varepsilon_0 r_{ij})$ 使方程无法精确求解。**中心力场近似**：把其他电子对这个电子的排斥平均成一个球对称的有效场，于是每个电子仍可标量子数 $(n, l)$，但感受到**有效核电荷** $Z^* = Z - \sigma$（$\sigma$ 为屏蔽常数，Slater 经验规则可估算）。单电子能级近似为

$$E_{nl} \approx -13.6\ \mathrm{eV}\times\frac{(Z-\sigma)^2}{n^2}$$

### 9.4.2 屏蔽与钻穿：能级为什么分裂

径向图像给出定性规律：

- **钻穿（penetration）**：$l$ 越小的轨道在核附近概率越大（1.4 节径向图：2s 在核处非零，2p 为零），被内层屏蔽得少，感受到的 $Z^*$ 大 → **同一 $n$ 中 $E_{ns} < E_{np} < E_{nd} < E_{nf}$**。
- **屏蔽（shielding）**：内层电子对外层电子屏蔽强（$\sigma\approx$ 每个内层电子贡献 0.85–1.00），同层电子彼此屏蔽弱（约 0.35）。

两者竞争的结果产生跨壳层交错：$4s$ 的钻穿强于 $3d$，使 $E_{4s}$ 略低于 $E_{3d}$——K、Ca 的电子先填 4s。但一旦 3d 被占据，其能级反降至 4s 之下，故**过渡金属电离时先失 4s 电子**（第 2 章留下的"为什么 Fe³⁺ 是 3d⁵4s⁰"在此解答）。

### 9.4.3 泡利原理的矩阵表述：Slater 行列式

多电子波函数必须反对称（公设五），满足要求的紧凑写法是 Slater 行列式（Slater determinant）。以基态锂（1s²2s¹，暂计三个空间–自旋坐标）为例：

$$\Psi(1,2,3) = \frac{1}{\sqrt{3!}}\begin{vmatrix} \psi_{1s\alpha}(1) & \psi_{1s\beta}(1) & \psi_{2s\alpha}(1) \\ \psi_{1s\alpha}(2) & \psi_{1s\beta}(2) & \psi_{2s\alpha}(2) \\ \psi_{1s\alpha}(3) & \psi_{1s\beta}(3) & \psi_{2s\alpha}(3) \end{vmatrix}$$

- 两行相同（两个电子同轨道同自旋）→ 行列式为零 → **泡利原理自动成立**；
- 交换任意两电子 = 交换两行 → 波函数变号 → **反对称自动成立**。

### 9.4.4 原子轨道能级与 Hund 规则

构造原理（Aufbau）+ Hund 规则：等价轨道（$n,l$ 相同）上电子先分占且自旋平行——原因是自旋平行时交换积分降低了排斥能（"交换能"）。由此可推：Cr 是 3d⁵4s¹ 而非 3d⁴4s²（半满对称+交换能），Mn²⁺ (3d⁵) 高自旋稳定。**周期表整张表，就是公设五 + 屏蔽钻穿的逐格推演**。

## 9.5 分子轨道理论：LCAO-MO

### 9.5.1 变分原理与 LCAO

多电子分子的薛定谔方程仍不可精确解，改用**变分法**（variational method）：对任意试解 $\varphi$，$\dfrac{\int\varphi^*\hat H\varphi\,\mathrm{d}\tau}{\int\varphi^*\varphi\,\mathrm{d}\tau} \ge E_0$——试解能量不低于基态，参数优化只能逼近真值。取试解为原子轨道线性组合（LCAO，linear combination of atomic orbitals）：$\psi = \sum_i c_i\phi_i$，能量极小化引出**久期方程**（secular equations）$\sum_j (H_{ij} - ES_{ij})c_j = 0$，有非平庸解要求久期行列式为零——一个矩阵特征值问题（回引第 1 章 1.3.2 节）。

### 9.5.2 成键三原则

两个原子轨道 $\phi_a, \phi_b$ 有效组合成分子轨道（MO）的条件：

1. **对称性匹配**：两轨道在对称操作下必须属于同一不可约表示（节面性质要"对得上"）。对称性不匹配的组合重叠积分正负抵消，净成键为零（如 H₂ 中 H 1s 与 Li 的 1s 不成键——能量原则也排除）。
2. **能量相近**：$|\alpha_a - \alpha_b|$ 越小，混合越有效；能量悬殊的组合近似"不混"，轨道基本留在原原子（异核分子的极性来源）。
3. **最大重叠**：重叠积分 $S_{ab} = \int\phi_a\phi_b\,\mathrm{d}\tau$ 的绝对值越大，成键–反键分裂越大，键越强。共价方向性（C 的 sp³ 四面体角）由此而来。

组合给出两个 MO：成键轨道（电子云在核间密集，能量低于原轨道）与反键轨道（含核间节面，能量更高），每个容纳 2 个电子。

### 9.5.3 同核双原子分子：完整分析

第二周期同核双原子（价层轨道 2s、2p 组合）的能级顺序分两组：

- **O₂、F₂（s–p 混合弱）**：$\sigma_{2s} < \sigma^*_{2s} < \sigma_{2p_z} < \pi_{2p_x} = \pi_{2p_y} < \pi^*_{2p} < \sigma^*_{2p_z}$
- **B₂、C₂、N₂（s–p 混合强，2s–2p 能量差小）**：$\sigma_{2s} < \sigma^*_{2s} < \pi_{2p_x} = \pi_{2p_y} < \sigma_{2p_z} < \pi^*_{2p} < \sigma^*_{2p_z}$

按电子填充计算**键级**（bond order）$= \dfrac{N_\text{成键} - N_\text{反键}}{2}$：

| 分子 | 电子组态要点 | 键级 | 磁性 | 实验 |
|---|---|---|---|---|
| N₂ | $(\sigma_{2s})^2(\sigma^*_{2s})^2(\pi)^4(\sigma_{2p_z})^2$ | 3 | 抗磁 | 键能 945 kJ/mol，极短键 110 pm |
| O₂ | …$(\pi)^4(\pi^*)^2$ | 2 | **顺磁（2 个未成对电子分占两条 π*）** | 键能 498 kJ/mol |
| F₂ | …$(\pi^*)^4$ | 1 | 抗磁 | 键能 159 kJ/mol |
| B₂ | $(\sigma_{2s})^2(\sigma^*_{2s})^2(\pi)^2$ | 1 | 顺磁（2 个未成对 π 电子，Hund 规则） | 顺磁性实验确立 π < σ 顺序 |
| C₂ | …$(\pi)^4$ | 2 | 抗磁 | 键级 2，但两条 π 键（无 σ 键）——MO 理论独有的预言 |

**O₂ 的顺磁性是 MO 理论战胜简单价键理论的标志性证据**：VB 的 Lewis 结构（O=O，所有电子配对）预言抗磁性，实验却是顺磁的；MO 自然给出两个未成对电子。键级顺序 N₂ > O₂ > F₂ 与键长、键能的实验顺序完全一致。

### 9.5.4 异核双原子分子

- **CO**（10 个价电子，与 N₂ 等电子）：键级 3，抗磁。但两原子电负性不同（C 2.55，O 3.44），成键 MO 偏向 O、反键 MO 偏向 C；**HOMO（5σ）主要落在 C 上**——这解释了 CO 作为配体用 C 端与金属成键（第 4 章羰基配合物、18 电子规则）。
- **HF**：F 的 2s 太低不参与，H 1s 只与 F 2p_z（对称性匹配方向）组合成 σ 键，F 的 2p_x、2p_y 保持非键（两对孤对电子）→ 键级 1。分子轨道"偏居氟端"对应分子的极性（μ = 1.83 D）。
- **偶极的方向问题**：CO 实验偶极很小（0.12 D）且 C 端为负——轨道极性与电荷分布不能想当然，这是 MO 分析中要尊重计算/实验的地方。

## 9.6 Hückel 分子轨道法：丁二烯完整手算

### 9.6.1 近似要点

Hückel 近似只处理 π 电子，取 LCAO 并引入三个经验简化：

1. 同种原子轨道的库仑积分取同一常数：$H_{ii} = \alpha$；
2. 相邻原子的交换积分取同一常数：$H_{ij} = \beta\ (i,j$ 相邻$)$，非相邻取 0；
3. 忽略重叠积分：$S_{ij} = \delta_{ij}$。

$\alpha$（约 −13.6 eV 量级但不必取库仑值）与 $\beta$（负，约 −2.5 eV）由实验标定。体系本征值问题化为矩阵对角化——**回引第 1 章 1.3.2 节：特征值 = 分子轨道能级，特征向量 = 轨道系数**。

### 9.6.2 丁二烯：久期方程 → 能级 → 系数

丁二烯 CH₂=CH–CH=CH₂ 有 4 个 p 轨道、4 个 π 电子。久期行列式（对角元 $\alpha - E$，相邻非对角元 $\beta$）：

$$\begin{vmatrix} \alpha-E & \beta & 0 & 0 \\ \beta & \alpha-E & \beta & 0 \\ 0 & \beta & \alpha-E & \beta \\ 0 & 0 & \beta & \alpha-E \end{vmatrix} = 0$$

令 $x = \dfrac{\alpha - E}{\beta}$（提出 $\beta^4$ 后）：

$$\begin{vmatrix} x & 1 & 0 & 0 \\ 1 & x & 1 & 0 \\ 0 & 1 & x & 1 \\ 0 & 0 & 1 & x \end{vmatrix} = x^4 - 3x^2 + 1 = 0$$

（按第一行展开的递推：记 $D_n$ 为 $n$ 阶三对角行列式，$D_1 = x$、$D_2 = x^2-1$、$D_3 = x^3-2x$，则 $D_4 = xD_3 - D_2 = x^4-3x^2+1$，与例题 9-3 的逐项展开同法。）

令 $t = x^2$：$t^2 - 3t + 1 = 0 \Rightarrow t = \dfrac{3\pm\sqrt5}{2}$，即 $t_+ = 2.618$、$t_- = 0.382$。故

$$x = \pm1.618,\ \pm0.618 \quad\Longrightarrow\quad E = \alpha - x\beta:\quad E_1 = \alpha+1.618\beta,\ E_2 = \alpha+0.618\beta,\ E_3 = \alpha-0.618\beta,\ E_4 = \alpha-1.618\beta$$

（约定 $\beta < 0$，故 $x$ 越大能量越低；四个能级代回原式均可验证。）4 个电子填 $E_1, E_2$（各 2 电子），HOMO = ψ₂，LUMO = ψ₃。

**系数**：把 $E$ 代回久期方程组递推求解并归一化（利用 $\sum_j c_j^2 = 1$）：

$$\psi_1 = 0.3717\,\phi_1 + 0.6015\,\phi_2 + 0.6015\,\phi_3 + 0.3717\,\phi_4$$
$$\psi_2 = 0.6015\,\phi_1 + 0.3717\,\phi_2 - 0.3717\,\phi_3 - 0.6015\,\phi_4$$

ψ₂ 在 2、3 位之间**变号**——HOMO 的节面正在中心键上，这预示中心键 π 成分最弱（对化学反应位点选择的预言，第 12 章 FMO 理论的起点）。

### 9.6.3 电荷密度、π 键级与离域化能

- **π 电荷密度**：$q_i = \sum_j n_j c_{ij}^2$（$n_j$ 为轨道 $j$ 占据数）。$q_1 = 2(0.3717^2 + 0.6015^2) = 1.000$，四个碳均为 1.0 → 无极性（对称分子的自检）。
- **π 键级**：$P_{ij} = \sum_j n_j c_{ij}c_{ji}$（占据轨道求和）：
  $$P_{12} = 2(0.3717\times0.6015 + 0.6015\times0.3717) = 0.894, \qquad P_{23} = 2(0.6015^2 - 0.3717^2) = 0.447$$
  **端键 0.894 < 1，中心键 0.447 > 0**：端键被削弱、中心键被激活——直接定量解释了丁二烯发生 1,4-加成（第 12 章）的原因，且 $P_{23}>0$ 解释了为何中心键长 146.7 pm 短于普通 C–C 单键 154 pm。
- **离域化能**：占据轨道总 π 能 $= 2E_1 + 2E_2 = 4\alpha + 4.472\beta$；若定域为两个孤立乙烯，则为 $2\times(2\alpha+2\beta) = 4\alpha+4\beta$。差值 $= 0.472\beta = 0.472|\beta| > 0$：**离域化稳定了约 $0.47|\beta|\approx 0.47\times2.5\ \mathrm{eV} \approx 1.2\ \mathrm{eV}\approx 113\ \mathrm{kJ/mol}$**。注意：热氢化实验测得的额外稳定化约 15 kJ/mol——Hückel 的 $\beta$ 只是经验参数，定量结论必须与实验标定对照（常见误区见 9.10）。

**推广**：同样的行列式技巧用于苯（环状、六元），给出 $E = \alpha + 2\beta, \alpha+\beta(\times2), \alpha-\beta(\times2), \alpha-2\beta$，总 π 能 $6\alpha+8\beta$，比三个孤立乙烯多稳定 $2\beta$——**芳香性（第 12 章 $4n+2$ 规则）的 Hückel 判据**由此而来。

## 9.7 计算化学入门：从模型到软件

### 9.7.1 Hartree–Fock 方法

中心思想：把多电子波函数写成 Slater 行列式（9.4.3），用变分原理优化其中的单电子轨道，得 **Hartree–Fock（HF）方程**：

$$\hat F\,\psi_i = \varepsilon_i\psi_i, \qquad \hat F = \hat h + \sum_j(2\hat J_j - \hat K_j)$$

$\hat J$（Coulomb 算符）代表其他电子的平均排斥，$\hat K$（交换算符）来自 Slater 行列式的反对称性。由于 $\hat F$ 依赖待求的轨道本身，需**自洽场迭代**（self-consistent field, SCF）：猜轨道 → 构造 F → 解方程 → 新轨道 → 循环至收敛。HF 精确处理了交换，但完全平均化了电子相关——能量偏高，差值称**相关能**。

### 9.7.2 密度泛函理论（DFT）

Hohenberg–Kohn 定理：基态能量是电子密度 $\rho(\mathbf r)$ 的唯一泛函。Kohn–Sham 方法把问题化为解一组形式类似 HF 的单电子方程，但交换相关能 $E_{xc}[\rho]$ 用泛函近似吸收——常用泛函 B3LYP（杂化）、PBE（GGA）、M06（ Minnesota 系）。DFT 以 HF 级别的计算量包含大部分相关能，是当今大体系计算的主力。

### 9.7.3 基组

轨道用基函数展开：最小基 STO-3G（每轨道 1 组、3 个高斯拟合）；劈裂价基 6-31G（价层双 ζ）、6-31G(d)（再加 d 极化函数，即 6-31G*）；相关一致基 cc-pVDZ/cc-pVTZ；弥散函数（+）用于阴离子与弱相互作用。**基组越大越接近 HF 极限，但计算量按 $N^4$（HF）或更高增长**——基组选择是精度与代价的第一权衡。

## 9.9 典型例题与解题思路

### 例题 9-1（基础计算）一维势箱估算丁二烯的紫外吸收

**题**：用自由电子模型估算丁二烯（CH₂=CH–CH=CH₂，4 个 π 电子）的最长吸收波长。已知链长取 $L = 0.578\ \mathrm{nm}$（即 5.78 Å：3 个 C–C 键共约 4.20 Å，两端各外延约 0.79 Å 的经验修正），并与实验值 $\lambda_{\max} = 217\ \mathrm{nm}$ 比较。

**思路**：π 电子 → 势箱；$N = 4$，HOMO $n=2$、LUMO $n=3$，$\Delta E = 5h^2/8mL^2$；再经 $E = hc/\lambda$ 求波长。

**解**：

$$\Delta E = 5\times\frac{h^2}{8mL^2} = 5\times\frac{(6.626\times10^{-34})^2}{8\times9.109\times10^{-31}\times(5.78\times10^{-10})^2}$$

分母 $8mL^2 = 8\times9.109\times10^{-31}\times3.341\times10^{-19} = 2.435\times10^{-48}\ \mathrm{kg\cdot m^2}$；
$h^2 = 4.390\times10^{-67}\ \mathrm{J^2\cdot s^2}$；

$$\frac{h^2}{8mL^2} = 1.803\times10^{-19}\ \mathrm{J}, \qquad \Delta E = 9.02\times10^{-19}\ \mathrm{J}$$

**量纲检查**：$\mathrm{\dfrac{J^2 s^2}{kg\cdot m^2} = \dfrac{(kg\,m^2/s^2)^2 s^2}{kg\,m^2} = \dfrac{kg^2 m^4/s^2}{kg\,m^2}\cdot\frac{1}{1} = kg\,m^2/s^2 = J}$ ✓

$$\lambda = \frac{hc}{\Delta E} = \frac{6.626\times10^{-34}\times2.998\times10^8}{9.02\times10^{-19}} = 2.20\times10^{-7}\ \mathrm{m} = 220\ \mathrm{nm}$$

与实验 217 nm 偏差 1.4%——简单模型之所以好，因为共轭 π 电子确实高度离域、"箱化"程度高。

### 例题 9-2（综合应用）由光谱数据反推键长与力常数

**题**：(a) HCl 的转动常数 $B = 10.59\ \mathrm{cm}^{-1}$，求键长。(b) HCl 基频振动 $\tilde\nu = 2886\ \mathrm{cm}^{-1}$，按谐振子模型求力常数 $k$。已知 $^{1}\mathrm{H}^{35}\mathrm{Cl}$：$\mu = \dfrac{1.0\times35.0}{36.0}\ \mathrm{u} = 0.9722\ \mathrm{u} = 1.627\times10^{-27}\ \mathrm{kg}$。

**解**：

(a) 由 $B = h/8\pi^2 c I$（$c$ 用 cm/s 保证波数量纲一致）：

$$I = \frac{h}{8\pi^2 c B} = \frac{6.626\times10^{-34}}{8\pi^2\times2.998\times10^{10}\times10.59} = 2.64\times10^{-46}\ \mathrm{kg\cdot m^2}$$

**量纲检查**：$\mathrm{\dfrac{J\,s}{(1/cm^2)\cdot(cm/s)\cdot cm^{-1}} = \dfrac{J\,s}{1/s} = J\cdot s^2 = kg\cdot m^2}$ ✓

$$r = \sqrt{\frac{I}{\mu}} = \sqrt{\frac{2.64\times10^{-46}}{1.627\times10^{-27}}} = 1.275\times10^{-10}\ \mathrm{m} = 127.5\ \mathrm{pm}$$

与实验 127.4 pm 吻合。

(b) 谐振子：$\tilde\nu = \dfrac{1}{2\pi c}\sqrt{k/\mu}$（$\tilde\nu$ 单位 m⁻¹ 时 $c$ 用 m/s；此处 $\tilde\nu = 2.886\times10^5\ \mathrm{m}^{-1}$）：

$$k = \mu(2\pi c\tilde\nu)^2 = 1.627\times10^{-27}\times(2\pi\times2.998\times10^8\times2.886\times10^5)^2$$

$2\pi c\tilde\nu = 5.438\times10^{14}\ \mathrm{s}^{-1}$（rad/s），

$$k = 1.627\times10^{-27}\times2.957\times10^{29} = 481\ \mathrm{N\cdot m^{-1}}$$

**量纲检查**：$\mathrm{kg\times s^{-2} = N/m}$ ✓。键越强力常数越大（HCl 481、N₂ 约 2290、单键 C–C 约 450 N/m——同一量级的比较见第 10 章）。

### 例题 9-3（综合应用）Hückel：烯丙基自由基

**题**：用 Hückel 法求烯丙基自由基 CH₂=CH–CH₂•（3 个 p 轨道、3 个 π 电子）的能级、总 π 能与未成对电子所在轨道，并求离域化能（相对一个乙烯 + 一个孤立 p 电子）。

**解**：久期行列式

$$\begin{vmatrix} x & 1 & 0 \\ 1 & x & 1 \\ 0 & 1 & x \end{vmatrix} = x(x^2-1) - x = x(x^2-2) = 0 \Rightarrow x = 0, \pm\sqrt2$$

$$E = \alpha+\sqrt2\,\beta,\quad \alpha,\quad \alpha-\sqrt2\,\beta \quad(\beta<0，E=\alpha-\sqrt2\beta \text{ 最低})$$

3 个电子填满 $E_1 = \alpha+\sqrt2\beta$（2 e⁻），单电子占据 $E_2 = \alpha$。总 π 能 $= 2(\alpha+\sqrt2\beta) + \alpha = 3\alpha + 2\sqrt2\beta$。参照态（乙烯 $2\alpha+2\beta$ 加孤立 p 电子 $\alpha$）$= 3\alpha + 2\beta$。离域化能 $= 2\sqrt2\beta - 2\beta = 2(\sqrt2-1)|\beta| \approx 0.83|\beta| \approx 1.0\ \mathrm{eV}\approx 96\ \mathrm{kJ/mol}$。

未成对电子的轨道系数（$x=0$：$c_1 + c_3 = 0$？逐式：由第 1 行 $c_2 = 0$，第 2 行 $c_1 + c_3 = 0$，归一化得 $c_1 = -c_3 = 1/\sqrt2$）：**未成对电子密度只在两端碳上**——这正是烯丙基自由基反应发生在端位（第 12 章自由基稳定性与共振稳定化）的量子根据。

### 例题 9-4（综合应用）氢原子：平均半径与最概然半径

**题**：对氢原子 1s 态 $\psi_{1s} = \dfrac{1}{\sqrt{\pi a_0^3}}e^{-r/a_0}$：(a) 求 $|\psi|^2$ 极大处；(b) 求 $\langle r\rangle$；(c) 求径向分布极大处 $r_\max$。

**解**：

(a) $|\psi|^2$ 随 $r$ 单调递减，极大在 $r = 0$（核上）。

(b) $\displaystyle\langle r\rangle = \int\psi^* r\,\psi\,\mathrm{d}\tau = \int_0^\infty r\,|\psi_{1s}|^2\,4\pi r^2\,\mathrm{d}r = \frac{4}{a_0^3}\int_0^\infty r^3 e^{-2r/a_0}\,\mathrm{d}r$

利用积分公式 $\int_0^\infty r^n e^{-\lambda r}\mathrm{d}r = n!/\lambda^{n+1}$（第 1 章 1.1.2）：

$$\langle r\rangle = \frac{4}{a_0^3}\times\frac{3!}{(2/a_0)^4} = \frac{4\times6\,a_0^4}{16\,a_0^3} = \frac{3}{2}a_0 = 79.4\ \mathrm{pm}$$

**量纲检查**：$a_0^4/a_0^3 = a_0$（长度）✓

(c) $D(r) = 4\pi r^2|\psi|^2 \propto r^2e^{-2r/a_0}$，令 $\mathrm{d}D/\mathrm{d}r = 0$：

$$2r\,e^{-2r/a_0} + r^2\left(-\frac{2}{a_0}\right)e^{-2r/a_0} = 0 \Rightarrow r_\max = a_0 = 52.9\ \mathrm{pm}$$

**结论**：密度极大（0）、最概然球壳（$a_0$）、平均半径（$1.5a_0$）是三个不同的量——Bohr 半径作为"氢原子大小"的准确含义是最概然球壳半径。

### 例题 9-5（拓展）O₂ 的 MO 分析与超氧根比较

**题**：(a) 写出 O₂ 的价层 MO 组态，判断键级与磁性。(b) O₂ 得 1 个电子成 O₂⁻（超氧根），再得 1 个成 O₂²⁻（过氧根），比较三者键级、键长顺序与磁性，并说明 KO₂ 为什么可作氧气源（航天/矿井）。

**解**：

(a) O₂ 价组态（12 个价电子，O₂/F₂ 顺序）：$(\sigma_{2s})^2(\sigma^*_{2s})^2(\sigma_{2p_z})^2(\pi_{2p_x,2p_y})^4(\pi^*_{2p})^2$。两条 π* 简并，按 Hund 规则各占 1 个且自旋平行 → **键级 2，顺磁**（2 个未成对电子），与液氧被磁铁吸引的演示实验一致。

(b) 电子填入反键 π*，每加一个电子键级减 1/2：

| 物种 | π* 电子 | 键级 | 磁性 | 键长趋势 |
|---|---|---|---|---|
| O₂ | 2 | 2 | 顺磁 | 121 pm（最短） |
| O₂⁻ | 3 | 1.5 | 顺磁（1 个未成对） | ≈133 pm |
| O₂²⁻ | 4 | 1 | 抗磁 | ≈149 pm（最长） |

KO₂ 与 CO₂/水汽反应 $4\mathrm{KO_2} + 2\mathrm{CO_2} \to 2\mathrm{K_2CO_3} + 3\mathrm{O_2}$：超氧根的高活性（单电子反键占据）既"吸收"呼出 CO₂ 又释放 O₂，一举两得——键级/反键占据的分析直接联系到工程应用。

## 9.10 常见误区与易错点

1. **"量子化来自薛定谔方程"**——错。方程本身对任意 $E$ 都有解；是**边界条件**（箱壁为零、波函数平方可积、周界匹配）筛出了分立能级。自由粒子（无边界）能级连续。
2. **振动/转动计算用原子质量 $m$ 而不是约化质量 $\mu$**——转动惯量 $I = \mu r^2$、振动频率 $\nu\propto\mu^{-1/2}$，必须用 $\mu$；双原子同核时 $\mu = m/2$。
3. **转动能级写成 $BJ^2$**——正确是 $BJ(J+1)$；相应谱线间距是 $2B$ 而非 $B$。
4. **"电子云 = 电子像云一样散开"**——$|\psi|^2$ 是概率密度，不是电荷涂抹；径向分布函数 $D(r)$ 与概率密度 $|\psi|^2$ 的极大位置不同（例题 9-4）。
5. **Hückel 的 $\beta$ 当真实能量差**——$\beta$ 是经验参数，必须用实验（电离能、热氢化焓、紫外跃迁）标定；离域化能的"数值"只有半定量意义，但键级、电荷密度的**相对**趋势相当可靠。
6. **单位换算混乱**：cm⁻¹ ↔ J ↔ eV ↔ kJ/mol 的换算（1 cm⁻¹ = 11.96 J/mol；1 eV = 96.485 kJ/mol = 8065.5 cm⁻¹）建议固定用一张换算卡（见模块导览）。
