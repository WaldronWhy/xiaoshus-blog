## 第 9 章 量子化学基础

## 9-1【概念】三个实验与三条量子假说的对应

**要点**：

- 黑体辐射 → **谐振子能量量子化** $E = nh\nu$：只有让腔壁振子的能量分立，短波模式才能因"量子代价太高"而不被激发，紫外灾难消失。量子化的是**振子（光发射体）的能量**。
- 光电效应 → **光的粒子性（光子）** $E = h\nu$、$p = h/\lambda$：能量以整份 $h\nu$ 交给单个电子，故存在临界频率、$K_{\max}$ 只依赖频率。量子化的是**光本身的能量携带**。
- 氢原子光谱 → **原子能级量子化**：分立谱线是分立能级差的直接显影 $\tilde\nu = \Delta E/hc$。量子化的是**电子在原子中的状态**。
- 前两者说"量子化的是光"，因为介入的量子是电磁场的（振子能量、光子）；第三个说"量子化的是原子"，因为光在此只是探针，分立性源自原子内部能级。

## 9-2【计算】纳米势箱中的电子

**列式**：$E_n = n^2h^2/8mL^2$，$L = 1.00\times10^{-9}\ \mathrm{m}$。

$$E_1 = \frac{(6.626\times10^{-34})^2}{8\times9.109\times10^{-31}\times(1.00\times10^{-9})^2} = \frac{4.390\times10^{-67}}{7.288\times10^{-48}} = 6.03\times10^{-20}\ \mathrm{J}$$

**量纲检查**：$\mathrm{J^2\,s^2/(kg\,m^2) = kg\,m^2\,s^{-2} = J}$ ✓

$$E_1 = 0.376\ \mathrm{eV}，\qquad E_2 = 4E_1 = 1.50\ \mathrm{eV}$$

**跃迁波长**：

$$\Delta E = 3E_1 = 1.128\ \mathrm{eV} \Rightarrow \lambda = \frac{1239.84\ \mathrm{eV\,nm}}{1.128\ \mathrm{eV}} = 1100\ \mathrm{nm}$$

**校验**：$E_1 = 0.376\ \mathrm{eV}$、$\lambda \approx 1100\ \mathrm{nm}$（近红外）✓ 与正文校验值一致。

**讨论**：$L$ 从 0.578 nm（丁二烯）增大到 1 nm，间隙 $\propto L^{-2}$ 缩小，跃迁从紫外移到近红外——"更大＝更红"的一般规律。

## 9-3【计算】己三烯的 $\lambda_{\max}$ 与模型局限

**列式**：$N = 6$，HOMO $n = 3$，LUMO $n = 4$，$\Delta E = (2\times3+1)h^2/8mL^2 = 7h^2/8mL^2$；$L = 8.4\times10^{-10}\ \mathrm{m}$。

$$\frac{h^2}{8mL^2} = \frac{4.390\times10^{-67}}{8\times9.109\times10^{-31}\times(8.4\times10^{-10})^2} = \frac{4.390\times10^{-67}}{5.142\times10^{-48}} = 8.54\times10^{-20}\ \mathrm{J}$$

**量纲检查**：同题 9-2，$= \mathrm{J}$ ✓

$$\Delta E = 7\times8.54\times10^{-20} = 5.98\times10^{-19}\ \mathrm{J} \Rightarrow \lambda = \frac{hc}{\Delta E} = \frac{1.986\times10^{-25}}{5.98\times10^{-19}} = 332\ \mathrm{nm}$$

**校验**：$\lambda_\mathrm{calc} \approx 332\ \mathrm{nm}$（正文校验值一致）✓；实验约 258 nm。

**偏差讨论**（模型为什么"越用越差"）：
1. 势箱取 $L = 8.4$ Å 偏大——真实共轭链端部势垒有限且键长交替（单双键不等长），有效箱长更短；
2. 忽略了 π 电子间排斥（自由电子模型）；3. 箱外势垒并非无限。
丁二烯偏差小（1.4%）而己三烯偏差大（+29%）：链越长，模型系统误差越累积。**结论**：势箱模型适合定性趋势（红移规律）与短链半定量估算，长链需 Hückel 或更高方法。

## 9-4【计算】HCl 力常数与同位素位移

**(a)** $\tilde\nu = \frac{1}{2\pi c}\sqrt{k/\mu}$（$\tilde\nu$ 以 m⁻¹：$2.886\times10^5\ \mathrm{m^{-1}}$；$\mu_{\mathrm{HCl}} = \frac{1.008\times34.97}{35.98}\ \mathrm{u} = 0.9797\ \mathrm{u} = 1.627\times10^{-27}\ \mathrm{kg}$）

$$k = \mu(2\pi c\tilde\nu)^2 = 1.627\times10^{-27}\times(2\pi\times2.998\times10^8\times2.886\times10^5)^2 = 1.627\times10^{-27}\times(5.438\times10^{14})^2$$

$$= 1.627\times10^{-27}\times2.957\times10^{29} = 481\ \mathrm{N\,m^{-1}}$$

**量纲检查**：$\mathrm{kg\,s^{-2} = (kg\,m\,s^{-2})/m = N/m}$ ✓。**校验**：481 N/m ✓。

**(b)** 同位素不改变电子云 → $k$ 相同（481 N/m），只有 $\mu$ 变：

$$\frac{\tilde\nu_{\mathrm{DCl}}}{\tilde\nu_{\mathrm{HCl}}} = \sqrt{\frac{\mu_{\mathrm{HCl}}}{\mu_{\mathrm{DCl}}}} = \sqrt{\frac{1.627\times10^{-27}}{3.166\times10^{-27}}} = 0.717$$

$$\tilde\nu_{\mathrm{DCl}} = 2886\times0.717 = 2070\ \mathrm{cm^{-1}}$$

**校验**：2070 cm⁻¹（实验 2091，差 1%——源于用基频代替 $\tilde\nu_e$ 的非谐效应）✓。**化学含义**：D–X 键零点能更低、更难断裂——动同位素效应的量子根源（衔接第 7 章）。

## 9-5【计算】CO 键长

**列式**：$B = 3.862/2 = 1.931\ \mathrm{cm^{-1}}$。

$$I = \frac{h}{8\pi^2 c B} = \frac{6.626\times10^{-34}}{8\pi^2\times2.998\times10^{10}\times1.931} = \frac{6.626\times10^{-34}}{4.571\times10^{13}} = 1.450\times10^{-46}\ \mathrm{kg\,m^2}$$

**量纲检查**：$\mathrm{\dfrac{J\,s}{cm^{-1}\cdot cm\,s^{-1}} = J\,s^2 = kg\,m^2}$ ✓

$$\mu_{\mathrm{CO}} = \frac{12.011\times15.999}{28.010}\ \mathrm{u} = 6.861\ \mathrm{u} = 1.139\times10^{-26}\ \mathrm{kg}, \qquad r = \sqrt{\frac{I}{\mu}} = \sqrt{\frac{1.450\times10^{-46}}{1.139\times10^{-26}}} = 1.128\times10^{-10}\ \mathrm{m}$$

**校验**：$r = 112.8$ pm ✓（与正文例题 9-2 的方法互为印证）。

## 9-6【计算】Balmer 系 Hα

**列式**：$n: 3\to2$：

$$\frac1\lambda = R_H\left(\frac14-\frac19\right) = R_H\times\frac{5}{36} \Rightarrow \lambda = \frac{36}{5R_H} = \frac{36}{5\times1.09678\times10^{7}} = 6.5647\times10^{-7}\ \mathrm{m}$$

**量纲检查**：$\mathrm{m^{-1}}$ 取倒数 → $\mathrm{m}$ ✓。

**校验**：656.5 nm（实验 656.3 nm，残差来自谱线精细结构与 $R_H$ 所用 $\mu$ 的极小差别）✓。

## 9-7【综合】氧分子物种系列

MO 分析：涉及的都是反键 $\pi^*_{2p}$（二重简并）。按 Hund 规则填充：

| 物种 | $\pi^*$ 电子 | 键级 | 磁性 | 键长（实验） |
|---|---|---|---|---|
| O₂²⁺ | 0 | 2.5 | 抗磁 | 112 pm |
| O₂ | 2（分占两条，自旋平行） | 2 | 顺磁（2 未成对） | 121 pm |
| O₂⁻ | 3 | 1.5 | 顺磁（1 未成对） | 133 pm |
| O₂²⁻ | 4（全满） | 1 | 抗磁 | 149 pm |

键长排序：O₂²⁺ < O₂ < O₂⁻ < O₂²⁻ ✓。

**一般规则**：电子得失是否改变键长，取决于电子进出的轨道性质——**进/出成键轨道**：得电子键变短、失电子键变长；**进/出反键轨道**：得电子键变长、失电子键变短。"得电子键变长"仅当 HOMO 是反键轨道时成立（O₂ 系列是典型；若 HOMO 为成键或非键轨道，如 CO 的 5σ，得电子反而键变化不大甚至变短）。

## 9-8【挑战】正交性与径向分布极大

**(a) 势箱本征函数正交性证明**：

$$\int_0^L \psi_m(x)\psi_n(x)\,\mathrm{d}x = \frac{2}{L}\int_0^L \sin\frac{m\pi x}{L}\sin\frac{n\pi x}{L}\,\mathrm{d}x$$

用积化和差（$m \neq n$）：

$$= \frac{1}{L}\int_0^L\left[\cos\frac{(m-n)\pi x}{L} - \cos\frac{(m+n)\pi x}{L}\right]\mathrm{d}x = \frac{1}{L}\left[\frac{L\sin((m-n)\pi)}{(m-n)\pi} - \frac{L\sin((m+n)\pi)}{(m+n)\pi}\right]$$

$m\pm n$ 为整数，$\sin(\text{整数}\times\pi) = 0$，故积分 $= 0$ ✓。（$m = n$ 时第一项为 $\sin 0/0$ 型极限，积分 $= L/2$，得归一化。）物理意义：不同本征值的厄米算符本征函数自动正交（第 9 章 9.2.2 厄米性的推论）。

**(b) 1s 径向分布极大在 $r = a_0$ 的证明**：

$$D(r) = 4\pi r^2|\psi_{1s}|^2 = 4\pi r^2\cdot\frac{1}{\pi a_0^3}e^{-2r/a_0} \propto r^2 e^{-2r/a_0}$$

$$\frac{\mathrm{d}D}{\mathrm{d}r} \propto e^{-2r/a_0}\left(2r - \frac{2r^2}{a_0}\right) = 2r\,e^{-2r/a_0}\left(1 - \frac{r}{a_0}\right) = 0 \Rightarrow r = a_0$$

（$r=0$ 为极小，$r\to\infty$ 衰减为零，$r = a_0$ 为唯一极大；二阶导在 $a_0$ 处为负，确认极大。）

**为什么不在核处**：$D(r)\mathrm{d}r$ 是**半径 $r$、厚度 $\mathrm{d}r$ 的球壳内**的概率，含球壳体积因子 $4\pi r^2$；在核附近 $r\to0$，尽管 $|\psi|^2$ 最大，球壳体积趋于零。两个因素（$r^2$ 增函数 vs 指数衰减）竞争，极大点在 $a_0$。这再次强调 9.2.4 公设四的要点："密度最大"与"最概然位置"是不同的问题。

## 第 10 章 结构化学

## 10-1【概念】IR 与 Raman 的统一判据

**要点**：统一判据是**跃迁矩**是否为零——

- IR 活性：振动/转动过程中**偶极矩**必须变化（$\partial\mu/\partial q \neq 0$）；
- Raman 活性：过程中**极化率**必须变化（$\partial\alpha/\partial q \neq 0$）。

应用一：H₂、N₂、O₂ 无固有偶极，转动也不产生偶极变化 → 无纯转动 IR 谱；但电子云极化率是各向异性的，转动使极化率张量在实验室系变化 → 转动拉曼谱存在（选律 $\Delta J = \pm2$）。

应用二：CO₂ 对称伸缩中两个 C=O 键偶极变化等值反向、净偶极始终为零 → IR 不活性；但键长同时伸缩使极化率显著变化 → Raman 强（1333 cm⁻¹）。

一句话：**IR 看"电荷不对称"的变化，Raman 看"电子云形状（可极化性）"的变化**——两者正交，故互补。

## 10-2【计算】HI 键长

$$I = \frac{h}{8\pi^2 c B} = \frac{6.626\times10^{-34}}{8\pi^2\times2.998\times10^{10}\times6.511} = \frac{6.626\times10^{-34}}{1.541\times10^{13}} = 4.30\times10^{-46}\ \mathrm{kg\,m^2}$$

**量纲检查**：$\mathrm{J\,s^2 = kg\,m^2}$ ✓

$$r = \sqrt{\frac{I}{\mu}} = \sqrt{\frac{4.30\times10^{-46}}{1.648\times10^{-27}}} = 1.615\times10^{-10}\ \mathrm{m}$$

**校验**：$r \approx 161.5$ pm ✓。HI 是卤化氢中键最长的——转动常数最小（$B \propto 1/I$），谱线最密。

## 10-3【计算】N₂ 力常数

$\mu = 14.007/2 = 7.004\ \mathrm{u} = 1.163\times10^{-26}\ \mathrm{kg}$；$\tilde\nu = 2.331\times10^5\ \mathrm{m^{-1}}$：

$$k = \mu(2\pi c\tilde\nu)^2 = 1.163\times10^{-26}\times(2\pi\times2.998\times10^8\times2.331\times10^5)^2 = 1.163\times10^{-26}\times(4.391\times10^{14})^2$$

$$= 1.163\times10^{-26}\times1.928\times10^{29} = 2.24\times10^{3}\ \mathrm{N\,m^{-1}}$$

**量纲检查**：$\mathrm{kg\,s^{-2} = N/m}$ ✓。**校验**：约 $2.24\times10^3$ N/m ✓。**比较**：C–C 单键约 450、C=C 约 980、C≡C 约 1560 N/m——N≡N 是常见化学键中最刚硬的，与其 945 kJ/mol 的极高键能一致。

## 10-4【计算】Kapustinskii 估算 KCl 点阵能

**列式**（$r$ 用 pm，$U$ 得 kJ/mol）：$r_0 = r_+ + r_- = 138 + 181 = 319$ pm，$\nu = 2$，$|z_+z_-| = 1$：

$$U = \frac{1.202\times10^5\times2\times1}{319}\left(1 - \frac{34.5}{319}\right) = 753.6\times0.8918 = 672\ \mathrm{kJ\,mol^{-1}}$$

**量纲检查**：$1.202\times10^5$ 的单位为 $\mathrm{kJ\,pm\,mol^{-1}}$，除以 pm 得 $\mathrm{kJ\,mol^{-1}}$ ✓。

**校验**：约 672 kJ/mol，比 Born–Haber 实验值 717 低约 6% ✓。

**讨论**：Kapustinskii 把马德隆常数与 Born 排斥"打包"进普适常数（$d = 34.5$ pm），只用量与半径，因此**不需要知道晶体结构**——代价是对特定结构（KCl 实为 NaCl 型，$A = 1.7476$ 而非平均化取值）精度下降。用途：快速估算、筛选尚无晶体数据的假想离子化合物；精确定量仍需 Born–Landé（需结构）或 Born–Haber（需热化学数据）。

## 10-5【推导】临界半径比

**八面体（CN 6，NaCl 型）**：在垂直于四重轴的截面上，中心正离子与四个负离子相切于正方形对角线方向。正方形边长 $2r_-$，对角线 $= 2(r_+ + r_-)$：

$$\sqrt2\times2r_- = 2(r_+ + r_-) \Rightarrow \frac{r_+}{r_-} = \sqrt2 - 1 = 0.414$$

**立方体（CN 8，CsCl 型）**：负离子占立方体八个顶点（相切于棱：棱长 $= 2r_-$），正离子在体心与八个负离子沿体对角线相切：

$$\sqrt3\times2r_- = 2(r_+ + r_-) \Rightarrow \frac{r_+}{r_-} = \sqrt3 - 1 = 0.732$$

**物理含义**：$r_+/r_-$ 低于临界值时负离子会"挤"到一起而正离子悬空——配位数必然降低；高于上限时正离子"撑开"结构，更高配位更稳定。这就是半径比规则的几何根源；注意它是纯几何判据，离子极化（正文 10.6.5）可使其失效。

## 10-6【综合】SO₂ 与 CO₂ 的振动活性对比

**SO₂（V 形，$C_{2v}$，与 H₂O 同群）**：正文例题 10-2 的方法给出 $\Gamma_\mathrm{vib} = 2A_1 + B_2$。$C_{2v}$ 中 $A_1 \ni z$、$B_2 \ni y$ → **3 个模式全部 IR 活性**（实验：$\nu_1 = 1145$ 对称伸缩、$\nu_2 = 518$ 弯曲、$\nu_3 = 1361$ 反对称伸缩，单位 cm⁻¹）；四个 irrep 均含二次型 → 全部 Raman 活性。无对称中心 → **不服从互斥规则**（IR 与 Raman 峰位重合）。

**CO₂（直线形，$D_{\infty h}$，有 $i$）**：4 个振动自由度（$3N-5$）组成 3 种模式：$\nu_1(\Sigma_g^+)$ 对称伸缩、$\nu_2(\Pi_u)$ 弯曲（二重简并）、$\nu_3(\Sigma_u^+)$ 反对称伸缩。互斥规则：g 模式（$\nu_1$）只 Raman（1333 cm⁻¹），u 模式（$\nu_2 = 667$、$\nu_3 = 2349$）只 IR。

**对照结论**：同样是三原子分子，对称性决定谱学表现——SO₂ 的 IR 谱有三条基频带、IR/Raman 峰重合；CO₂ 的 IR 谱只有两条基频带（$\nu_2$ 简并）、Raman 中出现 IR 看不到的 $\nu_1$。"IR–Raman 是否互补"本身就是分子有无对称中心的诊断。

## 10-7【综合】fcc 结构因子与铝的粉末线

**证明**：fcc 点阵的晶胞含 4 个同种原子，位置 $(0,0,0)$、$(\tfrac12,\tfrac12,0)$、$(\tfrac12,0,\tfrac12)$、$(0,\tfrac12,\tfrac12)$：

$$F(hkl) = f\left[1 + e^{i\pi(h+k)} + e^{i\pi(h+l)} + e^{i\pi(k+l)}\right]$$

- $h,k,l$ 全奇或全偶：$h+k$、$h+l$、$k+l$ 均为偶数，各指数项 $= e^{i\pi\cdot\text{偶}} = 1$，$F = 4f$（强线）；
- 奇偶混合：设 $h$ 偶、$k,l$ 奇，则 $h+k$、$h+l$ 奇（项 $= -1$）、$k+l$ 偶（项 $= +1$），$F = f(1 - 1 - 1 + 1) = 0$（消光）；其他混合情形同理。

**Al 的前三条线**（$a = 405$ pm，$\lambda = 154.18$ pm；允许 $N = h^2+k^2+l^2 = 3, 4, 8$）：

| $(hkl)$ | $d = a/\sqrt N$（pm） | $\sin\theta = \lambda/2d$ | $2\theta$ |
|---|---|---|---|
| 111 | 233.8 | 0.3297 | 38.5° |
| 200 | 202.5 | 0.3807 | 44.7° |
| 220 | 143.2 | 0.5383 | 65.2° |

**校验**：38.5°、44.7°、65.2° ✓（与 Al 的标准粉末卡片一致）。注意强度：结构因子只能给出"消失/出现"，相对强度还需 Lorentz–偏振与温度因子修正——粉末定量分析用 Rietveld 方法处理。

## 10-8【挑战】堆积系数证明

**fcc（等径球最密堆积）**：面对角线 $4r = \sqrt2 a \Rightarrow a = 2\sqrt2\,r$；晶胞 4 个原子：

$$\varphi = \frac{4\times\frac43\pi r^3}{a^3} = \frac{\frac{16}{3}\pi r^3}{(2\sqrt2\,r)^3} = \frac{\frac{16}{3}\pi r^3}{16\sqrt2\,r^3} = \frac{\pi}{3\sqrt2} = 0.7405$$

**hcp**：用六方原胞（含 2 个原子，$a = 2r$，理想轴比 $c/a = \sqrt{8/3}$，即 $c = 4r\sqrt{2/3}$），原胞体积 $V = a^2 c\sin120° = \frac{\sqrt3}{2}a^2c$：

$$V = \frac{\sqrt3}{2}(2r)^2\left(4r\sqrt{\frac23}\right) = 8\sqrt2\,r^3, \qquad \varphi = \frac{2\times\frac43\pi r^3}{8\sqrt2\,r^3} = \frac{\pi}{3\sqrt2} = 0.7405\ \checkmark$$

（fcc 与 hcp 同为最密堆积，占有率必然相等——这是两种堆垛只是"层序 ABC 与 AB 之别"的定量体现。）

**bcc**：体对角线 $\sqrt3 a = 4r \Rightarrow a = 4r/\sqrt3$；晶胞 2 个原子：

$$\varphi = \frac{2\times\frac43\pi r^3}{a^3} = \frac{\frac{8}{3}\pi r^3}{\left(\frac{4r}{\sqrt3}\right)^3} = \frac{\frac{8}{3}\pi r^3}{\frac{64}{3\sqrt3}r^3} = \frac{\sqrt3\pi}{8} = 0.6802$$

**讨论**：0.7405 是等径球堆积的数学上限（Kepler 猜想，1998 年经计算机证明）；金属之所以"选" bcc（0.6802），是因为 s–d 带杂化与温度（α-Fe ↔ γ-Fe 相变）等因素使非最密堆积在能量上可竞争——几何占有率的"次优"换键能的"更优"，是结构化学"几何 vs 电子"两条原则相互制衡的典型例证。
