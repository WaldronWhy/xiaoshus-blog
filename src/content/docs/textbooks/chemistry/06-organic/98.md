## 第 11 章 有机结构理论与反应机理

## 11-1 碳正离子稳定性排序

**答案**：Ph–CH₂⁺ ≳ CH₂=CH–CH₂⁺ > (CH₃)₃C⁺ > (CH₃)₂CH⁺ > CH₃⁺。

**分析**（两把尺子：共振 > 超共轭/诱导）：
- **Ph–CH₂⁺**：空 p 轨道与苯环 π 共轭，正电荷可分散到环上邻、对位碳（4 个以上有效共振式）——共振稳定最强；**CH₂=CH–CH₂⁺**：2 个等价共振式（CH₂=CH–CH₂⁺ ↔ ⁺CH₂–CH=CH₂），稳定但弱于苄基。二者同属"共振稳定级"。
- **(CH₃)₃C⁺**：9 个 β-C–H 的 σ–p 超共轭 + 3 个甲基的 +I；**(CH₃)₂CH⁺**：6 个 β-C–H；**CH₃⁺**：两者皆无，最不稳。
- 实验佐证：气相氢化物亲和能/溶剂解速率序列与上述一致；苄氯、烯丙氯的 SN1 溶剂解远快于伯卤（苄位 ≈ 3° 级以上）。

## 11-2 酚与取代酚的酸性

**要点**：
1. **苯酚 9.95 vs 环己醇 ≈16**：苯氧负离子 O 的 p 轨道与苯环 π 平行，负电荷离域到邻/对位（4 个共振式，负电荷从 O 分散到 C）；环己氧负离子的负电荷完全定域在 O 上。离域稳定共轭碱 ⇒ 酸性差 10^(16−9.95) ≈ 10⁶ 倍。（注意：比较时酸与共轭碱两头看——苯酚自身 O 的孤对也共轭给环，但共轭碱获得的稳定化更大。）
2. **对硝基苯酚 7.15 vs 间硝基苯酚 8.35 vs 苯酚 9.95**：对位异构体中，苯氧负离子的共振式之一恰好把负电荷放在**与 NO₂ 相连的碳**上，NO₂ 的 −C（π 受体）直接接续离域（负电荷可进一步落到硝基 O 上）——强协同；间位异构体的所有负电荷共振位置都**接触不到**硝基所连碳，只剩 NO₂ 的 −I（经 σ 骨架，衰减快）贡献，故其 pKa 只降 1.6 而对位降 2.8。**"邻/对位接线、间位只剩诱导"是判读取代苯酚/苯胺/苯甲酸 pKa 的通用规则**（与 Hammett σₚ(NO₂) = 0.78 > σₘ = 0.71 的差值同源）。

## 11-3 SN2 相对速率排序

**答案**：CH₃Br（30）> CH₃CH₂Br（1）≫ (CH₃)₂CHBr（≈0.03）≫ (CH₃)₃CCH₂Br（≈10⁻⁵）> (CH₃)₃CBr（≈0，不反应）。（括号内为 NaI/丙酮中的相对速率数量级。）

**分析**：SN2 三中心过渡态中亲核试剂与离去基同时在碳两侧——α 位取代越多，TS 越拥挤，ΔG‡ 越高（立体效应主导）；β-分支（新戊基）虽 α 位无取代，但叔丁基恰好堵在背面进攻路径上，速率被压到比 3° 还低——**"背面必须空"是 SN2 的几何前提**。3° 卤代烃在 SN2 条件下完全让位于 E2。

## 11-4 (3R,4S)-3-氯-4-甲基己烷的构型

结构：CH₃CH₂–**CH(Cl)**–**CH(CH₃)**–CH₂CH₃。

**C3 优先级**：Cl（1）> C4 侧链（2，第一个原子 C 连 (C,C,H)）> C2 乙基（3，(C,H,H)）> H（4）。H 朝后，1→2→3 走向 ⇒ R。
**C4 优先级**：C3 侧链（1，C 连 (Cl,C,H)——Cl 压倒一切）> C5 乙基（2，(C,H,H)）> CH₃（3，(H,H,H)）> H（4）⇒ S（按题给构型）。

**镜像判断**：分子中两个手性中心携带的基团**不同**（C3 有 Cl、C4 有 CH₃），不存在内对称面/对称中心 ⇒ 无内消旋可能。其镜像是 (3S,4R)，与原分子不能重合——**二者为对映体，不是同一分子**。（对比：若两个中心基团相同如酒石酸，(R,S) 即 meso。）

## 11-5 溴代环己烷的平伏比例（与正文校验值 67% 对照）

1. 平伏:直立 = e^(A/RT) = e^(1800/(8.314×298)) = e^0.727 = 2.07；
2. 平伏摩尔分数 = 2.07/(1+2.07) = 0.674 → **约 67%** ✓；
3. 讨论：Br 的 A 值（1.8 kJ/mol）远小于 CH₃（7.3），因为 C–Br 键较长、Br 可极化，直立位冲突小——卤代环己烷是"软"取代基，构象选择性弱；对比叔丁基（>5 kcal/mol）几乎锁死平伏位。

## 11-6 丙烷溴代的产物比（校验值 3 : 82 对照）

1. 每种氢的贡献 =（氢的数目）×（相对速率）：1° 位 6 H × 1 = 6；2° 位 2 H × 82 = 164；
2. 1-溴丙烷 : 2-溴丙烷 = 6 : 164 = **3 : 82**，即约 **3.5% : 96.5%** ✓；
3. 讨论：同一计算用氯代（1 : 3.8）得 6 : 7.6 ≈ 44% : 56%——氯代选择性差、溴代近乎"专取 2° H"。原因重述（Hammond）：溴代抽氢步 ΔH ≈ +45 kJ/mol（吸热多、晚 TS、像自由基）；氯代仅 +8 kJ/mol（早 TS、像反应物、结构不敏感）。

## 11-7 3-甲基-2-丁醇 + HBr 的重排机理

1. **质子化**：OH 孤对抓 H⁺ → –OH₂⁺（好离去基）；
2. **电离（决速）**：C–O 键电子对随 H₂O 离去 → **2° 碳正离子** CH₃–C⁺H–CH(CH₃)₂；
3. **1,2-负氢迁移**：C3（叔碳）上的 C–H σ 电子对携 H 迁到缺电子的 C2 → 正电荷移至 C3，得 **3° 碳正离子** (CH₃)₂C⁺–CH₂CH₃。迁移之所以快于 Br⁻ 捕获：迁移活化能低于离子对的扩散捕获，且产物正离子显著更稳（9 个 β-C–H 超共轭）；
4. **捕获**：Br⁻ 进攻平面 3° 正离子 → **2-溴-2-甲基丁烷**（主）。
- 若无重排、直接捕获 2° 正离子则得 2-溴-3-甲基丁烷——实测仅为次要产物，正说明**正离子寿命内重排优先**。SN2 条件（PBr₃）下同一醇则得无重排的 3-溴-2-甲基丁烷（经亚磷酸酯、SN2 翻转）——试剂选择决定机理路径。

## 11-8 为什么过氧化物效应只有 HBr

**核算**（所需键能：π 键 = BDE(C=C) − BDE(C–C) = 614 − 368 ≈ 246 kJ/mol；C–Cl 350、C–Br 293、C–I 239，取自 11.1.3 表）：

传播步 A（X• 加成：断 π、成 C–X）：ΔH = 246 − BDE(C–X)

| HX | 步 A：X• 加成 | 传播步 B（R• + HX：断 H–X、成 C–H ≈ 421）：ΔH = BDE(H–X) − 421 |
|---|---|---|
| HCl | 246−350 = **−104**（放热，快） | 431−421 = **+10**（吸热！太慢） |
| HBr | 246−293 = **−47**（放热） | 366−421 = **−55**（放热）✓ |
| HI | 246−239 = **+7**（吸热，可逆） | 299−421 = **−122**（放热） |

**结论**：链传播要求**两步都放热且不可逆**。只有 HBr 两步皆负（−47 与 −55）。HCl 卡在步 B（R• + HCl 吸热，与自由基二聚竞争失败）；HI 卡在步 A（I• 加成吸热、可逆；I• 也因体积大而加成慢）。总焓变核对：HBr 加成 ΔH = −47 + (−55) = −102 kJ/mol ✓（与生成焓数据一致）。

## 第 12 章 官能团化学

## 12-1 酰基化合物的三张排序表

| 化合物 | (a) 水解速率 | (b) C=O IR (cm⁻¹) | (c) 离去基共轭酸 pKa（酸性越强 ⇒ Y⁻ 越弱碱 ⇒ 越好离去） |
|---|---|---|---|
| 酰氯 RCOCl | 1（最快） | 1785–1815 | HCl：−7 |
| 酸酐 (RCO)₂O | 慢 | 1820/1760 双峰 | RCOOH：≈4.8 |
| 酯 RCOOR′ | 更慢 | 1735–1750 | ROH：≈16 |
| 酰胺 RCONH₂ | 极慢 | 1650–1690 | NH₃：38 |

**统一电子模型**：取代基 Y 对羰基施加两个相反的效应——**−I（吸电子）提高羰基碳亲电性与 C=O 键级**，**+C（孤对供电子入 π*）降低二者**。沿序 Cl → OCOR → OR → NH₂：−I 递减、+C 递增 ⇒ 羰基亲电性、IR 波数、离去能力（Y⁻ 碱性）三者**同向递减**——一张机理图解释三张表。（注意 (b) 中酸酐双峰源于两个 C=O 的对称/反对称耦合，整体高于酯因 –O(C=O)R 的 −I 强于 –OR。酰胺波数最低即 +C 最强，与活性最低同源。）

## 12-2 Claisen 缩合机理与两个"为什么"

1. EtO⁻ 抽 α-H（乙酯 α-H pKa 25 vs 乙醇 16——**平衡不利**，负离子仅痕量，但抽氢是催化性的、可再生）；
2. 碳端负离子进攻另一分子乙酸乙酯的 C=O（π → O）→ 四面体中间体（烷氧负离子）；
3. 中间体坍缩，O⁻ 电子回落成 C=O，EtO⁻ 离去 → β-酮酯；
4. **关键不可逆步**：产物的活性亚甲基（pKa ≈ 11 ≪ 乙醇 16）被 EtO⁻ 定量夺氢 → 负离子（这一步把 1–3 的平衡整体拉向产物——**产物去质子化是全反应的热力学驱动**）；5. 酸化后处理释放乙酰乙酸乙酯。
- **为什么不用 NaOH**：OH⁻ 对酯是不可逆皂化（产物 RCOO⁻ 无法再被亲核进攻，12.6.2）而非 Claisen；**为什么碱必须匹配醇氧基**：NaOMe 会与乙酯发生酯交换（进攻–离去基互换），得乙基/甲基混合酯。

## 12-3 1,2-环氧丙烷的区域选择反转

- **(a) CH₃O⁻/CH₃OH（碱性）**：纯 SN2，亲核试剂进攻**位阻小的 C1**（CH₂ 端）→ CH₃CH(OH)CH₂OCH₃（1-甲氧基-2-丙醇）；
- **(b) CH₃OH/H⁺（酸性）**：先质子化环氧 O → C–O 键带部分正碳离子性 → 进攻**取代多的 C2**（正电荷发育处的稳定化压过位阻）→ CH₃CH(OCH₃)CH₂OH（2-甲氧基-1-丙醇）。
- **本质**：碱性 TS 像 SN2（立体效应主导、早 TS）；酸性 TS 有碳正离子特征（电子效应主导、晚 TS）——**Hammond 假设把"条件"翻译成"选择性"**（回引第 11.4.2 节）。

## 12-4 芳香性判定

| 物种 | π 电子数 | 结论 | 理由 |
|---|---|---|---|
| 环戊二烯负离子 C₅H₅⁻ | 6（2 个 C=C + 负碳孤对） | **芳香** | 平面五元环全共轭，6 = 4n+2（n=1） |
| tropylium C₇H₇⁺ | 6（3 个 C=C） | **芳香** | 平面七元环全共轭，正电荷可缺一个 p（空 p 轨道） |
| 环辛四烯 C₈H₈ | 8 | **非芳香** | 8 = 4n 为反芳香→分子**逃避平面化**成 tub 构象，π 电子定域（键长交替 1.34/1.46 Å） |
| 环辛四烯双负离子 C₈H₈²⁻ | 10 | **芳香** | 获得 2e 后满足 4n+2，X 射线证实平面化、键长均一 |
| 吡咯 | 6（2 C=C + N 孤对**入环**） | **芳香** | N 为 sp²，孤对在 p 轨道参与 π；碱性极弱（孤对被占用） |
| 吡啶 | 6（C=N + 2 C=C；N 孤对**不入环**） | **芳香** | N 的孤对在环平面内 sp² 杂化轨道，朝外——可质子化（pKaH 5.2）、可配位 |

## 12-5 (2E,4Z,6E)-辛三烯的电环化

1. **可环化构象**：s-cis,s-cis 的"U 形"平面构象（C2、C7 端点靠近），此时两端 CH₃ 均指向 U 外侧（E/Z,E 几何唯一决定）；
2. **轨道判断**：6π 体系热反应用基态 HOMO（ψ₃，两个节点），两端 p 轨道**同相位** ⇒ 必须**对旋**（disrotatory）使同相瓣重叠成 σ 键（4n+2 热 → 对旋）；
3. **立体化学结果**：对旋时两端以相反方向旋转，两个"朝外"的 CH₃ 被转到**同一面** → 热反应得 **cis-5,6-二甲基-1,3-环己二烯**；
4. **光化学**：π→π* 激发后 HOMO 变为 ψ₄，两端相位相反 → **顺旋**（conrotatory），CH₃ 转到**异面** → **trans** 产物。
- 校验：与正文 12.9.1 表（4n+2 热-对旋/光-顺旋）一致。

## 12-6 谱学推断 C₈H₁₀O

1. 不饱和度 Ω = (2×8+2−10)/2 = **4** → 恰为一个苯环（1600/1500 cm⁻¹ 环骨架振动佐证）；
2. ¹H NMR δ 7.2（m，5H）→ **单取代苯**（5 个芳氢）；
3. 剩余 C₂H₄O + OH：δ 3.7（t，2H，–CH₂OH）、δ 2.8（t，2H，Ph–CH₂）——两组各 2 H 相互耦合（J ≈ 7 Hz 相等），各见 n+1 = 3 重峰 ✓；δ 1.9 宽峰可被 D₂O 交换消除 → OH ✓；
4. IR 3350 宽峰 = O–H 伸缩，无 1700 区 → 非羰基。
**结论**：**2-苯乙醇（苯乙醇，C₆H₅CH₂CH₂OH）**。

## 12-7 谷氨酸的 pI 与电泳（校验 pI = 3.22 对照）

1. 谷氨酸（酸性氨基酸）：全质子化形式 ⁺H₃N–CH(COOH)–(CH₂)₂–COOH 经两次去质子（pKa 2.19、4.25）到达净电荷为零的两性离子（COO⁻/COO⁻/NH₃⁺）→ pI 取这两个 pKa 的均值：pI = (2.19+4.25)/2 = **3.22** ✓；
2. pH 6.0 时：两个 COOH 几乎全解离（6 − 4.25 = 1.75 → 侧链 [COO⁻]/[COOH] = 10^1.75 ≈ 56），NH₃⁺ 保留（[NH₂]/[NH₃⁺] = 10^(6−9.67) ≈ 2×10⁻⁴）→ 净电荷 ≈ −(1 + 56/57) ≈ **−1.94**；
3. 净负电荷 → 电泳中**向阳极（正极）移动**。与正文校验一致。

## 12-8 氯苯类水解的条件指纹与两种机理

1. **氯苯 + NaOH（约 350 °C、高压）→ 苯酚**：环上无活化基，走**消除–加成（苯炔）**机理：NaNH₂? 此处工业 NaOH 高温——先邻位去质子、Cl⁻ 消去成苯炔，OH⁻ 加成任意一端。指纹：¹⁴C 标记氯苯水解产物苯酚中标记碳 50:50 分布于 C1/C2；强碱、高温是必要条件（C–H 的酸性弱、消去难）。
2. **2,4-二硝基氯苯 + Na₂CO₃ 水溶液室温**：NO₂ 在 Cl 的**邻与对**，走**加成–消除（SNAr）**机理：OH⁻ 加成（π → O）→ Meisenheimer 络合物（负电荷共振式恰可落到两个硝基的 O 上——与 11-2 的"邻/对接线"镜像对称）→ Cl⁻ 离去、芳香性恢复。指纹：弱碱即可、速率对[OH⁻]一级、无同位素打乱；间硝基氯苯几乎不反应（负电荷共振接触不到 NO₂）。
3. **对硝基氯苯居中**：只有一个（对位）NO₂ 接线，Meisenheimer 络合物稳定化减半 → 需约 150 °C 强碱；仍属 SNAr。
4. **条件指纹总结**：吸电子基邻/对 + 温和碱 → SNAr；无活化基 + 超强碱/高温 → 苯炔。两条路径在同一底物族上的切换是"电子效应决定机理"的教科书案例。

## 13-2 由苯合成正丁苯

**为什么不能用 FC 烷基化**：正丁基氯/AlCl₃ 先生成正丁基正离子，经 1,2-负氢迁移重排为更稳的**仲丁基正离子** → 主产物仲丁苯（第 11.8.3 节）。

**正确路线**（酰基化 + 还原，羰基"锚定"碳骨架不重排）：
1. 苯 + CH₃CH₂CH₂COCl（丁酰氯）/AlCl₃ → **丁酰苯** PhCOCH₂CH₂CH₃（EAS，酰基正离子 RCO⁺ 无重排可能；酰基钝化产物故不多元）；
2. Clemmensen 还原（Zn–Hg/HCl）或 Wolff–Kishner（N₂H₄/KOH，Δ）→ **正丁苯**（C=O → CH₂，碳骨架不动）。
- 若底物耐酸碱，两法皆可；酸性敏感用 W–K，碱性敏感用 Clemmensen——还原法选择即化学选择性应用（13.3）。

## 13-3 对硝基苯酚 → 对乙酰氨基酚（扑热息痛）的顺序设计

- **路线 A（先还原后 N-乙酰化，工业主流）**：① p-硝基苯酚 + H₂/Pd（或 Fe/HCl）→ 对氨基苯酚；② + 乙酐（约 1 eq，H₂O/稀 AcOH）→ 对乙酰氨基酚。选择性论证：胺 N 的亲核性 ≫ 酚 O（pKaH 4.6 vs 酚 9.95；N 孤对碱性/N 亲核性更强）→ **N-乙酰化优先**；控制乙酐用量可避免 O,N-二乙酰副产物（水解后处理可除去 O-酰）。
- **路线 B（先 O-乙酰化后还原）**：① p-硝基苯酚 + 乙酐/催化酸 → 乙酸对硝基苯酯；② H₂/Pd 还原硝基 → 产物。风险：酯对 Fe/HCl 酸性还原条件不稳定（水解回原料）；H₂/Pd 可行但多一个"酯在场"的兼容性约束。
- **结论**：路线 A 的选择性来自官能团本征活性差（化学选择性，13.3），步骤更稳健；路线 B 只在 N 保护需要时选用。**"操作顺序让官能团活性差为你工作"**。

## 13-4 PhCH₂CH₂COOH 的逆合成（原料 ≤ 2 碳 + C1 试剂）

**分拆**：COOH 可由 CN 水解而来（+1C，C1 试剂）；–CH₂CH₂– 可由**环氧乙烷（C2）**开环引入。

**路线 A（Grignard/环氧乙烷）**：
1. 苯 → 溴苯（Br₂/FeBr₃，EAS）；
2. 溴苯 + Mg/醚 → PhMgBr；
3. + 环氧乙烷（C2！），再 H₃O⁺ → 2-苯乙醇 PhCH₂CH₂OH（环氧乙烷 SN2 开环，Grignard 亲核进攻、+2C）；
4. PBr₃ → PhCH₂CH₂Br；
5. NaCN（SN2，伯卤理想底物，+1C）→ PhCH₂CH₂CN；
6. H₃O⁺，Δ 水解 → **PhCH₂CH₂COOH** ✓（3-苯基丙酸）。

**路线 B（苯乙烯途径，工业友好）**：
1. 苯 + CH₂=CH₂/H₃PO₄ → 乙苯（工业烷基化）；
2. 脱氢（Fe₂O₃ 催化，Δ）→ 苯乙烯 PhCH=CH₂；
3. HBr/ROOR（自由基反马氏，11-8 论证的唯一可行 HX）→ PhCH₂CH₂Br；
4. NaCN → 腈；5. 水解 → 目标物。
- **比较**：路线 A 是经典实验室路线（Grignard 需严格无水）；路线 B 借工业中间体苯乙烯、步骤中两次用 C1/C2 小分子——**同一逆合成键（苄基–链键）可有极性（A）与自由基/烯烃（B）两种等价实现**，选择取决于规模与设备。

## 13-5 线性 vs 收敛路线的总收率（校验 38% vs 61% 对照）

- 线性 6 步：0.85⁶ = 0.377 → **约 38%** ✓；
- 收敛：两个 3 步片段各 0.85³ = 0.614 → 汇合（设最终拼合定量）→ **约 61%** ✓；若拼合步也有 85% 收率，则为 0.614 × 0.85 ≈ **52%**，仍显著优于线性；
- 讨论：差距的根源是**连乘**——步数是指数惩罚项（13.1.3 判据 1）。这也是复杂天然产物（如紫杉醇）必走收敛路线的定量理由。

## 13-6 Suzuki 偶联循环与碱的作用

1. **氧化加成**：Pd(0)Lₙ 插入 Ar–X 键 → Ar–Pd(II)–X（Pd：0 → +2，配位数 +2，d¹⁰ → d⁸ 方形平面——回引 [第 4 章](/xiaoshus-blog/textbooks/chemistry/02-inorganic/02/) 氧化加成概念）；
2. **转金属**：碱先使 Ar′B(OH)₂ 成四配位硼酸盐 Ar′B(OH)₃⁻（B–C 键极性反转、Ar′ 迁移能力增强），随后 Ar′ 从 B 迁到 Pd：Ar–Pd(II)–Ar′（+ B(OH)₃）；
3. **还原消除**：两个芳基从 Pd 上偶联离去 → **Ar–Ar′** + Pd(0)（+2 → 0，催化剂再生）——C–C 键在这一步生成。
- **碱的两个作用**：(i) 活化硼酸（转金属的前置条件）；(ii) 中和 HX / 把 Pd–X 变为更易转金属的 Pd–OH，防止催化剂休眠。两作用缺一，循环都断在转金属——这是偶联反应"非碱不可"的机理依据。

## 13-7 维蒂希反应的原子经济性（校验 ≈27% 对照）

1. AE = M(苯乙烯)/(M(苯甲醛)+M(Ph₃P=CH₂)) = 104.2/(106.1+276.3) = 104.2/382.4 = **27.2%** ✓（按题给简化口径，不含制叶立德所耗碱/卤代甲烷）；
2. 副产物 Ph₃P=O（278.3）占投料质量的绝大部分——**一当量固体氧化膦废物**是维蒂希法的固有缺陷（E 因子视角）；
3. 对比：工业上苯乙烯由苯 + 乙烯 → 乙苯 → 催化脱氢制得，总反应相当于 C₆H₆ + C₂H₄ → C₆H₅CH=CH₂ + H₂，AE = 104.2/106.2 = **98%**——**催化 + 消除小分子副产物（H₂ 可收集利用）**是把 AE 从 27% 推向 100% 的两条标准杠杆（与 13.5.3 的 BHC 案例同一逻辑）。

## 13-8 甲苯 → 对甲基苯胺（两条路线比较）

**路线一（"氨基最后出现"，直接法）**：甲苯 —HNO₃/H₂SO₄→ 硝基甲苯（**o/p 混合物**，工业组成约 o 58% : p 38%）→ 分离对位 → Fe/HCl 或 H₂/Pd 还原 → 对甲基苯胺。
- 优点：步数最少（2 步）；缺点：邻位异构体占多数，**选择性差、分离负荷大**（E 因子高）。

**路线二（磺酸占位 + 可逆脱除）**：
1. 甲苯 + 发烟硫酸 → 对甲苯磺酸（对位为主，**结晶分离**可得纯品）；
2. HNO₃/H₂SO₄（温和）硝化：NO₂ 进入 2/6 位——**CH₃ 的 o/p 定位与 SO₃H 的 m 定位指向一致**（两基团"投票"一致时选择性最好，11.8.2）→ 2-硝基-4-甲基苯磺酸；
3. 稀酸水蒸气**脱磺化**（磺化可逆性的反向使用，11.8.3）→ 纯对硝基甲苯；
4. 还原硝基 → **对甲基苯胺**。
- 比较路线二多 2 步、产生磺化废物，但**对位选择性由分子内定位逻辑保证**，几乎无异构体分离问题。**权衡结论**：小规模/对纯度要求高 → 路线二；大规模/对位可结晶回收 → 路线一 + 异构体套用（邻位可另作他用）。
