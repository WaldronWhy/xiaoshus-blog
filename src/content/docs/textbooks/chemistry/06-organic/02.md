# 第 12 章 官能团化学

> **本章定位**：把第 11 章的机理工具按官能团族展开，建立"制备–反应–鉴别"三位一体的知识网络；羰基化学与碳负离子化学是重心；芳香性、周环反应与生物有机分子拓展边界。前接第 11 章四大机理，后接第 13 章合成设计（本章反应即合成试剂库）。

## 12.0 本章学习目标

学完本章，应当能够：

1. 对任一官能团族给出至少两条制备路线、三类代表反应与一种化学鉴别法，并说明每条反应属于第 11 章哪个基础机理；
2. 书写羰基亲核加成与亲核酰基取代的完整机理（含酸/碱催化变体），用活性顺序与 pKa 数据预测反应能否发生；
3. 设计 Aldol/Claisen/Michael/Robinson 环化序列并预测产物；
4. 用 Hückel 规则判断苯系与非苯体系的芳香性，解释吡咯/呋喃/吡啶的反应性差异；
5. 用前线轨道（FMO）与 Woodward–Hoffmann 规则预测电环化、[4+2] 环加成的立体化学结果；
6. 给出各族官能团的特征 IR/¹H NMR/¹³C NMR 区间并据此推断简单结构。

**阅读约定**：每节按"制备 → 反应 → 鉴别 → 波谱特征"展开；每条反应标注机理归属（SN2、E2、加成……）以接回第 11 章。

## 12.1 烷烃

**结构回顾**：sp³、σ 骨架、非极性（μ ≈ 0）。同系物沸点随分子量升高（色散力），每 +CH₂ 约 +20~30 K；支链增多沸点降低（接触面积减小）。

- **制备**：① 烯烃催化氢化（H₂/Pd-C）；② Wurtz 偶联（RX + Na，限对称）；③ Kolbe 电解（羧酸盐 → 二聚，兼作 13 章电合成案例）；④ Corey–House（R₂CuLi + R′X，优于 Wurtz 的选择性）。
- **反应**：光/热自由基卤代（第 11.9 节完整机理；选择性 Cl 低 Br 高）；催化裂化（大分子 → 烯烃/烷烃混合物，工业意义）；异构化与重整（芳构化）。
- **鉴别**：化学惰性本身即证据——不与 Br₂/CCl₄（避光）褪色、不与 KMnO₄ 反应；燃烧鉴别属元素分析范畴（回引 [第 5 章](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/) 元素分析）。
- **波谱**：¹H NMR δ 0.8–1.5（CH₃ ~0.9，CH₂ ~1.3）；IR 2850–2960（C–H 伸缩）与 1450/1375（弯曲）。**无官能团吸收**本身是判据。

## 12.2 烯烃与炔烃

### 12.2.1 制备

1. **E2/E1 消除**（第 11.6 节）：卤代烃 + 碱；醇 + H₂SO₄ △（E1，注意重排）；
2. **Wittig 反应**（C=C 构建法，13 章复用）：醛酮 + 磷叶立德 Ph₃P=CHR → 定位明确的烯烃（无重排问题）；
3. 炔烃部分加氢：Lindlar 催化剂（H₂，毒化 Pd）→ **cis-烯**；Na/NH₃(l) → **trans-烯**（反式专一，自由基机理）。**一对互补的立体控制工具**。

### 12.2.2 反应（机理归属）

| 反应 | 试剂/条件 | 机理 | 立体/区域化学 |
|---|---|---|---|
| 氢化 | H₂/Pd | 表面催化 | syn；定量放热（见下） |
| HX 加成 | HX | 亲电加成（11.7） | 马氏；可重排 |
| 溴水/Br₂ | Br₂/CCl₄ | 溴鎓离子 | 反式；鉴别用（褪色） |
| 水合 | H₂O/H⁺ | 碳正离子 | 马氏醇 |
| 硼氢化-氧化 | BH₃·THF; H₂O₂/OH⁻ | 协同 | **反马氏、syn** |
| 环氧化 | mCPBA | 一步协同 | syn；构型保持 |
| 双羟基化 | OsO₄/NMO | 环状酯 | **cis-diol** |
| 臭氧分解 | O₃; Zn/H₂O | 臭氧化物 | C=C 定位鉴定（→ 醛/酮） |
| 烯丙位卤代 | NBS/hν | 自由基链（11.9.3） | 烯丙位专一 |

**氢化焓 = 烯烃稳定性的量尺**（kJ/mol）：乙烯 −136.9、丙烯 −125.9、cis-2-丁烯 −119.7、trans-2-丁烯 −115.5、异丁烯 −119.2。由（a）−136.9 与 −125.9 之差 11.0 kJ/mol = 一个甲基的超共轭/取代稳定化；（b）cis 与 trans 差 4.2 kJ/mol = 顺式位阻代价。**热化学数据把"取代烯更稳"从印象变成测量**（回引 [第 6 章](/xiaoshus-blog/textbooks/chemistry/04-physical/01/) 量热）。

**炔烃特有**：末端炔氢弱酸性（pKa ≈ 25，sp 轨道 s 成分 50%，11.2.2）→ NaNH₂/NH₃(l) 成炔负离子 → **C–C 键构建**（+伯卤代烃 SN2；+羰基 → 炔醇，13 章合成案例素材）。炔与 HX 加成遵守马氏（经乙烯基正离子，选择性弱于烯）；Hg²⁺ 催化水合 → **酮**（经烯醇互变：烯醇 C=C–OH 中 O–H 的 pKa ≈ 10~11，远低于酮式 α-C–H 的 19.2，故烯醇负离子质子化优先发生在氧上、回落为酮式——见 12.5.3）。

### 12.2.3 鉴别与波谱

- 鉴别：Br₂/CCl₄ 褪色、KMnO₄（Baeyer 试剂）褪色（区别于烷烃/芳环）；末端炔 + Ag(NH₃)₂⁺ → 炔化银沉淀（区别末端/非末端）。
- ¹H NMR：烯氢 δ 4.5–6.5（耦合常数诊断几何：**cis J ≈ 6–12 Hz，trans J ≈ 12–18 Hz**——谱学定几何的标准手段）；炔氢 δ ~2.5（屏蔽异常，来自 π 电流各向异性）。
- IR：C=C 1640–1680（弱）；=C–H 3020–3100；C≡C 2100–2140（对称炔不可见）；末端 ≡C–H ~3300（尖）。

## 12.3 卤代烃

- **制备**：自由基卤代（烷烃，11.9）；烯烃加 HX/X₂；醇 + PBr₃/SOCl₂（构型可追踪：SOCl₂/吡啶翻转、无碱保持——SNi）；芳卤由 EAS 卤化。
- **反应**：SN1/SN2/E1/E2 全套（第 11.5–11.6 节为总纲）；**金属有机转化**：Mg/醚 → Grignard 试剂 RMgX（强碱强亲核，13 章核心 C–C 工具；遇水/醇/胺即失效——pKa 比较自动给出"哪些质子杀死 Grignard"）；R₂CuLi（Gilman，软亲核，与酰氯停留于酮）；芳卤 + Mg/Li 可行但反应性低于脂肪卤。
- **鉴别**：① AgNO₃/乙醇——SN1 速率序（3° 苄烯丙立即沉淀，1° 慢，芳卤不沉淀）；② NaI/丙酮（Finkelstein）——SN2 速率序（1° 快，3° 不反应）。**两个互补探针同时测，机理即现形**。
- **波谱**：¹H NMR δ(C–H–X) 3.0–4.0；¹³C(C–X) 30–60。C–X 伸缩 IR 500–850（指纹区，价值有限）。

## 12.4 醇、酚、醚

### 12.4.1 醇

- **制备**：① 烯烃水合/硼氢化（12.2）；② **Grignard + 羰基**（甲醛 → 伯醇 +1C；其他醛 → 仲；酮 → 叔；酯 + 2 eq → 叔；13 章逆合成核心拆解）；③ 醛酮还原（NaBH₄ 温和 / LiAlH₄ 强 / 催化氢化）；④ 卤代烃水解（注意消除竞争）。
- **反应**：O–H 酸性（ROH pKa 15.5–18：甲醇 15.5、乙醇 15.9、叔丁醇 18.0——烷基 +I 推电子使负离子不稳）；与 Na 成醇钠；**转化卤代**（HX/Lucas 试剂 ZnCl₂-HCl：叔醇立即浑浊、仲 5–10 min、伯室温不反应——**SN1 速率差异的检验法**）；**氧化**（Cr(VI)/Jones 橙→绿：伯→酸、仲→酮，叔不停留氧化即难氧化；PCC/CH₂Cl₂：伯→**醛**；Swern/DMP 现代温和氧化）；1,2-二醇的高碘酸断裂（C–C 定位）与频哪醇重排（碳正离子 + 1,2-迁移，11.5.2 重排概念的应用）。
- **鉴别**：Lucas 浊度分级；铈(IV)铵（红→无色，醇类通性）；¹H NMR 中 OH 宽峰可被 D₂O 交换消除（**D₂O 交换法**是辨认活性氢的标准操作）。

### 12.4.2 酚

酸性 pKa 9.95（11.2.2 共轭效应论证）；NaOH 可溶、NaHCO₃ 不溶（与羧酸分离的操作依据：pKa 4.76 vs 9.95，碳酸 pKa1 6.3——**"能被碳酸质子化谁"的定量判断**，回引 [第 3 章](/xiaoshus-blog/textbooks/chemistry/02-inorganic/01/) 平衡耦合）。反应：EAS 超活化（硝化/溴化常无需催化剂，苯酚 + Br₂/H₂O 直接 2,4,6-三溴苯酚白色沉淀——**定性检验**）；Kolbe–Schmitt 羧化（13 章阿司匹林案例）；FeCl₃ 显色（紫/蓝/绿，烯醇型通性）。

### 12.4.3 醚与环氧化物

- Williamson 合成（RO⁻ + R′X，SN2——**底物必须 1°/CH₃**，2° 以上 E2 抢戏；酚钠 + 1° 卤代烃是苯基醚标准路线）；醇分子间脱水（酸催化，制对称醚）。
- 环氧化物（epoxide）是"张力解锁的 SN2"：**碱性条件**下 Nu 进攻**位阻小**的碳（纯 SN2）；**酸性条件**下进攻**取代多**的碳（质子化后 C–O 键极性反转、TS 有碳正离子性，过渡态偏 SN1）——**同一底物、条件切换区域选择性反转**，是"机理决定选择性"的范例。
- 鉴别/波谱：醚无特征 IR（C–O 1000–1300 仅供参考）；¹H NMR O–CH 3.3–4.0；¹³C C–O 50–90。

## 12.5 醛与酮：羰基亲核加成与碳负离子化学

### 12.5.1 羰基的电子结构——一切的起点

C=O：σ + π，O（χ 3.44）强烈拉电子 → 碳 δ+（μ ≈ 2.88 D，丙酮），LUMO 为 π*（模块五 MO 语言：亲核试剂的 HOMO 进攻 π*）。**醛 > 酮的反应性** = 空间（H < R）+ 电子（烷基 +I/超共轭供给碳）双重弱化。羰基与 11 章卤代烃的差异：**可逆加成 vs 不可逆取代**由"π 键可再生 vs C–X 不可再生"决定。

### 12.5.2 亲核加成（机理逐类）

1. **氢负离子还原**：NaBH₄（温和，醇/水可用）/ LiAlH₄（强，需无水；酯/酸也还原）——1,2-加成 H⁻ 后质子化；
2. **Grignard/RLi**：RMgX + 醛酮 → 醇（见 12.4.1）；**注意底物不能含酸性氢**（pKa < ~40 的官能团优先自质子化——用 pKa 表筛选兼容性）；
3. **HCN**：氰醇（pKa(HCN) = 9.2；CN⁻ 是"软且小"的亲核试剂）；α-羟基酸合成前体；
4. **氨及胺**：Carbinolamine → 脱水 → **亚胺**（Schiff 碱，C=N）；仲胺 → **烯胺**（enamine，β 位亲核性等价于 enolate——**烯胺化学 = 中性条件的 enolate 替代品**，Stork 反应）；
5. **醇/缩醛**：酸催化、半缩醛 → **缩醛**（acetal）。机理每步不跳步版：质子化 C=O → 醇加成 → 质子转移 → OH₂⁺ 离去 → 氧鎓离子 → 第二分子醇进攻 → 脱质子。**热力学控制**：过量醇 + 除水（Dean–Stark）推正向；水解则稀酸过量水。**缩醛 = 羰基保护基**（耐碱/亲核/氧化、稀酸可脱——13 章例题 13.2 使用）；
6. **Wittig**：叶立德（Ph₃P=CHR，由 Ph₃P + 卤代烃 + 碱制备）加成 → 氧膦烷 → 分解成 C=C + Ph₃P=O（P=O 键强 ≈ 544 kJ/mol 是热力学驱动力）。
7. **氧化鉴别**：Tollens（Ag 镜）、Fehling（砖红 Cu₂O）专测**脂肪醛**；酮不行；**碘仿反应**（I₂/OH⁻）专测 **CH₃CO–** 与 CH₃CH(OH)–（黄 CHI₃ 沉淀）；2,4-DNP（橙黄腙沉淀）通测羰基。**鉴别逻辑：先用 DNP 定羰基，再用 Tollens 分醛酮，最后用碘仿/光谱定结构。**

### 12.5.3 烯醇化与 α-碳化学——碳负离子的舞台

**酮-烯醇互变**：碱催化（OH⁻ 抽 α-H → 烯醇负离子 → O 端质子化）与酸催化（O 质子化 → 抽 α-H）。平衡几乎全在酮侧（丙酮烯醇 6×10⁻⁷），但**反应沿少量烯醇/烯醇负离子进行**（催化循环，回引 [第 7 章](/xiaoshus-blog/textbooks/chemistry/04-physical/02/) 稳态近似思想）。α-H 酸性数据（水中/DMSO 中）：乙醛 16.7、丙酮 19.2、乙酸乙酯 25、丙二酸二乙酯 13、乙酰乙酸乙酯 11——**两个吸电子基夹持的 CH₂（"活性亚甲基"）pKa ≈ 11–13，用醇钠即可定量成负离子**；单羰基需 LDA（−78 °C，动力学控制、位阻碱夺位阻小的 H）。

**Aldol（羟醛）反应**——机理完整版（乙醛 + 稀 NaOH）：
1. OH⁻ 抽 α-H（pKa 16.7 vs H₂O 15.7——少量生成，循环再生）→ 烯醇负离子；
2. 负碳进攻另一分子乙醛 C=O → 烷氧负离子；
3. 质子化 → **3-羟基丁醛**（β-羟基醛）；
4. 加热或碱浓度高 → E1cb 脱水（负离子中间体!，区别于酸催化的 E1）→ **2-丁烯醛（巴豆醛）**。
交叉 Aldol 混乱 → 用**定向策略**：一分子无 α-H（苯甲醛、甲醛）或预先制成烯醇负离子（LDA）。Claisen–Schmidt（芳醛 + 脂肪醛酮，得查尔酮类）是定向交叉的经典。

**Claisen 酯缩合**：酯 + 醇钠。**为什么必须醇钠匹配酯的醇氧基**（乙酯用 EtO⁻）：亲核性与离去基相同才避免酯交换混乱（SN2 进攻酯羰基）。**为什么 pKa 25 的 α-H 能被 pKa 16 的 EtO⁻ 抽动还能反应**：平衡虽不利（10^(11−25)? 即负离子浓度 ~10⁻⁹），但产物 **β-酮酯的 α-H pKa ≈ 11 ≪ 乙醇 16** → 产物被定量拉成负离子，酸化才释放——**最后一步不可逆 pull，化学平衡耦合的范例**（回引 [第 3 章](/xiaoshus-blog/textbooks/chemistry/02-inorganic/01/) 平衡的耦合与移动）。

**Michael 加成与 Robinson 环化**：烯醇负离子对 **α,β-不饱和羰基** 的 1,4-共轭加成（软亲核–软受体；硬亲核走 1,2——HSAB 思想，回引 [第 4 章](/xiaoshus-blog/textbooks/chemistry/02-inorganic/02/) 软硬酸碱）。**Robinson 环化 = Michael（环己酮 enolate + 甲基乙烯基酮）+ 分子内 Aldol 缩水 → 双环 [4.4.0] 烯酮（Wieland–Miescher 骨架入口）**——一锅两步构建六元环，甾体合成的关键反应（13 章）。

**羰基波谱**：IR C=O——酮 1715、醛 1720–1740（+2720/2820 Fermi 双峰的醛 C–H）、环戊酮 1745/环丁酮 1780（**环张力升高波数**）、酯 1735–1750、酸 1710、酰胺 1650–1690（13 章共振解释）；¹H NMR：CHO 9–10、α-CH 2.0–2.7；¹³C：醛酮 190–220。**IR 波数是"羰基电子密度"的量尺**：给电子共振（酰胺）降波数，张力/吸电子升波数——与反应活性顺序（12.6.1）同源。

## 12.6 羧酸与羧酸衍生物：亲核酰基取代的统一机理

### 12.6.1 统一机理与活性顺序

所有 RCOY 的水解/醇解/氨解走同一机理——**亲核酰基取代（加成–消除）**：

Nu 进攻 C=O → **四面体中间体**（sp³，氧负）→ Y⁻ 离去 → 产物 RCONu。

**活性顺序**（酰基化合物反应性）：

$$\text{酰氯} > \text{酸酐} > \text{酯} \approx \text{羧酸} > \text{酰胺} > \text{羧酸盐}$$

**电子解释一步到位**：活性 = 羰基亲电性 − Y 的离去能力。离去基的碱性顺序 Cl⁻ < RCOO⁻ < RO⁻ < NH₂⁻（共轭酸 pKa：HCl −7、羧酸 ~4.8、醇 16、NH₃ 38）——**离去能力与碱性严格反序**（pKa 表直接读出）；而酰胺的 N 还有 p–π 共轭给电子（IR 波数最低是同一原因），亲电性与离去能力双降 → 最不活泼。**"pKa 决定离去基"是本章最可复用的规则**。

### 12.6.2 各衍生物制备–反应网络

- **酰氯**：SOCl₂/PCl₃ 由酸制；水解/醇解/氨解"下坡"转一切其他衍生物；与 Gilman → 酮（停留）；Rosenmund 还原 → 醛。
- **酸酐**：酰氯 + 羧酸盐；乙酐 + 酚/醇 → 酯（阿司匹林最后一步，13 章）。
- **酯**：**Fischer 酯化**（酸催化，加成–消除 + 水移出，平衡控制——回引 [第 6 章](/xiaoshus-blog/textbooks/chemistry/04-physical/01/) 勒沙特列）；水解：酸催化可逆 / **碱催化（皂化）不可逆**（OOH⁻ 进攻后 RCOO⁻ 无法被醇质子化——pKa 差 10 个数量级锁死）；与 Grignard → 叔醇（两当量，经酮再加成）；**还原分级**：LiAlH₄ → 醇，DIBAL-H（−78 °C, 1 eq）→ **醛**（四面体中间体低温稳定）。
- **酰胺**：酰氯/酯 + 氨（胺）；**Hofmann 重排**（Br₂/OH⁻：N-溴代 → 迁移 → 异氰酸酯 → 胺，**降一个碳**）；LiAlH₄ → 胺（+1C 主链）。肽键属酰胺（12.10）。
- **羧酸**：制备（Grignard + CO₂；腈水解；氧化）；酸性 pKa 4~5（羧酸根 π–π 共轭，11.2）；**脱羧**：β-酮酸/丙二酸衍生物受热脱 CO₂（六元环过渡态），是乙酰乙酸/丙二酸酯合成法的出口；LiAlH₄ → 伯醇。
- **乙酰乙酸酯合成法**与**丙二酸酯合成法**：活性亚甲基（pKa 11/13）烷基化（SN2，伯卤）→ 水解 → 脱羧，分别出**甲基酮**与**取代乙酸**——第 13 章 C–C 构建清单主力（例题 13.1 复用）。

**鉴别**：羧酸 + NaHCO₃ 放 CO₂（泡腾）；IR 酸 O–H 2500–3300 极宽（二聚体）；¹³C 羧基 165–185。

## 12.7 胺与重氮化合物

- **碱性数据**（pKaH，水中）：CH₃NH₂ 10.6、(CH₃)₂NH 10.7、(CH₃)₃N 9.8（溶剂化拖累）、苯胺 4.6（**p–π 共轭把孤对锁进环**）、乙酰胺 ≈ −0.5（孤对分给羰基）、吡啶 5.2（孤对在 sp² 杂化轨道、不进 π 体系）。**解读示例**：苯胺 pKaH 4.6 → 在 pH 7 水中 99.8% 为分子态（Henderson–Hasselbalch，回引 [第 3 章](/xiaoshus-blog/textbooks/chemistry/02-inorganic/01/)），药物吸收设计据此算分布。
- **制备**：硝化 + 还原（ArNO₂ → ArNH₂，Fe/HCl 或 H₂/Pd）；**Gabriel 合成**（邻苯二甲酰亚胺负离子 SN2 → 伯胺，纯 1°）；腈/酰胺/硝基还原；**还原胺化**（醛酮 + NH₃/RNH₂ → 亚胺/烯胺 → NaBH₃CN/H₂ 还原——生物体内转氨反应同构，12.10）；酰氯 + 胺 → 酰胺（保护基素材）。
- **反应**：烷基化（易过烷基化 → 用 Gabriel/还原胺化绕开）；**Hofmann 消除**（季铵碱 △，E2 反式共平面，**Hofmann 烯**——11.6.1）；与 HNO₂ 分流：伯脂肪胺 → N₂ 放出（**定量氮气 = 氨基定量的经典方法**）；**芳香重氮盐** ArN₂⁺Cl⁻（0–5 °C 稳定，>10 °C 放 N₂）。
- **重氮盐 = 芳环"官能团转换枢纽"**：Sandmeyer（CuCl/CuBr/CuCN → Cl/Br/CN，自由基机理）；KI/H₃PO₂ 直接 H（"删去氨基"导向策略——先 NH₂ 占位导向 EAS，再重氮化脱除）；与酚/芳胺偶联 → **偶氮染料**（Ar–N=N–Ar，大共轭吸收，联系 [第 5 章](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/) UV-Vis 生色团）。
- **鉴别**：Hinsberg 试验（TsCl/NaOH：伯胺产物溶碱、仲胺产物不溶、叔胺不反应——三相区分）；亚硝酸试验。

## 12.8 芳香性与芳环化学的深化

### 12.8.1 Hückel 规则与非苯芳烃

**判据**（回引 [第 9 章](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/01/) Hückel MO）：**环状、平面、完全共轭、π 电子数 4n+2 → 芳香**（闭壳、稳定化）；4n → 反芳香（若强行平面，去稳定化）；**逃避平面化**（如环辛四烯的 tub 构象，实测环内 C–C 1.46/环外 1.34 Å 交替、双键性质保留）则"非芳香"——比反芳香稳。实验证据链：环丁二烯只能低温基质隔离（反芳香）；环辛四烯 + 2K → 环辛四烯双负离子（10π，**平面化、芳香化**，键长均一化）——氧化还原"购买"芳香稳定化能。

**非苯体系**：环戊二烯负离子（6π，pKa 16 的原因，11.2.2）、tropylium 正离子 C₇H₇⁺（6π，环庚三烯 + H⁺ 稳定成盐）、**吡咯/呋喃/噻吩**（杂原子一对孤对入环成 6π；**吡咯 N–H pKa 17.5**——去质子后孤对处于环平面内的 sp² 轨道、不能与 π 体系共轭，负电荷定域于 N，芳香性虽保留但无离域稳定，故介于酚（9.95）与醇（16）之间）、**吡啶**（N 孤对在 sp² 杂化轨道**不参与 π**，环上 6π 由 3 对 π 电子构成；孤对朝外 → 碱性 pKaH 5.2、可质子化/可配位——回引 [第 4 章](/xiaoshus-blog/textbooks/chemistry/02-inorganic/02/) 吡啶配体）。

**杂环反应性对比**：吡咯 ≈ 苯胺级超活化（EAS 在 C-2，中间体正电荷可分给 N 的共振式最多）；呋喃/噻吩活化但弱；**吡啶钝化**（N 的 −I，类似硝基；亲电取代苛刻，m-定位）但**亲核取代可行**（NaNH₂ 进攻 C-2/C-4，负电荷可落在 N 上稳定）。**芳香性是"账户"：反应花掉芳香性要赔利息，赚回更多才成交。**

### 12.8.2 芳环亲核取代（SNAr）与苯炔

- **加成–消除 SNAr**：2,4-二硝基氯苯 + OH⁻ → 2,4-二硝基苯酚（温和条件!）。机理：OH⁻ 加成 → **Meisenheimer 络合物**（负电荷共振恰落在 NO₂ 的 O 上——与 11.8.2 的"邻对位接线"规则镜像对称）→ Cl⁻ 离去。**条件：环上有强吸电子基且位于离去基邻/对**；间位不行。氯苯本体不反应——活化的意义。
- **消除–加成（苯炔）**：氯苯 + NaNH₂/NH₃(l) → 苯胺。¹⁴C 标记氯苯给出 50:50 的标记分布（NH₂ 落在原 C 与邻位各半）——**苯炔中间体对称加成**的铁证。机理：邻位脱 H + Cl⁻ 离去协同生成"三键"（歪曲的炔），NH₂⁻ 任意端加成。

## 12.9 周环反应：FMO 与选择规则

周环反应（pericyclic）：经**环状、协同**过渡态，电子在环内循环流动；受**轨道对称性**控制（Woodward–Hoffmann 规则；Fukui FMO 理论，两人分获 1981 诺奖）。

### 12.9.1 电环化（electrocyclic）

直链多烯一个 σ 键生成/断裂。规则（基态/热反应；光照反转）：

| π 电子数 | 热反应 | 光反应 |
|---|---|---|
| 4n（如丁二烯 → 环丁烯） | **顺旋**（conrotatory） | 对旋 |
| 4n+2（如己三烯 → 环己二烯） | **对旋**（disrotatory） | 顺旋 |

**FMO 推导示范（4π，热）**：HOMO 是 ψ₂（一节点）；两端 p 轨道相位**反号** → 只有**同向旋转**（顺旋）才能同相位重叠成键 → 顺旋。取代基给出立体化学结果：trans,cis,trans-2,4,6-辛三烯（6π，热对旋）闭环 → **cis-5,6-二甲基-1,3-环己二烯**（对旋把两端甲基转向同侧）。**产物立体化学由"规则 + 起始构象"唯一确定，无中间体可投机。**

### 12.9.2 环加成与 Diels–Alder

[4+2]（Diels–Alder，1928，Nobel 1950）：双烯（HOMO）+ 亲双烯体（LUMO）**同面–同面**（[π4s + π2s] 允许）。要求与选择性：
1. **双烯必须 s-cis 构象**（环戊二烯被锁 s-cis → 反应极快，106 倍于丁二烯；环上双键天然 s-cis）；
2. **电子匹配**：正常需求富电子双烯 + 缺电子亲双烯体（马来酸酐、丙烯醛、醌）；反向电子需求 D–A 用缺电子双烯；
3. **区域选择性**：EDG-双烯 + EWG-亲双烯体 → **邻/对产物**（1-甲氧基丁二烯 + 丙烯醛 → 邻位异构为主）——FMO 系数最大的端头相接（HOMO 大系数在给电子端、LUMO 大系数在吸电子端）；
4. **立体专一**：亲双烯体构型保持（cis-亲双烯体 → cis-产物）；**endo 规则**（次级轨道重叠使内向异构体动力学优先，尽管外向更稳——又一个动力学/热力学分野案例）；
5. 单键可旋转 → 双烯体锁定 S-顺式程度决定反应性。

**[2+2] 环加成热禁阻**（[π2s+π2s] 对称性不允许）→ 光化学 [2+2]（激发态 LUMO 相位反转后允许）——**"热不允许的用光"**是 WH 规则的另一半（如肉桂酸光二聚）。

### 12.9.3 σ 迁移

[3,3]-Cope/Claisen 重排：六电子协同，经椅式过渡态——Claisen 重排（烯丙基芳基醚 → 邻烯丙基酚）把"醚的 O 桥"变成 C–C 键，天然产物构筑常用（13 章）。同位素标记证明协同性（无交叉产物）。

### 12.9.4 1,3-偶极环加成（Huisgen 环加成）

另一类重要周环：1,3-偶极体（叠氮 R–N=N⁺=N⁻、腈氧化物、硝酮、臭氧 O₃ 等）与烯烃/炔烃/累积双键**协同成五元杂环**。代表体系：**叠氮 + 端炔 → 1,4-二取代 1,2,3-三唑**（Huisgen, *Angew. Chem.* **1963**, *2*, 565；现代 Cu(I) 催化版即模块六·进阶章 2 的 CuAAC 点击化学，Kolb/Finn/Sharpless, *Angew. Chem. Int. Ed.* **2001**, *40*, 2004）。无金属时 Huisgen 原反应给出 1,4- 与 1,5-三唑混合物（区域选择性差），Cu(I) 或 Ru 催化可锁定单一区域异构体——是"周环选择规则 + 催化调控"结合的典型。臭氧分解（O₃ 对 C=C 的 1,3-偶极加成 → 臭氧化物 → 还原/氧化裂解）是这一族的**工业级应用**（烯烃定位断裂鉴定双键位置，回引 [第 5 章](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/)）。

**立体专一性**：与 [4+2] 同理，1,3-偶极加成保留偶极体与亲偶极体的立体关系（cis-烯烃 → cis-取代五元环），属同面–同面协同。

## 12.10 生物有机衔接：糖、氨基酸、蛋白质、核酸

### 12.10.1 糖类

葡萄糖：直链醛式 + 环状半缩醛（C5–OH 进攻 C1 → **吡喃糖**，C1 = 异头碳）。**变旋光**：α（[α]ᴅ +112°）与 β（+18.7°）经开链式互变平衡至 +52.7°——旋光动力学是半缩醛可逆性的直接观测。环己烷构象分析直接复用：β-D-吡喃葡萄糖**全部取代基平伏** → 自然界最丰富有机物；α 异头物受**异头效应**（σ_C–O → σ*_C–O 的立体电子稳定，部分抵消位阻）保留 36%。糖苷键（缩醛）耐碱、酸水解——**寡糖/多糖 = 缩醛聚合物，酶即立体专一的"酸催化剂"**；还原性糖（有半缩醛端，Tollens 阳性）与非还原糖（蔗糖，双缩醛）之分；溴水氧化只氧化醛糖（区别酮糖? 醛糖 → 糖酸）。

### 12.10.2 氨基酸、蛋白质

20 种常见 α-氨基酸（除甘氨酸均有手性碳，天然均为 **L/S 构型**——半胱氨酸因 S 优先级例外为 R）。**两性与等电点**：氨基酸以 NH₃⁺/COO⁻ 双极离子存在；pI 计算：中性型 pI = (pK₁ + pK₂)/2（甘氨酸 (2.34+9.60)/2 = **5.97**）；酸性型取两个酸性 pKa（Asp (2.09+3.86)/2 = **2.98**）；碱性型取两个碱性 pKa（Lys (8.95+10.53)/2 = **9.74**）。电泳分离方向由 pH vs pI 决定（例题 12.3）。**肽键**是酰胺：p–π 共轭使 C–N 键 1.32 Å（介于单双键）、**平面刚性和 trans 优势**（11.2 共轭效应的分子生物学后果）。反应：Sanger 试剂（FDNB）标 N 端、Edman 降解逐个切 N 端（异硫氰酸苯酯，PITC）、茚三酮显色（紫，570 nm，氨基酸定量）。

### 12.10.3 核酸

核苷酸 = 碱基 + 核糖/脱氧核糖（呋喃糖，N-糖苷键，**β 构型**）+ 磷酸（磷酸二酯键，3′→5′）。碱基（嘌呤 A、G；嘧啶 C、T、U）芳香（各 10π/6π 体系）——**UV 260 nm 吸收**是核酸定量的物理基础（回引 [第 5 章](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/)）。配对：A=T（2 H 键）、G≡C（3 H 键）→ DNA 双螺旋；G–C 富集区熔解温度更高（可核算：氢键 + 堆积）。**化学视角**：磷酸二酯的负电荷（pKa ≈ 1）使 DNA 骨架在生理 pH 全电离——稳定（防水解亲核进攻）且决定电泳迁移；RNA 的 2′-OH 邻基参与使其易水解——**化学稳定性差异 = "DNA 存档案、RNA 做拷贝"的分子基础**。

## 12.11 关键公式与方程速查

| 名称 | 表达式 | 适用条件 | 易错点 |
|---|---|---|---|
| pI（中性型） | (pK₁+pK₂)/2 | 一酸一碱两性离子 | 碱性/酸性氨基酸选错 pKa 对 |
| Henderson–Hasselbalch | pH = pKa + log([A⁻]/[HA]) | 缓冲/胺质子化分布 | 胺类用 pKaH |
| 酰基活性序 | 酰氯>酸酐>酯≈酸>酰胺 | 亲核酰基取代 | 别把"酸"排进可转化序列（需先活化） |
| Claisen 驱动 | 产物 β-二羰基 pKa ≪ 醇 pKa | 醇钠体系 | 必须酸化后处理才得产物 |
| Hückel | π = 4n+2 → 芳香 | 环、平面、全共轭 | 杂环孤对"入环否"逐个判断 |
| 电环化规则 | 4n 热顺旋 / 4n+2 热对旋 | 基态 | 光化学反转 |
| 烯烃氢化焓 | 稳定性 ↑ ⇒ −ΔH↓ | 气相/溶剂标准态 | 比较须同分子式异构体 |
| 缩醛平衡 | 过量醇/除水正移 | 酸催化 | 碱性条件缩醛稳定 |
| 变旋光 | [α]ᵗ = Σxᵢ[α]ᵢ | α/β 平衡 | 需测平衡后值才得 β 占比 |

## 12.12 典型例题与解题思路

### 例题 12.1（基础机理）乙醛稀碱 Aldol 至巴豆醛——每步不跳步

**解**（电子流向逐条）：
1. OH⁻ 孤对 → 乙醛 α-H（σ_C–H 电子对转入 C–C 间成 π）→ 烯醇负离子 CH₂=CH–O⁻（负电荷共振 O/C 两端）；
2. 碳端孤对 → 另一乙醛羰基 C（π → O）→ β-烷氧负离子 CH₃CH(O⁻)CH₂CHO；
3. O⁻ 抓水 H → 3-羟基丁醛 + OH⁻（催化剂再生——**循环**）；
4. 加热：OH⁻ 抽 α-H → 烯醇负离子 → E1cb：负电荷推 π 成 C=C、OH⁻ 离去 → 2-丁烯醛（更稳：C=C–C=O 共轭，约 −15 kJ/mol 级稳定化）。

### 例题 12.2（综合推断）谱学定结构

分子式 C₄H₈O₂；IR：1738 cm⁻¹ 强峰、无 2500–3300 宽峰；¹H NMR：δ 4.12（q，J = 7.1 Hz，2H）、2.05（s，3H）、1.26（t，J = 7.1 Hz，3H）。**解**：不饱和度 = (2×4+2−8)/2 = 1 → 一个双键；1738 + 无宽 O–H → 酯；δ 2.05 单峰 3H = CH₃CO–；δ 4.12 四重峰（被 CH₃ 耦合）+ δ 1.26 三重峰 = –OCH₂CH₃。**结论：乙酸乙酯**。校验：q/t 耦合对与 J 相等证实相邻（回引 [第 10 章](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/02/) n+1 规则与一级谱）。

### 例题 12.3（计算+应用）氨基酸等电点与电泳行为

赖氨酸 pKa：COOH 2.18、NH₃⁺(α) 8.95、NH₃⁺(侧链) 10.53。(a) 求 pI；(b) pH 7.0 电泳中它向哪极移动？

1. 碱性氨基酸：全质子化 → 中性两性离子（净 0）发生在 pK₂(8.95) 与 pK₃(10.53) 之间 → pI = (8.95+10.53)/2 = **9.74**；
2. pH 7.0 < pI → 分子净带正电 → **向阴极（负极）移动**；
3. 校验：pH 7 时侧链 NH₃⁺ 几乎全质子化（10.53 − 7.0 = 3.53 → [NH₂]/[NH₃⁺] = 10⁻³·⁵³），α-NH₃⁺ 大部分在（8.95−7 = 1.95 → 1:89 去质子比），净电荷 ≈ +0.98 —— 与"向阳极? 不，向阴极"一致。

### 例题 12.4（拓展）Diels–Alder 区域与立体化学综合

1-甲氧基-1,3-丁二烯 + 丙烯醛（CH₂=CHCHO）反应，预测主产物骨架、区域与 endo/exo。

1. 电子匹配：EDG（OMe）双烯 + EWG（CHO）亲双烯体 → 正常需求；
2. 区域：给电子端（C1，HOMO 大系数）接吸电子端（Cβ，LUMO 大系数）→ **"邻位"产物**（CHO 与 OMe 相邻取向）；
3. 立体：亲双烯体构型保持；endo 优先 → **endo-邻位加成物**（CHO 指向双烯 π 体系内侧）；
4. 校验：若换为环戊二烯 + 马来酸酐（教科书体系）同样 endo 为主，低温动力学产物、加热可部分转 exo（热力学）。

## 12.13 常见误区与易错点

1. **把酯排进"能被 NaBH₄ 还原"清单**：NaBH₄ 只对醛酮快；酯/酰胺需 LiAlH₄（或更强/专一试剂）。
2. **Claisen 用错碱**：NaOEt 配乙酯（醇氧基一致）；用 NaOMe 会酯交换、用 NaOH 皂化。
3. **吡咯当吡啶**：吡咯孤对入环（N 上无孤对可给碱），pKaH ≈ −0.3? 吡咯质子化发生在 C 上、碱性极弱；吡啶孤对在外，pKaH 5.2——"N 有没有孤对可给"是分水岭。
4. **4n+2 数错对象**：吡咯数 N 孤对那对入环（6π）；呋喃两对孤对只入一对；吡啶一对方向相反（孤对不入环，环内 6π 来自 C=N 与两根 C=C）。
5. **SNAr 忘了"邻对位吸电子"前提**：氯苯 + NaOH 常压不反应；间硝基氯苯也几乎不反应——Meisenheimer 络合物的稳定化位置决定一切。
6. **碘仿反应用于非甲基酮**：只有 CH₃CO–/CH₃CH(OH)– 阳性；乙醇阳性（氧化成乙醛）是特例不是通则。
7. **D–A 忘 s-cis 前提**：把固定 s-trans 的双烯（如某些桥环）当好双烯体——永远先检查构象可及性（复用第 11 章构象分析）。

## 12.15 进阶拓展

- **不对称合成进入官能团化学**：Sharpless 环氧化（烯丙醇 → 手性环氧，ee > 90%）、CBS 还原（酮 → 手性醇）——12.2/12.5 反应的对映选择版本（13.5 节展开）。
- **生物正交化学**（Bertozzi，2022 诺奖）：叠氮-炔点击（CuAAC 或 SPAAC）本质是"炔烃加成的生物版"，对糖与糖蛋白标记。
- **有机催化**：脯氨酸催化的直接 Aldol（List/Barbas 2000）= enamine 化学（12.5.2）的生物启发放大；2021 诺奖。
- **计算预测官能团反应性**：pKa/位阻/轨道能量的量化（DFT）与反应数据库挖掘，使"活性顺序"从经验表变为可计算量。

## 12.16 思考练习题

（解答见 [98-习题答案册](/xiaoshus-blog/textbooks/chemistry/06-organic/98/) 第 12 章部分。）

1. **概念**：把酰氯、酸酐、酯、酰胺按 (a) 水解速率、(b) 羰基 IR 波数、(c) 离去基共轭酸的 pKa 分别排序，并用一个统一电子模型解释三张排序表的一致性。
2. **机理**：写出 Claisen 缩合（乙酸乙酯 + NaOEt → 乙酰乙酸乙酯）每步电子流向，并回答：为什么不用 NaOH？为什么"产物的 pKa"是全反应的驱动力？
3. **预测**：环氧化合物 1,2-环氧丙烷分别与 (a) CH₃O⁻/CH₃OH、(b) CH₃OH/H⁺ 反应，主产物各是什么（含进攻位）？解释区域选择反转。
4. **芳香性**：判断下列物种芳香/反芳香/非芳香并给 π 电子数与几何理由：环戊二烯负离子、tropylium 正离子、环辛四烯、环辛四烯双负离子、吡咯、吡啶。
5. **周环**：(2E,4Z,6E)-2,4,6-辛三烯受热闭环产物的甲基立体关系是什么？若换成光化学反应呢？（写出顺旋/对旋推导；校验值：热反应得顺式产物，光反应得反式产物。）
6. **推断**：分子式 C₈H₁₀O；IR 3350（宽）、1600/1500；¹H NMR δ 7.2（m，5H）、3.7（t，J ≈ 7 Hz，2H）、2.8（t，J ≈ 7 Hz，2H）、1.9（br s，1H，可被 D₂O 交换消除）。给出结构与归属（提示：先算不饱和度；校验：两个亚甲基互相耦合，故均为三重峰）。
7. **计算**：谷氨酸 pKa：2.19（COOH）、4.25（侧链）、9.67（NH₃⁺）。求 pI，并判断 pH 6.0 电泳方向（校验 pI = 3.22）。
8. **挑战**：解释实验序列：氯苯与 NaOH 水溶液 300 °C 才反应得苯酚（工业老法）；2,4-二硝基氯苯与 Na₂CO₃ 水溶液室温即得产物；而对硝基氯苯居中。写出两种机理路径（SNAr 与苯炔）并指明各自的条件指纹。
