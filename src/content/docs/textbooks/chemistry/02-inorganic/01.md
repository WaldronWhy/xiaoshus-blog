# 第 3 章 酸碱、沉淀、氧化还原与配位平衡——四大平衡的统一热力学处理

> **本章定位**：本章把传统上分头讲授的酸碱、沉淀、氧化还原、配位四大平衡还原为**同一个热力学问题**（平衡常数与化学势的语言），是全模块定量能力的基石。回引[模块一第 1 章](/xiaoshus-blog/textbooks/chemistry/01-foundations/01/)的数学工具与[模块一第 2 章](/xiaoshus-blog/textbooks/chemistry/01-foundations/02/)的反应分类总览；向前直接支撑[模块三（分析化学）](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/)的三大滴定，并由[模块四第 6 章（热力学）](/xiaoshus-blog/textbooks/chemistry/04-physical/01/)把化学势进一步严格化。

## 3.0 本章学习目标

1. 能够用化学势与 $\Delta_\mathrm{r}G_\mathrm{m}^\ominus = -RT\ln K^\ominus$ 把酸碱、沉淀、氧化还原、配位平衡写成统一的平衡常数表达式，并说明"标准态"与"活度"的含义。
2. 能够独立完成一元弱酸（弱碱）pH 的**精确求解**，并能说明每一步近似引入的依据与误差量级（判据 $c/K_a \ge 500$、$cK_a \ge 20K_\mathrm{w}$）。
3. 能够推导并绘制二元酸的分布分数图，判断指定 pH 下物种的主要存在形式。
4. 能够从 $\Delta_\mathrm{r}G = -nFE$ 推导能斯特方程，用元素电势图判断歧化并计算相邻氧化态间的电势。
5. 能够计算逐级与累积稳定常数、EDTA 的酸效应系数与**条件稳定常数**，并判断滴定可行性。
6. 能够处理**多重平衡耦合**（沉淀转化、配位溶解、掩蔽），把总平衡常数写成各步常数的乘积。

## 3.1 统一的热力学视角：从化学势到平衡常数

### 3.1.1 化学势与活度

化学势（chemical potential）$\mu_\mathrm{B}$ 是物质 B 的偏摩尔 Gibbs 能，决定了物质从一相流向另一相、参与反应的方向。对理想稀溶液中的溶质，化学势取形式（严格推导见[模块四第 6 章](/xiaoshus-blog/textbooks/chemistry/04-physical/01/)，本章先按操作定义使用）

$$\mu_\mathrm{B} = \mu_\mathrm{B}^\ominus + RT\ln a_\mathrm{B}$$

其中 $a_\mathrm{B}$ 是**活度**（activity），即"有效浓度"：

$$a_\mathrm{B} = \gamma_\mathrm{B}\,\frac{c_\mathrm{B}}{c^\ominus},\qquad c^\ominus = 1~\mathrm{mol\cdot L^{-1}}$$

$\gamma_\mathrm{B}$ 为活度系数，$\gamma \to 1$ 当且仅当溶液足够稀（离子强度 $I = \tfrac{1}{2}\sum c_i z_i^2$ 足够小）。对 25 °C 的水溶液，Debye–Hückel 极限公式给出 $z \approx 1$ 的离子：

$$\lg\gamma \approx -0.509\,z^2\sqrt{I}$$

（该式由离子静电作用模型导出，模块五将给出其统计力学基础；实验证据是凝固点降低、电动势测量对理想行为的系统偏离。）

**本章默认的近似**：若题目只给浓度且离子强度不大（$I \lesssim 0.01$），取 $\gamma \approx 1$、$a \approx c/c^\ominus$。凡遇高浓度电解质（如浓盐水），必须回到活度。这一近似何时失效，正是 3.3.3 节"盐效应"的定量内容。

### 3.1.2 反应 Gibbs 能与标准平衡常数

对任意反应 $0 = \sum_\mathrm{B}\nu_\mathrm{B}\,\mathrm{B}$（产物 $\nu > 0$），把各物质的 $\mu_\mathrm{B} = \mu_\mathrm{B}^\ominus + RT\ln a_\mathrm{B}$ 代入摩尔反应 Gibbs 能：

$$\Delta_\mathrm{r}G_\mathrm{m} = \sum_\mathrm{B}\nu_\mathrm{B}\mu_\mathrm{B}
= \underbrace{\sum_\mathrm{B}\nu_\mathrm{B}\mu_\mathrm{B}^\ominus}_{\Delta_\mathrm{r}G_\mathrm{m}^\ominus}
+ RT\sum_\mathrm{B}\ln a_\mathrm{B}^{\nu_\mathrm{B}}
= \Delta_\mathrm{r}G_\mathrm{m}^\ominus + RT\ln Q$$

其中 $Q$ 为反应商（活度商）。平衡时宏观上组成不再变化，$\Delta_\mathrm{r}G_\mathrm{m} = 0$，故

$$\boxed{\ \Delta_\mathrm{r}G_\mathrm{m}^\ominus = -RT\ln K^\ominus\ }\qquad
\lg K^\ominus = \frac{-\Delta_\mathrm{r}G_\mathrm{m}^\ominus}{2.303RT} = \frac{-\Delta_\mathrm{r}G_\mathrm{m}^\ominus}{5.708~\mathrm{kJ\cdot mol^{-1}}}\ (298~\mathrm{K})$$

注意量纲：$\Delta_\mathrm{r}G_\mathrm{m}^\ominus$（kJ/mol）除以 $2.303RT$（kJ/mol）得纯数——$K^\ominus$ 是**无量纲**的，它由活度构成。25 °C 时 $2.303RT = 8.314\times10^{-3}~\mathrm{kJ\cdot mol^{-1}\cdot K^{-1}}\times 298.15~\mathrm{K}\times 2.303 = 5.708~\mathrm{kJ\cdot mol^{-1}}$。

**例 3-1（热力学 → 平衡常数）** 合成氨 $\mathrm{N_2(g) + 3H_2(g) \rightleftharpoons 2NH_3(g)}$ 在 298 K 的 $\Delta_\mathrm{r}G_\mathrm{m}^\ominus = -32.9~\mathrm{kJ\cdot mol^{-1}}$，求 $K^\ominus$。

解：$\lg K^\ominus = \dfrac{32.9~\mathrm{kJ\cdot mol^{-1}}}{5.708~\mathrm{kJ\cdot mol^{-1}}} = 5.77$，故 $K^\ominus = 10^{5.77} \approx 5.8\times10^{5}$。

量纲检查：分子分母同单位，商为纯数。热力学上 298 K 时反应强烈偏向氨——但铁催化剂上的工业合成要 400–500 °C（动力学需要，见模块四第 7 章）：**$K$ 大只保证"能到"，不保证"快到"**。

### 3.1.3 四大平衡是同一个 $K$ 的四种面孔

| 平衡类型 | 平衡常数 | 标准态约定（水溶液） |
|---|---|---|
| 酸碱 | $K_a, K_b, K_\mathrm{w}$ | $c^\ominus = 1~\mathrm{mol\cdot L^{-1}}$，物质活度 |
| 沉淀 | $K_\mathrm{sp}$ | 纯固体活度 $=1$，离子活度之积 |
| 氧化还原 | $K = 10^{nE^\ominus/0.0592}$（25 °C） | $E^\ominus = -\Delta_\mathrm{r}G_\mathrm{m}^\ominus/(nF)$ |
| 配位 | $\beta_n$（累积） | 与酸碱同 |

它们的推导起点完全一致：把反应中"自由离子/分子"与"束缚态"（共轭碱、晶格中的离子、氧化态、配离子）之间的转化写成反应式，套 $\Delta_\mathrm{r}G_\mathrm{m}^\ominus = -RT\ln K^\ominus$。**从第 3.2 节起，"记四大套公式"被替换为"写反应式、套一个公式"。**

## 3.2 酸碱平衡

### 3.2.1 质子理论与水的自偶电离

按 Brønsted 理论，酸是质子给体、碱是质子受体，酸碱反应是质子在共轭对之间转移（这是[模块一第 2 章 2.4 节](/xiaoshus-blog/textbooks/chemistry/01-foundations/02/)"质子转移与电子转移统一视角"的第一个定量应用）。水是最重要的两性物质：

$$\mathrm{H_2O + H_2O \rightleftharpoons H_3O^+ + OH^-},\qquad K_\mathrm{w} = a(\mathrm{H^+})\,a(\mathrm{OH^-}) = 1.0\times10^{-14}\ (25~\mathrm{^\circ C})$$

$K_\mathrm{w}$ 随温度升高而增大（电离吸热），100 °C 时约 $5\times10^{-13}$——"中性"的 $\mathrm{pH} = 7$ 只是 25 °C 的巧合。

### 3.2.2 强酸强碱：极稀情形的陷阱

$0.010~\mathrm{mol\cdot L^{-1}}$ HCl 完全解离，$a(\mathrm{H^+}) \approx 0.010$，pH $= 2.00$，无歧义。但当 $c \sim 10^{-8}~\mathrm{mol\cdot L^{-1}}$ 时，水的自偶电离贡献不可忽略：以强碱 NaOH 为例，电荷平衡 $[\mathrm{Na^+}] + [\mathrm{H^+}] = [\mathrm{OH^-}]$ 与 $K_\mathrm{w} = [\mathrm{H^+}][\mathrm{OH^-}]$ 联立（推导与计算见练习 3-1），pH 约 7.02 而不是"按浓度算"的 8（强酸情形对照约 6.98 而非 6）。**规则：只要 $c < 10^{-6}~\mathrm{mol\cdot L^{-1}}$，必须把 $K_\mathrm{w}$ 项写进电荷平衡。**

### 3.2.3 一元弱酸：完整推导与近似判据

设分析浓度（total concentration，含所有形态）为 $c$ 的一元弱酸 HA。体系有四个未知数 $[\mathrm{H^+}],[\mathrm{OH^-}],[\mathrm{HA}],[\mathrm{A^-}]$，需要四个方程：

**① 解离平衡**（$K_a$ 定义）：
$$K_a = \frac{a(\mathrm{H^+})\,a(\mathrm{A^-})}{a(\mathrm{HA})} \approx \frac{[\mathrm{H^+}][\mathrm{A^-}]}{[\mathrm{HA}]}$$
**② 水的平衡**：$K_\mathrm{w} = [\mathrm{H^+}][\mathrm{OH^-}]$
**③ 质量平衡**（mass balance）：$c = [\mathrm{HA}] + [\mathrm{A^-}]$
**④ 电荷平衡**（charge balance，溶液整体电中性）：$[\mathrm{H^+}] = [\mathrm{A^-}] + [\mathrm{OH^-}]$

由 ④ 得 $[\mathrm{A^-}] = [\mathrm{H^+}] - [\mathrm{OH^-}] = [\mathrm{H^+}] - K_\mathrm{w}/[\mathrm{H^+}]$；由 ③ 得 $[\mathrm{HA}] = c - [\mathrm{A^-}] = c - [\mathrm{H^+}] + K_\mathrm{w}/[\mathrm{H^+}]$。代入 ①：

$$K_a\left(c - [\mathrm{H^+}] + \frac{K_\mathrm{w}}{[\mathrm{H^+}]}\right) = [\mathrm{H^+}]\left([\mathrm{H^+}] - \frac{K_\mathrm{w}}{[\mathrm{H^+}]}\right) = [\mathrm{H^+}]^2 - K_\mathrm{w}$$

两边乘 $[\mathrm{H^+}]$ 整理得**精确式**（一元三次方程）：

$$[\mathrm{H^+}]^3 + K_a[\mathrm{H^+}]^2 - (K_ac + K_\mathrm{w})[\mathrm{H^+}] - K_aK_\mathrm{w} = 0$$

**逐级近似**（每一步都说明依据）：

- **第一近似**：弱酸贡献的 $\mathrm{H^+}$ 通常远多于水的（判据 $cK_a \ge 20K_\mathrm{w}$，此时 $\mathrm{H^+}$ 的相对贡献差 20 倍以上）→ 舍弃 $K_\mathrm{w}$ 项，得二次方程 $[\mathrm{H^+}]^2 + K_a[\mathrm{H^+}] - K_ac = 0$；
- **第二近似**：若解离度 $\alpha = [\mathrm{A^-}]/c \ll 1$，则 $[\mathrm{HA}] \approx c$（判据 $c/K_a \ge 500$，对应 $\alpha \lesssim 5\%$，且 $\alpha^2$ 级误差可忽略）→ 得**最简式**：

$$[\mathrm{H^+}] \approx \sqrt{K_a c},\qquad \alpha = \sqrt{\frac{K_a}{c}}$$

注意 $\alpha \propto c^{-1/2}$：**稀释使弱酸解离度增大**（Le Chatelier 对 $K$ 不变的直接体现——$K$ 只与温度有关，稀释后 $Q$ 减小，平衡右移）。

**例 3-2（基础）** 求 $0.100~\mathrm{mol\cdot L^{-1}}$ 乙酸（HAc，$K_a = 1.75\times10^{-5}$，25 °C）的 pH 与解离度。

解：判据检查：$cK_a = 0.100\times1.75\times10^{-5} = 1.75\times10^{-6} \ge 20K_\mathrm{w} = 2.0\times10^{-13}$ ✓；$c/K_a = 5714 \ge 500$ ✓。用最简式：

$$[\mathrm{H^+}] = \sqrt{1.75\times10^{-5}\times0.100}~\mathrm{mol\cdot L^{-1}} = 1.32\times10^{-3}~\mathrm{mol\cdot L^{-1}},\quad \mathrm{pH} = 2.88$$

$$\alpha = \sqrt{K_a/c} = \sqrt{1.75\times10^{-4}} = 1.32\%$$

量纲检查：$K_a$ 无量纲，$c$ 的单位 mol/L 开方后仍为 mol/L ✓。校验：$[\mathrm{H^+}]/c = 1.3\%\ll 5\%$，近似自洽。

弱碱完全对偶：把 $\mathrm{H^+}\leftrightarrow\mathrm{OH^-}$、$K_a\leftrightarrow K_b$，得 $[\mathrm{OH^-}] \approx \sqrt{K_b c}$。共轭关系 $K_a(\mathrm{HA})\cdot K_b(\mathrm{A^-}) = K_\mathrm{w}$ 可由总反应 $\mathrm{HA + H_2O \rightleftharpoons A^- + H_3O^+}$ 与 $\mathrm{A^- + H_2O \rightleftharpoons HA + OH^-}$ 相加得到（两反应相加，$\Delta G^\ominus$ 相加，故 $K$ 相乘——这是 3.6 节"总平衡常数法"的第一个例子）。

### 3.2.4 多元酸与分布分数

二元酸 $\mathrm{H_2A}$ 分步解离：$K_{a1} = [\mathrm{H^+}][\mathrm{HA^-}]/[\mathrm{H_2A}]$，$K_{a2} = [\mathrm{H^+}][\mathrm{A^{2-}}]/[\mathrm{HA^-}]$。由分步式反代得各形态浓度对 $[\mathrm{H_2A}]$ 的比：

$$[\mathrm{HA^-}] = \frac{K_{a1}[\mathrm{H_2A}]}{[\mathrm{H^+}]},\qquad
[\mathrm{A^{2-}}] = \frac{K_{a1}K_{a2}[\mathrm{H_2A}]}{[\mathrm{H^+}]^2}$$

代入质量平衡 $c = [\mathrm{H_2A}](1 + K_{a1}/[\mathrm{H^+}] + K_{a1}K_{a2}/[\mathrm{H^+}]^2)$，得**分布分数**（species distribution fraction）：

$$\delta_0 = \frac{[\mathrm{H_2A}]}{c} = \frac{[\mathrm{H^+}]^2}{D},\quad
\delta_1 = \frac{K_{a1}[\mathrm{H^+}]}{D},\quad
\delta_2 = \frac{K_{a1}K_{a2}}{D},\qquad
D = [\mathrm{H^+}]^2 + K_{a1}[\mathrm{H^+}] + K_{a1}K_{a2}$$

分布分数只依赖 pH（不依赖浓度），这是"分布图"之所以通用的原因。三个交点分别位于 $\mathrm{pH} = \mathrm{p}K_{a1}$（$\delta_0 = \delta_1 = 0.5$）与 $\mathrm{pH} = \mathrm{p}K_{a2}$（$\delta_1 = \delta_2$）；相邻两级 $K_a$ 相差 $\ge 10^4$（$\Delta\mathrm{p}K_a \ge 4$）时各步可分开处理。

**计算多元酸 pH 的实用规则**（依据：第一级远强于第二级时，$\mathrm{H^+}$ 几乎全部来自第一级）：

- 若 $c/K_{a1} < 500$：用精确二次式 $[\mathrm{H^+}]^2 + K_{a1}[\mathrm{H^+}] - K_{a1}c = 0$；
- 第二级及以后对 $[\mathrm{H^+}]$ 的贡献可忽略（条件 $\sqrt{K_{a1}c} \ge 40\,[\mathrm{H^+}]$ 量级上等价于 $\mathrm{p}K_{a2} - \mathrm{p}K_{a1} \gtrsim 3$ 且 $c$ 不太小）；
- 纯酸溶液中 $[\mathrm{A^{2-}}] \approx K_{a2}$：由 $K_{a2} = [\mathrm{H^+}][\mathrm{A^{2-}}]/[\mathrm{HA^-}]$ 且 $[\mathrm{HA^-}] \approx [\mathrm{H^+}]$ 即得。

**例 3-3（多元酸）** 求饱和硫化氢水溶液（$c(\mathrm{H_2S}) \approx 0.10~\mathrm{mol\cdot L^{-1}}$，$K_{a1} = 1.3\times10^{-7}$，$K_{a2} = 7.1\times10^{-15}$）的 pH 与 $[\mathrm{S^{2-}}]$。

解：$\Delta\mathrm{p}K_a = 14.15 - 6.89 \approx 7.3 \gg 3$，第二级可忽略。$c/K_{a1} = 7.7\times10^{5} \ge 500$，用最简式：

$$[\mathrm{H^+}] = \sqrt{1.3\times10^{-7}\times0.10}~\mathrm{mol\cdot L^{-1}} = 1.1\times10^{-4}~\mathrm{mol\cdot L^{-1}},\quad \mathrm{pH} = 3.94$$

纯酸中 $[\mathrm{S^{2-}}] \approx K_{a2} = 7.1\times10^{-15}~\mathrm{mol\cdot L^{-1}}$（量纲检查：$K_{a2}$ 无量纲，此处数值上等于以 mol/L 计的浓度，其来源是 $[\mathrm{A^{2-}}] \approx K_{a2}\,[\mathrm{HA^-}]/[\mathrm{H^+}]$ 且 $[\mathrm{HA^-}] \approx [\mathrm{H^+}]$）。

关键推论：**外加强酸控制 pH 后**，$[\mathrm{H_2S}] \approx c$ 不变而 $[\mathrm{H^+}]$ 不再由 $\mathrm{H_2S}$ 决定，联立两级平衡得

$$[\mathrm{S^{2-}}] = \frac{K_{a1}K_{a2}[\mathrm{H_2S}]}{[\mathrm{H^+}]^2}$$

——$\mathrm{S^{2-}}$ 浓度可随 pH 被"旋钮式"地调低（$[\mathrm{H^+}]$ 每增 10 倍，$[\mathrm{S^{2-}}]$ 降 100 倍）。这是 3.8 节例题 3-2 与练习 3-8"控制酸度分离金属硫化物"的引擎，也是经典定性分析分组方案的热力学根据。

三元酸（$\mathrm{H_3PO_4}$：$K_{a1} = 7.11\times10^{-3}$，$K_{a2} = 6.32\times10^{-8}$，$K_{a3} = 4.5\times10^{-13}$，即 $\mathrm{p}K_a$ = 2.15 / 7.20 / 12.35）同理，$\delta$ 的分母含六项，方法不变。**练习 3-4** 要求对 $0.010~\mathrm{mol\cdot L^{-1}}$ $\mathrm{H_3PO_4}$ 完成一次 $c/K_{a1} < 500$ 的精确计算。

### 3.2.5 缓冲溶液

向共轭对 $\mathrm{HA}/\mathrm{A^-}$ 共存的体系中取 $K_a$ 定义式并取负对数：

$$K_a = \frac{[\mathrm{H^+}][\mathrm{A^-}]}{[\mathrm{HA}]}
\ \Rightarrow\
\mathrm{pH} = \mathrm{p}K_a + \lg\frac{[\mathrm{A^-}]}{[\mathrm{HA}]} = \mathrm{p}K_a + \lg\frac{n(\mathrm{A^-})}{n(\mathrm{HA})}$$

最后一步是因为两物种同处一体积，浓度比 = 摩尔数比（Henderson–Hasselbalch 方程）。它成立的条件是两形态都大量存在（各 $\ge$ 约 10%），故有效缓冲范围为 $\mathrm{p}K_a \pm 1$。

**缓冲容量**（buffer capacity）$\beta$ 定义为使 1 L 溶液 pH 升高 1 所需强碱的摩尔数。设总浓度 $c = [\mathrm{HA}] + [\mathrm{A^-}]$，加碱把 HA 变为 A⁻，故 $\beta = \mathrm{d}[\mathrm{A^-}]/\mathrm{d}\,\mathrm{pH}$。由 $\delta_1 = [\mathrm{A^-}]/c = K_a/(K_a + [\mathrm{H^+}])$：

$$\frac{\mathrm{d}\delta_1}{\mathrm{d}[\mathrm{H^+}]} = -\frac{cK_a}{(K_a+[\mathrm{H^+}])^2},\qquad
\frac{\mathrm{d}\,[\mathrm{H^+}]}{\mathrm{d}\,\mathrm{pH}} = \frac{\mathrm{d}\,[\mathrm{H^+}]}{\mathrm{d}\,(-\lg[\mathrm{H^+}])} = -2.303[\mathrm{H^+}]$$

两式相除（链式法则，注意负负得正）：

$$\beta = \frac{2.303\,c\,K_a[\mathrm{H^+}]}{(K_a+[\mathrm{H^+}])^2},\qquad
[\mathrm{H^+}] = K_a\ \text{时}\ \beta_\mathrm{max} = \frac{2.303c}{4} \approx 0.576\,c$$

即**等物质的量比时缓冲能力最强**，且 $\beta \propto c$——血液（碳酸氢盐/碳酸缓冲对 + 血红蛋白缓冲对，pH 7.40 ± 0.05）与海水的 pH 稳态都是这一公式的生物学注脚。

**例 3-4（缓冲液设计）** 用 $0.10~\mathrm{mol\cdot L^{-1}}$ 氨水与 $0.10~\mathrm{mol\cdot L^{-1}}$ $\mathrm{NH_4Cl}$（$\mathrm{p}K_a(\mathrm{NH_4^+}) = 9.25$）配制 pH 8.95 的缓冲液，求体积比。

解：$\lg\frac{n(\mathrm{NH_3})}{n(\mathrm{NH_4^+})} = 8.95 - 9.25 = -0.30 \Rightarrow \frac{n(\mathrm{NH_3})}{n(\mathrm{NH_4^+})} = 10^{-0.30} = 0.50$。

因两液浓度相同，体积比 $V(\mathrm{NH_3}) : V(\mathrm{NH_4Cl}) = 1 : 2$。量纲检查：比值无量纲 ✓。

## 3.3 沉淀溶解平衡

### 3.3.1 溶度积的定义与换算

难溶电解质 $\mathrm{M}_m\mathrm{X}_n(\mathrm{s}) \rightleftharpoons m\mathrm{M}^{z+} + n\mathrm{X}^{y-}$ 的平衡常数即溶度积（solubility product）：

$$K_\mathrm{sp} = a(\mathrm{M}^{z+})^m\,a(\mathrm{X}^{y-})^n$$

（纯固体活度为 1，不进入表达式——这是标准态约定的直接结果。）溶解度 $s$ 与 $K_\mathrm{sp}$ 的换算（稀溶液、无副反应）：

$$\mathrm{AgCl:}\quad s = \sqrt{K_\mathrm{sp}};\qquad
\mathrm{Ag_2CrO_4:}\quad K_\mathrm{sp} = (2s)^2(s) = 4s^3\ \Rightarrow\ s = \sqrt[3]{K_\mathrm{sp}/4}$$

**例 3-5** 25 °C，$K_\mathrm{sp}(\mathrm{AgCl}) = 1.77\times10^{-10}$，$K_\mathrm{sp}(\mathrm{Ag_2CrO_4}) = 1.12\times10^{-12}$。求二者在纯水中的溶解度。

解：$s(\mathrm{AgCl}) = \sqrt{1.77\times10^{-10}} = 1.33\times10^{-5}~\mathrm{mol\cdot L^{-1}}$；
$s(\mathrm{Ag_2CrO_4}) = \sqrt[3]{1.12\times10^{-12}/4} = \sqrt[3]{2.8\times10^{-13}} = 6.5\times10^{-5}~\mathrm{mol\cdot L^{-1}}$。

量纲检查：$K_\mathrm{sp}$ 数值无量纲（活度积），$s$ 为 mol/L ✓。**注意悖论**：$\mathrm{Ag_2CrO_4}$ 的 $K_\mathrm{sp}$ 更小，溶解度反而更大——因为两种盐的离子数比不同，$K_\mathrm{sp}$ 不能跨类型直接比较"难溶程度"。

### 3.3.2 同离子效应

在含共同离子的溶液中溶解度被压低。设 AgCl 在 $0.010~\mathrm{mol\cdot L^{-1}}$ NaCl 中溶解度为 $s$，则 $[\mathrm{Ag^+}] = s$，$[\mathrm{Cl^-}] \approx 0.010$：

$$s = K_\mathrm{sp}/[\mathrm{Cl^-}] = \frac{1.77\times10^{-10}}{0.010} = 1.77\times10^{-8}~\mathrm{mol\cdot L^{-1}}$$

比纯水中低约 750 倍。应用：洗涤沉淀用"含少量沉淀剂的稀电解质溶液"而非纯水，抑制溶解损失；过量沉淀剂又不能太多（盐效应与配位溶解见下）。

### 3.3.3 盐效应

不含共同离子的强电解质反而**升高**溶解度。机理：离子强度 $I$ 增大使 $\gamma$ 变小（3.1.1 节），而 $K_\mathrm{sp}$ 是活度积——要维持活度积不变，浓度积 $[\mathrm{M^+}][\mathrm{X^-}] = K_\mathrm{sp}/(\gamma_+\gamma_-)$ 必须增大。对 AgCl 在 $0.010~\mathrm{mol\cdot L^{-1}}$ $\mathrm{KNO_3}$ 中：$I = 0.010$，$\lg\gamma = -0.509\sqrt{0.010} = -0.0509$，$\gamma = 0.889$，

$$s = \frac{\sqrt{K_\mathrm{sp}}}{\gamma} = \frac{1.33\times10^{-5}}{0.889} = 1.50\times10^{-5}~\mathrm{mol\cdot L^{-1}}$$

较纯水升高约 13%。**同离子效应与盐效应方向相反**；前者通常远强于后者，故过量沉淀剂仍以压低溶解度为主。

### 3.3.4 分步沉淀

混合离子溶液中滴加沉淀剂，**所需沉淀剂浓度最低者先沉淀**（比较 $Q$ 达到各自 $K_\mathrm{sp}$ 所需的 $[\mathrm{Ag^+}]$，而非比较 $K_\mathrm{sp}$ 大小——见 3.3.1 的悖论）。

**例 3-6** 溶液中 $\mathrm{Cl^-}$ 与 $\mathrm{I^-}$ 浓度均为 $0.010~\mathrm{mol\cdot L^{-1}}$，逐滴加入 $\mathrm{AgNO_3}$（$K_\mathrm{sp}(\mathrm{AgCl}) = 1.77\times10^{-10}$，$K_\mathrm{sp}(\mathrm{AgI}) = 8.52\times10^{-17}$）。

解：各自开始沉淀所需 $[\mathrm{Ag^+}]$：
$\mathrm{I^-}$：$8.52\times10^{-17}/0.010 = 8.5\times10^{-15}~\mathrm{mol\cdot L^{-1}}$；
$\mathrm{Cl^-}$：$1.77\times10^{-10}/0.010 = 1.8\times10^{-8}~\mathrm{mol\cdot L^{-1}}$。
$\mathrm{AgI}$ 需要的 $\mathrm{Ag^+}$ 低约 6 个数量级，**先沉淀**。当 $\mathrm{AgCl}$ 开始沉淀（$[\mathrm{Ag^+}] = 1.8\times10^{-8}$）时，

$$[\mathrm{I^-}] = \frac{8.52\times10^{-17}}{1.8\times10^{-8}} = 4.8\times10^{-9}~\mathrm{mol\cdot L^{-1}}$$

即 $\mathrm{I^-}$ 已沉淀 99.9995% 以上——二者可定量分离。这一逻辑推广为莫尔（Mohr）法滴定氯（以 $\mathrm{Ag_2CrO_4}$ 砖红色出现指示终点，利用的正是例 3-5 的溶解度差异），详见[模块三](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/)；练习 3-6 给出莫尔法的定量核算。

## 3.4 氧化还原平衡与电极电势

### 3.4.1 能斯特方程的推导

氧化还原反应的"束缚态/自由态"对比，就是**电子在氧化态与还原态之间的转移**。电化学把 Gibbs 能与电功联系起来：对可逆过程，体系 Gibbs 能的减少等于最大电功（推导见[模块四第 8 章](/xiaoshus-blog/textbooks/chemistry/04-physical/01/)，此处给出链条）：

$$\Delta_\mathrm{r}G = w_\text{电,max} = -nFE$$

$n$ 为转移电子数（无量纲），$F = 96485~\mathrm{C\cdot mol^{-1}}$ 为法拉第常数，$E$ 为可逆电池电动势（V）。代入 3.1.2 节的 $\Delta_\mathrm{r}G = \Delta_\mathrm{r}G^\ominus + RT\ln Q$：

$$-nFE = -nFE^\ominus + RT\ln Q
\quad\Longrightarrow\quad
E = E^\ominus - \frac{RT}{nF}\ln Q = E^\ominus - \frac{0.0592~\mathrm{V}}{n}\lg Q\ (25~\mathrm{^\circ C})$$

对半反应 $a\,\mathrm{Ox} + ne^- \rightleftharpoons b\,\mathrm{Red}$，$E$ 即该电对的电极电势：

$$\boxed{\ E = E^\ominus + \frac{0.0592~\mathrm{V}}{n}\lg\frac{a^a(\mathrm{Ox})}{a^b(\mathrm{Red})}\ }$$

量纲检查：0.0592 V 是 $2.303RT/F = (2.303\times8.314~\mathrm{J\cdot mol^{-1}\cdot K^{-1}}\times298.15~\mathrm{K})/(96485~\mathrm{C\cdot mol^{-1}})$，即 J/C = V ✓。$E$ 是**强度量**（不随电池大小改变），与 $\Delta_\mathrm{r}G$（广延量）的区别在于后者含 $n$。

### 3.4.2 三个标准应用

**（a）方向判断**：$E_\text{池} = E^\ominus_\text{正极} - E^\ominus_\text{负极} > 0$（或更一般地用非标准 $E$ 比较）反应自发。例如 $E^\ominus(\mathrm{Fe^{3+}/Fe^{2+}}) = +0.771~\mathrm{V} > E^\ominus(\mathrm{I_2/I^-}) = +0.535~\mathrm{V}$，故 $\mathrm{Fe^{3+}}$ 能氧化 $\mathrm{I^-}$。

**（b）浓度（电势）的调控**。设 $[\mathrm{Fe^{3+}}]/[\mathrm{Fe^{2+}}] = 10$：

$$E = 0.771~\mathrm{V} + 0.0592~\mathrm{V}\times\lg 10 = 0.830~\mathrm{V}$$

**（c）pH 调控**——含氧酸根的氧化性随酸度剧增。对 $\mathrm{O_2 + 4H^+ + 4e^- \rightleftharpoons 2H_2O}$（$E^\ominus = +1.229~\mathrm{V}$）：

$$E = 1.229~\mathrm{V} + \frac{0.0592~\mathrm{V}}{4}\lg\left([\mathrm{H^+}]^4\,p(\mathrm{O_2})\right) = 1.229~\mathrm{V} - 0.0592~\mathrm{V}\cdot\mathrm{pH} + \frac{0.0592~\mathrm{V}}{4}\lg p(\mathrm{O_2})$$

$p(\mathrm{O_2})$ 取标准值时 $E = 1.229 - 0.0592\,\mathrm{pH}$：pH 0 时 1.23 V，pH 7 时 0.815 V，pH 14 时 0.401 V。**同一条反应线在电势-pH 图（Pourbaix 图）上是一条斜线**——水的稳定窗口、金属腐蚀区/钝化区都由这类直线划定，为 3.11 节进阶内容埋设。

### 3.4.3 平衡常数与电势的换算

反应达平衡时 $Q = K$ 且 $E = 0$：

$$0 = E^\ominus - \frac{0.0592~\mathrm{V}}{n}\lg K
\quad\Longrightarrow\quad
\lg K = \frac{nE^\ominus}{0.0592~\mathrm{V}}\ (25~\mathrm{^\circ C})$$

这正是 3.1 节统一公式在电化学版本的体现（$E^\ominus = -\Delta_\mathrm{r}G^\ominus/nF$，代回 $\lg K = -\Delta_\mathrm{r}G^\ominus/5.708~\mathrm{kJ\cdot mol^{-1}}$ 自洽：$nE^\ominus\times96.485~\mathrm{kJ\cdot V^{-1}\cdot mol^{-1}} = -\Delta_\mathrm{r}G^\ominus$，$96.485\times0.0592 = 5.71$ ✓）。应用见练习 3-7。

### 3.4.4 元素电势图（Latimer 图）与歧化判据

把同一元素相邻氧化态的电势按氧化态从高到低排列，即 Latimer 图。锰在酸性介质（$a(\mathrm{H^+}) = 1$）：

$$\mathrm{MnO_4^-}\ \xrightarrow{\,0.564\,}\ \mathrm{MnO_4^{2-}}\ \xrightarrow{\,2.26\,}\ \mathrm{MnO_2}\ \xrightarrow{\,0.95\,}\ \mathrm{Mn^{3+}}\ \xrightarrow{\,1.51\,}\ \mathrm{Mn^{2+}}\ \xrightarrow{\,-1.18\,}\ \mathrm{Mn}$$

**（a）跨越式电势的加权计算**。电势是强度量，**不能直接平均**；必须经 $\Delta G^\ominus = -nFE^\ominus$ 线性叠加（$n$ = 各步转移电子数）。求 $E^\ominus(\mathrm{MnO_4^-}/\mathrm{MnO_2})$：$\mathrm{MnO_4^-}\to\mathrm{MnO_2}$ 转移 3 e⁻，路径分两步（1 e⁻ 与 2 e⁻）：

$$3F\times E^\ominus(\mathrm{MnO_4^-}/\mathrm{MnO_2}) = 1F\times0.564~\mathrm{V} + 2F\times2.26~\mathrm{V}
\ \Rightarrow\ E^\ominus = \frac{0.564 + 4.52}{3} = 1.69~\mathrm{V}$$

**（b）歧化判据**。设中间态 B 两侧电势为 $E^\ominus_\text{左}(\mathrm{A/B})$、$E^\ominus_\text{右}(\mathrm{B/C})$。歧化 $2\mathrm{B} \to \mathrm{A} + \mathrm{C}$ 的 $\Delta_\mathrm{r}G^\ominus$ = （A→B 的逆反应：$+nFE^\ominus_\text{左}$）+（B→C：$-nFE^\ominus_\text{右}$）$= nF(E^\ominus_\text{左} - E^\ominus_\text{右})$。故

$$\boxed{\ E^\ominus_\text{右} > E^\ominus_\text{左}\ \Longleftrightarrow\ \Delta_\mathrm{r}G^\ominus < 0\ \Longleftrightarrow\ \text{B 歧化自发}\ }$$

对 $\mathrm{MnO_4^{2-}}$：右 2.26 > 左 0.564，**在酸性条件下强烈歧化**（$3\mathrm{MnO_4^{2-}} + 4\mathrm{H^+} \to 2\mathrm{MnO_4^-} + \mathrm{MnO_2}\downarrow + 2\mathrm{H_2O}$）；对 $\mathrm{Mn^{3+}}$：右 1.51 > 左 0.95，同样歧化。歧化常数即 $\lg K = n(E^\ominus_\text{右}-E^\ominus_\text{左})/0.0592$（$\mathrm{Mn^{3+}}$ 歧化的定量计算见[第 4 章练习 4-5](/xiaoshus-blog/textbooks/chemistry/02-inorganic/02/)）。这也解释了绿色 $\mathrm{K_2MnO_4}$ 只能稳定存在于强碱中的实验事实——判据中的 $E^\ominus$ 值随 pH 改变（Nernst 项），碱性下 $\mathrm{MnO_4^{2-}}/\mathrm{MnO_2}$ 的电势降到 0.59 V 以下，歧化不再自发：**"稳定性"是介质条件的函数，不是物质的固有属性。**

## 3.5 配位平衡

### 3.5.1 稳定常数：逐级与累积

配离子生成是 Lewis 酸碱反应（金属离子 = 酸，配体 = 碱）。逐级稳定常数 $K_i$ 与累积稳定常数 $\beta_n$：

$$\mathrm{M + L \rightleftharpoons ML}\quad K_1;\qquad \mathrm{ML + L \rightleftharpoons ML_2}\quad K_2;\ \cdots$$
$$\mathrm{M + nL \rightleftharpoons ML_n}\quad \beta_n = K_1K_2\cdots K_n$$

（相加反应 → $\Delta G^\ominus$ 相加 → $K$ 相乘，3.2.3 节共轭关系同理。）各级 $K_i$ 一般递减（统计因子、空间位阻、电荷中和），但不单调的情形并不罕见。

**例 3-8（逐级/累积换算）** $\mathrm{Ag^+}$–$\mathrm{NH_3}$ 体系：$\lg K_1 = 3.24$，$\lg K_2 = 3.81$。则 $\lg\beta_2 = 3.24 + 3.81 = 7.05$，$\beta_2 = 1.1\times10^{7}$。逐级 $K_2 > K_1$ 反常于统计预期，源于 $\mathrm{[Ag(NH_3)]^+}$ 与 $\mathrm{[Ag(NH_3)_2]^+}$ 都是直线形二配位结构的重建（证据：X 射线晶体结构测得 N–Ag–N 近 180°）。

平均配位数（配体数）：

$$\bar n = \frac{c_\mathrm{L} - [\mathrm{L}]}{c_\mathrm{M}} = \frac{K_1[\mathrm{L}] + 2K_1K_2[\mathrm{L}]^2 + \cdots}{1 + K_1[\mathrm{L}] + K_1K_2[\mathrm{L}]^2 + \cdots}$$

（推导：分子是束缚配体的总浓度，分母是金属总浓度；各项即各配位形态的相对权重。）$\bar n$–$\mathrm{pL}$ 曲线可由电位滴定实验测得，再用[模块一第 1 章 1.5 节](/xiaoshus-blog/textbooks/chemistry/01-foundations/01/)的最小二乘法拟合出各级 $K_i$——稳定常数的"数据真实性"正是这样来的。

### 3.5.2 EDTA 与条件稳定常数

滴定剂 EDTA 是六齿配体 $\mathrm{H_4Y}$（溶液中以 $\mathrm{H_6Y^{2+}}$ 至 $\mathrm{Y^{4-}}$ 七种形态存在，$\mathrm{p}K_a$ = 0.90, 1.60, 2.07, 2.75, 6.24, 10.34），与多数金属形成 1:1 螯合物 $\mathrm{MY}$。绝对稳定常数只描述 $\mathrm{M^{n+} + Y^{4-}}$：

$$K(\mathrm{MY}) = \frac{[\mathrm{MY}]}{[\mathrm{M}][\mathrm{Y^{4-}}]}$$

（如 $\lg K(\mathrm{CaY}) = 10.69$，$\lg K(\mathrm{ZnY}) = 16.50$，$\lg K(\mathrm{FeY^-}) = 25.1$。）但实际 pH 下 $\mathrm{Y^{4-}}$ 只占总 EDTA 的一小部分——定义**酸效应系数**：

$$\alpha_{\mathrm{Y(H)}} = \frac{c_\mathrm{Y}}{[\mathrm{Y^{4-}}]} \ge 1,\qquad
\alpha_{\mathrm{Y(H)}} = 1 + \frac{[\mathrm{H^+}]}{K_{a6}} + \frac{[\mathrm{H^+}]^2}{K_{a6}K_{a5}} + \cdots$$

（推导与 3.2.4 分布分数完全同构：把 $\mathrm{Y^{4-}}$ 看作"碱"，各级质子化形态即"共轭酸"。）常用值：pH 5 时 $\lg\alpha_{\mathrm{Y(H)}} = 6.45$，pH 10 时 0.45，pH 12 时 0.01。**条件稳定常数**：

$$K'(\mathrm{MY}) = \frac{[\mathrm{MY}]}{[\mathrm{M}]\,c_\mathrm{Y}} = \frac{K(\mathrm{MY})}{\alpha_{\mathrm{Y(H)}}}\quad\Longrightarrow\quad
\lg K' = \lg K - \lg\alpha_{\mathrm{Y(H)}}$$

（金属无副反应时；若有，再乘金属副反应系数 $\alpha_\mathrm{M}$，逻辑相同。）

**例 3-9** 比较 pH 10 与 pH 5 时 $\mathrm{CaY}$ 的条件稳定常数。

解：pH 10：$\lg K' = 10.69 - 0.45 = 10.24$；pH 5：$\lg K' = 10.69 - 6.45 = 4.24$。

**结论**：同一鳌合物，酸度把有效稳定常数压低了 6 个数量级。滴定可行性判据为 $\lg(cK') \ge 6$（$c$ 为化学计量点时金属分析浓度；推导见[模块三](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/)）：$0.01~\mathrm{mol\cdot L^{-1}}$ 钙在 pH 10（$\lg cK' = 8.24$）可准确滴定，在 pH 5（$\lg cK' = 2.24$）不可。**"配位平衡独立于酸碱"是假象——四大平衡从来是联立的。**

## 3.6 四大平衡的耦合：竞争、转化与掩蔽

### 3.6.1 总平衡常数法

耦合反应 = 若干基元平衡的代数和：反应相加，$\Delta_\mathrm{r}G^\ominus$ 相加，故 $K$ **相乘**（相减则相除）。这是处理一切多重平衡的唯一需要的"新工具"。

**例 3-10（配位溶解）** 求 AgCl 在 $1.0~\mathrm{mol\cdot L^{-1}}$ 氨水中的溶解度（$K_\mathrm{sp} = 1.77\times10^{-10}$，$\beta_2[\mathrm{Ag(NH_3)_2^+}] = 1.1\times10^{7}$）。

总反应 $\mathrm{AgCl(s) + 2NH_3 \rightleftharpoons [Ag(NH_3)_2]^+ + Cl^-}$ 由"溶解"与"配位"两步相加而成：

$$K = K_\mathrm{sp}\times\beta_2 = 1.77\times10^{-10}\times1.1\times10^{7} = 1.95\times10^{-3}$$

设溶解度 $s$：$[\mathrm{Cl^-}] = s$，$[\mathrm{Ag(NH_3)_2^+}] = s$，自由 $[\mathrm{NH_3}] = 1.0 - 2s$：

$$\frac{s^2}{1.0 - 2s} = 1.95\times10^{-3}
\ \Rightarrow\ s^2 + 3.9\times10^{-3}s - 1.95\times10^{-3} = 0$$

$$s = \frac{-3.9\times10^{-3} + \sqrt{(3.9\times10^{-3})^2 + 4\times1.95\times10^{-3}}}{2} = 0.042~\mathrm{mol\cdot L^{-1}}$$

（解一元二次：判别式 $= 1.52\times10^{-5} + 7.80\times10^{-3} = 7.82\times10^{-3}$，$\sqrt{} = 0.0884$。）同法算 $\mathrm{AgI}$（$K_\mathrm{sp} = 8.52\times10^{-17}$）：$K = 9.4\times10^{-10}$，$s \approx \sqrt{9.4\times10^{-10}} = 3.1\times10^{-5}~\mathrm{mol\cdot L^{-1}}$，几乎不溶——**AgCl 溶于氨而 AgI 不溶**，是 $K_\mathrm{sp}$ 差 7 个数量级对 $K_\mathrm{total}$ 的胜利（完整推导见例题 3-3）。

### 3.6.2 沉淀转化

**例 3-11** $\mathrm{Ag_2CrO_4(s) + 2Cl^- \rightleftharpoons 2AgCl(s) + CrO_4^{2-}}$，由 $K_\mathrm{sp}(\mathrm{Ag_2CrO_4})/K_\mathrm{sp}(\mathrm{AgCl})^2$ 求总常数：

$$K = \frac{1.12\times10^{-12}}{(1.77\times10^{-10})^2} = \frac{1.12\times10^{-12}}{3.13\times10^{-20}} = 3.6\times10^{7}$$

$K$ 巨大：砖红色 $\mathrm{Ag_2CrO_4}$ 遇 $\mathrm{Cl^-}$ 定量转化为白色 AgCl。反方向转化（向更难溶者）总是容易的；"由难转易"则要靠配位或氧化还原"帮忙"。

### 3.6.3 掩蔽与解蔽

EDTA 滴定 $\mathrm{Zn^{2+}}$ 时共存 $\mathrm{Al^{3+}}$ 的干扰：加 $\mathrm{KF}$，$\mathrm{Al^{3+} + 6F^- \rightleftharpoons [AlF_6]^{3-}}$（$\lg\beta_6 \approx 19.8$，不同手册略有差异）。$[\mathrm{F^-}] = 0.01~\mathrm{mol\cdot L^{-1}}$ 时金属副反应系数 $\alpha_{\mathrm{Al(F)}} \approx \beta_6[\mathrm{F^-}]^6 = 6.9\times10^{19}\times10^{-12} = 6.9\times10^{7}$，游离 $\mathrm{Al^{3+}}$ 降至约 $1.4\times10^{-8}$ 倍总浓度——EDTA"看不见"铝了，而锌的氟配合物极弱不受影响。解蔽：加甲醛与 $\mathrm{[Zn(CN)_4]^{2-}}$ 释放 $\mathrm{Zn^{2+}}$（氰化物掩蔽-解蔽是经典但高毒操作，现代多用三乙醇胺、硫脲等替代掩蔽剂）。

### 3.6.4 氧化还原–沉淀/配位耦合

- **氧化把沉淀"拆掉"**：CuS 不溶于盐酸（$K_\mathrm{total} = K_\mathrm{sp}\cdot K_{a1}K_{a2}$ 太小），却溶于稀硝酸——因为 $\mathrm{S^{2-}}$ 被氧化为单质硫，把沉淀反应釜底抽薪：$3\mathrm{CuS} + 8\mathrm{HNO_3}(\text{稀}) \to 3\mathrm{Cu(NO_3)_2} + 3\mathrm{S}\downarrow + 2\mathrm{NO}\uparrow + 4\mathrm{H_2O}$。
- **配位压低电势**：$E^\ominus(\mathrm{Fe^{3+}/Fe^{2+}}) = 0.771~\mathrm{V}$，而 $E^\ominus([\mathrm{Fe(CN)_6}]^{3-}/[\mathrm{Fe(CN)_6}]^{4-}) = 0.36~\mathrm{V}$——强场配体 $\mathrm{CN^-}$ 改变了两个氧化态的相对稳定性，于是 $\mathrm{[Fe(CN)_6]^{3-}}$ 氧化 $\mathrm{I^-}$ 的能力远小于 $\mathrm{Fe^{3+}}$（这正是用 F⁻/CN⁻ 掩蔽 $\mathrm{Fe^{3+}}$ 后滴定 $\mathrm{Cu^{2+}}$ 或 $\mathrm{I^-}$ 的化学基础）。**任何一个 $K_\mathrm{sp}$、$\beta$ 都能被翻译成电势移动**：$E^\ominus(\mathrm{AgX/Ag}) = E^\ominus(\mathrm{Ag^+/Ag}) + 0.0592\lg K_\mathrm{sp}$（练习见第 4 章练习 4-6 的 Cu 版本）。

至此，四大平衡在"写总反应 → 乘总常数 → 比较 $Q$ 与 $K$"这一套操作下完全统一。

| 分布分数 | $\delta_1 = K_{a1}[\mathrm{H^+}]/D$ | 二元酸 | $\delta$ 只依赖 pH 不依赖 $c$ |
| 缓冲式 | $\mathrm{pH} = \mathrm{p}K_a + \lg\frac{n(\mathrm{A^-})}{n(\mathrm{HA})}$ | 两形态各 ≥10% | 用"摩尔比"不是"浓度差" |
| 缓冲容量 | $\beta = \frac{2.303cK_a[\mathrm{H^+}]}{(K_a+[\mathrm{H^+}])^2}$ | 共轭对体系 | $\beta_\mathrm{max} = 0.576c$ 在 $\mathrm{pH}=\mathrm{p}K_a$ |
| 溶度积换算 | $\mathrm{M_2X}$：$s = \sqrt[3]{K_\mathrm{sp}/4}$ | 无副反应 | $K_\mathrm{sp}$ 跨类型不可直接比大小 |
| 能斯特 | $E = E^\ominus + \frac{0.0592}{n}\lg\frac{a(\mathrm{Ox})}{a(\mathrm{Red})}$ | 25 °C | $n$ 是电子数；纯固体、纯水不写入 |
| 电势→$K$ | $\lg K = nE^\ominus/0.0592$ | 25 °C | 用电池 $E^\ominus$（两电对之差） |
| 电势图加权 | $n_3E_{13} = n_1E_{12} + n_2E_{23}$ | 同元素同介质 | 电势不可直接算术平均 |
| 歧化判据 | $E^\ominus_\text{右} > E^\ominus_\text{左}$ ⇔ 歧化自发 | 相邻三态同介质 | 左右勿倒置 |
| 条件稳定常数 | $\lg K' = \lg K - \lg\alpha_{\mathrm{Y(H)}}$ | 金属无副反应 | $\alpha$ 随 pH 剧变 |
| 总平衡常数法 | 反应相加 → $K$ 相乘 | 一切多重平衡 | 相减时除不要减 |

## 3.8 典型例题与解题思路

### 例题 3-1（基础计算）弱酸的精确处理：$0.050~\mathrm{mol\cdot L^{-1}}$ HF

**题**：$K_a(\mathrm{HF}) = 6.8\times10^{-4}$。求 pH，并比较最简式误差。

**思路**：先查判据——判据不过关，就必须回到精确式，这正是本例的教学点。

**解**：$c/K_a = 0.050/6.8\times10^{-4} = 73.5 < 500$（解离度将超过 10%），$cK_a = 3.4\times10^{-5} \gg 20K_\mathrm{w}$（水的电离仍可忽略）。取二次近似式 $[\mathrm{H^+}]^2 + K_a[\mathrm{H^+}] - K_ac = 0$：

$$[\mathrm{H^+}] = \frac{-K_a + \sqrt{K_a^2 + 4K_ac}}{2} = \frac{-6.8\times10^{-4} + \sqrt{4.62\times10^{-7} + 1.36\times10^{-4}}}{2}$$

$$= \frac{-6.8\times10^{-4} + 0.01168}{2} = 5.50\times10^{-3}~\mathrm{mol\cdot L^{-1}},\qquad \mathrm{pH} = 2.26$$

最简式给 $\sqrt{3.4\times10^{-5}} = 5.83\times10^{-3}$（pH 2.23），$[\mathrm{H^+}]$ 偏高约 6%——对 $\mathrm{pH}$ 只有 0.03 的差别，但对依赖 $[\mathrm{A^-}]/[\mathrm{HA}]$ 比的后续计算（如缓冲、滴定曲线）可能致命。解离度 $\alpha = 5.50\times10^{-3}/0.050 = 11\%$，验证了"判据 < 500 必须精确"的预判。量纲检查：根号内各项均为 $(\mathrm{mol\cdot L^{-1}})^2$ ✓。

### 例题 3-2（综合应用）氢氧化物沉淀法分离 $\mathrm{Fe^{3+}}$ 与 $\mathrm{Mg^{2+}}$

**题**：溶液含 $\mathrm{Fe^{3+}}$、$\mathrm{Mg^{2+}}$ 各 $0.010~\mathrm{mol\cdot L^{-1}}$。$K_\mathrm{sp}[\mathrm{Fe(OH)_3}] = 2.79\times10^{-39}$，$K_\mathrm{sp}[\mathrm{Mg(OH)_2}] = 5.61\times10^{-12}$。求把 $\mathrm{Fe^{3+}}$ 沉淀完全（残留 $< 1.0\times10^{-5}~\mathrm{mol\cdot L^{-1}}$）而 $\mathrm{Mg^{2+}}$ 不沉淀的 pH 范围。

**思路**：沉淀"开始"与"完全"都翻译为临界 $[\mathrm{OH^-}]$，再由 $\mathrm{pOH} = -\lg[\mathrm{OH^-}]$ 转 pH。

**解**：

Fe(OH)₃ 开始沉淀：$[\mathrm{OH^-}] = \sqrt[3]{K_\mathrm{sp}/c} = \sqrt[3]{2.79\times10^{-39}/0.010} = \sqrt[3]{2.79\times10^{-37}} = 6.5\times10^{-13}~\mathrm{mol\cdot L^{-1}}$（$\mathrm{pOH} = 12.19$，pH 1.81）。

Fe(OH)₃ 沉淀完全（残留 $10^{-5}$）：$[\mathrm{OH^-}] = \sqrt[3]{2.79\times10^{-39}/1.0\times10^{-5}} = \sqrt[3]{2.79\times10^{-34}} = 6.5\times10^{-12}~\mathrm{mol\cdot L^{-1}}$（pH 2.82）。

Mg(OH)₂ 开始沉淀：$[\mathrm{OH^-}] = \sqrt{K_\mathrm{sp}/c} = \sqrt{5.61\times10^{-12}/0.010} = \sqrt{5.61\times10^{-10}} = 2.4\times10^{-5}~\mathrm{mol\cdot L^{-1}}$（$\mathrm{pOH} = 4.63$，pH 9.37）。

**结论**：控制 pH 在约 **2.9 ~ 9.3** 之间（实践中用 NH₄Cl–NH₃ 缓冲液调至 pH ≈ 5–8，并注意 $\mathrm{Fe^{3+}}$ 强烈水解本身就会沉淀），$\mathrm{Fe^{3+}}$ 完全沉淀而 $\mathrm{Mg^{2+}}$ 留在溶液。量纲检查：$K_\mathrm{sp}$ 与浓度之商开三次/二次方，单位 mol/L ✓。**思路要点**：两类离子分属不同"价型"（3:1 与 2:1），$[\mathrm{OH^-}]$ 的幂次不同，这正是 $K_\mathrm{sp}$ 数值悬殊（差 27 个数量级）之外，分离之所以可操作的原因。

### 例题 3-3（拓展）耦合平衡的完整分析：AgCl 与 AgI 在氨水中的溶解

**题**：计算 AgCl 与 AgI 在 $1.0~\mathrm{mol\cdot L^{-1}}$ 氨水中的溶解度（数据：$K_\mathrm{sp}(\mathrm{AgCl}) = 1.77\times10^{-10}$，$K_\mathrm{sp}(\mathrm{AgI}) = 8.52\times10^{-17}$，$\beta_2 = 1.1\times10^{7}$），并从热力学上解释定性事实"AgCl 溶于氨水，AgI 不溶"。

**思路**：写出总反应 → 乘总常数 → 对"配体消耗"做质量平衡，得到一元二次方程。

**解**：总反应 $\mathrm{AgX(s) + 2NH_3 \rightleftharpoons [Ag(NH_3)_2]^+ + X^-}$，$K = K_\mathrm{sp}\beta_2$。

AgCl：$K = 1.95\times10^{-3}$，$s = 0.042~\mathrm{mol\cdot L^{-1}}$（见 3.6.1 例 3-10 的完整二次方程求解）。

AgI：$K = 8.52\times10^{-17}\times1.1\times10^{7} = 9.4\times10^{-10}$。设溶解度 $s$，$\frac{s^2}{1.0-2s} = 9.4\times10^{-10}$。因 $s \ll 1$，分母取 1.0（相对误差 $< 0.01\%$）：

$$s \approx \sqrt{9.4\times10^{-10}} = 3.1\times10^{-5}~\mathrm{mol\cdot L^{-1}}$$

**热力学解释**：配位溶解的净推动力是两步 $\Delta_\mathrm{r}G^\ominus$ 的代数和。AgCl 的"晶格–水化账"（$K_\mathrm{sp} = 1.77\times10^{-10}$ 对应 $\Delta_\mathrm{r}G^\ominus_\text{溶解} = -RT\ln K_\mathrm{sp} = +55.6~\mathrm{kJ\cdot mol^{-1}}$）被氨配位的"存款"（$\beta_2 = 1.1\times10^{7}$ 对应 $-40.2~\mathrm{kJ\cdot mol^{-1}}$）补偿后，**标准条件下仍余 $+15.4~\mathrm{kJ\cdot mol^{-1}}$（即 $K = 1.95\times10^{-3} < 1$）**——所以 AgCl 只是"溶解得可观"（$s = 0.042~\mathrm{mol\cdot L^{-1}}$，平衡时 $Q = s^2/(1-2s) = K$，产物远未达标准态），并非热力学上"完全敞开"。对 AgI（$K_\mathrm{sp} = 8.52\times10^{-17}$，溶解账 $+91.7~\mathrm{kJ\cdot mol^{-1}}$）：净 $\Delta_\mathrm{r}G^\ominus = +51.5~\mathrm{kJ\cdot mol^{-1}}$，$K = 9.4\times10^{-10}$，$s \approx 3.1\times10^{-5}~\mathrm{mol\cdot L^{-1}}$，几乎不溶。**同一份配位"存款"（$-40~\mathrm{kJ\cdot mol^{-1}}$）能否撬动沉淀，取决于晶格账单的厚薄**——这就是"AgCl 溶于氨水、AgI 不溶"这一经典鉴别实验的全部热力学内容。量纲检查：$s$ 单位 mol/L；$\Delta G$ 由 $K$（纯数）经 $RT$ 换算为 kJ/mol ✓。

## 3.9 常见误区与易错点

1. **"$K_\mathrm{sp}$ 小的先沉淀"**。错。分步沉淀比较的是达到各 $K_\mathrm{sp}$ 所需沉淀剂浓度（例 3-5、3-6：$K_\mathrm{sp}$ 更小的 $\mathrm{Ag_2CrO_4}$ 反而后沉淀）。只有当被沉淀离子浓度相同时比较才有间接意义，且仍受价型影响。
2. **最简式 $\sqrt{K_ac}$ 无判据套用**。$c/K_a < 500$ 或 $c < 10^{-6}~\mathrm{mol\cdot L^{-1}}$ 时必须回到精确式（例题 3-1 与练习 3-1 分别是两类失效）。
3. **电势直接算术平均**。Latimer 图跨越求电势必须按 $nE$ 加权（$n$ = 电子数），因为 $E$ 是强度量而 $-nFE$ 才是可加的 Gibbs 能。
4. **Nernst 方程把纯固体、溶剂写入 $Q$**。$\mathrm{Zn(s)}$、$\mathrm{H_2O}$ 活度为 1，不出现；但 $\mathrm{H^+}$、$\mathrm{OH^-}$ 必须写——含氧酸根电对漏写 $[\mathrm{H^+}]^m$ 是最高频错误。
5. **把 $\beta_n$ 当 $K_n$ 用**。累积与逐级差一个连乘；EDTA 条件常数是 $\lg K - \lg\alpha$（除法→对数减法），不是相加。
6. **"$\Delta G^\ominus$ 负就一定能观察到反应"**。$K$ 只回答"终态在哪儿"；速率由动力学决定（例 3-1 的合成氨、SiCl₄ 与 CCl₄ 水解的对照）。
