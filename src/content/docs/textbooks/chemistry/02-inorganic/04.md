# 模块二·进阶章 2　固体化学与缺陷（研究生进阶）

> **本章定位**：模块二第二进阶章。**本科章已建立的**：晶体场/配位场（[第 4 章 4.6 节](/xiaoshus-blog/textbooks/chemistry/02-inorganic/02/)）、晶体结构基元与配位多面体（[第 4 章 4.5 节](/xiaoshus-blog/textbooks/chemistry/02-inorganic/02/)）、四大平衡与离子平衡（[第 3 章 3.4 节](/xiaoshus-blog/textbooks/chemistry/02-inorganic/01/)）、热力学的 $G$ 与活度（[模块四（热力学）](/xiaoshus-blog/textbooks/chemistry/04-physical/01/)）。**本章在何处加深**：把"完美晶体"升级为含**缺陷（defect）**的真实固体——只有缺陷才让固体导电、发光、催化、扩散、变色。建立点缺陷四种（空位/间隙/杂质/反占位）与线/面/体缺陷的统一语言，用**缺陷化学（Kröger–Vink 符号 + 质量作用）**定量处理掺杂与电中性，并把晶体学（点群/空间群）延伸到固体的对称性与相变。前置：[第 3 章 3.4 节](/xiaoshus-blog/textbooks/chemistry/02-inorganic/01/)离子平衡；与[模块一·进阶章 1](/xiaoshus-blog/textbooks/chemistry/01-foundations/03/)（随机过程：缺陷浓度的统计来源）平行推进。前向：[模块三（分析化学）](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/)的 XRD/电子显微与 XAS、[模块四（热力学）](/xiaoshus-blog/textbooks/chemistry/04-physical/01/)的相图与相变、[模块五](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/01/)的能带。

## 2.0 本章学习目标

学完本章，你应当能够：

1. 用点/线/面/体缺陷分类描述真实固体的"不完美"，并指出每种缺陷的物理后果。
2. 用 Kröger–Vink 符号写出点缺陷，写出缺陷反应并强制满足**物质守恒、电荷守恒、晶格位点守恒**三条件。
3. 对 Schottky、Frenkel、本征/ extrinsic 电离三类点缺陷写出质量作用关系，推导出电子浓度 $n$、空穴浓度 $p$ 与缺陷浓度的 $T$ 依赖（及掺杂如何令一个自由度"冻结"）。
4. 用缺陷化学解释掺杂半导体的 n/p 行为、离子晶体的色心（F 心）与离子电导。
5. 读懂简单空间群（点阵类型 + 对称元素 + 等效位置），把晶体对称性联系到物理对称性（铁电/铁磁的对称破缺）。
6. 说明非整比化合物（non-stoichiometry）的缺陷来源与其对颜色的物理影响。

## 2.1 真实固体是"有缺陷的"

### 2.1.1 从完美晶体到真实晶体

本科章的 NaCl、CsCl、萤石、钙钛矿都是**理想周期结构**——原子无无限重复、无错漏。但真实固体几乎总有偏离：没有一克 NaCl 是严格 1:1 的；没有一块单晶硅没有位错；没有一种氧化物陶瓷没有晶界。**关键认知转变**：缺陷不是"次品"，而是**固体功能性的来源**（与[模块一·进阶章 1](/xiaoshus-blog/textbooks/chemistry/01-foundations/03/)里"涨落是物理"同一哲学）。下表即全章地图：

| 缺陷类型 | 例子 | 物理后果 |
|---|---|---|
| 点缺陷（0 维） | 空位、间隙原子、替位杂质、反占位（反结构） | 扩散、离子电导、色心、半导体、催化活性位 |
| 线缺陷（1 维） | 位错（刃型/螺型） | 塑性、强度、晶体生长、X 射线形貌衬度 |
| 面缺陷（2 维） | 晶界、相界、堆垛层错、表面 | 晶界扩散、烧结、腐蚀、多晶性能 |
| 体缺陷（3 维） | 析出相、孔洞、孪晶 | 断裂、密度、复合中心 |

**点缺陷浓度从何来**：在温度 $T$ 下，形成一个缺陷需要能量 $E_f$，体系在"缺陷带来的构型熵"与"形成能代价"之间取极值（[模块一·进阶章 1](/xiaoshus-blog/textbooks/chemistry/01-foundations/03/)的涨落–热力学）。浓度 $c \sim e^{-E_f/k_{\mathrm B}T}$——**缺陷是热平衡的产物**，这也是为什么"退火除缺陷"有效（降温冻结平衡态）。

### 2.1.2 点缺陷的四种基本类型

- **空位（vacancy）**：晶格点本应有原子而空缺。金属中称肖特基型空位；化合物中常成对出现（阴离子+阳离子同缺）以维持计量。
- **间隙（interstitial）**：原子挤入晶格间隙位。半径小的原子（H、C、N、Li⁺）易成间隙；金属中称弗伦克尔型（空位+间隙对）。
- **杂质/替位（substitutional impurity）**：外来原子占晶格点位（Ga 替 Si、Mg 替 Al₂O₃ 中的 Al）——**掺杂**的核心。
- **反占位（antisite）**：化合物中 A 占 B 位、B 占 A 位（GaAs 中的 Ga₍As₎、As₍Ga₎）——化合物特有的点缺陷。

**计量 vs 非整比**：严格计量化合物（如 NaCl）缺陷是热平衡的"少数派"；**非整比化合物**（如 $\mathrm{Fe_{1-x}O}$、$\mathrm{WO_{3-x}}$、$\mathrm{TiO_{2-x}}$）靠大量点缺陷维持电荷平衡，**本身就是缺陷工程**：$\mathrm{Fe_{1-x}O}$ 中铁缺位使部分 $\mathrm{Fe^{2+} \to Fe^{3+}}$ 补偿电荷，颜色随 $x$ 由黑绿变墨黑——缺陷改色是固体化学的常见事。

## 2.2 缺陷化学语言：Kröger–Vink 符号

### 2.2.1 符号定义与三守恒

用一套记号精确写"哪个点、什么缺陷、带什么有效电荷"：

| 记号 | 含义 |
|---|---|
| $\mathrm{V_A}$ | A 点位空位（A 缺失） |
| $\mathrm{A_i}$ | A 原子在间隙位 |
| $\mathrm{B_A}$ | B 占 A 位（替位/反占位） |
| $\cdot$（点） | 相对晶格带 **+1** 有效电荷 |
| $'$（撇） | 相对晶格带 **−1** 有效电荷 |
| $\times$（叉） | 有效电荷中性 |
| $e'$（电子）、$h^\cdot$（空穴） | 导带电子 / 价带空穴 |

"有效电荷"是**相对完美晶格**的电荷（如 $\mathrm{Ca^{2+}}$ 占 $\mathrm{Zr^{4+}}$ 位 ⇒ $\mathrm{Ca_{Zr}''}$，因少 +2 电荷 ↔ 净 −2 有效电荷）。

**写缺陷反应的三守恒**（每条反应必须逐项满足，否则无意义）：
1. **晶格位点守恒**：左/右两侧各亚晶格的点位数相等（如 MX 化合物，M 位总数 = X 位总数）；
2. **电荷守恒**：所有有效电荷代数和为零；
3. **物质守恒**：每种原子/电子的净数守恒（可用 $\mathrm{V_M}$、$\mathrm{O_O^\times}$ 等显式书写）。

### 2.2.2 三类标准点缺陷反应

**① Schottky 缺陷（成对外缺，维持计量）**——以 MX 化合物（NaCl 型）为例：

$$\mathrm{null} \rightleftharpoons \mathrm{V_M'} + \mathrm{V_X^\cdot} \quad(\text{同缺一个 M\text{、一个 X}})$$

（电荷：−1 + +1 = 0 ✓；位点：M 位、X 位各缺一个 ✓。）

**② Frenkel 缺陷（自体错位：空位 + 间隙对）**——以 AgBr（Ag⁺ 间隙易）为例：

$$\mathrm{Ag_{Ag}^\times} \rightleftharpoons \mathrm{V_{Ag}'} + \mathrm{Ag_i^\cdot}$$

（Ag 总数守恒：晶格中少一个、间隙多一个 ✓；电荷：−1 + +1 = 0 ✓。）

**③ 本征电离（热激发电子–空穴对）**——以氧化物（以 O 位为参考晶格）：

$$\mathrm{null} \rightleftharpoons e' + h^\cdot$$

（导带电子 + 价带空穴；是"完美晶格"也能发生的内禀激发，区别于掺杂。）

**④ 掺杂 / 非整比**（以 $\mathrm{ZrO_2}$ 掺 $\mathrm{Y_2O_3}$ 稳定立方相， hallmark 的氧离子导体）为例：

$$2\,\mathrm{Y_2O_3} \xrightarrow{\text{进 }\mathrm{ZrO_2}} 2\,\mathrm{Y_{Zr}^\cdot} + 3\,\mathrm{O_O^\times} + \mathrm{V_O^{\cdot\cdot}} + \mathrm{ZrO_2}$$

（每加 2 个 $\mathrm{Y^{3+}}$ 替 2 个 $\mathrm{Zr^{4+}}$：电荷缺 2+ ⇒ 必须生成 1 个 $\mathrm{V_O^{\cdot\cdot}}$（氧空位带 +2 有效电荷）补偿 ✓；位点：2 Zr 位被 Y 占、1 O 位空缺 ✓。这个 $\mathrm{V_O^{\cdot\cdot}}$ 就是氧离子导体传导的通道——YSZ（yttria-stabilized zirconia）的固态电解质原理。）

**电中性条件**（全局必须成立，所有缺陷反应叠加后强制）：

$$\sum(\text{正有效电荷}) = \sum(\text{负有效电荷})$$

这是缺陷化学求解的"联立方程右端"——下面用它把 $n, p$ 与掺杂浓度关起来。

## 2.3 缺陷平衡与质量作用：把浓度算出来

### 2.3.1 本征缺陷的质量作用

对本征电离（2.2.2③）：$K_i = n p = N_c N_v e^{-E_g/k_{\mathrm B}T}$（$n = [e']$、$p = [h^\cdot]$、$E_g$ 带隙；[模块五](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/01/)能带）。本征时 $n = p = \sqrt{K_i}$（电中性）。

对 Schottky（2.1.2①）：$K_s = [\mathrm{V_M'}][\mathrm{V_X^\cdot}]$。若两种空位浓度相等（对称生成）：$[\mathrm{V_M'}] = [\mathrm{V_X^\cdot}] = \sqrt{K_s} \propto e^{-E_s/2k_{\mathrm B}T}$（$E_s$ 为形成一个空位对的形成能；指数上的 1/2 来自"成对"）。

对 Frenkel（2.2.2②）：$K_f = [\mathrm{V_{Ag}'}][\mathrm{Ag_i^\cdot}]$（电荷平衡使二者相等）。

**温度依赖的统一读法**：缺陷浓度随 $T$ 升高指数上升——退火（缓慢冷却）让体系停在高温平衡的低缺陷态；淬火则"冻结"高温缺陷。

### 2.3.2 掺杂如何"冻结"一个自由度（n/p 半导体）

以 Si 掺 P（五价替四价）为例：P 给出多余电子 $\mathrm{P_{Si}^\cdot} + e'$（施主，donor）。电中性：

$$n = [e'] = [\mathrm{P_{Si}^\cdot}] + p \approx N_D + p$$

（设本征激发 $p = K_i/n \ll N_D$，即 $N_D \gg \sqrt{K_i}$——掺杂足够浓时成立。）

于是 **$n \approx N_D$ 几乎不随 $T$ 变**（被掺杂"钉死"），而本征激发 $p = K_i/n$ 随 $T$ 仍指数上升——作图 $\ln n$ vs $1/T$：低温平台区 $n \approx N_D$（extrinsic），高温回升区进入本征（$n \to \sqrt{K_i}$）。**这就是"掺杂把自由度冻结"的物理**：本征半导体只有一个可变的载流子对，掺杂强时电子浓度被施主数决定、空穴成从属变量。掺 B（三价，受主 acceptor）则 $p \approx N_A$、n 为从属——n 型/p 型由此分工。

### 2.3.3 离子电导与色心

**离子电导**：只靠点缺陷的迁移（空位/间隙"走位"）。Nernst–Einstein 关系把离子电导率 $\sigma_i$ 与扩散系数 $D$ 连起来（与[模块一·进阶章 1](/xiaoshus-blog/textbooks/chemistry/01-foundations/03/)的 Green–Kubo/Einstein 关系同源）：

$$\sigma_i = \frac{n_i q^2}{k_{\mathrm B}T} D$$

（YSZ 的 $\mathrm{V_O^{\cdot\cdot}}$ 在 800–1000 °C 大量迁移 → 氧离子导体，是固体氧化物燃料电池 SOFC 的电解质。）

**色心（color center）**：带电子的阴离子空位吸收可见光子 → 晶体着色。典型 **F 心**（$F$ = German *Farbe*）：碱卤化物中 $\mathrm{V_X^\cdot}$ 俘获一个电子 $\mathrm{V_X^\cdot} + e' \to \mathrm{V_X^\times}$（中性的"电子陷于空位"），其束缚电子能级落在带隙、吸收可见光——NaCl 被 Na 蒸气处理（"加碱金属蒸汽"）后变黄/棕。是缺陷吸收光谱的招牌现象（[模块三](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/)的 UV-Vis 与电子顺磁共振 EPR 可证）。

## 2.4 线缺陷：位错

### 2.4.1 刃型与螺型位错

**刃型位错（edge dislocation）**：在滑移面之上插入"半原子面"，位错线沿半面边缘。Burgers 矢量 $\mathbf b$ **垂直**于位错线。物理：滑移 = 半原子面"逐级推进"，应力远低于整体剪切——**塑性形变的载体**（[第 4 章 4.5 节](/xiaoshus-blog/textbooks/chemistry/02-inorganic/02/)的密堆积与滑移系在此具体化）。

**螺型位错（screw dislocation）**：原子面绕位错线呈螺旋阶梯，Burgers 矢量**平行**于位错线。晶体生长时螺旋位错提供"永不消失的台阶"——让蒸气/溶液分子持续堆积（螺旋位错是晶体生长速率从"二维成核"瓶颈解放的关键；这也是为什么完美晶面长得慢、有位错的快）。

### 2.4.2 位错的物理后果

- **强度**：位错密度↑ ⇒ 材料更硬（加工硬化：位错互相缠结，滑移更难；反之退火减少位错降硬度）。
- **扩散与烧结**：沿位错管扩散比体扩散快几个数量级；晶界+位错是陶瓷烧结的快道。
- **X 射线形貌/电子显微**：位错处应变场使衍射衬度，TEM 可直接"看见"单根位错（与[模块三](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/)的电子衍射成像衔接）。

## 2.5 面缺陷与体缺陷：晶界、相界、表面

### 2.5.1 晶界与多晶

多晶材料中晶粒之间的界面（晶界）是 5 个自由度（2 旋转 + 3 界面取向）的"错位面"。**高能晶界**是快扩散、腐蚀、沉淀偏聚的通道；**孪晶界**（镜面对称）能量低、几乎不阻碍性能。晶界工程（GB engineering）通过控制织构优化力学/电学——是结构陶瓷与高温超导带材的工艺核心。

### 2.5.2 表面：最特殊的"缺陷"

表面原子配位数不足（[第 4 章 4.5 节](/xiaoshus-blog/textbooks/chemistry/02-inorganic/02/)的配位多面体在表面被"砍半"）→ 悬键、高表面能 → **催化活性位**与吸附中心。表面重构（surface reconstruction）是表面为降能而自发的对称破缺——要理解催化剂，必先理解其表面（[03-进阶](/xiaoshus-blog/textbooks/chemistry/02-inorganic/03/)的均相活性位点 ↔ 表面的异相活性位的对照）。

### 2.5.3 体缺陷

析出相（第二相粒子）、气孔、孪晶、包裹体——影响断裂韧性、密度、光学透明与电学复合（半导体中的体缺陷是载流子"陷阱"）。透明陶瓷（如 YAG）要极低压气孔率正是为消除体缺陷的散射。

## 2.6 晶体对称性与空间群基础

### 2.6.1 点群回顾与空间群

本科章已用点群描述分子对称（[第 4 章 4.6 节](/xiaoshus-blog/textbooks/chemistry/02-inorganic/02/)）。**固体加一个点阵（平移对称）** ⇒ 7 个晶系 × 14 种 Bravais 点阵 × 230 个空间群。空间群的记号（Hermann–Mauguin）：

$$\text{点阵类型（P/I/F/R/C）} + \text{对称元素沿晶轴方向}$$

例：$\mathrm{NaCl}$ 为 $Fm\bar{3}m$（$F$ = 面心；$\bar{3}$ = 三次反演轴沿体对角线；$m$ = 镜面）；$\mathrm{CsCl}$ 为 $Pm\bar{3}m$；$ZrO_2$ 单斜相为 $P2_1/c$。空间群告诉你**哪些原子位置等效、哪些对称操作禁阻某个跃迁/偶极**——晶体对称性是理解固体物理性质的钥匙。

### 2.6.2 对称破缺与铁性

**铁电 / 铁磁 / 铁弹**都源于**对称破缺**：高温高对称相（顺电相，有对称中心）→ 降温穿过相变温度后自发极化/磁化/应变，失去对称中心（如 $\mathrm{BaTiO_3}$ 的钙钛矿在 120 °C 以上立方顺电、以下四方铁电）。**对称性决定可否有自发极化**（无对称中心是铁电的必要条件，居里原理）。相变点（Curie 温度）是热容/介电异常处——与[模块四（热力学）](/xiaoshus-blog/textbooks/chemistry/04-physical/01/)的二级相变（序参量连续、比热跳变）直接衔接（模块四进阶章会给出 Landau 理论的完整展开）。

## 2.7 非整比化合物与缺陷工程实例

### 2.7.1 非整比的来源

非整比 $\mathrm{A_{1-x}B}$、 $\mathrm{AB_{1-x}}$、$\mathrm{AB_{1\pm x}}$ 的稳定存在，本质是**靠点缺陷维持电中性**：
- $\mathrm{Fe_{1-x}O}$（方铁矿，wüstite）：Fe 缺位 ⇒ 部分 $\mathrm{Fe^{2+} \to Fe^{3+}}$（电荷补偿）；$x$ 可达 0.05–0.15；$x$ 越大颜色越深（Fe³⁺ 的电荷转移吸收）。
- $\mathrm{WO_{3-x}}$、$\mathrm{TiO_{2-x}}$（Magnéli 相）：氧空位有序化形成剪切结构，金属价态混合（W⁵⁺/W⁶⁺）→ 蓝色/青铜色，且变导电。
- $\mathrm{UO_{2+x}}$：间隙氧致非整比。

**物理后果系统**：非整比 ⇒ 混合价 ⇒ 电子跳跃导电（small polaron）、颜色、催化活性。 defect 浓度可设计（气氛/温度控制），就把"缺陷"变成了"材料参数"。

### 2.7.2 缺陷工程实例（串讲）

| 材料 | 关键缺陷 | 功能 |
|---|---|---|
| YSZ（$\mathrm{Y_2O_3}$ 稳 $\mathrm{ZrO_2}$） | $\mathrm{V_O^{\cdot\cdot}}$（氧空位） | 氧离子导体（SOFC 电解质） |
| $\mathrm{Li_xCoO_2}$（正极） | $\mathrm{Li^+}$ 空位/间隙 | 锂离子嵌入脱出（电池） |
| n-Si / p-Si | 施主/受主 | 半导体（2.3.2） |
| NaCl∶Na | F 心（$\mathrm{V_{Cl}^\times}$） | 色心、辐射剂量计 |
| $\mathrm{Fe_{1-x}O}$ | Fe 缺位 + Fe³⁺ | 非整比、变色、催化 |
| $\mathrm{SrTiO_3\colon Nb}$ | $\mathrm{Nb_{Ti}^\cdot}$ 施主 | n 型透明导电氧化物 |

## 2.8 关键公式与方程速查

| 名称 | 表达式 | 适用条件 | 易错点 |
|---|---|---|---|
| 缺陷浓度（热平衡） | $c \sim e^{-E_f/k_{\mathrm B}T}$ | 点缺陷、平衡 | 退火≠"无缺陷"，是冻结高温平衡 |
| Schottky 平衡 | $K_s = [\mathrm{V_M'}][\mathrm{V_X^\cdot}]$ | 计量化合物 | 成对生成 ⇒ $\sqrt{K_s}$ |
| Frenkel 平衡 | $K_f = [\mathrm{V_{Ag}'}][\mathrm{Ag_i^\cdot}]$ | 可间隙原子 | 缺陷总数守恒 |
| 本征电离 | $K_i = np = N_c N_v e^{-E_g/kT}$ | 本征半导体 | 本征时 $n = p = \sqrt{K_i}$ |
| 电中性 | $\sum q_+ = \sum q_-$ | 全局 | 所有缺陷反应叠加后强制 |
| 掺杂冻结 | $n \approx N_D$（$N_D \gg \sqrt{K_i}$） | n 型，浓掺 | 空穴 $p = K_i/n$ 仍随 $T$ 变 |
| Nernst–Einstein | $\sigma_i = \frac{n_i q^2}{k_{\mathrm B}T}D$ | 离子导体 | 与 Fick 扩散同根 |
| 有效电荷 | 相对完美晶格的净电荷 | Kröger–Vink | 不是原子的形式电荷 |

## 2.9 典型例题与解题思路

### 例题 2-1（基础计算）YSZ 掺杂的缺陷反应与氧空位浓度

**题**：把 $\mathrm{Y_2O_3}$（摩尔分数 $y = 0.10$）掺入 $\mathrm{ZrO_2}$，假设全部 $\mathrm{Y^{3+}}$ 替代 $\mathrm{Zr^{4+}}$ 并形成氧空位（2.2.2④）。（i）写缺陷反应并校验三守恒；（ii）若晶格中 Zr + Y 位点总数为 1，求氧空位浓度 $[\mathrm{V_O^{\cdot\cdot}}]$（小数，按阳离子位点计）；（iii）说明为什么这使它成为氧离子导体。

**解题思路**：先写反应校验三守恒 → 用化学计量关系（每 2 个 Y 产生 1 个氧空位）算浓度 → 联系 Nernst–Einstein。

**解**：（i）反应（在 ZrO₂ 基体中，以 1 个 ZrO₂ 公式单元为基准）：

$$2\,\mathrm{Y_2O_3} \;\longrightarrow\; 2\,\mathrm{Y_{Zr}^\cdot} + \mathrm{V_O^{\cdot\cdot}} + 3\,\mathrm{O_O^\times} + \mathrm{ZrO_2}$$

校验：电荷 $2\times(+1) + (+2) = +4$，右侧 O 位全占满（3 个 $\mathrm{O_O^\times}$）+ 1 个空位 ⇒ 净 +4 有效电荷平衡 ✓；Zr 位：1 个被 Y 占（2 Y 共享 2 个 Zr 位，此处按 2 个 ZrO₂ 计 ⇒ 就是 2 个 $\mathrm{Y_{Zr}^\cdot}$）✓；位点：每 2 个 $\mathrm{Y^{3+}}$ 替 2 个 $\mathrm{Zr^{4+}}$、缺 1 个 O 位 ⇒ $\mathrm{V_O^{\cdot\cdot}}$ ✓。

（ii）设阳离子位点总数 = 1，则 Y 占 $2y/(1+y)$、Zr 占 $(1-y)/(1+y)$（按两元配比）。每 2 个 Y 对应 1 个氧空位 ⇒ $[\mathrm{V_O^{\cdot\cdot}}] = y/(1+y)$（按阳离子位点计）。$y = 0.10$ ⇒ $[\mathrm{V_O^{\cdot\cdot}}] = 0.10/1.10 \approx 0.0909$（约 9.1%）。

（iii）氧空位让 $\mathrm{O^{2-}}$ 可在空位间"跳迁"（2.3.3 的离子电导），800–1000 °C 下迁移率足够高 ⇒ YSZ 是优良氧离子导体（SOFC 电解质、氧传感器）。**设计教训**：缺陷浓度可定量设计——太多空位反而破坏结构，9% 附近是稳定立方萤石相的甜点区。

### 例题 2-2（综合应用）本征/掺杂半导体的载流子随温度变化

**题**：Si 本征载流子浓度 $n_i(T) = \sqrt{N_cN_v}\,e^{-E_g/2kT}$，$E_g = 1.12\ \mathrm{eV}$。（i）求 300 K 与 600 K 的本征 $n_i$（取 $N_cN_v \approx 10^{39}\ \mathrm{cm^{-6}}$）；（ii）若掺 P 至 $N_D = 10^{16}\ \mathrm{cm^{-3}}$，估计 300 K 的 $n$ 与 $p$，并给出 $\ln n$–$1/T$ 两区段的物理；（iii）判断 600 K 时是否已进入本征区。

**解题思路**：本征 $n_i$ 直接用公式 → 掺杂后电中性 $n = N_D + p$ 且 $np = n_i^2$ → 比较 $N_D$ 与 $n_i$ 决定平台/本征区。

**解**：（i）$n_i(300) = 10^{19.5}\,e^{-1.12/(2\times8.617\times10^{-5}\times300)} = 10^{19.5}\,e^{-21.65} \approx 1.0\times10^{10}\ \mathrm{cm^{-3}}$（$e^{-21.65}\approx3.9\times10^{-10}$，$10^{19.5}\approx3.16\times10^{19}$）✓。$n_i(600)$：指数 $1.12/(2\times8.617\times10^{-5}\times600) = 10.83$ ⇒ $n_i = 10^{19.5}\,e^{-10.83} \approx 1.1\times10^{15}\ \mathrm{cm^{-3}}$。量纲检查：$E_g$ 用 eV、$k_{\mathrm B}T$ 用 eV（$8.617\times10^{-5}\ \mathrm{eV/K}$×300 = 0.02585 eV）⇒ 指数无因次 ✓。

（ii）$N_D = 10^{16} \gg n_i(300) = 10^{10}$ ⇒ extrinsic 区：$n \approx N_D = 10^{16}\ \mathrm{cm^{-3}}$，$p = n_i^2/n = 10^{20}/10^{16} = 10^4\ \mathrm{cm^{-3}}$。**$\ln n$–1/T**：低温段（extrinsic）几乎水平（$n \approx N_D$，不随 $T$ 变）；高温段进入本征，$n$ 随 $1/T$ 上升（趋 $\sqrt{K_i}$）。

（iii）600 K 时 $n_i = 1.1\times10^{15} \ll N_D = 10^{16}$ ⇒ 仍在 extrinsic 区（未本征化）。只有当 $T$ 升到 $n_i \sim N_D$（Si 约在 800–900 K 量级，取决于 $N_D$）才转入本征。

**讨论**：这正是集成电路工作温度上限的来由——温度太高，本征激发淹没了掺杂设计（2.3.2 的"冻结解除"）。

### 例题 2-3（拓展）色心与缺陷吸收：F 心能级估算

**题**：NaCl 在 Na 蒸气中 600 °C 处理后变黄。（i）写缺陷形成反应（Na 进入产生 F 心）并校验；（ii）若 F 心吸收峰 $\lambda_{\max} = 465\ \mathrm{nm}$，估算束缚电子从"空位陷获态"到导带附近的能级（相对价带顶 $E_g = 8.97\ \mathrm{eV}$ 的 NaCl 带隙）；（iii）说明为什么颜色随处理温度/时间加深。

**解题思路**：写"加碱金属蒸气产生色心"的反应 → 用 $E = hc/\lambda$ 把吸收波长转成能量 → 联系缺陷浓度随温度上升（2.1.1）。

**解**：（i）Na 蒸气处理 = Na 原子进入晶格、电离为 $\mathrm{Na^+}$ 占 Na 位并放出电子陷于 Cl 空位：

$$\mathrm{Na(g)} + \mathrm{V_{Cl}^\cdot} \longrightarrow \mathrm{Na_{Na}^\times} + \mathrm{V_{Cl}^\times}$$

（$\mathrm{V_{Cl}^\cdot}$ 是带 +1 有效电荷的 Cl 空位，俘获一个电子 $e'$ 后变中性 $\mathrm{V_{Cl}^\times}$ = F 心；电荷 $+1 - 1 = 0$ ✓；Na 守恒 ✓。）实质是 Cl 空位充当电子陷阱。

（ii）$E = hc/\lambda = (1240\ \mathrm{eV\cdot nm})/465\ \mathrm{nm} = 2.67\ \mathrm{eV}$——这是 F 心束缚电子到导带（或到一个激发能级）的能隙；缺陷能级落在 NaCl 的大带隙（8.97 eV）中下部，吸收蓝紫光 ⇒ 透射黄棕（互补色）。量纲检查：$hc = 1240\ \mathrm{eV\cdot nm}$ 是常用常数（由 $h = 4.136\times10^{-15}\ \mathrm{eV\cdot s}$、$c = 3\times10^{17}\ \mathrm{nm/s}$ 算得）✓。

（iii）处理温度↑ ⇒ 更多 Cl 空位（2.3.1 的 $e^{-E_f/kT}$）⇒ 更多 F 心 ⇒ 吸收更强、颜色更深；时间↑ 让平衡更充分。这也是辐射剂量计的定量基础（辐射产生空位，色心浓度 = 剂量）。

### 例题 2-4（拓展）位错与可塑性：为什么金属能"弯而不折"

**题**：Cu 单晶在剪切应力 $\tau$ 下沿 $\{111\}\langle 110\rangle$ 滑移系滑移。（i）用刃型/螺型位错说明滑移为何不需整体剪切；（ii）若位错密度 $\rho = 10^{10}\ \mathrm{cm^{-2}}$，Burgers 矢量 $b = 0.256\ \mathrm{nm}$，估算使位错线整体滑移 1 cm 所需的"原子级台阶"总行程，并解释加工硬化。

**解题思路**：位错是"半原子面的边缘递进" ⇒ 滑移能量低 → 用 $\rho, b, L$ 算总滑移量 = $\rho b L$（Orowan 关系）。

**解**：（i）滑移不是"把上半晶体相对下半整体错开一个 $b$"，而是**位错线作为边界，每前进一个原子间距就把滑移推进一个 $b$**——只有位错核心周围几个原子的键在重排（应变局域），整体剪切应力远低于完整晶面的理论剪切强度。螺位错则让原子面呈螺旋，滑移可绕位错线连续进行。

（ii）Orowan 关系：总塑性应变 $\gamma = \rho b \bar L$（$L$ 平均滑移距离）。滑移 1 cm（样品尺度）$L \sim 1\ \mathrm{cm}$ ⇒ 总"台阶行程" = $\rho b L = 10^{10}\ \mathrm{cm^{-2}} \times 2.56\times10^{-8}\ \mathrm{cm} \times 1\ \mathrm{cm} = 0.256$——即每单位面积累积滑移 0.256（无量纲应变意义）。加工硬化：塑性变形中位错不断增殖、互相交截缠结 ⇒ $\rho$ 升高、位错间弹性相互作用阻碍彼此滑移 ⇒ 继续变形需更大应力（[第 4 章 4.5 节](/xiaoshus-blog/textbooks/chemistry/02-inorganic/02/)密堆积滑移系 + 此处位错动力学的完整版）。

**讨论**：位错把"理想晶体的理论强度"与"真实金属的软"连了起来——缺陷的化学与力学的会师点。

## 2.10 常见误区与易错点

1. **"缺陷=次品"**：缺陷是功能来源（半导体、离子导体、催化、色心）；追求"零缺陷"只在少数场合（光学透明、量子相干）是正确的。
2. **Kröger–Vink 三守恒漏一项**：位点守恒最常被漏——写反应后逐亚晶格点一遍"左几位=右几位"。
3. **有效电荷当形式电荷**：$\mathrm{Ca_{Zr}''}$ 的 −2 是**相对 Zr⁴⁺点位的净欠电荷**，不是 Ca 的形式电荷；掺三价到四价位永远 −1/空位，与杂质本身的氧化态无关。
4. **"退火去掉缺陷"**：退火冻结高温平衡态，缺陷浓度按 $e^{-E_f/kT}$ 降低，但**永不归零**；淬火才"保留"高温缺陷。
5. **掺杂半导体"两段都自由"**：浓掺时一个载流子被掺杂钉死、另一个才是温度变量；画 $\ln n$–$1/T$ 先看哪段是平台。
6. **表面/晶界"无功能"**：表面是催化活性位、晶界是快扩散/腐蚀通道；多晶性能很大程度由界面决定，不能只盯体相。
