## 第 3 章 酸碱、沉淀、氧化还原与配位平衡

## 3-1【概念辨析】极稀强碱/强酸的 pH

**错误根源**：把"强电解质完全解离"误当成"解离出的离子是 $\mathrm{H^+/OH^-}$ 的唯一来源"，忽略了溶剂水本身的自偶电离贡献（$1.0\times10^{-7}~\mathrm{mol\cdot L^{-1}}$，比该溶液中 NaOH 还高一个量级）。

**NaOH 溶液（$c = 1.0\times10^{-8}~\mathrm{mol\cdot L^{-1}}$）**：电荷平衡（电中性：所有正电荷 = 所有负电荷）$[\mathrm{Na^+}] + [\mathrm{H^+}] = [\mathrm{OH^-}]$，代入 $[\mathrm{Na^+}] = c$ 与 $[\mathrm{OH^-}] = K_\mathrm{w}/[\mathrm{H^+}]$：

$$[\mathrm{H^+}]^2 + c[\mathrm{H^+}] - K_\mathrm{w} = 0
\ \Rightarrow\
[\mathrm{H^+}] = \frac{-c + \sqrt{c^2 + 4K_\mathrm{w}}}{2} = \frac{-1.0\times10^{-8} + \sqrt{1.0\times10^{-16} + 4.0\times10^{-14}}}{2}$$

$$= \frac{-1.0\times10^{-8} + 2.002\times10^{-7}}{2} = 9.51\times10^{-8}~\mathrm{mol\cdot L^{-1}},\qquad \mathrm{pH} = 7.02$$

**HCl 溶液（同浓度）**：$[\mathrm{H^+}] = c + K_\mathrm{w}/[\mathrm{H^+}]$ 给 $[\mathrm{H^+}] = \frac{c + \sqrt{c^2+4K_\mathrm{w}}}{2} = 1.05\times10^{-7}~\mathrm{mol\cdot L^{-1}}$，pH $= 6.98$。

**校验**：两答案对称地分布在 7 的两侧（±0.02），且严格满足电荷平衡与 $K_\mathrm{w}$，量纲为 mol/L ✓。

**活度何时不可忽略**：当离子强度 $I$ 大到 $\gamma$ 明显偏离 1 时（例如 $I \gtrsim 0.01$ 时 $\gamma_{\pm} \approx 0.89$，1 mol/L 时更低）。用浓度代替活度在高浓度电解质、海水、缓冲容量计算中会引入系统误差；实测的电极电势、酸度计读数响应的都是活度。

## 3-2【基础计算】HAc 两浓度下的 pH 与解离度

**（a）$c = 0.100~\mathrm{mol\cdot L^{-1}}$**：判据 $c/K_a = 0.100/1.75\times10^{-5} = 5714 \ge 500$ ✓，$cK_a = 1.75\times10^{-6} \ge 20K_\mathrm{w}$ ✓，用最简式：

$$[\mathrm{H^+}] = \sqrt{K_ac} = \sqrt{1.75\times10^{-5}\times0.100} = 1.32\times10^{-3}~\mathrm{mol\cdot L^{-1}},\quad \mathrm{pH} = 2.88,\quad \alpha = 1.32\%$$

自检：$[\mathrm{H^+}]/c = 1.3\% \ll 5\%$，近似自洽 ✓。

**（b）$c = 1.0\times10^{-4}~\mathrm{mol\cdot L^{-1}}$**：判据 $c/K_a = 5.7 < 500$——**最简式失效，必须用精确式**（$cK_a = 1.75\times10^{-9} \ge 20K_\mathrm{w}$，水的电离仍可忽略，取二次式）：

$$[\mathrm{H^+}] = \frac{-K_a + \sqrt{K_a^2 + 4K_ac}}{2} = \frac{-1.75\times10^{-5} + \sqrt{3.06\times10^{-10} + 7.00\times10^{-9}}}{2}$$

$$= \frac{-1.75\times10^{-5} + 8.55\times10^{-5}}{2} = 3.40\times10^{-5}~\mathrm{mol\cdot L^{-1}},\qquad \mathrm{pH} = 4.47,\quad \alpha = 34\%$$

**校验**：若误用最简式得 $\sqrt{1.75\times10^{-9}} = 4.18\times10^{-5}$（pH 4.38），$[\mathrm{H^+}]$ 偏高 23%——"稀释使弱酸更接近完全解离"（$\alpha$ 从 1.3% 增至 34%）正是最简式失效的物理原因。量纲检查：两次开方结果均为 mol/L ✓。

## 3-3【基础计算】pH 9.00 氨缓冲液的设计与抗扰

**（a）体积比**：$\mathrm{pH} = \mathrm{p}K_a + \lg\frac{n(\mathrm{NH_3})}{n(\mathrm{NH_4^+})}$，即 $\lg\frac{n(\mathrm{NH_3})}{n(\mathrm{NH_4^+})} = 9.00 - 9.25 = -0.25$：

$$\frac{n(\mathrm{NH_3})}{n(\mathrm{NH_4^+})} = 10^{-0.25} = 0.562$$

两液浓度相同（0.10 mol/L），体积比 = 摩尔比 = 0.562 : 1。500 mL 总体积：

$$V(\mathrm{NH_3}) = 500~\mathrm{mL}\times\frac{0.562}{1.562} = 180~\mathrm{mL},\qquad V(\mathrm{NH_4Cl}) = 320~\mathrm{mL}$$

（校验：$0.0180/0.0320 = 0.562$ ✓，总体积 500 mL ✓。）

**（b）加 $0.0010~\mathrm{mol}$ NaOH**：强碱定量把 $\mathrm{NH_4^+}$ 变为 $\mathrm{NH_3}$：

$$n(\mathrm{NH_3}) = 0.0180 + 0.0010 = 0.0190~\mathrm{mol},\qquad n(\mathrm{NH_4^+}) = 0.0320 - 0.0010 = 0.0310~\mathrm{mol}$$

$$\mathrm{pH} = 9.25 + \lg\frac{0.0190}{0.0310} = 9.25 + \lg(0.613) = 9.25 - 0.21 = 9.04$$

**校验**：$\Delta\mathrm{pH} = +0.04$，缓冲能力合格（若加进纯水，$[\mathrm{OH^-}]$ 将增大约 30 倍、pH 剧变）。比值无量纲 ✓。此题即"缓冲容量 $\beta \propto c$ 且在 $\mathrm{pH} = \mathrm{p}K_a$ 附近最大"（3.2.5 节）的数值演示。

## 3-4【综合计算】$0.010~\mathrm{mol\cdot L^{-1}}$ $\mathrm{H_3PO_4}$

**为何不能用最简式**：$c/K_{a1} = 0.010/7.11\times10^{-3} = 1.41 \ll 500$——磷酸第一级电离度极大（Ka1 与 c 同量级），$[\mathrm{H_3PO_4}]$ 不能近似为 $c$。$cK_{a1} = 7.1\times10^{-5} \gg 20K_\mathrm{w}$，水的电离可忽略。

**精确求解第一级**（$\mathrm{H_3PO_4 \rightleftharpoons H^+ + H_2PO_4^-}$，$K_{a1} = 7.11\times10^{-3}$）：

$$[\mathrm{H^+}] = \frac{-K_{a1} + \sqrt{K_{a1}^2 + 4K_{a1}c}}{2} = \frac{-7.11\times10^{-3} + \sqrt{5.06\times10^{-5} + 2.84\times10^{-4}}}{2} = \frac{-7.11\times10^{-3} + 0.01830}{2} = 5.60\times10^{-3}~\mathrm{mol\cdot L^{-1}}$$

$$\mathrm{pH} = 2.25$$

（若误用最简式：$\sqrt{7.11\times10^{-5}} = 8.43\times10^{-3}$，pH 2.07，$[\mathrm{H^+}]$ 偏高 34%。）

**第二、三级**：$\Delta\mathrm{p}K_a = 7.20 - 2.15 = 5.05 \gg 3$，第二级对 $[\mathrm{H^+}]$ 的贡献可忽略；由 $K_{a2} = [\mathrm{H^+}][\mathrm{HPO_4^{2-}}]/[\mathrm{H_2PO_4^-}]$ 且电荷平衡近似给出 $[\mathrm{H_2PO_4^-}] \approx [\mathrm{H^+}]$，得

$$[\mathrm{HPO_4^{2-}}] \approx K_{a2} = 6.3\times10^{-8}~\mathrm{mol\cdot L^{-1}}$$

（第三级更小：$[\mathrm{PO_4^{3-}}] = K_{a3}[\mathrm{HPO_4^{2-}}]/[\mathrm{H^+}] \approx 4.5\times10^{-13}\times6.3\times10^{-8}/5.6\times10^{-3} = 5\times10^{-18}~\mathrm{mol\cdot L^{-1}}$，完全可忽略。）

**校验**：$[\mathrm{H^+}]/c = 56\%$，与"弱的第一级也解离过半"自洽；$[\mathrm{H_3PO_4}] = 0.010 - 0.0056 = 4.4\times10^{-3}$，$K_{a1}$ 回代 $5.6\times10^{-3}\times5.6\times10^{-3}/4.4\times10^{-3} = 7.1\times10^{-3}$ ✓。

## 3-5【综合计算】Mg(OH)₂ 沉淀判断

混合后（体积加倍，浓度减半）：$[\mathrm{Mg^{2+}}] = 0.010\times\frac{20.0}{40.0} = 0.0050~\mathrm{mol\cdot L^{-1}}$，$c(\mathrm{NH_3}) = 0.10\times\frac{20.0}{40.0} = 0.050~\mathrm{mol\cdot L^{-1}}$。

氨水提供的 $[\mathrm{OH^-}]$（判据 $c/K_b = 2810 \ge 500$，用最简式）：

$$[\mathrm{OH^-}] = \sqrt{K_b\,c} = \sqrt{1.78\times10^{-5}\times0.050} = 9.4\times10^{-4}~\mathrm{mol\cdot L^{-1}}$$

离子积与溶度积比较：

$$Q = [\mathrm{Mg^{2+}}][\mathrm{OH^-}]^2 = 0.0050\times(9.4\times10^{-4})^2 = 4.4\times10^{-9}$$

$$Q = 4.4\times10^{-9} > K_\mathrm{sp} = 5.61\times10^{-12}\quad\Rightarrow\quad \textbf{生成 } \mathrm{Mg(OH)_2} \textbf{ 沉淀}$$

（量纲检查：$(\mathrm{mol\cdot L^{-1}})^3$ 型活度积比较，双方同价型 ✓。）若要抑制沉淀（如掩蔽 Mg²⁺），应加 $\mathrm{NH_4Cl}$：同离子 $\mathrm{NH_4^+}$ 压低 $[\mathrm{OH^-}]$，这正是"镁铵试剂"不沉淀 Mg 的原理。

## 3-6【综合计算】莫尔法的分步沉淀核算

各自开始沉淀所需 $[\mathrm{Ag^+}]$（$Q = K_\mathrm{sp}$ 的临界条件）：

$$\mathrm{AgCl:}\quad [\mathrm{Ag^+}] = \frac{1.77\times10^{-10}}{0.010} = 1.8\times10^{-8}~\mathrm{mol\cdot L^{-1}}$$

$$\mathrm{Ag_2CrO_4:}\quad [\mathrm{Ag^+}] = \sqrt{\frac{1.12\times10^{-12}}{0.010}} = 1.06\times10^{-5}~\mathrm{mol\cdot L^{-1}}$$

**AgCl 先沉淀**（所需 $\mathrm{Ag^+}$ 低近 3 个数量级——注意不是比较 $K_\mathrm{sp}$：Ag₂CrO₄ 的 $K_\mathrm{sp}$ 更小！）。

$\mathrm{Ag_2CrO_4}$ 开始沉淀时：

$$[\mathrm{Cl^-}] = \frac{K_\mathrm{sp}(\mathrm{AgCl})}{[\mathrm{Ag^+}]} = \frac{1.77\times10^{-10}}{1.06\times10^{-5}} = 1.7\times10^{-5}~\mathrm{mol\cdot L^{-1}}$$

**校验**：即 Cl⁻ 沉淀率 99.83%，符合化学计量滴定对终点的要求 ✓。

**指示剂用量讨论**：$[\mathrm{CrO_4^{2-}}]$ 太大 → 黄色过深干扰观察，且终点提前（少量 Ag⁺ 即显红）；太小 → 需过量 Ag⁺ 才出现 Ag₂CrO₄，终点拖后、正误差。定量核算（取 $[\mathrm{CrO_4^{2-}}] = 5\times10^{-3}~\mathrm{mol\cdot L^{-1}}$）给出终点超额 $\mathrm{Ag^+}$ 仅约 $1\times10^{-5}~\mathrm{mol\cdot L^{-1}}$，故实践控制在约 $5\times10^{-3}~\mathrm{mol\cdot L^{-1}}$ 并做空白校正。详细滴定曲线见[模块三](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/)。

## 3-7【综合计算】$\mathrm{MnO_4^-}$ 氧化 $\mathrm{Fe^{2+}}$ 的热力学

**（a）lg K**：

$$E^\ominus_\text{池} = E^\ominus(\mathrm{MnO_4^-/Mn^{2+}}) - E^\ominus(\mathrm{Fe^{3+}/Fe^{2+}}) = 1.512 - 0.771 = 0.741~\mathrm{V}$$

$$\lg K = \frac{nE^\ominus_\text{池}}{0.0592~\mathrm{V}} = \frac{5\times0.741}{0.0592} = 62.6,\qquad K \approx 3.8\times10^{62}$$

（量纲检查：V/V 无量纲；$n = 5$ 来自半反应 $\mathrm{MnO_4^- + 8H^+ + 5e^- \to Mn^{2+} + 4H_2O}$，勿用 1。）

**（b）pH 5 时的电动势**：其余物种均为标准态时 $Q = 1/[\mathrm{H^+}]^8 = 10^{40}$：

$$E = E^\ominus_\text{池} - \frac{0.0592~\mathrm{V}}{5}\lg Q = 0.741 - \frac{0.0592}{5}\times40 = 0.741 - 0.474 = 0.267~\mathrm{V}$$

对 Fe 电对（无 $\mathrm{H^+}$ 参与）$E(\mathrm{Fe^{3+}/Fe^{2+}}) = 0.771~\mathrm{V}$ 不变。**电池电动势** $E_\text{池} = E_\text{正} - E_\text{负} = 0.771 - 0.267 = 0.504~\mathrm{V}$；等价地按题给"直接算 $\mathrm{MnO_4^-}$ 电对"：

$$E(\mathrm{MnO_4^-/Mn^{2+}}) = 1.512 - \frac{0.0592}{5}\times40 = 1.04~\mathrm{V} > 0.771~\mathrm{V}\quad\Rightarrow\quad \textbf{方向不变，仍自发}$$

**校验**：1.512 − 0.474 = 1.038 ≈ 1.04 ✓。热力学上高锰酸钾在 pH 5 仍能氧化铁（滴定仍可行但斜率变缓），实际稀酸滴定控制 pH ≈ 1（硫酸介质）以保证速率与终点敏锐——热力学允许 ≠ 动力学合适（呼应 3.9 节误区 6）。

## 3-8【挑战题】控制酸度分离 $\mathrm{Zn^{2+}}$ / $\mathrm{Mn^{2+}}$（硫化物）

**（a）$[\mathrm{S^{2-}}]$–pH 关系**：两级解离式相乘（$K_{a1}K_{a2} = \frac{[\mathrm{H^+}]^2[\mathrm{S^{2-}}]}{[\mathrm{H_2S}]}$），在强酸性介质中 $[\mathrm{H_2S}] \approx c = 0.10~\mathrm{mol\cdot L^{-1}}$（$\delta_0 \approx 1$，因 $[\mathrm{H^+}] \gg K_{a1}$）：

$$[\mathrm{S^{2-}}] = \frac{K_{a1}K_{a2}[\mathrm{H_2S}]}{[\mathrm{H^+}]^2} = \frac{1.3\times10^{-7}\times7.1\times10^{-15}\times0.10}{[\mathrm{H^+}]^2} = \frac{9.2\times10^{-23}}{[\mathrm{H^+}]^2}$$

——$[\mathrm{H^+}]$ 每增大 10 倍，$[\mathrm{S^{2-}}]$ 缩小 100 倍，酸度是硫化物沉淀的"精调旋钮"。

**（b）pH 窗口**（三段临界条件，均以 $Q$ 对 $K_\mathrm{sp}$）：

- ZnS 沉淀完全（$[\mathrm{Zn^{2+}}] \le 1.0\times10^{-5}~\mathrm{mol\cdot L^{-1}}$）：需 $[\mathrm{S^{2-}}] \ge \frac{2\times10^{-25}}{1.0\times10^{-5}} = 2\times10^{-20}$，即 $[\mathrm{H^+}]^2 \le \frac{9.2\times10^{-23}}{2\times10^{-20}} = 4.6\times10^{-3}$，$[\mathrm{H^+}] \le 0.068~\mathrm{mol\cdot L^{-1}}$，**pH ≥ 1.17**；
- MnS 不沉淀（$[\mathrm{Mn^{2+}}] = 0.010$）：需 $[\mathrm{S^{2-}}] \le \frac{1.4\times10^{-15}}{0.010} = 1.4\times10^{-13}$，即 $[\mathrm{H^+}]^2 \ge \frac{9.2\times10^{-23}}{1.4\times10^{-13}} = 6.6\times10^{-10}$，$[\mathrm{H^+}] \ge 2.6\times10^{-5}~\mathrm{mol\cdot L^{-1}}$，**pH ≤ 4.59**。

**结论：pH 控制在约 1.2 ~ 4.6**（例如用甲酸–甲酸钠或邻苯二甲酸氢钾缓冲），ZnS 沉淀完全而 Mn²⁺ 留在溶液。

（校验：pH 2.0 时 $[\mathrm{S^{2-}}] = 9.2\times10^{-19}$，$Q(\mathrm{Zn}) = 9.2\times10^{-21} \gg 2\times10^{-25}$ 沉淀、$Q(\mathrm{Mn}) = 9.2\times10^{-21} \ll 1.4\times10^{-15}$ 不沉淀 ✓。硫化物 $K_\mathrm{sp}$ 随晶型差异大，换用别组数据窗口会平移，但"酸度分族"的逻辑不变。）

**（c）硫代乙酰胺为何更优**：$\mathrm{CH_3CSNH_2 + H_2O \xrightarrow{\Delta} CH_3CONH_2 + H_2S}$。直接通 $\mathrm{H_2S}$ 局部过饱和度极高 → 瞬时大量成核 → 细小胶状沉淀，易吸附共沉杂质、难过滤；硫代乙酰胺受热**均匀、缓慢**释放 $\mathrm{S^{2-}}$（均相沉淀），过饱和度低 → 成核少、晶粒长大为主 → 晶形完整、纯净、易过滤洗涤。这是"热力学（$Q$ vs $K$）之外还须考虑成核动力学"的教材级案例（衔接模块四第 7 章）。

## 第 4 章 元素化学与配位化学

## 4-1【概念辨析】Li 电势最负却反应最温和

**热力学（$E^\ominus$ 的 Born–Haber 分解）**：$\mathrm{M(s) \to M^+(aq) + e^-}$ 的 $\Delta G$ 由升华/电离/水化三项构成。Li 的电离能其实是碱金属中**最高**的（520 vs Na 496 kJ/mol，本不利于失电子），但 $\mathrm{Li^+}$ 半径最小、水合焓极负（约 −520 kJ/mol，Na⁺ 约 −406、K⁺ 约 −322 kJ/mol）——**强水合这一项把整个账目拉成最负**，于是 $E^\ominus(\mathrm{Li^+/Li}) = -3.04~\mathrm{V}$ 全金属最负。热力学只回答"倾向"，不回答"快慢"。

**动力学**：Li 熔点 180 °C（Na 98 °C）——反应热不至于把 Li 熔散成小球、表面更新慢；LiOH 在水中溶解度小，部分覆盖表面形成扩散屏障；Na 熔融铺展、NaOH 全溶，反应自加速（K 更甚，熔点 64 °C，$\mathrm{H_2}$ 即燃）。

**与锂电池的关系**：最负的 $E^\ominus$ + 最小的摩尔质量（6.94 g/mol）+ 最小的离子半径（电解液中迁移快）= 单位质量最高的电池电压与能量密度——水合焓的"债"在非质子有机电解质（无水参与）中不再支付，电势优势得以全额兑现。

## 4-2【概念辨析】碳酸盐热稳定性与反极化

**顺序**：同金属阳离子系列中，阳离子极化力（$z/r^2$，反极化能力）越强，$\mathrm{CO_3^{2-}}$ 的 O²⁻ 端被拉扯变形越厉害、C–O 键越易断裂，分解温度越低：

$$\mathrm{Na_2CO_3\ (\text{加热不分解，仅熔融，} 851\,^\circ C)} > \mathrm{MgCO_3\ (540\,^\circ C)} > \mathrm{BeCO_3\ (\approx100\,^\circ C)}$$

（同主族 II A 自下而上分解温度递减：$\mathrm{BaCO_3\ 1360 > SrCO_3\ 1290 > CaCO_3\ 900 > MgCO_3\ 540 > BeCO_3}$。）

**$\mathrm{(NH_4)_2CO_3}$ 最易分解**：$\mathrm{NH_4^+}$ 中四个 N–H 极性基团对 $\mathrm{CO_3^{2-}}$ 的 O²⁻ 端反极化极强（等效于高极化力阳离子），且分解产物全为气体分子（熵增项在高温下按 $\Delta G = \Delta H - T\Delta S$ 主导翻转）：

$$\mathrm{(NH_4)_2CO_3 \xrightarrow{\Delta} 2NH_3\uparrow + CO_2\uparrow + H_2O\ (约\ 58\,^\circ C\ 已明显分解)}$$

（校验：三级"极化力阶梯"——$\mathrm{Na^+}$(1+, 大) < $\mathrm{Mg^{2+}}$ < $\mathrm{Be^{2+}}$ < $\mathrm{NH_4^+/H^+}$——与分解温度单调对应 ✓。碳的"质子争夺战"就是 4.3.2 节灰岩溶蚀循环的同一化学。）

## 4-3【计算】$\mathrm{[Fe(H_2O)_6]^{2+}}$ 与 $\mathrm{[Fe(CN)_6]^{4-}}$

Fe²⁺ = d⁶。判据 $\Delta_\mathrm{o}$ vs $P$：

| | 组态 | 单电子数 | 自旋磁矩 $\mu=\sqrt{n(n+2)}~\mu_\mathrm{B}$ | CFSE |
|---|---|---|---|---|
| $\mathrm{[Fe(H_2O)_6]^{2+}}$ | 高自旋 $\mathrm{t_{2g}^4e_g^2}$ | 4 | $\sqrt{24} = 4.9$ | $[4(-0.4)+2(0.6)]\Delta_\mathrm{o} = -0.4\Delta_\mathrm{o}$（额外成对 0） |
| $\mathrm{[Fe(CN)_6]^{4-}}$ | 低自旋 $\mathrm{t_{2g}^6}$ | 0 | 0 | $-2.4\Delta_\mathrm{o} + 2P$（组态 3 对，自由离子 1 对，额外 2 对） |

（H₂O 中场配体、Fe²⁺ 电荷低 → $\Delta_\mathrm{o} < P$；CN⁻ 强场且 4d 级别不存在时靠强场胜出 → $\Delta_\mathrm{o} > P$。磁学实验（Gouy 天平/磁化率仪）是这两个自旋态的判据性证据，与 4.6.2 节电子光谱测得的 $\Delta_\mathrm{o}$ 互相印证。）

## 4-4【计算】水合焓的双峰曲线

高自旋八面体 $\mathrm{M^{2+}}$（d⁵–d⁸）的 CFSE：

$$\mathrm{d^5\ (t_{2g}^3e_g^2)}: 0;\qquad
\mathrm{d^6\ (t_{2g}^4e_g^2)}: -0.4\Delta_\mathrm{o};\qquad
\mathrm{d^7\ (t_{2g}^5e_g^2)}: -0.8\Delta_\mathrm{o};\qquad
\mathrm{d^8\ (t_{2g}^6e_g^2)}: -1.2\Delta_\mathrm{o}$$

水合焓 $\Delta_\mathrm{hyd}H(\mathrm{M^{2+}})$ 本应随离子半径自左向右收缩**平滑地更负**（Ca²⁺ → Zn²⁺ 趋势线）。实测曲线却在趋势线上叠加了 CFSE 修正，形成**双峰**：CFSE 在 d³（V²⁺，$-1.2\Delta_\mathrm{o}$）与 d⁸（Ni²⁺，$-1.2\Delta_\mathrm{o}$）达到局部极大 → 峰位于 $\mathrm{V^{2+}}$ 与 $\mathrm{Ni^{2+}}$；而 d⁰（Ca²⁺）、d⁵（Mn²⁺）、d¹⁰（Zn²⁺）CFSE = 0，**恰好落在平滑趋势线上**。从双峰曲线扣除 CFSE 后趋势线复原——这是晶体场理论早期最有力的实验证据之一（"理论预测的修正量 = 实验偏离量"）。

## 4-5【计算】Mn 的 Latimer 图

**（a）加权计算**（$\Delta G^\ominus = -nFE^\ominus$ 可加，$n$ = 电子数；$\mathrm{MnO_4^- \to MnO_2}$ 共 3 e⁻）：

$$E^\ominus(\mathrm{MnO_4^-/MnO_2}) = \frac{1\times0.564 + 2\times2.26}{3} = \frac{5.084}{3} = 1.69~\mathrm{V}$$

（校验：这应与文献值 1.695 V 一致 ✓；若算术平均 $(0.564+2.26)/2 = 1.41$ 则错误。）

**（b）歧化判断**（$E^\ominus_\text{右} > E^\ominus_\text{左}$ ⇔ 歧化自发）：

- $\mathrm{MnO_4^{2-}}$：右 2.26 > 左 0.564 → **歧化**；
- $\mathrm{Mn^{3+}}$：右 1.51 > 左 0.95 → **歧化**。

**（c）$\mathrm{Mn^{3+}}$ 歧化常数**（$2\mathrm{Mn^{3+} + 2H_2O \to Mn^{2+} + MnO_2 + 4H^+}$，1 e⁻ 转移）：

$$\lg K = \frac{1\times(1.51 - 0.95)}{0.0592} = \frac{0.56}{0.0592} = 9.5,\qquad K \approx 3\times10^{9}$$

（量纲检查：V/V 无量纲 ✓。）由此理解：$\mathrm{Mn^{3+}}$ 只能在强酸配位（如 $\mathrm{[Mn(CN)_6]^{3-}}$ 类）或固体中存在；$\mathrm{K_2MnO_4}$ 的绿色溶液遇酸即歧化变紫（生成 $\mathrm{MnO_4^-}$）并析出棕色 $\mathrm{MnO_2}$——4.4.2 节"产物由 pH 仲裁"的定量版本。

## 4-6【概念+计算】Fe 在酸中与被 $\mathrm{Cl_2}$ 氧化的价态问题

**Fe 溶于稀盐酸为何是 $\mathrm{Fe^{2+}}$**：三步热力学账。

① $\mathrm{Fe + 2H^+ \to Fe^{2+} + H_2}$：$E^\ominus_\text{池} = 0 - (-0.447) = 0.447~\mathrm{V}$，强自发（$\lg K = \frac{2\times0.447}{0.0592} = 15.1$，即 $K \approx 1.3\times10^{15}$）——**校验值 lg K ≈ 15.1** ✓。

② $\mathrm{Fe^{3+}/Fe}$ 电对：由 $\Delta G$ 加权，$3E^\ominus = 2(-0.447) + 0.771 = -0.123$，$E^\ominus(\mathrm{Fe^{3+}/Fe}) = -0.041~\mathrm{V}$。$\mathrm{H^+/H_2}$（0 V）仅比它高 0.041 V——生成 $\mathrm{Fe^{3+}}$ 的热力学驱动力微弱（$\lg K \approx 2.1$）。

③ 决定性一步：过量铁的存在下 $\mathrm{Fe + 2Fe^{3+} \to 3Fe^{2+}}$，$E^\ominus_\text{池} = 0.771 - (-0.447) = 1.218~\mathrm{V}$，$\lg K = \frac{2\times1.218}{0.0592} = 41$——**即使生成痕量 $\mathrm{Fe^{3+}}$ 也被铁立即还原回 $\mathrm{Fe^{2+}}$**。产物价态由"溶液中最强的还原剂是铁本身"决定。

**$\mathrm{Cl_2}$ 氧化 $\mathrm{Fe^{2+}}$**：$E^\ominus_\text{池} = 1.358 - 0.771 = 0.587~\mathrm{V} > 0$，自发（$K = 10^{19.8}$）——当氧化剂强到把 Fe²⁺/Fe³⁺ 电对"顶翻"，价态即上移到 +3（这也是铁与氯气直接化合得 $\mathrm{FeCl_3}$ 而与盐酸只得 $\mathrm{FeCl_2}$ 的统一解释：**产物价态 = 氧化剂强度与后续歧化/归中反应的联立解**，全部由 $E^\ominus$ 仲裁）。

## 4-7【计算+命名】$\mathrm{[Co(NH_3)_4Cl_2]Cl}$

**（a）命名**：外界 1 个 Cl⁻ → "氯化…"；内界配体按先阴后阳、字母顺序：二氯・四氨 → **氯化二氯四氨合钴(III)**。

**（b）氧化态与 d 电子数**：内界电荷 +1 = $x + 0\times4 + (-1)\times2$ → $x = +3$；Co³⁺ = d⁶（Co 基态 3d⁷4s²，先失 4s² 再失 3d¹）。

**（c）异构**：八面体 $\mathrm{MA_4B_2}$ 型 → **2 种几何异构体**（顺式：两个 Cl 相邻 90°；反式：相对 180°）。两种均含镜面（顺式含过金属与两 Cl 平分面的对称性）→ **无旋光异构**（对照：把两个 $\mathrm{NH_3}$ 换成双齿 en 得 $\mathrm{[Co(en)_2Cl_2]^+}$，顺式即出现 Δ/Λ 手性对）。

**（d）磁性与 CFSE**：Co³⁺ 电荷高、NH₃ 中强场 → $\Delta_\mathrm{o} > P$，低自旋 $\mathrm{t_{2g}^6}$：0 个单电子，**反磁**（μ = 0），CFSE $= -2.4\Delta_\mathrm{o} + 2P$。这也解释了该系列配合物（Werner 研究的原型）动力学惰性（低自旋 d⁶，4.6.5 节）——能被分离结晶、能做异构体实验，正因它是惰性的。

## 4-8【挑战题】Taube 内界电子转移机理

**（a）配平方程式**（检查：电荷 +4 = +2 + 2 ✓；原子 H 27 = 17 + 10 ✓，O 6 = 1 + 5 ✓）：

$$\mathrm{[Co(NH_3)_5Cl]^{2+} + [Cr(H_2O)_6]^{2+} \to [Co(NH_3)_5(H_2O)]^{2+} + [CrCl(H_2O)_5]^{2+}}$$

**（b）机理判定：内界机理**。证据链逐条：

1. **Cl 标记实验**：用 $\mathrm{^{36}Cl}$ 标记的钴配合物反应，放射性与 $\mathrm{[CrCl(H_2O)_5]^{2+}}$ 定量共存，且自由 $\mathrm{Cl^-}$ 的出现速率**慢于**电子转移——Cl 不是先掉下来再被 Cr 抓住，而是**随电子一起搬家**（桥连配体的"路由器"角色）。
2. **桥连前驱体的可行性**：$\mathrm{[Cr(H_2O)_6]^{2+}}$ 是 d⁴（HS $\mathrm{t_{2g}^3e_g^1}$，含反键 $\mathrm{e_g}$ 电子）→ Jahn–Teller 拉长 + 动力学**活性**，易失一个 $\mathrm{H_2O}$ 让出空位与 Cl 成桥，形成 $\mathrm{[(NH_3)_5Co{-}Cl{-}Cr(H_2O)_5]^{4+}}$。
3. **电子经桥转移**：沿 Co–Cl–Cr 路径，Co³⁺→Co²⁺、Cr²⁺→Cr³⁺。
4. **产物的动力学命运保住了证据**：Cr³⁺（d³，$\mathrm{t_{2g}^3}$ 无反键电子、CFSE = $-1.2\Delta_\mathrm{o}$）**惰性** → 新生的 Cr–Cl 键被"冻结"，得以分离鉴定；Co²⁺（d⁷ HS）**活性** → 立即水合为 $\mathrm{[Co(NH_3)_5(H_2O)]^{2+}}$ 并随后放出 $\mathrm{NH_3}$。一端活性保证成桥、另一端惰性保证证据——两端缺一不可，这正是"取代动力学服务机理判定"的逻辑闭环。
5. **桥配体依赖性**：改用 $\mathrm{[Co(NH_3)_5Br]^{2+}}$ 速率不同、改用不能成桥的配体时机理改变——速率对桥配体身份敏感是内界机理的动力学指纹。

**（c）换成 $\mathrm{[Co(NH_3)_6]^{3+}}$ 为何变慢且无 Cl**：六氨配合物**没有可成桥的配体**（NH₃ 的 N–H 不能桥连传递），只能走**外界机理**：两配位层保持完整、电子"隧穿"通过。热力学驱动相似（$E^\ominus(\mathrm{Co^{III}/^{II}})$ 氨系约 +0.1 V vs Cr −0.41 V，$\Delta E$ 甚至更大），慢的原因在**重组能**（Marcus 理论）：Co(III) 低自旋 d⁶ → Co(II) 高自旋 d⁷，Co–N 键长要显著伸长（离子半径跳变），核重排代价大；而 d⁶/d⁶ 的 $\mathrm{[Fe(CN)_6]^{3-/4-}}$ 自交换几乎不需重组、极快。产物为 $\mathrm{[Co(NH_3)_6]^{2+}}$（活性，随即水合）与 $\mathrm{[Cr(H_2O)_6]^{3+}}$——Cr 产物中没有 Cl 可带。**同一反应，桥配体之有无决定机理路径，重组能之大小决定速率**——这正是内界/外界机理对比的完整答案。
