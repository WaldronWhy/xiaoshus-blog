# 第 4 章 元素化学与配位化学

> **本章定位**：本章把[模块一第 2 章](/xiaoshus-blog/textbooks/chemistry/01-foundations/02/)的周期律量子解释与[第 3 章](/xiaoshus-blog/textbooks/chemistry/02-inorganic/01/)的平衡计算落实到具体元素与配位化合物，建立"结构 → 性质 → 反应 → 应用"的系统化学路线。配位化学部分向前支撑[模块三（络合滴定）](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/)，其理论由[模块五（结构化学与量子化学）](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/01/)完成定量化，金属–配体的电子效应延伸到[模块六（有机化学）](/xiaoshus-blog/textbooks/chemistry/06-organic/01/)。

## 4.0 本章学习目标

1. 能够对任一主族元素用"价层电子构型 → 成键图像 → 性质预测 → 代表反应"的路线给出结构性解释，而不依赖记忆孤立事实。
2. 能够写出第一过渡系重点元素（Cr、Mn、Fe、Co、Ni、Cu、Zn）各氧化态之间的关键转化方程，并用 Latimer 电势图（[第 3 章 3.4.4 节](/xiaoshus-blog/textbooks/chemistry/02-inorganic/01/)）判断哪些氧化态在酸/碱中稳定。
3. 能够计算镧系收缩对离子半径、碱性、Zr/Hf 分离的影响。
4. 能够用价键理论与晶体场理论判断配合物的自旋态、磁矩与几何构型，并计算 CFSE。
5. 能够用 π 给体/受体分子轨道图像解释光谱化学序列的两端。
6. 能够区分内界与外界电子转移机理并设计判别实验；能识别配合物的五大类异构现象。

## 4.1 元素化学的系统方法：一条路线代替一张清单

元素化学的信息量近似于 $\sum(\text{元素}\times\text{化合物}\times\text{反应})$，机械记忆不可行。可行的做法是把周期表当作**一张预测表**：从每个元素的三个结构参数出发——

| 参数 | 决定什么 | 数据来源（回引） |
|---|---|---|
| 价层电子构型 | 可能的氧化态、成键方式、单电子数 | [模块一第 2 章 2.1.3 节](/xiaoshus-blog/textbooks/chemistry/01-foundations/02/) |
| 原子/离子半径 | 配位数、晶格能、水合能、迁移性 | 同上（周期律的量子解释） |
| 电负性 | 键的极性、氧化态的"实际"含义、酸碱方向 | 同上（Pauling 电负性标度） |

路线：**结构**（电子构型、成键图像）→ **性质**（物性：熔沸点/溶解度/颜色/磁性；化性：酸碱性、氧化还原性、热稳定性）→ **反应**（用第 3 章的热力学裁判 $\Delta_\mathrm{r}G$ 或 $Q$ vs $K$ 定量确认）→ **应用**（工业、材料、生命）。每个环节的"反常"都是次级效应的信号：镧系收缩、惰性电子对效应、缺电子性、晶体场稳定化能、相对论效应（6p 重元素，本节点到）。

## 4.2 s 区：碱金属与碱土金属的水化学

**结构**：ns¹/ns²，低电离能（Li 520 → Cs 375 kJ/mol 递减），单一稳定氧化态 +1/+2。第一电离能低而第二电离能剧增（如 Na：496 → 4562 kJ/mol），故无 +2——这是量子力学直接"规定"的化学。

**性质 → 反应**：
- **与水反应**：$2\mathrm{Na} + 2\mathrm{H_2O} \to 2\mathrm{NaOH} + \mathrm{H_2}\uparrow$。剧烈程度 Li < Na < K < Rb < Cs（熔点降低、产物溶解更好、表面更新更快——**动力学**递增），但 $E^\ominus(\mathrm{Li^+/Li}) = -3.04~\mathrm{V}$ 反而最负——**热力学与动力学方向相反**。Li 电势极负的一半功劳属于 $\mathrm{Li^+}$ 的强水合（水合焓约 −520 kJ/mol，比 Na⁺ 负 170），这正是锂原电池能量密度高的化学根源（练习 4-1）。
- **碱土与水**：Be 表面致密氧化膜不反应；Mg 热水缓慢；Ca/Sr/Ba 冷水即反应，氢氧化物碱性递增、溶解度递增（$\mathrm{Mg(OH)_2}$ 难溶——乳浊液"镁乳"制胃酸中和剂；$\mathrm{Ba(OH)_2}$ 可溶）。硫酸盐溶解度**递减**（BaSO₄ 最低，$K_\mathrm{sp} = 1.08\times10^{-10}$，且不被 X 光穿透——"钡餐"）。碳酸盐热稳定性**递增**（4.3.2 节用反极化统一解释）。
- **对角线规则**（diagonal relationship）：Li–Mg、Be–Al、B–Si 因"半径/电荷比"相近而性质相似：Li 与 Mg 一样生成直接稳定的氮化物 $\mathrm{Li_3N}$、碳酸盐热分解、氟化物/磷酸盐难溶。周期表斜向的"等效性"是极化力（$z/r^2$）这一结构参数跨越主族的体现。

**应用**：钠（NaK 合金核反应堆载热剂）、锂（电池）、铍（X 射线窗口）、钙（骨、水泥 $\mathrm{CaO\cdot SiO_2}$ 体系）、硬水软化（$\mathrm{Ca^{2+}}$ 以碳酸盐沸石法/离子交换法除去——回引第 3 章沉淀平衡与第 5 章离子交换）。

## 4.3 p 区：以成键图像分族推进

### 4.3.1 硼族（13 族）：缺电子性

**结构**：ns²np¹，价电子 3 < 价轨道数 4 → **缺电子**（electron-deficient）。

- **三卤化硼**：$\mathrm{BF_3}$ 平面三角形，B 有一空 p 轨道 → 强 Lewis 酸；B–F 键实测 130 pm，比单键理论值短——F 的 p 孤对向 B 空 p 轨道反馈形成 pπ–pπ 大 π 键。此反馈 F > Cl > Br，故 Lewis 酸性顺序为 $\mathrm{BF_3 < BCl_3 < BBr_3}$——与电负性直觉相反，是"结构图像推翻直觉"的教科书案例（[模块六](/xiaoshus-blog/textbooks/chemistry/06-organic/01/)中 $\mathrm{BF_3}$ 作傅–克催化Lewis酸即用此性）。
- **硼酸的电离方式反常**：$\mathrm{B(OH)_3 + H_2O \rightleftharpoons [B(OH)_4]^- + H^+}$，$K_a = 5.8\times10^{-10}$。它不是给出自身质子（根本没有酸性 OH 之外的氢），而是**加合 OH⁻ 释放水合质子**——Lewis 酸性伪装成 Brønsted 酸。因此硼酸滴定须加甘油/甘露醇把 B 转为螯合性强酸（回引第 3 章 3.5 螯合效应，前向模块三）。
- **乙硼烷 $\mathrm{B_2H_6}$**：12 个价电子撑不起 7 条普通二中心键（需 14 个），两条 **三中心两电子桥键**（3c–2e）填平账目（X 射线与振动光谱证据：两个桥 H，末端 4 个 H 正常 B–H）。缺电子多中心键是[模块五分子轨道理论](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/01/)在无机化学的第一个胜利，也是硼氢化反应（有机合成的重要工具）的化学基础。

### 4.3.2 碳族（14 族）：从分子到网络的两极

- **CO₂ vs SiO₂**：同为"氧化物"，CO₂ 是线性小分子气体（C=O 双键强），SiO₂ 是 Si–O 四面体共价网络（Si–O 键能约 452 kJ/mol 且 Si 无低能 pπ–pπ 双键途径）——**结构决定聚集态**，一冷至 −78 °C 成干冰、一熔于 1710 °C。硅的"类似物"化学（硅酸盐、沸石分子筛，[模块四表面胶体](/xiaoshus-blog/textbooks/chemistry/04-physical/01/)与工业催化）皆源于此网络。
- **水解能力反例**：$\mathrm{SiCl_4}$ 遇水剧烈水解（$\mathrm{SiCl_4 + 4H_2O \to SiO_2\cdot xH_2O + 4HCl}$，热力学上由极强的 Si–O 键驱动），而 $\mathrm{CCl_4}$ 不水解。旧解释"碳无 d 轨道"已被修正：$\mathrm{CCl_4}$ 水解**热力学可行、动力学禁阻**（碳的价层饱和且无低能量亲核进攻路径，协同取代需越过高能过渡态）。区分热力学与动力学——第 3 章 3.9 节误区 6 的元素化学实例。
- **碳酸盐的热稳定性（反极化理论）**：$\mathrm{CO_3^{2-}}$ 的稳定性取决于金属阳离子对 $\mathrm{O^{2-}}$ 端的极化（争夺电子、削弱 C–O）——阳离子电荷越高、半径越小，极化越强，分解温度越低：

$$\mathrm{BeCO_3}(<100\,^\circ\mathrm{C}) < \mathrm{MgCO_3}(540\,^\circ\mathrm{C}) < \mathrm{CaCO_3}(900\,^\circ\mathrm{C}) < \mathrm{SrCO_3}(1290\,^\circ\mathrm{C}) < \mathrm{BaCO_3}(1360\,^\circ\mathrm{C})$$

$\mathrm{H^+}$ 是极化力最强的"阳离子"，故酸式碳酸盐分解温度更低、$\mathrm{(NH_4)_2CO_3}$ 最易分解（练习 4-2）。**灰岩–白云岩的地貌循环**（$\mathrm{CaCO_3 + CO_2 + H_2O \rightleftharpoons Ca(HCO_3)_2}$，正反应溶蚀成溶洞、逆反应沉积成钟乳石）就是这张极化-平衡账的亿年尺度重演。

### 4.3.3 氮族（15 族）：键能与惰性电子对

- **$\mathrm{N_2}$ 的惰性**：N≡N 键能 946 kJ/mol（仅次于 CO），HOMO–LUMO 能隙大——固氮之难在此；工业 Haber 法（例 3-1）与豆科根瘤菌固氮酶（4.7 节）殊途同归。
- **白磷 $\mathrm{P_4}$**：60° 张力角（比正常 p 轨道夹角 90° 更小），应变能高 → 白磷自燃、剧毒；红磷/黑磷无此张力而稳定。**同素异形体不是"同种元素的平行宇宙"，是同一结构账本的不同折旧方式。**
- **硝酸**：浓硝酸还原产物 $\mathrm{NO_2}$、稀硝酸 $\mathrm{NO}$（还原产物由 $E(\mathrm{NO_3^-}/\text{还原产物})$ 随酸度与浓度变化决定，第 3 章 3.4 节的 Nernst 逻辑）；冷浓硝酸使 Fe、Al、Cr 钝化（表面致密氧化物动力学屏障）。
- **惰性电子对效应（inert pair effect）**：13/14/15 族自上而下，ns² 电子对随有效核电荷增大越来越难参与成键 → 低价态稳定性上升：$\mathrm{Tl(I) > Tl(III)}$、$\mathrm{Pb(II) > Pb(IV)}$、$\mathrm{Bi(III) > Bi(V)}$。因此 $\mathrm{PbO_2}$（$E^\ominus(\mathrm{PbO_2/Pb^{2+}}) = 1.46~\mathrm{V}$）与 $\mathrm{NaBiO_3}$ 是强氧化剂——$\mathrm{NaBiO_3}$ 在硝酸中把 $\mathrm{Mn^{2+}}$ 氧化成紫色 $\mathrm{MnO_4^-}$，是分析化学鉴定 Mn²⁺ 的经典反应（前向模块三）。**"同一元素不同氧化态的相对稳定性"从来是热力学问题**（回引第 3 章 3.4.4）。

### 4.3.4 氧族（16 族）

- **O₂ 顺磁性**：分子轨道理论 $\pi^{*2p}$ 两个单电子（[模块一第 2 章](/xiaoshus-blog/textbooks/chemistry/01-foundations/02/)埋设、模块五定量化）——磁天平实验是 MO 理论压倒价键理论的判据性证据。$\mathrm{O_3}$ 弯曲形（117°）、抗磁、$E^\ominus(\mathrm{O_3/O_2}) = 2.07~\mathrm{V}$ 强氧化剂（饮水消毒）。
- **$\mathrm{H_2O_2}$ 的氧化还原两栖**：$E^\ominus(\mathrm{H_2O_2/H_2O}) = 1.78~\mathrm{V}$（酸性，氧化剂）、$E^\ominus(\mathrm{O_2/H_2O_2}) = 0.68~\mathrm{V}$（还原剂）。两个电势都高于/低于水的电对之一，故 $\mathrm{H_2O_2}$ 热力学上可歧化（$2\mathrm{H_2O_2} \to 2\mathrm{H_2O} + \mathrm{O_2}$，无催化剂时动力学缓慢，$\mathrm{MnO_2}$、过氧化氢酶催化——4.7 节呼应）。实验室"绿色"氧化剂：氧化产物是水。
- **过氧化钠供氧**：$\mathrm{2Na_2O_2 + 2CO_2 \to 2Na_2CO_3 + O_2}$（潜艇/矿井呼吸药板：把呼出的 CO₂ 变成 O₂，一箭双雕）。
- **硫酸工业**（接触法）：$\mathrm{S \to SO_2 \xrightarrow[V_2O_5]{O_2} SO_3 \xrightarrow{H_2O} H_2SO_4}$；V₂O₅ 催化剂的氧化态循环 V⁵⁺/V⁴⁺ 是"氧化还原催化"的原型（衔接模块四催化章节）。

### 4.3.5 卤族（17 族）：氢键与含氧酸规则

- **HF 弱酸**：$\mathrm{p}K_a = 3.17$，而 HCl/HBr/HI 全强酸。原因双重：H–F 键短而强、F⁻ 半径小水合焓极负——解离的**熵焓账都吃亏**；浓溶液中氢键缔合 $(\mathrm{HF})_n$ 使酸性回升并生成 $\mathrm{HF_2^-}$。HF 与 $\mathrm{SiO_2}$ 反应（$\mathrm{SiO_2 + 4HF \to SiF_4\uparrow + 2H_2O}$）用于刻蚀玻璃——"最弱酸的独门绝技"由 Si–F 键的极高键能买单（练习 4-1 的姊妹题）。
- **含氧酸强度的 ROH 规则**：把含氧酸看成 $(\mathrm{HO})_m\mathrm{EO}_n$，末端非羟基 O 越多，E 的吸电子越强、O–H 越易解离：

$$\mathrm{HClO\ (p}K_a\ 7.54) < \mathrm{HClO_2\ (1.96)} < \mathrm{HClO_3\ (\approx-1)} < \mathrm{HClO_4\ (\text{最强})}$$

同氧化态跨族：$\mathrm{HOCl(7.54) > HOBr(8.69) > HOI(10.64)}$。一个结构参数（非羟基 O 数）串起整族酸碱定量数据。
- **氧化性 F₂ > Cl₂ > Br₂ > I₂**：$E^\ominus$ = 2.87 / 1.36 / 1.09 / 0.54 V，与电负性一致；但水溶液中实际氧化能力还受 pH 与歧化/配位干扰（Cl₂ 歧化于碱：$\mathrm{Cl_2 + 2OH^- \to Cl^- + ClO^- + H_2O}$，漂白液；热浓碱得 $\mathrm{ClO_3^-}$——产物由温度对歧化动力学路径的选择决定）。

### 4.3.6 稀有气体（18 族）：被"打破"的族

1962 年 Bartlett 用 $\mathrm{PtF_6}$（电离能参照 $\mathrm{O_2}$ 的 1175 kJ/mol 类推 Xe 的 1170 kJ/mol）氧化 Xe，宣告"惰性气体"神话终结。结构–性质路线的成功预测：
- $\mathrm{XeF_2}$ 直线形（3c–4e 三中心键，与 $\mathrm{B_2H_6}$ 桥键同一多中心账本）、$\mathrm{XeF_4}$ 平面四方形（AX₄E₂，VSEPR 两对孤对反位——[模块一第 2 章]VSEPR 的胜利）、$\mathrm{XeF_6}$ 畸变八面体（一对立体活性孤对）。
- $\mathrm{XeO_3}$ 三角锥形、强爆性；$\mathrm{XeF_2}$ 是温和氟化剂、不影响双键——有机氟化学的精细工具。

## 4.4 d 区：过渡金属价层电子与氧化态规律

### 4.4.1 通性

价层 $(n-1)\mathrm{d}^{\,1\sim10}n\mathrm{s}^{\,1\sim2}$，d 与 s 能级近简并 → **多氧化态**（第一过渡系最高氧化态在 Mn 达 +7，随后回落——d 电子对核电荷的"屏蔽预算"用尽）；同族自上而下**高价态更稳定**（4d/5d 半径大、成键更强，Mn(VII) 是最强氧化剂而 Re(VII) 稳定）。第一过渡系 $\mathrm{M^{2+}/M}$ 电势（25 °C，酸性）：

| 电对 | Ti²⁺/Ti | V²⁺/V | Cr²⁺/Cr | Mn²⁺/Mn | Fe²⁺/Fe | Co²⁺/Co | Ni²⁺/Ni | Cu²⁺/Cu |
|---|---|---|---|---|---|---|---|---|
| $E^\ominus$/V | −1.63 | −1.18 | −0.91 | −1.18 | −0.45 | −0.28 | −0.26 | **+0.34** |

Cu 的 $E^\ominus > 0$：**铜不与稀盐酸/稀硫酸放氢**（练习 4-6 的对照面）。

### 4.4.2 第一过渡系重点元素（按氧化态化学速览）

**Cr（铬）**：$\mathrm{Cr^{3+}}$（d³，紫/绿色）在酸碱中都最稳定（动力学惰性，见 4.6.5）；$\mathrm{Cr_2O_7^{2-}}/\mathrm{Cr^{3+}}$（$E^\ominus = 1.36~\mathrm{V}$，酸）与 $\mathrm{CrO_4^{2-}}/\mathrm{Cr(OH)_3}$（$E^\ominus = -0.13~\mathrm{V}$，碱）——**碱性中把 Cr(III) 氧化成 Cr(VI) 容易，酸性中把 Cr(VI) 还原成 Cr(III) 容易**，同一元素氧化态的"安全区"由介质翻转。黄/橙平衡 $\mathrm{2CrO_4^{2-} + 2H^+ \rightleftharpoons Cr_2O_7^{2-} + H_2O}$（$K \approx 10^{14}$）是颜色指示酸度的活探针。$\mathrm{Cr(OH)_3}$ 两性：溶于过量碱成 $\mathrm{[Cr(OH)_4]^-}$。应用：不锈钢钝化膜（$\mathrm{Cr_2O_3}$）、铬鞣、镀铬；Cr(VI) 剧毒致癌（工业废水必须还原–沉淀两步法治理：先 $\mathrm{SO_2}$ 还原成 Cr(III) 再调 pH 沉淀——第 3 章两节知识的直接串联）。

**Mn（锰）**：氧化态 −3 至 +7 全谱（价层 d⁵s² 半满起点）。$\mathrm{MnO_4^-}$（d⁰，紫色）酸中 $E^\ominus = 1.512~\mathrm{V}$ 滴定级氧化剂且**自身指示终点**（紫→近无色）；碱性中被还原成绿色 $\mathrm{MnO_4^{2-}}$、中性得棕色 $\mathrm{MnO_2}$——**同一氧化剂三种价态产物由 pH 仲裁**（Nernst 的可视化）。$\mathrm{MnO_2}$ 双重身份：$\mathrm{H_2O_2}$ 歧化的催化剂与干电池正极；$\mathrm{Mn^{2+}}$ 粉红色（d⁵ 自旋禁阻 d–d 跃迁，颜色浅的原因，见 4.6.2）。

**Fe（铁）**：地壳丰度第一金属、核的终点（核聚变到 Fe 放能止）。$\mathrm{Fe^{2+}}$（浅绿）/ $\mathrm{Fe^{3+}}$（$E^\ominus = 0.771~\mathrm{V}$）可逆对是生物电子传递的通用货币（4.7 节）；$\mathrm{Fe^{3+}}$ 强水解（pKa ≈ 2.2，比醋酸还强——高电荷小半径的极化力），中性水即沉淀 $\mathrm{Fe(OH)_3}$ 胶体，这是 4.3.2 节极化账的阳离子版。鉴定：$\mathrm{Fe^{3+} + nSCN^- \to}$ 血红 $[\mathrm{Fe(SCN)}]^{2+}$；$\mathrm{K_4[Fe(CN)_6]}$ 与 $\mathrm{Fe^{3+}}$ 生成普鲁士蓝（混合价电荷迁移着色，ε 极大）。最高价 $\mathrm{FeO_4^{2-}}$（高铁酸盐，紫色）酸性 $E^\ominus \approx 2.2~\mathrm{V}$ 超过 $\mathrm{MnO_4^-}$，且还原产物 $\mathrm{Fe(OH)_3}$ 絮凝——水处理"氧化+混凝"一步完成。

**Co（钴）/ Ni（镍）**：$\mathrm{Co^{3+}}$ 水合离子 $E^\ominus(\mathrm{Co^{3+}/Co^{2+}}) = 1.82~\mathrm{V}$ 氧化水不能稳定存在；但配位后 $E^\ominus([\mathrm{Co(NH_3)_6}]^{3+}/[\mathrm{Co(NH_3)_6}]^{2+}) \approx +0.1~\mathrm{V}$——**配体把 +3 价"救活"**（例题 4-2 定量），所以钴化学以 Co(III) 配合物为主、二氯化钴六水合物粉红⇄无水蓝色是湿度指示硅胶的显色剂。Ni：氧化态 +2 一枝独秀；$\mathrm{Ni(CO)_4}$（Mond 法提纯镍，50 °C 生成、230 °C 分解，18 电子规则的标准样本，bp 43 °C）是"配合物即分离工具"的经典；镍氢电池与加氢催化剂 Raney Ni。

**Cu（铜）**：d¹⁰s¹。Cu(I) 与 Cu(II) 竞争：水溶液中 $\mathrm{Cu^+}$ 歧化（$E^\ominus$ 图 $\mathrm{Cu^{2+}\xrightarrow{0.159}Cu^+\xrightarrow{0.521}Cu}$，右 > 左——第 3 章 3.4.4 判据直接命中），但 $\mathrm{CuI}$（$K_\mathrm{sp} = 1.1\times10^{-12}$）、$\mathrm{CuCN}$、$\mathrm{Cu_2O}$ 中 Cu(I) 稳定——**沉淀/配位"冻结"了歧化**（例题 4-3 完整计算）。$\mathrm{[Cu(H_2O)_6]^{2+}}$ 天蓝、氨配位后深蓝 $[\mathrm{Cu(NH_3)_4(H_2O)_2}]^{2+}$（拉长八面体，Jahn–Teller，见 4.6.2）。

**Zn（锌）**：d¹⁰s²，无部分填充 d——严格说非"过渡元素"，无 d–d 颜色、无晶体场稳定化能。$\mathrm{Zn(OH)_2}$ 两性、易配位（四氨/四羟基），锌–碳与碱性电池负极、黄铜、镀锌牺牲阳极防腐（$E^\ominus(\mathrm{Zn^{2+}/Zn}) = -0.762~\mathrm{V}$ 的电化学应用）。

## 4.5 f 区概览：镧系收缩与分离

- **镧系收缩（lanthanide contraction）**：4f 电子对核电荷屏蔽差，$\mathrm{Ln^{3+}}$ 半径从 La³⁺ 103 pm（六配位 Shannon 值）平滑降到 Lu³⁺ 86 pm。两大约束性后果：① 第三过渡系受其"垫高"，$\mathrm{Zr^{4+}}$（72 pm）与 $\mathrm{Hf^{4+}}$（71 pm）几乎同半径 → 化学性质孪生、分离是工业难题；② 镧系内部碱性随原子序数递减（半径小、极化强、$\mathrm{Ln(OH)_3}$ 更难电离出 OH⁻）。
- **氧化态**：+3 一统天下（4f 轨道深埋原子芯区、不参与成键——与 d 区截然相反）；例外都有"对称红利"：$\mathrm{Ce^{4+}}$（4f⁰ 空壳，$E^\ominus(\mathrm{Ce^{4+}/Ce^{3+}}) \approx 1.6~\mathrm{V}$，铈量法滴定剂，前向模块三）、$\mathrm{Eu^{2+}}$（4f⁷ 半满）、$\mathrm{Yb^{2+}}$（4f¹⁴ 全满）。
- **分离**：半径差 17 pm 摊到 14 个元素，单级化学无法完成，必须**多级放大**——现代溶剂萃取（酸性磷类萃取剂 P507/P204，数千级混合澄清槽）与离子交换色谱（螯合树脂 + 淋洗剂，利用 $\beta_n$ 的微小差异逐级洗脱，正是第 3 章 3.5 节稳定常数的工业级应用）。
- **应用**：$\mathrm{Nd_2Fe_{14}B}$ 永磁体、$\mathrm{Eu^{3+}}$ 红色荧光粉、$\mathrm{CeO_2}$ 汽车三效催化剂（储放氧缓冲）、钇铝石榴石 YAG 激光。

## 4.6 配位化学深化

### 4.6.1 配合物与价键理论

Werner（1893）区分主价/副价（离子在外界、中性配体在内界）奠定了配位化学；[模块一第 2 章 2.2 节](/xiaoshus-blog/textbooks/chemistry/01-foundations/02/)的杂化轨道图像在配合物上得到最系统的应用——**价键理论**（valence bond theory）：

- **内轨型**：使用 $(n-1)\mathrm{d}$ 杂化（$\mathrm{d^2sp^3}$ 八面体、$\mathrm{dsp^2}$ 平面四方），要求内层 d 腾空 → 强场配体、低自旋；
- **外轨型**：使用 $n\mathrm{d}$ 杂化（$\mathrm{sp^3d^2}$、$\mathrm{sp^3}$），高自旋。

磁矩是判据（自旋公式 $\mu = \sqrt{n(n+2)}~\mu_\mathrm{B}$，$n$ 为未成对电子数）。例题 4-1 完整演示。**价键理论的局限**：不能解释颜色与光谱化学序列、对 $\mathrm{d^8}$ 平面四方的预测时灵时不灵、把"成对"当作配体强弱的因而不是果——这些缺口由晶体场/配位场理论补上。

### 4.6.2 晶体场理论（crystal field theory, CFT）

**模型**：把配体当作六个点负电荷，金属 d 轨道在八面体静电场中分裂——正对配体的 $\mathrm{e_g}(d_{z^2}, d_{x^2-y^2})$ 升高，避开配体的 $\mathrm{t_{2g}}(d_{xy}, d_{yz}, d_{xz})$ 降低，**重心不变**（静电场不做净功，能量只是重新分配）：

$$E(\mathrm{e_g}) = +0.6\Delta_\mathrm{o},\qquad E(\mathrm{t_{2g}}) = -0.4\Delta_\mathrm{o}$$

$\Delta_\mathrm{o}$（分裂能）由吸收光谱直接测出（光学证据闭环：$\Delta_\mathrm{o} = N_\mathrm{A}hc/\lambda_\text{max}$）。

**（a）高自旋/低自旋与 CFSE**。d⁴–d⁷ 时面临选择：进入 $\mathrm{e_g}$ 避开成对能 $P$，还是挤进 $\mathrm{t_{2g}}$ 付出 $P$。判据 $\Delta_\mathrm{o}$ vs $P$。**晶体场稳定化能**（CFSE，相对球形场）：

| dⁿ | 高自旋组态 | CFSE（Δₒ 单位） | 低自旋组态 | CFSE |
|---|---|---|---|---|
| d⁴ | t₂g³e_g¹ | −0.6 | t₂g⁴ | −1.6 + P |
| d⁵ | t₂g³e_g² | 0 | t₂g⁵ | −2.0 + 2P |
| d⁶ | t₂g⁴e_g² | −0.4 | t₂g⁶ | −2.4 + 2P |
| d⁷ | t₂g⁵e_g² | −0.8 | t₂g⁶e_g¹ | −1.8 + P |

（成对能项 $P$ 是相对自由离子额外付出的成对数。）d⁰、d⁵（高自旋）、d¹⁰ 无 CFSE——$\mathrm{Mn^{2+}}$ 水合焓落在同周期平滑趋势线上、颜色浅，皆因 CFSE = 0。

**（b）$\Delta_\mathrm{o}$ 的影响因素**（光谱化学序列，spectrochemical series）：

$$\mathrm{I^- < Br^- < S^{2-} < SCN^- < Cl^- < F^- < OH^- < C_2O_4^{2-} < H_2O < NCS^- < py < NH_3 < en < bipy < phen < NO_2^- < CN^- \approx CO}$$

- 同一配体：金属氧化态越高 $\Delta$ 越大（$[\mathrm{Co(H_2O)_6}]^{2+}$ 9 300 cm⁻¹ → $[\mathrm{Co(H_2O)_6}]^{3+}$ 18 200 cm⁻¹）；
- 同一金属同价：4d ≈ 1.5 × 3d，5d ≈ 1.25 × 4d（径向延展、共价增强）——所以第二、三过渡系几乎全是低自旋；
- 序列两端无法用"静电点电荷"解释（中性 CO 反而最强场）→ 需要配位场理论的 π 效应（4.6.3）。

**（c）四面体与平面四方形**。四面体场 $\Delta_\mathrm{t} = \frac{4}{9}\Delta_\mathrm{o}$（配体少、无正对轨道）→ 通常总为高自旋；$\mathrm{d^8}$ 的 Pt(II)、Pd(II) 及强场 Ni(II) 取平面四方形（可视为极端拉长的八面体，$\mathrm{d_{x^2-y^2}}$ 单独推至最高）。

**（d）Jahn–Teller 效应**：简并电子态不稳定，分子自动畸变消除简并。$\mathrm{Cu^{2+}}$（d⁹，$\mathrm{t_{2g}^6e_g^3}$——$\mathrm{e_g}$ 上有一个空位即简并未消）强烈畸变为**四个短键两个长键**的拉长八面体；高自旋 d⁴（$\mathrm{Mn^{3+}}$、$\mathrm{Cr^{2+}}$）同理。这是"电子结构直接规定几何构型"的最干净案例，也解释了 $\mathrm{CuSO_4\cdot5H_2O}$ 晶体中配位水的 4+1+1 排布。

**（e）颜色**：d–d 跃迁在中心对称八面体场中 Laporte 禁阻 → 摩尔吸光系数小（ε ≈ 1–100 L·mol⁻¹·cm⁻¹），四面体无对称中心则强数倍；电荷迁移跃迁（配体→金属或金属→金属）Laporte 允许、ε 达 10³–10⁴——$\mathrm{MnO_4^-}$ 的深紫、普鲁士蓝的深蓝都是电荷迁移而非 d–d。

### 4.6.3 从晶体场到配位场理论：π 效应统一光谱化学序列

把配体从"点电荷"升级为"有价轨道的分子"（分子轨道法，[模块五](/xiaoshus-blog/textbooks/chemistry/05-structural-quantum/01/)定量化）：

- **π 给体**（Cl⁻、F⁻、OH⁻、H₂O 弱端）：配体满充 π 轨道与金属 $\mathrm{t_{2g}}$ 作用 → $\mathrm{t_{2g}}$ 变为**反键**而升高 → $\Delta_\mathrm{o}$ 变小（序列左端）；
- **π 受体**（CO、CN⁻、NO₂⁻、bipy）：配体空 π* 轨道与金属 $\mathrm{t_{2g}}$ 作用 → $\mathrm{t_{2g}}$ 变为**成键**而降低，同时金属电子反馈进 π*（反馈键）→ $\Delta_\mathrm{o}$ 变大（序列右端）。

一个 π 图像同时解释了"中性 CO 为何最强场"与"$\mathrm{CN^-}$ 为何能稳定低价金属"（4.6.5 的电子转移与第 3 章 3.6.4 的电势移动在此获得电子结构根源）。

### 4.6.4 异构现象（以 $\mathrm{[Co(NH_3)_4Cl_2]^+}$ 家族为例）

| 类型 | 实例 | 判别手段 |
|---|---|---|
| 电离异构 | $\mathrm{[Co(NH_3)_5Br]SO_4}$ vs $\mathrm{[Co(NH_3)_5SO_4]Br}$ | 沉淀反应指向外界离子 |
| 水合异构 | $\mathrm{[Cr(H_2O)_6]Cl_3}$（紫）/ $\mathrm{[Cr(H_2O)_5Cl]Cl_2\cdot H_2O}$（绿）/ $\mathrm{[Cr(H_2O)_4Cl_2]Cl\cdot 2H_2O}$ | 摩尔电导与 AgCl 沉淀量 |
| 键合异构 | $\mathrm{NO_2^-}$ 硝基(N)/亚硝酸根(O)；$\mathrm{SCN^-}$ N 端/S 端 | 红外 ν(N–O)、ν(C–N) 特征带 |
| 几何异构 | 八面体 $\mathrm{MA_4B_2}$ 顺/反；$\mathrm{[Pt(NH_3)_2Cl_2]}$ 顺铂/反铂 | 偶极矩、X 射线；顺铂抗癌而反铂无效 |
| 旋光异构 | $\mathrm{[Co(en)_3]^{3+}}$ 的 Δ/Λ 手性对 | 旋光度、圆二色谱（拆分用 d-酒石酸盐沉淀其一） |

顺式 $\mathrm{[Co(NH_3)_4Cl_2]^+}$ 有镜面而无手性；把两个 $\mathrm{NH_3}$ 换成双齿 en（$\mathrm{[Co(en)_2Cl_2]^+}$）立即出现旋光对——**手性由"配体咬合的几何约束"涌现**（练习 4-7）。

### 4.6.5 反应机理：取代与电子转移

**取代（八面体）**：速率谱系用"活性（labile）/惰性（inert）"描述（Taube 定义：25 °C、约 0.1 mol/L 下半分钟内完成者为活性）。规律来自 CFSE 的**活化能贡献**（形成取代过渡态时要部分拆除配位键、损失 CFSE）：$\mathrm{d^3}$（Cr³⁺）与低自旋 $\mathrm{d^6}$（Co³⁺、Rh³⁺、Ir³⁺）——CFSE 大的组态——显著惰性；$\mathrm{d^{10}}$（Zn²⁺）、高自旋 $\mathrm{d^4}$ 等很快。取代路径 D（解离）/A（缔合）/I（交换），八面体以 I/d 为主，平面四方 Pt(II) 以 A 为主并受**反位效应**（trans effect）支配：已配位配体活化其反位位置的能力 $\mathrm{OH^- < NH_3 < Cl^- < Br^- < I^- < NO_2^- < CN^- \approx CO}$。顺铂的合成路线正是反位效应的工程应用：$\mathrm{[PtCl_4]^{2-}}$ 加氨得**顺式**（第二个 NH₃ 进入 Cl⁻ 反位），$\mathrm{[Pt(NH_3)_4]^{2+}}$ 加盐酸得**反式**（第二个 Cl⁻ 进入 Cl⁻ 反位）。

**电子转移**：
- **外界机理**（outer-sphere）：两配合物外壳接触，电子穿越配位层（无键断裂），速率由重组能决定——Marcus 理论（模块四第 7 章深化）。$\mathrm{[Fe(CN)_6]^{3-}/[Fe(CN)_6]^{4-}}$ 自交换速率 >10⁵ L·mol⁻¹·s⁻¹（结构几乎不重组）是其标志。
- **内界机理**（inner-sphere，Taube 1950s，1983 诺奖）：桥连配体既是"路由器"又随电子"搬家"。样板反应与判别分析见练习 4-8；判据是产物携带原桥配体（放射性 Cl 标记实验），前提是**一端活性（易被桥连）+ 产物端惰性（保住桥键）**——4.6.5 取代动力学直接服务机理判定。

| 体系 | 金属 | 结构 | 功能与化学本质 |
|---|---|---|---|
| 血红蛋白/肌红蛋白 | Fe(II) | 原卟啉 IX（四 N 平面配位）+ 近端 His 轴向 + O₂ 第 6 位 | O₂ 与 Fe(II) 的可逆配位（不是氧化成 Fe(III)——蛋白质口袋与 His 拉低 O₂/Fe 反应的电势）；CO 中毒 = CO 与 Fe 亲和力约为 O₂ 的 200 倍以上、占据第 6 配位位 |

## 4.9 典型例题与解题思路

### 例题 4-1（基础）价键理论判定结构与磁性：$\mathrm{[NiCl_4]^{2-}}$ 与 $\mathrm{[Ni(CN)_4]^{2-}}$

**题**：实测前者顺磁（μ ≈ 2.8 μB）四面体、后者反磁平面四方形。用价键理论解释。

**思路**：Ni²⁺ 为 3d⁸（3 个 d、1 个 s、3 个 p 价轨道）。磁矩反推单电子数：$\mu = \sqrt{n(n+2)} = 2.8 \Rightarrow n = 2$。

**解**：$\mathrm{[NiCl_4]^{2-}}$：Cl⁻ 弱场，3d 保持 $t$ 组态（3d⁸ 有 2 个单电子）不腾空，用最外层 $\mathrm{sp^3}$ 杂化成四面体、外轨型，2 个单电子，$\mu = \sqrt{8} = 2.83~\mu_\mathrm{B}$ ✓。

$\mathrm{[Ni(CN)_4]^{2-}}$：CN⁻ 强场使 3d 两个单电子成对（d⁸ 重排后空出 1 条 $d_{x^2-y^2}$），用 $\mathrm{dsp^2}$ 杂化成平面四方形、内轨型，0 单电子，$\mu = 0$ ✓。

**延伸**：d⁸ 的平面四方也由配位场理论给出（$\mathrm{d_{x^2-y^2}}$ 轨道能级远高于其他 → 电子全部进入低层轨道），且 Pt(II)（4d 半径大、$\Delta$ 大）永远走平面四方——价键理论与 CFT 在此会合。注意磁矩数据先于理论：是抗磁性实验"逼迫"出内轨假设（理论–证据闭环）。

### 例题 4-2（综合）CFSE 与氧化态的稳定化：$\mathrm{[CoF_6]^{3-}}$ 与 $\mathrm{[Co(NH_3)_6]^{3+}}$

**题**：计算两者的自旋组态、未成对电子数、磁矩与 CFSE；并解释为何水溶液中 Co³⁺ 不稳定（$E^\ominus = 1.82~\mathrm{V}$）而氨配合物可以被 $\mathrm{[Co(NH_3)_6]^{2+}}$ 的空气氧化顺利制备（$E^\ominus \approx +0.1~\mathrm{V}$）。

**思路**：Co³⁺ = d⁶。CFSE 表（4.6.2）查 d⁶ 高/低自旋；电势差用热力学语言统一（第 3 章 3.6.4：配位 = 改写 $E^\ominus$）。

**解**：

$[\mathrm{CoF_6}]^{3-}$：F⁻ 弱场，$\Delta_\mathrm{o} < P$ → 高自旋 $\mathrm{t_{2g}^4e_g^2}$，4 个单电子，$\mu = \sqrt{4\times6} = 4.9~\mu_\mathrm{B}$；CFSE $= [4(-0.4) + 2(0.6)]\Delta_\mathrm{o} = -0.4\Delta_\mathrm{o}$（额外成对 0，因自由离子 d⁶ 本有 1 对，组态中也是 1 对）。

$[\mathrm{Co(NH_3)_6}]^{3+}$：NH₃ 中强场、且 Co³⁺ 高电荷使 $\Delta_\mathrm{o}$ 翻倍以上 → $\Delta_\mathrm{o} > P$ → 低自旋 $\mathrm{t_{2g}^6}$，0 单电子，$\mu = 0$；CFSE $= -2.4\Delta_\mathrm{o} + 2P$（组态 3 对，自由离子 1 对，**额外** 2 对）。

热力学账：Co(III) 低自旋多赚 $2.0\Delta_\mathrm{o}$（$-2.4$ 对 $-0.4$）量级的晶体场稳定化，远超 Co(II)（d⁷）低/高自旋差（至多 $1.0\Delta_\mathrm{o}$）——**强场配体使 Co(III) 比 Co(II) 相对更稳定**，宏观上即 $E^\ominus$ 从 1.82 V 崩落到 0.1 V，低于 $\mathrm{O_2/H_2O}$（1.23 V）氧化所需门槛的反向要求，空气即可氧化。量纲检查：μ 单位玻尔磁子 ✓；CFSE 用 Δₒ 与 P 作单位（能量/离子）✓。

### 例题 4-3（拓展）沉淀/配位如何"冻结"歧化：Cu(I) 的命运

**题**：已知 $E^\ominus(\mathrm{Cu^{2+}/Cu^+}) = 0.159~\mathrm{V}$，$E^\ominus(\mathrm{Cu^+/Cu}) = 0.521~\mathrm{V}$，$K_\mathrm{sp}(\mathrm{CuI}) = 1.1\times10^{-12}$。（a）计算水溶液中 $\mathrm{Cu^+}$ 歧化的平衡常数；（b）计算 $E^\ominus(\mathrm{CuI/Cu})$，说明为何 $\mathrm{Cu^{2+} + 4I^- \to 2CuI\downarrow + I_2}$（碘量法基础）中 Cu(I) 稳定。

**思路**：（a）歧化判据 + $\lg K = nE^\ominus_\text{池}/0.0592$（第 3 章 3.4.3）；（b）把 $K_\mathrm{sp}$ 折算进电势（第 3 章 3.6.4 的逆操作）。

**解**：

（a）歧化 $2\mathrm{Cu^+} \to \mathrm{Cu^{2+} + Cu}$：$E^\ominus_\text{池} = 0.521 - 0.159 = 0.362~\mathrm{V}$（右 > 左，自歧化 ✓）。

$$\lg K = \frac{nE^\ominus_\text{池}}{0.0592~\mathrm{V}} = \frac{0.362}{0.0592} = 6.11\ \Rightarrow\ K = 1.3\times10^{6}$$

（量纲检查：V/V 无量纲 ✓）——游离 $\mathrm{Cu^+}$ 在水中几乎定量歧化，无法存在。

（b）对半反应 $\mathrm{CuI(s) + e^- \to Cu(s) + I^-}$，把 Nernst 项中的 $[\mathrm{Cu^+}] = K_\mathrm{sp}/[\mathrm{I^-}]$ 代入 $\mathrm{Cu^+/Cu}$ 电对的标准态（$[\mathrm{I^-}] = 1$）：

$$E^\ominus(\mathrm{CuI/Cu}) = E^\ominus(\mathrm{Cu^+/Cu}) + 0.0592\lg K_\mathrm{sp} = 0.521 + 0.0592\times(-11.96) = -0.19~\mathrm{V}$$

（$-11.96 = \lg(1.1\times10^{-12})$。）于是体系实际电势图变为 $\mathrm{Cu^{2+}\xrightarrow{0.159}CuI\xrightarrow{-0.19}Cu}$：右 < 左，歧化不再自发，反而 $\mathrm{I^-}$ 把 89% 的 Cu(II) 还原为 Cu(I) 并同步沉淀（$2\mathrm{Cu^{2+} + 4I^- \to 2CuI\downarrow + I_2}$，$E^\ominus_\text{池} = 0.535 - 0.159 = 0.376~\mathrm{V} > 0$）——碘量法测铜的定量依据，前向[模块三](/xiaoshus-blog/textbooks/chemistry/03-analytical/01/)。**沉淀/配位改变氧化态稳定性，与例题 4-2 的晶体场机制互为宏观/微观两张账本。**

## 4.10 常见误区与易错点

1. **把 d⁵ 高自旋写错**：t₂g³e_g²（不是 t₂g⁵）；它 CFSE = 0 且 5 个单电子，是"零稳定化基准点"，许多水合焓/颜色对比题的锚。
2. **CFSE 忘记额外成对能**：低自旋 d⁶ 是 $-2.4\Delta_\mathrm{o} + 2P$，写成 $-2.4\Delta_\mathrm{o}$ 会把自旋态判据（$\Delta_\mathrm{o}$ vs $P$）做错。
3. ** Latimer 图电势算术平均**：强度量不可平均，必须 $nE$ 加权（第 3 章 3.4.4），跨章最高频计算错误。
4. **"强场配体一定低自旋"**：还取决于金属——3d⁵ 除非 CN⁻/CO 级别强场否则高自旋，而 4d/5d 几乎永远低自旋（$\Delta$ 行间放大）。
5. **混淆内界/外界机理与内轨/外轨杂化**：前者是电子转移动力学概念（桥连与否），后者是价键理论成键概念，两套"内/外"毫无关系。
6. **反位效应当反位影响**：前者是取代速率/位置效应（进入配体选择反位），后者是基态键长削弱（热力学），判据与机理层次不同。
7. **"Zn 是过渡元素所以有颜色"**：d¹⁰ 无 d–d 跃迁、无 CFSE，Zn/Cd 化合物白色，与相邻 Cu/Ni 的彩色化学形成对照（这正是考点）。
