# 模块三·进阶章 1（进阶）现代分析技术与化学计量学（1.10 节思考练习题）

## 1-1【概念辨析】LoD / LoQ

**对应正文**：1.1.1 节。

**标准答案要点**：LoD = $3s_{\text{blank}}/k$（3σ，能检出的最低量）；LoQ = $10s_{\text{blank}}/k$（10σ，能准确定量的最低量）。LoQ 浓度高于 LoD 因"定量"要求更严（误差 < 可接受范围）。S/N≥3 对应**检测限 LoD**（定量一般要求 S/N≥10）。IUPAC 1995 亦见 3.3σ 较严形式。

**常见错误**：① 把 LoQ 当比 LoD 低（实际更高）；② 认为 S/N≥3 是定量限。

## 1-2【计算】LoD / LoQ

**对应正文**：1.1.1 节。

**完整解**：$s=0.008$、$k=0.50\ \mathrm{(AU\cdot L/mmol)}$。

- LoD $=3\times0.008/0.50=0.024/0.50=\boxed{0.048\ \mathrm{mmol/L}}$。
- LoQ $=10\times0.008/0.50=0.080/0.50=\boxed{0.16\ \mathrm{mmol/L}}$。

**量纲检查**：$s/k$ 单位 = AU/(AU·L/mmol)=mmol/L ✓。

**常见错误**：① 把 $k$ 单位当 L/mol 致答案差 1000；② 漏 ×3 / ×10。

## 1-3【综合】FTIR 双优势

**对应正文**：1.2.1 节。

**标准答案要点**：

- **Fellgett（多路）优势**：干涉仪同时测所有频率（vs 色散仪逐频扫描），相同时间 S/N 更高。
- **Jacquinot（高通量）优势**：无狭缝限制，光通量高、灵敏度高。

传统色散扫描仪逐频扫 + 狭缝限光 ⇒ 慢且弱；FTIR 同时采 + 全通量 ⇒ 快且灵敏。

**常见错误**：① 把两优势混为一谈（一多路、一通量）；② 以为 FTIR 靠"更高光源"。

## 1-4【计算】NMR 频率

**对应正文**：1.2.2 节。

**完整解**：$\nu_0=\gamma B_0/2\pi=42.577\ \mathrm{MHz/T}\times11.7\ \mathrm T\approx498.16\ \mathrm{MHz}$（即"500 MHz 谱仪"）。$\Delta\nu=\Delta\delta\times\nu_0/10^6=0.05\times498.16\times10^6/10^6=\boxed{24.9\ \mathrm{Hz}}$。

**量纲检查**：ppm×MHz=Hz ✓。

**常见错误**：① 用 9.4 T 算（题给 11.7 T）；② 把 δ 当 Hz 直接减。

## 1-5【推导】van Deemter 最优

**对应正文**：1.3.2 节。

**完整解**：$H=A+B/u+Cu$。$\mathrm dH/\mathrm du=-B/u^2+C=0$ ⇒

$$u^*=\sqrt{B/C}$$

代回：$H_{\min}=A+B/\sqrt{B/C}+C\sqrt{B/C}=A+\sqrt{BC}+\sqrt{BC}=A+2\sqrt{BC}$。即

$$\boxed{u^*=\sqrt{B/C}},\qquad \boxed{H_{\min}=A+2\sqrt{BC}}$$

**量纲检查**：$B/u$ 与 $Cu$ 单位均为 mm（同 $H$）✓。

**常见错误**：① 最优取 $u=0$（那是 $H\to\infty$）；② 漏 $A$ 项。

## 1-6【综合】PCA vs PLS

**对应正文**：1.4.2–1.4.3 节。

**标准答案要点**：

- **PCA 无监督**：只分解 $\mathbf X$，抓方差最大方向，不看 $\mathbf Y$（浓度/类别）；用于可视化、异常、去噪。
- **PLS 有监督**：联合分解 $\mathbf X$ 与 $\mathbf Y$，找协方差最大的潜变量，直接预测 $\mathbf Y$；需已知 $\mathbf Y$。
- **为何能处理 $p\gg n$**：PLS 把 $p$ 变量投影到少数潜变量（降维），避开了普通最小二乘 $(X^TX)^{-1}$ 在 $p>n$ 时奇异/共线不可求的问题。

**常见错误**：① 认为 PCA 能直接预测浓度（需标签）；② 把 PLS 当"普通 LS 加正则"忽略潜变量联合分解。

## 1-7【综合】过拟合与验证

**对应正文**：1.4.4 节。

**标准答案要点**：过拟合 = 模型在训练集"记住"噪声而致训练误差极小、预测误差大（变量多样本少时尤甚）。防范：① **交叉验证**（留一/K 折）——轮流留样验证估泛化误差；② **独立外部验证集**（训练时未用的样本）确认；③ 正则化/变量选择控制复杂度。仅看训练 $R^2$ 会乐观误判。

**常见错误**：① 用同批数据既训练又报性能；② 认为变量越多越好。

## 1-8【挑战】MS 分辨率

**对应正文**：1.2.3 节。

**完整解**：10% 谷分辨率 $R=m/\Delta m$。分辨 N₂⁺(28.006) 与 CO⁺(27.995) 需

$$R\ge\frac{28.006}{28.006-27.995}=\frac{28.006}{0.011}\approx\boxed{2546}$$

（即 $R$ 至少约 2500 才能分开质量差 0.011 的两离子）。**意义**：高分辨 MS（$R>10^5$）可区分等质量异素离子（如 CO/N₂、C₂H₄/N₂），直接给分子式——是结构鉴定的关键能力。

**常见错误**：① 用半高宽定义（IUPAC 用 10% 谷）；② 把 $\Delta m$ 当 1。
